## PageSettings class

يمثل إعدادات الطباعة لصفحة من عرض المشروع.

يعرض نوع PageSettings الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| PageSettings() | ينشئ مثيلًا جديدًا من الفئة [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            يمثل إعدادات الطباعة لصفحة من عرض المشروع. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_portrait | يحصل أو يضبط قيمة تشير إلى ما إذا كان اتجاه الصفحة عموديًا؛ يرجع false إذا كان اتجاه الصفحة أفقيًا. |
| adjust_to_percent_of_normal_size | يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب تعديل الطباعة إلى النسبة المئوية المحددة ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) من الحجم الطبيعي. |
| percent_of_normal_size | يحصل أو يعيّن نسبة مئوية من الحجم الطبيعي لتعديل الطباعة. |
| pages_in_width | يحصل أو يعيّن عدد الصفحات في العرض التي سيتم طباعتها. |
| pages_in_height | يحصل أو يعيّن عدد الصفحات في الارتفاع التي سيتم طباعتها. |
| paper_size | يحصل أو يعيّن حجم الورق. يمكن أن يكون أحد قيم تعداد [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | يحصل أو يعيّن عددًا صحيحًا يمثل أحد قيم PrinterPaperSize أو معرف حجم صفحة مخصص.<br/>            يمكن استخدام هذه القيمة للحصول على حجم الورق من إعدادات نظام التشغيل |
| first_page_number | يحصل أو يعيّن رقم الصفحة الأولى للطباعة. |
