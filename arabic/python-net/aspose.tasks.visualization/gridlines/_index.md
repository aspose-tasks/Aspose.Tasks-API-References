## Gridlines class

يمثل خطوط الشبكة التي تظهر في عرض مخطط جانت.

نوع Gridlines يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Gridlines() | ينشئ مثيلاً جديدًا من فئة Gridlines |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| interval | يحصل أو يضبط الرقم من 0 إلى 99 الذي يحدد الفاصل بين خطوط الشبكة. |
| interval_color | يحصل أو يضبط لون خطوط الشبكة الثانوية. |
| interval_pattern | يحصل أو يضبط نمط الخط لخطوط الشبكة الثانوية. |
| normal_color | يحصل أو يضبط لون خطوط الشبكة العادية. |
| normal_pattern | يحصل أو يضبط نمط الخط لخطوط الشبكة العادية. |
| نوع | يحصل أو يضبط نوع خط الشبكة. |
