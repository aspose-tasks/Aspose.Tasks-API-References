## PageViewSettings class

يمثل إعدادات الطباعة لعرض المشروع.

نوع PageViewSettings يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| PageViewSettings() | ينشئ مثيلاً جديدًا من فئة PageViewSettings |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| first_columns_count | يحصل أو يعيّن عدد الأعمدة الأولى التي سيتم طباعتها على جميع الصفحات. |
| fit_timescale_to_end_of_page | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب ملاءمة مقياس الوقت إلى نهاية الصفحة عند الطباعة. |
| print_all_sheet_columns | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب طباعة جميع أعمدة الورقة في العرض. |
| print_blank_pages | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب طباعة الصفحات الفارغة في العرض. |
| print_first_columns_count_on_all_pages | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب طباعة عدد محدد من الأعمدة الأولى على جميع الصفحات. |
| print_notes | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب طباعة الملاحظات. |
