## الخصائص
| الاسم | الوصف |
| :- | :- |
| count | يحصل أو يعيّن الفاصل الزمني لوحدة الوقت الذي تُظهر فيه التسميات للطبقة.<br/>            القيمة الافتراضية هي 1. |

| uses_fiscal_year | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب أن تستند تسميات الطبقة إلى السنة المالية. |
| show_ticks | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب إظهار علامات الفواصل التي تفصل الفترات الزمنية في الطبقة. |
| unit | يحصل أو يعيّن وحدة المقياس الزمني [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) للطبقة الزمنية.<br/>            القيمة الافتراضية هي |
| render_label_on_each_page | يحصل أو يعيّن العلامة التي تحدد ما إذا كان يجب عرض تسميات التاريخ على كل صفحة عندما تمتد فترة زمنية على عدة صفحات.<br/>            إذا كانت القيمة 'true'، عندما تمتد الفترة الزمنية على عدة صفحات، تُعرض تسميات التاريخ للفترة على كل صفحة.<br/>            إذا كانت القيمة 'false'، تُعرض تسمية التاريخ مرة واحدة فقط وفقاً لقيمة خاصية [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
