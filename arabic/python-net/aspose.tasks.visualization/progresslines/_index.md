## ProgressLines class

يمثل خطوط التقدم في عرض مخطط جانت.

يعرض نوع ProgressLines الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ProgressLines() | ينشئ مثيلاً جديداً من فئة ProgressLines |

| display_at_current_date | يحصل أو يضبط قيمة تشير إلى ما إذا كان سيتم عرض خط التقدم في التاريخ الحالي. |
| display_at_recurring_intervals | يحصل أو يضبط قيمة تشير إلى ما إذا كان سيتم عرض خط التقدم على فترات متكررة. |

| begin_at_date | يحصل أو يضبط التاريخ لعرض خطوط التقدم منه. |
| display_selected | يحصل أو يضبط قيمة تشير إلى ما إذا كان سيتم عرض خطوط التقدم في التواريخ المحددة. |
| is_baseline_plan | يحصل أو يضبط قيمة تشير إلى ما إذا كان سيتم عرض خطوط التقدم للخطة الأساسية أو الفعلية. |
