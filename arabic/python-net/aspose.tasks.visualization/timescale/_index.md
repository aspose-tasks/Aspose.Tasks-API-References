## Timescale enumeration

يحدد الخيارات التي تحدد كيفية عرض مقياس الزمن في مخطط جانت أو عروض استخدام المهمة أو استخدام الموارد عندما يتم تصدير المشروع إلى تنسيق رسومي.

## Members
| اسم العضو | الوصف |
| :- | :- |
| DEFINED_IN_VIEW | استخدم إعدادات مقياس الزمن المعرفة في خصائص عرض المشروع: [bottom_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/),<br/>            [middle_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/), [top_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/).<br/>            صالحة للتنسيقات التي تحتوي على بيانات العرض. على سبيل المثال، المشاريع التي تُقرأ من تنسيق MPP. |
| أيام | مقياس زمن مسبق التعريف بطبقتين حيث الحد الأدنى لتفصيل المعلومات هو يوم واحد. |
| THIRDS_OF_MONTHS | مقياس زمن مسبق التعريف بطبقتين حيث مستوى التفصيل هو ثلث الشهر. |
| شهور | مقياس زمن مسبق التعريف بطبقتين حيث الحد الأدنى لتفصيل المعلومات هو شهر واحد. |
