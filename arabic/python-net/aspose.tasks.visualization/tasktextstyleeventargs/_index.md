## TaskTextStyleEventArgs class

تمثل هذه الفئة مجموعة من البيانات المتعلقة بعملية عرض محتوى خلية الجدول.

نوع TaskTextStyleEventArgs يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| cell_text_style | يحصل أو يضبط TextStyle الذي سيُستخدم لرسم محتوى الخلية. يمكن استخدام هذا الكائن لتخصيص مظهر خلية الجدول. |
| task | يحصل على [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) الذي يتطابق مع الصف المُعرض حاليًا. |
| column | يحصل على [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) التي تنتمي إليها الخلية المُعرضة حاليًا. |
