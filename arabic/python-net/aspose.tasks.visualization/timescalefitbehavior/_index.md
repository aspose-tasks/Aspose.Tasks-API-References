## TimescaleFitBehavior enumeration

يمثل سلوكًا يُستخدم لمحاذاة منطقة مقياس الزمن مع عرض الصفحة.

## Members
| اسم العضو | الوصف |
| :- | :- |
| DEFINED_IN_VIEW | يتم عرض قسم التقويم وفقًا لخاصية View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage في العرض المعروض. |
| NO_SCALE_TO_END_DATE | يتم عرض قسم التقويم بدقة حتى EndDate، حتى وإن كان هناك مساحة فارغة في الصفحة. |
| NO_SCALE_TO_END_OF_PAGE | يتم عرض قسم التقويم إلى النهاية (الجانب الأيمن) من الصفحة الأخيرة.<br/>            وبالتالي قد يتجاوز تاريخ العرض الأخير EndDate. |
| SCALE_TO_END_OF_PAGE | سوف يحاول محرك العرض محاذاة التواريخ بحيث يكون EndDate محاذيًا مع النهاية (الجانب الأيمن) للصفحة الأخيرة.<br/>            يتوافق مع تمكين خيار "Page Setup \ View \ Fit timescale to end of page" في MS Project. |
