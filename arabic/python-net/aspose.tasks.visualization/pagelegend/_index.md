## PageLegend class

يمثل أسطورة الصفحة المستخدمة لطباعة المشروع.

يعرض نوع PageLegend الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| PageLegend() | يُنشئ مثيلاً جديدًا من الفئة PageLegend |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| left_text | يحصل أو يضبط النص المحاذى إلى اليسار لعرضه في العنصر الأصلي. |
| centered_text | يحصل أو يضبط النص المُوسَّط لعرضه في العنصر الأصلي. |
| right_text | يحصل أو يضبط النص المحاذى إلى اليمين لعرضه في العنصر الأصلي. |
| left_image | يحصل أو يضبط الصورة المحاذاة إلى اليسار لتُعرض في العن العنصر الأصلي. |
| centered_image | يحصل أو يضبط الصورة المُوسَّطة لتُعرض في العن العنصر الأصلي. |
| right_image | يحصل أو يضبط الصورة المحاذاة إلى اليمين لتُعرض في العنصر الأب. |
| left_image_size | يحصل أو يضبط الحجم المعروض للصورة اليسرى. |
| centered_image_size | يحصل أو يضبط الحجم المعروض للصورة المركزية. |
| right_image_size | يحصل أو يضبط الحجم المعروض للصورة اليمنى. |
| legend_on | يحصل أو يعيّن الصفحات التي يظهر فيها الأسطورة. يمكن أن تكون واحدة من قيم تعداد [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | يحصل أو يعيّن عرض الجزء الأيسر (الذي يحتوي على اسم المشروع والتاريخ افتراضيًا) من الأسطورة بالسنتيمتر. |
