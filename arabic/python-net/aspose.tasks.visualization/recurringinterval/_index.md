## RecurringInterval class

يمثل الفواصل المتكررة المستخدمة في خطوط التقدم في عرض مخطط جانت.

يعرض نوع RecurringInterval الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| RecurringInterval() | ينشئ مثيلاً جديدًا من الفئة RecurringInterval |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| interval | يحصل أو يضبط الفاصل المتكرر.<br/>            يمكن أن يكون أي قيمة من نوع [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | يحصل أو يضبط رقم اليوم اليومي. |
| daily_workday | يحصل أو يضبط قيمة تشير إلى ما إذا كان اليوم يوم عمل لخطوط التقدم اليومية. |
| weekly_week_number | يحصل أو يعيّن رقم الأسبوع لخطوط التقدم الأسبوعية. |
| monthly_day | يحصل أو يعيّن قيمة تشير إلى ما إذا كان سيتم عرض خطوط التقدم الشهرية حسب اليوم. |
| monthly_day_day_number | يحصل أو يعيّن رقم اليوم لخطوط التقدم الشهرية. |
| monthly_day_month_number | يحصل أو يعيّن رقم الشهر لخطوط التقدم الشهرية. |
| monthly_first_last | يحصل أو يعيّن قيمة تشير إلى ما إذا كان سيتم عرض خطوط التقدم حسب اليوم الأول أو الأخير المحدد مسبقًا. |
| monthly_first_last_month_number | يحصل أو يعيّن رقم الشهر لخطوط التقدم التي تُعرض حسب اليوم الأول أو الأخير المحدد مسبقًا. |
| monthly_first_last_day | يحصل أو يعيّن نوع اليوم الأول أو الأخير لخطوط التقدم الشهرية. |
| weekly_days | يحصل على قائمة بالأيام لخطوط التقدم الأسبوعية. |
