## RiskItemStatistics class

يعرض نوع RiskItemStatistics الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| item_type | يحصل على مثيل من تعداد [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/). |
| minimum | يحصل على القيمة الدنيا التي تم توليدها خلال محاكاة مونت كارلو. |
| maximum | يحصل على القيمة القصوى التي تم توليدها خلال محاكاة مونت كارلو. |
| expected_value | يحصل على القيمة المتوقعة لعنصر المخاطر. |
| standard_deviation | يحصل على الانحراف المعياري لعنصر المخاطر. |
