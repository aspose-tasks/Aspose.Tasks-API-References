## الخصائص
| الاسم | الوصف |
| :- | :- |
| start_date | يحصل أو يعيّن تاريخ بدء فترة التسوية. القيمة الافتراضية هي تاريخ بدء المشروع. |
| finish_date | يحصل أو يعيّن تاريخ انتهاء فترة التسوية. القيمة الافتراضية هي تاريخ انتهاء المشروع. |
| الموارد | يحصل أو يعيّن قائمة الموارد التي سيتم تسويتها. إذا تم تعيين null، سيتم تسوية جميع موارد المشروع. |
| leveling_order | يحصل على الترتيب الذي تقوم به خوارزمية التوازن بتأخير المهام التي لديها تخصيص مفرط.<br/>            بعد تحديد المهام التي تسبب التخصيص المفرط والمهام التي يمكن تأخيرها، يُستخدم الترتيب المحدد لتحديد أي مهمة يجب تأخيرها أولاً. |
| message_level | يحصل أو يضبط مستوى رسائل السجل التي تُصدرها Aspose.Tasks أثناء توازن الموارد. |
| message_handler | يحصل أو يضبط رد الاتصال لمعالج الرسائل الذي يمكن استخدامه لاعتراض رسائل السجل التي تنتجها Aspose.Tasks أثناء توازن الموارد. |
