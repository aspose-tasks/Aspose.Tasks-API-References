## MPPSaveOptions class

يسمح بتحديد خيارات إضافية عند حفظ بيانات المشروع إلى MPP.

يعرض نوع MPPSaveOptions الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| MPPSaveOptions() | ينشئ مثيلاً جديداً من الفئة [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| save_format | يحصل أو يعيّن الصيغة التي سيُحفظ بها المستند إذا تم استخدام كائن خيارات الحفظ هذا. |
| remove_invalid_assignments | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب إزالة تعيينات الموارد غير الصالحة عند الحفظ إلى MPP. |
| write_view_data | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب كتابة بيانات العرض عند حفظ المشروع بتنسيق MPP. |
| write_filters | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب كتابة بيانات الفلاتر عند حفظ المشروع إلى تنسيق MPP. |
| write_groups | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب كتابة بيانات المجموعات عند حفظ المشروع بتنسيق MPP. |
| clear_vba | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب إزالة بيانات ماكرو VBA الموجودة عند حفظ المشروع بتنسيق MPP. |
| write_vba | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب تحديث بيانات ماكرو VBA الموجودة في ملف MPP.<br/>            حالياً يتم دعم كتابة VbaModule.SourceCode. |
| protection_password | يحصل أو يعيّن كلمة مرور تُستخدم لحماية ملف MPP الناتج. حالياً يتم دعم ذلك لتنسيقات MS Project 2010 والأحدث. |
