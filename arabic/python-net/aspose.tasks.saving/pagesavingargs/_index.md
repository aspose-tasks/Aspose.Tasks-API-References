## PageSavingArgs class

تمثل هذه الفئة مجموعة من البيانات المتعلقة بحفظ صفحة المستند إلى تدفق.

يعرض نوع PageSavingArgs الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| page_number | يحصل على رقم الصفحة التي سيتم كتابتها. |
| keep_stream_open | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب على روتين العرض إبقاء [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) مفتوحًا بعد كتابة الصفحة. |
| stream | يحصل أو يعيّن تدفقًا لكتابة صفحة. |
