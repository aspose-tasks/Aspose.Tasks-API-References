## LegendDrawingOptions enumeration

## Members

| :- | :- |
| NO_LEGEND | لا يتم عرض أي أسطورة. |
| AFTER_LAST_PAGE | يتم عرض الأسطورة على صفحة منفصلة بعد الصفحة الأخيرة من صفحات المشروع. |
| ON_EVERY_PAGE | يتم عرض الأسطورة في كل صفحة. |
