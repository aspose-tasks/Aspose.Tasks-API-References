## CsvOptions class

يسمح بتحديد خيارات إضافية عند حفظ المشروع إلى CSV.

نوع CsvOptions يكشف عن الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| CsvOptions() | ينشئ مثيلًا جديدًا من الفئة [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) التي يمكن استخدامها لحفظ المشروع بصيغة CSV. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| save_format | يحصل أو يعيّن الصيغة التي سيُحفظ بها المستند إذا تم استخدام كائن خيارات الحفظ هذا. |
| data_category | يحصل أو يعيّن فئة بيانات ليتم حفظها. |
| الترميز | يحصل أو يعيّن ترميزًا لحفظ CSV به. |
| include_headers | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب تضمين رؤوس الأعمدة أم لا (القيمة الافتراضية هي TRUE). |
| text_delimiter | يحصل أو يعيّن محدد نص. |
| view | يحصل أو يعيّن قائمة بأعمدة العرض ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) لحفظها بصيغة XLSX.<br/>            إذا لم يتم تعيينها فسيتم حفظ الأعمدة الافتراضية. |
