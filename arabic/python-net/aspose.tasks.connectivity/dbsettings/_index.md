## DbSettings class

يسمح بتحديد الإعدادات للقراءة من قاعدة بيانات المشروع.

نوع DbSettings يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| connection_string | يحصل أو يضبط سلسلة الاتصال. |
| provider_invariant_name | يحصل أو يضبط اسم الموفر الثابت الذي يُستخدم للحصول على مثيل من الفئة. |
