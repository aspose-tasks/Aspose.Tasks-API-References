## MspDbSettings class

يسمح بتعيين الخيارات اللازمة لقراءة بيانات المشروع من قاعدة بيانات خادم MS Project.

نوع MspDbSettings يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | ينشئ مثيلًا جديدًا من الفئة [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| connection_string | يحصل أو يضبط سلسلة الاتصال. |
| provider_invariant_name | يحصل أو يضبط اسم الموفر الثابت الذي يُستخدم للحصول على مثيل من الفئة. |
| project_guid | يحصل على المعرف الفريد للمشروع للقراءة. |
| schema | يحصل أو يضبط مخطط خادم MS Project.<br/>            القيمة الافتراضية هي "pub". |
