## Value class

يمثّل قيمة في قائمة القيم.

نوع Value يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Value() | يُنشئ مثيلاً جديدًا من الفئة [Value](/tasks/python-net/aspose.tasks/value/). |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| id | يحصل أو يعيّن المعرف الفريد لقيمة عبر المشروع. |
| value_guid | يحصل على GUID يحدد هذه القيمة بين القيم الأخرى في المشروع بالكامل. |
| val | يحصل أو يعيّن القيمة الفعلية في التمثيل الداخلي. يفضّل استخدام الخصائص ذات النوع القوي المذكورة أدناه. |
| string_value | يحصل أو يعيّن القيمة الفعلية المستخدمة لتمثيل سلسلة النص. |
| numeric_value | يحصل أو يعيّن القيمة الفعلية المستخدمة لتمثيل رقم أو قيمة تكلفة. |
| duration | يحصل أو يعيّن القيمة الفعلية المستخدمة لتمثيل المدة. |
| date_time_value | يحصل أو يعيّن القيمة الفعلية إذا كان يمكن تمثيلها كـ DateTime. القيمة الافتراضية هي أصغر قيمة تاريخ. |
| description | يحصل أو يعيّن وصفًا لقيمة. |
| phonetic | يحصل أو يعيّن المعلومات الصوتية حول اسم الحقل المخصص. |
