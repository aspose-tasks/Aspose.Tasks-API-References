## OutlineValue class

يمثل قيمة مخطط تفصيلي.

يعرض نوع OutlineValue الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| OutlineValue() | ينشئ نسخة جديدة من فئة OutlineValue. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| value_id | يحصل أو يعيّن المعرف الفريد لقيمة رمز المخطط داخل المشروع. |
| value_guid | يحصل على GUID يحدد هذه القيمة بين القيم الأخرى في المشروع بالكامل. |
| نوع | الحصول أو تعيين نوع رمز المخطط. |
| parent_value_id | الحصول أو تعيين معرف العقدة الأم لرمز المخطط. |
| value | الحصول أو تعيين القيمة الفعلية. |
| duration_value | الحصول أو تعيين المدة إذا كان Type هو Duration. |
| description | الحصول أو تعيين وصف قيمة المخطط. |
| is_collapsed | الحصول أو تعيين قيمة تشير إلى ما إذا كانت قيمة المخطط مطوية أم لا. |
