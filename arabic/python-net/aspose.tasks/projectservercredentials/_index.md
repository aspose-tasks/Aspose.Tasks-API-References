## ProjectServerCredentials class

بيانات الاعتماد التي تُستخدم للاتصال بـ Project Online أو مثيل Project Server المحلي.

يعرض نوع ProjectServerCredentials الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | ينشئ مثلاً جديداً من الفئة [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) باستخدام عنوان URL لموقع SharePoint ورمز تفويض SPOIDCRL صالح لموقع PWA (الوصول إلى الويب للمشروع) الخاص بـ SharePoint. |
| ProjectServerCredentials(site_url, user_name, password) | ينشئ مثلاً جديداً من الفئة [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) باستخدام عنوان URL لموقع SharePoint ورمز تفويض SPOIDCRL صالح لموقع PWA (الوصول إلى الويب للمشروع) الخاص بـ SharePoint. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| site_url | يحصل على عنوان URL لـ PWA في موقع SharePoint أو عنوان URL لخادم المشروع المحلي.<br/>            على سبيل المثال، https://your_company_name.sharepoint.com/sites/pwa"; |
| auth_token | يحصل على رمز التفويض لمثيل SharePoint. |
| user_name | يحصل على اسم المستخدم لموقع SharePoint. |
