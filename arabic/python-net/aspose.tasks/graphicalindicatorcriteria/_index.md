## GraphicalIndicatorCriteria class

يمثل معيار مؤشر رسومي واحد مرتبط بصفة موسعة.

يعرض نوع GraphicalIndicatorCriteria الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | يقوم بإنشاء نسخة جديدة من فئة GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | يقوم بإنشاء نسخة جديدة من فئة GraphicalIndicatorCriteria |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| test | يحصل على نوع المقارنة التي تُجرى بين قيمة السمة الموسعة والقيم التي تعمل كمعيار لتطبيق المؤشر الرسومي.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | يحصل على القيمة المستخدمة لاختبار قيمة السمة الموسعة. |
| value2 | يحصل على القيمة الثانية المستخدمة لاختبار قيمة السمة الموسعة في حالة أنواع المقارنة 'IsWithin' و 'IsNotWithin'. |
| image_index | يحصل على فهرس الصورة التي سيتم عرضها عندما يفي الحقل بالمعايير. |
| row_type | يحصل على قيمة تعداد [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) الذي يحدد الصفوف التي يُطبق عليها المؤشر. |
