## ImageSavingArgs class

هذه الفئة تمثل مجموعة من البيانات المتعلقة بحفظ ملف الصورة الخارجي الذي<br/>                يحدث أثناء التحويل إلى تنسيق HTML.

يعرض نوع ImageSavingArgs الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ImageSavingArgs() | ينشئ مثيلًا جديدًا من فئة [ImageSavingArgs](/tasks/python-net/aspose.tasks/imagesavingargs/). |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| file_name | يحصل أو يعيّن اسم الملف المفترض الذي ينتقل من المحول إلى كود الطريقة المخصصة.<br/>             يمكن استخدامه في الكود المخصص لتحديد كيفية المعالجة أو مكان حفظ هذا الملف. |
| keep_stream_open | يحصل أو يعيّن قيمة تشير إلى ما إذا كان سيتم إبقاء الدفق مفتوحًا بعد انتهاء حفظ المورد. |
| stream | يحصل أو يعيّن المحتوى الثنائي للملف المحفوظ. |
| uri | يحصل أو يعيّن URI المورد. |
| image_type | يحصل على نوع صورة HTML. |
## الطرق
| الاسم | الوصف |
| :- | :- |
