## FilterCriteria class

يحدد المعايير التي يجب أن تفي بها المهام أو الموارد لتظهر في عرض MSP.

يعرض نوع FilterCriteria الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| FilterCriteria() | ينشئ مثيلاً جديداً من الفئة FilterCriteria |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| operation | يحصل أو يضبط المعيار المحدد بـ FieldName و Test و Value ويتعلق بمعايير أخرى في الفلتر. |
| field | يحصل أو يضبط [field](/tasks/python-net/aspose.tasks/filtercriteria/) للتغيير. |
| test | يحصل أو يضبط نوع المقارنة بين FieldName و Value والذي يعمل كمعيار اختيار للفلتر.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| values | يحصل على قيم الكائن للمقارنة مع قيمة الحقل المحدد بـ FieldName. |
| criteria_rows | يحصل على قائمة الصفوف الفرعية لـ [FilterCriteria](/tasks/python-net/aspose.tasks/filtercriteria/).<br/>            إذا كان الفلتر يحتوي على أكثر من صف معيار واحد، فإن تأثير عامل And هو أن المعايير لكلا الصفين يجب أن تتحقق لكي يتم عرض المهمة أو المورد نتيجة لهذا الفلتر.<br/>            تأثير عامل Or هو أن المعايير لصف واحد أو الآخر يجب أن تتحقق. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| is_field_value() | يحصل على ما إذا كانت القيمة اليمنى لـ FilterCriteria إشارة إلى حقل، وليس قيمة ثابتة. |
| set_value_field(value) | يضبط الحقل الذي ستُقارن قيمته مع قيمة الحقل المحدد بـ FieldName. |
