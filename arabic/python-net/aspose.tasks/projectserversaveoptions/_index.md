## ProjectServerSaveOptions class

يسمح بتحديد خيارات إضافية عندما يتم حفظ المشروع إلى Project Server أو Project Online.

يعرض نوع ProjectServerSaveOptions الأعضاء التالية:

| :- | :- |

## الخصائص
| الاسم | الوصف |
| :- | :- |
| project_name | يحصل أو يضبط اسم المشروع الذي يُعرض في قائمة مشاريع Project Server \ Project Online. يجب أن يكون فريداً داخل مثيل Project Server \ Project Online.<br/>            إذا تم حذف القيمة، سيتم استخدام قيمة الخاصية Prj.Name بدلاً منها. |
| project_guid | يحصل أو يضبط المعرف الفريد للمشروع. يجب أن يكون فريداً داخل مثيل Project Server \ Project Online. |
| timeout | يحصل أو يضبط مهلة الانتظار المستخدمة عند انتظار معالجة طلب حفظ المشروع بواسطة خدمة معالجة طابور Project Server. القيمة الافتراضية لهذه الخاصية هي دقيقة واحدة. |
| polling_interval | يحصل أو يضبط الفاصل الزمني بين طلبات حالة وظائف الطابور. القيمة الافتراضية هي ثانيتان. |
