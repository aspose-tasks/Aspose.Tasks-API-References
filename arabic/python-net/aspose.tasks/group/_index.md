## Group class

يمثل تعريف مجموعة.<br/>            كائن المجموعة هو عضو في مجموعة ResourceGroups أو مجموعة TaskGroups.

يعرض نوع Group الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Group() | يقوم بتهيئة نسخة جديدة من الفئة [Group](/tasks/python-net/aspose.tasks/group/). |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل أو يعيّن اسم كائن Group. |
| uid | يحصل على معرف فريد للمجموعة. |
| show_summary | يحصل أو يعيّن قيمة تشير إلى ما إذا كانت صفوف الملخص معروضة للمجموعة. |
| maintain_hierarchy | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب إظهار جميع مستويات مهام الملخص للمهام الفرعية داخل المجموعة. |
| show_in_menu | يحصل أو يعيّن قيمة تشير إلى ما إذا كان Project يعرض اسم المجموعة في القائمة المنسدلة Group في الشريط. |
| group_assignments | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب تجميع التعيينات بدلاً من المهام. |
| group_criteria | يحصل أو يعيّن مجموعة GroupCriteria تمثل الحقول في تعريف المجموعة. |
