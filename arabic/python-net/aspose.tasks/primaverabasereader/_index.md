## PrimaveraBaseReader class

يعرض نوع PrimaveraBaseReader الأعضاء التالية:
## الطرق
| الاسم | الوصف |
| :- | :- |
| get_project_uids() | إرجاع قائمة بمعرفات المشاريع الفريدة. |
| get_project_infos() | إرجاع قائمة بكائنات معلومات مختصرة للمشروع. |
