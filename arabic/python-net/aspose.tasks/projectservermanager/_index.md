## ProjectServerManager class

الفئة التي توفر الطرق لقراءة وتنفيذ العمليات على المشاريع في حساب Project Online المحدد أو<br/>            في مثيل Project Server المحلي المحدد (يتم دعم إصدارات Project Server 2016 و2019).

يعرض نوع ProjectServerManager الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ProjectServerManager(credentials) | يُنشئ مثيلًا جديدًا من الفئة [ProjectServerManager](/tasks/python-net/aspose.tasks/projectservermanager/). |
