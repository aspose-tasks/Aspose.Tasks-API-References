## PrimaveraTaskProperties class

يمثل خصائص خاصة بـ Primavera لمهمة تُقرأ من ملفات Primavera (XER أو P6XML).

يعرض نوع PrimaveraTaskProperties الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| sequence_number | يحصل أو يضبط رقم التسلسل لعنصر WBS (المهام الملخصة). يُستخدم لفرز المهام الملخصة في Primavera. |
| activity_id | يحصل على حقل معرف النشاط - معرف فريد للمهمة يستخدمه Primavera. |
| remaining_early_finish | يحصل على تاريخ الانتهاء المبكر المتبقي - التاريخ الذي من المقرر أن يكتمل فيه العمل المتبقي للنشاط. |
| remaining_early_start | يحصل على تاريخ البدء المبكر المتبقي - التاريخ الذي من المقرر أن يبدأ فيه العمل المتبقي للنشاط. |
| remaining_late_start | يحصل على تاريخ البدء المتأخر المتبقي. |
| remaining_late_finish | يحصل على تاريخ الانتهاء المتأخر المتبقي. |
| raw_duration_type | يحصل على تمثيل النص الخام (كما في ملف المصدر) لحقل 'Duration Type' للنشاط. |
| duration_type | يحصل على قيمة حقل 'Duration Type' للنشاط. |
| raw_activity_type | يحصل على تمثيل النص الخام (كما في ملف المصدر) لحقل 'Activity Type' للنشاط. |
| activity_type | يحصل على قيمة حقل 'Activity Type'. |
| percent_complete_type | يحصل على قيمة حقل '% Complete Type' للنشاط. |
| raw_complete_percent_type | يحصل على تمثيل النص الخام (كما في ملف المصدر) لحقل '% Complete Type' للنشاط. |
| raw_status | يحصل على تمثيل النص الخام (كما في ملف المصدر) لحقل 'Status' في النشاط. |
| physical_percent_complete | يحصل على قيمة النسبة المئوية للإنجاز الفعلي. |
| duration_percent_complete | يحصل على قيمة النسبة المئوية للإنجاز الزمني. |
| units_percent_complete | يحصل على قيمة النسبة المئوية للإنجاز بالوحدات. |
| actual_labor_units | يحصل على قيمة وحدات العمل الفعلية. |
| actual_non_labor_units | يحصل على قيمة وحدات غير العمل الفعلية. |
| remaining_labor_units | يحصل على قيمة وحدات العمل المتبقية. |
| remaining_non_labor_units | يحصل على قيمة وحدات غير العمل المتبقية. |
| actual_labor_cost | يحصل على قيمة تكلفة العمل الفعلية. |
| budgeted_labor_cost | يحصل على قيمة تكلفة العمل الموازنة (أو المخطط لها). |
| actual_nonlabor_cost | يحصل على قيمة تكلفة غير العمل الفعلية. |
| budgeted_nonlabor_cost | يحصل على قيمة تكلفة غير العمل الموازنة (أو المخطط لها). |
| actual_material_cost | يحصل على قيمة تكلفة المادة الفعلية. |
| budgeted_material_cost | يحصل على قيمة تكلفة المادة المخصصة (أو المخططة). |
| actual_expense_cost | يحصل على قيمة تكلفة النفقة الفعلية. |
| remaining_expense_cost | يحصل على قيمة تكلفة النفقة المتبقية. |
| budgeted_expense_cost | يحصل على قيمة تكلفة النفقة المخصصة (أو المخططة). |
| actual_total_cost | يحصل على القيمة الإجمالية للتكاليف الفعلية. |
| budgeted_total_cost | يحصل على القيمة الإجمالية للتكاليف المخصصة (أو المخططة). |
| primary_constraint_type | يحصل على نوع القيد الأساسي. |
| primary_constraint_date | يحصل على تاريخ القيد الأساسي. |
| secondary_constraint_type | يحصل على نوع القيد الثانوي. |
| secondary_constraint_date | يحصل على تاريخ القيد الثانوي. |
| planned_duration | يحصل على المدة الأصلية أو المخططة -- الوقت الإجمالي للعمل من تاريخ بدء المهمة المخطط إلى تاريخ الانتهاء المخطط.. |
