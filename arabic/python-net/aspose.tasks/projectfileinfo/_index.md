## ProjectFileInfo class

تحتوي مثيلة الفئة على معلومات حول تنسيق ملف المشروع وإصدار Microsoft Project حيث<br/>            تم إنشاء الملف.

يعرض نوع ProjectFileInfo الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| can_read | يحصل على قيمة تشير إلى ما إذا كان يمكن لـ Aspose.Tasks معالجة ملف المشروع. |
| is_password_protected | يحصل على قيمة تشير إلى ما إذا كان المشروع محميًا بكلمة مرور. |
| project_file_format | يحصل على تنسيق ملف المشروع. |
| project_application_info | يحصل على معلومات تطبيق ملف المشروع. |
