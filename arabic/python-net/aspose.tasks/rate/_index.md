## Rate class

يمثل تعريف فترة زمنية والأسعار المطبقة على مورد خلال تلك الفترة.

نوع Rate يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| rates_from | يحصل أو يعيّن التاريخ عندما يصبح السعر ساريًا. |
| rates_to | يحصل أو يعيّن التاريخ الأخير الذي يكون فيه السعر ساريًا. |
| rate_table | يحصل أو يعيّن المعرف الفريد لجدول الأسعار لمورد. |
| standard_rate | يحصل أو يعيّن السعر القياسي لكل ساعة لمورد. |
| standard_rate_format | يحصل أو يعيّن الوحدات التي يستخدمها Microsoft Project لعرض السعر القياسي. |
| overtime_rate | يحصل أو يعيّن سعر العمل الإضافي لكل ساعة لمورد. |
| overtime_rate_format | يحصل أو يعيّن الوحدات التي يستخدمها Microsoft Project لعرض سعر العمل الإضافي. |
| cost_per_use | يحصل أو يعيّن التكلفة لكل استخدام لمورد. يتم جلب هذه القيمة من التاريخ الحالي إذا كان هناك جدول أسعار للمورد. |
