## WeekDay class

يمثل يومًا من أيام الأسبوع يحدد إما الأيام العادية للأسبوع أو أيام الاستثناء في التقويم.

نوع WeekDay يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| WeekDay(day_type) | ينشئ مثلاً جديداً من الفئة [WeekDay](/tasks/python-net/aspose.tasks/weekday/) مع نوع اليوم المحدد. |
| WeekDay(day_type, working_times) | ينشئ مثلاً جديداً من فئة WeekDay |
| WeekDay(day_type, working_times) | ينشئ مثلاً جديداً من الفئة [WeekDay](/tasks/python-net/aspose.tasks/weekday/) مع نوع اليوم المحدد وفترات وقت العمل. |
| WeekDay() | ينشئ مثلاً جديداً من الفئة [WeekDay](/tasks/python-net/aspose.tasks/weekday/) مع نوع اليوم المحدد. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| day_type | يحصل على نوع اليوم. |
| day_working | يحصل أو يضبط قيمة تشير إلى ما إذا كان التاريخ المحدد أو نوع اليوم يعمل. |
| from_date | يحصل أو يضبط بداية وقت الاستثناء. |
| to_date | يحصل أو يضبط نهاية وقت الاستثناء. |
| working_times | يحصل على WorkingTimeCollection لهذا المثيل من WeekDay.<br/>            مجموعة أوقات العمل التي تحدد الوقت العامل في يوم الأسبوع. |
## الطرق

| :- | :- |
