## RecurringTaskInfo class

يمثل تفاصيل مهمة متكررة في مشروع.

نوع RecurringTaskInfo يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| recurrence_pattern | الحصول أو تعيين نمط تكرار للمهمة المتكررة. |
| start_date | الحصول أو تعيين التاريخ لبدء التكرارات. |
| end_date | الحصول أو تعيين التاريخ لنهاية التكرارات. |
| duration | الحصول أو تعيين المدة لحدوث واحد من المهمة المتكررة. |
| occurrences | الحصول أو تعيين عدد التكرارات للمهمة المتكررة. |
| use_end_date | الحصول أو تعيين قيمة تشير إلى ما إذا كان يجب استخدام تاريخ الانتهاء أو عدد التكرارات للمهمة المتكررة. |
| daily_repetitions | الحصول أو تعيين عدد التكرارات لنمط التكرار اليومي. |
| daily_use_workdays | يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب استخدام أيام العمل لنمط التكرار اليومي. |
| weekly_repetitions | يحصل أو يضبط عدد التكرارات لنمط التكرار الأسبوعي. |
| weekly_days | يحصل أو يضبط مجموعة الأيام المستخدمة في نمط التكرار الأسبوعي. |
| monthly_use_ordinal_day | يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب استخدام اليوم الترتيبي لنمط التكرار الشهري. |
| monthly_ordinal_number | يحصل أو يضبط رقمًا ترتيبيًا لنمط التكرار الشهري. |
| monthly_ordinal_repetitions | يحصل أو يضبط عدد التكرارات لنمط التكرار الشهري عند استخدام اليوم الترتيبي. |
| monthly_day | يحصل أو يضبط عدد الأيام لنمط التكرار الشهري. |
| monthly_repetitions | يحصل أو يضبط عدد التكرارات لنمط التكرار الشهري. |
| yearly_use_ordinal_day | يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب استخدام اليوم الترتيبي لنمط التكرار السنوي. |
| yearly_date | يحصل أو يضبط تاريخًا لنمط التكرار السنوي. |
| yearly_ordinal_number | يحصل أو يضبط رقمًا ترتيبيًا لنمط التكرار السنوي. |
| yearly_ordinal_month | يحصل أو يضبط شهرًا لنمط التكرار السنوي عند استخدام اليوم الترتيبي. |
| task | يحصل على مهمة الأصل لهذه المثيل من الفئة [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
