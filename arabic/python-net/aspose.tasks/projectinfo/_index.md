## ProjectInfo class

معلومات مختصرة حول المشروع المنشور المتاح على Project Online.

يعرض نوع ProjectInfo الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ProjectInfo() | ينشئ مثالًا جديدًا من الفئة [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/). |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| id | يحصل على المعرف الفريد للمشروع. |
| name | يحصل على اسم المشروع. |
| created_date | يحصل على التاريخ والوقت عندما تم إنشاء المشروع. |
| is_checked_out | يحصل على قيمة تشير إلى ما إذا كان المشروع مُستعارًا. |
| last_published_date | يحصل على أحدث تاريخ تم فيه نشر المشروع. |
| last_saved_date | يحصل على أحدث تاريخ تم فيه حفظ المشروع. |
| description | يحصل على وصف المشروع. |
