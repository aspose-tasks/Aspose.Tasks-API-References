## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل أو يعيّن اسم كائن Table. |
| show_in_menu | يحصل أو يعيّن قيمة تشير إلى ما إذا كان المشروع يعرض اسم الجدول في القائمة المنسدلة Tables في علامة التبويب View على الشريط. |
| table_fields | يحصل على مجموعة TableFields التي تمثل الحقول في الجدول. |
| table_type | يحصل أو يعيّن نوع الجدول للجدول المحدد. |
| uid | يحصل على المعرف الفريد للجدول. |
| row_height | يحصل أو يعيّن ارتفاع الصف في جدول، حيث أن ارتفاع الصف هو عدد أسطر النص. |
| date_format | يحصل أو يعيّن تنسيق التاريخ للجدول. |
| adjust_header_row_height | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يمكن تعديل ارتفاع صف الرأس في الجدول. |
| show_add_new_column | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب إظهار واجهة 'Add New Column'. |
| lock_first_column | يحصل أو يعيّن قيمة تشير إلى ما إذا كان العمود الأول في جدول مقفلاً أو قابلاً للتحرير. |
