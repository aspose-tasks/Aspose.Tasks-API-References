## FontResolveEventArgs class

يوفر الوسائط للنداء العكسي الذي يتم استدعاؤه عند حل الخط.

يعرض نوع FontResolveEventArgs الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| requested_font_name | يحصل على اسم الخط المطلوب. |
| resolved_font_name | يحصل أو يعيّن اسم الخط المحلول. يمكن تعيينه للتحكم في الخطوط المستخدمة لعرض المشهد. |
