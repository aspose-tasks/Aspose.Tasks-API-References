## PrimaveraProjectInfo class

يمثل معلومات مختصرة عن مشروع تم تحميله من تنسيق Primavera.

نوع PrimaveraProjectInfo يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| uid | يحصل على Uid للمشروع. |
| name | يحصل على اسم المشروع. |
| short_name | يحصل على الاسم المختصر للمشروع (معرف المشروع). |
| export_flag | يحصل على علامة تصدير المشروع. عندما يتم اختيار مشروع للتصدير في Primavera، تكون قيمة ExportFlag الخاصة به true.<br/>            قد يتم تصدير بعض المشاريع التي لم يتم اختيارها صراحةً للتصدير إلى ملف XER بسبب ارتباطها بالمشروع المُصدَّر. |
