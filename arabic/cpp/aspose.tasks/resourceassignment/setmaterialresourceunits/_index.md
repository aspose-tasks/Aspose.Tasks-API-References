## SetMaterialResourceUnits {#setmaterialresourceunits}

يضبط الوحدات لتعيين مورد مادي باستهلاك مادي متغير. يعني الاستهلاك المادي المتغير أنه كلما تغيرت مدة التعيين، تتغير كمية المواد المستخدمة بشكل متناسب.

**Returns:** void Aspose::Tasks::

```cpp
SetMaterialResourceUnits(double units, RateScaleType rateScaleType)
```

| معامل | الوصف |
| --- | --- |
| الوحدات | عدد الوحدات المتراكمة خلال الفترة الزمنية. |
| rateScaleType | الفترة الزمنية التي تُتراكم فيها قيمة الوحدة. |
