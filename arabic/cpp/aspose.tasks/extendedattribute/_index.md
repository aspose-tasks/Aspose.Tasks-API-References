## ExtendedAttribute class

يمثل السمات الموسعة.

حاليًا يتم دعم جميع أنواع السمات الموسعة للقراءة من MSP Xml 2003/2007 و mpp 2003. بالنسبة إلى MSP mpp 2007 يتم دعم قراءة جميع السمات الموسعة باستثناء الفترات والعلامات.
