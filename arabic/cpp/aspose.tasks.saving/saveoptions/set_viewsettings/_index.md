## set_ViewSettings {#set_viewsettings}

يضبط عرضًا (View) للعرض. يمكنك استخدام هذا الخيار لتحديد بشكل صريح أي عرض يجب حفظه بصيغ PDF أو HTML أو Image. إذا تم ضبط هذه الخاصية، يتم تجاهل خاصية Visualization::PresentationFormat عند حفظ المشروع. يجب أن يكون العرض من إحدى الشاشات التالية ((Aspose::Tasks::View::Screen)): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage).
