## Aspose::Tasks::Connectivity namespace

استخدم هذه الأنواع لتكوين الاتصالات بقاعدة بيانات خادم Microsoft Project (MspDbSettings)، وقواعد بيانات Primavera (PrimaveraDbSettings)، وملفات MPD (MpdSettings)، أو مصادر قواعد البيانات العامة (DbSettings). تُركز مساحة الاسم على تكوين الاتصال لتكامل سلس مع ميزات استخراج ومعالجة بيانات Aspose.Tasks.
