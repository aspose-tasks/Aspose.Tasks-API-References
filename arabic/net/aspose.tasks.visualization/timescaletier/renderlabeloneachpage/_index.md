## TimescaleTier.RenderLabelOnEachPage property

يحصل أو يضبط علامة تحدد ما إذا كان يجب عرض تسميات التاريخ على كل صفحة عندما تمتد فترة زمنية على عدة صفحات. إذا كانت القيمة 'true'، عندما تمتد الفترة الزمنية على عدة صفحات، يتم عرض تسميات التاريخ للفترة على كل صفحة. إذا كانت القيمة 'false'، يتم عرض تسمية التاريخ مرة واحدة فقط وفقًا لقيمة خاصية [`Alignment`](../alignment/).

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
