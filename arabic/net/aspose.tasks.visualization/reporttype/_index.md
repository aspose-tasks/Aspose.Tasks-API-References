## ReportType enumeration

نوع التقرير الرسومي للمشروع.

```csharp
public enum ReportType
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| ProjectOverview | `0` | يعرض تاريخ بدء وانتهاء المشروع، نسبة المدة المكتملة، نسبة الإنجاز للمهام العليا والمعالم القادمة. |
| CostOverview | `1` | يعرض تواريخ بدء وانتهاء المشروع، التكلفة المجدولة الحالية والمتبقية، نسبة الإنجاز وقيم التكلفة للمهام العليا. |
| WorkOverview | `2` | يعرض الخط الأساسي، الفعلي، والعمل المتبقي لكل مهمة عليا والعمل للموارد العاملة. |
| ResourceOverview | `3` | يعرض الخط الأساسي، الفعلي، والعمل المتبقي حسب المورد. |
| ResourceCostOverview | `4` | يعرض الخط الأساسي، الفعلي، والتكلفة المتبقية حسب المورد. |
| CriticalTasks | `5` | يعرض مهام المشروع الحرجة. |
| LateTasks | `6` | يعرض مهام المشروع المتأخرة. |
| Milestones | `7` | يعرض المعالم المتأخرة، القادمة والمكتملة. |
| UpcomingTask | `8` | يعرض المهام المستحقة خلال الأسبوع الحالي والمهام التي تبدأ خلال الأسبوع الحالي. |
| CostOverruns | `9` | يعرض تباين التكلفة حسب المهمة والمورد. |
| TaskCostOverview | `10` | يعرض الخط الأساسي، الفعلي، والتكلفة المتبقية لجميع المهام العليا. |
| OverallocatedResources | `11` | يعرض عدد ساعات العمل المتبقية للموارد المفرطة التخصيص. |
| SlippingTasks | `12` | يعرض المهام التي من المقرر أن تنتهي بعد تواريخ الانتهاء الخطية (يجب ضبط الخط الأساسي). |
| BestPracticeAnalyzer | `13` | يعرض المهام التي لا عمل فعلي لها، المهام غير المعينة، المهام ذات المدة أقل من 8 ساعات والملخصات المعينة للموارد. |
| Burndown | `14` | يتضمن مخططات انخفاض العمل ومهام الانخفاض. يُظهر مخطط انخفاض العمل مقدار العمل الذي أنجزه الأشخاص، مقدار ما هو مجدول للانتهاء قبل تاريخ انتهاء المشروع، وتقدير الخط الأساسي لمقدار العمل الذي سيُكمل في هذه المرحلة من المشروع. يُظهر مخطط انخفاض المهام عدد المهام المنجزة، العدد المتبقي، وتقدير الخط الأساسي لعدد المهام التي ستُنجز في هذه المرحلة من المشروع. |
| CashFlow | `15` | يعرض التكاليف والتكاليف التراكمية لكل ربع سنة لجميع المهام العليا. |

## الأمثلة

يعرض كيفية حفظ تقرير إنخفاض المشروع بصيغة PDF إلى الدفق المحدد.

```csharp
var project = new Project(DataDir + @"Homemoveplan.mpp");
using (var stream = new FileStream(OutDir + "Burndown_out.pdf", FileMode.Create))
{
    project.SaveReport(stream, ReportType.Burndown);
}
```
