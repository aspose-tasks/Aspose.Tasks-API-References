## PdfSaveOptions.UseProjectDefaultFont property

يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب استخدام الخط الافتراضي للتصيير.

```csharp
public bool UseProjectDefaultFont { get; set; }
```

### ملاحظات

عندما تكون القيمة False ويتم تحديد DefaultFontName، سيستخدم محرك العرض الخط المحدد بواسطة DefaultFontName كخط احتياطي. وإلا سيتم استخدام الخط 'Arial' (إذا كان مثبتًا) أو خطوط 'Generic Sans Serif' كخط احتياطي. يُستخدم الخط الاحتياطي أثناء عرض مشروع العرض عندما يشير نمط النص إلى خط غير مثبت على نظام التشغيل الحالي. للحصول على تحكم أكبر في حل الخطوط يمكنك استخدام الدالة الراجعة [`FontResolveCallback`](../fontresolvecallback).

### الأمثلة

يوضح كيفية تعيين خط مخصص سيُستخدم لطباعة ملف PDF الناتج.

```csharp
var project = new Project(DataDir + "EstimatedMilestoneTasks.mpp");

var options = new PdfSaveOptions
                  {
                      PresentationFormat = PresentationFormat.GanttChart, FitContent = true, UseProjectDefaultFont = false, DefaultFontName = "Segoe UI Black"
                  };
project.Save(OutDir + "CreateProject2_out.pdf", options);
```
