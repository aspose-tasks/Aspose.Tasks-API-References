## PrimaveraReadOptions.ReadBaselineProjects property

يحصل أو يضبط علامة تحدد ما إذا كان يجب تحميل مشاريع الخط الأساسي. القيمة الافتراضية هي true.

```csharp
public bool ReadBaselineProjects { get; set; }
```

## ملاحظات

العلامة تنطبق على ملفات Primavera XML التي تحتوي على مشاريع الخط الأساسي (الخطوط الأساسية غير مدعومة في تنسيق XER). يمكن تعيين الخيار إلى false لتسريع تحميل مشروع كبير يحتوي على خطوط أساسية عندما لا تكون بيانات الخط الأساسي مطلوبة.
