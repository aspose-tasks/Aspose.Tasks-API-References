## ITextStyleModificationCallback class

Rappresenta un callback che viene chiamato prima che TextStyle venga applicato a una cella della tabella.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [BeforeTaskTextStyleApplied](./beforetasktextstyleapplied/) | Il metodo da chiamare prima del rendering di una cella della tabella per una riga di attività nelle seguenti visualizzazioni: 'Gantt Chart', ' Task Sheet', ' Task Usage'. |
