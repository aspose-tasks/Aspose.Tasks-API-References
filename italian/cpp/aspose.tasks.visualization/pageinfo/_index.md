## PageInfo class

Rappresenta i dati di configurazione della pagina presenti nel formato file MPP e utilizzati per la stampa.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [PageInfo](./pageinfo/) | Inizializza una nuova istanza della classe PageInfo. Rappresenta i dati di configurazione della pagina presenti nel formato file MPP e utilizzati per la stampa. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Footer](./get_footer/) | Ottiene un'istanza della classe HeaderFooterInfo che rappresenta i dati del piè di pagina. |
| [get_Header](./get_header/) | Ottiene l'istanza della classe HeaderFooterInfo che rappresenta i dati dell'intestazione. |
| [get_Legend](./get_legend/) | Ottiene un'istanza della classe PageLegend che specifica le opzioni di rendering della legenda della pagina. |
| [get_Margins](./get_margins/) | Ottiene un'istanza della classe PageMargins che specifica i margini della pagina. |
| [get_Name](./get_name/) | Ottiene il nome della vista per la quale vengono utilizzati i dati di configurazione. |
| [get_PageSettings](./get_pagesettings/) | Ottiene un'istanza della classe PageSettings che specifica le impostazioni di stampa della pagina. |
| [get_PageViewSettings](./get_pageviewsettings/) | Ottiene un'istanza della classe PageViewSettings che specifica le impostazioni di stampa della vista della pagina. |
| [set_Footer](./set_footer/) | Imposta un'istanza della classe HeaderFooterInfo che rappresenta i dati del piè di pagina. |
| [set_Header](./set_header/) | Imposta l'istanza della classe HeaderFooterInfo che rappresenta i dati dell'intestazione. |
| [set_Legend](./set_legend/) | Imposta un'istanza della classe PageLegend che specifica le opzioni di rendering della legenda della pagina. |
