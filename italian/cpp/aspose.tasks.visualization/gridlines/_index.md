## Gridlines class

Rappresenta le linee della griglia che appaiono in una visualizzazione GanttChart.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Interval](./get_interval/) | Restituisce il numero da 0 a 99 che specifica l'intervallo tra le linee della griglia. |
| [get_IntervalColor](./get_intervalcolor/) | Restituisce il colore delle linee della griglia secondarie. |
| [get_IntervalPattern](./get_intervalpattern/) | Restituisce il modello di linea per le linee della griglia secondarie. |
| [get_NormalColor](./get_normalcolor/) | Restituisce il colore delle linee della griglia normali. |
| [get_NormalPattern](./get_normalpattern/) | Restituisce il modello di linea per le linee della griglia normali. |
| [get_Type](./get_type/) | Restituisce il tipo di linea della griglia. |
| [set_Interval](./set_interval/) | Imposta il numero da 0 a 99 che specifica l'intervallo tra le linee della griglia. |
| [set_IntervalColor](./set_intervalcolor/) | Imposta il colore delle linee della griglia secondarie. |
| [set_IntervalPattern](./set_intervalpattern/) | Imposta il modello di linea per le linee della griglia secondarie. |
| [set_NormalColor](./set_normalcolor/) | Imposta il colore delle linee della griglia normali. |
| [set_NormalPattern](./set_normalpattern/) | Imposta il modello di linea per le linee della griglia normali. |
| [set_Type](./set_type/) | Imposta il tipo di linea della griglia. |
