## TaskTextStyleEventArgs class

Questa classe rappresenta un insieme di dati relativi al rendering del contenuto della cella della tabella.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | Ottiene TextStyle che verrà utilizzato per disegnare il contenuto della cella. Questo oggetto può essere usato per personalizzare l'aspetto di una cella della tabella. |
| [get_Column](./get_column/) | Ottiene ViewColumn a cui appartiene la cella attualmente renderizzata. |
| [get_Task](./get_task/) | Ottiene Task che corrisponde alla riga attualmente renderizzata. |
| [set_CellTextStyle](./set_celltextstyle/) | Imposta TextStyle che verrà utilizzato per disegnare il contenuto della cella. Questo oggetto può essere usato per personalizzare l'aspetto di una cella della tabella. |
