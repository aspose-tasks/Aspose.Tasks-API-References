## TimescaleTier class

Rappresenta un unico livello della scala temporale su un Gantt Chart.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [TimescaleTier (2 overloads)](./timescaletier/) | Inizializza una nuova istanza della classe TimescaleTier. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Alignment](./get_alignment/) | Ottiene come allineare le etichette all'interno di ogni periodo di tempo del livello ( HorizontalStringAlignment ). |
| [get_Count](./get_count/) | Ottiene l'intervallo dell'unità di tempo in cui mostrare le etichette per il livello. Il valore predefinito è 1. |
| [get_DateTimeConverter](./get_datetimeconverter/) | Ottiene una funzione di callback per gestire il rendering del tick di data in questo livello. |
| [get_Label](./get_label/) | Ottiene l'etichetta di data DateLabel per il livello della scala temporale. |
| [get_RenderLabelOnEachPage](./get_renderlabeloneachpage/) | Ottiene il flag che definisce se le etichette di data devono essere renderizzate su ogni pagina quando un periodo di tempo si estende su più pagine. Se il valore è 'true', quando il periodo di tempo si estende su più pagine, le etichette di data per il periodo vengono renderizzate su ogni pagina. Se il valore è 'false', l'etichetta di data viene renderizzata una sola volta in base al valore della proprietà Alignment. |
| [get_ShowTicks](./get_showticks/) | Ottiene un valore che indica se mostrare i segni di spunta che separano i periodi di tempo nel livello. |
| [get_Unit](./get_unit/) | Ottiene l'unità di scala temporale TimescaleUnit per il livello della scala temporale. Il valore predefinito è Days. |
| [get_UsesFiscalYear](./get_usesfiscalyear/) | Ottiene un valore che indica se basare le etichette del livello sull'anno fiscale. |
