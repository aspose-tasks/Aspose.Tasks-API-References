## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Columns](./get_columns/) | Restituisce le colonne della vista del progetto. |
| [GetDefaultAssignmentView](./getdefaultassignmentview/) | Include le colonne Uid, nome attività, nome risorsa, lavoro e durata dell'assegnazione. |
| [GetDefaultGanttChartView](./getdefaultganttchartview/) | Include le colonne id, indicatori, nome, durata, inizio e fine dell'attività. |
| [GetDefaultResourceSheetView](./getdefaultresourcesheetview/) | Include le colonne Uid, nome risorsa, tipo, etichetta materiale, iniziali, gruppo, unità massime, tariffa standard, tariffa straordinaria, costo per utilizzo, accumulo a, calendario base e codice risorsa. |
| [GetDefaultResourceUsageView](./getdefaultresourceusageview/) | Include le colonne Uid, nome, inizio, fine e lavoro della risorsa. |
| [GetDefaultTaskSheetView](./getdefaulttasksheetview/) | Include id, indicatori, nome, durata, inizio, fine, predecessori e nomi delle risorse nelle colonne attività. |
