## RecurringInterval class

Rappresenta gli intervalli ricorrenti usati nelle linee di avanzamento di una visualizzazione Gantt Chart.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [DayType](./daytype/) | Rappresenta un tipo di giorno utilizzato nelle linee di avanzamento. |
| [get_DailyDayNumber](./get_dailydaynumber/) | Restituisce il numero giornaliero. |
| [get_DailyWorkday](./get_dailyworkday/) | Restituisce un valore che indica se un giorno è lavorativo per le linee di avanzamento giornaliere. |
| [get_Interval](./get_interval/) | Restituisce l'intervallo ricorrente. Può essere qualsiasi valore del tipo Interval. |
| [get_MonthlyDay](./get_monthlyday/) | Ottiene un valore che indica se visualizzare le linee di avanzamento mensili per giorno. |
| [get_MonthlyDayDayNumber](./get_monthlydaydaynumber/) | Ottiene il numero del giorno delle linee di avanzamento mensili. |
| [get_MonthlyDayMonthNumber](./get_monthlydaymonthnumber/) | Ottiene il numero del mese delle linee di avanzamento mensili. |
| [get_MonthlyFirstLast](./get_monthlyfirstlast/) | Ottiene un valore che indica se visualizzare le linee di avanzamento per il primo o l'ultimo giorno predefinito. |
| [get_MonthlyFirstLastDay](./get_monthlyfirstlastday/) | Ottiene il tipo di giorno, primo o ultimo, delle linee di avanzamento mensili. |
| [get_MonthlyFirstLastMonthNumber](./get_monthlyfirstlastmonthnumber/) | Ottiene il numero del mese delle linee di avanzamento, visualizzate per il primo o l'ultimo giorno predefinito. |
| [get_WeeklyDays](./get_weeklydays/) | Ottiene un elenco di giorni per le linee di avanzamento settimanali. |
| [get_WeeklyWeekNumber](./get_weeklyweeknumber/) | Ottiene il numero della settimana per le linee di avanzamento settimanali. |
| [set_DailyDayNumber](./set_dailydaynumber/) | Imposta il numero del giorno giornaliero. |
| [set_DailyWorkday](./set_dailyworkday/) | Imposta un valore che indica se un giorno è lavorativo per le linee di avanzamento giornaliere. |
| [set_Interval](./set_interval/) | Imposta l'intervallo ricorrente. Può essere qualsiasi valore del tipo Interval. |
| [set_MonthlyDay](./set_monthlyday/) | Imposta un valore che indica se visualizzare le linee di avanzamento mensili per giorno. |
| [set_MonthlyDayDayNumber](./set_monthlydaydaynumber/) | Imposta il numero del giorno delle linee di avanzamento mensili. |
| [set_MonthlyDayMonthNumber](./set_monthlydaymonthnumber/) | Imposta il numero del mese delle linee di avanzamento mensili. |
| [set_MonthlyFirstLast](./set_monthlyfirstlast/) | Imposta un valore che indica se visualizzare le linee di avanzamento per il primo o l'ultimo giorno predefinito. |
| [set_MonthlyFirstLastDay](./set_monthlyfirstlastday/) | Imposta il tipo di giorno, primo o ultimo, delle linee di avanzamento mensili. |
| [set_MonthlyFirstLastMonthNumber](./set_monthlyfirstlastmonthnumber/) | Imposta il numero del mese delle linee di avanzamento, visualizzate per il primo o l'ultimo giorno predefinito. |
| [set_WeeklyWeekNumber](./set_weeklyweeknumber/) | Imposta il numero della settimana per le linee di avanzamento settimanali. |
