## PageSettings class

Rappresenta le impostazioni di stampa per una pagina della visualizzazione del progetto.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [PageSettings](./pagesettings/) | Inizializza una nuova istanza della classe PageSettings. Rappresenta le impostazioni di stampa per una pagina della visualizzazione del progetto. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | Restituisce un valore che indica se regolare la stampa alla percentuale specificata ( PercentOfNormalSize ) della dimensione normale. |
| [get_FirstPageNumber](./get_firstpagenumber/) | Restituisce il numero della prima pagina per la stampa. |
| [get_IsPortrait](./get_isportrait/) | Restituisce un valore che indica se l'orientamento della pagina è verticale; restituisce false se l'orientamento della pagina è orizzontale. |
| [get_PagesInHeight](./get_pagesinheight/) | Restituisce il numero di pagine in altezza da stampare. |
| [get_PagesInWidth](./get_pagesinwidth/) | Ottiene un numero di pagine in larghezza da stampare. |
| [get_PaperSize](./get_papersize/) | Ottiene una dimensione della carta. Può essere uno dei valori dell'enumerazione PrinterPaperSize. |
| [get_PaperSizeId](./get_papersizeid/) | Ottiene un intero che rappresenta uno dei valori di PrinterPaperSize o un ID di dimensione pagina personalizzata. Questo valore può essere usato per ottenere PaperSize dalle impostazioni del sistema operativo |
| [get_PercentOfNormalSize](./get_percentofnormalsize/) | Ottiene una percentuale della dimensione normale a cui regolare la stampa. |
| [set_AdjustToPercentOfNormalSize](./set_adjusttopercentofnormalsize/) | Imposta un valore che indica se regolare la stampa alla percentuale specificata ( PercentOfNormalSize ) della dimensione normale. |
| [set_FirstPageNumber](./set_firstpagenumber/) | Imposta il numero della prima pagina per la stampa. |
| [set_IsPortrait](./set_isportrait/) | Imposta un valore che indica se l'orientamento della pagina è verticale; restituisce false se l'orientamento della pagina è orizzontale. |
| [set_PagesInHeight](./set_pagesinheight/) | Imposta un numero di pagine in altezza da stampare. |
| [set_PagesInWidth](./set_pagesinwidth/) | Imposta un numero di pagine in larghezza da stampare. |
| [set_PaperSize](./set_papersize/) | Imposta una dimensione della carta. Può essere uno dei valori dell'enumerazione PrinterPaperSize. |
| [set_PaperSizeId](./set_papersizeid/) | Imposta un intero che rappresenta uno dei valori di PrinterPaperSize o un ID di dimensione pagina personalizzata. Questo valore può essere usato per ottenere PaperSize dalle impostazioni del sistema operativo |
| [set_PercentOfNormalSize](./set_percentofnormalsize/) | Imposta una percentuale della dimensione normale a cui regolare la stampa. |
