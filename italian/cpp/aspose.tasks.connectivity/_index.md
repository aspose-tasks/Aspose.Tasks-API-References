## Aspose::Tasks::Connectivity namespace

Utilizza questi tipi per configurare connessioni a database Microsoft Project Server (MspDbSettings), database Primavera (PrimaveraDbSettings), file MPD (MpdSettings) o sorgenti di database generici (DbSettings). Lo spazio dei nomi centralizza la configurazione della connettività per un'integrazione fluida con le funzionalità di estrazione e manipolazione dei dati di Aspose.Tasks.


## Classi

| Nome | Descrizione |
| --- | --- |
| [DbSettings](./dbsettings/) | Consente di specificare le impostazioni per leggere dal database del progetto. |
| [MpdSettings](./mpdsettings/) | Consente di impostare le opzioni necessarie per leggere i dati del progetto dal formato MPD (MS Access |
| [MspDbSettings](./mspdbsettings/) | Consente di impostare le opzioni necessarie per leggere i dati del progetto dai dati di MS Project Server |
| [PrimaveraDbSettings](./primaveradbsettings/) | Consente di impostare le opzioni necessarie per leggere i dati del progetto dal database Primavera. |
