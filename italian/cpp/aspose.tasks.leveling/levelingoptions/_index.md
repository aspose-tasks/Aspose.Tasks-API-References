## LevelingOptions class

Consente di specificare i parametri del livellamento delle risorse.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Inizializza una nuova istanza della classe LevelingOptions. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_FinishDate](./get_finishdate/) | Restituisce la data di fine del periodo di livellamento. Il valore predefinito è la data di fine del progetto. |
| [get_LevelingOrder](./get_levelingorder/) | Restituisce l'ordine con cui l'algoritmo di livellamento ritarda le attività che hanno sovrallocazioni. Dopo aver determinato le attività che causano la sovrallocazione e quali attività possono essere ritardate, viene utilizzato l'ordine specificato per stabilire quale attività deve essere ritardata per prima. |
| [get_MessageHandler](./get_messagehandler/) | Restituisce la callback del gestore dei messaggi che può essere utilizzata per intercettare i messaggi di log prodotti da Aspose.Tasks durante il livellamento delle risorse. |
| [get_MessageLevel](./get_messagelevel/) | Restituisce il livello dei messaggi di log emessi da Aspose.Tasks durante il livellamento delle risorse. |
| [get_Resources](./get_resources/) | Restituisce l'elenco delle risorse che saranno livellate. Se viene impostato null, tutte le risorse del progetto saranno livellate. |
| [get_StartDate](./get_startdate/) | Restituisce la data di inizio del periodo di livellamento. Il valore predefinito è la data di inizio del progetto. |
| [set_FinishDate](./set_finishdate/) | Imposta la data di fine del periodo di livellamento. Il valore predefinito è la data di fine del progetto. |
| [set_LevelingOrder](./set_levelingorder/) | Restituisce l'ordine con cui l'algoritmo di livellamento ritarda le attività che hanno sovrallocazioni. Dopo aver determinato le attività che causano la sovrallocazione e quali attività possono essere ritardate, viene utilizzato l'ordine specificato per stabilire quale attività deve essere ritardata per prima. |
| [set_MessageHandler](./set_messagehandler/) | Imposta la callback del gestore dei messaggi che può essere utilizzata per intercettare i messaggi di log prodotti da Aspose.Tasks durante il livellamento delle risorse. |
| [set_MessageLevel](./set_messagelevel/) | Imposta il livello dei messaggi di log emessi da Aspose.Tasks durante il livellamento delle risorse. |
| [set_Resources](./set_resources/) | Imposta l'elenco delle risorse che saranno livellate. Se viene impostato null, tutte le risorse del progetto saranno livellate. |
| [set_StartDate](./set_startdate/) | Imposta la data di inizio del periodo di livellamento. Il valore predefinito è la data di inizio del progetto. |
