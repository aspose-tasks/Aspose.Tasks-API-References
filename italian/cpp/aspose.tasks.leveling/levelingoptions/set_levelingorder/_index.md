## set_LevelingOrder {#set_levelingorder}

Restituisce l'ordine con cui l'algoritmo di livellamento ritarda le attività che hanno sovrallocazioni. Dopo aver determinato le attività che causano la sovrallocazione e quali attività possono essere ritardate, viene utilizzato l'ordine specificato per stabilire quale attività deve essere ritardata per prima.
