## PageSavingArgs class

Questa classe rappresenta un insieme di dati relativi al salvataggio della pagina del documento in uno stream.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Restituisce un valore che indica se la routine di rendering deve mantenere lo Stream aperto dopo che una pagina è stata scritta. |
| [get_PageNumber](./get_pagenumber/) | Restituisce il numero della pagina da scrivere. |
| [get_Stream](./get_stream/) | Restituisce uno stream per scrivere una pagina. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Imposta un valore che indica se la routine di rendering deve mantenere lo Stream aperto dopo che una pagina è stata scritta. |
| [set_Stream](./set_stream/) | Imposta uno stream per scrivere una pagina. |
