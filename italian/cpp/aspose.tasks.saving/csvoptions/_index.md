## CsvOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Consente di specificare opzioni aggiuntive durante il salvataggio del progetto in CSV.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [CsvOptions](./csvoptions/) | Inizializza una nuova istanza della classe CsvOptions che può essere utilizzata per salvare il progetto in formato CSV. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_DataCategory](./get_datacategory/) | Ottiene una categoria di dati da salvare. |
| [get_Encoding](./get_encoding/) | Ottiene una codifica con cui salvare il CSV. |
| [get_IncludeHeaders](./get_includeheaders/) | Ottiene un valore che indica se includere le intestazioni o meno (il valore predefinito è TRUE). |
| [get_TextDelimiter](./get_textdelimiter/) | Ottiene un delimitatore di testo. |
| [get_View](./get_view/) | Ottiene un elenco delle colonne di visualizzazione ( GanttChartColumn ) da salvare nel formato XLSX. Se non impostato, vengono salvate le colonne predefinite. |
| [set_DataCategory](./set_datacategory/) | Imposta una categoria di dati da salvare. |
| [set_Encoding](./set_encoding/) | Imposta una codifica con cui salvare il CSV. |
| [set_IncludeHeaders](./set_includeheaders/) | Imposta un valore che indica se includere le intestazioni o meno (il valore predefinito è TRUE). |
| [set_TextDelimiter](./set_textdelimiter/) | Imposta un delimitatore di testo. |
| [set_View](./set_view/) | Imposta un elenco delle colonne di visualizzazione ( GanttChartColumn ) da salvare nel formato XLSX. Se non impostato, vengono salvate le colonne predefinite. |
