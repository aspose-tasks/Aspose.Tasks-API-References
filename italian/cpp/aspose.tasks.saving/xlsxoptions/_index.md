## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Consente di specificare opzioni aggiuntive durante il rendering delle pagine del progetto in XLSX.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Inizializza una nuova istanza della classe XlsxOptions che può essere utilizzata per salvare il progetto in formato XLSX. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Ottiene un elenco delle colonne di visualizzazione delle assegnazioni da renderizzare ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | Restituisce la codifica del file XLSX risultante. Il valore predefinito è System::Text::Encoding::UTF8. |
| [get_ResourceView](./get_resourceview/) | Ottiene un elenco delle colonne di visualizzazione delle risorse da renderizzare ( ResourceViewColumn ). |
| [get_View](./get_view/) | Ottiene un elenco delle colonne di visualizzazione ( GanttChartColumn ) da salvare nel formato XLSX. Se non impostato, vengono salvate le colonne predefinite. |
| [set_AssignmentView](./set_assignmentview/) | Imposta un elenco delle colonne di visualizzazione delle assegnazioni da renderizzare ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | Imposta la codifica del file XLSX risultante. Il valore predefinito è System::Text::Encoding::UTF8. |
| [set_ResourceView](./set_resourceview/) | Imposta un elenco delle colonne di visualizzazione delle risorse da renderizzare ( ResourceViewColumn ). |
| [set_View](./set_view/) | Imposta un elenco delle colonne di visualizzazione ( GanttChartColumn ) da salvare nel formato XLSX. Se non impostato, vengono salvate le colonne predefinite. |
