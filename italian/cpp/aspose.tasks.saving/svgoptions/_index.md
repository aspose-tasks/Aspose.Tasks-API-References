## SvgOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

Consente di specificare opzioni aggiuntive durante il rendering delle pagine del progetto in SVG.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [SvgOptions](./svgoptions/) | Inizializza una nuova istanza della classe SvgOptions che può essere utilizzata per salvare il progetto in formato SVG. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_PageSavingCallback](./get_pagesavingcallback/) | Restituisce un callback di implementazione definito dall'utente, utilizzato per ottenere uno stream di output per ogni pagina renderizzata. |
| [get_UseGradientBrush](./get_usegradientbrush/) | Determina se utilizzare il pennello a gradiente durante il rendering del layout del progetto. |
| [set_PageSavingCallback](./set_pagesavingcallback/) | Imposta una callback di implementazione definita dall'utente che viene utilizzata per ottenere un flusso di output per ogni pagina renderizzata. |
| [set_UseGradientBrush](./set_usegradientbrush/) | Determina se utilizzare il pennello a gradiente durante il rendering del layout del progetto. |
