## PdfSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

Consente di specificare opzioni aggiuntive durante il rendering delle pagine del progetto in PDF.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [PdfSaveOptions](./pdfsaveoptions/) | Inizializza una nuova istanza della classe PdfSaveOptions che può essere utilizzata per salvare un documento nel formato PDF. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Compliance](./get_compliance/) | Restituisce il livello di conformità desiderato per il documento PDF generato. Il valore predefinito è PdfCompliance::Pdf15. |
| [get_DigitalSignatureDetails](./get_digitalsignaturedetails/) | Restituisce i dettagli della firma digitale. Se non impostati, non verrà eseguita alcuna firma. |
| [get_EncryptionDetails](./get_encryptiondetails/) | Restituisce i dettagli della crittografia. Se non impostati, non verrà eseguita alcuna crittografia. |
| [get_FontSettings](./get_fontsettings/) | Specifica le impostazioni del font utilizzate durante il rendering della vista del progetto. |
| [get_Pages](./get_pages/) | Restituisce l'elenco dei numeri di pagina da salvare quando si salva il layout del progetto in file separati. |
| [get_PageSavingCallback](./get_pagesavingcallback/) | Restituisce una callback definita dall'utente che viene utilizzata per ottenere uno stream di output per ogni pagina renderizzata. È applicabile quando viene utilizzata l'opzione SaveToSeparateFiles. |
| [get_ReduceFooterGap](./get_reducefootergap/) | Ottiene un valore che indica se ridurre lo spazio tra l'ultima attività e il piè di pagina. |
| [get_SaveToSeparateFiles](./get_savetoseparatefiles/) | Restituisce un valore che indica se salvare le pagine del progetto in file separati. |
| [get_TextCompression](./get_textcompression/) | Restituisce il tipo di compressione da utilizzare per tutti i flussi di contenuto, eccetto le immagini. Il valore predefinito è PdfTextCompression::Flate. |
| [set_Compliance](./set_compliance/) | Imposta il livello di conformità desiderato per il documento PDF generato. Il valore predefinito è PdfCompliance::Pdf15. |
| [set_DigitalSignatureDetails](./set_digitalsignaturedetails/) | Imposta i dettagli della firma digitale. Se non impostati, non verrà eseguita alcuna firma. |
| [set_EncryptionDetails](./set_encryptiondetails/) | Imposta i dettagli della crittografia. Se non impostati, non verrà eseguita alcuna crittografia. |
| [set_Pages](./set_pages/) | Imposta l'elenco dei numeri di pagina da salvare quando si salva il layout del progetto in file separati. |
| [set_PageSavingCallback](./set_pagesavingcallback/) | Imposta una callback definita dall'utente che viene utilizzata per ottenere uno stream di output per ogni pagina renderizzata. È applicabile quando viene utilizzata l'opzione SaveToSeparateFiles. |
| [set_ReduceFooterGap](./set_reducefootergap/) | Imposta un valore che indica se ridurre lo spazio tra l'ultima attività e il piè di pagina. |
| [set_SaveToSeparateFiles](./set_savetoseparatefiles/) | Imposta un valore che indica se salvare le pagine del progetto in file separati. |
| [set_TextCompression](./set_textcompression/) | Imposta un tipo di compressione da utilizzare per tutti i flussi di contenuto eccetto le immagini. L'impostazione predefinita è PdfTextCompression::Flate . |
