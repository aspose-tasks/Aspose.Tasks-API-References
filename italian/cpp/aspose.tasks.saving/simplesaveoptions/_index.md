## SimpleSaveOptions class

Questa è una classe base astratta che consente all'utente di specificare opzioni di base durante il salvataggio di un progetto in un formato specifico.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_SaveFormat](./get_saveformat/) | Restituisce il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
| [get_TasksComparer](./get_taskscomparer/) | Restituisce il comparatore per ordinare le attività nel diagramma di Gantt e nel foglio delle attività. |
| [get_TasksFilter](./get_tasksfilter/) | Restituisce la condizione utilizzata per filtrare le attività visualizzate nei diagrammi di Gantt, nel foglio delle attività e nell'utilizzo delle attività. |
| [set_TasksComparer](./set_taskscomparer/) | Imposta il comparatore per ordinare le attività nel diagramma di Gantt e nel foglio delle attività. |
| [set_TasksFilter](./set_tasksfilter/) | Imposta la condizione utilizzata per filtrare le attività visualizzate nei diagrammi di Gantt, nel foglio delle attività e nell'utilizzo delle attività. |
