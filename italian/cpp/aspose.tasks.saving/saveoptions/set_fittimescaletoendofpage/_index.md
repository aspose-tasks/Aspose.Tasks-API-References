## set_FitTimescaleToEndOfPage {#set_fittimescaletoendofpage}

Imposta se una sezione calendario di una vista deve essere renderizzata fino alla fine (lato destro) dell'ultima pagina. Se il valore è false, la sezione calendario viene renderizzata esattamente fino a EndDate, anche se c'è uno spazio vuoto nella pagina.
