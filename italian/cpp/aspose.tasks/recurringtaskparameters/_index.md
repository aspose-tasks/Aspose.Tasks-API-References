## RecurringTaskParameters class

Rappresenta l'insieme dei parametri utilizzati per creare un'attività ricorrente in un progetto.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [RecurringTaskParameters](./recurringtaskparameters/) | Inizializza una nuova istanza della classe RecurringTaskParameters. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Duration](./get_duration/) | Ottiene la durata per una singola occorrenza dell'attività ricorrente. |
| [get_IgnoreResourceCalendar](./get_ignoreresourcecalendar/) | Ottiene un valore che indica se pianificare l'attività ricorrente anche se non si verifica quando sono disponibili risorse per lavorarci. |
| [get_RecurrencePattern](./get_recurrencepattern/) | Ottiene il modello di ricorrenza dell'attività ricorrente. |
| [get_TaskName](./get_taskname/) | Ottiene il nome dell'attività ricorrente. |
| [set_Duration](./set_duration/) | Imposta la durata per una singola occorrenza dell'attività ricorrente. |
| [set_IgnoreResourceCalendar](./set_ignoreresourcecalendar/) | Imposta un valore che indica se pianificare l'attività ricorrente anche se non si verifica quando sono disponibili risorse per lavorarci. |
| [set_RecurrencePattern](./set_recurrencepattern/) | Imposta il modello di ricorrenza dell'attività ricorrente. |
| [set_TaskName](./set_taskname/) | Imposta il nome dell'attività ricorrente. |
| [SetCalendar](./setcalendar/) | Imposta un calendario per l'attività ricorrente. Il calendario è selezionato dalla raccolta di calendari del progetto. |
