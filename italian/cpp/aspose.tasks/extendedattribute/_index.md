## ExtendedAttribute class

Rappresenta attributi estesi.

Attualmente sono supportati tutti i tipi di attributi estesi letti da MSP Xml 2003/2007 e mpp 2003. Per MSP mpp 2007 tutti gli attributi estesi sono supportati tranne le durate e i flag.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_AttributeDefinition](./get_attributedefinition/) | Restituisce la definizione dell'attributo. |
| [get_DateValue](./get_datevalue/) | Restituisce un valore per gli attributi con tipi data (Date, Start, Finish). |
| [get_DurationValue](./get_durationvalue/) | Restituisce il valore per gli attributi con tipo ' Duration '. |
| [get_FieldId](./get_fieldid/) | Restituisce l'ID di un campo. |
| [get_FlagValue](./get_flagvalue/) | Restituisce un valore che indica se un flag è impostato per un attributo con tipo 'Flag'. |
| [get_IsErrorValue](./get_iserrorvalue/) | Restituisce se il calcolo del valore dell'attributo esteso ha generato un errore. |
| [get_NumericValue](./get_numericvalue/) | Restituisce un valore per gli attributi di tipo numerico (Costo, Numero). |
| [get_TextValue](./get_textvalue/) | Restituisce un valore per gli attributi di tipo 'Testo'. |
| [get_ValueGuid](./get_valueguid/) | Restituisce il GUID di un valore di ricerca. |
| [get_ValueReadOnly](./get_valuereadonly/) | Restituisce un valore che indica se il valore di questa istanza di ExtendedAttribute è di sola lettura. Restituisce true se una formula o un rollup è definito in ExtendedAttributeDefinition per questo oggetto. |
| [set_DateValue](./set_datevalue/) | Imposta un valore per gli attributi di tipo data (Data, Inizio, Fine). |
| [set_DurationValue](./set_durationvalue/) | Imposta il valore per gli attributi di tipo 'Durata'. |
| [set_FlagValue](./set_flagvalue/) | Imposta un valore che indica se un flag è impostato per un attributo di tipo 'Flag'. |
| [set_NumericValue](./set_numericvalue/) | Imposta un valore per gli attributi di tipo numerico (Costo, Numero). |
| [set_TextValue](./set_textvalue/) | Imposta un valore per gli attributi di tipo 'Testo'. |
| [ToString](./tostring/) | Restituisce la rappresentazione stringa breve di un attributo esteso. |
