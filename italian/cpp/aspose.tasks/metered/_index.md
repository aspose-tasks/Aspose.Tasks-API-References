## Metered class

Fornisce metodi per impostare la chiave misurata.

In questo esempio, verrà tentato di impostare la chiave pubblica e privata metered <ms>

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> il file jar del componente:

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>

## Metodi

| Nome | Descrizione |
| --- | --- |
| [GetConsumptionCredit](./getconsumptioncredit/) | Ottiene il credito di consumo. |
| [GetConsumptionQuantity](./getconsumptionquantity/) | Ottiene la dimensione del file di consumo. |
| [IsLicensed](./islicensed/) | Verifica se il prodotto è stato licenziato correttamente utilizzando la licenza a consumo. |
| [ResetMeteredKey](./resetmeteredkey/) | Rimuove la licenza precedentemente configurata. |
| [SetMeteredKey](./setmeteredkey/) | Imposta le chiavi pubbliche e private a consumo. |
