## OutlineCodeDefinition class

Rappresenta una definizione di codice di contorno.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [OutlineCodeDefinition](./outlinecodedefinition/) | Inizializza una nuova istanza della classe OutlineCodeDefinition. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Alias](./get_alias/) | Restituisce l'alias di un codice di contorno personalizzato. |
| [get_AllLevelsRequired](./get_alllevelsrequired/) | Restituisce un valore che indica se i nuovi codici devono avere tutti i livelli. Non disponibile per i Codici Enterprise. |
| [get_Enterprise](./get_enterprise/) | Restituisce un valore che indica se un codice di contorno personalizzato è un codice di contorno personalizzato enterprise. |

| [get_Guid](./get_guid/) | Restituisce il GUID di un codice di contorno. |
