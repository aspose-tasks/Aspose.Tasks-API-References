## CheckPropAndGet {#checkpropandget}

Restituisce il valore a cui la proprietà è mappata in questo contenitore. Se questo contenitore non contiene il record ProjectItem, verrà aggiunto con il valore predefinito e verrà restituito il valore predefinito.

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| Parametro | Descrizione |
| --- | --- |
| chiave | la proprietà specificata. |
