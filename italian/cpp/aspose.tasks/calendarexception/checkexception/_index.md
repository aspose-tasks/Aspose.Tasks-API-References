## CheckException {#checkexception}

Restituisce true se l'istanza specificata della struct DateTime è il giorno di eccezione.

**Returns:** Returns true if DateTime value is the exception day; otherwise, false.

```cpp
CheckException(System::DateTime dt)
```

| Parametro | Descrizione |
| --- | --- |
| dt | l'istanza specificata della struttura DateTime. |
