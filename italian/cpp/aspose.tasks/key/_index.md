## Key< T, K > class

Rappresenta una chiave di proprietà di una classe del tipo specificato. Un'istanza di questa classe è utilizzata quando si ottiene o si imposta una proprietà di un contenitore.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_KeyType](./get_keytype/) | Ottiene la chiave della proprietà. |
