## FontResolveEventArgs class

Fornisce gli argomenti per il callback che viene invocato quando il font è risolto.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_RequestedFontName](./get_requestedfontname/) | Ottiene il nome del font richiesto. |
| [get_ResolvedFontName](./get_resolvedfontname/) | Ottiene il nome del font risolto. Può essere impostato per controllare i font usati per renderizzare una vista. |
| [set_ResolvedFontName](./set_resolvedfontname/) | Imposta il nome del font risolto. Può essere impostato per controllare i font usati per renderizzare una vista. |
