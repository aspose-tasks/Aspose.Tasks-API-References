## ProjectInfo class

Informazioni brevi sul progetto pubblicato disponibile su Project Online.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [ProjectInfo](./projectinfo/) | Inizializza una nuova istanza della classe ProjectInfo. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_CreatedDate](./get_createddate/) | Restituisce la data e l'ora in cui il progetto è stato creato. |
| [get_Description](./get_description/) | Restituisce la descrizione del progetto. |
| [get_Id](./get_id/) | Restituisce l'identificatore univoco del progetto. |
| [get_IsCheckedOut](./get_ischeckedout/) | Restituisce un valore che indica se il progetto è stato effettuato il check-out. |
| [get_LastPublishedDate](./get_lastpublisheddate/) | Restituisce la data più recente in cui il progetto è stato pubblicato. |
| [get_LastSavedDate](./get_lastsaveddate/) | Restituisce la data più recente in cui il progetto è stato salvato. |
| [get_Name](./get_name/) | Restituisce il nome del progetto. |
