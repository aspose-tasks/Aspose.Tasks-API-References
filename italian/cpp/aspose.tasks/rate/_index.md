## Rate class

Rappresenta una definizione di un periodo di tempo e le tariffe applicabili a una risorsa durante quel periodo.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Restituisce il costo per utilizzo di una risorsa. Questo valore viene recuperato dalla data corrente se esiste una tabella delle tariffe per una risorsa. |
| [get_OvertimeRate](./get_overtimerate/) | Restituisce la tariffa degli straordinari per ora per una risorsa. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Restituisce le unità utilizzate da Microsoft Project per visualizzare la tariffa degli straordinari. |
| [get_RatesFrom](./get_ratesfrom/) | Restituisce la data in cui una tariffa diventa effettiva. |
| [get_RatesTo](./get_ratesto/) | Restituisce l'ultima data in cui una tariffa è effettiva. |
| [get_RateTable](./get_ratetable/) | Restituisce l'identificatore univoco di una tabella delle tariffe per una risorsa. |
| [get_StandardRate](./get_standardrate/) | Restituisce la tariffa standard per ora per una risorsa. |
| [get_StandardRateFormat](./get_standardrateformat/) | Restituisce le unità utilizzate da Microsoft Project per visualizzare la tariffa standard. |
| [set_CostPerUse](./set_costperuse/) | Imposta il costo per utilizzo di una risorsa. Questo valore viene recuperato dalla data corrente se esiste una tabella delle tariffe per una risorsa. |
| [set_OvertimeRate](./set_overtimerate/) | Imposta la tariffa degli straordinari per ora per una risorsa. |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Imposta le unità utilizzate da Microsoft Project per visualizzare la tariffa degli straordinari. |
| [set_RatesFrom](./set_ratesfrom/) | Imposta la data in cui una tariffa diventa effettiva. |
| [set_RatesTo](./set_ratesto/) | Imposta l'ultima data in cui una tariffa è effettiva. |
| [set_RateTable](./set_ratetable/) | Imposta l'identificatore univoco di una tabella delle tariffe per una risorsa. |
| [set_StandardRate](./set_standardrate/) | Imposta la tariffa standard per ora per una risorsa. |
| [set_StandardRateFormat](./set_standardrateformat/) | Imposta le unità utilizzate da Microsoft Project per visualizzare la tariffa standard. |
