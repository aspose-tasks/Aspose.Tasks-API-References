## PrimaveraBaseReader class

Rappresenta un lettore di base che può essere utilizzato per leggere gli UID del progetto da file Primavera XER o XML multi-progetto.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [GetProjectInfos](./getprojectinfos/) | Restituisce un elenco di oggetti di informazioni brevi del progetto. |
| [GetProjectUids](./getprojectuids/) | Restituisce un elenco degli identificatori univoci dei progetti. |
| [LoadProject](./loadproject/) | Carica il progetto con l'identificatore univoco specificato. |
