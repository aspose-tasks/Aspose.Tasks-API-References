## FontSettings class

Specifica le impostazioni del font utilizzate durante il rendering della vista del progetto.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | Restituisce il font predefinito (o di fallback) per il rendering. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | Restituisce una callback che può essere usata per personalizzare i font risolti. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | Restituisce un valore che indica se il font predefinito deve essere usato per il rendering. |
| [set_DefaultFontName](./set_defaultfontname/) | Imposta il font predefinito (o di fallback) per il rendering. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | Imposta una callback che può essere utilizzata per personalizzare i font risolti. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | Imposta un valore che indica se il font predefinito deve essere usato per il rendering. |
| [SetFontFolders](./setfontfolders/) | Imposta le cartelle in cui Aspose.Tasks cerca i font TrueType durante il rendering della vista del progetto. |
