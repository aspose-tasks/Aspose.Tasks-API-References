## OleObject class

Rappresenta un oggetto OLE che può essere inserito nella vista Gantt Chart di un file MPP.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [OleObject](./oleobject/) | Inizializza una nuova istanza della classe OleObject. |
