## OleObjectCollection class

Rappresenta una raccolta contenente le istanze della classe OleObject.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [Clear](./clear/) | Cancella la collezione. Per rendere permanenti queste modifiche, dovrebbe essere chiamato project.Save con nuove MPPSaveOptions { WriteViewData = true; } |
| [GetEnumerator](./getenumerator/) | Restituisce un enumeratore per questa collezione. |
| [ToList](./tolist/) | Converte l'istanza della classe OleObjectCollection in un elenco contenente le istanze della classe OleObject. |
