## IsDayWorking {#isdayworking}

Determina se il giorno specificato è un giorno lavorativo secondo il calendario.

**Returns:** True if the day is a working day.

```cpp
IsDayWorking(System::DateTime dt)
```

| Parametro | Descrizione |
| --- | --- |
| dt | La data per verificare se il giorno è lavorativo. |
