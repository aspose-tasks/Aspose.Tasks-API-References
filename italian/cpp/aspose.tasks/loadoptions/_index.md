## LoadOptions class

Consente di specificare parametri di caricamento aggiuntivi durante il caricamento di un progetto da file o flusso.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [LoadOptions](./loadoptions/) | Inizializza una nuova istanza della classe LoadOptions. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_Encoding](./get_encoding/) | Ottiene la codifica utilizzata per leggere un progetto dai formati HTML, MPX, XER e Primavera XML. La codifica predefinita è UTF8. |
| [get_ErrorHandler](./get_errorhandler/) | Ottiene un metodo di callback per gestire gli errori di parsing XML. |
| [get_Password](./get_password/) | Ottiene una password di protezione. |
| [get_PrimaveraReadOptions](./get_primaverareadoptions/) | Ottiene un'istanza specificata della classe Tasks::PrimaveraReadOptions che può essere utilizzata per personalizzare il comportamento del caricamento dei formati Primavera (Primavera P6 XER o Primavera P6 Xml). |
| [set_Encoding](./set_encoding/) | Imposta la codifica utilizzata per leggere un progetto dai formati HTML, MPX, XER e Primavera XML. La codifica predefinita è UTF8. |
| [set_ErrorHandler](./set_errorhandler/) | Imposta un metodo di callback per gestire gli errori di parsing XML. |
| [set_Password](./set_password/) | Imposta una password di protezione. |
| [set_PrimaveraReadOptions](./set_primaverareadoptions/) | Imposta un'istanza specificata della classe Tasks::PrimaveraReadOptions che può essere utilizzata per personalizzare il comportamento del caricamento dei formati Primavera (Primavera P6 XER o Primavera P6 Xml). |
