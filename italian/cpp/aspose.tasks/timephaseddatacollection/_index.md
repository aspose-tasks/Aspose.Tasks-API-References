## TimephasedDataCollection class

Rappresenta una collezione di oggetti TimephasedData.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [Add](./add/) | Aggiunge un'istanza di TimephasedData a questo oggetto collezione. |
| [AddRange](./addrange/) | Aggiunge una collezione di istanze di TimephasedData a questo oggetto collezione. |
| [Clear](./clear/) | Rimuove tutti gli elementi dalla TimephasedDataCollection. |
| [Contains](./contains/) | Determina se la TimephasedDataCollection contiene un valore specifico. |
| [CopyTo](./copyto/) | Copia gli elementi della TimephasedDataCollection in un System::Array, iniziando da un indice specifico di System::Array. |
| [get_Count](./get_count/) | Ottiene il numero di oggetti contenuti in questo oggetto TimephasedDataCollection. |
| [get_IsReadOnly](./get_isreadonly/) | Ottiene un valore che indica se il System::Collections::Generic::ICollection<T> è di sola lettura. |
| [GetEnumerator](./getenumerator/) | Restituisce un enumeratore per questa collezione. |
| [idx_get](./idx_get/) | Restituisce l'elemento all'indice specificato. L'accessor di impostazione non è supportato. proprietà per impostare i dati timephased. |
| [idx_set](./idx_set/) | Restituisce l'elemento all'indice specificato. L'accessor di impostazione non è supportato. proprietà per impostare i dati timephased. |
| [Remove](./remove/) | Rimuove l'istanza di TimephasedData da questo oggetto collezione. |
| [SelectBetweenStartAndFinish](./selectbetweenstartandfinish/) | Seleziona tutte le fasi temporali tra startTime e finishTime. Ha una complessità O(log n) nel caso medio. |
