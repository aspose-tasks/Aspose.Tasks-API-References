## PrimaveraReadOptions class

Consente di specificare opzioni aggiuntive durante la lettura di file Primavera Xml o Primavera Xer.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [PrimaveraReadOptions](./primaverareadoptions/) | Inizializza una nuova istanza della classe PrimaveraReadOptions. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_PreserveUids](./get_preserveuids/) | Ottiene un flag che specifica se gli identificatori unici originali delle entità devono essere preservati. |
| [get_ProjectUid](./get_projectuid/) | Ottiene l'UID di un progetto da leggere da un file contenente più progetti. |
| [get_ReadBaselineProjects](./get_readbaselineprojects/) | Ottiene un flag che specifica se i progetti di baseline devono essere caricati. Il valore predefinito è true. |

| [set_PreserveUids](./set_preserveuids/) | Imposta un flag che specifica se gli identificatori unici originali delle entità devono essere preservati. |
| [set_ProjectUid](./set_projectuid/) | Imposta l'UID di un progetto da leggere da un file contenente più progetti. |
| [set_ReadBaselineProjects](./set_readbaselineprojects/) | Imposta un flag che specifica se i progetti di baseline devono essere caricati. Il valore predefinito è true. |
