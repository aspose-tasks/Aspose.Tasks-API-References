## PrimaveraProjectInfo class

Rappresenta informazioni brevi su un progetto caricato dal formato Primavera.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_ExportFlag](./get_exportflag/) | Ottiene il flag di esportazione del progetto. Quando un progetto è selezionato per l'esportazione in Primavera, il suo ExportFlag è true. Alcuni progetti non selezionati esplicitamente per l'esportazione possono essere esportati in un file XER a causa della loro relazione con il progetto esportato. |
| [get_Name](./get_name/) | Ottiene il nome del progetto. |
| [get_Uid](./get_uid/) | Ottiene l'Uid del progetto. |
