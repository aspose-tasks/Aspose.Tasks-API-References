## RiskAnalyzer class

Esegue una simulazione Monte Carlo basata sulle impostazioni specificate per l'analisi del rischio.

## Costruttori

| Nome | Descrizione |
| --- | --- |
| [RiskAnalyzer](./riskanalyzer/) | Inizializza una nuova istanza della classe RiskAnalyzer. |

## Metodi

| Nome | Descrizione |
| --- | --- |
| [Analyze](./analyze/) | Esegue l'analisi del rischio per il progetto specificato. L'analisi si basa sulla simulazione Monte Carlo e il risultato è un'istanza della classe RiskAnalysisResult. |
| [get_Settings](./get_settings/) | Ottiene l'istanza della classe RiskAnalysisSettings che definisce le impostazioni necessarie per l'analisi del rischio. |
| [set_Settings](./set_settings/) | Imposta l'istanza della classe RiskAnalysisSettings che definisce le impostazioni necessarie per l'analisi del rischio. |
