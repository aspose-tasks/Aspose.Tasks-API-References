## RiskItemStatistics class

Rappresenta un elemento che memorizza dati statistici per l'attività del progetto analizzato.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | Ottiene il valore atteso dell'elemento di rischio. |
| [get_ItemType](./get_itemtype/) | Ottiene un'istanza dell'enumerazione RiskItemType. |
| [get_Maximum](./get_maximum/) | Ottiene il valore massimo generato durante la simulazione Monte Carlo. |
| [get_Minimum](./get_minimum/) | Ottiene il valore minimo generato durante la simulazione Monte Carlo. |
| [get_StandardDeviation](./get_standarddeviation/) | Ottiene la deviazione standard dell'elemento di rischio. |
| [GetPercentile](./getpercentile/) | Ottiene un valore al di sotto del quale cade una percentuale specificata di campioni generati. |
| [ToString](./tostring/) | Restituisce una breve rappresentazione stringa di un elemento di rischio. I dettagli esatti della rappresentazione non sono specificati e soggetti a modifiche. |
