## Gridline.GetHashCode method

Restituisce un valore di codice hash per l'istanza della classe [`Gridline`](../).

```csharp
public override int GetHashCode()
```

### Valore di ritorno

restituisce un valore di hash per questo oggetto.

## Esempi

Mostra come ottenere il codice hash di una gridline.

```csharp
var gridline1 = new Gridline();
var gridline2 = new Gridline();

// Il codice hash di una gridline si basa sul campo GUID interno.
Console.WriteLine("Gridline 1 Hash Code: {0}", gridline1.GetHashCode());
Console.WriteLine("Gridline 2 Hash Code: {0}", gridline2.GetHashCode());
```
