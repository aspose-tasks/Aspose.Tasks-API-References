## TimescaleTier.RenderLabelOnEachPage property

Ottiene o imposta il flag che definisce se le etichette data devono essere renderizzate su ogni pagina quando un periodo di tempo si estende su più pagine. Se il valore è 'true', quando il periodo di tempo si estende su più pagine, le etichette data per il periodo sono renderizzate su ogni pagina. Se il valore è 'false', l'etichetta data è renderizzata una sola volta in base al valore della proprietà [`Alignment`](../alignment/).

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
