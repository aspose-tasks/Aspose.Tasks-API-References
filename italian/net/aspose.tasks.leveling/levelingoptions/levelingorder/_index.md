## LevelingOptions.LevelingOrder property

Ottiene l'ordine con cui l'algoritmo di livellamento ritarda le attività che hanno sovrallocazioni. Dopo aver determinato le attività che causano la sovrallocazione e quali attività possono essere ritardate, viene utilizzato l'ordine specificato per decidere quale attività ritardare per prima.

```csharp
public LevelingOrder LevelingOrder { get; set; }
```
