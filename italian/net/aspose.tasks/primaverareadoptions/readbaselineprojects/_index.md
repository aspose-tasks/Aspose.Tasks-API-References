## PrimaveraReadOptions.ReadBaselineProjects property

Ottiene o imposta un flag che specifica se i progetti di baseline devono essere caricati. Il valore predefinito è true.

```csharp
public bool ReadBaselineProjects { get; set; }
```

## Osservazioni

Il flag è applicabile ai file XML di Primavera contenenti progetti baseline (le baseline non sono supportate dal formato XER). L'opzione può essere impostata su false per velocizzare il caricamento di un progetto di grandi dimensioni con baseline quando i dati delle baseline non sono necessari.
