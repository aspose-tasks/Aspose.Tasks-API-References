## FontResolveEventArgs.ResolvedFontName property

Ottiene o imposta il nome del font risolto. Può essere impostato per controllare i font usati per renderizzare una vista.

```csharp
public string ResolvedFontName { get; set; }
```

### Valore di ritorno

Nome del font richiesto se il font è trovato o nome del font di riserva o null se il font non può essere trovato.
