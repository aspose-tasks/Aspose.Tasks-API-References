## Osservazioni

Il **Task** rappresenta un singolo blocco atomico di lavoro.

Si può usare **Task** per pianificare un progetto creando attività e assegnando loro le risorse appropriate. Le attività in un progetto sono organizzate come una struttura ad albero gerarchico radicato, con un'attività radice e sottoalberi di attività figlie.

Per costruire un albero di attività si può utilizzare una collezione specializzata [`TaskCollection`](../taskcollection/) accedendo alla proprietà [`RootTask`](../project/roottask/) ad esempio:

```csharp
Project project = new Project();

// aggiungi nuove attività
Task task1 = project.RootTask.Children.Add(); // a parent task with empty name is added
Task childTask1 = task1.Children.Add("Child 1");

childTask3.Set(Tsk.Finish, new DateTime(2020, 2, 13, 17, 0, 0));
Task childTask2 = task1.Children.Add("Child 2", 2); // inserts a task before the childTask3

// salvare il progetto in uno dei formati disponibili
project.Save("Filled project.xml", SaveFileFormat.MPP);
```
