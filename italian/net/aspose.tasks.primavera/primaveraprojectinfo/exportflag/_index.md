## PrimaveraProjectInfo.ExportFlag property

Ottiene il flag di esportazione del progetto. Quando un progetto è selezionato per l'esportazione in Primavera, il suo ExportFlag è true. Alcuni progetti non esplicitamente selezionati per l'esportazione possono essere esportati in un file XER a causa della loro relazione con il progetto esportato.

```csharp
public bool ExportFlag { get; }
```
