Specifica l'allineamento di una stringa di testo rispetto al suo rettangolo di layout.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Center](#Center) | Specifica che il testo è allineato al centro del rettangolo di layout. |
| [Far](#Far) | Specifica che il testo è allineato lontano dalla posizione di origine del rettangolo di layout. |
| [Near](#Near) | Specifica che il testo sia allineato vicino al layout. |
### Center {#Center}
```
public static final int Center
```


Specifica che il testo è allineato al centro del rettangolo di layout.

### Far {#Far}
```
public static final int Far
```


Specifica che il testo è allineato lontano dalla posizione di origine del rettangolo di layout. In un layout da sinistra a destra, la posizione lontana è a destra. In un layout da destra a sinistra, la posizione lontana è a sinistra.

### Near {#Near}
```
public static final int Near
```


Specifica che il testo sia allineato vicino al layout. In un layout da sinistra a destra, la posizione vicina è a sinistra. In un layout da destra a sinistra, la posizione vicina è a destra.
