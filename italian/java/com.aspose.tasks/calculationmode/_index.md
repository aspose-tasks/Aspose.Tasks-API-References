Specifica la modalità di calcolo del progetto.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Automatic](#Automatic) | Modalità automatica. |
| [Manual](#Manual) | Modalità manuale. |
| [None](#None) | Nessuno. |
### Automatic {#Automatic}
```
public static final int Automatic
```


Modalità automatica. Le date e i costi del progetto vengono ricalcolati quando si utilizza questa modalità.

### Manual {#Manual}
```
public static final int Manual
```


Modalità manuale. Solo i campi necessari vengono ricalcolati in questa modalità, ad esempio UID e ID degli oggetti.

### None {#None}
```
public static final int None
```


Nessuno. Le date e i costi del progetto non vengono ricalcolati in questa modalità.
