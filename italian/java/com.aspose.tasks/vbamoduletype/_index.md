Specifica il tipo di modulo in un progetto VBA.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ClassModule](#ClassModule) | Un modulo che contiene la definizione per un nuovo oggetto. |
| [DesignerModule](#DesignerModule) | Un modulo che estende i metodi e le proprietà di un controllo ActiveX registrato nel progetto. |
| [DocumentModule](#DocumentModule) | Un tipo di elemento di progetto VBA che specifica un modulo per macro incorporate e operazioni di accesso programmatico associate a un documento. |
| [ProceduralModule](#ProceduralModule) | Un modulo contenente una raccolta di subroutine e funzioni. |
### ClassModule {#ClassModule}
```
public static final int ClassModule
```


Un modulo che contiene la definizione per un nuovo oggetto. Ogni istanza di una classe crea un nuovo oggetto e le procedure definite nel modulo diventano proprietà e metodi dell'oggetto.

### DesignerModule {#DesignerModule}
```
public static final int DesignerModule
```


Un modulo che estende i metodi e le proprietà di un controllo ActiveX registrato nel progetto.

### DocumentModule {#DocumentModule}
```
public static final int DocumentModule
```


Un tipo di elemento di progetto VBA che specifica un modulo per macro incorporate e operazioni di accesso programmatico associate a un documento.

### ProceduralModule {#ProceduralModule}
```
public static final int ProceduralModule
```


Un modulo contenente una raccolta di subroutine e funzioni.
