### getParentStyle() {#getParentStyle--}
```
public final GanttBarStyle getParentStyle()
```


Ottiene lo stile genitore (o comune) per lo stile personalizzato specifico del compito.

--------------------

Un'attività può avere più stili personalizzati con diversi stili genitore. Ad esempio, consideriamo un'attività con uno stile personalizzato che ha lo stile genitore "Critical" e un altro stile con lo stile genitore "Normal". In parole povere, se l'attività è critica, viene applicato il primo stile. Se l'attività diventa non critica, viene applicato il secondo stile (questa logica è ereditata da Microsoft Project Professional).

**Returns:**
[GanttBarStyle](../../com.aspose.tasks/ganttbarstyle) - parent (or common) style for custom task-specific style.
