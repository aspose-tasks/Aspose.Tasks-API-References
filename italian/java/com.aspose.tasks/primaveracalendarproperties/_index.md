**Inheritance:**
java.lang.Object
```
public final class PrimaveraCalendarProperties
```

Rappresenta le proprietà specifiche di Primavera per un calendario letto dai file Primavera (XER o P6XML). Può essere usato per eseguire la conversione delle unità di tempo specifiche del calendario.
