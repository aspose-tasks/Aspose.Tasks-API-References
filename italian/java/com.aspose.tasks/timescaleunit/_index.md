Specifica l'unità di tempo per qualsiasi livello di una scala temporale in un diagramma Gantt o in un'altra visualizzazione a fasi temporali.

| [HalfYears](#HalfYears) | Indica l'unità di scala temporale Mezzo anno. |
| [Hours](#Hours) | Indica l'unità di scala temporale Ore. |
| [Minutes](#Minutes) | Indica l'unità di scala temporale Minuti. |
| [Months](#Months) | Indica l'unità di scala temporale Mesi. |
| [None](#None) | Indica Nessuno. |

| [Weeks](#Weeks) | Indica l'unità di scala temporale Settimane. |
