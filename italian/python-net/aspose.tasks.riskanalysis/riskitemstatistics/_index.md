## RiskItemStatistics class

Rappresenta un elemento che memorizza dati statistici per l'attività del progetto analizzato.

Il tipo RiskItemStatistics espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| item_type | Ottiene un'istanza dell'enumerazione [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/). |
| minimum | Ottiene il valore minimo generato durante la simulazione Monte Carlo. |
| maximum | Ottiene il valore massimo generato durante la simulazione Monte Carlo. |
| expected_value | Ottiene il valore atteso dell'elemento di rischio. |
| standard_deviation | Ottiene la deviazione standard dell'elemento di rischio. |
## Methods
| Nome | Descrizione |
| :- | :- |
| get_percentile(percent) | Ottiene un valore al di sotto del quale una percentuale specificata di campioni generati cade. |
