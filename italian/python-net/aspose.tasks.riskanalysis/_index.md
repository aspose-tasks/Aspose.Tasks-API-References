Contiene classi per creare il Rapporto di Analisi del Rischio.

## Classi
| Classe | Descrizione |
| :- | :- |
| [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) | Rappresenta un risultato dell'analisi del rischio. |
| [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) | Specifica le impostazioni per eseguire l'analisi del rischio. |
| [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) | Esegue una simulazione Monte Carlo basata sulle impostazioni di analisi del rischio specificate. |
| [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) | Rappresenta un elemento che memorizza dati statistici per l'attività del progetto analizzato. |
| [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) | Rappresenta una collezione contenente le istanze della classe [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) | Rappresenta un modello di rischio per un'attività di progetto. |
| [RiskPatternCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskpatterncollection/) | Rappresenta una collezione contenente le istanze della classe [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
## Enumerazioni
| Enumerazione | Descrizione |
| :- | :- |
| [ConfidenceLevel](/tasks/python-net/aspose.tasks.riskanalysis/confidencelevel/) | Specifica i livelli di confidenza supportati utilizzati nell'analisi del rischio che corrispondono al <br/>            percentuale di tempo in cui i valori effettivi saranno compresi tra le stime ottimistiche e pessimistiche. |
| [ProbabilityDistributionType](/tasks/python-net/aspose.tasks.riskanalysis/probabilitydistributiontype/) | Specifica i tipi di distribuzioni di probabilità supportate. |
| [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) | Specifica i campi delle attività per i quali vengono raccolte le informazioni statistiche durante l'analisi del rischio. |
