## RiskAnalyzer class

Esegue una simulazione Monte Carlo basata sulle impostazioni di analisi del rischio specificate.

Il tipo RiskAnalyzer espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| RiskAnalyzer(settings) | Inizializza una nuova istanza della classe [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| settings | Ottiene o imposta l'istanza della classe [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) che definisce le impostazioni necessarie per l'analisi del rischio. |
## Methods
| Nome | Descrizione |
| :- | :- |
| analyze(project) | Esegue l'analisi del rischio per il progetto specificato. L'analisi si basa su una simulazione Monte Carlo e il risultato è un'istanza della classe [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/). |
