Contiene classi per lavorare con database.

## Classi
| Classe | Descrizione |
| :- | :- |
| [DbSettings](/tasks/python-net/aspose.tasks.connectivity/dbsettings/) | Consente di specificare le impostazioni per leggere dal database del progetto. |
| [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) | Consente di impostare le opzioni necessarie per leggere i dati del progetto dal formato MPD (formato file del database MS Access). |
| [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) | Consente di impostare le opzioni necessarie per leggere i dati del progetto dal database MS Project Server. |
| [PrimaveraDbSettings](/tasks/python-net/aspose.tasks.connectivity/primaveradbsettings/) | Consente di impostare le opzioni necessarie per leggere i dati del progetto dal database Primavera. |
