## MspDbSettings class

Consente di impostare le opzioni necessarie per leggere i dati del progetto dal database MS Project Server.

Il tipo MspDbSettings espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Inizializza una nuova istanza della classe [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| connection_string | Ottiene o imposta la stringa di connessione. |
| provider_invariant_name | Ottiene o imposta il nome invariabile del provider che viene utilizzato per ottenere un'istanza della classe. |
| project_guid | Ottiene il guid del progetto da leggere. |
| schema | Ottiene o imposta lo schema del MS Project Server.<br/>            Il valore predefinito è "pub". |
