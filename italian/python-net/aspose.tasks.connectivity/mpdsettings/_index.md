## MpdSettings class

Consente di impostare le opzioni necessarie per leggere i dati del progetto dal formato MPD (formato file del database MS Access).

Il tipo MpdSettings espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| MpdSettings(connection_string, project_id) | Inizializza una nuova istanza della classe [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| connection_string | Ottiene o imposta la stringa di connessione. |
| provider_invariant_name | Ottiene o imposta il nome invariabile del provider che viene utilizzato per ottenere un'istanza della classe. |
| project_id | Ottiene l'ID del progetto da leggere. |
