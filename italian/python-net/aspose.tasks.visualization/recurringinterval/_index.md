## RecurringInterval class

Rappresenta gli intervalli ricorrenti utilizzati nelle linee di avanzamento di una vista Gantt Chart.

Il tipo RecurringInterval espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| RecurringInterval() | Inizializza una nuova istanza della classe RecurringInterval |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| interval | Ottiene o imposta l'intervallo ricorrente.<br/>            Può essere qualsiasi valore del tipo [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | Ottiene o imposta il numero del giorno giornaliero. |
| daily_workday | Ottiene o imposta un valore che indica se un giorno è lavorativo per le linee di avanzamento giornaliere. |
| weekly_week_number | Ottiene o imposta il numero della settimana per le linee di avanzamento settimanali. |
| monthly_day | Ottiene o imposta un valore che indica se mostrare le linee di avanzamento mensili per giorno. |
| monthly_day_day_number | Ottiene o imposta il numero del giorno delle linee di avanzamento mensili. |
| monthly_day_month_number | Ottiene o imposta il numero del mese delle linee di avanzamento mensili. |
| monthly_first_last | Ottiene o imposta un valore che indica se mostrare le linee di avanzamento per il primo o l'ultimo giorno predefinito. |
| monthly_first_last_month_number | Ottiene o imposta il numero del mese delle linee di avanzamento, che sono mostrate per il primo o l'ultimo giorno predefinito. |
| monthly_first_last_day | Ottiene o imposta il tipo di primo o ultimo giorno delle linee di avanzamento mensili. |
| weekly_days | Ottiene un elenco di giorni per le linee di avanzamento settimanali. |
