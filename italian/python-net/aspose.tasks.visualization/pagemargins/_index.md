## PageMargins class

Rappresenta i margini di pagina per la stampa.

Il tipo PageMargins espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PageMargins() | Inizializza una nuova istanza della classe PageMargins |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| top | Ottiene o imposta la dimensione del margine superiore in centimetri. |
| bottom | Ottiene o imposta la dimensione del margine inferiore in centimetri. |
| left | Ottiene o imposta la dimensione del margine sinistro in centimetri. |
| right | Ottiene o imposta la dimensione del margine destro in centimetri. |
| borders | Ottiene o imposta una posizione dove stampare i bordi. Può essere uno dei valori dell'enumerazione [Border](/tasks/python-net/aspose.tasks.visualization/border/). |
