## Timescale enumeration

Definisce le opzioni che specificano come renderizzare la scala temporale nelle viste Gantt Chart, Task Usage o Resource Usage quando il progetto viene esportato in un formato grafico.

## Members
| Nome membro | Descrizione |
| :- | :- |
| DEFINED_IN_VIEW | Utilizza le impostazioni della scala temporale definite nelle proprietà della vista progetto: [bottom_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/),<br/>            [middle_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/), [top_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/).<br/>            Valido per i formati che contengono dati di vista. Ad esempio, progetti letti dal formato MPP. |
| DAYS | Scala temporale a due livelli predefinita in cui il livello minimo di dettaglio è un giorno. |
| THIRDS_OF_MONTHS | Scala temporale a due livelli predefinita in cui il livello di dettaglio è un terzo di mese. |
| MONTHS | Scala temporale a due livelli predefinita in cui il livello minimo di dettaglio è un mese. |
