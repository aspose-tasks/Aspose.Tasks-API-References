## TextStyle class

Modifica lo stile visivo del testo per un elemento nella vista progetto.

Il tipo TextStyle espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextStyle() | Inizializza una nuova istanza della classe [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) con impostazioni predefinite. |
| TextStyle(font_size, font_style) | Inizializza una nuova istanza della classe TextStyle |
| TextStyle(font_style) | Inizializza una nuova istanza della classe [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) con il carattere predefinito e le dimensioni e lo stile del carattere specificati. |
| TextStyle(font) | Inizializza una nuova istanza della classe [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) con le impostazioni del carattere specificate. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| font | Ottiene o imposta il carattere dello stile di testo. |
| color | Ottiene o imposta il colore del testo. |
| item_type | Ottiene o imposta il [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) dello stile di testo. |
| background_pattern | Ottiene o imposta il modello di sfondo dello stile di testo.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Ottiene o imposta il colore di sfondo dello stile di testo.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
