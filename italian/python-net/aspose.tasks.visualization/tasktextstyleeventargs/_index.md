## TaskTextStyleEventArgs class

Questa classe rappresenta un insieme di dati relativi al rendering del contenuto delle celle della tabella.

Il tipo TaskTextStyleEventArgs espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| cell_text_style | Ottiene o imposta TextStyle che verrà utilizzato per disegnare il contenuto della cella. Questo oggetto può essere usato per personalizzare l'aspetto di una cella di tabella. |
| task | Ottiene [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) che corrisponde alla riga attualmente renderizzata. |
| column | Ottiene [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) a cui appartiene la cella attualmente renderizzata. |
