## PageInfo class

Rappresenta i dati di impostazione della pagina presenti nel formato file MPP e utilizzati per la stampa.

Il tipo PageInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PageInfo() | Inizializza una nuova istanza della classe [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/). <br/>            Rappresenta i dati di impostazione della pagina presenti nel formato file MPP e utilizzati per la stampa. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| header | Ottiene o imposta l'istanza della classe [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) che rappresenta i dati dell'intestazione. |
| footer | Ottiene o imposta un'istanza della classe [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) che rappresenta i dati del piè di pagina. |
| name | Ottiene il nome della vista per la quale vengono utilizzati i dati di configurazione. |
| page_settings | Ottiene un'istanza della classe [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) che specifica le impostazioni di stampa della pagina. |
| page_view_settings | Ottiene un'istanza della classe [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) che specifica le impostazioni di stampa della vista della pagina. |
| margins | Ottiene un'istanza della classe [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) che specifica i margini della pagina. |
| legend | Ottiene o imposta un'istanza della classe [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) che specifica le opzioni di rendering della legenda della pagina. |
