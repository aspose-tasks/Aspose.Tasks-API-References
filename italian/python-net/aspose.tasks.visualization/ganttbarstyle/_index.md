## GanttBarStyle class

Rappresenta uno stile di barra utilizzato da MSP nella visualizzazione del diagramma di Gantt.

Il tipo GanttBarStyle espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GanttBarStyle() | Inizializza una nuova istanza della classe [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| bottom_field | Ottiene o imposta i dati da visualizzare nella parte inferiore della barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| end_shape | Ottiene o imposta una forma finale della barra. |
| end_shape_color | Ottiene o imposta un colore della forma finale. |
| end_shape_type | Ottiene o imposta un tipo della forma finale.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| from_address | Ottiene o imposta la posizione del punto di partenza della barra Gantt.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | Ottiene o imposta i dati da visualizzare all'interno della barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| left_field | Ottiene o imposta i dati da visualizzare a sinistra della barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| middle_fill_pattern | Ottiene o imposta un modello di riempimento della barra Gantt. |
| middle_shape | Ottiene o imposta una forma intermedia della barra. |
| middle_shape_color | Ottiene o imposta un colore della forma intermedia. |
| name | Ottiene o imposta un nome dello stile. |
| right_field | Ottiene o imposta i dati da visualizzare a destra della barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| row | Ottiene o imposta un numero di riga. |
| show_for_categories | Ottiene o imposta le categorie di attività per le quali lo stile è applicato. È applicabile agli stili padre (o comuni) delle barre nel diagramma di Gantt<br/>            (vedi [bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| show_for_task_uid | Ottiene o imposta l'ID univoco di un'attività per la quale lo stile è applicato. È applicabile agli stili specifici per attività delle barre nel diagramma di Gantt (vedi [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | Ottiene o imposta una forma di partenza della barra. |
| start_shape_color | Ottiene o imposta un colore della forma di partenza. |
| start_shape_type | Ottiene o imposta un tipo della forma di partenza. |
| to | Ottiene o imposta la posizione del punto finale della barra Gantt. |
| top_field | Ottiene o imposta i dati da visualizzare in alto della barra. |
| parent_style | Ottiene o imposta lo stile padre (o comune) per lo stile personalizzato specifico per attività. |
