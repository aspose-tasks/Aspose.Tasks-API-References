## BarStyle class

Modifica lo stile visivo della barra per l'elemento nella visualizzazione del progetto.

Il tipo BarStyle espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| BarStyle() | Inizializza una nuova istanza della classe [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| bar_color | Ottiene o imposta aspose.pydrawing.Color dello stile della barra. |
| start_shape_color | Ottiene o imposta aspose.pydrawing.Color della forma all'inizio della barra. |
| start_shape_type | Ottiene o imposta un tipo della forma di partenza. |
| end_shape_color | Ottiene o imposta aspose.pydrawing.Color della forma alla fine della barra. |
| end_shape_type | Ottiene o imposta un tipo della forma finale.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | Ottiene o imposta [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) dello stile della barra. |
| bar_shape | Ottiene o imposta [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) dello stile della barra. |
| start_shape | Ottiene o imposta [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) all'inizio della barra. |
| end_shape | Ottiene o imposta [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) alla fine della barra. |
| text_style | Ottiene o imposta lo stile del testo della barra. |
| left_field | Ottiene o imposta un campo da visualizzare a sinistra della barra. |
| top_field | Ottiene o imposta un campo da visualizzare in alto della barra. |
| right_field | Ottiene o imposta un campo da visualizzare a destra della barra. |
| bottom_field | Ottiene o imposta un campo da visualizzare nella parte inferiore della barra. |
| inside_field | Ottiene o imposta un campo da visualizzare all'interno della barra. |
| from_address | Ottiene o imposta la posizione del punto di partenza della barra Gantt.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | Ottiene o imposta la posizione del punto finale della barra Gantt. |
