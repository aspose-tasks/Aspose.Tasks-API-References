## Gridlines class

Rappresenta le linee della griglia che appaiono in una visualizzazione GanttChart.

Il tipo Gridlines espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Gridlines() | Inizializza una nuova istanza della classe Gridlines |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| interval | Ottiene o imposta il numero da 0 a 99 che specifica l'intervallo tra le linee della griglia. |
| interval_color | Ottiene o imposta il colore delle linee secondarie della griglia. |
| interval_pattern | Ottiene o imposta il modello di linea per le linee della griglia secondarie. |
| normal_color | Ottiene o imposta il colore delle linee della griglia normali. |
| normal_pattern | Ottiene o imposta il modello di linea per le linee della griglia normali. |
| tipo | Ottiene o imposta il tipo di linea della griglia. |
