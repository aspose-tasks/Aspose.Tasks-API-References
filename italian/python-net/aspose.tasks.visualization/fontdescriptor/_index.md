## FontDescriptor class

Rappresenta le informazioni sul carattere.

Il tipo FontDescriptor espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| FontDescriptor(font_family, size) | Inizializza una nuova istanza della classe FontDescriptor |
| FontDescriptor(font_family, size, style) | Inizializza una nuova istanza della classe FontDescriptor |
| FontDescriptor(font, style) | Inizializza una nuova istanza della classe [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) con la famiglia di caratteri, la dimensione e lo stile specificati. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| font_family | Ottiene il nome della famiglia del carattere. |
| size | Ottiene la dimensione del carattere. |
| style | Ottiene lo stile del carattere. |
