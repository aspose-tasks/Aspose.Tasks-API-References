## TimescaleUnit enumeration

Specifica l'unità di tempo per qualsiasi livello di una scala temporale in un diagramma di Gantt o in altre visualizzazioni a fasi temporali.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Indica Nessuno. Il livello della scala temporale è nascosto. |
| MINUTES | Indica l'unità di scala temporale Minuti. |
| HOURS | Indica l'unità di scala temporale ore. |
| DAYS | Indica l'unità di scala temporale giorni. |
| WEEKS | Indica l'unità di scala temporale settimane. |
| THIRDS_OF_MONTHS | Indica l'unità di scala temporale terzi di mese. |
| MONTHS | Indica l'unità di scala temporale mesi. |
| QUARTERS | Indica l'unità di scala temporale trimestri di anno. |
| HALF_YEARS | Indica l'unità di scala temporale semestri. |
| YEARS | Indica l'unità di scala temporale anni. |
