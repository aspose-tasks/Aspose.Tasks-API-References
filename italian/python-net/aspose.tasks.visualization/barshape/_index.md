## BarShape enumeration

Forma del rettangolo della barra.

## Members
| Nome membro | Descrizione |
| :- | :- |
| FULL | Indica la forma a barra rettangolare Full. |
| HALF_HEIGHT | Indica la forma a barra rettangolare a mezza altezza allineata in alto. |
| HALF_HEIGHT_BOTTOM | Indica la forma a barra rettangolare a mezza altezza allineata in basso. |
| THIN | Indica forma di linea centrata. |
| NONE | Indica forma di barra Nessuna. |
| MIDDLE | Indica forma di linea centrata. |
| LINE_BOTTOM | Indica forma di linea allineata in basso. |
| LINE_TOP | Indica forma di linea allineata in alto. |
