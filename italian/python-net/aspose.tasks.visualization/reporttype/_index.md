## ReportType enumeration

Tipo del report grafico del progetto.

## Members
| Nome membro | Descrizione |
| :- | :- |
| PROJECT_OVERVIEW | Mostra la data di inizio e fine del progetto, <br/>            percentuale della durata completata, percentuale completata per le attività di livello superiore e le prossime pietre miliari. |
| COST_OVERVIEW | Mostra le date di inizio e fine del progetto, il costo attuale<br/>            programmato e residuo, % completato e i valori di costo per le attività di livello superiore. |
| WORK_OVERVIEW | Mostra il lavoro di baseline, reale e residuo per ogni attività di livello superiore e il lavoro per le risorse di lavoro. |
| RESOURCE_OVERVIEW | Mostra il lavoro di baseline, reale e residuo per risorsa. |
| RESOURCE_COST_OVERVIEW | Mostra il costo di baseline, reale e residuo per risorsa. |
| CRITICAL_TASKS | Mostra le attività del progetto che sono critiche. |
| LATE_TASKS | Mostra le attività del progetto in ritardo. |
| MILESTONES | Mostra le pietre miliari in ritardo, imminenti e completate. |
| UPCOMING_TASK | Mostra le attività in scadenza durante la settimana corrente e le attività che iniziano durante la settimana corrente. |
| COST_OVERRUNS | Mostra la variazione dei costi per attività e risorsa. |
| TASK_COST_OVERVIEW | Mostra il costo di baseline, effettivo e residuo di tutte le attività di livello superiore. |
| OVERALLOCATED_RESOURCES | Mostra il numero di ore di lavoro rimanenti per le risorse sovrallocate. |
| SLIPPING_TASKS | Mostra le attività che devono terminare dopo le loro date di fine di baseline (la baseline deve essere impostata). |
| BEST_PRACTICE_ANALYZER | Mostra le attività senza lavoro effettivo, attività non assegnate, <br/>            attività con durata inferiore a 8 ore e riepiloghi assegnati alle risorse. |
| BURNDOWN | Includi i grafici di burndown del lavoro e del compito.<br/>            Il grafico di burndown del lavoro mostra quanto lavoro le persone hanno completato, quanto è programmato per essere completato prima della data di fine del progetto, <br/>            e la stima di baseline di quanto lavoro sarebbe completato a questo punto del progetto.<br/>            Il grafico di burndown del compito mostra il numero di attività completate, il numero rimanente, <br/>            e la stima di baseline di quante sarebbero completate a questo punto del progetto. |
| CASH_FLOW | Mostra i costi e i costi cumulativi per trimestre di tutte le attività di livello superiore. |
