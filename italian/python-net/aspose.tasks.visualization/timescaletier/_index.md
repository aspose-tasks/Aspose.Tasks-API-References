## TimescaleTier class

Rappresenta un singolo livello della scala temporale in un Gantt Chart.

Il tipo TimescaleTier espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TimescaleTier() | Inizializza una nuova istanza della classe [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Inizializza una nuova istanza della classe TimescaleTier |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| count | Ottiene o imposta l'intervallo dell'unità di tempo in cui mostrare le etichette per il livello.<br/>            Il valore predefinito è 1. |
| label | Ottiene o imposta l'etichetta data [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) per il livello della scala temporale. |
| alignment | Ottiene o imposta come allineare le etichette all'interno di ogni periodo di tempo del livello ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Ottiene o imposta un valore che indica se basare le etichette del livello sull'anno fiscale. |
| show_ticks | Ottiene o imposta un valore che indica se mostrare i segni di spunta che separano i periodi di tempo nel livello. |
| unit | Ottiene o imposta l'unità di scala temporale [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) per il livello della scala temporale.<br/>            Il valore predefinito è |
| render_label_on_each_page | Ottiene o imposta il flag che definisce se le etichette data devono essere renderizzate su ogni pagina quando un periodo di tempo si estende su più pagine.<br/>            Se il valore è 'true', quando il periodo di tempo si estende su più pagine, le etichette data per il periodo sono renderizzate su ogni pagina.<br/>            Se il valore è 'false', l'etichetta data è renderizzata una sola volta in base al valore della proprietà [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
