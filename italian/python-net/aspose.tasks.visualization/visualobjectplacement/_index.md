## VisualObjectPlacement class

Rappresenta la posizione e l'aspetto di [OleObject](/tasks/python-net/aspose.tasks/oleobject/) in una vista.

Il tipo VisualObjectPlacement espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| VisualObjectPlacement() | Inizializza una nuova istanza della classe [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| ole_object_id | Ottiene o imposta l'Id dell'oggetto [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
| task_id | Ottiene o imposta l'Id dell'attività se l'opzione 'Attach to task' è selezionata, -1 altrimenti. |
| width | Ottiene o imposta la larghezza visualizzata dell'oggetto visuale. |
| height | Ottiene o imposta l'altezza visualizzata dell'oggetto visuale. |
| vertical_offset | Ottiene o imposta lo spostamento verticale dell'oggetto visuale. |
| horizontal_offset | Ottiene o imposta lo spostamento orizzontale dell'oggetto visuale. |
| timescale_date | Ottiene o imposta la data di posizionamento dell'oggetto visuale quando l'opzione 'Attach to timescale' è selezionata. |
| attachment_point | Ottiene o imposta l'allineamento dell'oggetto visuale rispetto a un'attività quando l'opzione 'Attach to task' è selezionata. |
| border_line_color | Ottiene o imposta il colore della linea del bordo. |
| border_line_thickness | Ottiene o imposta lo spessore della linea del bordo (i valori consentiti sono da 0 a 5). |
| fill_color | Ottiene o imposta il colore di riempimento. |
| fill_pattern | Ottiene o imposta il modello di riempimento. |
