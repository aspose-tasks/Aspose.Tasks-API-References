## HeaderFooterInfo class

Rappresenta il contenuto visivo dell'intestazione, del piè di pagina o della legenda utilizzato per la stampa \ rendering delle visualizzazioni.

Il tipo HeaderFooterInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| HeaderFooterInfo() | Inizializza una nuova istanza della classe [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/). |

| :- | :- |
