## PageViewSettings class

Rappresenta le impostazioni di stampa per una vista progetto.

Il tipo PageViewSettings espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PageViewSettings() | Inizializza una nuova istanza della classe PageViewSettings |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| first_columns_count | Ottiene o imposta il numero delle prime colonne da stampare su tutte le pagine. |
| fit_timescale_to_end_of_page | Ottiene o imposta un valore che indica se adattare la scala temporale alla fine di una pagina durante la stampa. |
| print_all_sheet_columns | Ottiene o imposta un valore che indica se stampare tutte le colonne del foglio di una vista. |
| print_blank_pages | Ottiene o imposta un valore che indica se stampare pagine vuote di una vista. |
| print_first_columns_count_on_all_pages | Ottiene o imposta un valore che indica se stampare un numero specificato di prime colonne su tutte le pagine. |
| print_notes | Ottiene o imposta un valore che indica se stampare le note. |
