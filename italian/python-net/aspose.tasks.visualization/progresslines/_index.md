## ProgressLines class

Rappresenta le linee di avanzamento in una vista Gantt Chart.

Il tipo ProgressLines espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ProgressLines() | Inizializza una nuova istanza della classe ProgressLines |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| display_at_current_date | Ottiene o imposta un valore che indica se visualizzare la linea di avanzamento alla data corrente. |
| display_at_recurring_intervals | Ottiene o imposta un valore che indica se visualizzare la linea di avanzamento a intervalli ricorrenti. |
| recurring_interval | Ottiene o imposta l'intervallo ricorrente.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Ottiene o imposta un valore che indica se visualizzare le linee di avanzamento dall'inizio della data di inizio del progetto. |
| begin_at_date | Ottiene o imposta la data da cui visualizzare le linee di avanzamento. |
| display_selected | Ottiene o imposta un valore che indica se visualizzare le linee di avanzamento nelle date selezionate. |
| is_baseline_plan | Ottiene o imposta un valore che indica se visualizzare le linee di avanzamento per il piano di base o reale. |
| show_date | Ottiene o imposta un valore che indica se mostrare la data per ogni linea di avanzamento. |
| date_format | Ottiene o imposta il formato della data ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Ottiene o imposta il carattere usato per l'etichetta della linea di avanzamento. |
| line_pattern | Ottiene o imposta il modello di linea della linea di avanzamento corrente.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Ottiene o imposta il colore della linea per la linea di avanzamento corrente. |
| progress_point_shape | Ottiene o imposta la forma del punto di avanzamento.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Ottiene o imposta il colore del punto di avanzamento. |
| other_line_pattern | Ottiene o imposta il modello di linea per l'altra linea di avanzamento. |
| other_line_color | Ottiene o imposta il colore dell'altra linea di avanzamento. |
| other_progress_point_shape | Ottiene o imposta la forma del punto di avanzamento dell'altra linea di avanzamento. |
| other_progress_point_color | Ottiene o imposta il colore dell'altro punto di avanzamento. |
| selected_dates | Ottiene l'elenco delle date selezionate per visualizzare le linee di avanzamento. |
