## PageSettings class

Rappresenta le impostazioni di stampa per una pagina della vista progetto.

Il tipo PageSettings espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PageSettings() | Inizializza una nuova istanza della classe [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Rappresenta le impostazioni di stampa per una pagina della visualizzazione del progetto. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_portrait | Ottiene o imposta un valore che indica se l'orientamento della pagina è verticale; restituisce false se l'orientamento della pagina è orizzontale. |
| adjust_to_percent_of_normal_size | Ottiene o imposta un valore che indica se regolare la stampa alla percentuale specificata ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) della dimensione normale. |
| percent_of_normal_size | Ottiene o imposta una percentuale della dimensione normale per regolare la stampa. |
| pages_in_width | Ottiene o imposta un numero di pagine in larghezza da stampare. |
| pages_in_height | Ottiene o imposta un numero di pagine in altezza da stampare. |
| paper_size | Ottiene o imposta una dimensione della carta. Può essere uno dei valori dell'enumerazione [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | Ottiene o imposta un intero che rappresenta uno dei valori di PrinterPaperSize o un ID di dimensione pagina personalizzata.<br/>            Questo valore può essere usato per ottenere PaperSize dalle impostazioni del sistema operativo |
| first_page_number | Ottiene o imposta il numero della prima pagina per la stampa. |
