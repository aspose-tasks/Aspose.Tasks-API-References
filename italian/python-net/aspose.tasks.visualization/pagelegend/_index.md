## PageLegend class

Rappresenta una legenda di pagina utilizzata per la stampa del progetto.

Il tipo PageLegend espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PageLegend() | Inizializza una nuova istanza della classe PageLegend |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| left_text | Ottiene o imposta il testo allineato a sinistra da visualizzare nell'elemento padre. |
| centered_text | Ottiene o imposta il testo centrato da visualizzare nell'elemento padre. |
| right_text | Ottiene o imposta il testo allineato a destra da visualizzare nell'elemento padre. |
| left_image | Ottiene o imposta l'immagine allineata a sinistra da visualizzare nell'elemento padre. |
| centered_image | Ottiene o imposta l'immagine centrata da visualizzare nell'elemento padre. |
| right_image | Ottiene o imposta l'immagine allineata a destra da visualizzare nell'elemento padre. |
| left_image_size | Ottiene o imposta la dimensione visualizzata dell'immagine a sinistra. |
| centered_image_size | Ottiene o imposta la dimensione visualizzata dell'immagine centrale. |
| right_image_size | Ottiene o imposta la dimensione visualizzata dell'immagine a destra. |
| legend_on | Ottiene o imposta le pagine su cui appare la legenda. Può essere uno dei valori dell'enumerazione [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | Ottiene o imposta la larghezza della parte sinistra (che contiene il nome e la data del progetto per impostazione predefinita) della legenda in centimetri. |
