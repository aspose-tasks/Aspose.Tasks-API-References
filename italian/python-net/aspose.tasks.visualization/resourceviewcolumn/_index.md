## ResourceViewColumn class

Classe di vista del progetto utilizzata nella vista ResourceUsage e nella vista ResourceSheet.

Il tipo ResourceViewColumn espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ResourceViewColumn(width, field) | Inizializza una nuova istanza della classe ResourceViewColumn |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| field | Campo colonna. <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/). |
| name | Ottiene il nome della colonna. |
| string_alignment | Ottiene o imposta l'allineamento del testo (può essere uno dei valori dell'enumerazione [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Ottiene la larghezza della colonna. |
| text_style_modification_callback | Ottiene o imposta il callback che può essere usato per personalizzare l'aspetto delle celle della colonna. |
## Methods
| Nome | Descrizione |
| :- | :- |
| get_column_text(resource) | Converte la risorsa corrente nel testo della colonna. |
