## TableTextStyle class

Rappresenta uno stile di testo in una tabella di vista.

Il tipo TableTextStyle espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TableTextStyle(row_uid) | Inizializza una nuova istanza della classe TableTextStyle |
| TableTextStyle(row_uid, font) | Inizializza una nuova istanza della classe TableTextStyle |
| TableTextStyle(row_uid, font_size, font_style) | Inizializza una nuova istanza della classe TableTextStyle |
| TableTextStyle(row_uid, font_style) | Inizializza una nuova istanza della classe TableTextStyle |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| font | Ottiene o imposta il carattere dello stile di testo. |
| color | Ottiene o imposta il colore del testo. |
| item_type | Restituisce un valore dell'enumerazione [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/). |
| background_pattern | Ottiene o imposta il modello di sfondo dello stile di testo.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Ottiene o imposta il colore di sfondo dello stile di testo.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| row_uid | Ottiene un ID univoco di riga. |
| field | Ottiene o imposta un campo a cui applicare lo stile.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/tabletextstyle/). |
