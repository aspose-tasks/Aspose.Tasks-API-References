## LevelingOptions class

Consente di specificare i parametri del livellamento delle risorse.

Il tipo LevelingOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| LevelingOptions() | Inizializza una nuova istanza della classe [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) . |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| start_date | Ottiene o imposta la data di inizio del periodo di livellamento. Il valore predefinito è la data di inizio del progetto. |
| finish_date | Ottiene o imposta la data di fine del periodo di livellamento. Il valore predefinito è la data di fine del progetto. |
| risorse | Ottiene o imposta l'elenco delle risorse che saranno livellate. Se viene impostato null, tutte le risorse del progetto saranno livellate. |
| leveling_order | Ottiene l'ordine in cui l'algoritmo di livellamento ritarda le attività che hanno sovrallocazioni.<br/>            Dopo la determinazione delle attività che causano la sovrallocazione e quali attività possono essere ritardate, viene utilizzato l'ordine specificato per stabilire quale attività deve essere ritardata per prima. |
| message_level | Ottiene o imposta il livello dei messaggi di log generati da Aspose.Tasks durante il livellamento delle risorse. |
| message_handler | Ottiene o imposta la callback del gestore dei messaggi che può essere utilizzata per intercettare i messaggi di log prodotti da Aspose.Tasks durante il livellamento delle risorse. |
