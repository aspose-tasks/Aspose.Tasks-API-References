## LevelingOrder enumeration

Definisce i possibili valori dell'ordine di livellamento.

## Members
| Nome membro | Descrizione |
| :- | :- |
| STANDARD | Le seguenti proprietà sono prese in considerazione: relazioni di predecessore, margine totale (un'attività con margine totale più alto viene ritardata per prima), data di inizio, priorità.<br/>            Questo è il valore predefinito. |
| ID_ONLY | Le attività sono ritardate in ordine crescente di Id. |
| PRIORITY_THEN_STANDARD | La priorità è considerata per prima, poi le stesse proprietà di Standard. |
