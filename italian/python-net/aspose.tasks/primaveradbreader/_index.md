## PrimaveraDbReader class

Rappresenta un lettore per leggere le informazioni di progetto dal database Primavera.

Il tipo PrimaveraDbReader espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PrimaveraDbReader(db_settings) | Inizializza una nuova istanza della classe [PrimaveraXerReader](/tasks/python-net/aspose.tasks/primaveraxerreader/). |
## Methods
| Nome | Descrizione |
| :- | :- |
| get_project_uids() | Restituisce un elenco degli identificatori univoci dei progetti. |
| get_project_infos() | Restituisce un elenco degli oggetti di informazioni brevi del progetto. |
| load_project(project_uid) | Carica il progetto con l'identificatore univoco specificato. |
