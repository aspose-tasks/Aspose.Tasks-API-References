## WeekDay class

Rappresenta un giorno della settimana che definisce sia i giorni regolari di una settimana sia i giorni di eccezione in un calendario.

Il tipo WeekDay espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| WeekDay(day_type) | Inizializza una nuova istanza della classe [WeekDay](/tasks/python-net/aspose.tasks/weekday/) con il tipo di giorno specificato. |
| WeekDay(day_type, working_times) | Inizializza una nuova istanza della classe WeekDay |
| WeekDay(day_type, working_times) | Inizializza una nuova istanza della classe [WeekDay](/tasks/python-net/aspose.tasks/weekday/) con il tipo di giorno specificato e i periodi di tempo lavorativi. |
| WeekDay() | Inizializza una nuova istanza della classe [WeekDay](/tasks/python-net/aspose.tasks/weekday/) con il tipo di giorno specificato. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| day_type | Ottiene il tipo di un giorno. |
| day_working | Ottiene o imposta un valore che indica se la data o il tipo di giorno specificati sono lavorativi. |
| from_date | Ottiene o imposta l'inizio di un intervallo di eccezione. |
| to_date | Ottiene o imposta la fine di un intervallo di eccezione. |
| working_times | Ottiene WorkingTimeCollection per questa istanza di WeekDay.<br/>            La collezione di orari di lavoro che definiscono il tempo lavorato nel giorno della settimana. |
## Methods
| Nome | Descrizione |
| :- | :- |
| create_default_working_day(day_type) | Crea un giorno lavorativo predefinito. |
| set_default_working_time(day) | Imposta i periodi di tempo predefiniti per il giorno della settimana specificato. |
| get_working_time() | Restituisce il tempo di lavoro per un giorno della settimana. |
| clone() | Restituisce una copia profonda del giorno della settimana. |
