## WorkingTime class

Rappresenta un orario di lavoro durante un giorno della settimana.

Il tipo WorkingTime espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| WorkingTime(from_time, to_time) | Inizializza una nuova istanza della classe [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) con un intervallo con gli orari di inizio e fine specificati. |
| WorkingTime(from_time, to_time) | Inizializza una nuova istanza della classe [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) con un elemento di intervallo con gli orari di inizio e fine specificati. |
| WorkingTime(from_hours, to_hours) | Inizializza una nuova istanza della classe WorkingTime |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| from_address | Ottiene l'inizio di un periodo di lavoro. |
| to | Ottiene la fine di un periodo di lavoro. |
