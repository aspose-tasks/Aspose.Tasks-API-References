## Methods
| Nome | Descrizione |
| :- | :- |
| get_timephased_data(start, end, timephased_type) | Restituisce l'oggetto [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) con i valori [timephased_data](/tasks/python-net/aspose.tasks/task/) compresi tra le date di inizio e fine specificate per il tipo di dati a intervalli temporali indicato. |
| get_timephased_data(start, end) | Restituisce l'oggetto [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) con i valori [timephased_data](/tasks/python-net/aspose.tasks/task/) compresi tra le date di inizio e fine specificate per il tipo di dati a intervalli temporali indicato. |
| move_to_sibling(before_task) | Sposta l'attività corrente allo stesso livello di struttura prima dell'attività specificata.<br/>            Se ParentProject.CalculationMode è None, l'utente dovrebbe invocare Project.Recalculate() dopo aver utilizzato questo metodo (riprogrammerà tutte le attività del progetto (date di inizio/fine, imposta date anticipate/posticipate) e calcolerà i campi dipendenti come i margini, il lavoro e i costi, i livelli di struttura).<br/>            Se ParentProject.CalculationMode è Manual, il metodo calcolerà automaticamente solo l'ID dell'attività, il livello di struttura e i numeri di struttura.<br/>            Se ParentProject.CalculationMode è Automatic, il metodo riprogramma automaticamente tutte le attività del progetto<br/>            (date di inizio/fine, imposta date anticipate/posticipate, calcola i margini, il lavoro e i costi, ricalcola gli ID e i livelli di struttura). |
| move_to_sibling(before_task_id) |  |
| select_all_child_tasks() | Raccoglie ricorsivamente tutte le attività figlie di questa attività. |
| clone() | Crea una copia completa di un'attività senza sottotask. |
| equals(other) | Restituisce un valore che indica se questa istanza è uguale a un'attività specificata. |
| delete() | Elimina un'attività dalla raccolta di attività del progetto padre e tutte le sue assegnazioni. |
| outline_indent() | Indenta un'attività nella struttura. |
| outline_outdent() | Promuove un'attività nella struttura. |
