## RecurringTaskParameters class

Rappresenta l'insieme dei parametri utilizzati per creare un'attività ricorrente in un progetto.

Il tipo RecurringTaskParameters espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| RecurringTaskParameters() | Inizializza una nuova istanza della classe [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| duration | Ottiene o imposta la durata di una singola occorrenza dell'attività ricorrente. |
| ignore_resource_calendar | Ottiene o imposta un valore che indica se pianificare l'attività ricorrente anche se non si verifica quando non ci sono risorse disponibili per lavorarci. |
| recurrence_pattern | Ottiene o imposta il modello di ricorrenza dell'attività ricorrente. |
| task_name | Ottiene o imposta il nome dell'attività ricorrente. |
## Methods
| Nome | Descrizione |
| :- | :- |
| set_calendar(project, calendar_name) | Imposta un calendario per l'attività ricorrente. Il calendario è selezionato dalla raccolta di calendari del progetto. |
