## FontResolveEventArgs class

Fornisce gli argomenti per il callback che viene invocato quando il font è risolto.

Il tipo FontResolveEventArgs espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| requested_font_name | Restituisce il nome del font richiesto. |
| resolved_font_name | Restituisce o imposta il nome del font risolto. Può essere impostato per controllare i font usati per renderizzare una vista. |
