## ExtendedAttribute class

Rappresenta attributi estesi.

Il tipo ExtendedAttribute espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| attribute_definition | Restituisce la definizione dell'attributo. |
| field_id | Restituisce l'ID di un campo. |
| duration_value | Ottiene o imposta il valore per gli attributi di tipo 'Duration'. |
| numeric_value | Ottiene o imposta un valore per gli attributi di tipo numerico (Cost, Number). |
| date_value | Ottiene o imposta un valore per gli attributi di tipo data (Date, Start, Finish). |
| flag_value | Ottiene o imposta un valore che indica se un flag è impostato per un attributo di tipo 'Flag'. |
| text_value | Ottiene o imposta un valore per gli attributi di tipo 'Text'. |
| value_guid | Restituisce il GUID di un valore di ricerca. |
| value_read_only | Restituisce un valore che indica se il valore di questa istanza di [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) è di sola lettura. |
| is_error_value | Restituisce se il calcolo del valore dell'attributo esteso ha generato un errore. |
