## OutlineValue class

Rappresenta un valore outline.

Il tipo OutlineValue espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| OutlineValue() | Inizializza una nuova istanza della classe OutlineValue |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| value_id | Ottiene o imposta l'Id univoco di un valore di codice di outline all'interno di un progetto. |
| value_guid | Ottiene un GUID che identifica questo valore tra gli altri nell'intero progetto. |
| tipo | Ottiene o imposta il tipo di codice di struttura. |
| parent_value_id | Ottiene o imposta l'Id di un nodo genitore di un codice di struttura. |
| value | Ottiene o imposta il valore effettivo. |
| duration_value | Ottiene o imposta la durata se il Tipo è Durata. |
| description | Ottiene o imposta la descrizione di un valore di struttura. |
| is_collapsed | Ottiene o imposta un valore che indica se il valore di struttura è compresso o meno. |
