## VbaModuleType enumeration

Specifica il tipo di modulo in un progetto VBA.

## Members
| Nome membro | Descrizione |
| :- | :- |
| DOCUMENT_MODULE | Un tipo di elemento di progetto VBA che specifica un modulo per macro incorporate e operazioni di accesso programmatico associate a un documento. |
| PROCEDURAL_MODULE | Un modulo contenente una raccolta di subroutine e funzioni. |
| CLASS_MODULE | Un modulo che contiene la definizione di un nuovo oggetto. Ogni istanza di una classe crea un nuovo oggetto, e le procedure definite nel modulo diventano proprietà e metodi dell'oggetto. |
| DESIGNER_MODULE | Un modulo che estende i metodi e le proprietà di un controllo ActiveX registrato nel progetto. |
