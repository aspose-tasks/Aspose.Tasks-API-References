## MonthPosition enumeration

Specifica la posizione di un elemento del mese all'interno di un mese.

## Members
| Nome membro | Descrizione |
| :- | :- |
| UNDEFINED | Indica la posizione del mese non definita. |
| FIRST | Indica la prima posizione del mese. |
| SECOND | Indica la seconda posizione del mese. |
| THIRD | Indica la terza posizione del mese. |
| FOURTH | Indica la quarta posizione del mese. |
| LAST | Indica l'ultima posizione del mese. |
