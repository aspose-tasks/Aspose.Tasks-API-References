## FontSettings class

Specifica le impostazioni dei font utilizzate durante il rendering della vista del progetto.

Il tipo FontSettings espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| FontSettings() | Inizializza una nuova istanza della classe FontSettings |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| default_font_name | Ottiene o imposta il font predefinito (o di riserva) per il rendering. |
| use_project_default_font | Ottiene o imposta un valore che indica se il font predefinito deve essere usato per il rendering. |
## Methods
| Nome | Descrizione |
| :- | :- |
| set_font_folders(font_folders, recursive) | Imposta le cartelle dove Aspose.Tasks cerca i font TrueType durante il rendering della vista del progetto. |
