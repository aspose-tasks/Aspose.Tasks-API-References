## ResourceCollection class

Rappresenta una collezione di oggetti [Resource](/tasks/python-net/aspose.tasks/resource/).

Il tipo ResourceCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| parent_project | Ottiene il progetto genitore dell'oggetto ResourceCollection. |
## Methods
| Nome | Descrizione |
| :- | :- |
| add() | Aggiunge una nuova risorsa all'ultima posizione di una collezione di risorse di progetto. |
| add(resource_name) | Aggiunge una nuova risorsa all'ultima posizione di una collezione di risorse di progetto. |
| add(resource_name, before_resource_id) |  |
| to_list() | Converte l'oggetto ResourceCollection in un elenco di oggetti [Resource](/tasks/python-net/aspose.tasks/resource/). |
| get_by_id(id) | Restituisce una risorsa con l'ID specificato. |
| get_by_uid(uid) | Restituisce una risorsa con l'UID specificato. |
