## UsageView class

Rappresenta una vista di utilizzo in un progetto.

Il tipo UsageView espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| filter | Ottiene o imposta un filtro utilizzato in una singola visualizzazione. |
| gruppo | Ottiene o imposta un gruppo della singola vista. |
| uid | Ottiene l'identificatore univoco di una vista. |
| highlight_filter | Ottiene o imposta un valore che indica se Microsoft Project evidenzia il filtro per una singola vista. |
| name | Ottiene o imposta il nome di un oggetto View. |
| screen | Ottiene il tipo di schermo per la singola vista.<br/>            Solo lettura [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Ottiene il genitore dell'oggetto View.<br/>            Solo lettura [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Ottiene o imposta una tabella della singola vista. |
| type | Ottiene il tipo di elemento nella singola vista, come attività o risorse.<br/>            Solo lettura [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Ottiene o imposta un valore che indica se Microsoft Project mostra il nome della singola vista nell'elenco a discesa Vista o Altre viste nel Ribbon. |
| page_info | Ottiene un'istanza della classe [page_info](/tasks/python-net/aspose.tasks/view/). Rappresenta i dati di impostazione della pagina presenti nel formato file mpp. |
| visual_objects_placements | Ottiene una raccolta di oggetti che rappresentano la posizione e l'aspetto di [OleObject](/tasks/python-net/aspose.tasks/oleobject/) nella vista. |
| align_details_data | Ottiene o imposta l'allineamento dei dati dei dettagli. |
| display_details_header_column | Ottiene o imposta un valore che indica se visualizzare la colonna dell'intestazione dei dettagli nella vista o meno. |
| display_short_detail_header_names | Ottiene o imposta un valore che indica se visualizzare i nomi brevi dell'intestazione dei dettagli o meno. |
| repeat_details_header_on_all_rows | Ottiene o imposta un valore che indica se ripetere l'intestazione dei dettagli su tutte le righe di assegnazione o meno. |
| timescale_size_percentage |  |
| bottom_timescale_tier | Ottiene o imposta le impostazioni del livello inferiore della scala temporale della vista.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | Ottiene o imposta le impostazioni del livello intermedio della scala temporale della vista.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | Ottiene o imposta le impostazioni del livello superiore della scala temporale della vista.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
## Methods
| Nome | Descrizione |
| :- | :- |
| compare_to(other) | Confronta l'istanza corrente con un altro oggetto dello stesso tipo e restituisce un intero che indica se l'istanza corrente precede, segue o si trova nella stessa posizione nell'ordine di ordinamento rispetto all'altro oggetto. |
