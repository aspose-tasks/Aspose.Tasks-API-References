## UndefinedConstraintHandlingBehavior enumeration

Specifica il comportamento usato per gestire le attività con vincoli non definiti.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Il comportamento predefinito per il caricamento dal formato XER.<br/>            Non viene eseguita alcuna azione. Il tipo di vincolo dell'attività è impostato su 'ConstraintType.Undefined'. |
| SUBSTITUTE_WITH_START_NO_EARLIER_THAN | I vincoli con tipo 'ConstraintType.StartNoEarlierThan' e data = Start vengono aggiunti per le attività con vincolo 'Undefined'. |
