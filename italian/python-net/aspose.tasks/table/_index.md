## Table class

Rappresenta una tabella in Project

Il tipo Table espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Table() | Inizializza una nuova istanza della classe [Table](/tasks/python-net/aspose.tasks/table/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| name | Ottiene o imposta il nome di un oggetto Table. |
| show_in_menu | Ottiene o imposta un valore che indica se il progetto mostra il nome della tabella nell'elenco a discesa Tables nella scheda Visualizza del Ribbon. |
| table_fields | Ottiene una collezione TableFields che rappresenta i campi nella tabella. |
| table_type | Ottiene o imposta il tipo di tabella per la tabella specificata. |
| uid | Ottiene l'identificatore univoco di una tabella. |
| row_height | Ottiene o imposta l'altezza della riga in una tabella, dove l'altezza della riga è il numero di righe di testo. |
| date_format | Ottiene o imposta il formato data della tabella. |
| adjust_header_row_height | Ottiene o imposta un valore che indica se l'altezza della riga di intestazione della tabella può essere regolata. |
| show_add_new_column | Ottiene o imposta un valore che indica se mostrare l'interfaccia 'Add New Column'. |
| lock_first_column | Ottiene o imposta un valore che indica se la prima colonna di una tabella è bloccata o modificabile. |
