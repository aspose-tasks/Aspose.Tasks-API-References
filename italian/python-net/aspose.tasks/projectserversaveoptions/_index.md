## ProjectServerSaveOptions class

Consente di specificare opzioni aggiuntive quando il progetto viene salvato su Project Server o Project Online.

Il tipo ProjectServerSaveOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ProjectServerSaveOptions() | Inizializza una nuova istanza della classe [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| project_name | Ottiene o imposta il nome di un progetto visualizzato nell'elenco dei progetti di Project Server \ Project Online. Deve essere univoco all'interno dell'istanza di Project Server \ Project Online.<br/>            Se il valore è omesso, verrà utilizzato il valore della proprietà Prj.Name. |
| project_guid | Ottiene o imposta l'identificatore univoco di un progetto. Deve essere univoco all'interno dell'istanza di Project Server \ Project Online. |
| timeout | Ottiene o imposta il timeout utilizzato durante l'attesa dell'elaborazione della richiesta di salvataggio del progetto da parte del servizio di elaborazione della coda di Project Server. Il valore predefinito per questa proprietà è 1 minuto. |
| polling_interval | Ottiene o imposta l'intervallo tra le richieste di stato dei lavori in coda. Il valore predefinito è 2 secondi. |
