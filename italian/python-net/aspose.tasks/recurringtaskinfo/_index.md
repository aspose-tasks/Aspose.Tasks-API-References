## RecurringTaskInfo class

Rappresenta i dettagli di un'attività ricorrente in un progetto.

Il tipo RecurringTaskInfo espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| recurrence_pattern | Ottiene o imposta un modello di ricorrenza dell'attività ricorrente. |
| start_date | Ottiene o imposta la data di inizio delle occorrenze. |
| end_date | Ottiene o imposta la data di fine delle occorrenze. |
| duration | Ottiene o imposta la durata di una singola occorrenza dell'attività ricorrente. |
| occurrences | Ottiene o imposta il numero di occorrenze dell'attività ricorrente. |
| use_end_date | Ottiene o imposta un valore che indica se utilizzare la data di fine o un numero di occorrenze per l'attività ricorrente. |
| daily_repetitions | Ottiene o imposta il numero di ripetizioni per il modello di ricorrenza giornaliera. |
| daily_use_workdays | Ottiene o imposta un valore che indica se utilizzare i giorni lavorativi per il modello di ricorrenza giornaliera. |
| weekly_repetitions | Ottiene o imposta un numero di ripetizioni per il modello di ricorrenza settimanale. |
| weekly_days | Ottiene o imposta una raccolta di giorni utilizzati nel modello di ricorrenza settimanale. |
| monthly_use_ordinal_day | Ottiene o imposta un valore che indica se utilizzare il giorno ordinal per il modello di ricorrenza mensile. |
| monthly_ordinal_number | Ottiene o imposta un numero ordinal del modello di ricorrenza mensile. |
| monthly_ordinal_repetitions | Ottiene o imposta un numero di ripetizioni per il modello di ricorrenza mensile quando si utilizza il giorno ordinal. |
| monthly_day | Ottiene o imposta un numero di giorno del modello di ricorrenza mensile. |
| monthly_repetitions | Ottiene o imposta un numero di ripetizioni per il modello di ricorrenza mensile. |
| yearly_use_ordinal_day | Ottiene o imposta un valore che indica se utilizzare il giorno ordinal per il modello di ricorrenza annuale. |
| yearly_date | Ottiene o imposta una data per il modello di ricorrenza annuale. |
| yearly_ordinal_number | Ottiene o imposta un numero ordinal del modello di ricorrenza annuale. |
| yearly_ordinal_month | Ottiene o imposta un mese del modello di ricorrenza annuale quando si utilizza il giorno ordinal. |
| task | Ottiene l'attività padre di questa istanza della classe [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
