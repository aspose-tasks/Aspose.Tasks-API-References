## LoadOptions class

Consente di specificare parametri di caricamento aggiuntivi durante il caricamento di un progetto da file o stream.

Il tipo LoadOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| LoadOptions() | Inizializza una nuova istanza della classe [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| password | Ottiene o imposta una password di protezione. |
| primavera_read_options | Ottiene o imposta un'istanza specificata della classe [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) che può essere utilizzata per personalizzare il comportamento del caricamento dei formati Primavera (Primavera P6 XER o Primavera P6 Xml). |
| encoding | Ottiene o imposta la codifica utilizzata per leggere un progetto dai formati HTML, MPX, XER e Primavera XML.<br/>            La codifica predefinita è UTF8. |
