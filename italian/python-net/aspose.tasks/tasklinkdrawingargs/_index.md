## TaskLinkDrawingArgs class

Fornisce argomenti per il callback che viene invocato quando il collegamento dell'attività è renderizzato.

Il tipo TaskLinkDrawingArgs espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| link | Restituisce il task link renderizzato. |
| color | Ottiene o imposta il colore usato per renderizzare il task link. Può essere usato per personalizzare i colori dei task link. |
