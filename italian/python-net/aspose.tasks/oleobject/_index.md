## OleObject class

Rappresenta un oggetto OLE che può essere inserito nella visualizzazione Gantt Chart di un file MPP.

Il tipo OleObject espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| OleObject() | Inizializza una nuova istanza della classe [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| name | Ottiene o imposta il nome dell'istanza dell'oggetto OLE. |
| application_name | Ottiene o imposta il nome dell'applicazione con cui aprire l'oggetto incorporato. |
| file_format | Ottiene o imposta il formato file dell'oggetto incorporato. |
| content | Ottiene o imposta i dati del file incorporato; null se non è stato incorporato alcun dato. |
| label | Ottiene o imposta l'etichetta dell'oggetto inserito. |
| full_path | Ottiene o imposta il percorso completo dell'oggetto inserito. |
| temporary_file | Ottiene o imposta il percorso del file temporaneo dell'oggetto inserito. |
| display_as_icon | Ottiene o imposta un flag che indica se l'oggetto OLE deve essere mostrato come icona o come immagine normale. |
| collegato | Ottiene un valore che indica se il file di progetto contiene solo un collegamento ai dati effettivi memorizzati all'origine del collegamento. |
| view | Ottiene o imposta l'istanza della classe [view](/tasks/python-net/aspose.tasks/oleobject/) a cui appartiene l'oggetto inserito. |
| id | Ottiene o imposta l'ID dell'oggetto. |
