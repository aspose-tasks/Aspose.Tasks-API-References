## TaskStatus enumeration

Specifica lo stato di un'attività.

## Members
| Nome membro | Descrizione |
| :- | :- |
| UNDEFINED | Stato attività non definito. |
| COMPLETE | L'attività è completata al 100 percento. |
| ON_SCHEDULE | L'attività è in programma se la percentuale cumulativa temporizzata completata è distribuita almeno fino al giorno precedente la data di stato. |
| LATE | L'attività è in ritardo se la percentuale cumulativa temporizzata completata non raggiunge la mezzanotte del giorno precedente la data di stato. |
| FUTURE | Lo stato dell'attività 'Future' è impostato quando la data di inizio dell'attività è maggiore della data di stato. |
