## GraphicalIndicatorCriteria class

Rappresenta un criterio di indicatore grafico associato a un attributo esteso.

Il tipo GraphicalIndicatorCriteria espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Inizializza una nuova istanza della classe GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Inizializza una nuova istanza della classe GraphicalIndicatorCriteria |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| test | Ottiene il tipo di confronto effettuato tra il valore dell'attributo esteso e i Valori che fungono da criterio per l'applicazione dell'indicatore grafico.<br/> [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Ottiene il valore usato per testare il valore dell'attributo esteso. |
| value2 | Ottiene il secondo valore usato per testare il valore dell'attributo esteso nel caso dei tipi di confronto 'IsWithin' e 'IsNotWithin'. |
| image_index | Ottiene l'indice dell'immagine da visualizzare quando il campo soddisfa i criteri. |
| row_type | Ottiene il valore dell'enumerazione [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) che indica per quali righe viene applicato l'indicatore. |
