## PrimaveraTaskProperties class

Rappresenta le proprietà specifiche di Primavera per un'attività letta da file Primavera (XER o P6XML).

Il tipo PrimaveraTaskProperties espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| sequence_number | Ottiene o imposta il numero di sequenza dell'elemento WBS (attività di riepilogo). Viene utilizzato per ordinare le attività di riepilogo in Primavera. |
| activity_id | Ottiene un campo activity id - l'identificatore univoco di un'attività utilizzato da Primavera. |
| remaining_early_finish | Ottiene la data di fine anticipata residua - la data in cui il lavoro residuo per l'attività è programmato per essere completato. |
| remaining_early_start | Ottiene la data di inizio anticipata residua - la data in cui il lavoro residuo per l'attività è programmato per iniziare. |
| remaining_late_start | Ottiene la data di inizio tardiva residua. |
| remaining_late_finish | Ottiene la data di fine tardiva residua. |
| raw_duration_type | Ottiene la rappresentazione testuale grezza (come nel file sorgente) del campo 'Duration Type' dell'attività. |
| duration_type | Ottiene il valore del campo 'Duration Type' dell'attività. |
| raw_activity_type | Ottiene la rappresentazione testuale grezza (come nel file sorgente) del campo 'Activity Type' dell'attività. |
| activity_type | Ottiene il valore del campo 'Activity Type'. |
| percent_complete_type | Ottiene il valore del campo '% Complete Type' dell'attività. |
| raw_complete_percent_type | Ottiene la rappresentazione testuale grezza (come nel file sorgente) del campo '% Complete Type' dell'attività. |
| raw_status | Ottiene la rappresentazione del testo grezzo (come nel file sorgente) del campo 'Status' dell'attività. |
| physical_percent_complete | Ottiene il valore di Physical Percent Complete. |
| duration_percent_complete | Ottiene il valore della percentuale di completamento della durata. |
| units_percent_complete | Ottiene il valore della percentuale di completamento delle unità. |
| actual_labor_units | Ottiene il valore delle unità di lavoro effettive. |
| actual_non_labor_units | Ottiene il valore delle unità non lavorative effettive. |
| remaining_labor_units | Ottiene il valore delle unità di lavoro rimanenti. |
| remaining_non_labor_units | Ottiene il valore delle unità non lavorative rimanenti. |
| actual_labor_cost | Ottiene il valore del costo del lavoro effettivo . |
| budgeted_labor_cost | Ottiene il valore del costo del lavoro preventivato (o pianificato) . |
| actual_nonlabor_cost | Ottiene il valore del costo non lavorativo effettivo . |
| budgeted_nonlabor_cost | Ottiene il valore del costo non lavorativo preventivato (o pianificato) . |
| actual_material_cost | Ottiene il valore del costo materiale effettivo. |
| budgeted_material_cost | Ottiene il valore del costo materiale preventivato (o pianificato). |
| actual_expense_cost | Ottiene il valore del costo spesa effettivo. |
| remaining_expense_cost | Ottiene il valore del costo spesa rimanente. |
| budgeted_expense_cost | Ottiene il valore del costo spesa preventivato (o pianificato). |
| actual_total_cost | Ottiene il valore totale dei costi effettivi. |
| budgeted_total_cost | Ottiene il valore totale dei costi preventivati (o pianificati). |
| primary_constraint_type | Ottiene un tipo di vincolo primario. |
| primary_constraint_date | Ottiene la data del vincolo primario. |
| secondary_constraint_type | Ottiene un tipo di vincolo secondario. |
| secondary_constraint_date | Ottiene la data del vincolo secondario. |
| planned_duration | Ottiene la durata originale o pianificata -- il tempo totale di lavoro dalla data di inizio pianificata dell'attività alla data di fine pianificata.. |
