## OutlineMask class

Rappresenta quattro elementi di una maschera che definisce un formato di codice outline.

Il tipo OutlineMask espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| OutlineMask() | Inizializza una nuova istanza della classe [OutlineMask](/tasks/python-net/aspose.tasks/outlinemask/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| level | Ottiene o imposta il livello di una maschera. |
| tipo | Ottiene o imposta il tipo di una maschera. |
| length | Ottiene o imposta la lunghezza massima (in caratteri) dei valori del codice di contorno. 0 se la lunghezza non è definita. |
| separator | Ottiene o imposta il separatore dei valori di codice. |
