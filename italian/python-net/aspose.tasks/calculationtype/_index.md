## CalculationType enumeration

Specifica il tipo di calcolo del valore dell'attributo personalizzato.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Indica che l'attributo esteso non ha una tabella di ricerca di formule e memorizza semplicemente il valore impostato dall'utente. |
| LOOKUP | Indica che il valore dell'attributo esteso è limitato ai valori provenienti da una tabella di ricerca. |
| FORMULA | Indica che il valore dell'attributo esteso è calcolato usando la formula definita in [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
