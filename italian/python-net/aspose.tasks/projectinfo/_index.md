## ProjectInfo class

Breve informazioni sul progetto pubblicato disponibile su Project Online.

Il tipo ProjectInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ProjectInfo() | Inizializza una nuova istanza della classe [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| id | Ottiene l'identificatore univoco del progetto. |
| name | Ottiene il nome del progetto. |
| created_date | Ottiene la data e l'ora in cui il progetto è stato creato. |
| is_checked_out | Ottiene un valore che indica se il progetto è stato controllato. |
| last_published_date | Ottiene la data più recente in cui il progetto è stato pubblicato. |
| last_saved_date | Ottiene la data più recente in cui il progetto è stato salvato. |
| description | Ottiene la descrizione del progetto. |
