## CalculationMode enumeration

Specifica la modalità di calcolo del progetto.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Nessuno. Le date e i costi del progetto non vengono ricalcolati in questa modalità. |
| AUTOMATIC | Modalità automatica. Le date e i costi del progetto vengono ricalcolati quando si utilizza questa modalità. |
| MANUAL | Modalità manuale. Solo i campi necessari vengono ricalcolati in questa modalità, ad esempio UID e ID degli oggetti. |
