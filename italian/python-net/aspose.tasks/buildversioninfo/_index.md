## BuildVersionInfo class

Contiene la versione di build e le informazioni sul prodotto.

Il tipo BuildVersionInfo espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| ASSEMBLY_VERSION | Versione dell'assembly. |
| ASSEMBLY_INFORMATIONAL_VERSION | Il numero di versione informativa dell'assembly. |
| FILE_VERSION | Versione del file. |
| PRODOTTO | Nome del prodotto. |
