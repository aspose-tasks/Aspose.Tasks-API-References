## TaskLink class

Rappresenta un collegamento predecessore.

Il tipo TaskLink espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_cross_project | Ottiene o imposta un valore che indica se un predecessore fa parte di un altro progetto. |
| cross_project_name | Ottiene o imposta il progetto predecessore esterno. |
| link_lag | Ottiene o imposta il ritardo in decimi di minuto o in percentuale. |
| link_lag_time_span | Ottiene o imposta la durata del ritardo, a seconda di LagFormat. |
| lag_format | Ottiene o imposta il formato per esprimere il ritardo. |
| pred_task | Ottiene o imposta l'attività predecessore. |
| succ_task | Ottiene o imposta l'attività successiva. |
| link_type | Ottiene o imposta il tipo di collegamento. |
## Methods

| :- | :- |
