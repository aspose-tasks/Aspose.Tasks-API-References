## TableField class

Rappresenta un campo di una tabella in un progetto.

Il tipo TableField espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TableField() | Inizializza una nuova istanza della classe [TableField](/tasks/python-net/aspose.tasks/tablefield/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| align_data | Ottiene o imposta l'allineamento dei dati in un campo tabella. |
| align_title | Ottiene o imposta l'allineamento del titolo in un campo tabella. |
| field | Ottiene o imposta il tipo di un campo tabella. |
| title | Ottiene o imposta il titolo del campo in una tabella. |
| width | Ottiene o imposta la larghezza in punti della colonna del campo in una tabella. |
| wrap_header | Ottiene o imposta un valore che indica se l'intestazione della colonna della tabella può andare a capo su più righe, o se deve essere troncata quando supera la larghezza della colonna. |
| wrap_text | Ottiene o imposta un valore che indica se il testo della colonna può andare a capo su più righe, o se deve essere troncato quando supera la larghezza della colonna. |
