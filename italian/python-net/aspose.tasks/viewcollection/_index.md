## ViewCollection class

Contiene un elenco di oggetti [View](/tasks/python-net/aspose.tasks/view/).<br/>            Implementa l'interfaccia ICollection<View>.

Il tipo ViewCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| parent_project | Ottiene il genitore dell'oggetto View.<br/>            Solo lettura [Project](/tasks/python-net/aspose.tasks/project/). |
## Methods
| Nome | Descrizione |
| :- | :- |
| to_list() | Converte una collezione di visualizzazioni in un elenco di oggetti [View](/tasks/python-net/aspose.tasks/view/). |
| get_by_view_screen(screen) | Cerca una View con la proprietà Screen specificata e restituisce la prima occorrenza nella collezione. |
| get_by_name(view_name) | Cerca una View con il nome e restituisce la prima occorrenza nella collezione. |
