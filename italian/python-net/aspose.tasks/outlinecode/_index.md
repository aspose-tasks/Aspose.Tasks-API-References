## OutlineCode class

Rappresenta un valore di un codice outline.

Il tipo OutlineCode espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| OutlineCode() | Inizializza una nuova istanza della classe [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/). |
| OutlineCode(code_definition, outline_value) | Inizializza una nuova istanza della classe [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/) utilizzando il Outline Code specificato e uno dei suoi valori. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| field_id | Ottiene o imposta il valore numerico del campo personalizzato Id del progetto. |
| value_id | Ottiene o imposta l'Id nella lista dei valori associata alla definizione nella collezione di outline code. |
| value_guid | Ottiene o imposta il GUID del valore nella lista dei valori. Il ValueGuid corrisponde al FieldGuid nella lista dei valori. |
