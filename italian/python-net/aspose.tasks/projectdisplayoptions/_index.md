## ProjectDisplayOptions class

Rappresenta le opzioni di visualizzazione per un'istanza di progetto.

Il tipo ProjectDisplayOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ProjectDisplayOptions() | Inizializza una nuova istanza della classe [ProjectDisplayOptions](/tasks/python-net/aspose.tasks/projectdisplayoptions/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| add_space_before_label | Ottiene o imposta un valore che indica se aggiungere uno spazio prima del valore numerico e dell'abbreviazione temporale (1 wk rispetto a 1wk). |
| underline_hyperlinks | Ottiene o imposta un valore che indica se sottolineare i collegamenti ipertestuali. |
| show_task_schedule_warnings | Ottiene o imposta un valore che indica se mostrare avvisi quando Project identifica un possibile conflitto di pianificazione con un'attività programmata manualmente. |
| show_task_schedule_suggestions | Ottiene o imposta un valore che indica se mostrare suggerimenti quando Project identifica un possibile conflitto di pianificazione con un'attività programmata manualmente. |
| show_project_summary_task | Ottiene o imposta un valore che indica se visualizzare le informazioni di riepilogo di un intero progetto su una singola riga con la propria barra di attività di riepilogo nella parte superiore della vista Gantt Chart view. |
| minute_label | Ottiene o imposta come viene visualizzata l'etichetta dei minuti. |
| hour_label | Ottiene o imposta come viene visualizzata l'etichetta delle ore. |
| day_label | Ottiene o imposta come viene visualizzata l'etichetta dei giorni. |
| week_label | Ottiene o imposta come viene visualizzata l'etichetta delle settimane. |
| month_label | Ottiene o imposta come viene visualizzata l'etichetta del mese. |
| year_label | Ottiene o imposta come viene visualizzata l'etichetta dell'anno. |
