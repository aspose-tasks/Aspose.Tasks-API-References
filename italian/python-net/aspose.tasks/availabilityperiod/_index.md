## AvailabilityPeriod class

Rappresenta un periodo in cui una risorsa è disponibile.

Il tipo AvailabilityPeriod espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| AvailabilityPeriod() | Inizializza una nuova istanza di [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | Inizializza una nuova istanza di [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) con l'intervallo di date specificato e le unità disponibili. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| available_from | Ottiene o imposta la data in cui una risorsa diventa disponibile per il periodo specificato. |
| available_to | Ottiene o imposta l'ultima data in cui una risorsa è disponibile per il periodo specificato. |
| available_units | Ottiene o imposta la percentuale di una risorsa disponibile durante il periodo specificato. |
