## Duration class

Rappresenta la durata in un progetto.

Il tipo Duration espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Duration() | Inizializza una nuova istanza della classe Duration |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| time_span | Ottiene l'istanza [time_span](/tasks/python-net/aspose.tasks/duration/) di questo oggetto Duration. |
| time_unit | Ottiene il tipo di unità di tempo per questo oggetto. |
| is_estimated | Ottiene un valore che indica se l'unità di tempo è stimata. |
| is_elapsed | Ottiene un valore che indica se l'unità di tempo è trascorsa. |
## Methods
| Nome | Descrizione |
| :- | :- |
| add(d) | Aggiunge la durata specificata a questa durata. |
| add(val) | Aggiunge il valore double specificato a questa durata. |
| subtract(d) | Sottrae la durata specificata da questa istanza di durata. |
| subtract(val) | Sottrae il valore double specificato da questa istanza di durata. |
| parse(p, value) | Converte la stringa specificata nell'istanza della struct [Duration](/tasks/python-net/aspose.tasks/duration/). |
| parse_time_span(value) | Analizza la stringa di durata nel formato "PT--H--M--S--". |
| to_double() | Converte l'oggetto Duration in valore float. |
| convert(time_unit_type) | Converte l'oggetto Duration in un'altra durata con le unità di tempo specificate. |
| equals(other) | Restituisce un valore che indica se questa istanza è uguale a un oggetto specificato. |
