## PrimaveraCalendarProperties class

Rappresenta le proprietà specifiche di Primavera per un calendario letto da file Primavera (XER o P6XML).<br/>            Può essere usato per eseguire la conversione delle unità di tempo specifiche del calendario.

Il tipo PrimaveraCalendarProperties espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| hours_per_day | Ottiene la quantità di ore al giorno dalle impostazioni 'Time Periods' del calendario. |
| hours_per_week | Ottiene la quantità di ore alla settimana dalle impostazioni 'Time Periods' del calendario. |
| hours_per_month | Ottiene la quantità di ore al mese dalle impostazioni 'Time Periods' del calendario. |
| hours_per_year | Ottiene la quantità di ore al mese dalle impostazioni 'Time Periods' del calendario. |
