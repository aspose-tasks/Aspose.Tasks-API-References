## TaskLinkCollection class

Rappresenta una raccolta di [Task](/tasks/python-net/aspose.tasks/task/) oggetti.

Il tipo TaskLinkCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| parent_project | Ottiene il progetto principale dell'oggetto ResourceAssignmentCollection. |
## Methods
| Nome | Descrizione |
| :- | :- |
| add(pred, succ) | Restituisce un'istanza di Finish-Start [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) che è stata aggiunta all'oggetto TaskLinkCollection. |
| add(pred, succ, link_type) | Restituisce un'istanza di [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) che è stata aggiunta all'oggetto TaskLinkCollection. |
| add(pred, succ, link_type, lag) | Restituisce un'istanza di [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) che è stata aggiunta all'oggetto TaskLinkCollection. |
| to_list() | Converte l'oggetto TaskLinkCollection in un elenco di oggetti [TaskLink](/tasks/python-net/aspose.tasks/tasklink/). |
