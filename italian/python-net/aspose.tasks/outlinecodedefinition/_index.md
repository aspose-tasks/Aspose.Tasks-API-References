## OutlineCodeDefinition class

Rappresenta una definizione di codice outline.

Il tipo OutlineCodeDefinition espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| OutlineCodeDefinition() | Inizializza una nuova istanza della classe [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| guid | Ottiene o imposta il Guid di un codice di struttura. |
| field_id | Ottiene o imposta il numero del campo di un codice di struttura. |
| field_name | Ottiene o imposta il nome di un codice di struttura personalizzato. |
| alias | Ottiene o imposta l'alias di un codice di struttura personalizzato. |
| phonetic_alias | Ottiene o imposta la pronuncia fonetica dell'alias del codice di struttura personalizzato. |
| values | Ottiene l'oggetto OutlineValueCollection.<br/>            I valori della tabella associata a questo codice di struttura. |
| enterprise | Ottiene o imposta un valore che indica se un codice di struttura personalizzato è un codice di struttura personalizzato enterprise. |
| enterprise_outline_code_alias | Ottiene o imposta un riferimento a un altro campo personalizzato per il quale questa definizione di codice di struttura è un alias. |
| resource_substitution_enabled | Ottiene o imposta un valore che indica se il codice di struttura personalizzato può essere utilizzato<br/>            dalla procedura guidata di sostituzione risorse in Microsoft Project. |
| leaf_only | Ottiene o imposta un valore che indica se i valori specificati in questo campo di codice di struttura devono essere valori foglia. |
| all_levels_required | Ottiene o imposta un valore che indica se i nuovi codici devono avere tutti i livelli.<br/>            Non disponibile per i codici Enterprise. |
| only_table_values_allowed | Ottiene o imposta un valore che indica se i valori specificati devono provenire dalla tabella dei valori. |
| masks | Ottiene l'oggetto OutlineMaskCollection.<br/>            La tabella delle voci che definiscono la maschera del codice di struttura.<br/>            Istanza di sola lettura [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/). |
| show_indent | Ottiene o imposta un valore che indica se le rientranze di questo codice di struttura devono essere visualizzate. |
