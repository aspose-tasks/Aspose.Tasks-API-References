## Value class

Rappresenta un valore in un elenco di valori.

Il tipo Value espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Value() | Inizializza una nuova istanza della classe [Value](/tasks/python-net/aspose.tasks/value/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| id | Ottiene o imposta l'identificatore univoco di un valore in tutto il progetto. |
| value_guid | Ottiene un GUID che identifica questo valore tra gli altri nell'intero progetto. |
| val | Ottiene o imposta il valore effettivo nella rappresentazione interna. Si consiglia di utilizzare le proprietà tipizzate fortemente elencate di seguito. |
| string_value | Ottiene o imposta il valore effettivo utilizzato per rappresentare la stringa di testo. |
| numeric_value | Ottiene o imposta il valore effettivo utilizzato per rappresentare un numero o un valore di costo. |
| duration | Ottiene o imposta il valore effettivo utilizzato per rappresentare la Durata. |
| date_time_value | Ottiene o imposta il valore effettivo se può essere rappresentato come DateTime. Il valore predefinito è la data minima. |
| description | Ottiene o imposta la descrizione di un valore. |
| phonetic | Ottiene o imposta le informazioni fonetiche sul nome del campo personalizzato. |
