## ProjectFileInfo class

L'istanza della classe contiene informazioni sul formato del file di progetto e sulla versione di Microsoft Project in cui<br/>            è stato creato il file.

Il tipo ProjectFileInfo espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| can_read | Restituisce un valore che indica se le definizioni possono essere elaborate da Aspose.Tasks nel file di progetto. |
| is_password_protected | Restituisce un valore che indica se un progetto è protetto da password. |
| project_file_format | Restituisce il formato del file di progetto. |
| project_application_info | Restituisce le informazioni sull'applicazione del file di progetto. |
