## GraphicalIndicatorsInfo class

Rappresenta una definizione di indicatori grafici associata a un attributo esteso.

Il tipo GraphicalIndicatorsInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GraphicalIndicatorsInfo() | Inizializza una nuova istanza del tipo [GraphicalIndicatorsInfo](/tasks/python-net/aspose.tasks/graphicalindicatorsinfo/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| summary_rows_inherit_from_non_summary_rows | Ottiene o imposta il flag che indica se le righe di riepilogo ereditano i criteri dalle righe non di riepilogo. |
| project_summary_inherit_from_non_summary_rows | Ottiene o imposta il flag che indica se la riga di riepilogo del progetto eredita i criteri dalle righe di riepilogo. |
| show_data_values_in_tooltip | Ottiene o imposta il flag che indica se i valori dei dati per il campo devono essere mostrati nei tooltip. |
| criteria | Ottiene un elenco di criteri dell'indicatore grafico. |
