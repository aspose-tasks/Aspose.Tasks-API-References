## Rate class

Rappresenta una definizione di un periodo di tempo e delle tariffe applicabili a una risorsa durante tale periodo.

Il tipo Tariffa espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| rates_from | Ottiene o imposta la data in cui una tariffa diventa effettiva. |
| rates_to | Ottiene o imposta l'ultima data in cui una tariffa è effettiva. |
| rate_table | Ottiene o imposta l'identificatore univoco di una tabella delle tariffe per una risorsa. |
| standard_rate | Ottiene o imposta la tariffa standard per ora per una risorsa. |
| standard_rate_format | Ottiene o imposta le unità utilizzate da Microsoft Project per visualizzare la tariffa standard. |
| overtime_rate | Ottiene o imposta la tariffa di straordinario per ora per una risorsa. |
| overtime_rate_format | Ottiene o imposta le unità utilizzate da Microsoft Project per visualizzare la tariffa di straordinario. |
| cost_per_use | Ottiene o imposta il costo per utilizzo di una risorsa. Questo valore viene recuperato dalla data corrente se esiste una tabella delle tariffe per una risorsa. |
