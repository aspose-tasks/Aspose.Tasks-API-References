## Group class

Rappresenta una definizione di gruppo.<br/>            Un oggetto Group è un membro della collezione ResourceGroups o della collezione TaskGroups.

Il tipo Group espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Group() | Inizializza una nuova istanza della classe [Group](/tasks/python-net/aspose.tasks/group/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| name | Ottiene o imposta il nome di un oggetto Group. |
| uid | Ottiene un identificatore univoco di un gruppo. |
| show_summary | Ottiene o imposta un valore che indica se le righe di riepilogo sono visualizzate per il gruppo. |
| maintain_hierarchy | Ottiene o imposta un valore che indica se mostrare tutti i livelli delle attività di riepilogo per le sottoattività all'interno del gruppo. |
| show_in_menu | Ottiene o imposta un valore che indica se Project mostra il nome del gruppo nell'elenco a discesa Group nella barra multifunzione. |
| group_assignments | Ottiene o imposta un valore che indica se le assegnazioni devono essere raggruppate invece delle attività. |
| group_criteria | Ottiene o imposta una collezione GroupCriteria che rappresenta i campi in una definizione di gruppo. |
