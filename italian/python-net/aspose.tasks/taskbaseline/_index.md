## TaskBaseline class

Rappresenta la Baseline di un'attività.

Il tipo TaskBaseline espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TaskBaseline(task) | Inizializza una nuova istanza della classe [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| baseline_number | Ottiene o imposta il numero univoco di un record di dati di baseline. |
| lavoro | Ottiene o imposta il lavoro assegnato a una risorsa quando la baseline viene salvata. |
| cost | Ottiene o imposta il costo previsto di una risorsa quando la baseline viene salvata. |
| bcws | Ottiene o imposta il costo di budget di un lavoro programmato per una risorsa. |
| bcwp | Ottiene o imposta il costo di budget di un lavoro eseguito da una risorsa per un progetto fino ad oggi. |
| timephased_data | Ottiene o imposta un'istanza di TimephasedDataCollection per questo oggetto.<br/>            I dati temporizzati associati alla baseline dell'attività. |
| interim | Ottiene o imposta un valore che indica se questa è una Baseline Intermedia. |
| avvio | Ottiene o imposta la data di inizio programmata dell'attività quando la baseline è stata salvata. |
| finish | Ottiene o imposta la data di fine programmata dell'attività quando la baseline è stata salvata. |
| duration | Ottiene o imposta la durata programmata dell'attività quando la baseline è stata salvata. |
| estimated_duration | Ottiene o imposta un valore che indica se la durata di base dell'attività è stata stimata. |
| fixed_cost | Ottiene o imposta un costo fisso dell'attività quando la baseline è stata salvata. |
