## Baseline class

Rappresenta i valori di baseline di una risorsa.

Il tipo Baseline espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Baseline() | Inizializza una nuova istanza della classe Baseline |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| baseline_number | Ottiene o imposta il numero univoco di un record di dati di baseline. |
| lavoro | Ottiene o imposta il lavoro assegnato a una risorsa quando la baseline viene salvata. |
| cost | Ottiene o imposta il costo previsto di una risorsa quando la baseline viene salvata. |
| bcws | Ottiene o imposta il costo di budget di un lavoro programmato per una risorsa. |
| bcwp | Ottiene o imposta il costo di budget di un lavoro eseguito da una risorsa per un progetto fino ad oggi. |
## Methods
| Nome | Descrizione |
| :- | :- |
| equals(other) | Restituisce un valore che indica se questa istanza è uguale a un oggetto specificato. |
| compare_to(other) | Implementazione dell'interfaccia IComparable.<br/>            Confronta questa istanza con l'oggetto Baseline specificato. |
