## FilterComparisonType enumeration

Il tipo di confronto effettuato tra FieldName e Value che funge da criterio di selezione per un filtro o indicatore grafico.

## Members
| Nome membro | Descrizione |
| :- | :- |
| EQUALS | Il valore di Field è uguale a Value. |
| DOES_NOT_EQUAL | Il valore di Field non è uguale a Value. |
| IS_GREATER_THAN | Il valore di Field è maggiore di Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | Il valore di Field è maggiore o uguale a Value. |
| IS_LESS_THAN | Il valore di Field è minore di Value. |
| IS_LESS_THAN_OR_EQUAL_TO | Il valore di Field è minore o uguale a Value. |
| IS_WITHIN | Il valore di Field è compreso in Value. |
| IS_NOT_WITHIN | Il valore di Field non è compreso in Value. |
| CONTAINS | Il valore di Field contiene Value. |
| DOES_NOT_CONTAIN | Il valore di Field non contiene Value. |
| CONTAINS_EXACTLY | Il valore di Field contiene esattamente Value. |
| IS_ONE_OF | Il valore di Field è uguale a uno dei Values specificati. Utilizzato negli AutoFilters. |
| UNDEFINED | Valore non definito. |
| IS_ANY_VALUE | 'Is any value' condizione. Applicabile agli indicatori grafici. |
