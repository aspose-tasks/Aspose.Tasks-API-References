## RateCollection class

Rappresenta una collezione che contiene oggetti [Rate](/tasks/python-net/aspose.tasks/rate/).

Il tipo RateCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| count | Restituisce il numero di elementi contenuti in RateCollection. |
| is_read_only | Restituisce un valore che indica se questa collezione è di sola lettura. |
| parent_resource | Restituisce l'oggetto [Resource](/tasks/python-net/aspose.tasks/resource/) genitore per questa collezione. |
## Methods
| Nome | Descrizione |
| :- | :- |
| add(rates_from) | Aggiunge una nuova istanza di [Rate](/tasks/python-net/aspose.tasks/rate/) a questa collezione. |
| add(rates_from, type) | Aggiunge una nuova istanza di [Rate](/tasks/python-net/aspose.tasks/rate/) a questa collezione. |
| to_list() | Converte l'oggetto [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) in un elenco di oggetti [Rate](/tasks/python-net/aspose.tasks/rate/). |
| to_list(type) | Converte l'oggetto [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) in un elenco di oggetti [Rate](/tasks/python-net/aspose.tasks/rate/) filtrati per il tipo [RateType](/tasks/python-net/aspose.tasks/ratetype/) specificato. |
| remove(item) | Rimuove l'istanza Rate da questa collezione. |
