## VbaModule class

Rappresenta un modulo VBA.

Il tipo VbaModule espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| attributes | Ottiene una collezione degli attributi del modulo. |
| name | Ottiene un nome del modulo VBA |
| tipo | Ottiene il tipo del modulo. |
| source_code | Ottiene o imposta il codice sorgente del modulo VBA |
## Methods
| Nome | Descrizione |
| :- | :- |
| create_procedural_module(name) | Crea un'istanza di [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) con il tipo VbaModuleType.ProceduralModule. |
| create_class_module(name) | Crea un'istanza di [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) con il tipo VbaModuleType.ClassModule. |
