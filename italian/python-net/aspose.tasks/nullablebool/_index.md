## NullableBool class

Una classe per valori booleani con la possibilità di verificare se il valore è stato definito o meno.

Il tipo NullableBool espone i seguenti membri:

| Nome | Descrizione |
| :- | :- |
| NullableBool(value) | Inizializza una nuova istanza della struttura [NullableBool](/tasks/python-net/aspose.tasks/nullablebool/) con il valore booleano specificato. |
| NullableBool(value, is_defined) | Inizializza una nuova istanza della struttura [NullableBool](/tasks/python-net/aspose.tasks/nullablebool/) con il valore booleano specificato. |
| NullableBool() | Inizializza una nuova istanza della struttura [NullableBool](/tasks/python-net/aspose.tasks/nullablebool/) con il valore booleano specificato. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| value | Ottiene o imposta un valore che indica se il valore corrente è vero o falso. |
| is_defined | Ottiene un valore che indica se il valore è stato definito; altrimenti, false. |
