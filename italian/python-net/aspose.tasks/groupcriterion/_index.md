## GroupCriterion class

Rappresenta un criterio in una definizione di gruppo.<br/>            L'oggetto GroupCriterion è un membro della collezione [GroupCriterionCollection](/tasks/python-net/aspose.tasks/groupcriterioncollection/).

Il tipo GroupCriterion espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GroupCriterion() | Inizializza una nuova istanza della classe GroupCriterion |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| ascending | Ottiene o imposta un valore che indica se un campo utilizzato come criterio in una definizione di gruppo è ordinato in ordine ascending. False se il campo è ordinato in ordine descending. |
| cell_color | Ottiene o imposta il colore dello sfondo della cella per un campo utilizzato come criterio in una definizione di gruppo. |
| font_color | Ottiene o imposta il colore del carattere per un campo utilizzato come criterio in una definizione di gruppo. |

| pattern | Ottiene o imposta il modello della cella per un campo utilizzato come criterio in una definizione di gruppo. |
| start_at | Ottiene o imposta l'inizio degli intervalli per un campo utilizzato come criterio in una definizione di gruppo. |
| group_interval | Ottiene o imposta l'intervallo per un campo utilizzato come criterio in una definizione di gruppo. |
| font | Ottiene o imposta il carattere per un criterio in una definizione di gruppo. |
