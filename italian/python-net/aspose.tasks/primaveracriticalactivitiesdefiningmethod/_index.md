## PrimaveraCriticalActivitiesDefiningMethod enumeration

Specifica il metodo per definire le attività critiche in Primavera.

## Members
| Nome membro | Descrizione |
| :- | :- |
| TOTAL_FLOAT | Le attività con TotalSlack (Total Float in Primavera) minore o uguale al valore di [critical_total_float_limit](/tasks/python-net/aspose.tasks/primaveraprojectproperties/) sono contrassegnate come critiche. |
| LONGEST_PATH | Le attività sul percorso più lungo sono contrassegnate come critiche. |
