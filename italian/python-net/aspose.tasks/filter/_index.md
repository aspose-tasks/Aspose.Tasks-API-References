## Filter class

Rappresenta un filtro in Project.

Il tipo Filter espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Filter() | Inizializza una nuova istanza della classe Filter |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| filter_type | Ottiene il tipo del filtro. |
| name | Ottiene o imposta il nome di un oggetto Filter. |
| show_in_menu | Ottiene o imposta un valore che indica se il progetto mostra il nome del filtro nell'elenco a discesa Filter nella scheda Visualizza del Ribbon. |
| show_related_summary_rows | Ottiene o imposta un valore che indica se le righe di riepilogo correlate vengono visualizzate per il filtro. |
| index | Ottiene l'indice di un oggetto [Filter](/tasks/python-net/aspose.tasks/filter/) nell'oggetto contenitore Filters. |
| uid | Ottiene l'identificatore univoco di un filtro. |
| criteria | Ottiene o imposta i criteri che attività o risorse devono soddisfare per essere visualizzate nella vista MSP. |
## Methods
| Nome | Descrizione |
| :- | :- |
| compare_to(other) | Confronta questa istanza con l'istanza specificata della classe [Filter](/tasks/python-net/aspose.tasks/filter/) e restituisce un'indicazione del loro ordine relativo. |
| equals(other) | Restituisce un valore che indica se questa istanza è uguale all'oggetto AssignmentBaseline specificato. |
