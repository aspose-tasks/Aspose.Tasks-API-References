## SummaryRowsCalculationType enumeration

Specifica il tipo di calcolo del valore dell'attributo personalizzato per le righe di riepilogo.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Indica che il valore dell'attributo personalizzato per le righe di riepilogo non è calcolato. |
| ROLLUP | Indica che il valore dell'attributo personalizzato per le righe di riepilogo è calcolato usando la funzione di rollup definita in [rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
| USE_FORMULA | Indica che il valore dell'attributo personalizzato per le righe di riepilogo è calcolato usando la formula definita in [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
