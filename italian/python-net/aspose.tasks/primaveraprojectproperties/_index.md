## PrimaveraProjectProperties class

Rappresenta le proprietà specifiche di Primavera per un progetto letto da file Primavera (XER o P6XML).

Il tipo PrimaveraProjectProperties espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| relationship_lag_calendar | Ottiene un'opzione che definisce quale calendario utilizzare per la pianificazione del ritardo di relazione nei progetti Primavera |
| use_expected_finish_dates | Ottiene un flag che definisce se le date di fine attività devono essere programmate come date di fine previste. |
| make_open_ended_activities_critical | Ottiene un flag che definisce se le attività devono essere contrassegnate come critiche durante la pianificazione del progetto. |
| ignore_other_project_relationships | Ottiene un flag che definisce se ignorare le relazioni di attività tra progetti. |
| current_baseline_project_id | Ottiene l'Id del progetto baseline corrente.<br/>            È applicabile ai progetti letti da file XML di Primavera contenenti baseline esportate. |
| baseline_projects | Ottiene l'array dei progetti baseline del progetto corrente.<br/>            È applicabile ai progetti letti da file XML di Primavera contenenti baseline esportate. |
| critical_activities_defining_method | Ottiene il metodo per definire le attività critiche: percorso più lungo o approccio del float totale. |
| critical_total_float_limit | Ottiene il valore soglia utilizzato per definire le attività critiche se viene usato il metodo TotalFloat. |
| short_name | Ottiene il nome breve del progetto (ID progetto). |
