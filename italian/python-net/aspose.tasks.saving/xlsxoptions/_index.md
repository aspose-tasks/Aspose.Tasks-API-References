## XlsxOptions class

Consente di specificare opzioni aggiuntive durante il rendering delle pagine del progetto in XLSX.

Il tipo XlsxOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| XlsxOptions() | Inizializza una nuova istanza della classe [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) che può essere usata per salvare il progetto in formato XLSX. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| save_format | Ottiene o imposta il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
| resource_view | Ottiene o imposta un elenco delle colonne di visualizzazione delle risorse da renderizzare ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Ottiene o imposta un elenco delle colonne di visualizzazione delle assegnazioni da renderizzare ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| encoding | Ottiene o imposta la codifica del file XLSX risultante. Il valore predefinito è . |
| view | Ottiene o imposta un elenco delle colonne di visualizzazione ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) da salvare nel formato XLSX.<br/>            Se non impostato, vengono salvate le colonne predefinite. |
