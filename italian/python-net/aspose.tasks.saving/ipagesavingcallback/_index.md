## IPageSavingCallback class

Rappresenta una callback che viene chiamata quando ogni pagina di un documento multipagina viene salvata in un flusso separato.

Il tipo IPageSavingCallback espone i seguenti membri:
## Methods
| Nome | Descrizione |
| :- | :- |
| page_saving(args) | Il metodo da chiamare quando una pagina viene salvata in uno stream. |
| on_finish() | Metodo che verrà chiamato quando tutte le pagine sono state scritte. |
