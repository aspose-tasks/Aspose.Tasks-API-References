## MPPSaveOptions class

Consente di specificare opzioni aggiuntive durante il salvataggio dei dati del progetto in MPP.

Il tipo MPPSaveOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| MPPSaveOptions() | Inizializza una nuova istanza della classe [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| save_format | Ottiene o imposta il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
| remove_invalid_assignments | Ottiene o imposta un valore che indica se rimuovere le assegnazioni di risorse non valide durante il salvataggio in MPP. |
| write_view_data | Ottiene o imposta un valore che indica se scrivere i dati di visualizzazione durante il salvataggio di un progetto nel formato MPP. |
| write_filters | Ottiene o imposta un valore che indica se scrivere i dati dei filtri durante il salvataggio di un progetto in MPP per formato. |
| write_groups | Ottiene o imposta un valore che indica se scrivere i dati dei gruppi durante il salvataggio di un progetto in formato MPP. |
| clear_vba | Ottiene o imposta un valore che indica se rimuovere i dati delle macro VBA esistenti durante il salvataggio di un progetto in formato MPP. |
| write_vba | Ottiene o imposta un valore che indica se aggiornare i dati delle macro VBA esistenti nel file MPP.<br/>            Attualmente è supportata la scrittura di VbaModule.SourceCode. |
| protection_password | Ottiene o imposta una password utilizzata per proteggere il file MPP risultante. Attualmente è supportata per MS Project 2010 e formati più recenti. |
