## PrimaveraXmlSaveOptions class

Consente di specificare opzioni aggiuntive durante il salvataggio del progetto nel formato Primavera XML.

Il tipo PrimaveraXmlSaveOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PrimaveraXmlSaveOptions() | Inizializza una nuova istanza della classe [PrimaveraXmlSaveOptions](/tasks/python-net/aspose.tasks.saving/primaveraxmlsaveoptions/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| save_format | Ottiene o imposta il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
| save_root_task | Ottiene o imposta un valore che indica se salvare o meno un'attività radice. |
| skip_summary_assignments | Ottiene o imposta un valore che indica se le assegnazioni di risorse alle attività di riepilogo devono essere omesse durante l'esportazione. |
