## Spreadsheet2003SaveOptions class

Consente di specificare opzioni aggiuntive durante il rendering delle pagine del progetto in Spreadsheet2003.

Il tipo Spreadsheet2003SaveOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Spreadsheet2003SaveOptions() | Inizializza una nuova istanza della classe [Spreadsheet2003SaveOptions](/tasks/python-net/aspose.tasks.saving/spreadsheet2003saveoptions/). |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| save_format | Ottiene o imposta il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
| resource_view | Ottiene o imposta un elenco delle colonne di visualizzazione delle risorse da renderizzare ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Ottiene o imposta un elenco delle colonne di visualizzazione delle assegnazioni da renderizzare ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| view | Ottiene o imposta un elenco delle colonne di visualizzazione ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) da salvare.<br/>            Se non impostato, vengono salvate le colonne predefinite. |
