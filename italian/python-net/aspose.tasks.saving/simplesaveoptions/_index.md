## SimpleSaveOptions class

Questa è una classe base astratta che consente all'utente di specificare opzioni di base durante il salvataggio di un progetto in un formato particolare.

Il tipo SimpleSaveOptions espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| save_format | Ottiene o imposta il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
