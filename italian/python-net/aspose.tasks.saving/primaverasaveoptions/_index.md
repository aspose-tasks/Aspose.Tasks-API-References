## PrimaveraSaveOptions class

Consente di specificare opzioni aggiuntive durante il salvataggio del progetto nel formato Primavera XER.

Il tipo PrimaveraSaveOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PrimaveraSaveOptions() | Inizializza una nuova istanza della classe [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/) . |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| save_format | Ottiene o imposta il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
| activity_id_increment | Ottiene o imposta l'incremento utilizzato nella ridenominazione degli ID delle attività. |
| activity_id_prefix | Ottiene o imposta il prefisso utilizzato nella ridenominazione degli ID delle attività. |
| activity_id_suffix | Ottiene o imposta il suffisso utilizzato nella ridenominazione degli ID delle attività. |
| renumber_activity_ids | Ottiene o imposta un valore che indica se è necessario ridenominare gli ID delle attività. |
| skip_summary_assignments | Ottiene o imposta un valore che indica se le assegnazioni di risorse alle attività di riepilogo devono essere omesse durante l'esportazione. |
