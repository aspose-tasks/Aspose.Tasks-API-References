## PageSavingArgs class

Questa classe rappresenta un insieme di dati relativi al salvataggio della pagina del documento in un flusso.

Il tipo PageSavingArgs espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| page_number | Ottiene il numero di pagina da scrivere. |
| keep_stream_open | Ottiene o imposta un valore che indica se la routine di rendering deve mantenere il [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) aperto dopo che una pagina è stata scritta. |
| stream | Ottiene o imposta un flusso per scrivere una pagina. |
