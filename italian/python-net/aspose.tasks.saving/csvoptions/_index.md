## CsvOptions class

Consente di specificare opzioni aggiuntive durante il salvataggio del progetto in CSV.

Il tipo CsvOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| CsvOptions() | Inizializza una nuova istanza della classe [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) che può essere utilizzata per salvare il progetto in formato CSV. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| save_format | Ottiene o imposta il formato in cui il documento verrà salvato se viene utilizzato questo oggetto di opzioni di salvataggio. |
| data_category | Ottiene o imposta una categoria di dati da salvare. |
| encoding | Ottiene o imposta una codifica con cui salvare il CSV. |
| include_headers | Ottiene o imposta un valore che indica se includere le intestazioni o meno (il valore predefinito è TRUE). |
| text_delimiter | Ottiene o imposta un delimitatore di testo. |
| view | Ottiene o imposta un elenco delle colonne di visualizzazione ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) da salvare nel formato XLSX.<br/>            Se non impostato, vengono salvate le colonne predefinite. |
