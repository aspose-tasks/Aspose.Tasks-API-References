## PrimaveraProjectInfo class

Rappresenta informazioni brevi su un progetto caricato dal formato Primavera.

Il tipo PrimaveraProjectInfo espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| uid | Restituisce l'Uid del progetto. |
| name | Restituisce il nome del progetto. |
| short_name | Ottiene il nome breve del progetto (ID progetto). |
| export_flag | Restituisce il flag di esportazione del progetto. Quando un progetto è selezionato per l'esportazione in Primavera, il suo ExportFlag è true.<br/>            Alcuni progetti non esplicitamente selezionati per l'esportazione possono essere esportati in un file XER a causa della loro relazione con il progetto esportato. |
