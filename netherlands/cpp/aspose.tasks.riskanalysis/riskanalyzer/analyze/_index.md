## Analyze {#analyze}

Voert een risicoanalyse uit voor het opgegeven project. De analyse is gebaseerd op Monte Carlo-simulatie en het resultaat is een instantie van de RiskAnalysisResult klasse.

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| Parameter | Beschrijving |
| --- | --- |
| project | de opgegeven instantie van de Project klasse om te analyseren. |
