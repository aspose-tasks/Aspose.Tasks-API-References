## RiskItemStatistics class

Stelt een item voor dat statistische gegevens opslaat voor de taak van het geanalyseerde project.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | Haalt de verwachte waarde van het risico-item op. |
| [get_ItemType](./get_itemtype/) | Haalt een instantie van de RiskItemType-enumeratie op. |
| [get_Maximum](./get_maximum/) | Haalt de maximale waarde op die tijdens Monte Carlo-simulatie is gegenereerd. |
| [get_Minimum](./get_minimum/) | Haalt de minimale waarde op die tijdens Monte Carlo-simulatie is gegenereerd. |
| [get_StandardDeviation](./get_standarddeviation/) | Haalt de standaarddeviatie van het risico-item op. |
| [GetPercentile](./getpercentile/) | Haalt een waarde op waaronder een opgegeven percentage van de gegenereerde monsters valt. |
| [ToString](./tostring/) | Retourneert een korte tekenreeksrepresentatie van een risico-item. De exacte details van de representatie zijn niet gespecificeerd en kunnen wijzigen. |
