## PrimaveraProjectInfo class

Stelt korte informatie over een project dat is geladen vanuit Primavera-formaat voor.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_ExportFlag](./get_exportflag/) | Haalt de exportvlag van het project op. Wanneer een project in Primavera is geselecteerd voor export, is de ExportFlag waar. Sommige projecten die niet expliciet zijn geselecteerd voor export, kunnen toch naar een XER-bestand worden geëxporteerd vanwege hun relatie met het geëxporteerde project. |
| [get_Name](./get_name/) | Haalt de naam van het project op. |
| [get_Uid](./get_uid/) | Haalt de UID van het project op. |
