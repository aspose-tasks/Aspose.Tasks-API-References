## TaskTextStyleEventArgs class

Deze klasse vertegenwoordigt een set gegevens die gerelateerd zijn aan het renderen van de inhoud van een tabelcel.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | Haalt TextStyle op die zal worden gebruikt om de inhoud van de cel te tekenen. Dit object kan worden gebruikt om het uiterlijk van een tabelcel aan te passen. |
| [get_Column](./get_column/) | Haalt ViewColumn op waartoe de momenteel gerenderde cel behoort. |
| [get_Task](./get_task/) | Haalt Task op die overeenkomt met de momenteel gerenderde rij. |
| [set_CellTextStyle](./set_celltextstyle/) | Stelt TextStyle in die zal worden gebruikt om de inhoud van de cel te tekenen. Dit object kan worden gebruikt om het uiterlijk van een tabelcel aan te passen. |
