## get_ProjectName {#get_projectname}

Haalt de naam van een project op die wordt weergegeven in de Project Server \ Project Online‑projectenlijst. Deze moet uniek zijn binnen een Project Server \ Project Online‑instantie. Als de waarde wordt weggelaten, wordt de waarde van de Prj.Name‑eigenschap gebruikt.

**Returns:** System::String Aspose::Tasks::

```cpp
get_ProjectName()
```
