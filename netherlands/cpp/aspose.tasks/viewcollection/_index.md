## ViewCollection class

Bevat een lijst met View-objecten. Implementeert de ICollection< View > interface.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [Add](./add/) | Voegt het opgegeven item toe aan deze collectie. |
| [Clear](./clear/) | Verwijdert alle items uit deze collectie. |
| [Contains](./contains/) | Retourneert true als het opgegeven item in deze collectie wordt gevonden; anders false. |
| [CopyTo](./copyto/) | Kopieert de elementen van deze collectie naar de opgegeven array, beginnend bij de opgegeven array-index. |
| [get_Count](./get_count/) | Haalt het aantal elementen op dat in deze collectie zit. |
| [get_IsReadOnly](./get_isreadonly/) | Haalt een waarde op die aangeeft of deze collectie alleen-lezen is; anders false. |
| [get_ParentProject](./get_parentproject/) | Haalt de bovenliggende van het View‑object op. Alleen‑lezen Project. |
| [GetByName](./getbyname/) | Zoekt naar een View met de naam en retourneert de eerste vondst binnen de collectie. |
| [GetByViewScreen](./getbyviewscreen/) | Zoekt naar een View met de opgegeven Screen‑eigenschap en retourneert de eerste vondst binnen de collectie. |
| [GetEnumerator](./getenumerator/) | Retourneert een enumerator voor deze collectie. |
| [Remove](./remove/) | Verwijdert de eerste voorkoming van een specifiek object uit deze collectie. |
| [ToList](./tolist/) | Converteert een view‑collectie naar een lijst met View‑objecten. |
