## PrimaveraBaseReader class

Stelt een basislezer voor die kan worden gebruikt om Project UIDs te lezen uit multi‑project Primavera XER‑ of XML‑bestanden.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [GetProjectInfos](./getprojectinfos/) | Retourneert een lijst met de korte info‑objecten van het project. |
| [GetProjectUids](./getprojectuids/) | Retourneert een lijst met de unieke identifiers van de projecten. |
| [LoadProject](./loadproject/) | Laadt het project met de opgegeven unieke identifier. |
