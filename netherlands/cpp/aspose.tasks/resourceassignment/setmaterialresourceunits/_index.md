## SetMaterialResourceUnits {#setmaterialresourceunits}

Stelt eenheden in voor de toewijzing van een materiële resource met variabele materiaalconsumptie. De variabele materiaalconsumptie betekent dat naarmate de toewijzingsduur verandert, de hoeveelheid gebruikte materialen evenredig verandert.

**Returns:** void Aspose::Tasks::

```cpp
SetMaterialResourceUnits(double units, RateScaleType rateScaleType)
```

| Parameter | Beschrijving |
| --- | --- |
| eenheden | Aantal eenheden opgebouwd gedurende de tijdsperiode. |
| rateScaleType | Tijdsperiode waarin de eenheidswaarde wordt opgebouwd. |
