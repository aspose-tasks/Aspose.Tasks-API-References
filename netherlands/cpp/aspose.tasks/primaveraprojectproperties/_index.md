## PrimaveraProjectProperties class

Stelt Primavera-specifieke eigenschappen voor een project voor die uit Primavera-bestanden (XER of P6XML) worden gelezen.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | Haalt een array op van baselineprojecten van het huidige project. Van toepassing op projecten die uit Primavera XML-bestanden met geëxporteerde baselines worden gelezen. |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | Haalt de Id op van het huidige baselineproject. Van toepassing op projecten die uit Primavera XML-bestanden met geëxporteerde baselines worden gelezen. |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | Haalt een vlag op die bepaalt of activiteitrelaties tussen projecten genegeerd moeten worden. |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | Haalt een vlag op die bepaalt of activiteiten als kritiek gemarkeerd moeten worden bij het plannen van het project. |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | Haalt een optie op die bepaalt welke agenda gebruikt moet worden voor het plannen van Relationship Lag in Primavera-projecten. |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | Haalt een vlag op die bepaalt of einddatums van activiteiten gepland moeten worden als de verwachte einddatums. |
