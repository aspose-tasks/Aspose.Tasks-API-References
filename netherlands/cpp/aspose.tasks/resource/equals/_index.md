## Equals (1 of 2) {#equals_1}

Retourneert een waarde die aangeeft of deze instantie gelijk is aan een opgegeven instantie van de Resource-klasse.

**Returns:** True if the specified instance of the Resource class has the same Uid value as this instance; otherwise, false .

```cpp
Equals(System::SharedPtr< Resource > other)
```

| Parameter | Beschrijving |

| anders | De opgegeven instantie van de Resource-klasse om te vergelijken met deze instantie. |
