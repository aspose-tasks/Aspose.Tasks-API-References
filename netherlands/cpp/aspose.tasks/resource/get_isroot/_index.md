## get_IsRoot {#get_isroot}

Haalt de vlag op die aangeeft of de resource een rootresource is. Een rootresource is een speciale resource die bedoeld is om de interne formaten van MS Project te ondersteunen en niet bedoeld is om rechtstreeks vanuit de code van de gebruiker te worden gebruikt.
