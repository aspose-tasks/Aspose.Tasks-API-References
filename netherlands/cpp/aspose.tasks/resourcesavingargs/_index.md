## ResourceSavingArgs class

Deze klasse vertegenwoordigt een set gegevens die gerelateerd zijn aan het opslaan van een extern resourcebestand dat plaatsvindt tijdens de conversie naar HTML-indeling.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [CloseStreamIfRequired](./closestreamifrequired/) | Sluit de stream als KeepStreamOpen onwaar is, anders spoel je deze. |
| [get_FileName](./get_filename/) | Haalt de veronderstelde bestandsnaam op die van de converter naar de code van de aangepaste methode gaat. Kan worden gebruikt in aangepaste code om te bepalen hoe dit te verwerken of waar het bestand op te slaan. |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Haalt een waarde op die aangeeft of de stream open blijft nadat het opslaan van de resource is voltooid. |
| [get_Stream](./get_stream/) | Haalt de binaire inhoud van het opgeslagen bestand op. |
| [get_Uri](./get_uri/) | Haalt de resource-URI op. |
| [set_FileName](./set_filename/) | Stelt de veronderstelde bestandsnaam in die van de converter naar de code van de aangepaste methode gaat. Kan worden gebruikt in aangepaste code om te bepalen hoe dit te verwerken of waar het bestand op te slaan. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Stelt een waarde in die aangeeft of de stream open blijft nadat het opslaan van de resource is voltooid. |
| [set_Stream](./set_stream/) | Stelt de binaire inhoud van het opgeslagen bestand in. |
| [set_Uri](./set_uri/) | Stelt de resource-URI in. |
