## CheckPropAndGet {#checkpropandget}

Retourneert de waarde waaraan de eigenschap in deze container is gekoppeld. Als deze container het record ProjectItem niet bevat, wordt het toegevoegd met de standaardwaarde en wordt de standaardwaarde geretourneerd.

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| sleutel | de opgegeven eigenschap. |
