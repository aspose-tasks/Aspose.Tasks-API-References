## FontResolveEventArgs class

Biedt argumenten voor de callback die wordt aangeroepen wanneer het lettertype is opgelost.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_RequestedFontName](./get_requestedfontname/) | Haalt de naam op van het aangevraagde lettertype. |
| [get_ResolvedFontName](./get_resolvedfontname/) | Haalt de naam op van het opgeloste lettertype. Kan worden ingesteld om de lettertypen te beheersen die worden gebruikt om een weergave te renderen. |
| [set_ResolvedFontName](./set_resolvedfontname/) | Stelt de naam in van het opgeloste lettertype. Kan worden ingesteld om de lettertypen te beheersen die worden gebruikt om een weergave te renderen. |
