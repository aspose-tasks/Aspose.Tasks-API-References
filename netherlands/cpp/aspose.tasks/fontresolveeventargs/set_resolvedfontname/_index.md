## set_ResolvedFontName {#set_resolvedfontname}

Stelt de naam in van het opgeloste lettertype. Kan worden ingesteld om de lettertypen te beheersen die worden gebruikt om een weergave te renderen.

**Returns:** Name of the requested font if font is found or name of fallback font or null if font cannot be found.
