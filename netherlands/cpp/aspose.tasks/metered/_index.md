## Metered class

Biedt methoden om de gemeten sleutel in te stellen.

In dit voorbeeld wordt geprobeerd om de metered openbare en privésleutel in te stellen <ms>

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> het component-jarbestand:

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>
