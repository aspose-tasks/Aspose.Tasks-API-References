## FontSettings class

Specificeert lettertype-instellingen die worden gebruikt bij het renderen van de weergave van het project.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | Haalt het standaard (of fallback) lettertype op voor weergave. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | Haalt een callback op die kan worden gebruikt om opgeloste lettertypen aan te passen. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | Haalt een waarde op die aangeeft of het standaardlettertype moet worden gebruikt voor weergave. |
| [set_DefaultFontName](./set_defaultfontname/) | Stelt het standaard (of fallback) lettertype in voor weergave. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | Stelt een callback in die kan worden gebruikt om opgeloste lettertypen aan te passen. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | Stelt een waarde in die aangeeft of het standaardlettertype moet worden gebruikt voor weergave. |
| [SetFontFolders](./setfontfolders/) | Stelt de mappen in waar Aspose.Tasks zoekt naar TrueType-lettertypen bij het weergeven van de projectweergave. |
