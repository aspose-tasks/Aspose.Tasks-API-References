## ProjectFileInfo class

De klasse‑instantie bevat informatie over het projectbestandsformaat en de versie van Microsoft Project waarin het bestand is gemaakt.

Gebruik de CanRead‑eigenschap om aan te geven dat de bibliotheek het projectbestand kan verwerken.
