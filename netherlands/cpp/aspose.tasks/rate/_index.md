## Rate class

Stelt een definitie voor van een tijdsperiode en tarieven die van toepassing zijn op een resource gedurende die periode.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Haalt de kosten per gebruik van een resource op. Deze waarde wordt opgehaald vanaf de huidige datum als er een tarieftabel bestaat voor een resource. |
| [get_OvertimeRate](./get_overtimerate/) | Haalt het overurenttarief per uur voor een resource op. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Haalt de eenheden op die door Microsoft Project worden gebruikt om het overurenttarief weer te geven. |
| [get_RatesFrom](./get_ratesfrom/) | Haalt de datum op waarop een tarief van kracht wordt. |
| [get_RatesTo](./get_ratesto/) | Haalt de laatste datum op waarop een tarief van kracht is. |
| [get_RateTable](./get_ratetable/) | Haalt de unieke identifier van een tarieftabel voor een resource op. |
| [get_StandardRate](./get_standardrate/) | Haalt het standaardtarief per uur voor een resource op. |
| [get_StandardRateFormat](./get_standardrateformat/) | Haalt de eenheden op die door Microsoft Project worden gebruikt om het standaardtarief weer te geven. |
| [set_CostPerUse](./set_costperuse/) | Stelt de kosten per gebruik van een resource in. Deze waarde wordt opgehaald vanaf de huidige datum als er een tarieftabel bestaat voor een resource. |
| [set_OvertimeRate](./set_overtimerate/) | Stelt het overurenttarief per uur voor een resource in. |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Stelt de eenheden in die door Microsoft Project worden gebruikt om het overurenttarief weer te geven. |
| [set_RatesFrom](./set_ratesfrom/) | Stelt de datum in waarop een tarief van kracht wordt. |
| [set_RatesTo](./set_ratesto/) | Stelt de laatste datum in waarop een tarief van kracht is. |
| [set_RateTable](./set_ratetable/) | Stelt de unieke identifier van een tarieftabel voor een resource in. |
| [set_StandardRate](./set_standardrate/) | Stelt het standaardtarief per uur voor een resource in. |
