## CopyTo {#copyto}

Kopieert de elementen van de TimephasedDataCollection naar een System::Array, beginnend bij een specifieke System::Array-index.

**Returns:** void Aspose::Tasks::

```cpp
CopyTo(System::ArrayPtr< System::SharedPtr< TimephasedData >> array, int32_t arrayIndex)
```

| Parameter | Beschrijving |
| --- | --- |
| array | De eendimensionale System::Array die de bestemming is van de elementen die gekopieerd zijn vanuit TimephasedDataCollection. De System::Array moet nulgebaseerde indexering hebben. |
| arrayIndex | De nulgebaseerde index in de array waarop het kopiëren begint. |
