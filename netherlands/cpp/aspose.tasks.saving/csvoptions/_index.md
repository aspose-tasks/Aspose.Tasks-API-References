## CsvOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Staat toe extra opties op te geven bij het opslaan van een project naar CSV.

## Constructors

| Naam | Beschrijving |
| --- | --- |
| [CsvOptions](./csvoptions/) | Initialiseert een nieuw exemplaar van de CsvOptions klasse die kan worden gebruikt om een project op te slaan in CSV-indeling. |

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_DataCategory](./get_datacategory/) | Haalt een gegevenscategorie op die moet worden opgeslagen. |
| [get_Encoding](./get_encoding/) | Haalt een codering op waarmee CSV wordt opgeslagen. |
| [get_IncludeHeaders](./get_includeheaders/) | Haalt een waarde op die aangeeft of kopteksten moeten worden opgenomen al dan niet (standaardwaarde is WAAR). |
| [get_TextDelimiter](./get_textdelimiter/) | Haalt een tekstscheidingsteken op. |
| [get_View](./get_view/) | Haalt een lijst op van de weergavekolommen ( GanttChartColumn ) die moeten worden opgeslagen in XLSX-indeling. Indien niet ingesteld, worden de standaardkolommen opgeslagen. |
| [set_DataCategory](./set_datacategory/) | Stelt een gegevenscategorie in die moet worden opgeslagen. |
| [set_Encoding](./set_encoding/) | Stelt een codering in waarmee CSV wordt opgeslagen. |
| [set_IncludeHeaders](./set_includeheaders/) | Stelt een waarde in die aangeeft of kopteksten moeten worden opgenomen al dan niet (standaardwaarde is WAAR). |
| [set_TextDelimiter](./set_textdelimiter/) | Stelt een tekstscheidingsteken in. |
| [set_View](./set_view/) | Stelt een lijst in van de weergavekolommen ( GanttChartColumn ) die moeten worden opgeslagen in XLSX-indeling. Indien niet ingesteld, worden de standaardkolommen opgeslagen. |
