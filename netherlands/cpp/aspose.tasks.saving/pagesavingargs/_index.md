## PageSavingArgs class

Deze klasse vertegenwoordigt een set gegevens die gerelateerd zijn aan het opslaan van een documentpagina naar een stream.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Haalt een waarde op die aangeeft of de renderingsroutine de Stream open moet houden nadat een pagina is weggeschreven. |
| [get_PageNumber](./get_pagenumber/) | Haalt een paginanummer op dat moet worden weggeschreven. |
| [get_Stream](./get_stream/) | Haalt een stream op voor het weggeschreven van een pagina. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Stelt een waarde in die aangeeft of de renderingsroutine de Stream open moet houden nadat een pagina is weggeschreven. |
| [set_Stream](./set_stream/) | Stelt een stream in voor het weggeschreven van een pagina. |
