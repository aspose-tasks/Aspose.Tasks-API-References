## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Staat toe extra opties op te geven bij het renderen van projectpagina's naar XLSX.

## Constructors

| Naam | Beschrijving |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Initialiseert een nieuw exemplaar van de XxlsxOptions klasse dat kan worden gebruikt om een project op te slaan in XLSX-formaat. |

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Haalt een lijst op van de weergavekolommen voor toewijzingen die moeten worden gerenderd ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | Haalt de codering op van het resulterende XLSX‑bestand. De standaardwaarde is System::Text::Encoding::UTF8. |
| [get_ResourceView](./get_resourceview/) | Haalt een lijst op van de weergavekolommen voor resources die moeten worden gerenderd ( ResourceViewColumn ). |
| [get_View](./get_view/) | Haalt een lijst op van de weergavekolommen ( GanttChartColumn ) die moeten worden opgeslagen in XLSX-indeling. Indien niet ingesteld, worden de standaardkolommen opgeslagen. |
| [set_AssignmentView](./set_assignmentview/) | Stelt een lijst in van de weergavekolommen voor toewijzingen die moeten worden gerenderd ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | Stelt de codering in van het resulterende XLSX‑bestand. De standaardwaarde is System::Text::Encoding::UTF8. |
| [set_ResourceView](./set_resourceview/) | Stelt een lijst in van de weergavekolommen voor resources die moeten worden gerenderd ( ResourceViewColumn ). |
| [set_View](./set_view/) | Stelt een lijst in van de weergavekolommen ( GanttChartColumn ) die moeten worden opgeslagen in XLSX-indeling. Indien niet ingesteld, worden de standaardkolommen opgeslagen. |
