## set_View {#set_view}

Stelt een lijst in van de weergavekolommen die moeten worden gerenderd ( GanttChartColumn ). Als dit niet is ingesteld, worden alleen taak‑ids, taaknamen, start en einde gerenderd. Als zowel View als ViewSettings properties zijn ingesteld, hebben kolommen van View voorrang op kolommen van ViewSettings.
