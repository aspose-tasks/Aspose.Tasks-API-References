### getExportFlag() {#getExportFlag--}
```
public final boolean getExportFlag()
```


Haalt de exportvlag van het project op. Wanneer een project is geselecteerd voor export in Primavera, is de ExportFlag waar. Sommige projecten die niet expliciet zijn geselecteerd voor export, kunnen toch geëxporteerd worden naar een XER‑bestand vanwege hun relatie met het geëxporteerde project.

**Returns:**
boolean - exportvlag van het project.
