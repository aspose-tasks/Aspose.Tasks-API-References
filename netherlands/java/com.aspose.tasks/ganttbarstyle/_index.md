### getParentStyle() {#getParentStyle--}
```
public final GanttBarStyle getParentStyle()
```


Haalt de bovenliggende (of gemeenschappelijke) stijl op voor een aangepaste taak‑specifieke stijl.

--------------------

Een taak kan meerdere aangepaste stijlen hebben met verschillende bovenliggende stijlen. Bijvoorbeeld, beschouw een taak met een aangepaste stijl met de bovenliggende stijl \"Critical\" en een andere stijl met de bovenliggende stijl \"Normal\". Simpel gezegd, als de taak kritiek is, wordt de eerste stijl toegepast. Als de taak niet‑kritiek wordt, wordt de tweede stijl toegepast (deze logica is geërfd van Microsoft Project Professional).

**Returns:**
[GanttBarStyle](../../com.aspose.tasks/ganttbarstyle) - parent (or common) style for custom task-specific style.
