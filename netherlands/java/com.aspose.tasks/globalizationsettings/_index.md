Stelt de globalisatie‑instellingen van het project voor.

De aanbevolen manier is om door het hele project cultuuronafhankelijke literals of opmaak te gebruiken. Als een project echter cultuurspecifieke literals gebruikt, kan deze klasse worden gebruikt om de formule‑berekeningsengine te helpen die literals te parseren.
