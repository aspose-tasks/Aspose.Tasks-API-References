## PrimaveraReadOptions.ReadBaselineProjects property

Haalt of stelt een vlag in die aangeeft of baseline-projecten geladen moeten worden. De standaardwaarde is true.

```csharp
public bool ReadBaselineProjects { get; set; }
```

## Opmerkingen

De vlag is van toepassing op Primavera XML‑bestanden die baselineprojecten bevatten (baseline‑projecten worden niet ondersteund door het XER‑formaat). De optie kan op false worden gezet om het laden van een groot project met baseline‑projecten te versnellen wanneer baseline‑gegevens niet nodig zijn.
