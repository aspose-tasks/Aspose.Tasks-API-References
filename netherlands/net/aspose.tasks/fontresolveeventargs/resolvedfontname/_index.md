## FontResolveEventArgs.ResolvedFontName property

Haalt de naam op of stelt deze in van het opgeloste lettertype. Kan worden ingesteld om de lettertypen te beheersen die worden gebruikt om een weergave te renderen.

```csharp
public string ResolvedFontName { get; set; }
```

### Retourwaarde

Naam van het aangevraagde lettertype als het lettertype wordt gevonden, of de naam van het fallback-lettertype, of null als het lettertype niet kan worden gevonden.
