## VbaModuleType enumeration

Specificeert het type van een module in een VBA-project.

```csharp
public enum VbaModuleType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| DocumentModule | `0` | Een type VBA‑projectitem dat een module specificeert voor ingebedde macro's en programmatische toegangs‑bewerkingen die aan een document zijn gekoppeld. |
| ProceduralModule | `1` | Een module die een verzameling subroutines en functies bevat. |
| ClassModule | `2` | Een module die de definitie van een nieuw object bevat. Elke instantie van een klasse maakt een nieuw object aan, en procedures die in de module zijn gedefinieerd, worden eigenschappen en methoden van het object. |
| DesignerModule | `3` | Een module die de methoden en eigenschappen van een ActiveX‑besturingselement uitbreidt dat met het project is geregistreerd. |
