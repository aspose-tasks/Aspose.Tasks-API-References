## PrimaveraProjectInfo.ExportFlag property

Haalt exportvlag van project op. Wanneer een project is geselecteerd voor export in Primavera, is de ExportFlag waar. Sommige projecten die niet expliciet zijn geselecteerd voor export, kunnen toch worden geëxporteerd naar een XER-bestand vanwege hun relatie met het geëxporteerde project.

public bool ExportFlag { get; }
