Bevat klassen voor het maken van een risico‑analyse‑rapport.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | Stelt een resultaat van risicoanalyse voor. |
| [RiskAnalysisSettings](./riskanalysissettings/) | Specificeert instellingen voor het uitvoeren van risicoanalyse. |
| [RiskAnalyzer](./riskanalyzer/) | Voert een Monte Carlo-simulatie uit op basis van de gespecificeerde instellingen voor risicoanalyse. |
| [RiskItemStatistics](./riskitemstatistics/) | Stelt een item voor dat statistische gegevens opslaat voor de taak van het geanalyseerde project. |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | Stelt een collectie voor die de instanties van de klasse [`RiskItemStatistics`](../aspose.tasks.riskanalysis/riskitemstatistics/) bevat. |
| [RiskPattern](./riskpattern/) | Stelt een risicopatroon voor een projecttaak voor. |
| [RiskPatternCollection](./riskpatterncollection/) | Stelt een collectie voor die de instanties van de klasse [`RiskPattern`](../aspose.tasks.riskanalysis/riskpattern/) bevat. |
## Enumeratie

| Enumeratie | Beschrijving |
| --- | --- |
| [ConfidenceLevel](./confidencelevel/) | Specificeert ondersteunde betrouwbaarheidsniveaus die in risicoanalyse worden gebruikt en overeenkomen met het percentage van de tijd dat de werkelijke waarden binnen optimistische en pessimistische schattingen vallen. |
| [ProbabilityDistributionType](./probabilitydistributiontype/) | Specificeert typen van ondersteunde kansverdelingen. |
| [RiskItemType](./riskitemtype/) | Specificeert taakvelden waarvoor de statistische informatie wordt verzameld tijdens risicoanalyse. |
