## PrimaveraProjectInfo class

Geeft korte informatie weer over een project geladen vanuit Primavera-formaat.

Het type PrimaveraProjectInfo geeft de volgende leden weer:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| uid | Haalt de Uid van het project op. |
| name | Haalt de naam van het project op. |
| short_name | Haalt de korte naam van het project op (Project‑ID). |
| export_flag | Haalt de exportvlag van het project op. Wanneer een project is geselecteerd voor export in Primavera, is de ExportFlag waar.<br/>            Sommige projecten die niet expliciet zijn geselecteerd voor export, kunnen toch worden geëxporteerd naar een XER‑bestand vanwege hun relatie met het geëxporteerde project. |
