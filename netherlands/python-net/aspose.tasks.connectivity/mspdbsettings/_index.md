## MspDbSettings class

Staat toe om de benodigde opties in te stellen om projectgegevens uit een MS Project Server-database te lezen.

Het type MspDbSettings bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Initialiseert een nieuw exemplaar van de klasse [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| connection_string | Haalt de verbindingsreeks op of stelt deze in. |
| provider_invariant_name | Haalt of stelt de provider‑invariante naam in, die wordt gebruikt om een exemplaar van de klasse te verkrijgen. |
| project_guid | Haalt de GUID van het project op om te lezen. |
| schema | Haalt het schema van de MS Project Server op of stelt het in.<br/>            De standaardwaarde is "pub". |
