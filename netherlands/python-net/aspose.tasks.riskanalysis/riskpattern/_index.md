## RiskPattern class

Stelt een risicopatroon voor voor een projecttaak.

Het type RiskPattern biedt de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| RiskPattern(task) | Initialiseert een nieuw exemplaar van de klasse [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| task | Haalt een projecttaak op waarop dit risicopatroon wordt toegepast. |
| distribution | Haalt op of stelt de kansverdeling in die wordt gebruikt in Monte Carlo-simulatie.<br/>            De standaardwaarde is ProbabilityDistributionType.Normal. |
| confidence_level | Haalt op of stelt het betrouwbaarheidsniveau in dat overeenkomt met het percentage van de tijd dat de daadwerkelijk gegenereerde waarden binnen de optimistische en pessimistische schattingen vallen.<br/>            De standaardwaarde is CL99. |
| optimistic | Haalt op of stelt het percentage in van de meest waarschijnlijke taakduur die kan optreden in het best mogelijke projectscenario.<br/>            De standaardwaarde is 75, wat betekent dat als de geschatte taakduur 4 dagen is, de optimistische duur 3 dagen zal zijn. |
| pessimistic | Haalt op of stelt het percentage in van de meest waarschijnlijke taakduur die kan optreden in het slechtst mogelijke projectscenario.<br/>            De standaardwaarde is 125, wat betekent dat als de geschatte taakduur 4 dagen is, de pessimistische duur 5 dagen zal zijn. |
