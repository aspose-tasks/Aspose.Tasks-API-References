## RiskAnalyzer class

Voert een Monte Carlo-simulatie uit op basis van de gespecificeerde instellingen voor risicoanalyse.

Het type RiskAnalyzer bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| RiskAnalyzer(settings) | Initialiseert een nieuw exemplaar van de klasse [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |

| Naam | Beschrijving |
| :- | :- |
| settings | Haalt of stelt de instantie van de klasse [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) in, die de benodigde instellingen voor risicoanalyse definieert. |
