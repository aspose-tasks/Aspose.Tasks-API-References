## RiskItemStatistics class

Geeft een item weer dat statistische gegevens opslaat voor de taak van het geanalyseerde project.

Het type RiskItemStatistics bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| item_type | Haalt een exemplaar op van de [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) enumeratie. |
| minimum | Haalt de minimumwaarde op die tijdens Monte Carlo-simulatie is gegenereerd. |
| maximum | Haalt de maximumwaarde op die tijdens Monte Carlo-simulatie is gegenereerd. |
| expected_value | Haalt de verwachte waarde van het risico-item op. |
| standard_deviation | Haalt de standaarddeviatie van het risico-item op. |
## Methods
| Naam | Beschrijving |
| :- | :- |
| get_percentile(percent) | Haalt een waarde op die onder een opgegeven percentage van de gegenereerde monsters valt. |
