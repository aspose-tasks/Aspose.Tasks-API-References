## TextStyle class

Wijzig de visuele stijl van de tekst voor een item in de projectweergave.

Het TextStyle-type geeft de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| TextStyle() | Initialiseert een nieuw exemplaar van de [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) klasse met standaardinstellingen. |
| TextStyle(font_size, font_style) | Initialiseert een nieuw exemplaar van de TextStyle-klasse |
| TextStyle(font_style) | Initialiseert een nieuw exemplaar van de [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) klasse met het standaardlettertype en de opgegeven lettergrootte en stijl. |
| TextStyle(font) | Initialiseert een nieuw exemplaar van de [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) klasse met de opgegeven lettertype-instellingen. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| font | Haalt het lettertype van de tekststijl op of stelt dit in. |
| color | Haalt de kleur van de tekst op of stelt deze in. |
| item_type | Haalt het [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) van de tekststijl op of stelt dit in. |
| background_pattern | Haalt het achtergrondpatroon van de tekststijl op of stelt dit in.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Haalt de achtergrondkleur van de tekststijl op of stelt deze in.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
