## RecurringInterval class

Geeft terugkerende intervallen weer die worden gebruikt in voortgangslijnen van een Gantt-diagramweergave.

Het type RecurringInterval bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| RecurringInterval() | Initialiseert een nieuw exemplaar van de RecurringInterval-klasse |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| interval | Haalt op of stelt het terugkerende interval in.<br/>            Kan elke waarde van het type [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/) zijn. |
| daily_day_number | Haalt op of stelt het dagelijkse dagnummer in. |
| daily_workday | Haalt op of stelt een waarde in die aangeeft of een dag een werkdag is voor dagelijkse voortgangslijnen. |
| weekly_week_number | Haalt het weeknummer op of stelt het in voor wekelijkse voortgangslijnen. |
| monthly_day | Haalt een waarde op of stelt deze in die aangeeft of maandelijkse voortgangslijnen per dag worden weergegeven. |
| monthly_day_day_number | Haalt het dagnummer op of stelt het in voor maandelijkse voortgangslijnen. |
| monthly_day_month_number | Haalt het maandnummer op of stelt het in voor maandelijkse voortgangslijnen. |
| monthly_first_last | Haalt een waarde op of stelt deze in die aangeeft of voortgangslijnen worden weergegeven op de eerste of laatste vooraf gedefinieerde dag. |
| monthly_first_last_month_number | Haalt het maandnummer op of stelt het in voor voortgangslijnen die worden weergegeven op de eerste of laatste vooraf gedefinieerde dag. |
| monthly_first_last_day | Haalt het type van de eerste of laatste dag op of stelt dit in voor maandelijkse voortgangslijnen. |
| weekly_days | Haalt een lijst met dagen op voor wekelijkse voortgangslijnen. |
