## PageInfo class

Stelt paginainstellingsgegevens voor die aanwezig zijn in het MPP‑bestandsformaat en worden gebruikt voor afdrukken.

Het PageInfo-type geeft de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| PageInfo() | Initialiseert een nieuw exemplaar van de [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) klasse. <br/>            Vertegenwoordigt paginainstellingsgegevens die aanwezig zijn in het MPP-bestandsformaat en worden gebruikt voor afdrukken. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| header | Haalt op of stelt de instantie van de [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) klasse in die headergegevens vertegenwoordigt. |
| footer | Haalt op of stelt de instantie van de [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) klasse in die voettekstgegevens vertegenwoordigt. |
| name | Haalt de naam op van de weergave waarvoor instellingsgegevens worden gebruikt. |
| page_settings | Haalt een instantie op van de [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) klasse die pagina-afdrukinstellingen specificeert. |
| page_view_settings | Haalt een instantie op van de [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) klasse die weergave-afdrukinstellingen van de pagina specificeert. |
| margins | Haalt een instantie op van de [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) klasse die paginamarges specificeert. |
| legend | Haalt op of stelt een instantie in van de [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) klasse die weergaveopties van de paginalegend specificeert. |
