## PageSettings class

Geeft de afdrukinstellingen voor een pagina van de projectweergave weer.

Het type PageSettings biedt de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| PageSettings() | Initialiseert een nieuw exemplaar van de [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/) klasse. <br/>            Vertegenwoordigt afdrukinstellingen voor een pagina van de projectweergave. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| is_portrait | Haalt op of stelt een waarde in die aangeeft of de paginarichting portret is; retourneert false als de paginarichting landschap is. |
| adjust_to_percent_of_normal_size | Haalt een waarde op of stelt deze in die aangeeft of het afdrukken moet worden aangepast naar het opgegeven percentage ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) van de normale grootte. |
| percent_of_normal_size | Haalt een percentage van de normale grootte op of stelt deze in om het afdrukken aan te passen. |
| pages_in_width | Haalt een aantal pagina's in de breedte op of stelt dit in om af te drukken. |
| pages_in_height | Haalt een aantal pagina's in de hoogte op of stelt dit in om af te drukken. |
| paper_size | Haalt een papierformaat op of stelt dit in. Kan een van de waarden van de [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/) enumeratie zijn. |
| paper_size_id | Haalt een geheel getal op of stelt dit in dat één van de PrinterPaperSize-waarden of een aangepast paginagrootte‑id vertegenwoordigt.<br/>            Deze waarde kan worden gebruikt om PaperSize op te halen uit de OS‑instellingen |
| first_page_number | Haalt een eerste paginanummer op of stelt dit in voor afdrukken. |
