## GanttBarStyle class

Stelt een balkstijl voor die door MSP wordt gebruikt in de Gantt‑Chart‑weergave.

Het type GanttBarStyle bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| GanttBarStyle() | Initialiseert een nieuw exemplaar van de klasse [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
