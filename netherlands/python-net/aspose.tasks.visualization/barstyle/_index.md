## BarStyle class

Wijzigt de visuele stijl van de balk voor het item in de projectweergave.

Het BarStyle-type biedt de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| BarStyle() | Initialiseert een nieuw exemplaar van de klasse [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/) . |
