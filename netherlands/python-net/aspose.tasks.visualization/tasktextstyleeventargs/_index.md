## TaskTextStyleEventArgs class

Deze klasse vertegenwoordigt een set gegevens die gerelateerd zijn aan het renderen van de inhoud van een tabelcel.

Het type TaskTextStyleEventArgs bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| cell_text_style | Haalt op of stelt TextStyle in die wordt gebruikt om de inhoud van de cel te tekenen. Dit object kan worden gebruikt om het uiterlijk van een tabelcel aan te passen. |
| task | Haalt [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) op die overeenkomt met de momenteel gerenderde rij. |
| column | Haalt [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) op waartoe de momenteel gerenderde cel behoort. |
