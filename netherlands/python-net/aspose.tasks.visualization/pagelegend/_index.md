## PageLegend class

Stelt een paginalegende voor die wordt gebruikt voor projectafdrukken.

Het PageLegend-type geeft de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| PageLegend() | Initialiseert een nieuw exemplaar van de PageLegend-klasse |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| left_text | Haalt op of stelt de links uitgelijnde tekst in die moet worden weergegeven in het bovenliggende element. |
| centered_text | Haalt op of stelt de gecentreerde tekst in die moet worden weergegeven in het bovenliggende element. |
| right_text | Haalt op of stelt de rechts uitgelijnde tekst in die moet worden weergegeven in het bovenliggende element. |
| left_image | Haalt op of stelt de links uitgelijnde afbeelding in die moet worden weergegeven in het bovenliggende element. |
| centered_image | Haalt op of stelt de gecentreerde afbeelding in die moet worden weergegeven in het bovenliggende element. |
| right_image | Haalt of stelt de rechts uitgelijnde afbeelding in die moet worden weergegeven in het bovenliggende element. |
| left_image_size | Haalt of stelt de weergegeven grootte van de linkse afbeelding in. |
| centered_image_size | Haalt of stelt de weergegeven grootte van de gecentreerde afbeelding in. |
| right_image_size | Haalt of stelt de weergegeven grootte van de rechtse afbeelding in. |
| legend_on | Haalt de pagina's op of stelt ze in waarop de legenda verschijnt. Kan een van de waarden van de [Legend](/tasks/python-net/aspose.tasks.visualization/legend/) enumeratie zijn. |
| width | Haalt de breedte op of stelt deze in van het linkerdeel (standaard met de naam en datum van het project) van de legenda in centimeters. |
