## Timescale enumeration

Definieert opties die specificeren hoe de tijdschaal moet worden gerenderd in Gantt-diagram-, taakgebruik- of resourcegebruikweergaven wanneer het project wordt geëxporteerd naar een grafisch formaat.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| DEFINED_IN_VIEW | Gebruik de tijdsschaalinstellingen die zijn gedefinieerd in de eigenschappen van de projectweergave: [bottom_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/),<br/>            [middle_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/), [top_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/).<br/>            Geldig voor formaten die weergavegegevens bevatten. Bijvoorbeeld projecten die uit het MPP-formaat worden gelezen. |
| DAGEN | Vooraf gedefinieerde tweelaagse tijdsschaal waarbij het minimale detailniveau één dag is. |
| DERDEEN_VAN_DE_MAANDEN | Vooraf gedefinieerde tweelaagse tijdsschaal waarbij het detailniveau één derde van een maand is. |
| MAANDEN | Vooraf gedefinieerde tweelaagse tijdsschaal waarbij het minimale detailniveau één maand is. |
