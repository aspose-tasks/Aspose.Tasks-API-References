## TimescaleUnit enumeration

Specificeert de tijdseenheid voor elke laag van een tijdschaal in een Gantt-diagram of andere tijdsgebaseerde weergave.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| NONE | Geeft Geen aan. De tijdschaallaag is verborgen. |
| MINUTES | Geeft Minuten tijdschaaleenheid aan. |
| UREN | Geeft de tijdseenheid uren aan. |
| DAGEN | Geeft de tijdseenheid dagen aan. |
| WEEKEN | Geeft de tijdseenheid weken aan. |
| DERDEEN_VAN_DE_MAANDEN | Geeft de tijdseenheid derde delen van maanden aan. |
| MAANDEN | Geeft de tijdseenheid maanden aan. |
| KWARTAALEN | Geeft de tijdseenheid kwartalen van jaren aan. |
| HALF_JAREN | Geeft de tijdseenheid halve jaren aan. |
| JAREN | Geeft de tijdseenheid jaren aan. |
