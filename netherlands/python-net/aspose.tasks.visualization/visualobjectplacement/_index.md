## VisualObjectPlacement class

Geeft de plaatsing en het uiterlijk van [OleObject](/tasks/python-net/aspose.tasks/oleobject/) in een weergave weer.

Het type VisualObjectPlacement bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| VisualObjectPlacement() | Initialiseert een nieuw exemplaar van de [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| ole_object_id | Haalt of stelt de Id van het [OleObject](/tasks/python-net/aspose.tasks/oleobject/) object in. |
| task_id | Haalt of stelt de Id van de taak in als de optie 'Attach to task' is geselecteerd, anders -1. |
| width | Haalt of stelt de weergegeven breedte van het visuele object in. |
| height | Haalt of stelt de weergegeven hoogte van het visuele object in. |
| vertical_offset | Haalt of stelt de verticale offset van het visuele object in. |
| horizontal_offset | Haalt of stelt de horizontale offset van het visuele object in. |
| timescale_date | Haalt of stelt de datumplaatsing van het visuele object in wanneer de optie 'Attach to timescale' is geselecteerd. |
| attachment_point | Haalt of stelt de uitlijning van het visuele object ten opzichte van een taak in wanneer de optie 'Attach to task' is geselecteerd. |
| border_line_color | Haalt de kleur van de randlijn op of stelt deze in. |
| border_line_thickness | Haalt de dikte van de randlijn op of stelt deze in (toegestane waarden zijn 0 - 5). |
| fill_color | Haalt de vulkleur op of stelt deze in. |
| fill_pattern | Haalt het vulpatroon op of stelt dit in. |
