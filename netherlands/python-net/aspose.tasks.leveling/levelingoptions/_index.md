## LevelingOptions class

Staat toe om parameters van resource-leveling op te geven.

Het type LevelingOptions bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| LevelingOptions() | Initialiseert een nieuw exemplaar van de [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| start_date | Haalt op of stelt de startdatum van de egalisatieperiode in. De standaardwaarde is de startdatum van het project. |
| finish_date | Haalt op of stelt de einddatum van de egalisatieperiode in. De standaardwaarde is de einddatum van het project. |
| bronnen | Haalt op of stelt de lijst met resources in die geëgaliseerd zullen worden. Als null wordt ingesteld, worden alle projectresources geëgaliseerd. |
| leveling_order | Haalt de volgorde op waarin het nivelleringalgoritme taken met overallocaties vertraagt.<br/>            Na bepaling van de taken die de overallocatie veroorzaken en welke taken kunnen worden vertraagd, wordt de opgegeven volgorde gebruikt om te bepalen welke taak als eerste moet worden vertraagd. |
| message_level | Haalt het niveau op of stelt het in van logberichten die door Aspose.Tasks worden gegenereerd tijdens resource-nivellering. |
| message_handler | Haalt de callback voor berichtafhandeling op of stelt deze in, die kan worden gebruikt om logberichten die door Aspose.Tasks tijdens resource-nivellering worden geproduceerd, af te vangen. |
