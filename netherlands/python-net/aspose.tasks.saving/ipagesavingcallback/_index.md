## IPageSavingCallback class

Stelt een callback voor die wordt aangeroepen wanneer elke pagina in een meerpagina-document wordt opgeslagen naar een aparte stream.

Het type IPageSavingCallback exposeert de volgende leden:
## Methods
| Naam | Beschrijving |
| :- | :- |
| page_saving(args) | De methode die moet worden aangeroepen wanneer een pagina wordt opgeslagen naar een stream. |
| on_finish() | Methode die wordt aangeroepen wanneer alle pagina's zijn geschreven. |
