## PageSavingArgs class

Deze klasse vertegenwoordigt een set gegevens die gerelateerd zijn aan het opslaan van een documentpagina naar een stream.

Het type PageSavingArgs bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| page_number | Geeft een paginanummer dat moet worden geschreven. |
| keep_stream_open | Haalt of stelt een waarde in die aangeeft of de renderingsroutine de [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) open moet houden nadat een pagina is geschreven. |
| stream | Haalt of stelt een stream in voor het schrijven van een pagina. |
