## CsvOptions class

Staat toe om extra opties op te geven bij het opslaan van een project naar CSV.

Het type CsvOptions biedt de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| CsvOptions() | Initialiseert een nieuw exemplaar van de [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) klasse die kan worden gebruikt om een project op te slaan in CSV-formaat. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| save_format | Haalt of stelt het formaat in waarin het document wordt opgeslagen als dit opslaan-opties-object wordt gebruikt. |
| data_category | Haalt of stelt een gegevenscategorie in die moet worden opgeslagen. |
| codering | Haalt of stelt een codering in waarmee CSV moet worden opgeslagen. |
| include_headers | Haalt of stelt een waarde in die aangeeft of kopteksten al dan niet moeten worden opgenomen (standaardwaarde is WAAR). |
| text_delimiter | Haalt of stelt een tekstscheidingsteken in. |
| view | Haalt of stelt een lijst van de weergavekolommen ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) in die moeten worden opgeslagen in XLSX-formaat.<br/>            Als dit niet is ingesteld, worden de standaardkolommen opgeslagen. |
