## LoadOptions class

Staat toe om extra laadparameters op te geven bij het laden van een project uit een bestand of stream.

Het type LoadOptions biedt de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| LoadOptions() | Initialiseert een nieuw exemplaar van de [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| wachtwoord | Haalt een beschermingswachtwoord op of stelt deze in. |
| primavera_read_options | Haalt een opgegeven instantie van de [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) klasse op of stelt deze in, die kan worden gebruikt om het gedrag bij het laden van Primavera-formaten (Primavera P6 XER of Primavera P6 Xml) aan te passen. |
| codering | Haalt de codering op die wordt gebruikt om een project te lezen uit HTML-, MPX-, XER- en Primavera XML-formaten.<br/>            De standaardcodering is UTF8. |
