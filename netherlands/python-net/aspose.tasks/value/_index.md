## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| id | Haalt of stelt de unieke identificatie van een waarde binnen een project in. |
| value_guid | Haalt een GUID op die deze waarde identificeert tussen andere waarden in het gehele project. |
| val | Haalt of stelt de werkelijke waarde in interne representatie in. Gebruik bij voorkeur sterk getypeerde eigenschappen die hieronder worden vermeld. |

| numeric_value | Haalt of stelt de werkelijke waarde in die wordt gebruikt om een getal of kostenwaarde weer te geven. |
| duration | Haalt of stelt de werkelijke waarde in die wordt gebruikt om een duur weer te geven. |
| date_time_value | Haalt of stelt de werkelijke waarde in als deze kan worden weergegeven als DateTime. Standaardwaarde is de minimale datumwaarde. |
| description | Haalt of stelt de beschrijving van een waarde in. |
| phonetic | Haalt of stelt de fonetische informatie over de naam van een aangepast veld in. |
