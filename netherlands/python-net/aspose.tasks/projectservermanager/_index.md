## ProjectServerManager class

De klasse die de methoden biedt om projecten te lezen en bewerkingen uit te voeren in het opgegeven Project Online‑account of<br/>            in de opgegeven on‑premise Project Server‑instance (versies 2016 en 2019 van Project Server worden ondersteund).
