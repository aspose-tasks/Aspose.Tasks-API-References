## TaskBaseline class

Stelt de basislijn van een taak voor.

Het type TaskBaseline bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| TaskBaseline(task) | Initialiseert een nieuw exemplaar van de [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| baseline_number | Haalt of stelt het unieke nummer van een baseline-gegevensrecord in. |
| work | Haalt of stelt het werk in dat aan een resource is toegewezen wanneer de baseline wordt opgeslagen. |
| cost | Haalt of stelt de geprojecteerde kosten van een resource in wanneer de baseline wordt opgeslagen. |
| bcws | Haalt of stelt de budgetkosten van een voor een resource gepland werk in. |
| bcwp | Haalt of stelt de begrote kosten van een door een resource uitgevoerd werk voor een project tot nu toe in. |
| timephased_data | Leest of stelt een TimephasedDataCollection-instantie voor dit object in.<br/>            De tijdgephaseerde gegevens die aan de taakbaseline zijn gekoppeld. |
| interim | Leest of stelt een waarde in die aangeeft of dit een Tijdelijke baseline is. |
| start | Leest of stelt de geplande startdatum van de taak in op het moment dat de baseline werd opgeslagen. |
| finish | Leest of stelt de geplande einddatum van de taak in op het moment dat de baseline werd opgeslagen. |
| duration | Leest of stelt de geplande duur van de taak in op het moment dat de baseline werd opgeslagen. |
| estimated_duration | Geeft of stelt een waarde in die aangeeft of de basislijnduur van de taak werd geschat. |
| fixed_cost | Geeft of stelt een vaste kost van de taak in wanneer de basislijn werd opgeslagen. |
