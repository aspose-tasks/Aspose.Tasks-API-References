## PrimaveraCalendarProperties class

Stelt Primavera‑specifieke eigenschappen voor een agenda voor die is gelezen uit Primavera‑bestanden (XER of P6XML).<br/>            Kan worden gebruikt om agenda‑specifieke tijdseenheden om te rekenen.

Het type PrimaveraCalendarProperties bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| hours_per_day | Haalt het aantal uren per dag op uit de 'Time Periods'-instellingen van de kalender. |
| hours_per_week | Haalt het aantal uren per week op uit de 'Time Periods'-instellingen van de kalender. |
| hours_per_month | Haalt het aantal uren per maand op uit de 'Time Periods'-instellingen van de kalender. |
| hours_per_year | Haalt het aantal uren per maand op uit de 'Time Periods'-instellingen van de kalender. |
