## ResourceSavingArgs class

Deze klasse stelt een set gegevens voor die gerelateerd zijn aan het opslaan van een extern resource‑bestand dat<br/>              plaatsvindt tijdens de conversie naar HTML‑formaat.

Het type ResourceSavingArgs geeft de volgende leden weer:

| :- | :- |

## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| file_name | Haalt of stelt de veronderstelde bestandsnaam in die van de converter naar de code van een aangepaste methode gaat.<br/>             Kan worden gebruikt in aangepaste code om te bepalen hoe het bestand te verwerken of waar het op te slaan. |
| keep_stream_open | Haalt of stelt een waarde in die aangeeft of de stream open blijft nadat het opslaan van de bron is voltooid. |
