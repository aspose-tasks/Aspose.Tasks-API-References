## ViewCollection class

Bevat een lijst van [View](/tasks/python-net/aspose.tasks/view/) objecten.<br/>            Implementeert de ICollection<View>-interface.

Het type ViewCollection bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| parent_project | Haalt de ouder van het View-object op.<br/>            Alleen-lezen [Project](/tasks/python-net/aspose.tasks/project/). |
## Methods
| Naam | Beschrijving |
| :- | :- |
| to_list() | Converteert een view-collectie naar een lijst van [View](/tasks/python-net/aspose.tasks/view/) objecten. |
| get_by_view_screen(screen) | Zoekt naar een View met de opgegeven Screen-eigenschap en retourneert de eerste overeenkomst binnen de collectie. |
| get_by_name(view_name) | Zoekt naar een View met de naam en retourneert de eerste overeenkomst binnen de collectie. |
