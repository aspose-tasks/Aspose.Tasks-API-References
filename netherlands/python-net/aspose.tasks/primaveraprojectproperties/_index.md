## PrimaveraProjectProperties class

Stelt Primavera‑specifieke eigenschappen voor een project voor die is gelezen uit Primavera‑bestanden (XER of P6XML).

Het type PrimaveraProjectProperties bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| relationship_lag_calendar | Haalt een optie op die bepaalt welke agenda gebruikt moet worden voor het plannen van Relationship Lag in Primavera-projecten |
| use_expected_finish_dates | Haalt een vlag op die bepaalt of einddatums van activiteiten moeten worden gepland als de verwachte einddatums. |
| make_open_ended_activities_critical | Haalt een vlag op die bepaalt of activiteiten gemarkeerd moeten worden als kritiek bij het plannen van het project. |
| ignore_other_project_relationships | Haalt een vlag op die bepaalt of activiteitsrelaties tussen projecten genegeerd moeten worden. |
| current_baseline_project_id | Haalt de Id op van het huidige baseline‑project.<br/>            Is van toepassing op projecten die zijn gelezen uit Primavera‑XML‑bestanden met geëxporteerde baselines. |
| baseline_projects | Haalt een array op van baseline‑projecten van het huidige project.<br/>            Is van toepassing op projecten die zijn gelezen uit Primavera‑XML‑bestanden met geëxporteerde baselines. |
| critical_activities_defining_method | Haalt de methode op voor het definiëren van kritieke activiteiten: Langste pad of Total Float‑benadering. |
| critical_total_float_limit | Haalt de drempelwaarde op die wordt gebruikt om kritieke activiteiten te definiëren wanneer de TotalFloat‑methode wordt gebruikt. |
| short_name | Haalt de korte naam van het project op (Project‑ID). |
