## ProjectServerCredentials class

Inloggegevens die worden gebruikt om verbinding te maken met Project Online of een on‑premise‑instance van Project Server.

Het type ProjectServerCredentials bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | Initialiseert een nieuw exemplaar van de klasse [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) met de URL van de SharePoint-site en een geldig SPOIDCRL-autorisatietoken voor de PWA-site (Project Web Access) van SharePoint. |
| ProjectServerCredentials(site_url, user_name, password) | Initialiseert een nieuw exemplaar van de klasse [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) met de URL van de SharePoint-site en een geldig SPOIDCRL-autorisatietoken voor de PWA-site (Project Web Access) van SharePoint. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| site_url | Haalt de URL van PWA op bij de SharePoint-site of de URL van een on-premise Project Server.<br/>            Bijvoorbeeld, https://your_company_name.sharepoint.com/sites/pwa"; |
| auth_token | Haalt het autorisatietoken op voor de SharePoint-instatie. |
| user_name | Haalt de gebruikersnaam op voor de SharePoint-site. |
