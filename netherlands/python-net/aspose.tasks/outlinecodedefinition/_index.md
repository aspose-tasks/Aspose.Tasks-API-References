## OutlineCodeDefinition class

Stelt een outline-code definitie voor.

Het type OutlineCodeDefinition geeft de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| OutlineCodeDefinition() | Initialiseert een nieuw exemplaar van de [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| guid | Haalt de Guid van een outlinecode op of stelt deze in. |
| field_id | Haalt het veldnummer van een outlinecode op of stelt dit in. |
| field_name | Haalt de naam van een aangepast outlinecode op of stelt deze in. |
| alias | Haalt de alias van een aangepast outlinecode op of stelt deze in. |
| phonetic_alias | Haalt de fonetische uitspraak van de alias van de aangepaste outlinecode op of stelt deze in. |
| values | Haalt OutlineValueCollection-object op.<br/>            De waarden van de tabel die aan deze outlinecode is gekoppeld. |
| enterprise | Haalt een waarde op of stelt deze in die aangeeft of een aangepaste outlinecode een enterprise aangepaste outlinecode is. |
| enterprise_outline_code_alias | Haalt een verwijzing naar een ander aangepast veld op of stelt deze in waarvoor deze outlinecode-definitie een alias is. |
| resource_substitution_enabled | Haalt een waarde op of stelt deze in die aangeeft of de aangepaste outlinecode kan worden gebruikt<br/>            door de Resource Substitution Wizard in Microsoft Project. |
| leaf_only | Haalt een waarde op of stelt deze in die aangeeft of de in dit outlinecode-veld opgegeven waarden bladwaarden moeten zijn. |
| all_levels_required | Haalt een waarde op of stelt deze in die aangeeft of de nieuwe codes alle niveaus moeten hebben.<br/>            Niet beschikbaar voor Enterprise-codes. |
| only_table_values_allowed | Haalt een waarde op of stelt deze in die aangeeft of de opgegeven waarden uit de waardentabel moeten komen. |
| masks | Haalt het OutlineMaskCollection-object op.<br/>            De tabel met items die de outlinecode-masker definiëren.<br/>            Alleen-lezen [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/) instantie. |
| show_indent | Haalt een waarde op of stelt deze in die aangeeft of de inspringingen van deze outlinecode moeten worden weergegeven. |
