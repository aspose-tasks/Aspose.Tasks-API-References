## Baseline class

Stelt baseline-waarden van een resource voor.

Het type Baseline bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| Baseline() | Initialiseert een nieuw exemplaar van de Baseline-klasse |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| baseline_number | Haalt of stelt het unieke nummer van een baseline-gegevensrecord in. |
| work | Haalt of stelt het werk in dat aan een resource is toegewezen wanneer de baseline wordt opgeslagen. |
| cost | Haalt of stelt de geprojecteerde kosten van een resource in wanneer de baseline wordt opgeslagen. |
| bcws | Haalt of stelt de budgetkosten van een voor een resource gepland werk in. |
| bcwp | Haalt of stelt de begrote kosten van een door een resource uitgevoerd werk voor een project tot nu toe in. |
