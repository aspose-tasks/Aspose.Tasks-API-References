## WeekDay class

Stelt een weekdag voor die ofwel reguliere dagen van een week of uitzonderingsdagen in een kalender definieert.

Het WeekDay-type geeft de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| WeekDay(day_type) | Initialiseert een nieuw exemplaar van de [WeekDay](/tasks/python-net/aspose.tasks/weekday/) klasse met het opgegeven dagtype. |
| WeekDay(day_type, working_times) | Initialiseert een nieuw exemplaar van de WeekDay-klasse |
| WeekDay(day_type, working_times) | Initialiseert een nieuw exemplaar van de [WeekDay](/tasks/python-net/aspose.tasks/weekday/) klasse met het opgegeven dagtype en werkperiode. |

## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| day_type | Haalt het type van een dag op. |
| day_working | Haalt een waarde op of stelt deze in die aangeeft of de opgegeven datum of het dagtype een werkdag is. |
| from_date | Haalt het begin van een uitzonderingstijd op of stelt het in. |
| to_date | Haalt het einde van een uitzonderingstijd op of stelt het in. |
| working_times | Haalt WorkingTimeCollection op voor deze WeekDay-instantie.<br/>            De verzameling werktijden die de gewerkte tijd op de weekdag definiëren. |
## Methods
| Naam | Beschrijving |
| :- | :- |
| create_default_working_day(day_type) | Maakt een standaardwerkdag aan. |
| set_default_working_time(day) | Stelt standaardtijdperioden in voor de opgegeven weekdag. |
| get_working_time() | Retourneert de werktijd voor een weekdag. |
| clone() | Retourneert een diepe kopie van de weekdag. |
