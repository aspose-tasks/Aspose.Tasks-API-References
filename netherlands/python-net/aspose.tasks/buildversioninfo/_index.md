## BuildVersionInfo class

Bevat buildversie en productinformatie.

Het type BuildVersionInfo bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| ASSEMBLY_VERSION | Assembly-versie. |
| ASSEMBLY_INFORMATIONAL_VERSION | Het informatieve versienummer van de assembly. |
| FILE_VERSION | Bestandsversie. |
| PRODUCT | Productnaam. |
