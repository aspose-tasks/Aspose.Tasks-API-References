## OutlineMask class

Stelt vier elementen van een masker voor die een outline-codeformaat definiëren.

Het OutlineMask-type geeft de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| OutlineMask() | Initialiseert een nieuw exemplaar van de [OutlineMask](/tasks/python-net/aspose.tasks/outlinemask/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| level | Haalt het niveau van een masker op of stelt het in. |
| type | Haalt het type van een masker op of stelt het in. |
| length | Haalt de maximale lengte (in tekens) van de outline-codewaarden op of stelt deze in. 0 als de lengte niet is gedefinieerd. |
