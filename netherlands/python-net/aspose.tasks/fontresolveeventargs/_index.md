## FontResolveEventArgs class

Biedt argumenten voor de callback die wordt aangeroepen wanneer het lettertype is opgelost.

Het type FontResolveEventArgs bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| requested_font_name | Haalt de naam van het aangevraagde lettertype op. |
| resolved_font_name | Haalt de naam van het opgeloste lettertype op of stelt deze in. Kan worden ingesteld om de lettertypen te bepalen die worden gebruikt om een weergave te renderen. |
