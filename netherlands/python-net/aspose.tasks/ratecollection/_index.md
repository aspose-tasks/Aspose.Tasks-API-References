## RateCollection class

Stelt een collectie voor die [Rate](/tasks/python-net/aspose.tasks/rate/) objecten bevat.

Het type RateCollection bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| count | Haalt het aantal elementen op dat in de RateCollection zit. |
| is_read_only | Haalt een waarde op die aangeeft of deze collectie alleen-lezen is. |
| parent_resource | Haalt het bovenliggende [Resource](/tasks/python-net/aspose.tasks/resource/) object voor deze collectie op. |
## Methods
| Naam | Beschrijving |
| :- | :- |
| add(rates_from) | Voegt een nieuw [Rate](/tasks/python-net/aspose.tasks/rate/) exemplaar toe aan deze collectie. |
| add(rates_from, type) | Voegt een nieuw [Rate](/tasks/python-net/aspose.tasks/rate/) exemplaar toe aan deze collectie. |
| to_list() | Converteert het [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) object naar een lijst van [Rate](/tasks/python-net/aspose.tasks/rate/) objecten. |
| to_list(type) | Converteert het [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) object naar een lijst van [Rate](/tasks/python-net/aspose.tasks/rate/) objecten, gefilterd op het opgegeven [RateType](/tasks/python-net/aspose.tasks/ratetype/) type. |
| remove(item) | Verwijdert Rate instantie uit deze collectie. |
