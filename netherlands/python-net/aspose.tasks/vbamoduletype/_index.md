## VbaModuleType enumeration

Specificeert het type van een module in een VBA-project.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| DOCUMENT_MODULE | Een type VBA-projectitem dat een module specificeert voor ingebedde macro's en programmatische toegangsoperaties die aan een document zijn gekoppeld. |
| PROCEDURAL_MODULE | Een module die een verzameling subroutines en functies bevat. |
| CLASS_MODULE | Een module die de definitie van een nieuw object bevat. Elke instantie van een klasse maakt een nieuw object aan, en procedures die in de module zijn gedefinieerd, worden eigenschappen en methoden van het object. |
| DESIGNER_MODULE | Een module die de methoden en eigenschappen van een ActiveX-besturingselement uitbreidt dat met het project is geregistreerd. |
