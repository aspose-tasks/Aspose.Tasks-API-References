## RecurringTaskParameters class

Stelt de set parameters voor die worden gebruikt om een terugkerende taak in een project te maken.

Het type RecurringTaskParameters exposeert de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| RecurringTaskParameters() | Initialiseert een nieuw exemplaar van de [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| duration | Geeft of stelt de duur in voor één gebeurtenis van de terugkerende taak. |
| ignore_resource_calendar | Geeft of stelt een waarde in die aangeeft of de terugkerende taak moet worden gepland, zelfs als deze niet plaatsvindt wanneer er geen middelen beschikbaar zijn om eraan te werken. |
| recurrence_pattern | Geeft of stelt het terugkeerpatroon van de terugkerende taak in. |
| task_name | Geeft of stelt de naam van de terugkerende taak in. |
## Methods
| Naam | Beschrijving |
| :- | :- |
| set_calendar(project, calendar_name) | Stel een agenda in voor de terugkerende taak. De agenda wordt geselecteerd uit de agenda-collectie van het project. |
