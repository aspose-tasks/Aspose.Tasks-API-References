## ExtendedAttribute class

Stelt uitgebreide attributen voor.

Het type ExtendedAttribute bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| attribute_definition | Haalt de attribuutdefinitie op. |
| field_id | Haalt de id van een veld op. |
| duration_value | Haalt op of stelt de waarde in voor attributen met het type 'Duration'. |
| numeric_value | Haalt op of stelt een waarde in voor attributen met numerieke types (Cost, Number). |
| date_value | Haalt op of stelt een waarde in voor attributen met datumtypes (Date, Start, Finish). |
| flag_value | Haalt op of stelt een waarde in die aangeeft of een vlag is ingesteld voor een attribuut met het type 'Flag'. |
| text_value | Haalt op of stelt een waarde in voor attributen met het type 'Text'. |
| value_guid | Haalt de guid van een lookup-waarde op. |
| value_read_only | Haalt een waarde op die aangeeft of een waarde van deze [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) instantie alleen-lezen is. |
| is_error_value | Haalt op of de berekening van de waarde van het uitgebreide attribuut een fout heeft opgeleverd. |
