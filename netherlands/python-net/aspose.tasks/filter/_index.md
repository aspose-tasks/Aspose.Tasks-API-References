## Filter class

Stelt een filter in Project voor.

## Constructors
| Naam | Beschrijving |
| :- | :- |
| Filter() | Initialiseert een nieuw exemplaar van de Filter-klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| filter_type | Haalt het type van het filter op. |
| name | Haalt de naam van een Filter-object op of stelt deze in. |
| show_in_menu | Haalt een waarde op of stelt deze in die aangeeft of het project de filternaam weergeeft in de vervolgkeuzelijst Filter op het tabblad Beeld van het lint. |
| show_related_summary_rows | Haalt een waarde op of stelt deze in die aangeeft of gerelateerde samenvattingsrijen worden weergegeven voor het filter. |
| index | Haalt de index op van een [Filter](/tasks/python-net/aspose.tasks/filter/) object in het Filters-bevattende object. |
| uid | Haalt de unieke identifier van een filter op. |
| criteria | Haalt de criteria op of stelt deze in waaraan taken of resources moeten voldoen om weergegeven te worden in de MSP-weergave. |
