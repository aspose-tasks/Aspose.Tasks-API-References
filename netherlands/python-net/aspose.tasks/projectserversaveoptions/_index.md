## ProjectServerSaveOptions class

Staat toe om extra opties op te geven wanneer een project wordt opgeslagen naar Project Server of Project Online.

Het type ProjectServerSaveOptions geeft de volgende leden weer:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| ProjectServerSaveOptions() | Initialiseert een nieuw exemplaar van de [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| project_name | Haalt de naam van een project op of stelt deze in, die wordt weergegeven in de lijst met projecten van Project Server \ Project Online. Moet uniek zijn binnen de Project Server \ Project Online‑instantie.<br/>            Als de waarde wordt weggelaten, wordt de waarde van de eigenschap Prj.Name gebruikt. |
| project_guid | Haalt de unieke identifier van een project op of stelt deze in. Moet uniek zijn binnen de Project Server \ Project Online‑instantie. |
| timeout | Haalt de time‑out op of stelt deze in die wordt gebruikt bij het wachten op de verwerking van een opslaan‑project‑verzoek door de wachtrij‑verwerkingsservice van Project Server. De standaardwaarde voor deze eigenschap is 1 minuut. |
| polling_interval | Haalt het interval tussen wachtrij‑taakstatus‑verzoeken op of stelt dit in. De standaardwaarde is 2 seconden. |
