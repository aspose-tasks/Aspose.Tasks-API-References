## OleObject class

Stelt een OLE-object voor dat kan worden ingevoegd in de Gantt-diagramweergave van een MPP-bestand.

Het type OleObject exposeert de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| OleObject() | Initialiseert een nieuw exemplaar van de [OleObject](/tasks/python-net/aspose.tasks/oleobject/) klasse. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| name | Haalt de naam op of stelt deze in van de instantie van het OLE-object. |
| application_name | Haalt de toepassingsnaam op of stelt deze in waarmee het ingesloten object wordt geopend. |
| file_format | Haalt het bestandsformaat op of stelt dit in van het ingesloten object. |
| content | Haalt de gegevens van het ingesloten bestand op of stelt deze in; null als er geen gegevens zijn ingesloten. |
| label | Haalt het label op of stelt dit in van het ingevoegde object. |
| full_path | Haalt het volledige pad op of stelt dit in van het ingevoegde object. |
| temporary_file | Haalt het pad naar het tijdelijke bestand op of stelt dit in van het ingevoegde object. |
| display_as_icon | Haalt of stelt een vlag in die aangeeft dat het OLE-object moet worden weergegeven als een pictogram of als de reguliere afbeelding. |
| gelinkt | Haalt een waarde op die aangeeft of het projectbestand alleen een koppeling bevat naar de feitelijke gegevens die bij de koppelingsbron zijn opgeslagen. |
| view | Haalt of stelt de instantie van de [view](/tasks/python-net/aspose.tasks/oleobject/) klasse waartoe het ingevoegde object behoort, in. |
| id | Haalt of stelt de object-id in. |
