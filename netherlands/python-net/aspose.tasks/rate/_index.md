## Rate class

Stelt een definitie voor van een tijdsperiode en tarieven die van toepassing zijn op een resource gedurende die periode.

Het type Tarief geeft de volgende leden weer:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| rates_from | Haalt op of stelt de datum in waarop een tarief van kracht wordt. |
| rates_to | Haalt op of stelt de laatste datum in waarop een tarief van kracht is. |
| rate_table | Haalt op of stelt de unieke identifier van een tarieftabel voor een resource in. |
| standard_rate | Haalt op of stelt het standaardtarief per uur voor een resource in. |
| standard_rate_format | Haalt op of stelt de eenheden in die Microsoft Project gebruikt om het standaardtarief weer te geven. |
| overtime_rate | Haalt op of stelt het overurenttarief per uur voor een resource in. |
| overtime_rate_format | Haalt op of stelt de eenheden in die Microsoft Project gebruikt om het overurenttarief weer te geven. |
| cost_per_use | Haalt op of stelt de kosten per gebruik van een resource in. Deze waarde wordt opgehaald op basis van de huidige datum als er een tarieftabel voor een resource bestaat. |
