## PrimaveraTaskProperties class

Stelt Primavera‑specifieke eigenschappen voor een taak voor die is gelezen uit Primavera‑bestanden (XER of P6XML).

Het type PrimaveraTaskProperties stelt de volgende leden beschikbaar:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| sequence_number | Haalt of stelt het volgnummer van het WBS-item (samenvattende taken) in. Het wordt gebruikt om samenvattende taken in Primavera te sorteren. |
| activity_id | Haalt een activity id-veld op - een unieke identifier van een taak die door Primavera wordt gebruikt. |
| remaining_early_finish | Haalt de resterende vroegste einddatum op - de datum waarop het resterende werk voor de activiteit gepland is om te worden voltooid. |
| remaining_early_start | Haalt de resterende vroegste startdatum op - de datum waarop het resterende werk voor de activiteit gepland is om te beginnen. |
| remaining_late_start | Haalt de resterende late startdatum op. |
| remaining_late_finish | Haalt de resterende late einddatum op. |
| raw_duration_type | Haalt de ruwe tekstrepresentatie (zoals in het bronbestand) van het veld 'Duration Type' van de activiteit op. |
| duration_type | Haalt de waarde van het veld 'Duration Type' van de activiteit op. |
| raw_activity_type | Haalt de ruwe tekstrepresentatie (zoals in het bronbestand) van het veld 'Activity Type' van de activiteit op. |
| activity_type | Haalt de waarde van het veld 'Activity Type' op. |
| percent_complete_type | Haalt de waarde van het veld '% Complete Type' van de activiteit op. |
| raw_complete_percent_type | Haalt de ruwe tekstrepresentatie (zoals in het bronbestand) van het veld '% Complete Type' van de activiteit op. |
| raw_status | Haalt ruwe tekstrepresentatie (zoals in bronbestand) op van het 'Status'-veld van de activiteit. |
| physical_percent_complete | Haalt de waarde op van Physical Percent Complete. |
| duration_percent_complete | Haalt de waarde op van duration percent complete. |
| units_percent_complete | Haalt de waarde op van units percent complete. |
| actual_labor_units | Haalt de waarde op van actual labor units. |
| actual_non_labor_units | Haalt de waarde op van actual non labor units. |
| remaining_labor_units | Haalt de waarde op van remaining labor units. |
| remaining_non_labor_units | Haalt de waarde op van remaining non labor units. |
| actual_labor_cost | Haalt de waarde op van actual labor cost . |
| budgeted_labor_cost | Haalt de waarde op van budgeted (of gepland) labor cost . |
| actual_nonlabor_cost | Haalt de waarde op van actual non labor cost . |
| budgeted_nonlabor_cost | Haalt de waarde op van budgeted (of gepland) non labor cost . |
| actual_material_cost | Haalt de waarde van de werkelijke materiaalkost op. |
| budgeted_material_cost | Haalt de waarde van de begrote (of geplande) materiaalkost op. |
| actual_expense_cost | Haalt de waarde van de werkelijke uitgavenkost op. |
| remaining_expense_cost | Haalt de waarde van de resterende uitgavenkost op. |
| budgeted_expense_cost | Haalt de waarde van de begrote (of geplande) uitgavenkost op. |
| actual_total_cost | Haalt de totale waarde van de werkelijke kosten op. |
| budgeted_total_cost | Haalt de totale waarde van de begrote (of geplande) kosten op. |
| primary_constraint_type | Haalt een type van de primaire beperking op. |
| primary_constraint_date | Haalt de datum van de primaire beperking op. |
| secondary_constraint_type | Haalt een type van de secundaire beperking op. |
| secondary_constraint_date | Haalt de datum van de secundaire beperking op. |
| planned_duration | Haalt de oorspronkelijke of geplande duur op -- de totale werktijd van de geplande startdatum van de taak tot de geplande einddatum.. |
