## AvailabilityPeriod class

Stelt een periode voor waarin een resource beschikbaar is.

Het type AvailabilityPeriod biedt de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| AvailabilityPeriod() | Initialiseert een nieuw exemplaar van de [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | Initialiseert een nieuw exemplaar van de [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) met het opgegeven datumbereik en de beschikbare eenheden. |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| available_from | Haalt de datum op of stelt de datum in waarop een resource beschikbaar wordt voor de opgegeven periode. |
| available_to | Haalt de laatste datum op of stelt de laatste datum in waarop een resource beschikbaar is voor de opgegeven periode. |
| available_units | Haalt het percentage op of stelt het percentage in van een resource dat beschikbaar is gedurende de opgegeven periode. |
