## TaskStatus enumeration

Specificeert de status van een taak.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| UNDEFINED | Ongedefinieerde taakstatus. |
| COMPLETE | De taak is 100 procent voltooid. |
| ON_SCHEDULE | De taak loopt op schema als het tijdgephaseerde cumulatieve voltooiingspercentage zich uitstrekt tot ten minste de dag vóór de statusdatum. |
| LATE | De taak is te laat als het tijdgephaseerde cumulatieve voltooiingspercentage op de dag vóór de statusdatum middernacht niet bereikt. |
| FUTURE | 'Future' taakstatus wordt ingesteld wanneer de startdatum van de taak later is dan de statusdatum. |
