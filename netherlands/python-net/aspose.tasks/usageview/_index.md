## UsageView class

Stel een gebruiksweergave in een project voor.

Het type UsageView biedt de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| filter | Haalt of stelt een filter in dat wordt gebruikt in een enkele weergave. |
| groep | Haalt een groep van de enkele weergave op of stelt deze in. |
| uid | Haalt de unieke identifier van een weergave op. |
| highlight_filter | Haalt een waarde op of stelt deze in die aangeeft of Microsoft Project het filter voor een enkele weergave markeert. |
| name | Haalt de naam van een View-object op of stelt deze in. |
| screen | Haalt het schermtype voor de enkele weergave op.<br/>            Alleen-lezen [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Haalt de ouder van het View-object op.<br/>            Alleen-lezen [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Haalt een tabel van de enkele weergave op of stelt deze in. |
| type | Haalt het type item in de enkele weergave op, zoals taken of resources.<br/>            Alleen-lezen [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Haalt een waarde op of stelt deze in die aangeeft of Microsoft Project de naam van de enkele weergave toont in de View- of de Andere weergaven‑keuzelijsten in het lint. |
| page_info | Haalt een instantie van de [page_info](/tasks/python-net/aspose.tasks/view/) klasse op. Vertegenwoordigt paginainstellingsgegevens die aanwezig zijn in het mpp‑bestandsformaat. |
| visual_objects_placements | Haalt een verzameling objecten op die de plaatsing en weergave van [OleObject](/tasks/python-net/aspose.tasks/oleobject/) in de weergave vertegenwoordigen. |
| align_details_data | Haalt de uitlijning van detailgegevens op of stelt deze in. |
| display_details_header_column | Haalt een waarde op of stelt deze in die aangeeft of de kolom met detailkoppen in de weergave moet worden weergegeven. |
| display_short_detail_header_names | Haalt een waarde op of stelt deze in die aangeeft of korte detailkopnamen moeten worden weergegeven. |
| repeat_details_header_on_all_rows | Haalt een waarde op of stelt deze in die aangeeft of de detailkop op elke toewijzingsrij moet worden herhaald. |
| timescale_size_percentage |  |
| bottom_timescale_tier | Haalt de instellingen van de onderste tijdschaallaag van de weergave op of stelt deze in.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | Haalt de instellingen van de middelste tijdschaallaag van de weergave op of stelt deze in.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | Haalt of stelt de instellingen van de bovenste tijdschaallaag van de weergave in.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
