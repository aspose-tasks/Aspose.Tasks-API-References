## GraphicalIndicatorCriteria class

Stelt één criterium voor grafische indicatoren voor dat is gekoppeld aan een uitgebreid attribuut.

Het type GraphicalIndicatorCriteria bevat de volgende leden:
## Constructors
| Naam | Beschrijving |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Initialiseert een nieuw exemplaar van de GraphicalIndicatorCriteria-klasse |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Initialiseert een nieuw exemplaar van de GraphicalIndicatorCriteria-klasse |
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| test | Haalt het type vergelijking op dat wordt gemaakt tussen de waarde van het uitgebreide attribuut en Waarden die dienen als criterium voor de toepassing van de grafische indicator.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Haalt de waarde op die wordt gebruikt om de waarde van het uitgebreide attribuut te testen. |
| value2 | Haalt de tweede waarde op die wordt gebruikt om de waarde van het uitgebreide attribuut te testen in het geval van de vergelijkingssoorten 'IsWithin' en 'IsNotWithin'. |
| image_index | Haalt de index van de afbeelding op die moet worden weergegeven wanneer het veld aan de criteria voldoet. |
| row_type | Haalt de waarde op van de [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) enum die aangeeft voor welke rijen de indicator wordt toegepast. |
