## RecurringTaskInfo class

Stelt de details van een terugkerende taak in een project voor.

Het type RecurringTaskInfo exposeert de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| recurrence_pattern | Geeft of stelt een terugkeerpatroon van de terugkerende taak in. |
| start_date | Geeft of stelt de datum in waarop de gebeurtenissen beginnen. |
| end_date | Geeft of stelt de datum in waarop de gebeurtenissen eindigen. |
| duration | Geeft of stelt de duur in voor één gebeurtenis van de terugkerende taak. |
| occurrences | Geeft of stelt een aantal gebeurtenissen van de terugkerende taak in. |
| use_end_date | Geeft of stelt een waarde in die aangeeft of de einddatum of een aantal gebeurtenissen moet worden gebruikt voor de terugkerende taak. |
| daily_repetitions | Geeft of stelt een aantal herhalingen in voor het dagelijkse terugkeerpatroon. |
| daily_use_workdays | Haalt een waarde op of stelt een waarde in die aangeeft of werkdagen moeten worden gebruikt voor het dagelijkse herhalingspatroon. |
| weekly_repetitions | Haalt een aantal herhalingen op of stelt dit in voor het wekelijkse herhalingspatroon. |
| weekly_days | Haalt een verzameling dagen op of stelt deze in die worden gebruikt in het wekelijkse herhalingspatroon. |
| monthly_use_ordinal_day | Haalt een waarde op of stelt deze in die aangeeft of een ordinale dag moet worden gebruikt voor het maandelijkse herhalingspatroon. |
| monthly_ordinal_number | Haalt een ordinaal getal op of stelt dit in voor het maandelijkse herhalingspatroon. |
| monthly_ordinal_repetitions | Haalt een aantal herhalingen op of stelt dit in voor het maandelijkse herhalingspatroon bij gebruik van een ordinale dag. |
| monthly_day | Haalt een aantal dagen op of stelt dit in voor het maandelijkse herhalingspatroon. |
| monthly_repetitions | Haalt een aantal herhalingen op of stelt dit in voor het maandelijkse herhalingspatroon. |
| yearly_use_ordinal_day | Haalt een waarde op of stelt deze in die aangeeft of een ordinale dag moet worden gebruikt voor het jaarlijkse herhalingspatroon. |
| yearly_date | Haalt een datum op of stelt deze in voor het jaarlijkse herhalingspatroon. |
| yearly_ordinal_number | Haalt een ordinaal getal op of stelt dit in voor het jaarlijkse herhalingspatroon. |
| yearly_ordinal_month | Haalt een maand op of stelt deze in voor het jaarlijkse herhalingspatroon bij gebruik van een ordinale dag. |
| task | Haalt de bovenliggende taak op van deze instantie van de klasse [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
