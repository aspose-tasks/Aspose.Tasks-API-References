## FilterComparisonType enumeration

Het type vergelijking gemaakt tussen FieldName en Value dat fungeert als selectiecriteria voor een filter of grafische indicator.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| EQUALS | De waarde van Veld is gelijk aan Waarde. |
| DOES_NOT_EQUAL | De waarde van Veld is niet gelijk aan Waarde. |
| IS_GREATER_THAN | De waarde van Veld is groter dan Waarde. |
| IS_GREATER_THAN_OR_EQUAL_TO | De waarde van Veld is groter dan of gelijk aan Waarde. |
| IS_LESS_THAN | De waarde van Veld is kleiner dan Waarde. |
| IS_LESS_THAN_OR_EQUAL_TO | De waarde van Veld is kleiner dan of gelijk aan Waarde. |
| IS_WITHIN | De waarde van Veld ligt binnen Waarde. |
| IS_NOT_WITHIN | De waarde van Field is niet binnen Value. |
| CONTAINS | De waarde van Field bevat Value. |
| DOES_NOT_CONTAIN | De waarde van Field bevat Value niet. |
| CONTAINS_EXACTLY | De waarde van Field bevat Value exact. |
| IS_ONE_OF | De waarde van Field is gelijk aan een van de opgegeven Values. Gebruikt in AutoFilters. |
| UNDEFINED | Ongedefinieerde waarde. |
| IS_ANY_VALUE | 'Is any value' conditie. Toepasbaar op grafische indicatoren. |
