## TaskLinkDrawingArgs class

Biedt argumenten voor de callback die wordt aangeroepen wanneer een taakkoppeling wordt gerenderd.

Het type TaskLinkDrawingArgs bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| link | Haalt de gerenderde taaklink op. |
| color | Haalt de kleur op of stelt deze in die wordt gebruikt om de taaklink te renderen. Kan worden gebruikt voor het aanpassen van de kleuren van taaklinks. |
