## MPPSaveOptions class

允许在将项目数据保存为 MPP 时指定其他选项。

MPPSaveOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| MPPSaveOptions() | 初始化一个新的 [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| save_format | 获取或设置在使用此保存选项对象时文档将被保存的格式。 |
| remove_invalid_assignments | 获取或设置一个值，指示在保存为 MPP 时是否删除无效的资源分配。 |
| write_view_data | 获取或设置一个值，指示在将项目保存为 MPP 格式时是否写入视图数据。 |
| write_filters | 获取或设置一个值，指示在将项目保存为 MPP 格式时是否写入过滤器数据。 |
| write_groups | 获取或设置一个值，指示在将项目保存为 MPP 格式时是否写入组数据。 |
| clear_vba | 获取或设置一个值，指示在将项目保存为 MPP 格式时是否删除现有的 VBA 宏数据。 |
| write_vba | 获取或设置一个值，指示是否在 MPP 文件中更新现有的 VBA 宏数据。<br/>            当前支持写入 VbaModule.SourceCode。 |
| protection_password | 获取或设置用于保护生成的 MPP 文件的密码。当前支持 MS Project 2010 及更高版本的格式。 |
