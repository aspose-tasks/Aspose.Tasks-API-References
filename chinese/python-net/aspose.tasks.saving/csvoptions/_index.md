## CsvOptions class

允许在将项目保存为 CSV 时指定其他选项。

CsvOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| CsvOptions() | 初始化一个新的 [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) 类实例，可用于以 CSV 格式保存项目。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| save_format | 获取或设置在使用此保存选项对象时文档将被保存的格式。 |
| data_category | 获取或设置要保存的数据类别。 |
| 编码 | 获取或设置用于保存 CSV 的编码。 |
| include_headers | 获取或设置一个值，指示是否包含标题（默认值为 TRUE）。 |
| text_delimiter | 获取或设置文本分隔符。 |
| view | 获取或设置要保存为 XLSX 格式的视图列列表 ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/))。<br/>            如果未设置，则保存默认列。 |
