## Spreadsheet2003SaveOptions class

允许在将项目页面渲染为 Spreadsheet2003 时指定其他选项。

Spreadsheet2003SaveOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Spreadsheet2003SaveOptions() | 初始化一个新的 [Spreadsheet2003SaveOptions](/tasks/python-net/aspose.tasks.saving/spreadsheet2003saveoptions/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| save_format | 获取或设置在使用此保存选项对象时文档将被保存的格式。 |
| resource_view | 获取或设置要呈现的资源视图列列表（[ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)）。 |
| assignment_view | 获取或设置要呈现的分配视图列列表（[AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)）。 |
| view | 获取或设置要保存的视图列列表（[GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)）。<br/>            如果未设置，则保存默认列。 |
