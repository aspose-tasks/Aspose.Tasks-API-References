## PrimaveraXmlSaveOptions class

允许在将项目保存为 Primavera XML 格式时指定其他选项。

PrimaveraXmlSaveOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PrimaveraXmlSaveOptions() | 初始化一个新的 [PrimaveraXmlSaveOptions](/tasks/python-net/aspose.tasks.saving/primaveraxmlsaveoptions/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| save_format | 获取或设置在使用此保存选项对象时文档将被保存的格式。 |
| save_root_task | 获取或设置一个值，指示是否保存根任务。 |
| skip_summary_assignments | 获取或设置一个值，指示在导出时是否应跳过资源对汇总任务的分配。 |
