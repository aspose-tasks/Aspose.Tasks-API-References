## PageSavingArgs class

此类表示与将文档页面保存到流相关的一组数据。

PageSavingArgs 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| page_number | 获取要写入的页码。 |
| keep_stream_open | 获取或设置一个值，指示渲染例程在写入页面后是否应保持 [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) 打开。 |
| stream | 获取或设置用于写入页面的流。 |
