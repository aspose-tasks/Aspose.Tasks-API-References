## PrimaveraSaveOptions class

允许在将项目保存为 Primavera XER 格式时指定其他选项。

PrimaveraSaveOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PrimaveraSaveOptions() | 初始化一个新的 [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| save_format | 获取或设置在使用此保存选项对象时文档将被保存的格式。 |
| activity_id_increment | 获取或设置用于活动 ID 重新编号的增量。 |
| activity_id_prefix | 获取或设置用于活动 ID 重新编号的前缀。 |
| activity_id_suffix | 获取或设置用于活动 ID 重新编号的后缀。 |
| renumber_activity_ids | 获取或设置一个值，指示是否需要重新编号活动 ID。 |
| skip_summary_assignments | 获取或设置一个值，指示在导出时是否应跳过资源对汇总任务的分配。 |
