## IPageSavingCallback class

表示一个回调函数，当多页文档中的每一页保存到单独的流时被调用。

IPageSavingCallback 类型公开以下成员：
## Methods
| 名称 | 描述 |
| :- | :- |
| page_saving(args) | 页面保存到流时调用的方法。 |
| on_finish() | 所有页面写入完成后将调用的方法。 |
