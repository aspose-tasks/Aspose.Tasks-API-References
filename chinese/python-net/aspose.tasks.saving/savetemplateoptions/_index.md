## SaveTemplateOptions class

允许在将项目另存为模板时指定其他选项。

SaveTemplateOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| SaveTemplateOptions() | 初始化 SaveTemplateOptions 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| remove_actual_values | 获取或设置一个值，指示是否应删除项目模板中的所有实际值。 |
| remove_baseline_values | 获取或设置一个值，指示是否应删除项目模板中的所有基线值。 |
| remove_fixed_costs | 获取或设置一个值，指示是否应删除项目模板中的所有固定成本。 |
| remove_resource_rates | 获取或设置一个值，指示是否应删除项目模板中的资源费率。 |
