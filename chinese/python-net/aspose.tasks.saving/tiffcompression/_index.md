## TiffCompression enumeration

指定将页面保存为 TIFF 格式时要应用的压缩类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 指定不进行压缩。 |
| RLE | 指定 RLE 压缩方案。 |
| CCITT3 | 指定 CCITT3 压缩方案。 |
| CCITT4 | 指定 CCITT4 压缩方案。 |
| LZW | 指定 LZW 压缩方案。 |
