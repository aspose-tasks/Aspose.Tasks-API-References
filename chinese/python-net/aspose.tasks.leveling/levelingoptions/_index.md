## LevelingOptions class

允许指定资源平衡的参数。

LevelingOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| LevelingOptions() | 初始化一个新的 [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| start_date | 获取或设置平衡期间的开始日期。默认值为项目的开始日期。 |
| finish_date | 获取或设置平衡期间的结束日期。默认值为项目的完成日期。 |
| 资源 | 获取或设置将被平衡的资源列表。如果设置为 null，则所有项目资源都将被平衡。 |
| leveling_order | 获取平衡算法延迟具有超额分配的任务的顺序。<br/>            在确定导致超额分配的任务以及哪些任务可以被延迟后，使用指定的顺序来决定应首先延迟哪个任务。 |
| message_level | 获取或设置 Aspose.Tasks 在资源平衡期间发出的日志消息级别。 |
| message_handler | 获取或设置消息处理程序回调，可用于拦截 Aspose.Tasks 在资源平衡期间产生的日志消息。 |
