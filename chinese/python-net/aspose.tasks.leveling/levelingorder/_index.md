## LevelingOrder enumeration

定义平衡顺序的可能取值。

## Members
| 成员名称 | 描述 |
| :- | :- |
| STANDARD | 考虑以下属性：前置关系、总浮动（总浮动更大的任务优先延迟）、开始日期、优先级。<br/>            这是默认值。 |
| ID_ONLY | 任务按 Id 升序延迟。 |
| PRIORITY_THEN_STANDARD | 首先考虑优先级，然后使用与 Standard 相同的属性。 |
