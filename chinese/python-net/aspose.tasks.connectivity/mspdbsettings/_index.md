## MspDbSettings class

允许设置读取 MS Project Server 数据库项目数据所需的选项。

MspDbSettings 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | 初始化 [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| connection_string | 获取或设置连接字符串。 |
| provider_invariant_name | 获取或设置提供程序不变名称，该名称用于获取类的实例。 |
| project_guid | 获取要读取的项目的 GUID。 |
| schema | 获取或设置 MS Project Server 的模式。<br/>            默认值为 "pub"。 |
