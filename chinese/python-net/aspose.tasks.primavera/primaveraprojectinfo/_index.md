## PrimaveraProjectInfo class

表示从 Primavera 格式加载的项目的简要信息。

PrimaveraProjectInfo 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| uid | 获取项目的 Uid。 |
| name | 获取项目的名称。 |
| short_name | 获取项目的短名称（项目 ID）。 |
| export_flag | 获取项目的导出标志。当在 Primavera 中选择项目进行导出时，其 ExportFlag 为 true。<br/>由于与已导出项目的关系，一些未明确选择导出的项目可能会被导出为 XER 文件。 |
