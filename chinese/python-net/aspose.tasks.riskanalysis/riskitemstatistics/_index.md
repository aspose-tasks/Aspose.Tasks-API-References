## RiskItemStatistics class

表示存储已分析项目任务统计数据的项。

RiskItemStatistics 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| item_type | 获取 [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) 枚举的实例。 |
| minimum | 获取在蒙特卡罗模拟期间生成的最小值。 |
| maximum | 获取在蒙特卡罗模拟期间生成的最大值。 |
| expected_value | 获取风险项的期望值。 |
| standard_deviation | 获取风险项的标准偏差。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| get_percentile(percent) | 获取一个值，该值以下是指定百分比的生成样本。 |
