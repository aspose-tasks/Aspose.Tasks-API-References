## TimescaleTier class

表示甘特图时间尺度的单个层级。

TimescaleTier 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| TimescaleTier() | 初始化一个新的 [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) 类的实例。 |
| TimescaleTier(unit, count) | 初始化 TimescaleTier 类的一个新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| count | 获取或设置在该层级中显示标签的时间单位间隔。<br/>            默认值为 1。 |
| label | 获取或设置时间尺度层级的日期标签 [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)。 |
| alignment | 获取或设置在该层级每个时间段内对齐标签的方式（[HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)）。 |
| uses_fiscal_year | 获取或设置一个值，指示是否基于财政年度来设置层级标签。 |
| show_ticks | 获取或设置一个值，指示是否显示分隔层级中时间段的刻度线。 |
| unit | 获取或设置时间尺度层级的时间尺度单位 [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/)。<br/>            默认值为 |
| render_label_on_each_page | 获取或设置标志，定义当时间段跨越多页时是否在每页上渲染日期标签。<br/>            如果值为 'true'，当时间段跨越多页时，期间的日期标签将在每页上渲染。<br/>            如果值为 'false'，日期标签仅根据 [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/) 属性的值渲染一次。 |
