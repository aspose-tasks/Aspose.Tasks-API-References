## ReportType enumeration

项目图形报告的类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| PROJECT_OVERVIEW | 显示项目的开始和结束日期，<br/>            已完成的持续时间百分比，顶层任务的完成百分比以及即将到来的里程碑。 |
| COST_OVERVIEW | 显示项目的开始和结束日期，当前<br/>            计划和剩余成本，完成百分比以及顶层任务的成本值。 |
| WORK_OVERVIEW | 显示每个顶层任务的基线、实际和剩余工作量，以及工作资源的工作量。 |
| RESOURCE_OVERVIEW | 按资源显示基线、实际和剩余工作量。 |
| RESOURCE_COST_OVERVIEW | 按资源显示基线、实际和剩余成本。 |
| CRITICAL_TASKS | 显示关键的项目任务。 |
| LATE_TASKS | 显示已延迟的项目任务。 |
| MILESTONES | 显示已延迟、即将到来和已完成的里程碑。 |
| UPCOMING_TASK | 显示本周到期的任务以及本周开始的任务。 |
| COST_OVERRUNS | 显示按任务和资源划分的成本差异。 |
| TASK_COST_OVERVIEW | 显示所有顶层任务的基线成本、实际成本和剩余成本。 |
| OVERALLOCATED_RESOURCES | 显示超额分配资源的剩余工作小时数。 |
| SLIPPING_TASKS | 显示在基线完成日期之后才完成的任务（必须设置基线）。 |
| BEST_PRACTICE_ANALYZER | 显示没有实际工作、未分配的任务，<br/>            持续时间少于8小时的任务以及与资源关联的汇总。 |
| BURNDOWN | 包括工作燃尽图和任务燃尽图。<br/>            工作燃尽图显示人员已完成的工作量、在项目结束日期前计划完成的工作量，<br/>            以及在项目此阶段预计完成的工作量的基线估计。<br/>            任务燃尽图显示已完成的任务数量、剩余任务数量，<br/>            以及在项目此阶段预计完成的任务数量的基线估计。 |
| CASH_FLOW | 显示所有顶层任务每季度的成本和累计成本。 |
