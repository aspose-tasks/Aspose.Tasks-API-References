## ProgressLines class

表示甘特图视图中的进度线。

ProgressLines 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ProgressLines() | 初始化 ProgressLines 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| display_at_current_date | 获取或设置一个值，指示是否在当前日期显示进度线。 |
| display_at_recurring_intervals | 获取或设置一个值，指示是否在循环间隔显示进度线。 |
| recurring_interval | 获取或设置循环间隔。<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | 获取或设置一个值，指示是否从项目开始日期起显示进度线。 |
| begin_at_date | 获取或设置显示进度线的起始日期。 |
| display_selected | 获取或设置一个值，指示是否在选定日期显示进度线。 |
| is_baseline_plan | 获取或设置一个值，指示是为基线计划还是实际显示进度线。 |
| show_date | 获取或设置一个值，指示是否为每条进度线显示日期。 |
| date_format | 获取或设置日期格式（[DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)）。 |
| font | 获取或设置用于进度线标签的字体。 |
| line_pattern | 获取或设置当前进度线的线型。<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/)。 |
| line_color | 获取或设置当前进度线的线条颜色。 |
| progress_point_shape | 获取或设置进度点形状。<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/)。 |
| progress_point_color | 获取或设置进度点的颜色。 |
| other_line_pattern | 获取或设置其他进度线的线型。 |
| other_line_color | 获取或设置其他进度线的颜色。 |
| other_progress_point_shape | 获取或设置其他进度线的进度点形状。 |
| other_progress_point_color | 获取或设置其他进度点的颜色。 |
| selected_dates | 获取用于显示进度线的已选日期列表。 |
