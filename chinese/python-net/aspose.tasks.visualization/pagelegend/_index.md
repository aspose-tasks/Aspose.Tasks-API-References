## PageLegend class

表示用于项目打印的页面图例。

PageLegend 类型公开以下成员:
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PageLegend() | 初始化 PageLegend 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| left_text | 获取或设置左对齐的文本，以显示在父元素中。 |
| centered_text | 获取或设置居中的文本，以显示在父元素中。 |
| right_text | 获取或设置右对齐的文本，以显示在父元素中。 |
| left_image | 获取或设置左对齐的图像，以显示在父元素中。 |
| centered_image | 获取或设置居中的图像，以显示在父元素中。 |
| right_image | 获取或设置在父元素中显示的右对齐图像。 |
| left_image_size | 获取或设置左侧图像的显示尺寸。 |
| centered_image_size | 获取或设置居中图像的显示尺寸。 |
| right_image_size | 获取或设置右侧图像的显示尺寸。 |
| legend_on | 获取或设置图例出现的页面。可以是 [Legend](/tasks/python-net/aspose.tasks.visualization/legend/) 枚举的其中一个值。 |
| width | 获取或设置图例左侧部分（默认包含项目名称和日期）的宽度（单位：厘米）。 |
