## RecurringInterval class

表示甘特图视图中进度线使用的循环间隔。

RecurringInterval 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| RecurringInterval() | 初始化 RecurringInterval 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| interval | 获取或设置循环间隔。<br/>            可以是 [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/) 类型的任何值。 |
| daily_day_number | 获取或设置每日天数。 |
| daily_workday | 获取或设置一个值，指示该日是否为每日进度线的工作日。 |
| weekly_week_number | 获取或设置每周进度线的周数。 |
| monthly_day | 获取或设置一个值，指示是否按天显示每月进度线。 |
| monthly_day_day_number | 获取或设置每月进度线的日期号。 |
| monthly_day_month_number | 获取或设置每月进度线的月份号。 |
| monthly_first_last | 获取或设置一个值，指示是否按预定义的第一天或最后一天显示进度线。 |
| monthly_first_last_month_number | 获取或设置进度线的月份号，这些进度线按预定义的第一天或最后一天显示。 |
| monthly_first_last_day | 获取或设置每月进度线的第一天或最后一天类型。 |
| weekly_days | 获取每周进度线的日期列表。 |
