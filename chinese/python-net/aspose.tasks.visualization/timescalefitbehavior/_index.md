## TimescaleFitBehavior enumeration

表示用于将时间刻度区域与页面宽度对齐的行为。

## Members
| 成员名称 | 描述 |
| :- | :- |
| DEFINED_IN_VIEW | 日历部分根据渲染视图的 View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage 属性进行渲染。 |
| NO_SCALE_TO_END_DATE | 日历部分精确渲染至 EndDate，即使页面上有空白空间。 |
| NO_SCALE_TO_END_OF_PAGE | 日历部分渲染至最后一页的末端（右侧）。<br/>            因此最后渲染的日期可能超过 EndDate。 |
| SCALE_TO_END_OF_PAGE | 渲染引擎将尝试对齐日期，使 EndDate 与最后一页的末端（右侧）对齐。<br/>            对应于启用的 MS Project 的 "Page Setup \ View \ Fit timescale to end of page" 选项。 |
