## PageSettings class

表示项目视图页面的打印设置。

PageSettings 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PageSettings() | 初始化 [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/) 类的新实例。 <br/>            表示项目视图页面的打印设置。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| is_portrait | 获取或设置指示页面方向是否为纵向的值；如果页面方向为横向，则返回 false。 |
| adjust_to_percent_of_normal_size | 获取或设置一个值，指示是否将打印调整为正常尺寸的指定百分比（[percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)）。 |
| percent_of_normal_size | 获取或设置用于调整打印的正常尺寸百分比。 |
| pages_in_width | 获取或设置要打印的宽度页数。 |
| pages_in_height | 获取或设置要打印的高度页数。 |
| paper_size | 获取或设置纸张大小。可以是 [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/) 枚举的其中一个值。 |
| paper_size_id | 获取或设置一个整数，表示 PrinterPaperSize 值之一或自定义页面大小 ID。<br/>            此值可用于从操作系统设置中获取 PaperSize。 |
| first_page_number | 获取或设置打印的起始页码。 |
