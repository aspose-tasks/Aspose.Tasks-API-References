## TaskTextStyleEventArgs class

此类表示与表格单元格内容渲染相关的数据集合。

TaskTextStyleEventArgs 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| cell_text_style | 获取或设置用于绘制单元格内容的 TextStyle。此对象可用于自定义表格单元格的外观。 |
| task | 获取对应于当前渲染行的 [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/)。 |
| column | 获取当前渲染单元格所属的 [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/)。 |
