## Gridlines class

表示出现在甘特图视图中的网格线。

Gridlines 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Gridlines() | 初始化 Gridlines 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| interval | 获取或设置 0 到 99 之间的数字，用于指定网格线之间的间隔。 |
| interval_color | 获取或设置次要网格线的颜色。 |
| interval_pattern | 获取或设置次要网格线的线型。 |
| normal_color | 获取或设置普通网格线的颜色。 |
| normal_pattern | 获取或设置普通网格线的线型。 |
| type | 获取或设置网格线类型。 |
