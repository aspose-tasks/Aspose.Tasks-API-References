## VisualObjectPlacement class

表示视图中 [OleObject](/tasks/python-net/aspose.tasks/oleobject/) 的放置和外观。

VisualObjectPlacement 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| VisualObjectPlacement() | 初始化一个新的 [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/) 类的实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| ole_object_id | 获取或设置 [OleObject](/tasks/python-net/aspose.tasks/oleobject/) 对象的 Id。 |
| task_id | 如果选择了'Attach to task'选项，则获取或设置任务的 Id，否则为 -1。 |
| width | 获取或设置可视对象的显示宽度。 |
| height | 获取或设置可视对象的显示高度。 |
| vertical_offset | 获取或设置可视对象的垂直偏移。 |
| horizontal_offset | 获取或设置可视对象的水平偏移。 |
| timescale_date | 当选择了'Attach to timescale'选项时，获取或设置可视对象的日期放置。 |
| attachment_point | 当选择了'Attach to task'选项时，获取或设置可视对象相对于任务的对齐方式。 |
| border_line_color | 获取或设置边框线颜色. |
| border_line_thickness | 获取或设置边框线粗细（允许的值为 0 - 5）. |
| fill_color | 获取或设置填充颜色. |
| fill_pattern | 获取或设置填充图案. |
