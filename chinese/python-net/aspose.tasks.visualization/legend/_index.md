## Legend enumeration

指定在渲染视图图例时使用的可能选项。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NO_LEGEND | 未渲染图例。 |
| AFTER_LAST_PAGE | 图例在项目页面的最后一页之后的单独页面上渲染。 |
| ON_EVERY_PAGE | 图例在每页上渲染。 |
