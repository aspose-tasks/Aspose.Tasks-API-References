## BarShape enumeration

条形矩形的形状。

## Members
| 成员名称 | 描述 |
| :- | :- |
| FULL | 指示 Full 矩形条形状。 |
| HALF_HEIGHT | 指示顶部对齐的半高度矩形条形状。 |
| HALF_HEIGHT_BOTTOM | 指示底部对齐的半高度矩形条形状。 |
| THIN | 指示居中对齐的线形状。 |
| NONE | 指示 None 条形状。 |
| MIDDLE | 指示居中对齐的线形状。 |
| LINE_BOTTOM | 指示底部对齐的线形状。 |
| LINE_TOP | 指示顶部对齐的线形状。 |
