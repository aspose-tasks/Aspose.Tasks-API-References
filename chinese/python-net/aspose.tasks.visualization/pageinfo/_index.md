## PageInfo class

表示 MPP 文件格式中存在且用于打印的页面设置数据。

PageInfo 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PageInfo() | 初始化 [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) 类的新实例。 <br/>            表示在 MPP 文件格式中存在并用于打印的页面设置数据。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| header | 获取或设置 [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) 类的实例，该实例表示页眉数据。 |
| footer | 获取或设置 [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) 类的实例，该实例表示页脚数据。 |
| name | 获取用于设置数据的视图名称。 |
| page_settings | 获取 [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) 类的实例，该实例指定页面打印设置。 |
| page_view_settings | 获取 [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) 类的实例，该实例指定页面视图打印设置。 |
| margins | 获取 [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) 类的实例，该实例指定页面边距。 |
| legend | 获取或设置 [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) 类的实例，该实例指定页面图例的渲染选项。 |
