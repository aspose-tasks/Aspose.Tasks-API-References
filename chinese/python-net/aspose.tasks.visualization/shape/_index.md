## Shape enumeration

在将视图数据保存为某些 [SaveFileFormat](/tasks/python-net/aspose.tasks.saving/savefileformat/) 时，要渲染的条形样式起始或结束标记的形状。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 指示无形状。 |
| VERTICAL_LINE | 指示垂直线形状。 |
| PENTAGON | 指示五边形形状。 |
| TRIANGLE | 指示三角形形状。 |
| LEFT_BRACKET | 指示左括号形状。 |
| RIGHT_BRACKET | 指示右括号形状。 |
| ARROW_DOWN | 指示 ArrowDown 形状。 |
| LEFT_FADE | 指示 Left fade 形状。 |
| RIGHT_FADE | 指示 Right fade 形状。 |
| DIAMOND | 指示 Diamond 形状。 |
| CIRCLE | 指示 Circle 形状。 |
