## PageMargins class

表示用于打印的页面边距。

PageMargins 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PageMargins() | 初始化 PageMargins 类的一个新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| top | 获取或设置顶部边距的大小（单位：厘米）。 |
| bottom | 获取或设置底部边距的大小（单位：厘米）。 |
| left | 获取或设置左侧边距的大小（单位：厘米）。 |
| right | 获取或设置右边距的大小（单位为厘米）。 |
| borders | 获取或设置打印边框的位置。可以是 [Border](/tasks/python-net/aspose.tasks.visualization/border/) 枚举的其中一个值。 |
