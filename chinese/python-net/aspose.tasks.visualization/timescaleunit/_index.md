## TimescaleUnit enumeration

指定甘特图或其他时间分段视图中时间刻度任意层级的时间单位。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 指示无。时间尺度层级被隐藏。 |
| MINUTES | 指示分钟时间尺度单位。 |
| 小时 | 指示小时时间尺度单位。 |
| 天 | 指示天时间尺度单位。 |
| 周 | 指示周时间尺度单位。 |
| THIRDS_OF_MONTHS | 指示月的三分之一时间尺度单位。 |
| 月份 | 指示月份时间尺度单位。 |
| 季度 | 指示年度季度时间尺度单位。 |
| HALF_YEARS | 指示半年时间尺度单位。 |
| 年 | 指示年时间尺度单位。 |
