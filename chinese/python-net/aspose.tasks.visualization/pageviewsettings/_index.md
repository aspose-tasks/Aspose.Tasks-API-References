## PageViewSettings class

表示项目视图的打印设置。

PageViewSettings 类型公开以下成员:
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PageViewSettings() | 初始化 PageViewSettings 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| first_columns_count | 获取或设置在所有页面上要打印的首列数量。 |
| fit_timescale_to_end_of_page | 获取或设置一个值，指示在打印时是否将时间轴适配到页面末尾。 |
| print_all_sheet_columns | 获取或设置一个值，指示是否打印视图的所有工作表列。 |
| print_blank_pages | 获取或设置一个值，指示是否打印视图的空白页。 |
| print_first_columns_count_on_all_pages | 获取或设置一个值，指示是否在所有页面上打印指定数量的首列。 |
| print_notes | 获取或设置一个值，指示是否打印注释。 |
