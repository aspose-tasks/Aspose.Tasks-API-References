## VbaModuleType enumeration

指定 VBA 项目中模块的类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| DOCUMENT_MODULE | VBA 项目项的类型，指定用于嵌入宏和与文档关联的编程访问操作的模块。 |
| PROCEDURAL_MODULE | 一个包含子程序和函数集合的模块。 |
| CLASS_MODULE | 一个包含新对象定义的模块。类的每个实例都会创建一个新对象，且在模块中定义的过程会成为该对象的属性和方法。 |
| DESIGNER_MODULE | 一个扩展已在项目中注册的 ActiveX 控件的方法和属性的模块。 |
