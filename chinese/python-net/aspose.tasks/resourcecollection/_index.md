## ResourceCollection class

表示一个包含 [Resource](/tasks/python-net/aspose.tasks/resource/) 对象的集合。

ResourceCollection 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| parent_project | 获取 ResourceCollection 对象的父项目。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| add() | 在项目资源集合的最后位置添加新资源。 |
| add(resource_name) | 在项目资源集合的最后位置添加新资源。 |
| add(resource_name, before_resource_id) |  |
| to_list() | 将 ResourceCollection 对象转换为 [Resource](/tasks/python-net/aspose.tasks/resource/) 对象的列表。 |
| get_by_id(id) | 返回具有指定 id 的资源。 |
| get_by_uid(uid) | 返回具有指定 Uid 的资源。 |
