## RecurringTaskInfo class

表示项目中循环任务的详细信息。

RecurringTaskInfo 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| recurrence_pattern | 获取或设置循环任务的重复模式。 |
| start_date | 获取或设置事件开始的日期。 |
| end_date | 获取或设置事件结束的日期。 |
| duration | 获取或设置循环任务单次出现的持续时间。 |
| occurrences | 获取或设置循环任务的出现次数。 |
| use_end_date | 获取或设置一个值，指示循环任务是使用结束日期还是出现次数。 |
| daily_repetitions | 获取或设置每日重复模式的重复次数。 |
| daily_use_workdays | 获取或设置一个值，指示是否在每日重复模式中使用工作日。 |
| weekly_repetitions | 获取或设置每周重复模式的重复次数。 |
| weekly_days | 获取或设置每周重复模式中使用的天集合。 |
| monthly_use_ordinal_day | 获取或设置一个值，指示是否在每月重复模式中使用序数日。 |
| monthly_ordinal_number | 获取或设置每月重复模式的序数。 |
| monthly_ordinal_repetitions | 获取或设置在使用序数日时每月重复模式的重复次数。 |
| monthly_day | 获取或设置每月重复模式的天数。 |
| monthly_repetitions | 获取或设置每月重复模式的重复次数。 |
| yearly_use_ordinal_day | 获取或设置一个值，指示是否在每年重复模式中使用序数日。 |
| yearly_date | 获取或设置每年重复模式的日期。 |
| yearly_ordinal_number | 获取或设置每年重复模式的序数。 |
| yearly_ordinal_month | 获取在使用序数日时每年重复模式的月份。 |
| task | 获取此实例的父任务，该实例属于 [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/) 类。 |
