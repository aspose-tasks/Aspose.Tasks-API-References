## LoadOptions class

允许在从文件或流加载项目时指定额外的加载参数。

LoadOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| LoadOptions() | 初始化一个新的 [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/) 类的实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| 密码 | 获取或设置保护密码。 |
| primavera_read_options | 获取或设置 [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) 类的指定实例，可用于自定义加载 Primavera 格式（Primavera P6 XER 或 Primavera P6 Xml）的行为。 |
| 编码 | 获取或设置用于从 HTML、MPX、XER 和 Primavera XML 格式读取项目的编码。<br/>            默认编码为 UTF8。 |
