## Group class

表示组定义。<br/>            Group 对象是 ResourceGroups 集合或 TaskGroups 集合的成员。

Group 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Group() | 初始化一个新的 [Group](/tasks/python-net/aspose.tasks/group/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取或设置 Group 对象的名称。 |
| uid | 获取组的唯一标识符。 |
| show_summary | 获取或设置一个值，指示是否为该组显示汇总行。 |
| maintain_hierarchy | 获取或设置一个值，指示是否显示组内子任务的所有汇总任务级别。 |
| show_in_menu | 获取或设置一个值，指示项目是否在功能区的 Group 下拉列表中显示组名。 |
| group_assignments | 获取或设置一个值，指示是否应将分配而不是任务进行分组。 |
| group_criteria | 获取或设置一个 GroupCriteria 集合，表示组定义中的字段。 |
