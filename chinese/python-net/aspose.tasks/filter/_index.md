## Filter class

表示项目中的过滤器。

Filter 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Filter() | 初始化 Filter 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| filter_type | 获取过滤器的类型。 |
| name | 获取或设置 Filter 对象的名称。 |
| show_in_menu | 获取或设置一个值，指示项目是否在功能区“视图”选项卡的 Filter 下拉列表中显示过滤器名称。 |
| show_related_summary_rows | 获取或设置一个值，指示是否为该过滤器显示相关的汇总行。 |
| index | 获取 Filters 所包含对象中 [Filter](/tasks/python-net/aspose.tasks/filter/) 对象的索引。 |
| uid | 获取过滤器的唯一标识符。 |
| criteria | 获取或设置任务或资源必须满足的条件，以在 MSP 视图中显示。 |
