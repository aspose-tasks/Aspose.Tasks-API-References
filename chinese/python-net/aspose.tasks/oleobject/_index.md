## OleObject class

表示可以插入到 MPP 文件的甘特图视图中的 OLE 对象。

OleObject 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| OleObject() | 初始化 [OleObject](/tasks/python-net/aspose.tasks/oleobject/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取或设置 OLE 对象实例的名称。 |
| application_name | 获取或设置用于打开嵌入对象的应用程序名称。 |
| file_format | 获取或设置嵌入对象的文件格式。 |
| content | 获取或设置嵌入文件的数据；如果未嵌入数据则为 null。 |
| label | 获取或设置插入对象的标签。 |
| full_path | 获取或设置插入对象的完整路径。 |
| temporary_file | 获取或设置插入对象的临时文件路径。 |
| display_as_icon | 获取或设置一个标志，指示 OLE 对象应显示为图标或其常规图片。 |
| 已链接 | 获取一个值，指示项目文件是否仅包含指向链接源中实际数据的链接。 |
| view | 获取或设置插入对象所属的 [view](/tasks/python-net/aspose.tasks/oleobject/) 类的实例。 |
| id | 获取或设置对象 ID。 |
