## ProjectServerSaveOptions class

允许在将项目保存到 Project Server 或 Project Online 时指定其他选项。

ProjectServerSaveOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ProjectServerSaveOptions() | 初始化 [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| project_name | 获取或设置项目的名称，该名称显示在 Project Server \ Project Online 项目列表中。应在 Project Server \ Project Online 实例中唯一。<br/>如果省略该值，将使用 Prj.Name 属性的值。 |
| project_guid | 获取或设置项目的唯一标识符。应在 Project Server \ Project Online 实例中唯一。 |
| timeout | 获取或设置在等待 Project Server 的队列处理服务处理保存项目请求时使用的超时时间。此属性的默认值为 1 分钟。 |
| polling_interval | 获取或设置队列作业状态请求之间的间隔。默认值为 2 秒。 |
