## CalculationMode enumeration

指定项目计算模式。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 无。在此模式下，项目日期和成本不会重新计算。 |
| AUTOMATIC | 自动模式。使用此模式时，项目日期和成本会重新计算。 |
| MANUAL | 手动模式。此模式下仅重新计算必要的字段，例如对象的 UID 和 ID。 |
