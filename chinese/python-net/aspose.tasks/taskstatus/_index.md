## TaskStatus enumeration

指定任务的状态.

## Members
| 成员名称 | 描述 |
| :- | :- |
| UNDEFINED | 未定义的任务状态。 |
| COMPLETE | 任务已完成 100%。 |
| ON_SCHEDULE | 如果分阶段累计完成百分比至少覆盖状态日期前一天，则任务按计划进行。 |
| LATE | 如果分阶段累计完成百分比未在状态日期前一天的午夜达到，则任务延迟。 |
| FUTURE | 当任务开始日期大于状态日期时，'Future' 任务状态被设置。 |
