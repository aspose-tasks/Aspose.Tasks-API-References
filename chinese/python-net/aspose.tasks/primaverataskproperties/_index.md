## PrimaveraTaskProperties class

表示从 Primavera 文件（XER 或 P6XML）读取的任务的 Primavera 特定属性。

PrimaveraTaskProperties 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| sequence_number | 获取或设置 WBS 项目（汇总任务）的序列号。它用于在 Primavera 中对汇总任务进行排序。 |
| activity_id | 获取 activity id 字段——Primavera 使用的任务唯一标识符。 |
| remaining_early_finish | 获取剩余的提前完成日期——即活动剩余工作计划完成的日期。 |
| remaining_early_start | 获取剩余的提前开始日期——即活动剩余工作计划开始的日期。 |
| remaining_late_start | 获取剩余的最迟开始日期。 |
| remaining_late_finish | 获取剩余的最迟完成日期。 |
| raw_duration_type | 获取活动的 “Duration Type” 字段的原始文本表示（如源文件中所示）。 |
| duration_type | 获取活动的 “Duration Type” 字段的值。 |
| raw_activity_type | 获取活动的 “Activity Type” 字段的原始文本表示（如源文件中所示）。 |
| activity_type | 获取 “Activity Type” 字段的值。 |
| percent_complete_type | 获取活动的 “% Complete Type” 字段的值。 |
| raw_complete_percent_type | 获取活动的 “% Complete Type” 字段的原始文本表示（如源文件中所示）。 |
| raw_status | 获取活动中 'Status' 字段的原始文本表示（如源文件中所示）。 |
| physical_percent_complete | 获取 Physical Percent Complete 的值。 |
| duration_percent_complete | 获取 duration percent complete 的值。 |
| units_percent_complete | 获取 units percent complete 的值。 |
| actual_labor_units | 获取 actual labor units 的值。 |
| actual_non_labor_units | 获取 actual non labor units 的值。 |
| remaining_labor_units | 获取 remaining labor units 的值。 |
| remaining_non_labor_units | 获取 remaining non labor units 的值。 |
| actual_labor_cost | 获取 actual labor cost 的值。 |
| budgeted_labor_cost | 获取 budgeted (or planned) labor cost 的值。 |
| actual_nonlabor_cost | 获取 actual non labor cost 的值。 |
| budgeted_nonlabor_cost | 获取 budgeted (or planned) non labor cost 的值。 |
| actual_material_cost | 获取实际材料成本的值。 |
| budgeted_material_cost | 获取预算（或计划）材料成本的值。 |
| actual_expense_cost | 获取实际费用成本的值。 |
| remaining_expense_cost | 获取剩余费用成本的值。 |
| budgeted_expense_cost | 获取预算（或计划）费用成本的值。 |
| actual_total_cost | 获取实际成本的总值。 |
| budgeted_total_cost | 获取预算（或计划）成本的总值。 |
| primary_constraint_type | 获取主要约束的类型。 |
| primary_constraint_date | 获取主要约束的日期。 |
| secondary_constraint_type | 获取次要约束的类型。 |
| secondary_constraint_date | 获取次要约束的日期。 |
| planned_duration | 获取原始或计划的持续时间——从任务计划开始日期到计划完成日期的总工作时间。 |
