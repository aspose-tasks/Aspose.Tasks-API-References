## OutlineCodeDefinition class

表示大纲代码定义。

OutlineCodeDefinition 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| OutlineCodeDefinition() | 初始化 [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| guid | 获取或设置大纲代码的 Guid。 |
| field_id | 获取或设置大纲代码的字段编号。 |
| field_name | 获取或设置自定义大纲代码的名称。 |
| alias | 获取或设置自定义大纲代码的别名。 |
| phonetic_alias | 获取或设置自定义大纲代码别名的音标发音。 |
| values | 获取 OutlineValueCollection 对象。<br/>            与此大纲代码关联的表格值。 |
| enterprise | 获取或设置一个值，指示自定义大纲代码是否为企业自定义大纲代码。 |
| enterprise_outline_code_alias | 获取或设置对另一个自定义字段的引用，该字段的此大纲代码定义是别名。 |
| resource_substitution_enabled | 获取或设置一个值，指示自定义大纲代码是否可以被使用<br/>            Microsoft Project 中的资源替换向导。 |
| leaf_only | 获取或设置一个值，指示此大纲代码字段中指定的值是否必须为叶子值。 |
| all_levels_required | 获取或设置一个值，指示新代码是否必须包含所有层级。<br/>            企业代码不支持此功能。 |
| only_table_values_allowed | 获取或设置一个值，指示指定的值是否必须来自值表。 |
| masks | 获取 OutlineMaskCollection 对象。<br/>            定义大纲代码掩码的条目表。<br/>            只读的 [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/) 实例。 |
| show_indent | 获取或设置一个值，指示是否必须显示此大纲代码的缩进。 |
