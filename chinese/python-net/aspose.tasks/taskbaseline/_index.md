## TaskBaseline class

表示任务的基准线。

TaskBaseline 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| TaskBaseline(task) | 初始化一个新的 [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/) 类的实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| baseline_number | 获取或设置基线数据记录的唯一编号。 |
| work | 获取或设置基线保存时分配给资源的工作。 |
| cost | 获取或设置基线保存时资源的预计成本。 |
| bcws | 获取或设置为资源安排的工作预算成本。 |
| bcwp | 获取或设置资源截至目前为项目执行的工作预算成本。 |
| timephased_data | 获取或设置此对象的 TimephasedDataCollection 实例。<br/>            与任务基准关联的时间分段数据。 |
| 临时 | 获取或设置一个值，以指示这是否为临时基准。 |
| 开始 | 获取或设置基准保存时任务的计划开始日期。 |
| finish | 获取或设置基准保存时任务的计划完成日期。 |
| duration | 获取或设置基准保存时任务的计划持续时间。 |
| estimated_duration | 获取或设置一个值，指示任务的基准持续时间是否为估计值。 |
| fixed_cost | 获取或设置在保存基准时任务的固定成本。 |
