## WeekDay class

表示一个工作日，可定义一周的常规天数或日历中的例外天数。

WeekDay 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| WeekDay(day_type) | 使用指定的日期类型初始化 [WeekDay](/tasks/python-net/aspose.tasks/weekday/) 类的新实例。 |
| WeekDay(day_type, working_times) | 初始化 WeekDay 类的新实例 |
| WeekDay(day_type, working_times) | 使用指定的日期类型和工作时间段初始化 [WeekDay](/tasks/python-net/aspose.tasks/weekday/) 类的新实例。 |
| WeekDay() | 使用指定的日期类型初始化 [WeekDay](/tasks/python-net/aspose.tasks/weekday/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| day_type | 获取一天的类型。 |
| day_working | 获取或设置一个值，指示指定的日期或日期类型是否为工作日。 |
| from_date | 获取或设置异常时间的开始。 |
| to_date | 获取或设置异常时间的结束。 |
| working_times | 获取此 WeekDay 实例的 WorkingTimeCollection。<br/>            定义工作日工作时间的工作时间集合。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| create_default_working_day(day_type) | 创建默认工作日。 |
| set_default_working_time(day) | 为指定的工作日设置默认时间段。 |
| get_working_time() | 返回工作日的工作时间。 |
| clone() | 返回工作日的深拷贝。 |
