## FilterComparisonType enumeration

指定在 FieldName 与 Value 之间进行的比较类型，用作过滤器或图形指示器的选择条件。

## Members
| 成员名称 | 描述 |
| :- | :- |
| EQUALS | Field 的值等于 Value。 |
| DOES_NOT_EQUAL | Field 的值不等于 Value。 |
| IS_GREATER_THAN | Field 的值大于 Value。 |
| IS_GREATER_THAN_OR_EQUAL_TO | Field 的值大于或等于 Value。 |
| IS_LESS_THAN | Field 的值小于 Value。 |
| IS_LESS_THAN_OR_EQUAL_TO | Field 的值小于或等于 Value。 |
| IS_WITHIN | Field 的值在 Value 范围内。 |
| IS_NOT_WITHIN | Field 的值不在 Value 范围内。 |
| CONTAINS | Field 的值包含 Value。 |
| DOES_NOT_CONTAIN | Field 的值不包含 Value。 |
| CONTAINS_EXACTLY | Field 的值精确包含 Value。 |
| IS_ONE_OF | Field 的值等于指定的 Values 之一。用于 AutoFilters。 |
| UNDEFINED | 未定义的值。 |
| IS_ANY_VALUE | “Is any value” 条件。适用于图形指示器。 |
