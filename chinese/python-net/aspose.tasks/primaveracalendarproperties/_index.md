## PrimaveraCalendarProperties class

表示从 Primavera 文件（XER 或 P6XML）读取的日历的 Primavera 特定属性。<br/>            可用于执行日历特定的时间单位转换。

PrimaveraCalendarProperties 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| hours_per_day | 从日历的“时间段”设置中获取每天的小时数。 |
| hours_per_week | 从日历的“时间段”设置中获取每周的小时数。 |
| hours_per_month | 从日历的“时间段”设置中获取每月的小时数。 |
| hours_per_year | 从日历的“时间段”设置中获取每月的小时数。 |
