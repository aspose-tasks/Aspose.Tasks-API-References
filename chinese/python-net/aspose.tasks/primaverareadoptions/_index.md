## PrimaveraReadOptions class

允许在读取 Primavera Xml 或 Primavera Xer 文件时指定其他选项。

PrimaveraReadOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| PrimaveraReadOptions() | 初始化一个新的 [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| project_uid | 获取或设置要从包含多个项目的文件中读取的项目 UID。 |
| undefined_constraint_handling_behavior | 指定用于处理从 XER 格式读取的具有未定义约束的任务的行为。 |
| preserve_uids | 获取或设置一个标志，指定是否应保留实体的原始唯一标识符。 |
| read_baseline_projects | 获取或设置一个标志，指定是否应加载基线项目。默认值为 true。 |
