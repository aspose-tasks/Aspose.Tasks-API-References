## AvailabilityPeriod class

表示资源可用的时间段。

AvailabilityPeriod 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| AvailabilityPeriod() | 初始化一个新的 [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) 实例。 |
| AvailabilityPeriod(available_from, available_to, available_units) | 使用指定的日期范围和可用单位初始化一个新的 [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) 实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| available_from | 获取或设置资源在指定期间可用的日期。 |
| available_to | 获取或设置资源在指定期间可用的结束日期。 |
| available_units | 获取或设置资源在指定期间可用的百分比。 |
