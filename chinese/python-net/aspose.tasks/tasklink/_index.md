## TaskLink class

表示一个前置链接。

TaskLink 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_cross_project | 获取或设置一个值，指示前置任务是否属于另一个项目。 |
| cross_project_name | 获取或设置外部前置项目。 |
| link_lag | 获取或设置以十分之一分钟或百分比表示的时滞。 |
| link_lag_time_span | 获取或设置时滞持续时间，取决于 LagFormat。 |
| lag_format | 获取或设置用于表示时滞格式的格式。 |
| pred_task | 获取或设置前置任务。 |
| succ_task | 获取或设置后续任务。 |
| link_type | 获取或设置链接的类型。 |
