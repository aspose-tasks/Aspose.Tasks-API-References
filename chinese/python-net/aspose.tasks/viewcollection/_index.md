## ViewCollection class

包含一个 [View](/tasks/python-net/aspose.tasks/view/) 对象的列表。<br/>            实现 ICollection<View> 接口。

ViewCollection 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| parent_project | 获取 View 对象的父对象。<br/>            只读 [Project](/tasks/python-net/aspose.tasks/project/)。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| to_list() | 将视图集合转换为 [View](/tasks/python-net/aspose.tasks/view/) 对象的列表。 |
| get_by_view_screen(screen) | 搜索具有指定 Screen 属性的 View，并返回集合中的首次出现。 |
| get_by_name(view_name) | 搜索具有指定名称的 View，并返回集合中的首次出现。 |
