## RecurringTaskParameters class

表示用于在项目中创建循环任务的一组参数。

RecurringTaskParameters 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| RecurringTaskParameters() | 初始化一个新的 [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| duration | 获取或设置循环任务单次出现的持续时间。 |
| ignore_resource_calendar | 获取或设置一个值，指示即使在没有任何资源可用时是否仍安排循环任务。 |
| recurrence_pattern | 获取或设置循环任务的重复模式。 |
| task_name | 获取或设置循环任务的名称。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| set_calendar(project, calendar_name) | 为循环任务设置日历。该日历从项目日历集合中选择。 |
