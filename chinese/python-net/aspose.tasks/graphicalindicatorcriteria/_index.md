## GraphicalIndicatorCriteria class

表示与扩展属性关联的一个图形指示器条件。

GraphicalIndicatorCriteria 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | 初始化 GraphicalIndicatorCriteria 类的新实例 |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | 初始化 GraphicalIndicatorCriteria 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| test | 获取在扩展属性值与用于图形指示器应用的标准之间进行比较的类型。<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | 获取用于测试扩展属性值的值。 |
| value2 | 获取在 'IsWithin' 和 'IsNotWithin' 比较类型情况下用于测试扩展属性值的第二个值。 |
| image_index | 获取当字段满足条件时要显示的图像索引。 |
| row_type | 获取 [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) 枚举的值，该枚举指示指示器适用于哪些行。 |
