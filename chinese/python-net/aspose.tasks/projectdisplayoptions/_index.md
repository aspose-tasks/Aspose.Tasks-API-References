## ProjectDisplayOptions class

表示项目实例的显示选项。

ProjectDisplayOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ProjectDisplayOptions() | 初始化一个新的 [ProjectDisplayOptions](/tasks/python-net/aspose.tasks/projectdisplayoptions/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| add_space_before_label | 获取或设置一个值，指示是否在数字值和时间缩写前添加空格（例如 1 wk 而不是 1wk）。 |
| underline_hyperlinks | 获取或设置一个值，指示是否为超链接添加下划线。 |
| show_task_schedule_warnings | 获取或设置一个值，指示当 Project 识别出手动安排的任务可能出现调度冲突时是否显示警告。 |
| show_task_schedule_suggestions | 获取或设置一个值，指示当 Project 识别出手动安排的任务可能出现调度冲突时是否显示建议。 |
| show_project_summary_task | 获取或设置一个值，指示是否在甘特图视图顶部的摘要任务栏中，以单行显示整个项目的摘要信息。 |
| minute_label | 获取或设置分钟标签的显示方式。 |
| hour_label | 获取或设置小时标签的显示方式。 |
| day_label | 获取或设置天标签的显示方式。 |
| week_label | 获取或设置周标签的显示方式。 |
| month_label | 获取或设置月份标签的显示方式。 |
| year_label | 获取或设置年份标签的显示方式。 |
