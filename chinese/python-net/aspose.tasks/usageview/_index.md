## UsageView class

表示项目中的使用视图。

UsageView 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| filter | 获取或设置在单个视图中使用的过滤器。 |
| 组 | 获取或设置单个视图的组。 |
| uid | 获取视图的唯一标识符。 |
| highlight_filter | 获取或设置一个值，指示 Microsoft Project 是否为单个视图突出显示筛选器。 |
| name | 获取或设置 View 对象的名称。 |
| screen | 获取单个视图的屏幕类型。<br/>            只读 [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/)。 |
| parent_project | 获取 View 对象的父对象。<br/>            只读 [Project](/tasks/python-net/aspose.tasks/project/)。 |
| table | 获取或设置单个视图的表。 |
| type | 获取单个视图中项目的类型，例如任务或资源。<br/>            只读 [ItemType](/tasks/python-net/aspose.tasks/itemtype/)。 |
| show_in_menu | 获取或设置一个值，指示 Microsoft Project 是否在功能区的“视图”或“其他视图”下拉列表中显示单个视图的名称。 |
| page_info | 获取 [page_info](/tasks/python-net/aspose.tasks/view/) 类的实例。表示存在于 mpp 文件格式中的页面设置数据。 |
| visual_objects_placements | 获取表示视图中 [OleObject](/tasks/python-net/aspose.tasks/oleobject/) 的放置和外观的对象集合。 |
| align_details_data | 获取或设置详细数据的对齐方式。 |
| display_details_header_column | 获取或设置一个值，指示是否在视图中显示详细标题列。 |
| display_short_detail_header_names | 获取或设置一个值，指示是否显示简短的详细标题名称。 |
| repeat_details_header_on_all_rows | 获取或设置一个值，指示是否在所有分配行上重复详细标题。 |
| timescale_size_percentage |  |
| bottom_timescale_tier | 获取或设置视图底部时间刻度层的设置。<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | 获取或设置视图中间时间刻度层的设置。<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/)。 |
| top_timescale_tier | 获取或设置视图顶部时间刻度层的设置。<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
## Methods
| 名称 | 描述 |
| :- | :- |
| compare_to(other) | 比较当前实例与同类型的另一个对象，并返回一个整数，指示当前实例在排序顺序中是位于该对象之前、之后，还是处于相同位置。 |
