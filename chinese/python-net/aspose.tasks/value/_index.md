## Value class

表示值列表中的一个值。

Value 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Value() | 初始化 [Value](/tasks/python-net/aspose.tasks/value/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| id | 获取或设置跨项目的值的唯一标识符。 |
| value_guid | 获取一个 GUID，用于在整个项目中标识此值与其他值的区别。 |
| val | 获取或设置内部表示中的实际值。建议使用下面列出的强类型属性。 |
| string_value | 获取或设置用于表示文本字符串的实际值。 |
| numeric_value | 获取或设置用于表示数字或费用值的实际值。 |
| duration | 获取或设置用于表示持续时间的实际值。 |
| date_time_value | 获取或设置如果可以表示为 DateTime 的实际值。默认值为最小日期值。 |
| description | 获取或设置值的描述。 |
| phonetic | 获取或设置自定义字段名称的拼音信息。 |
