## PrimaveraProjectProperties class

表示从 Primavera 文件（XER 或 P6XML）读取的项目的 Primavera 特定属性。

PrimaveraProjectProperties 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| relationship_lag_calendar | 获取一个选项，用于定义在 Primavera 项目中调度 Relationship Lag 时使用的日历。 |
| use_expected_finish_dates | 获取一个标志，用于定义是否应将活动完成日期调度为预期完成日期。 |
| make_open_ended_activities_critical | 获取一个标志，用于定义在项目调度时是否应将活动标记为 critical。 |
| ignore_other_project_relationships | 获取一个标志，用于定义是否忽略项目之间的活动关系。 |
| current_baseline_project_id | 获取当前基线项目的 Id。<br/>            适用于从包含已导出基线的 Primavera XML 文件读取的项目。 |
| baseline_projects | 获取当前项目的基线项目数组。<br/>            适用于从包含已导出基线的 Primavera XML 文件读取的项目。 |
| critical_activities_defining_method | 获取定义关键活动的方法：最长路径或总浮动方法。 |
| critical_total_float_limit | 获取在使用 TotalFloat 方法时用于定义关键活动的阈值。 |
| short_name | 获取项目的短名称（项目 ID）。 |
