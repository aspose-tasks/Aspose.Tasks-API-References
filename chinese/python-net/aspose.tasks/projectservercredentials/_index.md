## ProjectServerCredentials class

用于连接 Project Online 或本地部署的 Project Server 实例的凭据。

ProjectServerCredentials 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | 使用 SharePoint 站点的 URL 和有效的 SPOIDCRL 授权令牌为 SharePoint 的 PWA（Project Web Access）站点初始化 [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) 类的新实例。 |
| ProjectServerCredentials(site_url, user_name, password) | 使用 SharePoint 站点的 URL 和有效的 SPOIDCRL 授权令牌为 SharePoint 的 PWA（Project Web Access）站点初始化 [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| site_url | 获取 SharePoint 站点上 PWA 的 URL 或本地部署的 Project Server 的 URL。<br/>            For example, https://your_company_name.sharepoint.com/sites/pwa\"; |
| auth_token | 获取 SharePoint 实例的授权令牌。 |
| user_name | 获取 SharePoint 站点的用户名。 |
