## ExtendedAttribute class

表示扩展属性。

ExtendedAttribute 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| attribute_definition | 获取属性定义。 |
| field_id | 获取字段的 ID。 |
| duration_value | 获取或设置 'Duration' 类型属性的值。 |
| numeric_value | 获取或设置数值类型（Cost、Number）属性的值。 |
| date_value | 获取或设置日期类型（Date、Start、Finish）属性的值。 |
| flag_value | 获取或设置一个值，指示是否为 'Flag' 类型的属性设置了标志。 |
| text_value | 获取或设置 'Text' 类型属性的值。 |
| value_guid | 获取查找值的 GUID。 |
| value_read_only | 获取一个值，指示此 [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) 实例的值是否为只读。 |
| is_error_value | 获取扩展属性值的计算是否导致错误。 |
