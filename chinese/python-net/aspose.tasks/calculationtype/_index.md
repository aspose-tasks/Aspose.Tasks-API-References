## CalculationType enumeration

指定自定义属性值的计算类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 表示扩展属性没有公式查找表，仅存储用户设置的值。 |
| LOOKUP | 表示扩展属性的值受限于查找表中的值。 |
| FORMULA | 表示扩展属性的值是使用在 [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/) 中定义的公式计算的。 |
