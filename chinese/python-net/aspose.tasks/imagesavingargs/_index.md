## ImageSavingArgs class

此类表示与外部图像文件保存相关的数据集合，该保存在转换为 HTML 格式期间发生。<br/>                

ImageSavingArgs 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ImageSavingArgs() | 初始化 [ImageSavingArgs](/tasks/python-net/aspose.tasks/imagesavingargs/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| file_name | 获取或设置从转换器传递到自定义方法代码的假定文件名。<br/>             可在自定义代码中用于决定如何处理或将文件保存在哪里。 |
| keep_stream_open | 获取或设置一个值，指示在资源保存完成后流是否保持打开。 |
| stream | 获取或设置已保存文件的二进制内容。 |
| uri | 获取或设置资源的 URI。 |
| image_type | 获取 HTML 图像类型。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| close_stream_if_required() | 如果 KeepStreamOpen 为 false，则关闭流；否则刷新流。 |
