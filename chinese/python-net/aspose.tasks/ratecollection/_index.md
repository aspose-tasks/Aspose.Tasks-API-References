## RateCollection class

表示包含 [Rate](/tasks/python-net/aspose.tasks/rate/) 对象的集合。

RateCollection 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| count | 获取 RateCollection 中包含的元素数量。 |
| is_read_only | 获取一个值，指示此集合是否只读。 |
| parent_resource | 获取此集合的父级 [Resource](/tasks/python-net/aspose.tasks/resource/) 对象。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| add(rates_from) | 向此集合添加一个新的 [Rate](/tasks/python-net/aspose.tasks/rate/) 实例。 |
| add(rates_from, type) | 向此集合添加一个新的 [Rate](/tasks/python-net/aspose.tasks/rate/) 实例。 |
| to_list() | 将 [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) 对象转换为 [Rate](/tasks/python-net/aspose.tasks/rate/) 对象的列表。 |
| to_list(type) | 将 [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) 对象转换为按指定 [RateType](/tasks/python-net/aspose.tasks/ratetype/) 类型过滤的 [Rate](/tasks/python-net/aspose.tasks/rate/) 对象列表。 |
| remove(item) | 从此集合中移除 Rate 实例。 |
