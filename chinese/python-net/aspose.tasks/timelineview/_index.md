## TimelineView class

表示项目的时间轴视图。

TimelineView 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| TimelineView() | 初始化 [TimelineView](/tasks/python-net/aspose.tasks/timelineview/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| filter | 获取或设置在单个视图中使用的过滤器。 |
| 组 | 获取或设置单个视图的组。 |
| uid | 获取视图的唯一标识符。 |
| highlight_filter | 获取或设置一个值，指示 Microsoft Project 是否为单个视图突出显示筛选器。 |
| name | 获取或设置 View 对象的名称。 |
| screen | 获取单个视图的屏幕类型。<br/>            只读 [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/)。 |
| parent_project | 获取 View 对象的父对象。<br/>            只读 [Project](/tasks/python-net/aspose.tasks/project/)。 |
| table | 获取或设置单个视图的表。 |
| type | 获取单个视图中项目的类型，例如任务或资源。<br/>            只读 [ItemType](/tasks/python-net/aspose.tasks/itemtype/)。 |
| show_in_menu | 获取或设置一个值，指示 Microsoft Project 是否在功能区的“视图”或“其他视图”下拉列表中显示单个视图的名称。 |
| page_info | 获取 [page_info](/tasks/python-net/aspose.tasks/view/) 类的实例。表示存在于 mpp 文件格式中的页面设置数据。 |
| visual_objects_placements | 获取表示视图中 [OleObject](/tasks/python-net/aspose.tasks/oleobject/) 的放置和外观的对象集合。 |
| date_format | 获取或设置一个值，指示如何在时间线视图上格式化日期。 |
| display_overlapped | 获取或设置一个值，指示是否在多行上显示重叠任务。 |
| show_dates | 获取一个值，指示是否显示日期。 |
| show_pan_zoom | 获取或设置一个值，指示是否显示平移和缩放控制。 |
| show_timescale | 获取或设置一个值，指示是否显示时间刻度。 |
| show_today | 获取或设置一个值，指示是否显示表示今天的线条。 |
| text_lines_count | 获取或设置一个值，指示在时间轴中用于显示任务的行数。 |
