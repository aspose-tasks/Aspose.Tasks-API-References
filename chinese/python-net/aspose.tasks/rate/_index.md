## Rate class

表示资源在特定时间段内适用的时间段定义及费率。

Rate 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| rates_from | 获取或设置费率生效的日期。 |
| rates_to | 获取或设置费率有效的最后日期。 |
| rate_table | 获取或设置资源的费率表唯一标识符。 |
| standard_rate | 获取或设置资源的每小时标准费率。 |
| standard_rate_format | 获取或设置 Microsoft Project 用于显示标准费率的单位。 |
| overtime_rate | 获取或设置资源的每小时加班费率。 |
| overtime_rate_format | 获取或设置 Microsoft Project 用于显示加班费率的单位。 |
| cost_per_use | 获取或设置资源的每次使用成本。如果资源存在费率表，则此值从当前日期获取。 |
