## Table class

表示 Project 中的表。

Table 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Table() | 初始化 [Table](/tasks/python-net/aspose.tasks/table/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取或设置 Table 对象的名称。 |
| show_in_menu | 获取或设置一个值，指示项目是否在功能区“视图”选项卡的 Tables 下拉列表中显示表名。 |
| table_fields | 获取表示表中字段的 TableFields 集合。 |
| table_type | 获取或设置指定表的表类型。 |
| uid | 获取表的唯一标识符。 |
| row_height | 获取或设置表中行的高度，行高度以文本行数表示。 |
| date_format | 获取或设置表的日期格式。 |
| adjust_header_row_height | 获取或设置一个值，指示是否可以调整表的标题行高度。 |
| show_add_new_column | 获取或设置一个值，指示是否显示“添加新列”界面。 |
| lock_first_column | 获取或设置一个值，指示表的第一列是锁定还是可编辑。 |
