## ProjectInfo class

关于在 Project Online 上可用的已发布项目的简要信息。

ProjectInfo 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ProjectInfo() | 初始化一个新的 [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/) 类实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| id | 获取项目的唯一标识符。 |
| name | 获取项目的名称。 |
| created_date | 获取项目创建的日期和时间。 |
| is_checked_out | 获取指示项目是否已签出的值。 |
| last_published_date | 获取项目最近一次发布的日期。 |
| last_saved_date | 获取项目最近一次保存的日期。 |
| description | 获取项目的描述。 |
