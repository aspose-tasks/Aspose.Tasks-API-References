## UndefinedConstraintHandlingBehavior enumeration

指定用于处理约束未定义的任务的行为。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 从 XER 格式加载的默认行为。<br/>            不执行任何操作。任务约束类型被设置为 'ConstraintType.Undefined'。 |
| SUBSTITUTE_WITH_START_NO_EARLIER_THAN | 对于具有 'Undefined' 约束的任务，添加类型为 'ConstraintType.StartNoEarlierThan' 且日期 = Start 的约束。 |
