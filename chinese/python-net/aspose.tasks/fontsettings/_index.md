## FontSettings class

指定在渲染项目视图时使用的字体设置。

FontSettings 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| FontSettings() | 初始化 FontSettings 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| default_font_name | 获取或设置渲染时的默认（或回退）字体。 |
| use_project_default_font | 获取或设置一个值，指示渲染时是否必须使用默认字体。 |
## Methods
| 名称 | 描述 |
| :- | :- |
| set_font_folders(font_folders, recursive) | 设置 Aspose.Tasks 在渲染项目视图时查找 TrueType 字体的文件夹。 |
