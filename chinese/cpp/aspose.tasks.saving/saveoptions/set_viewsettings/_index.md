## set_ViewSettings {#set_viewsettings}

设置要渲染的视图（ View ）。您可以使用此选项显式指定应保存为 PDF、HTML 或 Image 格式的视图。如果设置了此属性，保存项目时会忽略 Visualization::PresentationFormat 属性。View 应来自以下屏幕之一 (( Aspose::Tasks::View::Screen ))：（Gantt、TaskSheet、TaskUsage、ResourceSheet、ResourceUsage）
