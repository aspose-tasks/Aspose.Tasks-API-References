## set_View {#set_view}

设置要渲染的视图列列表（ GanttChartColumn ）。如果未设置，则仅渲染任务 ID、任务名称、开始和结束。如果同时设置了 View 和 ViewSettings 属性，则 View 的列会覆盖 ViewSettings 的列。
