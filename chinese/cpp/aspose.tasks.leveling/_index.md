## Aspose::Tasks::Leveling namespace

使用 LevelingOptions 指定平衡参数，使用 ResourceLeveler 执行平衡过程，并使用 LevelingResult 获取结果。此命名空间在 Aspose.Tasks 中提供对资源分配和冲突解决的细粒度控制。


## 名称

| 表示 ResourceAssignment 对象的属性。 | Aspose::Tasks 命名空间提供核心类和枚举，用于在 C++ 中管理项目数据、资源、分配和基线信息。 |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | 允许指定资源平衡的参数。 |
| [LevelingResult](./levelingresult/) | 表示资源平衡的结果。 |
