## Analyze {#analyze}

对指定项目执行风险分析。该分析基于蒙特卡罗模拟，结果是 RiskAnalysisResult 类的实例。

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| 参数 | Aspose::Tasks 命名空间提供核心类和枚举，用于在 C++ 中管理项目数据、资源、分配和基线信息。 |
| --- | --- |
| project | 要分析的指定 Project 类实例。 |
