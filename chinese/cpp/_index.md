API 提供了丰富的对象模型，用于处理 Project XML、MPX、MPP 和 Primavera XER 格式，支持任务、资源、分配、日历和自定义字段。其功能被组织为九个命名空间：Aspose::Tasks 用于核心实体，Connectivity 用于文件 I/O，Leveling 用于资源平衡，Primavera 用于 Primavera‑specific 对象，Properties 用于扩展属性，RiskAnalysis 用于 Monte‑Carlo 风险建模，Saving 用于导出选项，Util 用于辅助实用程序，以及 Visualization 用于甘特图和报告渲染。
