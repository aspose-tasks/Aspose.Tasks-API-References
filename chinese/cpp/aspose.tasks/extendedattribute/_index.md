## ExtendedAttribute class

表示扩展属性。

当前支持从 MSP Xml 2003/2007 和 mpp 2003 读取的所有类型的扩展属性。对于 MSP mpp 2007，支持读取的所有扩展属性，除持续时间和标志外。
