## PrimaveraProjectProperties class

表示从 Primavera 文件（XER 或 P6XML）读取的项目的 Primavera 特定属性。

## 方法

| 表示 ResourceAssignment 对象的属性。 | Aspose::Tasks 命名空间提供核心类和枚举，用于在 C++ 中管理项目数据、资源、分配和基线信息。 |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | 获取当前项目的基线项目数组。适用于从包含已导出基线的 Primavera XML 文件读取的项目。 |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | 获取当前基线项目的 Id。适用于从包含已导出基线的 Primavera XML 文件读取的项目。 |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | 获取一个标志，定义是否忽略项目之间的活动关系。 |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | 获取一个标志，定义在调度项目时是否应将活动标记为关键。 |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | 获取一个选项，定义在 Primavera 项目中调度关系延迟时使用哪个日历。 |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | 获取一个标志，定义是否应将活动完成日期调度为预期完成日期。 |
