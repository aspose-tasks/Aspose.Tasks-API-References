## SetMaterialResourceUnits {#setmaterialresourceunits}

为具有可变材料消耗的材料资源分配设置单位。可变材料消耗意味着随着分配持续时间的变化，使用的材料数量成比例变化。

**Returns:** void Aspose::Tasks::

```cpp
SetMaterialResourceUnits(double units, RateScaleType rateScaleType)
```

| 参数 | Aspose::Tasks 命名空间提供核心类和枚举，用于在 C++ 中管理项目数据、资源、分配和基线信息。 |
| --- | --- |
| 单位 | 在该时间段累计的单位数量。 |
| rateScaleType | 累计单位值的时间段。 |
