## Aspose::Tasks::Connectivity namespace

使用这些类型来配置对 Microsoft Project Server 数据库 (MspDbSettings)、Primavera 数据库 (PrimaveraDbSettings)、MPD 文件 (MpdSettings) 或通用数据库源 (DbSettings) 的连接。该命名空间集中管理连接配置，以实现与 Aspose.Tasks 数据提取和操作功能的无缝集成。


## 名称

| 表示 ResourceAssignment 对象的属性。 | Aspose::Tasks 命名空间提供核心类和枚举，用于在 C++ 中管理项目数据、资源、分配和基线信息。 |
| --- | --- |
| [DbSettings](./dbsettings/) | 允许指定从项目数据库读取的设置。 |
| [MpdSettings](./mpdsettings/) | 允许设置必要的选项以从 MPD 格式 (MS Access 读取项目数据。 |
| [MspDbSettings](./mspdbsettings/) | 允许设置必要的选项以从 MS Project Server 数据读取项目数据。 |
| [PrimaveraDbSettings](./primaveradbsettings/) | 允许设置必要的选项以从 Primavera 数据库读取项目数据。 |
