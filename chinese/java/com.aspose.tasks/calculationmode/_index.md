## 字段

### Automatic {#Automatic}
```
public static final int Automatic
```


自动模式。使用此模式时，项目日期和成本会重新计算。

### Manual {#Manual}
```
public static final int Manual
```


手动模式。仅在此模式下重新计算必要的字段，例如对象的 UID 和 ID。

### None {#None}
```
public static final int None
```


无。在此模式下不重新计算项目日期和成本。
