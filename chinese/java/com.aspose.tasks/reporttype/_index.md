### BestPracticeAnalyzer {#BestPracticeAnalyzer}
```
public static final int BestPracticeAnalyzer
```


显示没有实际工作、未分配的任务、持续时间少于 8 小时的任务以及分配给资源的摘要。

### Burndown {#Burndown}
```
public static final int Burndown
```


包括工作燃尽图和任务燃尽图。工作燃尽图显示人员已完成的工作量、计划在项目结束日期前完成的工作量，以及基线对当前项目阶段应完成工作量的估计。任务燃尽图显示已完成的任务数量、剩余任务数量，以及基线对当前项目阶段应完成任务数量的估计。
