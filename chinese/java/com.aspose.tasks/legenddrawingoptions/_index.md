指定在渲染视图图例时使用的可能选项。
## 字段

| 字段 | 描述 |
| --- | --- |
| [AfterLastPage](#AfterLastPage) | 图例在项目最后一页之后的单独页面上渲染。 |
| [DefinedInView](#DefinedInView) | 图例根据渲染视图的 View.PageInfo.Legend.LegendOn 属性进行渲染。 |
| [NoLegend](#NoLegend) | 不渲染图例。 |
| [OnEveryPage](#OnEveryPage) | 图例在每页上渲染。 |
