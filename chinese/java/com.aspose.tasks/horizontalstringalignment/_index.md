指定文本字符串相对于其布局矩形的对齐方式。
## 字段

| 字段 | 描述 |
| --- | --- |
| [Center](#Center) | 指定文本在布局矩形的中心对齐。 |
| [Far](#Far) | 指定文本在布局矩形的原点位置的远端对齐。 |
| [Near](#Near) | 指定文本在布局的近端对齐。 |
### Center {#Center}
```
public static final int Center
```


指定文本在布局矩形的中心对齐。

### Far {#Far}
```
public static final int Far
```


指定文本在布局矩形的原点位置的远端对齐。在从左到右的布局中，远端位置在右侧。在从右到左的布局中，远端位置在左侧。

### Near {#Near}
```
public static final int Near
```


指定文本在布局的近端对齐。在从左到右的布局中，近端位置在左侧。在从右到左的布局中，近端位置在右侧。
