包含用于创建风险分析报告的类。

## 类

| 类 | 描述 |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | 表示风险分析的结果。 |
| [RiskAnalysisSettings](./riskanalysissettings/) | 指定执行风险分析的设置。 |
| [RiskAnalyzer](./riskanalyzer/) | 基于指定的风险分析设置执行蒙特卡罗模拟。 |
| [RiskItemStatistics](./riskitemstatistics/) | 表示存储已分析项目任务统计数据的项。 |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | 表示包含 [`RiskItemStatistics`](../aspose.tasks.riskanalysis/riskitemstatistics/) 类实例的集合。 |
| [RiskPattern](./riskpattern/) | 表示项目任务的风险模式。 |
| [RiskPatternCollection](./riskpatterncollection/) | 表示包含 [`RiskPattern`](../aspose.tasks.riskanalysis/riskpattern/) 类实例的集合。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [ConfidenceLevel](./confidencelevel/) | 指定风险分析中使用的受支持置信水平，这些水平对应实际值在乐观和悲观估计范围内出现的时间百分比。 |
| [ProbabilityDistributionType](./probabilitydistributiontype/) | 指定受支持的概率分布类型。 |
| [RiskItemType](./riskitemtype/) | 指定在风险分析期间收集统计信息的任务字段。 |
