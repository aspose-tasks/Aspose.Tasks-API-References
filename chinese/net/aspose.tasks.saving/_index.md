包含用于将项目保存为不同格式的类。

## 类

| 类 | 描述 |
| --- | --- |
| [CsvOptions](./csvoptions/) | 允许在将项目保存为 CSV 时指定附加选项。 |
| [HtmlSaveOptions](./htmlsaveoptions/) | 允许在将项目页面渲染为 HTML 时指定附加选项。 |
| [ImageSaveOptions](./imagesaveoptions/) | 允许在将项目页面渲染为图像时指定附加选项。 |
| [MPPSaveOptions](./mppsaveoptions/) | 允许在将项目数据保存为 MPP 时指定附加选项。 |
| [PageSavingArgs](./pagesavingargs/) | 此类表示与将文档页面保存到流相关的数据集合。 |
| [PdfDigitalSignatureDetails](./pdfdigitalsignaturedetails/) | 包含 PDF 数字签名的详细信息。 |
| [PdfEncryptionDetails](./pdfencryptiondetails/) | 包含 PDF 加密的详细信息。 |
| [PdfSaveOptions](./pdfsaveoptions/) | 允许在将项目页面渲染为 PDF 时指定附加选项。 |
| [PrimaveraSaveOptions](./primaverasaveoptions/) | 允许在将项目保存为 Primavera XER 格式时指定附加选项。 |
| [PrimaveraXmlSaveOptions](./primaveraxmlsaveoptions/) | 允许在将项目保存为 Primavera XML 格式时指定附加选项。 |
| [PrintOptions](./printoptions/) | 允许在打印项目时指定附加选项。 |
| [SaveOptions](./saveoptions/) | 这是一个抽象基类，供允许用户在将项目保存为特定格式时指定附加选项的类使用。 |
| [SaveTemplateOptions](./savetemplateoptions/) | 允许在将项目保存为模板时指定附加选项。 |
| [SimpleSaveOptions](./simplesaveoptions/) | 这是一个抽象基类，允许用户在将项目保存为特定格式时指定基本选项。 |
| [Spreadsheet2003SaveOptions](./spreadsheet2003saveoptions/) | 允许在将项目页面渲染为 Spreadsheet2003 时指定附加选项。 |
| [SvgOptions](./svgoptions/) | 允许在将项目页面渲染为 SVG 时指定其他选项。 |
| [TaskLinkDrawingCallbackDelegate](./tasklinkdrawingcallbackdelegate/) | 表示在甘特图视图中渲染任务链接时调用的回调。 |
| [XamlOptions](./xamloptions/) | /// 允许在将项目页面渲染为 XAML 时指定其他选项。 |
| [XlsxOptions](./xlsxoptions/) | 允许在将项目页面渲染为 XLSX 时指定其他选项。 |
| [XpsOptions](./xpsoptions/) | 允许在将项目页面渲染为 XPS 时指定其他选项。 |

| 接口 | 描述 |
