## PrimaveraReadOptions.ReadBaselineProjects property

获取或设置一个标志，指定是否应加载基线项目。默认值为 true。

```csharp
public bool ReadBaselineProjects { get; set; }
```

## 备注

此标志适用于包含基线项目的 Primavera XML 文件（XER 格式不支持基线）。当不需要基线数据时，可以将该选项设置为 false，以加快加载带基线的大型项目的速度。
