## VbaModuleType enumeration

指定 VBA 项目中模块的类型。

```csharp
public enum VbaModuleType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| DocumentModule | `0` | 一种 VBA 项目项类型，指定与文档关联的嵌入宏和编程访问操作的模块。 |
| ProceduralModule | `1` | 包含子例程和函数集合的模块。 |
| ClassModule | `2` | 包含新对象定义的模块。类的每个实例都会创建一个新对象，模块中定义的过程成为对象的属性和方法。 |
| DesignerModule | `3` | 扩展已在项目中注册的 ActiveX 控件的方法和属性的模块。 |
