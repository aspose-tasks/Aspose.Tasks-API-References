## TimescaleTier.RenderLabelOnEachPage property

获取或设置一个标志，定义当时间段跨越多个页面时是否在每页上渲染日期标签。如果值为 'true'，当时间段跨越多个页面时，该期间的日期标签将在每页上渲染。如果值为 'false'，日期标签仅根据 [`Alignment`](../alignment/) 属性的值渲染一次。

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
