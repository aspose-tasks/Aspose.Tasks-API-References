包含用于处理 Primavera 特定格式（XER、Primavera XML）所需的类。

## 类

| 类 | 描述 |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | 表示从 Primavera 格式加载的项目的简要信息。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [PrimaveraActivityType](./primaveraactivitytype/) | 指定 Primavera 活动的类型。 |
| [PrimaveraConstraintType](./primaveraconstrainttype/) | 指定活动约束的类型。 |
| [PrimaveraDurationType](./primaveradurationtype/) | 指定 Primavera 活动的持续时间类型。 |
| [PrimaveraPercentCompleteType](./primaverapercentcompletetype/) | 指定 Primavera 活动的 '% Complete Type' 字段的值。 |
| [PrimaveraRelationshipLagCalendar](./primaverarelationshiplagcalendar/) | 指定在 Primavera 项目中调度关系延迟时使用的日历。 |
