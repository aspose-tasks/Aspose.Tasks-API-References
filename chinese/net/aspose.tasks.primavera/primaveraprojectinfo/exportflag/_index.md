## PrimaveraProjectInfo.ExportFlag property

获取项目的导出标志。当在 Primavera 中选择项目进行导出时，其 ExportFlag 为 true。某些未明确选择导出的项目可能因与已导出项目的关系而被导出到 XER 文件。

```csharp
public bool ExportFlag { get; }
```
