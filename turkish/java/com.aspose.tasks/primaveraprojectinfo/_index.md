### getExportFlag() {#getExportFlag--}
```
public final boolean getExportFlag()
```


Projenin dışa aktarma bayrağını alır. Primavera'da bir proje dışa aktarma için seçildiğinde, ExportFlag değeri true olur. Açıkça dışa aktarma için seçilmeyen bazı projeler, dışa aktarılan proje ile ilişkileri nedeniyle bir XER dosyasına aktarılabilir.
