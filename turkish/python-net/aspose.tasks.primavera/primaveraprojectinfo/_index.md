## PrimaveraProjectInfo class

Primavera formatından yüklenen bir proje hakkında kısa bilgi temsil eder.

PrimaveraProjectInfo türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| uid | Projenin Uid'sini alır. |
| name | Projenin adını alır. |
| short_name | Projenin kısa adını (Proje Kimliği) alır. |
| export_flag | Projenin export bayrağını alır. Primavera'da bir proje dışa aktarma için seçildiğinde, ExportFlag değeri true olur.<br/>            Açıkça dışa aktarma için seçilmeyen bazı projeler, dışa aktarılan proje ile ilişkileri nedeniyle bir XER dosyasına dışa aktarılabilir. |
