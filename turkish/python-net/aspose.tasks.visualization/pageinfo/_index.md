## PageInfo class

MPP dosya formatında bulunan ve yazdırma için kullanılan sayfa ayarı verilerini temsil eder.

PageInfo türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| PageInfo() | Yeni bir [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) sınıfı örneği başlatır. <br/>            MPP dosya formatında bulunan ve yazdırma için kullanılan sayfa ayar verilerini temsil eder. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| header | Üst bilgi verisini temsil eden [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) sınıfının örneğini alır veya ayarlar. |
| footer | Alt bilgi verisini temsil eden [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) sınıfının bir örneğini alır veya ayarlar. |
| name | Kurulum verisinin kullanıldığı görünümün adını alır. |
| page_settings | [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) sınıfının sayfa yazdırma ayarlarını belirten bir örneğini alır. |
| page_view_settings | [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) sınıfının sayfa görünümü yazdırma ayarlarını belirten bir örneğini alır. |
| margins | [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) sınıfının sayfa kenar boşluklarını belirten bir örneğini alır. |
| legend | [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) sınıfının sayfa açıklama çizelgesi render seçeneklerini belirten bir örneğini alır veya ayarlar. |
