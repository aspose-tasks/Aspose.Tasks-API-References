## ProgressLines class

Gantt Chart görünümündeki ilerleme çizgilerini temsil eder.

ProgressLines türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| ProgressLines() | ProgressLines sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| display_at_current_date | İlerleme çizgisini geçerli tarihte gösterip göstermeyeceğini belirten bir değeri alır veya ayarlar. |
| display_at_recurring_intervals | İlerleme çizgisini yinelenen aralıklarla gösterip göstermeyeceğini belirten bir değeri alır veya ayarlar. |
| recurring_interval | Yinelenen aralığı alır veya ayarlar.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Proje başlangıç tarihinin başından itibaren ilerleme çizgilerini gösterip göstermeyeceğini belirten bir değeri alır veya ayarlar. |
| begin_at_date | İlerleme çizgilerinin gösterileceği tarihi alır veya ayarlar. |
| display_selected | Seçilen tarihlerde ilerleme çizgilerini gösterip göstermeyeceğini belirten bir değeri alır veya ayarlar. |
| is_baseline_plan | Temel plan için mi yoksa gerçek için mi ilerleme çizgilerini göstereceğini belirten bir değeri alır veya ayarlar. |
| show_date | Her ilerleme çizgisi için tarihi gösterip göstermeyeceğini belirten bir değeri alır veya ayarlar. |
| date_format | Tarih biçimini alır veya ayarlar ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |

| line_pattern | Mevcut ilerleme çizgisinin çizgi desenini alır veya ayarlar.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Mevcut ilerleme çizgisi için çizgi rengini alır veya ayarlar. |
| progress_point_shape | İlerleme noktası şeklini alır veya ayarlar.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | İlerleme noktasının rengini alır veya ayarlar. |
| other_line_pattern | Diğer ilerleme çizgisi için çizgi desenini alır veya ayarlar. |
| other_line_color | Diğer ilerleme çizgisinin rengini alır veya ayarlar. |
| other_progress_point_shape | Diğer ilerleme çizgisinin ilerleme noktası şeklini alır veya ayarlar. |
| other_progress_point_color | Diğer ilerleme noktasının rengini alır veya ayarlar. |
| selected_dates | İlerleme çizgilerini göstermek için seçilen tarihlerin listesini alır. |
