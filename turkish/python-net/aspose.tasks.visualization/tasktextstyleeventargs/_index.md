## TaskTextStyleEventArgs class

Bu sınıf, tablo hücresinin içeriğinin işlenmesiyle ilgili veri kümesini temsil eder.

TaskTextStyleEventArgs türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| cell_text_style | Hücrenin içeriğini çizmeye kullanılacak TextStyle'ı alır veya ayarlar. Bu nesne, bir tablo hücresinin görünümünü özelleştirmek için kullanılabilir. |
| task | Şu anda işlenen satıra karşılık gelen [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) öğesini alır. |
| column | Şu anda işlenen hücrenin ait olduğu [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) öğesini alır. |
