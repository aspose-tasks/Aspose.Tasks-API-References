## TimescaleFitBehavior enumeration

Zaman ölçeği alanını sayfa genişliğiyle hizalamak için kullanılan bir davranışı temsil eder.

## Members
| Üye adı | Açıklama |
| :- | :- |
| DEFINED_IN_VIEW | Takvim bölümü, oluşturulan Görünümün View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage özelliğine göre işlenir. |
| NO_SCALE_TO_END_DATE | Takvim bölümü, sayfada boş bir alan olsa bile, EndDate'e tam olarak işlenir. |
| NO_SCALE_TO_END_OF_PAGE | Takvim bölümü, son sayfanın sonuna (sağ tarafına) işlenir.<br/>            Bu nedenle son işlenen tarih EndDate'i aşabilir. |
| SCALE_TO_END_OF_PAGE | İşleme motoru, tarihleri EndDate'in son sayfanın sonuna (sağ tarafına) hizalanacak şekilde ayarlamaya çalışır.<br/>            Bu, MS Project'in "Sayfa Ayarı \ Görünüm \ Zaman ölçeğini sayfanın sonuna sığdır" seçeneğinin etkinleştirilmiş olmasına karşılık gelir. |
