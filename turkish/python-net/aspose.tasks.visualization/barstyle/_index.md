## BarStyle class

Proje görünümündeki öğenin çubuğunun görsel stilini değiştir.

BarStyle türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| BarStyle() | Yeni bir [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| bar_color | Çubuk stilinin aspose.pydrawing.Color değerini alır veya ayarlar. |
| start_shape_color | Çubuğun başlangıcındaki şeklin aspose.pydrawing.Color değerini alır veya ayarlar. |
| start_shape_type | Başlangıç şeklinin türü alınır veya ayarlanır. |
| end_shape_color | Çubuğun sonundaki şeklin aspose.pydrawing.Color değerini alır veya ayarlar. |
| end_shape_type | Son şeklin tipini alır veya ayarlar.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | Çubuk stilinin [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) değerini alır veya ayarlar. |
| bar_shape | Çubuk stilinin [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) değerini alır veya ayarlar. |
| start_shape | Çubuğun başlangıcındaki [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) değerini alır veya ayarlar. |
| end_shape | Çubuğun sonundaki [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) değerini alır veya ayarlar. |
| text_style | Çubuğun metninin stilini alır veya ayarlar. |
| left_field | Çubuğun solunda gösterilecek bir alanı alır veya ayarlar. |
| top_field | Çubuğun üstünde gösterilecek bir alanı alır veya ayarlar. |
| right_field | Çubuğun sağında gösterilecek bir alanı alır veya ayarlar. |
| bottom_field | Çubuğun alt kısmında görüntülenecek bir alanı alır veya ayarlar. |
| inside_field | Çubuğun içinde görüntülenecek bir alanı alır veya ayarlar. |
| from_address | Gantt çubuğunun başlangıç noktası konumunu alır veya ayarlar.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | Gantt çubuğunun bitiş noktası konumu alınır veya ayarlanır. |
