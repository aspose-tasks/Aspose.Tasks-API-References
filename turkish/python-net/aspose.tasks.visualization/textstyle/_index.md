## TextStyle class

Proje görünümündeki bir öğe için metnin görsel stilini değiştir.

TextStyle türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| TextStyle() | Varsayılan ayarlarla yeni bir [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) sınıfı örneği başlatır. |
| TextStyle(font_size, font_style) | Yeni bir TextStyle sınıfı örneği başlatır |
| TextStyle(font_style) | Varsayılan yazı tipi ve belirtilen yazı tipi boyutu ve stiliyle yeni bir [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) sınıfı örneği başlatır. |
| TextStyle(font) | Belirtilen yazı tipi ayarlarıyla yeni bir [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| font | Metin stilinin yazı tipini alır veya ayarlar. |
| color | Metnin rengini alır veya ayarlar. |
| item_type | Metin stilinin [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) değerini alır veya ayarlar. |
| background_pattern | Metin stilinin arka plan desenini alır veya ayarlar.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Metin stilinin arka plan rengini alır veya ayarlar.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
