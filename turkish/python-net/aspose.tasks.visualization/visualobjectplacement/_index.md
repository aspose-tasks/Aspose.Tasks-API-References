## VisualObjectPlacement class

Bir görünümdeki [OleObject](/tasks/python-net/aspose.tasks/oleobject/) konumunu ve görünümünü temsil eder.

VisualObjectPlacement türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| VisualObjectPlacement() | Yeni bir [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| ole_object_id | [OleObject](/tasks/python-net/aspose.tasks/oleobject/) nesnesinin Id'sini alır veya ayarlar. |
| task_id | 'Attach to task' seçeneği seçildiğinde görevin Id'sini alır veya ayarlar, aksi takdirde -1. |
| width | Görsel nesnenin görüntülenen genişliğini alır veya ayarlar. |
| height | Görsel nesnenin görüntülenen yüksekliğini alır veya ayarlar. |
| vertical_offset | Görsel nesnenin dikey ofsetini alır veya ayarlar. |
| horizontal_offset | Görsel nesnenin yatay ofsetini alır veya ayarlar. |
| timescale_date | 'Attach to timescale' seçeneği seçildiğinde görsel nesnenin tarih yerleşimini alır veya ayarlar. |
| attachment_point | 'Attach to task' seçeneği seçildiğinde görsel nesnenin bir göreve göre hizalamasını alır veya ayarlar. |
| border_line_color | Sınır çizgi rengini alır veya ayarlar. |
| border_line_thickness | Sınır çizgi kalınlığını alır veya ayarlar (izin verilen değerler 0 - 5). |
| fill_color | Dolgu rengini alır veya ayarlar. |
| fill_pattern | Dolgu desenini alır veya ayarlar. |
