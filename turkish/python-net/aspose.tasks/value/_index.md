## Value class

Bir değer listesindeki bir değeri temsil eder.

Value türü aşağıdaki üyeleri ortaya çıkarır:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Value() | Yeni bir [Value](/tasks/python-net/aspose.tasks/value/) sınıfının bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| id | Bir proje genelinde bir değerin benzersiz tanımlayıcısını alır veya ayarlar. |
| value_guid | Bu değeri tüm projedeki diğerleri arasında tanımlayan bir GUID alır. |
| val | İç temsildeki gerçek değeri alır veya ayarlar. Aşağıda listelenen güçlü tipli özellikleri kullanmayı tercih edin. |
| string_value | Metin dizesini temsil etmek için kullanılan gerçek değeri alır veya ayarlar. |
| numeric_value | Sayı veya maliyet değerini temsil etmek için kullanılan gerçek değeri alır veya ayarlar. |
| duration | Süreyi temsil etmek için kullanılan gerçek değeri alır veya ayarlar. |
| date_time_value | DateTime olarak temsil edilebiliyorsa gerçek değeri alır veya ayarlar. Varsayılan değer minimum tarih değeridir. |
| description | Bir değerin açıklamasını alır veya ayarlar. |
| phonetic | Özel alan adıyla ilgili fonetik bilgiyi alır veya ayarlar. |
