## ExtendedAttribute class

Genişletilmiş öznitelikleri temsil eder.

ExtendedAttribute türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| attribute_definition | Özellik tanımını alır. |
| field_id | Bir alanın kimliğini alır. |
| duration_value | ‘Duration’ tipindeki özellikler için değeri alır veya ayarlar. |
| numeric_value | Sayısal tipteki (Cost, Number) özellikler için değeri alır veya ayarlar. |
| date_value | Tarih tipindeki (Date, Start, Finish) özellikler için değeri alır veya ayarlar. |
| flag_value | ‘Flag’ tipindeki bir özellik için bayrağın ayarlanıp ayarlanmadığını gösteren değeri alır veya ayarlar. |
| text_value | ‘Text’ tipindeki özellikler için değeri alır veya ayarlar. |
| value_guid | Bir arama değerinin GUID'ini alır. |
| value_read_only | Bu [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) örneğinin değerinin yalnızca okunur olup olmadığını gösteren bir değeri alır. |
| is_error_value | Genişletilmiş özelliğin değerinin hesaplamasının bir hatayla sonuçlanıp sonuçlanmadığını alır. |
