## GraphicalIndicatorCriteria class

Genişletilmiş bir öznitelikle ilişkili bir grafik gösterge kriterini temsil eder.

GraphicalIndicatorCriteria türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | GraphicalIndicatorCriteria sınıfının yeni bir örneğini başlatır |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | GraphicalIndicatorCriteria sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| test | Genişletilmiş öznitelik değerinin ve Değerlerin karşılaştırma türünü alır; bu, grafik göstergenin uygulanması için bir kriter olarak işlev görür.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Genişletilmiş öznitelik değerini test etmek için kullanılan değeri alır. |
| value2 | 'IsWithin' ve 'IsNotWithin' karşılaştırma türleri durumunda, genişletilmiş öznitelik değerini test etmek için kullanılan ikinci değeri alır. |
| image_index | Alan kriterleri karşıladığında görüntülenecek resmin indeksini alır. |
| row_type | [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) enum'ının, göstergenin hangi satırlara uygulanacağını belirten değerini alır. |
