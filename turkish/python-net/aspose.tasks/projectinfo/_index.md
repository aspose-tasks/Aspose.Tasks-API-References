## ProjectInfo class

Project Online'da bulunan yayınlanmış proje hakkında kısa bilgi.

ProjectInfo türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| ProjectInfo() | Yeni bir [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/) sınıfının örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| id | Projenin benzersiz tanımlayıcısını alır. |
| name | Projenin adını alır. |
| created_date | Projenin oluşturulduğu tarih ve saati alır. |
| is_checked_out | Projenin çıkış yapılmış olup olmadığını gösteren bir değeri alır. |
| last_published_date | Projenin en son yayınlandığı tarihi alır. |
| last_saved_date | Projenin en son kaydedildiği tarihi alır. |
| description | Projenin açıklamasını alır. |
