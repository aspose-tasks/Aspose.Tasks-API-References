## RecurringTaskInfo class

Bir projedeki yineleyen görevin ayrıntılarını temsil eder.

RecurringTaskInfo türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| recurrence_pattern | Yinelenen görevin bir yineleme desenini alır veya ayarlar. |
| start_date | Oluşumların başlayacağı tarihi alır veya ayarlar. |
| end_date | Oluşumların biteceği tarihi alır veya ayarlar. |
| duration | Yinelenen görevin bir oluşumu için süreyi alır veya ayarlar. |
| occurrences | Yinelenen görevin oluşum sayısını alır veya ayarlar. |
| use_end_date | Yinelenen görev için bitiş tarihini mi yoksa oluşum sayısını mı kullanacağını gösteren bir değeri alır veya ayarlar. |
| daily_repetitions | Günlük yineleme deseni için tekrar sayısını alır veya ayarlar. |
| daily_use_workdays | Günlük yineleme deseninde iş günlerinin kullanılıp kullanılmayacağını gösteren bir değeri alır veya ayarlar. |
| weekly_repetitions | Haftalık yineleme desenindeki tekrar sayısını alır veya ayarlar. |
| weekly_days | Haftalık yineleme deseninde kullanılan günlerin koleksiyonunu alır veya ayarlar. |
| monthly_use_ordinal_day | Aylık yineleme deseninde sıra gününün kullanılıp kullanılmayacağını gösteren bir değeri alır veya ayarlar. |
| monthly_ordinal_number | Aylık yineleme deseninin sıra numarasını alır veya ayarlar. |
| monthly_ordinal_repetitions | Sıra günü kullanıldığında aylık yineleme desenindeki tekrar sayısını alır veya ayarlar. |
| monthly_day | Aylık yineleme desenindeki gün sayısını alır veya ayarlar. |
| monthly_repetitions | Aylık yineleme desenindeki tekrar sayısını alır veya ayarlar. |
| yearly_use_ordinal_day | Yıllık yineleme deseninde sıra gününün kullanılıp kullanılmayacağını gösteren bir değeri alır veya ayarlar. |
| yearly_date | Yıllık yineleme deseni için bir tarihi alır veya ayarlar. |
| yearly_ordinal_number | Yıllık yineleme deseninin sıra numarasını alır veya ayarlar. |
| yearly_ordinal_month | Sıra günü kullanıldığında yıllık yineleme deseninin ayını alır. |
| task | Bu [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/) sınıfı örneğinin üst görevini alır. |
