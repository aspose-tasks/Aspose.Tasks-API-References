## View class

Projede bir görünümü temsil eder.

View türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| View() | Yeni bir [View](/tasks/python-net/aspose.tasks/view/) sınıfı örneği başlatır. |
| View(view_screen) | Yeni bir [View](/tasks/python-net/aspose.tasks/view/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| filter | Tek bir görünümde kullanılan bir filtreyi alır veya ayarlar. |
| grup | Tek görünümün bir grubunu alır veya ayarlar. |
| uid | Bir görünümün benzersiz tanımlayıcısını alır. |
| highlight_filter | Microsoft Project'in tek bir görünüm için filtreyi vurgulayıp vurgulamadığını belirten bir değeri alır veya ayarlar. |
| name | Bir View nesnesinin adını alır veya ayarlar. |
| screen | Tek görünüm için ekran tipini alır.<br/>            Salt okunur [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | View nesnesinin üst nesnesini alır.<br/>            Salt okunur [Project](/tasks/python-net/aspose.tasks/project/). |
| tablo | Tek görünümün bir tablosunu alır veya ayarlar. |
| type | Tek görünümdeki öğenin türünü, örneğin görevler veya kaynaklar, alır.<br/>            Salt okunur [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Microsoft Project'in Tek Görünüm adını Şeritteki Görünüm veya Diğer Görünümler açılır listelerinde gösterip göstermediğini belirten bir değeri alır veya ayarlar. |
| page_info | [page_info](/tasks/python-net/aspose.tasks/view/) sınıfının bir örneğini alır. mpp dosya formatında bulunan sayfa ayarı verilerini temsil eder. |
| visual_objects_placements | Görünümdeki [OleObject](/tasks/python-net/aspose.tasks/oleobject/) yerleşimini ve görünümünü temsil eden nesneler koleksiyonunu alır. |
