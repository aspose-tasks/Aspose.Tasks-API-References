## PrimaveraTaskProperties class

Primavera dosyalarından (P6XML'in XER'i) okunan bir görev için Primavera'ya özgü özellikleri temsil eder.

PrimaveraTaskProperties türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| sequence_number | WBS öğesinin (özet görevler) sıra numarasını alır veya ayarlar. Primavera'da özet görevleri sıralamak için kullanılır. |
| activity_id | Bir aktivite kimliği alanı alır - Primavera tarafından kullanılan bir görevin benzersiz tanımlayıcısı. |
| remaining_early_finish | Kalan erken bitiş tarihini alır - aktivite için kalan işin tamamlanması planlanan tarih. |
| remaining_early_start | Kalan erken başlangıç tarihini alır - aktivite için kalan işin başlaması planlanan tarih. |
| remaining_late_start | Kalan geç başlangıç tarihini alır. |
| remaining_late_finish | Kalan geç bitiş tarihini alır. |
| raw_duration_type | Aktivitenin 'Duration Type' alanının ham metin temsilini (kaynak dosyada olduğu gibi) alır. |
| duration_type | Aktivitenin 'Duration Type' alanının değerini alır. |
| raw_activity_type | Aktivitenin 'Activity Type' alanının ham metin temsilini (kaynak dosyada olduğu gibi) alır. |
| activity_type | 'Activity Type' alanının değerini alır. |
| percent_complete_type | Aktivitenin '% Complete Type' alanının değerini alır. |
| raw_complete_percent_type | Aktivitenin '% Complete Type' alanının ham metin temsilini (kaynak dosyada olduğu gibi) alır. |
| raw_status | Etkinliğin 'Status' alanının (kaynak dosyadaki gibi) ham metin temsilini alır. |
| physical_percent_complete | Physical Percent Complete değerini alır. |
| duration_percent_complete | duration percent complete değerini alır. |
| units_percent_complete | units percent complete değerini alır. |
| actual_labor_units | actual labor units değerini alır. |
| actual_non_labor_units | actual non labor units değerini alır. |
| remaining_labor_units | remaining labor units değerini alır. |
| remaining_non_labor_units | remaining non labor units değerini alır. |
| actual_labor_cost | actual labor cost değerini alır. |
| budgeted_labor_cost | budgeted (or planned) labor cost değerini alır. |
| actual_nonlabor_cost | actual non labor cost değerini alır. |
| budgeted_nonlabor_cost | budgeted (or planned) non labor cost değerini alır. |
| actual_material_cost | Gerçek malzeme maliyetinin değerini alır. |
| budgeted_material_cost | Bütçelenmiş (veya planlanmış) malzeme maliyetinin değerini alır. |
| actual_expense_cost | Gerçek gider maliyetinin değerini alır. |
| remaining_expense_cost | Kalan gider maliyetinin değerini alır. |
| budgeted_expense_cost | Bütçelenmiş (veya planlanmış) gider maliyetinin değerini alır. |
| actual_total_cost | Gerçek maliyetlerin toplam değerini alır. |
| budgeted_total_cost | Bütçelenmiş (veya planlanmış) maliyetlerin toplam değerini alır. |
| primary_constraint_type | Birincil kısıtlama türünü alır. |
| primary_constraint_date | Birincil kısıtlamanın tarihini alır. |
| secondary_constraint_type | İkincil kısıtlama türünü alır. |
| secondary_constraint_date | İkincil kısıtlamanın tarihini alır. |
| planned_duration | Orijinal veya planlanmış süreyi alır -- görevin planlanan başlangıç tarihinden planlanan bitiş tarihine kadar olan toplam çalışma süresi.. |
