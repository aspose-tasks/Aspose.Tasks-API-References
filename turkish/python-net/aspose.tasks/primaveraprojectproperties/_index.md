## PrimaveraProjectProperties class

Primavera dosyalarından (P6XML'in XER'i) okunan bir proje için Primavera'ya özgü özellikleri temsil eder.

PrimaveraProjectProperties türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| relationship_lag_calendar | Primavera projelerinde Relationship Lag zamanlaması için kullanılacak takvimi tanımlayan bir seçenek alır. |
| use_expected_finish_dates | Etkinlik bitiş tarihlerinin beklenen bitiş tarihleri olarak planlanıp planlanmayacağını tanımlayan bir bayrak alır. |
| make_open_ended_activities_critical | Projeyi zamanlarken etkinliklerin kritik olarak işaretlenip işaretlenmeyeceğini tanımlayan bir bayrak alır. |
| ignore_other_project_relationships | Projeler arasındaki etkinlik ilişkilerini yok sayıp saymayacağını tanımlayan bir bayrak alır. |
| current_baseline_project_id | Mevcut temel proje kimliğini alır.<br/>            Dışa aktarılmış temeller içeren Primavera XML dosyalarından okunan projeler için geçerlidir. |
| baseline_projects | Mevcut projenin temel proje dizisini alır.<br/>            Dışa aktarılmış temeller içeren Primavera XML dosyalarından okunan projeler için geçerlidir. |
| critical_activities_defining_method | Kritik aktiviteleri tanımlama yöntemini alır: En Uzun Yol veya Toplam Yüzerlik yaklaşımı. |
| critical_total_float_limit | TotalFloat yöntemi kullanıldığında kritik aktiviteleri tanımlamak için kullanılan eşik değerini alır. |
| short_name | Projenin kısa adını (Proje Kimliği) alır. |
