## ProjectServerCredentials class

Project Online veya yerel Project Server örneğine bağlanmak için kullanılan kimlik bilgileri.

ProjectServerCredentials türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | Yeni bir [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) sınıfının örneğini, SharePoint sitesinin URL'si ve SharePoint'in PWA (Project Web Access) sitesi için geçerli SPOIDCRL yetkilendirme belirteci kullanarak başlatır. |
| ProjectServerCredentials(site_url, user_name, password) | Yeni bir [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) sınıfının örneğini, SharePoint sitesinin URL'si ve SharePoint'in PWA (Project Web Access) sitesi için geçerli SPOIDCRL yetkilendirme belirteci kullanarak başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| site_url | PWA'nın SharePoint sitesindeki URL'sini veya şirket içi Project Server'ın URL'sini alır.<br/>            For example, https://your_company_name.sharepoint.com/sites/pwa"; |
| auth_token | SharePoint örneği için yetkilendirme belirtecini alır. |
| user_name | SharePoint sitesi için kullanıcı adını alır. |
