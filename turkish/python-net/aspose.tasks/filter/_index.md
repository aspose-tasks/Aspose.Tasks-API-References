## Filter class

Project içinde bir filtreyi temsil eder.

Filter türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Filter() | Filter sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| filter_type | Filtrenin türünü alır. |
| name | Bir Filter nesnesinin adını alır veya ayarlar. |
| show_in_menu | Projenin, Ribbon üzerindeki Görünüm sekmesindeki Filter açılır listesindeki filtre adını gösterip göstermediğini belirten bir değeri alır veya ayarlar. |
| show_related_summary_rows | Filtre için ilgili özet satırlarının gösterilip gösterilmediğini belirten bir değeri alır veya ayarlar. |
| index | Filters içeren nesnedeki bir [Filter](/tasks/python-net/aspose.tasks/filter/) nesnesinin dizinini alır. |
| uid | Bir filtrenin benzersiz tanımlayıcısını alır. |
| criteria | Görevlerin veya kaynakların MSP görünümünde görüntülenmesi için karşılaması gereken kriterleri alır veya ayarlar. |
