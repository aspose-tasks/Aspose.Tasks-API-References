## OleObject class

Bir MPP dosyasının Gantt Şeması Görünümüne eklenebilen bir OLE nesnesini temsil eder.

OleObject türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| OleObject() | Yeni bir [OleObject](/tasks/python-net/aspose.tasks/oleobject/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | OLE nesnesinin örnek adını alır veya ayarlar. |
| application_name | Gömülü nesneyi açmak için kullanılacak uygulama adını alır veya ayarlar. |
| file_format | Gömülü nesnenin dosya biçimini alır veya ayarlar. |
| content | Gömülü dosyanın verilerini alır veya ayarlar; veri gömülmemişse null. |
| label | Eklenen nesnenin etiketini alır veya ayarlar. |
| full_path | Eklenen nesnenin tam yolunu alır veya ayarlar. |
| temporary_file | Eklenen nesnenin geçici dosyasının yolunu alır veya ayarlar. |
| display_as_icon | OLE nesnesinin bir simge olarak mı yoksa normal resmi olarak mı gösterileceğini belirten bir bayrağı alır veya ayarlar. |
| bağlı | Proje dosyasının yalnızca bağlantı kaynağında depolanan gerçek veriye bir bağlantı içerip içermediğini belirten bir değeri alır. |
| view | Eklenen nesnenin ait olduğu [view](/tasks/python-net/aspose.tasks/oleobject/) sınıfının örneğini alır veya ayarlar. |
| id | Nesne kimliğini alır veya ayarlar. |
