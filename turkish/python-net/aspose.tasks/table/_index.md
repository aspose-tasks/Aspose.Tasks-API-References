## Table class

Project içinde bir tabloyu temsil eder

Table türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Table() | Yeni bir [Table](/tasks/python-net/aspose.tasks/table/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Bir Table nesnesinin adını alır veya ayarlar. |
| show_in_menu | Proje, Şeritteki View sekmesindeki Tables açılır listesinde tablo adının gösterilip gösterilmediğini belirten bir değeri alır veya ayarlar. |
| table_fields | Tablodaki alanları temsil eden bir TableFields koleksiyonu alır. |
| table_type | Belirtilen tablo için tablo tipini alır veya ayarlar. |
| uid | Bir tablonun benzersiz tanımlayıcısını alır. |
| row_height | Bir tabloda satır yüksekliğini alır veya ayarlar; satır yüksekliği metin satır sayısıdır. |
| date_format | Tablonun tarih biçimini alır veya ayarlar. |
| adjust_header_row_height | Tablonun başlık satırı yüksekliğinin ayarlanıp ayarlanamayacağını belirten bir değeri alır veya ayarlar. |
| show_add_new_column | ‘Add New Column’ arayüzünün gösterilip gösterilmeyeceğini belirten bir değeri alır veya ayarlar. |
| lock_first_column | Bir tablonun ilk sütununun kilitli mi yoksa düzenlenebilir mi olduğunu belirten bir değeri alır veya ayarlar. |
