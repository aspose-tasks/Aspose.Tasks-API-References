## LevelingOptions class

Kaynak dengelemesinin parametrelerini belirtmeye izin verir.

LevelingOptions türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| LevelingOptions() | Yeni bir [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| start_date | Dengeleme dönemi başlangıç tarihini alır veya ayarlar. Varsayılan değer `project`s` başlangıç tarihidir. |
| finish_date | Dengeleme dönemi bitiş tarihini alır veya ayarlar. Varsayılan değer `project`s` bitiş tarihidir. |
| kaynaklar | Dengelenecek kaynakların listesini alır veya ayarlar. Eğer null ayarlanırsa, tüm proje kaynakları dengelenecektir. |
| leveling_order | Dengeleme algoritmasının aşırı tahsisatlı görevleri geciktirdiği sırayı alır.<br/>            Aşırı tahsisata neden olan görevlerin ve hangi görevlerin geciktirilebileceğinin belirlenmesinden sonra, hangi görevin önce geciktirileceğini belirten belirtilen sıra kullanılır. |
| message_level | Aspose.Tasks tarafından kaynak dengelemesi sırasında üretilen günlük mesajlarının seviyesini alır veya ayarlar. |
| message_handler | Aspose.Tasks tarafından kaynak dengelemesi sırasında üretilen günlük mesajlarını yakalamak için kullanılabilecek mesaj işleyici geri çağrısını alır veya ayarlar. |
