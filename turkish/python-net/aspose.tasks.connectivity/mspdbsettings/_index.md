## MspDbSettings class

MS Project Server veritabanından proje verilerini okumak için gerekli seçenekleri ayarlamaya izin verir.

MspDbSettings türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Yeni bir [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) sınıf örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| connection_string | connection string'i alır veya ayarlar. |
| provider_invariant_name | provider invariant name'i alır veya ayarlar; bu, sınıfın bir örneğini elde etmek için kullanılır. |
| project_guid | Okunacak projenin guid'ini alır. |
| schema | MS Project Server'ın şemasını alır veya ayarlar.<br/>            Varsayılan değer "pub"dır. |
