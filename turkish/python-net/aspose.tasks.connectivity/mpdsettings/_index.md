## MpdSettings class

## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| MpdSettings(connection_string, project_id) | Yeni bir [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) sınıf örneği başlatır. |
