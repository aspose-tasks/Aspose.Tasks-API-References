## License class

Bileşeni lisanslamak için yöntemler sağlar.

Bu örnekte, <ms> bileşeni içeren klasörde, çağıran derlemenin bulunduğu klasörde, giriş derlemesinin klasöründe ve ardından çağıran derlemenin gömülü kaynaklarında MyLicense.lic adlı bir lisans dosyası bulunmaya çalışılacaktır.

```cpp
[C#]
 
License license = new License();
license.SetLicense("MyLicense.lic");
 
 
[Visual Basic]
 
Dim license As license = New license
License.SetLicense("MyLicense.lic")
```

</ms> <java> bileşen jar dosyası:

```cpp
License license = new License();
license.setLicense("MyLicense.lic");
```

</java>
