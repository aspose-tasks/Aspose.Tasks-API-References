## get_ResolvedFontName {#get_resolvedfontname}

Çözülmüş yazı tipinin adını alır. Görünüm oluşturmak için kullanılan yazı tiplerini kontrol etmek üzere ayarlanabilir.

**Returns:** Name of the requested font if font is found or name of fallback font or null if font cannot be found.

```cpp
get_ResolvedFontName()
```
