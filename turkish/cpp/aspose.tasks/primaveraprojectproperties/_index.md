## PrimaveraProjectProperties class

Primavera dosyalarından (XER veya P6XML) okunan bir proje için Primavera'ye özgü özellikleri temsil eder.

## Yöntemler

| Ad | Açıklama |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | Mevcut projenin temel projeler dizisini alır. Dışa aktarılan temel verileri içeren Primavera XML dosyalarından okunan projeler için geçerlidir. |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | Mevcut temel projenin kimliğini alır. Dışa aktarılan temel verileri içeren Primavera XML dosyalarından okunan projeler için geçerlidir. |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | Projeler arasındaki etkinlik ilişkilerini yok sayıp saymayacağını tanımlayan bir bayrak alır. |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | Projeyi zamanlarken etkinliklerin kritik olarak işaretlenip işaretlenmeyeceğini tanımlayan bir bayrak alır. |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | Primavera projelerinde İlişki Gecikmesini zamanlamak için hangi takvimin kullanılacağını tanımlayan bir seçenek alır. |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | Etkinlik bitiş tarihlerinin beklenen bitiş tarihleri olarak zamanlanıp zamanlanmayacağını tanımlayan bir bayrak alır. |
