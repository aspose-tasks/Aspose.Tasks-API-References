## Aspose::Tasks::Connectivity namespace

Bu türleri, Microsoft Project Server veritabanları (MspDbSettings), Primavera veritabanları (PrimaveraDbSettings), MPD dosyaları (MpdSettings) veya genel veritabanı kaynakları (DbSettings) için bağlantıları yapılandırmak amacıyla kullanın. Ad alanı, Aspose.Tasks veri çıkarma ve manipülasyon özellikleriyle sorunsuz entegrasyon için bağlantı yapılandırmasını merkezileştirir.
