## set_ViewSettings {#set_viewsettings}

Render edilecek bir görünüm ( View ) ayarlar. Bu seçeneği, hangi görünümün PDF, HTML veya Image formatlarında kaydedileceğini açıkça belirtmek için kullanabilirsiniz. Bu özellik ayarlıysa, proje kaydedildiğinde Visualization::PresentationFormat özelliği yok sayılır. Görünüm, aşağıdaki ekranlardan biri olmalıdır (( Aspose::Tasks::View::Screen )): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage).
