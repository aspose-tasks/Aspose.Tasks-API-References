## PrimaveraProjectInfo.ExportFlag property

Projenin dışa aktarım bayrağını alır. Bir proje Primavera'da dışa aktarım için seçildiğinde, ExportFlag değeri true olur. Açıkça dışa aktarım için seçilmeyen bazı projeler, dışa aktarılan projeyle ilişkileri nedeniyle bir XER dosyasına aktarılabilir.

```csharp
public bool ExportFlag { get; }
```
