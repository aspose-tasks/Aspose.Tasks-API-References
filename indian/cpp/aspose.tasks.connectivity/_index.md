## Aspose::Tasks::Connectivity namespace

इन प्रकारों का उपयोग Microsoft Project Server डेटाबेस (MspDbSettings), Primavera डेटाबेस (PrimaveraDbSettings), MPD फ़ाइलें (MpdSettings), या सामान्य डेटाबेस स्रोतों (DbSettings) के कनेक्शन को कॉन्फ़िगर करने के लिए करें। यह नेमस्पेस कनेक्टिविटी कॉन्फ़िगरेशन को केंद्रीकृत करता है ताकि Aspose.Tasks डेटा निष्कर्षण और हेरफेर सुविधाओं के साथ सहज एकीकरण हो सके।
