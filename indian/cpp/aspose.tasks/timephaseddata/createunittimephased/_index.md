## CreateUnitTimephased {#createunittimephased}

सामग्री संसाधन के असाइनमेंट के इकाई-आधारित समय-फ़ेज़्ड डेटा के लिए Aspose::Tasks::TimephasedData क्लास का एक नया उदाहरण बनाता और प्रारंभ करता है।

**Returns:** A instance of the Aspose::Tasks::TimephasedData class for cost-based time phased data.

```cpp
CreateUnitTimephased(int32_t uid, System::DateTime start, System::DateTime finish, double units, Aspose::Tasks::TimephasedDataType type)
```

| पैरामीटर | विवरण |
| --- | --- |
| uid | कार्य का UID। |
| शुरू | Start तिथि-समय। |
| समाप्ति | समाप्ति तिथि-समय। |
| इकाइयाँ | इकाइयों की संख्या। |
| type | समय-फ़ेज़्ड डेटा प्रकार। |
