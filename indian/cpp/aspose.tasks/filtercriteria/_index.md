## FilterCriteria class

MSP दृश्य में प्रदर्शित होने के लिए कार्यों या संसाधनों को पूरा करना आवश्यक मानदंड निर्धारित करता है।

## विधियाँ

| नाम | विवरण |
| --- | --- |
| [get_CriteriaRows](./get_criteriarows/) | चाइल्ड FilterCriteria पंक्तियों की सूची प्राप्त करता है। यदि फ़िल्टर में एक से अधिक मानदंड पंक्तियाँ हैं तो And ऑपरेटर का प्रभाव यह है कि दोनों पंक्तियों के मानदंड पूरे होने चाहिए ताकि कार्य या संसाधन इस फ़िल्टर के परिणामस्वरूप प्रदर्शित हो सके। Or ऑपरेटर का प्रभाव यह है कि किसी एक पंक्ति के मानदंड पूरे होने चाहिए। |
| [get_Field](./get_field/) | बदलने के लिए एक फ़ील्ड प्राप्त करता है। |
| [get_Operation](./get_operation/) | फ़िल्टर में FieldName, Test और Value के साथ स्थापित मानदंड को प्राप्त करता है जो अन्य मानदंडों से संबंधित है। |
| [get_Test](./get_test/) | फ़िल्टर के चयन मानदंड के रूप में कार्य करने वाले FieldName और Value के बीच किए गए तुलना प्रकार को प्राप्त करता है। FilterComparisonType |
| [get_Values](./get_values/) | FieldName द्वारा निर्दिष्ट फ़ील्ड के मान के साथ तुलना करने के लिए ऑब्जेक्ट मान प्राप्त करता है। |
| [IsFieldValue](./isfieldvalue/) | यह प्राप्त करता है कि FilterCriteria का दायाँ मान एक फ़ील्ड संदर्भ है, स्थिर मान नहीं। |
| [set_Field](./set_field/) | बदलने के लिए एक फ़ील्ड सेट करता है। |
| [set_Operation](./set_operation/) | फ़िल्टर में FieldName, Test और Value के साथ स्थापित मानदंड को सेट करता है जो अन्य मानदंडों से संबंधित है। |
| [set_Test](./set_test/) | फ़िल्टर के चयन मानदंड के रूप में कार्य करने वाले FieldName और Value के बीच किए गए तुलना प्रकार को सेट करता है। FilterComparisonType |
| [SetValueField](./setvaluefield/) | उस फ़ील्ड को सेट करता है जिसका मान FieldName द्वारा निर्दिष्ट फ़ील्ड के मान के साथ तुलना किया जाएगा। |
| [ToString](./tostring/) | FilterCriteria क्लास के इंस्टेंस का स्ट्रिंग प्रतिनिधित्व लौटाता है। |
