## PrimaveraProjectProperties class

Primavera फ़ाइलों (XER या P6XML) से पढ़े गए प्रोजेक्ट के लिए Primavera-विशिष्ट गुणों का प्रतिनिधित्व करता है।

## विधियाँ

| नाम | विवरण |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | वर्तमान प्रोजेक्ट के बेसलाइन प्रोजेक्ट्स की एरे प्राप्त करता है। यह उन प्रोजेक्ट्स पर लागू होता है जो निर्यातित बेसलाइन वाली Primavera XML फ़ाइलों से पढ़े गए हैं। |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | वर्तमान बेसलाइन प्रोजेक्ट का Id प्राप्त करता है। यह उन प्रोजेक्ट्स पर लागू होता है जो निर्यातित बेसलाइन वाली Primavera XML फ़ाइलों से पढ़े गए हैं। |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | एक फ़्लैग प्राप्त करता है जो निर्धारित करता है कि प्रोजेक्ट्स के बीच एक्टिविटी रिलेशनशिप को अनदेखा किया जाए या नहीं। |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | एक फ़्लैग प्राप्त करता है जो निर्धारित करता है कि प्रोजेक्ट शेड्यूल करते समय एक्टिविटीज़ को क्रिटिकल के रूप में चिह्नित किया जाना चाहिए या नहीं। |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | एक विकल्प प्राप्त करता है जो निर्धारित करता है कि Primavera प्रोजेक्ट्स में रिलेशनशिप लैग शेड्यूल करने के लिए कौन सा कैलेंडर उपयोग किया जाए। |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | एक फ़्लैग प्राप्त करता है जो निर्धारित करता है कि एक्टिविटी समाप्ति तिथियों को अपेक्षित समाप्ति तिथियों के रूप में शेड्यूल किया जाना चाहिए या नहीं। |
