## ResourceCollection class

| नाम | विवरण |
| --- | --- |
| [Add (3 overloads)](./add/) | प्रोजेक्ट संसाधन संग्रह के अंतिम स्थान पर नया संसाधन जोड़ता है। |
| [Clear](./clear/) | सीधे साफ़ करना समर्थित नहीं है, यह मेथड केवल NotSupportedException फेंकता है। |
| [get_Count](./get_count/) | ResourceCollection में शामिल तत्वों की संख्या प्राप्त करता है। |
| [get_ParentProject](./get_parentproject/) | ResourceCollection ऑब्जेक्ट के पैरेंट प्रोजेक्ट को प्राप्त करता है। |
| [GetById](./getbyid/) | निर्दिष्ट id वाला संसाधन लौटाता है। |
| [GetByUid](./getbyuid/) | निर्दिष्ट Uid वाला संसाधन लौटाता है। |
| [GetEnumerator](./getenumerator/) | इस संग्रह के लिए एक एन्यूमरेटर लौटाता है। |
| [idx_get](./idx_get/) | निर्दिष्ट इंडेक्स पर तत्व लौटाता है। |
| [idx_set](./idx_set/) | निर्दिष्ट इंडेक्स पर तत्व लौटाता है। |
| [Remove](./remove/) | यह ICollection के Remove मेथड की स्टब इम्प्लीमेंटेशन है, जो केवल NotSupportedException फेंकती है। |
| [ToList](./tolist/) | ResourceCollection ऑब्जेक्ट को संसाधन ऑब्जेक्ट्स की सूची में परिवर्तित करता है। |
