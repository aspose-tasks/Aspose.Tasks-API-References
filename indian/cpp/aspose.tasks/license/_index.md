## License class

घटक को लाइसेंस करने के लिए मेथड प्रदान करता है।

इस उदाहरण में, MyLicense.lic नाम की लाइसेंस फ़ाइल को खोजने का प्रयास किया जाएगा, पहले उस फ़ोल्डर में जो घटक को शामिल करता है, फिर कॉलिंग असेंबली को शामिल करने वाले फ़ोल्डर में, फिर एंट्री असेंबली के फ़ोल्डर में और अंत में कॉलिंग असेंबली के एम्बेडेड रिसोर्सेज़ में।

```cpp
[C#]
 
License license = new License();
license.SetLicense("MyLicense.lic");
 
 
[Visual Basic]
 
Dim license As license = New license
License.SetLicense("MyLicense.lic")
```

</ms> <java> घटक जार फ़ाइल:

```cpp
License license = new License();
license.setLicense("MyLicense.lic");
```

</java>
