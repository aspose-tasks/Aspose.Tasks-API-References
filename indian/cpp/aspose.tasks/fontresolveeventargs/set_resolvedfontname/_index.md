## set_ResolvedFontName {#set_resolvedfontname}

समाधान किए गए फ़ॉन्ट का नाम सेट करता है। इसे दृश्य को रेंडर करने के लिए उपयोग किए जाने वाले फ़ॉन्ट को नियंत्रित करने के लिए सेट किया जा सकता है।

**Returns:** Name of the requested font if font is found or name of fallback font or null if font cannot be found.

```cpp
set_ResolvedFontName(const System::String & value)
```
