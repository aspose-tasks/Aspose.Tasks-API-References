## OleObjectCollection class

OleObject क्लास के इंस्टेंस को शामिल करने वाले संग्रह का प्रतिनिधित्व करता है।

## विधियाँ

| नाम | विवरण |
| --- | --- |
| [Clear](./clear/) | संग्रह को साफ़ करता है। इन परिवर्तनों को स्थायी बनाने के लिए project.Save को नए MPPSaveOptions { WriteViewData = true; } के साथ कॉल किया जाना चाहिए। |
| [GetEnumerator](./getenumerator/) | इस संग्रह के लिए एक एन्यूमरेटर लौटाता है। |
| [ToList](./tolist/) | OleObjectCollection क्लास के इंस्टेंस को OleObject क्लास के इंस्टेंसों वाली सूची में परिवर्तित करता है। |
