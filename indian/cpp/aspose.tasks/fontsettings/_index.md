## FontSettings class

प्रोजेक्ट के दृश्य को रेंडर करने के दौरान उपयोग किए जाने वाले फ़ॉन्ट सेटिंग्स निर्दिष्ट करता है।

## विधियाँ

| नाम | विवरण |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | रेंडरिंग के लिए डिफ़ॉल्ट (या फॉलबैक) फ़ॉन्ट प्राप्त करता है। |
| [get_FontResolveCallback](./get_fontresolvecallback/) | एक कॉलबैक प्राप्त करता है जिसका उपयोग हल किए गए फ़ॉन्ट को अनुकूलित करने के लिए किया जा सकता है। |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | रेंडरिंग के लिए डिफ़ॉल्ट फ़ॉन्ट का उपयोग अनिवार्य है या नहीं, यह दर्शाने वाला मान प्राप्त करता है। |
| [set_DefaultFontName](./set_defaultfontname/) | रेंडरिंग के लिए डिफ़ॉल्ट (या फॉलबैक) फ़ॉन्ट सेट करता है। |
| [set_FontResolveCallback](./set_fontresolvecallback/) | एक कॉलबैक सेट करता है जिसका उपयोग हल किए गए फ़ॉन्ट को अनुकूलित करने के लिए किया जा सकता है। |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | एक मान सेट करता है जो दर्शाता है कि रेंडरिंग के लिए डिफ़ॉल्ट फ़ॉन्ट का उपयोग करना चाहिए या नहीं। |
| [SetFontFolders](./setfontfolders/) | फ़ोल्डर सेट करता है जहाँ Aspose.Tasks प्रोजेक्ट के दृश्य को रेंडर करते समय TrueType फ़ॉन्ट खोजता है। |
