## CheckPropAndGet {#checkpropandget}

इस कंटेनर में जिस मान पर प्रॉपर्टी मैप की गई है, वह मान लौटाता है। यदि इस कंटेनर में रिकॉर्ड ProjectItem मौजूद नहीं है, तो इसे डिफ़ॉल्ट मान के साथ जोड़ा जाएगा और डिफ़ॉल्ट मान लौटाया जाएगा।

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| पैरामीटर | विवरण |
| --- | --- |
| key | निर्दिष्ट प्रॉपर्टी। |
