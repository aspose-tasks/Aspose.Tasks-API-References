## SaveOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

यह एक सारभूत बेस क्लास है जो उन क्लासों के लिए है जो उपयोगकर्ता को किसी प्रोजेक्ट को विशेष फॉर्मेट में सहेजते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देती है।

SaveOptions क्लास से किसी भी व्युत्पन्न क्लास की एक इंस्टेंस को स्ट्रीम Save या स्ट्रिंग Save ओवरलोड्स को पास किया जाता है ताकि उपयोगकर्ता दस्तावेज़ सहेजते समय कस्टम विकल्प निर्धारित कर सके।
