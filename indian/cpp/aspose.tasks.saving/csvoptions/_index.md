## CsvOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

प्रोजेक्ट को CSV में सहेजते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देता है।

## कंस्ट्रक्टर्स

| नाम | विवरण |
| --- | --- |
| [CsvOptions](./csvoptions/) | CsvOptions क्लास का एक नया इंस्टेंस इनिशियलाइज़ करता है जिसका उपयोग प्रोजेक्ट को CSV फ़ॉर्मेट में सहेजने के लिए किया जा सकता है। |

| नाम | विवरण |

| [get_TextDelimiter](./get_textdelimiter/) | टेक्स्ट डिलिमिटर प्राप्त करता है। |

| [set_TextDelimiter](./set_textdelimiter/) | टेक्स्ट डिलिमिटर सेट करता है। |
