## RiskPatternCollection class

RiskPattern क्लास की इंस्टेंसेज़ को सम्मिलित करने वाले संग्रह का प्रतिनिधित्व करता है।

## विधियाँ

| नाम | विवरण |
| --- | --- |
| [Add](./add/) | इस संग्रह में RiskPattern वर्ग की एक इंस्टेंस जोड़ता है। |
| [Clear](./clear/) | इस संग्रह से सभी आइटम हटाता है। |
| [Contains](./contains/) | यदि निर्दिष्ट आइटम इस संग्रह में पाया जाता है तो true लौटाता है; अन्यथा false। |
| [CopyTo](./copyto/) | इस संग्रह के तत्वों को निर्दिष्ट एरे में कॉपी करता है, निर्दिष्ट एरे इंडेक्स से शुरू करते हुए। |
| [get_Count](./get_count/) | इस संग्रह में मौजूद तत्वों की संख्या प्राप्त करता है। |
| [get_IsReadOnly](./get_isreadonly/) | एक मान प्राप्त करता है जो दर्शाता है कि यह संग्रह केवल-पढ़ने योग्य है या नहीं; अन्यथा, false। |
| [GetEnumerator](./getenumerator/) | इस संग्रह के लिए एक एन्यूमरेटर लौटाता है। |
| [idx_get](./idx_get/) | निर्दिष्ट कार्य के लिए RiskPattern वर्ग की इंस्टेंस प्राप्त करता है। |
| [Remove](./remove/) | इस संग्रह से किसी विशिष्ट वस्तु की पहली उपस्थिति हटाता है। |
