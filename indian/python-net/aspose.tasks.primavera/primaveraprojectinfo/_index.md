## PrimaveraProjectInfo class

Primavera फ़ॉर्मेट से लोड किए गए प्रोजेक्ट के बारे में संक्षिप्त जानकारी दर्शाता है।

PrimaveraProjectInfo प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| uid | प्रोजेक्ट का Uid प्राप्त करता है। |
| name | प्रोजेक्ट का नाम प्राप्त करता है। |
| short_name | प्रोजेक्ट का शॉर्ट नाम (Project ID) प्राप्त करता है। |
| export_flag | प्रोजेक्ट के निर्यात फ़्लैग को प्राप्त करता है। जब Primavera में निर्यात के लिए कोई प्रोजेक्ट चुना जाता है, तो उसका ExportFlag true होता है।<br/>            कुछ प्रोजेक्ट जो स्पष्ट रूप से निर्यात के लिए नहीं चुने गए हैं, उनके निर्यातित प्रोजेक्ट के संबंध के कारण XER फ़ाइल में निर्यात हो सकते हैं। |
