## RiskItemStatistics class

विश्लेषित प्रोजेक्ट के कार्य के लिए सांख्यिकीय डेटा संग्रहीत करने वाले आइटम को दर्शाता है।

RiskItemStatistics प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| item_type | [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) एन्ह्यूमरेशन का एक उदाहरण प्राप्त करता है। |
| minimum | Monte Carlo सिमुलेशन के दौरान उत्पन्न न्यूनतम मान प्राप्त करता है। |
| maximum | Monte Carlo सिमुलेशन के दौरान उत्पन्न अधिकतम मान प्राप्त करता है। |
| expected_value | जोखिम आइटम का अपेक्षित मान प्राप्त करता है। |
| standard_deviation | जोखिम आइटम का मानक विचलन प्राप्त करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
| get_percentile(percent) | एक मान प्राप्त करता है जिसके नीचे उत्पन्न नमूनों का एक निर्दिष्ट प्रतिशत गिरता है। |
