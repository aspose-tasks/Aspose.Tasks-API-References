## RiskAnalyzer class

निर्दिष्ट जोखिम विश्लेषण सेटिंग्स के आधार पर मोन्टे कार्लो सिमुलेशन करता है।

RiskAnalyzer प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| RiskAnalyzer(settings) | नया उदाहरण प्रारंभ करता है [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) वर्ग का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| settings | प्राप्त करता है या सेट करता है [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) वर्ग का उदाहरण जो जोखिम विश्लेषण के लिए आवश्यक सेटिंग्स को परिभाषित करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
| analyze(project) | निर्दिष्ट प्रोजेक्ट के लिए जोखिम विश्लेषण करता है। विश्लेषण मोन्टे कार्लो सिमुलेशन पर आधारित है और परिणाम [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) वर्ग का एक उदाहरण है। |
