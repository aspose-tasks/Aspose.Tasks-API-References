## CustomProjectProperty class

एक कस्टम प्रॉपर्टी का प्रतिनिधित्व करता है।

यह CustomProjectProperty प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| name | प्रॉपर्टी का नाम प्राप्त करता है। |
| value | प्रॉपर्टी का मान प्राप्त करता है या सेट करता है। |
| type | प्रॉपर्टी का प्रकार प्राप्त करता है। |
