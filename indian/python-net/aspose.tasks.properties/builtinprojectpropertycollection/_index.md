## BuiltInProjectPropertyCollection class

बिल्ट-इन प्रोजेक्ट प्रॉपर्टीज़ का एक संग्रह दर्शाता है।

यह BuiltInProjectPropertyCollection प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| title | प्रोजेक्ट का शीर्षक प्राप्त करता है या सेट करता है। |
| subject | प्रोजेक्ट का विषय प्राप्त करता है या सेट करता है। |
| लेखक | प्रोजेक्ट के लेखक को प्राप्त करता है या सेट करता है। |
| manager | प्रोजेक्ट के प्रबंधक को प्राप्त करता है या सेट करता है। |
| company | प्रोजेक्ट की कंपनी को प्राप्त करता है या सेट करता है। |
| category | प्रोजेक्ट की श्रेणी को प्राप्त करता है या सेट करता है। |
| keywords | प्रोजेक्ट के कीवर्ड्स को प्राप्त करता है या सेट करता है। |
| comments | प्रोजेक्ट की टिप्पणियों को प्राप्त करता है या सेट करता है। |
| hyperlink_base | प्रोजेक्ट के हाइपरलिंक बेस को प्राप्त करता है या सेट करता है। |
| नाम |  |
