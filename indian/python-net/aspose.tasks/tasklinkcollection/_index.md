## TaskLinkCollection class

एक संग्रह में [Task](/tasks/python-net/aspose.tasks/task/) वस्तुओं को दर्शाता है।

TaskLinkCollection प्रकार निम्नलिखित सदस्यों को उजागर करता है:

| नाम | विवरण |
| :- | :- |
| parent_project | ResourceAssignmentCollection ऑब्जेक्ट के पैरेंट प्रोजेक्ट को प्राप्त करता है। |

| add(pred, succ, link_type) | [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) का एक उदाहरण लौटाता है जो TaskLinkCollection ऑब्जेक्ट में जोड़ा गया है। |

| to_list() | TaskLinkCollection ऑब्जेक्ट को [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) ऑब्जेक्ट्स की सूची में परिवर्तित करता है। |
