## FontSettings class

परियोजना के दृश्य को रेंडर करने के समय उपयोग किए जाने वाले फ़ॉन्ट सेटिंग्स निर्दिष्ट करता है।

यह FontSettings प्रकार निम्नलिखित सदस्य उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| FontSettings() | FontSettings वर्ग का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| default_font_name | रेंडरिंग के लिए डिफ़ॉल्ट (या फॉलबैक) फ़ॉन्ट प्राप्त करता है या सेट करता है। |
| use_project_default_font | रेंडरिंग के लिए डिफ़ॉल्ट फ़ॉन्ट का उपयोग करना आवश्यक है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
| set_font_folders(font_folders, recursive) | परियोजना के दृश्य को रेंडर करते समय Aspose.Tasks जहाँ TrueType फ़ॉन्ट खोजता है, उन फ़ोल्डरों को सेट करता है। |
