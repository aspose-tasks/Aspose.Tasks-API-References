## OutlineValue class

एक आउटलाइन मान का प्रतिनिधित्व करता है।

OutlineValue प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| OutlineValue() | OutlineValue क्लास का एक नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| value_id | परियोजना के भीतर एक रूपरेखा कोड मान का अद्वितीय Id प्राप्त करता है या सेट करता है। |
| value_guid | पूरे प्रोजेक्ट में इस मान को अन्य मानों में पहचानने वाला GUID प्राप्त करता है। |
| type | आउटलाइन कोड प्रकार को प्राप्त करता है या सेट करता है। |
| parent_value_id | आउटलाइन कोड के पैरेंट नोड की Id को प्राप्त करता है या सेट करता है। |
| value | वास्तविक मान को प्राप्त करता है या सेट करता है। |
| duration_value | यदि प्रकार Duration है तो अवधि को प्राप्त करता है या सेट करता है। |
| description | आउटलाइन मान का विवरण प्राप्त करता है या सेट करता है। |
| is_collapsed | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि आउटलाइन मान संकुचित है या नहीं। |
