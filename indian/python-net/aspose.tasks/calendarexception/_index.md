## CalendarException class

कैलेंडर में असाधारण समय अवधि का प्रतिनिधित्व करता है।

CalendarException प्रकार निम्नलिखित सदस्य उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| CalendarException() | एक नया उदाहरण प्रारंभ करता है [CalendarException](/tasks/python-net/aspose.tasks/calendarexception/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| entered_by_occurrences | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि पुनरावृत्ति की सीमा घटनाओं की संख्या दर्ज करके परिभाषित है या नहीं।<br/>            False यह निर्दिष्ट करता है कि पुनरावृत्ति की सीमा समाप्ति तिथि दर्ज करके परिभाषित है। |
| from_date | अपवाद समय की शुरुआत प्राप्त करता है या सेट करता है। |
| to_date | अपवाद समय का अंत प्राप्त करता है या सेट करता है। |
| occurrences | कैलेंडर अपवाद के लिए वैध घटनाओं की संख्या प्राप्त करता है या सेट करता है। |
| name | अपवाद का नाम प्राप्त करता है या सेट करता है। |
| type | अपवाद प्रकार प्राप्त करता है या सेट करता है। |
| period | अपवाद के लिए पुनरावृत्ति अवधि प्राप्त करता है या सेट करता है। |
| days_of_week | इस ऑब्जेक्ट के लिए DayTypeCollection प्राप्त करता है।<br/>            वह सप्ताह के दिन जिन पर अपवाद वैध है। |
| month_item | उस महीने के आइटम को प्राप्त करता है या सेट करता है जिसके लिए अपवाद पुनरावृत्ति निर्धारित है। |
| month_position | एक महीने के भीतर महीने के आइटम की स्थिति प्राप्त करता है या सेट करता है। |
| महीना | उस महीने को प्राप्त करता है या सेट करता है जिसके लिए अपवाद पुनरावृत्ति निर्धारित है। |
| month_day | उस महीने के दिन को प्राप्त करता है या सेट करता है जिस पर अपवाद पुनरावृत्ति निर्धारित है। |
| day_working | निर्दिष्ट तिथि या दिन प्रकार कार्यशील है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| working_times | WorkingTimeCollection ऑब्जेक्ट प्राप्त करता है या सेट करता है।<br/>            कार्यदिवस पर कार्य किए गए समय को परिभाषित करने वाला कार्य समय संग्रह। |
| parent_calendar | इस वस्तु के लिए पैरेंट कैलेंडर प्राप्त करता है। |
