## Metered class

मीटरयुक्त कुंजी सेट करने के लिए विधियाँ प्रदान करता है।

यह Metered प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Metered() | Metered क्लास का नया उदाहरण आरंभ करता है |
## Methods
| नाम | विवरण |
| :- | :- |
| set_metered_key(public_key, private_key) | मेटर्ड सार्वजनिक और निजी कुंजियों को सेट करता है। |
| reset_metered_key() | पहले सेट की गई लाइसेंस को हटाता है। |
| get_consumption_credit() | उपभोग क्रेडिट प्राप्त करता है। |
| get_consumption_quantity() | उपभोग फ़ाइल आकार प्राप्त करता है। |
| is_licensed() | जाँचता है कि उत्पाद Metered लाइसेंस का उपयोग करके सफलतापूर्वक लाइसेंस किया गया है या नहीं। |
