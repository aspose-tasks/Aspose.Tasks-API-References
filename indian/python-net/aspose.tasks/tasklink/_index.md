## TaskLink class

एक पूर्ववर्ती लिंक का प्रतिनिधित्व करता है।

TaskLink प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| is_cross_project | किसी पूर्ववर्ती का किसी अन्य प्रोजेक्ट का हिस्सा है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| cross_project_name | बाहरी पूर्ववर्ती प्रोजेक्ट को प्राप्त करता है या सेट करता है। |
| link_lag | मिनट के दशमलव हिस्से या प्रतिशत में देरी को प्राप्त करता है या सेट करता है। |
| link_lag_time_span | LagFormat के आधार पर देरी की अवधि को प्राप्त करता है या सेट करता है। |
| lag_format | देरी के स्वरूप को व्यक्त करने के लिए फ़ॉर्मेट को प्राप्त करता है या सेट करता है। |
| pred_task | पूर्ववर्ती कार्य को प्राप्त करता है या सेट करता है। |
| succ_task | उत्तराधिकारी कार्य को प्राप्त करता है या सेट करता है। |
| link_type | लिंक के प्रकार को प्राप्त करता है या सेट करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
