## Filter class

प्रोजेक्ट में एक फ़िल्टर का प्रतिनिधित्व करता है।

Filter प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Filter() | Filter वर्ग का एक नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| filter_type | फ़िल्टर का प्रकार प्राप्त करता है। |
| name | फ़िल्टर ऑब्जेक्ट का नाम प्राप्त करता है या सेट करता है। |
| show_in_menu | प्रोजेक्ट व्यू टैब के रिबन में फ़िल्टर ड्रॉप‑डाउन सूची में फ़िल्टर नाम दिखाने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| show_related_summary_rows | फ़िल्टर के लिए संबंधित सारांश पंक्तियों के प्रदर्शित होने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| index | फ़िल्टरों वाले ऑब्जेक्ट में एक [Filter](/tasks/python-net/aspose.tasks/filter/) ऑब्जेक्ट का सूचकांक प्राप्त करता है। |
| uid | फ़िल्टर की अद्वितीय पहचानकर्ता प्राप्त करता है। |
| criteria | MSP दृश्य में प्रदर्शित होने के लिए कार्यों या संसाधनों को पूरा करना आवश्यक मानदंड प्राप्त करता है या सेट करता है। |
## Methods
| नाम | विवरण |
| :- | :- |

| equals(other) | यह दर्शाने वाला मान लौटाता है कि यह इंस्टेंस निर्दिष्ट AssignmentBaseline ऑब्जेक्ट के बराबर है या नहीं। |
