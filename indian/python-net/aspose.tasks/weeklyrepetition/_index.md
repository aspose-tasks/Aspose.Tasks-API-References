## WeeklyRepetition class

WeeklyRepetition प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| WeeklyRepetition() | निम्नलिखित [WeeklyRepetition](/tasks/python-net/aspose.tasks/weeklyrepetition/) वर्ग की एक नई इंस्टेंस को प्रारंभ करता है। |

| नाम | विवरण |
| :- | :- |
| repetition_interval | घटनाओं के बीच सप्ताहों में अंतराल को दर्शाने वाले सप्ताहों की संख्या को प्राप्त करता है या सेट करता है। |
| week_days | सप्ताह के दिनों का प्रकार प्राप्त करता है या सेट करता है। |
