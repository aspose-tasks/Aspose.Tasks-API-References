## ProjectInfo class

Project Online पर उपलब्ध प्रकाशित प्रोजेक्ट के बारे में संक्षिप्त जानकारी।

ProjectInfo प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| ProjectInfo() | [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/) क्लास का नया इंस्टेंस इनिशियलाइज़ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| id | प्रोजेक्ट की विशिष्ट पहचानकर्ता प्राप्त करता है। |
| name | प्रोजेक्ट का नाम प्राप्त करता है। |
| created_date | प्रोजेक्ट के निर्मित होने की तिथि और समय प्राप्त करता है। |
| is_checked_out | यह दर्शाने वाला मान प्राप्त करता है कि प्रोजेक्ट चेक आउट है या नहीं। |
| last_published_date | प्रोजेक्ट के प्रकाशित होने की सबसे हालिया तिथि प्राप्त करता है। |
| last_saved_date | प्रोजेक्ट के सेव होने की सबसे हालिया तिथि प्राप्त करता है। |
| description | प्रोजेक्ट का विवरण प्राप्त करता है। |
