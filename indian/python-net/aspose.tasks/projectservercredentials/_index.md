## ProjectServerCredentials class

Project Online या ऑन-प्रिमाइसेस Project Server इंस्टेंस से कनेक्ट करने के लिए उपयोग किए जाने वाले क्रेडेंशियल्स।

ProjectServerCredentials प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | SharePoint साइट के URL और वैध SPOIDCRL प्राधिकरण टोकन का उपयोग करके [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) क्लास का नया उदाहरण प्रारंभ करता है। |
| ProjectServerCredentials(site_url, user_name, password) | SharePoint साइट के URL और वैध SPOIDCRL प्राधिकरण टोकन का उपयोग करके [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) क्लास का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| site_url | SharePoint साइट पर PWA का URL या ऑन-प्रेमाइज़ प्रोजेक्ट सर्वर का URL प्राप्त करता है।<br/>            उदाहरण के लिए, https://your_company_name.sharepoint.com/sites/pwa\"; |
| auth_token | SharePoint इंस्टेंस के लिए प्राधिकरण टोकन प्राप्त करता है। |
| user_name | SharePoint साइट के लिए उपयोगकर्ता नाम प्राप्त करता है। |
