## RateCollection class

[Rate](/tasks/python-net/aspose.tasks/rate/) ऑब्जेक्ट्स को शामिल करने वाले संग्रह को दर्शाता है।

RateCollection प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| count | RateCollection में सम्मिलित तत्वों की संख्या प्राप्त करता है। |
| is_read_only | यह दर्शाने वाला मान प्राप्त करता है कि यह संग्रह केवल-पढ़ने योग्य है या नहीं। |
| parent_resource | इस संग्रह के लिए पैरेंट [Resource](/tasks/python-net/aspose.tasks/resource/) ऑब्जेक्ट प्राप्त करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
| add(rates_from) | इस संग्रह में एक नया [Rate](/tasks/python-net/aspose.tasks/rate/) उदाहरण जोड़ता है। |
| add(rates_from, type) | इस संग्रह में एक नया [Rate](/tasks/python-net/aspose.tasks/rate/) उदाहरण जोड़ता है। |
| to_list() | [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) ऑब्जेक्ट को [Rate](/tasks/python-net/aspose.tasks/rate/) ऑब्जेक्ट्स की सूची में परिवर्तित करता है। |
| to_list(type) | [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) ऑब्जेक्ट को निर्दिष्ट [RateType](/tasks/python-net/aspose.tasks/ratetype/) प्रकार द्वारा फ़िल्टर की गई [Rate](/tasks/python-net/aspose.tasks/rate/) ऑब्जेक्ट्स की सूची में परिवर्तित करता है। |
| remove(item) | इस संग्रह से Rate उदाहरण को हटाता है। |
