## FontSavingArgs class

यह क्लास बाहरी फ़ॉन्ट फ़ाइल के सहेजने से संबंधित डेटा सेट का प्रतिनिधित्व करती है जो<br/>              HTML प्रारूप में रूपांतरण के दौरान होती है।

FontSavingArgs प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| FontSavingArgs() | FontSavingArgs क्लास की नई इंस्टेंस को प्रारंभ करता है |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| file_name | कस्टम मेथड के कोड तक कन्वर्टर से जाने वाले अनुमानित फ़ाइल नाम को प्राप्त करता है या सेट करता है।<br/>             इसे कस्टम कोड में यह तय करने के लिए उपयोग किया जा सकता है कि फ़ाइल को कैसे प्रोसेस किया जाए या कहाँ सहेजा जाए। |
| keep_stream_open | संसाधन सहेजने के समाप्त होने के बाद स्ट्रीम को खुला रखने का संकेत देने वाला मान प्राप्त करता है या सेट करता है। |
| stream | सहेजी गई फ़ाइल की बाइनरी सामग्री को प्राप्त करता है या सेट करता है। |
| uri | संसाधन URI को प्राप्त करता है या सेट करता है। |
