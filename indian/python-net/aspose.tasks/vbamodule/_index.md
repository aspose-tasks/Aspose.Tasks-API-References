## VbaModule class

एक VBA मॉड्यूल का प्रतिनिधित्व करता है।

VbaModule प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| गुण | मॉड्यूल के गुणों का संग्रह प्राप्त करता है। |
| name | VBA मॉड्यूल का नाम प्राप्त करता है |
| type | मॉड्यूल का प्रकार प्राप्त करता है। |
| source_code | VBA मॉड्यूल का स्रोत कोड प्राप्त करता है या सेट करता है |
## Methods
| नाम | विवरण |
| :- | :- |
| create_procedural_module(name) | VbaModuleType.ProceduralModule प्रकार के साथ [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) का एक उदाहरण बनाता है। |
| create_class_module(name) | VbaModuleType.ClassModule प्रकार के साथ [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) का एक उदाहरण बनाता है। |
