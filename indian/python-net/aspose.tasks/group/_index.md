## Group class

एक समूह परिभाषा का प्रतिनिधित्व करता है।<br/>            एक Group ऑब्जेक्ट ResourceGroups संग्रह या TaskGroups संग्रह का सदस्य होता है।

Group प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Group() | निम्नलिखित [Group](/tasks/python-net/aspose.tasks/group/) वर्ग की एक नई इंस्टेंस को प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| name | Group ऑब्जेक्ट का नाम प्राप्त करता है या सेट करता है। |
| uid | एक समूह की विशिष्ट पहचानकर्ता प्राप्त करता है। |
| show_summary | समूह के लिए सारांश पंक्तियों को प्रदर्शित किया जाता है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| maintain_hierarchy | समूह के भीतर उपकार्य के लिए सभी स्तरों के सारांश कार्य दिखाने चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| show_in_menu | प्रोजेक्ट रिबन में समूह ड्रॉप-डाउन सूची में समूह का नाम दिखाता है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| group_assignments | कार्य के बजाय असाइनमेंट को समूहित किया जाना चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| group_criteria | समूह परिभाषा में फ़ील्ड को दर्शाने वाले GroupCriteria संग्रह को प्राप्त करता है या सेट करता है। |
