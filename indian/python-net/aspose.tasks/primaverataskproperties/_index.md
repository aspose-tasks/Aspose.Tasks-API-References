## PrimaveraTaskProperties class

Primavera फ़ाइलों (XER या P6XML) से पढ़े गए टास्क के लिए Primavera-विशिष्ट गुणों का प्रतिनिधित्व करता है।

PrimaveraTaskProperties प्रकार निम्नलिखित सदस्य उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| sequence_number | WBS आइटम (सारांश कार्य) का क्रम संख्या प्राप्त करता है या सेट करता है। यह Primavera में सारांश कार्यों को क्रमबद्ध करने के लिए उपयोग किया जाता है। |
| activity_id | एक activity id फ़ील्ड प्राप्त करता है - Primavera द्वारा उपयोग किया जाने वाला कार्य का अद्वितीय पहचानकर्ता। |
| remaining_early_finish | शेष प्रारंभिक समाप्ति तिथि प्राप्त करता है - वह तिथि जब गतिविधि के शेष कार्य को समाप्त करने के लिए निर्धारित किया गया है। |
| remaining_early_start | शेष प्रारंभिक प्रारंभ तिथि प्राप्त करता है - वह तिथि जब गतिविधि के शेष कार्य को शुरू करने के लिए निर्धारित किया गया है। |
| remaining_late_start | शेष देर से प्रारंभ तिथि प्राप्त करता है। |
| remaining_late_finish | शेष देर से समाप्ति तिथि प्राप्त करता है। |
| raw_duration_type | गतिविधि के 'Duration Type' फ़ील्ड का कच्चा पाठ प्रतिनिधित्व (जैसे स्रोत फ़ाइल में) प्राप्त करता है। |
| duration_type | गतिविधि के 'Duration Type' फ़ील्ड का मान प्राप्त करता है। |
| raw_activity_type | गतिविधि के 'Activity Type' फ़ील्ड का कच्चा पाठ प्रतिनिधित्व (जैसे स्रोत फ़ाइल में) प्राप्त करता है। |
| activity_type | 'Activity Type' फ़ील्ड का मान प्राप्त करता है। |
| percent_complete_type | गतिविधि के '% Complete Type' फ़ील्ड का मान प्राप्त करता है। |
| raw_complete_percent_type | गतिविधि के '% Complete Type' फ़ील्ड का कच्चा पाठ प्रतिनिधित्व (जैसे स्रोत फ़ाइल में) प्राप्त करता है। |
| raw_status | गतिविधि के 'Status' फ़ील्ड की कच्चा पाठ प्रतिनिधित्व (जैसे स्रोत फ़ाइल में) प्राप्त करता है। |
| physical_percent_complete | Physical Percent Complete का मान प्राप्त करता है। |
| duration_percent_complete | duration percent complete का मान प्राप्त करता है। |
| units_percent_complete | units percent complete का मान प्राप्त करता है। |
| actual_labor_units | actual labor units का मान प्राप्त करता है। |
| actual_non_labor_units | actual non labor units का मान प्राप्त करता है। |
| remaining_labor_units | remaining labor units का मान प्राप्त करता है। |
| remaining_non_labor_units | remaining non labor units का मान प्राप्त करता है। |
| actual_labor_cost | actual labor cost का मान प्राप्त करता है। |
| budgeted_labor_cost | budgeted (or planned) labor cost का मान प्राप्त करता है। |
| actual_nonlabor_cost | actual non labor cost का मान प्राप्त करता है। |
| budgeted_nonlabor_cost | budgeted (or planned) non labor cost का मान प्राप्त करता है। |
| actual_material_cost | वास्तविक सामग्री लागत का मान प्राप्त करता है। |
| budgeted_material_cost | बजटेड (या नियोजित) सामग्री लागत का मान प्राप्त करता है। |
| actual_expense_cost | वास्तविक खर्च लागत का मान प्राप्त करता है। |
| remaining_expense_cost | शेष खर्च लागत का मान प्राप्त करता है। |
| budgeted_expense_cost | बजटेड (या नियोजित) खर्च लागत का मान प्राप्त करता है। |
| actual_total_cost | वास्तविक लागतों का कुल मान प्राप्त करता है। |
| budgeted_total_cost | बजटेड (या नियोजित) लागतों का कुल मान प्राप्त करता है। |
| primary_constraint_type | प्राथमिक प्रतिबंध का प्रकार प्राप्त करता है। |
| primary_constraint_date | प्राथमिक प्रतिबंध की तिथि प्राप्त करता है। |
| secondary_constraint_type | द्वितीयक प्रतिबंध का प्रकार प्राप्त करता है। |
| secondary_constraint_date | द्वितीयक प्रतिबंध की तिथि प्राप्त करता है। |
| planned_duration | मूल या नियोजित अवधि प्राप्त करता है -- कार्य की नियोजित प्रारम्भ तिथि से नियोजित समाप्ति तिथि तक का कुल कार्य समय.. |
