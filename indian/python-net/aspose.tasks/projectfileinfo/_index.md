## ProjectFileInfo class

क्लास इंस्टेंस में प्रोजेक्ट फ़ाइल फ़ॉर्मेट और Microsoft Project के संस्करण की जानकारी होती है जहाँ<br/>            फ़ाइल बनाई गई थी।

यह ProjectFileInfo प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| can_read | यह मान प्राप्त करता है जो दर्शाता है कि क्या परिभाषाएँ Aspose.Tasks को प्रोजेक्ट फ़ाइल को प्रोसेस करने की अनुमति देती हैं। |
| is_password_protected | यह मान प्राप्त करता है जो दर्शाता है कि क्या प्रोजेक्ट पासवर्ड से सुरक्षित है। |
| project_file_format | प्रोजेक्ट फ़ाइल प्रारूप प्राप्त करता है। |
| project_application_info | प्रोजेक्ट फ़ाइल एप्लिकेशन जानकारी प्राप्त करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
