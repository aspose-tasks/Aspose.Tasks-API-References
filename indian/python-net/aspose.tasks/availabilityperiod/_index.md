## AvailabilityPeriod class

संसाधन उपलब्ध होने की अवधि को दर्शाता है।

AvailabilityPeriod प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| AvailabilityPeriod() | एक नया उदाहरण प्रारंभ करता है [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) का। |
| AvailabilityPeriod(available_from, available_to, available_units) | निर्दिष्ट तिथि सीमा और उपलब्ध इकाइयों के साथ [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| available_from | निर्दिष्ट अवधि के लिए जब कोई संसाधन उपलब्ध हो जाता है, तब की तिथि को प्राप्त करता है या सेट करता है। |
| available_to | निर्दिष्ट अवधि के लिए जब कोई संसाधन उपलब्ध होता है, तब की अंतिम तिथि को प्राप्त करता है या सेट करता है। |
| available_units | निर्दिष्ट अवधि के दौरान उपलब्ध रहने वाले संसाधन का प्रतिशत प्राप्त करता है या सेट करता है। |
