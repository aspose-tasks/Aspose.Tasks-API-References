## PrimaveraProjectProperties class

Primavera फ़ाइलों (XER या P6XML) से पढ़े गए प्रोजेक्ट के लिए Primavera-विशिष्ट गुणों का प्रतिनिधित्व करता है।

PrimaveraProjectProperties प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| relationship_lag_calendar | Primavera परियोजनाओं में Relationship Lag को शेड्यूल करने के लिए किस कैलेंडर का उपयोग करना है, यह निर्धारित करने वाला विकल्प प्राप्त करता है। |
| use_expected_finish_dates | यह निर्धारित करने वाला फ़्लैग प्राप्त करता है कि क्या गतिविधि समाप्ति तिथियों को अपेक्षित समाप्ति तिथियों के रूप में शेड्यूल किया जाना चाहिए। |
| make_open_ended_activities_critical | यह निर्धारित करने वाला फ़्लैग प्राप्त करता है कि क्या गतिविधियों को परियोजना शेड्यूल करते समय महत्वपूर्ण के रूप में चिह्नित किया जाना चाहिए। |
| ignore_other_project_relationships | परियोजनाओं के बीच गतिविधि संबंधों को अनदेखा करना है या नहीं, यह निर्धारित करने वाला फ़्लैग प्राप्त करता है। |
| current_baseline_project_id | वर्तमान बेसलाइन प्रोजेक्ट की Id प्राप्त करता है।<br/>            निर्यात किए गए बेसलाइन वाले Primavera XML फ़ाइलों से पढ़े गए प्रोजेक्ट्स पर लागू होता है। |
| baseline_projects | वर्तमान प्रोजेक्ट के बेसलाइन प्रोजेक्ट्स का एरे प्राप्त करता है।<br/>            निर्यात किए गए बेसलाइन वाले Primavera XML फ़ाइलों से पढ़े गए प्रोजेक्ट्स पर लागू होता है। |
| critical_activities_defining_method | क्रिटिकल एक्टिविटीज़ को परिभाषित करने की विधि प्राप्त करता है: सबसे लंबा पथ या टोटल फ़्लोट दृष्टिकोण। |
| critical_total_float_limit | यदि TotalFloat विधि का उपयोग किया जाता है तो क्रिटिकल एक्टिविटीज़ को परिभाषित करने के लिए उपयोग किए जाने वाले थ्रेशोल्ड मान को प्राप्त करता है। |
| short_name | प्रोजेक्ट का शॉर्ट नाम (Project ID) प्राप्त करता है। |
