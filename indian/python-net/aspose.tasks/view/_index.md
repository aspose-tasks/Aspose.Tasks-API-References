## गुणधर्म
| नाम | विवरण |
| :- | :- |
| filter | एकल दृश्य में उपयोग किए जाने वाले फ़िल्टर को प्राप्त करता है या सेट करता है। |
| समूह | एकल दृश्य का समूह प्राप्त करता है या सेट करता है। |

| टेबल | एकल दृश्य की टेबल प्राप्त करता है या सेट करता है। |
| type | एकल दृश्य में आइटम का प्रकार प्राप्त करता है, जैसे कार्य या संसाधन।<br/>            केवल-पढ़ने योग्य [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि Microsoft Project रिबन में View या Other Views ड्रॉप-डाउन सूची में एकल दृश्य का नाम दिखाता है या नहीं। |
| page_info | एक [page_info](/tasks/python-net/aspose.tasks/view/) क्लास का इंस्टेंस प्राप्त करता है। यह mpp फ़ाइल फ़ॉर्मेट में मौजूद पेज सेटअप डेटा का प्रतिनिधित्व करता है। |
| visual_objects_placements | दृश्य में [OleObject](/tasks/python-net/aspose.tasks/oleobject/) की प्लेसमेंट और उपस्थिति दर्शाने वाले ऑब्जेक्ट्स का संग्रह प्राप्त करता है। |
