## RecurringTaskParameters class

प्रोजेक्ट में एक आवर्ती कार्य बनाने के लिए उपयोग किए जाने वाले पैरामीटर सेट को दर्शाता है।

RecurringTaskParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| RecurringTaskParameters() | [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/) क्लास का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| duration | आवर्ती कार्य की एक घटना की अवधि प्राप्त करता है या सेट करता है। |
| ignore_resource_calendar | संसाधन उपलब्ध होने पर भी आवर्ती कार्य को शेड्यूल करने के लिए एक मान प्राप्त करता है या सेट करता है, चाहे वह कभी भी नहीं हो। |
| recurrence_pattern | आवर्ती कार्य के पुनरावृत्ति पैटर्न को प्राप्त करता है या सेट करता है। |
| task_name | आवर्ती कार्य का नाम प्राप्त करता है या सेट करता है। |
