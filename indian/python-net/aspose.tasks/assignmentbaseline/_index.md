## AssignmentBaseline class

संसाधन असाइनमेंट की बेसलाइन को दर्शाता है।

यह AssignmentBaseline प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| AssignmentBaseline() | AssignmentBaseline वर्ग की नई इंस्टेंस को प्रारंभ करता है |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| baseline_number | Baseline डेटा रिकॉर्ड की अद्वितीय संख्या को प्राप्त करता है या सेट करता है। |
| काम | Baseline सहेजे जाने पर संसाधन को सौंपे गए कार्य को प्राप्त करता है या सेट करता है। |
| cost | Baseline सहेजे जाने पर संसाधन की अनुमानित लागत को प्राप्त करता है या सेट करता है। |
| bcws | संसाधन के लिए निर्धारित कार्य की बजट लागत को प्राप्त करता है या सेट करता है। |
| bcwp | परियोजना के लिए अब तक संसाधन द्वारा किए गए कार्य की बजटेड लागत को प्राप्त करता है या सेट करता है। |
| timephased_data | इस वस्तु के लिए [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) इंस्टेंस को प्राप्त करता है या सेट करता है।<br/>            संसाधन असाइनमेंट बेसलाइन से संबंधित समय-फ़ेज़्ड डेटा। |
| शुरू | Baseline सहेजे जाने पर संसाधन असाइनमेंट की निर्धारित प्रारंभ तिथि को प्राप्त करता है या सेट करता है। |
| finish | Baseline सहेजे जाने पर संसाधन असाइनमेंट की निर्धारित समाप्ति तिथि को प्राप्त करता है या सेट करता है। |
