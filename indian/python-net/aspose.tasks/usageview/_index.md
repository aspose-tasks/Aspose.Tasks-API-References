## UsageView class

प्रोजेक्ट में उपयोग दृश्य को दर्शाता है।

UsageView प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| filter | एकल दृश्य में उपयोग किए जाने वाले फ़िल्टर को प्राप्त करता है या सेट करता है। |
| समूह | एकल दृश्य का समूह प्राप्त करता है या सेट करता है। |
| uid | एक दृश्य की अद्वितीय पहचानकर्ता प्राप्त करता है। |
| highlight_filter | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि Microsoft Project एकल दृश्य के लिए फ़िल्टर को हाइलाइट करता है या नहीं। |
| name | एक View ऑब्जेक्ट का नाम प्राप्त करता है या सेट करता है। |
| screen | एकल दृश्य के लिए स्क्रीन प्रकार प्राप्त करता है।<br/>            केवल-पढ़ने योग्य [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | View ऑब्जेक्ट के पैरेंट को प्राप्त करता है।<br/>            केवल-पढ़ने योग्य [Project](/tasks/python-net/aspose.tasks/project/). |
| टेबल | एकल दृश्य की टेबल प्राप्त करता है या सेट करता है। |
| type | एकल दृश्य में आइटम का प्रकार प्राप्त करता है, जैसे कार्य या संसाधन।<br/>            केवल-पढ़ने योग्य [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि Microsoft Project रिबन में View या Other Views ड्रॉप-डाउन सूची में एकल दृश्य का नाम दिखाता है या नहीं। |
| page_info | एक [page_info](/tasks/python-net/aspose.tasks/view/) क्लास का इंस्टेंस प्राप्त करता है। यह mpp फ़ाइल फ़ॉर्मेट में मौजूद पेज सेटअप डेटा का प्रतिनिधित्व करता है। |
| visual_objects_placements | दृश्य में [OleObject](/tasks/python-net/aspose.tasks/oleobject/) की प्लेसमेंट और उपस्थिति दर्शाने वाले ऑब्जेक्ट्स का संग्रह प्राप्त करता है। |
| align_details_data | विवरण डेटा संरेखण प्राप्त करता है या सेट करता है। |
| display_details_header_column | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि दृश्य में विवरण हेडर कॉलम दिखाना है या नहीं। |
| display_short_detail_header_names | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि छोटे विवरण हेडर नाम दिखाने हैं या नहीं। |
| repeat_details_header_on_all_rows | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि सभी असाइनमेंट पंक्तियों में विवरण हेडर दोहराना है या नहीं। |
| timescale_size_percentage |  |
| bottom_timescale_tier | दृश्य के नीचे के टाइमस्केल टियर की सेटिंग्स प्राप्त करता है या सेट करता है।<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | दृश्य के मध्य टाइमस्केल टियर की सेटिंग्स प्राप्त करता है या सेट करता है।<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | व्यू के शीर्ष टाइमस्केल टियर की सेटिंग्स प्राप्त करता है या सेट करता है।<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
