## OutlineCode class

एक आउटलाइन कोड के मान का प्रतिनिधित्व करता है।

OutlineCode प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| OutlineCode() | नया उदाहरण प्रारंभ करता है [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/) वर्ग का। |
| OutlineCode(code_definition, outline_value) | निर्दिष्ट Outline Code और उसके एक मान का उपयोग करके नया उदाहरण प्रारंभ करता है [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/) वर्ग का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| field_id | प्रोजेक्ट Id कस्टम फ़ील्ड का संख्या मान प्राप्त करता है या सेट करता है। |
| value_id | आउटलाइन कोड संग्रह में परिभाषा से जुड़े मान सूची में Id प्राप्त करता है या सेट करता है। |
| value_guid | मान सूची में मान का GUID प्राप्त करता है या सेट करता है। ValueGuid मान सूची में FieldGuid से मेल खाता है। |
