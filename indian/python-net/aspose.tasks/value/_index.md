## Value class

मान सूची में एक मान का प्रतिनिधित्व करता है।

Value प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Value() | नया उदाहरण प्रारंभ करता है [Value](/tasks/python-net/aspose.tasks/value/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| id | एक प्रोजेक्ट में किसी मान का अद्वितीय पहचानकर्ता प्राप्त करता है या सेट करता है। |
| value_guid | पूरे प्रोजेक्ट में इस मान को अन्य मानों में पहचानने वाला GUID प्राप्त करता है। |
| val | आंतरिक प्रतिनिधित्व में वास्तविक मान प्राप्त करता है या सेट करता है। नीचे सूचीबद्ध सख्ती से टाइप किए गए प्रॉपर्टीज़ का उपयोग करने की सलाह दी जाती है। |
| string_value | टेक्स्ट स्ट्रिंग को दर्शाने के लिए उपयोग किया जाने वाला वास्तविक मान प्राप्त करता है या सेट करता है। |
| numeric_value | संख्या या लागत मान को दर्शाने के लिए उपयोग किया जाने वाला वास्तविक मान प्राप्त करता है या सेट करता है। |
| duration | अवधि को दर्शाने के लिए उपयोग किया जाने वाला वास्तविक मान प्राप्त करता है या सेट करता है। |
| date_time_value | यदि इसे DateTime के रूप में दर्शाया जा सकता है तो वास्तविक मान प्राप्त करता है या सेट करता है। डिफ़ॉल्ट मान न्यूनतम तिथि मान है। |
| description | किसी मान का विवरण प्राप्त करता है या सेट करता है। |
| phonetic | कस्टम फ़ील्ड नाम के बारे में ध्वन्यात्मक जानकारी प्राप्त करता है या सेट करता है। |
