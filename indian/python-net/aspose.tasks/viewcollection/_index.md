## ViewCollection class

में [View](/tasks/python-net/aspose.tasks/view/) ऑब्जेक्ट्स की सूची शामिल है।<br/>            ICollection<View> इंटरफ़ेस को लागू करता है।

ViewCollection प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| parent_project | View ऑब्जेक्ट के पैरेंट को प्राप्त करता है।<br/>            केवल-पढ़ने योग्य [Project](/tasks/python-net/aspose.tasks/project/). |
## Methods
| नाम | विवरण |
| :- | :- |
| to_list() | एक view collection को [View](/tasks/python-net/aspose.tasks/view/) ऑब्जेक्ट्स की सूची में परिवर्तित करता है। |
| get_by_view_screen(screen) | निर्दिष्ट Screen प्रॉपर्टी वाले View को खोजता है, और संग्रह में पहली घटना लौटाता है। |
| get_by_name(view_name) | नाम वाले View को खोजता है, और संग्रह में पहली घटना लौटाता है। |
