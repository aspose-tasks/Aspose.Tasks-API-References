## TaskBaseline class

कार्य की बेसलाइन का प्रतिनिधित्व करता है।

TaskBaseline प्रकार निम्नलिखित सदस्य उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| TaskBaseline(task) | एक नया उदाहरण प्रारंभ करता है [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| baseline_number | Baseline डेटा रिकॉर्ड की अद्वितीय संख्या को प्राप्त करता है या सेट करता है। |
| काम | Baseline सहेजे जाने पर संसाधन को सौंपे गए कार्य को प्राप्त करता है या सेट करता है। |
| cost | Baseline सहेजे जाने पर संसाधन की अनुमानित लागत को प्राप्त करता है या सेट करता है। |
| bcws | संसाधन के लिए निर्धारित कार्य की बजट लागत को प्राप्त करता है या सेट करता है। |
| bcwp | परियोजना के लिए अब तक संसाधन द्वारा किए गए कार्य की बजटेड लागत को प्राप्त करता है या सेट करता है। |
| timephased_data | इस ऑब्जेक्ट के लिए TimephasedDataCollection इंस्टेंस को प्राप्त करता है या सेट करता है।<br/>            टास्क बेसलाइन से जुड़ा टाइम-फ़ेज़्ड डेटा। |
| interim | यह एक Interim Baseline है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| शुरू | जब बेसलाइन सहेजी गई थी, तब टास्क की निर्धारित प्रारंभ तिथि को प्राप्त करता है या सेट करता है। |
| finish | जब बेसलाइन सहेजी गई थी, तब टास्क की निर्धारित समाप्ति तिथि को प्राप्त करता है या सेट करता है। |
| duration | जब बेसलाइन सहेजी गई थी, तब टास्क की निर्धारित अवधि को प्राप्त करता है या सेट करता है। |
| estimated_duration | कार्य की बेसलाइन अवधि का अनुमान लगाया गया था या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| fixed_cost | जब बेसलाइन सहेजी गई थी, तब कार्य की निश्चित लागत प्राप्त करता है या सेट करता है। |
