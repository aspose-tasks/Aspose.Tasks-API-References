## WeekDay class

एक सप्ताह के दिन का प्रतिनिधित्व करता है जो या तो सप्ताह के नियमित दिनों या कैलेंडर में अपवाद दिनों को परिभाषित करता है।

WeekDay प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| WeekDay(day_type) | निर्दिष्ट दिन प्रकार के साथ [WeekDay](/tasks/python-net/aspose.tasks/weekday/) वर्ग का नया उदाहरण प्रारंभ करता है। |
| WeekDay(day_type, working_times) | WeekDay वर्ग का नया उदाहरण प्रारंभ करता है |
| WeekDay(day_type, working_times) | निर्दिष्ट दिन प्रकार और कार्य समय अवधि के साथ [WeekDay](/tasks/python-net/aspose.tasks/weekday/) वर्ग का नया उदाहरण प्रारंभ करता है। |
| WeekDay() | निर्दिष्ट दिन प्रकार के साथ [WeekDay](/tasks/python-net/aspose.tasks/weekday/) वर्ग का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| day_type | एक दिन का प्रकार प्राप्त करता है। |
| day_working | निर्दिष्ट तिथि या दिन प्रकार कार्यशील है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| from_date | एक अपवाद समय की शुरुआत प्राप्त करता है या सेट करता है। |
| to_date | एक अपवाद समय का अंत प्राप्त करता है या सेट करता है। |
| working_times | इस WeekDay उदाहरण के लिए WorkingTimeCollection प्राप्त करता है।<br/>            सप्ताह के दिन पर कार्य किए गए समय को परिभाषित करने वाले कार्य समय का संग्रह। |
## Methods
| नाम | विवरण |
| :- | :- |
| create_default_working_day(day_type) | डिफ़ॉल्ट कार्य दिवस बनाता है। |
| set_default_working_time(day) | निर्दिष्ट सप्ताह के दिन के लिए डिफ़ॉल्ट समय अवधि सेट करता है। |
| get_working_time() | एक सप्ताह के दिन के लिए कार्य समय लौटाता है। |
| clone() | सप्ताह के दिन की गहरी प्रतिलिपि लौटाता है। |
