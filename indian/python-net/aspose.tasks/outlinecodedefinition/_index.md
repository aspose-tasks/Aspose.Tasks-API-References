## OutlineCodeDefinition class

एक आउटलाइन कोड परिभाषा का प्रतिनिधित्व करता है।

OutlineCodeDefinition प्रकार निम्नलिखित सदस्य प्रकट करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| OutlineCodeDefinition() | [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/) क्लास का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| guid | आउटलाइन कोड का Guid प्राप्त करता है या सेट करता है। |
| field_id | आउटलाइन कोड का फ़ील्ड नंबर प्राप्त करता है या सेट करता है। |
| field_name | कस्टम आउटलाइन कोड का नाम प्राप्त करता है या सेट करता है। |
| alias | कस्टम आउटलाइन कोड का उपनाम प्राप्त करता है या सेट करता है। |
| phonetic_alias | कस्टम आउटलाइन कोड के उपनाम की ध्वन्यात्मक उच्चारण प्राप्त करता है या सेट करता है। |
| values | OutlineValueCollection ऑब्जेक्ट प्राप्त करता है।<br/>            इस आउटलाइन कोड से जुड़ी तालिका के मान। |
| enterprise | कस्टम आउटलाइन कोड एक एंटरप्राइज़ कस्टम आउटलाइन कोड है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| enterprise_outline_code_alias | इस आउटलाइन कोड परिभाषा के उपनाम वाले दूसरे कस्टम फ़ील्ड का संदर्भ प्राप्त करता है या सेट करता है। |
| resource_substitution_enabled | कस्टम आउटलाइन कोड को उपयोग किया जा सकता है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है<br/>            Microsoft Project में Resource Substitution Wizard द्वारा। |
| leaf_only | इस आउटलाइन कोड फ़ील्ड में निर्दिष्ट मानों को केवल लीफ़ मान होना चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| all_levels_required | नए कोडों को सभी स्तरों की आवश्यकता है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है।<br/>            एंटरप्राइज़ कोडों के लिए उपलब्ध नहीं है। |
| only_table_values_allowed | निर्दिष्ट मानों को मान तालिका से आना चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| masks | OutlineMaskCollection ऑब्जेक्ट प्राप्त करता है।<br/>            आउटलाइन कोड मास्क को परिभाषित करने वाले प्रविष्टियों की तालिका।<br/>            केवल-रीड [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/) इंस्टेंस। |
| show_indent | इस आउटलाइन कोड के इंडेंट को दिखाया जाना चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
