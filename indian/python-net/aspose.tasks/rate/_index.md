## Rate class

उस अवधि के दौरान संसाधन के लिए लागू समय अवधि और दरों की परिभाषा को दर्शाता है।

दर प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| rates_from | दर के प्रभावी होने की तिथि को प्राप्त करता है या सेट करता है। |
| rates_to | दर के प्रभावी रहने की अंतिम तिथि को प्राप्त करता है या सेट करता है। |
| rate_table | संसाधन के लिए दर तालिका का अनन्य पहचानकर्ता प्राप्त करता है या सेट करता है। |
| standard_rate | संसाधन के लिए प्रति घंटे मानक दर प्राप्त करता है या सेट करता है। |
| standard_rate_format | Microsoft Project द्वारा मानक दर दिखाने के लिए उपयोग किए जाने वाले इकाइयों को प्राप्त करता है या सेट करता है। |
| overtime_rate | संसाधन के लिए प्रति घंटे ओवरटाइम दर प्राप्त करता है या सेट करता है। |
| overtime_rate_format | Microsoft Project द्वारा ओवरटाइम दर दिखाने के लिए उपयोग किए जाने वाले इकाइयों को प्राप्त करता है या सेट करता है। |
| cost_per_use | संसाधन के प्रति उपयोग लागत को प्राप्त करता है या सेट करता है। यदि संसाधन के लिए दर तालिका मौजूद है तो यह मान वर्तमान तिथि से प्राप्त किया जाता है। |
