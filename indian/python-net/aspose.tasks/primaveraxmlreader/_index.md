## PrimaveraXmlReader class

एक रीडर का प्रतिनिधित्व करता है जो Primavera Xml फ़ाइल से प्रोजेक्ट UID प्राप्त करने की अनुमति देता है।

PrimaveraXmlReader प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PrimaveraXmlReader(template_path) | निम्नलिखित [PrimaveraXmlReader](/tasks/python-net/aspose.tasks/primaveraxmlreader/) वर्ग की एक नई इंस्टेंस को प्रारंभ करता है। |
| PrimaveraXmlReader(stream) | निम्नलिखित [PrimaveraXmlReader](/tasks/python-net/aspose.tasks/primaveraxmlreader/) वर्ग की एक नई इंस्टेंस को प्रारंभ करता है। |
