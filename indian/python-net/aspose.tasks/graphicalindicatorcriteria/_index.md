## GraphicalIndicatorCriteria class

विस्तारित गुण के साथ जुड़े एक ग्राफ़िकल इंडिकेटर मानदंड का प्रतिनिधित्व करता है।

GraphicalIndicatorCriteria प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | GraphicalIndicatorCriteria वर्ग की नई इंस्टेंस को प्रारंभ करता है |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | GraphicalIndicatorCriteria वर्ग की नई इंस्टेंस को प्रारंभ करता है |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| test | विस्तारित गुण के मान और मानों के बीच किए गए तुलना प्रकार को प्राप्त करता है जो ग्राफिकल संकेतक के अनुप्रयोग के लिए मानदंड के रूप में कार्य करता है।<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | विस्तारित गुण के मान का परीक्षण करने के लिए उपयोग किए गए मान को प्राप्त करता है। |
| value2 | 'IsWithin' और 'IsNotWithin' तुलना प्रकारों के मामले में विस्तारित गुण के मान का परीक्षण करने के लिए उपयोग किए गए दूसरे मान को प्राप्त करता है। |
| image_index | फ़ील्ड मानदंड को पूरा करने पर प्रदर्शित होने वाली छवि का सूचकांक प्राप्त करता है। |
| row_type | उस मान को प्राप्त करता है जो [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) एन्‍युम में है, जो दर्शाता है कि संकेतक किन पंक्तियों पर लागू होता है। |
