## ExtendedAttribute class

विस्तारित गुणों का प्रतिनिधित्व करता है।

ExtendedAttribute प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| attribute_definition | एट्रिब्यूट परिभाषा प्राप्त करता है। |
| field_id | फ़ील्ड की आईडी प्राप्त करता है। |
| duration_value | ‘Duration’ प्रकार वाले एट्रिब्यूट्स के लिए मान प्राप्त करता है या सेट करता है। |
| numeric_value | संख्यात्मक प्रकार (Cost, Number) वाले एट्रिब्यूट्स के लिए मान प्राप्त करता है या सेट करता है। |
| date_value | तारीख प्रकार (Date, Start, Finish) वाले एट्रिब्यूट्स के लिए मान प्राप्त करता है या सेट करता है। |
| flag_value | ‘Flag’ प्रकार वाले एट्रिब्यूट के लिए यह दर्शाने वाला मान प्राप्त करता है या सेट करता है कि फ़्लैग सेट है या नहीं। |
| text_value | ‘Text’ प्रकार वाले एट्रिब्यूट्स के लिए मान प्राप्त करता है या सेट करता है। |
| value_guid | लुकअप मान का GUID प्राप्त करता है। |
| value_read_only | इस [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) इंस्टेंस का मान केवल-पढ़ने योग्य है या नहीं, यह दर्शाने वाला मान प्राप्त करता है। |
| is_error_value | विस्तारित एट्रिब्यूट के मान की गणना में त्रुटि हुई है या नहीं, यह प्राप्त करता है। |
