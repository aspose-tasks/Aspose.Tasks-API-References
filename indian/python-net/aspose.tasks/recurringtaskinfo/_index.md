## RecurringTaskInfo class

प्रोजेक्ट में एक आवर्ती कार्य के विवरण को दर्शाता है।

RecurringTaskInfo प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| recurrence_pattern | आवर्ती कार्य का पुनरावृत्ति पैटर्न प्राप्त करता है या सेट करता है। |
| start_date | घटनाओं के शुरू होने की तिथि प्राप्त करता है या सेट करता है। |

| occurrences | आवर्ती कार्य की घटनाओं की संख्या प्राप्त करता है या सेट करता है। |

| monthly_ordinal_number | मासिक आवृत्ति पैटर्न का क्रमांकित संख्या प्राप्त करता है या सेट करता है। |
| monthly_ordinal_repetitions | क्रमांकित दिन का उपयोग करते समय मासिक आवृत्ति पैटर्न के लिए दोहराव की संख्या प्राप्त करता है या सेट करता है। |
| monthly_day | मासिक आवृत्ति पैटर्न के दिन की संख्या प्राप्त करता है या सेट करता है। |
| monthly_repetitions | मासिक आवृत्ति पैटर्न के लिए दोहराव की संख्या प्राप्त करता है या सेट करता है। |
