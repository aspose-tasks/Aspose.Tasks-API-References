## Duration class

प्रोजेक्ट में अवधि का प्रतिनिधित्व करता है।

Duration प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Duration() | Duration वर्ग की नई इंस्टेंस को आरंभ करता है |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| time_span | इस Duration ऑब्जेक्ट का [time_span](/tasks/python-net/aspose.tasks/duration/) इंस्टेंस प्राप्त करता है। |
| time_unit | इस ऑब्जेक्ट के लिए समय इकाई प्रकार प्राप्त करता है। |
| is_estimated | समय इकाई अनुमानित है या नहीं, यह दर्शाने वाला मान प्राप्त करता है। |
| is_elapsed | समय इकाई समाप्त हो चुकी है या नहीं, यह दर्शाने वाला मान प्राप्त करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
| add(d) | निर्दिष्ट अवधि को इस अवधि में जोड़ता है। |
| add(val) | निर्दिष्ट डबल मान को इस अवधि में जोड़ता है। |
| subtract(d) | निर्दिष्ट अवधि को इस अवधि इंस्टेंस से घटाता है। |
| subtract(val) | निर्दिष्ट डबल मान को इस अवधि इंस्टेंस से घटाता है। |
| parse(p, value) | निर्दिष्ट स्ट्रिंग को [Duration](/tasks/python-net/aspose.tasks/duration/) स्ट्रक्चर की इंस्टेंस में परिवर्तित करता है। |
| parse_time_span(value) | "PT--H--M--S--" प्रारूप में अवधि स्ट्रिंग को पार्स करता है। |
| to_double() | Duration ऑब्जेक्ट को फ्लोट मान में परिवर्तित करता है। |
| convert(time_unit_type) | निर्दिष्ट समय इकाइयों के साथ Duration ऑब्जेक्ट को दूसरी अवधि में परिवर्तित करता है। |
| equals(other) | एक मान लौटाता है जो यह दर्शाता है कि यह उदाहरण किसी निर्दिष्ट वस्तु के बराबर है या नहीं। |
