## ResourceCollection class

[Resource](/tasks/python-net/aspose.tasks/resource/) ऑब्जेक्ट्स के संग्रह को दर्शाता है।

ResourceCollection प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| parent_project | ResourceCollection ऑब्जेक्ट का पैरेंट प्रोजेक्ट प्राप्त करता है। |
## Methods
| नाम | विवरण |
| :- | :- |
| add() | प्रोजेक्ट संसाधन संग्रह के अंतिम स्थान पर नया संसाधन जोड़ता है। |
| add(resource_name) | प्रोजेक्ट संसाधन संग्रह के अंतिम स्थान पर नया संसाधन जोड़ता है। |
| add(resource_name, before_resource_id) |  |
| to_list() | ResourceCollection ऑब्जेक्ट को [Resource](/tasks/python-net/aspose.tasks/resource/) ऑब्जेक्ट्स की सूची में परिवर्तित करता है। |
| get_by_id(id) | निर्दिष्ट id के साथ एक संसाधन लौटाता है। |
| get_by_uid(uid) | निर्दिष्ट Uid के साथ एक संसाधन लौटाता है। |
