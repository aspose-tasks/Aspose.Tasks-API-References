## WBSCodeDefinition class

WBS कोड परिभाषा का प्रतिनिधित्व करता है।

WBSCodeDefinition प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| WBSCodeDefinition() | नया उदाहरण प्रारंभ करता है [WBSCodeDefinition](/tasks/python-net/aspose.tasks/wbscodedefinition/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| code_prefix | परियोजना कोड उपसर्ग को प्राप्त करता है या सेट करता है। |
| generate_wbs_code | नए कार्य के लिए WBS कोड उत्पन्न करने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| verify_uniqueness | नए WBS कोड की विशिष्टता की जाँच करने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| code_mask_collection | WBSCodeMask वस्तुओं का संग्रह प्राप्त करता है। |
