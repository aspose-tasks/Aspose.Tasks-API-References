## FontResolveEventArgs class

फ़ॉन्ट हल होने पर कॉलबैक को बुलाए जाने के लिए तर्क प्रदान करता है।

यह FontResolveEventArgs प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| requested_font_name | अनुरोधित फ़ॉन्ट का नाम प्राप्त करता है। |
| resolved_font_name | समाधान किए गए फ़ॉन्ट का नाम प्राप्त करता है या सेट करता है। इसे दृश्य को रेंडर करने के लिए उपयोग किए जाने वाले फ़ॉन्ट को नियंत्रित करने के लिए सेट किया जा सकता है। |
