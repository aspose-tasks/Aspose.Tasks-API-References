## ExtendedAttributeDefinition class

प्रोजेक्ट से जुड़ी विस्तारित गुण परिभाषा का प्रतिनिधित्व करता है।

ExtendedAttributeDefinition प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| field_id | कस्टम फ़ील्ड के प्रोजेक्ट आईडी के अनुरूप प्राप्त करता है या सेट करता है।<br/>            एक स्थिरांक की स्ट्रिंग प्रतिनिधित्व का उपयोग करें जो [ExtendedAttributeTask](/tasks/python-net/aspose.tasks/extendedattributetask/) क्लास से है, ताकि [field_id](/tasks/python-net/aspose.tasks/extendedattributedefinition/) प्रॉपर्टी को निर्दिष्ट किया जा सके। |
| field_name | कस्टम फ़ील्ड का नाम प्राप्त करता है। |
| cf_type | कस्टम फ़ील्ड का प्रकार प्राप्त करता है। |
| guid | कस्टम फ़ील्ड का GUID प्राप्त करता है या सेट करता है। |
| element_type | विस्तारित विशेषता को प्राप्त करता है या सेट करता है जो<br/>            एक कार्य, एक संसाधन या एक असाइनमेंट से जुड़ी होती है। |
| max_multi_values | पिक सूची में आप जो अधिकतम मान सेट कर सकते हैं, उसे प्राप्त करता है या सेट करता है। |
| user_def | कस्टम फ़ील्ड उपयोगकर्ता द्वारा परिभाषित है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| alias | कस्टम फ़ील्ड का उपनाम प्राप्त करता है या सेट करता है। |

| default_guid | डिफ़ॉल्ट लुकअप टेबल प्रविष्टि का GUID प्राप्त करता है या सेट करता है। |
| lookup_uid | कस्टम फ़ील्ड से जुड़े लुकअप टेबल का GUID प्राप्त करता है। |
| phonetics_alias | कस्टम फ़ील्ड के उपनाम की ध्वन्यात्मक उच्चारण प्राप्त करता है या सेट करता है। |
| rollup_type | रोलअप की गणना का तरीका प्राप्त करता है या सेट करता है। |
| calculation_type | कस्टम एट्रिब्यूट के मान की गणना प्रकार प्राप्त करता है या सेट करता है। |
| summary_rows_calculation_type | सारांश पंक्तियों के लिए कस्टम एट्रिब्यूट के मान की गणना प्रकार प्राप्त करता है या सेट करता है। |
| formula | Microsoft Project द्वारा कस्टम टास्क फ़ील्ड को भरने के लिए उपयोग की जाने वाली फ़ॉर्मूला प्राप्त करता है या सेट करता है। |
| graphical_indicator | विस्तारित विशेषता से जुड़ी ग्राफिकल संकेतक जानकारी प्राप्त करता है या सेट करता है।<br/>            MPP फ़ॉर्मेट के लिए लागू। |
| restrict_values | कस्टम फ़ील्ड मानों को [value_list](/tasks/python-net/aspose.tasks/extendedattributedefinition/) में मानों तक सीमित रखने का संकेत देने वाला मान प्राप्त करता है या सेट करता है। |
| valuelist_sort_order | मान सूची को क्रमबद्ध करने का तरीका प्राप्त करता है या सेट करता है। मान हैं: 0=अवरोही, 1=आरोही। |
| append_new_values | प्रोजेक्ट में जोड़े गए नए मानों को स्वचालित रूप से सूची में जोड़ने का संकेत देने वाला मान प्राप्त करता है या सेट करता है। |
| default | सूची में डिफ़ॉल्ट मान प्राप्त करता है या सेट करता है। |
| value_list | List<Value> ValueList प्राप्त करता है। |
| secondary_guid | विस्तारित विशेषता का द्वितीयक guid प्राप्त करता है या सेट करता है। |
| parent_project | [ExtendedAttributeDefinition](/tasks/python-net/aspose.tasks/extendedattributedefinition/) उदाहरण के लिए पैरेंट प्रोजेक्ट प्राप्त करता है। |
