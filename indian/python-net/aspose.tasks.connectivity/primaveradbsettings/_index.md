## PrimaveraDbSettings class

Primavera डेटाबेस से प्रोजेक्ट डेटा पढ़ने के लिए आवश्यक विकल्प सेट करने की अनुमति देता है।

PrimaveraDbSettings प्रकार निम्नलिखित सदस्य उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PrimaveraDbSettings(connection_string, project_id) | नया उदाहरण प्रारंभ करता है [PrimaveraDbSettings](/tasks/python-net/aspose.tasks.connectivity/primaveradbsettings/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| connection_string | कनेक्शन स्ट्रिंग को प्राप्त करता है या सेट करता है। |
| provider_invariant_name | प्रोवाइडर इनवेरिएंट नाम को प्राप्त करता है या सेट करता है, जिसका उपयोग क्लास की एक इंस्टेंस प्राप्त करने के लिए किया जाता है। |
| project_id | प्रोजेक्ट को पढ़ने के लिए आईडी प्राप्त करता है। |
