## MspDbSettings class

MS Project Server डेटाबेस से प्रोजेक्ट डेटा पढ़ने के लिए आवश्यक विकल्प सेट करने की अनुमति देता है।

MspDbSettings प्रकार निम्नलिखित सदस्य उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | नया उदाहरण प्रारंभ करता है [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| connection_string | कनेक्शन स्ट्रिंग को प्राप्त करता है या सेट करता है। |
| provider_invariant_name | प्रोवाइडर इनवेरिएंट नाम को प्राप्त करता है या सेट करता है, जिसका उपयोग क्लास की एक इंस्टेंस प्राप्त करने के लिए किया जाता है। |
| project_guid | प्रोजेक्ट को पढ़ने के लिए GUID प्राप्त करता है। |
| schema | MS Project Server की स्कीमा को प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान "pub" है। |
