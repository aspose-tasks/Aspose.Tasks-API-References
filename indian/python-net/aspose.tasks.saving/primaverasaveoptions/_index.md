## PrimaveraSaveOptions class

प्रोजेक्ट को Primavera XER फ़ॉर्मेट में सहेजते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देता है।

PrimaveraSaveOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PrimaveraSaveOptions() | नया उदाहरण इनिशियलाइज़ करता है [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| save_format | यदि इस सहेज विकल्प वस्तु का उपयोग किया जाता है तो दस्तावेज़ को सहेजने के फ़ॉर्मेट को प्राप्त करता है या सेट करता है। |
| activity_id_increment | गतिविधि IDs के पुनः क्रमांकन में उपयोग किए जाने वाले इन्क्रिमेंट को प्राप्त करता है या सेट करता है। |
| activity_id_prefix | गतिविधि IDs के पुनः क्रमांकन में उपयोग किए जाने वाले प्रीफ़िक्स को प्राप्त करता है या सेट करता है। |
| activity_id_suffix | गतिविधि IDs के पुनः क्रमांकन में उपयोग किए जाने वाले सफ़िक्स को प्राप्त करता है या सेट करता है। |
| renumber_activity_ids | एक मान प्राप्त करता है या सेट करता है जो यह दर्शाता है कि क्या गतिविधि IDs को पुनः क्रमांकित करने की आवश्यकता है। |
| skip_summary_assignments | एक्सपोर्ट के दौरान संसाधनों के असाइनमेंट को समरी टास्क में छोड़ना चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
