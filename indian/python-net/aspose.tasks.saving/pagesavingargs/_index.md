## PageSavingArgs class

यह क्लास दस्तावेज़ पृष्ठ को स्ट्रीम में सहेजने से संबंधित डेटा सेट का प्रतिनिधित्व करता है।

PageSavingArgs प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| page_number | लिखी जाने वाली पृष्ठों की संख्या प्राप्त करता है। |
| keep_stream_open | रेंडरिंग रूटीन को पृष्ठ लिखे जाने के बाद [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) को खुला रखना चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| stream | पृष्ठ लिखने के लिए एक स्ट्रीम प्राप्त करता है या सेट करता है। |
