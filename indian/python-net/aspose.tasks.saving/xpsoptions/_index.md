## XpsOptions class

प्रोजेक्ट पृष्ठों को XPS में रेंडर करते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देता है।

XpsOptions प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| XpsOptions() | नया उदाहरण प्रारंभ करता है [XpsOptions](/tasks/python-net/aspose.tasks.saving/xpsoptions/) वर्ग का। |

| draw_non_working_time | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि गैर-कार्य समय को चित्रित किया जाना चाहिए या नहीं (डिफ़ॉल्ट मान TRUE है)। |

| timescale | प्रोजेक्ट को ग्राफिकल फ़ॉर्मेट में सहेजते समय टाइमस्केल (यदि मौजूद हो) को कैसे रेंडर किया जाता है, इसे नियंत्रित करने के लिए उपयोग किए जाने वाले [timescale](/tasks/python-net/aspose.tasks.saving/saveoptions/) मान को प्राप्त करता है या सेट करता है। |
| use_gradient_brush | रेंडर करते समय Gantt Chart में ग्रेडिएंट ब्रश का उपयोग किया जाना चाहिए या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| view | रेंडर करने के लिए व्यू कॉलम की सूची प्राप्त करता है या सेट करता है ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/))।<br/>यदि सेट नहीं किया गया है तो केवल टास्क आईडी, टास्क नाम, प्रारंभ और समाप्ति रेंडर होते हैं।<br/>यदि View और [view_settings](/tasks/python-net/aspose.tasks.saving/saveoptions/) दोनों प्रॉपर्टी सेट हैं, तो View के कॉलम ViewSettings के कॉलम को ओवरराइड करते हैं। |

| render_to_single_page | किसी मान को प्राप्त करता है या सेट करता है जो दर्शाता है कि प्रोजेक्ट को एक पेज में रेंडर किया जाना चाहिए<br/>            जब प्रोजेक्ट ग्राफिकल फॉर्मेट में सहेजा जाता है।<br/>            पेज आकार बदल दिया जाएगा ताकि रेंडर किया गया प्रोजेक्ट एक पेज में फिट हो सके। |
