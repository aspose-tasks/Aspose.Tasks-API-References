## MPPSaveOptions class

प्रोजेक्ट डेटा को MPP में सहेजते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देता है।

MPPSaveOptions प्रकार निम्नलिखित सदस्यों को प्रकट करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| MPPSaveOptions() | एक नया उदाहरण प्रारंभ करता है [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| save_format | यदि इस सहेज विकल्प वस्तु का उपयोग किया जाता है तो दस्तावेज़ को सहेजने के फ़ॉर्मेट को प्राप्त करता है या सेट करता है। |
| remove_invalid_assignments | MPP में सहेजते समय अमान्य संसाधन असाइनमेंट को हटाने का संकेत देने वाला मान प्राप्त करता है या सेट करता है। |
| write_view_data | प्रोजेक्ट को MPP स्वरूप में सहेजते समय दृश्य डेटा लिखने का संकेत देने वाला मान प्राप्त करता है या सेट करता है। |
| write_filters | प्रोजेक्ट को MPP स्वरूप में सहेजते समय फ़िल्टर डेटा लिखने का संकेत देने वाला मान प्राप्त करता है या सेट करता है। |
| write_groups | प्रोजेक्ट को MPP फ़ॉर्मेट में सहेजते समय समूह डेटा लिखने के बारे में संकेत करने वाला मान प्राप्त करता है या सेट करता है। |
| clear_vba | प्रोजेक्ट को MPP फ़ॉर्मेट में सहेजते समय मौजूदा VBA मैक्रो डेटा को हटाने के बारे में संकेत करने वाला मान प्राप्त करता है या सेट करता है। |
| write_vba | MPP फ़ाइल में मौजूदा VBA मैक्रो डेटा को अपडेट करने के बारे में संकेत करने वाला मान प्राप्त करता है या सेट करता है।<br/>            वर्तमान में VbaModule.SourceCode की लेखन समर्थित है। |
| protection_password | एक पासवर्ड प्राप्त करता है या सेट करता है जिसका उपयोग उत्पन्न MPP फ़ाइल की सुरक्षा के लिए किया जाता है। वर्तमान में MS Project 2010 और नए फ़ॉर्मेट के लिए समर्थित है। |
