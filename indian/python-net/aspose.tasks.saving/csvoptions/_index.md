## CsvOptions class

प्रोजेक्ट को CSV में सहेजते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देता है।

CsvOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| CsvOptions() | [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) क्लास का एक नया उदाहरण प्रारंभ करता है जिसका उपयोग प्रोजेक्ट को CSV प्रारूप में सहेजने के लिए किया जा सकता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| save_format | यदि इस सहेज विकल्प वस्तु का उपयोग किया जाता है तो दस्तावेज़ को सहेजने के फ़ॉर्मेट को प्राप्त करता है या सेट करता है। |
| data_category | सहेजे जाने वाले डेटा श्रेणी को प्राप्त करता है या सेट करता है। |
| encoding | CSV को सहेजने के लिए एन्कोडिंग को प्राप्त करता है या सेट करता है। |
| include_headers | हेडर शामिल करने हैं या नहीं (डिफ़ॉल्ट मान TRUE है) यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
| text_delimiter | टेक्स्ट डिलिमिटर को प्राप्त करता है या सेट करता है। |
| view | XLSX प्रारूप में सहेजने के लिए व्यू कॉलमों की सूची ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) को प्राप्त करता है या सेट करता है।<br/>            यदि सेट नहीं किया गया तो डिफ़ॉल्ट कॉलम सहेजे जाएंगे। |
