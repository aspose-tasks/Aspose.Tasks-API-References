## PdfEncryptionDetails class

PDF एन्क्रिप्शन के विवरण शामिल हैं।

PdfEncryptionDetails प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PdfEncryptionDetails(user_password, owner_password, encryption_algorithm) | नया उदाहरण [PdfEncryptionDetails](/tasks/python-net/aspose.tasks.saving/pdfencryptiondetails/) वर्ग का प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| encryption_algorithm | एन्क्रिप्शन मोड को प्राप्त करता है या सेट करता है। |
| owner_password | Owner पासवर्ड को प्राप्त करता है या सेट करता है। |
| permissions | अनुमतियों को प्राप्त करता है या सेट करता है। |
| user_password | User पासवर्ड को प्राप्त करता है या सेट करता है। |
