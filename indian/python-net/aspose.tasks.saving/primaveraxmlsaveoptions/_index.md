## PrimaveraXmlSaveOptions class

प्रोजेक्ट को Primavera XML फ़ॉर्मेट में सहेजते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देता है।

PrimaveraXmlSaveOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PrimaveraXmlSaveOptions() | एक नया [PrimaveraXmlSaveOptions](/tasks/python-net/aspose.tasks.saving/primaveraxmlsaveoptions/) क्लास का इंस्टेंस इनिशियलाइज़ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| save_format | यदि इस सहेज विकल्प वस्तु का उपयोग किया जाता है तो दस्तावेज़ को सहेजने के फ़ॉर्मेट को प्राप्त करता है या सेट करता है। |
| save_root_task | रूट टास्क को सेव करना है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
