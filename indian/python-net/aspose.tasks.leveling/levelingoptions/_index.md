## LevelingOptions class

संसाधन लेवलिंग के पैरामीटर निर्दिष्ट करने की अनुमति देता है।

LevelingOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| LevelingOptions() | नया उदाहरण इनिशियलाइज़ करता है [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| start_date | लेवलिंग अवधि की शुरूआत तिथि को प्राप्त करता है या सेट करता है। डिफ़ॉल्ट मान प्रोजेक्ट की शुरूआत तिथि है। |
| finish_date | लेवलिंग अवधि की समाप्ति तिथि को प्राप्त करता है या सेट करता है। डिफ़ॉल्ट मान प्रोजेक्ट की समाप्ति तिथि है। |
| संसाधन | लेवल किए जाने वाले संसाधनों की सूची को प्राप्त करता है या सेट करता है। यदि null सेट किया जाता है, तो सभी प्रोजेक्ट संसाधन लेवल किए जाएंगे। |
| leveling_order | लेवलिंग एल्गोरिद्म द्वारा अधिक आवंटन वाले कार्यों को विलंबित करने के क्रम को प्राप्त करता है।<br/>            अधिक आवंटन का कारण बनने वाले कार्यों और जिन्हें विलंबित किया जा सकता है, का निर्धारण करने के बाद, यह निर्धारित क्रम उपयोग किया जाता है कि कौन सा कार्य पहले विलंबित होना चाहिए। |
| message_level | Aspose.Tasks द्वारा संसाधन लेवलिंग के दौरान उत्पन्न लॉग संदेशों के स्तर को प्राप्त या सेट करता है। |
| message_handler | Aspose.Tasks द्वारा संसाधन लेवलिंग के दौरान उत्पन्न लॉग संदेशों को इंटरसेप्ट करने के लिए उपयोग किए जा सकने वाले संदेश हैंडलर कॉलबैक को प्राप्त या सेट करता है। |
