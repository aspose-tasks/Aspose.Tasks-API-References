## TextStyle class

प्रोजेक्ट व्यू में किसी आइटम के टेक्स्ट की दृश्य शैली बदलें।

TextStyle प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| TextStyle() | डिफ़ॉल्ट सेटिंग्स के साथ [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) क्लास का नया उदाहरण प्रारंभ करता है। |
| TextStyle(font_size, font_style) | TextStyle क्लास का नया उदाहरण प्रारंभ करता है। |
| TextStyle(font_style) | डिफ़ॉल्ट फ़ॉन्ट और निर्दिष्ट फ़ॉन्ट आकार व शैली के साथ [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) क्लास का नया उदाहरण प्रारंभ करता है। |
| TextStyle(font) | निर्दिष्ट फ़ॉन्ट सेटिंग्स के साथ [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) क्लास का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| font | टेक्स्ट शैली का फ़ॉन्ट प्राप्त करता है या सेट करता है। |
| color | टेक्स्ट का रंग प्राप्त करता है या सेट करता है। |
| item_type | टेक्स्ट शैली का [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) प्राप्त करता है या सेट करता है। |
| background_pattern | टेक्स्ट शैली का बैकग्राउंड पैटर्न प्राप्त करता है या सेट करता है।<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | टेक्स्ट शैली का बैकग्राउंड रंग प्राप्त करता है या सेट करता है।<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
