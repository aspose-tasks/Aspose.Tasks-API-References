## VisualObjectPlacement class

व्यू में [OleObject](/tasks/python-net/aspose.tasks/oleobject/) की प्लेसमेंट और दिखावट का प्रतिनिधित्व करता है।

VisualObjectPlacement प्रकार निम्नलिखित सदस्यों को प्रकट करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| VisualObjectPlacement() | निम्नलिखित [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/) वर्ग का एक नया उदाहरण आरंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| ole_object_id | [OleObject](/tasks/python-net/aspose.tasks/oleobject/) ऑब्जेक्ट का Id प्राप्त करता है या सेट करता है। |
| task_id | यदि 'Attach to task' विकल्प चुना गया हो तो कार्य का Id प्राप्त करता है या सेट करता है, अन्यथा -1। |
| width | विज़ुअल ऑब्जेक्ट की प्रदर्शित चौड़ाई प्राप्त करता है या सेट करता है। |
| height | विज़ुअल ऑब्जेक्ट की प्रदर्शित ऊँचाई प्राप्त करता है या सेट करता है। |
| vertical_offset | विज़ुअल ऑब्जेक्ट का ऊर्ध्वाधर ऑफ़सेट प्राप्त करता है या सेट करता है। |
| horizontal_offset | विज़ुअल ऑब्जेक्ट का क्षैतिज ऑफ़सेट प्राप्त करता है या सेट करता है। |
| timescale_date | 'Attach to timescale' विकल्प चुने जाने पर विज़ुअल ऑब्जेक्ट की तिथि प्लेसमेंट प्राप्त करता है या सेट करता है। |
| attachment_point | 'Attach to task' विकल्प चुने जाने पर कार्य के सापेक्ष विज़ुअल ऑब्जेक्ट का संरेखण प्राप्त करता है या सेट करता है। |
| border_line_color | बॉर्डर लाइन रंग को प्राप्त करता है या सेट करता है। |
| border_line_thickness | बॉर्डर लाइन मोटाई को प्राप्त करता है या सेट करता है (अनुमत मान 0 - 5 हैं)। |
| fill_color | भरण रंग को प्राप्त करता है या सेट करता है। |
| fill_pattern | भरण पैटर्न को प्राप्त करता है या सेट करता है। |
