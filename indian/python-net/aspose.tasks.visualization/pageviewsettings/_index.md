## PageViewSettings class

प्रोजेक्ट व्यू के लिए प्रिंट सेटिंग्स का प्रतिनिधित्व करता है।

PageViewSettings प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PageViewSettings() | PageViewSettings क्लास का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| first_columns_count | सभी पृष्ठों पर प्रिंट किए जाने वाले पहले कॉलमों की संख्या प्राप्त करता है या सेट करता है। |
| fit_timescale_to_end_of_page | प्रिंट करते समय टाइमस्केल को पृष्ठ के अंत तक फिट करने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| print_all_sheet_columns | दृश्य की सभी शीट कॉलमों को प्रिंट करने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| print_blank_pages | दृश्य के खाली पृष्ठों को प्रिंट करने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| print_first_columns_count_on_all_pages | सभी पृष्ठों पर निर्दिष्ट संख्या में पहले कॉलमों को प्रिंट करने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| print_notes | नोट्स को प्रिंट करने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
