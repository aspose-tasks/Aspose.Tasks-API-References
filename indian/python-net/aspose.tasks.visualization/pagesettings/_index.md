## PageSettings class

प्रोजेक्ट व्यू के पृष्ठ के लिए प्रिंट सेटिंग्स का प्रतिनिधित्व करता है।

PageSettings प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PageSettings() | [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/) वर्ग का एक नया उदाहरण आरंभ करता है। <br/>            प्रोजेक्ट दृश्य के एक पृष्ठ के प्रिंटिंग सेटिंग्स का प्रतिनिधित्व करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| is_portrait | यह दर्शाने वाला मान प्राप्त करता है या सेट करता है कि पृष्ठ अभिविन्यास पोर्ट्रेट है या नहीं; यदि पृष्ठ अभिविन्यास लैंडस्केप है तो false लौटाता है। |
| adjust_to_percent_of_normal_size | यह दर्शाने वाला मान प्राप्त या सेट करता है कि सामान्य आकार के निर्दिष्ट प्रतिशत ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) के अनुसार प्रिंटिंग को समायोजित किया जाए या नहीं। |
| percent_of_normal_size | प्रिंटिंग को समायोजित करने के लिए सामान्य आकार का प्रतिशत प्राप्त करता है या सेट करता है। |
| pages_in_width | प्रिंट किए जाने वाले चौड़ाई में पृष्ठों की संख्या प्राप्त करता है या सेट करता है। |
| pages_in_height | प्रिंट किए जाने वाले ऊँचाई में पृष्ठों की संख्या प्राप्त करता है या सेट करता है। |
| paper_size | कागज़ का आकार प्राप्त करता है या सेट करता है। यह [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/) enumeration के मानों में से एक हो सकता है। |
| paper_size_id | PrinterPaperSize मानों में से एक या कस्टम पेज साइज आईडी का प्रतिनिधित्व करने वाला पूर्णांक प्राप्त करता है या सेट करता है।<br/>            इस मान का उपयोग OS सेटिंग्स से PaperSize प्राप्त करने के लिए किया जा सकता है |
| first_page_number | प्रिंटिंग के लिए पहला पृष्ठ संख्या प्राप्त करता है या सेट करता है। |
