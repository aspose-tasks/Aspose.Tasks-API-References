## RecurringInterval class

गैंट चार्ट व्यू की प्रोग्रेस लाइनों में उपयोग किए जाने वाले आवर्ती अंतराल का प्रतिनिधित्व करता है।

RecurringInterval प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| RecurringInterval() | RecurringInterval क्लास का एक नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| interval | आवर्ती अंतराल को प्राप्त करता है या सेट करता है.<br/>            यह [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/) प्रकार का कोई भी मान हो सकता है। |
| daily_day_number | दैनिक दिन संख्या को प्राप्त करता है या सेट करता है। |
| daily_workday | एक मान प्राप्त करता है या सेट करता है जो दर्शाता है कि कोई दिन दैनिक प्रगति रेखाओं के लिए कार्यदिवस है या नहीं। |
| weekly_week_number | साप्ताहिक प्रगति रेखाओं के लिए सप्ताह संख्या को प्राप्त करता है या सेट करता है। |
| monthly_day | मासिक प्रगति रेखाओं को दिन के अनुसार दिखाने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| monthly_day_day_number | मासिक प्रगति रेखाओं के दिन संख्या को प्राप्त करता है या सेट करता है। |
| monthly_day_month_number | मासिक प्रगति रेखाओं के महीने संख्या को प्राप्त करता है या सेट करता है। |
| monthly_first_last | पहले या अंतिम पूर्वनिर्धारित दिन के अनुसार प्रगति रेखाओं को दिखाने का संकेत देने वाले मान को प्राप्त करता है या सेट करता है। |
| monthly_first_last_month_number | पहले या अंतिम पूर्वनिर्धारित दिन के अनुसार दिखाए जाने वाली प्रगति रेखाओं के महीने संख्या को प्राप्त करता है या सेट करता है। |
| monthly_first_last_day | मासिक प्रगति रेखाओं के पहले या अंतिम दिन प्रकार को प्राप्त करता है या सेट करता है। |
| weekly_days | साप्ताहिक प्रगति रेखाओं के लिए दिनों की सूची प्राप्त करता है। |
