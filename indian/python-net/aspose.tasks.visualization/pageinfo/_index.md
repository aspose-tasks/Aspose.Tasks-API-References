## PageInfo class

MPP फ़ाइल फ़ॉर्मेट में मौजूद और प्रिंटिंग के लिए उपयोग किए जाने वाले पेज सेटअप डेटा को दर्शाता है।

PageInfo प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| PageInfo() | नया उदाहरण प्रारंभ करता है [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) क्लास का। <br/>            MPP फ़ाइल फ़ॉर्मेट में मौजूद पेज सेटअप डेटा को दर्शाता है और प्रिंटिंग के लिए उपयोग किया जाता है। |
