## BarStyle class

प्रोजेक्ट व्यू में आइटम के बार की दृश्य शैली बदलें।

BarStyle प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| BarStyle() | एक नया उदाहरण प्रारंभ करता है [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/) वर्ग का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| bar_color | बार शैली की aspose.pydrawing.Color को प्राप्त करता है या सेट करता है। |
| start_shape_color | बार की शुरुआत में आकार की aspose.pydrawing.Color को प्राप्त करता है या सेट करता है। |
| start_shape_type | प्रारंभिक आकृति का प्रकार प्राप्त करता है या सेट करता है। |
| end_shape_color | बार के अंत में आकार की aspose.pydrawing.Color को प्राप्त करता है या सेट करता है। |
| end_shape_type | अंत आकार का प्रकार प्राप्त करता है या सेट करता है।<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | बार शैली के [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) को प्राप्त करता है या सेट करता है। |
| bar_shape | बार शैली के [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) को प्राप्त करता है या सेट करता है। |
| start_shape | बार की शुरुआत में [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) को प्राप्त करता है या सेट करता है। |
| end_shape | बार के अंत में [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) को प्राप्त करता है या सेट करता है। |
| text_style | बार के पाठ की शैली को प्राप्त करता है या सेट करता है। |
| left_field | बार के बाएँ तरफ प्रदर्शित होने वाले फ़ील्ड को प्राप्त करता है या सेट करता है। |
| top_field | बार के शीर्ष पर प्रदर्शित होने वाले फ़ील्ड को प्राप्त करता है या सेट करता है। |
| right_field | बार के दाएँ तरफ प्रदर्शित होने वाले फ़ील्ड को प्राप्त करता है या सेट करता है। |
| bottom_field | बार के नीचे प्रदर्शित होने वाले फ़ील्ड को प्राप्त करता है या सेट करता है। |
| inside_field | बार के अंदर प्रदर्शित होने वाले फ़ील्ड को प्राप्त करता है या सेट करता है। |
| from_address | गैंट बार के प्रारंभ बिंदु की स्थिति को प्राप्त करता है या सेट करता है।<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | गैंट बार के समाप्ति बिंदु की स्थिति को प्राप्त करता है या सेट करता है। |
