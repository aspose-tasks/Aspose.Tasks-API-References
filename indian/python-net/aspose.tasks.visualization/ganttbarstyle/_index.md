## GanttBarStyle class

MSP द्वारा Gantt Chart व्यू में उपयोग किए जाने वाले बार शैली को दर्शाता है।

GanttBarStyle प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| GanttBarStyle() | नए उदाहरण को प्रारंभ करता है [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/) क्लास का। |

| end_shape | बार के अंत आकार को प्राप्त करता है या सेट करता है। |

| from_address | गैंट बार के प्रारंभ बिंदु की स्थिति को प्राप्त करता है या सेट करता है।<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | बार के अंदर प्रदर्शित होने वाले डेटा को प्राप्त करता है या सेट करता है।<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
