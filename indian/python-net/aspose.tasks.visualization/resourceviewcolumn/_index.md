## ResourceViewColumn class

रिसोर्स उपयोग व्यू और रिसोर्स शीट व्यू में उपयोग की जाने वाली प्रोजेक्ट की व्यू क्लास।

ResourceViewColumn प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| ResourceViewColumn(width, field) | ResourceViewColumn क्लास का नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| field | कॉलम फ़ील्ड। <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/). |
| name | कॉलम का नाम प्राप्त करता है। |
| string_alignment | पाठ का संरेखण प्राप्त करता है या सेट करता है (यह [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/) enumeration के मानों में से एक हो सकता है)। |
| width | कॉलम की चौड़ाई प्राप्त करता है। |
| text_style_modification_callback | कॉलम की कोशिकाओं की उपस्थिति को अनुकूलित करने के लिए उपयोग किया जा सकने वाला कॉलबैक प्राप्त करता है या सेट करता है। |
## Methods
