## FontDescriptor class

फ़ॉन्ट जानकारी को दर्शाता है।

FontDescriptor प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| FontDescriptor(font_family, size) | FontDescriptor क्लास की नई इंस्टेंस को प्रारंभ करता है |
| FontDescriptor(font_family, size, style) | FontDescriptor क्लास की नई इंस्टेंस को प्रारंभ करता है |
| FontDescriptor(font, style) | निर्दिष्ट फ़ॉन्ट परिवार, आकार और शैली के साथ [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) क्लास की नई इंस्टेंस को प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| font_family | फ़ॉन्ट परिवार का नाम प्राप्त करता है। |
| size | फ़ॉन्ट का आकार प्राप्त करता है। |
| style | फ़ॉन्ट की शैली प्राप्त करता है। |
