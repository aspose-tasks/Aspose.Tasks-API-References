## Gridline class

प्रोजेक्ट व्यू में दिखाई देने वाली क्षैतिज या लंबवत रेखा।

Gridline प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Gridline() | नया उदाहरण प्रारंभ करता है [Gridline](/tasks/python-net/aspose.tasks.visualization/gridline/) क्लास का। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| color | एक ग्रिडलाइन का [color](/tasks/python-net/aspose.tasks.visualization/gridline/) प्राप्त करता है या सेट करता है। |
| gridline_type | ग्रिडलाइन का प्रकार ([gridline_type](/tasks/python-net/aspose.tasks.visualization/gridline/)) प्राप्त करता है या सेट करता है। |
| pattern | एक ग्रिडलाइन का [LinePattern](/tasks/python-net/aspose.tasks.visualization/linepattern/) प्राप्त करता है या सेट करता है। |
