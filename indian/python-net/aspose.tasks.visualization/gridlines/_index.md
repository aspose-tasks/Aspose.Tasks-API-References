## Gridlines class

GanttChart व्यू में दिखाई देने वाली ग्रिडलाइन को दर्शाता है।

Gridlines प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Gridlines() | Gridlines क्लास का नया इंस्टेंस इनिशियलाइज़ करता है |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| interval | 0 से 99 तक की संख्या प्राप्त करता है या सेट करता है जो ग्रिडलाइन के बीच अंतराल को निर्दिष्ट करती है। |
| interval_color | द्वितीयक ग्रिडलाइन का रंग प्राप्त करता है या सेट करता है। |
| interval_pattern | सेकेंडरी ग्रिडलाइन के लिए लाइन पैटर्न को प्राप्त करता है या सेट करता है। |
| normal_color | नॉर्मल ग्रिडलाइन के रंग को प्राप्त करता है या सेट करता है। |
| normal_pattern | नॉर्मल ग्रिडलाइन के लिए लाइन पैटर्न को प्राप्त करता है या सेट करता है। |
| type | ग्रिडलाइन प्रकार को प्राप्त करता है या सेट करता है। |
