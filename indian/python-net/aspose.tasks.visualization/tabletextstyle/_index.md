## TableTextStyle class

व्यू टेबल में टेक्स्ट शैली का प्रतिनिधित्व करता है।

TableTextStyle प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| TableTextStyle(row_uid) | TableTextStyle क्लास का एक नया उदाहरण प्रारंभ करता है। |
| TableTextStyle(row_uid, font) | TableTextStyle क्लास का एक नया उदाहरण प्रारंभ करता है। |
| TableTextStyle(row_uid, font_size, font_style) | TableTextStyle क्लास का एक नया उदाहरण प्रारंभ करता है। |
| TableTextStyle(row_uid, font_style) | TableTextStyle क्लास का एक नया उदाहरण प्रारंभ करता है। |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| font | टेक्स्ट शैली का फ़ॉन्ट प्राप्त करता है या सेट करता है। |
| color | टेक्स्ट का रंग प्राप्त करता है या सेट करता है। |
| item_type | एक मान लौटाता है जो [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) enum का है। |
| background_pattern | टेक्स्ट शैली का बैकग्राउंड पैटर्न प्राप्त करता है या सेट करता है।<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | टेक्स्ट शैली का बैकग्राउंड रंग प्राप्त करता है या सेट करता है।<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| row_uid | एक पंक्ति का अद्वितीय आईडी प्राप्त करता है। |
| field | स्टाइल लागू होने वाले फ़ील्ड को प्राप्त करता है या सेट करता है.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/tabletextstyle/). |
