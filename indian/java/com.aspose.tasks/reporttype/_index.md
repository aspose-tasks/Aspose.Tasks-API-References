### Burndown {#Burndown}
```
public static final int Burndown
```


कार्य बर्नडाउन और टास्क बर्नडाउन चार्ट शामिल हैं। कार्य बर्नडाउन चार्ट दिखाता है कि लोगों ने कितना कार्य पूरा किया है, परियोजना समाप्ति तिथि से पहले कितना कार्य समाप्त करने की योजना है, और इस बिंदु पर परियोजना में कितना कार्य पूरा होगा इसका बेसलाइन अनुमान। टास्क बर्नडाउन चार्ट दिखाता है समाप्त हुए कार्यों की संख्या, शेष कार्यों की संख्या, और इस बिंदु पर कितने कार्य समाप्त होंगे इसका बेसलाइन अनुमान।
