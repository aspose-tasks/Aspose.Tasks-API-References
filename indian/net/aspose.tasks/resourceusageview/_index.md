## उदाहरण

संसाधन उपयोग दृश्य को रेंडर करने का तरीका दिखाता है।

```csharp
var project = new Project(DataDir + "ResourceUsageView.mpp");

// आवश्यक TimeScale सेटिंग्स को Days के रूप में सेट करके SaveOptions को परिभाषित करें।
SaveOptions options = new PdfSaveOptions
{
    Timescale = Timescale.Days,

    // Presentation फ़ॉर्मेट को ResourceUsage पर सेट करें।
    PresentationFormat = PresentationFormat.ResourceUsage
};

project.Save(OutDir + "ResourceUsage_days_out.pdf", options);
```
