## PrimaveraReadOptions.ReadBaselineProjects property

एक फ़्लैग प्राप्त करता है या सेट करता है जो यह निर्दिष्ट करता है कि बेसलाइन प्रोजेक्ट लोड किए जाने चाहिए या नहीं। डिफ़ॉल्ट मान true है।

```csharp
public bool ReadBaselineProjects { get; set; }
```

## टिप्पणियाँ

यह फ़्लैग उन Primavera XML फ़ाइलों पर लागू होता है जिनमें बेसलाइन प्रोजेक्ट होते हैं (बेसलाइन XER फ़ॉर्मेट द्वारा समर्थित नहीं हैं)। जब बेसलाइन डेटा की आवश्यकता नहीं होती है, तो बड़े प्रोजेक्ट को बेसलाइन के साथ लोड करने की गति बढ़ाने के लिए इस विकल्प को false सेट किया जा सकता है।
