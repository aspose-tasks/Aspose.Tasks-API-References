## ReportType enumeration

```csharp
public enum ReportType
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| ProjectOverview | `0` | परियोजना की शुरूआत और समाप्ति तिथि, पूर्ण अवधि का प्रतिशत, शीर्ष-स्तर कार्यों की पूर्णता प्रतिशत और आने वाले माइलस्टोन को दिखाता है। |
| CostOverview | `1` | परियोजना की शुरूआत और समाप्ति तिथियों, वर्तमान निर्धारित और शेष लागत, % पूर्णता और शीर्ष-स्तर कार्यों के लागत मान को दिखाता है। |
| WorkOverview | `2` | प्रत्येक शीर्ष-स्तर कार्य के लिए बेसलाइन, वास्तविक और शेष कार्य तथा कार्य संसाधनों के लिए कार्य को दिखाता है। |
| ResourceOverview | `3` | संसाधन के अनुसार बेसलाइन, वास्तविक और शेष कार्य को दिखाता है। |
| ResourceCostOverview | `4` | संसाधन के अनुसार बेसलाइन, वास्तविक और शेष लागत को दिखाता है। |
| CriticalTasks | `5` | परियोजना के महत्वपूर्ण कार्यों को दिखाता है। |
| LateTasks | `6` | परियोजना के देर से होने वाले कार्यों को दिखाता है। |
| Milestones | `7` | देर से होने वाले, आने वाले और पूर्ण हुए माइलस्टोन को दिखाता है। |
| UpcomingTask | `8` | वर्तमान सप्ताह के दौरान नियत कार्यों और वर्तमान सप्ताह में शुरू होने वाले कार्यों को दिखाता है। |
| CostOverruns | `9` | कार्य और संसाधन के अनुसार लागत विचलन को दिखाता है। |
| TaskCostOverview | `10` | सभी शीर्ष-स्तर कार्यों की बेसलाइन, वास्तविक और शेष लागत को दिखाता है। |
| OverallocatedResources | `11` | अधिक आवंटित संसाधनों के लिए शेष कार्य घंटों की संख्या को दिखाता है। |
| SlippingTasks | `12` | ऐसे कार्यों को दिखाता है जो उनकी बेसलाइन समाप्ति तिथियों के बाद समाप्त होने के नियत हैं (बेसलाइन सेट होना आवश्यक है)। |
| BestPracticeAnalyzer | `13` | ऐसे कार्यों को दिखाता है जिनमें वास्तविक कार्य नहीं है, असाइन न किए गए कार्य, 8 घंटे से कम अवधि वाले कार्य और संसाधनों के साथ असाइन किए गए सारांश। |
| Burndown | `14` | काम बर्नडाउन और कार्य बर्नडाउन चार्ट शामिल हैं। काम बर्नडाउन चार्ट दिखाता है कि लोगों ने कितना काम पूरा किया है, परियोजना समाप्ति तिथि से पहले कितना काम निर्धारित है, और इस बिंदु पर परियोजना में कितना काम पूरा होगा इसका बेसलाइन अनुमान। कार्य बर्नडाउन चार्ट दिखाता है पूर्ण हुए कार्यों की संख्या, शेष कार्यों की संख्या, और इस बिंदु पर कितने कार्य पूरे होंगे इसका बेसलाइन अनुमान। |
| CashFlow | `15` | सभी शीर्ष-स्तर कार्यों के लिए प्रति तिमाही लागत और संचयी लागत को दिखाता है। |

## उदाहरण

दिखाता है कि प्रोजेक्ट बर्नडाउन रिपोर्ट को PDF फ़ॉर्मेट में निर्दिष्ट स्ट्रीम पर कैसे सहेजा जाए।

```csharp
var project = new Project(DataDir + @"Homemoveplan.mpp");
using (var stream = new FileStream(OutDir + "Burndown_out.pdf", FileMode.Create))
{
    project.SaveReport(stream, ReportType.Burndown);
}
```
