## TimescaleTier.RenderLabelOnEachPage property

एक फ़्लैग प्राप्त करता है या सेट करता है जो निर्धारित करता है कि जब समय अवधि कई पृष्ठों में फैली हो तो प्रत्येक पृष्ठ पर डेट लेबल रेंडर किए जाएँ या नहीं। यदि मान 'true' है, तो समय अवधि कई पृष्ठों में फैली होने पर अवधि के डेट लेबल प्रत्येक पृष्ठ पर रेंडर होते हैं। यदि मान 'false' है, तो डेट लेबल केवल एक बार रेंडर होता है, जो [`Alignment`](../alignment/) प्रॉपर्टी के मान के अनुसार होता है।

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
