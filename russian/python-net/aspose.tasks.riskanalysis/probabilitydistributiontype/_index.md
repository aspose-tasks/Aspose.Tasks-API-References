## ProbabilityDistributionType enumeration

Указывает типы поддерживаемых распределений вероятностей.

## Members
| Имя члена | Описание |
| :- | :- |
| UNIFORM | Распределение, при котором каждое значение выбирается с одинаковой вероятностью. |
| NORMAL | Распределение, иногда неформально называемое колоколообразной кривой (гауссово распределение). |
