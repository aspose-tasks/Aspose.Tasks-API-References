Содержит классы для создания отчёта анализа рисков.

## Классы
| Класс | Описание |
| :- | :- |
| [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) | Представляет результат анализа рисков. |
| [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) | Указывает настройки для выполнения анализа рисков. |
| [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) | Выполняет моделирование Монте-Карло на основе указанных настроек анализа рисков. |
| [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) | Представляет элемент, который хранит статистические данные для задачи анализируемого проекта. |
| [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) | Представляет коллекцию, содержащую экземпляры класса [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) | Представляет шаблон риска для задачи проекта. |
| [RiskPatternCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskpatterncollection/) | Представляет коллекцию, содержащую экземпляры класса [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
