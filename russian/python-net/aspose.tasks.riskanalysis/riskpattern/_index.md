## RiskPattern class

Представляет шаблон риска для задачи проекта.

Тип RiskPattern раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RiskPattern(task) | Инициализирует новый экземпляр класса [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
## Свойства
| Имя | Описание |
| :- | :- |
| task | Получает задачу проекта, к которой применяется данный шаблон риска. |
| distribution | Получает или задает распределение вероятностей, используемое в моделировании Монте-Карло.<br/>            Значение по умолчанию — ProbabilityDistributionType.Normal. |
| confidence_level | Получает или задает уровень доверия, соответствующий проценту времени, когда фактические сгенерированные значения находятся в пределах оптимистичных и пессимистичных оценок.<br/>            Значение по умолчанию — CL99. |
| optimistic | Получает или задает процент наиболее вероятной продолжительности задачи, который может произойти в наилучшем сценарии проекта.<br/>            Значение по умолчанию — 75, что означает, что если оценочная продолжительность задачи составляет 4 дня, то оптимистичная продолжительность будет 3 дня. |
| pessimistic | Получает или задает процент наиболее вероятной продолжительности задачи, который может произойти в наихудшем сценарии проекта.<br/>            Значение по умолчанию — 125, что означает, что если оценочная продолжительность задачи составляет 4 дня, то пессимистичная продолжительность будет 5 дней. |
