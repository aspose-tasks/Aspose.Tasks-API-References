## RiskAnalyzer class

Выполняет моделирование Монте-Карло на основе указанных настроек анализа рисков.

Тип RiskAnalyzer раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RiskAnalyzer(settings) | Инициализирует новый экземпляр класса [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |
## Свойства
| Имя | Описание |
| :- | :- |
| settings | Получает или задает экземпляр класса [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/), определяющий необходимые настройки для анализа рисков. |
## Методы
| Имя | Описание |
| :- | :- |
| analyze(project) | Выполняет анализ рисков для указанного проекта. Анализ основан на моделировании Монте-Карло, и результат представляет собой экземпляр класса [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/). |
