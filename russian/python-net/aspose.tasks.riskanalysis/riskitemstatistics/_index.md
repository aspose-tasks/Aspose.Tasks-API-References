## RiskItemStatistics class

Представляет элемент, который хранит статистические данные для задачи анализируемого проекта.

Тип RiskItemStatistics раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| item_type | Получает экземпляр перечисления [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/). |
| minimum | Получает минимальное значение, сгенерированное во время моделирования Монте-Карло. |
| maximum | Получает максимальное значение, сгенерированное во время моделирования Монте-Карло. |
| expected_value | Получает ожидаемое значение элемента риска. |
| standard_deviation | Получает стандартное отклонение элемента риска. |
## Методы
| Имя | Описание |
| :- | :- |
| get_percentile(percent) | Получает значение, ниже которого падает указанный процент сгенерированных образцов. |
