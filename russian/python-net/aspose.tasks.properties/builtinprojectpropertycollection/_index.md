## BuiltInProjectPropertyCollection class

Представляет коллекцию встроенных свойств проекта.

Тип BuiltInProjectPropertyCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| title | Получает или задает заголовок проекта. |
| subject | Получает или задает тему проекта. |
| author | Получает или задает автора проекта. |
| manager | Получает или задает руководителя проекта. |
| company | Получает или задает компанию проекта. |
| category | Получает или задает категорию проекта. |
| keywords | Получает или задает ключевые слова проекта. |
| comments | Получает или задает комментарии проекта. |
| hyperlink_base | Получает или задает базовый URL гиперссылки проекта. |
| имена |  |
