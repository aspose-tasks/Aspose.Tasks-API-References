## CustomPropertyType enumeration

Представляет перечисление типов пользовательских свойств.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Свойство не имеет типа. |
| STRING | Свойство имеет строковое значение. |
| DATE_TIME | Свойство является значением даты и времени. |
| NUMBER | Свойство является целочисленным значением. |
| BOOLEAN | Свойство является логическим значением. |
