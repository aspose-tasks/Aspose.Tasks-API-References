## ProjectDisplayOptions class

Представляет параметры отображения экземпляра проекта.

Тип ProjectDisplayOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ProjectDisplayOptions() | Инициализирует новый экземпляр класса [ProjectDisplayOptions](/tasks/python-net/aspose.tasks/projectdisplayoptions/) . |
## Свойства
| Имя | Описание |
| :- | :- |
| add_space_before_label | Получает или задает значение, указывающее, следует ли добавлять пробел перед числовым значением и сокращением времени (1 wk as opposed to 1wk). |
| underline_hyperlinks | Получает или задает значение, указывающее, следует ли подчёркивать гиперссылки. |
| show_task_schedule_warnings | Получает или задает значение, указывающее, следует ли показывать предупреждения, когда Project обнаруживает возможный конфликт планирования с вручную запланированной задачей. |
| show_task_schedule_suggestions | Получает или задает значение, указывающее, следует ли показывать предложения, когда Project обнаруживает возможный конфликт планирования с вручную запланированной задачей. |
| show_project_summary_task | Получает или задает значение, указывающее, следует ли отображать сводную информацию о полном проекте в одной строке со своей полосой сводной задачи в верхней части представления диаграммы Ганта. |
| minute_label | Получает или задает способ отображения метки минут. |
| hour_label | Получает или задает способ отображения метки часов. |
| day_label | Получает или задает способ отображения метки дней. |
| week_label | Получает или задает способ отображения метки недель. |
| month_label | Получает или задает, как отображается метка месяца. |
| year_label | Получает или задает, как отображается метка года. |
