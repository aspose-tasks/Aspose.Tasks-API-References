## AssignmentBaseline class

Представляет базовую линию назначения ресурса.

Тип AssignmentBaseline раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| AssignmentBaseline() | Инициализирует новый экземпляр класса AssignmentBaseline |
## Свойства
| Имя | Описание |
| :- | :- |
| baseline_number | Получает или задает уникальный номер записи данных базовой линии. |
| work | Получает или задает работу, назначенную ресурсу при сохранении базовой линии. |
| cost | Получает или задает прогнозируемую стоимость ресурса при сохранении базовой линии. |
| bcws | Получает или задает бюджетную стоимость работы, запланированной для ресурса. |
| bcwp | Получает или задает бюджетную стоимость работы, выполненной ресурсом для проекта на текущую дату. |
| timephased_data | Получает или задает экземпляр [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) для этого объекта.<br/>            Данные, распределённые по времени, связанные с базовой линией назначения ресурса. |
| начало | Получает или задает запланированную дату начала назначения ресурса, когда базовая линия была сохранена. |
| finish | Получает или задает запланированную дату завершения назначения ресурса, когда базовая линия была сохранена. |
