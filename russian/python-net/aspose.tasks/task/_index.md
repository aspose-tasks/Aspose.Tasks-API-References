## Методы
| Имя | Описание |
| :- | :- |
| get_timephased_data(start, end, timephased_type) | Возвращает объект [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) со значениями [timephased_data](/tasks/python-net/aspose.tasks/task/) в указанных начальной и конечной датах заданного типа временных данных. |
| get_timephased_data(start, end) | Возвращает объект [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) со значениями [timephased_data](/tasks/python-net/aspose.tasks/task/) в указанных начальной и конечной датах заданного типа временных данных. |
| move_to_sibling(before_task) | Перемещает текущую задачу на том же уровне Outline перед указанной задачей.<br/>            Если ParentProject.CalculationMode имеет значение None, пользователь должен вызвать Project.Recalculate() после использования этого метода (это перенесёт все задачи проекта (даты начала/окончания, устанавливает ранние/поздние даты) и вычислит зависимые поля, такие как запасы времени, трудозатраты и стоимость, уровни Outline).<br/>            Если ParentProject.CalculationMode имеет значение Manual, метод автоматически вычислит только идентификатор задачи, уровень Outline и номера Outline.<br/>            Если ParentProject.CalculationMode имеет значение Automatic, метод автоматически перенесёт все задачи проекта<br/>            (даты начала/окончания, устанавливает ранние/поздние даты, вычисляет запасы времени, трудозатраты и стоимость, пересчитывает идентификаторы и уровни Outline). |
| move_to_sibling(before_task_id) |  |
| select_all_child_tasks() | Рекурсивно собирает все дочерние задачи этой задачи. |
| clone() | Создаёт полную копию задачи без подзадач. |
| equals(other) | Возвращает значение, указывающее, равен ли этот экземпляр указанной задаче. |
| delete() | Удаляет задачу из коллекции задач родительского проекта и все её назначения. |
| outline_indent() | Добавляет отступ задаче в структуре. |
| outline_outdent() | Продвигает задачу в структуре. |
