## WeekDay class

Представляет день недели, который определяет либо обычные дни недели, либо исключительные дни в календаре.

Тип WeekDay раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| WeekDay(day_type) | Инициализирует новый экземпляр класса [WeekDay](/tasks/python-net/aspose.tasks/weekday/) с указанным типом дня. |
| WeekDay(day_type, working_times) | Инициализирует новый экземпляр класса WeekDay |
| WeekDay(day_type, working_times) | Инициализирует новый экземпляр класса [WeekDay](/tasks/python-net/aspose.tasks/weekday/) с указанным типом дня и периодами рабочего времени. |
| WeekDay() | Инициализирует новый экземпляр класса [WeekDay](/tasks/python-net/aspose.tasks/weekday/) с указанным типом дня. |
## Свойства
| Имя | Описание |
| :- | :- |
| day_type | Получает тип дня. |
| day_working | Получает или задает значение, указывающее, является ли указанная дата или тип дня рабочим. |
| from_date | Получает или задает начало исключительного времени. |
| to_date | Получает или задает конец исключительного времени. |
| working_times | Получает WorkingTimeCollection для этого экземпляра WeekDay.<br/>            Коллекция рабочих периодов, определяющих время работы в будний день. |
## Методы
| Имя | Описание |
| :- | :- |
| create_default_working_day(day_type) | Создает рабочий день по умолчанию. |
| set_default_working_time(day) | Задает период времени по умолчанию для указанного дня недели. |
| get_working_time() | Возвращает рабочее время для дня недели. |
| clone() | Возвращает глубокую копию дня недели. |
