## TableField class

Представляет поле таблицы в проекте.

Тип TableField раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TableField() | Инициализирует новый экземпляр класса [TableField](/tasks/python-net/aspose.tasks/tablefield/). |
## Свойства
| Имя | Описание |
| :- | :- |
| align_data | Получает или задает выравнивание данных в поле таблицы. |
| align_title | Получает или задает выравнивание заголовка в поле таблицы. |
| field | Получает или задает тип поля таблицы. |
| title | Получает или задает заголовок поля в таблице. |
| width | Получает или задает ширину в пунктах столбца поля в таблице. |
| wrap_header | Получает или задает значение, указывающее, может ли заголовок столбца таблицы переноситься на несколько строк или должен обрезаться, когда превышает ширину столбца. |
| wrap_text | Получает или задает значение, указывающее, может ли текст столбца переноситься на несколько строк или должен обрезаться, когда превышает ширину столбца. |
