## Rate class

Представляет определение временного периода и ставок, применимых к ресурсу в течение этого периода.

Тип Rate раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| rates_from | Получает или задает дату, с которой ставка вступает в силу. |
| rates_to | Получает или задает последнюю дату, когда ставка действительна. |
| rate_table | Получает или задает уникальный идентификатор таблицы ставок для ресурса. |
| standard_rate | Получает или задает стандартную ставку в час для ресурса. |
| standard_rate_format | Получает или задает единицы измерения, используемые Microsoft Project для отображения стандартной ставки. |
| overtime_rate | Получает или задает ставку сверхурочных в час для ресурса. |
| overtime_rate_format | Получает или задает единицы измерения, используемые Microsoft Project для отображения ставки сверхурочных. |
| cost_per_use | Получает или задает стоимость использования ресурса. Это значение извлекается из текущей даты, если для ресурса существует таблица ставок. |
