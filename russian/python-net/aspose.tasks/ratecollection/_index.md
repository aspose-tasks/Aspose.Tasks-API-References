## RateCollection class

Представляет коллекцию, содержащую объекты [Rate](/tasks/python-net/aspose.tasks/rate/).

Тип RateCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| count | Возвращает количество элементов, содержащихся в RateCollection. |
| is_read_only | Возвращает значение, указывающее, является ли эта коллекция только для чтения. |
| parent_resource | Получает родительский объект [Resource](/tasks/python-net/aspose.tasks/resource/) для этой коллекции. |
## Методы
| Имя | Описание |
| :- | :- |
| add(rates_from) | Добавляет новый экземпляр [Rate](/tasks/python-net/aspose.tasks/rate/) в эту коллекцию. |
| add(rates_from, type) | Добавляет новый экземпляр [Rate](/tasks/python-net/aspose.tasks/rate/) в эту коллекцию. |
| to_list() | Преобразует объект [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) в список объектов [Rate](/tasks/python-net/aspose.tasks/rate/). |
| to_list(type) | Преобразует объект [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) в список объектов [Rate](/tasks/python-net/aspose.tasks/rate/), отфильтрованных по указанному типу [RateType](/tasks/python-net/aspose.tasks/ratetype/). |
| remove(item) | Удаляет экземпляр Rate из этой коллекции. |
