## FontResolveEventArgs class

Предоставляет аргументы для обратного вызова, который вызывается при разрешении шрифта.

Тип FontResolveEventArgs раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| requested_font_name | Возвращает имя запрошенного шрифта. |
| resolved_font_name | Возвращает или задает имя разрешённого шрифта. Может быть установлен для управления шрифтами, используемыми при рендеринге представления. |
