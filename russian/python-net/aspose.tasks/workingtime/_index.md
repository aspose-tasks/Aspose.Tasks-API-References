## Конструкторы
| Имя | Описание |
| :- | :- |
| WorkingTime(from_time, to_time) | Инициализирует новый экземпляр класса [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) с интервалом, заданным указанными временем начала и окончания. |
| WorkingTime(from_time, to_time) | Инициализирует новый экземпляр класса [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) с элементом интервала, заданным указанными временем начала и окончания. |
