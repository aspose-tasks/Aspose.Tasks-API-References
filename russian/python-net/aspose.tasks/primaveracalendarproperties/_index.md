## PrimaveraCalendarProperties class

Представляет специфичные для Primavera свойства календаря, считанного из файлов Primavera (XER или P6XML).<br/>            Может использоваться для выполнения преобразования единиц времени, специфичных для календаря.

Тип PrimaveraCalendarProperties раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| hours_per_day | Получает количество часов в день из настроек 'Time Periods' календаря. |
| hours_per_week | Получает количество часов в неделю из настроек 'Time Periods' календаря. |
| hours_per_month | Получает количество часов в месяц из настроек 'Time Periods' календаря. |
| hours_per_year | Получает количество часов в месяц из настроек 'Time Periods' календаря. |
