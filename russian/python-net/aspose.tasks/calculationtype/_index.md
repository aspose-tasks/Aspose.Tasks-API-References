## CalculationType enumeration

Указывает тип расчёта значения пользовательского атрибута.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Означает, что расширенный атрибут не имеет таблицы поиска формул и просто сохраняет значение, установленное пользователем. |
| LOOKUP | Означает, что значение расширенного атрибута ограничено значениями из таблицы поиска. |
| FORMULA | Означает, что значение расширенного атрибута вычисляется с помощью формулы, определённой в [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
