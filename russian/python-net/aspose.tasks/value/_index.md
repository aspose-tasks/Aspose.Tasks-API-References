## Value class

Представляет значение в списке значений.

Тип Value раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Value() | Инициализирует новый экземпляр класса [Value](/tasks/python-net/aspose.tasks/value/). |
## Свойства
| Имя | Описание |
| :- | :- |
| id | Получает или задает уникальный идентификатор значения в проекте. |
| value_guid | Получает GUID, который идентифицирует это значение среди остальных во всём проекте. |
| val | Получает или задает фактическое значение во внутреннем представлении. Предпочтительно использовать строго типизированные свойства, перечисленные ниже. |
| string_value | Получает или задает фактическое значение, используемое для представления текстовой строки. |
| numeric_value | Получает или задает фактическое значение, используемое для представления числового или стоимостного значения. |
| duration | Получает или задает фактическое значение, используемое для представления длительности. |
| date_time_value | Получает или задает фактическое значение, если оно может быть представлено как DateTime. Значение по умолчанию — минимальная дата. |
| description | Получает или задает описание значения. |
| phonetic | Получает или задает фонетическую информацию о названии пользовательского поля. |
