## TaskStatus enumeration

Указывает статус задачи.

## Members
| Имя члена | Описание |
| :- | :- |
| UNDEFINED | Неопределенный статус задачи. |
| COMPLETE | Задача выполнена на 100 процентов. |
| ON_SCHEDULE | Задача находится в графике, если кумулятивный процент выполнения по времени распределён как минимум до дня, предшествующего дате статуса. |
| LATE | Задача просрочена, если кумулятивный процент выполнения по времени не достигает полуночи дня, предшествующего дате статуса. |
| FUTURE | 'Future' статус задачи устанавливается, когда дата начала задачи больше даты статуса. |
