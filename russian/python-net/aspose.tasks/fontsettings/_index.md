## FontSettings class

Указывает настройки шрифта, используемые при рендеринге представления проекта.

Тип FontSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| FontSettings() | Инициализирует новый экземпляр класса FontSettings |
## Свойства
| Имя | Описание |
| :- | :- |
| default_font_name | Получает или задает шрифт по умолчанию (или резервный) для рендеринга. |
| use_project_default_font | Получает или задает значение, указывающее, должен ли использоваться шрифт по умолчанию для рендеринга. |
## Методы
| Имя | Описание |
| :- | :- |
| set_font_folders(font_folders, recursive) | Устанавливает папки, в которых Aspose.Tasks ищет шрифты TrueType при рендеринге представления проекта. |
