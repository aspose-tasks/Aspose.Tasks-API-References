## ExtendedAttribute class

Представляет расширенные атрибуты.

Тип ExtendedAttribute раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| attribute_definition | Возвращает определение атрибута. |
| field_id | Возвращает идентификатор поля. |
| duration_value | Получает или задает значение для атрибутов типа 'Duration'. |
| numeric_value | Получает или задает значение для атрибутов числовых типов (Cost, Number). |
| date_value | Получает или задает значение для атрибутов типов даты (Date, Start, Finish). |
| flag_value | Получает или задает значение, указывающее, установлен ли флаг для атрибута типа 'Flag'. |
| text_value | Получает или задает значение для атрибутов типа 'Text'. |
| value_guid | Возвращает GUID значения справочника. |
| value_read_only | Возвращает значение, указывающее, является ли значение этого [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) только для чтения. |
| is_error_value | Возвращает, произошла ли ошибка при вычислении значения расширенного атрибута. |
