## Metered class

Предоставляет методы для установки измеряемого ключа.

Тип Metered раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Metered() | Инициализирует новый экземпляр класса Metered |
## Методы
| Имя | Описание |
| :- | :- |
| set_metered_key(public_key, private_key) | Устанавливает публичный и приватный ключи Metered. |
| reset_metered_key() | Удаляет ранее настроенную лицензию. |
| get_consumption_credit() | Получает кредит потребления. |
| get_consumption_quantity() | Получает размер файла потребления. |
| is_licensed() | Проверяет, успешно ли продукт лицензирован с помощью лицензии Metered. |
