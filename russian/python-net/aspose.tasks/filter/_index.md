## Filter class

Представляет фильтр в Project.

Тип Filter раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Filter() | Инициализирует новый экземпляр класса Filter |
## Свойства
| Имя | Описание |
| :- | :- |
| filter_type | Получает тип фильтра. |
| name | Получает или задает имя объекта Filter. |
| show_in_menu | Получает или задает значение, указывающее, отображает ли проект имя фильтра в раскрывающемся списке Filter на вкладке View ленты. |
| show_related_summary_rows | Получает или задает значение, указывающее, отображаются ли связанные строки сводки для фильтра. |
| index | Получает индекс объекта [Filter](/tasks/python-net/aspose.tasks/filter/) в содержащем объекте Filters. |
| uid | Получает уникальный идентификатор фильтра. |
| criteria | Получает или задает критерии, которым задачи или ресурсы должны соответствовать для отображения в представлении MSP. |
## Методы
| Имя | Описание |
| :- | :- |
| compare_to(other) | Сравнивает этот экземпляр с указанным экземпляром класса [Filter](/tasks/python-net/aspose.tasks/filter/) и возвращает указание их относительного порядка. |
| equals(other) | Возвращает значение, указывающее, равен ли этот экземпляр указанному объекту AssignmentBaseline. |
