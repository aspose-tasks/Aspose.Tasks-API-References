## RecurringTaskInfo class

Представляет детали повторяющейся задачи в проекте.

Тип RecurringTaskInfo раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| recurrence_pattern | Получает или задает шаблон повторения повторяющейся задачи. |
| start_date | Получает или задает дату начала повторений. |
| end_date | Получает или задает дату окончания повторений. |
| duration | Получает или задает длительность одного повторения повторяющейся задачи. |
| occurrences | Получает или задает количество повторений повторяющейся задачи. |
| use_end_date | Получает или задает значение, указывающее, использовать дату окончания или количество повторений для повторяющейся задачи. |
| daily_repetitions | Получает или задает количество повторений для ежедневного шаблона повторения. |
| daily_use_workdays | Получает или задает значение, указывающее, использовать ли рабочие дни для ежедневного шаблона повторения. |
| weekly_repetitions | Получает или задает количество повторений для еженедельного шаблона повторения. |
| weekly_days | Получает или задает коллекцию дней, используемых в еженедельном шаблоне повторения. |
| monthly_use_ordinal_day | Получает или задает значение, указывающее, использовать ли порядковый день для ежемесячного шаблона повторения. |
| monthly_ordinal_number | Получает или задает порядковый номер ежемесячного шаблона повторения. |
| monthly_ordinal_repetitions | Получает или задает количество повторений для ежемесячного шаблона повторения при использовании порядкового дня. |
| monthly_day | Получает или задает число дня ежемесячного шаблона повторения. |
| monthly_repetitions | Получает или задает количество повторений для ежемесячного шаблона повторения. |
| yearly_use_ordinal_day | Получает или задает значение, указывающее, использовать ли порядковый день для ежегодного шаблона повторения. |
| yearly_date | Получает или задает дату для ежегодного шаблона повторения. |
| yearly_ordinal_number | Получает или задает порядковый номер ежегодного шаблона повторения. |
| yearly_ordinal_month | Получает или задает месяц ежегодного шаблона повторения при использовании порядкового дня. |
| task | Получает родительскую задачу этого экземпляра класса [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/) . |
