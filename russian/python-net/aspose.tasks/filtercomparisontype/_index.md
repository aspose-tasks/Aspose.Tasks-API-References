## FilterComparisonType enumeration

Тип сравнения между FieldName и Value, который служит критерием выбора для фильтра или графического индикатора.

## Members
| Имя члена | Описание |
| :- | :- |
| EQUALS | Значение поля Field равно Value. |
| DOES_NOT_EQUAL | Значение поля Field не равно Value. |
| IS_GREATER_THAN | Значение поля Field больше Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | Значение поля Field больше или равно Value. |
| IS_LESS_THAN | Значение поля Field меньше Value. |
| IS_LESS_THAN_OR_EQUAL_TO | Значение поля Field меньше или равно Value. |
| IS_WITHIN | Значение поля Field находится в пределах Value. |
| IS_NOT_WITHIN | Значение поля Field не находится в пределах Value. |
| CONTAINS | Значение поля Field содержит Value. |
| DOES_NOT_CONTAIN | Значение поля Field не содержит Value. |
| CONTAINS_EXACTLY | Значение поля Field точно содержит Value. |
| IS_ONE_OF | Значение поля Field равно одному из указанных значений Values. Используется в AutoFilters. |
| UNDEFINED | Неопределённое значение. |
| IS_ANY_VALUE | 'Is any value' условие. Применимо к графическим индикаторам. |
