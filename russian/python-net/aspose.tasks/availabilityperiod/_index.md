## AvailabilityPeriod class

Представляет период, когда ресурс доступен.

Тип AvailabilityPeriod раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| AvailabilityPeriod() | Инициализирует новый экземпляр [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | Инициализирует новый экземпляр [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) с указанным диапазоном дат и доступными единицами. |
## Свойства
| Имя | Описание |
| :- | :- |
| available_from | Получает или задает дату, когда ресурс становится доступным в указанный период. |
| available_to | Получает или задает последнюю дату, когда ресурс доступен в указанный период. |
| available_units | Получает или задает процент ресурса, доступного в указанный период. |
