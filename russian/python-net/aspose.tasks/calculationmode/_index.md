## CalculationMode enumeration

Указывает режим расчёта проекта.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | None. Даты проекта и затраты не пересчитываются в этом режиме. |
| AUTOMATIC | Автоматический режим. Даты проекта и затраты пересчитываются при использовании этого режима. |
| MANUAL | Ручной режим. В этом режиме пересчитываются только необходимые поля, например UID и ID объектов. |
