## BuildVersionInfo class

Содержит информацию о версии сборки и продукте.

Тип BuildVersionInfo раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| ASSEMBLY_VERSION | Версия сборки. |
| ASSEMBLY_INFORMATIONAL_VERSION | Информационный номер версии сборки. |
| FILE_VERSION | Версия файла. |
| ПРОДУКТ | Название продукта. |
