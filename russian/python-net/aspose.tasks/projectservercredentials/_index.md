## ProjectServerCredentials class

Учётные данные, которые используются для подключения к Project Online или локальному экземпляру Project Server.

Тип ProjectServerCredentials раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | Инициализирует новый экземпляр класса [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) с использованием URL сайта SharePoint и действительного токена авторизации SPOIDCRL для сайта PWA (Project Web Access) SharePoint. |
| ProjectServerCredentials(site_url, user_name, password) | Инициализирует новый экземпляр класса [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) с использованием URL сайта SharePoint и действительного токена авторизации SPOIDCRL для сайта PWA (Project Web Access) SharePoint. |
## Свойства
| Имя | Описание |
| :- | :- |
| site_url | Получает URL PWA на сайте SharePoint или URL локального сервера Project Server.<br/>            Например, https://your_company_name.sharepoint.com/sites/pwa"; |
| auth_token | Получает токен авторизации для экземпляра SharePoint. |
| user_name | Получает имя пользователя для сайта SharePoint. |
