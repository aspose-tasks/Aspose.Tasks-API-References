## PrimaveraTaskProperties class

Представляет специфичные для Primavera свойства задачи, считанной из файлов Primavera (XER или P6XML).

Тип PrimaveraTaskProperties раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| sequence_number | Получает или задает номер последовательности элемента WBS (сводные задачи). Используется для сортировки сводных задач в Primavera. |
| activity_id | Получает поле идентификатора активности — уникальный идентификатор задачи, используемый в Primavera. |
| remaining_early_finish | Получает дату раннего завершения оставшейся работы — дату, когда планируется завершить оставшуюся работу по активности. |
| remaining_early_start | Получает дату раннего начала оставшейся работы — дату, когда планируется начать оставшуюся работу по активности. |
| remaining_late_start | Получает дату позднего начала оставшейся работы. |
| remaining_late_finish | Получает дату позднего завершения оставшейся работы. |
| raw_duration_type | Получает необработанное текстовое представление (как в исходном файле) поля 'Duration Type' активности. |
| duration_type | Получает значение поля 'Duration Type' активности. |
| raw_activity_type | Получает необработанное текстовое представление (как в исходном файле) поля 'Activity Type' активности. |
| activity_type | Получает значение поля 'Activity Type'. |
| percent_complete_type | Получает значение поля '% Complete Type' активности. |
| raw_complete_percent_type | Получает необработанное текстовое представление (как в исходном файле) поля '% Complete Type' активности. |
| raw_status | Получает необработанное текстовое представление (как в исходном файле) поля 'Status' активности. |
| physical_percent_complete | Получает значение Physical Percent Complete. |
| duration_percent_complete | Получает значение duration percent complete. |
| units_percent_complete | Получает значение units percent complete. |
| actual_labor_units | Получает значение actual labor units. |
| actual_non_labor_units | Получает значение actual non labor units. |
| remaining_labor_units | Получает значение remaining labor units. |
| remaining_non_labor_units | Получает значение remaining non labor units. |
| actual_labor_cost | Получает значение actual labor cost . |
| budgeted_labor_cost | Получает значение budgeted (or planned) labor cost . |
| actual_nonlabor_cost | Получает значение actual non labor cost . |
| budgeted_nonlabor_cost | Получает значение budgeted (or planned) non labor cost . |
| actual_material_cost | Получает значение фактической стоимости материала. |
| budgeted_material_cost | Получает значение запланированной (или бюджетной) стоимости материала. |
| actual_expense_cost | Получает значение фактической стоимости расходов. |
| remaining_expense_cost | Получает значение оставшейся стоимости расходов. |
| budgeted_expense_cost | Получает значение запланированной (или бюджетной) стоимости расходов. |
| actual_total_cost | Получает общую стоимость фактических расходов. |
| budgeted_total_cost | Получает общую стоимость запланированных (или бюджетных) расходов. |
| primary_constraint_type | Получает тип первичного ограничения. |
| primary_constraint_date | Получает дату первичного ограничения. |
| secondary_constraint_type | Получает тип вторичного ограничения. |
| secondary_constraint_date | Получает дату вторичного ограничения. |
| planned_duration | Получает оригинальную или запланированную продолжительность — общее рабочее время от запланированной даты начала задачи до запланированной даты завершения.. |
