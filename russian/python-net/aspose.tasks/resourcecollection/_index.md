## ResourceCollection class

Представляет коллекцию объектов [Resource](/tasks/python-net/aspose.tasks/resource/).

Тип ResourceCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| parent_project | Получает родительский проект объекта ResourceCollection. |
## Методы
| Имя | Описание |
| :- | :- |
| add() | Добавляет новый ресурс в последнюю позицию коллекции ресурсов проекта. |
| add(resource_name) | Добавляет новый ресурс в последнюю позицию коллекции ресурсов проекта. |
| add(resource_name, before_resource_id) |  |
| to_list() | Преобразует объект ResourceCollection в список объектов [Resource](/tasks/python-net/aspose.tasks/resource/) . |
| get_by_id(id) | Возвращает ресурс с указанным идентификатором. |
| get_by_uid(uid) | Возвращает ресурс с указанным Uid. |
