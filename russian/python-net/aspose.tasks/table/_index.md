## Table class

Представляет таблицу в Project

Тип Table раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Table() | Инициализирует новый экземпляр класса [Table](/tasks/python-net/aspose.tasks/table/). |
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает или задает имя объекта Table. |
| show_in_menu | Получает или задает значение, указывающее, отображает ли проект имя таблицы в раскрывающемся списке Tables на вкладке View ленты. |
| table_fields | Получает коллекцию TableFields, представляющую поля в таблице. |
| table_type | Получает или задает тип таблицы для указанной таблицы. |
| uid | Получает уникальный идентификатор таблицы. |
| row_height | Получает или задает высоту строки в таблице, где высота строки — это количество строк текста. |
| date_format | Получает или задает формат даты таблицы. |
| adjust_header_row_height | Получает или задает значение, указывающее, можно ли изменить высоту строки заголовка таблицы. |
| show_add_new_column | Получает или задает значение, указывающее, показывать ли интерфейс 'Add New Column'. |
| lock_first_column | Получает или задает значение, указывающее, заблокирован ли первый столбец таблицы или доступен для редактирования. |
