## VbaModule class

Представляет модуль VBA.

Тип VbaModule раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| атрибуты | Получает коллекцию атрибутов модуля. |
| name | Получает имя VBA‑модуля |
| тип | Получает тип модуля. |
| source_code | Получает или задает исходный код VBA‑модуля |
## Методы
| Имя | Описание |
| :- | :- |
| create_procedural_module(name) | Создает экземпляр [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) с типом VbaModuleType.ProceduralModule. |
| create_class_module(name) | Создает экземпляр [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) с типом VbaModuleType.ClassModule. |
