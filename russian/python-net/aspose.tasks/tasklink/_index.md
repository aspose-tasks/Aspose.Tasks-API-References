## TaskLink class

Представляет предшествующую связь.

Тип TaskLink раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_cross_project | Получает или задает значение, указывающее, является ли предшественник частью другого проекта. |
| cross_project_name | Получает или задает внешний проект‑предшественник. |
| link_lag | Получает или задает задержку в десятых долях минуты или в процентах. |
| link_lag_time_span | Получает или задает длительность задержки в зависимости от LagFormat. |
| lag_format | Получает или задает формат представления задержки. |
| pred_task | Получает или задает задачу‑предшественник. |
| succ_task | Получает или задает задачу‑последователя. |
| link_type | Получает или задает тип ссылки. |
## Методы
| Имя | Описание |
| :- | :- |
| equals(other) | Возвращает значение, указывающее, равен ли данный экземпляр указанному объекту. |
