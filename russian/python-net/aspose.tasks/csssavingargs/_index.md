## CssSavingArgs class

Этот класс представляет набор данных, связанных с сохранением внешнего CSS‑файла, которое<br/>              происходит во время преобразования в формат HTML.

Тип CssSavingArgs раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| CssSavingArgs() | Инициализирует новый экземпляр класса [CssSavingArgs](/tasks/python-net/aspose.tasks/csssavingargs/). |
## Свойства
| Имя | Описание |
| :- | :- |
| file_name | Получает или задает предполагаемое имя файла, которое передаётся от конвертера к коду пользовательского метода.<br/>             Может использоваться в пользовательском коде для решения, как обрабатывать или где сохранять этот файл. |
| keep_stream_open | Получает или задает значение, указывающее, будет ли поток оставлен открытым после завершения сохранения ресурса. |
| stream | Получает или задает двоичное содержимое сохранённого файла. |
| uri | Получает или задает URI ресурса. |
## Методы
| Имя | Описание |
| :- | :- |
| close_stream_if_required() | Закрывает поток, если KeepStreamOpen равно false, иначе сбрасывает его. |
