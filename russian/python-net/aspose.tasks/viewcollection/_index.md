## ViewCollection class

Содержит список объектов [View](/tasks/python-net/aspose.tasks/view/).<br/>            Реализует интерфейс ICollection<View>.

Тип ViewCollection предоставляет следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| parent_project | Получает родительский объект View.<br/>            Только для чтения [Project](/tasks/python-net/aspose.tasks/project/). |
## Методы
| Имя | Описание |
| :- | :- |
| to_list() | Преобразует коллекцию представлений в список объектов [View](/tasks/python-net/aspose.tasks/view/). |
| get_by_view_screen(screen) | Ищет объект View с указанным свойством Screen и возвращает первое вхождение в коллекцию. |
| get_by_name(view_name) | Ищет объект View по имени и возвращает первое вхождение в коллекцию. |
