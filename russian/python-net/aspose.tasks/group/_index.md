## Group class

Представляет определение группы.<br/>            Объект Group является членом коллекции ResourceGroups или коллекции TaskGroups.

Тип Group раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Group() | Инициализирует новый экземпляр класса [Group](/tasks/python-net/aspose.tasks/group/) . |
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает или задает имя объекта Group. |
| uid | Получает уникальный идентификатор группы. |
| show_summary | Получает или задает значение, указывающее, отображаются ли строки сводки для группы. |
| maintain_hierarchy | Получает или задает значение, указывающее, показывать ли все уровни сводных задач для подзадач внутри группы. |
| show_in_menu | Получает или задает значение, указывающее, отображает ли Project имя группы в выпадающем списке Group на ленте. |
| group_assignments | Получает или задает значение, указывающее, должны ли назначения группироваться вместо задач. |
| group_criteria | Получает или задает коллекцию GroupCriteria, представляющую поля в определении группы. |
