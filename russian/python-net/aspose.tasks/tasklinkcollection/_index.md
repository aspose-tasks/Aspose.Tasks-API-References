## TaskLinkCollection class

Представляет коллекцию объектов [Task](/tasks/python-net/aspose.tasks/task/).

Тип TaskLinkCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| parent_project | Получает родительский проект объекта ResourceAssignmentCollection. |
## Методы
| Имя | Описание |
| :- | :- |
| add(pred, succ) | Возвращает экземпляр Finish-Start [TaskLink](/tasks/python-net/aspose.tasks/tasklink/), который был добавлен в объект TaskLinkCollection. |
| add(pred, succ, link_type) | Возвращает экземпляр [TaskLink](/tasks/python-net/aspose.tasks/tasklink/), который был добавлен в объект TaskLinkCollection. |
| add(pred, succ, link_type, lag) | Возвращает экземпляр [TaskLink](/tasks/python-net/aspose.tasks/tasklink/), который был добавлен в объект TaskLinkCollection. |
| to_list() | Преобразует объект TaskLinkCollection в список объектов [TaskLink](/tasks/python-net/aspose.tasks/tasklink/). |
