## CalendarException class

Представляет исключительные периоды времени в календаре.

Тип CalendarException раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| CalendarException() | Инициализирует новый экземпляр класса [CalendarException](/tasks/python-net/aspose.tasks/calendarexception/). |
## Свойства
| Имя | Описание |
| :- | :- |
| entered_by_occurrences | Получает или задает значение, указывающее, определяется ли диапазон повторения вводом количества повторений.<br/>            False указывает, что диапазон повторения определяется вводом конечной даты. |
| from_date | Получает или задает начало времени исключения. |
| to_date | Получает или задает конец времени исключения. |
| occurrences | Получает или задает количество повторений, для которых исключение календаря действительно. |
| name | Получает или задает имя исключения. |
| тип | Получает или задает тип исключения. |
| period | Получает или задает период повторения для исключения. |
| days_of_week | Получает DayTypeCollection для этого объекта.<br/>            Дни недели, в которые исключение действительно. |
| month_item | Получает или задает элемент месяца, для которого запланировано повторение исключения. |
| month_position | Получает или задает позицию элемента месяца внутри месяца. |
| месяц | Получает или задает месяц, для которого запланировано повторение исключения. |
| month_day | Получает или задает день месяца, в который запланировано повторение исключения. |
| day_working | Получает или задает значение, указывающее, является ли указанная дата или тип дня рабочим. |
| working_times | Получает или задает объект WorkingTimeCollection.<br/>            Коллекция рабочих времён, определяющая время работы в будний день. |
| parent_calendar | Получает родительский календарь для этого объекта. |
## Методы
| Имя | Описание |
| :- | :- |
| delete() | Удаляет экземпляр Exception из родительского календаря объекта CalendarExceptionCollection. |
| check_exception(dt) | Возвращает true, если указанная экземпляр структуры datetime является днём исключения. |
| get_working_time() | Возвращает рабочее время для исключения календаря. |
| get_exception_dates() | Возвращает даты, на которые применяется исключение календаря. |
