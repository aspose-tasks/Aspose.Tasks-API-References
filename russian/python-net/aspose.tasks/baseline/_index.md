## Baseline class

Представляет базовые значения ресурса.

Тип Baseline раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Baseline() | Инициализирует новый экземпляр класса Baseline |
## Свойства
| Имя | Описание |
| :- | :- |
| baseline_number | Получает или задает уникальный номер записи данных базовой линии. |
| work | Получает или задает работу, назначенную ресурсу при сохранении базовой линии. |
| cost | Получает или задает прогнозируемую стоимость ресурса при сохранении базовой линии. |
| bcws | Получает или задает бюджетную стоимость работы, запланированной для ресурса. |
| bcwp | Получает или задает бюджетную стоимость работы, выполненной ресурсом для проекта на текущую дату. |
## Методы
| Имя | Описание |
| :- | :- |
| equals(other) | Возвращает значение, указывающее, равен ли данный экземпляр указанному объекту. |
| compare_to(other) | Реализация интерфейса IComparable.<br/>            Сравнивает данный экземпляр с указанным объектом Baseline. |
