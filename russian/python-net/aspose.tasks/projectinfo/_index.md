## ProjectInfo class

Краткая информация о опубликованном проекте, доступном в Project Online.

Тип ProjectInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ProjectInfo() | Инициализирует новый экземпляр класса [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/). |
## Свойства
| Имя | Описание |
| :- | :- |
| id | Получает уникальный идентификатор проекта. |
| name | Получает название проекта. |
| created_date | Получает дату и время создания проекта. |
| is_checked_out | Получает значение, указывающее, проверен ли проект. |
| last_published_date | Получает последнюю дату публикации проекта. |
| last_saved_date | Получает последнюю дату сохранения проекта. |
| description | Получает описание проекта. |
