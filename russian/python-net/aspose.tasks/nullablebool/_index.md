## NullableBool class

Класс для логических значений с возможностью проверить, было ли значение определено или нет.

Тип NullableBool раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| NullableBool(value) | Инициализирует новый экземпляр структуры [NullableBool](/tasks/python-net/aspose.tasks/nullablebool/) с указанным логическим значением. |
| NullableBool(value, is_defined) | Инициализирует новый экземпляр структуры [NullableBool](/tasks/python-net/aspose.tasks/nullablebool/) с указанным логическим значением. |
| NullableBool() | Инициализирует новый экземпляр структуры [NullableBool](/tasks/python-net/aspose.tasks/nullablebool/) с указанным логическим значением. |
## Свойства
| Имя | Описание |
| :- | :- |
| value | Получает или задает значение, указывающее, является ли текущее значение истинным или false. |
| is_defined | Получает значение, указывающее, было ли значение определено; в противном случае, false. |
## Методы
| Имя | Описание |
| :- | :- |
