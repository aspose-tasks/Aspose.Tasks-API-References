## TaskBaseline class

Представляет базовый план задачи.

Тип TaskBaseline раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TaskBaseline(task) | Инициализирует новый экземпляр класса [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/). |
## Свойства
| Имя | Описание |
| :- | :- |
| baseline_number | Получает или задает уникальный номер записи данных базовой линии. |
| work | Получает или задает работу, назначенную ресурсу при сохранении базовой линии. |
| cost | Получает или задает прогнозируемую стоимость ресурса при сохранении базовой линии. |
| bcws | Получает или задает бюджетную стоимость работы, запланированной для ресурса. |
| bcwp | Получает или задает бюджетную стоимость работы, выполненной ресурсом для проекта на текущую дату. |
| timephased_data | Получает или задает экземпляр TimephasedDataCollection для этого объекта.<br/>            Временные данные, связанные с базовым планом задачи. |
| interim | Получает или задает значение, указывающее, является ли это промежуточной базой. |
| начало | Получает или задает запланированную дату начала задачи, когда база была сохранена. |
| finish | Получает или задает запланированную дату завершения задачи, когда база была сохранена. |
| duration | Получает или задает запланированную длительность задачи, когда база была сохранена. |
| estimated_duration | Получает или задает значение, указывающее, была ли оценена длительность базовой линии задачи. |
| fixed_cost | Получает или задает фиксированную стоимость задачи, когда базовая линия была сохранена. |
