## Duration class

Представляет продолжительность в проекте.

Тип Duration раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Duration() | Инициализирует новый экземпляр класса Duration |
## Свойства
| Имя | Описание |
| :- | :- |
| time_span | Получает экземпляр [time_span](/tasks/python-net/aspose.tasks/duration/) этого объекта Duration. |
| time_unit | Получает тип единицы времени для этого объекта. |
| is_estimated | Получает значение, указывающее, является ли единица времени оценочной. |
| is_elapsed | Получает значение, указывающее, является ли единица времени прошедшей. |
## Методы
| Имя | Описание |
| :- | :- |
| add(d) | Добавляет указанную длительность к этой длительности. |
| add(val) | Добавляет указанное значение типа double к этой длительности. |
| subtract(d) | Вычитает указанную длительность из этого экземпляра длительности. |
| subtract(val) | Вычитает указанное значение типа double из этого экземпляра длительности. |
| parse(p, value) | Преобразует указанную строку в экземпляр структуры [Duration](/tasks/python-net/aspose.tasks/duration/). |
| parse_time_span(value) | Разбирает строку длительности в формате "PT--H--M--S--". |
| to_double() | Преобразует объект Duration в значение типа float. |
| convert(time_unit_type) | Преобразует объект Duration в другую длительность с указанными единицами времени. |
| equals(other) | Возвращает значение, указывающее, равен ли данный экземпляр указанному объекту. |
