## GroupCriterion class

Представляет критерий в определении группы.<br/>            Объект GroupCriterion является членом коллекции [GroupCriterionCollection](/tasks/python-net/aspose.tasks/groupcriterioncollection/).

Тип GroupCriterion раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| GroupCriterion() | Инициализирует новый экземпляр класса GroupCriterion |
## Свойства
| Имя | Описание |
| :- | :- |
| ascending | Получает или задает значение, указывающее, сортируется ли поле, используемое в качестве критерия в определении группы, по возрастанию. Ложно, если поле сортируется по убыванию. |
| cell_color | Получает или задает цвет фона ячейки для поля, используемого в качестве критерия в определении группы. |
| font_color | Получает или задает цвет шрифта для поля, используемого в качестве критерия в определении группы. |
| field | Получает или задает поле, по которому производится группировка. |
| group_on | Получает или задает тип группировки для поля, используемого в качестве критерия в определении группы. |
| pattern | Получает или задает шаблон ячейки для поля, используемого в качестве критерия в определении группы. |
| start_at | Получает или задает начало интервалов для поля, используемого в качестве критерия в определении группы. |
| group_interval | Получает или задает интервал для поля, используемого в качестве критерия в определении группы. |
| font | Получает или задает шрифт для критерия в определении группы. |
