## RecurringTaskParameters class

Представляет набор параметров, используемых для создания повторяющейся задачи в проекте.

Тип RecurringTaskParameters раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RecurringTaskParameters() | Инициализирует новый экземпляр класса [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Свойства
| Имя | Описание |
| :- | :- |
| duration | Получает или задает длительность одного повторения повторяющейся задачи. |
| ignore_resource_calendar | Получает или задает значение, указывающее, следует ли планировать повторяющуюся задачу, даже если она не может быть выполнена, когда какие-либо ресурсы доступны для работы над ней. |
| recurrence_pattern | Получает или задает шаблон повторения повторяющейся задачи. |
| task_name | Получает или задает имя повторяющейся задачи. |
## Методы
| Имя | Описание |
| :- | :- |
| set_calendar(project, calendar_name) | Устанавливает календарь для повторяющейся задачи. Календарь выбирается из коллекции календарей проекта. |
