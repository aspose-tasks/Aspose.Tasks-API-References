## MessageLevel enumeration

Определяет возможные уровни детализации сообщений.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Не выводить сообщения. |
| ERROR | Выводить только сообщения об ошибках. |
| CRITICAL | Выводить критические сообщения. |
| WARNING | Выводить предупреждения. |
| INFORMATION | Выводить информационные сообщения. |
| VERBOSE | Выводить отладочные сообщения. |
