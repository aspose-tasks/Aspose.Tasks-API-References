## VbaModuleType enumeration

Указывает тип модуля в проекте VBA.

## Members
| Имя члена | Описание |
| :- | :- |
| DOCUMENT_MODULE | Тип элемента проекта VBA, который определяет модуль для встроенных макросов и операций программного доступа, связанных с документом. |
| PROCEDURAL_MODULE | Модуль, содержащий набор подпрограмм и функций. |
| CLASS_MODULE | Модуль, содержащий определение нового объекта. Каждый экземпляр класса создает новый объект, а процедуры, определённые в модуле, становятся свойствами и методами объекта. |
| DESIGNER_MODULE | Модуль, расширяющий методы и свойства ActiveX‑контрола, зарегистрированного в проекте. |
