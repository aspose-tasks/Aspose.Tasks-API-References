## SummaryRowsCalculationType enumeration

Указывает тип расчёта значения пользовательского атрибута для итоговых строк.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Означает, что значение пользовательского атрибута для итоговых строк не рассчитывается. |
| ROLLUP | Означает, что значение пользовательского атрибута для итоговых строк рассчитывается с использованием функции rollup, определённой в [rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
| USE_FORMULA | Означает, что значение пользовательского атрибута для итоговых строк рассчитывается с использованием формулы, определённой в [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
