## UsageView class

Представляет представление использования в проекте.

Тип UsageView раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| filter | Получает или задает фильтр, используемый в отдельном представлении. |
| группа | Получает или задает группу единственного представления. |
| uid | Получает уникальный идентификатор представления. |
| highlight_filter | Получает или задает значение, указывающее, выделяет ли Microsoft Project фильтр для единственного представления. |
| name | Получает или задает имя объекта View. |
| screen | Получает тип экрана для единственного представления.<br/>            Только для чтения [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Получает родительский объект View.<br/>            Только для чтения [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Получает или задает таблицу единственного представления. |
| type | Получает тип элемента в единственном представлении, например задачи или ресурсы.<br/>            Только для чтения [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Получает или задает значение, указывающее, отображает ли Microsoft Project имя единственного представления в выпадающих списках View или Other Views на ленте. |
| page_info | Получает экземпляр класса [page_info](/tasks/python-net/aspose.tasks/view/). Представляет данные настройки страницы, присутствующие в формате файла mpp. |
| visual_objects_placements | Получает коллекцию объектов, представляющих размещение и внешний вид [OleObject](/tasks/python-net/aspose.tasks/oleobject/) в представлении. |
| align_details_data | Получает или задает выравнивание данных деталей. |
| display_details_header_column | Получает или задает значение, указывающее, отображать ли столбец заголовка деталей в представлении. |
| display_short_detail_header_names | Получает или задает значение, указывающее, отображать ли короткие имена заголовков деталей. |
| repeat_details_header_on_all_rows | Получает или задает значение, указывающее, повторять ли заголовок деталей на каждой строке назначения. |
| timescale_size_percentage |  |
| bottom_timescale_tier | Получает или задает настройки нижнего уровня шкалы времени представления.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | Получает или задает настройки среднего уровня шкалы времени представления.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | Получает или задает настройки верхнего уровня шкалы времени представления.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
## Методы
| Имя | Описание |
| :- | :- |
| compare_to(other) | Сравнивает текущий экземпляр с другим объектом того же типа и возвращает целое число, указывающее, предшествует ли текущий экземпляр, следует ли за ним или находится в том же положении в порядке сортировки, что и другой объект. |
