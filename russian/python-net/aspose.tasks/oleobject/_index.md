## OleObject class

Представляет OLE‑объект, который может быть вставлен в представление диаграммы Ганта файла MPP.

Тип OleObject раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| OleObject() | Инициализирует новый экземпляр класса [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает или задает имя экземпляра OLE‑объекта. |
| application_name | Получает или задает имя приложения, с помощью которого открывается встроенный объект. |
| file_format | Получает или задает формат файла встроенного объекта. |
| content | Получает или задает данные встроенного файла; null, если данные не были встроены. |
| label | Получает или задает метку вставленного объекта. |
| full_path | Получает или задает полный путь к вставленному объекту. |
| temporary_file | Получает или задает путь к временному файлу вставленного объекта. |
| display_as_icon | Получает или задает флаг, указывающий, что объект OLE должен отображаться либо как значок, либо как его обычное изображение. |
| связан | Получает значение, указывающее, содержит ли файл проекта только ссылку на фактические данные, хранящиеся в источнике ссылки. |
| view | Получает или задает экземпляр класса [view](/tasks/python-net/aspose.tasks/oleobject/), к которому принадлежит вставленный объект. |
| id | Получает или задает идентификатор объекта. |
