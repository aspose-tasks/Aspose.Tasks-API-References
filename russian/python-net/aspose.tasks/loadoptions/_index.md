## LoadOptions class

Позволяет указывать дополнительные параметры загрузки при загрузке проекта из файла или потока.

Тип LoadOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LoadOptions() | Инициализирует новый экземпляр класса [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/). |
## Свойства
| Имя | Описание |
| :- | :- |
| пароль | Получает или задает пароль защиты. |
| primavera_read_options | Получает или задает указанный экземпляр класса [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/), который может использоваться для настройки поведения загрузки форматов Primavera (Primavera P6 XER или Primavera P6 Xml). |
| кодировка | Получает или задает кодировку, используемую для чтения проекта из форматов HTML, MPX, XER и Primavera XML.<br/>            Кодировка по умолчанию — UTF8. |
