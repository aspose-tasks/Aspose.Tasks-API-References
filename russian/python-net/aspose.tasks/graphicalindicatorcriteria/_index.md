## GraphicalIndicatorCriteria class

Представляет один критерий графического индикатора, связанный с расширенным атрибутом.

Тип GraphicalIndicatorCriteria раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Инициализирует новый экземпляр класса GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Инициализирует новый экземпляр класса GraphicalIndicatorCriteria |
## Свойства
| Имя | Описание |
| :- | :- |
| test | Получает тип сравнения, выполняемого между значением расширенного атрибута и Values, который служит критерием для применения графического индикатора.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Получает значение, используемое для проверки значения расширенного атрибута. |
| value2 | Получает второе значение, используемое для проверки значения расширенного атрибута в случае типов сравнения 'IsWithin' и 'IsNotWithin'. |
| image_index | Получает индекс изображения, которое будет отображено, когда поле соответствует критерию. |
| row_type | Получает значение перечисления [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/), которое указывает, для каких строк применяется индикатор. |
