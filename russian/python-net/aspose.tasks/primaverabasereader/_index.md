## PrimaveraBaseReader class

Представляет базовый считыватель, который может использоваться для чтения UID проектов из файлов Primavera XER или XML, содержащих несколько проектов.

Тип PrimaveraBaseReader раскрывает следующие члены:
## Методы
| Имя | Описание |
| :- | :- |
| get_project_uids() | Возвращает список уникальных идентификаторов проектов. |
| get_project_infos() | Возвращает список коротких информационных объектов проекта. |
| load_project(project_uid) | Загружает проект с указанным уникальным идентификатором. |
