## LevelingOrder enumeration

Определяет возможные значения порядка выравнивания.

## Members
| Имя члена | Описание |
| :- | :- |
| STANDARD | Учитываются следующие свойства: предшествующие зависимости, общий запас времени (задача с большим общим запасом откладывается первой), дата начала, приоритет.<br/>            Это значение по умолчанию. |
| ID_ONLY | Задачи откладываются в порядке возрастания Id. |
| PRIORITY_THEN_STANDARD | Сначала учитывается приоритет, затем те же свойства, что и в режиме Standard. |
