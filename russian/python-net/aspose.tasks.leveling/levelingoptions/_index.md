## LevelingOptions class

Позволяет указать параметры выравнивания ресурсов.

Тип LevelingOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LevelingOptions() | Инициализирует новый экземпляр класса [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/). |
## Свойства
| Имя | Описание |
| :- | :- |
| start_date | Получает или задает дату начала периода выравнивания. Значение по умолчанию — дата начала проекта. |
| finish_date | Получает или задает дату окончания периода выравнивания. Значение по умолчанию — дата завершения проекта. |
| ресурсы | Получает или задает список ресурсов, которые будут выравнены. Если установить null, будут выравнены все ресурсы проекта. |
| leveling_order | Получает порядок, в котором алгоритм выравнивания откладывает задачи с переизбытком ресурсов.<br/>            После определения задач, вызывающих переизбыток, и задач, которые можно отложить, используется указанный порядок, определяющий, какая задача должна быть отложена первой. |
| message_level | Получает или задает уровень лог‑сообщений, генерируемых Aspose.Tasks во время выравнивания ресурсов. |
| message_handler | Получает или задает обратный вызов обработчика сообщений, который может использоваться для перехвата лог‑сообщений, создаваемых Aspose.Tasks во время выравнивания ресурсов. |
