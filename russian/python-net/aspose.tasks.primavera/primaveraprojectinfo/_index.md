## PrimaveraProjectInfo class

Представляет краткую информацию о проекте, загруженном из формата Primavera.

Тип PrimaveraProjectInfo раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| uid | Получает UID проекта. |
| name | Получает имя проекта. |
| short_name | Получает короткое название проекта (Project ID). |
| export_flag | Получает флаг экспорта проекта. Когда проект выбран для экспорта в Primavera, его ExportFlag равно true.<br/>            Некоторые проекты, не явно выбранные для экспорта, могут быть экспортированы в файл XER из‑за их связи с экспортируемым проектом. |
