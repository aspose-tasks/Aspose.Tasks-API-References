## LegendDrawingOptions enumeration

Указывает возможные параметры, используемые при рендеринге легенды представления.

## Members
| Имя члена | Описание |
| :- | :- |
| NO_LEGEND | Легенда не отображается. |
| AFTER_LAST_PAGE | Легенда отображается на отдельной странице после последней страницы проекта. |
| ON_EVERY_PAGE | Легенда отображается на каждой странице. |
| DEFINED_IN_VIEW | Легенда отображается в соответствии со свойством View.PageInfo.Legend.LegendOn отрисованного представления. |
