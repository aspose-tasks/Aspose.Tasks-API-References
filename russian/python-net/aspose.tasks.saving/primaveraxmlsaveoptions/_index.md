## PrimaveraXmlSaveOptions class

Позволяет указать дополнительные параметры при сохранении проекта в формат Primavera XML.

Тип PrimaveraXmlSaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PrimaveraXmlSaveOptions() | Инициализирует новый экземпляр класса [PrimaveraXmlSaveOptions](/tasks/python-net/aspose.tasks.saving/primaveraxmlsaveoptions/). |
## Свойства
| Имя | Описание |
| :- | :- |
| save_format | Получает или задает формат, в котором будет сохранён документ, если используется этот объект параметров сохранения. |
| save_root_task | Получает или задает значение, указывающее, сохранять корневую задачу или нет. |
| skip_summary_assignments | Получает или задает значение, указывающее, следует ли пропускать назначения ресурсов к сводным задачам при экспорте. |
