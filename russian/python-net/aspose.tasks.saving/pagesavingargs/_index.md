## PageSavingArgs class

Этот класс представляет набор данных, связанных с сохранением страницы документа в поток.

Тип PageSavingArgs раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| page_number | Получает номер страницы, которую следует записать. |
| keep_stream_open | Получает или задает значение, указывающее, должна ли процедура рендеринга оставлять [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) открытым после записи страницы. |
| stream | Получает или задает поток для записи страницы. |
