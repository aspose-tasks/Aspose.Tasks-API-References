## ImageSaveOptions class

Позволяет указать дополнительные параметры при рендеринге страниц проекта в изображения.

Тип ImageSaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ImageSaveOptions(save_format) | Инициализирует новый экземпляр класса [ImageSaveOptions](/tasks/python-net/aspose.tasks.saving/imagesaveoptions/), который можно использовать для сохранения отрисованных изображений в форматах TIFF, PNG, BMP или JPEG. |
## Свойства
| Имя | Описание |
| :- | :- |
| save_format |  |
| bar_styles | Получает или задает список экземпляров класса [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/), которые отображаются в представлении проекта. |
| draw_non_working_time | Получает или задает значение, указывающее, следует ли отображать нерабочее время (значение по умолчанию — TRUE). |
| end_date | Получает или задает дату, до которой следует завершить рендеринг. |
| timescale_fit_behavior | Получает или задает поведение, определяющее, как выровнять правый конец шкалы времени с концом страницы. |
| fit_content | Получает или задает значение, указывающее, следует ли увеличивать высоту строки, чтобы она соответствовала содержимому. |
| gridlines | Получает или задает список [Gridline](/tasks/python-net/aspose.tasks.visualization/gridline/), отображаемых в представлении проекта. |
| legend_drawing_options | Получает или задает значение, определяющее, как отрисовывать легенду. Значение по умолчанию — LegendDrawingOptions.OnEveryPage. |
| legend_items | Получает или задает массив PageLegendItem, определяющий, какие полосы должны быть отрисованы в легенде страницы.<br/>            Если null, отрисовываются элементы по умолчанию. |
| mark_critical_tasks | Получает или задает значение, указывающее, должны ли критические задачи отображаться красным цветом (значение по умолчанию — FALSE). |
| non_working_time_color | Получает или задает цвет нерабочего времени. |
| page_count | Получает или задает количество страниц проекта. |
| page_size | Получает или задает размер страницы для отрисовки (значение по умолчанию — PageSize.A4). |
| is_portrait | Получает или задает значение, указывающее, является ли ориентация страницы портретной; возвращает false, если ориентация страницы альбомная. |
| presentation_format | Получает или задает [presentation_format](/tasks/python-net/aspose.tasks.saving/saveoptions/), в котором будет сохраняться документ. |
| roll_up_gantt_bars | Получает или задает значение, указывающее, должны ли подп задачи на полосе сводной задачи быть помечены.<br/>            Для подп задач поле Rollup указывает, будет ли информация о полосах Gantt подп задачи свёрнута в полосу сводной задачи.<br/>            Для сводных задач поле Rollup указывает, отображает ли полоса сводной задачи свёрнутые полосы.<br/>            Вы должны установить поле Rollup для сводных задач в значение Yes, чтобы любые подп задачи могли быть свёрнуты в них. |
| start_date | Получает или задает дату, с которой начинается отрисовка. |
| text_styles | Получает или задает список стилей текста, применяемых при отрисовке представления проекта. |
| timescale | Получает или задает значение [timescale](/tasks/python-net/aspose.tasks.saving/saveoptions/), которое используется для управления тем, как шкала времени (если присутствует) отрисовывается при сохранении проекта в графическом формате. |
| use_gradient_brush | Получает или задает значение, указывающее, следует ли использовать градиентную кисть при рендеринге диаграммы Ганта. |
| view | Получает или задает список столбцов представления для отрисовки ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)).<br/>            Если не задано, отрисовываются только идентификаторы задач, названия задач, даты начала и окончания.<br/>            Если заданы свойства View и [view_settings](/tasks/python-net/aspose.tasks.saving/saveoptions/), столбцы из View переопределяют столбцы из ViewSettings. |
| view_settings | Получает или задает представление ([view](/tasks/python-net/aspose.tasks.saving/saveoptions/)) для отрисовки. Вы можете использовать эту опцию, чтобы явно указать, какое представление следует сохранять в форматы PDF, HTML или Image.<br/>            Если это свойство задано, свойство [PresentationFormat](/tasks/python-net/aspose.tasks.visualization/presentationformat/) игнорируется при сохранении проекта.<br/>            Представление должно быть одним из следующих экранов (([screen](/tasks/python-net/aspose.tasks/view/))): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage) |
| custom_page_size | Получает или задает пользовательский размер страницы в пунктах (1 пункт = 1/72 дюйма). |
| render_to_single_page | Получает или задает значение, указывающее, следует ли рендерить проект в одну страницу<br/>            когда проект сохраняется в графическом формате.<br/>            Размер страницы будет изменён, чтобы отрендеренный проект поместился на одной странице. |
| font_settings | Указывает настройки шрифта, используемые при рендеринге представления проекта. |
| pages | Получает или задает список номеров страниц для сохранения при сохранении макета проекта в отдельные файлы. |
| jpeg_quality | Получает или задает качество JPEG. Допустимый диапазон значений — 0..100. |
| reduce_footer_gap | Получает или задает значение, указывающее, следует ли уменьшить зазор между последней задачей и нижним колонтитулом. |
| tiff_compression | Получает или задает тип сжатия, применяемый при сохранении сгенерированных изображений в формате TIFF. |
| pixel_format | Получает или задает формат цветовых данных для каждого пикселя изображения. |
| horizontal_resolution | Получает или задает горизонтальное разрешение в dpi. |
| vertical_resolution | Получает или задает вертикальное разрешение в dpi. |
| page_saving_callback | Получает или задает пользовательский обратный вызов, который используется для получения выходного потока для каждой отрисованной страницы. |
