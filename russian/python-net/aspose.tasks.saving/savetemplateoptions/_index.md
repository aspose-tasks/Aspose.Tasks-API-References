## SaveTemplateOptions class

Позволяет указать дополнительные параметры при сохранении проекта в виде шаблона.

Тип SaveTemplateOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SaveTemplateOptions() | Инициализирует новый экземпляр класса SaveTemplateOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| remove_actual_values | Получает или задает значение, указывающее, следует ли удалять все фактические значения из шаблона проекта. |
| remove_baseline_values | Получает или задает значение, указывающее, следует ли удалять все базовые значения из шаблона проекта. |
| remove_fixed_costs | Получает или задает значение, указывающее, следует ли удалять все фиксированные затраты из шаблона проекта. |
| remove_resource_rates | Получает или задает значение, указывающее, следует ли удалять ставки ресурсов из шаблона проекта. |
