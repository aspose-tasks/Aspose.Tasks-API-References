## CsvOptions class

Позволяет указать дополнительные параметры при сохранении проекта в CSV.

Тип CsvOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| CsvOptions() | Создает новый экземпляр класса [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) который можно использовать для сохранения проекта в формате CSV. |
## Свойства
| Имя | Описание |
| :- | :- |
| save_format | Получает или задает формат, в котором будет сохранён документ, если используется этот объект параметров сохранения. |
| data_category | Получает или задает категорию данных для сохранения. |
| кодировка | Получает или задает кодировку, с которой сохраняется CSV. |
| include_headers | Получает или задает значение, указывающее, включать ли заголовки (значение по умолчанию — TRUE). |
| text_delimiter | Получает или задает текстовый разделитель. |
| view | Получает или задает список столбцов представления ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) которые сохраняются в формате XLSX.<br/>            Если не задано, сохраняются столбцы по умолчанию. |
