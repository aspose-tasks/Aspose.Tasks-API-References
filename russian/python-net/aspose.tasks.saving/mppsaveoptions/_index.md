## MPPSaveOptions class

Позволяет указать дополнительные параметры при сохранении данных проекта в MPP.

Тип MPPSaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| MPPSaveOptions() | Инициализирует новый экземпляр класса [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## Свойства
| Имя | Описание |
| :- | :- |
| save_format | Получает или задает формат, в котором будет сохранён документ, если используется этот объект параметров сохранения. |
| remove_invalid_assignments | Получает или задает значение, указывающее, следует ли удалять недействительные назначения ресурсов при сохранении в MPP. |
| write_view_data | Получает или задает значение, указывающее, следует ли записывать данные представления при сохранении проекта в формате MPP. |
| write_filters | Получает или задает значение, указывающее, следует ли записывать данные фильтров при сохранении проекта в формат MPP. |
| write_groups | Получает или задает значение, указывающее, следует ли записывать данные групп при сохранении проекта в формат MPP. |
| clear_vba | Получает или задает значение, указывающее, следует ли удалять существующие данные макросов VBA при сохранении проекта в формат MPP. |
| write_vba | Получает или задает значение, указывающее, следует ли обновлять существующие данные макросов VBA в файле MPP.<br/>            В настоящее время поддерживается запись VbaModule.SourceCode. |
| protection_password | Получает или задает пароль, который используется для защиты получаемого файла MPP. В настоящее время поддерживается для форматов MS Project 2010 и новее. |
