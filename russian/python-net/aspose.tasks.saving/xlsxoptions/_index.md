## XlsxOptions class

Позволяет указать дополнительные параметры при рендеринге страниц проекта в XLSX.

Тип XlsxOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| XlsxOptions() | Инициализирует новый экземпляр класса [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/), который можно использовать для сохранения проекта в формате XLSX. |
## Свойства
| Имя | Описание |
| :- | :- |
| save_format | Получает или задает формат, в котором будет сохранён документ, если используется этот объект параметров сохранения. |
| resource_view | Получает или задает список столбцов представления ресурсов для отображения ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Получает или задает список столбцов представления назначений для отображения ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| кодировка | Получает или задает кодировку результирующего файла XLSX. Значение по умолчанию — . |
| view | Получает или задает список столбцов представления ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) которые сохраняются в формате XLSX.<br/>            Если не задано, сохраняются столбцы по умолчанию. |
