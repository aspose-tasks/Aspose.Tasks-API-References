## IPageSavingCallback class

Представляет обратный вызов, который вызывается, когда каждая страница многостраничного документа сохраняется в отдельный поток.

Тип IPageSavingCallback раскрывает следующие члены:
## Методы
| Имя | Описание |
| :- | :- |
| page_saving(args) | Метод, вызываемый при сохранении страницы в поток. |
| on_finish() | Метод, который будет вызван после записи всех страниц. |
