## MspDbSettings class

Позволяет задать необходимые параметры для чтения данных проекта из базы данных MS Project Server.

Тип MspDbSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Инициализирует новый экземпляр класса [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Свойства
| Имя | Описание |
| :- | :- |
| connection_string | Получает или задает строку подключения. |
| provider_invariant_name | Получает или задает имя провайдера invariant, которое используется для получения экземпляра  класса. |
| project_guid | Получает GUID проекта для чтения. |
| schema | Получает или задает схему MS Project Server.<br/>            Значение по умолчанию — "pub". |
