Содержит классы для работы с базами данных.

## Классы
| Класс | Описание |
| :- | :- |
| [DbSettings](/tasks/python-net/aspose.tasks.connectivity/dbsettings/) | Позволяет указать настройки для чтения из базы данных проекта. |
| [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) | Позволяет задать необходимые параметры для чтения данных проекта из формата MPD (формат файла базы данных MS Access). |
| [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) | Позволяет задать необходимые параметры для чтения данных проекта из базы данных MS Project Server. |
| [PrimaveraDbSettings](/tasks/python-net/aspose.tasks.connectivity/primaveradbsettings/) | Позволяет задать необходимые параметры для чтения данных проекта из базы данных Primavera. |
