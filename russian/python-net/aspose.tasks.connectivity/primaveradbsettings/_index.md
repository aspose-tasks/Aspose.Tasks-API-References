## PrimaveraDbSettings class

Позволяет задать необходимые параметры для чтения данных проекта из базы данных Primavera.

Тип PrimaveraDbSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PrimaveraDbSettings(connection_string, project_id) | Инициализирует новый экземпляр класса [PrimaveraDbSettings](/tasks/python-net/aspose.tasks.connectivity/primaveradbsettings/). |
## Свойства
| Имя | Описание |
| :- | :- |
| connection_string | Получает или задает строку подключения. |
| provider_invariant_name | Получает или задает имя провайдера invariant, которое используется для получения экземпляра  класса. |
| project_id | Получает идентификатор проекта для чтения. |
