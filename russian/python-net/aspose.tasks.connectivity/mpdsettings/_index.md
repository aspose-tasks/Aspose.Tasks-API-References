## MpdSettings class

Позволяет задать необходимые параметры для чтения данных проекта из формата MPD (формат файла базы данных MS Access).

Тип MpdSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| MpdSettings(connection_string, project_id) | Инициализирует новый экземпляр класса [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/). |
## Свойства
| Имя | Описание |
| :- | :- |
| connection_string | Получает или задает строку подключения. |
| provider_invariant_name | Получает или задает имя провайдера invariant, которое используется для получения экземпляра  класса. |
| project_id | Получает идентификатор проекта для чтения. |
