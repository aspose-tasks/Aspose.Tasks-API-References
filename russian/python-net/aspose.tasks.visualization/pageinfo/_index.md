## PageInfo class

Представляет данные настройки страницы, присутствующие в формате файла MPP и используемые для печати.

Тип PageInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PageInfo() | Инициализирует новый экземпляр класса [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) . <br/>            Представляет данные настройки страницы, которые присутствуют в формате файла MPP и используются для печати. |
## Свойства
| Имя | Описание |
| :- | :- |
| header | Получает или задает экземпляр класса [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) который представляет данные заголовка. |
| footer | Получает или задает экземпляр класса [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) который представляет данные нижнего колонтитула. |
| name | Получает имя представления, для которого используются данные настройки. |
| page_settings | Получает экземпляр класса [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) который задает параметры печати страницы. |
| page_view_settings | Получает экземпляр класса [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) который задает параметры печати представления страницы. |
| margins | Получает экземпляр класса [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) который задает поля страницы. |
| legend | Получает или задает экземпляр класса [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) который задает параметры отображения легенды страницы. |
