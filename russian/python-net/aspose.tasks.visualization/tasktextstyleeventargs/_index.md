## TaskTextStyleEventArgs class

Этот класс представляет набор данных, связанных с отображением содержимого ячейки таблицы.

Тип TaskTextStyleEventArgs раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| cell_text_style | Получает или задает TextStyle, который будет использоваться для отрисовки содержимого ячейки. Этот объект можно использовать для настройки внешнего вида ячейки таблицы. |
| task | Получает [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/), соответствующий текущей отрисовываемой строке. |
| column | Получает [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/), к которому принадлежит текущая отрисовываемая ячейка. |
