## ViewColumn class

Представляет столбец в представлении проекта.

Тип ViewColumn раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| field | Получает или задает поле столбца.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/viewcolumn/). |
| name | Получает имя столбца. |
| string_alignment | Получает или задает выравнивание текста (может быть одним из значений перечисления [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Получает ширину столбца. |
| text_style_modification_callback | Получает или задает обратный вызов, который можно использовать для настройки внешнего вида ячеек столбца. |
