## TableTextStyle class

Представляет стиль текста в таблице представления.

Тип TableTextStyle раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TableTextStyle(row_uid) | Инициализирует новый экземпляр класса TableTextStyle |
| TableTextStyle(row_uid, font) | Инициализирует новый экземпляр класса TableTextStyle |
| TableTextStyle(row_uid, font_size, font_style) | Инициализирует новый экземпляр класса TableTextStyle |
| TableTextStyle(row_uid, font_style) | Инициализирует новый экземпляр класса TableTextStyle |
## Свойства
| Имя | Описание |
| :- | :- |
| font | Получает или задает шрифт стиля текста. |
| color | Получает или задает цвет текста. |
| item_type | Возвращает значение перечисления [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/). |
| background_pattern | Получает или задает шаблон фона стиля текста.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Получает или задает цвет фона стиля текста.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| row_uid | Получает уникальный идентификатор строки. |
| field | Получает или задает поле, к которому применяется стиль.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/tabletextstyle/). |
