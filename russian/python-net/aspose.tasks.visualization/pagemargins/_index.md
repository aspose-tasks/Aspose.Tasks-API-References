## PageMargins class

Представляет поля страницы для печати.

Тип PageMargins раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PageMargins() | Инициализирует новый экземпляр класса PageMargins |
## Свойства
| Имя | Описание |
| :- | :- |
| top | Получает или задает размер верхнего поля в сантиметрах. |
| bottom | Получает или задает размер нижнего поля в сантиметрах. |
| left | Получает или задает размер левого поля в сантиметрах. |
| right | Получает или задает размер правого поля в сантиметрах. |
| borders | Получает или задает позицию, где печатать границы. Может быть одним из значений перечисления [Border](/tasks/python-net/aspose.tasks.visualization/border/). |
