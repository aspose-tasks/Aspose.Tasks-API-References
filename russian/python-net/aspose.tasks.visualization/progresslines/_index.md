## ProgressLines class

Представляет линии прогресса в представлении диаграммы Ганта.

Тип ProgressLines раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ProgressLines() | Инициализирует новый экземпляр класса ProgressLines |
## Свойства
| Имя | Описание |
| :- | :- |
| display_at_current_date | Получает или задает значение, указывающее, отображать ли линию прогресса на текущую дату. |
| display_at_recurring_intervals | Получает или задает значение, указывающее, отображать ли линию прогресса с повторяющимися интервалами. |
| recurring_interval | Получает или задает повторяющийся интервал.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Получает или задает значение, указывающее, отображать ли линии прогресса с начала даты начала проекта. |
| begin_at_date | Получает или задает дату, с которой отображать линии прогресса. |
| display_selected | Получает или задает значение, указывающее, отображать ли линии прогресса в выбранные даты. |
| is_baseline_plan | Получает или задает значение, указывающее, отображать ли линии прогресса для базового плана или фактических данных. |
| show_date | Получает или задает значение, указывающее, показывать ли дату для каждой линии прогресса. |
| date_format | Получает или задает формат даты ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Получает или задает шрифт, используемый для метки линии прогресса. |
| line_pattern | Получает или задает шаблон линии текущей линии прогресса.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Получает или задает цвет линии для текущей линии прогресса. |
| progress_point_shape | Получает или задает форму точки прогресса.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Получает или задает цвет точки прогресса. |
| other_line_pattern | Получает или задает шаблон линии для другой линии прогресса. |
| other_line_color | Получает или задает цвет другой линии прогресса. |
| other_progress_point_shape | Получает или задает форму точки прогресса другой линии прогресса. |
| other_progress_point_color | Получает или задает цвет другой точки прогресса. |
| selected_dates | Получает список выбранных дат для отображения линий прогресса. |
