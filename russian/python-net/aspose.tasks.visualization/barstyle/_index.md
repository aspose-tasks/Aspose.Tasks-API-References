## BarStyle class

Изменить визуальный стиль полосы для элемента в представлении проекта.

Тип BarStyle раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| BarStyle() | Инициализирует новый экземпляр класса [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/). |
## Свойства
| Имя | Описание |
| :- | :- |
| bar_color | Получает или задает aspose.pydrawing.Color стиля столбца. |
| start_shape_color | Получает или задает aspose.pydrawing.Color формы в начале столбца. |
| start_shape_type | Получает или задает тип начальной формы. |
| end_shape_color | Получает или задает aspose.pydrawing.Color формы в конце столбца. |
| end_shape_type | Получает или задает тип формы конца.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | Получает или задает [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) стиля столбца. |
| bar_shape | Получает или задает [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) стиля столбца. |
| start_shape | Получает или задает [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) в начале столбца. |
| end_shape | Получает или задает [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) в конце столбца. |
| text_style | Получает или задает стиль текста столбца. |
| left_field | Получает или задает поле, отображаемое слева от столбца. |
| top_field | Получает или задает поле, отображаемое сверху столбца. |
| right_field | Получает или задает поле, отображаемое справа от столбца. |
| bottom_field | Получает или задает поле, отображаемое в нижней части полосы. |
| inside_field | Получает или задает поле, отображаемое внутри полосы. |
| from_address | Получает или задает позицию начальной точки ганттовой полосы.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | Получает или задает позицию конечной точки полосы диаграммы Ганта. |
