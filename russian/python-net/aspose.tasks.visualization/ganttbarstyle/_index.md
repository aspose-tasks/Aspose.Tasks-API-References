## GanttBarStyle class

Представляет стиль полосы, используемый MSP в представлении диаграммы Ганта.

Тип GanttBarStyle раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| GanttBarStyle() | Инициализирует новый экземпляр класса [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
## Свойства
| Имя | Описание |
| :- | :- |
| bottom_field | Получает или задает данные, отображаемые в нижней части полосы.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| end_shape | Получает или задает форму конца полосы. |
| end_shape_color | Получает или задает цвет формы конца. |
| end_shape_type | Получает или задает тип формы конца.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| from_address | Получает или задает позицию начальной точки ганттовой полосы.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | Получает или задает данные, отображаемые внутри полосы.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| left_field | Получает или задает данные, отображаемые слева от полосы.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| middle_fill_pattern | Получает или задает шаблон заливки ганттовой полосы. |
| middle_shape | Получает или задает среднюю форму полосы. |
| middle_shape_color | Получает или задает цвет средней формы. |
| name | Получает или задает имя стиля. |
| right_field | Получает или задает данные, отображаемые справа от полосы.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| row | Получает или задает номер строки. |
| show_for_categories | Получает или задает категории задач, к которым применяется стиль. Применяется к родительским (или общим) стилям полос в диаграмме Ганта<br/>            (см. [bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| show_for_task_uid | Получает или задает уникальный идентификатор задачи, к которой применяется стиль. Применяется к стилям полос, специфичным для задачи, в диаграмме Ганта (см. [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | Получает или задает начальную форму полосы. |
| start_shape_color | Получает или задает цвет начальной формы. |
| start_shape_type | Получает или задает тип начальной формы. |
| to | Получает или задает позицию конечной точки полосы диаграммы Ганта. |
| top_field | Получает или задает данные, отображаемые в верхней части полосы. |
| parent_style | Получает или задает родительский (или общий) стиль для пользовательского стиля, специфичного для задачи. |
