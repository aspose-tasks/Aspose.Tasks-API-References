## TimescaleTier class

Представляет один уровень шкалы времени на диаграмме Ганта.

Тип TimescaleTier раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TimescaleTier() | Инициализирует новый экземпляр класса [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Инициализирует новый экземпляр класса TimescaleTier |
## Свойства
| Имя | Описание |
| :- | :- |
| count | Получает или задает интервал единицы времени, в котором отображаются метки для уровня.<br/>            Значение по умолчанию — 1. |
| label | Получает или задает метку даты [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) для уровня шкалы времени. |
| alignment | Получает или задает способ выравнивания меток внутри каждого временного периода уровня ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Получает или задает значение, указывающее, следует ли основывать метки уровня на финансовом году. |
| show_ticks | Получает или задает значение, указывающее, следует ли отображать деления, разделяющие временные периоды в уровне. |
| unit | Получает или задает единицу шкалы времени [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) для уровня шкалы времени.<br/>            Значение по умолчанию — |
| render_label_on_each_page | Получает или задает флаг, определяющий, должны ли метки даты отображаться на каждой странице, когда временной период охватывает несколько страниц.<br/>            Если значение равно 'true', когда временной период охватывает несколько страниц, метки даты для периода отображаются на каждой странице.<br/>            Если значение равно 'false', метка даты отображается только один раз в соответствии со значением свойства [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
