## Timescale enumeration

Определяет параметры, указывающие, как отрисовывать шкалу времени в представлениях Диаграмма Ганта, Использование задач или Использование ресурсов при экспорте проекта в графический формат.

## Members
| Имя члена | Описание |
| :- | :- |
| DEFINED_IN_VIEW | Используйте настройки шкалы времени, определённые в свойствах представления проекта: [bottom_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/),<br/>            [middle_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/), [top_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/).<br/>            Действительно для форматов, содержащих данные представления. Например, проекты, считанные из формата MPP. |
| ДНИ | Предопределённая двухуровневая шкала времени, где минимальный уровень детализации — один день. |
| ТРЕТИ_МЕСЯЦА | Предопределённая двухуровневая шкала времени, где уровень детализации — одна треть месяца. |
| МЕСЯЦЫ | Предопределённая двухуровневая шкала времени, где минимальный уровень детализации — один месяц. |
