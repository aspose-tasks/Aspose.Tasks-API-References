## ReportType enumeration

Тип графического отчёта проекта.

## Members
| Имя члена | Описание |
| :- | :- |
| PROJECT_OVERVIEW | Отображает дату начала и завершения проекта, <br/>            процент завершённой длительности, процент выполнения для задач верхнего уровня и предстоящих контрольных точек. |
| COST_OVERVIEW | Отображает даты начала и завершения проекта, текущие<br/>            запланированные и оставшиеся затраты, % выполнения и значения затрат для задач верхнего уровня. |
| WORK_OVERVIEW | Отображает базовый, фактический и оставшийся объём работы для каждой задачи верхнего уровня и работу для трудовых ресурсов. |
| RESOURCE_OVERVIEW | Отображает базовый, фактический и оставшийся объём работы по ресурсам. |
| RESOURCE_COST_OVERVIEW | Отображает базовые, фактические и оставшиеся затраты по ресурсам. |
| CRITICAL_TASKS | Отображает задачи проекта, которые являются критическими. |
| LATE_TASKS | Отображает задачи проекта, которые задерживаются. |
| MILESTONES | Отображает контрольные точки, которые задержаны, предстоящие и завершённые. |
| UPCOMING_TASK | Показывает задачи, которые должны быть выполнены в текущей неделе, и задачи, начинающиеся в текущей неделе. |
| COST_OVERRUNS | Показывает отклонения стоимости по задаче и ресурсу. |
| TASK_COST_OVERVIEW | Показывает базовую, фактическую и оставшуюся стоимость всех задач верхнего уровня. |
| OVERALLOCATED_RESOURCES | Показывает количество оставшихся рабочих часов для перераспределённых ресурсов. |
| SLIPPING_TASKS | Показывает задачи, которые должны завершиться после их базовых дат завершения (база должна быть установлена). |
| BEST_PRACTICE_ANALYZER | Показывает задачи без фактической работы, не назначенные задачи, <br/>            задачи с длительностью менее 8 часов и сводки, назначенные ресурсам. |
| BURNDOWN | Включает графики сгорания работы и сгорания задач.<br/>            График сгорания работы показывает, сколько работы люди завершили, сколько запланировано завершить до даты завершения проекта, <br/>            и базовую оценку того, сколько работы будет выполнено к этому моменту проекта.<br/>            График сгорания задач показывает количество завершённых задач, количество оставшихся, <br/>            и базовую оценку того, сколько будет завершено к этому моменту проекта. |
| CASH_FLOW | Показывает затраты и накопительные затраты за квартал для всех задач верхнего уровня. |
