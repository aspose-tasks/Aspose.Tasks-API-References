## VisualObjectPlacement class

Представляет размещение и внешний вид [OleObject](/tasks/python-net/aspose.tasks/oleobject/) в представлении.

Тип VisualObjectPlacement раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| VisualObjectPlacement() | Инициализирует новый экземпляр класса [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Свойства
| Имя | Описание |
| :- | :- |
| ole_object_id | Получает или задаёт Id объекта [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
| task_id | Получает или задаёт Id задачи, если выбран параметр 'Attach to task', иначе -1. |
| width | Получает или задаёт отображаемую ширину визуального объекта. |
| height | Получает или задаёт отображаемую высоту визуального объекта. |
| vertical_offset | Получает или задаёт вертикальное смещение визуального объекта. |
| horizontal_offset | Получает или задаёт горизонтальное смещение визуального объекта. |
| timescale_date | Получает или задаёт размещение даты визуального объекта, когда выбран параметр 'Attach to timescale'. |
| attachment_point | Получает или задаёт выравнивание визуального объекта относительно задачи, когда выбран параметр 'Attach to task'. |
| border_line_color | Получает или задает цвет линии границы. |
| border_line_thickness | Получает или задает толщину линии границы (допустимые значения от 0 до 5). |
| fill_color | Получает или задает цвет заливки. |
| fill_pattern | Получает или задает шаблон заливки. |
