## TimescaleUnit enumeration

Указывает единицу времени для любого уровня шкалы времени в диаграмме Ганта или другом представлении с фазированием времени.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Указывает отсутствие. Уровень шкалы времени скрыт. |
| MINUTES | Указывает единицу шкалы времени — минуты. |
| ЧАСЫ | Указывает единицу шкалы времени Часы. |
| ДНИ | Указывает единицу шкалы времени Дни. |
| НЕДЕЛИ | Указывает единицу шкалы времени Недели. |
| ТРЕТИ_МЕСЯЦА | Указывает единицу шкалы времени Трети месяца. |
| МЕСЯЦЫ | Указывает единицу шкалы времени Месяцы. |
| КВАРТАЛЫ | Указывает единицу шкалы времени Кварталы лет. |
| ПОЛГОДЫ | Указывает единицу шкалы времени Полугоды. |
| ГОДЫ | Указывает единицу шкалы времени Годы. |
