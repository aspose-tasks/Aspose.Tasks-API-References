## Shape enumeration

Форма маркера в начале или в конце стиля полосы, которая будет отрисована при сохранении данных представления в один из форматов [SaveFileFormat](/tasks/python-net/aspose.tasks.saving/savefileformat/).

| VERTICAL_LINE | Указывает форму вертикальной линии. |
| PENTAGON | Указывает форму пятиугольника. |
| TRIANGLE | Указывает форму треугольника. |
| LEFT_BRACKET | Указывает форму левой скобки. |
| RIGHT_BRACKET | Указывает форму правой скобки. |
| ARROW_DOWN | Указывает форму ArrowDown. |

| RIGHT_FADE | Указывает форму Right fade. |

| CIRCLE | Указывает форму Circle. |
