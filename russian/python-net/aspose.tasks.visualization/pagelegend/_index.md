## PageLegend class

Представляет легенду страницы, используемую для печати проекта.

Тип PageLegend раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PageLegend() | Инициализирует новый экземпляр класса PageLegend |
## Свойства
| Имя | Описание |
| :- | :- |
| left_text | Получает или задает выровненный по левому краю текст для отображения в родительском элементе. |
| centered_text | Получает или задает центрированный текст для отображения в родительском элементе. |
| right_text | Получает или задает выровненный по правому краю текст для отображения в родительском элементе. |
| left_image | Получает или задает выровненное по левому краю изображение для отображения в родительском элементе. |
| centered_image | Получает или задает центрированное изображение для отображения в родительском элементе. |
| right_image | Получает или задает изображение, выровненное по правому краю, которое будет отображаться в родительском элементе. |
| left_image_size | Получает или задает отображаемый размер левого изображения. |
| centered_image_size | Получает или задает отображаемый размер центрального изображения. |
| right_image_size | Получает или задает отображаемый размер правого изображения. |
| legend_on | Получает или задает страницы, на которых отображается легенда. Может быть одним из значений перечисления [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | Получает или задает ширину левой части (по умолчанию содержит название проекта и дату) легенды в сантиметрах. |
