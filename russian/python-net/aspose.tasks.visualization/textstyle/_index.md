## TextStyle class

Измените визуальный стиль текста для элемента в представлении проекта.

Тип TextStyle раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextStyle() | Инициализирует новый экземпляр класса [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) с настройками по умолчанию. |
| TextStyle(font_size, font_style) | Инициализирует новый экземпляр класса TextStyle |
| TextStyle(font_style) | Инициализирует новый экземпляр класса [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) с шрифтом по умолчанию и указанным размером и стилем шрифта. |
| TextStyle(font) | Инициализирует новый экземпляр класса [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) с указанными настройками шрифта. |
## Свойства
| Имя | Описание |
| :- | :- |
| font | Получает или задает шрифт стиля текста. |
| color | Получает или задает цвет текста. |
| item_type | Получает или задает [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) стиля текста. |
| background_pattern | Получает или задает шаблон фона стиля текста.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Получает или задает цвет фона стиля текста.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
