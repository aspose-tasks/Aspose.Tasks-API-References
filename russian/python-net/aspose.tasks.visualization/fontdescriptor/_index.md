## FontDescriptor class

Представляет информацию о шрифте.

Тип FontDescriptor раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| FontDescriptor(font_family, size) | Инициализирует новый экземпляр класса FontDescriptor |
| FontDescriptor(font_family, size, style) | Инициализирует новый экземпляр класса FontDescriptor |
| FontDescriptor(font, style) | Инициализирует новый экземпляр класса [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) с указанными семейством шрифта, размером и стилем. |
## Свойства
| Имя | Описание |
| :- | :- |
| font_family | Получает название семейства шрифта. |
| size | Получает размер шрифта. |
| style | Получает стиль шрифта. |
