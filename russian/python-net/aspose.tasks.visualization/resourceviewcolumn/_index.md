## ResourceViewColumn class

Класс представления проекта, используемый в представлениях ResourceUsage и ResourceSheet.

Тип ResourceViewColumn раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ResourceViewColumn(width, field) | Инициализирует новый экземпляр класса ResourceViewColumn |
## Свойства
| Имя | Описание |
| :- | :- |
| field | Поле столбца. <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/). |
| name | Получает имя столбца. |
| string_alignment | Получает или задает выравнивание текста (может быть одним из значений перечисления [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Получает ширину столбца. |
| text_style_modification_callback | Получает или задает обратный вызов, который можно использовать для настройки внешнего вида ячеек столбца. |
## Методы
| Имя | Описание |
| :- | :- |
| get_column_text(resource) | Преобразует текущий ресурс в текст столбца. |
