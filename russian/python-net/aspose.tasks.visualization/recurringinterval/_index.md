## RecurringInterval class

Представляет повторяющиеся интервалы, используемые в линиях прогресса представления диаграммы Ганта.

Тип RecurringInterval раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RecurringInterval() | Инициализирует новый экземпляр класса RecurringInterval |
## Свойства
| Имя | Описание |
| :- | :- |
| interval | Получает или задает период повторения.<br/>            Может быть любым значением типа [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | Получает или задает номер дня. |
| daily_workday | Получает или задает значение, указывающее, является ли день рабочим для линий ежедневного прогресса. |
| weekly_week_number | Получает или задает номер недели для еженедельных линий прогресса. |
| monthly_day | Получает или задает значение, указывающее, показывать ли ежемесячные линии прогресса по дням. |
| monthly_day_day_number | Получает или задает номер дня ежемесячных линий прогресса. |
| monthly_day_month_number | Получает или задает номер месяца ежемесячных линий прогресса. |
| monthly_first_last | Получает или задает значение, указывающее, показывать ли линии прогресса по первому или последнему предопределенному дню. |
| monthly_first_last_month_number | Получает или задает номер месяца линий прогресса, которые отображаются по первому или последнему предопределенному дню. |
| monthly_first_last_day | Получает или задает тип первого или последнего дня ежемесячных линий прогресса. |
| weekly_days | Получает список дней для еженедельных линий прогресса. |
