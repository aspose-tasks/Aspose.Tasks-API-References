## ProjectView class

Класс представления проекта

Тип ProjectView раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ProjectView(columns) | Инициализирует новый экземпляр класса [ProjectView](/tasks/python-net/aspose.tasks.visualization/projectview/). |
## Свойства
| Имя | Описание |
| :- | :- |
| columns | Получает столбцы представления проекта. |
## Методы
| Имя | Описание |
| :- | :- |
| get_default_gantt_chart_view() | Включает столбцы id, индикаторы, имя, продолжительность, начало и завершение задачи. |
| get_default_task_sheet_view() | Включает столбцы задачи: id, индикаторы, имя, длительность, начало, окончание, предшественники и имена ресурсов. |
| get_default_resource_usage_view() | Включает столбцы ресурса: Uid, имя, начало, окончание и работа. |
| get_default_assignment_view() | Включает столбцы назначения: Uid, имя задачи, имя ресурса, работа и длительность. |
| get_default_resource_sheet_view() | Включает столбцы ресурса: Uid, имя ресурса, тип, метка материала, инициалы, группа, максимальные единицы,<br/>            стандартная ставка, ставка за сверхурочную работу, стоимость за использование, начисление, базовый календарь и столбец code. |
