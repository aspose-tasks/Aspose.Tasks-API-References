## PageSettings class

Представляет параметры печати для страницы представления проекта.

Тип PageSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PageSettings() | Инициализирует новый экземпляр класса [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Представляет настройки печати для страницы представления проекта. |
## Свойства
| Имя | Описание |
| :- | :- |
| is_portrait | Получает или задает значение, указывающее, является ли ориентация страницы портретной; возвращает false, если ориентация страницы альбомная. |
| adjust_to_percent_of_normal_size | Получает или задает значение, указывающее, следует ли корректировать печать до указанного процента ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) от нормального размера. |
| percent_of_normal_size | Получает или задает процент от нормального размера для настройки печати. |
| pages_in_width | Получает или задает количество страниц по ширине для печати. |
| pages_in_height | Получает или задает количество страниц по высоте для печати. |
| paper_size | Получает или задает размер бумаги. Может быть одним из значений перечисления [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | Получает или задает целое число, представляющее одно из значений PrinterPaperSize или пользовательский идентификатор размера страницы.<br/>            Это значение можно использовать для получения PaperSize из настроек ОС |
| first_page_number | Получает или задает номер первой страницы для печати. |
