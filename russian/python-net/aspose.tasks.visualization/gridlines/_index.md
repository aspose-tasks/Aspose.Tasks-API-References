## Gridlines class

Представляет линии сетки, отображаемые в представлении диаграммы Ганта.

Тип Gridlines раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Gridlines() | Инициализирует новый экземпляр класса Gridlines |
## Свойства
| Имя | Описание |
| :- | :- |
| interval | Получает или задает число от 0 до 99, определяющее интервал между линиями сетки. |
| interval_color | Получает или задает цвет вторичных линий сетки. |
| interval_pattern | Получает или задает шаблон линии для вторичных линий сетки. |
| normal_color | Получает или задает цвет обычных линий сетки. |
| normal_pattern | Получает или задает шаблон линии для обычных линий сетки. |
| тип | Получает или задает тип линии сетки. |
