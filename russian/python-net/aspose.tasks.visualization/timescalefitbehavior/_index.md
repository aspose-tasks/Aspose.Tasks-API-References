## TimescaleFitBehavior enumeration

Представляет поведение, используемое для выравнивания области шкалы времени по ширине страницы.

## Members
| Имя члена | Описание |
| :- | :- |
| DEFINED_IN_VIEW | Раздел календаря отображается в соответствии со свойством View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage отображаемого представления. |
| NO_SCALE_TO_END_DATE | Раздел календаря отображается точно до EndDate, даже если на странице есть пустое пространство. |
| NO_SCALE_TO_END_OF_PAGE | Раздел календаря отображается до конца (правой стороны) последней страницы.<br/>            Таким образом, последняя отображаемая дата может превышать EndDate. |
| SCALE_TO_END_OF_PAGE | Механизм рендеринга попытается выровнять даты так, чтобы EndDate был выровнен с концом (правой стороной) последней страницы.<br/>            Соответствует включенной опции "Page Setup \ View \ Fit timescale to end of page" в MS Project. |
