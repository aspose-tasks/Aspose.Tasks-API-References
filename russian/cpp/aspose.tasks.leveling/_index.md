## Aspose::Tasks::Leveling namespace

Используйте LevelingOptions для указания параметров выравнивания, ResourceLeveler для выполнения процесса выравнивания и LevelingResult для получения результатов. Это пространство имён предоставляет детальный контроль над распределением ресурсов и разрешением конфликтов в Aspose.Tasks.


## Классы

| Имя | Описание |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Позволяет указать параметры ресурсного выравнивания. |
| [LevelingResult](./levelingresult/) | Представляет результаты ресурсного выравнивания. |
| [ResourceLeveler](./resourceleveler/) | Содержит методы ресурсного выравнивания. |
