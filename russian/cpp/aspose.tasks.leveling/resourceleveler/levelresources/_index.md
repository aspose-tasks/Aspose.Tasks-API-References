## LevelResources {#levelresources}

Выравнивает задачи для указанных ресурсов, используя заданные параметры выравнивания.

**Returns:** Object containing results of resource leveling.

```cpp
LevelResources(const System::SharedPtr< Project > & project, const System::SharedPtr< LevelingOptions > & options)
```

| Параметр | Описание |
| --- | --- |
| проект | Проект для применения уравновешивания ресурсов. |
| options | Параметры, определяющие, как уравновешивать ресурсы. |
