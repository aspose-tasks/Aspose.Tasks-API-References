## ResourceLeveler class

Содержит методы ресурсного выравнивания.

## Методы

| Имя | Описание |
| --- | --- |
| [ClearLeveling (2 overloads)](./clearleveling/) | Очищает любые задержки выравнивания, ранее добавленные в проект во время выравнивания ресурсов. |
| [LevelAll](./levelall/) | Выравнивает задачи для всех ресурсов проекта, используя параметры выравнивания по умолчанию. |
| [LevelResources](./levelresources/) | Выравнивает задачи для указанных ресурсов, используя заданные параметры выравнивания. |
