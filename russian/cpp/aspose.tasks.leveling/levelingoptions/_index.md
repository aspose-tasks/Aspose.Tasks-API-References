## LevelingOptions class

Позволяет указать параметры ресурсного выравнивания.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Инициализирует новый экземпляр класса LevelingOptions. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_FinishDate](./get_finishdate/) | Получает дату окончания периода выравнивания. Значение по умолчанию — дата завершения проекта. |
| [get_LevelingOrder](./get_levelingorder/) | Получает порядок, в котором алгоритм выравнивания откладывает задачи с перераспределениями. После определения задач, вызывающих перераспределение, и задач, которые можно отложить, используется указанный порядок, определяющий, какая задача должна быть отложена первой. |
| [get_MessageHandler](./get_messagehandler/) | Получает обратный вызов обработчика сообщений, который можно использовать для перехвата сообщений журнала, создаваемых Aspose.Tasks во время выравнивания ресурсов. |
| [get_MessageLevel](./get_messagelevel/) | Получает уровень сообщений журнала, генерируемых Aspose.Tasks во время выравнивания ресурсов. |
| [get_Resources](./get_resources/) | Получает список ресурсов, которые будут выравнены. Если установлено значение null, будут выравнены все ресурсы проекта. |
| [get_StartDate](./get_startdate/) | Получает дату начала периода выравнивания. Значение по умолчанию — дата начала проекта. |
| [set_FinishDate](./set_finishdate/) | Устанавливает дату окончания периода выравнивания. Значение по умолчанию — дата завершения проекта. |
| [set_LevelingOrder](./set_levelingorder/) | Получает порядок, в котором алгоритм выравнивания откладывает задачи с перераспределениями. После определения задач, вызывающих перераспределение, и задач, которые можно отложить, используется указанный порядок, определяющий, какая задача должна быть отложена первой. |
| [set_MessageHandler](./set_messagehandler/) | Устанавливает обратный вызов обработчика сообщений, который можно использовать для перехвата сообщений журнала, создаваемых Aspose.Tasks во время выравнивания ресурсов. |
| [set_MessageLevel](./set_messagelevel/) | Устанавливает уровень сообщений журнала, генерируемых Aspose.Tasks во время выравнивания ресурсов. |
| [set_Resources](./set_resources/) | Устанавливает список ресурсов, которые будут выравнены. Если установлено значение null, будут выравнены все ресурсы проекта. |
| [set_StartDate](./set_startdate/) | Устанавливает дату начала периода выравнивания. Значение по умолчанию — дата начала проекта. |
