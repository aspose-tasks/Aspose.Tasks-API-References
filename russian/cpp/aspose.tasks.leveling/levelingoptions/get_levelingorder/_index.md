## get_LevelingOrder {#get_levelingorder}

Получает порядок, в котором алгоритм выравнивания откладывает задачи с перераспределениями. После определения задач, вызывающих перераспределение, и задач, которые можно отложить, используется указанный порядок, определяющий, какая задача должна быть отложена первой.

**Returns:** Aspose::Tasks::Leveling::LevelingOrder Aspose::Tasks::Leveling::

```cpp
get_LevelingOrder()
```
