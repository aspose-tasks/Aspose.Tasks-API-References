## PrimaveraProjectInfo class

Представляет краткую информацию о проекте, загруженном из формата Primavera.

## Методы

| Имя | Описание |
| --- | --- |
| [get_ExportFlag](./get_exportflag/) | Получает флаг экспорта проекта. Когда проект выбран для экспорта в Primavera, его ExportFlag равно true. Некоторые проекты, не явно выбранные для экспорта, могут быть экспортированы в файл XER из‑за их связи с экспортируемым проектом. |
| [get_Name](./get_name/) | Получает имя проекта. |
| [get_Uid](./get_uid/) | Получает Uid проекта. |
