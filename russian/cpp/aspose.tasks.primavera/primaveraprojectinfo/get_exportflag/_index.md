## get_ExportFlag {#get_exportflag}

Получает флаг экспорта проекта. Когда проект выбран для экспорта в Primavera, его ExportFlag равно true. Некоторые проекты, не явно выбранные для экспорта, могут быть экспортированы в файл XER из‑за их связи с экспортируемым проектом.
