## SaveOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Это абстрактный базовый класс для классов, позволяющих пользователю указывать дополнительные параметры при сохранении проекта в определённый формат.

Экземпляр любого производного класса от класса SaveOptions передаётся в перегрузки Save для потока или строки, позволяя пользователю задавать пользовательские параметры при сохранении документа.
