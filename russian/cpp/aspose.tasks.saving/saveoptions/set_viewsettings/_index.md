## set_ViewSettings {#set_viewsettings}

Устанавливает представление ( View ) для отображения. Вы можете использовать эту опцию, чтобы явно указать, какое представление должно быть сохранено в форматах PDF, HTML или Image. Если это свойство задано, свойство Visualization::PresentationFormat игнорируется при сохранении проекта. Представление должно быть выбрано из одного из следующих экранов (( Aspose::Tasks::View::Screen )): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage).
