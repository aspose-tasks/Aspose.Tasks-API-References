## get_View {#get_view}

Получает список столбцов представления для отображения ( GanttChartColumn ). Если не задано, отображаются только идентификаторы задач, названия задач, начало и завершение. Если заданы свойства View и ViewSettings, столбцы из View переопределяют столбцы из ViewSettings.

**Returns:** System::SharedPtr< Aspose::Tasks::Visualization::ProjectView > Aspose::Tasks::Saving::
