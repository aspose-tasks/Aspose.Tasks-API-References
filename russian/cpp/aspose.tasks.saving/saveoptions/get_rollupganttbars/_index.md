## get_RollUpGanttBars {#get_rollupganttbars}

Возвращает значение, указывающее, следует ли помечать подзадачи на полосе сводной задачи. Для подзадач поле Rollup указывает, будет ли информация о полосах Ганта подзадач агрегирована в полосу сводной задачи. Для сводных задач поле Rollup указывает, отображает ли полоса сводной задачи агрегированные полосы. Для того чтобы любые подзадачи агрегировались, поле Rollup для сводных задач должно быть установлено в Yes.
