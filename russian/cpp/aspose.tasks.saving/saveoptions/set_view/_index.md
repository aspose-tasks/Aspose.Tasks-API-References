## set_View {#set_view}

Устанавливает список столбцов представления для отображения ( GanttChartColumn ). Если не задано, отображаются только идентификаторы задач, названия задач, начало и завершение. Если заданы свойства View и ViewSettings, столбцы из View переопределяют столбцы из ViewSettings.
