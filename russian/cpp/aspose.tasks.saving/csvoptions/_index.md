## CsvOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Позволяет указать дополнительные параметры при сохранении проекта в CSV.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [CsvOptions](./csvoptions/) | Инициализирует новый экземпляр класса CsvOptions, который можно использовать для сохранения проекта в формате CSV. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_DataCategory](./get_datacategory/) | Получает категорию данных для сохранения. |
| [get_Encoding](./get_encoding/) | Получает кодировку для сохранения CSV. |
| [get_IncludeHeaders](./get_includeheaders/) | Получает значение, указывающее, включать ли заголовки (значение по умолчанию – TRUE). |
| [get_TextDelimiter](./get_textdelimiter/) | Получает разделитель текста. |
| [get_View](./get_view/) | Получает список столбцов представления ( GanttChartColumn ), которые сохраняются в формате XLSX. Если не задано, сохраняются столбцы по умолчанию. |
| [set_DataCategory](./set_datacategory/) | Устанавливает категорию данных для сохранения. |
| [set_Encoding](./set_encoding/) | Устанавливает кодировку для сохранения CSV. |
| [set_IncludeHeaders](./set_includeheaders/) | Устанавливает значение, указывающее, включать ли заголовки (значение по умолчанию – TRUE). |
| [set_TextDelimiter](./set_textdelimiter/) | Устанавливает разделитель текста. |
| [set_View](./set_view/) | Устанавливает список столбцов представления ( GanttChartColumn ), которые сохраняются в формате XLSX. Если не задано, сохраняются столбцы по умолчанию. |
