## MPPSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Позволяет указать дополнительные параметры при сохранении данных проекта в MPP.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [MPPSaveOptions](./mppsaveoptions/) | Инициализирует новый экземпляр класса MPPSaveOptions. |

| [get_ProtectionPassword](./get_protectionpassword/) | Возвращает пароль, используемый для защиты получаемого файла MPP. В настоящее время поддерживается для форматов MS Project 2010 и новее. |
