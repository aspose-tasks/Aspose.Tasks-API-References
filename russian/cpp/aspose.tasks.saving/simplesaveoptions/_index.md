## SimpleSaveOptions class

Это абстрактный базовый класс, позволяющий пользователю указывать базовые параметры при сохранении проекта в определённый формат.

## Методы

| Имя | Описание |
| --- | --- |
| [get_SaveFormat](./get_saveformat/) | Возвращает формат, в котором будет сохранён документ, если используется этот объект параметров сохранения. |
| [get_TasksComparer](./get_taskscomparer/) | Возвращает компаратор для сортировки задач на диаграмме Ганта и листе задач. |
| [get_TasksFilter](./get_tasksfilter/) | Возвращает условие, используемое для фильтрации задач, отображаемых на диаграммах Ганта, листе задач и использовании задач. |
| [set_TasksComparer](./set_taskscomparer/) | Устанавливает компаратор для сортировки задач на диаграмме Ганта и листе задач. |
| [set_TasksFilter](./set_tasksfilter/) | Устанавливает условие, используемое для фильтрации задач, отображаемых на диаграммах Ганта, листе задач и использовании задач. |
