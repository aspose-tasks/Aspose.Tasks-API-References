## SaveTemplateOptions class

Позволяет указать дополнительные параметры при сохранении проекта в виде шаблона.

## Методы

| Имя | Описание |
| --- | --- |
| [get_RemoveActualValues](./get_removeactualvalues/) | Возвращает значение, указывающее, следует ли удалить все фактические значения из шаблона проекта. |
| [get_RemoveBaselineValues](./get_removebaselinevalues/) | Возвращает значение, указывающее, следует ли удалить все базовые значения из шаблона проекта. |
| [get_RemoveFixedCosts](./get_removefixedcosts/) | Возвращает значение, указывающее, следует ли удалить все фиксированные затраты из шаблона проекта. |
| [get_RemoveResourceRates](./get_removeresourcerates/) | Возвращает значение, указывающее, следует ли удалить ставки ресурсов из шаблона проекта. |
| [set_RemoveActualValues](./set_removeactualvalues/) | Устанавливает значение, указывающее, следует ли удалить все фактические значения из шаблона проекта. |
| [set_RemoveBaselineValues](./set_removebaselinevalues/) | Устанавливает значение, указывающее, следует ли удалить все базовые значения из шаблона проекта. |
| [set_RemoveFixedCosts](./set_removefixedcosts/) | Устанавливает значение, указывающее, следует ли удалить все фиксированные затраты из шаблона проекта. |
| [set_RemoveResourceRates](./set_removeresourcerates/) | Устанавливает значение, указывающее, следует ли удалить ставки ресурсов из шаблона проекта. |
