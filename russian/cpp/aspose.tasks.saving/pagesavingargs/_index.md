## PageSavingArgs class

Этот класс представляет набор данных, связанных с сохранением страницы документа в поток.

## Методы

| Имя | Описание |
| --- | --- |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Получает значение, указывающее, должна ли процедура рендеринга оставлять поток открытым после записи страницы. |
| [get_PageNumber](./get_pagenumber/) | Получает номер страницы, которую следует записать. |
| [get_Stream](./get_stream/) | Получает поток для записи страницы. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Устанавливает значение, указывающее, должна ли процедура рендеринга оставлять поток открытым после записи страницы. |
| [set_Stream](./set_stream/) | Устанавливает поток для записи страницы. |
