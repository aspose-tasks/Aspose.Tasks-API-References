## ImageSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

Позволяет указать дополнительные параметры при рендеринге страниц проекта в изображения.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [ImageSaveOptions](./imagesaveoptions/) | Инициализирует новый экземпляр класса ImageSaveOptions, который можно использовать для сохранения отрисованных изображений в форматах TIFF, PNG, BMP или JPEG. |
