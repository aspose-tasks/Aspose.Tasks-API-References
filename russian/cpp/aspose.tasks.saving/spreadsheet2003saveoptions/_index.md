## Spreadsheet2003SaveOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Позволяет указать дополнительные параметры при отрисовке страниц проекта в Spreadsheet2003.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [Spreadsheet2003SaveOptions](./spreadsheet2003saveoptions/) | Инициализирует новый экземпляр класса Spreadsheet2003SaveOptions. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Получает список столбцов представления назначений для отрисовки ( AssignmentViewColumn ). |
| [get_ResourceView](./get_resourceview/) | Получает список столбцов представления ресурсов для отрисовки ( ResourceViewColumn ). |
| [get_View](./get_view/) | Получает список столбцов представления ( GanttChartColumn ) для сохранения. Если не задано, сохраняются столбцы по умолчанию. |
| [set_AssignmentView](./set_assignmentview/) | Устанавливает список столбцов представления назначений для отрисовки ( AssignmentViewColumn ). |
| [set_ResourceView](./set_resourceview/) | Устанавливает список столбцов представления ресурсов для отрисовки ( ResourceViewColumn ). |
| [set_View](./set_view/) | Устанавливает список столбцов представления ( GanttChartColumn ) для сохранения. Если не задано, сохраняются столбцы по умолчанию. |
