## PdfSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

Позволяет указать дополнительные параметры при рендеринге страниц проекта в PDF.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [PdfSaveOptions](./pdfsaveoptions/) | Инициализирует новый экземпляр класса PdfSaveOptions, который можно использовать для сохранения документа в формате PDF. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_Compliance](./get_compliance/) | Возвращает желаемый уровень соответствия для создаваемого PDF‑документа. По умолчанию — PdfCompliance::Pdf15. |
| [get_DigitalSignatureDetails](./get_digitalsignaturedetails/) | Возвращает сведения о цифровой подписи. Если не задано, подпись не будет выполнена. |
| [get_EncryptionDetails](./get_encryptiondetails/) | Возвращает сведения о шифровании. Если не задано, шифрование не будет выполнено. |

| [get_PageSavingCallback](./get_pagesavingcallback/) | Возвращает пользовательский обратный вызов, используемый для получения выходного потока для каждой отрисованной страницы. Применяется, когда используется параметр SaveToSeparateFiles. |
| [get_ReduceFooterGap](./get_reducefootergap/) | Получает значение, указывающее, следует ли уменьшить промежуток между последней задачей и нижним колонтитулом. |

| [get_TextCompression](./get_textcompression/) | Возвращает тип сжатия, используемый для всех потоков содержимого, кроме изображений. По умолчанию — PdfTextCompression::Flate. |
| [set_Compliance](./set_compliance/) | Устанавливает желаемый уровень соответствия для создаваемого PDF‑документа. По умолчанию — PdfCompliance::Pdf15. |

| [set_EncryptionDetails](./set_encryptiondetails/) | Устанавливает сведения о шифровании. Если не задано, шифрование не будет выполнено. |
| [set_Pages](./set_pages/) | Устанавливает список номеров страниц для сохранения при сохранении макета проекта в отдельные файлы. |

| [set_ReduceFooterGap](./set_reducefootergap/) | Устанавливает значение, указывающее, следует ли уменьшить зазор между последней задачей и нижним колонтитулом. |
| [set_SaveToSeparateFiles](./set_savetoseparatefiles/) | Устанавливает значение, указывающее, следует ли сохранять страницы проекта в отдельные файлы. |
