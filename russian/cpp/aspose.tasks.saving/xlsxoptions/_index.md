## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Позволяет указать дополнительные параметры при рендеринге страниц проекта в XLSX.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Инициализирует новый экземпляр класса XlsxOptions, который можно использовать для сохранения проекта в формате XLSX. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Получает список столбцов представления назначений для отрисовки ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | Получает кодировку получаемого файла XLSX. Значение по умолчанию — System::Text::Encoding::UTF8. |
| [get_ResourceView](./get_resourceview/) | Получает список столбцов представления ресурсов для отрисовки ( ResourceViewColumn ). |
| [get_View](./get_view/) | Получает список столбцов представления ( GanttChartColumn ), которые сохраняются в формате XLSX. Если не задано, сохраняются столбцы по умолчанию. |
| [set_AssignmentView](./set_assignmentview/) | Устанавливает список столбцов представления назначений для отрисовки ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | Устанавливает кодировку получаемого файла XLSX. Значение по умолчанию — System::Text::Encoding::UTF8. |
| [set_ResourceView](./set_resourceview/) | Устанавливает список столбцов представления ресурсов для отрисовки ( ResourceViewColumn ). |
| [set_View](./set_view/) | Устанавливает список столбцов представления ( GanttChartColumn ), которые сохраняются в формате XLSX. Если не задано, сохраняются столбцы по умолчанию. |
