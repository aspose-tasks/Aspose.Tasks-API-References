## GetRiskItems {#getriskitems}

Возвращает экземпляр RiskItemStatisticsCollection для указанного типа риска.

**Returns:** an instance of the RiskItemStatisticsCollection for the specified risk type.

```cpp
GetRiskItems(RiskItemType itemType)
```

| Параметр | Описание |
| --- | --- |
| itemType | указанный тип риска; может быть одним из значений перечисления RiskItemType. |
