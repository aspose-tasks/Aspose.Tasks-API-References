## RiskAnalyzer class

Выполняет моделирование Монте‑Карло на основе указанных настроек анализа риска.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [RiskAnalyzer](./riskanalyzer/) | Инициализирует новый экземпляр класса RiskAnalyzer. |

## Методы

| Имя | Описание |
| --- | --- |
| [Analyze](./analyze/) | Выполняет анализ рисков для указанного проекта. Анализ основан на моделировании Монте‑Карло, и результатом является экземпляр класса RiskAnalysisResult. |
| [get_Settings](./get_settings/) | Получает экземпляр класса RiskAnalysisSettings, который определяет необходимые настройки для анализа рисков. |
| [set_Settings](./set_settings/) | Устанавливает экземпляр класса RiskAnalysisSettings, который определяет необходимые настройки для анализа рисков. |
