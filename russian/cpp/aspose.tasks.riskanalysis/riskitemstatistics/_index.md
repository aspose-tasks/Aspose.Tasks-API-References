## RiskItemStatistics class

Представляет элемент, который хранит статистические данные для задачи анализируемого проекта.

## Методы

| Имя | Описание |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | Получает ожидаемое значение риск‑элемента. |
| [get_ItemType](./get_itemtype/) | Получает экземпляр перечисления RiskItemType. |
| [get_Maximum](./get_maximum/) | Получает максимальное значение, сгенерированное во время моделирования Монте-Карло. |
| [get_Minimum](./get_minimum/) | Получает минимальное значение, сгенерированное во время моделирования Монте-Карло. |
| [get_StandardDeviation](./get_standarddeviation/) | Получает стандартное отклонение риск‑элемента. |
| [GetPercentile](./getpercentile/) | Получает значение, ниже которого находится указанный процент сгенерированных образцов. |
| [ToString](./tostring/) | Возвращает короткое строковое представление риск‑элемента. Точные детали представления не указаны и могут измениться. |
