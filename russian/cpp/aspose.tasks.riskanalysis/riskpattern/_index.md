## RiskPattern class

Представляет шаблон риска для задачи проекта.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [RiskPattern](./riskpattern/) | Инициализирует новый экземпляр класса RiskPattern. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_ConfidenceLevel](./get_confidencelevel/) | Получает уровень доверия, соответствующий проценту времени, когда фактические сгенерированные значения будут находиться в пределах оптимистических и пессимистических оценок. Значение по умолчанию — CL99. |
| [get_Distribution](./get_distribution/) | Получает распределение вероятностей, используемое в моделировании Монте-Карло. Значение по умолчанию — ProbabilityDistributionType.Normal. |
| [get_Optimistic](./get_optimistic/) | Получает процент наиболее вероятной продолжительности задачи, который может произойти в лучшем возможном сценарии проекта. Значение по умолчанию — 75, что означает, что если оценочная продолжительность задачи составляет 4 дня, то оптимистическая продолжительность будет 3 дня. |
| [get_Pessimistic](./get_pessimistic/) | Получает процент наиболее вероятной продолжительности задачи, который может произойти в наихудшем возможном сценарии проекта. Значение по умолчанию — 125, что означает, что если оценочная продолжительность задачи составляет 4 дня, то пессимистическая продолжительность будет 5 дней. |
| [get_Task](./get_task/) | Получает задачу проекта, к которой применяется данный шаблон риска. |
| [set_ConfidenceLevel](./set_confidencelevel/) | Устанавливает уровень доверия, соответствующий проценту времени, когда фактические сгенерированные значения будут находиться в пределах оптимистических и пессимистических оценок. Значение по умолчанию — CL99. |
| [set_Distribution](./set_distribution/) | Устанавливает распределение вероятностей, используемое в моделировании Монте-Карло. Значение по умолчанию — ProbabilityDistributionType.Normal. |
| [set_Optimistic](./set_optimistic/) | Устанавливает процент наиболее вероятной продолжительности задачи, который может произойти в лучшем возможном сценарии проекта. Значение по умолчанию — 75, что означает, что если оценочная продолжительность задачи составляет 4 дня, то оптимистическая продолжительность будет 3 дня. |
| [set_Pessimistic](./set_pessimistic/) | Устанавливает процент наиболее вероятной продолжительности задачи, который может произойти в наихудшем возможном сценарии проекта. Значение по умолчанию — 125, что означает, что если оценочная продолжительность задачи составляет 4 дня, то пессимистическая продолжительность будет 5 дней. |
