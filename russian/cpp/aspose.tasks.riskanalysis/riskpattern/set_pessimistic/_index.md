## set_Pessimistic {#set_pessimistic}

Устанавливает процент наиболее вероятной продолжительности задачи, который может произойти в наихудшем возможном сценарии проекта. Значение по умолчанию — 125, что означает, что если оценочная продолжительность задачи составляет 4 дня, то пессимистическая продолжительность будет 5 дней.
