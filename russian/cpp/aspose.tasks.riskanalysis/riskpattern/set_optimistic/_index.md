## set_Optimistic {#set_optimistic}

Устанавливает процент наиболее вероятной продолжительности задачи, который может произойти в лучшем возможном сценарии проекта. Значение по умолчанию — 75, что означает, что если оценочная продолжительность задачи составляет 4 дня, то оптимистическая продолжительность будет 3 дня.
