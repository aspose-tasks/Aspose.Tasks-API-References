## Aspose::Tasks::Connectivity namespace

Используйте эти типы для настройки соединений с базами данных Microsoft Project Server (MspDbSettings), базами данных Primavera (PrimaveraDbSettings), MPD‑файлами (MpdSettings) или общими источниками баз данных (DbSettings). Пространство имён централизует конфигурацию соединений для бесшовной интеграции с функциями извлечения и обработки данных Aspose.Tasks.


## Классы

| Имя | Описание |
| --- | --- |
| [DbSettings](./dbsettings/) | Позволяет указать настройки для чтения из базы данных проекта. |
| [MpdSettings](./mpdsettings/) | Позволяет задать необходимые параметры для чтения данных проекта из формата MPD (MS Access |
| [MspDbSettings](./mspdbsettings/) | Позволяет задать необходимые параметры для чтения данных проекта из MS Project Server |
| [PrimaveraDbSettings](./primaveradbsettings/) | Позволяет задать необходимые параметры для чтения данных проекта из базы данных Primavera. |
