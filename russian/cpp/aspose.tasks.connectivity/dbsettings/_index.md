## DbSettings class

Позволяет указать настройки для чтения из базы данных проекта.

## Методы

| Имя | Описание |
| --- | --- |
| [get_ConnectionString](./get_connectionstring/) | Получает строку подключения. |
| [get_ProviderInvariantName](./get_providerinvariantname/) | Получает инвариантное имя поставщика, которое используется для получения экземпляра класса System::Data::Common::DbProviderFactory. |
| [set_ConnectionString](./set_connectionstring/) | Устанавливает строку подключения. |
| [set_ProviderInvariantName](./set_providerinvariantname/) | Устанавливает инвариантное имя поставщика, которое используется для получения экземпляра класса System::Data::Common::DbProviderFactory. |
