## ProjectView class

Класс представления проекта

## Конструкторы

| Имя | Описание |
| --- | --- |
| [ProjectView](./projectview/) | Инициализирует новый экземпляр класса ProjectView. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_Columns](./get_columns/) | Получает столбцы представления проекта. |
| [GetDefaultAssignmentView](./getdefaultassignmentview/) | Включает столбцы Uid, имя задачи, имя ресурса, работу и продолжительность назначения. |
| [GetDefaultGanttChartView](./getdefaultganttchartview/) | Включает столбцы id, индикаторы, имя, продолжительность, начало и завершение задачи. |
| [GetDefaultResourceSheetView](./getdefaultresourcesheetview/) | Включает столбцы Uid, имя ресурса, тип, метка материала, инициалы, группа, максимальное количество единиц, стандартная ставка, ставка за сверхурочную работу, стоимость за использование, начисление, базовый календарь и код ресурса. |
| [GetDefaultResourceUsageView](./getdefaultresourceusageview/) | Включает столбцы Uid, имя, начало, завершение и работу ресурса. |
| [GetDefaultTaskSheetView](./getdefaulttasksheetview/) | Включает столбцы задачи: id, индикаторы, имя, продолжительность, начало, завершение, предшественники и имена ресурсов. |
