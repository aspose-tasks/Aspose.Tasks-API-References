## GetDefaultResourceSheetView {#getdefaultresourcesheetview}

Включает столбцы Uid, имя ресурса, тип, метка материала, инициалы, группа, максимальное количество единиц, стандартная ставка, ставка за сверхурочную работу, стоимость за использование, начисление, базовый календарь и код ресурса.

**Returns:** a view which contains a list of ResourceViewColumn .

```cpp
GetDefaultResourceSheetView()
```
