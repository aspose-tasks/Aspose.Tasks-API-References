## PageLegend class

**Inherits:** Aspose::Tasks::Visualization::HeaderFooterInfo

Представляет легенду страницы, используемую для печати проекта.

## Методы

| Имя | Описание |
| --- | --- |
| [get_LegendOn](./get_legendon/) | Получает страницы, на которых отображается легенда. Может быть одним из значений перечисления Legend. |
| [get_Width](./get_width/) | Получает ширину левой части (по умолчанию содержащей название проекта и дату) легенды в сантиметрах. |
| [set_LegendOn](./set_legendon/) | Устанавливает страницы, на которых отображается легенда. Может быть одним из значений перечисления Legend. |
| [set_Width](./set_width/) | Устанавливает ширину левой части (по умолчанию содержащей название проекта и дату) легенды в сантиметрах. |
