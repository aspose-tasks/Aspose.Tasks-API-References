## PageInfo class

Представляет данные настройки страницы, которые присутствуют в формате файла MPP и используются для печати.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [PageInfo](./pageinfo/) | Инициализирует новый экземпляр класса PageInfo. Представляет данные настройки страницы, которые присутствуют в формате файла MPP и используются для печати. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_Footer](./get_footer/) | Получает экземпляр класса HeaderFooterInfo, который представляет данные нижнего колонтитула. |
| [get_Header](./get_header/) | Получает экземпляр класса HeaderFooterInfo, который представляет данные верхнего колонтитула. |
| [get_Legend](./get_legend/) | Получает экземпляр класса PageLegend, который задает параметры отрисовки легенды страницы. |
| [get_Margins](./get_margins/) | Получает экземпляр класса PageMargins, который задает поля страницы. |
| [get_Name](./get_name/) | Получает имя представления, для которого используются данные настройки. |
| [get_PageSettings](./get_pagesettings/) | Получает экземпляр класса PageSettings, который задает параметры печати страницы. |
| [get_PageViewSettings](./get_pageviewsettings/) | Получает экземпляр класса PageViewSettings, который задает параметры печати представления страницы. |
| [set_Footer](./set_footer/) | Устанавливает экземпляр класса HeaderFooterInfo, который представляет данные нижнего колонтитула. |
| [set_Header](./set_header/) | Устанавливает экземпляр класса HeaderFooterInfo, который представляет данные верхнего колонтитула. |
| [set_Legend](./set_legend/) | Устанавливает экземпляр класса PageLegend, который задает параметры отрисовки легенды страницы. |
