## set_RenderLabelOnEachPage {#set_renderlabeloneachpage}

Устанавливает флаг, определяющий, должны ли метки даты отображаться на каждой странице, когда временной период охватывает несколько страниц. Если значение равно 'true', при охвате периода несколькими страницами метки даты для периода отображаются на каждой странице. Если значение равно 'false', метка даты отображается только один раз в соответствии со значением свойства Alignment.
