## get_RenderLabelOnEachPage {#get_renderlabeloneachpage}

Получает флаг, определяющий, должны ли метки даты отображаться на каждой странице, когда временной период охватывает несколько страниц. Если значение равно 'true', при охвате периода несколькими страницами метки даты для периода отображаются на каждой странице. Если значение равно 'false', метка даты отображается только один раз в соответствии со значением свойства Alignment.

**Returns:** bool Aspose::Tasks::Visualization::

```cpp
get_RenderLabelOnEachPage()
```
