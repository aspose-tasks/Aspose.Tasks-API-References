## PageMargins class

Представляет поля страницы для печати.

## Методы

| Имя | Описание |
| --- | --- |
| [get_Borders](./get_borders/) | Получает позицию, где печатать границы. Может быть одним из значений перечисления Border. |
| [get_Bottom](./get_bottom/) | Получает размер нижнего поля в сантиметрах. |
| [get_Left](./get_left/) | Получает размер левого поля в сантиметрах. |
| [get_Right](./get_right/) | Получает размер правого поля в сантиметрах. |
| [get_Top](./get_top/) | Получает размер верхнего поля в сантиметрах. |
| [set_Borders](./set_borders/) | Устанавливает позицию, где печатать границы. Может быть одним из значений перечисления Border. |
| [set_Bottom](./set_bottom/) | Устанавливает размер нижнего поля в сантиметрах. |
| [set_Left](./set_left/) | Устанавливает размер левого поля в сантиметрах. |
| [set_Right](./set_right/) | Устанавливает размер правого поля в сантиметрах. |
| [set_Top](./set_top/) | Устанавливает размер верхнего поля в сантиметрах. |
