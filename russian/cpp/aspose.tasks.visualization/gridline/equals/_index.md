## Equals {#equals}

Возвращает флаг, указывающий, равен ли данный экземпляр указанному объекту.

**Returns:** a flag indicating whether this instance is equal to the specified object.

```cpp
Equals(System::SharedPtr< System::Object > obj)
```

| Параметр | Описание |
| --- | --- |
| obj | указанный объект для сравнения с этим экземпляром. |
