## Gridlines class

Представляет сетку, отображаемую в представлении GanttChart.

## Методы

| Имя | Описание |
| --- | --- |
| [get_Interval](./get_interval/) | Получает число от 0 до 99, которое задает интервал между линиями сетки. |
| [get_IntervalColor](./get_intervalcolor/) | Получает цвет вторичных линий сетки. |
| [get_IntervalPattern](./get_intervalpattern/) | Получает шаблон линии для вторичных линий сетки. |
| [get_NormalColor](./get_normalcolor/) | Получает цвет обычных линий сетки. |
| [get_NormalPattern](./get_normalpattern/) | Получает шаблон линии для обычных линий сетки. |
| [get_Type](./get_type/) | Получает тип линии сетки. |
| [set_Interval](./set_interval/) | Устанавливает число от 0 до 99, которое задает интервал между линиями сетки. |
| [set_IntervalColor](./set_intervalcolor/) | Устанавливает цвет вторичных линий сетки. |
| [set_IntervalPattern](./set_intervalpattern/) | Устанавливает шаблон линии для вторичных линий сетки. |
| [set_NormalColor](./set_normalcolor/) | Устанавливает цвет обычных линий сетки. |
| [set_NormalPattern](./set_normalpattern/) | Устанавливает шаблон линии для обычных линий сетки. |
| [set_Type](./set_type/) | Устанавливает тип линии сетки. |
