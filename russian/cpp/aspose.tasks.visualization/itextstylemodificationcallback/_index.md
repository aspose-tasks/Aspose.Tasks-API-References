## ITextStyleModificationCallback class

Представляет обратный вызов, который вызывается до применения TextStyle к ячейке таблицы.

## Методы

| Имя | Описание |
| --- | --- |
| [BeforeTaskTextStyleApplied](./beforetasktextstyleapplied/) | Метод, который вызывается перед отрисовкой ячейки таблицы для строки задачи в следующих представлениях: 'Gantt Chart', ' Task Sheet', ' Task Usage'. |
