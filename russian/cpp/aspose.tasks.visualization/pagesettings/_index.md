## PageSettings class

Представляет настройки печати для страницы представления проекта.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [PageSettings](./pagesettings/) | Инициализирует новый экземпляр класса PageSettings. Представляет настройки печати для страницы представления проекта. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | Получает значение, указывающее, следует ли корректировать печать до указанного процента ( PercentOfNormalSize ) от нормального размера. |
| [get_FirstPageNumber](./get_firstpagenumber/) | Получает номер первой страницы для печати. |
| [get_IsPortrait](./get_isportrait/) | Возвращает значение, указывающее, является ли ориентация страницы портретной; возвращает false, если ориентация страницы альбомная. |
| [get_PagesInHeight](./get_pagesinheight/) | Получает количество страниц по высоте, которые необходимо напечатать. |
| [get_PagesInWidth](./get_pagesinwidth/) | Получает количество страниц по ширине для печати. |
| [get_PaperSize](./get_papersize/) | Получает размер бумаги. Может быть одним из значений перечисления PrinterPaperSize. |
| [get_PaperSizeId](./get_papersizeid/) | Получает целое число, представляющее одно из значений PrinterPaperSize или идентификатор пользовательского размера страницы. Это значение можно использовать для получения PaperSize из настроек ОС. |
| [get_PercentOfNormalSize](./get_percentofnormalsize/) | Получает процент от нормального размера для корректировки печати. |
| [set_AdjustToPercentOfNormalSize](./set_adjusttopercentofnormalsize/) | Устанавливает значение, указывающее, следует ли корректировать печать до указанного процента (PercentOfNormalSize) от нормального размера. |
| [set_FirstPageNumber](./set_firstpagenumber/) | Устанавливает номер первой страницы для печати. |
| [set_IsPortrait](./set_isportrait/) | Устанавливает значение, указывающее, является ли ориентация страницы портретной; возвращает false, если ориентация страницы ландшафтная. |
| [set_PagesInHeight](./set_pagesinheight/) | Устанавливает количество страниц по высоте для печати. |
| [set_PagesInWidth](./set_pagesinwidth/) | Устанавливает количество страниц по ширине для печати. |
| [set_PaperSize](./set_papersize/) | Устанавливает размер бумаги. Может быть одним из значений перечисления PrinterPaperSize. |
| [set_PaperSizeId](./set_papersizeid/) | Устанавливает целое число, представляющее одно из значений PrinterPaperSize или идентификатор пользовательского размера страницы. Это значение можно использовать для получения PaperSize из настроек ОС. |
| [set_PercentOfNormalSize](./set_percentofnormalsize/) | Устанавливает процент от нормального размера для корректировки печати. |
