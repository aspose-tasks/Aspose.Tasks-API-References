## ViewColumn class

Представляет столбец в представлении проекта.

## Методы

| Имя | Описание |
| --- | --- |
| [get_Field](./get_field/) | Получает поле столбца. Поле . |
| [get_Name](./get_name/) | Получает имя столбца. |
| [get_StringAlignment](./get_stringalignment/) | Получает выравнивание текста (может быть одним из значений перечисления HorizontalStringAlignment). |
| [get_TextStyleModificationCallback](./get_textstylemodificationcallback/) | Получает обратный вызов, который можно использовать для настройки внешнего вида ячеек столбца. |
| [get_Width](./get_width/) | Получает ширину столбца. |
| [set_Field](./set_field/) | Устанавливает поле столбца. Поле . |
| [set_StringAlignment](./set_stringalignment/) | Устанавливает выравнивание текста (может быть одним из значений перечисления HorizontalStringAlignment). |
| [set_TextStyleModificationCallback](./set_textstylemodificationcallback/) | Устанавливает обратный вызов, который можно использовать для настройки внешнего вида ячеек столбца. |
