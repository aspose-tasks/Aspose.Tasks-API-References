## TaskTextStyleEventArgs class

Этот класс представляет набор данных, связанных с отрисовкой содержимого ячейки таблицы.

## Методы

| Имя | Описание |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | Получает TextStyle, который будет использоваться для отрисовки содержимого ячейки. Этот объект можно использовать для настройки внешнего вида ячейки таблицы. |
| [get_Column](./get_column/) | Получает ViewColumn, к которому принадлежит текущая отрисовываемая ячейка. |
| [get_Task](./get_task/) | Получает Task, соответствующий текущей отрисовываемой строке. |
| [set_CellTextStyle](./set_celltextstyle/) | Устанавливает TextStyle, который будет использоваться для отрисовки содержимого ячейки. Этот объект можно использовать для настройки внешнего вида ячейки таблицы. |
