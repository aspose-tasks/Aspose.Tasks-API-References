## ProgressLines class

Представляет линии прогресса в представлении диаграммы Ганта.

## Методы

| Имя | Описание |

| [get_BeginAtDate](./get_beginatdate/) | Получает дату, с которой отображаются линии прогресса. |

| [get_DateFormat](./get_dateformat/) | Получает формат даты ( DateLabel ). |

| [get_DisplaySelected](./get_displayselected/) | Получает значение, указывающее, следует ли отображать линии прогресса на выбранных датах. |
