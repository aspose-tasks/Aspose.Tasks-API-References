API предлагает богатую объектную модель для работы с форматами Project XML, MPX, MPP и Primavera XER, поддерживая задачи, ресурсы, назначения, календари и пользовательские поля. Его функциональность организована в девять пространств имён: Aspose::Tasks для основных сущностей, Connectivity для ввода‑вывода файлов, Leveling для выравнивания ресурсов, Primavera для объектов, специфичных для Primavera, Properties для расширенных атрибутов, RiskAnalysis для моделирования риска методом Монте‑Карло, Saving для параметров экспорта, Util для вспомогательных утилит и Visualization для визуализации диаграмм Ганта и генерации отчетов.
