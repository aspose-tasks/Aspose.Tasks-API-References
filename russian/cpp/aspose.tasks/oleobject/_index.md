## OleObject class

Представляет объект OLE, который может быть вставлен в представление диаграммы Ганта файла MPP.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [OleObject](./oleobject/) | Инициализирует новый экземпляр класса OleObject. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_ApplicationName](./get_applicationname/) | Получает имя приложения, с помощью которого открывается встроенный объект. |
| [get_Content](./get_content/) | Получает данные встроенного файла; null, если данные не были встроены. |
| [get_DisplayAsIcon](./get_displayasicon/) | Получает флаг, указывающий, должен ли объект OLE отображаться как значок или как обычное изображение. |
| [get_FileFormat](./get_fileformat/) | Получает формат файла встроенного объекта. |
| [get_FullPath](./get_fullpath/) | Получает полный путь вставленного объекта. |
| [get_Id](./get_id/) | Получает идентификатор объекта. |
| [get_Label](./get_label/) | Получает метку вставленного объекта. |
| [get_Linked](./get_linked/) | Получает значение, указывающее, содержит ли файл проекта только ссылку на фактические данные, хранящиеся в источнике ссылки. |
| [get_Name](./get_name/) | Получает имя экземпляра объекта OLE. |
| [get_TemporaryFile](./get_temporaryfile/) | Получает путь к временному файлу вставленного объекта. |
| [get_View](./get_view/) | Получает экземпляр класса View, к которому относится вставленный объект. |
| [set_ApplicationName](./set_applicationname/) | Устанавливает имя приложения, с помощью которого открывается внедрённый объект. |
| [set_Content](./set_content/) | Устанавливает данные внедрённого файла; null, если данные не были внедрены. |
| [set_DisplayAsIcon](./set_displayasicon/) | Устанавливает флаг, указывающий, что объект OLE должен отображаться либо как значок, либо как обычное изображение. |
| [set_FileFormat](./set_fileformat/) | Устанавливает формат файла внедрённого объекта. |
| [set_FullPath](./set_fullpath/) | Устанавливает полный путь к вставленному объекту. |
| [set_Id](./set_id/) | Устанавливает идентификатор объекта. |
| [set_Label](./set_label/) | Устанавливает метку вставленного объекта. |
| [set_Name](./set_name/) | Устанавливает имя экземпляра объекта OLE. |
| [set_TemporaryFile](./set_temporaryfile/) | Устанавливает путь к временному файлу вставленного объекта. |
| [set_View](./set_view/) | Устанавливает экземпляр класса View, к которому относится вставленный объект. |
