## Remove {#remove}

Удаляет указанное назначение из коллекции, если она не только для чтения, иначе бросает NotSupportedException.

**Returns:** true, if specified item was removed, false otherwise.

```cpp
Remove(const System::SharedPtr< ResourceAssignment > & item)
```

| Параметр | Описание |
| --- | --- |
| элемент | Назначение для удаления. |
