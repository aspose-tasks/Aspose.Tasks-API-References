## ProjectServerSaveOptions class

Позволяет указать дополнительные параметры при сохранении проекта в Project Server или Project Online.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [ProjectServerSaveOptions](./projectserversaveoptions/) | Инициализирует новый экземпляр класса ProjectServerSaveOptions. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_PollingInterval](./get_pollinginterval/) | Получает интервал между запросами статуса задач в очереди. Значение по умолчанию — 2 секунды. |
| [get_ProjectGuid](./get_projectguid/) | Получает уникальный идентификатор проекта. Должен быть уникальным в пределах экземпляра Project Server \ Project Online. |
| [get_ProjectName](./get_projectname/) | Получает имя проекта, которое отображается в списке проектов Project Server \ Project Online. Должно быть уникальным в пределах экземпляра Project Server \ Project Online. Если значение опущено, будет использовано значение свойства Prj.Name. |
| [get_Timeout](./get_timeout/) | Получает тайм-аут, используемый при ожидании обработки запроса сохранения проекта службой обработки очереди Project Server. Значение свойства по умолчанию — 1 минута. |
| [set_PollingInterval](./set_pollinginterval/) | Устанавливает интервал между запросами статуса задач очереди. Значение по умолчанию — 2 секунды. |
| [set_ProjectGuid](./set_projectguid/) | Устанавливает уникальный идентификатор проекта. Должен быть уникален в пределах экземпляра Project Server \ Project Online. |
| [set_ProjectName](./set_projectname/) | Устанавливает имя проекта, отображаемое в списке проектов Project Server \ Project Online. Должно быть уникально в пределах экземпляра Project Server \ Project Online. Если значение опущено, будет использовано значение свойства Prj.Name. |
| [set_Timeout](./set_timeout/) | Устанавливает тайм-аут, используемый при ожидании обработки запроса сохранения проекта службой обработки очереди Project Server. Значение свойства по умолчанию — 1 минута. |
