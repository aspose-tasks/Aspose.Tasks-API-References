## get_ProjectName {#get_projectname}

Получает имя проекта, которое отображается в списке проектов Project Server \ Project Online. Должно быть уникальным в пределах экземпляра Project Server \ Project Online. Если значение опущено, будет использовано значение свойства Prj.Name.

**Returns:** System::String Aspose::Tasks::

```cpp
get_ProjectName()
```
