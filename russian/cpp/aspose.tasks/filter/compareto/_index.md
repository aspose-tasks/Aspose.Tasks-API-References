## CompareTo {#compareto}

Сравнивает этот экземпляр с указанным экземпляром класса Filter и возвращает указание их относительного порядка.

**Returns:** an indication of their relative order.

```cpp
CompareTo(System::SharedPtr< Filter > other)
```

| Параметр | Описание |
| --- | --- |
| другой | указанный экземпляр класса Filter для сравнения с этим объектом. |
