## idx_get {#idx_get}

Возвращает элемент по указанному индексу. Сеттер не поддерживается. свойство для установки timephased data.

**Returns:** the element at the specified index.

```cpp
idx_get(int32_t index)
```

| Параметр | Описание |
| --- | --- |
| индекс | Нулевой индекс элемента, который нужно получить. |
