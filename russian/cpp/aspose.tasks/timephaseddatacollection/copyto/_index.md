## CopyTo {#copyto}

Копирует элементы TimephasedDataCollection в System::Array, начиная с определённого индекса System::Array.

**Returns:** void Aspose::Tasks::

```cpp
CopyTo(System::ArrayPtr< System::SharedPtr< TimephasedData >> array, int32_t arrayIndex)
```

| Параметр | Описание |
| --- | --- |
| array | Одномерный System::Array, который является назначением элементов, скопированных из TimephasedDataCollection. System::Array должен иметь нулевую индексацию. |
| arrayIndex | Нулевой индекс в массиве, с которого начинается копирование. |
