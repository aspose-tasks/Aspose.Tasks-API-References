## ProjectDisplayOptions class

Представляет параметры отображения для экземпляра проекта.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [ProjectDisplayOptions](./projectdisplayoptions/) | Инициализирует новый экземпляр класса ProjectDisplayOptions. |
