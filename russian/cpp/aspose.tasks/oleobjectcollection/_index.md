## OleObjectCollection class

Представляет коллекцию, содержащую экземпляры класса OleObject.

## Методы

| Имя | Описание |
| --- | --- |
| [Clear](./clear/) | Очищает коллекцию. Чтобы сохранить эти изменения, следует вызвать project.Save с новыми MPPSaveOptions { WriteViewData = true; } |
| [GetEnumerator](./getenumerator/) | Возвращает перечислитель для этой коллекции. |
| [ToList](./tolist/) | Преобразует экземпляр класса OleObjectCollection в список, содержащий экземпляры класса OleObject. |
