## Convert {#convert}

Преобразует объект Duration в другую длительность с указанными единицами времени.

**Returns:** returns new duration with the specified unit type.

```cpp
Convert(TimeUnitType timeUnitType)
```

| Параметр | Описание |
| --- | --- |
| timeUnitType | указанный тип единицы времени. |
