## OutlineCodeDefinition class

Представляет определение кода структуры.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [OutlineCodeDefinition](./outlinecodedefinition/) | Инициализирует новый экземпляр класса OutlineCodeDefinition. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_Alias](./get_alias/) | Получает псевдоним пользовательского кода структуры. |
| [get_AllLevelsRequired](./get_alllevelsrequired/) | Получает значение, указывающее, должны ли новые коды иметь все уровни. Недоступно для Enterprise Codes. |
| [get_Enterprise](./get_enterprise/) | Получает значение, указывающее, является ли пользовательский код структуры корпоративным пользовательским кодом структуры. |
| [get_EnterpriseOutlineCodeAlias](./get_enterpriseoutlinecodealias/) | Получает ссылку на другое пользовательское поле, для которого данное определение кода структуры является псевдонимом. |
| [get_FieldId](./get_fieldid/) | Получает номер поля кода структуры. |
| [get_FieldName](./get_fieldname/) | Получает имя пользовательского кода структуры. |
| [get_Guid](./get_guid/) | Получает Guid кода структуры. |
| [get_LeafOnly](./get_leafonly/) | Получает значение, указывающее, должны ли значения, указанные в этом поле кода структуры, быть листовыми значениями. |
| [get_Masks](./get_masks/) | Получает объект OutlineMaskCollection. Таблица записей, определяющих маску кода структуры. Экземпляр OutlineMaskCollection только для чтения. |
| [get_OnlyTableValuesAllowed](./get_onlytablevaluesallowed/) | Получает значение, указывающее, должны ли указанные значения поступать из таблицы значений. |
| [get_PhoneticAlias](./get_phoneticalias/) | Получает фонетическое произношение псевдонима пользовательского кода структуры. |
| [get_ResourceSubstitutionEnabled](./get_resourcesubstitutionenabled/) | Получает значение, указывающее, может ли пользовательский код структуры использоваться мастером подстановки ресурсов в Microsoft Project. |
| [get_ShowIndent](./get_showindent/) | Получает значение, указывающее, должны ли отступы этого кода структуры отображаться. |
| [get_Values](./get_values/) | Получает объект OutlineValueCollection. Значения таблицы, связанной с этим кодом структуры. |
| [set_Alias](./set_alias/) | Устанавливает псевдоним пользовательского кода структуры. |
| [set_AllLevelsRequired](./set_alllevelsrequired/) | Устанавливает значение, указывающее, должны ли новые коды иметь все уровни. Недоступно для Enterprise Codes. |
| [set_Enterprise](./set_enterprise/) | Устанавливает значение, указывающее, является ли пользовательский код структуры корпоративным пользовательским кодом структуры. |
| [set_EnterpriseOutlineCodeAlias](./set_enterpriseoutlinecodealias/) | Устанавливает ссылку на другое пользовательское поле, для которого данное определение кода структуры является псевдонимом. |
| [set_FieldId](./set_fieldid/) | Устанавливает номер поля кода структуры. |
| [set_FieldName](./set_fieldname/) | Устанавливает имя пользовательского кода структуры. |
| [set_Guid](./set_guid/) | Устанавливает Guid контурного кода. |
| [set_LeafOnly](./set_leafonly/) | Устанавливает значение, указывающее, должны ли указанные в этом поле контурного кода значения быть конечными. |
