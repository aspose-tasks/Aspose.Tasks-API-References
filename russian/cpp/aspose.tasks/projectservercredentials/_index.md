## ProjectServerCredentials class

Учётные данные, которые используются для подключения к Project Online или локальному экземпляру Project Server.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [ProjectServerCredentials (3 overloads)](./projectservercredentials/) | Инициализирует новый экземпляр класса ProjectServerCredentials, используя URL сайта SharePoint и действительный токен авторизации SPOIDCRL для сайта PWA (Project Web Access) SharePoint. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_AuthToken](./get_authtoken/) | Получает токен авторизации для экземпляра SharePoint. |
| [get_SiteUrl](./get_siteurl/) | Получает URL PWA на сайте SharePoint или URL локального сервера Project Server. Например, https://your_company_name.sharepoint.com/sites/pwa \"; |
| [get_UserName](./get_username/) | Получает имя пользователя для сайта SharePoint. |
| [ToString](./tostring/) | Возвращает строковое представление этого экземпляра. |
