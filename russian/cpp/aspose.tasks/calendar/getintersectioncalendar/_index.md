## GetIntersectionCalendar {#getintersectioncalendar}

Получает экземпляр ICalendar, который можно использовать для вычислений пересечения рабочих расписаний двух календарей.

**Returns:** Implementation of ICalendar interface.

```cpp
GetIntersectionCalendar(const System::SharedPtr< Calendar > & calendar1, const System::SharedPtr< Calendar > & calendar2)
```

| Параметр | Описание |
| --- | --- |
| calendar1 | Первый календарь. |
| calendar2 | Второй календарь. |
