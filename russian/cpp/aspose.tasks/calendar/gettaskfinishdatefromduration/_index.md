## GetTaskFinishDateFromDuration {#gettaskfinishdatefromduration}

Вычисляет дату и время завершения задачи исходя из её даты начала, разбитых частей и длительности работы.

**Returns:** Task 's finish date for the given start date and duration.

```cpp
GetTaskFinishDateFromDuration(System::SharedPtr< Task > task, System::TimeSpan duration)
```

| Параметр | Описание |
| --- | --- |
| задача | Задача, для которой рассчитывается дата завершения. |
| длительность | Длительность для расчёта. |
