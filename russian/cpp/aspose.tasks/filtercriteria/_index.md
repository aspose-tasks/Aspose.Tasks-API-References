## FilterCriteria class

Определяет критерии, которым задачи или ресурсы должны соответствовать, чтобы отображаться в представлении MSP.

## Методы

| Имя | Описание |
| --- | --- |
| [get_CriteriaRows](./get_criteriarows/) | Получает список дочерних строк FilterCriteria. Если фильтр содержит более одной строки критерия, то действие оператора And заключается в том, что критерии обеих строк должны быть выполнены, чтобы задача или ресурс отобразились в результате этого фильтра. Действие оператора Or заключается в том, что критерий одной из строк должен быть выполнен. |
| [get_Field](./get_field/) | Получает поле для изменения. |
| [get_Operation](./get_operation/) | Получает критерий, установленный с помощью FieldName, Test и Value, который относится к другим критериям в фильтре. |
| [get_Test](./get_test/) | Получает тип сравнения между FieldName и Value, который используется в качестве критериев выбора для фильтра. FilterComparisonType |
| [get_Values](./get_values/) | Получает объектные значения для сравнения со значением поля, указанного в FieldName. |
| [IsFieldValue](./isfieldvalue/) | Получает, является ли правое значение FilterCriteria ссылкой на поле, а не константным значением. |
| [set_Field](./set_field/) | Устанавливает поле для изменения. |
| [set_Operation](./set_operation/) | Устанавливает критерий, установленный с помощью FieldName, Test и Value, который относится к другим критериям в фильтре. |
| [set_Test](./set_test/) | Устанавливает тип сравнения между FieldName и Value, который используется в качестве критериев выбора для фильтра. FilterComparisonType |
| [SetValueField](./setvaluefield/) | Устанавливает поле, значение которого будет сравниваться со значением поля, указанного в FieldName. |
| [ToString](./tostring/) | Возвращает строковое представление экземпляра класса FilterCriteria. |
