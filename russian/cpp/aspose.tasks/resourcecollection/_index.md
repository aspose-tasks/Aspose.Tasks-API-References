## ResourceCollection class

Представляет коллекцию объектов Resource.

## Методы

| Имя | Описание |
| --- | --- |
| [Add (3 overloads)](./add/) | Добавляет новый ресурс в последнюю позицию коллекции ресурсов проекта. |
| [Clear](./clear/) | Прямая очистка не поддерживается, этот метод просто бросает NotSupportedException. |
| [get_Count](./get_count/) | Получает количество элементов, содержащихся в ResourceCollection. |
| [get_ParentProject](./get_parentproject/) | Получает родительский проект объекта ResourceCollection. |
| [GetById](./getbyid/) | Возвращает ресурс с указанным идентификатором. |
| [GetByUid](./getbyuid/) | Возвращает ресурс с указанным Uid. |
| [GetEnumerator](./getenumerator/) | Возвращает перечислитель для этой коллекции. |
| [idx_get](./idx_get/) | Возвращает элемент по указанному индексу. |
| [idx_set](./idx_set/) | Возвращает элемент по указанному индексу. |
| [Remove](./remove/) | Это заглушка реализации метода Remove интерфейса ICollection, который только бросает NotSupportedException |
| [ToList](./tolist/) | Преобразует объект ResourceCollection в список объектов Resource. |
