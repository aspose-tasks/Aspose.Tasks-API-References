## IsDayWorking {#isdayworking}

Определяет, является ли указанный день рабочим согласно календарю.

**Returns:** True if the day is a working day.

```cpp
IsDayWorking(System::DateTime dt)
```

| Параметр | Описание |
| --- | --- |
| dt | Дата, для которой проверяется, является ли день рабочим. |
