## PrimaveraProjectProperties class

Представляет специфичные для Primavera свойства проекта, читаемые из файлов Primavera (XER или P6XML).

## Методы

| Имя | Описание |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | Возвращает массив базовых проектов текущего проекта. Применяется к проектам, прочитанным из XML‑файлов Primavera, содержащих экспортированные базовые версии. |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | Возвращает идентификатор текущего базового проекта. Применяется к проектам, прочитанным из XML‑файлов Primavera, содержащих экспортированные базовые версии. |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | Возвращает флаг, определяющий, следует ли игнорировать взаимосвязи задач между проектами. |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | Возвращает флаг, определяющий, должны ли задачи помечаться как критические при планировании проекта. |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | Возвращает параметры, определяющие, какой календарь использовать для планирования задержки зависимостей в проектах Primavera. |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | Возвращает флаг, определяющий, следует ли планировать даты завершения задач как ожидаемые даты завершения. |
