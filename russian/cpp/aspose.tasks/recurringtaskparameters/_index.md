## RecurringTaskParameters class

Представляет набор параметров, используемых для создания повторяющейся задачи в проекте.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [RecurringTaskParameters](./recurringtaskparameters/) | Инициализирует новый экземпляр класса RecurringTaskParameters. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_Duration](./get_duration/) | Получает продолжительность одного появления повторяющейся задачи. |
| [get_IgnoreResourceCalendar](./get_ignoreresourcecalendar/) | Получает значение, указывающее, следует ли планировать повторяющуюся задачу, даже если она не может быть выполнена, когда доступны ресурсы для её выполнения. |
| [get_RecurrencePattern](./get_recurrencepattern/) | Получает шаблон повторения повторяющейся задачи. |
| [get_TaskName](./get_taskname/) | Получает имя повторяющейся задачи. |
| [set_Duration](./set_duration/) | Устанавливает продолжительность одного появления повторяющейся задачи. |
| [set_IgnoreResourceCalendar](./set_ignoreresourcecalendar/) | Устанавливает значение, указывающее, следует ли планировать повторяющуюся задачу, даже если она не может быть выполнена, когда доступны ресурсы для её выполнения. |
| [set_RecurrencePattern](./set_recurrencepattern/) | Устанавливает шаблон повторения повторяющейся задачи. |
| [set_TaskName](./set_taskname/) | Устанавливает имя повторяющейся задачи. |
| [SetCalendar](./setcalendar/) | Установите календарь для повторяющейся задачи. Календарь выбирается из коллекции календарей проекта. |
