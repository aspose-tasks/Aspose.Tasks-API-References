## SetFontFolders {#setfontfolders}

Устанавливает папки, в которых Aspose.Tasks ищет TrueType‑шрифты при рендеринге представления проекта.

**Returns:** void Aspose::Tasks::

```cpp
SetFontFolders(const System::ArrayPtr< System::String > & fontFolders, bool recursive)
```

| Параметр | Описание |
| --- | --- |
| fontFolders | Массив папок, содержащих шрифты TrueType. |
| recursive | Если true, указанные папки будут сканироваться рекурсивно. |
