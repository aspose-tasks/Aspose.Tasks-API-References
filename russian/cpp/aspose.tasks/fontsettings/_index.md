## FontSettings class

Указывает настройки шрифта, используемые при рендеринге представления проекта.

## Методы

| Имя | Описание |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | Получает шрифт по умолчанию (или резервный) для рендеринга. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | Получает обратный вызов, который можно использовать для настройки разрешённых шрифтов. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | Получает значение, указывающее, должен ли использоваться шрифт по умолчанию для рендеринга. |
| [set_DefaultFontName](./set_defaultfontname/) | Устанавливает шрифт по умолчанию (или резервный) для рендеринга. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | Устанавливает обратный вызов, который можно использовать для настройки разрешённых шрифтов. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | Устанавливает значение, указывающее, следует ли использовать шрифт по умолчанию для рендеринга. |
| [SetFontFolders](./setfontfolders/) | Устанавливает папки, в которых Aspose.Tasks ищет TrueType‑шрифты при рендеринге представления проекта. |
