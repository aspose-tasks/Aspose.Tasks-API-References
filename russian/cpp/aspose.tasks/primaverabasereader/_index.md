## PrimaveraBaseReader class

Представляет базовый считыватель, который может использоваться для чтения UID проектов из многопроектных файлов Primavera XER или XML.

## Методы

| Имя | Описание |
| --- | --- |
| [GetProjectInfos](./getprojectinfos/) | Возвращает список объектов краткой информации проекта. |
| [GetProjectUids](./getprojectuids/) | Возвращает список уникальных идентификаторов проектов. |
| [LoadProject](./loadproject/) | Загружает проект с указанным уникальным идентификатором. |
