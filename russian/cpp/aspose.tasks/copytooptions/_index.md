## CopyToOptions class

Позволяет указать дополнительные параметры при копировании данных проекта.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [CopyToOptions](./copytooptions/) | Инициализирует новый экземпляр класса CopyToOptions. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_CopyViewData](./get_copyviewdata/) | Возвращает значение, указывающее, следует ли копировать данные представления при копировании данных проекта. Значение по умолчанию — true. |
| [set_CopyViewData](./set_copyviewdata/) | Устанавливает значение, указывающее, следует ли копировать данные представления при копировании данных проекта. Значение по умолчанию — true. |
