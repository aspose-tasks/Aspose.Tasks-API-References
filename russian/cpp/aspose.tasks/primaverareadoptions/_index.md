## PrimaveraReadOptions class

Позволяет указывать дополнительные параметры при чтении файлов Primavera Xml или Primavera Xer.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [PrimaveraReadOptions](./primaverareadoptions/) | Инициализирует новый экземпляр класса PrimaveraReadOptions. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_PreserveUids](./get_preserveuids/) | Получает флаг, указывающий, следует ли сохранять оригинальные уникальные идентификаторы сущностей. |
| [get_ProjectUid](./get_projectuid/) | Получает UID проекта для чтения из файла, содержащего несколько проектов. |
| [get_ReadBaselineProjects](./get_readbaselineprojects/) | Получает флаг, указывающий, следует ли загружать базовые проекты. Значение по умолчанию — true. |
| [get_UndefinedConstraintHandlingBehavior](./get_undefinedconstrainthandlingbehavior/) | Указывает поведение, используемое для обработки задач с неопределёнными ограничениями, прочитанных из формата XER. |
| [set_PreserveUids](./set_preserveuids/) | Устанавливает флаг, указывающий, следует ли сохранять оригинальные уникальные идентификаторы сущностей. |
| [set_ProjectUid](./set_projectuid/) | Устанавливает UID проекта для чтения из файла, содержащего несколько проектов. |
| [set_ReadBaselineProjects](./set_readbaselineprojects/) | Устанавливает флаг, указывающий, следует ли загружать базовые проекты. Значение по умолчанию — true. |
| [set_UndefinedConstraintHandlingBehavior](./set_undefinedconstrainthandlingbehavior/) | Указывает поведение, используемое для обработки задач с неопределёнными ограничениями, прочитанных из формата XER. |
