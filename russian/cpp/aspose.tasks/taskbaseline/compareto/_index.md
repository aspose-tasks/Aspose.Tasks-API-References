## CompareTo {#compareto}

Реализация интерфейса IComparable. Сравнивает этот экземпляр с указанным объектом Baseline.

**Returns:** returns -1 if this instance is less than the specified object, 1 if this instance is greater than the specified object; otherwise returns 0

```cpp
CompareTo(System::SharedPtr< TaskBaseline > other)
```

| Параметр | Описание |
| --- | --- |
| другой | указанный объект Baseline, с которым сравнивается данный экземпляр. |
