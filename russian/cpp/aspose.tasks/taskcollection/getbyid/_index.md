## GetById {#getbyid}

Возвращает задачу с указанным Id, чей предок является родительской задачей этой коллекции.

**Returns:** returns the instance of Task class with the specified id whose ancestor is parent task of this collection.

```cpp
GetById(int32_t id)
```

| Параметр | Описание |
| --- | --- |
| id | TaskEntity Id |
