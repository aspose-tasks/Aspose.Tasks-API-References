## GetByUid {#getbyuid}

Возвращает задачу с указанным Uid, чей предок является родительской задачей этой коллекции.

**Returns:** returns the instance of Task class with the specified uid whose ancestor is parent task of this collection.

```cpp
GetByUid(int32_t uid)
```

| Параметр | Описание |
| --- | --- |
| uid | TaskEntity Uid. |
