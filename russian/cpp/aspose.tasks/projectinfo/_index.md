## ProjectInfo class

Краткая информация о опубликованном проекте, доступном в Project Online.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [ProjectInfo](./projectinfo/) | Инициализирует новый экземпляр класса ProjectInfo. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_CreatedDate](./get_createddate/) | Возвращает дату и время создания проекта. |
| [get_Description](./get_description/) | Возвращает описание проекта. |
| [get_Id](./get_id/) | Возвращает уникальный идентификатор проекта. |
| [get_IsCheckedOut](./get_ischeckedout/) | Возвращает значение, указывающее, проверен ли проект. |
| [get_LastPublishedDate](./get_lastpublisheddate/) | Возвращает самую последнюю дату публикации проекта. |
| [get_LastSavedDate](./get_lastsaveddate/) | Возвращает самую последнюю дату сохранения проекта. |
| [get_Name](./get_name/) | Возвращает имя проекта. |
