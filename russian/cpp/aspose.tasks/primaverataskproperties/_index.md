## PrimaveraTaskProperties class

Представляет специфические для Primavera свойства задачи, прочитанные из файлов Primavera (XER или P6XML).

## Методы

| Имя | Описание |
| --- | --- |
| [get_ActivityId](./get_activityid/) | Получает поле идентификатора активности — уникальный идентификатор задачи, используемый в Primavera. |
| [get_ActivityType](./get_activitytype/) | Получает значение поля «Activity Type». |
| [get_ActualExpenseCost](./get_actualexpensecost/) | Получает значение фактической стоимости расходов. |
| [get_ActualLaborCost](./get_actuallaborcost/) | Получает значение фактической стоимости труда. |
| [get_ActualLaborUnits](./get_actuallaborunits/) | Получает значение фактических единиц труда. |
| [get_ActualMaterialCost](./get_actualmaterialcost/) | Получает значение фактической стоимости материалов. |
| [get_ActualNonlaborCost](./get_actualnonlaborcost/) | Получает значение фактической стоимости без труда. |
| [get_ActualNonLaborUnits](./get_actualnonlaborunits/) | Получает значение фактических единиц без труда. |
| [get_ActualTotalCost](./get_actualtotalcost/) | Получает общую стоимость фактических расходов. |
| [get_BudgetedExpenseCost](./get_budgetedexpensecost/) | Получает значение запланированных (или плановых) расходов. |
| [get_BudgetedLaborCost](./get_budgetedlaborcost/) | Получает значение запланированных (или плановых) затрат на труд. |
| [get_BudgetedMaterialCost](./get_budgetedmaterialcost/) | Получает значение запланированных (или плановых) затрат на материалы. |
| [get_BudgetedNonlaborCost](./get_budgetednonlaborcost/) | Получает значение запланированных (или плановых) затрат без труда. |
| [get_BudgetedTotalCost](./get_budgetedtotalcost/) | Получает общую стоимость запланированных (или плановых) расходов. |
| [get_DurationPercentComplete](./get_durationpercentcomplete/) | Получает значение процента завершения длительности. |
| [get_DurationType](./get_durationtype/) | Получает значение поля ' Duration Type' активности. |
| [get_PercentCompleteType](./get_percentcompletetype/) | Получает значение поля '% Complete Type' активности. |
| [get_PhysicalPercentComplete](./get_physicalpercentcomplete/) | Получает значение физического процента завершения. |
| [get_PrimaryConstraintDate](./get_primaryconstraintdate/) | Получает дату первичного ограничения. |
| [get_PrimaryConstraintType](./get_primaryconstrainttype/) | Получает тип первичного ограничения. |
| [get_RawActivityType](./get_rawactivitytype/) | Получает необработанное текстовое представление (как в исходном файле) поля 'Activity Type' активности. |
| [get_RawCompletePercentType](./get_rawcompletepercenttype/) | Получает необработанное текстовое представление (как в исходном файле) поля '% Complete Type' активности. |
| [get_RawDurationType](./get_rawdurationtype/) | Получает необработанное текстовое представление (как в исходном файле) поля ' Duration Type' активности. |
| [get_RawStatus](./get_rawstatus/) | Получает необработанное текстовое представление (как в исходном файле) поля 'Status' активности. |
| [get_RemainingEarlyFinish](./get_remainingearlyfinish/) | Получает оставшуюся раннюю дату завершения — дату, когда оставшаяся работа по активности запланирована к завершению. |
| [get_RemainingEarlyStart](./get_remainingearlystart/) | Получает оставшуюся раннюю дату начала — дату, когда оставшаяся работа по активности запланирована к началу. |
| [get_RemainingExpenseCost](./get_remainingexpensecost/) | Получает значение оставшихся расходов. |
| [get_RemainingLaborUnits](./get_remaininglaborunits/) | Получает значение оставшихся единиц труда. |
| [get_RemainingLateFinish](./get_remaininglatefinish/) | Получает оставшуюся позднюю дату завершения. |
| [get_RemainingLateStart](./get_remaininglatestart/) | Получает оставшуюся дату позднего начала. |
| [get_RemainingNonLaborUnits](./get_remainingnonlaborunits/) | Получает значение оставшихся единиц, не связанных с трудом. |
| [get_SecondaryConstraintDate](./get_secondaryconstraintdate/) | Получает дату вторичного ограничения. |
| [get_SecondaryConstraintType](./get_secondaryconstrainttype/) | Получает тип вторичного ограничения. |
| [get_SequenceNumber](./get_sequencenumber/) | Получает порядковый номер элемента WBS (сводные задачи). Он используется для сортировки сводных задач в Primavera. |
| [get_UnitsPercentComplete](./get_unitspercentcomplete/) | Получает значение процента завершения единиц. |
