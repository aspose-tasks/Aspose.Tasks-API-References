## FontResolveEventArgs class

Предоставляет аргументы для обратного вызова, который вызывается при разрешении шрифта.

## Методы

| Имя | Описание |
| --- | --- |
| [get_RequestedFontName](./get_requestedfontname/) | Получает имя запрошенного шрифта. |
| [get_ResolvedFontName](./get_resolvedfontname/) | Получает имя разрешённого шрифта. Может быть установлен для управления шрифтами, используемыми при отрисовке представления. |
| [set_ResolvedFontName](./set_resolvedfontname/) | Устанавливает имя разрешённого шрифта. Может быть установлен для управления шрифтами, используемыми при отрисовке представления. |
