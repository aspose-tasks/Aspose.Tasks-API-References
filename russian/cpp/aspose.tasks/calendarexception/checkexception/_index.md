## CheckException {#checkexception}

Возвращает true, если указанный экземпляр структуры DateTime является исключительным днём.

**Returns:** Returns true if DateTime value is the exception day; otherwise, false.

```cpp
CheckException(System::DateTime dt)
```

| Параметр | Описание |
| --- | --- |
| dt | указанный экземпляр структуры DateTime. |
