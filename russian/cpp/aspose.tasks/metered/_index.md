## Metered class

Предоставляет методы установки измеряемого ключа.

В этом примере будет предпринята попытка установить измеряемый публичный и приватный ключ <ms>

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> файл jar компонента:

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>

## Методы

| Имя | Описание |
| --- | --- |
| [GetConsumptionCredit](./getconsumptioncredit/) | Получает кредит потребления. |
| [GetConsumptionQuantity](./getconsumptionquantity/) | Получает размер файла потребления. |
| [IsLicensed](./islicensed/) | Проверяет, успешно ли продукт лицензирован с помощью лицензии Metered. |
| [ResetMeteredKey](./resetmeteredkey/) | Удаляет ранее настроенную лицензию. |
| [SetMeteredKey](./setmeteredkey/) | Устанавливает публичные и приватные ключи Metered. |
