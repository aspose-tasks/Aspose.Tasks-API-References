## LoadOptions class

Позволяет указать дополнительные параметры загрузки при загрузке проекта из файла или потока.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [LoadOptions](./loadoptions/) | Инициализирует новый экземпляр класса LoadOptions. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_Encoding](./get_encoding/) | Получает кодировку, используемую для чтения проекта из форматов HTML, MPX, XER и Primavera XML. Кодировка по умолчанию — UTF8. |
| [get_ErrorHandler](./get_errorhandler/) | Получает метод обратного вызова для обработки ошибок разбора XML. |
| [get_Password](./get_password/) | Получает пароль защиты. |
| [get_PrimaveraReadOptions](./get_primaverareadoptions/) | Получает указанный экземпляр класса Tasks::PrimaveraReadOptions, который можно использовать для настройки поведения загрузки форматов Primavera (Primavera P6 XER или Primavera P6 Xml). |
| [set_Encoding](./set_encoding/) | Устанавливает кодировку, используемую для чтения проекта из форматов HTML, MPX, XER и Primavera XML. Кодировка по умолчанию — UTF8. |
| [set_ErrorHandler](./set_errorhandler/) | Устанавливает метод обратного вызова для обработки ошибок разбора XML. |
| [set_Password](./set_password/) | Устанавливает пароль защиты. |
| [set_PrimaveraReadOptions](./set_primaverareadoptions/) | Устанавливает указанный экземпляр класса Tasks::PrimaveraReadOptions, который можно использовать для настройки поведения загрузки форматов Primavera (Primavera P6 XER или Primavera P6 Xml). |
