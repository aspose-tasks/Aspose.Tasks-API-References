## Value class

Представляет значение в списке значений.

## Конструкторы

| Имя | Описание |
| --- | --- |
| [Value](./value/) | Инициализирует новый экземпляр класса Value. |

## Методы

| Имя | Описание |
| --- | --- |
| [get_DateTimeValue](./get_datetimevalue/) | Возвращает фактическое значение, если оно может быть представлено как DateTime. Значение по умолчанию — DateTime::MinValue. |
| [get_Description](./get_description/) | Возвращает описание значения. |
| [get_Duration](./get_duration/) | Возвращает фактическое значение, используемое для представления Duration. |
| [get_Id](./get_id/) | Возвращает уникальный идентификатор значения в рамках проекта. |
| [get_NumericValue](./get_numericvalue/) | Возвращает фактическое значение, используемое для представления числового или стоимостного значения. |
| [get_Phonetic](./get_phonetic/) | Возвращает фонетическую информацию о названии пользовательского поля. |
| [get_StringValue](./get_stringvalue/) | Возвращает фактическое значение, используемое для представления строкового текста. |
| [get_Val](./get_val/) | Возвращает фактическое значение во внутреннем представлении. Предпочтительно использовать строго типизированные свойства, перечисленные ниже. |
| [get_ValueGuid](./get_valueguid/) | Возвращает GUID, который идентифицирует это значение среди остальных во всём проекте. |
| [set_DateTimeValue](./set_datetimevalue/) | Устанавливает фактическое значение, если оно может быть представлено как DateTime. Значение по умолчанию — DateTime::MinValue. |
| [set_Description](./set_description/) | Устанавливает описание значения. |
| [set_Duration](./set_duration/) | Устанавливает фактическое значение, используемое для представления Duration. |
| [set_Id](./set_id/) | Устанавливает уникальный идентификатор значения в рамках проекта. |
| [set_NumericValue](./set_numericvalue/) | Устанавливает фактическое значение, используемое для представления числового или стоимостного значения. |
| [set_Phonetic](./set_phonetic/) | Устанавливает фонетическую информацию о названии пользовательского поля. |
| [set_StringValue](./set_stringvalue/) | Устанавливает фактическое значение, используемое для представления строкового текста. |
