## GetByName {#getbyname}

Ищет View с указанным именем и возвращает первое вхождение в коллекцию.

**Returns:** The first View in collection with the specified name, if found; otherwise, null.

```cpp
GetByName(const System::String & viewName)
```

| Параметр | Описание |
| --- | --- |
| viewName | Имя представления для поиска. |
