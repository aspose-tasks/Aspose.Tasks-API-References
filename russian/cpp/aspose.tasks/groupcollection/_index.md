## GroupCollection class

Содержит список объектов Group. Реализует интерфейс ICollection< Group >.

## Методы

| Имя | Описание |
| --- | --- |
| [Add](./add/) | Добавляет указанный элемент в эту коллекцию. |
| [Clear](./clear/) | Удаляет все элементы из этой коллекции. |
| [Contains](./contains/) | Возвращает true, если указанный элемент найден в этой коллекции; в противном случае — false. |
| [CopyTo](./copyto/) | Копирует элементы этой коллекции в указанный массив, начиная с указанного индекса массива. |
| [get_Count](./get_count/) | Получает количество элементов, содержащихся в этой коллекции. |
| [get_IsReadOnly](./get_isreadonly/) | Получает значение, указывающее, является ли эта коллекция только для чтения. |
| [GetEnumerator](./getenumerator/) | Возвращает перечислитель для этой коллекции. |
| [Remove](./remove/) | Удаляет первое вхождение конкретного объекта из этой коллекции. |
| [ToList](./tolist/) | Преобразует коллекцию групп в список объектов Group. |
