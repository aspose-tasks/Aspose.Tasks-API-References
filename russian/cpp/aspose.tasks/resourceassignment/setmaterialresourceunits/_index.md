## SetMaterialResourceUnits {#setmaterialresourceunits}

Устанавливает единицы измерения для назначения материального ресурса с переменным потреблением материалов. Переменное потребление материалов означает, что при изменении длительности назначения количество используемых материалов меняется пропорционально.

**Returns:** void Aspose::Tasks::

```cpp
SetMaterialResourceUnits(double units, RateScaleType rateScaleType)
```

| Параметр | Описание |
| --- | --- |
| единицы | Количество единиц, накопленных за период времени. |
| rateScaleType | Период времени, за который начисляется значение единицы. |
