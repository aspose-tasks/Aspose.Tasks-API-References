## CreateDefaultWorkingDay {#createdefaultworkingday}

Создаёт рабочий день по умолчанию.

**Returns:** A default working day with working times 8-12 and 13-17.

```cpp
CreateDefaultWorkingDay(Aspose::Tasks::DayType dayType)
```

| Параметр | Описание |
| --- | --- |
| dayType | Тип дня, из которого создаётся рабочий день по умолчанию. |
