## ResourceSavingArgs class

Этот класс представляет набор данных, связанных с сохранением внешнего файлового ресурса, происходящим при конвертации в формат HTML.

## Методы

| Имя | Описание |
| --- | --- |
| [CloseStreamIfRequired](./closestreamifrequired/) | Закрыть поток, если KeepStreamOpen равно false, иначе выполнить его сброс. |
| [get_FileName](./get_filename/) | Получает предполагаемое имя файла, которое передаётся из конвертера в код пользовательского метода. Может использоваться в пользовательском коде для решения, как обрабатывать или где сохранять этот файл. |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Получает значение, указывающее, будет ли поток оставаться открытым после завершения сохранения ресурса. |
| [get_Stream](./get_stream/) | Получает двоичное содержимое сохранённого файла. |
| [get_Uri](./get_uri/) | Получает URI ресурса. |
| [set_FileName](./set_filename/) | Устанавливает предполагаемое имя файла, которое передаётся из конвертера в код пользовательского метода. Может использоваться в пользовательском коде для решения, как обрабатывать или где сохранять этот файл. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Устанавливает значение, указывающее, будет ли поток оставаться открытым после завершения сохранения ресурса. |
| [set_Stream](./set_stream/) | Устанавливает двоичное содержимое сохранённого файла. |
| [set_Uri](./set_uri/) | Устанавливает URI ресурса. |
