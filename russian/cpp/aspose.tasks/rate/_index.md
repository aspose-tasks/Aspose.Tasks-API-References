## Rate class

Представляет определение временного периода и тарифов, применимых к ресурсу в течение этого периода.

## Методы

| Имя | Описание |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Получает стоимость за использование ресурса. Это значение извлекается из текущей даты, если для ресурса существует таблица ставок. |
| [get_OvertimeRate](./get_overtimerate/) | Получает ставку сверхурочных за час для ресурса. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Получает единицы измерения, используемые Microsoft Project для отображения ставки сверхурочных. |
| [get_RatesFrom](./get_ratesfrom/) | Получает дату, с которой ставка вступает в силу. |
| [get_RatesTo](./get_ratesto/) | Получает последнюю дату, когда ставка действует. |
| [get_RateTable](./get_ratetable/) | Получает уникальный идентификатор таблицы ставок для ресурса. |
| [get_StandardRate](./get_standardrate/) | Получает стандартную ставку за час для ресурса. |
| [get_StandardRateFormat](./get_standardrateformat/) | Получает единицы измерения, используемые Microsoft Project для отображения стандартной ставки. |
| [set_CostPerUse](./set_costperuse/) | Устанавливает стоимость за использование ресурса. Это значение извлекается из текущей даты, если для ресурса существует таблица ставок. |
| [set_OvertimeRate](./set_overtimerate/) | Устанавливает ставку сверхурочных за час для ресурса. |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Устанавливает единицы измерения, используемые Microsoft Project для отображения ставки сверхурочных. |
| [set_RatesFrom](./set_ratesfrom/) | Устанавливает дату, с которой ставка вступает в силу. |
| [set_RatesTo](./set_ratesto/) | Устанавливает последнюю дату, когда ставка действует. |
| [set_RateTable](./set_ratetable/) | Устанавливает уникальный идентификатор таблицы ставок для ресурса. |
