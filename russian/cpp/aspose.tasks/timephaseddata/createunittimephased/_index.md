## CreateUnitTimephased {#createunittimephased}

Создаёт и инициализирует новый экземпляр класса Aspose::Tasks::TimephasedData для данных, фазированных по единицам, назначения материального ресурса.

**Returns:** A instance of the Aspose::Tasks::TimephasedData class for cost-based time phased data.

```cpp
CreateUnitTimephased(int32_t uid, System::DateTime start, System::DateTime finish, double units, Aspose::Tasks::TimephasedDataType type)
```

| Параметр | Описание |
| --- | --- |
| uid | UID задачи. |
| начало | Начальная дата и время. |
| конец | дата и время завершения. |
| единицы | Количество единиц. |
| type | Тип данных с фазированием во времени. |
