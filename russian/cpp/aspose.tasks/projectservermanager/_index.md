## ProjectServerManager class

Класс, который предоставляет методы для чтения и выполнения операций над проектами в указанном аккаунте Project Online или в указанном локальном экземпляре Project Server (поддерживаются версии Project Server 2016 и 2019).

## Конструкторы

| Имя | Описание |
| --- | --- |
| [ProjectServerManager](./projectservermanager/) | Инициализирует новый экземпляр класса ProjectServerManager. |

## Методы

| Имя | Описание |
| --- | --- |
| [CreateNewProject (2 overloads)](./createnewproject/) | Создаёт новый проект в экземпляре Project Server\Project Online, используя параметры сохранения по умолчанию. |
| [GetProject](./getproject/) | Получает проект с указанным guid из аккаунта Project Online \ экземпляра Project Server. |
| [GetProjectList](./getprojectlist/) | Получает список проектов из хранилища 'Working' текущего аккаунта Project Online \ экземпляра Project Server. |
| [GetProjectRawData](./getprojectrawdata/) | Получает двоичные данные проекта для целей устранения неполадок. |
| [UpdateProject (2 overloads)](./updateproject/) | Обновляет существующий проект в экземпляре Project Server\Project Online, используя параметры сохранения по умолчанию. Существующий проект будет перезаписан. |
| [ExecutingWebRequest](./executingwebrequest/) | Событие, которое вызывается, когда веб‑запрос отправляется в веб‑API Project Server. |
