## CheckPropAndSet {#checkpropandset}

Отображает указанное свойство на указанное значение в этом контейнере. Если этот контейнер не содержит запись ProjectItem, она будет добавлена.

```cpp
CheckPropAndSet(const Key < TValue, T > & key, const TValue & val)
```

| Параметр | Описание |
| --- | --- |
| ключ | указанное свойство. |
| val | значение. |
