## PropertyContainer< T > class

Представляет контейнер свойств.

## Методы

| Имя | Описание |
| --- | --- |
| [CheckPropAndGet](./checkpropandget/) | Возвращает значение, к которому свойство сопоставлено в этом контейнере. Если этот контейнер не содержит запись ProjectItem, она будет добавлена со значением по умолчанию, и будет возвращено значение по умолчанию. |
| [CheckPropAndSet](./checkpropandset/) | Отображает указанное свойство на указанное значение в этом контейнере. Если этот контейнер не содержит запись ProjectItem, она будет добавлена. |
