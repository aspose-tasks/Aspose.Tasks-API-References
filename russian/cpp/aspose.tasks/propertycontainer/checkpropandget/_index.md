## CheckPropAndGet {#checkpropandget}

Возвращает значение, к которому свойство сопоставлено в этом контейнере. Если этот контейнер не содержит запись ProjectItem, она будет добавлена со значением по умолчанию, и будет возвращено значение по умолчанию.

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| Параметр | Описание |
| --- | --- |
| ключ | указанное свойство. |
