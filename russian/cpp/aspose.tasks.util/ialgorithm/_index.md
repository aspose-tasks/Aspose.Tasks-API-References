## IAlgorithm< T > class

Представляет алгоритм, который может быть применён к списку объектов T .

## Методы

| Имя | Описание |
| --- | --- |
| [Alg](./alg/) | Обрабатывает объект в списке. Вызывается после IAlgorithm<T>::PreAlg ; |
| [PostAlg](./postalg/) | Вызывается после обработки объекта. |
| [PreAlg](./prealg/) | Вызывается перед обработкой объекта. |
