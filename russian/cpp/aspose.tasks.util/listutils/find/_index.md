## Find {#find}

Находит первое вхождение элемента списка, который удовлетворяет указанному условию.

**Returns:** List element or null.

```cpp
Find(const System::SharedPtr< System::Collections::Generic::IList< T >> & list, const System::SharedPtr< ICondition < T >> & cond)
```

| Параметр | Описание |
| --- | --- |
| список | Список для обработки. |
| cond | Условие, используемое для поиска элемента в указанном списке. |
