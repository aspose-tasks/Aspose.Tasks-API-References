## ListUtils class

Утилитный класс для обработки списков.

## Методы

| Имя | Описание |
| --- | --- |
| [Apply](./apply/) | Применяет алгоритм к каждому элементу списка, начиная с указанной позиции. |
| [Filter](./filter/) | Фильтрует элементы списка по указанному условию. |
| [Find](./find/) | Находит первое вхождение элемента списка, который удовлетворяет указанному условию. |
