## GetDefaultTaskFieldTitle {#getdefaulttaskfieldtitle}

Возвращает заголовок по умолчанию для конкретного поля задачи.

**Returns:** A default title of the specific task field if the field can be displayed in MS Project 's view, null otherwise.

```cpp
GetDefaultTaskFieldTitle(TaskKey taskKey)
```

| Параметр | Описание |
| --- | --- |
| taskKey | Поле задачи для получения стандартного заголовка. |
