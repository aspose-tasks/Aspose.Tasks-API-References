## TaskUtils class

Вспомогательный класс, предоставляющий полезные операции с задачами.

## Методы

| Имя | Описание |
| --- | --- |
| [Apply](./apply/) | Применяет указанный алгоритм к каждой задаче дерева. |
| [Filter](./filter/) | Создаёт новое дерево задач, удовлетворяющих условию. |
| [Find](./find/) | Находит задачу, удовлетворяющую условию, в дереве задач. |
| [TaskChildrenCount](./taskchildrencount/) | Рекурсивно вычисляет количество дочерних задач задачи на всех уровнях. |
