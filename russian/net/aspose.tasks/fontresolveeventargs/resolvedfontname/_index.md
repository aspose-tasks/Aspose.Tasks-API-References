## FontResolveEventArgs.ResolvedFontName property

Возвращает или задает имя разрешённого шрифта. Может быть установлен для управления шрифтами, используемыми при рендеринге представления.

```csharp
public string ResolvedFontName { get; set; }
```

### Возвращаемое значение

Имя запрошенного шрифта, если шрифт найден, или имя резервного шрифта, либо null, если шрифт не найден.
