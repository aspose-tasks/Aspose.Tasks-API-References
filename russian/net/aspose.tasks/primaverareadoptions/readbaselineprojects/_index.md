## PrimaveraReadOptions.ReadBaselineProjects property

Получает или задает флаг, указывающий, следует ли загружать базовые проекты. Значение по умолчанию — true.

```csharp
public bool ReadBaselineProjects { get; set; }
```

## Примечания

Этот флаг применяется к файлам Primavera XML, содержащим базовые проекты (базовые проекты не поддерживаются форматом XER). Параметр можно установить в false, чтобы ускорить загрузку большого проекта с базовыми проектами, когда данные базовых проектов не нужны.
