## CostAccrualType enumeration

Указывает тип начисляемой стоимости.

```csharp
public enum CostAccrualType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Undefined | `-1` | Указывает, что неопределённое значение означает, что поле не было определено в оригинальном файле проекта. |
| Start | `0` | Указывает тип начисления стоимости в начале. |
| Prorated | `1` | Указывает тип пропорционального начисления стоимости. |
| End | `2` | Указывает тип начисления стоимости в конце. |
| Invalid | `3` | Указывает недопустимый тип начисления стоимости. |

## Примечания

При экспорте в XML неопределённые значения будут удалены из результирующего XML.

## Примеры

Показывает, как и когда стандартные и сверхурочные затраты ресурса должны быть начислены или учтены (метод начисления: определяет, когда затраты на ресурс возникают и когда фактические затраты списываются на проект. Вы можете начислять затраты в начале [Start] или в конце [End] задачи или распределять их пропорционально [Prorated] в течение задачи.), к стоимости задачи (CostAccrualType.End).

```csharp
var project = new Project(DataDir + "Project2.mpp");
var resource = project.Resources.GetById(1);
// установить тип начисления стоимости
// если вы выберете опцию End, затраты не начисляются, пока оставшаяся работа не станет нулевой.
resource.Set(Rsc.AccrueAt, CostAccrualType.End);
// работать с проектом...
```
