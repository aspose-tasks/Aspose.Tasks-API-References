## TimescaleTier.RenderLabelOnEachPage property

Получает или задает флаг, определяющий, следует ли отображать метки даты на каждой странице, когда временной период охватывает несколько страниц. Если значение 'true', при охвате нескольких страниц метки даты для периода отображаются на каждой странице. Если значение 'false', метка даты отображается только один раз в соответствии со значением свойства [`Alignment`](../alignment/).

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
