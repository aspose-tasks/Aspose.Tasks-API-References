## ReportType enumeration

Тип графического отчёта проекта.

```csharp
public enum ReportType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ProjectOverview | `0` | Отображает дату начала и завершения проекта, процент завершённой продолжительности, процент выполнения для задач верхнего уровня и предстоящих контрольных точек. |
| CostOverview | `1` | Отображает даты начала и завершения проекта, текущие запланированные и оставшиеся затраты, % выполнения и значения затрат для задач верхнего уровня. |
| WorkOverview | `2` | Отображает базовый, фактический и оставшийся объём работы для каждой задачи верхнего уровня и работу ресурсов. |
| ResourceOverview | `3` | Отображает базовый, фактический и оставшийся объём работы по ресурсам. |
| ResourceCostOverview | `4` | Отображает базовые, фактические и оставшиеся затраты по ресурсам. |
| CriticalTasks | `5` | Отображает задачи проекта, которые являются критическими. |
| LateTasks | `6` | Отображает задачи проекта, которые отстают. |
| Milestones | `7` | Отображает контрольные точки, которые отстают, предстоящие и завершённые. |
| UpcomingTask | `8` | Отображает задачи, срок выполнения которых наступает в текущей неделе, и задачи, начинающиеся в текущей неделе. |
| CostOverruns | `9` | Отображает отклонения затрат по задачам и ресурсам. |
| TaskCostOverview | `10` | Отображает базовые, фактические и оставшиеся затраты всех задач верхнего уровня. |
| OverallocatedResources | `11` | Отображает количество оставшихся рабочих часов для переизбыточно распределённых ресурсов. |
| SlippingTasks | `12` | Отображает задачи, которые должны завершиться после их базовых дат завершения (база должна быть установлена). |
| BestPracticeAnalyzer | `13` | Отображает задачи без фактической работы, не назначенные задачи, задачи с продолжительностью менее 8 часов и сводки, назначенные ресурсам. |
| Burndown | `14` | Включает графики снижения объёма работы и снижения количества задач. График снижения объёма работы показывает, сколько работы люди завершили, сколько запланировано завершить до даты завершения проекта, а также базовую оценку того, сколько работы будет выполнено к этому моменту проекта. График снижения количества задач показывает количество завершённых задач, количество оставшихся и базовую оценку того, сколько задач будет завершено к этому моменту проекта. |
| CashFlow | `15` | Отображает затраты и накопительные затраты за квартал для всех задач верхнего уровня. |

## Примеры

Показывает, как сохранить отчёт о сгорании проекта в формате PDF в указанный поток.

```csharp
var project = new Project(DataDir + @"Homemoveplan.mpp");
using (var stream = new FileStream(OutDir + "Burndown_out.pdf", FileMode.Create))
{
    project.SaveReport(stream, ReportType.Burndown);
}
```
