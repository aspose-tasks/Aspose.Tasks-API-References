## LevelingOptions.LevelingOrder property

Получает порядок, в котором алгоритм уравнивания откладывает задачи с переизбытком ресурсов. После определения задач, вызывающих переизбыток, и задач, которые можно отложить, используется указанный порядок, определяющий, какая задача должна быть отложена первой.

```csharp
public LevelingOrder LevelingOrder { get; set; }
```
