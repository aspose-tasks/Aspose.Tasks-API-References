Содержит классы для создания отчёта по анализу рисков.

## Классы

| Класс | Описание |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | Представляет результат анализа рисков. |
| [RiskAnalysisSettings](./riskanalysissettings/) | Указывает настройки для выполнения анализа рисков. |
| [RiskAnalyzer](./riskanalyzer/) | Выполняет моделирование Монте‑Карло на основе указанных настроек анализа рисков. |
| [RiskItemStatistics](./riskitemstatistics/) | Представляет элемент, который хранит статистические данные для задачи анализируемого проекта. |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | Представляет коллекцию, содержащую экземпляры класса [`RiskItemStatistics`](../aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](./riskpattern/) | Представляет шаблон риска для задачи проекта. |
| [RiskPatternCollection](./riskpatterncollection/) | Представляет коллекцию, содержащую экземпляры класса [`RiskPattern`](../aspose.tasks.riskanalysis/riskpattern/). |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [ConfidenceLevel](./confidencelevel/) | Указывает поддерживаемые уровни доверия, используемые в анализе рисков, которые соответствуют проценту времени, когда фактические значения находятся в пределах оптимистических и пессимистических оценок. |
| [ProbabilityDistributionType](./probabilitydistributiontype/) | Указывает типы поддерживаемых распределений вероятностей. |
| [RiskItemType](./riskitemtype/) | Указывает поля задач, для которых собирается статистическая информация во время анализа рисков. |
