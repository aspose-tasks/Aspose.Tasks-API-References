Содержит классы, необходимые для работы со специфическими форматами Primavera (XER, Primavera XML).

## Классы

| Класс | Описание |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Представляет краткую информацию о проекте, загруженном из формата Primavera. |
