## PrimaveraProjectInfo.ExportFlag property

Получает флаг экспорта проекта. Когда проект выбран для экспорта в Primavera, его ExportFlag имеет значение true. Некоторые проекты, не явно выбранные для экспорта, могут быть экспортированы в файл XER из‑за их связи с экспортируемым проектом.

```csharp
public bool ExportFlag { get; }
```
