## SaveOptions.FitTimescaleToEndOfPage property

Получает или задает, следует ли рендерить секцию календаря представления до конца (правой стороны) последней страницы. Если значение ложно, секция календаря рендерится точно до EndDate, даже если на странице остаётся пустое пространство.

```csharp
public bool FitTimescaleToEndOfPage { get; set; }
```
