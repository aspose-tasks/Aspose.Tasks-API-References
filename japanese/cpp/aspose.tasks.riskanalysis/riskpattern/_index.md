## RiskPattern class

プロジェクトタスクのリスクパターンを表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [RiskPattern](./riskpattern/) | RiskPattern クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_ConfidenceLevel](./get_confidencelevel/) | 実際に生成された値が楽観的および悲観的な見積もりの範囲内にある時間の割合に対応する信頼水準を取得します。デフォルト値は CL99 です。 |
| [get_Distribution](./get_distribution/) | Monte Carlo シミュレーションで使用される確率分布を取得します。デフォルト値は ProbabilityDistributionType.Normal です。 |
| [get_Optimistic](./get_optimistic/) | 最良のプロジェクトシナリオで発生し得る最も可能性の高いタスク期間の割合を取得します。デフォルト値は 75 で、これは、推定されたタスク期間が 4 日の場合、楽観的な期間は 3 日になることを意味します。 |
| [get_Pessimistic](./get_pessimistic/) | 最悪のプロジェクトシナリオで発生し得る最も可能性の高いタスク期間の割合を取得します。デフォルト値は 125 で、これは、推定されたタスク期間が 4 日の場合、悲観的な期間は 5 日になることを意味します。 |
| [get_Task](./get_task/) | このリスクパターンが適用されるプロジェクトタスクを取得します。 |
| [set_ConfidenceLevel](./set_confidencelevel/) | 実際に生成された値が楽観的および悲観的な見積もりの範囲内にある時間の割合に対応する信頼水準を設定します。デフォルト値は CL99 です。 |
| [set_Distribution](./set_distribution/) | Monte Carlo シミュレーションで使用される確率分布を設定します。デフォルト値は ProbabilityDistributionType.Normal です。 |
| [set_Optimistic](./set_optimistic/) | 最良のプロジェクトシナリオで発生し得る最も可能性の高いタスク期間の割合を設定します。デフォルト値は 75 で、これは、推定されたタスク期間が 4 日の場合、楽観的な期間は 3 日になることを意味します。 |
| [set_Pessimistic](./set_pessimistic/) | 最悪のプロジェクトシナリオで発生し得る最も可能性の高いタスク期間の割合を設定します。デフォルト値は 125 で、これは、推定されたタスク期間が 4 日の場合、悲観的な期間は 5 日になることを意味します。 |
