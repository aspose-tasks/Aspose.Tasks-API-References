## Analyze {#analyze}

指定されたプロジェクトのリスク分析を実行します。分析はモンテカルロシミュレーションに基づき、結果は RiskAnalysisResult クラスのインスタンスです。

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| パラメーター | 説明 |
| --- | --- |
| プロジェクト | 分析対象の Project クラスの指定されたインスタンス。 |
