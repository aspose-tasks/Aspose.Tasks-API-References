## Aspose::Tasks::RiskAnalysis namespace

Aspose::Tasks::RiskAnalysis 名前空間には、設定、パターン、統計コレクション、解析器自体を含む、リスクシミュレーションの構成、実行、結果取得に使用されるコア型が含まれています。これらのオブジェクトにより、開発者は不確実性をモデル化し、複数回のイテレーションを実行し、タスクの日付やプロジェクト全体の完了に対する影響を評価できます。


## クラス

| 名前 | 説明 |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | リスク分析の結果を表します。 |
| [RiskAnalysisSettings](./riskanalysissettings/) | リスク分析を実行するための設定を指定します。 |
| [RiskAnalyzer](./riskanalyzer/) | 指定されたリスク分析設定に基づいてモンテカルロシミュレーションを実行します。 |
| [RiskItemStatistics](./riskitemstatistics/) | 分析されたプロジェクトのタスクの統計データを格納する項目を表します。 |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | RiskItemStatistics クラスのインスタンスを含むコレクションを表します。 |
| [RiskPattern](./riskpattern/) | プロジェクトタスクのリスクパターンを表します。 |
| [RiskPatternCollection](./riskpatterncollection/) | RiskPattern クラスのインスタンスを含むコレクションを表します。 |
