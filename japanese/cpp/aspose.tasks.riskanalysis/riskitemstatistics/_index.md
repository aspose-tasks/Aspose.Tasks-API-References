## RiskItemStatistics class

分析対象プロジェクトのタスクに関する統計データを保存する項目を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | リスク項目の期待値を取得します。 |
| [get_ItemType](./get_itemtype/) | RiskItemType 列挙体のインスタンスを取得します。 |
| [get_Maximum](./get_maximum/) | Monte Carlo シミュレーション中に生成された最大値を取得します。 |
| [get_Minimum](./get_minimum/) | Monte Carlo シミュレーション中に生成された最小値を取得します。 |
| [get_StandardDeviation](./get_standarddeviation/) | リスク項目の標準偏差を取得します。 |
| [GetPercentile](./getpercentile/) | 生成されたサンプルの指定されたパーセンテージが下回る値を取得します。 |
| [ToString](./tostring/) | リスク項目の短い文字列表現を返します。表現の正確な詳細は未定義で、変更される可能性があります。 |
