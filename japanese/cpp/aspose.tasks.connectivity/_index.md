## Aspose::Tasks::Connectivity namespace

これらの型を使用して、Microsoft Project Server データベース (MspDbSettings)、Primavera データベース (PrimaveraDbSettings)、MPD ファイル (MpdSettings)、または汎用データベース ソース (DbSettings) への接続を構成します。名前空間は、Aspose.Tasks のデータ抽出および操作機能とのシームレスな統合のために、接続設定を集中管理します。


## クラス

| 名前 | 説明 |
| --- | --- |
| [DbSettings](./dbsettings/) | プロジェクトデータベースから読み取るための設定を指定できます。 |
| [MpdSettings](./mpdsettings/) | MPD 形式 (MS Access) からプロジェクトデータを読み取るために必要なオプションを設定できます。 |
| [MspDbSettings](./mspdbsettings/) | MS Project Server データからプロジェクトデータを読み取るために必要なオプションを設定できます。 |
| [PrimaveraDbSettings](./primaveradbsettings/) | Primavera データベースからプロジェクトデータを読み取るために必要なオプションを設定できます。 |
