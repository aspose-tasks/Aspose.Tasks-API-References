## DbSettings class

プロジェクトデータベースから読み取るための設定を指定できます。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_ConnectionString](./get_connectionstring/) | 接続文字列を取得します。 |
| [get_ProviderInvariantName](./get_providerinvariantname/) | System::Data::Common::DbProviderFactory クラスのインスタンスを取得するために使用されるプロバイダー不変名を取得します。 |
| [set_ConnectionString](./set_connectionstring/) | 接続文字列を設定します。 |
| [set_ProviderInvariantName](./set_providerinvariantname/) | System::Data::Common::DbProviderFactory クラスのインスタンスを取得するために使用されるプロバイダー不変名を設定します。 |
