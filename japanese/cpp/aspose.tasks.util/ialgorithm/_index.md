## IAlgorithm< T > class

オブジェクト T のリストに適用できるアルゴリズムを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Alg](./alg/) | リスト内のオブジェクトを処理します。IAlgorithm<T>::PreAlg の後に呼び出されます； |
| [PostAlg](./postalg/) | オブジェクトの処理後に呼び出されます。 |
| [PreAlg](./prealg/) | オブジェクトの処理前に呼び出されます。 |
