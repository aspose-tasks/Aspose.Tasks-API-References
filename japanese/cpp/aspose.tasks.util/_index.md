## Aspose::Tasks::Util namespace

この名前空間は Aspose.Tasks 全体で使用される汎用ユーティリティをまとめており、条件コンビネータ、ツリープロセッシングアルゴリズム、フィールドハンドリングヘルパーなどが含まれ、開発者がカスタムフィルターを作成し、タスク階層を評価し、処理ロジックを効率的に拡張できるようにします。


## クラス

| 名前 | 説明 |
| --- | --- |
| [And< T >](./and/) | 指定された条件に論理 AND を適用します。 |
| [AndAllCondition< T >](./andallcondition/) | すべての条件に論理 AND を適用します。例: cond1 AND cond2 AND cond3... |
| [CheckCircuit](./checkcircuit/) | タスクのツリーに回路が含まれているかチェックします。 |
| [ChildTasksCollector](./childtaskscollector/) | すべての子タスクを収集します。 |
| [FieldHelper](./fieldhelper/) | フィールドに対する便利な操作を提供するヘルパークラスです。 |
| [IAlgorithm< T >](./ialgorithm/) | オブジェクト T のリストに適用できるアルゴリズムを表します。 |
| [ICondition< T >](./icondition/) | フィルターや検索メソッドで使用できる条件を表します。 |
| [ITreeAlgorithm< T >](./itreealgorithm/) | オブジェクト T のツリーに適用できるアルゴリズムを表します。 |
| [ListUtils](./listutils/) | リスト処理用ユーティリティクラスです。 |
| [Not< T >](./not/) | 指定された条件に論理 NOT を適用します。 |
