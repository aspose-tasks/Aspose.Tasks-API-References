## TaskUtils class

タスクに対する便利な操作を提供するヘルパークラスです。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Apply](./apply/) | 指定されたアルゴリズムをツリーの各タスクに適用します。 |
| [Filter](./filter/) | 条件を満たすタスクの新しいツリーを構築します。 |
| [Find](./find/) | タスクのツリー内で条件を満たすタスクを検索します。 |
| [TaskChildrenCount](./taskchildrencount/) | すべてのレベルにわたってタスクの子タスク数を再帰的に計算します。 |
