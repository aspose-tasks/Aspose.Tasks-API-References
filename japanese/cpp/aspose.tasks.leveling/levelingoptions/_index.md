## LevelingOptions class

リソースレベリングのパラメータを指定できます。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | LevelingOptions クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_FinishDate](./get_finishdate/) | レベリング期間の終了日を取得します。既定値はプロジェクトの完了日です。 |
| [get_LevelingOrder](./get_levelingorder/) | レベリングアルゴリズムが過剰割り当てされたタスクを遅延させる順序を取得します。過剰割り当てを引き起こすタスクと遅延可能なタスクを特定した後、指定された順序が使用され、どのタスクを最初に遅延させるかが決まります。 |
| [get_MessageHandler](./get_messagehandler/) | リソースレベリング中に Aspose.Tasks が生成するログメッセージをインターセプトできるメッセージハンドラコールバックを取得します。 |
| [get_MessageLevel](./get_messagelevel/) | リソースレベリング中に Aspose.Tasks が出力するログメッセージのレベルを取得します。 |
| [get_Resources](./get_resources/) | レベリング対象となるリソースの一覧を取得します。null が設定された場合、すべてのプロジェクトリソースがレベリングされます。 |
| [get_StartDate](./get_startdate/) | レベリング期間の開始日を取得します。既定値はプロジェクトの開始日です。 |
| [set_FinishDate](./set_finishdate/) | レベリング期間の終了日を設定します。既定値はプロジェクトの完了日です。 |
| [set_LevelingOrder](./set_levelingorder/) | レベリングアルゴリズムが過剰割り当てされたタスクを遅延させる順序を取得します。過剰割り当てを引き起こすタスクと遅延可能なタスクを特定した後、指定された順序が使用され、どのタスクを最初に遅延させるかが決まります。 |
| [set_MessageHandler](./set_messagehandler/) | リソースレベリング中に Aspose.Tasks が生成するログメッセージをインターセプトできるメッセージハンドラコールバックを設定します。 |
| [set_MessageLevel](./set_messagelevel/) | リソースレベリング中に Aspose.Tasks が出力するログメッセージのレベルを設定します。 |
| [set_Resources](./set_resources/) | レベリング対象となるリソースの一覧を設定します。null が設定された場合、すべてのプロジェクトリソースがレベリングされます。 |
| [set_StartDate](./set_startdate/) | レベリング期間の開始日を設定します。既定値はプロジェクトの開始日です。 |
