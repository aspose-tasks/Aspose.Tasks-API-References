## Aspose::Tasks::Properties namespace

BuiltInProjectProperty、CustomProjectProperty などの型や、プロジェクトメタデータの取得、変更、列挙を可能にする汎用プロパティコレクションが含まれます。これらのクラスを使用して、開始日などの標準プロパティにアクセスしたり、拡張プロジェクト情報のためにカスタムのキー‑バリューペアを定義したりできます。


## クラス

| 名前 | 説明 |
| --- | --- |
| [BuiltInProjectProperty](./builtinprojectproperty/) | 組み込みプロパティを表します。 |
| [BuiltInProjectPropertyCollection](./builtinprojectpropertycollection/) | 組み込みプロジェクトプロパティのコレクションを表します。 |
| [CustomProjectProperty](./customprojectproperty/) | カスタムプロパティを表します。 |
| [CustomProjectPropertyCollection](./customprojectpropertycollection/) | カスタムプロジェクトプロパティのコレクションを表します。 |
| [GenericProperty< TKey >](./genericproperty/) | コンテナプロパティを表します。 |
| [Property](./property/) | プロパティの基底クラスを表します。 |
| [PropertyCollection< T >](./propertycollection/) | プロパティコレクションの基底クラスです。 |
| [PropertyKeyedCollection< T >](./propertykeyedcollection/) | プロパティコレクションの基底クラスです。 |
