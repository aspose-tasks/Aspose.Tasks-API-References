## PropertyKeyedCollection< T > class

プロパティコレクションの基底クラスです。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Add](./add/) | 新しいカスタム プロパティを作成します。 |
| [Contains](./contains/) | Aspose::Tasks::Properties::PropertyCollection<T> が指定された名前のプロパティを含むかどうかを判断します。 |
| [get_Count](./get_count/) | コレクション内のプロパティ数を取得します。 |
| [get_IsReadOnly](./get_isreadonly/) | このコレクションが読み取り専用であるかどうかを示す値を取得します。そうでなければ false です。 |
| [get_Names](./get_names/) | すべてのプロパティ名のコレクションを取得します。 |
| [idx_get](./idx_get/) | 指定されたキーに関連付けられたプロパティを取得します。 |
