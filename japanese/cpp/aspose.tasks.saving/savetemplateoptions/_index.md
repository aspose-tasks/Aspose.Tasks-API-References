## SaveTemplateOptions class

プロジェクトをテンプレートとして保存する際に、追加オプションを指定できます。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_RemoveActualValues](./get_removeactualvalues/) | プロジェクトテンプレートからすべての実際の値を削除すべきかどうかを示す値を取得します。 |
| [get_RemoveBaselineValues](./get_removebaselinevalues/) | プロジェクトテンプレートからすべてのベースライン値を削除すべきかどうかを示す値を取得します。 |
| [get_RemoveFixedCosts](./get_removefixedcosts/) | プロジェクトテンプレートからすべての固定費用を削除すべきかどうかを示す値を取得します。 |
| [get_RemoveResourceRates](./get_removeresourcerates/) | プロジェクトテンプレートからリソースレートを削除すべきかどうかを示す値を取得します。 |
| [set_RemoveActualValues](./set_removeactualvalues/) | プロジェクトテンプレートからすべての実際の値を削除すべきかどうかを示す値を設定します。 |
| [set_RemoveBaselineValues](./set_removebaselinevalues/) | プロジェクトテンプレートからすべてのベースライン値を削除すべきかどうかを示す値を設定します。 |
| [set_RemoveFixedCosts](./set_removefixedcosts/) | プロジェクトテンプレートからすべての固定費用を削除すべきかどうかを示す値を設定します。 |
| [set_RemoveResourceRates](./set_removeresourcerates/) | プロジェクトテンプレートからリソースレートを削除すべきかどうかを示す値を設定します。 |
