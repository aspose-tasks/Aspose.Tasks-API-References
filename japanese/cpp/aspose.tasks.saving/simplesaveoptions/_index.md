## SimpleSaveOptions class

これは抽象基底クラスで、ユーザーがプロジェクトを特定の形式で保存する際に基本的なオプションを指定できるようにします。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_SaveFormat](./get_saveformat/) | この保存オプション オブジェクトが使用された場合に、ドキュメントが保存される形式を取得します。 |
| [get_TasksComparer](./get_taskscomparer/) | ガント チャートとタスク シート チャートでタスクをソートするための比較子を取得します。 |
| [get_TasksFilter](./get_tasksfilter/) | ガント、タスク シート、タスク 使用状況チャートに描画されるタスクをフィルタリングするために使用される条件を取得します。 |
| [set_TasksComparer](./set_taskscomparer/) | ガント チャートとタスク シート チャートでタスクをソートする比較子を設定します。 |
| [set_TasksFilter](./set_tasksfilter/) | ガント、タスク シート、タスク 使用状況チャートに描画されるタスクをフィルタリングする条件を設定します。 |
