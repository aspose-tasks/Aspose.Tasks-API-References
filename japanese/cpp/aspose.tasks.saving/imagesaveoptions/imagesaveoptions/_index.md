## ImageSaveOptions {#imagesaveoptions}

ImageSaveOptions クラスの新しいインスタンスを初期化します。このインスタンスは、レンダリングされた画像を TIFF、PNG、BMP、または JPEG 形式で保存するために使用できます。

**Returns:** Aspose::Tasks::Saving::

```cpp
ImageSaveOptions(SaveFileFormat saveFormat)
```

| パラメーター | 説明 |
| --- | --- |
| saveFormat | TIFF、PNG、BMP、または JPEG の SaveFileFormat にできます。 |
