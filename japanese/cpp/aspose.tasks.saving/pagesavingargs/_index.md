## PageSavingArgs class

このクラスは、ドキュメントのページをストリームに保存することに関連するデータのセットを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_KeepStreamOpen](./get_keepstreamopen/) | ページが書き込まれた後、レンダリングルーチンがストリームを開いたままにすべきかどうかを示す値を取得します。 |
| [get_PageNumber](./get_pagenumber/) | 書き込まれるページ番号を取得します。 |
| [get_Stream](./get_stream/) | ページを書き込むためのストリームを取得します。 |
| [set_KeepStreamOpen](./set_keepstreamopen/) | ページが書き込まれた後、レンダリングルーチンがストリームを開いたままにすべきかどうかを示す値を設定します。 |
| [set_Stream](./set_stream/) | ページを書き込むためのストリームを設定します。 |
