## PageViewSettings class

プロジェクトビューの印刷設定を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_FirstColumnsCount](./get_firstcolumnscount/) | すべてのページに印刷される最初の列の数を取得します。 |
| [get_FitTimescaleToEndOfPage](./get_fittimescaletoendofpage/) | 印刷時にタイムスケールをページの末尾に合わせるかどうかを示す値を取得します。 |
| [get_PrintAllSheetColumns](./get_printallsheetcolumns/) | ビューのすべてのシート列を印刷するかどうかを示す値を取得します。 |
| [get_PrintBlankPages](./get_printblankpages/) | ビューの空白ページを印刷するかどうかを示す値を取得します。 |
| [get_PrintFirstColumnsCountOnAllPages](./get_printfirstcolumnscountonallpages/) | すべてのページに指定された数の最初の列を印刷するかどうかを示す値を取得します。 |
| [get_PrintNotes](./get_printnotes/) | ノートを印刷するかどうかを示す値を取得します。 |
| [set_FirstColumnsCount](./set_firstcolumnscount/) | すべてのページに印刷される最初の列の数を設定します。 |
| [set_FitTimescaleToEndOfPage](./set_fittimescaletoendofpage/) | 印刷時にタイムスケールをページの末尾に合わせるかどうかを示す値を設定します。 |
| [set_PrintAllSheetColumns](./set_printallsheetcolumns/) | ビューのすべてのシート列を印刷するかどうかを示す値を設定します。 |
| [set_PrintBlankPages](./set_printblankpages/) | ビューの空白ページを印刷するかどうかを示す値を設定します。 |
| [set_PrintFirstColumnsCountOnAllPages](./set_printfirstcolumnscountonallpages/) | すべてのページに指定された数の最初の列を印刷するかどうかを示す値を設定します。 |
| [set_PrintNotes](./set_printnotes/) | ノートを印刷するかどうかを示す値を設定します。 |
