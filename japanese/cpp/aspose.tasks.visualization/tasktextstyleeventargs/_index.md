## TaskTextStyleEventArgs class

このクラスはテーブルセルの内容の描画に関連するデータのセットを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | セルの内容を描画するために使用される TextStyle を取得します。このオブジェクトはテーブルセルの外観をカスタマイズするために使用できます。 |
| [get_Column](./get_column/) | 現在描画されているセルが属する ViewColumn を取得します。 |
| [get_Task](./get_task/) | 現在描画されている行に対応する Task を取得します。 |
| [set_CellTextStyle](./set_celltextstyle/) | セルの内容を描画するために使用される TextStyle を設定します。このオブジェクトはテーブルセルの外観をカスタマイズするために使用できます。 |
