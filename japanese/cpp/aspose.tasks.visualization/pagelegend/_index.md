## PageLegend class

**Inherits:** Aspose::Tasks::Visualization::HeaderFooterInfo

プロジェクト印刷に使用されるページ凡例を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_LegendOn](./get_legendon/) | 凡例が表示されるページを取得します。Legend 列挙体の値のいずれかになる可能性があります。 |
| [get_Width](./get_width/) | 凡例の左側部分（デフォルトでプロジェクト名と日付を含む）の幅をセンチメートル単位で取得します。 |
| [set_LegendOn](./set_legendon/) | 凡例が表示されるページを設定します。Legend 列挙体の値のいずれかにすることができます。 |
| [set_Width](./set_width/) | 凡例の左側部分（デフォルトでプロジェクト名と日付が含まれます）の幅をセンチメートル単位で設定します。 |
