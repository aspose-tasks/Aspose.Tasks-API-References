## RecurringInterval class

Gantt Chart ビューの進捗ラインで使用される繰り返し間隔を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [DayType](./daytype/) | 進捗ラインで使用される日タイプを表します。 |
| [get_DailyDayNumber](./get_dailydaynumber/) | 日次の日番号を取得します。 |
| [get_DailyWorkday](./get_dailyworkday/) | 日次の進捗ラインでその日が稼働日かどうかを示す値を取得します。 |
| [get_Interval](./get_interval/) | 繰り返し間隔を取得します。Interval タイプの任意の値にすることができます。 |
| [get_MonthlyDay](./get_monthlyday/) | 月次の進捗ラインを日単位で表示するかどうかを示す値を取得します。 |
| [get_MonthlyDayDayNumber](./get_monthlydaydaynumber/) | 月次の進捗ラインの日番号を取得します。 |
| [get_MonthlyDayMonthNumber](./get_monthlydaymonthnumber/) | 月次の進捗ラインの月番号を取得します。 |
| [get_MonthlyFirstLast](./get_monthlyfirstlast/) | 最初または最後の事前定義された日で進捗ラインを表示するかどうかを示す値を取得します。 |
| [get_MonthlyFirstLastDay](./get_monthlyfirstlastday/) | 月次の進捗ラインの最初または最後の日タイプを取得します。 |
| [get_MonthlyFirstLastMonthNumber](./get_monthlyfirstlastmonthnumber/) | 最初または最後の事前定義された日で表示される進捗ラインの月番号を取得します。 |
| [get_WeeklyDays](./get_weeklydays/) | 週次の進捗ライン用の日のリストを取得します。 |
| [get_WeeklyWeekNumber](./get_weeklyweeknumber/) | 週次の進捗ラインの週番号を取得します。 |
| [set_DailyDayNumber](./set_dailydaynumber/) | 日次の日番号を設定します。 |
| [set_DailyWorkday](./set_dailyworkday/) | 日次の進捗ラインにおいて、その日が平日かどうかを示す値を設定します。 |
| [set_Interval](./set_interval/) | 繰り返し間隔を設定します。Interval 型の任意の値を使用できます。 |
| [set_MonthlyDay](./set_monthlyday/) | 月次の進捗ラインを日単位で表示するかどうかを示す値を設定します。 |
| [set_MonthlyDayDayNumber](./set_monthlydaydaynumber/) | 月次の進捗ラインの日番号を設定します。 |
| [set_MonthlyDayMonthNumber](./set_monthlydaymonthnumber/) | 月次の進捗ラインの月番号を設定します。 |
| [set_MonthlyFirstLast](./set_monthlyfirstlast/) | 最初または最後の事前定義された日で進捗ラインを表示するかどうかを示す値を設定します。 |
| [set_MonthlyFirstLastDay](./set_monthlyfirstlastday/) | 月次の進捗ラインの最初または最後の日タイプを設定します。 |
| [set_MonthlyFirstLastMonthNumber](./set_monthlyfirstlastmonthnumber/) | 最初または最後の事前定義された日で表示される進捗ラインの月番号を設定します。 |
| [set_WeeklyWeekNumber](./set_weeklyweeknumber/) | 週次の進捗ラインの週番号を設定します。 |
