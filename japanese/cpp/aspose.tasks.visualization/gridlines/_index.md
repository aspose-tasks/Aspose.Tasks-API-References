## Gridlines class

GanttChart ビューに表示されるグリッドラインを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_Interval](./get_interval/) | グリッドライン間の間隔を指定する 0 から 99 の数値を取得します。 |
| [get_IntervalColor](./get_intervalcolor/) | 二次グリッドラインの色を取得します。 |
| [get_IntervalPattern](./get_intervalpattern/) | 二次グリッドラインの線パターンを取得します。 |
| [get_NormalColor](./get_normalcolor/) | 通常のグリッドラインの色を取得します。 |
| [get_NormalPattern](./get_normalpattern/) | 通常のグリッドラインの線パターンを取得します。 |
| [get_Type](./get_type/) | グリッドラインのタイプを取得します。 |
| [set_Interval](./set_interval/) | グリッドライン間の間隔を指定する 0 から 99 の数値を設定します。 |
| [set_IntervalColor](./set_intervalcolor/) | 二次グリッドラインの色を設定します。 |
| [set_IntervalPattern](./set_intervalpattern/) | 二次グリッドラインの線パターンを設定します。 |
| [set_NormalColor](./set_normalcolor/) | 通常のグリッドラインの色を設定します。 |
| [set_NormalPattern](./set_normalpattern/) | 通常のグリッドラインの線パターンを設定します。 |
| [set_Type](./set_type/) | グリッドラインのタイプを設定します。 |
