## PageSettings class

プロジェクトビューのページの印刷設定を表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [PageSettings](./pagesettings/) | PageSettings クラスの新しいインスタンスを初期化します。プロジェクトビューのページの印刷設定を表します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | 印刷を標準サイズの指定パーセンテージ（PercentOfNormalSize）に調整するかどうかを示す値を取得します。 |
| [get_FirstPageNumber](./get_firstpagenumber/) | 印刷の開始ページ番号を取得します。 |
| [get_IsPortrait](./get_isportrait/) | ページの向きが縦向きかどうかを示す値を取得します。横向きの場合は false を返します。 |
| [get_PagesInHeight](./get_pagesinheight/) | 印刷する縦方向のページ数を取得します。 |
| [get_PagesInWidth](./get_pagesinwidth/) | 印刷する幅のページ数を取得します。 |
| [get_PaperSize](./get_papersize/) | 用紙サイズを取得します。PrinterPaperSize 列挙体の値のいずれかになる可能性があります。 |
| [get_PaperSizeId](./get_papersizeid/) | PrinterPaperSize の値のいずれか、またはカスタムページサイズ ID を表す整数を取得します。この値は OS 設定から PaperSize を取得するために使用できます。 |
| [get_PercentOfNormalSize](./get_percentofnormalsize/) | 印刷を調整する標準サイズのパーセンテージを取得します。 |
| [set_AdjustToPercentOfNormalSize](./set_adjusttopercentofnormalsize/) | 印刷を標準サイズの指定されたパーセンテージ（PercentOfNormalSize）に調整するかどうかを示す値を設定します。 |
| [set_FirstPageNumber](./set_firstpagenumber/) | 印刷の開始ページ番号を設定します。 |
| [set_IsPortrait](./set_isportrait/) | ページの向きが縦向きかどうかを示す値を設定します。ページの向きが横向きの場合は false を返します。 |
| [set_PagesInHeight](./set_pagesinheight/) | 印刷する高さのページ数を設定します。 |
| [set_PagesInWidth](./set_pagesinwidth/) | 印刷する幅のページ数を設定します。 |
| [set_PaperSize](./set_papersize/) | 用紙サイズを設定します。PrinterPaperSize 列挙体の値のいずれかになる可能性があります。 |
| [set_PaperSizeId](./set_papersizeid/) | PrinterPaperSize の値のいずれか、またはカスタムページサイズ ID を表す整数を設定します。この値は OS 設定から PaperSize を取得するために使用できます。 |
| [set_PercentOfNormalSize](./set_percentofnormalsize/) | 印刷を調整する標準サイズのパーセンテージを設定します。 |
