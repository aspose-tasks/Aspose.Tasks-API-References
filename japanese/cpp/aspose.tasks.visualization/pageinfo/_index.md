## PageInfo class

MPP ファイル形式に存在し、印刷に使用されるページ設定データを表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [PageInfo](./pageinfo/) | PageInfo クラスの新しいインスタンスを初期化します。MPP ファイル形式に存在し、印刷に使用されるページ設定データを表します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_Footer](./get_footer/) | フッターデータを表す HeaderFooterInfo クラスのインスタンスを取得します。 |
| [get_Header](./get_header/) | ヘッダーデータを表す HeaderFooterInfo クラスのインスタンスを取得します。 |
| [get_Legend](./get_legend/) | ページ凡例のレンダリングオプションを指定する PageLegend クラスのインスタンスを取得します。 |
| [get_Margins](./get_margins/) | ページ余白を指定する PageMargins クラスのインスタンスを取得します。 |
| [get_Name](./get_name/) | 設定データが使用されるビューの名前を取得します。 |
| [get_PageSettings](./get_pagesettings/) | ページ印刷設定を指定する PageSettings クラスのインスタンスを取得します。 |
| [get_PageViewSettings](./get_pageviewsettings/) | ページビュー印刷設定を指定する PageViewSettings クラスのインスタンスを取得します。 |
| [set_Footer](./set_footer/) | フッターデータを表す HeaderFooterInfo クラスのインスタンスを設定します。 |
| [set_Header](./set_header/) | ヘッダーデータを表す HeaderFooterInfo クラスのインスタンスを設定します。 |
| [set_Legend](./set_legend/) | ページ凡例のレンダリングオプションを指定する PageLegend クラスのインスタンスを設定します。 |
