## set_RenderLabelOnEachPage {#set_renderlabeloneachpage}

時間期間が複数ページにまたがる場合に、各ページで日付ラベルを描画するかどうかを定義するフラグを設定します。値が 'true' の場合、時間期間が複数ページにまたがるとき、期間の日時ラベルが各ページに描画されます。値が 'false' の場合、Alignment プロパティの値に従って日付ラベルは一度だけ描画されます。

**Returns:** void Aspose::Tasks::Visualization::

```cpp
set_RenderLabelOnEachPage(bool value)
```
