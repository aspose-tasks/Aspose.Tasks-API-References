## PageMargins class

印刷用のページ余白を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_Borders](./get_borders/) | 罫線を印刷する位置を取得します。Border 列挙体のいずれかの値を使用できます。 |
| [get_Bottom](./get_bottom/) | 下余白のサイズ（センチメートル）を取得します。 |
| [get_Left](./get_left/) | 左余白のサイズ（センチメートル）を取得します。 |
| [get_Right](./get_right/) | 右余白のサイズ（センチメートル）を取得します。 |
| [get_Top](./get_top/) | 上余白のサイズ（センチメートル）を取得します。 |
| [set_Borders](./set_borders/) | 罫線を印刷する位置を設定します。Border 列挙体のいずれかの値を使用できます。 |
| [set_Bottom](./set_bottom/) | 下部余白のサイズをセンチメートル単位で設定します。 |
| [set_Left](./set_left/) | 左余白のサイズをセンチメートル単位で設定します。 |
| [set_Right](./set_right/) | 右余白のサイズをセンチメートル単位で設定します。 |
| [set_Top](./set_top/) | 上部余白のサイズをセンチメートル単位で設定します。 |
