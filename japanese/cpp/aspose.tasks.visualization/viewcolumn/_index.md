## ViewColumn class

プロジェクトビューの列を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_Field](./get_field/) | 列フィールドを取得します。フィールド。 |
| [get_Name](./get_name/) | 列名を取得します。 |
| [get_StringAlignment](./get_stringalignment/) | テキストの配置を取得します（HorizontalStringAlignment 列挙体の値のいずれかになります）。 |
| [get_TextStyleModificationCallback](./get_textstylemodificationcallback/) | 列のセルの外観をカスタマイズするために使用できるコールバックを取得します。 |
| [get_Width](./get_width/) | 列幅を取得します。 |
| [set_Field](./set_field/) | 列フィールドを設定します。フィールド。 |
| [set_StringAlignment](./set_stringalignment/) | テキストの配置を設定します（HorizontalStringAlignment 列挙体の値のいずれかにできます）。 |
| [set_TextStyleModificationCallback](./set_textstylemodificationcallback/) | 列のセルの外観をカスタマイズするために使用できるコールバックを設定します。 |
