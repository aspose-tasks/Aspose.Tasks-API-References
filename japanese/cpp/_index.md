API は、Project XML、MPX、MPP、Primavera XER 形式の処理を可能にする豊富なオブジェクトモデルを提供し、タスク、リソース、割り当て、カレンダー、カスタム フィールドをサポートします。その機能は 9 つの名前空間に整理されています：コア エンティティ用の Aspose::Tasks、ファイル I/O 用の Connectivity、リソース レベリング用の Leveling、Primavera 固有オブジェクト用の Primavera、拡張属性用の Properties、モンテカルロ リスク モデリング用の RiskAnalysis、エクスポート オプション用の Saving、ヘルパー ユーティリティ用の Util、ガント チャートとレポートのレンダリング用の Visualization。

## 名前空間

| 名前空間 | 説明 |
| --- | --- |
| [Aspose::Tasks](./aspose.tasks/) | Aspose::Tasks 名前空間は、C++ におけるプロジェクト データ、リソース、割り当て、ベースライン情報を管理するためのコア クラスと列挙体を提供します。 |
| [Aspose::Tasks::Connectivity](./aspose.tasks.connectivity/) | Aspose::Tasks::Connectivity 名前空間は、さまざまなプロジェクト管理データベースへの接続設定を定義するクラスを提供します。 |
| [Aspose::Tasks::Leveling](./aspose.tasks.leveling/) | Aspose::Tasks::Leveling 名前空間は、プロジェクト スケジュールにおけるリソース レベリングの構成と実行のためのクラスを提供します。 |
| [Aspose::Tasks::Primavera](./aspose.tasks.primavera/) | Aspose.Tasks for C++ 内で Primavera プロジェクト データを処理するための型を提供します。 |
| [Aspose::Tasks::Properties](./aspose.tasks.properties/) | Aspose::Tasks::Properties 名前空間は、Aspose.Tasks for C++ における組み込みおよびカスタム プロジェクト プロパティを管理するクラスとコレクションを提供します。 |
| [Aspose::Tasks::RiskAnalysis](./aspose.tasks.riskanalysis/) | プロジェクト スケジュールに対するモンテカルロ リスク分析を実行するためのクラスと列挙体を提供します。 |
| [Aspose::Tasks::Saving](./aspose.tasks.saving/) | Aspose::Tasks::Saving 名前空間は、さまざまな形式で Project ファイルを保存する際の構成と制御のためのクラスとインターフェイスを提供します。 |
| [Aspose::Tasks::Util](./aspose.tasks.util/) | Aspose::Tasks::Util 名前空間は、タスク ツリーの走査と評価のためのユーティリティ クラス、アルゴリズム、条件ヘルパーを提供します。 |
| [Aspose::Tasks::Visualization](./aspose.tasks.visualization/) | Aspose.Tasks におけるガント チャート、グリッドライン、フォント、割り当てビュー列の描画のための可視化コンポーネントを提供します。 |
