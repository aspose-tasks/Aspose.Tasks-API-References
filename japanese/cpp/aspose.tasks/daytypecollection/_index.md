## DayTypeCollection class

DayType オブジェクトのコレクションを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Add](./add/) | 指定された項目をこのコレクションに追加します。 |
| [Clear](./clear/) | このコレクションからすべての項目を削除します。 |
| [Contains](./contains/) | 指定された項目がこのコレクションに見つかった場合は true を返し、そうでない場合は false を返します。 |
| [CopyTo](./copyto/) | このコレクションの要素を指定された配列にコピーし、指定された配列インデックスから開始します。 |
| [get_Count](./get_count/) | このコレクションに含まれる要素数を取得します。 |
| [get_IsReadOnly](./get_isreadonly/) | このコレクションが読み取り専用かどうかを示す値を取得します。そうでない場合は false です。 |
| [GetEnumerator](./getenumerator/) | このコレクションの列挙子を返します。 |
| [idx_get](./idx_get/) | 指定されたインデックスの要素を返します。 |
| [idx_set](./idx_set/) | 指定されたインデックスの要素を設定します。 |
| [IndexOf](./indexof/) | このコレクション内の指定された項目のインデックスを決定します。 |
| [Insert](./insert/) | 指定されたインデックスに指定された項目を挿入します。 |
| [Remove](./remove/) | このコレクションから特定のオブジェクトの最初の出現を削除します。 |
| [RemoveAt](./removeat/) | 指定されたインデックスの項目を削除します。 |
