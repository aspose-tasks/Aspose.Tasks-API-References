## Rate class

リソースに対してその期間中に適用される時間期間とレートの定義を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | リソースの使用単位あたりのコストを取得します。レートテーブルがリソースに存在する場合、この値は現在の日付から取得されます。 |
| [get_OvertimeRate](./get_overtimerate/) | リソースの時間あたりの残業料金を取得します。 |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Microsoft Project が残業料金を表示する際に使用する単位を取得します。 |
| [get_RatesFrom](./get_ratesfrom/) | レートが有効になる日付を取得します。 |
| [get_RatesTo](./get_ratesto/) | レートが有効である最終日付を取得します。 |
| [get_RateTable](./get_ratetable/) | リソースのレートテーブルの一意識別子を取得します。 |
| [get_StandardRate](./get_standardrate/) | リソースの時間あたりの標準レートを取得します。 |
| [get_StandardRateFormat](./get_standardrateformat/) | Microsoft Project が標準レートを表示する際に使用する単位を取得します。 |
| [set_CostPerUse](./set_costperuse/) | リソースの使用単位あたりのコストを設定します。レートテーブルがリソースに存在する場合、この値は現在の日付から取得されます。 |
| [set_OvertimeRate](./set_overtimerate/) | リソースの時間あたりの残業料金を設定します。 |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Microsoft Project が残業料金を表示する際に使用する単位を設定します。 |
| [set_RatesFrom](./set_ratesfrom/) | レートが有効になる日付を設定します。 |
| [set_RatesTo](./set_ratesto/) | レートが有効である最終日付を設定します。 |
| [set_RateTable](./set_ratetable/) | リソースのレートテーブルの一意識別子を設定します。 |
| [set_StandardRate](./set_standardrate/) | リソースの時間あたりの標準レートを設定します。 |
| [set_StandardRateFormat](./set_standardrateformat/) | Microsoft Project が標準レートを表示する際に使用する単位を設定します。 |
