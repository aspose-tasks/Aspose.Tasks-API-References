## TimephasedDataCollection class

TimephasedData オブジェクトのコレクションを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Add](./add/) | TimephasedData インスタンスをこのコレクションオブジェクトに追加します。 |
| [AddRange](./addrange/) | TimephasedData インスタンスのコレクションをこのコレクションオブジェクトに追加します。 |
| [Clear](./clear/) | TimephasedDataCollection からすべての項目を削除します。 |
| [Contains](./contains/) | TimephasedDataCollection が特定の値を含むかどうかを判断します。 |
| [CopyTo](./copyto/) | TimephasedDataCollection の要素を System::Array にコピーし、特定の System::Array インデックスから開始します。 |
| [get_Count](./get_count/) | この TimephasedDataCollection オブジェクトに含まれるオブジェクト数を取得します。 |
| [get_IsReadOnly](./get_isreadonly/) | System::Collections::Generic::ICollection<T> が読み取り専用かどうかを示す値を取得します。 |
| [GetEnumerator](./getenumerator/) | このコレクションの列挙子を返します。 |
| [idx_get](./idx_get/) | 指定されたインデックスの要素を返します。設定アクセサはサポートされていません。timephased データを設定するプロパティです。 |
| [idx_set](./idx_set/) | 指定されたインデックスの要素を返します。設定アクセサはサポートされていません。timephased データを設定するプロパティです。 |
| [Remove](./remove/) | TimephasedData インスタンスをこのコレクションオブジェクトから削除します。 |
| [SelectBetweenStartAndFinish](./selectbetweenstartandfinish/) | startTime と finishTime の間のすべての時間フェーズを選択します。平均ケースで O(log n) の複雑性があります。 |
| [ToList](./tolist/) | TimephasedDataCollection オブジェクトを TimephasedData オブジェクトのリストに変換します。 |
