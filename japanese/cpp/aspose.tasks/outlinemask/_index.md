## OutlineMask class

アウトラインコード形式を定義するマスクの4つの要素を表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [OutlineMask](./outlinemask/) | OutlineMask クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_Length](./get_length/) | アウトラインコード値の最大長さ（文字数）を取得します。長さが定義されていない場合は 0 です。 |
| [get_Level](./get_level/) | マスクのレベルを取得します。 |
| [get_Separator](./get_separator/) | コード値の区切り文字を取得します。 |
| [get_Type](./get_type/) | マスクのタイプを取得します。 |
| [set_Length](./set_length/) | アウトラインコード値の最大長さ（文字数）を設定します。長さが定義されていない場合は 0 です。 |
| [set_Level](./set_level/) | マスクのレベルを設定します。 |
| [set_Separator](./set_separator/) | コード値の区切り文字を設定します。 |
| [set_Type](./set_type/) | マスクのタイプを設定します。 |
