## ProjectFileInfo class

このクラスのインスタンスは、プロジェクトファイルの形式およびファイルが作成された Microsoft Project のバージョンに関する情報を含みます。

CanRead プロパティを使用して、ライブラリがプロジェクトファイルを処理できるかどうかを定義します。

| [get_CanRead](./get_canread/) | Aspose.Tasks がプロジェクトファイルを処理できるかどうかを示す値を取得します。 |
| [get_IsPasswordProtected](./get_ispasswordprotected/) | プロジェクトがパスワードで保護されているかどうかを示す値を取得します。 |

| [get_ProjectFileFormat](./get_projectfileformat/) | プロジェクトファイルの形式を取得します。 |
| [GetHashCode](./gethashcode/) | ProjectFileInfo クラスのインスタンスのハッシュコード値を返します。 |
