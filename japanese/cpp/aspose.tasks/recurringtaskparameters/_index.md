## RecurringTaskParameters class

プロジェクト内で繰り返しタスクを作成するために使用されるパラメータのセットを表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [RecurringTaskParameters](./recurringtaskparameters/) | RecurringTaskParameters クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_Duration](./get_duration/) | 繰り返しタスクの1回の発生の期間を取得します。 |
| [get_IgnoreResourceCalendar](./get_ignoreresourcecalendar/) | 利用可能なリソースがなくても繰り返しタスクをスケジュールするかどうかを示す値を取得します。 |
| [get_RecurrencePattern](./get_recurrencepattern/) | 繰り返しタスクの繰り返しパターンを取得します。 |
| [get_TaskName](./get_taskname/) | 繰り返しタスクの名前を取得します。 |
| [set_Duration](./set_duration/) | 繰り返しタスクの1回の発生の期間を設定します。 |
| [set_IgnoreResourceCalendar](./set_ignoreresourcecalendar/) | 利用可能なリソースがなくても繰り返しタスクをスケジュールするかどうかを示す値を設定します。 |
| [set_RecurrencePattern](./set_recurrencepattern/) | 繰り返しタスクの繰り返しパターンを設定します。 |
| [set_TaskName](./set_taskname/) | 繰り返しタスクの名前を設定します。 |
| [SetCalendar](./setcalendar/) | 繰り返しタスクのカレンダーを設定します。カレンダーはプロジェクトのカレンダーコレクションから選択されます。 |
