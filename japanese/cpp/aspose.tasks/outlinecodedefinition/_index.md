## OutlineCodeDefinition class

アウトラインコード定義を表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [OutlineCodeDefinition](./outlinecodedefinition/) | OutlineCodeDefinition クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_Alias](./get_alias/) | カスタム アウトライン コードのエイリアスを取得します。 |
| [get_AllLevelsRequired](./get_alllevelsrequired/) | 新しいコードがすべてのレベルを持つ必要があるかどうかを示す値を取得します。エンタープライズ コードでは使用できません。 |
| [get_Enterprise](./get_enterprise/) | カスタム アウトライン コードがエンタープライズ カスタム アウトライン コードかどうかを示す値を取得します。 |
| [get_EnterpriseOutlineCodeAlias](./get_enterpriseoutlinecodealias/) | このアウトライン コード定義がエイリアスである別のカスタム フィールドへの参照を取得します。 |
| [get_FieldId](./get_fieldid/) | アウトライン コードのフィールド番号を取得します。 |
| [get_FieldName](./get_fieldname/) | カスタム アウトライン コードの名前を取得します。 |
| [get_Guid](./get_guid/) | アウトライン コードの Guid を取得します。 |
| [get_LeafOnly](./get_leafonly/) | このアウトライン コード フィールドで指定された値がリーフ値である必要があるかどうかを示す値を取得します。 |
| [get_Masks](./get_masks/) | OutlineMaskCollection オブジェクトを取得します。アウトライン コード マスクを定義するエントリのテーブルです。読み取り専用の OutlineMaskCollection インスタンスです。 |
| [get_OnlyTableValuesAllowed](./get_onlytablevaluesallowed/) | 指定された値が値テーブルから取得される必要があるかどうかを示す値を取得します。 |
| [get_PhoneticAlias](./get_phoneticalias/) | カスタム アウトライン コードのエイリアスの音声表記を取得します。 |
| [get_ResourceSubstitutionEnabled](./get_resourcesubstitutionenabled/) | カスタム アウトライン コードが Microsoft Project のリソース置換ウィザードで使用できるかどうかを示す値を取得します。 |
| [get_ShowIndent](./get_showindent/) | このアウトライン コードのインデントを表示する必要があるかどうかを示す値を取得します。 |
| [get_Values](./get_values/) | OutlineValueCollection オブジェクトを取得します。このアウトライン コードに関連付けられたテーブルの値です。 |
| [set_Alias](./set_alias/) | カスタム アウトライン コードのエイリアスを設定します。 |
| [set_AllLevelsRequired](./set_alllevelsrequired/) | 新しいコードがすべてのレベルを持つ必要があるかどうかを示す値を設定します。エンタープライズ コードでは使用できません。 |
| [set_Enterprise](./set_enterprise/) | カスタム アウトライン コードがエンタープライズ カスタム アウトライン コードかどうかを示す値を設定します。 |
| [set_EnterpriseOutlineCodeAlias](./set_enterpriseoutlinecodealias/) | このアウトライン コード定義がエイリアスである別のカスタム フィールドへの参照を設定します。 |
| [set_FieldId](./set_fieldid/) | アウトライン コードのフィールド番号を設定します。 |
| [set_FieldName](./set_fieldname/) | カスタム アウトライン コードの名前を設定します。 |
| [set_Guid](./set_guid/) | アウトラインコードの Guid を設定します。 |
| [set_LeafOnly](./set_leafonly/) | このアウトラインコード フィールドで指定された値がリーフ値である必要があるかどうかを示す値を設定します。 |
| [set_OnlyTableValuesAllowed](./set_onlytablevaluesallowed/) | 指定された値が値テーブルから取得される必要があるかどうかを示す値を設定します。 |
| [set_PhoneticAlias](./set_phoneticalias/) | カスタムアウトラインコードのエイリアスの音声表記を設定します。 |
| [set_ResourceSubstitutionEnabled](./set_resourcesubstitutionenabled/) | カスタムアウトラインコードが Microsoft Project のリソース置換ウィザードで使用できるかどうかを示す値を設定します。 |
| [set_ShowIndent](./set_showindent/) | このアウトラインコードのインデントを表示する必要があるかどうかを示す値を設定します。 |
