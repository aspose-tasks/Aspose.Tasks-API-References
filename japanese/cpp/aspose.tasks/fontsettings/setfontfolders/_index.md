## SetFontFolders {#setfontfolders}

プロジェクトのビューをレンダリングする際に Aspose.Tasks が TrueType フォントを検索するフォルダーを設定します。

**Returns:** void Aspose::Tasks::

```cpp
SetFontFolders(const System::ArrayPtr< System::String > & fontFolders, bool recursive)
```

| パラメーター | 説明 |
| --- | --- |
| fontFolders | TrueType フォントを含むフォルダーの配列。 |
| recursive | true の場合、指定されたフォルダーは再帰的にスキャンされます。 |
