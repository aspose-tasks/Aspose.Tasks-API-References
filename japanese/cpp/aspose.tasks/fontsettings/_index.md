## FontSettings class

プロジェクトのビューをレンダリングする際に使用されるフォント設定を指定します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | レンダリング用のデフォルト（またはフォールバック）フォントを取得します。 |
| [get_FontResolveCallback](./get_fontresolvecallback/) | 解決されたフォントをカスタマイズするために使用できるコールバックを取得します。 |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | レンダリングにデフォルトフォントを使用しなければならないかどうかを示す値を取得します。 |
| [set_DefaultFontName](./set_defaultfontname/) | レンダリング用のデフォルト（またはフォールバック）フォントを設定します。 |
| [set_FontResolveCallback](./set_fontresolvecallback/) | 解決されたフォントをカスタマイズするために使用できるコールバックを設定します。 |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | レンダリングにデフォルトフォントを使用すべきかどうかを示す値を設定します。 |
| [SetFontFolders](./setfontfolders/) | プロジェクトのビューをレンダリングする際に Aspose.Tasks が TrueType フォントを検索するフォルダーを設定します。 |
