## WeekDayCollection class

WeekDay オブジェクトのコレクションを表します。

## メソッド

| --- | --- |
| [Add](./add/) | このオブジェクトに WeekDay インスタンスを追加します。 |
| [Clear](./clear/) | WeekDayCollection オブジェクトをクリアします。 |
| [Contains](./contains/) | コレクションに指定された WeekDay が含まれているかチェックします。 |
| [CopyTo](./copyto/) | コレクションの内容を指定されたインデックスの配列にコピーします。 |
| [get_Count](./get_count/) | この WeekDayCollection オブジェクトに含まれるオブジェクトの数を取得します。 |

| [idx_get](./idx_get/) | 指定されたインデックスの項目値を取得します。 |
| [idx_set](./idx_set/) | 指定されたインデックスの項目値を設定します。 |
| [IndexOf](./indexof/) | 指定された WeekDay のインデックスを返します。 |
| [Insert](./insert/) | 指定されたインデックスに WeekDay を挿入します。 |
| [Remove](./remove/) | 指定された WeekDay を（存在すれば）削除します。 |
