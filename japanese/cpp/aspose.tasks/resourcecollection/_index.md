## ResourceCollection class

Resource オブジェクトのコレクションを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Add (3 overloads)](./add/) | プロジェクトのリソースコレクションの最後の位置に新しいリソースを追加します。 |
| [Clear](./clear/) | 直接クリアはサポートされておらず、このメソッドは NotSupportedException をスローします。 |
| [get_Count](./get_count/) | ResourceCollection に含まれる要素数を取得します。 |
| [get_ParentProject](./get_parentproject/) | ResourceCollection オブジェクトの親プロジェクトを取得します。 |
| [GetById](./getbyid/) | 指定された ID のリソースを返します。 |
| [GetByUid](./getbyuid/) | 指定された Uid のリソースを返します。 |
| [GetEnumerator](./getenumerator/) | このコレクションの列挙子を返します。 |
| [idx_get](./idx_get/) | 指定されたインデックスの要素を返します。 |
| [idx_set](./idx_set/) | 指定されたインデックスの要素を返します。 |
| [Remove](./remove/) | これは ICollection の Remove メソッドのスタブ実装で、NotSupportedException をスローするだけです。 |
| [ToList](./tolist/) | ResourceCollection オブジェクトを Resource オブジェクトのリストに変換します。 |
