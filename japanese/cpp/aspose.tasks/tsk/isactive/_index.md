## IsActive {#isactive}

タスクがアクティブかどうかを決定する。非アクティブなタスクは、他のタスクやプロジェクト全体のスケジュールに影響しなくなる。

**Returns:** static Key < NullableBool , TaskKey>& Aspose::Tasks::

```cpp
IsActive()
```
