## WorkUnit class

作業時間を表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [WorkUnit](./workunit/) | WorkUnit クラスの新しいインスタンスを初期化します。指定された From と To の日付で新しい WorkUnit オブジェクトを作成します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_From](./get_from/) | From 日付を取得します。 |
| [get_To](./get_to/) | To 日付を取得します。 |
| [get_WorkingHours](./get_workinghours/) | 作業時間の期間を取得します。 |
| [set_From](./set_from/) | From 日付を設定します。 |
| [set_To](./set_to/) | To 日付を設定します。 |
| [set_WorkingHours](./set_workinghours/) | 作業時間の期間を設定します。 |
