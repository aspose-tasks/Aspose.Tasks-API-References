## PropertyContainer< T > class

プロパティ コンテナを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [CheckPropAndGet](./checkpropandget/) | このコンテナでプロパティがマッピングされている値を返します。このコンテナに ProjectItem レコードが存在しない場合、デフォルト値で追加され、そのデフォルト値が返されます。 |
| [CheckPropAndSet](./checkpropandset/) | このコンテナ内の指定されたプロパティを指定された値にマップします。このコンテナにレコード ProjectItem が含まれていない場合、追加されます。 |
