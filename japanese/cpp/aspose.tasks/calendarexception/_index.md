## CalendarException class

カレンダー内の例外的な期間を表します。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [CalendarException](./calendarexception/) | CalendarException クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [CheckException](./checkexception/) | 指定された DateTime 構造体のインスタンスが例外日である場合、true を返します。 |
| [Delete](./delete/) | 親カレンダーの CalendarExceptionCollection オブジェクトから Exception インスタンスを削除します。 |

| [get_FromDate](./get_fromdate/) | 例外時間の開始時刻を取得します。 |
| [get_Month](./get_month/) | 例外の繰り返しが予定されている月を取得します。 |
| [get_MonthDay](./get_monthday/) | 例外の繰り返しが予定されている月の日を取得します。 |
| [get_MonthItem](./get_monthitem/) | 例外の繰り返しが予定されている月項目を取得します。 |
| [get_MonthPosition](./get_monthposition/) | 月内の月項目の位置を取得します。 |
| [get_Name](./get_name/) | 例外の名前を取得します。 |
| [get_Occurrences](./get_occurrences/) | カレンダー例外が有効な発生回数を取得します。 |
| [get_ParentCalendar](./get_parentcalendar/) | このオブジェクトの親カレンダーを取得します。 |
| [get_Period](./get_period/) | 例外の繰り返し期間を取得します。 |
| [get_ToDate](./get_todate/) | 例外時間の終了時刻を取得します。 |
| [get_Type](./get_type/) | 例外の種類を取得します。 |

| [GetExceptionDates](./getexceptiondates/) | カレンダー例外が適用される日付を返します。 |
| [GetWorkingTime](./getworkingtime/) | カレンダー例外の作業時間を返します。 |
| [set_DayWorking](./set_dayworking/) | 指定された日付または曜日タイプが作業日かどうかを示す値を設定します。 |
| [set_EnteredByOccurrences](./set_enteredbyoccurrences/) | 繰り返し範囲が発生回数の入力によって定義されるかどうかを示す値を設定します。false は、繰り返し範囲が終了日を入力して定義されることを指定します。 |
| [set_FromDate](./set_fromdate/) | 例外時間の開始時刻を設定します。 |
| [set_Month](./set_month/) | 例外の繰り返しが予定されている月を設定します。 |
| [set_MonthDay](./set_monthday/) | 例外の繰り返しが予定されている月の日を設定します。 |

| [set_Period](./set_period/) | 例外の繰り返し期間を設定します。 |
| [set_ToDate](./set_todate/) | 例外時間の終了時刻を設定します。 |
| [set_Type](./set_type/) | 例外の種類を設定します。 |
| [set_WorkingTimes](./set_workingtimes/) | WorkingTimeCollection オブジェクトを設定します。平日に作業した時間を定義する作業時間のコレクションです。 |
