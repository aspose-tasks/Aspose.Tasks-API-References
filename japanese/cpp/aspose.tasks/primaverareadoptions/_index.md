## PrimaveraReadOptions class

Primavera Xml または Primavera Xer ファイルを読み取る際に、追加オプションを指定できます。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [PrimaveraReadOptions](./primaverareadoptions/) | PrimaveraReadOptions クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_PreserveUids](./get_preserveuids/) | エンティティの元の一意識別子を保持するかどうかを指定するフラグを取得します。 |
| [get_ProjectUid](./get_projectuid/) | 複数のプロジェクトが含まれるファイルから読み取るプロジェクトの UID を取得します。 |
| [get_ReadBaselineProjects](./get_readbaselineprojects/) | ベースラインプロジェクトをロードするかどうかを指定するフラグを取得します。デフォルト値は true です。 |
| [get_UndefinedConstraintHandlingBehavior](./get_undefinedconstrainthandlingbehavior/) | XER 形式から読み取った制約が未定義のタスクを処理する際に使用する動作を指定します。 |
| [set_PreserveUids](./set_preserveuids/) | エンティティの元の一意識別子を保持するかどうかを指定するフラグを設定します。 |
| [set_ProjectUid](./set_projectuid/) | 複数のプロジェクトが含まれるファイルから読み取るプロジェクトの UID を設定します。 |
| [set_ReadBaselineProjects](./set_readbaselineprojects/) | ベースラインプロジェクトをロードするかどうかを指定するフラグを設定します。デフォルト値は true です。 |
| [set_UndefinedConstraintHandlingBehavior](./set_undefinedconstrainthandlingbehavior/) | XER 形式から読み取った制約が未定義のタスクを処理する際に使用する動作を指定します。 |
