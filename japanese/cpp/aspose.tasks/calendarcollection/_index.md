| [get_Count](./get_count/) | この CalendarCollection オブジェクトに含まれるオブジェクト数を取得します。 |
| [GetByName](./getbyname/) | 指定された名前のカレンダーを返します。 |
| [GetByUid](./getbyuid/) | 指定された UID のカレンダーを返します。 |
| [GetEnumerator](./getenumerator/) | このコレクションの列挙子を返します。 |
| [Remove](./remove/) | Project CalendarCollection からカレンダーを削除します。 |
