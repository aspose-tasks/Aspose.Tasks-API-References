## ViewCollection class

View オブジェクトのリストを含みます。ICollection< View > インターフェイスを実装します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Add](./add/) | 指定された項目をこのコレクションに追加します。 |
| [Clear](./clear/) | このコレクションからすべての項目を削除します。 |
| [Contains](./contains/) | 指定された項目がこのコレクションに見つかった場合は true を返し、そうでない場合は false を返します。 |
| [CopyTo](./copyto/) | このコレクションの要素を指定された配列にコピーし、指定された配列インデックスから開始します。 |
| [get_Count](./get_count/) | このコレクションに含まれる要素数を取得します。 |
| [get_IsReadOnly](./get_isreadonly/) | このコレクションが読み取り専用であるかどうかを示す値を取得します。そうでなければ false です。 |
| [get_ParentProject](./get_parentproject/) | View オブジェクトの親を取得します。読み取り専用の Project。 |
| [GetByName](./getbyname/) | 名前で View を検索し、コレクション内で最初に見つかったものを返します。 |
| [GetByViewScreen](./getbyviewscreen/) | 指定された Screen プロパティを持つ View を検索し、コレクション内で最初に見つかったものを返します。 |
| [GetEnumerator](./getenumerator/) | このコレクションの列挙子を返します。 |
| [Remove](./remove/) | このコレクションから特定のオブジェクトの最初の出現を削除します。 |
| [ToList](./tolist/) | ビューコレクションを View オブジェクトのリストに変換します。 |
