## GetByName {#getbyname}

名前で View を検索し、コレクション内で最初に見つかったものを返します。

**Returns:** The first View in collection with the specified name, if found; otherwise, null.

```cpp
GetByName(const System::String & viewName)
```

| パラメーター | 説明 |
| --- | --- |
| viewName | 検索するビューの名前。 |
