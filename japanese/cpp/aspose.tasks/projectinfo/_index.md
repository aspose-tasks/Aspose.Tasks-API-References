## ProjectInfo class

Project Online で利用可能な公開プロジェクトに関する簡潔な情報です。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [ProjectInfo](./projectinfo/) | ProjectInfo クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_CreatedDate](./get_createddate/) | プロジェクトが作成された日時を取得します。 |
| [get_Description](./get_description/) | プロジェクトの説明を取得します。 |
| [get_Id](./get_id/) | プロジェクトの一意の識別子を取得します。 |
| [get_IsCheckedOut](./get_ischeckedout/) | プロジェクトがチェックアウトされているかどうかを示す値を取得します。 |
| [get_LastPublishedDate](./get_lastpublisheddate/) | プロジェクトが公開された最新の日付を取得します。 |
| [get_LastSavedDate](./get_lastsaveddate/) | プロジェクトが保存された最新の日付を取得します。 |
| [get_Name](./get_name/) | プロジェクトの名前を取得します。 |
