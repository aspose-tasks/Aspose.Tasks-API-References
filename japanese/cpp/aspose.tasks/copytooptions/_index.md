## CopyToOptions class

プロジェクト データをコピーする際に追加オプションを指定できます。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [CopyToOptions](./copytooptions/) | CopyToOptions クラスの新しいインスタンスを初期化します。 |

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_CopyViewData](./get_copyviewdata/) | プロジェクト データをコピーする際にビュー データもコピーするかどうかを示す値を取得します。デフォルト値は true です。 |
| [set_CopyViewData](./set_copyviewdata/) | プロジェクト データをコピーする際にビュー データもコピーするかどうかを示す値を設定します。デフォルト値は true です。 |
