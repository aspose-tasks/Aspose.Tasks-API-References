## OleObjectCollection class

OleObjectクラスのインスタンスを含むコレクションを表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [Clear](./clear/) | コレクションをクリアします。これらの変更を永続化するには、project.Save を new MPPSaveOptions { WriteViewData = true; } と共に呼び出す必要があります。 |
| [GetEnumerator](./getenumerator/) | このコレクションの列挙子を返します。 |
| [ToList](./tolist/) | OleObjectCollection クラスのインスタンスを OleObject クラスのインスタンスを含むリストに変換します。 |
