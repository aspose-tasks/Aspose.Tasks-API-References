## Group class

グループ定義を表します。Group オブジェクトは ResourceGroups コレクションまたは TaskGroups コレクションのメンバーです。

## コンストラクター

| 名前 | 説明 |
| --- | --- |
| [Group](./group/) | Group クラスの新しいインスタンスを初期化します。 |

| [get_Index](./get_index/) | Groups リスト内の Group オブジェクトのインデックスを取得します。 |
| [get_MaintainHierarchy](./get_maintainhierarchy/) | グループ内のサブタスクに対して、サマリタスクのすべてのレベルを表示すべきかどうかを示す値を取得します。 |
| [get_Name](./get_name/) | Group オブジェクトの名前を取得します。 |

| [set_Name](./set_name/) | Group オブジェクトの名前を設定します。 |
