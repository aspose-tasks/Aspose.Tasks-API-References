## FilterCriteria class

MSPビューに表示されるために、タスクまたはリソースが満たすべき基準を定義します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_CriteriaRows](./get_criteriarows/) | 子フィルタ基準行のリストを取得します。フィルタに複数の基準行が含まれる場合、AND 演算子の効果は、タスクまたはリソースがこのフィルタの結果として表示されるために、両方の行の基準を満たす必要があることです。OR 演算子の効果は、いずれか一方の行の基準を満たす必要があることです。 |
| [get_Field](./get_field/) | 変更するフィールドを取得します。 |
| [get_Operation](./get_operation/) | FieldName、Test、Valueで設定された基準がフィルタ内の他の基準とどのように関連するかを取得します。 |
| [get_Test](./get_test/) | フィルタの選択基準として機能する、FieldName と Value の間で行われる比較の種類を取得します。FilterComparisonType |
| [get_Values](./get_values/) | FieldName で指定されたフィールドの値と比較するオブジェクト値を取得します。 |
| [IsFieldValue](./isfieldvalue/) | FilterCriteria の右側の値が定数ではなくフィールド参照であるかどうかを取得します。 |
| [set_Field](./set_field/) | 変更するフィールドを設定します。 |
| [set_Operation](./set_operation/) | FieldName、Test、Valueで設定された基準がフィルタ内の他の基準とどのように関連するかを設定します。 |
| [set_Test](./set_test/) | フィルタの選択基準として機能する、FieldName と Value の間で行われる比較の種類を設定します。FilterComparisonType |
| [SetValueField](./setvaluefield/) | FieldName で指定されたフィールドの値と比較されるフィールドを設定します。 |
| [ToString](./tostring/) | FilterCriteria クラスのインスタンスの文字列表現を返します。 |
