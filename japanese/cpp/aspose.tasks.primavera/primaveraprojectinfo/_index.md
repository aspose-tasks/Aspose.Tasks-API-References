## PrimaveraProjectInfo class

Primavera 形式で読み込まれたプロジェクトの簡易情報を表します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [get_ExportFlag](./get_exportflag/) | プロジェクトのエクスポートフラグを取得します。Primaveraでプロジェクトがエクスポート対象に選択されると、その ExportFlag は true になります。エクスポート対象として明示的に選択されていないプロジェクトでも、エクスポートされたプロジェクトとの関係により XER ファイルにエクスポートされることがあります。 |
| [get_Name](./get_name/) | プロジェクトの名前を取得します。 |
| [get_Uid](./get_uid/) | プロジェクトの Uid を取得します。 |
