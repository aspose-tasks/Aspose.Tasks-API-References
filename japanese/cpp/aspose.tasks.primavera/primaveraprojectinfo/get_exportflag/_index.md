## get_ExportFlag {#get_exportflag}

プロジェクトのエクスポートフラグを取得します。Primaveraでプロジェクトがエクスポート対象に選択されると、その ExportFlag は true になります。エクスポート対象として明示的に選択されていないプロジェクトでも、エクスポートされたプロジェクトとの関係により XER ファイルにエクスポートされることがあります。

**Returns:** bool Aspose::Tasks::Primavera::

```cpp
get_ExportFlag()
```
