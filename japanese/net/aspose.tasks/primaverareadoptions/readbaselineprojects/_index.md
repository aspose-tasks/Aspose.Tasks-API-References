## PrimaveraReadOptions.ReadBaselineProjects property

ベースライン プロジェクトを読み込むかどうかを指定するフラグを取得または設定します。デフォルト値は true です。

```csharp
public bool ReadBaselineProjects { get; set; }
```

## 備考

このフラグはベースライン プロジェクトを含む Primavera XML ファイルに適用されます（XER 形式ではベースラインはサポートされません）。ベースライン データが不要な場合、大規模プロジェクトの読み込みを高速化するためにオプションを false に設定できます。
