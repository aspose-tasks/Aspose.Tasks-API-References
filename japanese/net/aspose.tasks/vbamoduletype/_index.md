## VbaModuleType enumeration

```csharp
public enum VbaModuleType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| DocumentModule | `0` | ドキュメントに関連付けられた組み込みマクロおよびプログラム的アクセス操作のためのモジュールを指定する VBA プロジェクト項目のタイプです。 |
| ProceduralModule | `1` | サブルーチンと関数のコレクションを含むモジュールです。 |
| ClassModule | `2` | 新しいオブジェクトの定義を含むモジュールです。クラスの各インスタンスは新しいオブジェクトを作成し、モジュールで定義された手続きはオブジェクトのプロパティおよびメソッドになります。 |
| DesignerModule | `3` | プロジェクトに登録された ActiveX コントロールのメソッドとプロパティを拡張するモジュールです。 |
