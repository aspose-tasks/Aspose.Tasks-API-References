## PrimaveraProjectInfo.ExportFlag property

プロジェクトのエクスポートフラグを取得します。Primavera でエクスポート対象として選択されたプロジェクトは ExportFlag が true になります。エクスポート対象として明示的に選択されていないプロジェクトでも、エクスポートされたプロジェクトとの関係により XER ファイルにエクスポートされることがあります。

```csharp
public bool ExportFlag { get; }
```
