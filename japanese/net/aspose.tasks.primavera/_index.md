Primavera 固有のフォーマット (XER、Primavera XML) を扱うために必要なクラスを含みます。

## クラス

| クラス | 説明 |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Primavera フォーマットから読み込まれたプロジェクトに関する簡単な情報を表します。 |
## 列挙体

| 列挙体 | 説明 |
| --- | --- |
| [PrimaveraActivityType](./primaveraactivitytype/) | Primavera アクティビティのタイプを指定します。 |
| [PrimaveraConstraintType](./primaveraconstrainttype/) | アクティビティの制約タイプを指定します。 |
| [PrimaveraDurationType](./primaveradurationtype/) | Primavera アクティビティの期間タイプを指定します。 |
| [PrimaveraPercentCompleteType](./primaverapercentcompletetype/) | Primavera アクティビティの「% 完了タイプ」フィールドの値を指定します。 |
| [PrimaveraRelationshipLagCalendar](./primaverarelationshiplagcalendar/) | Primavera プロジェクトでリレーションシップ遅延をスケジュールする際に使用するカレンダーを指定します。 |
