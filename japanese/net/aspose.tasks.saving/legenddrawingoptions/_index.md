## LegendDrawingOptions enumeration

ビューの凡例を描画する際に使用される可能なオプションを指定します。

```csharp
public enum LegendDrawingOptions
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NoLegend | `0` | 凡例は描画されません。 |
| AfterLastPage | `1` | 凡例は、プロジェクトのページの最終ページの後の別ページに描画されます。 |
| OnEveryPage | `2` | 凡例は各ページに描画されます。 |
| DefinedInView | `3` | 凡例は、描画されたビューの View.PageInfo.Legend.LegendOn プロパティに従って描画されます。 |
