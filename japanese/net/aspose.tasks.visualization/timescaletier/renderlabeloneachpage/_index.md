## TimescaleTier.RenderLabelOnEachPage property

時間期間が複数ページにまたがる場合に、日付ラベルを各ページに描画するかどうかを定義するフラグを取得または設定します。値が 'true' の場合、期間が複数ページにまたがると、期間の日時ラベルが各ページに描画されます。値が 'false' の場合、[`Alignment`](../alignment/) プロパティの値に従って日付ラベルは一度だけ描画されます。

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
