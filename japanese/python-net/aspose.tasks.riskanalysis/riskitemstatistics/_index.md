## RiskItemStatistics class

分析対象プロジェクトのタスクの統計データを格納する項目を表します。

RiskItemStatistics 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| item_type | [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) 列挙体のインスタンスを取得します。 |
| minimum | Monte Carlo シミュレーション中に生成された最小値を取得します。 |
| maximum | Monte Carlo シミュレーション中に生成された最大値を取得します。 |
| expected_value | リスク項目の期待値を取得します。 |
| standard_deviation | リスク項目の標準偏差を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_percentile(percent) | 生成されたサンプルの指定されたパーセンテージが下回る値を取得します。 |
