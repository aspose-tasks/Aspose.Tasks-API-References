## RiskAnalysisSettings class

リスク分析を実行するための設定を指定します。

RiskAnalysisSettings 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| RiskAnalysisSettings() | 新しい [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| iterations_count | Monte Carlo シミュレーションで使用する反復回数を取得または設定します。<br/>            デフォルト値は 100 です。 |
| patterns | [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) クラスのインスタンスを含むコレクションを取得します。 |
