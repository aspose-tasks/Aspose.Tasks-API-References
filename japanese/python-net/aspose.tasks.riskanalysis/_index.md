リスク分析レポートを作成するためのクラスを含みます。

## クラス
| クラス | 説明 |
| :- | :- |
| [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) | リスク分析の結果を表します。 |
| [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) | リスク分析を実行するための設定を指定します。 |
| [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) | 指定されたリスク分析設定に基づいてモンテカルロシミュレーションを実行します。 |
| [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) | 分析対象プロジェクトのタスクの統計データを格納する項目を表します。 |
| [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) | [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) クラスのインスタンスを含むコレクションを表します。 |
| [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) | プロジェクトタスクのリスクパターンを表します。 |
| [RiskPatternCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskpatterncollection/) | [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) クラスのインスタンスを含むコレクションを表します。 |
## 列挙型
| 列挙 | 説明 |
| :- | :- |
| [ConfidenceLevel](/tasks/python-net/aspose.tasks.riskanalysis/confidencelevel/) | リスク分析で使用されるサポートされている信頼レベルを指定します。<br/>            実際の値が楽観的および悲観的な見積もりの範囲内にある時間の割合に対応します。 |
| [ProbabilityDistributionType](/tasks/python-net/aspose.tasks.riskanalysis/probabilitydistributiontype/) | サポートされている確率分布のタイプを指定します。 |
| [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) | リスク分析中に統計情報が収集されるタスクフィールドを指定します。 |
