## RiskAnalyzer class

指定されたリスク分析設定に基づいてモンテカルロシミュレーションを実行します。

RiskAnalyzer 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| RiskAnalyzer(settings) | 新しい [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| settings | リスク分析に必要な設定を定義する [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) クラスのインスタンスを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| analyze(project) | 指定されたプロジェクトのリスク分析を実行します。分析はモンテカルロシミュレーションに基づき、結果は [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) クラスのインスタンスです。 |
