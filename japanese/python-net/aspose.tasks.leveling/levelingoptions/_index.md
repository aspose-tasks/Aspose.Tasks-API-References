## LevelingOptions class

リソースレベリングのパラメーターを指定できます。

LevelingOptions 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| LevelingOptions() | 新しい [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| start_date | レベリング期間の開始日を取得または設定します。デフォルト値はプロジェクトの開始日です。 |
| finish_date | レベリング期間の終了日を取得または設定します。デフォルト値はプロジェクトの終了日です。 |
| リソース | レベリング対象となるリソースのリストを取得または設定します。null が設定された場合、すべてのプロジェクトリソースがレベリングされます。 |
| leveling_order | レベリングアルゴリズムが過剰割り当てされたタスクを遅延させる順序を取得します。<br/>            全体割り当てを引き起こすタスクと遅延可能なタスクを特定した後、どのタスクを最初に遅延させるかを示す指定された順序が使用されます。 |
| message_level | リソースレベリング中に Aspose.Tasks が出力するログメッセージのレベルを取得または設定します。 |
| message_handler | リソースレベリング中に Aspose.Tasks が生成するログメッセージをインターセプトできるメッセージハンドラコールバックを取得または設定します。 |
