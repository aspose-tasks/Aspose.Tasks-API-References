## LevelingOrder enumeration

レベリング順序の可能な値を定義します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| STANDARD | 考慮されるプロパティは次のとおりです：前任タスクの関係、総スラック（総スラックが大きいタスクが最初に遅延します）、開始日、優先度。<br/>            これがデフォルト値です。 |
| ID_ONLY | タスクは ID の昇順で遅延されます。 |
| PRIORITY_THEN_STANDARD | まず優先度が考慮され、次に Standard と同じプロパティが適用されます。 |
