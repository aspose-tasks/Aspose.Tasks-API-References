## Spreadsheet2003SaveOptions class

プロジェクトページを Spreadsheet2003 にレンダリングする際に、追加オプションを指定できます。

Spreadsheet2003SaveOptions 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| Spreadsheet2003SaveOptions() | 新しい [Spreadsheet2003SaveOptions](/tasks/python-net/aspose.tasks.saving/spreadsheet2003saveoptions/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| save_format | この保存オプションオブジェクトが使用された場合に、ドキュメントが保存される形式を取得または設定します。 |
| resource_view | レンダリングするリソースビュー列のリストを取得または設定します ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | レンダリングする割り当てビュー列のリストを取得または設定します ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| view | 保存するビュー列のリストを取得または設定します ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/))。<br/>            設定されていない場合はデフォルト列が保存されます。 |
