## SaveTemplateOptions class

プロジェクトをテンプレートとして保存する際に、追加オプションを指定できます。

SaveTemplateOptions 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| SaveTemplateOptions() | SaveTemplateOptions クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| remove_actual_values | プロジェクトテンプレートからすべての実際の値を削除するかどうかを示す値を取得または設定します。 |
| remove_baseline_values | プロジェクトテンプレートからすべてのベースライン値を削除するかどうかを示す値を取得または設定します。 |
| remove_fixed_costs | プロジェクトテンプレートからすべての固定費用を削除するかどうかを示す値を取得または設定します。 |
| remove_resource_rates | プロジェクトテンプレートからリソースレートを削除するかどうかを示す値を取得または設定します。 |
