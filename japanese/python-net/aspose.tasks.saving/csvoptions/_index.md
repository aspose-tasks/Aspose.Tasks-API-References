## CsvOptions class

プロジェクトを CSV に保存する際に、追加オプションを指定できます。

CsvOptions 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| CsvOptions() | [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) クラスの新しいインスタンスを初期化します。このインスタンスはプロジェクトを CSV 形式で保存するために使用できます。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| save_format | この保存オプションオブジェクトが使用された場合に、ドキュメントが保存される形式を取得または設定します。 |
| data_category | 保存するデータカテゴリを取得または設定します。 |
| エンコーディング | CSV を保存する際のエンコーディングを取得または設定します。 |
| include_headers | ヘッダーを含めるかどうかを示す値を取得または設定します（デフォルト値は TRUE）。 |
| text_delimiter | テキスト区切り文字を取得または設定します。 |
| view | XLSX 形式で保存するためのビュー列のリスト（[GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)）を取得または設定します。<br/>            設定されていない場合は、デフォルトの列が保存されます。 |
