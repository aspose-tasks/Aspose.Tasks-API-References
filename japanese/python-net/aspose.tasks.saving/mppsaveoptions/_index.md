## MPPSaveOptions class

プロジェクトデータを MPP に保存する際に、追加オプションを指定できます。

MPPSaveOptions 型は次のメンバーを公開します。
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| MPPSaveOptions() | 新しい [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| save_format | この保存オプションオブジェクトが使用された場合に、ドキュメントが保存される形式を取得または設定します。 |
| remove_invalid_assignments | MPP に保存する際に無効なリソース割り当てを削除するかどうかを示す値を取得または設定します。 |
| write_view_data | プロジェクトを MPP 形式で保存する際にビュー データを書き込むかどうかを示す値を取得または設定します。 |
| write_filters | プロジェクトを MPP 形式で保存する際にフィルタ データを書き込むかどうかを示す値を取得または設定します。 |
| write_groups | プロジェクトを MPP 形式で保存する際にグループ データを書き込むかどうかを示す値を取得または設定します。 |
| clear_vba | プロジェクトを MPP 形式で保存する際に既存の VBA マクロ データを削除するかどうかを示す値を取得または設定します。 |
| write_vba | MPP ファイル内の既存の VBA マクロ データを更新するかどうかを示す値を取得または設定します。<br/>            現在、VbaModule.SourceCode の書き込みがサポートされています。 |
| protection_password | 結果として生成される MPP ファイルを保護するために使用されるパスワードを取得または設定します。現在、MS Project 2010 以降の形式でサポートされています。 |
