## SimpleSaveOptions class

これは、プロジェクトを特定の形式で保存する際にユーザーが基本オプションを指定できる抽象基底クラスです。

SimpleSaveOptions 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| save_format | この保存オプションオブジェクトが使用された場合に、ドキュメントが保存される形式を取得または設定します。 |
