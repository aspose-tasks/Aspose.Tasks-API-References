## PageSavingArgs class

このクラスは、ドキュメントのページをストリームに保存することに関連するデータのセットを表します。

PageSavingArgs 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| page_number | 書き込まれるページ番号を取得します。 |
| keep_stream_open | ページが書き込まれた後に、レンダリングルーチンが[stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) を開いたままにするかどうかを示す値を取得または設定します。 |
| stream | ページを書き込むためのストリームを取得または設定します。 |
