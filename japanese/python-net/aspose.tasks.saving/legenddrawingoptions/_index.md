## LegendDrawingOptions enumeration

ビューの凡例をレンダリングする際に使用される可能なオプションを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NO_LEGEND | 凡例は描画されません。 |
| AFTER_LAST_PAGE | 凡例は、プロジェクトのページの最終ページの後の別ページに描画されます。 |
| ON_EVERY_PAGE | 凡例はすべてのページに描画されます。 |
| DEFINED_IN_VIEW | 凡例は、レンダリングされたビューの View.PageInfo.Legend.LegendOn プロパティに従って描画されます。 |
