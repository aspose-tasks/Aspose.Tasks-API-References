## PrimaveraSaveOptions class

プロジェクトを Primavera XER 形式で保存する際に、追加オプションを指定できます。

PrimaveraSaveOptions 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PrimaveraSaveOptions() | 新しい [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| save_format | この保存オプションオブジェクトが使用された場合に、ドキュメントが保存される形式を取得または設定します。 |
| activity_id_increment | アクティビティ ID の再番号付けに使用される増分を取得または設定します。 |
| activity_id_prefix | アクティビティ ID の再番号付けに使用されるプレフィックスを取得または設定します。 |
| activity_id_suffix | アクティビティ ID の再番号付けに使用されるサフィックスを取得または設定します。 |
| renumber_activity_ids | アクティビティ ID を再番号付けする必要があるかどうかを示す値を取得または設定します。 |
| skip_summary_assignments | エクスポート時にリソースのサマリータスクへの割り当てをスキップするかどうかを示す値を取得または設定します。 |
