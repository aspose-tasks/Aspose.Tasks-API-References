## XlsxOptions class

プロジェクトページを XLSX にレンダリングする際に、追加オプションを指定できます。

XlsxOptions 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| XlsxOptions() | XLSX 形式でプロジェクトを保存するために使用できる [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| save_format | この保存オプションオブジェクトが使用された場合に、ドキュメントが保存される形式を取得または設定します。 |
| resource_view | レンダリングするリソースビュー列のリストを取得または設定します ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | レンダリングする割り当てビュー列のリストを取得または設定します ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| エンコーディング | 生成された XLSX ファイルのエンコーディングを取得または設定します。デフォルト値は . です。 |
| view | XLSX 形式で保存するためのビュー列のリスト（[GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)）を取得または設定します。<br/>            設定されていない場合は、デフォルトの列が保存されます。 |
