Primavera 固有のフォーマット（XER、Primavera XML）を扱うために必要なクラスを含みます。

## クラス
| クラス | 説明 |
| :- | :- |
| [PrimaveraProjectInfo](/tasks/python-net/aspose.tasks.primavera/primaveraprojectinfo/) | Primavera 形式から読み込まれたプロジェクトに関する簡易情報を表します。 |
## 列挙型
| 列挙 | 説明 |
| :- | :- |
| [PrimaveraActivityType](/tasks/python-net/aspose.tasks.primavera/primaveraactivitytype/) | Primavera アクティビティのタイプを指定します。 |
| [PrimaveraConstraintType](/tasks/python-net/aspose.tasks.primavera/primaveraconstrainttype/) | アクティビティの制約のタイプを指定します。 |
| [PrimaveraDurationType](/tasks/python-net/aspose.tasks.primavera/primaveradurationtype/) | Primavera アクティビティの期間タイプを指定します。 |
| [PrimaveraPercentCompleteType](/tasks/python-net/aspose.tasks.primavera/primaverapercentcompletetype/) | Primavera アクティビティの「% 完了タイプ」フィールドの値を指定します。 |
| [PrimaveraRelationshipLagCalendar](/tasks/python-net/aspose.tasks.primavera/primaverarelationshiplagcalendar/) | Primavera プロジェクトで関係遅延をスケジュールする際に使用するカレンダーを指定します。 |
