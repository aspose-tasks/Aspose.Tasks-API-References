## PrimaveraProjectInfo class

Primavera 形式から読み込まれたプロジェクトに関する簡易情報を表します。

PrimaveraProjectInfo 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| uid | プロジェクトの Uid を取得します。 |
| name | プロジェクトの名前を取得します。 |
| short_name | プロジェクトの短縮名（Project ID）を取得します。 |
| export_flag | プロジェクトのエクスポートフラグを取得します。Primavera でエクスポート対象としてプロジェクトが選択された場合、ExportFlag は true になります。<br/>            明示的にエクスポート対象として選択されていないプロジェクトでも、エクスポート対象プロジェクトとの関係により XER ファイルにエクスポートされることがあります。 |
