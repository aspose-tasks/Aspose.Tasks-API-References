## ViewColumn class

プロジェクトビューの列を表します。

ViewColumn 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| field | 列フィールドを取得または設定します。<br/>            [field](/tasks/python-net/aspose.tasks.visualization/viewcolumn/)。 |
| name | 列名を取得します。 |
| string_alignment | テキストの配置を取得または設定します（[HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/) 列挙体のいずれかの値にできます）。 |
| width | 列の幅を取得します。 |
| text_style_modification_callback | 列のセルの外観をカスタマイズするために使用できるコールバックを取得または設定します。 |
