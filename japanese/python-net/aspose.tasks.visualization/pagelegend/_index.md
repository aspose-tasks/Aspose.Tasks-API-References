## PageLegend class

プロジェクト印刷に使用されるページ凡例を表します。

PageLegend 型は以下のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PageLegend() | PageLegend クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| left_text | 親要素に表示する左揃えテキストを取得または設定します。 |
| centered_text | 親要素に表示する中央揃えテキストを取得または設定します。 |
| right_text | 親要素に表示する右揃えテキストを取得または設定します。 |
| left_image | 親要素に表示される左揃え画像を取得または設定します。 |
| centered_image | 親要素に表示される中央揃え画像を取得または設定します。 |
| right_image | 親要素に表示される右揃えの画像を取得または設定します。 |
| left_image_size | 左画像の表示サイズを取得または設定します。 |
| centered_image_size | 中央画像の表示サイズを取得または設定します。 |
| right_image_size | 右画像の表示サイズを取得または設定します。 |
| legend_on | 凡例が表示されるページを取得または設定します。 [Legend](/tasks/python-net/aspose.tasks.visualization/legend/) 列挙体の値のいずれかにすることができます。 |
| width | 凡例の左側部分（デフォルトでプロジェクト名と日付が含まれます）の幅をセンチメートル単位で取得または設定します。 |
