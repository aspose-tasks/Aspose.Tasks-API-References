## TaskTextStyleEventArgs class

このクラスは、テーブルセルのコンテンツのレンダリングに関連するデータのセットを表します。

TaskTextStyleEventArgs 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| cell_text_style | セルの内容を描画するために使用される TextStyle を取得または設定します。このオブジェクトはテーブルセルの外観をカスタマイズするために使用できます。 |
| task | 現在描画されている行に対応する [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) を取得します。 |
| column | 現在描画されているセルが属する [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) を取得します。 |
