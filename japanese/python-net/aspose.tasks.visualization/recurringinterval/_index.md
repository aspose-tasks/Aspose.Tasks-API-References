## RecurringInterval class

ガントチャートビューの進捗ラインで使用される繰り返し間隔を表します。

RecurringInterval 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| RecurringInterval() | RecurringInterval クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| interval | 定期的な間隔を取得または設定します。<br/>            任意の [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/) 型の値にできます。 |
| daily_day_number | 日次の日番号を取得または設定します。 |
| daily_workday | 日次の進捗ラインに対して、その日が稼働日かどうかを示す値を取得または設定します。 |
| weekly_week_number | 週次進捗ラインの週番号を取得または設定します。 |
| monthly_day | 日単位で月次進捗ラインを表示するかどうかを示す値を取得または設定します。 |
| monthly_day_day_number | 月次進捗ラインの日番号を取得または設定します。 |
| monthly_day_month_number | 月次進捗ラインの月番号を取得または設定します。 |
| monthly_first_last | 最初または最後の事前定義された日で進捗ラインを表示するかどうかを示す値を取得または設定します。 |
| monthly_first_last_month_number | 最初または最後の事前定義された日で表示される進捗ラインの月番号を取得または設定します。 |
| monthly_first_last_day | 月次進捗ラインの最初または最後の日タイプを取得または設定します。 |
| weekly_days | 週次進捗ラインの日リストを取得します。 |
