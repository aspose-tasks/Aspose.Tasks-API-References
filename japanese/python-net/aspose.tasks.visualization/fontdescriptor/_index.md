## FontDescriptor class

フォント情報を表します。

FontDescriptor 型は次のメンバーを公開します。
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| FontDescriptor(font_family, size) | FontDescriptor クラスの新しいインスタンスを初期化します。 |
| FontDescriptor(font_family, size, style) | FontDescriptor クラスの新しいインスタンスを初期化します。 |
| FontDescriptor(font, style) | 指定されたフォントファミリー、サイズ、スタイルで [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| font_family | フォントファミリーの名前を取得します。 |
| size | フォントのサイズを取得します。 |
| style | フォントのスタイルを取得します。 |
