## VisualObjectPlacement class

ビュー内の[OleObject](/tasks/python-net/aspose.tasks/oleobject/)の配置と外観を表します。

VisualObjectPlacement 型は以下のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| VisualObjectPlacement() | 新しい [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| ole_object_id | [OleObject](/tasks/python-net/aspose.tasks/oleobject/) オブジェクトの Id を取得または設定します。 |
| task_id | 'Attach to task' オプションが選択されている場合はタスクの Id を取得または設定し、そうでない場合は -1 を設定します。 |
| width | ビジュアルオブジェクトの表示幅を取得または設定します。 |
| height | ビジュアルオブジェクトの表示高さを取得または設定します。 |
| vertical_offset | ビジュアルオブジェクトの垂直オフセットを取得または設定します。 |
| horizontal_offset | ビジュアルオブジェクトの水平オフセットを取得または設定します。 |
| timescale_date | 'Attach to timescale' オプションが選択されている場合のビジュアルオブジェクトの日時配置を取得または設定します。 |
| attachment_point | 'Attach to task' オプションが選択されている場合のタスクに対するビジュアルオブジェクトの配置を取得または設定します。 |
| border_line_color | 境界線の色を取得または設定します。 |
| border_line_thickness | 境界線の太さを取得または設定します（許容値は 0〜5 です）。 |
| fill_color | 塗りつぶしの色を取得または設定します。 |
| fill_pattern | 塗りつぶしパターンを取得または設定します。 |
