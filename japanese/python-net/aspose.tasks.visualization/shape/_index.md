## Shape enumeration

ビュー データを [SaveFileFormat](/tasks/python-net/aspose.tasks.saving/savefileformat/) のいくつかに保存する際にレンダリングされる、バー スタイルの開始または終了にあるマーカーの形状。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | なし形状を示す。 |
| VERTICAL_LINE | 垂直線形状を示す。 |
| PENTAGON | 五角形を示す。 |
| TRIANGLE | 三角形を示す。 |
| LEFT_BRACKET | 左括弧形状を示す。 |
| RIGHT_BRACKET | 右括弧形状を示す。 |
| ARROW_DOWN | ArrowDown シェイプを示します。 |
| LEFT_FADE | Left フェード シェイプを示します。 |
| RIGHT_FADE | Right フェード シェイプを示します。 |
| DIAMOND | Diamond シェイプを示します。 |
| CIRCLE | Circle シェイプを示します。 |
