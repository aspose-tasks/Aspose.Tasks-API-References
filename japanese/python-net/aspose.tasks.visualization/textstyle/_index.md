## TextStyle class

プロジェクトビューの項目のテキストの視覚スタイルを変更します。

TextStyle 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| TextStyle() | デフォルト設定で [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) クラスの新しいインスタンスを初期化します。 |
| TextStyle(font_size, font_style) | TextStyle クラスの新しいインスタンスを初期化します。 |
| TextStyle(font_style) | デフォルトフォントと指定されたフォントサイズおよびスタイルで [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) クラスの新しいインスタンスを初期化します。 |
| TextStyle(font) | 指定されたフォント設定で [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| font | テキストスタイルのフォントを取得または設定します。 |
| color | テキストの色を取得または設定します。 |
| item_type | テキストスタイルの [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) を取得または設定します。 |
| background_pattern | テキストスタイルの背景パターンを取得または設定します。<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/)。 |
| background_color | テキストスタイルの背景色を取得または設定します。<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/)。 |
