## TimescaleUnit enumeration

ガントチャートまたはその他の時間フェーズビューにおけるタイムスケールの任意の層の時間単位を指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | なしを示します。タイムスケール層は非表示です。 |
| MINUTES | 分のタイムスケール単位を示します。 |
| HOURS | Hours タイムスケール単位を示します。 |
| DAYS | Days タイムスケール単位を示します。 |
| WEEKS | Weeks タイムスケール単位を示します。 |
| THIRDS_OF_MONTHS | Thirds of months タイムスケール単位を示します。 |
| MONTHS | Months タイムスケール単位を示します。 |
| QUARTERS | Quarters of years タイムスケール単位を示します。 |
| HALF_YEARS | Half years タイムスケール単位を示します。 |
| YEARS | Years タイムスケール単位を示します。 |
