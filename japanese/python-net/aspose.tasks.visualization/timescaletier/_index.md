## TimescaleTier class

ガントチャートのタイムスケールの単一層を表します。

TimescaleTier 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| TimescaleTier() | 新しい [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) クラスのインスタンスを初期化します。 |
| TimescaleTier(unit, count) | TimescaleTier クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| count | 階層のラベルを表示する時間単位間隔を取得または設定します。<br/>            デフォルト値は 1 です。 |
| label | タイムスケール階層の日時ラベル [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) を取得または設定します。 |
| alignment | 階層の各時間期間内でラベルをどのように配置するかを取得または設定します（[HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)）。 |
| uses_fiscal_year | 階層ラベルを会計年度に基づくかどうかを示す値を取得または設定します。 |
| show_ticks | 階層内の時間期間を区切る目盛りを表示するかどうかを示す値を取得または設定します。 |
| unit | タイムスケール階層のタイムスケール単位 [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) を取得または設定します。<br/>            デフォルト値は |
| render_label_on_each_page | 時間期間が複数ページにまたがる場合に、各ページに日付ラベルを描画するかどうかを定義するフラグを取得または設定します。<br/>            値が 'true' の場合、時間期間が複数ページにまたがると、期間の日時ラベルが各ページに描画されます。<br/>            値が 'false' の場合、[alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/) プロパティの値に従って日付ラベルは一度だけ描画されます。 |
