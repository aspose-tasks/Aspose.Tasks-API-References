## BarShape enumeration

バー矩形の形状です。

## Members
| メンバー名 | 説明 |
| :- | :- |
| FULL | Full 長方形バー形状を示します。 |
| HALF_HEIGHT | 上揃えの半高さ長方形バー形状を示します。 |
| HALF_HEIGHT_BOTTOM | 下揃えの半高さ長方形バー形状を示します。 |
| THIN | 中央揃えのライン形状を示します。 |
| NONE | バー形状がなしであることを示します。 |
| MIDDLE | 中央揃えのライン形状を示します。 |
| LINE_BOTTOM | 下揃えのライン形状を示します。 |
| LINE_TOP | 上揃えのライン形状を示します。 |
