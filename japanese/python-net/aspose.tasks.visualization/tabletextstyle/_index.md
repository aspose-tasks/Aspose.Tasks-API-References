## TableTextStyle class

ビューのテーブル内のテキストスタイルを表します。

TableTextStyle 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| TableTextStyle(row_uid) | TableTextStyle クラスの新しいインスタンスを初期化します |
| TableTextStyle(row_uid, font) | TableTextStyle クラスの新しいインスタンスを初期化します |
| TableTextStyle(row_uid, font_size, font_style) | TableTextStyle クラスの新しいインスタンスを初期化します |
| TableTextStyle(row_uid, font_style) | TableTextStyle クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| font | テキストスタイルのフォントを取得または設定します。 |
| color | テキストの色を取得または設定します。 |
| item_type | [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) 列挙体の値を返します。 |
| background_pattern | テキストスタイルの背景パターンを取得または設定します。<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/)。 |
| background_color | テキストスタイルの背景色を取得または設定します。<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/)。 |
| row_uid | 行の一意の ID を取得します。 |
| field | スタイルが適用されるフィールドを取得または設定します。<br/>            [field](/tasks/python-net/aspose.tasks.visualization/tabletextstyle/). |
