## ReportType enumeration

プロジェクトのグラフィカルレポートのタイプ。

## Members
| メンバー名 | 説明 |
| :- | :- |
| PROJECT_OVERVIEW | プロジェクトの開始日と終了日、<br/>            完了した期間の割合、上位タスクの完了率、そして今後のマイルストーンを表示します。 |
| COST_OVERVIEW | プロジェクトの開始日と終了日、現在の<br/>            予定コストと残りコスト、上位タスクの完了率とコスト値を表示します。 |
| WORK_OVERVIEW | 各上位タスクのベースライン、実績、残り作業量と、作業リソースの作業量を表示します。 |
| RESOURCE_OVERVIEW | リソースごとのベースライン、実績、残り作業量を表示します。 |
| RESOURCE_COST_OVERVIEW | リソースごとのベースライン、実績、残りコストを表示します。 |
| CRITICAL_TASKS | 重要なプロジェクトタスクを表示します。 |
| LATE_TASKS | 遅延しているプロジェクトタスクを表示します。 |
| MILESTONES | 遅延している、今後の、完了したマイルストーンを表示します。 |
| UPCOMING_TASK | 現在の週に期限があるタスクと、現在の週に開始するタスクを表示します。 |
| COST_OVERRUNS | タスクとリソースごとのコスト差異を表示します。 |
| TASK_COST_OVERVIEW | すべてのトップレベルタスクのベースライン、実績、残りのコストを表示します。 |
| OVERALLOCATED_RESOURCES | 過剰割り当てされたリソースの残り作業時間数を表示します。 |
| SLIPPING_TASKS | ベースラインの終了日を過ぎて完了予定のタスクを表示します（ベースラインが設定されている必要があります）。 |
| BEST_PRACTICE_ANALYZER | 実作業がないタスク、割り当てられていないタスク、<br/>            所要時間が8時間未満のタスク、およびリソースに割り当てられたサマリーを表示します。 |
| BURNDOWN | 作業バーンダウンとタスクバーンダウンのチャートが含まれます。<br/>            作業バーンダウンチャートは、メンバーが完了した作業量、プロジェクト完了日までに完了予定の作業量、<br/>            そしてこの時点でプロジェクトで完了すると見込まれる作業量のベースライン推定を示します。<br/>            タスクバーンダウンチャートは、完了したタスク数、残りのタスク数、<br/>            そしてこの時点で完了すると見込まれるタスク数のベースライン推定を示します。 |
| CASH_FLOW | すべてのトップレベルタスクの四半期ごとのコストと累積コストを表示します。 |
