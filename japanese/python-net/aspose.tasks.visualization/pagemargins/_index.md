## PageMargins class

印刷用のページ余白を表します。

PageMargins 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PageMargins() | PageMargins クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| top | 上余白のサイズ（センチメートル）を取得または設定します。 |
| bottom | 下余白のサイズ（センチメートル）を取得または設定します。 |
| left | 左余白のサイズ（センチメートル）を取得または設定します。 |
| right | 右余白のサイズをセンチメートル単位で取得または設定します。 |
| borders | 罫線を印刷する位置を取得または設定します。 [Border](/tasks/python-net/aspose.tasks.visualization/border/) 列挙体の値のいずれかにすることができます。 |
