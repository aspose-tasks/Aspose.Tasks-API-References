## TimescaleFitBehavior enumeration

タイムスケール領域をページ幅に合わせるために使用される動作を表します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| DEFINED_IN_VIEW | カレンダー セクションは、レンダリングされたビューの View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage プロパティに従って描画されます。 |
| NO_SCALE_TO_END_DATE | カレンダー セクションは EndDate まで正確に描画されます。ページに空白があってもです。 |
| NO_SCALE_TO_END_OF_PAGE | カレンダー セクションは最終ページの末尾（右側）まで描画されます。<br/>            そのため、最後に描画された日付が EndDate を超える場合があります。 |
| SCALE_TO_END_OF_PAGE | レンダリング エンジンは、EndDate が最終ページの末尾（右側）に合わせるように日付を調整しようとします。<br/>            これは、MS Project の「ページ設定 \ 表示 \ タイムスケールをページの末尾に合わせる」オプションが有効になっていることに相当します。 |
