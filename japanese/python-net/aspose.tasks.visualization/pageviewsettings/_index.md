## PageViewSettings class

プロジェクトビューの印刷設定を表します。

PageViewSettings 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PageViewSettings() | PageViewSettings クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| first_columns_count | すべてのページに印刷される最初の列の数を取得または設定します。 |
| fit_timescale_to_end_of_page | 印刷時にタイムスケールをページの末尾に合わせるかどうかを示す値を取得または設定します。 |
| print_all_sheet_columns | ビューのすべてのシート列を印刷するかどうかを示す値を取得または設定します。 |
| print_blank_pages | ビューの空白ページを印刷するかどうかを示す値を取得または設定します。 |
| print_first_columns_count_on_all_pages | すべてのページに指定された数の最初の列を印刷するかどうかを示す値を取得または設定します。 |
| print_notes | ノートを印刷するかどうかを示す値を取得または設定します。 |
