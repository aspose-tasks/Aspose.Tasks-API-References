## HorizontalStringAlignment enumeration

テキスト文字列がそのレイアウト矩形に対してどのように配置されるかを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NEAR | テキストをレイアウトの近くに配置することを指定します。左から右へのレイアウトでは、近い位置は左になります。右から左へのレイアウトでは、近い位置は右になります。 |
| CENTER | テキストがレイアウト矩形の中央に配置されることを指定します。 |
| FAR | テキストをレイアウト矩形の原点位置から遠くに配置することを指定します。左から右へのレイアウトでは、遠い位置は右になります。右から左へのレイアウトでは、遠い位置は左になります。 |
