## ProgressLines class

ガントチャートビューの進捗ラインを表します。

ProgressLines 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| ProgressLines() | ProgressLines クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| display_at_current_date | 現在の日付に進捗ラインを表示するかどうかを示す値を取得または設定します。 |
| display_at_recurring_intervals | 定期的な間隔で進捗ラインを表示するかどうかを示す値を取得または設定します。 |
| recurring_interval | 定期的な間隔を取得または設定します。<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | プロジェクト開始日の開始時点から進捗ラインを表示するかどうかを示す値を取得または設定します。 |
| begin_at_date | 進捗ラインを表示する開始日を取得または設定します。 |
| display_selected | 選択された日付で進捗ラインを表示するかどうかを示す値を取得または設定します。 |
| is_baseline_plan | ベースライン計画または実績の進捗ラインを表示するかどうかを示す値を取得または設定します。 |
| show_date | 各進捗ラインの日付を表示するかどうかを示す値を取得または設定します。 |
| date_format | 日付形式を取得または設定します ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | 進捗ラインラベルに使用されるフォントを取得または設定します。 |
| line_pattern | 現在の進捗ラインの線パターンを取得または設定します。<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | 現在の進捗ラインの線の色を取得または設定します。 |
| progress_point_shape | 進捗ポイントの形状を取得または設定します。<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | 進捗ポイントの色を取得または設定します。 |
| other_line_pattern | 他の進捗ラインの線パターンを取得または設定します。 |
| other_line_color | 他の進捗ラインの色を取得または設定します。 |
| other_progress_point_shape | 他の進捗ラインの進捗ポイントの形状を取得または設定します。 |
| other_progress_point_color | 他の進捗ポイントの色を取得または設定します。 |
| selected_dates | 進捗ラインを表示するために選択された日付の一覧を取得します。 |
