## Gridlines class

GanttChart ビューに表示されるグリッドラインを表します。

Gridlines 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| Gridlines() | Gridlines クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| interval | グリッドライン間の間隔を指定する 0 から 99 の数値を取得または設定します。 |
| interval_color | 二次グリッドラインの色を取得または設定します。 |
| interval_pattern | 二次グリッドラインの線パターンを取得または設定します。 |
| normal_color | 通常のグリッドラインの色を取得または設定します。 |
| normal_pattern | 通常のグリッドラインの線パターンを取得または設定します。 |
| type | グリッドラインの種類を取得または設定します。 |
