## ResourceViewColumn class

ResourceUsage ビューと ResourceSheet ビューで使用されるプロジェクトのビュークラスです。

ResourceViewColumn 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| ResourceViewColumn(width, field) | ResourceViewColumn クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| field | 列フィールド。 <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)。 |
| name | 列名を取得します。 |
| string_alignment | テキストの配置を取得または設定します（[HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/) 列挙体のいずれかの値にできます）。 |
| width | 列の幅を取得します。 |
| text_style_modification_callback | 列のセルの外観をカスタマイズするために使用できるコールバックを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_column_text(resource) | 現在のリソースを列テキストに変換します。 |
