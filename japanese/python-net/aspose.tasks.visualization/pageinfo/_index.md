## PageInfo class

印刷に使用され、MPP ファイル形式に存在するページ設定データを表します。

PageInfo 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PageInfo() | 新しい [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) クラスのインスタンスを初期化します。 <br/>            MPP ファイル形式に存在し、印刷に使用されるページ設定データを表します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| header | ヘッダー データを表す [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) クラスのインスタンスを取得または設定します。 |
| footer | フッター データを表す [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) クラスのインスタンスを取得または設定します。 |
| name | 設定データが使用されるビューの名前を取得します。 |
| page_settings | [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) クラスのインスタンスを取得します。このクラスはページ印刷設定を指定します。 |
| page_view_settings | [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) クラスのインスタンスを取得します。このクラスはページビュー印刷設定を指定します。 |
| margins | [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) クラスのインスタンスを取得します。このクラスはページ余白を指定します。 |
| legend | [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) クラスのインスタンスを取得または設定します。このクラスはページ凡例の描画オプションを指定します。 |
