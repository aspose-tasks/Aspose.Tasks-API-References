## BarStyle class

プロジェクトビュー内の項目のバーのビジュアルスタイルを変更します。

BarStyle 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| BarStyle() | 新しい [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| bar_color | バー スタイルの aspose.pydrawing.Color を取得または設定します。 |
| start_shape_color | バーの開始位置にある形状の aspose.pydrawing.Color を取得または設定します。 |
| start_shape_type | 開始形状のタイプを取得または設定します。 |
| end_shape_color | バーの終了位置にある形状の aspose.pydrawing.Color を取得または設定します。 |
| end_shape_type | 終端形状のタイプを取得または設定します。<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/)。 |
| item_type | バー スタイルの [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) を取得または設定します。 |
| bar_shape | バー スタイルの [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) を取得または設定します。 |
| start_shape | バーの開始位置にある [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) を取得または設定します。 |
| end_shape | バーの終了位置にある [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) を取得または設定します。 |
| text_style | バーのテキストのスタイルを取得または設定します。 |
| left_field | バーの左側に表示されるフィールドを取得または設定します。 |
| top_field | バーの上側に表示されるフィールドを取得または設定します。 |
| right_field | バーの右側に表示されるフィールドを取得または設定します。 |
| bottom_field | バーの下部に表示されるフィールドを取得または設定します。 |
| inside_field | バーの内部に表示されるフィールドを取得または設定します。 |
| from_address | ガントバーの開始点位置を取得または設定します。<br/>            [Field](/tasks/python-net/aspose.tasks/field/)。 |
| to | ガントバーの終了点位置を取得または設定します。 |
