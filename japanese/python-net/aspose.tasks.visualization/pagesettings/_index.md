## PageSettings class

プロジェクトビューのページの印刷設定を表します。

PageSettings 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PageSettings() | [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/) クラスの新しいインスタンスを初期化します。<br/>            プロジェクトビューのページの印刷設定を表します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_portrait | ページの向きが縦向きかどうかを示す値を取得または設定します。横向きの場合は false が返されます。 |
| adjust_to_percent_of_normal_size | 印刷を通常サイズの指定パーセンテージ（[percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)）に調整するかどうかを示す値を取得または設定します。 |
| percent_of_normal_size | 印刷を調整するための標準サイズのパーセンテージを取得または設定します。 |
| pages_in_width | 印刷する幅方向のページ数を取得または設定します。 |
| pages_in_height | 印刷する高さ方向のページ数を取得または設定します。 |
| paper_size | 用紙サイズを取得または設定します。 [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/) 列挙体のいずれかの値にすることができます。 |
| paper_size_id | PrinterPaperSize の値のいずれか、またはカスタムページサイズ ID を表す整数を取得または設定します。<br/> この値は OS 設定から PaperSize を取得するために使用できます |
| first_page_number | 印刷する最初のページ番号を取得または設定します。 |
