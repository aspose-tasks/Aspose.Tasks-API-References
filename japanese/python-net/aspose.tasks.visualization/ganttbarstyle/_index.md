## GanttBarStyle class

Gantt チャートビューで MSP が使用するバー スタイルを表します。

GanttBarStyle 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| GanttBarStyle() | [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| bottom_field | バーの下部に表示されるデータを取得または設定します。<br/>            [Field](/tasks/python-net/aspose.tasks/field/)。 |
| end_shape | バーの終端形状を取得または設定します。 |
| end_shape_color | 終端形状の色を取得または設定します。 |
| end_shape_type | 終端形状のタイプを取得または設定します。<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/)。 |
| from_address | ガントバーの開始点位置を取得または設定します。<br/>            [Field](/tasks/python-net/aspose.tasks/field/)。 |
| inside_field | バー内部に表示されるデータを取得または設定します。<br/>            [Field](/tasks/python-net/aspose.tasks/field/)。 |
| left_field | バーの左側に表示されるデータを取得または設定します。<br/>            [Field](/tasks/python-net/aspose.tasks/field/)。 |
| middle_fill_pattern | ガントバーの塗りつぶしパターンを取得または設定します。 |
| middle_shape | バーの中間形状を取得または設定します。 |
| middle_shape_color | 中間形状の色を取得または設定します。 |
| name | スタイルの名前を取得または設定します。 |
| right_field | バーの右側に表示されるデータを取得または設定します。<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| row | 行番号を取得または設定します。 |
| show_for_categories | スタイルが適用されるタスクカテゴリを取得または設定します。Gantt チャートのバーの親（または共通）スタイルに適用可能です<br/>            (see [bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| show_for_task_uid | スタイルが適用されるタスクのユニーク ID を取得または設定します。Gantt チャートのタスク固有のバーのスタイルに適用可能です (see [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | バーの開始形状を取得または設定します。 |
| start_shape_color | 開始形状の色を取得または設定します。 |
| start_shape_type | 開始形状のタイプを取得または設定します。 |
| to | ガントバーの終了点位置を取得または設定します。 |
| top_field | バーの上部に表示されるデータを取得または設定します。 |
| parent_style | カスタムタスク固有スタイルの親（または共通）スタイルを取得または設定します。 |
