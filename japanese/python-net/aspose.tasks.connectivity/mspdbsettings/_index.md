## MspDbSettings class

MS Project Server データベースからプロジェクトデータを読み取るために必要なオプションを設定できます。

MspDbSettings 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | 新しい [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| connection_string | 接続文字列を取得または設定します。 |
| provider_invariant_name | プロバイダー不変名を取得または設定します。この名前はクラスのインスタンスを取得するために使用されます。 |
| project_guid | 読み取るプロジェクトの GUID を取得します。 |
| schema | MS Project Server のスキーマを取得または設定します。<br/>            デフォルト値は "pub" です。 |
