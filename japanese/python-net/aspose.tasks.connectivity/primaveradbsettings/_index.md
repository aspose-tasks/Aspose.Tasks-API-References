## PrimaveraDbSettings class

Primavera データベースからプロジェクトデータを読み取るために必要なオプションを設定できます。

PrimaveraDbSettings 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PrimaveraDbSettings(connection_string, project_id) | 新しい [PrimaveraDbSettings](/tasks/python-net/aspose.tasks.connectivity/primaveradbsettings/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| connection_string | 接続文字列を取得または設定します。 |
| provider_invariant_name | プロバイダー不変名を取得または設定します。この名前はクラスのインスタンスを取得するために使用されます。 |
| project_id | 読み取るプロジェクトの ID を取得します。 |
