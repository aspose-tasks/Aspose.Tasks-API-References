## MpdSettings class

MPD 形式（MS Access データベースファイル形式）からプロジェクトデータを読み取るために必要なオプションを設定できます。

MpdSettings 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| MpdSettings(connection_string, project_id) | 新しい [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| connection_string | 接続文字列を取得または設定します。 |
| provider_invariant_name | プロバイダー不変名を取得または設定します。この名前はクラスのインスタンスを取得するために使用されます。 |
| project_id | 読み取るプロジェクトの ID を取得します。 |
