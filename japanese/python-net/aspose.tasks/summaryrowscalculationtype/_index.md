## SummaryRowsCalculationType enumeration

集計行のカスタム属性値の計算タイプを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | 集計行のカスタム属性値が計算されないことを意味します。 |
| ROLLUP | 集計行のカスタム属性値が、[rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/) で定義されたロールアップ関数を使用して計算されることを意味します。 |
| USE_FORMULA | 集計行のカスタム属性値が、[formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/) で定義された数式を使用して計算されることを意味します。 |
