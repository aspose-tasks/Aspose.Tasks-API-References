## AssignmentBaseline class

リソース割り当てのベースラインを表します。

AssignmentBaseline 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| AssignmentBaseline() | AssignmentBaseline クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| baseline_number | ベースライン データ レコードの一意の番号を取得または設定します。 |
| work | ベースラインが保存されたときにリソースに割り当てられる作業を取得または設定します。 |
| cost | ベースラインが保存されたときのリソースの予測コストを取得または設定します。 |
| bcws | リソースにスケジュールされた作業の予算コストを取得または設定します。 |
| bcwp | リソースがプロジェクトのために実施した作業のこれまでの予算コストを取得または設定します。 |
| timephased_data | このオブジェクトの [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) インスタンスを取得または設定します。<br/>            リソース割り当てベースラインに関連付けられた時間フェーズ データです。 |
| start | ベースラインが保存されたときのリソース割り当ての予定開始日を取得または設定します。 |
| finish | ベースラインが保存されたときのリソース割り当ての予定完了日を取得または設定します。 |
