## TaskLinkDrawingArgs class

タスクリンクがレンダリングされる際に呼び出されるコールバックに対する引数を提供します。

TaskLinkDrawingArgs 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| link | レンダリングされたタスクリンクを取得します。 |
| color | タスクリンクのレンダリングに使用される色を取得または設定します。タスクリンクの色のカスタマイズに使用できます。 |
