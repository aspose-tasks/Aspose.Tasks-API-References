## ViewCollection class

[View](/tasks/python-net/aspose.tasks/view/) オブジェクトのリストを含みます。<br/>            ICollection<View> インターフェイスを実装します。

ViewCollection 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| parent_project | View オブジェクトの親を取得します。<br/>            読み取り専用 [Project](/tasks/python-net/aspose.tasks/project/)。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| to_list() | ビュー コレクションを [View](/tasks/python-net/aspose.tasks/view/) オブジェクトのリストに変換します。 |
| get_by_view_screen(screen) | 指定された Screen プロパティを持つ View を検索し、コレクション内で最初に見つかったものを返します。 |
| get_by_name(view_name) | 名前で View を検索し、コレクション内で最初に見つかったものを返します。 |
