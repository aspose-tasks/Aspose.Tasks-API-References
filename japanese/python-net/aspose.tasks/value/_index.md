## Value class

値リスト内の値を表します。

Value 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| Value() | 新しいインスタンスを初期化します。[Value](/tasks/python-net/aspose.tasks/value/) クラス。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| id | プロジェクト全体で値の一意の識別子を取得または設定します。 |
| value_guid | この値をプロジェクト全体の他の値と区別する GUID を取得します。 |
| val | 内部表現で実際の値を取得または設定します。以下に列挙された強く型付けされたプロパティの使用を推奨します。 |
| string_value | テキスト文字列を表すために使用される実際の値を取得または設定します。 |
| numeric_value | 数値またはコスト値を表すために使用される実際の値を取得または設定します。 |
| duration | 期間を表すために使用される実際の値を取得または設定します。 |
| date_time_value | DateTime として表現できる場合、実際の値を取得または設定します。デフォルト値は最小日付です。 |
| description | 値の説明を取得または設定します。 |
| phonetic | カスタムフィールド名に関する音声情報を取得または設定します。 |
