## OutlineCodeDefinition class

アウトラインコード定義を表します。

OutlineCodeDefinition 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| OutlineCodeDefinition() | [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| guid | アウトラインコードの Guid を取得または設定します。 |
| field_id | アウトラインコードのフィールド番号を取得または設定します。 |
| field_name | カスタムアウトラインコードの名前を取得または設定します。 |
| alias | カスタムアウトラインコードのエイリアスを取得または設定します。 |
| phonetic_alias | カスタムアウトラインコードのエイリアスの音声表記を取得または設定します。 |
| values | OutlineValueCollection オブジェクトを取得します。<br/>            このアウトラインコードに関連付けられたテーブルの値です。 |
| enterprise | カスタムアウトラインコードがエンタープライズ カスタムアウトラインコードかどうかを示す値を取得または設定します。 |
| enterprise_outline_code_alias | このアウトラインコード定義がエイリアスとなる別のカスタム フィールドへの参照を取得または設定します。 |
| resource_substitution_enabled | カスタムアウトラインコードが使用できるかどうかを示す値を取得または設定します。<br/>            Microsoft Project のリソース置換ウィザードで使用できるかどうか。 |
| leaf_only | このアウトラインコード フィールドで指定された値がリーフ値である必要があるかどうかを示す値を取得または設定します。 |
| all_levels_required | 新しいコードがすべてのレベルを持つ必要があるかどうかを示す値を取得または設定します。<br/>            エンタープライズ コードでは使用できません。 |
| only_table_values_allowed | 指定された値が値テーブルから取得される必要があるかどうかを示す値を取得または設定します。 |
| masks | OutlineMaskCollection オブジェクトを取得します。<br/>            アウトラインコードマスクを定義するエントリのテーブルです。<br/>            読み取り専用の [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/) インスタンスです。 |
| show_indent | このアウトラインコードのインデントを表示する必要があるかどうかを示す値を取得または設定します。 |
