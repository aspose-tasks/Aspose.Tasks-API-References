## メソッド
| 名前 | 説明 |
| :- | :- |
| get_timephased_data(start, end, timephased_type) | 指定された時間フェーズデータタイプの開始日と終了日の範囲内の [timephased_data](/tasks/python-net/aspose.tasks/task/) 値を含む [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) オブジェクトを返します。 |
| get_timephased_data(start, end) | 指定された時間フェーズデータタイプの開始日と終了日の範囲内の [timephased_data](/tasks/python-net/aspose.tasks/task/) 値を含む [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) オブジェクトを返します。 |
| move_to_sibling(before_task) | 現在のタスクを同じアウトラインレベルで指定されたタスクの前に移動します。<br/>            ParentProject.CalculationMode が None の場合、このメソッド使用後に Project.Recalculate() を呼び出す必要があります（これにより、すべてのプロジェクトタスクのスケジュールが再計算され（開始/終了日、早期/遅延日が設定され）、スラック、作業量、コストフィールド、アウトラインレベルなどの依存フィールドが計算されます）。<br/>            ParentProject.CalculationMode が Manual の場合、メソッドはタスク ID、アウトラインレベル、アウトライン番号のみを自動的に計算します。<br/>            ParentProject.CalculationMode が Automatic の場合、メソッドはプロジェクトのすべてのタスクを自動的に再スケジュールします<br/>            （開始/終了日、早期/遅延日を設定し、スラック、作業量、コストフィールドを計算し、ID とアウトラインレベルを再計算します）。 |
