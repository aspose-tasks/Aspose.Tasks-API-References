## ProjectServerSaveOptions class

プロジェクトを Project Server または Project Online に保存する際に追加オプションを指定できるようにします。

ProjectServerSaveOptions 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| ProjectServerSaveOptions() | [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| project_name | Project Server \ Project Online のプロジェクト一覧に表示されるプロジェクトの名前を取得または設定します。Project Server \ Project Online インスタンス内で一意である必要があります。<br/>            値が省略された場合、Prj.Name プロパティの値が代わりに使用されます。 |
| project_guid | プロジェクトの一意の識別子を取得または設定します。Project Server \ Project Online インスタンス内で一意である必要があります。 |
| timeout | Project Server のキュー処理サービスによるプロジェクト保存リクエストの処理待ちに使用されるタイムアウトを取得または設定します。このプロパティのデフォルト値は 1 分です。 |
| polling_interval | キュー ジョブのステータス要求間の間隔を取得または設定します。デフォルト値は 2 秒です。 |
