## ProjectInfo class

Project Online で利用可能な公開プロジェクトに関する簡単な情報です。

ProjectInfo 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| ProjectInfo() | [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| id | プロジェクトの一意の識別子を取得します。 |
| name | プロジェクトの名前を取得します。 |
| created_date | プロジェクトが作成された日時を取得します。 |
| is_checked_out | プロジェクトがチェックアウトされているかどうかを示す値を取得します。 |
| last_published_date | プロジェクトが最後に公開された日時を取得します。 |
| last_saved_date | プロジェクトが最後に保存された日時を取得します。 |
| description | プロジェクトの説明を取得します。 |
