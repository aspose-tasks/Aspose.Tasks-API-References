## PrimaveraProjectProperties class

Primavera ファイル (XER または P6XML) から読み取ったプロジェクトの Primavera 固有プロパティを表します。

PrimaveraProjectProperties型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| relationship_lag_calendar | Primaveraプロジェクトで関係遅延のスケジューリングに使用するカレンダーを定義するオプションを取得します。 |
| use_expected_finish_dates | アクティビティの完了日を期待完了日としてスケジュールすべきかどうかを定義するフラグを取得します。 |
| make_open_ended_activities_critical | プロジェクトのスケジューリング時にアクティビティをクリティカルとしてマークすべきかどうかを定義するフラグを取得します。 |
| ignore_other_project_relationships | プロジェクト間のアクティビティ関係を無視すべきかどうかを定義するフラグを取得します。 |
| current_baseline_project_id | 現在のベースラインプロジェクトの Id を取得します。<br/>            エクスポートされたベースラインを含む Primavera XML ファイルから読み込んだプロジェクトに適用できます。 |
| baseline_projects | 現在のプロジェクトのベースラインプロジェクトの配列を取得します。<br/>            エクスポートされたベースラインを含む Primavera XML ファイルから読み込んだプロジェクトに適用できます。 |
| critical_activities_defining_method | クリティカルアクティビティを定義する方法を取得します：Longest Path または Total Float アプローチ。 |
| critical_total_float_limit | TotalFloat メソッドが使用される場合にクリティカルアクティビティを定義するために使用される閾値を取得します。 |
| short_name | プロジェクトの短縮名（Project ID）を取得します。 |
