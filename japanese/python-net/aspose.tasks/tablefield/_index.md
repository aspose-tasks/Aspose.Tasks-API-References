## TableField class

プロジェクト内のテーブルのフィールドを表します。

TableField 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| TableField() | 新しい [TableField](/tasks/python-net/aspose.tasks/tablefield/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| align_data | テーブルフィールド内のデータの配置を取得または設定します。 |
| align_title | テーブルフィールド内のタイトルの配置を取得または設定します。 |
| field | テーブルフィールドのタイプを取得または設定します。 |
| title | テーブル内のフィールドのタイトルを取得または設定します。 |
| width | テーブル内のフィールド列の幅（ポイント）を取得または設定します。 |
| wrap_header | テーブル列の見出しを複数行に折り返すか、列幅を超えた場合に切り捨てるかを示す値を取得または設定します。 |
| wrap_text | 列のテキストが複数行に折り返すか、列幅を超えた場合に切り捨てられるかを示す値を取得または設定します。 |
