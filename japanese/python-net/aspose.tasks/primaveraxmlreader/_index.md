## PrimaveraXmlReader class

Primavera Xml ファイルからプロジェクト UID を取得できるリーダーを表します。

PrimaveraXmlReader 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PrimaveraXmlReader(template_path) | 新しい [PrimaveraXmlReader](/tasks/python-net/aspose.tasks/primaveraxmlreader/) クラスのインスタンスを初期化します。 |
| PrimaveraXmlReader(stream) | 新しい [PrimaveraXmlReader](/tasks/python-net/aspose.tasks/primaveraxmlreader/) クラスのインスタンスを初期化します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_project_uids() | プロジェクトの一意識別子のリストを返します。 |
| get_project_infos() | プロジェクトの短い情報オブジェクトのリストを返します。 |
| load_project(project_uid) | 指定された一意識別子を持つプロジェクトをロードします。 |
