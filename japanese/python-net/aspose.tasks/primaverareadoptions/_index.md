## PrimaveraReadOptions class

Primavera Xml または Primavera Xer ファイルを読み取る際に追加オプションを指定できます。

PrimaveraReadOptions 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PrimaveraReadOptions() | 新しい [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| project_uid | 複数のプロジェクトを含むファイルから読み取るプロジェクトの UID を取得または設定します。 |
| undefined_constraint_handling_behavior | XER 形式から読み取った未定義の制約を持つタスクを処理する際に使用される動作を指定します。 |
| preserve_uids | エンティティの元の一意識別子を保持するかどうかを指定するフラグを取得または設定します。 |
| read_baseline_projects | ベースライン プロジェクトをロードするかどうかを指定するフラグを取得または設定します。デフォルト値は true です。 |
