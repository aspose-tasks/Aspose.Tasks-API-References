## RecurringTaskInfo class

プロジェクト内の繰り返しタスクの詳細を表します。

RecurringTaskInfo 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| recurrence_pattern | 繰り返しタスクの繰り返しパターンを取得または設定します。 |
| start_date | 発生開始日の日付を取得または設定します。 |
| end_date | 発生終了日の日付を取得または設定します。 |
| duration | 繰り返しタスクの1回の発生の期間を取得または設定します。 |
| occurrences | 繰り返しタスクの発生回数を取得または設定します。 |
| use_end_date | 繰り返しタスクで終了日を使用するか、発生回数を使用するかを示す値を取得または設定します。 |
| daily_repetitions | 日次繰り返しパターンの繰り返し回数を取得または設定します。 |
| daily_use_workdays | 日次の繰り返しパターンで平日を使用するかどうかを示す値を取得または設定します。 |
| weekly_repetitions | 週次の繰り返しパターンの繰り返し回数を取得または設定します。 |
| weekly_days | 週次の繰り返しパターンで使用される曜日のコレクションを取得または設定します。 |
| monthly_use_ordinal_day | 月次の繰り返しパターンで序数日を使用するかどうかを示す値を取得または設定します。 |
| monthly_ordinal_number | 月次の繰り返しパターンの序数番号を取得または設定します。 |
| monthly_ordinal_repetitions | 序数日を使用する場合の月次の繰り返しパターンの繰り返し回数を取得または設定します。 |
| monthly_day | 月次の繰り返しパターンの日数を取得または設定します。 |
| monthly_repetitions | 月次の繰り返しパターンの繰り返し回数を取得または設定します。 |
| yearly_use_ordinal_day | 年次の繰り返しパターンで序数日を使用するかどうかを示す値を取得または設定します。 |
| yearly_date | 年次の繰り返しパターンの日付を取得または設定します。 |
| yearly_ordinal_number | 年次の繰り返しパターンの序数番号を取得または設定します。 |
| yearly_ordinal_month | 序数日を使用する場合の年次の繰り返しパターンの月を取得または設定します。 |
| task | このインスタンスの [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/) クラスの親タスクを取得します。 |
