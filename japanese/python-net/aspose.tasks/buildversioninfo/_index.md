## BuildVersionInfo class

ビルド バージョンと製品情報を含みます。

BuildVersionInfo 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| ASSEMBLY_VERSION | アセンブリ バージョン。 |
| ASSEMBLY_INFORMATIONAL_VERSION | アセンブリの情報バージョン番号です。 |
| FILE_VERSION | ファイル バージョン。 |
| 製品 | 製品名。 |
