## GroupCriterion class

グループ定義内の基準を表します。<br/>            GroupCriterionオブジェクトは[GroupCriterionCollection](/tasks/python-net/aspose.tasks/groupcriterioncollection/) コレクションのメンバーです。

GroupCriterion 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| GroupCriterion() | GroupCriterion クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| 昇順 | グループ定義で基準として使用されるフィールドが昇順でソートされているかどうかを示す値を取得または設定します。フィールドが降順でソートされている場合は false です。 |
| cell_color | グループ定義で基準として使用されるフィールドのセル背景色を取得または設定します。 |
| font_color | グループ定義で基準として使用されるフィールドのフォント色を取得または設定します。 |
| field | グループ化対象のフィールドを取得または設定します。 |
| group_on | グループ定義で基準として使用されるフィールドのグループ化タイプを取得または設定します。 |
| パターン | グループ定義で基準として使用されるフィールドのセルのパターンを取得または設定します。 |
| start_at | グループ定義で基準として使用されるフィールドの間隔の開始点を取得または設定します。 |
| group_interval | グループ定義で基準として使用されるフィールドの間隔を取得または設定します。 |
| font | グループ定義の基準のフォントを取得または設定します。 |
