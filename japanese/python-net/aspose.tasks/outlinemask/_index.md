## OutlineMask class

アウトラインコード形式を定義するマスクの4つの要素を表します。

OutlineMask 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| OutlineMask() | 新しい [OutlineMask](/tasks/python-net/aspose.tasks/outlinemask/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| level | マスクのレベルを取得または設定します。 |
| type | マスクのタイプを取得または設定します。 |
| length | アウトラインコード値の最大長さ（文字数）を取得または設定します。長さが未定義の場合は 0 です。 |
| separator | コード値の区切り文字を取得または設定します。 |
