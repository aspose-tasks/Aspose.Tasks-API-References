## Rate class

その期間中にリソースに適用される時間期間とレートの定義を表します。

Rate 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| rates_from | レートが有効になる日付を取得または設定します。 |
| rates_to | レートが有効な最終日付を取得または設定します。 |
| rate_table | リソースのレートテーブルの一意の識別子を取得または設定します。 |
| standard_rate | リソースの標準レート（時間あたり）を取得または設定します。 |
| standard_rate_format | Microsoft Project が標準レートを表示する際に使用する単位を取得または設定します。 |
| overtime_rate | リソースの残業レート（時間あたり）を取得または設定します。 |
| overtime_rate_format | Microsoft Project が残業レートを表示する際に使用する単位を取得または設定します。 |
| cost_per_use | リソースの使用単価を取得または設定します。レートテーブルがリソースに存在する場合、この値は現在の日付から取得されます。 |
