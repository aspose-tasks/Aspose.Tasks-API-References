## CalculationType enumeration

カスタム属性の値の計算タイプを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | 拡張属性に数式のルックアップテーブルがなく、ユーザーが設定した値を単に保存することを意味します。 |
| LOOKUP | 拡張属性の値がルックアップテーブルの値に制限されていることを意味します。 |
| FORMULA | 拡張属性の値が [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/) で定義された数式を使用して計算されることを意味します。 |
