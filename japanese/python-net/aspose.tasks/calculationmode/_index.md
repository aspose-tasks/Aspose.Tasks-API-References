## CalculationMode enumeration

プロジェクトの計算モードを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | なし。このモードではプロジェクトの日付とコストは再計算されません。 |
| AUTOMATIC | 自動モード。このモードを使用すると、プロジェクトの日付とコストが再計算されます。 |
| MANUAL | 手動モード。このモードでは必要なフィールドのみが再計算されます。例としてオブジェクトの UID や ID があります。 |
