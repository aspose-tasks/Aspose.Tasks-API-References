## FontResolveEventArgs class

フォントが解決されたときに呼び出されるコールバックに対する引数を提供します。

FontResolveEventArgs 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| requested_font_name | 要求されたフォントの名前を取得します。 |
| resolved_font_name | 解決されたフォントの名前を取得または設定します。ビューのレンダリングに使用されるフォントを制御するために設定できます。 |
