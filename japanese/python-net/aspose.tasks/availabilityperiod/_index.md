## AvailabilityPeriod class

リソースが利用可能な期間を表します。

AvailabilityPeriod 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| AvailabilityPeriod() | 新しい [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) のインスタンスを初期化します。 |
| AvailabilityPeriod(available_from, available_to, available_units) | 指定された日付範囲と利用可能な単位で新しい [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) のインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| available_from | 指定された期間にリソースが利用可能になる日付を取得または設定します。 |
| available_to | 指定された期間にリソースが利用可能な最終日付を取得または設定します。 |
| available_units | 指定された期間中にリソースが利用可能な割合を取得または設定します。 |
