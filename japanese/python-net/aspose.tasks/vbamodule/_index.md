## VbaModule class

VBA モジュールを表します。

VbaModule 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| attributes | モジュールの属性のコレクションを取得します。 |
| name | VBA モジュールの名前を取得します |
| type | モジュールのタイプを取得します。 |
| source_code | VBA モジュールのソースコードを取得または設定します |
## メソッド
| 名前 | 説明 |
| :- | :- |
| create_procedural_module(name) | VbaModuleType.ProceduralModule タイプで [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) のインスタンスを作成します。 |
| create_class_module(name) | VbaModuleType.ClassModule タイプで [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) のインスタンスを作成します。 |
