## TaskBaseline class

タスクのベースラインを表します。

TaskBaseline 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| TaskBaseline(task) | [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| baseline_number | ベースライン データ レコードの一意の番号を取得または設定します。 |
| work | ベースラインが保存されたときにリソースに割り当てられる作業を取得または設定します。 |
| cost | ベースラインが保存されたときのリソースの予測コストを取得または設定します。 |
| bcws | リソースにスケジュールされた作業の予算コストを取得または設定します。 |
| bcwp | リソースがプロジェクトのために実施した作業のこれまでの予算コストを取得または設定します。 |
| timephased_data | このオブジェクトの TimephasedDataCollection インスタンスを取得または設定します。<br/>            タスクベースラインに関連付けられた時間分割データです。 |
| interim | このベースラインが暫定ベースラインかどうかを示す値を取得または設定します。 |
| start | ベースラインが保存された時点でのタスクの予定開始日を取得または設定します。 |
| finish | ベースラインが保存された時点でのタスクの予定完了日を取得または設定します。 |
| duration | ベースラインが保存された時点でのタスクの予定期間を取得または設定します。 |
| estimated_duration | タスクのベースライン期間が見積もられたかどうかを示す値を取得または設定します。 |
| fixed_cost | ベースラインが保存されたときのタスクの固定コストを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| equals(other) | このインスタンスが指定された TaskBaseline オブジェクトと等しいかどうかを示す値を返します。 |
| equals(other) | このインスタンスが指定されたオブジェクトと等しいかどうかを示す値を返します。 |
| compare_to(other) | IComparable インターフェイスの実装です。<br/>            このインスタンスを指定された Baseline オブジェクトと比較します。 |
| compare_to(other) | IComparable インターフェイスの実装です。<br/>            このインスタンスを指定された Baseline オブジェクトと比較します。 |
