## WeekDay class

カレンダーで通常の曜日または例外日のいずれかを定義する平日を表します。

WeekDay 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| WeekDay(day_type) | 指定された日タイプで [WeekDay](/tasks/python-net/aspose.tasks/weekday/) クラスの新しいインスタンスを初期化します。 |
| WeekDay(day_type, working_times) | WeekDay クラスの新しいインスタンスを初期化します。 |
| WeekDay(day_type, working_times) | 指定された日タイプと作業時間帯で [WeekDay](/tasks/python-net/aspose.tasks/weekday/) クラスの新しいインスタンスを初期化します。 |
| WeekDay() | 指定された日タイプで [WeekDay](/tasks/python-net/aspose.tasks/weekday/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| day_type | 日のタイプを取得します。 |
| day_working | 指定された日付または日タイプが作業日かどうかを示す値を取得または設定します。 |
| from_date | 例外時間の開始時刻を取得または設定します。 |
| to_date | 例外時間の終了時刻を取得または設定します。 |
| working_times | この WeekDay インスタンスの WorkingTimeCollection を取得します。<br/>            曜日に作業した時間を定義する作業時間のコレクションです。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| create_default_working_day(day_type) | デフォルトの作業日を作成します。 |
| set_default_working_time(day) | 指定された曜日のデフォルト時間帯を設定します。 |
| get_working_time() | 週の曜日の作業時間を返します。 |
| clone() | 曜日のディープコピーを返します。 |
