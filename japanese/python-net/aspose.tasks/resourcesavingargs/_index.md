## ResourceSavingArgs class

このクラスは、外部リソースファイルの保存に関連するデータのセットを表します<br/>              HTML 形式への変換中に発生します。

ResourceSavingArgs 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| ResourceSavingArgs() | ResourceSavingArgs クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| file_name | コンバータからカスタムメソッドのコードへ渡される想定のファイル名を取得または設定します。<br/>             カスタムコード内で、ファイルの処理方法や保存場所を決定するために使用できます。 |
| keep_stream_open | リソースの保存が完了した後にストリームを開いたままにするかどうかを示す値を取得または設定します。 |
| stream | 保存されたファイルのバイナリ内容を取得または設定します。 |
| uri | リソースの URI を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| close_stream_if_required() | KeepStreamOpen が false の場合はストリームを閉じ、そうでない場合はフラッシュします。 |
