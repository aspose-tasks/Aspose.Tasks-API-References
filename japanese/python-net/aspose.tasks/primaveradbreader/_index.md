## PrimaveraDbReader class

Primavera DB からプロジェクト情報を読み取るリーダーを表します。

PrimaveraDbReader 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| PrimaveraDbReader(db_settings) | 新しい [PrimaveraXerReader](/tasks/python-net/aspose.tasks/primaveraxerreader/) クラスのインスタンスを初期化します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_project_uids() | プロジェクトの一意識別子のリストを返します。 |
| get_project_infos() | プロジェクトの短い情報オブジェクトのリストを返します。 |
| load_project(project_uid) | 指定された一意識別子を持つプロジェクトをロードします。 |
