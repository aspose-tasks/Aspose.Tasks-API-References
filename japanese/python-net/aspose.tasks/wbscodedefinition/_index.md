## WBSCodeDefinition class

WBSCodeDefinition 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| WBSCodeDefinition() | 新しい [WBSCodeDefinition](/tasks/python-net/aspose.tasks/wbscodedefinition/) クラスのインスタンスを初期化します。 |

| 名前 | 説明 |
| :- | :- |
| code_prefix | プロジェクトコードプレフィックスを取得または設定します。 |
