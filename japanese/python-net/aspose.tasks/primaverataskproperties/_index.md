## PrimaveraTaskProperties class

Primavera ファイル (XER または P6XML) から読み取ったタスクの Primavera 固有プロパティを表します。

PrimaveraTaskProperties 型は以下のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| sequence_number | WBS アイテム（サマリータスク）のシーケンス番号を取得または設定します。Primavera でサマリータスクを並べ替えるために使用されます。 |
| activity_id | activity id フィールドを取得します - Primavera で使用されるタスクの一意の識別子です。 |
| remaining_early_finish | 残りの早期完了日を取得します - アクティビティの残り作業が完了する予定の日付です。 |
| remaining_early_start | 残りの早期開始日を取得します - アクティビティの残り作業が開始される予定の日付です。 |
| remaining_late_start | 残りの遅延開始日を取得します。 |
| remaining_late_finish | 残りの遅延完了日を取得します。 |
| raw_duration_type | アクティビティの 'Duration Type' フィールドの生テキスト表現（ソースファイルと同様）を取得します。 |
| duration_type | アクティビティの 'Duration Type' フィールドの値を取得します。 |
| raw_activity_type | アクティビティの 'Activity Type' フィールドの生テキスト表現（ソースファイルと同様）を取得します。 |
| activity_type | 'Activity Type' フィールドの値を取得します。 |
| percent_complete_type | アクティビティの '% Complete Type' フィールドの値を取得します。 |
| raw_complete_percent_type | アクティビティの '% Complete Type' フィールドの生テキスト表現（ソースファイルと同様）を取得します。 |
| raw_status | アクティビティの 'Status' フィールドの、生のテキスト表現（ソースファイルと同様）を取得します。 |
| physical_percent_complete | Physical Percent Complete の値を取得します。 |
| duration_percent_complete | duration percent complete の値を取得します。 |
| units_percent_complete | units percent complete の値を取得します。 |
| actual_labor_units | actual labor units の値を取得します。 |
| actual_non_labor_units | actual non labor units の値を取得します。 |
| remaining_labor_units | remaining labor units の値を取得します。 |
| remaining_non_labor_units | remaining non labor units の値を取得します。 |
| actual_labor_cost | actual labor cost の値を取得します。 |
| budgeted_labor_cost | budgeted（または planned） labor cost の値を取得します。 |
| actual_nonlabor_cost | actual non labor cost の値を取得します。 |
| budgeted_nonlabor_cost | budgeted（または planned） non labor cost の値を取得します。 |
| actual_material_cost | 実際の材料費の値を取得します。 |
| budgeted_material_cost | 予算（または計画）された材料費の値を取得します。 |
| actual_expense_cost | 実際の支出コストの値を取得します。 |
| remaining_expense_cost | 残りの支出コストの値を取得します。 |
| budgeted_expense_cost | 予算（または計画）された支出コストの値を取得します。 |
| actual_total_cost | 実際のコストの合計値を取得します。 |
| budgeted_total_cost | 予算（または計画）されたコストの合計値を取得します。 |
| primary_constraint_type | 主要制約のタイプを取得します。 |
| primary_constraint_date | 主要制約の日付を取得します。 |
| secondary_constraint_type | 二次制約のタイプを取得します。 |
| secondary_constraint_date | 二次制約の日付を取得します。 |
| planned_duration | 元のまたは計画された期間を取得します -- タスクの計画開始日から計画完了日までの総作業時間です.. |
