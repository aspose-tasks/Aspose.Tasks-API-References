## PrimaveraBaseReader class

複数プロジェクトの Primavera XER または XML ファイルからプロジェクト UID を読み取るために使用できる基本リーダーを表します。

PrimaveraBaseReader 型は次のメンバーを公開します:
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_project_uids() | プロジェクトの一意識別子のリストを返します。 |
| get_project_infos() | プロジェクトの短い情報オブジェクトのリストを返します。 |
| load_project(project_uid) | 指定された一意識別子を持つプロジェクトをロードします。 |
