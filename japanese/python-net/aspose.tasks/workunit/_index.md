## WorkUnit class

作業時間を表します。

WorkUnit 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| WorkUnit(from_address, to) | [WorkUnit](/tasks/python-net/aspose.tasks/workunit/) クラスの新しいインスタンスを初期化します。<br/>            指定された From と To の日付で新しい WorkUnit オブジェクトを作成します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| from_address | From 日付を取得または設定します。 |
| to | To 日付を取得または設定します。 |
| working_hours | 作業時間の期間を取得または設定します。 |
