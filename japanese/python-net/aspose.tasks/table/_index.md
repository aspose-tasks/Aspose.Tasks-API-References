## Table class

Project のテーブルを表します

Table 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| Table() | 新しい [Table](/tasks/python-net/aspose.tasks/table/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| name | Table オブジェクトの名前を取得または設定します。 |
| show_in_menu | プロジェクトがリボンの View タブの Tables ドロップダウンリストにテーブル名を表示するかどうかを示す値を取得または設定します。 |
| table_fields | テーブル内のフィールドを表す TableFields コレクションを取得します。 |
| table_type | 指定されたテーブルのテーブルタイプを取得または設定します。 |
| uid | テーブルの一意の識別子を取得します。 |
| row_height | テーブル内の行の高さを取得または設定します。行の高さはテキスト行数で表されます。 |
| date_format | テーブルの日付形式を取得または設定します。 |
| adjust_header_row_height | テーブルのヘッダー行の高さを調整できるかどうかを示す値を取得または設定します。 |
| show_add_new_column | 「Add New Column」インターフェイスを表示するかどうかを示す値を取得または設定します。 |
| lock_first_column | テーブルの最初の列がロックされているか編集可能かを示す値を取得または設定します。 |
