## UndefinedConstraintHandlingBehavior enumeration

未定義の制約を持つタスクの処理に使用される動作を指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | XER 形式からロードする際のデフォルト動作です。<br/>            何も実行されません。タスク制約タイプは 'ConstraintType.Undefined' に設定されます。 |
| SUBSTITUTE_WITH_START_NO_EARLIER_THAN | 'ConstraintType.StartNoEarlierThan' タイプの制約と日付 = Start が、'Undefined' 制約のタスクに追加されます。 |
