## RateCollection class

[Rate](/tasks/python-net/aspose.tasks/rate/) オブジェクトを含むコレクションを表します。

RateCollection 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| count | RateCollection に含まれる要素数を取得します。 |
| is_read_only | このコレクションが読み取り専用かどうかを示す値を取得します。 |
| parent_resource | このコレクションの親 [Resource](/tasks/python-net/aspose.tasks/resource/) オブジェクトを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| add(rates_from) | このコレクションに新しい [Rate](/tasks/python-net/aspose.tasks/rate/) インスタンスを追加します。 |
| add(rates_from, type) | このコレクションに新しい [Rate](/tasks/python-net/aspose.tasks/rate/) インスタンスを追加します。 |
| to_list() | [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) オブジェクトを [Rate](/tasks/python-net/aspose.tasks/rate/) オブジェクトのリストに変換します。 |
| to_list(type) | [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) オブジェクトを、指定された [RateType](/tasks/python-net/aspose.tasks/ratetype/) タイプでフィルタリングされた [Rate](/tasks/python-net/aspose.tasks/rate/) オブジェクトのリストに変換します。 |
| remove(item) | このコレクションから Rate インスタンスを削除します。 |
