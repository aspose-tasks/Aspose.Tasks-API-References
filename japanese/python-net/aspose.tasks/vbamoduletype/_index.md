## VbaModuleType enumeration

VBA プロジェクト内のモジュールのタイプを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| DOCUMENT_MODULE | ドキュメントに関連付けられた組み込みマクロおよびプログラム的アクセス操作用のモジュールを指定する VBA プロジェクト項目のタイプです。 |
| PROCEDURAL_MODULE | サブルーチンと関数のコレクションを含むモジュールです。 |
| CLASS_MODULE | 新しいオブジェクトの定義を含むモジュールです。クラスの各インスタンスは新しいオブジェクトを作成し、モジュールで定義された手続きはオブジェクトのプロパティおよびメソッドになります。 |
| DESIGNER_MODULE | プロジェクトに登録された ActiveX コントロールのメソッドとプロパティを拡張するモジュールです。 |
