## TaskLink class

前任タスクへのリンクを表します。

TaskLink 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_cross_project | 前任タスクが別のプロジェクトに属しているかどうかを示す値を取得または設定します。 |
| cross_project_name | 外部の前任プロジェクトを取得または設定します。 |
| link_lag | 分の十分の一またはパーセンテージでの遅延を取得または設定します。 |
| link_lag_time_span | LagFormat に応じて遅延期間を取得または設定します。 |
| lag_format | 遅延の表現形式を取得または設定します。 |
| pred_task | 前任タスクを取得または設定します。 |
| succ_task | 後続タスクを取得または設定します。 |
| link_type | リンクの種類を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| equals(other) | このインスタンスが指定されたオブジェクトと等しいかどうかを示す値を返します。 |
