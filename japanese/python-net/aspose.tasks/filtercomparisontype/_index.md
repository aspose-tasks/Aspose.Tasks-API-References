## FilterComparisonType enumeration

フィルターまたはグラフィカルインジケーターの選択基準として機能する、FieldName と Value の間で行われる比較のタイプです。

## Members
| メンバー名 | 説明 |
| :- | :- |
| EQUALS | Field の値は Value と等しいです。 |
| DOES_NOT_EQUAL | Field の値は Value と等しくありません。 |
| IS_GREATER_THAN | Field の値は Value より大きいです。 |
| IS_GREATER_THAN_OR_EQUAL_TO | Field の値は Value 以上です。 |
| IS_LESS_THAN | Field の値は Value 未満です。 |
| IS_LESS_THAN_OR_EQUAL_TO | Field の値は Value 以下です。 |
| IS_WITHIN | Field の値は Value の範囲内です。 |
| IS_NOT_WITHIN | Field の値が Value の範囲内にありません。 |
| CONTAINS | Field の値に Value が含まれています。 |
| DOES_NOT_CONTAIN | Field の値に Value が含まれていません。 |
| CONTAINS_EXACTLY | Field の値は正確に Value を含んでいます。 |
| IS_ONE_OF | Field の値は指定された Values のいずれかと等しいです。AutoFilters で使用されます。 |
| UNDEFINED | 未定義の値です。 |
| IS_ANY_VALUE | 「Is any value」条件です。グラフィカル インジケータに適用できます。 |
