## TaskLinkCollection class

[Task](/tasks/python-net/aspose.tasks/task/) オブジェクトのコレクションを表します。

TaskLinkCollection 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| parent_project | ResourceAssignmentCollection オブジェクトの親プロジェクトを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| add(pred, succ) | TaskLinkCollection オブジェクトに追加された Finish-Start [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) のインスタンスを返します。 |
| add(pred, succ, link_type) | TaskLinkCollection オブジェクトに追加された [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) のインスタンスを返します。 |
| add(pred, succ, link_type, lag) | TaskLinkCollection オブジェクトに追加された [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) のインスタンスを返します。 |
| to_list() | TaskLinkCollection オブジェクトを [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) オブジェクトのリストに変換します。 |
