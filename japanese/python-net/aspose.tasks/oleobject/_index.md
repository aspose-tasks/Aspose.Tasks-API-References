## OleObject class

MPP ファイルのガントチャートビューに挿入できる OLE オブジェクトを表します。

OleObject 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| OleObject() | [OleObject](/tasks/python-net/aspose.tasks/oleobject/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| name | OLE オブジェクトのインスタンスの名前を取得または設定します。 |
| application_name | 埋め込みオブジェクトを開くためのアプリケーション名を取得または設定します。 |
| file_format | 埋め込みオブジェクトのファイル形式を取得または設定します。 |
| content | 埋め込みファイルのデータを取得または設定します。データが埋め込まれていない場合は null です。 |
| label | 挿入されたオブジェクトのラベルを取得または設定します。 |
| full_path | 挿入されたオブジェクトのフルパスを取得または設定します。 |
| temporary_file | 挿入されたオブジェクトの一時ファイルへのパスを取得または設定します。 |
| display_as_icon | OLE オブジェクトをアイコンとして表示するか、通常の画像として表示するかを示すフラグを取得または設定します。 |
| リンク済み | プロジェクト ファイルがリンク元に保存されている実際のデータへのリンクのみを含むかどうかを示す値を取得します。 |
| view | 挿入されたオブジェクトが属する [view](/tasks/python-net/aspose.tasks/oleobject/) クラスのインスタンスを取得または設定します。 |
| id | オブジェクト ID を取得または設定します。 |
