## ExtendedAttribute class

拡張属性を表します。

ExtendedAttribute 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| attribute_definition | 属性定義を取得します。 |
| field_id | フィールドの ID を取得します。 |
| duration_value | 「Duration」型の属性の値を取得または設定します。 |
| numeric_value | 数値型（Cost、Number）の属性の値を取得または設定します。 |
| date_value | 日付型（Date、Start、Finish）の属性の値を取得または設定します。 |
| flag_value | 「Flag」型の属性にフラグが設定されているかどうかを示す値を取得または設定します。 |
| text_value | 「Text」型の属性の値を取得または設定します。 |
| value_guid | ルックアップ値の GUID を取得します。 |
| value_read_only | この [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) インスタンスの値が読み取り専用かどうかを示す値を取得します。 |
| is_error_value | 拡張属性の値の計算がエラーになったかどうかを取得します。 |
