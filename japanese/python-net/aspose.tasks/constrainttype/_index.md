## ConstraintType enumeration

タスクの開始日または終了日に対する制約を指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| UNDEFINED | 元のプロジェクト ファイルで値が定義されていませんでした。 |
| AS_SOON_AS_POSSIBLE | [None](/tasks/python-net/aspose.tasks/tsk/) と [None](/tasks/python-net/aspose.tasks/tsk/) の [Task](/tasks/python-net/aspose.tasks/task/) の日付は ASAP にスケジュールされます<br/>            親の [None](/tasks/python-net/aspose.tasks/tsk/) と [None](/tasks/python-net/aspose.tasks/tsk/) の日付を考慮し、[task_links](/tasks/python-net/aspose.tasks/project/) を考慮します。 |
| AS_LATE_AS_POSSIBLE | [None](/tasks/python-net/aspose.tasks/tsk/) と [None](/tasks/python-net/aspose.tasks/tsk/) の [Task](/tasks/python-net/aspose.tasks/task/) の日付は ALAP にスケジュールされます<br/>            親の [None](/tasks/python-net/aspose.tasks/tsk/) と [None](/tasks/python-net/aspose.tasks/tsk/) の日付を考慮し、[task_links](/tasks/python-net/aspose.tasks/project/) を考慮します。 |
| MUST_START_ON | 開始必須 |
| MUST_FINISH_ON | 終了必須 |
| START_NO_EARLIER_THAN | 開始はこれより早くできません |
| START_NO_LATER_THAN | 開始はこれより遅くできません |
| FINISH_NO_EARLIER_THAN | 終了はこれより早くできません |
| FINISH_NO_LATER_THAN | 終了はこれより遅くできません |
