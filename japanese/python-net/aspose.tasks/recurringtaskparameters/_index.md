## RecurringTaskParameters class

プロジェクト内で繰り返しタスクを作成するために使用されるパラメータのセットを表します。

RecurringTaskParameters 型は次のメンバーを公開します。
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| RecurringTaskParameters() | [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| duration | 繰り返しタスクの1回の発生の期間を取得または設定します。 |
| ignore_resource_calendar | リソースが利用可能でなくても、定期タスクをスケジュールするかどうかを示す値を取得または設定します。 |
| recurrence_pattern | 定期タスクの繰り返しパターンを取得または設定します。 |
| task_name | 定期タスクの名前を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| set_calendar(project, calendar_name) | 定期タスクのカレンダーを設定します。カレンダーはプロジェクトのカレンダーコレクションから選択されます。 |
