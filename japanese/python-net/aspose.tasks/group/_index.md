## Group class

グループ定義を表します。<br/>            GroupオブジェクトはResourceGroupsコレクションまたはTaskGroupsコレクションのメンバーです。

Group 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| Group() | 新しい [Group](/tasks/python-net/aspose.tasks/group/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| name | Group オブジェクトの名前を取得または設定します。 |
| uid | グループの一意の識別子を取得します。 |
| show_summary | グループに対してサマリ行が表示されるかどうかを示す値を取得または設定します。 |
| maintain_hierarchy | グループ内のサブタスクに対して、サマリタスクのすべてのレベルを表示するかどうかを示す値を取得または設定します。 |
| show_in_menu | リボンの Group ドロップダウンリストにプロジェクトがグループ名を表示するかどうかを示す値を取得または設定します。 |
| group_assignments | タスクの代わりに割り当てをグループ化すべきかどうかを示す値を取得または設定します。 |
| group_criteria | グループ定義のフィールドを表す GroupCriteria コレクションを取得または設定します。 |
