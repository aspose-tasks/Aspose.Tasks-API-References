## EndAfterRecurrenceRange class

EndAfterRecurrenceRange 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| EndAfterRecurrenceRange() | 新しい [EndAfterRecurrenceRange](/tasks/python-net/aspose.tasks/endafterrecurrencerange/) クラスのインスタンスを初期化します。 |

| 名前 | 説明 |
| :- | :- |
| start | 繰り返しタスクの再発範囲の開始日を取得または設定します。 |
| occurrence_number | 繰り返しタスクの再発範囲を制限する発生回数を取得または設定します。 |
