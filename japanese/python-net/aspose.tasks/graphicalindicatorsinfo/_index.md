## GraphicalIndicatorsInfo class

拡張属性に関連付けられたグラフィカルインジケータの定義を表します。

GraphicalIndicatorsInfo 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| GraphicalIndicatorsInfo() | 新しい [GraphicalIndicatorsInfo](/tasks/python-net/aspose.tasks/graphicalindicatorsinfo/) 型のインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| summary_rows_inherit_from_non_summary_rows | 要約行が非要約行から基準を継承するかどうかを示すフラグを取得または設定します。 |
| project_summary_inherit_from_non_summary_rows | プロジェクトの要約行が要約行から基準を継承するかどうかを示すフラグを取得または設定します。 |
| show_data_values_in_tooltip | フィールドのデータ値をツールチップに表示するかどうかを示すフラグを取得または設定します。 |
| criteria | グラフィカルインジケータの基準のリストを取得します。 |
