## ProjectFileInfo class

クラス インスタンスは、プロジェクト ファイル形式とファイルが作成された Microsoft Project のバージョンに関する情報を含みます。<br/>            

ProjectFileInfo 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| can_read | Aspose.Tasks がプロジェクト ファイルを処理できるかどうかを示す値を取得します。 |
| is_password_protected | プロジェクトがパスワードで保護されているかどうかを示す値を取得します。 |
| project_file_format | プロジェクト ファイルの形式を取得します。 |
| project_application_info | プロジェクト ファイルのアプリケーション情報を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| equals(other) | このインスタンスが指定されたオブジェクトと等しいかどうかを示す値を返します。 |
