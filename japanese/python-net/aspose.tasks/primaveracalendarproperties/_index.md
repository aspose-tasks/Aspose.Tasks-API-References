## PrimaveraCalendarProperties class

Primavera ファイル (XER または P6XML) から読み取ったカレンダーの Primavera 固有プロパティを表します。<br/>            カレンダー固有の時間単位変換を実行するために使用できます。

PrimaveraCalendarProperties 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| hours_per_day | カレンダーの「Time Periods」設定から1日あたりの時間数を取得します。 |
| hours_per_week | カレンダーの「Time Periods」設定から1週間あたりの時間数を取得します。 |
| hours_per_month | カレンダーの「Time Periods」設定から1か月あたりの時間数を取得します。 |
| hours_per_year | カレンダーの「Time Periods」設定から1か月あたりの時間数を取得します。 |
