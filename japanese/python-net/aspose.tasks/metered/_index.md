## Metered class

メーターキーを設定するためのメソッドを提供します。

Metered 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| Metered() | Metered クラスの新しいインスタンスを初期化します |

| 名前 | 説明 |
| :- | :- |
| set_metered_key(public_key, private_key) | metered の公開キーと秘密キーを設定します。 |
