## View class

Project のビューを表します。

View 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| View() | 新しい [View](/tasks/python-net/aspose.tasks/view/) クラスのインスタンスを初期化します。 |
| View(view_screen) | 新しい [View](/tasks/python-net/aspose.tasks/view/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| filter | 単一ビューで使用されるフィルターを取得または設定します。 |
| グループ | 単一ビューのグループを取得または設定します。 |
| uid | ビューの一意の識別子を取得します。 |
| ハイライト_フィルタ | Microsoft Project が単一ビューのフィルタをハイライトするかどうかを示す値を取得または設定します。 |
| name | View オブジェクトの名前を取得または設定します。 |
| screen | 単一ビューの画面タイプを取得します。<br/>            読み取り専用 [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/)。 |
| parent_project | View オブジェクトの親を取得します。<br/>            読み取り専用 [Project](/tasks/python-net/aspose.tasks/project/)。 |
| テーブル | 単一ビューのテーブルを取得または設定します。 |
| type | 単一ビュー内のアイテムの種類（タスクやリソースなど）を取得します。<br/>            読み取り専用 [ItemType](/tasks/python-net/aspose.tasks/itemtype/)。 |
| show_in_menu | Microsoft Project がリボンの「View」または「Other Views」ドロップダウンリストに単一ビュー名を表示するかどうかを示す値を取得または設定します。 |
| page_info | [page_info](/tasks/python-net/aspose.tasks/view/) クラスのインスタンスを取得します。mpp ファイル形式に含まれるページ設定データを表します。 |
| visual_objects_placements | ビュー内の [OleObject](/tasks/python-net/aspose.tasks/oleobject/) の配置と外観を表すオブジェクトのコレクションを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| compare_to(other) | 現在のインスタンスを同じ型の別のオブジェクトと比較し、現在のインスタンスが他のオブジェクトより前にあるか、後にあるか、または同じ位置にあるかを示す整数を返します。 |
