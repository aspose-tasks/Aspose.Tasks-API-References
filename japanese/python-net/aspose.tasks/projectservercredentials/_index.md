## ProjectServerCredentials class

Project Online またはオンプレミスの Project Server インスタンスに接続するために使用される認証情報です。

ProjectServerCredentials 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | SharePoint サイトの URL と、SharePoint の PWA（Project Web Access）サイト用の有効な SPOIDCRL 認証トークンを使用して、[ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) クラスの新しいインスタンスを初期化します。 |
| ProjectServerCredentials(site_url, user_name, password) | SharePoint サイトの URL と、SharePoint の PWA（Project Web Access）サイト用の有効な SPOIDCRL 認証トークンを使用して、[ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| site_url | SharePoint サイトの PWA の URL またはオンプレミス Project Server の URL を取得します。<br/>            例: https://your_company_name.sharepoint.com/sites/pwa"; |
| auth_token | SharePoint インスタンスの認証トークンを取得します。 |
| user_name | SharePoint サイトのユーザー名を取得します。 |
