## OutlineValue class

アウトライン値を表します。

OutlineValue 型は次のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| OutlineValue() | OutlineValue クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| value_id | プロジェクト内のアウトラインコード値の一意の Id を取得または設定します。 |
| value_guid | この値をプロジェクト全体の他の値と区別する GUID を取得します。 |
| type | アウトラインコードのタイプを取得または設定します。 |
| parent_value_id | アウトラインコードの親ノードの Id を取得または設定します。 |
| value | 実際の値を取得または設定します。 |
| duration_value | タイプが Duration の場合、期間を取得または設定します。 |
| description | アウトライン値の説明を取得または設定します。 |
| is_collapsed | アウトライン値が折りたたまれているかどうかを示す値を取得または設定します。 |
