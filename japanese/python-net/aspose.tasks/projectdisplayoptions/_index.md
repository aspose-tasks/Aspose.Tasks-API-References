## ProjectDisplayOptions class

プロジェクト インスタンスの表示オプションを表します。

ProjectDisplayOptions 型は以下のメンバーを公開します：
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| ProjectDisplayOptions() | 新しい [ProjectDisplayOptions](/tasks/python-net/aspose.tasks/projectdisplayoptions/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| add_space_before_label | 数値と時間の省略形の前にスペースを追加するかどうかを示す値を取得または設定します（1 wk と 1wk の違い）。 |
| underline_hyperlinks | ハイパーリンクに下線を付けるかどうかを示す値を取得または設定します。 |
| show_task_schedule_warnings | Project が手動でスケジュールされたタスクで潜在的なスケジュール競合を検出したときに警告を表示するかどうかを示す値を取得または設定します。 |
| show_task_schedule_suggestions | Project が手動でスケジュールされたタスクで潜在的なスケジュール競合を検出したときに提案を表示するかどうかを示す値を取得または設定します。 |
| show_project_summary_task | プロジェクト全体の概要情報を、ガントチャートビューの上部にある独自のサマリタスクバーとともに単一行で表示するかどうかを示す値を取得または設定します。 |
| minute_label | 分ラベルの表示方法を取得または設定します。 |
| hour_label | 時間ラベルの表示方法を取得または設定します。 |
| day_label | 日ラベルの表示方法を取得または設定します。 |
| week_label | 週ラベルの表示方法を取得または設定します。 |
| month_label | 月ラベルの表示方法を取得または設定します。 |
| year_label | 年ラベルの表示方法を取得または設定します。 |
