## TaskStatus enumeration

タスクのステータスを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| UNDEFINED | 未定義のタスクステータスです。 |
| COMPLETE | タスクは 100 パーセント完了しています。 |
| ON_SCHEDULE | タスクは、時間別累積完了率がステータス日以前の少なくとも前日まで広がっている場合、スケジュール通りです。 |
| LATE | タスクは、時間別累積完了率がステータス日の前日の深夜に達しない場合、遅れています。 |
| FUTURE | 'Future' タスクステータスは、タスク開始日がステータス日より大きい場合に設定されます。 |
