## WorkingTime class

平日中の作業時間を表します。

WorkingTime 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| WorkingTime(from_time, to_time) | 指定された開始時刻と終了時刻を持つ間隔で、[WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) クラスの新しいインスタンスを初期化します。 |
| WorkingTime(from_time, to_time) | 指定された開始時刻と終了時刻を持つ間隔項目で、[WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) クラスの新しいインスタンスを初期化します。 |
| WorkingTime(from_hours, to_hours) | WorkingTime クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| from_address | 作業時間の開始時刻を取得します。 |
| to | 作業時間の終了時刻を取得します。 |
