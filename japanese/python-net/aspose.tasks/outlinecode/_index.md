## OutlineCode class

アウトラインコードの値を表します。

OutlineCode 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| OutlineCode() | 新しい [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/) クラスのインスタンスを初期化します。 |
| OutlineCode(code_definition, outline_value) | 指定された Outline Code とその値のいずれかを使用して、新しい [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| field_id | プロジェクト Id カスタム フィールドの数値を取得または設定します。 |
| value_id | アウトライン コード コレクションの定義に関連付けられた値リスト内の Id を取得または設定します。 |
| value_guid | 値リスト内の値の GUID を取得または設定します。ValueGuid は値リストの FieldGuid と一致します。 |
