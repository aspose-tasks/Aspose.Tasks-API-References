## LoadOptions class

ファイルまたはストリームからプロジェクトをロードする際に、追加のロードパラメータを指定できるようにします。

LoadOptions 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| LoadOptions() | 新しい [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/) クラスのインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| パスワード | 保護パスワードを取得または設定します。 |
| primavera_read_options | ロード時の Primavera フォーマット（Primavera P6 XER または Primavera P6 Xml）の動作をカスタマイズするために使用できる、[PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) クラスの指定インスタンスを取得または設定します。 |
| エンコーディング | HTML、MPX、XER、Primavera XML フォーマットからプロジェクトを読み取る際に使用されるエンコーディングを取得または設定します。<br/>            デフォルトのエンコーディングは UTF8 です。 |
