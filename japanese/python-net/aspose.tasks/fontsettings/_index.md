## FontSettings class

プロジェクトのビューをレンダリングする際に使用されるフォント設定を指定します。

FontSettings 型は次のメンバーを公開します:
## コンストラクタ
| 名前 | 説明 |
| :- | :- |
| FontSettings() | FontSettings クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| default_font_name | レンダリングに使用するデフォルト（またはフォールバック）フォントを取得または設定します。 |
| use_project_default_font | レンダリングにデフォルトフォントを使用するかどうかを示す値を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| set_font_folders(font_folders, recursive) | プロジェクトのビューをレンダリングする際に Aspose.Tasks が TrueType フォントを検索するフォルダーを設定します。 |
