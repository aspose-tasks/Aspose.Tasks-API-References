## BuiltInProjectPropertyCollection class

組み込みプロジェクトプロパティのコレクションを表します。

BuiltInProjectPropertyCollection 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| title | プロジェクトのタイトルを取得または設定します。 |
| subject | プロジェクトの件名を取得または設定します。 |
| author | プロジェクトの作成者を取得または設定します。 |
| manager | プロジェクトのマネージャーを取得または設定します。 |
| company | プロジェクトの会社を取得または設定します。 |
| category | プロジェクトのカテゴリを取得または設定します。 |
| keywords | プロジェクトのキーワードを取得または設定します。 |
| comments | プロジェクトのコメントを取得または設定します。 |
| hyperlink_base | プロジェクトのハイパーリンクベースを取得または設定します。 |
| 名前 |  |
