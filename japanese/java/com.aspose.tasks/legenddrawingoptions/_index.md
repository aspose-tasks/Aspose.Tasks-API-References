ビューの凡例をレンダリングする際に使用される可能なオプションを指定します。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [AfterLastPage](#AfterLastPage) | 凡例はプロジェクトのページの最終ページの後の別ページにレンダリングされます。 |
| [DefinedInView](#DefinedInView) | 凡例は、レンダリングされたビューの View.PageInfo.Legend.LegendOn プロパティに従って描画されます。 |
| [NoLegend](#NoLegend) | 凡例はレンダリングされません。 |
| [OnEveryPage](#OnEveryPage) | 凡例はすべてのページにレンダリングされます。 |
