プロジェクトの計算モードを指定します。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [Automatic](#Automatic) | 自動モードです。 |
| [Manual](#Manual) | 手動モードです。 |
| [None](#None) | なし。 |
### Automatic {#Automatic}
```
public static final int Automatic
```


自動モードです。このモードを使用すると、プロジェクトの日付とコストが再計算されます。

### Manual {#Manual}
```
public static final int Manual
```


手動モード。このモードでは必要なフィールドのみが再計算されます。たとえばオブジェクトの UID と ID などです。

### None {#None}
```
public static final int None
```


なし。このモードではプロジェクトの日付とコストは再計算されません。
