### getParentStyle() {#getParentStyle--}
```
public final GanttBarStyle getParentStyle()
```


カスタムタスク固有スタイルの親（または共通）スタイルを取得します。

--------------------

タスクは、異なる親スタイルを持つ複数のカスタムスタイルを設定できます。たとえば、親スタイルが "Critical" のカスタムスタイルと、親スタイルが "Normal" の別のスタイルがあるタスクを考えてみます。簡単に言えば、タスクがクリティカルな場合は最初のスタイルが適用され、タスクが非クリティカルになると二番目のスタイルが適用されます（このロジックは Microsoft Project Professional から継承されています）。

**Returns:**
[GanttBarStyle](../../com.aspose.tasks/ganttbarstyle) - parent (or common) style for custom task-specific style.

タスクは、異なる親スタイルを持つ複数のカスタムスタイルを設定できます。たとえば、親スタイルが "Critical" のカスタムスタイルと、親スタイルが "Normal" の別のスタイルがあるタスクを考えてみます。簡単に言えば、タスクがクリティカルな場合は最初のスタイルが適用され、タスクが非クリティカルになると二番目のスタイルが適用されます（このロジックは Microsoft Project Professional から継承されています）。

**Parameters:**
| パラメーター | 型 | 説明 |
| --- | --- | --- |
| value | [GanttBarStyle](../../com.aspose.tasks/ganttbarstyle) | カスタムタスク固有スタイル用の親（または共通）スタイル。 |
