## フィールド

| フィールド | 説明 |
| --- | --- |
| [Complete](#Complete) | タスクは 100% 完了しています。 |
| [Future](#Future) | 'Future' タスクステータスは、タスクの開始日がステータス日より後の場合に設定されます。 |
| [Late](#Late) | タスクは、ステータス日の前日の深夜までに時間分割累積完了率が達しない場合、遅れています。 |
| [OnSchedule](#OnSchedule) | タスクは、時間分割累積完了率がステータス日の前日までに少なくとも達している場合、予定通りです。 |
| [Undefined](#Undefined) | 未定義のタスクステータス。 |
