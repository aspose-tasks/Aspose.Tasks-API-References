| [DoesNotEqual](#DoesNotEqual) | Field の値が Value と等しくありません。 |
| [Equals](#Equals) | Field の値は Value と等しいです。 |
| [IsAnyValue](#IsAnyValue) | 「任意の値」条件。 |
| [IsGreaterThan](#IsGreaterThan) | Field の値が Value より大きいです。 |
| [IsGreaterThanOrEqualTo](#IsGreaterThanOrEqualTo) | Field の値が Value 以上です。 |
| [IsLessThan](#IsLessThan) | Field の値が Value 未満です。 |
| [IsLessThanOrEqualTo](#IsLessThanOrEqualTo) | Field の値が Value 以下です。 |
| [IsNotWithin](#IsNotWithin) | Field の値が Value の範囲外です。 |
| [IsOneOf](#IsOneOf) | Field の値が指定された Values のいずれかに等しいです。 |
