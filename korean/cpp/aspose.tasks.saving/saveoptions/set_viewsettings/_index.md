## set_ViewSettings {#set_viewsettings}

렌더링할 보기 ( View )를 설정합니다. 이 옵션을 사용하여 PDF, HTML 또는 이미지 형식으로 저장할 보기를 명시적으로 지정할 수 있습니다. 이 속성이 설정되면 프로젝트를 저장할 때 Visualization::PresentationFormat 속성이 무시됩니다. View는 다음 화면 중 하나여야 합니다 (( Aspose::Tasks::View::Screen )): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage).
