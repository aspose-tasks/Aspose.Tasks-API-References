## get_RollUpGanttBars {#get_rollupganttbars}

요약 작업 막대에 하위 작업이 표시될지 여부를 나타내는 값을 가져옵니다. 하위 작업의 경우 Rollup 필드는 하위 작업 Gantt 막대의 정보가 요약 작업 막대로 롤업되는지를 나타냅니다. 요약 작업의 경우 Rollup 필드는 요약 작업 막대가 롤업된 막대를 표시하는지를 나타냅니다. 하위 작업이 롤업되려면 요약 작업의 Rollup 필드를 Yes로 설정해야 합니다.
