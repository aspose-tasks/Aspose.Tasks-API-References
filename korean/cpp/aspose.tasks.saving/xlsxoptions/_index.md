## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

프로젝트 페이지를 XLSX로 렌더링할 때 추가 옵션을 지정할 수 있습니다.

## 생성자

| 이름 | 설명 |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | XlsxOptions 클래스를 새 인스턴스로 초기화합니다. 이 인스턴스는 프로젝트를 XLSX 형식으로 저장하는 데 사용할 수 있습니다. |

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | 렌더링할 할당 보기 열 목록을 가져옵니다 ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | 결과 XLSX 파일의 인코딩을 가져옵니다. 기본값은 System::Text::Encoding::UTF8 입니다. |
| [get_ResourceView](./get_resourceview/) | 렌더링할 리소스 보기 열 목록을 가져옵니다 ( ResourceViewColumn ). |
| [get_View](./get_view/) | XLSX 형식으로 저장할 보기 열(GanttChartColumn)의 목록을 가져옵니다. 설정되지 않은 경우 기본 열이 저장됩니다. |
| [set_AssignmentView](./set_assignmentview/) | 렌더링할 할당 보기 열 목록을 설정합니다 ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | 결과 XLSX 파일의 인코딩을 설정합니다. 기본값은 System::Text::Encoding::UTF8 입니다. |
| [set_ResourceView](./set_resourceview/) | 렌더링할 리소스 보기 열 목록을 설정합니다 ( ResourceViewColumn ). |
| [set_View](./set_view/) | XLSX 형식으로 저장할 보기 열(GanttChartColumn)의 목록을 설정합니다. 설정되지 않은 경우 기본 열이 저장됩니다. |
