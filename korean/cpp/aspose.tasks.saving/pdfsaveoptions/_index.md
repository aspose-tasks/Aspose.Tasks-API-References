## PdfSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

프로젝트 페이지를 PDF로 렌더링할 때 추가 옵션을 지정할 수 있습니다.

## 생성자

| 이름 | 설명 |
| --- | --- |
| [PdfSaveOptions](./pdfsaveoptions/) | PdfSaveOptions 클래스를 사용하여 PDF 형식으로 문서를 저장할 수 있는 새 인스턴스를 초기화합니다. |

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_Compliance](./get_compliance/) | 생성된 PDF 문서에 대한 원하는 준수 수준을 가져옵니다. 기본값은 PdfCompliance::Pdf15 입니다. |
| [get_DigitalSignatureDetails](./get_digitalsignaturedetails/) | 디지털 서명 세부 정보를 가져옵니다. 설정되지 않은 경우 서명이 수행되지 않습니다. |
| [get_EncryptionDetails](./get_encryptiondetails/) | 암호화 세부 정보를 가져옵니다. 설정되지 않은 경우 암호화가 수행되지 않습니다. |
| [get_FontSettings](./get_fontsettings/) | 프로젝트 뷰를 렌더링할 때 사용되는 글꼴 설정을 지정합니다. |
| [get_Pages](./get_pages/) | 프로젝트 레이아웃을 별도 파일로 저장할 때 저장할 페이지 번호 목록을 가져옵니다. |
| [get_PageSavingCallback](./get_pagesavingcallback/) | 렌더링된 각 페이지에 대한 출력 스트림을 가져오는 데 사용되는 사용자 정의 콜백을 가져옵니다. SaveToSeparateFiles 옵션을 사용할 때 적용됩니다. |
| [get_ReduceFooterGap](./get_reducefootergap/) | 마지막 작업과 푸터 사이의 간격을 줄여야 하는지 여부를 나타내는 값을 가져옵니다. |
| [get_SaveToSeparateFiles](./get_savetoseparatefiles/) | 프로젝트 페이지를 별도 파일로 저장해야 하는지 여부를 나타내는 값을 가져옵니다. |
| [get_TextCompression](./get_textcompression/) | 이미지를 제외한 모든 콘텐츠 스트림에 사용할 압축 유형을 가져옵니다. 기본값은 PdfTextCompression::Flate 입니다. |
| [set_Compliance](./set_compliance/) | 생성된 PDF 문서에 대한 원하는 준수 수준을 설정합니다. 기본값은 PdfCompliance::Pdf15 입니다. |
| [set_DigitalSignatureDetails](./set_digitalsignaturedetails/) | 디지털 서명 세부 정보를 설정합니다. 설정되지 않은 경우 서명이 수행되지 않습니다. |
| [set_EncryptionDetails](./set_encryptiondetails/) | 암호화 세부 정보를 설정합니다. 설정되지 않은 경우 암호화가 수행되지 않습니다. |
| [set_Pages](./set_pages/) | 프로젝트 레이아웃을 별도 파일로 저장할 때 저장할 페이지 번호 목록을 설정합니다. |
| [set_PageSavingCallback](./set_pagesavingcallback/) | 렌더링된 각 페이지에 대한 출력 스트림을 가져오는 데 사용되는 사용자 정의 콜백을 설정합니다. SaveToSeparateFiles 옵션을 사용할 때 적용됩니다. |
| [set_ReduceFooterGap](./set_reducefootergap/) | 마지막 작업과 푸터 사이의 간격을 줄여야 하는지 여부를 나타내는 값을 설정합니다. |
| [set_SaveToSeparateFiles](./set_savetoseparatefiles/) | 프로젝트 페이지를 별도 파일로 저장해야 하는지 여부를 나타내는 값을 설정합니다. |
| [set_TextCompression](./set_textcompression/) | 이미지를 제외한 모든 콘텐츠 스트림에 사용할 압축 유형을 설정합니다. 기본값은 PdfTextCompression::Flate 입니다. |
