## Analyze {#analyze}

지정된 프로젝트에 대한 위험 분석을 수행합니다. 분석은 몬테카를로 시뮬레이션을 기반으로 하며 결과는 RiskAnalysisResult 클래스의 인스턴스입니다.

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| 매개변수 | 설명 |
| --- | --- |
| 프로젝트 | 분석할 Project 클래스의 지정된 인스턴스. |
