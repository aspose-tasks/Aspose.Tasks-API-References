## GetRiskItems {#getriskitems}

**Returns:** an instance of the RiskItemStatisticsCollection for the specified risk type.

```cpp
GetRiskItems(RiskItemType itemType)
```

| 매개변수 | 설명 |
| --- | --- |
| itemType | 지정된 위험 유형; RiskItemType 열거형의 값 중 하나일 수 있습니다. |
