## RiskItemStatistics class

분석된 프로젝트의 작업에 대한 통계 데이터를 저장하는 항목을 나타냅니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | 위험 항목의 기대값을 가져옵니다. |
| [get_ItemType](./get_itemtype/) | RiskItemType 열거형의 인스턴스를 가져옵니다. |
| [get_Maximum](./get_maximum/) | Monte Carlo 시뮬레이션 중에 생성된 최대값을 가져옵니다. |
| [get_Minimum](./get_minimum/) | Monte Carlo 시뮬레이션 중에 생성된 최소값을 가져옵니다. |
| [get_StandardDeviation](./get_standarddeviation/) | 위험 항목의 표준 편차를 가져옵니다. |
| [GetPercentile](./getpercentile/) | 생성된 샘플 중 지정된 비율이 이하가 되는 값을 가져옵니다. |
| [ToString](./tostring/) | 위험 항목의 짧은 문자열 표현을 반환합니다. 표현의 정확한 세부 사항은 명시되지 않았으며 변경될 수 있습니다. |
