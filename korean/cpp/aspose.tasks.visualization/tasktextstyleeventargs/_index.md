## TaskTextStyleEventArgs class

이 클래스는 테이블 셀 내용 렌더링과 관련된 데이터 집합을 나타냅니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | 셀 내용 그리기에 사용될 TextStyle을 가져옵니다. 이 객체는 테이블 셀의 모양을 사용자 정의하는 데 사용할 수 있습니다. |
| [get_Column](./get_column/) | 현재 렌더링된 셀이 속한 ViewColumn을 가져옵니다. |
| [get_Task](./get_task/) | 현재 렌더링된 행에 해당하는 Task를 가져옵니다. |
| [set_CellTextStyle](./set_celltextstyle/) | 셀 내용 그리기에 사용될 TextStyle을 설정합니다. 이 객체는 테이블 셀의 모양을 사용자 정의하는 데 사용할 수 있습니다. |
