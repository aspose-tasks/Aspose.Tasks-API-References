## get_RenderLabelOnEachPage {#get_renderlabeloneachpage}

시간 구간이 여러 페이지에 걸칠 때 날짜 레이블을 각 페이지에 렌더링할지 여부를 정의하는 플래그를 가져옵니다. 값이 'true'이면 시간 구간이 여러 페이지에 걸칠 때 해당 기간의 날짜 레이블이 각 페이지에 렌더링됩니다. 값이 'false'이면 Alignment 속성값에 따라 날짜 레이블이 한 번만 렌더링됩니다.
