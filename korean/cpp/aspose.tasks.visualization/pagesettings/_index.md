## PageSettings class

프로젝트 보기 페이지의 인쇄 설정을 나타냅니다.

## 생성자

| 이름 | 설명 |
| --- | --- |
| [PageSettings](./pagesettings/) | PageSettings 클래스의 새 인스턴스를 초기화합니다. 프로젝트 뷰 페이지의 인쇄 설정을 나타냅니다. |

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | 인쇄를 정상 크기의 지정된 백분율(PercentOfNormalSize)로 조정할지 여부를 나타내는 값을 가져옵니다. |
| [get_FirstPageNumber](./get_firstpagenumber/) | 인쇄할 첫 페이지 번호를 가져옵니다. |
| [get_IsPortrait](./get_isportrait/) | 페이지 방향이 세로인지 여부를 나타내는 값을 가져옵니다; 페이지 방향이 가로인 경우 false를 반환합니다. |
| [get_PagesInHeight](./get_pagesinheight/) | 인쇄할 세로 방향 페이지 수를 가져옵니다. |
| [get_PagesInWidth](./get_pagesinwidth/) | 인쇄될 너비 페이지 수를 가져옵니다. |
| [get_PaperSize](./get_papersize/) | 용지 크기를 가져옵니다. PrinterPaperSize 열거형의 값 중 하나일 수 있습니다. |
| [get_PaperSizeId](./get_papersizeid/) | PrinterPaperSize 값 중 하나 또는 사용자 지정 페이지 크기 ID를 나타내는 정수를 가져옵니다. 이 값은 OS 설정에서 PaperSize를 가져오는 데 사용할 수 있습니다. |
| [get_PercentOfNormalSize](./get_percentofnormalsize/) | 인쇄를 조정할 정상 크기의 백분율을 가져옵니다. |
| [set_AdjustToPercentOfNormalSize](./set_adjusttopercentofnormalsize/) | 정상 크기의 지정된 백분율(PercentOfNormalSize)로 인쇄를 조정할지 여부를 나타내는 값을 설정합니다. |
| [set_FirstPageNumber](./set_firstpagenumber/) | 인쇄할 첫 페이지 번호를 설정합니다. |
| [set_IsPortrait](./set_isportrait/) | 페이지 방향이 세로인지 여부를 나타내는 값을 설정합니다; 페이지 방향이 가로인 경우 false를 반환합니다. |
| [set_PagesInHeight](./set_pagesinheight/) | 인쇄될 높이 페이지 수를 설정합니다. |
| [set_PagesInWidth](./set_pagesinwidth/) | 인쇄될 너비 페이지 수를 설정합니다. |
| [set_PaperSize](./set_papersize/) | 용지 크기를 설정합니다. PrinterPaperSize 열거형의 값 중 하나일 수 있습니다. |
| [set_PaperSizeId](./set_papersizeid/) | PrinterPaperSize 값 중 하나 또는 사용자 지정 페이지 크기 ID를 나타내는 정수를 설정합니다. 이 값은 OS 설정에서 PaperSize를 가져오는 데 사용할 수 있습니다. |
| [set_PercentOfNormalSize](./set_percentofnormalsize/) | 인쇄를 조정할 정상 크기의 백분율을 설정합니다. |
