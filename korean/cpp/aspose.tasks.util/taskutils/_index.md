## TaskUtils class

작업과 관련된 유용한 작업을 제공하는 도우미 클래스입니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [Apply](./apply/) | 지정된 알고리즘을 트리의 각 작업에 적용합니다. |
| [Filter](./filter/) | 조건을 만족하는 작업들의 새로운 트리를 구축합니다. |
| [Find](./find/) | 작업 트리에서 조건을 만족하는 작업을 찾습니다. |
| [TaskChildrenCount](./taskchildrencount/) | 재귀적으로 모든 레벨에 걸쳐 작업의 하위 작업 수를 계산합니다. |
