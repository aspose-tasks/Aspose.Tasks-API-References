## Aspose::Tasks::Connectivity namespace

이러한 유형을 사용하여 Microsoft Project Server 데이터베이스(MspDbSettings), Primavera 데이터베이스(PrimaveraDbSettings), MPD 파일(MpdSettings) 또는 일반 데이터베이스 소스(DbSettings)에 대한 연결을 구성합니다. 이 네임스페이스는 Aspose.Tasks 데이터 추출 및 조작 기능과의 원활한 통합을 위해 연결 구성을 중앙 집중화합니다.


## 클래스

| --- | --- |
| [DbSettings](./dbsettings/) | 프로젝트 데이터베이스에서 읽기 위한 설정을 지정할 수 있습니다. |
| [MpdSettings](./mpdsettings/) | MPD 형식(MS Access)에서 프로젝트 데이터를 읽기 위한 필요한 옵션을 설정할 수 있습니다. |
| [MspDbSettings](./mspdbsettings/) | MS Project Server 데이터에서 프로젝트 데이터를 읽기 위한 필요한 옵션을 설정할 수 있습니다. |
| [PrimaveraDbSettings](./primaveradbsettings/) | Primavera 데이터베이스에서 프로젝트 데이터를 읽기 위한 필요한 옵션을 설정할 수 있습니다. |
