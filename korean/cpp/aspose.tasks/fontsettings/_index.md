## FontSettings class

프로젝트 뷰를 렌더링할 때 사용되는 글꼴 설정을 지정합니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | 렌더링을 위한 기본(또는 대체) 글꼴을 가져옵니다. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | 해결된 글꼴을 사용자 지정하는 데 사용할 수 있는 콜백을 가져옵니다. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | 렌더링에 기본 글꼴을 사용해야 하는지 여부를 나타내는 값을 가져옵니다. |
| [set_DefaultFontName](./set_defaultfontname/) | 렌더링을 위한 기본(또는 대체) 글꼴을 설정합니다. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | 해결된 글꼴을 사용자 지정하는 데 사용할 수 있는 콜백을 설정합니다. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | 렌더링에 기본 글꼴을 사용해야 하는지 여부를 나타내는 값을 설정합니다. |
| [SetFontFolders](./setfontfolders/) | 프로젝트 뷰를 렌더링할 때 Aspose.Tasks가 TrueType 글꼴을 찾는 폴더를 설정합니다. |
