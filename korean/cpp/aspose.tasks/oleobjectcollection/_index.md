## OleObjectCollection class

OleObject 클래스의 인스턴스를 포함하는 컬렉션을 나타냅니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [Clear](./clear/) | 컬렉션을 비웁니다. 이러한 변경 사항을 지속하려면 project.Save를 새 MPPSaveOptions { WriteViewData = true; }와 함께 호출해야 합니다. |
| [GetEnumerator](./getenumerator/) | 이 컬렉션에 대한 열거자를 반환합니다. |
| [ToList](./tolist/) | OleObjectCollection 클래스의 인스턴스를 OleObject 클래스 인스턴스를 포함하는 리스트로 변환합니다. |
