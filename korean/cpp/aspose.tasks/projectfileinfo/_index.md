## ProjectFileInfo class

클래스 인스턴스에는 파일이 생성된 Microsoft Project의 프로젝트 파일 형식 및 버전에 대한 정보가 포함됩니다.

CanRead 속성을 사용하여 라이브러리가 프로젝트 파일을 처리할 수 있음을 정의합니다.
