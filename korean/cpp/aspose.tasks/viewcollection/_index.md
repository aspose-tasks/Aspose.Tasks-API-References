## ViewCollection class

View 객체 목록을 포함합니다. ICollection< View > 인터페이스를 구현합니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [Add](./add/) | 지정된 항목을 이 컬렉션에 추가합니다. |
| [Clear](./clear/) | 이 컬렉션의 모든 항목을 제거합니다. |
| [Contains](./contains/) | 지정된 항목이 이 컬렉션에 있으면 true를 반환하고, 그렇지 않으면 false를 반환합니다. |
| [CopyTo](./copyto/) | 지정된 배열 인덱스부터 시작하여 이 컬렉션의 요소를 지정된 배열에 복사합니다. |
| [get_Count](./get_count/) | 이 컬렉션에 포함된 요소 수를 가져옵니다. |
| [get_IsReadOnly](./get_isreadonly/) | 이 컬렉션이 읽기 전용인지 여부를 나타내는 값을 가져옵니다; 그렇지 않으면 false. |
| [get_ParentProject](./get_parentproject/) | View 객체의 상위 항목을 가져옵니다. 읽기 전용 Project. |
| [GetByName](./getbyname/) | 이름이 지정된 View를 검색하고 컬렉션 내에서 첫 번째 항목을 반환합니다. |
| [GetByViewScreen](./getbyviewscreen/) | 지정된 Screen 속성을 가진 View를 검색하고 컬렉션 내에서 첫 번째 항목을 반환합니다. |
| [GetEnumerator](./getenumerator/) | 이 컬렉션에 대한 열거자를 반환합니다. |
| [Remove](./remove/) | 이 컬렉션에서 특정 객체의 첫 번째 발생을 제거합니다. |
| [ToList](./tolist/) | 뷰 컬렉션을 View 객체 목록으로 변환합니다. |
