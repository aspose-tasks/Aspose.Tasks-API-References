## GetTimephasedData (1 of 2) {#gettimephaseddata_1}

**Returns:** List of Aspose::Tasks::TimephasedData .

```cpp

```

| 매개변수 | 설명 |
| --- | --- |
| 시작 | 시간 단계 데이터의 시작 날짜. |
| end | 시간 단계 데이터의 종료 날짜입니다. |
