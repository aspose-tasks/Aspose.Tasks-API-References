## ResourceCollection class

Resource 객체의 컬렉션을 나타냅니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [Add (3 overloads)](./add/) | 프로젝트 리소스 컬렉션의 마지막 위치에 새 리소스를 추가합니다. |
| [Clear](./clear/) | 직접 삭제는 지원되지 않으며, 이 메서드는 NotSupportedException을 발생시킵니다. |
| [get_Count](./get_count/) | ResourceCollection에 포함된 요소 수를 가져옵니다. |
| [get_ParentProject](./get_parentproject/) | ResourceCollection 객체의 상위 프로젝트를 가져옵니다. |
| [GetById](./getbyid/) | 지정된 ID를 가진 리소스를 반환합니다. |
| [GetByUid](./getbyuid/) | 지정된 UID를 가진 리소스를 반환합니다. |
| [GetEnumerator](./getenumerator/) | 이 컬렉션에 대한 열거자를 반환합니다. |
| [idx_get](./idx_get/) | 지정된 인덱스의 요소를 반환합니다. |
| [idx_set](./idx_set/) | 지정된 인덱스의 요소를 반환합니다. |
| [Remove](./remove/) | 이것은 ICollection의 Remove 메서드에 대한 스텁 구현으로, NotSupportedException만 발생시킵니다. |
| [ToList](./tolist/) | ResourceCollection 객체를 Resource 객체 목록으로 변환합니다. |
