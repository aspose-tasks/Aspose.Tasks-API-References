## LoadOptions class

파일이나 스트림에서 프로젝트를 로드할 때 추가 로드 매개변수를 지정할 수 있습니다.

## 생성자

| 이름 | 설명 |
| --- | --- |
| [LoadOptions](./loadoptions/) | LoadOptions 클래스의 새 인스턴스를 초기화합니다. |

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_Encoding](./get_encoding/) | HTML, MPX, XER 및 Primavera XML 형식에서 프로젝트를 읽는 데 사용되는 인코딩을 가져옵니다. 기본 인코딩은 UTF8입니다. |
| [get_ErrorHandler](./get_errorhandler/) | XML 구문 분석 오류를 처리하기 위한 콜백 메서드를 가져옵니다. |
| [get_Password](./get_password/) | 보호 비밀번호를 가져옵니다. |
| [get_PrimaveraReadOptions](./get_primaverareadoptions/) | Primavera 형식(Primavera P6 XER 또는 Primavera P6 Xml)을 로드하는 동작을 사용자 지정하는 데 사용할 수 있는 Tasks::PrimaveraReadOptions 클래스의 지정된 인스턴스를 가져옵니다. |
| [set_Encoding](./set_encoding/) | HTML, MPX, XER 및 Primavera XML 형식에서 프로젝트를 읽는 데 사용되는 인코딩을 설정합니다. 기본 인코딩은 UTF8입니다. |
| [set_ErrorHandler](./set_errorhandler/) | XML 구문 분석 오류를 처리하기 위한 콜백 메서드를 설정합니다. |
| [set_Password](./set_password/) | 보호 비밀번호를 설정합니다. |
| [set_PrimaveraReadOptions](./set_primaverareadoptions/) | Primavera 형식(Primavera P6 XER 또는 Primavera P6 Xml)을 로드하는 동작을 사용자 지정하는 데 사용할 수 있는 Tasks::PrimaveraReadOptions 클래스의 지정된 인스턴스를 설정합니다. |
