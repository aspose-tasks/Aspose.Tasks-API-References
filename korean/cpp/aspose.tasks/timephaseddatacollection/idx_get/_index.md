## idx_get {#idx_get}

지정된 인덱스에 있는 요소를 반환합니다. 설정 접근자는 지원되지 않습니다. 시간 단계 데이터를 설정하는 속성.

**Returns:** the element at the specified index.

```cpp
idx_get(int32_t index)
```

| 매개변수 | 설명 |
| --- | --- |
| 인덱스 | 가져올 요소의 0 기반 인덱스. |
