## ExtendedAttribute class

확장 속성을 나타냅니다.

현재 MSP Xml 2003/2007 및 mpp 2003에서 확장 속성을 읽는 모든 유형을 지원합니다. MSP mpp 2007의 경우 지속 시간 및 플래그를 제외한 모든 확장 속성 읽기를 지원합니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [get_AttributeDefinition](./get_attributedefinition/) | 속성 정의를 가져옵니다. |
| [get_DateValue](./get_datevalue/) | 날짜 유형(날짜, 시작, 종료) 속성에 대한 값을 가져옵니다. |
| [get_DurationValue](./get_durationvalue/) | ' Duration ' 유형의 속성에 대한 값을 가져옵니다. |
| [get_FieldId](./get_fieldid/) | 필드의 ID를 가져옵니다. |
| [get_FlagValue](./get_flagvalue/) | 'Flag' 유형의 속성에 플래그가 설정되어 있는지 여부를 나타내는 값을 가져옵니다. |
| [get_IsErrorValue](./get_iserrorvalue/) | 확장 속성 값 계산이 오류가 발생했는지 여부를 가져옵니다. |
| [get_NumericValue](./get_numericvalue/) | 숫자 유형(Cost, Number) 속성에 대한 값을 가져옵니다. |
| [get_TextValue](./get_textvalue/) | 'Text' 유형 속성에 대한 값을 가져옵니다. |
| [get_ValueGuid](./get_valueguid/) | 조회 값의 GUID를 가져옵니다. |
| [get_ValueReadOnly](./get_valuereadonly/) | 이 ExtendedAttribute 인스턴스의 값이 읽기 전용인지 여부를 나타내는 값을 가져옵니다. 이 객체에 대한 ExtendedAttributeDefinition에 수식이나 롤업이 정의되어 있으면 true를 반환합니다. |
| [set_DateValue](./set_datevalue/) | 날짜 유형(Date, Start, Finish) 속성에 값을 설정합니다. |
| [set_DurationValue](./set_durationvalue/) | ' Duration ' 유형 속성에 값을 설정합니다. |
| [set_FlagValue](./set_flagvalue/) | 'Flag' 유형 속성에 플래그가 설정되어 있는지 여부를 나타내는 값을 설정합니다. |
| [set_NumericValue](./set_numericvalue/) | 숫자 유형(Cost, Number) 속성에 값을 설정합니다. |
| [set_TextValue](./set_textvalue/) | 'Text' 유형 속성에 값을 설정합니다. |
| [ToString](./tostring/) | 확장 속성의 짧은 문자열 표현을 반환합니다. |
