## IPageSavingCallback class

다중 페이지 문서의 각 페이지가 별도의 스트림에 저장될 때 호출되는 콜백을 나타냅니다.

IPageSavingCallback 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| page_saving(args) | 페이지가 스트림에 저장될 때 호출되는 메서드입니다. |
| on_finish() | 모든 페이지가 기록될 때 호출되는 메서드입니다. |
