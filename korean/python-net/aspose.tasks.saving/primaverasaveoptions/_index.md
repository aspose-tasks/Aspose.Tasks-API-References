## PrimaveraSaveOptions class

프로젝트를 Primavera XER 형식으로 저장할 때 추가 옵션을 지정할 수 있습니다.

PrimaveraSaveOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PrimaveraSaveOptions() | 새로운 [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| save_format | 이 저장 옵션 개체가 사용될 경우 문서가 저장될 형식을 가져오거나 설정합니다. |
| activity_id_increment | 활동 ID를 재번호 매기는데 사용되는 증가값을 가져오거나 설정합니다. |
| activity_id_prefix | 활동 ID를 재번호 매기는데 사용되는 접두사를 가져오거나 설정합니다. |
| activity_id_suffix | 활동 ID를 재번호 매기는데 사용되는 접미사를 가져오거나 설정합니다. |
| renumber_activity_ids | 활동 ID를 재번호 매겨야 하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| skip_summary_assignments | 내보내기 중에 리소스가 요약 작업에 할당되는 것을 건너뛸지 여부를 나타내는 값을 가져오거나 설정합니다. |
