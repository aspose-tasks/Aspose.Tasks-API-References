## PageSavingArgs class

이 클래스는 문서 페이지를 스트림에 저장하는 것과 관련된 데이터 집합을 나타냅니다.

PageSavingArgs 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| page_number | 작성될 페이지 번호를 가져옵니다. |
| keep_stream_open | 렌더링 루틴이 페이지가 기록된 후 [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/)을 열어 둬야 하는지를 나타내는 값을 가져오거나 설정합니다. |
| stream | 페이지를 쓰기 위한 스트림을 가져오거나 설정합니다. |
