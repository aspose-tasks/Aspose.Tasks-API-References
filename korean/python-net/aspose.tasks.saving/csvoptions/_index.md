## CsvOptions class

프로젝트를 CSV로 저장할 때 추가 옵션을 지정할 수 있습니다.

CsvOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| CsvOptions() | [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) 클래스의 새 인스턴스를 초기화합니다. 이 인스턴스는 프로젝트를 CSV 형식으로 저장하는 데 사용할 수 있습니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| save_format | 이 저장 옵션 개체가 사용될 경우 문서가 저장될 형식을 가져오거나 설정합니다. |
| data_category | 저장될 데이터 카테고리를 가져오거나 설정합니다. |
| 인코딩 | CSV를 저장할 인코딩을 가져오거나 설정합니다. |
| include_headers | 헤더를 포함할지 여부를 나타내는 값을 가져오거나 설정합니다 (기본값은 TRUE). |
| text_delimiter | 텍스트 구분자를 가져오거나 설정합니다. |
| view | XLSX 형식으로 저장할 보기 열([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) 목록을 가져오거나 설정합니다.<br/>            설정하지 않으면 기본 열이 저장됩니다. |
