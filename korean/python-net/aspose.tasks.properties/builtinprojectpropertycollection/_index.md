## BuiltInProjectPropertyCollection class

내장 프로젝트 속성의 컬렉션을 나타냅니다.

BuiltInProjectPropertyCollection 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| title | 프로젝트의 제목을 가져오거나 설정합니다. |
| subject | 프로젝트의 주제를 가져오거나 설정합니다. |
| author | 프로젝트의 저자를 가져오거나 설정합니다. |
| manager | 프로젝트의 관리자를 가져오거나 설정합니다. |
| company | 프로젝트의 회사를 가져오거나 설정합니다. |
| category | 프로젝트의 범주를 가져오거나 설정합니다. |
| keywords | 프로젝트의 키워드를 가져오거나 설정합니다. |
| comments | 프로젝트의 주석을 가져오거나 설정합니다. |
| hyperlink_base | 프로젝트의 하이퍼링크 기본값을 가져오거나 설정합니다. |
| 이름 |  |
