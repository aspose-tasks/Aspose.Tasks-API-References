## MpdSettings class

MPD 형식(MS Access 데이터베이스 파일 형식)에서 프로젝트 데이터를 읽기 위한 필요한 옵션을 설정할 수 있습니다.

MpdSettings 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| MpdSettings(connection_string, project_id) | 새 인스턴스를 초기화합니다 [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) 클래스. |
## 속성
| 이름 | 설명 |
| :- | :- |
| connection_string | 연결 문자열을 가져오거나 설정합니다. |
| provider_invariant_name | 프로바이더 불변 이름을 가져오거나 설정합니다. 이 이름은 클래스의 인스턴스를 가져오는 데 사용됩니다. |
| project_id | 읽을 프로젝트의 ID를 가져옵니다. |
