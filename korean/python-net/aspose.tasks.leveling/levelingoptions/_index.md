## LevelingOptions class

리소스 레벨링 매개변수를 지정할 수 있습니다.

LevelingOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| LevelingOptions() | 새로운 [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| start_date | 레벨링 기간 시작 날짜를 가져오거나 설정합니다. 기본값은 프로젝트의 시작 날짜입니다. |
| finish_date | 레벨링 기간 종료 날짜를 가져오거나 설정합니다. 기본값은 프로젝트의 종료 날짜입니다. |
| 리소스 | 레벨링될 리소스 목록을 가져오거나 설정합니다. null로 설정하면 모든 프로젝트 리소스가 레벨링됩니다. |
| leveling_order | 레벨링 알고리즘이 과다 할당된 작업을 지연시키는 순서를 가져옵니다.<br/>            전체 할당 초과를 일으키는 작업과 지연될 수 있는 작업을 결정한 후, 지정된 순서가 사용되어 먼저 지연시켜야 할 작업을 결정합니다. |
| message_level | Aspose.Tasks가 리소스 레벨링 중에 발생시키는 로그 메시지의 수준을 가져오거나 설정합니다. |
| message_handler | Aspose.Tasks가 리소스 레벨링 중에 생성하는 로그 메시지를 가로챌 수 있는 메시지 핸들러 콜백을 가져오거나 설정합니다. |
