## PageMargins class

인쇄용 페이지 여백을 나타냅니다.

PageMargins 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PageMargins() | 새 인스턴스를 초기화합니다 PageMargins 클래스. |
## 속성
| 이름 | 설명 |
| :- | :- |
| top | 상단 여백의 크기를 센티미터 단위로 가져오거나 설정합니다. |
| bottom | 하단 여백의 크기를 센티미터 단위로 가져오거나 설정합니다. |
| left | 왼쪽 여백의 크기를 센티미터 단위로 가져오거나 설정합니다. |
| right | 오른쪽 여백의 크기를 센티미터 단위로 가져오거나 설정합니다. |
| borders | 테두리를 인쇄할 위치를 가져오거나 설정합니다. [Border](/tasks/python-net/aspose.tasks.visualization/border/) 열거형의 값 중 하나일 수 있습니다. |
