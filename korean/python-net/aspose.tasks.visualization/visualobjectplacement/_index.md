## VisualObjectPlacement class

보기에서 [OleObject](/tasks/python-net/aspose.tasks/oleobject/)의 배치 및 모양을 나타냅니다.

VisualObjectPlacement 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| VisualObjectPlacement() | 새로운 [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| ole_object_id | [OleObject](/tasks/python-net/aspose.tasks/oleobject/) 객체의 Id를 가져오거나 설정합니다. |
| task_id | 'Attach to task' 옵션이 선택된 경우 작업의 Id를 가져오거나 설정하고, 그렇지 않으면 -1을 반환합니다. |
| width | 시각 객체의 표시 너비를 가져오거나 설정합니다. |
| height | 시각 객체의 표시 높이를 가져오거나 설정합니다. |
| vertical_offset | 시각 객체의 수직 오프셋을 가져오거나 설정합니다. |
| horizontal_offset | 시각 객체의 수평 오프셋을 가져오거나 설정합니다. |
| timescale_date | 'Attach to timescale' 옵션이 선택된 경우 시각 객체의 날짜 배치를 가져오거나 설정합니다. |
| attachment_point | 'Attach to task' 옵션이 선택된 경우 시각 객체를 작업에 상대적으로 정렬하는 방식을 가져오거나 설정합니다. |
| border_line_color | 테두리 선 색상을 가져오거나 설정합니다. |
| border_line_thickness | 테두리 선 두께를 가져오거나 설정합니다 (허용 값은 0 - 5입니다). |
| fill_color | 채우기 색상을 가져오거나 설정합니다. |
| fill_pattern | 채우기 패턴을 가져오거나 설정합니다. |
