## TableTextStyle class

보기 테이블의 텍스트 스타일을 나타냅니다.

TableTextStyle 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TableTextStyle(row_uid) | TableTextStyle 클래스의 새 인스턴스를 초기화합니다. |
| TableTextStyle(row_uid, font) | TableTextStyle 클래스의 새 인스턴스를 초기화합니다. |
| TableTextStyle(row_uid, font_size, font_style) | TableTextStyle 클래스의 새 인스턴스를 초기화합니다. |
| TableTextStyle(row_uid, font_style) | TableTextStyle 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| font | 텍스트 스타일의 글꼴을 가져오거나 설정합니다. |
| color | 텍스트의 색상을 가져오거나 설정합니다. |
| item_type | 다음 [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) 열거형 값을 반환합니다. |
| background_pattern | 텍스트 스타일의 배경 패턴을 가져오거나 설정합니다.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | 텍스트 스타일의 배경 색상을 가져오거나 설정합니다.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| row_uid | 행 고유 ID를 가져옵니다. |
| field | 스타일이 적용될 필드를 가져오거나 설정합니다.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/tabletextstyle/). |
