## PageSettings class

프로젝트 보기의 페이지에 대한 인쇄 설정을 나타냅니다.

PageSettings 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PageSettings() | [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/) 클래스의 새 인스턴스를 초기화합니다. <br/>            프로젝트 뷰의 페이지에 대한 인쇄 설정을 나타냅니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| is_portrait | 페이지 방향이 세로인지 여부를 나타내는 값을 가져오거나 설정합니다; 페이지 방향이 가로인 경우 false를 반환합니다. |
| adjust_to_percent_of_normal_size | 정규 크기의 지정된 백분율([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/))에 맞게 인쇄를 조정할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| percent_of_normal_size | 인쇄를 조정하기 위해 정상 크기의 백분율을 가져오거나 설정합니다. |
| pages_in_width | 인쇄할 가로 페이지 수를 가져오거나 설정합니다. |
| pages_in_height | 인쇄할 세로 페이지 수를 가져오거나 설정합니다. |
| paper_size | 용지 크기를 가져오거나 설정합니다. [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/) 열거형의 값 중 하나일 수 있습니다. |
| paper_size_id | PrinterPaperSize 값 중 하나 또는 사용자 정의 페이지 크기 ID를 나타내는 정수를 가져오거나 설정합니다.<br/>            이 값은 OS 설정에서 PaperSize를 가져오는 데 사용할 수 있습니다. |
| first_page_number | 인쇄할 첫 페이지 번호를 가져오거나 설정합니다. |
