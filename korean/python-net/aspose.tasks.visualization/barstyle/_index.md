## BarStyle class

프로젝트 보기에서 항목의 막대 시각 스타일을 변경합니다.

BarStyle 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| BarStyle() | 새로운 [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| bar_color | 바 스타일의 aspose.pydrawing.Color를 가져오거나 설정합니다. |
| start_shape_color | 막대 시작 부분에 있는 모양의 aspose.pydrawing.Color를 가져오거나 설정합니다. |
| start_shape_type | 시작 모양의 유형을 가져오거나 설정합니다. |
| end_shape_color | 막대 끝 부분에 있는 모양의 aspose.pydrawing.Color를 가져오거나 설정합니다. |
| end_shape_type | 끝 모양의 유형을 가져오거나 설정합니다.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | 바 스타일의 [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/)을 가져오거나 설정합니다. |
| bar_shape | 바 스타일의 [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/)을 가져오거나 설정합니다. |
| start_shape | 막대 시작 부분에 있는 [Shape](/tasks/python-net/aspose.tasks.visualization/shape/)을 가져오거나 설정합니다. |
| end_shape | 막대 끝 부분에 있는 [Shape](/tasks/python-net/aspose.tasks.visualization/shape/)을 가져오거나 설정합니다. |
| text_style | 막대 텍스트의 스타일을 가져오거나 설정합니다. |
| left_field | 막대 왼쪽에 표시될 필드를 가져오거나 설정합니다. |
| top_field | 막대 상단에 표시될 필드를 가져오거나 설정합니다. |
| right_field | 막대 오른쪽에 표시될 필드를 가져오거나 설정합니다. |
| bottom_field | 막대의 하단에 표시될 필드를 가져오거나 설정합니다. |
| inside_field | 막대 내부에 표시될 필드를 가져오거나 설정합니다. |
| from_address | 간트 막대의 시작점 위치를 가져오거나 설정합니다.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | gant 막대의 종료 지점 위치를 가져오거나 설정합니다. |
