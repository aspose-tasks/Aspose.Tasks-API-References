## FontDescriptor class

글꼴 정보를 나타냅니다.

FontDescriptor 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| FontDescriptor(font_family, size) | FontDescriptor 클래스의 새 인스턴스를 초기화합니다. |
| FontDescriptor(font_family, size, style) | FontDescriptor 클래스의 새 인스턴스를 초기화합니다. |
| FontDescriptor(font, style) | 지정된 글꼴 패밀리, 크기 및 스타일을 사용하여 [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| font_family | 글꼴 패밀리의 이름을 가져옵니다. |
| size | 글꼴의 크기를 가져옵니다. |
| style | 글꼴의 스타일을 가져옵니다. |
