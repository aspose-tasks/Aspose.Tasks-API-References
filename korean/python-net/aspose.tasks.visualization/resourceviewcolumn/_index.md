## ResourceViewColumn class

ResourceUsage 보기와 ResourceSheet 보기에서 사용되는 프로젝트의 보기 클래스입니다.

ResourceViewColumn 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ResourceViewColumn(width, field) | ResourceViewColumn 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| field | 열 필드. <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/). |
| name | 열 이름을 가져옵니다. |
| string_alignment | 텍스트 정렬을 가져오거나 설정합니다 ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/) 열거형의 값 중 하나일 수 있습니다). |
| width | 열 너비를 가져옵니다. |
| text_style_modification_callback | 열 셀의 모양을 사용자 정의하는 데 사용할 수 있는 콜백을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_column_text(resource) | 현재 리소스를 열 텍스트로 변환합니다. |
