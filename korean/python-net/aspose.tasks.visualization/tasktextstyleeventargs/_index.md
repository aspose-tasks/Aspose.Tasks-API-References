## TaskTextStyleEventArgs class

이 클래스는 테이블 셀 내용 렌더링과 관련된 데이터 집합을 나타냅니다.

TaskTextStyleEventArgs 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| cell_text_style | 셀 내용 그리기에 사용될 TextStyle를 가져오거나 설정합니다. 이 객체를 사용하여 테이블 셀의 모양을 사용자 지정할 수 있습니다. |
| task | 현재 렌더링된 행에 해당하는 [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/)을 가져옵니다. |
| column | 현재 렌더링된 셀이 속한 [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/)을 가져옵니다. |
