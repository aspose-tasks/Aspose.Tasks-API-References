## TextStyle class

프로젝트 보기의 항목에 대한 텍스트 시각 스타일을 변경합니다.

TextStyle 유형은 다음 멤버를 제공합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextStyle() | 기본 설정으로 [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) 클래스의 새 인스턴스를 초기화합니다. |
| TextStyle(font_size, font_style) | TextStyle 클래스의 새 인스턴스를 초기화합니다. |
| TextStyle(font_style) | [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) 클래스의 새 인스턴스를 기본 글꼴과 지정된 글꼴 크기 및 스타일로 초기화합니다. |
| TextStyle(font) | [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) 클래스의 새 인스턴스를 지정된 글꼴 설정으로 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| font | 텍스트 스타일의 글꼴을 가져오거나 설정합니다. |
| color | 텍스트의 색상을 가져오거나 설정합니다. |
| item_type | 텍스트 스타일의 [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/)을 가져오거나 설정합니다. |
| background_pattern | 텍스트 스타일의 배경 패턴을 가져오거나 설정합니다.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | 텍스트 스타일의 배경 색상을 가져오거나 설정합니다.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
