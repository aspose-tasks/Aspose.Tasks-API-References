## TimescaleTier class

간트 차트의 타임스케일에 대한 단일 계층을 나타냅니다.

TimescaleTier 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TimescaleTier() | 새 인스턴스를 초기화합니다 [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) 클래스. |
| TimescaleTier(unit, count) | 새 인스턴스를 초기화합니다 TimescaleTier 클래스. |
## 속성
| 이름 | 설명 |
| :- | :- |
| count | 계층에 대한 레이블을 표시할 시간 단위 간격을 가져오거나 설정합니다.<br/>            기본값은 1입니다. |
| label | 시간 눈금 계층에 대한 날짜 레이블 [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)을 가져오거나 설정합니다. |
| alignment | 계층의 각 시간 기간 내에서 레이블을 정렬하는 방법을 가져오거나 설정합니다 ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | 계층 레이블을 회계 연도에 기반할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_ticks | 계층에서 시간 기간을 구분하는 눈금 표시를 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| unit | 시간 눈금 계층에 대한 시간 눈금 단위 [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/)를 가져오거나 설정합니다.<br/>            기본값은 |
| render_label_on_each_page | 시간 기간이 여러 페이지에 걸칠 때 각 페이지에 날짜 레이블을 렌더링할지 여부를 정의하는 플래그를 가져오거나 설정합니다.<br/>            값이 'true'이면, 시간 기간이 여러 페이지에 걸칠 때 해당 기간의 날짜 레이블이 각 페이지에 렌더링됩니다.<br/>            값이 'false'이면, [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/) 속성 값에 따라 날짜 레이블이 한 번만 렌더링됩니다. |
