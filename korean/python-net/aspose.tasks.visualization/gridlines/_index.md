## Gridlines class

GanttChart 보기에서 나타나는 그리드 라인을 나타냅니다.

Gridlines 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Gridlines() | Gridlines 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| interval | 그리드 라인 사이의 간격을 지정하는 0에서 99 사이의 숫자를 가져오거나 설정합니다. |
| interval_color | 보조 그리드 라인의 색상을 가져오거나 설정합니다. |
| interval_pattern | 보조 그리드 라인의 선 패턴을 가져오거나 설정합니다. |
| normal_color | 일반 그리드 라인의 색상을 가져오거나 설정합니다. |
| normal_pattern | 일반 그리드 라인의 선 패턴을 가져오거나 설정합니다. |
| type | 그리드 라인 유형을 가져오거나 설정합니다. |
