## PageViewSettings class

프로젝트 보기의 인쇄 설정을 나타냅니다.

PageViewSettings 유형은 다음 멤버를 제공합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PageViewSettings() | PageViewSettings 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| first_columns_count | 모든 페이지에 인쇄될 첫 번째 열의 수를 가져오거나 설정합니다. |
| fit_timescale_to_end_of_page | 인쇄 시 타임스케일을 페이지 끝에 맞출지 여부를 나타내는 값을 가져오거나 설정합니다. |
| print_all_sheet_columns | 뷰의 모든 시트 열을 인쇄할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| print_blank_pages | 뷰의 빈 페이지를 인쇄할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| print_first_columns_count_on_all_pages | 모든 페이지에 지정된 수의 첫 번째 열을 인쇄할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| print_notes | 노트를 인쇄할지 여부를 나타내는 값을 가져오거나 설정합니다. |
