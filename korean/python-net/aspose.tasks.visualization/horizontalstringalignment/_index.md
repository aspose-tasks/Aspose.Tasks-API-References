## HorizontalStringAlignment enumeration

텍스트 문자열이 레이아웃 사각형에 대해 정렬되는 방식을 지정합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| NEAR | 텍스트를 레이아웃에 가깝게 정렬하도록 지정합니다. 왼쪽에서 오른쪽으로 진행하는 레이아웃에서는 가까운 위치가 왼쪽이며, 오른쪽에서 왼쪽으로 진행하는 레이아웃에서는 가까운 위치가 오른쪽입니다. |
| CENTER | 텍스트가 레이아웃 사각형의 중앙에 정렬되도록 지정합니다. |
| FAR | 텍스트가 레이아웃 사각형의 원점 위치에서 멀리 정렬되도록 지정합니다. 왼쪽에서 오른쪽으로 진행하는 레이아웃에서는 먼 위치가 오른쪽이며, 오른쪽에서 왼쪽으로 진행하는 레이아웃에서는 먼 위치가 왼쪽입니다. |
