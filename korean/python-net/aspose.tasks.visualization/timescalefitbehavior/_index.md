## TimescaleFitBehavior enumeration

시간축 영역을 페이지 너비에 맞추는 동작을 나타냅니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| DEFINED_IN_VIEW | 캘린더 섹션은 렌더링된 View의 View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage 속성에 따라 렌더링됩니다. |
| NO_SCALE_TO_END_DATE | 캘린더 섹션은 페이지에 빈 공간이 있더라도 EndDate까지 정확히 렌더링됩니다. |
| NO_SCALE_TO_END_OF_PAGE | 캘린더 섹션은 마지막 페이지의 끝(오른쪽)까지 렌더링됩니다.<br/>            따라서 마지막으로 렌더링된 날짜가 EndDate를 초과할 수 있습니다. |
| SCALE_TO_END_OF_PAGE | 렌더링 엔진은 EndDate가 마지막 페이지의 끝(오른쪽)과 정렬되도록 날짜를 맞추려고 시도합니다.<br/>            이는 MS Project의 "Page Setup \ View \ Fit timescale to end of page" 옵션이 활성화된 것과 동일합니다. |
