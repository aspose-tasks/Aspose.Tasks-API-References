## TimescaleUnit enumeration

Gantt 차트 또는 기타 시간 단계 보기에서 시간축의 모든 계층에 대한 시간 단위를 지정합니다.

| 멤버 이름 | 설명 |
| :- | :- |

| MINUTES | 분 시간 눈금 단위를 나타냅니다. |

| THIRDS_OF_MONTHS | 월의 3분의 1 단위의 타임스케일을 나타냅니다. |
