## GanttBarStyle class

Gantt 차트 보기에서 MSP가 사용하는 막대 스타일을 나타냅니다.

GanttBarStyle 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| GanttBarStyle() | 새로운 [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| bottom_field | 막대 하단에 표시될 데이터를 가져오거나 설정합니다.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| end_shape | 막대의 끝 모양을 가져오거나 설정합니다. |
| end_shape_color | 끝 모양의 색상을 가져오거나 설정합니다. |
| end_shape_type | 끝 모양의 유형을 가져오거나 설정합니다.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| from_address | 간트 막대의 시작점 위치를 가져오거나 설정합니다.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | 막대 내부에 표시될 데이터를 가져오거나 설정합니다.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| left_field | 막대 왼쪽에 표시될 데이터를 가져오거나 설정합니다.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| middle_fill_pattern | 간트 막대의 채우기 패턴을 가져오거나 설정합니다. |
| middle_shape | 막대의 중간 모양을 가져오거나 설정합니다. |
| middle_shape_color | 중간 모양의 색상을 가져오거나 설정합니다. |
| name | 스타일의 이름을 가져오거나 설정합니다. |
| right_field | 막대 오른쪽에 표시될 데이터를 가져오거나 설정합니다.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| row | 행 번호를 가져오거나 설정합니다. |
| show_for_categories | 스타일이 적용되는 작업 카테고리를 가져오거나 설정합니다. Gantt 차트의 막대에 대한 상위(또는 공통) 스타일에 적용됩니다.<br/>            (참조 [bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| show_for_task_uid | 스타일이 적용되는 작업의 고유 ID를 가져오거나 설정합니다. Gantt 차트의 막대에 대한 작업별 스타일에 적용됩니다 (참조 [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | 막대의 시작 모양을 가져오거나 설정합니다. |
| start_shape_color | 시작 모양의 색상을 가져오거나 설정합니다. |
| start_shape_type | 시작 모양의 유형을 가져오거나 설정합니다. |
| to | gant 막대의 종료 지점 위치를 가져오거나 설정합니다. |
| top_field | 막대 상단에 표시될 데이터를 가져오거나 설정합니다. |
| parent_style | 사용자 지정 작업별 스타일에 대한 상위(또는 공통) 스타일을 가져오거나 설정합니다. |
