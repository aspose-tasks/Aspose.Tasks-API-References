## RecurringInterval class

간트 차트 보기의 진행 라인에 사용되는 반복 간격을 나타냅니다.

RecurringInterval 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| RecurringInterval() | RecurringInterval 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| interval | 반복 간격을 가져오거나 설정합니다.<br/>            [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/) 유형의 모든 값을 사용할 수 있습니다. |
| daily_day_number | 일일 날짜 번호를 가져오거나 설정합니다. |
| daily_workday | 일일 진행 라인에 대해 해당 날짜가 근무일인지 여부를 나타내는 값을 가져오거나 설정합니다. |
| weekly_week_number | 주간 진행 라인의 주 번호를 가져오거나 설정합니다. |
| monthly_day | 월별 진행 라인을 일별로 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| monthly_day_day_number | 월별 진행 라인의 일 번호를 가져오거나 설정합니다. |
| monthly_day_month_number | 월별 진행 라인의 월 번호를 가져오거나 설정합니다. |
| monthly_first_last | 첫 번째 또는 마지막 사전 정의된 일에 따라 진행 라인을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| monthly_first_last_month_number | 첫 번째 또는 마지막 사전 정의된 일에 따라 표시되는 진행 라인의 월 번호를 가져오거나 설정합니다. |
| monthly_first_last_day | 월별 진행 라인의 첫 번째 또는 마지막 일 유형을 가져오거나 설정합니다. |
| weekly_days | 주간 진행 라인의 일 목록을 가져옵니다. |
