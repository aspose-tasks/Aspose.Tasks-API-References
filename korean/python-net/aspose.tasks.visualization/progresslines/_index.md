## ProgressLines class

간트 차트 보기의 진행 라인을 나타냅니다.

ProgressLines 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ProgressLines() | ProgressLines 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| display_at_current_date | 현재 날짜에 진행 라인을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| display_at_recurring_intervals | 반복 간격에 진행 라인을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| recurring_interval | 반복 간격을 가져오거나 설정합니다.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/) |
| begin_at_project_start | 프로젝트 시작 날짜부터 진행 라인을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| begin_at_date | 진행 라인을 표시할 시작 날짜를 가져오거나 설정합니다. |
| display_selected | 선택된 날짜에 진행 라인을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| is_baseline_plan | 베이스라인 계획 또는 실제에 대한 진행 라인을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_date | 각 진행 라인에 대한 날짜를 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| date_format | 날짜 형식을 가져오거나 설정합니다 ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | 진행 라인 레이블에 사용되는 글꼴을 가져오거나 설정합니다. |
| line_pattern | 현재 진행 라인의 선 패턴을 가져오거나 설정합니다.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | 현재 진행 라인의 선 색상을 가져오거나 설정합니다. |
| progress_point_shape | 진행 지점 모양을 가져오거나 설정합니다.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | 진행 지점의 색상을 가져오거나 설정합니다. |
| other_line_pattern | 다른 진행 라인의 선 패턴을 가져오거나 설정합니다. |
| other_line_color | 다른 진행 라인의 색상을 가져오거나 설정합니다. |
| other_progress_point_shape | 다른 진행 라인의 진행 지점 모양을 가져오거나 설정합니다. |
| other_progress_point_color | 다른 진행 지점의 색상을 가져오거나 설정합니다. |
| selected_dates | 진행 라인을 표시하기 위해 선택된 날짜 목록을 가져옵니다. |
