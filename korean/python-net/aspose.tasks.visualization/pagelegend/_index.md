## PageLegend class

프로젝트 인쇄에 사용되는 페이지 범례를 나타냅니다.

PageLegend 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PageLegend() | PageLegend 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| left_text | 부모 요소에 표시할 왼쪽 정렬 텍스트를 가져오거나 설정합니다. |
| centered_text | 부모 요소에 표시할 가운데 정렬 텍스트를 가져오거나 설정합니다. |
| right_text | 부모 요소에 표시할 오른쪽 정렬 텍스트를 가져오거나 설정합니다. |
| left_image | 부모 요소에 표시될 왼쪽 정렬 이미지를 가져오거나 설정합니다. |
| centered_image | 부모 요소에 표시될 가운데 정렬 이미지를 가져오거나 설정합니다. |
| right_image | 부모 요소에 표시될 오른쪽 정렬 이미지를 가져오거나 설정합니다. |
| left_image_size | 왼쪽 이미지의 표시 크기를 가져오거나 설정합니다. |
| centered_image_size | 중앙 이미지의 표시 크기를 가져오거나 설정합니다. |
| right_image_size | 오른쪽 이미지의 표시 크기를 가져오거나 설정합니다. |
| legend_on | 범례가 표시되는 페이지를 가져오거나 설정합니다. [Legend](/tasks/python-net/aspose.tasks.visualization/legend/) 열거형의 값 중 하나일 수 있습니다. |
| width | 범례의 왼쪽 부분(기본적으로 프로젝트 이름과 날짜를 포함)의 너비를 센티미터 단위로 가져오거나 설정합니다. |
