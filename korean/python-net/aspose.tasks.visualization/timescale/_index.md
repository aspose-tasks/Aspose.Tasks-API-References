## Timescale enumeration

프로젝트를 그래픽 형식으로 내보낼 때 Gantt 차트, 작업 사용량 또는 리소스 사용량 보기에서 시간축을 렌더링하는 방법을 지정하는 옵션을 정의합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| DEFINED_IN_VIEW | 프로젝트 보기 속성에 정의된 타임스케일 설정을 사용합니다: [bottom_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/),<br/>            [middle_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/), [top_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/).<br/>            보기 데이터가 포함된 형식에 대해 유효합니다. 예를 들어, MPP 형식으로 읽은 프로젝트가 해당됩니다. |
| DAYS | 세부 수준이 최소 하루인 사전 정의된 2단계 타임스케일입니다. |
| THIRDS_OF_MONTHS | 세부 수준이 한 달의 3분의 1인 사전 정의된 2단계 타임스케일입니다. |
| MONTHS | 세부 수준이 최소 한 달인 사전 정의된 2단계 타임스케일입니다. |
