## PageInfo class

MPP 파일 형식에 존재하며 인쇄에 사용되는 페이지 설정 데이터를 나타냅니다.

PageInfo 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PageInfo() | 새로운 [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) 클래스 인스턴스를 초기화합니다. <br/>            MPP 파일 형식에 존재하고 인쇄에 사용되는 페이지 설정 데이터를 나타냅니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| header | 헤더 데이터를 나타내는 [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) 클래스의 인스턴스를 가져오거나 설정합니다. |
| footer | 푸터 데이터를 나타내는 [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) 클래스의 인스턴스를 가져오거나 설정합니다. |
| name | 설정 데이터가 사용되는 뷰의 이름을 가져옵니다. |
| page_settings | [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) 클래스의 인스턴스를 가져오며, 페이지 인쇄 설정을 지정합니다. |
| page_view_settings | [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) 클래스의 인스턴스를 가져오며, 페이지 뷰 인쇄 설정을 지정합니다. |
| margins | [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) 클래스의 인스턴스를 가져오며, 페이지 여백을 지정합니다. |
| legend | 페이지 레전드의 렌더링 옵션을 지정하는 [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) 클래스의 인스턴스를 가져오거나 설정합니다. |
