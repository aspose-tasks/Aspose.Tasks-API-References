## PrimaveraProjectInfo class

Primavera 형식에서 로드된 프로젝트에 대한 간략한 정보를 나타냅니다.

PrimaveraProjectInfo 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| uid | 프로젝트의 Uid를 가져옵니다. |
| name | 프로젝트의 이름을 가져옵니다. |
| short_name | 프로젝트의 짧은 이름(프로젝트 ID)을 가져옵니다. |
| export_flag | 프로젝트의 export flag를 가져옵니다. Primavera에서 프로젝트를 내보내기로 선택하면 ExportFlag가 true가 됩니다.<br/>            명시적으로 내보내기로 선택되지 않은 일부 프로젝트도 내보낸 프로젝트와의 관계 때문에 XER 파일로 내보내질 수 있습니다. |
