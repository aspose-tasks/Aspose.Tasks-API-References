## RecurringTaskInfo class

프로젝트 내 반복 작업의 세부 정보를 나타냅니다.

RecurringTaskInfo 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| recurrence_pattern | 반복 작업의 반복 패턴을 가져오거나 설정합니다. |
| start_date | 발생이 시작되는 날짜를 가져오거나 설정합니다. |
| end_date | 발생이 종료되는 날짜를 가져오거나 설정합니다. |
| duration | 반복 작업의 한 발생에 대한 지속 시간을 가져오거나 설정합니다. |
| occurrences | 반복 작업의 발생 횟수를 가져오거나 설정합니다. |
| use_end_date | 반복 작업에 종료 날짜를 사용할지 발생 횟수를 사용할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| daily_repetitions | 일일 반복 패턴에 대한 반복 횟수를 가져오거나 설정합니다. |
| daily_use_workdays | 일일 반복 패턴에 작업일을 사용할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| weekly_repetitions | 주간 반복 패턴에 대한 반복 횟수를 가져오거나 설정합니다. |
| weekly_days | 주간 반복 패턴에 사용되는 요일 컬렉션을 가져오거나 설정합니다. |
| monthly_use_ordinal_day | 월간 반복 패턴에 서수일을 사용할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| monthly_ordinal_number | 월간 반복 패턴의 서수 번호를 가져오거나 설정합니다. |
| monthly_ordinal_repetitions | 서수일을 사용할 때 월간 반복 패턴에 대한 반복 횟수를 가져오거나 설정합니다. |
| monthly_day | 월간 반복 패턴의 일 수를 가져오거나 설정합니다. |
| monthly_repetitions | 월간 반복 패턴에 대한 반복 횟수를 가져오거나 설정합니다. |
| yearly_use_ordinal_day | 연간 반복 패턴에 서수일을 사용할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| yearly_date | 연간 반복 패턴의 날짜를 가져오거나 설정합니다. |
| yearly_ordinal_number | 연간 반복 패턴의 서수 번호를 가져오거나 설정합니다. |
| yearly_ordinal_month | 서수일을 사용할 때 연간 반복 패턴의 월을 가져오거나 설정합니다. |
| task | [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/) 클래스의 이 인스턴스에 대한 상위 작업을 가져옵니다. |
