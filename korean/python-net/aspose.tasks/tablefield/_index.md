## TableField class

프로젝트 내 테이블의 필드를 나타냅니다.

TableField 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TableField() | [TableField](/tasks/python-net/aspose.tasks/tablefield/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| align_data | 표 필드의 데이터 정렬을 가져오거나 설정합니다. |
| align_title | 표 필드의 제목 정렬을 가져오거나 설정합니다. |
| field | 표 필드의 유형을 가져오거나 설정합니다. |
| title | 표에서 필드의 제목을 가져오거나 설정합니다. |
| width | 표에서 필드 열의 너비(포인트)를 가져오거나 설정합니다. |
| wrap_header | 표 열 머리글을 여러 줄로 자동 줄바꿈할지, 열 너비를 초과하면 잘라낼지 여부를 나타내는 값을 가져오거나 설정합니다. |
| wrap_text | 열 텍스트가 여러 줄로 자동 줄바꿈될 수 있는지, 또는 열 너비를 초과할 경우 잘릴지를 나타내는 값을 가져오거나 설정합니다. |
