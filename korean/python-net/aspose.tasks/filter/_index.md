## Filter class

프로젝트의 필터를 나타냅니다.

Filter 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Filter() | Filter 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| filter_type | 필터의 유형을 가져옵니다. |
| name | Filter 개체의 이름을 가져오거나 설정합니다. |
| show_in_menu | 프로젝트가 리본의 보기 탭에 있는 필터 드롭다운 목록에 필터 이름을 표시하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_related_summary_rows | 필터에 대해 관련 요약 행이 표시되는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| index | Filters 포함 개체에서 [Filter](/tasks/python-net/aspose.tasks/filter/) 개체의 인덱스를 가져옵니다. |
| uid | 필터의 고유 식별자를 가져옵니다. |
| criteria | MSP 보기에서 표시되기 위해 작업 또는 리소스가 충족해야 하는 기준을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| compare_to(other) | 이 인스턴스를 지정된 [Filter](/tasks/python-net/aspose.tasks/filter/) 클래스 인스턴스와 비교하고 상대적인 순서에 대한 표시를 반환합니다. |
| equals(other) | 이 인스턴스가 지정된 AssignmentBaseline 개체와 같은지 여부를 나타내는 값을 반환합니다. |
