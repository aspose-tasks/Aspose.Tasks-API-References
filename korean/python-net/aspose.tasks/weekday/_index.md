## WeekDay class

정규 주일 또는 캘린더의 예외 일자를 정의하는 요일을 나타냅니다.

WeekDay 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| WeekDay(day_type) | 지정된 요일 유형으로 [WeekDay](/tasks/python-net/aspose.tasks/weekday/) 클래스를 새 인스턴스로 초기화합니다. |
| WeekDay(day_type, working_times) | WeekDay 클래스의 새 인스턴스를 초기화합니다. |
| WeekDay(day_type, working_times) | 지정된 요일 유형 및 작업 시간 기간으로 [WeekDay](/tasks/python-net/aspose.tasks/weekday/) 클래스를 새 인스턴스로 초기화합니다. |
| WeekDay() | 지정된 요일 유형으로 [WeekDay](/tasks/python-net/aspose.tasks/weekday/) 클래스를 새 인스턴스로 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| day_type | 날의 유형을 가져옵니다. |
| day_working | 지정된 날짜 또는 요일 유형이 작업일인지 여부를 나타내는 값을 가져오거나 설정합니다. |
| from_date | 예외 시간의 시작을 가져오거나 설정합니다. |
| to_date | 예외 시간의 끝을 가져오거나 설정합니다. |
| working_times | 이 WeekDay 인스턴스에 대한 WorkingTimeCollection을 가져옵니다.<br/>            평일에 작업한 시간을 정의하는 작업 시간 컬렉션입니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| create_default_working_day(day_type) | 기본 작업일을 생성합니다. |
| set_default_working_time(day) | 지정된 요일에 대한 기본 시간 기간을 설정합니다. |
| get_working_time() | 주중 하루에 대한 작업 시간을 반환합니다. |
| clone() | 주중 하루의 깊은 복사본을 반환합니다. |
