## PrimaveraBaseReader class

다중 프로젝트 Primavera XER 또는 XML 파일에서 프로젝트 UID를 읽는 데 사용할 수 있는 기본 리더를 나타냅니다.

PrimaveraBaseReader 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_project_uids() | 프로젝트들의 고유 식별자 목록을 반환합니다. |
| get_project_infos() | 프로젝트의 짧은 정보 객체 목록을 반환합니다. |
| load_project(project_uid) | 지정된 고유 식별자를 가진 프로젝트를 로드합니다. |
