## ExtendedAttribute class

확장 속성을 나타냅니다.

ExtendedAttribute 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| attribute_definition | 속성 정의를 가져옵니다. |
| field_id | 필드의 ID를 가져옵니다. |
| duration_value | ‘Duration’ 유형의 속성에 대한 값을 가져오거나 설정합니다. |
| numeric_value | 숫자 유형(Cost, Number)의 속성에 대한 값을 가져오거나 설정합니다. |
| date_value | 날짜 유형(Date, Start, Finish)의 속성에 대한 값을 가져오거나 설정합니다. |
| flag_value | ‘Flag’ 유형의 속성에 플래그가 설정되었는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| text_value | ‘Text’ 유형의 속성에 대한 값을 가져오거나 설정합니다. |
| value_guid | 조회 값의 GUID를 가져옵니다. |
| value_read_only | 이 [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) 인스턴스의 값이 읽기 전용인지 여부를 나타내는 값을 가져옵니다. |
| is_error_value | 확장 속성 값의 계산이 오류로 끝났는지 여부를 가져옵니다. |
