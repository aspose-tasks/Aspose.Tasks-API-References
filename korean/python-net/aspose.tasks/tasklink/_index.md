## TaskLink class

선행 작업 링크를 나타냅니다.

TaskLink 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_cross_project | 선행 작업이 다른 프로젝트에 속하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| cross_project_name | 외부 선행 프로젝트를 가져오거나 설정합니다. |
| link_lag | 분의 10분의 1 또는 백분율 단위로 지연을 가져오거나 설정합니다. |
| link_lag_time_span | LagFormat에 따라 지연 기간을 가져오거나 설정합니다. |
| lag_format | 지연 형식을 표현하는 형식을 가져오거나 설정합니다. |
| pred_task | 선행 작업을 가져오거나 설정합니다. |
| succ_task | 후속 작업을 가져오거나 설정합니다. |
| link_type | 링크 유형을 가져오거나 설정합니다. |
