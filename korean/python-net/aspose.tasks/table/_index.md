## Table class

Project의 테이블을 나타냅니다.

Table 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Table() | 새 인스턴스를 초기화합니다 [Table](/tasks/python-net/aspose.tasks/table/) 클래스. |
## 속성
| 이름 | 설명 |
| :- | :- |
| name | Table 객체의 이름을 가져오거나 설정합니다. |
| show_in_menu | 프로젝트가 리본의 View 탭에 있는 Tables 드롭다운 목록에 테이블 이름을 표시하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| table_fields | 테이블의 필드를 나타내는 TableFields 컬렉션을 가져옵니다. |
| table_type | 지정된 테이블에 대한 테이블 유형을 가져오거나 설정합니다. |
| uid | 테이블의 고유 식별자를 가져옵니다. |
| row_height | 테이블에서 행 높이를 가져오거나 설정합니다. 행 높이는 텍스트 줄 수를 나타냅니다. |
| date_format | 테이블의 날짜 형식을 가져오거나 설정합니다. |
| adjust_header_row_height | 테이블의 헤더 행 높이를 조정할 수 있는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_add_new_column | ‘Add New Column’ 인터페이스를 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| lock_first_column | 테이블의 첫 번째 열이 잠겨 있는지 또는 편집 가능한지를 나타내는 값을 가져오거나 설정합니다. |
