## ProjectServerSaveOptions class

프로젝트를 Project Server 또는 Project Online에 저장할 때 추가 옵션을 지정할 수 있습니다.

ProjectServerSaveOptions 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ProjectServerSaveOptions() | [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| project_name | 프로젝트 서버 \ 프로젝트 온라인 프로젝트 목록에 표시되는 프로젝트 이름을 가져오거나 설정합니다. 프로젝트 서버 \ 프로젝트 온라인 인스턴스 내에서 고유해야 합니다.<br/>            값이 생략된 경우, Prj.Name 속성의 값이 대신 사용됩니다. |
| project_guid | 프로젝트의 고유 식별자를 가져오거나 설정합니다. 프로젝트 서버 \ 프로젝트 온라인 인스턴스 내에서 고유해야 합니다. |
| timeout | 프로젝트 서버의 큐 처리 서비스가 저장 프로젝트 요청을 처리할 때 대기하는 데 사용되는 제한 시간을 가져오거나 설정합니다. 이 속성의 기본값은 1분입니다. |
| polling_interval | 큐 작업 상태 요청 사이의 간격을 가져오거나 설정합니다. 기본값은 2초입니다. |
