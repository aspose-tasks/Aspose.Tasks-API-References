## ViewCollection class

다음은 [View](/tasks/python-net/aspose.tasks/view/) 객체들의 목록을 포함합니다.<br/>            ICollection<View> 인터페이스를 구현합니다.

ViewCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| parent_project | View 객체의 상위 항목을 가져옵니다.<br/>            읽기 전용 [Project](/tasks/python-net/aspose.tasks/project/). |
## 메서드
| 이름 | 설명 |
| :- | :- |
| to_list() | 뷰 컬렉션을 [View](/tasks/python-net/aspose.tasks/view/) 객체 목록으로 변환합니다. |
| get_by_view_screen(screen) | 지정된 Screen 속성을 가진 View를 검색하고, 컬렉션 내에서 첫 번째 항목을 반환합니다. |
| get_by_name(view_name) | 이름이 지정된 View를 검색하고, 컬렉션 내에서 첫 번째 항목을 반환합니다. |
