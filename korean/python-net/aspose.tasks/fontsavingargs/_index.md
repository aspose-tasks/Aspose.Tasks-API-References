## FontSavingArgs class

이 클래스는 HTML 형식으로 변환되는 동안 발생하는 외부 글꼴 파일 저장과 관련된 데이터 집합을 나타냅니다.<br/>              

FontSavingArgs 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| FontSavingArgs() | FontSavingArgs 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| file_name | 변환기에서 사용자 정의 메서드 코드로 전달되는 파일 이름을 가져오거나 설정합니다.<br/>             사용자 정의 코드에서 파일을 어떻게 처리할지 또는 어디에 저장할지 결정하는 데 사용할 수 있습니다. |
| keep_stream_open | 리소스 저장이 완료된 후 스트림을 열어 둘지 여부를 나타내는 값을 가져오거나 설정합니다. |
| stream | 저장된 파일의 이진 콘텐츠를 가져오거나 설정합니다. |
| uri | 리소스 URI를 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| close_stream_if_required() | KeepStreamOpen이 false이면 스트림을 닫고, 그렇지 않으면 플러시합니다. |
