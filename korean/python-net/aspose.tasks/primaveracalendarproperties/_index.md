## PrimaveraCalendarProperties class

Primavera 파일(XER 또는 P6XML)에서 읽은 캘린더에 대한 Primavera 전용 속성을 나타냅니다.<br/>            캘린더별 시간 단위 변환을 수행하는 데 사용할 수 있습니다.

PrimaveraCalendarProperties 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| hours_per_day | 캘린더의 'Time Periods' 설정에서 하루당 시간 수를 가져옵니다. |
| hours_per_week | 캘린더의 'Time Periods' 설정에서 주당 시간 수를 가져옵니다. |
| hours_per_month | 캘린더의 'Time Periods' 설정에서 월당 시간 수를 가져옵니다. |
| hours_per_year | 캘린더의 'Time Periods' 설정에서 월당 시간 수를 가져옵니다. |
