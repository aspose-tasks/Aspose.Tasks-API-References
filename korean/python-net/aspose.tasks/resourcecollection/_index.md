## ResourceCollection class

[Resource](/tasks/python-net/aspose.tasks/resource/) 객체의 컬렉션을 나타냅니다.

ResourceCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| parent_project | ResourceCollection 객체의 상위 프로젝트를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| add() | 프로젝트 리소스 컬렉션의 마지막 위치에 새 리소스를 추가합니다. |
| add(resource_name) | 프로젝트 리소스 컬렉션의 마지막 위치에 새 리소스를 추가합니다. |
| add(resource_name, before_resource_id) |  |
| to_list() | ResourceCollection 객체를 [Resource](/tasks/python-net/aspose.tasks/resource/) 객체 목록으로 변환합니다. |
| get_by_id(id) | 지정된 id를 가진 리소스를 반환합니다. |
| get_by_uid(uid) | 지정된 Uid를 가진 리소스를 반환합니다. |
