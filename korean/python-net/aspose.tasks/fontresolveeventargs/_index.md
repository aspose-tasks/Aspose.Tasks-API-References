## FontResolveEventArgs class

글꼴이 해결될 때 호출되는 콜백에 대한 인수를 제공합니다.

FontResolveEventArgs 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| requested_font_name | 요청된 글꼴의 이름을 가져옵니다. |
| resolved_font_name | 해결된 글꼴의 이름을 가져오거나 설정합니다. 뷰를 렌더링하는 데 사용되는 글꼴을 제어하도록 설정할 수 있습니다. |
