## Metered class

계량 키를 설정하는 메서드를 제공합니다.

Metered 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Metered() | Metered 클래스의 새 인스턴스를 초기화합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| set_metered_key(public_key, private_key) | 계량된 공개 키와 개인 키를 설정합니다. |
| reset_metered_key() | 이전에 설정된 라이선스를 제거합니다. |
| get_consumption_credit() | 소비 크레딧을 가져옵니다. |
| get_consumption_quantity() | 소비 파일 크기를 가져옵니다. |
| is_licensed() | Metered 라이선스를 사용하여 제품이 성공적으로 라이선스가 부여되었는지 확인합니다. |
