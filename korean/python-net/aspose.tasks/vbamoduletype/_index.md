## VbaModuleType enumeration

VBA 프로젝트의 모듈 유형을 지정합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| DOCUMENT_MODULE | 문서와 연결된 임베디드 매크로 및 프로그래밍 액세스 작업을 위한 모듈을 지정하는 VBA 프로젝트 항목 유형입니다. |
| PROCEDURAL_MODULE | 하위 루틴 및 함수들의 컬렉션을 포함하는 모듈입니다. |
| CLASS_MODULE | 새 객체에 대한 정의를 포함하는 모듈입니다. 클래스의 각 인스턴스는 새로운 객체를 생성하며, 모듈에 정의된 프로시저는 객체의 속성과 메서드가 됩니다. |
| DESIGNER_MODULE | 프로젝트에 등록된 ActiveX 컨트롤의 메서드와 속성을 확장하는 모듈입니다. |
