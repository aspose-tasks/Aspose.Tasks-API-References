## Group class

그룹 정의를 나타냅니다.<br/>            Group 객체는 ResourceGroups 컬렉션 또는 TaskGroups 컬렉션의 구성원입니다.

Group 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Group() | 새로운 [Group](/tasks/python-net/aspose.tasks/group/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| name | Group 객체의 이름을 가져오거나 설정합니다. |
| uid | 그룹의 고유 식별자를 가져옵니다. |
| show_summary | 그룹에 대한 요약 행이 표시되는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| maintain_hierarchy | 그룹 내 하위 작업에 대한 모든 수준의 요약 작업을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_in_menu | 리본의 Group 드롭다운 목록에 프로젝트가 그룹 이름을 표시하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| group_assignments | 작업 대신 할당을 그룹화할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| group_criteria | 그룹 정의의 필드를 나타내는 GroupCriteria 컬렉션을 가져오거나 설정합니다. |
