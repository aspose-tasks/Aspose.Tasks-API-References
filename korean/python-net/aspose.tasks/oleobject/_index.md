## OleObject class

MPP 파일의 간트 차트 보기에 삽입할 수 있는 OLE 객체를 나타냅니다.

OleObject 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| OleObject() | 새로운 [OleObject](/tasks/python-net/aspose.tasks/oleobject/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| name | OLE 객체 인스턴스의 이름을 가져오거나 설정합니다. |
| application_name | 임베드된 객체를 열 애플리케이션 이름을 가져오거나 설정합니다. |
| file_format | 임베드된 객체의 파일 형식을 가져오거나 설정합니다. |
| content | 임베드된 파일 데이터를 가져오거나 설정합니다; 데이터가 임베드되지 않은 경우 null입니다. |
| label | 삽입된 객체의 레이블을 가져오거나 설정합니다. |
| full_path | 삽입된 객체의 전체 경로를 가져오거나 설정합니다. |
| temporary_file | 삽입된 객체의 임시 파일 경로를 가져오거나 설정합니다. |
| display_as_icon | OLE object가 아이콘으로 표시될지 일반 그림으로 표시될지를 나타내는 플래그를 가져오거나 설정합니다. |
| 연결됨 | 프로젝트 파일이 실제 데이터가 저장된 링크 소스에 대한 링크만 포함하는지를 나타내는 값을 가져옵니다. |
| view | 삽입된 객체가 속한 [view](/tasks/python-net/aspose.tasks/oleobject/) 클래스의 인스턴스를 가져오거나 설정합니다. |
| id | 객체 ID를 가져오거나 설정합니다. |
