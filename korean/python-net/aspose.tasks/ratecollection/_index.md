## RateCollection class

[Rate](/tasks/python-net/aspose.tasks/rate/) 객체를 포함하는 컬렉션을 나타냅니다.

RateCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| count | RateCollection에 포함된 요소 수를 가져옵니다. |
| is_read_only | 이 컬렉션이 읽기 전용인지 여부를 나타내는 값을 가져옵니다. |
| parent_resource | 이 컬렉션에 대한 상위 [Resource](/tasks/python-net/aspose.tasks/resource/) 객체를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| add(rates_from) | 이 컬렉션에 새로운 [Rate](/tasks/python-net/aspose.tasks/rate/) 인스턴스를 추가합니다. |
| add(rates_from, type) | 이 컬렉션에 새로운 [Rate](/tasks/python-net/aspose.tasks/rate/) 인스턴스를 추가합니다. |
| to_list() | [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) 객체를 [Rate](/tasks/python-net/aspose.tasks/rate/) 객체 목록으로 변환합니다. |
| to_list(type) | [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) 객체를 지정된 [RateType](/tasks/python-net/aspose.tasks/ratetype/) 유형으로 필터링된 [Rate](/tasks/python-net/aspose.tasks/rate/) 객체 목록으로 변환합니다. |
| remove(item) | 이 컬렉션에서 Rate 인스턴스를 제거합니다. |
