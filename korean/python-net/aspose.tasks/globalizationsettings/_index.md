## GlobalizationSettings class

프로젝트의 글로벌화 설정을 나타냅니다.

GlobalizationSettings 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| GlobalizationSettings() | GlobalizationSettings 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| formula_date_na | 날짜 필드 수식에 사용되는 "NA"(빈 값) 리터럴을 가져옵니다. |
| true_literal | 수식에 사용되는 부울 'true' 리터럴에 대한 문자열을 가져옵니다. |
| false_literal | 수식에 사용되는 부울 'false' 리터럴에 대한 문자열을 가져옵니다. |
