## TaskStatus enumeration

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| UNDEFINED | 정의되지 않은 작업 상태. |
| COMPLETE | 작업이 100% 완료되었습니다. |
| ON_SCHEDULE | 작업은 timephased cumulative percent complete가 상태 날짜 전날까지 최소한으로 분산되어 있으면 일정에 맞춰진 것입니다. |
