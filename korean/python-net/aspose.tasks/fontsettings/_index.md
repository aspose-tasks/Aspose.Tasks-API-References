## FontSettings class

프로젝트 보기 렌더링 시 사용되는 글꼴 설정을 지정합니다.

FontSettings 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| FontSettings() | FontSettings 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| default_font_name | 렌더링에 사용할 기본(또는 대체) 글꼴을 가져오거나 설정합니다. |
| use_project_default_font | 렌더링에 기본 글꼴을 사용해야 하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| set_font_folders(font_folders, recursive) | 프로젝트 뷰를 렌더링할 때 Aspose.Tasks가 TrueType 글꼴을 찾는 폴더를 설정합니다. |
