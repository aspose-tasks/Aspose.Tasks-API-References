## ProjectServerCredentials class

Project Online 또는 온프레미스 Project Server 인스턴스에 연결하는 데 사용되는 자격 증명을 나타냅니다.

ProjectServerCredentials 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | 새 인스턴스를 초기화합니다 [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) 클래스를 사용하여 SharePoint 사이트 URL과 SharePoint의 PWA(프로젝트 웹 액세스) 사이트에 대한 유효한 SPOIDCRL 인증 토큰을 사용합니다. |
| ProjectServerCredentials(site_url, user_name, password) | 새 인스턴스를 초기화합니다 [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) 클래스를 사용하여 SharePoint 사이트 URL과 SharePoint의 PWA(프로젝트 웹 액세스) 사이트에 대한 유효한 SPOIDCRL 인증 토큰을 사용합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| site_url | SharePoint 사이트의 PWA URL 또는 온프레미스 Project Server URL을 가져옵니다.<br/>            예: https://your_company_name.sharepoint.com/sites/pwa"; |
| auth_token | SharePoint 인스턴스에 대한 인증 토큰을 가져옵니다. |
| user_name | SharePoint 사이트의 사용자 이름을 가져옵니다. |
