## PrimaveraTaskProperties class

Primavera 파일(XER 또는 P6XML)에서 읽은 작업에 대한 Primavera 전용 속성을 나타냅니다.

PrimaveraTaskProperties 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| sequence_number | WBS 항목(요약 작업)의 순번을 가져오거나 설정합니다. Primavera에서 요약 작업을 정렬하는 데 사용됩니다. |
| activity_id | 활동 ID 필드를 가져옵니다 - Primavera에서 사용되는 작업의 고유 식별자입니다. |
| remaining_early_finish | 남은 조기 종료 날짜를 가져옵니다 - 활동의 남은 작업이 완료될 예정인 날짜입니다. |
| remaining_early_start | 남은 조기 시작 날짜를 가져옵니다 - 활동의 남은 작업이 시작될 예정인 날짜입니다. |
| remaining_late_start | 남은 늦은 시작 날짜를 가져옵니다. |
| remaining_late_finish | 남은 늦은 종료 날짜를 가져옵니다. |
| raw_duration_type | 활동의 'Duration Type' 필드에 대한 원시 텍스트 표현(소스 파일과 동일)을 가져옵니다. |
| duration_type | 활동의 'Duration Type' 필드 값을 가져옵니다. |
| raw_activity_type | 활동의 'Activity Type' 필드에 대한 원시 텍스트 표현(소스 파일과 동일)을 가져옵니다. |
| activity_type | 'Activity Type' 필드 값을 가져옵니다. |
| percent_complete_type | 활동의 '% Complete Type' 필드 값을 가져옵니다. |
| raw_complete_percent_type | 활동의 '% Complete Type' 필드에 대한 원시 텍스트 표현(소스 파일과 동일)을 가져옵니다. |
| raw_status | 활동의 'Status' 필드에 대한 원시 텍스트 표현(소스 파일과 동일)을 가져옵니다. |
| physical_percent_complete | Physical Percent Complete의 값을 가져옵니다. |
| duration_percent_complete | duration percent complete의 값을 가져옵니다. |
| units_percent_complete | units percent complete의 값을 가져옵니다. |
| actual_labor_units | actual labor units의 값을 가져옵니다. |
| actual_non_labor_units | actual non labor units의 값을 가져옵니다. |
| remaining_labor_units | remaining labor units의 값을 가져옵니다. |
| remaining_non_labor_units | remaining non labor units의 값을 가져옵니다. |
| actual_labor_cost | actual labor cost의 값을 가져옵니다. |
| budgeted_labor_cost | budgeted (or planned) labor cost의 값을 가져옵니다. |
| actual_nonlabor_cost | actual non labor cost의 값을 가져옵니다. |
| budgeted_nonlabor_cost | budgeted (or planned) non labor cost의 값을 가져옵니다. |
| actual_material_cost | 실제 재료 비용의 값을 가져옵니다. |
| budgeted_material_cost | 예산(또는 계획된) 재료 비용의 값을 가져옵니다. |
| actual_expense_cost | 실제 비용의 값을 가져옵니다. |
| remaining_expense_cost | 남은 비용의 값을 가져옵니다. |
| budgeted_expense_cost | 예산(또는 계획된) 비용의 값을 가져옵니다. |
| actual_total_cost | 실제 비용의 총 값을 가져옵니다. |
| budgeted_total_cost | 예산(또는 계획된) 비용의 총 값을 가져옵니다. |
| primary_constraint_type | 주요 제약 조건의 유형을 가져옵니다. |
| primary_constraint_date | 주요 제약 조건의 날짜를 가져옵니다. |
| secondary_constraint_type | 보조 제약 조건의 유형을 가져옵니다. |
| secondary_constraint_date | 보조 제약 조건의 날짜를 가져옵니다. |
| planned_duration | 원래 또는 계획된 기간을 가져옵니다 -- 작업 계획 시작 날짜부터 계획된 종료 날짜까지의 총 작업 시간. |
