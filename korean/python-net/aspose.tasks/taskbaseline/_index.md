## TaskBaseline class

작업의 기준선을 나타냅니다.

TaskBaseline 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TaskBaseline(task) | [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| baseline_number | 베이스라인 데이터 레코드의 고유 번호를 가져오거나 설정합니다. |
| work | 베이스라인이 저장될 때 리소스에 할당된 작업을 가져오거나 설정합니다. |
| cost | 베이스라인이 저장될 때 리소스의 예상 비용을 가져오거나 설정합니다. |
| bcws | 리소스에 예약된 작업의 예산 비용을 가져오거나 설정합니다. |
| bcwp | 프로젝트에 대해 현재까지 리소스가 수행한 작업의 예산 비용을 가져오거나 설정합니다. |
| timephased_data | 이 객체에 대한 TimephasedDataCollection 인스턴스를 가져오거나 설정합니다.<br/>            작업 기준선과 연결된 시간 구분 데이터입니다. |
| interim | 이것이 중간 기준선인지 여부를 나타내는 값을 가져오거나 설정합니다. |
| 시작 | 기준선이 저장될 때 작업의 예정 시작 날짜를 가져오거나 설정합니다. |
| finish | 기준선이 저장될 때 작업의 예정 종료 날짜를 가져오거나 설정합니다. |
| duration | 기준선이 저장될 때 작업의 예정 기간을 가져오거나 설정합니다. |
| estimated_duration | 작업의 기준선 기간이 추정되었는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| fixed_cost | 기준선이 저장될 때 작업의 고정 비용을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| equals(other) | 이 인스턴스가 지정된 TaskBaseline 객체와 동일한지 여부를 나타내는 값을 반환합니다. |
| equals(other) | 이 인스턴스가 지정된 객체와 같은지 여부를 나타내는 값을 반환합니다. |
| compare_to(other) | IComparable 인터페이스 구현.<br/>            이 인스턴스를 지정된 Baseline 객체와 비교합니다. |
| compare_to(other) | IComparable 인터페이스 구현.<br/>            이 인스턴스를 지정된 Baseline 객체와 비교합니다. |
