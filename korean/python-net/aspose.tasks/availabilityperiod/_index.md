## AvailabilityPeriod class

리소스가 사용 가능한 기간을 나타냅니다.

AvailabilityPeriod 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| AvailabilityPeriod() | 새 인스턴스를 초기화합니다 [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | 지정된 날짜 범위와 사용 가능한 단위로 [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/)의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| available_from | 지정된 기간 동안 리소스가 사용 가능해지는 날짜를 가져오거나 설정합니다. |
| available_to | 지정된 기간 동안 리소스가 사용 가능한 마지막 날짜를 가져오거나 설정합니다. |
| available_units | 지정된 기간 동안 사용 가능한 리소스의 비율을 가져오거나 설정합니다. |
