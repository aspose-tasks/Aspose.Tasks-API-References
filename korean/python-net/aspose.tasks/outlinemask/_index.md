## OutlineMask class

아웃라인 코드 형식을 정의하는 마스크의 네 요소를 나타냅니다.

OutlineMask 유형은 다음 멤버를 제공합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| OutlineMask() | [OutlineMask](/tasks/python-net/aspose.tasks/outlinemask/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| level | 마스크의 레벨을 가져오거나 설정합니다. |
| type | 마스크의 유형을 가져오거나 설정합니다. |
| length | 아웃라인 코드 값의 최대 길이(문자 수)를 가져오거나 설정합니다. 길이가 정의되지 않은 경우 0입니다. |
| separator | 코드 값의 구분자를 가져오거나 설정합니다. |
