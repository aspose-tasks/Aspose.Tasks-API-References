## PrimaveraProjectProperties class

Primavera 파일(XER 또는 P6XML)에서 읽은 프로젝트에 대한 Primavera 전용 속성을 나타냅니다.

PrimaveraProjectProperties 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| relationship_lag_calendar | Primavera 프로젝트에서 관계 지연을 스케줄링할 때 사용할 캘린더를 정의하는 옵션을 가져옵니다. |
| use_expected_finish_dates | 활동 종료 날짜를 예상 종료 날짜로 스케줄링할지 여부를 정의하는 플래그를 가져옵니다. |
| make_open_ended_activities_critical | 프로젝트를 스케줄링할 때 활동을 중요 항목으로 표시할지 여부를 정의하는 플래그를 가져옵니다. |
| ignore_other_project_relationships | 프로젝트 간 활동 관계를 무시할지 여부를 정의하는 플래그를 가져옵니다. |
| current_baseline_project_id | 현재 기준선 프로젝트의 Id를 가져옵니다.<br/>            내보낸 기준선을 포함하는 Primavera XML 파일에서 읽은 프로젝트에 적용됩니다. |
| baseline_projects | 현재 프로젝트의 기준선 프로젝트 배열을 가져옵니다.<br/>            내보낸 기준선을 포함하는 Primavera XML 파일에서 읽은 프로젝트에 적용됩니다. |
| critical_activities_defining_method | 중요 활동을 정의하는 방법을 가져옵니다: 최장 경로 또는 총 부동 접근법. |
| critical_total_float_limit | TotalFloat 방법을 사용할 경우 중요 활동을 정의하는 데 사용되는 임계값을 가져옵니다. |
| short_name | 프로젝트의 짧은 이름(프로젝트 ID)을 가져옵니다. |
