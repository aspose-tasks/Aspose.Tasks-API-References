## Rate class

해당 기간 동안 리소스에 적용되는 시간 기간 및 요율 정의를 나타냅니다.

Rate 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| rates_from | 비율이 적용되는 날짜를 가져오거나 설정합니다. |
| rates_to | 비율이 적용되는 마지막 날짜를 가져오거나 설정합니다. |
| rate_table | 리소스에 대한 비율 테이블의 고유 식별자를 가져오거나 설정합니다. |
| standard_rate | 리소스의 시간당 표준 비율을 가져오거나 설정합니다. |
| standard_rate_format | Microsoft Project에서 표준 비율을 표시하는 데 사용되는 단위를 가져오거나 설정합니다. |
| overtime_rate | 리소스의 시간당 초과 근무 비율을 가져오거나 설정합니다. |
| overtime_rate_format | Microsoft Project에서 초과 근무 비율을 표시하는 데 사용되는 단위를 가져오거나 설정합니다. |
| cost_per_use | 리소스 사용당 비용을 가져오거나 설정합니다. 비율 테이블이 리소스에 존재하는 경우 현재 날짜에서 이 값을 가져옵니다. |
