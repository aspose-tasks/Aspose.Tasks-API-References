## UsageView class

프로젝트의 사용 보기를 나타냅니다.

UsageView 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| filter | 단일 보기에서 사용되는 필터를 가져오거나 설정합니다. |
| 그룹 | 단일 보기의 그룹을 가져오거나 설정합니다. |
| uid | 보기의 고유 식별자를 가져옵니다. |
| highlight_filter | Microsoft Project가 단일 보기의 필터를 강조 표시하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| name | View 객체의 이름을 가져오거나 설정합니다. |
| screen | 단일 보기의 화면 유형을 가져옵니다.<br/>            읽기 전용 [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | View 객체의 상위 항목을 가져옵니다.<br/>            읽기 전용 [Project](/tasks/python-net/aspose.tasks/project/). |
| table | 단일 보기의 테이블을 가져오거나 설정합니다. |
| type | 단일 보기의 항목 유형(예: 작업 또는 리소스)을 가져옵니다.<br/>            읽기 전용 [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Microsoft Project가 리본의 View 또는 Other Views 드롭다운 목록에 단일 보기 이름을 표시하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| page_info | [page_info](/tasks/python-net/aspose.tasks/view/) 클래스의 인스턴스를 가져옵니다. mpp 파일 형식에 존재하는 페이지 설정 데이터를 나타냅니다. |
| visual_objects_placements | [OleObject](/tasks/python-net/aspose.tasks/oleobject/)의 배치 및 모양을 나타내는 객체 컬렉션을 가져옵니다. |
| align_details_data | 세부 데이터 정렬을 가져오거나 설정합니다. |
| display_details_header_column | 보기에서 세부 헤더 열을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| display_short_detail_header_names | 짧은 세부 헤더 이름을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| repeat_details_header_on_all_rows | 모든 할당 행에 세부 헤더를 반복할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| timescale_size_percentage |  |
| bottom_timescale_tier | 보기의 하단 타임스케일 티어 설정을 가져오거나 설정합니다.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | 보기의 중간 타임스케일 티어 설정을 가져오거나 설정합니다.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | 보기의 상위 타임스케일 티어 설정을 가져오거나 설정합니다.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
## 메서드
| 이름 | 설명 |
| :- | :- |
| compare_to(other) | 현재 인스턴스를 동일한 유형의 다른 객체와 비교하고, 현재 인스턴스가 정렬 순서에서 다른 객체보다 앞서거나 뒤에 있거나 같은 위치에 있는지를 나타내는 정수를 반환합니다. |
