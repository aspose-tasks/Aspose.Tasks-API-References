## RecurringTaskParameters class

프로젝트에서 반복 작업을 생성하는 데 사용되는 매개변수 집합을 나타냅니다.

RecurringTaskParameters 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| RecurringTaskParameters() | [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| duration | 반복 작업의 한 발생에 대한 지속 시간을 가져오거나 설정합니다. |
| ignore_resource_calendar | 리소스가 사용 가능하지 않을 때에도 반복 작업을 예약할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| recurrence_pattern | 반복 작업의 반복 패턴을 가져오거나 설정합니다. |
| task_name | 반복 작업의 이름을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| set_calendar(project, calendar_name) | 반복 작업에 대한 캘린더를 설정합니다. 캘린더는 프로젝트 캘린더 컬렉션에서 선택됩니다. |
