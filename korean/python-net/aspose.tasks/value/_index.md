## Value class

값 목록의 값을 나타냅니다.

Value 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Value() | [Value](/tasks/python-net/aspose.tasks/value/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| id | 프로젝트 전체에서 값의 고유 식별자를 가져오거나 설정합니다. |
| value_guid | 전체 프로젝트에서 이 값을 다른 값들과 구별하는 GUID를 가져옵니다. |
| val | 내부 표현에서 실제 값을 가져오거나 설정합니다. 아래에 나열된 강력하게 형식화된 속성을 사용하는 것이 좋습니다. |
| string_value | 텍스트 문자열을 나타내는 실제 값을 가져오거나 설정합니다. |
| numeric_value | 숫자 또는 비용 값을 나타내는 실제 값을 가져오거나 설정합니다. |
| duration | 기간을 나타내는 실제 값을 가져오거나 설정합니다. |
| date_time_value | DateTime으로 표현될 수 있는 경우 실제 값을 가져오거나 설정합니다. 기본값은 최소 날짜 값입니다. |
| description | 값의 설명을 가져오거나 설정합니다. |
| phonetic | 사용자 정의 필드 이름에 대한 음성 정보를 가져오거나 설정합니다. |
