## PrimaveraDbReader class

Primavera DB에서 프로젝트 정보를 읽는 리더를 나타냅니다.

PrimaveraDbReader 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PrimaveraDbReader(db_settings) | 새 인스턴스를 초기화합니다 [PrimaveraXerReader](/tasks/python-net/aspose.tasks/primaveraxerreader/) 클래스. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_project_uids() | 프로젝트들의 고유 식별자 목록을 반환합니다. |
| get_project_infos() | 프로젝트의 짧은 정보 객체 목록을 반환합니다. |
| load_project(project_uid) | 지정된 고유 식별자를 가진 프로젝트를 로드합니다. |
