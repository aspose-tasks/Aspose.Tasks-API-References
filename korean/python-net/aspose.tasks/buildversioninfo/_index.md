## BuildVersionInfo class

빌드 버전 및 제품 정보를 포함합니다.

BuildVersionInfo 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| ASSEMBLY_VERSION | 어셈블리 버전. |
| ASSEMBLY_INFORMATIONAL_VERSION | 어셈블리의 정보 버전 번호. |
| FILE_VERSION | 파일 버전. |
| 제품 | 제품 이름. |
