## ProjectDisplayOptions class

프로젝트 인스턴스에 대한 표시 옵션을 나타냅니다.

ProjectDisplayOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ProjectDisplayOptions() | [ProjectDisplayOptions](/tasks/python-net/aspose.tasks/projectdisplayoptions/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| add_space_before_label | 숫자 값과 시간 약어 앞에 공백을 추가할지 여부를 나타내는 값을 가져오거나 설정합니다 (예: 1 wk vs 1wk). |
| underline_hyperlinks | 하이퍼링크에 밑줄을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_task_schedule_warnings | 프로젝트가 수동으로 일정이 지정된 작업과의 잠재적인 일정 충돌을 감지했을 때 경고를 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_task_schedule_suggestions | 프로젝트가 수동으로 일정이 지정된 작업과의 잠재적인 일정 충돌을 감지했을 때 제안을 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
| show_project_summary_task | 전체 프로젝트에 대한 요약 정보를 Gantt 차트 보기 상단에 자체 요약 작업 막대와 함께 단일 행에 표시할지 여부를 나타내는 값을 가져오거나 설정합니다. |
