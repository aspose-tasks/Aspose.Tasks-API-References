## ProjectFileInfo class

클래스 인스턴스는 파일이 생성된 Microsoft Project의 프로젝트 파일 형식 및 버전에 대한 정보를 포함합니다.<br/>            파일이 생성된 위치.

ProjectFileInfo 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| can_read | Aspose.Tasks가 프로젝트 파일을 처리할 수 있는지 여부를 나타내는 값을 가져옵니다. |
| is_password_protected | 프로젝트가 비밀번호로 보호되어 있는지 여부를 나타내는 값을 가져옵니다. |
| project_file_format | 프로젝트 파일 형식을 가져옵니다. |
| project_application_info | 프로젝트 파일 애플리케이션 정보를 가져옵니다. |
