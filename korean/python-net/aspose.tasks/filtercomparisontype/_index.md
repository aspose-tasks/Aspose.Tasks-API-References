## FilterComparisonType enumeration

FieldName과 Value 사이에 수행되는 비교 유형을 지정합니다.

| DOES_NOT_EQUAL | Field 값이 Value와 같지 않습니다. |
| IS_GREATER_THAN | Field 값이 Value보다 큽니다. |
| IS_GREATER_THAN_OR_EQUAL_TO | Field 값이 Value보다 크거나 같습니다. |
| IS_LESS_THAN | Field 값이 Value보다 작습니다. |
