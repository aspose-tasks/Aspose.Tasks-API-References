## 생성자
| 이름 | 설명 |
| :- | :- |
| OutlineCodeDefinition() | [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/) 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| guid | 개요 코드의 Guid를 가져오거나 설정합니다. |

| only_table_values_allowed | 지정된 값이 값 테이블에서 가져와야 하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
| masks | OutlineMaskCollection 개체를 가져옵니다.<br/>            개요 코드 마스크를 정의하는 항목들의 테이블입니다.<br/>            읽기 전용 [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/) 인스턴스입니다. |
| show_indent | 이 개요 코드의 들여쓰기를 표시해야 하는지 여부를 나타내는 값을 가져오거나 설정합니다. |
