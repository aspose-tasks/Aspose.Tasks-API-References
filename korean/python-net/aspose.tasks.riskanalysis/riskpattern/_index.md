## RiskPattern class

프로젝트 작업에 대한 위험 패턴을 나타냅니다.

RiskPattern 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| RiskPattern(task) | 새로운 [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) 클래스 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| task | 이 위험 패턴이 적용되는 프로젝트 작업을 가져옵니다. |
| distribution | Monte Carlo 시뮬레이션에 사용되는 확률 분포를 가져오거나 설정합니다.<br/>            기본값은 ProbabilityDistributionType.Normal입니다. |
| confidence_level | 실제 생성된 값이 낙관적 및 비관적 추정치 범위 내에 있을 확률에 해당하는 신뢰 수준을 가져오거나 설정합니다.<br/>            기본값은 CL99입니다. |
| optimistic | 최상의 프로젝트 시나리오에서 발생할 수 있는 가장 가능성이 높은 작업 기간의 비율을 가져오거나 설정합니다.<br/>            기본값은 75이며, 이는 지정된 작업 기간이 4일로 추정될 경우 낙관적 기간은 3일이 됨을 의미합니다. |
| pessimistic | 최악의 프로젝트 시나리오에서 발생할 수 있는 가장 가능성이 높은 작업 기간의 비율을 가져오거나 설정합니다.<br/>            기본값은 125이며, 이는 지정된 작업 기간이 4일로 추정될 경우 비관적 기간은 5일이 됨을 의미합니다. |
