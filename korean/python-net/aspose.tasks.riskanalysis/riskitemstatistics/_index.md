## RiskItemStatistics class

분석된 프로젝트의 작업에 대한 통계 데이터를 저장하는 항목을 나타냅니다.

RiskItemStatistics 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| item_type | [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) 열거형의 인스턴스를 가져옵니다. |
| minimum | Monte Carlo 시뮬레이션 중에 생성된 최소값을 가져옵니다. |
| maximum | Monte Carlo 시뮬레이션 중에 생성된 최대값을 가져옵니다. |
| expected_value | 위험 항목의 기대값을 가져옵니다. |
| standard_deviation | 위험 항목의 표준 편차를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_percentile(percent) | 생성된 샘플 중 지정된 비율 이하에 해당하는 값을 가져옵니다. |
