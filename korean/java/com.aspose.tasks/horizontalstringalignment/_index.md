### Far {#Far}
```
public static final int Far
```


텍스트가 레이아웃 사각형의 원점 위치에서 멀리 정렬됨을 지정합니다. 왼쪽에서 오른쪽으로 흐르는 레이아웃에서는 멀리 위치가 오른쪽이며, 오른쪽에서 왼쪽으로 흐르는 레이아웃에서는 멀리 위치가 왼쪽입니다.

### Near {#Near}
```
public static final int Near
```


텍스트가 레이아웃에 가깝게 정렬됨을 지정합니다. 왼쪽에서 오른쪽으로 흐르는 레이아웃에서는 가까운 위치가 왼쪽이며, 오른쪽에서 왼쪽으로 흐르는 레이아웃에서는 가까운 위치가 오른쪽입니다.
