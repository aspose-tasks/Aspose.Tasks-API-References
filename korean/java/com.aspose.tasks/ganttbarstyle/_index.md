### getParentStyle() {#getParentStyle--}

```
public final GanttBarStyle getParentStyle()
```


사용자 지정 작업별 스타일을 위한 상위(또는 공통) 스타일을 가져옵니다.

--------------------

작업은 서로 다른 상위 스타일을 가진 여러 사용자 정의 스타일을 가질 수 있습니다. 예를 들어, "Critical" 상위 스타일을 가진 사용자 정의 스타일과 "Normal" 상위 스타일을 가진 또 다른 스타일을 가진 작업을 고려해 보십시오. 간단히 말해, 작업이 중요하면 첫 번째 스타일이 적용됩니다. 작업이 비중요해지면 두 번째 스타일이 적용됩니다(이 논리는 Microsoft Project Professional에서 상속됩니다).

**Returns:**
[GanttBarStyle](../../com.aspose.tasks/ganttbarstyle) - parent (or common) style for custom task-specific style.
