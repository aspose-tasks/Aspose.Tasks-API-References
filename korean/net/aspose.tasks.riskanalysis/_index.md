위험 분석 보고서를 생성하기 위한 클래스를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | 위험 분석 결과를 나타냅니다. |
| [RiskAnalysisSettings](./riskanalysissettings/) | 위험 분석 수행을 위한 설정을 지정합니다. |
| [RiskAnalyzer](./riskanalyzer/) | 지정된 위험 분석 설정을 기반으로 몬테카를로 시뮬레이션을 수행합니다. |
| [RiskItemStatistics](./riskitemstatistics/) | 분석된 프로젝트 작업에 대한 통계 데이터를 저장하는 항목을 나타냅니다. |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | `[`RiskItemStatistics`](../aspose.tasks.riskanalysis/riskitemstatistics/)` 클래스의 인스턴스를 포함하는 컬렉션을 나타냅니다. |
| [RiskPattern](./riskpattern/) | 프로젝트 작업에 대한 위험 패턴을 나타냅니다. |
| [RiskPatternCollection](./riskpatterncollection/) | `[`RiskPattern`](../aspose.tasks.riskanalysis/riskpattern/)` 클래스의 인스턴스를 포함하는 컬렉션을 나타냅니다. |
## 열거형

| 열거형 | 설명 |
| --- | --- |
| [ConfidenceLevel](./confidencelevel/) | 위험 분석에서 사용되는 지원되는 신뢰 수준을 지정합니다. 이는 실제 값이 낙관적 및 비관적 추정치 범위 내에 있을 확률을 백분율로 나타냅니다. |
| [ProbabilityDistributionType](./probabilitydistributiontype/) | 지원되는 확률 분포 유형을 지정합니다. |
| [RiskItemType](./riskitemtype/) | 위험 분석 중 통계 정보가 수집되는 작업 필드를 지정합니다. |
