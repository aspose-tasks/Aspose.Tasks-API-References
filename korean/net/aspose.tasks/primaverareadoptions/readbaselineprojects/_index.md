## PrimaveraReadOptions.ReadBaselineProjects property

베이스라인 프로젝트를 로드할지 여부를 지정하는 플래그를 가져오거나 설정합니다. 기본값은 true입니다.

```csharp
public bool ReadBaselineProjects { get; set; }
```

## 비고

이 플래그는 기준선 프로젝트를 포함하는 Primavera XML 파일에 적용됩니다(기준선은 XER 형식에서 지원되지 않습니다). 기준선 데이터가 필요하지 않을 때 큰 프로젝트를 로드하는 속도를 높이기 위해 옵션을 false로 설정할 수 있습니다.
