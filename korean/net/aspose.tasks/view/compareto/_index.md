## View.CompareTo method

현재 인스턴스를 동일한 유형의 다른 객체와 비교하고, 현재 인스턴스가 정렬 순서에서 앞선, 뒤에 있거나 같은 위치에 있는지를 나타내는 정수를 반환합니다.

```csharp
public int CompareTo(View other)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 다른 | View | 비교할 지정된 View 객체. |

### 반환 값

32비트 부호 있는 정수로, 비교되는 객체들의 상대 순서를 나타냅니다. 반환 값은 다음과 같은 의미를 가집니다: 값 의미
Less than zero 이 인스턴스는 정렬 순서에서 *other*보다 앞섭니다.
Zero 이 인스턴스는 정렬 순서에서 *other*와 같은 위치에 있습니다.
Greater than zero 이 인스턴스는 정렬 순서에서 *other*보다 뒤에 있습니다.
