Primavera 전용 형식(XER, Primavera XML) 작업에 필요한 클래스를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Primavera 형식에서 로드된 프로젝트에 대한 간략한 정보를 나타냅니다. |
## 열거형

| 열거형 | 설명 |
| --- | --- |
| [PrimaveraActivityType](./primaveraactivitytype/) | Primavera 활동 유형을 지정합니다. |
| [PrimaveraConstraintType](./primaveraconstrainttype/) | 활동 제약 조건의 유형을 지정합니다. |
| [PrimaveraDurationType](./primaveradurationtype/) | Primavera 활동의 기간 유형을 지정합니다. |
| [PrimaveraPercentCompleteType](./primaverapercentcompletetype/) | Primavera 활동에 대한 '% Complete Type' 필드 값을 지정합니다. |
| [PrimaveraRelationshipLagCalendar](./primaverarelationshiplagcalendar/) | Primavera 프로젝트에서 관계 지연을 일정에 잡을 때 사용할 캘린더를 지정합니다. |
