## PrimaveraProjectInfo.ExportFlag property

프로젝트의 내보내기 플래그를 가져옵니다. Primavera에서 프로젝트가 내보내기로 선택되면 ExportFlag가 true가 됩니다. 명시적으로 내보내기로 선택되지 않은 일부 프로젝트도 내보낸 프로젝트와의 관계 때문에 XER 파일로 내보내질 수 있습니다.

```csharp
public bool ExportFlag { get; }
```
