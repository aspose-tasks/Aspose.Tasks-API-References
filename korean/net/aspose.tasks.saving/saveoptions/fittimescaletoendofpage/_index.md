## SaveOptions.FitTimescaleToEndOfPage property

보기의 캘린더 섹션을 마지막 페이지의 끝(오른쪽)까지 렌더링할지 여부를 가져오거나 설정합니다. 값이 false인 경우, 빈 페이지 공간이 있더라도 캘린더 섹션은 EndDate까지 정확히 렌더링됩니다.

```csharp
public bool FitTimescaleToEndOfPage { get; set; }
```
