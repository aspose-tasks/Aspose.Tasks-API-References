## FilterCriteria class

Defines the criteria that tasks or resources must meet to be displayed in MSP view.

## Methods

| Name | Description |
| --- | --- |
| [get_CriteriaRows](./get_criteriarows/) | Gets the list of child FilterCriteria rows. If the filter contains more than one criterion row then the effect of an And operator is that the criteria for both rows must be met for the task or resource to be displayed as a result of this filter. The effect of an Or operator is that the criteria for one or the other row must be met. |
| [get_Field](./get_field/) | Gets a Field to change. |
| [get_Operation](./get_operation/) | Gets the criterion established with FieldName, Test, and Value relates to other criteria in the filter. |
| [get_Test](./get_test/) | Gets the type of comparison made between FieldName and Value that acts as selection criteria for the filter. FilterComparisonType |
| [get_Values](./get_values/) | Gets the object values to compare with the value of the field specified with FieldName. |
| [IsFieldValue](./isfieldvalue/) | Gets whether the right-hand value of FilterCriteria is a field reference, not a constant value. |
| [set_Field](./set_field/) | Sets a Field to change. |
| [set_Operation](./set_operation/) | Sets the criterion established with FieldName, Test, and Value relates to other criteria in the filter. |
| [set_Test](./set_test/) | Sets the type of comparison made between FieldName and Value that acts as selection criteria for the filter. FilterComparisonType |
| [SetValueField](./setvaluefield/) | Sets the field whose value will be compared with the value of the field specified by FieldName. |
| [ToString](./tostring/) | Returns string representation of the instance of the FilterCriteria class. |
