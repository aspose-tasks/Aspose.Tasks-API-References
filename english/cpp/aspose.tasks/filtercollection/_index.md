## FilterCollection class

Contains a list of Filter objects. Implements ICollection< Filter > interface.

| [Clear](./clear/) | Removes all items from this collection. |

| [CopyTo](./copyto/) | Copies the elements of this collection to the specified array, starting at the specified array index. |
| [get_Count](./get_count/) | Gets the number of elements contained in this collection. |
| [get_IsReadOnly](./get_isreadonly/) | Gets a value indicating whether this collection is read-only; otherwise, false. |
