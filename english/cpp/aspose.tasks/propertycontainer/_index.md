## PropertyContainer< T > class

Represents property container.

## Methods

| Name | Description |
| --- | --- |
| [CheckPropAndGet](./checkpropandget/) | Returns the value to which the property is mapped in this container. If this container doesn't contain record ProjectItem it will be added with default value and default value will be returned. |
| [CheckPropAndSet](./checkpropandset/) | Maps the specified property to the specified value in this container. If this container doesn't contain record ProjectItem it will be added. |
