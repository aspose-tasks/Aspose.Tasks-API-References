## OleObjectCollection class

Represents a collection containing the instances of the OleObject class.

## Methods

| Name | Description |
| --- | --- |
| [Clear](./clear/) | Clears the collection. In order to persist these changes project.Save should be called with new MPPSaveOptions { WriteViewData = true; } |
| [GetEnumerator](./getenumerator/) | Returns an enumerator for this collection. |
| [ToList](./tolist/) | Converts the instance of the OleObjectCollection class to a list containing the instances of the OleObject class. |
