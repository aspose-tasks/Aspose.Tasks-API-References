## Metered class

Provides methods to set metered key.

In this example, an attempt will be made to set metered public and private key <ms>

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> the component jar file:

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>

## Methods

| Name | Description |
| --- | --- |
| [GetConsumptionCredit](./getconsumptioncredit/) | Gets consumption credit. |
| [GetConsumptionQuantity](./getconsumptionquantity/) | Gets consumption file size. |
| [IsLicensed](./islicensed/) | Checks whether the product is successfully licensed using Metered license. |
| [ResetMeteredKey](./resetmeteredkey/) | Removes previously setup license. |
| [SetMeteredKey](./setmeteredkey/) | Sets metered public and private keys. |
