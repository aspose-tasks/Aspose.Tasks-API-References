## Aspose::Tasks::Primavera namespace

The Aspose::Tasks::Primavera namespace groups classes and enumerations that enable reading, creating, and manipulating Primavera P6 project files. Use these types, such as PrimaveraProjectInfo, to access project metadata and integrate Primavera data with other Aspose.Tasks functionality.


## Classes

| Name | Description |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Represents short info about a project loaded from Primavera format. |
