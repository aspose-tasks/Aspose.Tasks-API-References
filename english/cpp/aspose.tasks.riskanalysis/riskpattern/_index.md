## RiskPattern class

Represents a risk pattern for a project task.

## Constructors

| Name | Description |
| --- | --- |
| [RiskPattern](./riskpattern/) | Initializes a new instance of the RiskPattern class. |

## Methods

| Name | Description |
| --- | --- |
| [get_ConfidenceLevel](./get_confidencelevel/) | Gets the confidence level that correspond to the percentage of the time the actual generated values will be within optimistic and pessimistic estimates. The default value is CL99. |
| [get_Distribution](./get_distribution/) | Gets the probability distribution used in Monte Carlo simulation. The default value is ProbabilityDistributionType.Normal. |
| [get_Optimistic](./get_optimistic/) | Gets the percentage of the most likely task duration which can happen in the best possible project scenario. The default value is 75, which means that if the estimated specified task duration is 4 days then the optimistic duration will be 3 days. |
| [get_Pessimistic](./get_pessimistic/) | Gets the percentage of the most likely task duration which can happen in the worst possible project scenario. The default value is 125, which means that if the estimated specified task duration is 4 days then the pessimistic duration will be 5 days. |
| [get_Task](./get_task/) | Gets a project task to which this risk pattern is applied. |
| [set_ConfidenceLevel](./set_confidencelevel/) | Sets the confidence level that correspond to the percentage of the time the actual generated values will be within optimistic and pessimistic estimates. The default value is CL99. |
| [set_Distribution](./set_distribution/) | Sets the probability distribution used in Monte Carlo simulation. The default value is ProbabilityDistributionType.Normal. |
| [set_Optimistic](./set_optimistic/) | Sets the percentage of the most likely task duration which can happen in the best possible project scenario. The default value is 75, which means that if the estimated specified task duration is 4 days then the optimistic duration will be 3 days. |
| [set_Pessimistic](./set_pessimistic/) | Sets the percentage of the most likely task duration which can happen in the worst possible project scenario. The default value is 125, which means that if the estimated specified task duration is 4 days then the pessimistic duration will be 5 days. |
