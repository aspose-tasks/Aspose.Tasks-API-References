## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Allows to specify additional options when rendering project pages to XLSX.

## Constructors

| Name | Description |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Initializes a new instance of the XlsxOptions class that can be used to save project in XLSX format. |

| [set_View](./set_view/) | Sets a list of the view columns ( GanttChartColumn ) to save to XLSX format. If not set then default columns are saved. |
