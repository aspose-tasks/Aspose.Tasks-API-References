## SimpleSaveOptions class

This is an abstract base class that allow the user to specify basic options when saving a project into a particular format.

| [get_TasksFilter](./get_tasksfilter/) | Gets the condition which is used to filter tasks rendered on Gantt, Task Sheet and Task Usage charts. |
| [set_TasksComparer](./set_taskscomparer/) | Sets the comparer to sort tasks on Gantt chart and Task Sheet chart. |
