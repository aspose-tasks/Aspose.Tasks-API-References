## TaskUtils class

Helper class which provides useful operations with tasks.

## Methods

| Name | Description |
| --- | --- |
| [Apply](./apply/) | Applies specified algorithm to each task of a tree. |
| [Filter](./filter/) | Builds new tree of tasks which satisfy the condition. |
| [Find](./find/) | Finds a task which satisfy the condition in a tree of tasks. |
| [TaskChildrenCount](./taskchildrencount/) | Recursively calculates a number of task's children tasks through all levels. |
