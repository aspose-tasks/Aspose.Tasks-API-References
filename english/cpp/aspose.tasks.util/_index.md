## Aspose::Tasks::Util namespace

This namespace groups generic utilities used throughout Aspose.Tasks, such as condition combinators, tree‑processing algorithms, and field‑handling helpers, enabling developers to create custom filters, evaluate task hierarchies, and extend processing logic efficiently.


## Classes

| Name | Description |
| --- | --- |

| [AndAllCondition< T >](./andallcondition/) | Applies logical AND to all conditions. For example: cond1 AND cond2 AND cond3... |
| [CheckCircuit](./checkcircuit/) | Checks a tree (of tasks) whether it contains a circuit. |
| [ChildTasksCollector](./childtaskscollector/) | Collects all child tasks. |
| [FieldHelper](./fieldhelper/) | Helper class which provides useful operations with fields. |
| [IAlgorithm< T >](./ialgorithm/) | Represents an algorithm that can be applied to a list of objects T . |
