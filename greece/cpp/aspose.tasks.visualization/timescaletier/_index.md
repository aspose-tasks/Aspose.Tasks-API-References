## TimescaleTier class

Αναπαριστά ένα ενιαίο επίπεδο της κλίμακας χρόνου σε ένα Gantt Chart.

## Κατασκευαστές

| Όνομα | Περιγραφή |
| --- | --- |
| [TimescaleTier (2 overloads)](./timescaletier/) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης TimescaleTier. |

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_Alignment](./get_alignment/) | Λαμβάνει πώς να ευθυγραμμιστούν οι ετικέτες μέσα σε κάθε χρονική περίοδο του επιπέδου ( HorizontalStringAlignment ). |
| [get_Count](./get_count/) | Λαμβάνει το διάστημα μονάδας χρόνου στο οποίο θα εμφανίζονται ετικέτες για το επίπεδο. Η προεπιλεγμένη τιμή είναι 1. |
| [get_DateTimeConverter](./get_datetimeconverter/) | Λαμβάνει μια συνάρτηση callback για τη διαχείριση του χρονοσήμου απόδοσης ημερομηνίας σε αυτό το επίπεδο. |
