## ViewColumn class

Αναπαριστά μια στήλη σε προβολή έργου.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_Field](./get_field/) | Λαμβάνει το πεδίο της στήλης. Πεδίο . |
| [get_Name](./get_name/) | Λαμβάνει το όνομα της στήλης. |
| [get_StringAlignment](./get_stringalignment/) | Λαμβάνει την ευθυγράμμιση του κειμένου (μπορεί να είναι μία από τις τιμές της απαρίθμησης HorizontalStringAlignment). |
| [get_TextStyleModificationCallback](./get_textstylemodificationcallback/) | Λαμβάνει την κλήση επιστροφής που μπορεί να χρησιμοποιηθεί για την προσαρμογή της εμφάνισης των κελιών της στήλης. |
| [get_Width](./get_width/) | Λαμβάνει το πλάτος της στήλης. |
| [set_Field](./set_field/) | Ορίζει το πεδίο της στήλης. Πεδίο . |
| [set_StringAlignment](./set_stringalignment/) | Ορίζει την ευθυγράμμιση του κειμένου (μπορεί να είναι μία από τις τιμές της απαρίθμησης HorizontalStringAlignment). |
| [set_TextStyleModificationCallback](./set_textstylemodificationcallback/) | Ορίζει την κλήση επιστροφής που μπορεί να χρησιμοποιηθεί για την προσαρμογή της εμφάνισης των κελιών της στήλης. |
