## PageSettings class

Αναπαριστά τις ρυθμίσεις εκτύπωσης για μια σελίδα της προβολής του έργου.

## Κατασκευαστές

| Όνομα | Περιγραφή |
| --- | --- |
| [PageSettings](./pagesettings/) | Αρχικοποιεί μια νέα παρουσία της κλάσης PageSettings. Αντιπροσωπεύει τις ρυθμίσεις εκτύπωσης για μια σελίδα της προβολής του έργου. |

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | Λαμβάνει μια τιμή που υποδεικνύει εάν θα προσαρμοστεί η εκτύπωση στο καθορισμένο ποσοστό ( PercentOfNormalSize ) του κανονικού μεγέθους. |
| [get_FirstPageNumber](./get_firstpagenumber/) | Λαμβάνει τον αριθμό της πρώτης σελίδας για εκτύπωση. |
| [get_IsPortrait](./get_isportrait/) | Λαμβάνει μια τιμή που υποδεικνύει εάν ο προσανατολισμός της σελίδας είναι πορτραίτο· επιστρέφει false εάν ο προσανατολισμός της σελίδας είναι τοπίο. |
| [get_PagesInHeight](./get_pagesinheight/) | Λαμβάνει τον αριθμό των σελίδων σε ύψος που θα εκτυπωθούν. |

| [set_FirstPageNumber](./set_firstpagenumber/) | Ορίζει έναν αριθμό πρώτης σελίδας για εκτύπωση. |

| [set_PagesInHeight](./set_pagesinheight/) | Ορίζει έναν αριθμό σελίδων σε ύψος που θα εκτυπωθούν. |
| [set_PagesInWidth](./set_pagesinwidth/) | Ορίζει έναν αριθμό σελίδων σε πλάτος που θα εκτυπωθούν. |
| [set_PaperSize](./set_papersize/) | Ορίζει ένα μέγεθος χαρτιού. Μπορεί να είναι μία από τις τιμές της απαρίθμησης PrinterPaperSize. |
