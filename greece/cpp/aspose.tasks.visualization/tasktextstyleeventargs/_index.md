## TaskTextStyleEventArgs class

Αυτή η κλάση αναπαριστά ένα σύνολο δεδομένων που σχετίζονται με την απόδοση του περιεχομένου ενός κελιού πίνακα.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | Λαμβάνει το TextStyle που θα χρησιμοποιηθεί για τη σχεδίαση του περιεχομένου του κελιού. Αυτό το αντικείμενο μπορεί να χρησιμοποιηθεί για την προσαρμογή της εμφάνισης ενός κελιού πίνακα. |
| [get_Column](./get_column/) | Λαμβάνει το ViewColumn στο οποίο ανήκει το τρέχον εμφανιζόμενο κελί. |
| [get_Task](./get_task/) | Λαμβάνει το Task που αντιστοιχεί στη τρέχουσα εμφανιζόμενη σειρά. |
| [set_CellTextStyle](./set_celltextstyle/) | Ορίζει το TextStyle που θα χρησιμοποιηθεί για τη σχεδίαση του περιεχομένου του κελιού. Αυτό το αντικείμενο μπορεί να χρησιμοποιηθεί για την προσαρμογή της εμφάνισης ενός κελιού πίνακα. |
