## RecurringInterval class

Αναπαριστά τα επαναλαμβανόμενα διαστήματα που χρησιμοποιούνται στις γραμμές προόδου μιας προβολής Gantt Chart.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [DayType](./daytype/) | Αναπαριστά έναν τύπο ημέρας που χρησιμοποιείται σε γραμμές προόδου. |
| [get_DailyDayNumber](./get_dailydaynumber/) | Λαμβάνει τον ημερήσιο αριθμό ημέρας. |
| [get_DailyWorkday](./get_dailyworkday/) | Λαμβάνει μια τιμή που υποδεικνύει εάν μια ημέρα είναι εργάσιμη για ημερήσιες γραμμές προόδου. |
| [get_Interval](./get_interval/) | Λαμβάνει το επαναλαμβανόμενο διάστημα. Μπορεί να είναι οποιαδήποτε τιμή του τύπου Interval. |
| [get_MonthlyDay](./get_monthlyday/) | Λαμβάνει μια τιμή που υποδεικνύει εάν θα εμφανίζονται μηνιαίες γραμμές προόδου ανά ημέρα. |
| [get_MonthlyDayDayNumber](./get_monthlydaydaynumber/) | Λαμβάνει τον αριθμό ημέρας των μηνιαίων γραμμών προόδου. |
| [get_MonthlyDayMonthNumber](./get_monthlydaymonthnumber/) | Λαμβάνει τον αριθμό μήνα των μηνιαίων γραμμών προόδου. |
| [get_MonthlyFirstLast](./get_monthlyfirstlast/) | Λαμβάνει μια τιμή που υποδεικνύει εάν θα εμφανίζονται γραμμές προόδου με την πρώτη ή την τελευταία προκαθορισμένη ημέρα. |
| [get_MonthlyFirstLastDay](./get_monthlyfirstlastday/) | Λαμβάνει τον τύπο της πρώτης ή της τελευταίας ημέρας των μηνιαίων γραμμών προόδου. |
| [get_MonthlyFirstLastMonthNumber](./get_monthlyfirstlastmonthnumber/) | Λαμβάνει τον αριθμό του μήνα των γραμμών προόδου, που εμφανίζονται με την πρώτη ή την τελευταία προκαθορισμένη ημέρα. |
| [get_WeeklyDays](./get_weeklydays/) | Λαμβάνει μια λίστα ημερών για τις εβδομαδιαίες γραμμές προόδου. |

| [set_DailyWorkday](./set_dailyworkday/) | Ορίζει μια τιμή που υποδεικνύει εάν μια ημέρα είναι εργάσιμη για τις ημερήσιες γραμμές προόδου. |
| [set_Interval](./set_interval/) | Ορίζει το επαναλαμβανόμενο διάστημα. Μπορεί να είναι οποιαδήποτε τιμή του τύπου Interval. |
| [set_MonthlyDay](./set_monthlyday/) | Ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται οι μηνιαίες γραμμές προόδου ανά ημέρα. |
| [set_MonthlyDayDayNumber](./set_monthlydaydaynumber/) | Ορίζει τον αριθμό ημέρας των μηνιαίων γραμμών προόδου. |
