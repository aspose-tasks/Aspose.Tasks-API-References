## Gridlines class

Αναπαριστά τις γραμμές πλέγματος που εμφανίζονται σε προβολή GanttChart.

| [get_IntervalColor](./get_intervalcolor/) | Λαμβάνει το χρώμα των δευτερευουσών γραμμών πλέγματος. |
| [get_IntervalPattern](./get_intervalpattern/) | Λαμβάνει το μοτίβο γραμμής για τις δευτερεύουσες γραμμές πλέγματος. |
