## SetMaterialResourceUnits {#setmaterialresourceunits}

Ορίζει μονάδες για την ανάθεση ενός υλικού πόρου με μεταβλητή κατανάλωση υλικού. Η μεταβλητή κατανάλωση υλικού σημαίνει ότι καθώς η διάρκεια της ανάθεσης αλλάζει, η ποσότητα των χρησιμοποιούμενων υλικών αλλάζει ανάλογα.

**Returns:** void Aspose::Tasks::

```cpp
SetMaterialResourceUnits(double units, RateScaleType rateScaleType)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| μονάδες | Αριθμός μονάδων που συσσωρεύονται στην χρονική περίοδο. |
| rateScaleType | Χρονική περίοδος στην οποία η τιμή μονάδας συσσωρεύεται. |
