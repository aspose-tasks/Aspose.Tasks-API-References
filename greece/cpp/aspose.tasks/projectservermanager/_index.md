## ProjectServerManager class

Η κλάση που παρέχει τις μεθόδους για ανάγνωση και εκτέλεση λειτουργιών σε έργα στον καθορισμένο λογαριασμό Project Online ή στην καθορισμένη on-premise Project Server παρουσία (υποστηρίζονται οι εκδόσεις Project Server 2016 και 2019).
