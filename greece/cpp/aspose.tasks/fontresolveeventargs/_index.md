## FontResolveEventArgs class

Παρέχει επιχειρήματα για την κλήση επιστροφής που καλείται όταν η γραμματοσειρά επιλύεται.

| [get_ResolvedFontName](./get_resolvedfontname/) | Λαμβάνει το όνομα της επιλυμένης γραμματοσειράς. Μπορεί να οριστεί για να ελέγχει τις γραμματοσειρές που χρησιμοποιούνται για την απόδοση μιας προβολής. |
| [set_ResolvedFontName](./set_resolvedfontname/) | Ορίζει το όνομα της επιλυμένης γραμματοσειράς. Μπορεί να οριστεί για να ελέγχει τις γραμματοσειρές που χρησιμοποιούνται για την απόδοση μιας προβολής. |
