## PrimaveraProjectProperties class

Αναπαριστά τις ιδιότητες ειδικές για Primavera ενός έργου που διαβάζεται από αρχεία Primavera (XER ή P6XML).

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | Λαμβάνει πίνακα των έργων βάσης του τρέχοντος έργου. Ισχύει για έργα που διαβάζονται από αρχεία Primavera XML που περιέχουν εξαγόμενες βάσεις. |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | Λαμβάνει το Id του τρέχοντος έργου βάσης. Ισχύει για έργα που διαβάζονται από αρχεία Primavera XML που περιέχουν εξαγόμενες βάσεις. |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | Λαμβάνει μια σημαία που ορίζει εάν θα αγνοηθούν οι σχέσεις δραστηριοτήτων μεταξύ έργων. |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | Λαμβάνει μια σημαία που ορίζει εάν οι δραστηριότητες θα πρέπει να σημειώνονται ως κρίσιμες κατά τον προγραμματισμό του έργου. |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | Λαμβάνει μια επιλογή που ορίζει ποιο ημερολόγιο θα χρησιμοποιηθεί για τον προγραμματισμό της καθυστέρησης σχέσης (Relationship Lag) σε έργα Primavera. |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | Λαμβάνει μια σημαία που ορίζει εάν οι ημερομηνίες λήξης των δραστηριοτήτων θα πρέπει να προγραμματίζονται ως οι αναμενόμενες ημερομηνίες λήξης. |
