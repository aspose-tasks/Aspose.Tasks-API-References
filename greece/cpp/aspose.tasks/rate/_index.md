## Rate class

Αντιπροσωπεύει έναν ορισμό χρονικής περιόδου και των τιμών που ισχύουν για έναν πόρο κατά τη διάρκεια αυτής της περιόδου.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Λαμβάνει το κόστος ανά χρήση ενός πόρου. Αυτή η τιμή λαμβάνεται από την τρέχουσα ημερομηνία εάν υπάρχει πίνακας τιμών για τον πόρο. |
| [get_OvertimeRate](./get_overtimerate/) | Λαμβάνει το ποσοστό υπερωρίας ανά ώρα για έναν πόρο. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Λαμβάνει τις μονάδες που χρησιμοποιεί το Microsoft Project για την εμφάνιση του ποσοστού υπερωρίας. |
| [get_RatesFrom](./get_ratesfrom/) | Λαμβάνει την ημερομηνία κατά την οποία μια τιμή τίθεται σε ισχύ. |
| [get_RatesTo](./get_ratesto/) | Λαμβάνει την τελευταία ημερομηνία κατά την οποία ισχύει ένα ποσοστό. |
| [get_RateTable](./get_ratetable/) | Λαμβάνει το μοναδικό αναγνωριστικό του πίνακα τιμών για έναν πόρο. |
| [get_StandardRate](./get_standardrate/) | Λαμβάνει το τυπικό ποσοστό ανά ώρα για έναν πόρο. |
| [get_StandardRateFormat](./get_standardrateformat/) | Λαμβάνει τις μονάδες που χρησιμοποιεί το Microsoft Project για την εμφάνιση του τυπικού ποσοστού. |
| [set_CostPerUse](./set_costperuse/) | Ορίζει το κόστος ανά χρήση ενός πόρου. Αυτή η τιμή λαμβάνεται από την τρέχουσα ημερομηνία εάν υπάρχει πίνακας τιμών για τον πόρο. |
| [set_OvertimeRate](./set_overtimerate/) | Ορίζει το ωριαίο ποσοστό υπερωρίας για έναν πόρο. |
