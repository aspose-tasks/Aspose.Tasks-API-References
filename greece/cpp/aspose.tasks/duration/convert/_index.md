Μετατρέπει το αντικείμενο Duration σε άλλη διάρκεια με καθορισμένες μονάδες χρόνου.

**Returns:** returns new duration with the specified unit type.

```cpp
Convert(TimeUnitType timeUnitType)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| timeUnitType | ο καθορισμένος τύπος μονάδας χρόνου. |
