## PrimaveraTaskProperties class

Αντιπροσωπεύει τις ιδιότητες ειδικές για Primavera ενός έργου που διαβάζονται από αρχεία Primavera (XER ή P6XML).

| [get_ActivityType](./get_activitytype/) | Λαμβάνει την τιμή του πεδίου 'Activity Type'. |

| [get_BudgetedMaterialCost](./get_budgetedmaterialcost/) | Λαμβάνει την τιμή του προϋπολογισμένου (ή προγραμματισμένου) κόστους υλικών. |

| [get_RawStatus](./get_rawstatus/) | Λαμβάνει την ακατέργαστη αναπαράσταση κειμένου (όπως στο αρχείο προέλευσης) του πεδίου 'Status' της δραστηριότητας. |

| [get_UnitsPercentComplete](./get_unitspercentcomplete/) | Λαμβάνει την τιμή του ποσοστού ολοκλήρωσης μονάδων. |
