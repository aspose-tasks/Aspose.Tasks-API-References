## CheckPropAndSet {#checkpropandset}

Αντιστοιχίζει την καθορισμένη ιδιότητα στην καθορισμένη τιμή σε αυτό το δοχείο. Εάν αυτό το δοχείο δεν περιέχει την εγγραφή ProjectItem, θα προστεθεί.

```cpp
CheckPropAndSet(const Key < TValue, T > & key, const TValue & val)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| κλειδί | η καθορισμένη ιδιότητα. |
| val | η τιμή. |
