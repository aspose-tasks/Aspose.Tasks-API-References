## CheckPropAndGet {#checkpropandget}

Επιστρέφει την τιμή στην οποία αντιστοιχεί η ιδιότητα σε αυτό το δοχείο. Εάν αυτό το δοχείο δεν περιέχει την εγγραφή ProjectItem, θα προστεθεί με προεπιλεγμένη τιμή και η προεπιλεγμένη τιμή θα επιστραφεί.

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| κλειδί | η καθορισμένη ιδιότητα. |
