## Metered class

Παρέχει μεθόδους για τον ορισμό κλειδιού μετρητή.

Σε αυτό το παράδειγμα, θα γίνει προσπάθεια να οριστεί το δημόσιο και ιδιωτικό κλειδί μετρημένου <ms>

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> το αρχείο jar του στοιχείου:

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>
