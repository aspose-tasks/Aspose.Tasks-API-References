## CheckException {#checkexception}

Επιστρέφει true εάν η καθορισμένη παρουσία της δομής DateTime είναι η ημέρα εξαίρεσης.

**Returns:** Returns true if DateTime value is the exception day; otherwise, false.

```cpp
CheckException(System::DateTime dt)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| dt | την καθορισμένη παρουσία της δομής DateTime. |
