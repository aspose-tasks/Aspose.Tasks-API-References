## get_ProjectName {#get_projectname}

Λαμβάνει το όνομα ενός έργου που εμφανίζεται στη λίστα έργων του Project Server \ Project Online. Θα πρέπει να είναι μοναδικό εντός του αντικειμένου Project Server \ Project Online. Εάν η τιμή παραλειφθεί, θα χρησιμοποιηθεί η τιμή της ιδιότητας Prj.Name.

**Returns:** System::String Aspose::Tasks::

```cpp
get_ProjectName()
```
