## ProjectServerSaveOptions class

Επιτρέπει τον καθορισμό πρόσθετων επιλογών όταν το έργο αποθηκεύεται στο Project Server ή στο Project Online.

## Κατασκευαστές

| Όνομα | Περιγραφή |
| --- | --- |
| [ProjectServerSaveOptions](./projectserversaveoptions/) | Αρχικοποιεί μια νέα παρουσία της κλάσης ProjectServerSaveOptions. |

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_PollingInterval](./get_pollinginterval/) | Λαμβάνει το διάστημα μεταξύ των αιτήσεων κατάστασης εργασίας στην ουρά. Η προεπιλεγμένη τιμή είναι 2 δευτερόλεπτα. |
| [get_ProjectGuid](./get_projectguid/) | Λαμβάνει το μοναδικό αναγνωριστικό ενός έργου. Θα πρέπει να είναι μοναδικό εντός του αντικειμένου Project Server \ Project Online. |
| [get_ProjectName](./get_projectname/) | Λαμβάνει το όνομα ενός έργου που εμφανίζεται στη λίστα έργων του Project Server \ Project Online. Θα πρέπει να είναι μοναδικό εντός του αντικειμένου Project Server \ Project Online. Εάν η τιμή παραλειφθεί, θα χρησιμοποιηθεί η τιμή της ιδιότητας Prj.Name. |
| [get_Timeout](./get_timeout/) | Λαμβάνει το χρονικό όριο που χρησιμοποιείται κατά την αναμονή επεξεργασίας του αιτήματος αποθήκευσης έργου από την υπηρεσία επεξεργασίας ουράς του Project Server. Η προεπιλεγμένη τιμή για αυτήν την ιδιότητα είναι 1 λεπτό. |
| [set_PollingInterval](./set_pollinginterval/) | Ορίζει το διάστημα μεταξύ των αιτήσεων κατάστασης εργασίας στην ουρά. Η προεπιλεγμένη τιμή είναι 2 δευτερόλεπτα. |
| [set_ProjectGuid](./set_projectguid/) | Ορίζει το μοναδικό αναγνωριστικό ενός έργου. Θα πρέπει να είναι μοναδικό εντός του αντικειμένου Project Server \ Project Online. |
| [set_ProjectName](./set_projectname/) | Ορίζει το όνομα ενός έργου που εμφανίζεται στη λίστα έργων του Project Server \ Project Online. Θα πρέπει να είναι μοναδικό εντός του αντικειμένου Project Server \ Project Online. Εάν η τιμή παραλειφθεί, θα χρησιμοποιηθεί η τιμή της ιδιότητας Prj.Name. |
| [set_Timeout](./set_timeout/) | Ορίζει το χρονικό όριο που χρησιμοποιείται κατά την αναμονή για την επεξεργασία του αιτήματος αποθήκευσης έργου από την υπηρεσία επεξεργασίας ουράς του Project Server. Η προεπιλεγμένη τιμή για αυτήν την ιδιότητα είναι 1 λεπτό. |
