## CompareTo {#compareto}

Υλοποίηση διεπαφής IComparable. Συγκρίνει αυτήν την παρουσία με το καθορισμένο αντικείμενο Baseline.

**Returns:** returns -1 if this instance is less than the specified object, 1 if this instance is greater than the specified object; otherwise returns 0

```cpp
CompareTo(System::SharedPtr< Baseline > other)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| άλλο | το καθορισμένο αντικείμενο Baseline για σύγκριση με αυτό το αντίγραφο. |
