## IsDayWorking {#isdayworking}

Καθορίζει εάν η καθορισμένη ημέρα είναι εργάσιμη ημέρα σύμφωνα με το ημερολόγιο.

**Returns:** True if the day is a working day.

```cpp
IsDayWorking(System::DateTime dt)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| dt | Η ημερομηνία για να ελέγξετε αν η ημέρα είναι εργάσιμη. |
