## OleObjectCollection class

Αντιπροσωπεύει μια συλλογή που περιέχει τις παρουσίες της κλάσης OleObject.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [Clear](./clear/) | Καθαρίζει τη συλλογή. Για να διατηρηθούν αυτές οι αλλαγές, πρέπει να κληθεί το project.Save με νέο MPPSaveOptions { WriteViewData = true; } |
| [GetEnumerator](./getenumerator/) | Επιστρέφει έναν enumerator για αυτή τη συλλογή. |
| [ToList](./tolist/) | Μετατρέπει την παρουσίαση της κλάσης OleObjectCollection σε μια λίστα που περιέχει τις παρουσίες της κλάσης OleObject. |
