## FontSettings class

Καθορίζει τις ρυθμίσεις γραμματοσειράς που χρησιμοποιούνται κατά την απόδοση της προβολής του έργου.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | Λαμβάνει την προεπιλεγμένη (ή εφεδρική) γραμματοσειρά για την απόδοση. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | Λαμβάνει μια κλήση επιστροφής που μπορεί να χρησιμοποιηθεί για την προσαρμογή των επιλυμένων γραμματοσειρών. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | Λαμβάνει μια τιμή που υποδεικνύει αν η προεπιλεγμένη γραμματοσειρά πρέπει να χρησιμοποιηθεί για την απόδοση. |
| [set_DefaultFontName](./set_defaultfontname/) | Ορίζει την προεπιλεγμένη (ή εφεδρική) γραμματοσειρά για την απόδοση. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | Ορίζει μια κλήση επιστροφής που μπορεί να χρησιμοποιηθεί για την προσαρμογή των επιλυμένων γραμματοσειρών. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | Ορίζει μια τιμή που υποδεικνύει αν η προεπιλεγμένη γραμματοσειρά πρέπει να χρησιμοποιηθεί για την απόδοση. |
| [SetFontFolders](./setfontfolders/) | Ορίζει τους φακέλους όπου το Aspose.Tasks αναζητά γραμματοσειρές TrueType κατά την απόδοση της προβολής του έργου. |
