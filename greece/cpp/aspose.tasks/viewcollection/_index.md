## ViewCollection class

Περιέχει μια λίστα αντικειμένων View. Υλοποιεί τη διεπαφή ICollection< View >.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [Add](./add/) | Προσθέτει το καθορισμένο στοιχείο σε αυτή τη συλλογή. |
| [Clear](./clear/) | Αφαιρεί όλα τα στοιχεία από αυτή τη συλλογή. |
| [Contains](./contains/) | Επιστρέφει true εάν το καθορισμένο στοιχείο βρεθεί σε αυτή τη συλλογή· διαφορετικά, false. |
| [CopyTo](./copyto/) | Αντιγράφει τα στοιχεία αυτής της συλλογής στον καθορισμένο πίνακα, ξεκινώντας από το καθορισμένο δείκτη πίνακα. |
| [get_Count](./get_count/) | Λαμβάνει τον αριθμό των στοιχείων που περιέχονται σε αυτή τη συλλογή. |
| [get_IsReadOnly](./get_isreadonly/) | Αποκτά μια τιμή που υποδεικνύει εάν αυτή η συλλογή είναι μόνο για ανάγνωση· διαφορετικά, false. |
| [get_ParentProject](./get_parentproject/) | Αποκτά το γονικό αντικείμενο του αντικειμένου View. Μόνο για ανάγνωση Project. |
| [GetByName](./getbyname/) | Αναζητά ένα View με το όνομα και επιστρέφει την πρώτη εμφάνιση μέσα στη συλλογή. |
| [GetByViewScreen](./getbyviewscreen/) | Αναζητά ένα View με την καθορισμένη ιδιότητα Screen και επιστρέφει την πρώτη εμφάνιση μέσα στη συλλογή. |
| [GetEnumerator](./getenumerator/) | Επιστρέφει έναν enumerator για αυτή τη συλλογή. |
| [Remove](./remove/) | Αφαιρεί την πρώτη εμφάνιση ενός συγκεκριμένου αντικειμένου από αυτή τη συλλογή. |
| [ToList](./tolist/) | Μετατρέπει μια συλλογή view σε μια λίστα από αντικείμενα View. |
