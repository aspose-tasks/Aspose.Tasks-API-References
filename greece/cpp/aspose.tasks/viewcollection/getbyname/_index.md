## GetByName {#getbyname}

Αναζητά ένα View με το όνομα και επιστρέφει την πρώτη εμφάνιση μέσα στη συλλογή.

**Returns:** The first View in collection with the specified name, if found; otherwise, null.

```cpp
GetByName(const System::String & viewName)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| viewName | Όνομα της προβολής για αναζήτηση. |
