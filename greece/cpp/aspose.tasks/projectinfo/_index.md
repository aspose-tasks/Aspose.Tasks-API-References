## ProjectInfo class

Σύντομες πληροφορίες σχετικά με το δημοσιευμένο έργο που είναι διαθέσιμο στο Project Online.

## Κατασκευαστές

| Όνομα | Περιγραφή |
| --- | --- |
| [ProjectInfo](./projectinfo/) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης ProjectInfo. |

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_CreatedDate](./get_createddate/) | Λαμβάνει την ημερομηνία και ώρα δημιουργίας του έργου. |
| [get_Description](./get_description/) | Λαμβάνει την περιγραφή του έργου. |
| [get_Id](./get_id/) | Λαμβάνει το μοναδικό αναγνωριστικό του έργου. |
| [get_IsCheckedOut](./get_ischeckedout/) | Λαμβάνει μια τιμή που υποδεικνύει εάν το έργο έχει ελεγχθεί. |
| [get_LastPublishedDate](./get_lastpublisheddate/) | Λαμβάνει την πιο πρόσφατη ημερομηνία που δημοσιεύτηκε το έργο. |
| [get_LastSavedDate](./get_lastsaveddate/) | Λαμβάνει την πιο πρόσφατη ημερομηνία που αποθηκεύτηκε το έργο. |
| [get_Name](./get_name/) | Λαμβάνει το όνομα του έργου. |
