## IAlgorithm< T > class

Αναπαριστά έναν αλγόριθμο που μπορεί να εφαρμοστεί σε μια λίστα αντικειμένων T.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [Alg](./alg/) | Επεξεργάζεται ένα αντικείμενο στη λίστα. Καλείται μετά το IAlgorithm<T>::PreAlg ; |
| [PostAlg](./postalg/) | Καλείται μετά την επεξεργασία ενός αντικειμένου. |
| [PreAlg](./prealg/) | Καλείται πριν από την επεξεργασία ενός αντικειμένου. |
