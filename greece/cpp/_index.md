Το API προσφέρει ένα πλούσιο μοντέλο αντικειμένων για τη διαχείριση μορφών Project XML, MPX, MPP και Primavera XER, υποστηρίζοντας εργασίες, πόρους, αναθέσεις, ημερολόγια και προσαρμοσμένα πεδία. Η λειτουργικότητά του είναι οργανωμένη σε εννέα χώρους ονομάτων: Aspose::Tasks για βασικές οντότητες, Connectivity για είσοδο/έξοδο αρχείων, Leveling για εξισορρόπηση πόρων, Primavera για αντικείμενα ειδικά για Primavera, Properties για εκτεταμένα χαρακτηριστικά, RiskAnalysis για μοντελοποίηση κινδύνου Monte‑Carlo, Saving για επιλογές εξαγωγής, Util για βοηθητικές λειτουργίες, και Visualization για απόδοση διαγραμμάτων Gantt και αναφορών.
