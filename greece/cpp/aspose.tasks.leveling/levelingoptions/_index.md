## LevelingOptions class

Επιτρέπει τον καθορισμό παραμέτρων εξισορρόπησης πόρων.

## Κατασκευαστές

| Όνομα | Περιγραφή |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Αρχικοποιεί μια νέα παρουσία της κλάσης LevelingOptions. |

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_FinishDate](./get_finishdate/) | Λαμβάνει την ημερομηνία λήξης της περιόδου εξισορρόπησης. Η προεπιλεγμένη τιμή είναι η ημερομηνία λήξης του έργου. |
| [get_LevelingOrder](./get_levelingorder/) | Λαμβάνει τη σειρά με την οποία ο αλγόριθμος εξισορρόπησης καθυστερεί εργασίες που έχουν υπερκατανομές. Μετά τον προσδιορισμό των εργασιών που προκαλούν την υπερκατανομή και των εργασιών που μπορούν να καθυστερηθούν, χρησιμοποιείται η καθορισμένη σειρά για το ποια εργασία πρέπει να καθυστερήσει πρώτα. |
| [get_MessageHandler](./get_messagehandler/) | Λαμβάνει την κλήση επανάκλησης του διαχειριστή μηνυμάτων που μπορεί να χρησιμοποιηθεί για την παρέμβαση στα μηνύματα καταγραφής που παράγονται από το Aspose.Tasks κατά τη διάρκεια της εξισορρόπησης πόρων. |
| [get_MessageLevel](./get_messagelevel/) | Λαμβάνει το επίπεδο των μηνυμάτων καταγραφής που εκδίδονται από το Aspose.Tasks κατά τη διάρκεια της εξισορρόπησης πόρων. |
| [get_Resources](./get_resources/) | Λαμβάνει τη λίστα των πόρων που θα εξισορροπηθούν. Εάν οριστεί null, όλοι οι πόροι του έργου θα εξισορροπηθούν. |
| [get_StartDate](./get_startdate/) | Λαμβάνει την ημερομηνία έναρξης της περιόδου εξισορρόπησης. Η προεπιλεγμένη τιμή είναι η ημερομηνία έναρξης του έργου. |
| [set_FinishDate](./set_finishdate/) | Ορίζει την ημερομηνία λήξης της περιόδου εξισορρόπησης. Η προεπιλεγμένη τιμή είναι η ημερομηνία λήξης του έργου. |
| [set_LevelingOrder](./set_levelingorder/) | Λαμβάνει τη σειρά με την οποία ο αλγόριθμος εξισορρόπησης καθυστερεί εργασίες που έχουν υπερκατανομές.
