## LevelResources {#levelresources}

Εξισορροπεί τις εργασίες για τους καθορισμένους πόρους χρησιμοποιώντας τις καθορισμένες επιλογές εξισορρόπησης.

**Returns:** Object containing results of resource leveling.

```cpp
LevelResources(const System::SharedPtr< Project > & project, const System::SharedPtr< LevelingOptions > & options)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| έργο | Έργο για την εφαρμογή εξισορρόπησης πόρων. |
| options | Επιλογές που καθορίζουν πώς να εξισορροπηθούν οι πόροι. |
