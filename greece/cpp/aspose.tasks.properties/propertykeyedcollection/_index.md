## PropertyKeyedCollection< T > class

Μια βασική κλάση συλλογής ιδιοτήτων.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [Add](./add/) | Δημιουργεί μια νέα προσαρμοσμένη ιδιότητα. |

| [get_IsReadOnly](./get_isreadonly/) | Αποκτά μια τιμή που υποδεικνύει εάν αυτή η συλλογή είναι μόνο για ανάγνωση· διαφορετικά, false. |
