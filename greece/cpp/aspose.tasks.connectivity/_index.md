## Aspose::Tasks::Connectivity namespace

Χρησιμοποιήστε αυτούς τους τύπους για να διαμορφώσετε συνδέσεις με βάσεις δεδομένων Microsoft Project Server (MspDbSettings), βάσεις δεδομένων Primavera (PrimaveraDbSettings), αρχεία MPD (MpdSettings) ή γενικές πηγές βάσεων δεδομένων (DbSettings). Ο χώρος ονομάτων συγκεντρώνει τη διαμόρφωση συνδεσιμότητας για αδιάλειπτη ενσωμάτωση με τις δυνατότητες εξαγωγής και επεξεργασίας δεδομένων του Aspose.Tasks.
