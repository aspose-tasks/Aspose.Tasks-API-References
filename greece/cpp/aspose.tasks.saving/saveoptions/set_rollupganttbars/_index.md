## set_RollUpGanttBars {#set_rollupganttbars}

Ορίζει μια τιμή που υποδεικνύει εάν οι υποεργασίες στη μπάρα της συνολικής εργασίας πρέπει να σημειωθούν. Για τις υποεργασίες, το πεδίο Rollup υποδεικνύει εάν οι πληροφορίες των μπαρ Gantt των υποεργασιών θα συγκεντρωθούν στη μπάρα της συνολικής εργασίας. Για τις συνολικές εργασίες, το πεδίο Rollup υποδεικνύει εάν η μπάρα της συνολικής εργασίας εμφανίζει συγκεντρωμένα μπαρ. Πρέπει να έχετε το πεδίο Rollup για τις συνολικές εργασίες ορισμένο σε Yes ώστε οποιεσδήποτε υποεργασίες να συγκεντρωθούν σε αυτές.
