## get_ViewSettings {#get_viewsettings}

Λαμβάνει μια προβολή ( View ) για απόδοση. Μπορείτε να χρησιμοποιήσετε αυτήν την επιλογή για να καθορίσετε ρητά ποια προβολή πρέπει να αποθηκευτεί σε μορφές PDF, HTML ή Image. Εάν αυτή η ιδιότητα οριστεί, η ιδιότητα Visualization::PresentationFormat αγνοείται όταν το έργο αποθηκεύεται. Η προβολή πρέπει να προέρχεται από μία από τις παρακάτω οθόνες (( Aspose::Tasks::View::Screen )): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage).

**Returns:** System::SharedPtr< Aspose::Tasks::View > Aspose::Tasks::Saving::
