## get_RollUpGanttBars {#get_rollupganttbars}

Λαμβάνει μια τιμή που υποδεικνύει εάν οι υποεργασίες στη γραμμή εργασίας σύνοψης πρέπει να σημειωθούν. Για τις υποεργασίες, το πεδίο Rollup υποδεικνύει εάν οι πληροφορίες των γραμμών Gantt των υποεργασιών θα συγκεντρωθούν στη γραμμή εργασίας σύνοψης. Για τις εργασίες σύνοψης, το πεδίο Rollup υποδεικνύει εάν η γραμμή εργασίας σύνοψης εμφανίζει συγκεντρωμένες γραμμές. Πρέπει να έχετε το πεδίο Rollup για τις εργασίες σύνοψης ορισμένο σε Yes ώστε οποιεσδήποτε υποεργασίες να συγκεντρωθούν σε αυτές.
