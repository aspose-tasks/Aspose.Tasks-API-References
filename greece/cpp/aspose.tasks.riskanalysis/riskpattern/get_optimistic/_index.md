## get_Optimistic {#get_optimistic}

Λαμβάνει το ποσοστό της πιο πιθανής διάρκειας εργασίας που μπορεί να συμβεί στο καλύτερο δυνατό σενάριο του έργου. Η προεπιλεγμένη τιμή είναι 75, που σημαίνει ότι εάν η εκτιμώμενη καθορισμένη διάρκεια εργασίας είναι 4 ημέρες, τότε η αισιόδοξη διάρκεια θα είναι 3 ημέρες.

**Returns:** int32_t Aspose::Tasks::RiskAnalysis::

```cpp
get_Optimistic()
```
