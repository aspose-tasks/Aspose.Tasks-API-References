## Analyze {#analyze}

Πραγματοποιεί ανάλυση κινδύνου για το καθορισμένο έργο. Η ανάλυση βασίζεται σε προσομοίωση Monte Carlo και το αποτέλεσμα είναι μια περίπτωση της κλάσης RiskAnalysisResult.

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| έργο | η καθορισμένη παρουσία της κλάσης Project για ανάλυση. |
