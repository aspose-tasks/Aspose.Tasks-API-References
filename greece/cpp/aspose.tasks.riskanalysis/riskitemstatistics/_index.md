## RiskItemStatistics class

Αντιπροσωπεύει ένα αντικείμενο που αποθηκεύει στατιστικά δεδομένα για την εργασία του αναλυόμενου έργου.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | Λαμβάνει την αναμενόμενη τιμή του στοιχείου κινδύνου. |
| [get_ItemType](./get_itemtype/) | Λαμβάνει μια παρουσία της απαρίθμησης RiskItemType. |
| [get_Maximum](./get_maximum/) | Λαμβάνει τη μέγιστη τιμή που δημιουργήθηκε κατά τη διάρκεια της προσομοίωσης Monte Carlo. |
| [get_Minimum](./get_minimum/) | Λαμβάνει τη ελάχιστη τιμή που δημιουργήθηκε κατά τη διάρκεια της προσομοίωσης Monte Carlo. |
| [get_StandardDeviation](./get_standarddeviation/) | Λαμβάνει την τυπική απόκλιση του στοιχείου κινδύνου. |
| [GetPercentile](./getpercentile/) | Λαμβάνει μια τιμή κάτω από την οποία πέφτει ένα καθορισμένο ποσοστό των παραγόμενων δειγμάτων. |
| [ToString](./tostring/) | Επιστρέφει σύντομη αναπαράσταση συμβολοσειράς ενός στοιχείου κινδύνου. Οι ακριβείς λεπτομέρειες της αναπαράστασης δεν έχουν οριστεί και ενδέχεται να αλλάξουν. |
