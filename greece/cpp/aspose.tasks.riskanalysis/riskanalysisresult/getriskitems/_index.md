## GetRiskItems {#getriskitems}

Επιστρέφει μια περίπτωση της RiskItemStatisticsCollection για τον καθορισμένο τύπο κινδύνου.

**Returns:** an instance of the RiskItemStatisticsCollection for the specified risk type.

```cpp
GetRiskItems(RiskItemType itemType)
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| itemType | ο καθορισμένος τύπος κινδύνου· μπορεί να είναι μία από τις τιμές της απαρίθμησης RiskItemType. |
