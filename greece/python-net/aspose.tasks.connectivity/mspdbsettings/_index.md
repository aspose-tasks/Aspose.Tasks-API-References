## MspDbSettings class

Επιτρέπει τον ορισμό των απαραίτητων επιλογών για ανάγνωση δεδομένων έργου από τη βάση δεδομένων MS Project Server.

Ο τύπος MspDbSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Αρχικοποιεί ένα νέο παράδειγμα της κλάσης [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| connection_string | Λαμβάνει ή ορίζει τη συμβολοσειρά σύνδεσης. |
| provider_invariant_name | Λαμβάνει ή ορίζει το όνομα αμετάβλητου παρόχου που χρησιμοποιείται για τη λήψη ενός παραδείγματος της κλάσης. |
| project_guid | Λαμβάνει το GUID του έργου για ανάγνωση. |
| schema | Λαμβάνει ή ορίζει το σχήμα του MS Project Server.<br/>            Η προεπιλεγμένη τιμή είναι "pub". |
