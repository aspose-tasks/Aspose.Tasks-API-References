## MpdSettings class

Επιτρέπει τον ορισμό των απαραίτητων επιλογών για ανάγνωση δεδομένων έργου από μορφή MPD (μορφή αρχείου βάσης δεδομένων MS Access).

Ο τύπος MpdSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| MpdSettings(connection_string, project_id) | Αρχικοποιεί ένα νέο παράδειγμα της κλάσης [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| connection_string | Λαμβάνει ή ορίζει τη συμβολοσειρά σύνδεσης. |
| provider_invariant_name | Λαμβάνει ή ορίζει το όνομα αμετάβλητου παρόχου που χρησιμοποιείται για τη λήψη ενός παραδείγματος της κλάσης. |
| project_id | Λαμβάνει το αναγνωριστικό του έργου για ανάγνωση. |
