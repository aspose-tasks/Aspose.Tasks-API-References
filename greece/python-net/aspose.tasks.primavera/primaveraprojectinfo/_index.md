## PrimaveraProjectInfo class

Αναπαριστά σύντομες πληροφορίες για ένα έργο που φορτώθηκε από μορφή Primavera.

Ο τύπος PrimaveraProjectInfo εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| uid | Λαμβάνει το UID του έργου. |
| name | Λαμβάνει το όνομα του έργου. |
| short_name | Λαμβάνει το σύντομο όνομα του έργου (Project ID). |
| export_flag | Λαμβάνει τη σημαία εξαγωγής του έργου. Όταν ένα έργο επιλέγεται για εξαγωγή στο Primavera, η ExportFlag του είναι true.<br/>            Ορισμένα έργα που δεν έχουν επιλεγεί ρητά για εξαγωγή ενδέχεται να εξαχθούν σε αρχείο XER λόγω της σχέσης τους με το εξαγόμενο έργο. |
