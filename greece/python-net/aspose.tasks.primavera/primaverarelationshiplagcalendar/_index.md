## PrimaveraRelationshipLagCalendar enumeration

Καθορίζει ποιο ημερολόγιο θα χρησιμοποιηθεί για τον προγραμματισμό του καθυστέρησης σχέσης (Relationship Lag) σε έργα Primavera.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| PREDECESSOR | Χρησιμοποιήστε το ημερολόγιο δραστηριότητας του προγόνου |
| SUCCESSOR | Χρησιμοποιήστε το ημερολόγιο δραστηριότητας του απογόνου |
| CALENDAR_24_HOUR | Χρησιμοποιήστε το ημερολόγιο 24 ωρών |
| DEFAULT | Χρησιμοποιήστε το προεπιλεγμένο ημερολόγιο του έργου |
