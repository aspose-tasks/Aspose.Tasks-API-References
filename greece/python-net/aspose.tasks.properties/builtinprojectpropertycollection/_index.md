## BuiltInProjectPropertyCollection class

Αναπαριστά μια συλλογή ενσωματωμένων ιδιοτήτων έργου.

Ο τύπος BuiltInProjectPropertyCollection εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| title | Λαμβάνει ή ορίζει τον τίτλο ενός έργου. |
| subject | Λαμβάνει ή ορίζει το θέμα ενός έργου. |
| author | Λαμβάνει ή ορίζει τον συγγραφέα ενός έργου. |
| manager | Λαμβάνει ή ορίζει τον διαχειριστή ενός έργου. |
| company | Λαμβάνει ή ορίζει την εταιρεία ενός έργου. |
| category | Λαμβάνει ή ορίζει την κατηγορία ενός έργου. |
| keywords | Λαμβάνει ή ορίζει τις λέξεις-κλειδιά ενός έργου. |
| comments | Λαμβάνει ή ορίζει τα σχόλια ενός έργου. |
| hyperlink_base | Λαμβάνει ή ορίζει τη βάση υπερσυνδέσμου ενός έργου. |
| ονόματα |  |
