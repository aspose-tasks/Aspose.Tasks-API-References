## OutlineCodeDefinition class

Αναπαριστά έναν ορισμό κώδικα περιγράμματος.

Ο τύπος OutlineCodeDefinition εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| OutlineCodeDefinition() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| guid | Λαμβάνει ή ορίζει το Guid ενός κώδικα περιγράμματος. |
| field_id | Λαμβάνει ή ορίζει τον αριθμό πεδίου ενός κώδικα περιγράμματος. |
| field_name | Λαμβάνει ή ορίζει το όνομα ενός προσαρμοσμένου κώδικα περιγράμματος. |
| alias | Λαμβάνει ή ορίζει το ψευδώνυμο ενός προσαρμοσμένου κώδικα περιγράμματος. |
| phonetic_alias | Λαμβάνει ή ορίζει την φωνητική προφορά του ψευδώνυμου του προσαρμοσμένου κώδικα περιγράμματος. |
| values | Λαμβάνει το αντικείμενο OutlineValueCollection.<br/>            Οι τιμές του πίνακα που σχετίζονται με αυτόν τον κώδικα περιγράμματος. |
| enterprise | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν ένας προσαρμοσμένος κώδικας περιγράμματος είναι επιχειρηματικός προσαρμοσμένος κώδικας περιγράμματος. |
| enterprise_outline_code_alias | Λαμβάνει ή ορίζει μια αναφορά σε άλλο προσαρμοσμένο πεδίο για το οποίο αυτός ο ορισμός κώδικα περιγράμματος είναι ψευδώνυμο. |
| resource_substitution_enabled | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν ο προσαρμοσμένος κώδικας περιγράμματος μπορεί να χρησιμοποιηθεί<br/>            από τον Οδηγό Αντικατάστασης Πόρων στο Microsoft Project. |
| leaf_only | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι τιμές που καθορίζονται σε αυτό το πεδίο κώδικα περιγράμματος πρέπει να είναι φύλλα. |
| all_levels_required | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι νέοι κώδικες πρέπει να έχουν όλα τα επίπεδα.<br/>            Δεν είναι διαθέσιμο για Επιχειρηματικούς Κώδικες. |
| only_table_values_allowed | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι καθορισμένες τιμές πρέπει να προέρχονται από τον πίνακα τιμών. |
| masks | Λαμβάνει το αντικείμενο OutlineMaskCollection.<br/>            Ο πίνακας των καταχωρίσεων που ορίζουν τη μάσκα κώδικα περιγράμματος.<br/>            Μόνο για ανάγνωση [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/). |
| show_indent | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι εσοχές αυτού του κώδικα περιγράμματος πρέπει να εμφανίζονται. |
