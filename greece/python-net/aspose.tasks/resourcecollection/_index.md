## ResourceCollection class

Αντιπροσωπεύει μια συλλογή αντικειμένων [Resource](/tasks/python-net/aspose.tasks/resource/).

Ο τύπος ResourceCollection εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| parent_project | Αποκτά το γονικό έργο του αντικειμένου ResourceCollection. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| add() | Προσθέτει νέο πόρο στην τελευταία θέση της συλλογής πόρων ενός έργου. |
| add(resource_name) | Προσθέτει νέο πόρο στην τελευταία θέση της συλλογής πόρων ενός έργου. |
| add(resource_name, before_resource_id) |  |
| to_list() | Μετατρέπει το αντικείμενο ResourceCollection σε μια λίστα από αντικείμενα τύπου [Resource](/tasks/python-net/aspose.tasks/resource/). |
| get_by_id(id) | Επιστρέφει έναν πόρο με το καθορισμένο αναγνωριστικό. |
| get_by_uid(uid) | Επιστρέφει έναν πόρο με το καθορισμένο Uid. |
