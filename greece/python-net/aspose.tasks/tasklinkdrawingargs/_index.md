## TaskLinkDrawingArgs class

Παρέχει επιχειρήματα για την κλήση επιστροφής που καλείται όταν αποδίδεται ο σύνδεσμος εργασίας.

Ο τύπος TaskLinkDrawingArgs εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| link | Λαμβάνει το αποδομένο σύνδεσμο εργασίας. |
| color | Λαμβάνει ή ορίζει το χρώμα που χρησιμοποιείται για την απόδοση του συνδέσμου εργασίας. Μπορεί να χρησιμοποιηθεί για την προσαρμογή των χρωμάτων των συνδέσμων εργασίας. |
