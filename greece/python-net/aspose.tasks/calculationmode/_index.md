## CalculationMode enumeration

Καθορίζει τη λειτουργία υπολογισμού του έργου.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NONE | Κανένα. Οι ημερομηνίες και τα κόστη του έργου δεν επαναϋπολογίζονται σε αυτή τη λειτουργία. |
| AUTOMATIC | Αυτόματη λειτουργία. Οι ημερομηνίες και τα κόστη του έργου επαναϋπολογίζονται όταν χρησιμοποιείται αυτή η λειτουργία. |
| MANUAL | Χειροκίνητη λειτουργία. Μόνο τα απαραίτητα πεδία επαναϋπολογίζονται σε αυτή τη λειτουργία, για παράδειγμα τα UID και τα ID των αντικειμένων. |
