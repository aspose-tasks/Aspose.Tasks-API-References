## ResourceSavingArgs class

Αυτή η κλάση αντιπροσωπεύει ένα σύνολο δεδομένων που σχετίζονται με την αποθήκευση εξωτερικού αρχείου πόρου που<br/>              συμβαίνει κατά τη μετατροπή σε μορφή HTML.

Ο τύπος ResourceSavingArgs εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| ResourceSavingArgs() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης ResourceSavingArgs |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| file_name | Λαμβάνει ή ορίζει το υποτιθέμενο όνομα αρχείου που περνά από τον μετατροπέα στον κώδικα της προσαρμοσμένης μεθόδου.<br/>             Μπορεί να χρησιμοποιηθεί σε προσαρμοσμένο κώδικα για να αποφασίσει πώς να επεξεργαστεί ή πού να αποθηκεύσει το αρχείο. |
| keep_stream_open | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η ροή θα παραμείνει ανοιχτή μετά το τέλος της αποθήκευσης του πόρου. |
| stream | Λαμβάνει ή ορίζει το δυαδικό περιεχόμενο του αποθηκευμένου αρχείου. |
| uri | Λαμβάνει ή ορίζει το URI του πόρου. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| close_stream_if_required() | Κλείνει τη ροή εάν το KeepStreamOpen είναι ψευδές, αλλιώς την αδειάζει. |
