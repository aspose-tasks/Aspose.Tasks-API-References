## FontSettings class

Καθορίζει τις ρυθμίσεις γραμματοσειράς που χρησιμοποιούνται κατά την απόδοση της προβολής του έργου.

Ο τύπος FontSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| FontSettings() | Αρχικοποιεί μια νέα παρουσία της κλάσης FontSettings |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| default_font_name | Λαμβάνει ή ορίζει την προεπιλεγμένη (ή εφεδρική) γραμματοσειρά για την απόδοση. |
| use_project_default_font | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η προεπιλεγμένη γραμματοσειρά πρέπει να χρησιμοποιείται για την απόδοση. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| set_font_folders(font_folders, recursive) | Ορίζει τους φακέλους όπου το Aspose.Tasks αναζητά γραμματοσειρές TrueType κατά την απόδοση της προβολής του έργου. |
