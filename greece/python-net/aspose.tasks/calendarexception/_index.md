## CalendarException class

Αναπαριστά εξαιρετικές χρονικές περιόδους σε ένα ημερολόγιο.

Ο τύπος CalendarException εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| CalendarException() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [CalendarException](/tasks/python-net/aspose.tasks/calendarexception/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| entered_by_occurrences | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η περιοχή επανάληψης ορίζεται με την εισαγωγή αριθμού εμφανίσεων.<br/>            Η τιμή False υποδεικνύει ότι η περιοχή επανάληψης ορίζεται με την εισαγωγή ημερομηνίας λήξης. |
| from_date | Λαμβάνει ή ορίζει την έναρξη του χρόνου εξαίρεσης. |
| to_date | Λαμβάνει ή ορίζει το τέλος του χρόνου εξαίρεσης. |
| occurrences | Λαμβάνει ή ορίζει τον αριθμό των εμφανίσεων για τις οποίες η εξαίρεση ημερολογίου είναι έγκυρη. |
| name | Λαμβάνει ή ορίζει το όνομα της εξαίρεσης. |
| τύπος | Λαμβάνει ή ορίζει τον τύπο της εξαίρεσης. |
| period | Λαμβάνει ή ορίζει την περίοδο επανάληψης για την εξαίρεση. |
| days_of_week | Λαμβάνει το DayTypeCollection για αυτό το αντικείμενο.<br/>            Οι ημέρες της εβδομάδας στις οποίες η εξαίρεση είναι έγκυρη. |
| month_item | Λαμβάνει ή ορίζει το στοιχείο μήνα για το οποίο προγραμματίζεται η επανάληψη της εξαίρεσης. |
| month_position | Λαμβάνει ή ορίζει τη θέση ενός στοιχείου μήνα μέσα σε έναν μήνα. |
| month | Λαμβάνει ή ορίζει τον μήνα για τον οποίο προγραμματίζεται η επανάληψη της εξαίρεσης. |
| month_day | Λαμβάνει ή ορίζει την ημέρα ενός μήνα στην οποία προγραμματίζεται η επανάληψη της εξαίρεσης. |
| day_working | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η καθορισμένη ημερομηνία ή ο τύπος ημέρας είναι εργάσιμη. |
| working_times | Λαμβάνει ή ορίζει το αντικείμενο WorkingTimeCollection.<br/>            Η συλλογή των ωρών εργασίας που ορίζει τον χρόνο εργασίας κατά τη διάρκεια της καθημερινής ημέρας. |
| parent_calendar | Λαμβάνει το γονικό ημερολόγιο για αυτό το αντικείμενο. |
## Methods

| get_exception_dates() | Επιστρέφει τις ημερομηνίες στις οποίες η εξαίρεση ημερολογίου ισχύει. |
