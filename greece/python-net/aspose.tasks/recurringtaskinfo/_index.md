## RecurringTaskInfo class

Αντιπροσωπεύει τις λεπτομέρειες μιας επαναλαμβανόμενης εργασίας σε ένα έργο.

Ο τύπος RecurringTaskInfo εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| recurrence_pattern | Λαμβάνει ή ορίζει ένα μοτίβο επανάληψης της επαναλαμβανόμενης εργασίας. |
| start_date | Λαμβάνει ή ορίζει την ημερομηνία έναρξης των εμφανίσεων. |
| end_date | Λαμβάνει ή ορίζει την ημερομηνία λήξης των εμφανίσεων. |
| duration | Λαμβάνει ή ορίζει τη διάρκεια μιας εμφάνισης της επαναλαμβανόμενης εργασίας. |
| occurrences | Λαμβάνει ή ορίζει έναν αριθμό εμφανίσεων της επαναλαμβανόμενης εργασίας. |
| use_end_date | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα χρησιμοποιηθεί η ημερομηνία λήξης ή ένας αριθμός εμφανίσεων για την επαναλαμβανόμενη εργασία. |
| daily_repetitions | Λαμβάνει ή ορίζει έναν αριθμό επαναλήψεων για το ημερήσιο μοτίβο επανάληψης. |
| daily_use_workdays | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα χρησιμοποιηθούν εργάσιμες ημέρες για το καθημερινό πρότυπο επανάληψης. |
| weekly_repetitions | Λαμβάνει ή ορίζει έναν αριθμό επαναλήψεων για το εβδομαδιαίο πρότυπο επανάληψης. |
| weekly_days | Λαμβάνει ή ορίζει μια συλλογή ημερών που χρησιμοποιούνται στο εβδομαδιαίο πρότυπο επανάληψης. |
| monthly_use_ordinal_day | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα χρησιμοποιηθεί η αριθμητική ημέρα για το μηνιαίο πρότυπο επανάληψης. |
| monthly_ordinal_number | Λαμβάνει ή ορίζει έναν αριθμητικό αριθμό του μηνιαίου προτύπου επανάληψης. |
| monthly_ordinal_repetitions | Λαμβάνει ή ορίζει έναν αριθμό επαναλήψεων για το μηνιαίο πρότυπο επανάληψης όταν χρησιμοποιείται η αριθμητική ημέρα. |
| monthly_day | Λαμβάνει ή ορίζει έναν αριθμό ημερών του μηνιαίου προτύπου επανάληψης. |
| monthly_repetitions | Λαμβάνει ή ορίζει έναν αριθμό επαναλήψεων για το μηνιαίο πρότυπο επανάληψης. |
| yearly_use_ordinal_day | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα χρησιμοποιηθεί η αριθμητική ημέρα για το ετήσιο πρότυπο επανάληψης. |
| yearly_date | Λαμβάνει ή ορίζει μια ημερομηνία για το ετήσιο πρότυπο επανάληψης. |
| yearly_ordinal_number | Λαμβάνει ή ορίζει έναν αριθμητικό αριθμό του ετήσιου προτύπου επανάληψης. |
| yearly_ordinal_month | Λαμβάνει ή ορίζει ένα μήνα του ετήσιου προτύπου επανάληψης όταν χρησιμοποιείται η αριθμητική ημέρα. |
| task | Λαμβάνει την γονική εργασία αυτής της παρουσίας της κλάσης [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
