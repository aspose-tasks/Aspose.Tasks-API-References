## Filter class

Αναπαριστά ένα φίλτρο στο Project.

Ο τύπος Filter εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Filter() | Αρχικοποιεί μια νέα παρουσία της κλάσης Filter |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| filter_type | Λαμβάνει τον τύπο του φίλτρου. |
| name | Λαμβάνει ή ορίζει το όνομα ενός αντικειμένου Filter. |
| show_in_menu | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το έργο εμφανίζει το όνομα του φίλτρου στη λίστα επιλογής Filter στην καρτέλα View της Ribbon. |
| show_related_summary_rows | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν εμφανίζονται σχετικές γραμμές σύνοψης για το φίλτρο. |
| index | Λαμβάνει το δείκτη ενός αντικειμένου [Filter](/tasks/python-net/aspose.tasks/filter/) στο αντικείμενο που περιέχει τα Filters. |
| uid | Λαμβάνει το μοναδικό αναγνωριστικό ενός φίλτρου. |
| criteria | Λαμβάνει ή ορίζει τα κριτήρια που πρέπει να πληρούν οι εργασίες ή οι πόροι για να εμφανιστούν στην προβολή MSP. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| compare_to(other) | Συγκρίνει αυτήν την παρουσία με την καθορισμένη παρουσία της κλάσης [Filter](/tasks/python-net/aspose.tasks/filter/) και επιστρέφει ένδειξη της σχετικής τους σειράς. |
| equals(other) | Επιστρέφει μια τιμή που υποδεικνύει εάν αυτή η παρουσία είναι ίση με το καθορισμένο αντικείμενο AssignmentBaseline. |
