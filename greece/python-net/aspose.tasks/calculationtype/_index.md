## CalculationType enumeration

Καθορίζει τον τύπο υπολογισμού της τιμής του προσαρμοσμένου χαρακτηριστικού.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NONE | Σημαίνει ότι το επεκτατικό χαρακτηριστικό δεν έχει πίνακα αναζήτησης τύπου και απλώς αποθηκεύει την τιμή που ορίζει ο χρήστης. |
| LOOKUP | Σημαίνει ότι η τιμή του επεκτατικού χαρακτηριστικού περιορίζεται σε τιμές από έναν πίνακα αναζήτησης. |
| FORMULA | Σημαίνει ότι η τιμή του επεκτατικού χαρακτηριστικού υπολογίζεται χρησιμοποιώντας τον τύπο που ορίζεται στο [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
