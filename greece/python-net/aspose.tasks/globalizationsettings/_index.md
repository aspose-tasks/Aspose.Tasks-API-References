## GlobalizationSettings class

Ο τύπος GlobalizationSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| GlobalizationSettings() | Αρχικοποιεί μια νέα παρουσία της κλάσης GlobalizationSettings |

| Όνομα | Περιγραφή |
