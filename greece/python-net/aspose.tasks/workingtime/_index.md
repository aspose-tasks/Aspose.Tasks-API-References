## WorkingTime class

Αντιπροσωπεύει έναν χρόνο εργασίας κατά τη διάρκεια μιας ημέρας της εβδομάδας.

Ο τύπος WorkingTime εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| WorkingTime(from_time, to_time) | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) με ένα διάστημα με τις καθορισμένες ώρες έναρξης και λήξης. |
| WorkingTime(from_time, to_time) | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) με ένα στοιχείο διαστήματος με τις καθορισμένες ώρες έναρξης και λήξης. |
| WorkingTime(from_hours, to_hours) | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης WorkingTime |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| from_address | Λαμβάνει την αρχή ενός χρόνου εργασίας. |
| to | Λαμβάνει το τέλος ενός χρόνου εργασίας. |
