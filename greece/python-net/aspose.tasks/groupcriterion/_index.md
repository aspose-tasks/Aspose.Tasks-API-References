## GroupCriterion class

Αντιπροσωπεύει ένα κριτήριο σε έναν ορισμό ομάδας.<br/>            Το αντικείμενο GroupCriterion είναι μέλος της συλλογής [GroupCriterionCollection](/tasks/python-net/aspose.tasks/groupcriterioncollection/).
