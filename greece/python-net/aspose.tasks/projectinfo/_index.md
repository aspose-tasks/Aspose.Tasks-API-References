## ProjectInfo class

Σύντομες πληροφορίες για το δημοσιευμένο έργο που είναι διαθέσιμο στο Project Online.

Ο τύπος ProjectInfo εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| ProjectInfo() | Αρχικοποιεί μια νέα παρουσία της [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/) κλάσης. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| id | Λαμβάνει το μοναδικό αναγνωριστικό του έργου. |
| name | Λαμβάνει το όνομα του έργου. |
| created_date | Λαμβάνει την ημερομηνία και ώρα δημιουργίας του έργου. |
| is_checked_out | Λαμβάνει μια τιμή που υποδεικνύει εάν το έργο είναι ελεγμένο. |
| last_published_date | Λαμβάνει την πιο πρόσφατη ημερομηνία δημοσίευσης του έργου. |
| last_saved_date | Λαμβάνει την πιο πρόσφατη ημερομηνία αποθήκευσης του έργου. |
| description | Λαμβάνει την περιγραφή του έργου. |
