## FontResolveEventArgs class

Παρέχει επιχειρήματα για την κλήση επιστροφής που καλείται όταν η γραμματοσειρά επιλύεται.

Ο τύπος FontResolveEventArgs εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| requested_font_name | Λαμβάνει το όνομα της ζητούμενης γραμματοσειράς. |
| resolved_font_name | Λαμβάνει ή ορίζει το όνομα της επιλυμένης γραμματοσειράς. Μπορεί να οριστεί για να ελέγχει τις γραμματοσειρές που χρησιμοποιούνται για την απόδοση μιας προβολής. |
