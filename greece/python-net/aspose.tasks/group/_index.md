## Group class

Αντιπροσωπεύει έναν ορισμό ομάδας.<br/>            Ένα αντικείμενο Group είναι μέλος της συλλογής ResourceGroups ή της συλλογής TaskGroups.

Ο τύπος Group εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Group() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [Group](/tasks/python-net/aspose.tasks/group/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| name | Λαμβάνει ή ορίζει το όνομα ενός αντικειμένου Group. |
| uid | Λαμβάνει ένα μοναδικό αναγνωριστικό μιας ομάδας. |
| show_summary | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν εμφανίζονται γραμμές σύνοψης για την ομάδα. |
| maintain_hierarchy | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται όλα τα επίπεδα εργασιών σύνοψης για τις υποεργασίες εντός της ομάδας. |
| show_in_menu | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το Project εμφανίζει το όνομα της ομάδας στη λίστα επιλογής Group στην κορδέλα. |
| group_assignments | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι εκχωρήσεις πρέπει να ομαδοποιούνται αντί για εργασίες. |
| group_criteria | Λαμβάνει ή ορίζει μια συλλογή GroupCriteria που αντιπροσωπεύει τα πεδία σε έναν ορισμό ομάδας. |
