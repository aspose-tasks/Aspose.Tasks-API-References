## OleObject class

Αναπαριστά ένα αντικείμενο OLE που μπορεί να εισαχθεί στην προβολή Gantt Chart ενός αρχείου MPP.

Ο τύπος OleObject εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| OleObject() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| name | Λαμβάνει ή ορίζει το όνομα του στιγμιότυπου του αντικειμένου OLE. |
| application_name | Λαμβάνει ή ορίζει το όνομα της εφαρμογής με την οποία θα ανοίξει το ενσωματωμένο αντικείμενο. |
| file_format | Λαμβάνει ή ορίζει τη μορφή αρχείου του ενσωματωμένου αντικειμένου. |
| content | Λαμβάνει ή ορίζει τα δεδομένα του ενσωματωμένου αρχείου· null εάν δεν έχουν ενσωματωθεί δεδομένα. |
| label | Λαμβάνει ή ορίζει την ετικέτα του εισαχθέντος αντικειμένου. |
| full_path | Λαμβάνει ή ορίζει τη πλήρη διαδρομή του εισαχθέντος αντικειμένου. |
| temporary_file | Λαμβάνει ή ορίζει τη διαδρομή του προσωρινού αρχείου του εισαχθέντος αντικειμένου. |
| display_as_icon | Λαμβάνει ή ορίζει μια σημαία που υποδεικνύει ότι το αντικείμενο OLE πρέπει να εμφανίζεται είτε ως εικονίδιο είτε ως κανονική εικόνα. |
| συνδεδεμένο | Λαμβάνει μια τιμή που υποδεικνύει εάν το αρχείο έργου περιέχει μόνο έναν σύνδεσμο προς τα πραγματικά δεδομένα που αποθηκεύονται στην πηγή του συνδέσμου. |
| view | Λαμβάνει ή ορίζει το στιγμιότυπο της κλάσης [view](/tasks/python-net/aspose.tasks/oleobject/) στην οποία ανήκει το εισαχθέν αντικείμενο. |
| id | Λαμβάνει ή ορίζει το αναγνωριστικό του αντικειμένου. |
