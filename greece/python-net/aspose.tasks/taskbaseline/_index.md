## TaskBaseline class

Αναπαριστά τη Βάση Αναφοράς μιας Εργασίας.

Ο τύπος TaskBaseline εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| TaskBaseline(task) | Αρχικοποιεί μια νέα παρουσία της κλάσης [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| baseline_number | Λαμβάνει ή ορίζει τον μοναδικό αριθμό μιας εγγραφής δεδομένων baseline. |
| work | Λαμβάνει ή ορίζει την εργασία που έχει ανατεθεί σε έναν πόρο όταν αποθηκεύεται το baseline. |
| cost | Λαμβάνει ή ορίζει το προβλεπόμενο κόστος ενός πόρου όταν αποθηκεύεται το baseline. |
| bcws | Λαμβάνει ή ορίζει το προϋπολογισμένο κόστος μιας εργασίας που έχει προγραμματιστεί για έναν πόρο. |
| bcwp | Λαμβάνει ή ορίζει το προϋπολογισμένο κόστος μιας εργασίας που εκτελείται από έναν πόρο για ένα έργο μέχρι σήμερα. |
| timephased_data | Λαμβάνει ή ορίζει μια παρουσία της TimephasedDataCollection για αυτό το αντικείμενο.<br/>            Τα δεδομένα χρονικής φάσης που σχετίζονται με τη βάση εργασίας. |
| interim | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν αυτή είναι μια Ενδιάμεση Βάση. |
| έναρξη | Λαμβάνει ή ορίζει την προγραμματισμένη ημερομηνία έναρξης της εργασίας όταν αποθηκεύτηκε η βάση. |
| finish | Λαμβάνει ή ορίζει την προγραμματισμένη ημερομηνία λήξης της εργασίας όταν αποθηκεύτηκε η βάση. |
| duration | Λαμβάνει ή ορίζει τη προγραμματισμένη διάρκεια της εργασίας όταν αποθηκεύτηκε η βάση. |
| estimated_duration | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η διάρκεια βάσης της εργασίας εκτιμήθηκε. |
| fixed_cost | Λαμβάνει ή ορίζει ένα σταθερό κόστος της εργασίας όταν η βάση αποθηκεύτηκε. |
