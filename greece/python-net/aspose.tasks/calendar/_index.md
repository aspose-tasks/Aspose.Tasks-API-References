## Calendar class

Αναπαριστά ένα ημερολόγιο που χρησιμοποιείται σε ένα έργο.

Ο τύπος Calendar εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| name | Λαμβάνει ή ορίζει το όνομα του ημερολογίου. |
| uid | Λαμβάνει ή ορίζει το μοναδικό αναγνωριστικό του ημερολογίου. |
| week_days | Λαμβάνει το WeekDaysCollection για αυτό το ημερολόγιο.<br/>            Η συλλογή των ημερών της εβδομάδας που ορίζει το ημερολόγιο. |
| exceptions | Λαμβάνει το αντικείμενο CalendarExceptionCollection.<br/>            Η συλλογή των εξαιρέσεων που σχετίζονται με το ημερολόγιο. |
| work_weeks | Λαμβάνει το αντικείμενο WorkWeekCollections.<br/>            Η συλλογή των εβδομάδων εργασίας που σχετίζονται με το ημερολόγιο. |
| is_base_calendar | Λαμβάνει μια τιμή που υποδεικνύει εάν το ημερολόγιο είναι βασικό ημερολόγιο. |
| base_calendar | Λαμβάνει ή ορίζει το βασικό ημερολόγιο από το οποίο εξαρτάται αυτό το ημερολόγιο.<br/>            Ισχύει μόνο εάν το ημερολόγιο δεν είναι βασικό ημερολόγιο. |
| is_baseline_calendar | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το ημερολόγιο είναι ημερολόγιο βάσης. |
| guid | Λαμβάνει το Guid του ημερολογίου. |
| primavera_properties | Λαμβάνει ένα αντικείμενο που περιέχει ιδιότητες ειδικές για Primavera για ένα ημερολόγιο που διαβάστηκε από μορφές Primavera. |
