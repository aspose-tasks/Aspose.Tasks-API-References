## PrimaveraXmlReader class

Αναπαριστά έναν αναγνώστη που επιτρέπει την ανάκτηση των UID έργων από αρχείο Primavera Xml.

Ο τύπος PrimaveraXmlReader εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PrimaveraXmlReader(template_path) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [PrimaveraXmlReader](/tasks/python-net/aspose.tasks/primaveraxmlreader/). |
| PrimaveraXmlReader(stream) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [PrimaveraXmlReader](/tasks/python-net/aspose.tasks/primaveraxmlreader/). |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| get_project_uids() | Επιστρέφει μια λίστα με τα μοναδικά αναγνωριστικά των έργων. |
| get_project_infos() | Επιστρέφει μια λίστα με τα σύντομα αντικείμενα πληροφοριών του έργου. |
| load_project(project_uid) | Φορτώνει το έργο με το καθορισμένο μοναδικό αναγνωριστικό. |
