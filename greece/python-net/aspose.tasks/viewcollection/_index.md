## ViewCollection class

Περιέχει μια λίστα αντικειμένων [View](/tasks/python-net/aspose.tasks/view/).<br/>            Υλοποιεί τη διεπαφή ICollection<View>.

Ο τύπος ViewCollection εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| parent_project | Λαμβάνει το γονικό στοιχείο του αντικειμένου View.<br/>            Μόνο για ανάγνωση [Project](/tasks/python-net/aspose.tasks/project/). |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| to_list() | Μετατρέπει μια συλλογή προβολών σε λίστα αντικειμένων [View](/tasks/python-net/aspose.tasks/view/). |
| get_by_view_screen(screen) | Αναζητά μια View με την καθορισμένη ιδιότητα Screen και επιστρέφει την πρώτη εμφάνιση μέσα στη συλλογή. |
| get_by_name(view_name) | Αναζητά μια View με το όνομα και επιστρέφει την πρώτη εμφάνιση μέσα στη συλλογή. |
