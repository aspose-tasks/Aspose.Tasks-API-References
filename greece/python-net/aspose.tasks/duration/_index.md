## Duration class

Αναπαριστά τη διάρκεια σε ένα έργο.

Ο τύπος Duration εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Duration() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης Duration |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| time_span | Λαμβάνει το [time_span](/tasks/python-net/aspose.tasks/duration/) παράδειγμα αυτού του αντικειμένου Duration. |
| time_unit | Λαμβάνει τον τύπο μονάδας χρόνου για αυτό το αντικείμενο. |
| is_estimated | Λαμβάνει μια τιμή που υποδεικνύει εάν η μονάδα χρόνου είναι εκτιμημένη. |
| is_elapsed | Λαμβάνει μια τιμή που υποδεικνύει εάν η μονάδα χρόνου έχει παρέλθει. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| add(d) | Προσθέτει τη συγκεκριμένη διάρκεια σε αυτή τη διάρκεια. |
| add(val) | Προσθέτει τη συγκεκριμένη διπλή τιμή σε αυτή τη διάρκεια. |
| subtract(d) | Αφαιρεί τη συγκεκριμένη διάρκεια από αυτή την περίπτωση διάρκειας. |
| subtract(val) | Αφαιρεί τη συγκεκριμένη διπλή τιμή από αυτή την περίπτωση διάρκειας. |
| parse(p, value) | Μετατρέπει τη συγκεκριμένη συμβολοσειρά στην περίπτωση του struct [Duration](/tasks/python-net/aspose.tasks/duration/). |
| parse_time_span(value) | Αναλύει τη συμβολοσειρά διάρκειας στη μορφή "PT--H--M--S--". |
| to_double() | Μετατρέπει το αντικείμενο Duration σε τιμή float. |
| convert(time_unit_type) | Μετατρέπει το αντικείμενο Duration σε άλλη διάρκεια με τις καθορισμένες μονάδες χρόνου. |
| equals(other) | Επιστρέφει μια τιμή που υποδεικνύει εάν αυτή η παρουσία είναι ίση με ένα καθορισμένο αντικείμενο. |
