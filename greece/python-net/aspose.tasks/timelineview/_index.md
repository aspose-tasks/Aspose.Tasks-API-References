## TimelineView class

Αναπαριστά μια προβολή χρονοδιαγράμματος ενός έργου.

Ο τύπος TimelineView εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| TimelineView() | Αρχικοποιεί μια νέα παρουσία της κλάσης [TimelineView](/tasks/python-net/aspose.tasks/timelineview/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| filter | Λαμβάνει ή ορίζει ένα φίλτρο που χρησιμοποιείται σε μια μοναδική προβολή. |
| group | Λαμβάνει ή ορίζει μια ομάδα της μονής προβολής. |
| uid | Λαμβάνει το μοναδικό αναγνωριστικό μιας προβολής. |
| highlight_filter | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το Microsoft Project επισημαίνει το φίλτρο για μια μονή προβολή. |
| name | Λαμβάνει ή ορίζει το όνομα ενός αντικειμένου View. |
| screen | Λαμβάνει τον τύπο οθόνης για τη μονή προβολή.<br/>            Μόνο για ανάγνωση [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Λαμβάνει το γονικό στοιχείο του αντικειμένου View.<br/>            Μόνο για ανάγνωση [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Λαμβάνει ή ορίζει έναν πίνακα της μονής προβολής. |
| type | Λαμβάνει τον τύπο στοιχείου στη μονή προβολή, όπως εργασίες ή πόρους.<br/>            Μόνο για ανάγνωση [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το Microsoft Project εμφανίζει το όνομα της μονής προβολής στη λίστα View ή Other Views στο Ribbon. |
| page_info | Λαμβάνει μια παρουσία της κλάσης [page_info](/tasks/python-net/aspose.tasks/view/). Αντιπροσωπεύει τα δεδομένα ρύθμισης σελίδας που υπάρχουν σε μορφή αρχείου mpp. |
| visual_objects_placements | Λαμβάνει μια συλλογή αντικειμένων που αντιπροσωπεύουν τη θέση και την εμφάνιση του [OleObject](/tasks/python-net/aspose.tasks/oleobject/) στην προβολή. |
| date_format | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει πώς να μορφοποιηθούν οι ημερομηνίες στην προβολή Timeline. |
| display_overlapped | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται επικαλυπτόμενες εργασίες σε πολλαπλές γραμμές. |
| show_dates | Λαμβάνει μια τιμή που υποδεικνύει εάν θα εμφανίζονται ημερομηνίες. |
| show_pan_zoom | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζεται ο έλεγχος μετακίνησης και ζουμ. |
| show_timescale | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζεται η κλίμακα χρόνου. |
| show_today | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανιστεί μια γραμμή που αντιπροσωπεύει τη σημερινή ημέρα. |
| text_lines_count | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει πόσες γραμμές χρησιμοποιούνται για την εμφάνιση της εργασίας σε χρονοδιάγραμμα. |
