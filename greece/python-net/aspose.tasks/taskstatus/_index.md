## TaskStatus enumeration

Καθορίζει την κατάσταση μιας εργασίας.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| UNDEFINED | Απροσδιόριστη κατάσταση εργασίας. |
| COMPLETE | Η εργασία είναι ολοκληρωμένη κατά 100 τοις εκατό. |
| ON_SCHEDULE | Η εργασία είναι εντός προγράμματος εάν το χρονομερισμένο συνολικό ποσοστό ολοκλήρωσης είναι διανεμημένο τουλάχιστον μέχρι την ημέρα πριν από την ημερομηνία κατάστασης. |
| LATE | Η εργασία είναι καθυστερημένη εάν το χρονομερισμένο συνολικό ποσοστό ολοκλήρωσης δεν φτάσει τα μεσάνυχτα την ημέρα πριν από την ημερομηνία κατάστασης. |
| FUTURE | 'Future' κατάσταση εργασίας ορίζεται όταν η ημερομηνία έναρξης της εργασίας είναι μεγαλύτερη από την ημερομηνία κατάστασης. |
