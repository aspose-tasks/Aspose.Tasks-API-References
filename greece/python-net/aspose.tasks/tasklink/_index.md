## TaskLink class

Αναπαριστά έναν σύνδεσμο προκάτοχου.

Ο τύπος TaskLink εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_cross_project | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν ένας προκάτοχος αποτελεί μέρος άλλου έργου. |
| cross_project_name | Λαμβάνει ή ορίζει το εξωτερικό έργο προκάτοχου. |
| link_lag | Λαμβάνει ή ορίζει την καθυστέρηση σε δεκάδες του λεπτού ή ποσοστό. |
| link_lag_time_span | Λαμβάνει ή ορίζει τη διάρκεια της καθυστέρησης, ανάλογα με το LagFormat. |
| lag_format | Λαμβάνει ή ορίζει τη μορφή για την έκφραση της μορφής καθυστέρησης. |
| pred_task | Λαμβάνει ή ορίζει το έργο προκάτοχο. |
| succ_task | Λαμβάνει ή ορίζει το έργο διάδοχο. |
| link_type | Λαμβάνει ή ορίζει τον τύπο ενός συνδέσμου. |
