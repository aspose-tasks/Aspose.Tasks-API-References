## AssignmentBaseline class

Αναπαριστά τη Βάση μιας ανάθεσης πόρου.

Ο τύπος AssignmentBaseline εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| AssignmentBaseline() | Αρχικοποιεί μια νέα παρουσία της κλάσης AssignmentBaseline |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| baseline_number | Λαμβάνει ή ορίζει τον μοναδικό αριθμό μιας εγγραφής δεδομένων baseline. |
| work | Λαμβάνει ή ορίζει την εργασία που έχει ανατεθεί σε έναν πόρο όταν αποθηκεύεται το baseline. |
| cost | Λαμβάνει ή ορίζει το προβλεπόμενο κόστος ενός πόρου όταν αποθηκεύεται το baseline. |
| bcws | Λαμβάνει ή ορίζει το προϋπολογισμένο κόστος μιας εργασίας που έχει προγραμματιστεί για έναν πόρο. |
| bcwp | Λαμβάνει ή ορίζει το προϋπολογισμένο κόστος μιας εργασίας που εκτελείται από έναν πόρο για ένα έργο μέχρι σήμερα. |
| timephased_data | Λαμβάνει ή ορίζει την [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) παρουσία για αυτό το αντικείμενο.<br/>            Τα δεδομένα χρονικής φάσης που σχετίζονται με το baseline ανάθεσης πόρου. |
| έναρξη | Λαμβάνει ή ορίζει την προγραμματισμένη ημερομηνία έναρξης της ανάθεσης πόρου όταν αποθηκεύτηκε το baseline. |
| finish | Λαμβάνει ή ορίζει την προγραμματισμένη ημερομηνία λήξης της ανάθεσης πόρου όταν αποθηκεύτηκε το baseline. |
