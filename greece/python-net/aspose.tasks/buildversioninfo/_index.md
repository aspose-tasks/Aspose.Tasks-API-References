## BuildVersionInfo class

Περιέχει την έκδοση κατασκευής και τις πληροφορίες προϊόντος.

Ο τύπος BuildVersionInfo εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| ASSEMBLY_VERSION | Έκδοση συναρμολόγησης. |
| ASSEMBLY_INFORMATIONAL_VERSION | Ο αριθμός ενημερωτικής έκδοσης της συναρμολόγησης. |
| FILE_VERSION | Έκδοση αρχείου. |
| ΠΡΟΪΟΝ | Όνομα προϊόντος. |
