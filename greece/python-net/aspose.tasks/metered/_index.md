## Metered class

Παρέχει μεθόδους για τον ορισμό κλειδιού μέτρησης.

Ο τύπος Metered εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Metered() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης Metered |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| set_metered_key(public_key, private_key) | Ορίζει τα δημόσια και ιδιωτικά κλειδιά μετρημένου τύπου. |
| reset_metered_key() | Αφαιρεί την προηγουμένως ρυθμισμένη άδεια. |
| get_consumption_credit() | Λαμβάνει το πιστωτικό καταναλωσης. |
| get_consumption_quantity() | Λαμβάνει το μέγεθος αρχείου κατανάλωσης. |
| is_licensed() | Ελέγχει εάν το προϊόν είναι επιτυχώς αδειοδοτημένο χρησιμοποιώντας άδεια Metered. |
