## AvailabilityPeriod class

Αναπαριστά μια περίοδο όταν ένας πόρος είναι διαθέσιμος.

Ο τύπος AvailabilityPeriod εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| AvailabilityPeriod() | Αρχικοποιεί μια νέα παρουσία του [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | Αρχικοποιεί μια νέα παρουσία του [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) με το καθορισμένο εύρος ημερομηνιών και τις διαθέσιμες μονάδες. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| available_from | Λαμβάνει ή ορίζει την ημερομηνία κατά την οποία ένας πόρος γίνεται διαθέσιμος για την καθορισμένη περίοδο. |
| available_to | Λαμβάνει ή ορίζει την τελευταία ημερομηνία κατά την οποία ένας πόρος είναι διαθέσιμος για την καθορισμένη περίοδο. |
| available_units | Λαμβάνει ή ορίζει το ποσοστό ενός πόρου που είναι διαθέσιμο κατά τη διάρκεια της καθορισμένης περιόδου. |
