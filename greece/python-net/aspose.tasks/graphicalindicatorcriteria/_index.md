## GraphicalIndicatorCriteria class

Αντιπροσωπεύει ένα κριτήριο γραφικού δείκτη που σχετίζεται με μια εκτεταμένη ιδιότητα.

Ο τύπος GraphicalIndicatorCriteria εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Αρχικοποιεί μια νέα παρουσία της κλάσης GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Αρχικοποιεί μια νέα παρουσία της κλάσης GraphicalIndicatorCriteria |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| test | Λαμβάνει τον τύπο σύγκρισης που γίνεται μεταξύ της τιμής του εκτεταμένου χαρακτηριστικού και των Τιμών που λειτουργούν ως κριτήριο για την εφαρμογή του γραφικού δείκτη.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Λαμβάνει την τιμή που χρησιμοποιείται για τη δοκιμή της τιμής του εκτεταμένου χαρακτηριστικού. |
| value2 | Λαμβάνει τη δεύτερη τιμή που χρησιμοποιείται για τη δοκιμή της τιμής του εκτεταμένου χαρακτηριστικού σε περίπτωση τύπων σύγκρισης 'IsWithin' και 'IsNotWithin'. |
| image_index | Λαμβάνει το δείκτη της εικόνας που θα εμφανιστεί όταν το πεδίο πληροί τα κριτήρια. |
| row_type | Λαμβάνει την τιμή του enum [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) που υποδεικνύει για ποιες γραμμές εφαρμόζεται ο δείκτης. |
