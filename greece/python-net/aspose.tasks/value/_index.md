## Value class

Αναπαριστά μια τιμή σε μια λίστα τιμών.

Ο τύπος Value εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Value() | Αρχικοποιεί μια νέα παρουσία της κλάσης [Value](/tasks/python-net/aspose.tasks/value/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| id | Λαμβάνει ή ορίζει το μοναδικό αναγνωριστικό μιας τιμής σε όλο το έργο. |
| value_guid | Λαμβάνει ένα GUID που αναγνωρίζει αυτήν την τιμή μεταξύ των άλλων σε ολόκληρο το έργο. |
| val | Λαμβάνει ή ορίζει την πραγματική τιμή στην εσωτερική αναπαράσταση. Προτιμήστε τη χρήση ισχυρά τυποποιημένων ιδιοτήτων που παρατίθενται παρακάτω. |
| string_value | Λαμβάνει ή ορίζει την πραγματική τιμή που χρησιμοποιείται για την αναπαράσταση κειμένου. |
| numeric_value | Λαμβάνει ή ορίζει την πραγματική τιμή που χρησιμοποιείται για την αναπαράσταση αριθμού ή τιμής κόστους. |
| duration | Λαμβάνει ή ορίζει την πραγματική τιμή που χρησιμοποιείται για την αναπαράσταση Διάρκειας. |
| date_time_value | Λαμβάνει ή ορίζει την πραγματική τιμή εάν μπορεί να αναπαρασταθεί ως DateTime. Η προεπιλεγμένη τιμή είναι η ελάχιστη τιμή ημερομηνίας. |
| description | Λαμβάνει ή ορίζει την περιγραφή μιας τιμής. |
| phonetic | Λαμβάνει ή ορίζει τις φωνητικές πληροφορίες σχετικά με το όνομα προσαρμοσμένου πεδίου. |
