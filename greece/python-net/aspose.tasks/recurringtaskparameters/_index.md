## RecurringTaskParameters class

Αντιπροσωπεύει το σύνολο των παραμέτρων που χρησιμοποιούνται για τη δημιουργία μιας επαναλαμβανόμενης εργασίας σε ένα έργο.

Ο τύπος RecurringTaskParameters εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| RecurringTaskParameters() | Αρχικοποιεί μια νέα παρουσία της κλάσης [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| duration | Λαμβάνει ή ορίζει τη διάρκεια μιας εμφάνισης της επαναλαμβανόμενης εργασίας. |
| ignore_resource_calendar | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα προγραμματιστεί η επαναλαμβανόμενη εργασία ακόμη και αν δεν μπορεί να εκτελεστεί όταν δεν υπάρχουν διαθέσιμοι πόροι για την εκτέλεσή της. |
| recurrence_pattern | Λαμβάνει ή ορίζει το πρότυπο επανάληψης της επαναλαμβανόμενης εργασίας. |
| task_name | Λαμβάνει ή ορίζει το όνομα της επαναλαμβανόμενης εργασίας. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| set_calendar(project, calendar_name) | Ορίζει ένα ημερολόγιο για την επαναλαμβανόμενη εργασία. Το ημερολόγιο επιλέγεται από τη συλλογή ημερολογίων του έργου. |
