## ICalendar class

Αντιπροσωπεύει μια αφηρημένη έννοια ημερολογίου που μπορεί να χρησιμοποιηθεί για διάφορους υπολογισμούς ημερομηνιών και διάρκειων.

Ο τύπος ICalendar εκθέτει τα ακόλουθα μέλη:
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| get_start_date_from_finish_and_duration(finish, duration) | Επιστρέφει την ημερομηνία έναρξης βάσει της καθορισμένης ημερομηνίας λήξης και διάρκειας. |
| get_start_date_from_finish_and_duration(finish, duration) | Επιστρέφει την ημερομηνία έναρξης βάσει της καθορισμένης ημερομηνίας λήξης και διάρκειας. |
| get_working_hours(start, finish) | Επιστρέφει το WorkUnit - Έναρξη, Λήξη και Διάρκεια των ωρών εργασίας για το καθορισμένο χρονικό διάστημα. |
| get_working_hours(dt) | Επιστρέφει το WorkUnit - Έναρξη, Λήξη και Διάρκεια των ωρών εργασίας για το καθορισμένο χρονικό διάστημα. |
| get_finish_date_by_start_and_work(start, work) | Υπολογίζει την ημερομηνία όταν το καθορισμένο ποσό χρόνου εργασίας θα περάσει σύμφωνα με το ημερολόγιο. |
| get_finish_date_by_start_and_work(start, work) | Υπολογίζει την ημερομηνία όταν το καθορισμένο ποσό χρόνου εργασίας θα περάσει σύμφωνα με το ημερολόγιο. |
| is_day_working(dt) | Καθορίζει αν η καθορισμένη ημέρα είναι εργάσιμη ημέρα σύμφωνα με το ημερολόγιο. |
| get_working_hours_time_span(start, finish) | Επιστρέφει το ποσό των εργάσιμων ωρών μεταξύ των καθορισμένων ημερομηνιών. |
| get_task_finish_date_from_duration(task, duration) | Υπολογίζει την ημερομηνία και ώρα λήξης της εργασίας από την ημερομηνία έναρξής της, τα διαχωρισμένα μέρη και τη διάρκεια εργασίας. |
| get_working_times(dt) | Επιστρέφει [WorkingTimeCollection](/tasks/python-net/aspose.tasks/workingtimecollection/) των ωρών εργασίας για την καθορισμένη ημερομηνία. |
| get_previous_working_day_end(date) | Υπολογίζει το τέλος της προηγούμενης εργάσιμης ημερομηνίας από την καθορισμένη ημερομηνία. |
| get_next_working_day_start(date) | Υπολογίζει την έναρξη της επόμενης εργάσιμης ημέρας για την καθορισμένη ημερομηνία. |
| get_work_start(date) | Υπολογίζει την έναρξη του επόμενου εργάσιμου χρόνου ξεκινώντας από την καθορισμένη ημερομηνία και ώρα. |
| is_empty() | Επιστρέφει αν το ημερολόγιο δεν έχει ορισμένες εργάσιμες ώρες. |
