## VbaModule class

Αναπαριστά μια μονάδα VBA.

Ο τύπος VbaModule εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| attributes | Λαμβάνει μια συλλογή των attributes του module. |
| name | Λαμβάνει ένα όνομα του VBA module |
| τύπος | Λαμβάνει τον τύπο του module. |
| source_code | Λαμβάνει ή ορίζει έναν κώδικα πηγής του VBA module |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| create_procedural_module(name) | Δημιουργεί μια παρουσία του [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) με τύπο VbaModuleType.ProceduralModule. |
| create_class_module(name) | Δημιουργεί μια παρουσία του [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) με τύπο VbaModuleType.ClassModule. |
