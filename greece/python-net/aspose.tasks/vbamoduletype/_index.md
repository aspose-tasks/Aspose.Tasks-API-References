## VbaModuleType enumeration

Καθορίζει τον τύπο μιας μονάδας σε έργο VBA.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| DOCUMENT_MODULE | Ένας τύπος αντικειμένου έργου VBA που καθορίζει ένα μοντέλο για ενσωματωμένες μακροεντολές και λειτουργίες προγραμματιστικής πρόσβασης που σχετίζονται με ένα έγγραφο. |
| PROCEDURAL_MODULE | Μια μονάδα που περιέχει συλλογή υπορουτινών και συναρτήσεων. |
| CLASS_MODULE | Μια μονάδα που περιέχει τον ορισμό για ένα νέο αντικείμενο. Κάθε παρουσία μιας κλάσης δημιουργεί ένα νέο αντικείμενο, και οι διαδικασίες που ορίζονται στη μονάδα γίνονται ιδιότητες και μέθοδοι του αντικειμένου. |
| DESIGNER_MODULE | Μια μονάδα που επεκτείνει τις μεθόδους και τις ιδιότητες ενός ελέγχου ActiveX που έχει καταχωρηθεί στο έργο. |
