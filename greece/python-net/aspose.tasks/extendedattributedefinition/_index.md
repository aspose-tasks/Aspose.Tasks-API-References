## ExtendedAttributeDefinition class

Αναπαριστά έναν ορισμό εκτεταμένου χαρακτηριστικού που σχετίζεται με ένα έργο.

Ο τύπος ExtendedAttributeDefinition εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| field_id | Λαμβάνει ή ορίζει το πεδίο που αντιστοιχεί στο αναγνωριστικό έργου ενός προσαρμοσμένου πεδίου.<br/>            Χρησιμοποιήστε τη συμβολοσειρά αναπαράστασης μιας σταθεράς από την κλάση [ExtendedAttributeTask](/tasks/python-net/aspose.tasks/extendedattributetask/) για να καθορίσετε την ιδιότητα [field_id](/tasks/python-net/aspose.tasks/extendedattributedefinition/) . |
| field_name | Λαμβάνει το όνομα ενός προσαρμοσμένου πεδίου. |
| cf_type | Λαμβάνει τον τύπο ενός προσαρμοσμένου πεδίου. |
| guid | Λαμβάνει ή ορίζει το Guid ενός προσαρμοσμένου πεδίου. |
| element_type | Λαμβάνει ή ορίζει το εκτεταμένο χαρακτηριστικό που συσχετίζεται<br/>            με μια εργασία, έναν πόρο ή μια ανάθεση. |
| max_multi_values | Λαμβάνει ή ορίζει τον μέγιστο αριθμό τιμών που μπορείτε να ορίσετε σε μια λίστα επιλογής. |
| user_def | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν ένα προσαρμοσμένο πεδίο ορίζεται από τον χρήστη. |
| alias | Λαμβάνει ή ορίζει το ψευδώνυμο ενός προσαρμοσμένου πεδίου. |
| secondary_pid | Λαμβάνει ή ορίζει το δευτερεύον PID ενός προσαρμοσμένου πεδίου. |
| auto_roll_down | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν είναι ενεργοποιημένη η αυτόματη μεταφορά σε εκχωρήσεις. |
| default_guid | Λαμβάνει ή ορίζει το Guid της προεπιλεγμένης εγγραφής πίνακα αναζήτησης. |
| lookup_uid | Λαμβάνει ένα Guid του πίνακα αναζήτησης που σχετίζεται με ένα προσαρμοσμένο πεδίο. |
| phonetics_alias | Λαμβάνει ή ορίζει τη φωνητική προφορά του ψευδώνυμου ενός προσαρμοσμένου πεδίου. |
| rollup_type | Λαμβάνει ή ορίζει τον τρόπο με τον οποίο υπολογίζονται οι συγκεντρώσεις. |
| calculation_type | Λαμβάνει ή ορίζει τον τύπο υπολογισμού της τιμής του προσαρμοσμένου χαρακτηριστικού. |
| summary_rows_calculation_type | Λαμβάνει ή ορίζει τον τύπο υπολογισμού της τιμής του προσαρμοσμένου χαρακτηριστικού για γραμμές σύνοψης. |
| formula | Λαμβάνει ή ορίζει τον τύπο που χρησιμοποιεί το Microsoft Project για τη συμπλήρωση ενός προσαρμοσμένου πεδίου εργασίας. |
| graphical_indicator | Αποκτά ή ορίζει πληροφορίες γραφικών δεικτών που σχετίζονται με το εκτεταμένο χαρακτηριστικό.<br/>            Εφαρμόσιμο στη μορφή MPP. |
| restrict_values | Αποκτά ή ορίζει μια τιμή που υποδεικνύει εάν οι τιμές του προσαρμοσμένου πεδίου περιορίζονται σε τιμές στη [value_list](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
| valuelist_sort_order | Αποκτά ή ορίζει τον τρόπο ταξινόμησης των λιστών τιμών. Οι τιμές είναι: 0=Φθίνουσα, 1=Αύξουσα. |
| append_new_values | Αποκτά ή ορίζει μια τιμή που υποδεικνύει εάν οι νέες τιμές που προστίθενται σε ένα έργο προστίθενται αυτόματα στη λίστα. |
| default | Αποκτά ή ορίζει την προεπιλεγμένη τιμή στη λίστα. |
| value_list | Αποκτά τη List<Value> ValueList. |
| secondary_guid | Αποκτά ή ορίζει το δευτερεύον guid του εκτεταμένου χαρακτηριστικού. |
| parent_project | Αποκτά το γονικό έργο για το παράδειγμα [ExtendedAttributeDefinition](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
