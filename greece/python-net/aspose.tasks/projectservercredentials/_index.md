## ProjectServerCredentials class

Διαπιστευτήρια που χρησιμοποιούνται για σύνδεση στο Project Online ή στην τοπική εγκατάσταση του Project Server.

Ο τύπος ProjectServerCredentials εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | Αρχικοποιεί μια νέα παρουσία της κλάσης [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) χρησιμοποιώντας το URL του ιστότοπου SharePoint και ένα έγκυρο διακριτικό εξουσιοδότησης SPOIDCRL για τον ιστότοπο PWA (Project Web Access) του SharePoint). |
| ProjectServerCredentials(site_url, user_name, password) | Αρχικοποιεί μια νέα παρουσία της κλάσης [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) χρησιμοποιώντας το URL του ιστότοπου SharePoint και ένα έγκυρο διακριτικό εξουσιοδότησης SPOIDCRL για τον ιστότοπο PWA (Project Web Access) του SharePoint). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| site_url | Λαμβάνει το URL του PWA στον ιστότοπο SharePoint ή το URL του τοπικού Project Server.<br/>            Για παράδειγμα, https://your_company_name.sharepoint.com/sites/pwa"; |
| auth_token | Λαμβάνει το διακριτικό εξουσιοδότησης για το στιγμιότυπο SharePoint. |
| user_name | Λαμβάνει το όνομα χρήστη για τον ιστότοπο SharePoint. |
