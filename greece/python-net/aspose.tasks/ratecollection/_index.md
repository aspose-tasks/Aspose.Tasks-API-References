## RateCollection class

Αντιπροσωπεύει μια συλλογή που περιέχει αντικείμενα [Rate](/tasks/python-net/aspose.tasks/rate/).

Ο τύπος RateCollection εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| count | Επιστρέφει τον αριθμό των στοιχείων που περιέχονται στο RateCollection. |
| is_read_only | Επιστρέφει μια τιμή που υποδεικνύει αν αυτή η συλλογή είναι μόνο για ανάγνωση. |
| parent_resource | Επιστρέφει το γονικό αντικείμενο [Resource](/tasks/python-net/aspose.tasks/resource/) για αυτή τη συλλογή. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| add(rates_from) | Προσθέτει ένα νέο αντικείμενο [Rate](/tasks/python-net/aspose.tasks/rate/) σε αυτή τη συλλογή. |
| add(rates_from, type) | Προσθέτει ένα νέο αντικείμενο [Rate](/tasks/python-net/aspose.tasks/rate/) σε αυτή τη συλλογή. |
| to_list() | Μετατρέπει το αντικείμενο [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) σε λίστα αντικειμένων [Rate](/tasks/python-net/aspose.tasks/rate/). |
| to_list(type) | Μετατρέπει το αντικείμενο [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) σε λίστα αντικειμένων [Rate](/tasks/python-net/aspose.tasks/rate/) φιλτραρισμένη κατά τον καθορισμένο τύπο [RateType](/tasks/python-net/aspose.tasks/ratetype/). |
| remove(item) | Αφαιρεί το αντικείμενο Rate από αυτή τη συλλογή. |
