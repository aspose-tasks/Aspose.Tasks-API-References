## ProjectFileInfo class

Η παρουσία της κλάσης περιέχει πληροφορίες σχετικά με τη μορφή του αρχείου έργου και την έκδοση του Microsoft Project όπου<br/>            δημιουργήθηκε το αρχείο.

Ο τύπος ProjectFileInfo εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| can_read | Λαμβάνει μια τιμή που υποδεικνύει εάν το Aspose.Tasks μπορεί να επεξεργαστεί το αρχείο έργου. |
| is_password_protected | Λαμβάνει μια τιμή που υποδεικνύει εάν ένα έργο είναι προστατευμένο με κωδικό. |
| project_file_format | Λαμβάνει τη μορφή του αρχείου έργου. |
| project_application_info | Λαμβάνει τις πληροφορίες εφαρμογής του αρχείου έργου. |
