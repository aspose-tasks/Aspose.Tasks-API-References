## UndefinedConstraintHandlingBehavior enumeration

Καθορίζει τη συμπεριφορά που χρησιμοποιείται για τη διαχείριση εργασιών με ακαθόριστους περιορισμούς.

| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NONE | Η προεπιλεγμένη συμπεριφορά για τη φόρτωση από μορφή XER.<br/>            Δεν γίνεται καμία ενέργεια. Ένας τύπος περιορισμού εργασίας ορίζεται σε 'ConstraintType.Undefined'. |
