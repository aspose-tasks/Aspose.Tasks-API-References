## Rate class

Αντιπροσωπεύει έναν ορισμό χρονικής περιόδου και τιμών που ισχύουν για έναν πόρο κατά τη διάρκεια αυτής της περιόδου.

Ο τύπος Rate εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| rates_from | Λαμβάνει ή ορίζει την ημερομηνία κατά την οποία ένα rate γίνεται αποτελεσματικό. |
| rates_to | Λαμβάνει ή ορίζει την τελευταία ημερομηνία κατά την οποία ένα rate είναι αποτελεσματικό. |
| rate_table | Λαμβάνει ή ορίζει το μοναδικό αναγνωριστικό ενός rate table για έναν πόρο. |
| standard_rate | Λαμβάνει ή ορίζει το τυπικό rate ανά ώρα για έναν πόρο. |
| standard_rate_format | Λαμβάνει ή ορίζει τις μονάδες που χρησιμοποιεί το Microsoft Project για την εμφάνιση του τυπικού rate. |
| overtime_rate | Λαμβάνει ή ορίζει το υπερωριακό rate ανά ώρα για έναν πόρο. |
| overtime_rate_format | Λαμβάνει ή ορίζει τις μονάδες που χρησιμοποιεί το Microsoft Project για την εμφάνιση του υπερωριακού rate. |
| cost_per_use | Λαμβάνει ή ορίζει το κόστος ανά χρήση ενός πόρου. Αυτή η τιμή λαμβάνεται από την τρέχουσα ημερομηνία εάν υπάρχει ένα rate table για έναν πόρο. |
