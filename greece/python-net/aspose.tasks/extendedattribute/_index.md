## ExtendedAttribute class

Αναπαριστά εκτεταμένα χαρακτηριστικά.

Ο τύπος ExtendedAttribute εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| attribute_definition | Λαμβάνει τον ορισμό του χαρακτηριστικού. |
| field_id | Λαμβάνει το αναγνωριστικό ενός πεδίου. |
| duration_value | Λαμβάνει ή ορίζει τιμή για χαρακτηριστικά τύπου 'Duration'. |
| numeric_value | Λαμβάνει ή ορίζει τιμή για χαρακτηριστικά αριθμητικών τύπων (Cost, Number). |
| date_value | Λαμβάνει ή ορίζει τιμή για χαρακτηριστικά τύπων ημερομηνίας (Date, Start, Finish). |
| flag_value | Λαμβάνει ή ορίζει τιμή που υποδεικνύει αν έχει οριστεί σημαία για χαρακτηριστικό τύπου 'Flag'. |
| text_value | Λαμβάνει ή ορίζει τιμή για χαρακτηριστικά τύπου 'Text'. |
| value_guid | Λαμβάνει το guid μιας τιμής αναζήτησης. |
| value_read_only | Λαμβάνει τιμή που υποδεικνύει αν μια τιμή αυτής της παρουσίας [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) είναι μόνο για ανάγνωση. |
| is_error_value | Λαμβάνει αν ο υπολογισμός της τιμής του εκτεταμένου χαρακτηριστικού κατέληξε σε σφάλμα. |
