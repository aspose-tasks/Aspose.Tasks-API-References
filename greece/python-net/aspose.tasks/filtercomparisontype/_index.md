## FilterComparisonType enumeration

Ο τύπος σύγκρισης που γίνεται μεταξύ του FieldName και του Value και λειτουργεί ως κριτήριο επιλογής για ένα φίλτρο ή γραφικό δείκτη.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| EQUALS | Η τιμή του Field είναι ίση με Value. |
| DOES_NOT_EQUAL | Η τιμή του Field δεν είναι ίση με Value. |
| IS_GREATER_THAN | Η τιμή του Field είναι μεγαλύτερη από Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | Η τιμή του Field είναι μεγαλύτερη ή ίση με Value. |
| IS_LESS_THAN | Η τιμή του Field είναι μικρότερη από Value. |
| IS_LESS_THAN_OR_EQUAL_TO | Η τιμή του Field είναι μικρότερη ή ίση με Value. |
| IS_WITHIN | Η τιμή του Field είναι εντός Value. |
| IS_NOT_WITHIN | Η τιμή του Field δεν είναι εντός του Value. |
| CONTAINS | Η τιμή του Field περιέχει το Value. |
| DOES_NOT_CONTAIN | Η τιμή του Field δεν περιέχει το Value. |
| CONTAINS_EXACTLY | Η τιμή του Field περιέχει ακριβώς το Value. |
| IS_ONE_OF | Η τιμή του Field ισούται με μία από τις καθορισμένες Values. Χρησιμοποιείται στα AutoFilters. |
| UNDEFINED | Απροσδιόριστη τιμή. |
| IS_ANY_VALUE | Η κατάσταση 'Is any value'. Εφαρμόσιμη σε γραφικούς δείκτες. |
