## PrimaveraBaseReader class

Αναπαριστά έναν βασικό αναγνώστη που μπορεί να χρησιμοποιηθεί για την ανάγνωση των UID έργων από αρχεία Primavera XER ή XML πολλαπλών έργων.

Ο τύπος PrimaveraBaseReader εκθέτει τα ακόλουθα μέλη:
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| get_project_uids() | Επιστρέφει μια λίστα με τα μοναδικά αναγνωριστικά των έργων. |
| get_project_infos() | Επιστρέφει μια λίστα με τα σύντομα αντικείμενα πληροφοριών του έργου. |
| load_project(project_uid) | Φορτώνει το έργο με το καθορισμένο μοναδικό αναγνωριστικό. |
