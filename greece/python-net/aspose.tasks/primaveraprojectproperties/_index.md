## PrimaveraProjectProperties class

Αναπαριστά ιδιότητες ειδικές για Primavera για ένα έργο που διαβάζεται από αρχεία Primavera (XER του P6XML).

Ο τύπος PrimaveraProjectProperties εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| relationship_lag_calendar | Λαμβάνει μια επιλογή που ορίζει ποιο ημερολόγιο θα χρησιμοποιηθεί για τον προγραμματισμό του Relationship Lag σε έργα Primavera |
| use_expected_finish_dates | Λαμβάνει μια σημαία που ορίζει αν οι ημερομηνίες λήξης των δραστηριοτήτων πρέπει να προγραμματιστούν ως οι αναμενόμενες ημερομηνίες λήξης. |
| make_open_ended_activities_critical | Λαμβάνει μια σημαία που ορίζει αν οι δραστηριότητες πρέπει να σημειωθούν ως κρίσιμες κατά τον προγραμματισμό του έργου. |
| ignore_other_project_relationships | Λαμβάνει μια σημαία που ορίζει αν θα αγνοηθούν οι σχέσεις δραστηριοτήτων μεταξύ έργων. |
| current_baseline_project_id | Λαμβάνει το Id του τρέχοντος baseline έργου.<br/>            Ισχύει για έργα που διαβάζονται από αρχεία Primavera XML που περιέχουν εξαγόμενα baseline. |
| baseline_projects | Λαμβάνει τον πίνακα των baseline έργων του τρέχοντος έργου.<br/>            Ισχύει για έργα που διαβάζονται από αρχεία Primavera XML που περιέχουν εξαγόμενα baseline. |
| critical_activities_defining_method | Λαμβάνει τη μέθοδο για τον ορισμό κρίσιμων δραστηριοτήτων: προσέγγιση Longest Path ή Total Float. |
| critical_total_float_limit | Λαμβάνει την τιμή όριου που χρησιμοποιείται για τον ορισμό κρίσιμων δραστηριοτήτων εάν χρησιμοποιηθεί η μέθοδος TotalFloat. |
| short_name | Λαμβάνει το σύντομο όνομα του έργου (Project ID). |
