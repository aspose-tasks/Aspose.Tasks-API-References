## CssSavingArgs class

Αυτή η κλάση αναπαριστά ένα σύνολο δεδομένων που σχετίζονται με την αποθήκευση εξωτερικού αρχείου CSS που<br/>              συμβαίνει κατά τη μετατροπή σε μορφή HTML.

Ο τύπος CssSavingArgs εκθέτει τα ακόλουθα μέλη:

| :- | :- |

| Όνομα | Περιγραφή |
