## OutlineMask class

Αναπαριστά τέσσερα στοιχεία μιας μάσκας που ορίζει τη μορφή ενός κώδικα περιγράμματος.

Ο τύπος OutlineMask εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| OutlineMask() | Αρχικοποιεί μια νέα παρουσία της κλάσης [OutlineMask](/tasks/python-net/aspose.tasks/outlinemask/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| level | Λαμβάνει ή ορίζει το επίπεδο μιας μάσκας. |
| τύπος | Λαμβάνει ή ορίζει τον τύπο μιας μάσκας. |
| length | Λαμβάνει ή ορίζει το μέγιστο μήκος (σε χαρακτήρες) των τιμών κώδικα περιγράμματος. 0 εάν το μήκος δεν είναι ορισμένο. |
| separator | Λαμβάνει ή ορίζει το διαχωριστικό των τιμών κώδικα. |
