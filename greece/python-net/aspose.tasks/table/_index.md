## Table class

Αντιπροσωπεύει έναν πίνακα στο Project

Ο τύπος Table εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Table() | Αρχικοποιεί μια νέα παρουσία της κλάσης [Table](/tasks/python-net/aspose.tasks/table/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| name | Αποκτά ή ορίζει το όνομα ενός αντικειμένου Table. |
| show_in_menu | Αποκτά ή ορίζει μια τιμή που υποδεικνύει εάν το έργο εμφανίζει το όνομα του πίνακα στη λίστα αναπτυσσόμενου μενού Tables στην καρτέλα View της Ribbon. |
| table_fields | Αποκτά μια συλλογή TableFields που αντιπροσωπεύει τα πεδία στον πίνακα. |
| table_type | Αποκτά ή ορίζει τον τύπο πίνακα για τον καθορισμένο πίνακα. |
| uid | Αποκτά το μοναδικό αναγνωριστικό ενός πίνακα. |
| row_height | Αποκτά ή ορίζει το ύψος γραμμής σε έναν πίνακα, όπου το ύψος γραμμής είναι ο αριθμός των γραμμών κειμένου. |
| date_format | Αποκτά ή ορίζει τη μορφή ημερομηνίας του πίνακα. |
| adjust_header_row_height | Αποκτά ή ορίζει μια τιμή που υποδεικνύει εάν το ύψος της γραμμής κεφαλίδας του πίνακα μπορεί να προσαρμοστεί. |
| show_add_new_column | Αποκτά ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανιστεί η διεπαφή 'Add New Column'. |
| lock_first_column | Αποκτά ή ορίζει μια τιμή που υποδεικνύει εάν η πρώτη στήλη ενός πίνακα είναι κλειδωμένη ή επεξεργάσιμη. |
