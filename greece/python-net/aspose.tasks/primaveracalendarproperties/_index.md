## PrimaveraCalendarProperties class

Αναπαριστά ιδιότητες ειδικές για Primavera για ένα ημερολόγιο που διαβάζεται από αρχεία Primavera (XER του P6XML).<br/>            Μπορεί να χρησιμοποιηθεί για τη μετατροπή μονάδων χρόνου ειδικών για το ημερολόγιο.

Ο τύπος PrimaveraCalendarProperties εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| hours_per_day | Λαμβάνει την ποσότητα ωρών ανά ημέρα από τις ρυθμίσεις 'Time Periods' του ημερολογίου. |
| hours_per_week | Λαμβάνει την ποσότητα ωρών ανά εβδομάδα από τις ρυθμίσεις 'Time Periods' του ημερολογίου. |
| hours_per_month | Λαμβάνει την ποσότητα ωρών ανά μήνα από τις ρυθμίσεις 'Time Periods' του ημερολογίου. |
| hours_per_year | Λαμβάνει την ποσότητα ωρών ανά μήνα από τις ρυθμίσεις 'Time Periods' του ημερολογίου. |
