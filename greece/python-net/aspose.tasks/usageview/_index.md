## UsageView class

Αναπαριστά μια προβολή χρήσης σε ένα έργο.

Ο τύπος UsageView εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| filter | Λαμβάνει ή ορίζει ένα φίλτρο που χρησιμοποιείται σε μια μοναδική προβολή. |
| group | Λαμβάνει ή ορίζει μια ομάδα της μονής προβολής. |
| uid | Λαμβάνει το μοναδικό αναγνωριστικό μιας προβολής. |
| highlight_filter | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το Microsoft Project επισημαίνει το φίλτρο για μια μονή προβολή. |
| name | Λαμβάνει ή ορίζει το όνομα ενός αντικειμένου View. |
| screen | Λαμβάνει τον τύπο οθόνης για τη μονή προβολή.<br/>            Μόνο για ανάγνωση [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Λαμβάνει το γονικό στοιχείο του αντικειμένου View.<br/>            Μόνο για ανάγνωση [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Λαμβάνει ή ορίζει έναν πίνακα της μονής προβολής. |
| type | Λαμβάνει τον τύπο στοιχείου στη μονή προβολή, όπως εργασίες ή πόρους.<br/>            Μόνο για ανάγνωση [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το Microsoft Project εμφανίζει το όνομα της μονής προβολής στη λίστα View ή Other Views στο Ribbon. |
| page_info | Λαμβάνει μια παρουσία της κλάσης [page_info](/tasks/python-net/aspose.tasks/view/). Αντιπροσωπεύει τα δεδομένα ρύθμισης σελίδας που υπάρχουν σε μορφή αρχείου mpp. |
| visual_objects_placements | Λαμβάνει μια συλλογή αντικειμένων που αντιπροσωπεύουν τη θέση και την εμφάνιση του [OleObject](/tasks/python-net/aspose.tasks/oleobject/) στην προβολή. |
| align_details_data | Λαμβάνει ή ορίζει την ευθυγράμμιση των δεδομένων λεπτομερειών. |
| display_details_header_column | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζεται η στήλη κεφαλίδας λεπτομερειών στην προβολή ή όχι. |
| display_short_detail_header_names | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται σύντομα ονόματα κεφαλίδας λεπτομερειών ή όχι. |
| repeat_details_header_on_all_rows | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα επαναλαμβάνεται η κεφαλίδα λεπτομερειών σε όλες τις γραμμές ανάθεσης ή όχι. |
| timescale_size_percentage |  |
| bottom_timescale_tier | Λαμβάνει ή ορίζει τις ρυθμίσεις του κάτω επιπέδου κλίμακας χρόνου της προβολής.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | Λαμβάνει ή ορίζει τις ρυθμίσεις του μεσαίου επιπέδου κλίμακας χρόνου της προβολής.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | Λαμβάνει ή ορίζει τις ρυθμίσεις του ανώτερου επιπέδου κλίμακας χρόνου της προβολής.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| compare_to(other) | Συγκρίνει το τρέχον αντικείμενο με ένα άλλο αντικείμενο του ίδιου τύπου και επιστρέφει έναν ακέραιο που υποδεικνύει εάν το τρέχον αντικείμενο προηγείται, ακολουθεί ή βρίσκεται στην ίδια θέση στη σειρά ταξινόμησης με το άλλο αντικείμενο. |
