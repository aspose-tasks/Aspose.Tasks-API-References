## OutlineCode class

Αναπαριστά μια τιμή ενός κώδικα περιγράμματος.

Ο τύπος OutlineCode εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| OutlineCode() | Αρχικοποιεί μια νέα παρουσία της κλάσης [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/). |
| OutlineCode(code_definition, outline_value) | Αρχικοποιεί μια νέα παρουσία της κλάσης [OutlineCode](/tasks/python-net/aspose.tasks/outlinecode/) χρησιμοποιώντας τον καθορισμένο Outline Code και μία από τις τιμές του. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| field_id | Λαμβάνει ή ορίζει την αριθμητική τιμή του προσαρμοσμένου πεδίου Id του έργου. |
| value_id | Λαμβάνει ή ορίζει το Id στη λίστα τιμών που σχετίζεται με τον ορισμό στη συλλογή outline code. |
| value_guid | Λαμβάνει ή ορίζει το GUID της τιμής στη λίστα τιμών. Το ValueGuid ταιριάζει με το FieldGuid στη λίστα τιμών. |
