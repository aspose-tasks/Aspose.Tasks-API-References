## SummaryRowsCalculationType enumeration

Καθορίζει τον τύπο υπολογισμού της τιμής του προσαρμοσμένου χαρακτηριστικού για γραμμές σύνοψης.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NONE | Σημαίνει ότι η τιμή του προσαρμοσμένου χαρακτηριστικού για τις συνοπτικές γραμμές δεν υπολογίζεται. |
| ROLLUP | Σημαίνει ότι η τιμή του προσαρμοσμένου χαρακτηριστικού για τις συνοπτικές γραμμές υπολογίζεται χρησιμοποιώντας τη λειτουργία συγκέντρωσης (rollup) που ορίζεται στο [rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
| USE_FORMULA | Σημαίνει ότι η τιμή του προσαρμοσμένου χαρακτηριστικού για τις συνοπτικές γραμμές υπολογίζεται χρησιμοποιώντας τον τύπο που ορίζεται στο [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
