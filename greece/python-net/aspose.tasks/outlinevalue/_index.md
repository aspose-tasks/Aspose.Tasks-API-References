## OutlineValue class

Αναπαριστά μια τιμή περιγράμματος.

Ο τύπος OutlineValue εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| OutlineValue() | Αρχικοποιεί μια νέα παρουσία της κλάσης OutlineValue. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| value_id | Λαμβάνει ή ορίζει το μοναδικό Id μιας τιμής κώδικα περιγράμματος εντός ενός έργου. |
| value_guid | Λαμβάνει ένα GUID που αναγνωρίζει αυτήν την τιμή μεταξύ των άλλων σε ολόκληρο το έργο. |
| τύπος | Λαμβάνει ή ορίζει τον τύπο κώδικα περιγράμματος. |
| parent_value_id | Λαμβάνει ή ορίζει το Id ενός γονικού κόμβου ενός κώδικα περιγράμματος. |
| value | Λαμβάνει ή ορίζει την πραγματική τιμή. |
| duration_value | Λαμβάνει ή ορίζει τη διάρκεια εάν ο Τύπος είναι Διάρκεια. |
| description | Λαμβάνει ή ορίζει την περιγραφή μιας τιμής περιγράμματος. |
| is_collapsed | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η τιμή περιγράμματος είναι συμπτυγμένη ή όχι. |
