## ProjectServerManager class

Η κλάση που παρέχει τις μεθόδους για ανάγνωση και εκτέλεση λειτουργιών σε έργα στον καθορισμένο λογαριασμό Project Online ή<br/>            στην καθορισμένη τοπική εγκατάσταση του Project Server (υποστηρίζονται οι εκδόσεις 2016 και 2019 του Project Server).

Ο τύπος ProjectServerManager εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| ProjectServerManager(credentials) | Αρχικοποιεί μια νέα παρουσία της κλάσης [ProjectServerManager](/tasks/python-net/aspose.tasks/projectservermanager/). |
