## WeekDay class

Αντιπροσωπεύει μια ημέρα της εβδομάδας που είτε ορίζει κανονικές ημέρες της εβδομάδας είτε ημέρες εξαίρεσης σε ένα ημερολόγιο.

Ο τύπος WeekDay εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| WeekDay(day_type) | Αρχικοποιεί μια νέα παρουσία της κλάσης [WeekDay](/tasks/python-net/aspose.tasks/weekday/) με τον καθορισμένο τύπο ημέρας. |
| WeekDay(day_type, working_times) | Αρχικοποιεί μια νέα παρουσία της κλάσης WeekDay |
| WeekDay(day_type, working_times) | Αρχικοποιεί μια νέα παρουσία της κλάσης [WeekDay](/tasks/python-net/aspose.tasks/weekday/) με τον καθορισμένο τύπο ημέρας και τις περιόδους εργασίας. |
| WeekDay() | Αρχικοποιεί μια νέα παρουσία της κλάσης [WeekDay](/tasks/python-net/aspose.tasks/weekday/) με τον καθορισμένο τύπο ημέρας. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| day_type | Λαμβάνει τον τύπο μιας ημέρας. |
| day_working | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η καθορισμένη ημερομηνία ή ο τύπος ημέρας είναι εργάσιμη. |
| from_date | Λαμβάνει ή ορίζει την αρχή μιας χρονικής εξαίρεσης. |
| to_date | Λαμβάνει ή ορίζει το τέλος μιας χρονικής εξαίρεσης. |
| working_times | Λαμβάνει το WorkingTimeCollection για αυτήν την παρουσία WeekDay.<br/>            Η συλλογή των ωρών εργασίας που ορίζουν τον χρόνο εργασίας κατά τη διάρκεια της ημέρας της εβδομάδας. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| create_default_working_day(day_type) | Δημιουργεί προεπιλεγμένη εργάσιμη ημέρα. |
| set_default_working_time(day) | Ορίζει προεπιλεγμένες χρονικές περιόδους για την καθορισμένη ημέρα της εβδομάδας. |
| get_working_time() | Επιστρέφει τον χρόνο εργασίας για μια ημέρα της εβδομάδας. |
| clone() | Επιστρέφει ένα βαθύ αντίγραφο της ημέρας της εβδομάδας. |
