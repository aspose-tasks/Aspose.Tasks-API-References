## PrimaveraTaskProperties class

Αναπαριστά ιδιότητες ειδικές για Primavera για μια εργασία που διαβάζεται από αρχεία Primavera (XER του P6XML).

Ο τύπος PrimaveraTaskProperties εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| sequence_number | Λαμβάνει ή ορίζει τον αριθμό ακολουθίας του στοιχείου WBS (συνοπτικές εργασίες). Χρησιμοποιείται για την ταξινόμηση των συνοπτικών εργασιών στο Primavera. |
| activity_id | Λαμβάνει ένα πεδίο activity id - το μοναδικό αναγνωριστικό μιας εργασίας που χρησιμοποιείται από το Primavera. |
| remaining_early_finish | Λαμβάνει την ημερομηνία πρώιμου ολοκλήρωσης που απομένει - την ημερομηνία κατά την οποία η υπόλοιπη εργασία για τη δραστηριότητα προγραμματίζεται να ολοκληρωθεί. |
| remaining_early_start | Λαμβάνει την ημερομηνία πρώιμης έναρξης που απομένει - την ημερομηνία κατά την οποία η υπόλοιπη εργασία για τη δραστηριότητα προγραμματίζεται να ξεκινήσει. |
| remaining_late_start | Λαμβάνει την ημερομηνία καθυστερημένης έναρξης που απομένει. |
| remaining_late_finish | Λαμβάνει την ημερομηνία καθυστερημένου ολοκλήρωσης που απομένει. |
| raw_duration_type | Λαμβάνει την ακατέργαστη αναπαράσταση κειμένου (όπως στο αρχείο προέλευσης) του πεδίου 'Duration Type' της δραστηριότητας. |
| duration_type | Λαμβάνει την τιμή του πεδίου 'Duration Type' της δραστηριότητας. |
| raw_activity_type | Λαμβάνει την ακατέργαστη αναπαράσταση κειμένου (όπως στο αρχείο προέλευσης) του πεδίου 'Activity Type' της δραστηριότητας. |
| activity_type | Λαμβάνει την τιμή του πεδίου 'Activity Type'. |
| percent_complete_type | Λαμβάνει την τιμή του πεδίου '% Complete Type' της δραστηριότητας. |
| raw_complete_percent_type | Λαμβάνει την ακατέργαστη αναπαράσταση κειμένου (όπως στο αρχείο προέλευσης) του πεδίου '% Complete Type' της δραστηριότητας. |
| raw_status | Λαμβάνει την ακατέργαστη αναπαράσταση κειμένου (όπως στο αρχείο προέλευσης) του πεδίου 'Status' της δραστηριότητας. |
| physical_percent_complete | Λαμβάνει την τιμή του Φυσικού Ποσοστού Ολοκλήρωσης. |
| duration_percent_complete | Λαμβάνει την τιμή του ποσοστού ολοκλήρωσης διάρκειας. |
| units_percent_complete | Λαμβάνει την τιμή του ποσοστού ολοκλήρωσης μονάδων. |
| actual_labor_units | Λαμβάνει την τιμή των πραγματικών μονάδων εργασίας. |
| actual_non_labor_units | Λαμβάνει την τιμή των πραγματικών μονάδων μη εργασίας. |
| remaining_labor_units | Λαμβάνει την τιμή των εναπομείναντων μονάδων εργασίας. |
| remaining_non_labor_units | Λαμβάνει την τιμή των εναπομείναντων μονάδων μη εργασίας. |
| actual_labor_cost | Λαμβάνει την τιμή του πραγματικού κόστους εργασίας. |
| budgeted_labor_cost | Λαμβάνει την τιμή του προϋπολογισμένου (ή προγραμματισμένου) κόστους εργασίας. |
| actual_nonlabor_cost | Λαμβάνει την τιμή του πραγματικού κόστους μη εργασίας. |
| budgeted_nonlabor_cost | Λαμβάνει την τιμή του προϋπολογισμένου (ή προγραμματισμένου) κόστους μη εργασίας. |
| actual_material_cost | Λαμβάνει την τιμή του πραγματικού κόστους υλικού. |
| budgeted_material_cost | Λαμβάνει την τιμή του προϋπολογισμένου (ή προγραμματισμένου) κόστους υλικού. |
| actual_expense_cost | Λαμβάνει την τιμή του πραγματικού κόστους δαπάνης. |
| remaining_expense_cost | Λαμβάνει την τιμή του εναπομείναντος κόστους δαπάνης. |
| budgeted_expense_cost | Λαμβάνει την τιμή του προϋπολογισμένου (ή προγραμματισμένου) κόστους δαπάνης. |
| actual_total_cost | Λαμβάνει τη συνολική τιμή των πραγματικών εξόδων. |
| budgeted_total_cost | Λαμβάνει τη συνολική τιμή των προϋπολογισμένων (ή προγραμματισμένων) εξόδων. |
| primary_constraint_type | Λαμβάνει έναν τύπο του πρωτεύοντος περιορισμού. |
| primary_constraint_date | Λαμβάνει την ημερομηνία του πρωτεύοντος περιορισμού. |
| secondary_constraint_type | Λαμβάνει έναν τύπο του δευτερεύοντος περιορισμού. |
| secondary_constraint_date | Λαμβάνει την ημερομηνία του δευτερεύοντος περιορισμού. |
| planned_duration | Λαμβάνει τη αρχική ή προγραμματισμένη διάρκεια -- το συνολικό χρόνο εργασίας από την προγραμματισμένη ημερομηνία έναρξης της εργασίας έως την προγραμματισμένη ημερομηνία λήξης.. |
