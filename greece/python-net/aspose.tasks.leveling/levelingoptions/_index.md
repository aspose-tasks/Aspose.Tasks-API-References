## LevelingOptions class

Επιτρέπει τον καθορισμό παραμέτρων εξισορρόπησης πόρων.

Ο τύπος LevelingOptions εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| LevelingOptions() | Αρχικοποιεί μια νέα παρουσία της κλάσης [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| start_date | Λαμβάνει ή ορίζει την ημερομηνία έναρξης της περιόδου εξισορρόπησης. Η προεπιλεγμένη τιμή είναι η ημερομηνία έναρξης του project`s. |
| finish_date | Λαμβάνει ή ορίζει την ημερομηνία λήξης της περιόδου εξισορρόπησης. Η προεπιλεγμένη τιμή είναι η ημερομηνία λήξης του project`s. |
| πόροι | Λαμβάνει ή ορίζει τη λίστα των πόρων που θα εξισορροπηθούν. Εάν οριστεί null, όλοι οι πόροι του έργου θα εξισορροπηθούν. |
| leveling_order | Λαμβάνει τη σειρά με την οποία ο αλγόριθμος εξισορρόπησης καθυστερεί τις εργασίες που έχουν υπερκατανομές.<br/>            Μετά τον προσδιορισμό των εργασιών που προκαλούν την υπερκατανομή και ποιες εργασίες μπορούν να καθυστερήσουν, χρησιμοποιείται η καθορισμένη σειρά για το ποια εργασία πρέπει να καθυστερήσει πρώτα. |
| message_level | Λαμβάνει ή ορίζει το επίπεδο των μηνυμάτων καταγραφής που εκδίδονται από το Aspose.Tasks κατά τη διάρκεια της εξισορρόπησης πόρων. |
| message_handler | Λαμβάνει ή ορίζει την κλήση επανάκλησης του διαχειριστή μηνυμάτων που μπορεί να χρησιμοποιηθεί για την παρέμβαση στα μηνύματα καταγραφής που παράγονται από το Aspose.Tasks κατά τη διάρκεια της εξισορρόπησης πόρων. |
