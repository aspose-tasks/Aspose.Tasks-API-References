## LevelingOrder enumeration

Ορίζει τις πιθανές τιμές της σειράς εξισορρόπησης.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| STANDARD | Λαμβάνονται υπόψη οι ακόλουθες ιδιότητες: σχέσεις προγόνων, συνολική ελεύθερη διάρκεια (μια εργασία με μεγαλύτερη συνολική ελεύθερη διάρκεια καθυστερεί πρώτη), ημερομηνία έναρξης, προτεραιότητα.<br/>            Αυτή είναι η προεπιλεγμένη τιμή. |
| ID_ONLY | Οι εργασίες καθυστερούν με αύξουσα σειρά ID. |
| PRIORITY_THEN_STANDARD | Η προτεραιότητα λαμβάνεται υπόψη πρώτα, έπειτα οι ίδιες ιδιότητες όπως στο Standard. |
