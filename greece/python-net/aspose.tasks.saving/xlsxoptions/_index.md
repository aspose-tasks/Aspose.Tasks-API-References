## XlsxOptions class

Επιτρέπει τον καθορισμό πρόσθετων επιλογών κατά την απόδοση των σελίδων του έργου σε XLSX.

Ο τύπος XlsxOptions εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| XlsxOptions() | Δημιουργεί μια νέα παρουσία της κλάσης [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) που μπορεί να χρησιμοποιηθεί για την αποθήκευση του έργου σε μορφή XLSX. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| save_format | Λαμβάνει ή ορίζει τη μορφή στην οποία θα αποθηκευτεί το έγγραφο εάν χρησιμοποιηθεί αυτό το αντικείμενο επιλογών αποθήκευσης. |
| resource_view | Λαμβάνει ή ορίζει μια λίστα των στηλών προβολής πόρων για απόδοση ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Λαμβάνει ή ορίζει μια λίστα των στηλών προβολής εκχωρήσεων για απόδοση ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| encoding | Λαμβάνει ή ορίζει την κωδικοποίηση του παραγόμενου αρχείου XLSX. Η προεπιλεγμένη τιμή είναι . |
| view | Λαμβάνει ή ορίζει μια λίστα των στηλών προβολής ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) για αποθήκευση σε μορφή XLSX.<br/>            Εάν δεν οριστεί, τότε αποθηκεύονται οι προεπιλεγμένες στήλες. |
