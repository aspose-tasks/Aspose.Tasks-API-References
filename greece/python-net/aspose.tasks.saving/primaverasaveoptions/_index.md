## PrimaveraSaveOptions class

Επιτρέπει τον καθορισμό πρόσθετων επιλογών κατά την αποθήκευση του έργου σε μορφή Primavera XER.

Ο τύπος PrimaveraSaveOptions εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PrimaveraSaveOptions() | Αρχικοποιεί μια νέα παρουσία της κλάσης [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| save_format | Λαμβάνει ή ορίζει τη μορφή στην οποία θα αποθηκευτεί το έγγραφο εάν χρησιμοποιηθεί αυτό το αντικείμενο επιλογών αποθήκευσης. |
| activity_id_increment | Λαμβάνει ή ορίζει το αύξημα που χρησιμοποιείται στην επανααρίθμηση των αναγνωριστικών δραστηριότητας. |
| activity_id_prefix | Λαμβάνει ή ορίζει το πρόθεμα που χρησιμοποιείται στην επανααρίθμηση των αναγνωριστικών δραστηριότητας. |
| activity_id_suffix | Λαμβάνει ή ορίζει το επίθημα που χρησιμοποιείται στην επανααρίθμηση των αναγνωριστικών δραστηριότητας. |
| renumber_activity_ids | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν χρειάζεται να επανααριθμηθούν τα αναγνωριστικά δραστηριότητας. |
| skip_summary_assignments | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι εκχωρήσεις πόρων σε συνοπτικές εργασίες πρέπει να παραλειφθούν κατά την εξαγωγή. |
