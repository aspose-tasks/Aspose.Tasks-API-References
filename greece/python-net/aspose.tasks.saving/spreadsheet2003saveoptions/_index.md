## Spreadsheet2003SaveOptions class

Επιτρέπει τον καθορισμό πρόσθετων επιλογών κατά την απόδοση των σελίδων του έργου σε Spreadsheet2003.

Ο τύπος Spreadsheet2003SaveOptions εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Spreadsheet2003SaveOptions() | Αρχικοποιεί μια νέα παρουσία του [Spreadsheet2003SaveOptions](/tasks/python-net/aspose.tasks.saving/spreadsheet2003saveoptions/) κλάσης. |
## Ιδιότητες

| :- | :- |

| resource_view | Λαμβάνει ή ορίζει μια λίστα των στηλών προβολής πόρων για απόδοση ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
