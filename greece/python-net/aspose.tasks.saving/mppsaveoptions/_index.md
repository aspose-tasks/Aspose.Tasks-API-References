## MPPSaveOptions class

Επιτρέπει τον καθορισμό πρόσθετων επιλογών κατά την αποθήκευση των δεδομένων του έργου σε MPP.

Ο τύπος MPPSaveOptions εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| MPPSaveOptions() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| save_format | Λαμβάνει ή ορίζει τη μορφή στην οποία θα αποθηκευτεί το έγγραφο εάν χρησιμοποιηθεί αυτό το αντικείμενο επιλογών αποθήκευσης. |
| remove_invalid_assignments | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα αφαιρεθούν οι μη έγκυρες εκχωρήσεις πόρων κατά την αποθήκευση σε MPP. |
| write_view_data | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα γραφτούν τα δεδομένα προβολής κατά την αποθήκευση ενός έργου σε μορφή MPP. |
| write_filters | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα γραφτούν τα δεδομένα φίλτρων κατά την αποθήκευση ενός έργου σε μορφή MPP. |
| write_groups | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα γράφει δεδομένα ομάδων κατά την αποθήκευση ενός έργου σε μορφή MPP. |
| clear_vba | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα αφαιρέσει τα υπάρχοντα δεδομένα μακροεντολών VBA κατά την αποθήκευση ενός έργου σε μορφή MPP. |
| write_vba | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα ενημερώσει τα υπάρχοντα δεδομένα μακροεντολών VBA σε αρχείο MPP.<br/>            Προς το παρόν υποστηρίζεται η εγγραφή του VbaModule.SourceCode. |
| protection_password | Λαμβάνει ή ορίζει έναν κωδικό πρόσβασης που χρησιμοποιείται για την προστασία του τελικού αρχείου MPP. Προς το παρόν υποστηρίζεται για τα φορμά MS Project 2010 και νεότερα. |
