## CsvOptions class

Επιτρέπει τον καθορισμό πρόσθετων επιλογών κατά την αποθήκευση του έργου σε CSV.

Ο τύπος CsvOptions εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| CsvOptions() | Αρχικοποιεί μια νέα παρουσία της κλάσης [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) που μπορεί να χρησιμοποιηθεί για την αποθήκευση του έργου σε μορφή CSV. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| save_format | Λαμβάνει ή ορίζει τη μορφή στην οποία θα αποθηκευτεί το έγγραφο εάν χρησιμοποιηθεί αυτό το αντικείμενο επιλογών αποθήκευσης. |
| data_category | Λαμβάνει ή ορίζει μια κατηγορία δεδομένων προς αποθήκευση. |
| encoding | Λαμβάνει ή ορίζει μια κωδικοποίηση με την οποία θα αποθηκευτεί το CSV. |
| include_headers | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα συμπεριληφθούν κεφαλίδες ή όχι (η προεπιλεγμένη τιμή είναι TRUE). |
| text_delimiter | Λαμβάνει ή ορίζει έναν διαχωριστικό κειμένου. |
| view | Λαμβάνει ή ορίζει μια λίστα των στηλών προβολής ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) για αποθήκευση σε μορφή XLSX.<br/>            Εάν δεν οριστεί, τότε αποθηκεύονται οι προεπιλεγμένες στήλες. |
