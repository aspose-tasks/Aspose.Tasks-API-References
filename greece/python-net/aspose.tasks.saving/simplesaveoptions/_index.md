## SimpleSaveOptions class

Αυτή είναι μια αφηρημένη βασική κλάση που επιτρέπει στον χρήστη να καθορίσει βασικές επιλογές κατά την αποθήκευση ενός έργου σε συγκεκριμένη μορφή.

Ο τύπος SimpleSaveOptions εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| save_format | Λαμβάνει ή ορίζει τη μορφή στην οποία θα αποθηκευτεί το έγγραφο εάν χρησιμοποιηθεί αυτό το αντικείμενο επιλογών αποθήκευσης. |
