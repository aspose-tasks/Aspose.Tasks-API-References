## SaveOptions class

Αυτή είναι μια αφηρημένη βασική κλάση για κλάσεις που επιτρέπουν στον χρήστη να καθορίσει πρόσθετες επιλογές κατά την αποθήκευση ενός έργου<br/>            σε συγκεκριμένη μορφή.

Ο τύπος SaveOptions εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| save_format | Λαμβάνει ή ορίζει τη μορφή στην οποία θα αποθηκευτεί το έγγραφο εάν χρησιμοποιηθεί αυτό το αντικείμενο επιλογών αποθήκευσης. |
| bar_styles | Λαμβάνει ή ορίζει τη λίστα των στιγμιοτύπων της κλάσης [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/) που εμφανίζονται στην προβολή του έργου. |
| draw_non_working_time | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν πρέπει να σχεδιαστεί ο μη εργάσιμος χρόνος (Η προεπιλεγμένη τιμή είναι TRUE). |
| end_date | Λαμβάνει ή ορίζει μια ημερομηνία για την ολοκλήρωση της απόδοσης. |
| timescale_fit_behavior | Λαμβάνει ή ορίζει μια συμπεριφορά που ορίζει πώς να ευθυγραμμιστεί το δεξιό άκρο της κλίμακας χρόνου με το άκρο της σελίδας. |
| fit_content | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το ύψος της γραμμής πρέπει να αυξηθεί ώστε να ταιριάζει στο περιεχόμενό του. |
| gridlines | Λαμβάνει ή ορίζει μια λίστα των [Gridline](/tasks/python-net/aspose.tasks.visualization/gridline/) που εμφανίζονται στην προβολή του έργου. |
| legend_drawing_options | Λαμβάνει ή ορίζει μια τιμή που καθορίζει πώς θα αποδοθεί ένα υπόμνημα. Η προεπιλεγμένη τιμή είναι LegendDrawingOptions.OnEveryPage. |
| legend_items | Λαμβάνει ή ορίζει έναν πίνακα των PageLegendItem που καθορίζουν ποια μπαρ πρέπει να αποδοθούν στο υπόμνημα της σελίδας.<br/>            Εάν είναι null, αποδίδονται τα προεπιλεγμένα στοιχεία. |
| mark_critical_tasks | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι κρίσιμες εργασίες πρέπει να εμφανίζονται με κόκκινο χρώμα (Η προεπιλεγμένη τιμή είναι FALSE). |
| non_working_time_color | Λαμβάνει ή ορίζει το χρώμα του μη εργάσιμου χρόνου. |
| page_count | Λαμβάνει ή ορίζει τον αριθμό των σελίδων του έργου. |
| page_size | Λαμβάνει ή ορίζει το μέγεθος της σελίδας που θα αποδοθεί (Η προεπιλεγμένη τιμή είναι PageSize.A4). |
| is_portrait | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν ο προσανατολισμός της σελίδας είναι πορτραίτο· επιστρέφει false εάν ο προσανατολισμός είναι τοπίο. |
| presentation_format | Λαμβάνει ή ορίζει το [presentation_format](/tasks/python-net/aspose.tasks.saving/saveoptions/) με το οποίο θα αποθηκευτεί το έγγραφο. |
| roll_up_gantt_bars | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι υποεργασίες στη γραμμή εργασίας σύνοψης πρέπει να σημειωθούν.<br/>            Για τις υποεργασίες, το πεδίο Rollup υποδεικνύει εάν οι πληροφορίες των γραμμών Gantt των υποεργασιών θα συγκεντρωθούν στη γραμμή εργασίας σύνοψης.<br/>            Για τις εργασίες σύνοψης, το πεδίο Rollup υποδεικνύει εάν η γραμμή εργασίας σύνοψης εμφανίζει συγκεντρωμένες γραμμές.<br/>            Πρέπει να έχετε το πεδίο Rollup για τις εργασίες σύνοψης ορισμένο σε Yes ώστε οποιεσδήποτε υποεργασίες να συγκεντρωθούν σε αυτές. |
| start_date | Λαμβάνει ή ορίζει την ημερομηνία από την οποία θα ξεκινήσει η απόδοση. |
| text_styles | Λαμβάνει ή ορίζει τη λίστα των στυλ κειμένου που εφαρμόζονται κατά την απόδοση μιας προβολής έργου. |
| timescale | Λαμβάνει ή ορίζει την τιμή του [timescale](/tasks/python-net/aspose.tasks.saving/saveoptions/) που χρησιμοποιείται για τον έλεγχο του τρόπου απόδοσης της κλίμακας χρόνου (εάν υπάρχει) όταν το έργο αποθηκεύεται σε γραφική μορφή. |
| use_gradient_brush | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα χρησιμοποιηθεί διαβαθμισμένο πινέλο κατά την απόδοση του Gantt Chart. |
| view | Λαμβάνει ή ορίζει μια λίστα των στηλών προβολής που θα αποδοθούν ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)).<br/>            Εάν δεν οριστεί, αποδίδονται μόνο τα αναγνωριστικά εργασιών, τα ονόματα εργασιών, η έναρξη και η λήξη.<br/>            Εάν οριστούν και οι ιδιότητες View και [view_settings](/tasks/python-net/aspose.tasks.saving/saveoptions/), οι στήλες από το View υπερισχύουν των στηλών από το ViewSettings. |
| view_settings | Λαμβάνει ή ορίζει μια προβολή ([view](/tasks/python-net/aspose.tasks.saving/saveoptions/)) για απόδοση. Μπορείτε να χρησιμοποιήσετε αυτήν την επιλογή για να καθορίσετε ρητά ποια προβολή πρέπει να αποθηκευτεί σε μορφές PDF, HTML ή Image.<br/>            Εάν αυτή η ιδιότητα οριστεί, η ιδιότητα [PresentationFormat](/tasks/python-net/aspose.tasks.visualization/presentationformat/) αγνοείται όταν το έργο αποθηκεύεται.<br/>            Η προβολή πρέπει να προέρχεται από μία από τις ακόλουθες οθόνες (([screen](/tasks/python-net/aspose.tasks/view/))): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage) |
| custom_page_size | Λαμβάνει ή ορίζει το προσαρμοσμένο μέγεθος σελίδας σε πόντους (1 πόντος = 1/72 ίντσας). |
| render_to_single_page | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν ένα έργο πρέπει να αποδοθεί σε μία σελίδα<br/>            όταν το έργο αποθηκεύεται σε γραφική μορφή.<br/>            Το μέγεθος της σελίδας θα αλλάξει ώστε το αποδοθέν έργο να χωράει σε μία σελίδα. |
