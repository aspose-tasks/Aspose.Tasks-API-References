## LegendDrawingOptions enumeration

Καθορίζει τις πιθανές επιλογές που χρησιμοποιούνται κατά την απόδοση του υπομνήματος της προβολής.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NO_LEGEND | Δεν αποδίδεται υπόμνημα. |
| AFTER_LAST_PAGE | Το υπόμνημα αποδίδεται σε ξεχωριστή σελίδα μετά την τελευταία σελίδα των σελίδων του έργου. |
| ON_EVERY_PAGE | Το υπόμνημα αποδίδεται σε κάθε σελίδα. |
| DEFINED_IN_VIEW | Το υπόμνημα αποδίδεται σύμφωνα με την ιδιότητα View.PageInfo.Legend.LegendOn της αποδοθείσας View. |
