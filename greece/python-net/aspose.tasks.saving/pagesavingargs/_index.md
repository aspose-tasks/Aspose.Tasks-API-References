## PageSavingArgs class

Αυτή η κλάση αντιπροσωπεύει ένα σύνολο δεδομένων που σχετίζονται με την αποθήκευση της σελίδας του εγγράφου σε ρεύμα.

Ο τύπος PageSavingArgs εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| page_number | Λαμβάνει έναν αριθμό σελίδας που θα γραφτεί. |
| keep_stream_open | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η διαδικασία απόδοσης πρέπει να διατηρεί το [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) ανοιχτό μετά τη γραφή μιας σελίδας. |
| stream | Λαμβάνει ή ορίζει ένα stream για τη γραφή μιας σελίδας. |
