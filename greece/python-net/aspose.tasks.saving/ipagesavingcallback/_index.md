## IPageSavingCallback class

Αντιπροσωπεύει μια κλήση επιστροφής που καλείται όταν κάθε σελίδα σε έγγραφο πολλαπλών σελίδων αποθηκεύεται σε ξεχωριστό ρεύμα.

Ο τύπος IPageSavingCallback εκθέτει τα ακόλουθα μέλη:
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| page_saving(args) | Η μέθοδος που θα κληθεί όταν μια σελίδα αποθηκευτεί σε ροή. |
| on_finish() | Μέθοδος που θα κληθεί όταν όλες οι σελίδες έχουν γραφτεί. |
