## PageMargins class

Αναπαριστά τα περιθώρια σελίδας για εκτύπωση.

Ο τύπος PageMargins εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PageMargins() | Αρχικοποιεί μια νέα παρουσία της κλάσης PageMargins |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| top | Λαμβάνει ή ορίζει το μέγεθος του επάνω περιθωρίου σε εκατοστά. |
| bottom | Λαμβάνει ή ορίζει το μέγεθος του κάτω περιθωρίου σε εκατοστά. |
| left | Λαμβάνει ή ορίζει το μέγεθος του αριστερού περιθωρίου σε εκατοστά. |
| right | Λαμβάνει ή ορίζει το μέγεθος του δεξιού περιθωρίου σε εκατοστά. |
| borders | Λαμβάνει ή ορίζει τη θέση όπου θα εκτυπωθούν τα περιγράμματα. Μπορεί να είναι μία από τις τιμές της απαρίθμησης [Border](/tasks/python-net/aspose.tasks.visualization/border/). |
