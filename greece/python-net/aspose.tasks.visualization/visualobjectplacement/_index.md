## VisualObjectPlacement class

Αντιπροσωπεύει τη θέση και την εμφάνιση του [OleObject](/tasks/python-net/aspose.tasks/oleobject/) σε μια προβολή.

Ο τύπος VisualObjectPlacement εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| VisualObjectPlacement() | Αρχικοποιεί μια νέα παρουσία της κλάσης [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| ole_object_id | Λαμβάνει ή ορίζει το Id του αντικειμένου [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
| task_id | Λαμβάνει ή ορίζει το Id της εργασίας εάν η επιλογή 'Attach to task' είναι επιλεγμένη, -1 διαφορετικά. |
| width | Λαμβάνει ή ορίζει το εμφανιζόμενο πλάτος του οπτικού αντικειμένου. |
| height | Λαμβάνει ή ορίζει το εμφανιζόμενο ύψος του οπτικού αντικειμένου. |
| vertical_offset | Λαμβάνει ή ορίζει την κάθετη μετατόπιση του οπτικού αντικειμένου. |
| horizontal_offset | Λαμβάνει ή ορίζει την οριζόντια μετατόπιση του οπτικού αντικειμένου. |
| timescale_date | Λαμβάνει ή ορίζει την τοποθέτηση της ημερομηνίας του οπτικού αντικειμένου όταν η επιλογή 'Attach to timescale' είναι επιλεγμένη. |
| attachment_point | Λαμβάνει ή ορίζει την ευθυγράμμιση του οπτικού αντικειμένου σε σχέση με μια εργασία όταν η επιλογή 'Attach to task' είναι επιλεγμένη. |
| border_line_color | Λαμβάνει ή ορίζει το χρώμα της γραμμής περιγράμματος. |
| border_line_thickness | Λαμβάνει ή ορίζει το πάχος της γραμμής περιγράμματος (επιτρεπόμενες τιμές είναι 0 - 5). |
| fill_color | Λαμβάνει ή ορίζει το χρώμα γεμίσματος. |
| fill_pattern | Λαμβάνει ή ορίζει το μοτίβο γεμίσματος. |
