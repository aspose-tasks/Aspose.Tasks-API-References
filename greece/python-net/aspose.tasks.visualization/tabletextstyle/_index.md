## TableTextStyle class

Αντιπροσωπεύει ένα στυλ κειμένου σε έναν πίνακα προβολής.

Ο τύπος TableTextStyle παρέχει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| TableTextStyle(row_uid) | Αρχικοποιεί μια νέα παρουσία της κλάσης TableTextStyle |
| TableTextStyle(row_uid, font) | Αρχικοποιεί μια νέα παρουσία της κλάσης TableTextStyle |
| TableTextStyle(row_uid, font_size, font_style) | Αρχικοποιεί μια νέα παρουσία της κλάσης TableTextStyle |
| TableTextStyle(row_uid, font_style) | Αρχικοποιεί μια νέα παρουσία της κλάσης TableTextStyle |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| font | Λαμβάνει ή ορίζει τη γραμματοσειρά του στυλ κειμένου. |
| color | Λαμβάνει ή ορίζει το χρώμα του κειμένου. |
| item_type | Επιστρέφει μια τιμή του enum [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/). |
| background_pattern | Λαμβάνει ή ορίζει το μοτίβο φόντου του στυλ κειμένου.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Λαμβάνει ή ορίζει το χρώμα φόντου του στυλ κειμένου.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| row_uid | Λαμβάνει ένα μοναδικό αναγνωριστικό γραμμής. |
| field | Λαμβάνει ή ορίζει ένα πεδίο στο οποίο θα εφαρμοστεί το στυλ.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/tabletextstyle/). |
