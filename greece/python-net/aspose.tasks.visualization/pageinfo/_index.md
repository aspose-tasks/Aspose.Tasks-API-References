## PageInfo class

Αναπαριστά τα δεδομένα ρύθμισης σελίδας που υπάρχουν στη μορφή αρχείου MPP και χρησιμοποιούνται για εκτύπωση.

Ο τύπος PageInfo εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PageInfo() | Αρχικοποιεί μια νέα παρουσία της κλάσης [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/). <br/>            Αντιπροσωπεύει δεδομένα ρύθμισης σελίδας που υπάρχουν στη μορφή αρχείου MPP και χρησιμοποιούνται για εκτύπωση. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| header | Λαμβάνει ή ορίζει την παρουσία της κλάσης [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) η οποία αντιπροσωπεύει δεδομένα κεφαλίδας. |
| footer | Λαμβάνει ή ορίζει μια παρουσία της κλάσης [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) η οποία αντιπροσωπεύει δεδομένα υποσέλιδου. |
| name | Λαμβάνει το όνομα της προβολής για την οποία χρησιμοποιούνται τα δεδομένα ρύθμισης. |
| page_settings | Λαμβάνει μια παρουσία της κλάσης [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) η οποία καθορίζει τις ρυθμίσεις εκτύπωσης σελίδας. |
| page_view_settings | Λαμβάνει μια παρουσία της κλάσης [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) η οποία καθορίζει τις ρυθμίσεις εκτύπωσης προβολής σελίδας. |
| margins | Λαμβάνει μια παρουσία της κλάσης [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) η οποία καθορίζει τα περιθώρια της σελίδας. |
| legend | Λαμβάνει ή ορίζει μια παρουσία της κλάσης [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) η οποία καθορίζει τις επιλογές απόδοσης του υπομνήματος σελίδας. |
