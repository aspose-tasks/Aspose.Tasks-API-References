## PageLegend class

Αναπαριστά ένα υπόμνημα σελίδας που χρησιμοποιείται για την εκτύπωση του έργου.

Ο τύπος PageLegend εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PageLegend() | Αρχικοποιεί μια νέα παρουσία της κλάσης PageLegend |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| left_text | Λαμβάνει ή ορίζει το αριστερά ευθυγραμμισμένο κείμενο που θα εμφανίζεται στο γονικό στοιχείο. |
| centered_text | Λαμβάνει ή ορίζει το κεντραρισμένο κείμενο που θα εμφανίζεται στο γονικό στοιχείο. |
| right_text | Λαμβάνει ή ορίζει το δεξιά ευθυγραμμισμένο κείμενο που θα εμφανίζεται στο γονικό στοιχείο. |
| left_image | Λαμβάνει ή ορίζει την αριστερά ευθυγραμμισμένη εικόνα που θα εμφανίζεται στο γονικό στοιχείο. |
| centered_image | Λαμβάνει ή ορίζει την κεντραρισμένη εικόνα που θα εμφανίζεται στο γονικό στοιχείο. |
| right_image | Λαμβάνει ή ορίζει την εικόνα με δεξιά στοίχιση που θα εμφανίζεται στο γονικό στοιχείο. |
| left_image_size | Λαμβάνει ή ορίζει το εμφανιζόμενο μέγεθος της αριστερής εικόνας. |
| centered_image_size | Λαμβάνει ή ορίζει το εμφανιζόμενο μέγεθος της κεντρικής εικόνας. |
| right_image_size | Λαμβάνει ή ορίζει το εμφανιζόμενο μέγεθος της δεξιάς εικόνας. |
| legend_on | Λαμβάνει ή ορίζει τις σελίδες στις οποίες εμφανίζεται η υπόμνηση. Μπορεί να είναι μία από τις τιμές της απαρίθμησης [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | Λαμβάνει ή ορίζει το πλάτος του αριστερού τμήματος (που περιέχει το όνομα και την ημερομηνία του έργου εξ ορισμού) της υπόμνησης σε εκατοστά. |
