## TaskTextStyleEventArgs class

Αυτή η κλάση αντιπροσωπεύει ένα σύνολο δεδομένων που σχετίζονται με την απόδοση του περιεχομένου του κελιού του πίνακα.

Ο τύπος TaskTextStyleEventArgs εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| cell_text_style | Λαμβάνει ή ορίζει το TextStyle που θα χρησιμοποιηθεί για τη σχεδίαση του περιεχομένου του κελιού. Αυτό το αντικείμενο μπορεί να χρησιμοποιηθεί για την προσαρμογή της εμφάνισης ενός κελιού πίνακα. |
| task | Λαμβάνει [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) που αντιστοιχεί στη τρέχουσα εμφανιζόμενη σειρά. |
| column | Λαμβάνει [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) στην οποία ανήκει το τρέχον εμφανιζόμενο κελί. |
