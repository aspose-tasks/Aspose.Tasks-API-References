## ReportType enumeration

Τύπος του γραφικού αναφοράς του έργου.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| PROJECT_OVERVIEW | Εμφανίζει την ημερομηνία έναρξης και λήξης του έργου, <br/>            το ποσοστό της διάρκειας που έχει ολοκληρωθεί, το ποσοστό ολοκλήρωσης για εργασίες ανώτερου επιπέδου και τα επερχόμενα ορόσημα. |
| COST_OVERVIEW | Εμφανίζει τις ημερομηνίες έναρξης και λήξης του έργου, το τρέχον<br/>            προγραμματισμένο και υπόλοιπο κόστος, % Ολοκλήρωσης και τις τιμές κόστους για εργασίες ανώτερου επιπέδου. |
| WORK_OVERVIEW | Εμφανίζει τη βασική, την πραγματική και την υπόλοιπη εργασία για κάθε εργασία ανώτερου επιπέδου και την εργασία για τους πόρους εργασίας. |
| RESOURCE_OVERVIEW | Εμφανίζει τη βασική, την πραγματική και την υπόλοιπη εργασία ανά πόρο. |
| RESOURCE_COST_OVERVIEW | Εμφανίζει το baseline, το πραγματικό και το υπόλοιπο κόστος ανά πόρο. |
| CRITICAL_TASKS | Εμφανίζει τις εργασίες του έργου που είναι κρίσιμες. |
| LATE_TASKS | Εμφανίζει τις εργασίες του έργου που είναι καθυστερημένες. |
| MILESTONES | Εμφανίζει τα ορόσημα που είναι καθυστερημένα, επερχόμενα και ολοκληρωμένα. |
| UPCOMING_TASK | Εμφανίζει τις εργασίες που πρέπει να ολοκληρωθούν κατά τη διάρκεια της τρέχουσας εβδομάδας και τις εργασίες που ξεκινούν κατά τη διάρκεια της τρέχουσας εβδομάδας. |
| COST_OVERRUNS | Εμφανίζει τη διακύμανση κόστους ανά εργασία και πόρο. |
| TASK_COST_OVERVIEW | Εμφανίζει το αρχικό, το πραγματικό και το εναπομείναν κόστος όλων των εργασιών ανώτερου επιπέδου. |
| OVERALLOCATED_RESOURCES | Εμφανίζει τον αριθμό των εναπομείναντων ωρών εργασίας για υπερκατανεμημένους πόρους. |
| SLIPPING_TASKS | Εμφανίζει τις εργασίες που πρέπει να ολοκληρωθούν μετά τις ημερομηνίες λήξης του αρχικού χρονοδιαγράμματος (πρέπει να οριστεί το αρχικό χρονοδιάγραμμα). |
| BEST_PRACTICE_ANALYZER | Εμφανίζει εργασίες χωρίς πραγματική εργασία, μη εκχωρημένες εργασίες, <br/>            εργασίες με διάρκεια λιγότερη από 8 ώρες και περιλήψεις που έχουν εκχωρηθεί με τους πόρους. |
| BURNDOWN | Περιλαμβάνει διαγράμματα κατανάλωσης εργασίας (work burndown) και διαγράμματα κατανάλωσης εργασιών (task burndown).<br/>            Το διάγραμμα κατανάλωσης εργασίας δείχνει πόση εργασία έχουν ολοκληρώσει οι άνθρωποι, πόση είναι προγραμματισμένη να ολοκληρωθεί πριν από την ημερομηνία λήξης του έργου, <br/>            και την εκτίμηση του αρχικού χρονοδιαγράμματος για το πόση εργασία θα ολοκληρωνόταν σε αυτό το σημείο του έργου.<br/>            Το διάγραμμα κατανάλωσης εργασιών δείχνει τον αριθμό των ολοκληρωμένων εργασιών, τον αριθμό των εναπομείναντων, <br/>            και την εκτίμηση του αρχικού χρονοδιαγράμματος για το πόσες θα ολοκληρώνονταν σε αυτό το σημείο του έργου. |
| CASH_FLOW | Εμφανίζει τα κόστη και τα συσσωρευμένα κόστη ανά τρίμηνο για όλες τις εργασίες ανώτερου επιπέδου. |
