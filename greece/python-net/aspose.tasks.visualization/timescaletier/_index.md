## TimescaleTier class

Αντιπροσωπεύει ένα μοναδικό επίπεδο της κλίμακας χρόνου σε ένα Gantt Chart.

Ο τύπος TimescaleTier εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| TimescaleTier() | Αρχικοποιεί μια νέα παρουσία της κλάσης [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Αρχικοποιεί μια νέα παρουσία της κλάσης TimescaleTier |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| count | Λαμβάνει ή ορίζει το διάστημα μονάδας χρόνου στο οποίο θα εμφανίζονται ετικέτες για το επίπεδο.<br/>            Η προεπιλεγμένη τιμή είναι 1. |
| label | Λαμβάνει ή ορίζει την ετικέτα ημερομηνίας [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) για το επίπεδο κλίμακας χρόνου. |
| alignment | Λαμβάνει ή ορίζει πώς θα ευθυγραμμιστούν οι ετικέτες μέσα σε κάθε χρονική περίοδο του επιπέδου ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν οι ετικέτες του επιπέδου θα βασίζονται στο οικονομικό έτος. |
| show_ticks | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται σημεία σήμανσης που διαχωρίζουν τις χρονικές περιόδους στο επίπεδο. |
| unit | Λαμβάνει ή ορίζει τη μονάδα κλίμακας χρόνου [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) για το επίπεδο κλίμακας χρόνου.<br/>            Η προεπιλεγμένη τιμή είναι |
| render_label_on_each_page | Λαμβάνει ή ορίζει τη σημαία που καθορίζει εάν οι ετικέτες ημερομηνίας πρέπει να αποδίδονται σε κάθε σελίδα όταν μια χρονική περίοδος εκτείνεται σε πολλές σελίδες.<br/>            Εάν η τιμή είναι 'true', όταν η χρονική περίοδος εκτείνεται σε πολλές σελίδες, οι ετικέτες ημερομηνίας για την περίοδο αποδίδονται σε κάθε σελίδα.<br/>            Εάν η τιμή είναι 'false', η ετικέτα ημερομηνίας αποδίδεται μόνο μία φορά σύμφωνα με την τιμή της ιδιότητας [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
