## TimescaleUnit enumeration

Καθορίζει τη μονάδα χρόνου για οποιοδήποτε επίπεδο κλίμακας χρόνου σε ένα Gantt chart ή άλλη προβολή φάσης χρόνου.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NONE | Δείχνει Κανένα. Το επίπεδο κλίμακας χρόνου είναι κρυφό. |
| MINUTES | Δείχνει μονάδα κλίμακας χρόνου λεπτών. |
| ΩΡΕΣ | Δείχνει τη μονάδα χρονικής κλίμακας ΩΡΕΣ. |
| ΗΜΕΡΕΣ | Δείχνει τη μονάδα χρονικής κλίμακας ΗΜΕΡΕΣ. |
| ΕΒΔΟΜΑΔΕΣ | Δείχνει τη μονάδα χρονικής κλίμακας ΕΒΔΟΜΑΔΕΣ. |
| THIRDS_OF_MONTHS | Δείχνει τη μονάδα χρονικής κλίμακας τρίτα του μήνα. |
| ΜΗΝΕΣ | Δείχνει τη μονάδα χρονικής κλίμακας ΜΗΝΕΣ. |
| ΤΡΙΜΗΝΙΑ | Δείχνει τη μονάδα χρονικής κλίμακας τριμήνια ετών. |
| HALF_YEARS | Δείχνει τη μονάδα χρονικής κλίμακας ημιετών. |
| ΕΤΗ | Δείχνει τη μονάδα χρονικής κλίμακας ΕΤΗ. |
