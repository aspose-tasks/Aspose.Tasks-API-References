## TextStyle class

Αλλάξτε το οπτικό στυλ του κειμένου για ένα στοιχείο στην προβολή έργου.

Ο τύπος TextStyle εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| TextStyle() | Αρχικοποιεί μια νέα παρουσία της κλάσης [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) με προεπιλεγμένες ρυθμίσεις. |
| TextStyle(font_size, font_style) | Αρχικοποιεί μια νέα παρουσία της κλάσης TextStyle |
| TextStyle(font_style) | Αρχικοποιεί μια νέα παρουσία της κλάσης [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) με την προεπιλεγμένη γραμματοσειρά και το καθορισμένο μέγεθος και στυλ γραμματοσειράς. |
| TextStyle(font) | Αρχικοποιεί μια νέα παρουσία της κλάσης [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) με τις καθορισμένες ρυθμίσεις γραμματοσειράς. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| font | Λαμβάνει ή ορίζει τη γραμματοσειρά του στυλ κειμένου. |
| color | Λαμβάνει ή ορίζει το χρώμα του κειμένου. |
| item_type | Λαμβάνει ή ορίζει το [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) του στυλ κειμένου. |
| background_pattern | Λαμβάνει ή ορίζει το μοτίβο φόντου του στυλ κειμένου.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Λαμβάνει ή ορίζει το χρώμα φόντου του στυλ κειμένου.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
