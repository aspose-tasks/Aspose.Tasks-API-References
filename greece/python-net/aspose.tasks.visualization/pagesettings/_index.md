## PageSettings class

Αντιπροσωπεύει τις ρυθμίσεις εκτύπωσης για μια σελίδα της προβολής έργου.

Ο τύπος PageSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PageSettings() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Αντιπροσωπεύει τις ρυθμίσεις εκτύπωσης για μια σελίδα της προβολής του έργου. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_portrait | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν ο προσανατολισμός της σελίδας είναι πορτραίτο· επιστρέφει false εάν ο προσανατολισμός είναι τοπίο. |
| adjust_to_percent_of_normal_size | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν θα προσαρμοστεί η εκτύπωση στο καθορισμένο ποσοστό ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) του κανονικού μεγέθους. |
| percent_of_normal_size | Λαμβάνει ή ορίζει ένα ποσοστό του κανονικού μεγέθους για προσαρμογή της εκτύπωσης. |
| pages_in_width | Λαμβάνει ή ορίζει έναν αριθμό σελίδων σε πλάτος που θα εκτυπωθούν. |
| pages_in_height | Λαμβάνει ή ορίζει έναν αριθμό σελίδων σε ύψος που θα εκτυπωθούν. |
| paper_size | Λαμβάνει ή ορίζει ένα μέγεθος χαρτιού. Μπορεί να είναι μία από τις τιμές της απαρίθμησης [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | Λαμβάνει ή ορίζει έναν ακέραιο που αντιπροσωπεύει μία από τις τιμές του PrinterPaperSize ή ένα προσαρμοσμένο αναγνωριστικό μεγέθους σελίδας.<br/>            Αυτή η τιμή μπορεί να χρησιμοποιηθεί για λήψη του PaperSize από τις ρυθμίσεις του λειτουργικού συστήματος |
| first_page_number | Λαμβάνει ή ορίζει τον αριθμό της πρώτης σελίδας για εκτύπωση. |
