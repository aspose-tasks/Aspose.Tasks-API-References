## ProgressLines class

Αντιπροσωπεύει τις γραμμές προόδου σε μια προβολή Gantt Chart.

Ο τύπος ProgressLines εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| ProgressLines() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης ProgressLines |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| display_at_current_date | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζεται η γραμμή προόδου στην τρέχουσα ημερομηνία. |
| display_at_recurring_intervals | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζεται η γραμμή προόδου σε επαναλαμβανόμενα διαστήματα. |
| recurring_interval | Λαμβάνει ή ορίζει το επαναλαμβανόμενο διάστημα.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται οι γραμμές προόδου από την αρχή της ημερομηνίας έναρξης του έργου. |
| begin_at_date | Λαμβάνει ή ορίζει την ημερομηνία από την οποία θα εμφανίζονται οι γραμμές προόδου. |
| display_selected | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται οι γραμμές προόδου στις επιλεγμένες ημερομηνίες. |
| is_baseline_plan | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται οι γραμμές προόδου για το βασικό σχέδιο ή το πραγματικό. |
| show_date | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζεται η ημερομηνία για κάθε γραμμή προόδου. |
| date_format | Λαμβάνει ή ορίζει τη μορφή ημερομηνίας ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Λαμβάνει ή ορίζει τη γραμματοσειρά που χρησιμοποιείται για την ετικέτα της γραμμής προόδου. |
| line_pattern | Λαμβάνει ή ορίζει το μοτίβο γραμμής της τρέχουσας γραμμής προόδου.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Λαμβάνει ή ορίζει το χρώμα γραμμής για την τρέχουσα γραμμή προόδου. |
| progress_point_shape | Λαμβάνει ή ορίζει το σχήμα σημείου προόδου.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Λαμβάνει ή ορίζει το χρώμα του σημείου προόδου. |
| other_line_pattern | Λαμβάνει ή ορίζει το μοτίβο γραμμής για άλλη γραμμή προόδου. |
| other_line_color | Λαμβάνει ή ορίζει το χρώμα άλλης γραμμής προόδου. |
| other_progress_point_shape | Λαμβάνει ή ορίζει το σχήμα σημείου προόδου άλλης γραμμής προόδου. |
| other_progress_point_color | Λαμβάνει ή ορίζει το χρώμα άλλου σημείου προόδου. |
| selected_dates | Λαμβάνει τη λίστα των επιλεγμένων ημερομηνιών για εμφάνιση γραμμών προόδου. |
