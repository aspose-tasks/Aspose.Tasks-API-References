## HeaderFooterInfo class

Αναπαριστά το οπτικό περιεχόμενο της κεφαλίδας, του υποσέλιδου ή του υπομνήματος που χρησιμοποιείται για την εκτύπωση \ rendering των προβολών.

Ο τύπος HeaderFooterInfo εκθέτει τα ακόλουθα μέλη:
