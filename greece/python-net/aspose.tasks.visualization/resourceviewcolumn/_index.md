## ResourceViewColumn class

Η κλάση προβολής του έργου που χρησιμοποιείται στην προβολή ResourceUsage και στην προβολή ResourceSheet.

Ο τύπος ResourceViewColumn εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| ResourceViewColumn(width, field) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης ResourceViewColumn |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| field | Πεδίο στήλης. <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/). |
| name | Λαμβάνει το όνομα της στήλης. |
| string_alignment | Λαμβάνει ή ορίζει την ευθυγράμμιση του κειμένου (μπορεί να είναι μία από τις τιμές της απαρίθμησης [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Λαμβάνει το πλάτος της στήλης. |
| text_style_modification_callback | Λαμβάνει ή ορίζει την κλήση επιστροφής (callback) που μπορεί να χρησιμοποιηθεί για προσαρμογή της εμφάνισης των κελιών της στήλης. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| get_column_text(resource) | Μετατρέπει τον τρέχοντα πόρο σε κείμενο στήλης. |
