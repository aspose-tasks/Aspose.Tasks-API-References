## ProjectView class

Κλάση προβολής του έργου

Ο τύπος ProjectView εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| ProjectView(columns) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [ProjectView](/tasks/python-net/aspose.tasks.visualization/projectview/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| columns | Λαμβάνει τις στήλες προβολής του έργου. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| get_default_gantt_chart_view() | Περιλαμβάνει στήλες id, δείκτες, όνομα, διάρκεια, έναρξη και λήξη εργασίας. |
| get_default_task_sheet_view() | Περιλαμβάνει id, δείκτες, όνομα, διάρκεια, έναρξη, λήξη, προγόνους και στήλες εργασιών ονομάτων πόρων. |
| get_default_resource_usage_view() | Περιλαμβάνει Uid, όνομα, έναρξη, λήξη και στήλες πόρων εργασίας. |
| get_default_assignment_view() | Περιλαμβάνει Uid, όνομα εργασίας, όνομα πόρου, εργασία και στήλες ανάθεσης διάρκειας. |
| get_default_resource_sheet_view() | Περιλαμβάνει Uid, όνομα πόρου, τύπο, ετικέτα υλικού, αρχικά, ομάδα, μέγιστες μονάδες,<br/>            τυπική τιμή, τιμή υπερωριών, κόστος ανά χρήση, συσσωμάτωση, βασικό ημερολόγιο και στήλες κώδικα πόρου. |
