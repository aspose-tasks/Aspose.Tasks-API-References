## Gridlines class

Αναπαριστά τις γραμμές πλέγματος που εμφανίζονται σε προβολή GanttChart.

Ο τύπος Gridlines εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Gridlines() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης Gridlines |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| interval | Λαμβάνει ή ορίζει τον αριθμό από 0 έως 99 που καθορίζει το διάστημα μεταξύ των γραμμών πλέγματος. |
| interval_color | Λαμβάνει ή ορίζει το χρώμα των δευτερευουσών γραμμών πλέγματος. |
| interval_pattern | Λαμβάνει ή ορίζει το μοτίβο γραμμής για δευτερεύουσες γραμμές πλέγματος. |
| normal_color | Λαμβάνει ή ορίζει το χρώμα των κανονικών γραμμών πλέγματος. |
| normal_pattern | Λαμβάνει ή ορίζει το μοτίβο γραμμής για κανονικές γραμμές πλέγματος. |
| τύπος | Λαμβάνει ή ορίζει τον τύπο της γραμμής πλέγματος. |
