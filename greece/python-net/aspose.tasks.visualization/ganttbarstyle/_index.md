## GanttBarStyle class

Αναπαριστά ένα στυλ μπάρας που χρησιμοποιείται από το MSP στην προβολή Διάγραμμα Gantt.

Ο τύπος GanttBarStyle εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| GanttBarStyle() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
