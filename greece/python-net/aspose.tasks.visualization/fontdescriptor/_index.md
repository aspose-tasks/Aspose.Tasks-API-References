## FontDescriptor class

Αναπαριστά πληροφορίες γραμματοσειράς.

Ο τύπος FontDescriptor εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| FontDescriptor(font_family, size) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης FontDescriptor |
| FontDescriptor(font_family, size, style) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης FontDescriptor |
| FontDescriptor(font, style) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) με την καθορισμένη οικογένεια γραμματοσειράς, μέγεθος και στυλ. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| font_family | Λαμβάνει το όνομα της οικογένειας γραμματοσειράς. |
| size | Λαμβάνει το μέγεθος της γραμματοσειράς. |
| style | Λαμβάνει το στυλ της γραμματοσειράς. |
