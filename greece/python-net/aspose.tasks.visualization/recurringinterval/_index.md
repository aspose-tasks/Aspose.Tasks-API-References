## RecurringInterval class

Αντιπροσωπεύει τα επαναλαμβανόμενα διαστήματα που χρησιμοποιούνται στις γραμμές προόδου μιας προβολής Gantt Chart.

Ο τύπος RecurringInterval παρέχει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| RecurringInterval() | Αρχικοποιεί μια νέα παρουσία της κλάσης RecurringInterval |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| interval | Λαμβάνει ή ορίζει το επαναλαμβανόμενο διάστημα.<br/>            Μπορεί να είναι οποιαδήποτε τιμή του τύπου [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | Λαμβάνει ή ορίζει τον αριθμό της ημερήσιας ημέρας. |
| daily_workday | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν μια ημέρα είναι εργάσιμη για τις γραμμές προόδου ανά ημέρα. |
| weekly_week_number | Λαμβάνει ή ορίζει τον αριθμό εβδομάδας για τις γραμμές προόδου εβδομαδιαίας. |
| monthly_day | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται οι γραμμές προόδου μηνιαίας ανά ημέρα. |
| monthly_day_day_number | Λαμβάνει ή ορίζει τον αριθμό ημέρας των μηνιαίων γραμμών προόδου. |
| monthly_day_month_number | Λαμβάνει ή ορίζει τον αριθμό μήνα των μηνιαίων γραμμών προόδου. |
| monthly_first_last | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εμφανίζονται οι γραμμές προόδου με την πρώτη ή την τελευταία προκαθορισμένη ημέρα. |
| monthly_first_last_month_number | Λαμβάνει ή ορίζει τον αριθμό μήνα των γραμμών προόδου, οι οποίες εμφανίζονται με την πρώτη ή την τελευταία προκαθορισμένη ημέρα. |
| monthly_first_last_day | Λαμβάνει ή ορίζει τον τύπο της πρώτης ή της τελευταίας ημέρας των μηνιαίων γραμμών προόδου. |
| weekly_days | Λαμβάνει μια λίστα ημερών για τις γραμμές προόδου εβδομαδιαίας. |
