## PageViewSettings class

Αντιπροσωπεύει τις ρυθμίσεις εκτύπωσης για μια προβολή έργου.

Ο τύπος PageViewSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PageViewSettings() | Αρχικοποιεί μια νέα παρουσία της κλάσης PageViewSettings |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| first_columns_count | Λαμβάνει ή ορίζει τον αριθμό των πρώτων στηλών που θα εκτυπωθούν σε όλες τις σελίδες. |
| fit_timescale_to_end_of_page | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν θα προσαρμοστεί η κλίμακα χρόνου στο τέλος μιας σελίδας κατά την εκτύπωση. |
| print_all_sheet_columns | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν θα εκτυπωθούν όλες οι στήλες φύλλου μιας προβολής. |
| print_blank_pages | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν θα εκτυπωθούν κενές σελίδες μιας προβολής. |
| print_first_columns_count_on_all_pages | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν θα εκτυπωθεί ένας καθορισμένος αριθμός πρώτων στηλών σε όλες τις σελίδες. |
| print_notes | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν θα εκτυπωθούν σημειώσεις. |
