## BarStyle class

Αλλάξτε το οπτικό στυλ της μπάρας για το στοιχείο στην προβολή του έργου.

Ο τύπος BarStyle εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| BarStyle() | Αρχικοποιεί ένα νέο παράδειγμα της κλάσης [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| bar_color | Λαμβάνει ή ορίζει το aspose.pydrawing.Color του στυλ ράβδου. |
| start_shape_color | Λαμβάνει ή ορίζει το aspose.pydrawing.Color του σχήματος στην αρχή της ράβδου. |
| start_shape_type | Λαμβάνει ή ορίζει έναν τύπο του αρχικού σχήματος. |
| end_shape_color | Λαμβάνει ή ορίζει το aspose.pydrawing.Color του σχήματος στο τέλος της ράβδου. |
| end_shape_type | Λαμβάνει ή ορίζει έναν τύπο του σχήματος λήξης.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | Λαμβάνει ή ορίζει το [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) του στυλ ράβδου. |
| bar_shape | Λαμβάνει ή ορίζει το [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) του στυλ ράβδου. |
| start_shape | Λαμβάνει ή ορίζει το [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) στην αρχή της ράβδου. |
| end_shape | Λαμβάνει ή ορίζει το [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) στο τέλος της ράβδου. |
| text_style | Λαμβάνει ή ορίζει το στυλ του κειμένου της ράβδου. |
| left_field | Λαμβάνει ή ορίζει ένα πεδίο που θα εμφανίζεται στα αριστερά της ράβδου. |
| top_field | Λαμβάνει ή ορίζει ένα πεδίο που θα εμφανίζεται στην κορυφή της ράβδου. |
| right_field | Λαμβάνει ή ορίζει ένα πεδίο που θα εμφανίζεται στα δεξιά της ράβδου. |
| bottom_field | Λαμβάνει ή ορίζει ένα πεδίο που θα εμφανίζεται στο κάτω μέρος της μπάρας. |
| inside_field | Λαμβάνει ή ορίζει ένα πεδίο που θα εμφανίζεται μέσα στη μπάρα. |
| from_address | Λαμβάνει ή ορίζει τη θέση του σημείου εκκίνησης της γραμμής gantt.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | Λαμβάνει ή ορίζει τη θέση του σημείου λήξης της μπάρας gantt. |
