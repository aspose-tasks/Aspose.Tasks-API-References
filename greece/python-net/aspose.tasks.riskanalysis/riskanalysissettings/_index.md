## RiskAnalysisSettings class

Καθορίζει τις ρυθμίσεις για την εκτέλεση ανάλυσης κινδύνου.

Ο τύπος RiskAnalysisSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| RiskAnalysisSettings() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| iterations_count | Λαμβάνει ή ορίζει τον αριθμό των επαναλήψεων που θα χρησιμοποιηθούν στην προσομοίωση Monte Carlo.<br/>            Η προεπιλεγμένη τιμή είναι 100. |
| patterns | Λαμβάνει μια συλλογή που περιέχει τις εμφανίσεις της κλάσης [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
