## RiskAnalyzer class

Πραγματοποιεί προσομοίωση Monte Carlo βασισμένη στις καθορισμένες ρυθμίσεις ανάλυσης κινδύνου.

Ο τύπος RiskAnalyzer εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| RiskAnalyzer(settings) | Αρχικοποιεί μια νέα παρουσία της κλάσης [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| settings | Λαμβάνει ή ορίζει το αντικείμενο της κλάσης [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) που ορίζει τις απαραίτητες ρυθμίσεις για την ανάλυση κινδύνου. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| analyze(project) | Πραγματοποιεί ανάλυση κινδύνου για το καθορισμένο έργο. Η ανάλυση βασίζεται στην προσομοίωση Monte Carlo και το αποτέλεσμα είναι μια παρουσία της κλάσης [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/). |
