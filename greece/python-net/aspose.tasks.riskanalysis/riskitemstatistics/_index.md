## RiskItemStatistics class

Αναπαριστά ένα στοιχείο που αποθηκεύει στατιστικά δεδομένα για την εργασία του αναλυόμενου έργου.

Ο τύπος RiskItemStatistics εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| item_type | Λαμβάνει μια τιμή της απαρίθμησης [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/). |
| minimum | Λαμβάνει την ελάχιστη τιμή που δημιουργήθηκε κατά τη διάρκεια της προσομοίωσης Monte Carlo. |
| maximum | Λαμβάνει τη μέγιστη τιμή που δημιουργήθηκε κατά τη διάρκεια της προσομοίωσης Monte Carlo. |
| expected_value | Λαμβάνει την αναμενόμενη τιμή του στοιχείου κινδύνου. |
| standard_deviation | Λαμβάνει την τυπική απόκλιση του στοιχείου κινδύνου. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| get_percentile(percent) | Λαμβάνει μια τιμή κάτω από την οποία ένα καθορισμένο ποσοστό των παραγόμενων δειγμάτων πέφτει. |
