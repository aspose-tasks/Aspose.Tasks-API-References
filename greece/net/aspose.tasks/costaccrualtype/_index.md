## CostAccrualType enumeration

Καθορίζει τον τύπο ενός κόστους συσσωμάτωσης.

```csharp
public enum CostAccrualType
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Undefined | `-1` | Δηλώνει ότι η μη ορισμένη τιμή σημαίνει ότι το πεδίο δεν ήταν ορισμένο στο αρχικό αρχείο έργου. |
| Start | `0` | Δηλώνει τύπο κόστους συσσωμάτωσης Έναρξης. |
| Prorated | `1` | Δηλώνει τύπο κόστους συσσωμάτωσης Αναλογικής. |
| End | `2` | Δηλώνει τύπο κόστους συσσωμάτωσης Λήξης. |
| Invalid | `3` | Δηλώνει μη έγκυρο τύπο κόστους συσσωμάτωσης. |

## Παρατηρήσεις

Κατά την εξαγωγή σε XML, οι μη ορισμένες τιμές θα αφαιρεθούν από το τελικό XML.

## Παραδείγματα

Δείχνει πώς και πότε τα τυπικά και υπερωριακά κόστη πόρων πρέπει να χρεώνονται ή να συσσωρεύονται (μέθοδος συσσωμάτωσης: Καθορίζει πότε το κόστος για έναν πόρο προκύπτει και πότε τα πραγματικά κόστη χρεώνονται σε ένα έργο. Μπορείτε να προκύψετε κόστη στην αρχή [Start] ή στο τέλος [End] μιας εργασίας ή να τα αναλογίσετε [Prorated] κατά τη διάρκεια της εργασίας.), στο κόστος μιας εργασίας (CostAccrualType.End).

```csharp
var project = new Project(DataDir + "Project2.mpp");
var resource = project.Resources.GetById(1);
// ορίστε τύπο κόστους συσσωμάτωσης
// εάν επιλέξετε την επιλογή Λήξη, τα κόστη δεν συσσωρεύονται μέχρι το υπόλοιπο έργο να είναι μηδέν.
resource.Set(Rsc.AccrueAt, CostAccrualType.End);
// εργαστείτε με το έργο...
```
