## PrimaveraReadOptions.ReadBaselineProjects property

Λαμβάνει ή ορίζει μια σημαία που καθορίζει εάν τα βασικά (baseline) έργα πρέπει να φορτωθούν. Η προεπιλεγμένη τιμή είναι true.

```csharp
public bool ReadBaselineProjects { get; set; }
```

## Παρατηρήσεις

Η σημαία ισχύει για αρχεία Primavera XML που περιέχουν baseline projects (τα baseline δεν υποστηρίζονται από τη μορφή XER). Η επιλογή μπορεί να οριστεί σε false για να επιταχύνει τη φόρτωση ενός μεγάλου έργου με baseline όταν δεν χρειάζονται τα δεδομένα baseline.
