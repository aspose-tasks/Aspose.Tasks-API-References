## FontResolveEventArgs.ResolvedFontName property

Επιστρέφει ή ορίζει το όνομα της επιλυμένης γραμματοσειράς. Μπορεί να οριστεί για να ελέγχει τις γραμματοσειρές που χρησιμοποιούνται για την απόδοση μιας προβολής.

```csharp
public string ResolvedFontName { get; set; }
```

### Τιμή Επιστροφής

Όνομα της ζητούμενης γραμματοσειράς εάν βρεθεί ή όνομα της εναλλακτικής γραμματοσειράς ή null εάν η γραμματοσειρά δεν μπορεί να βρεθεί.
