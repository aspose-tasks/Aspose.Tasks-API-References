## ReportType enumeration

Τύπος του γραφικού αναφοράς του έργου.

```csharp
public enum ReportType
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| ProjectOverview | `0` | Εμφανίζει την ημερομηνία έναρξης και λήξης του έργου, το ποσοστό της διάρκειας που έχει ολοκληρωθεί, το ποσοστό ολοκλήρωσης για τις εργασίες ανώτερου επιπέδου και τα επερχόμενα ορόσημα. |
| CostOverview | `1` | Εμφανίζει τις ημερομηνίες έναρξης και λήξης του έργου, το τρέχον προγραμματισμένο και υπόλοιπο κόστος, το % ολοκλήρωσης και τις τιμές κόστους για τις εργασίες ανώτερου επιπέδου. |
| WorkOverview | `2` | Εμφανίζει τη βασική, την πραγματική και την υπόλοιπη εργασία για κάθε εργασία ανώτερου επιπέδου και την εργασία για τους πόρους εργασίας. |
| ResourceOverview | `3` | Εμφανίζει τη βασική, την πραγματική και την υπόλοιπη εργασία ανά πόρο. |
| ResourceCostOverview | `4` | Εμφανίζει το βασικό, το πραγματικό και το υπόλοιπο κόστος ανά πόρο. |
| CriticalTasks | `5` | Εμφανίζει τις εργασίες του έργου που είναι κρίσιμες. |
| LateTasks | `6` | Εμφανίζει τις εργασίες του έργου που είναι καθυστερημένες. |
| Milestones | `7` | Εμφανίζει τα ορόσημα που είναι καθυστερημένα, επερχόμενα και ολοκληρωμένα. |
| UpcomingTask | `8` | Εμφανίζει τις εργασίες που λήγουν κατά τη διάρκεια της τρέχουσας εβδομάδας και τις εργασίες που ξεκινούν κατά τη διάρκεια της τρέχουσας εβδομάδας. |
| CostOverruns | `9` | Εμφανίζει τη διακύμανση κόστους ανά εργασία και πόρο. |
| TaskCostOverview | `10` | Εμφανίζει το βασικό, το πραγματικό και το υπόλοιπο κόστος όλων των εργασιών ανώτερου επιπέδου. |
| OverallocatedResources | `11` | Εμφανίζει τον αριθμό των υπόλοιπων ωρών εργασίας για τους υπερκατανεμημένους πόρους. |
| SlippingTasks | `12` | Εμφανίζει τις εργασίες που πρέπει να ολοκληρωθούν μετά τις βασικές ημερομηνίες λήξης τους (πρέπει να οριστεί η βάση). |
| BestPracticeAnalyzer | `13` | Εμφανίζει εργασίες χωρίς πραγματική εργασία, μη ανατεθειμένες εργασίες, εργασίες με διάρκεια λιγότερη από 8 ώρες και περιλήψεις που έχουν ανατεθεί στους πόρους. |
| Burndown | `14` | Περιλαμβάνει διαγράμματα κατανάλωσης εργασίας και εργασιών. Το διάγραμμα κατανάλωσης εργασίας δείχνει πόση εργασία έχουν ολοκληρώσει οι άνθρωποι, πόση είναι προγραμματισμένη να ολοκληρωθεί πριν από την ημερομηνία λήξης του έργου, και την εκτίμηση βάσης για το πόση εργασία θα ολοκληρωθεί σε αυτό το σημείο του έργου. Το διάγραμμα κατανάλωσης εργασιών δείχνει τον αριθμό των ολοκληρωμένων εργασιών, τον αριθμό των υπολειπόμενων, και την εκτίμηση βάσης για το πόσες θα ολοκληρωθούν σε αυτό το σημείο του έργου. |
| CashFlow | `15` | Εμφανίζει τα κόστη και τα συσσωρευμένα κόστη ανά τρίμηνο για όλες τις εργασίες ανώτερου επιπέδου. |

## Παραδείγματα

Δείχνει πώς να αποθηκεύσετε την αναφορά εκκαθάρισης έργου σε μορφή PDF στη συγκεκριμένη ροή.

```csharp
var project = new Project(DataDir + @"Homemoveplan.mpp");
using (var stream = new FileStream(OutDir + "Burndown_out.pdf", FileMode.Create))
{
    project.SaveReport(stream, ReportType.Burndown);
}
```
