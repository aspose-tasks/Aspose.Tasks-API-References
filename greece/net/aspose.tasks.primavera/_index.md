Περιέχει κλάσεις που είναι απαραίτητες για εργασία με μορφές ειδικές για Primavera (XER, Primavera XML).

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Αντιπροσωπεύει σύντομες πληροφορίες για ένα έργο που φορτώθηκε από μορφή Primavera. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [PrimaveraActivityType](./primaveraactivitytype/) | Καθορίζει τον τύπο δραστηριότητας Primavera. |
| [PrimaveraConstraintType](./primaveraconstrainttype/) | Καθορίζει έναν τύπο περιορισμού της δραστηριότητας. |
| [PrimaveraDurationType](./primaveradurationtype/) | Καθορίζει τον τύπο διάρκειας της δραστηριότητας Primavera. |
| [PrimaveraPercentCompleteType](./primaverapercentcompletetype/) | Καθορίζει την τιμή του πεδίου '% Complete Type' για δραστηριότητες Primavera. |
| [PrimaveraRelationshipLagCalendar](./primaverarelationshiplagcalendar/) | Καθορίζει ποιο ημερολόγιο να χρησιμοποιηθεί για τον προγραμματισμό του καθυστέρησης σχέσης (Relationship Lag) σε έργα Primavera. |
