## PrimaveraProjectInfo.ExportFlag property

Λαμβάνει τη σημαία εξαγωγής του έργου. Όταν ένα έργο επιλέγεται για εξαγωγή στο Primavera, το ExportFlag του είναι true. Ορισμένα έργα που δεν έχουν επιλεγεί ρητά για εξαγωγή ενδέχεται να εξαχθούν σε αρχείο XER λόγω της σχέσης τους με το εξαγόμενο έργο.

```csharp
public bool ExportFlag { get; }
```
