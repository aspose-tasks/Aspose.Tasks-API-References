Περιέχει κλάσεις για δημιουργία Αναφοράς Ανάλυσης Κινδύνου.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | Αντιπροσωπεύει ένα αποτέλεσμα ανάλυσης κινδύνου. |
| [RiskAnalysisSettings](./riskanalysissettings/) | Καθορίζει τις ρυθμίσεις για την εκτέλεση ανάλυσης κινδύνου. |
| [RiskAnalyzer](./riskanalyzer/) | Πραγματοποιεί προσομοίωση Monte Carlo βασισμένη στις καθορισμένες ρυθμίσεις ανάλυσης κινδύνου. |
| [RiskItemStatistics](./riskitemstatistics/) | Αντιπροσωπεύει ένα στοιχείο που αποθηκεύει στατιστικά δεδομένα για την εργασία του αναλυθέντος έργου. |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | Αντιπροσωπεύει μια συλλογή που περιέχει τις περιπτώσεις της κλάσης [`RiskItemStatistics`](../aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](./riskpattern/) | Αντιπροσωπεύει ένα πρότυπο κινδύνου για μια εργασία έργου. |
| [RiskPatternCollection](./riskpatterncollection/) | Αντιπροσωπεύει μια συλλογή που περιέχει τις περιπτώσεις της κλάσης [`RiskPattern`](../aspose.tasks.riskanalysis/riskpattern/). |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [ConfidenceLevel](./confidencelevel/) | Καθορίζει τα υποστηριζόμενα επίπεδα εμπιστοσύνης που χρησιμοποιούνται στην ανάλυση κινδύνου και αντιστοιχούν στο ποσοστό του χρόνου που οι πραγματικές τιμές θα βρίσκονται εντός των αισιόδοξων και απαισιόδοξων εκτιμήσεων. |
| [ProbabilityDistributionType](./probabilitydistributiontype/) | Καθορίζει τους τύπους των υποστηριζόμενων κατανομών πιθανότητας. |
| [RiskItemType](./riskitemtype/) | Καθορίζει τα πεδία εργασιών για τα οποία συλλέγονται στατιστικές πληροφορίες κατά την ανάλυση κινδύνου. |
