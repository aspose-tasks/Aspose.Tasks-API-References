## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Επιτρέπει τον καθορισμό παραμέτρων της εξισορρόπησης πόρων. |
| [LevelingResult](./levelingresult/) | Αντιπροσωπεύει τα αποτελέσματα της εξισορρόπησης πόρων. |
| [ResourceLeveler](./resourceleveler/) | Περιέχει μεθόδους εξισορρόπησης πόρων. |

| Απαρίθμηση | Περιγραφή |
