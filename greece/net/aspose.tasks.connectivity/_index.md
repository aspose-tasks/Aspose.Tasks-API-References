Περιέχει κλάσεις για εργασία με βάσεις δεδομένων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DbSettings](./dbsettings/) | Επιτρέπει τον καθορισμό ρυθμίσεων για ανάγνωση από τη βάση δεδομένων του έργου. |
| [MpdSettings](./mpdsettings/) | Επιτρέπει τον καθορισμό των απαραίτητων επιλογών για ανάγνωση δεδομένων έργου από τη μορφή MPD (μορφή αρχείου βάσης δεδομένων MS Access). |
| [MspDbSettings](./mspdbsettings/) | Επιτρέπει τον καθορισμό των απαραίτητων επιλογών για ανάγνωση δεδομένων έργου από τη βάση δεδομένων του MS Project Server. |
| [PrimaveraDbSettings](./primaveradbsettings/) | Επιτρέπει τον καθορισμό των απαραίτητων επιλογών για ανάγνωση δεδομένων έργου από τη βάση δεδομένων Primavera. |
