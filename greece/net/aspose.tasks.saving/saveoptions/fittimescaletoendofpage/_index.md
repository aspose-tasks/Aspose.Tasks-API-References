## SaveOptions.FitTimescaleToEndOfPage property

Λαμβάνει ή ορίζει εάν ένα τμήμα ημερολογίου μιας προβολής πρέπει να αποδοθεί στο τέλος (δεξιά πλευρά) της τελευταίας σελίδας. Εάν η τιμή είναι ψευδής, το τμήμα ημερολογίου αποδίδεται ακριβώς μέχρι το EndDate, ακόμη και αν υπάρχει κενός χώρος στη σελίδα.

```csharp
public bool FitTimescaleToEndOfPage { get; set; }
```
