### getExportFlag() {#getExportFlag--}
```
public final boolean getExportFlag()
```


Λαμβάνει τη σημαία εξαγωγής του έργου. Όταν ένα έργο επιλέγεται για εξαγωγή στο Primavera, η ExportFlag του είναι αληθής. Ορισμένα έργα που δεν έχουν επιλεγεί ρητά για εξαγωγή μπορεί να εξαχθούν σε αρχείο XER λόγω της σχέσης τους με το εξαγόμενο έργο.

**Returns:**
boolean - σημαία εξαγωγής του έργου.
