Καθορίζει την ευθυγράμμιση μιας συμβολοσειράς κειμένου σε σχέση με το ορθογώνιο διάταξης της.
## Πεδία

| Πεδίο | Περιγραφή |
| --- | --- |
| [Center](#Center) | Καθορίζει ότι το κείμενο ευθυγραμμίζεται στο κέντρο του ορθογωνίου διάταξης. |
| [Far](#Far) | Καθορίζει ότι το κείμενο ευθυγραμμίζεται μακριά από τη θέση προέλευσης του ορθογωνίου διάταξης. |
| [Near](#Near) | Καθορίζει ότι το κείμενο ευθυγραμμίζεται κοντά στη διάταξη. |
### Center {#Center}
```
public static final int Center
```


Καθορίζει ότι το κείμενο ευθυγραμμίζεται στο κέντρο του ορθογωνίου διάταξης.

### Far {#Far}
```
public static final int Far
```


Καθορίζει ότι το κείμενο ευθυγραμμίζεται μακριά από τη θέση προέλευσης του ορθογωνίου διάταξης. Σε διάταξη από αριστερά προς δεξιά, η μακριά θέση είναι δεξιά. Σε διάταξη από δεξιά προς αριστερά, η μακριά θέση είναι αριστερά.

### Near {#Near}
```
public static final int Near
```


Καθορίζει ότι το κείμενο ευθυγραμμίζεται κοντά στη διάταξη. Σε διάταξη από αριστερά προς δεξιά, η κοντινή θέση είναι αριστερά. Σε διάταξη από δεξιά προς αριστερά, η κοντινή θέση είναι δεξιά.
