### getAdjustToPercentOfNormalSize() {#getAdjustToPercentOfNormalSize--}
```
public final boolean getAdjustToPercentOfNormalSize()
```


Λαμβάνει μια τιμή που υποδεικνύει εάν θα προσαρμόσει την εκτύπωση στο καθορισμένο ποσοστό (`PercentOfNormalSize`([getPercentOfNormalSize()](../../com.aspose/tasks/pagesettings\#getPercentOfNormalSize--)/ [setPercentOfNormalSize(int)](../../com.aspose/tasks/pagesettings\#setPercentOfNormalSize-int-))) του κανονικού μεγέθους.

--------------------

Δεν είναι αποτελεσματικό όταν το έργο αποδίδεται σε μορφή HTML.

**Returns:**
boolean - μια τιμή που υποδεικνύει εάν θα προσαρμόσει την εκτύπωση στο καθορισμένο ποσοστό (`PercentOfNormalSize`([getPercentOfNormalSize()](../../com.aspose/tasks/pagesettings\#getPercentOfNormalSize--)/ [setPercentOfNormalSize(int)](../../com.aspose/tasks/pagesettings\#setPercentOfNormalSize-int-))) του κανονικού μεγέθους.

### isPortrait() {#isPortrait--}
```
public final boolean isPortrait()
```


Λαμβάνει μια τιμή που υποδεικνύει εάν ο προσανατολισμός της σελίδας είναι κατακόρυφος· επιστρέφει false εάν ο προσανατολισμός της σελίδας είναι οριζόντιος.

--------------------

Ισχύει κατά τη διαδικασία απόδοσης όταν SaveOptions.getPageSize() == PageSize.DefinedInView.

**Returns:**
boolean - τιμή που υποδεικνύει αν ο προσανατολισμός της σελίδας είναι πορτραίτο· επιστρέφει false εάν ο προσανατολισμός είναι τοπίο.
