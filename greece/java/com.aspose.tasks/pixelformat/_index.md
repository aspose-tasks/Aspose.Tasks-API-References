### Alpha {#Alpha}

Τα δεδομένα εικονοστοιχείων περιέχουν τιμές άλφα που δεν είναι προπολλαπλασιασμένες.

### Canonical {#Canonical}
```
public static final int Canonical
```


Η προεπιλεγμένη μορφή pixel είναι 32 bits ανά pixel. Η μορφή καθορίζει βάθος χρώματος 24-bit και κανάλι alpha 8-bit.

### Format16bppArgb1555 {#Format16bppArgb1555}
```
public static final int Format16bppArgb1555
```


Η μορφή pixel είναι 16 bits ανά pixel. Οι πληροφορίες χρώματος καθορίζουν 32.768 αποχρώσεις χρώματος, από τις οποίες 5 bits είναι κόκκινο, 5 bits είναι πράσινο, 5 bits είναι μπλε και 1 bit είναι alpha.
