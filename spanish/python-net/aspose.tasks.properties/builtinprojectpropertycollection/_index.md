## BuiltInProjectPropertyCollection class

Representa una colección de propiedades de proyecto incorporadas.

El tipo BuiltInProjectPropertyCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| título | Obtiene o establece el título de un proyecto. |
| subject | Obtiene o establece el asunto de un proyecto. |
| author | Obtiene o establece el autor de un proyecto. |
| manager | Obtiene o establece el gestor de un proyecto. |
| company | Obtiene o establece la empresa de un proyecto. |
| category | Obtiene o establece la categoría de un proyecto. |
| keywords | Obtiene o establece las palabras clave de un proyecto. |
| comments | Obtiene o establece los comentarios de un proyecto. |
| hyperlink_base | Obtiene o establece la base de hipervínculo de un proyecto. |
