## PrimaveraProjectInfo class

Representa información breve sobre un proyecto cargado desde el formato Primavera.

El tipo PrimaveraProjectInfo expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| uid | Obtiene el UID del proyecto. |
| name | Obtiene el nombre del proyecto. |
| short_name | Obtiene el nombre corto del proyecto (ID del proyecto). |
| export_flag | Obtiene la bandera de exportación del proyecto. Cuando un proyecto se selecciona para exportar en Primavera, su ExportFlag es true.<br/>            Algunos proyectos no seleccionados explícitamente para exportar pueden exportarse a un archivo XER debido a su relación con el proyecto exportado. |
