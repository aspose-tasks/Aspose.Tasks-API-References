## PrimaveraXmlSaveOptions class

Permite especificar opciones adicionales al guardar el proyecto en formato Primavera XML.

El tipo PrimaveraXmlSaveOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PrimaveraXmlSaveOptions() | Inicializa una nueva instancia de la clase [PrimaveraXmlSaveOptions](/tasks/python-net/aspose.tasks.saving/primaveraxmlsaveoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| save_format | Obtiene o establece el formato en el que se guardará el documento si se utiliza este objeto de opciones de guardado. |
| save_root_task | Obtiene o establece un valor que indica si se debe guardar una tarea raíz o no. |
| skip_summary_assignments | Obtiene o establece un valor que indica si se deben omitir las asignaciones de recursos a tareas resumen durante la exportación. |
