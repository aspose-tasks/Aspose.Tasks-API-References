## CsvOptions class

Permite especificar opciones adicionales al guardar el proyecto en CSV.

El tipo CsvOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| CsvOptions() | Inicializa una nueva instancia de la clase [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) que se puede usar para guardar el proyecto en formato CSV. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| save_format | Obtiene o establece el formato en el que se guardará el documento si se utiliza este objeto de opciones de guardado. |
| data_category | Obtiene o establece una categoría de datos para guardar. |
| encoding | Obtiene o establece una codificación con la que guardar el CSV. |
| include_headers | Obtiene o establece un valor que indica si se deben incluir encabezados o no (el valor predeterminado es TRUE). |
| text_delimiter | Obtiene o establece un delimitador de texto. |
| view | Obtiene o establece una lista de las columnas de vista ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) para guardar en formato XLSX.<br/>            Si no se establece, se guardan las columnas predeterminadas. |
