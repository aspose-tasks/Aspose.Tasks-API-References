## PrimaveraSaveOptions class

Permite especificar opciones adicionales al guardar el proyecto en formato Primavera XER.

El tipo PrimaveraSaveOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PrimaveraSaveOptions() | Inicializa una nueva instancia de la clase [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| save_format | Obtiene o establece el formato en el que se guardará el documento si se utiliza este objeto de opciones de guardado. |
| activity_id_increment | Obtiene o establece el incremento utilizado al renumerar los IDs de actividad. |
| activity_id_prefix | Obtiene o establece el prefijo utilizado al renumerar los IDs de actividad. |
| activity_id_suffix | Obtiene o establece el sufijo utilizado al renumerar los IDs de actividad. |
| renumber_activity_ids | Obtiene o establece un valor que indica si es necesario renumerar los IDs de actividad. |
| skip_summary_assignments | Obtiene o establece un valor que indica si se deben omitir las asignaciones de recursos a tareas resumen durante la exportación. |
