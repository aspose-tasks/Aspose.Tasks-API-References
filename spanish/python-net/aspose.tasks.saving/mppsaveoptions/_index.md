## MPPSaveOptions class

Permite especificar opciones adicionales al guardar los datos del proyecto en MPP.

El tipo MPPSaveOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| MPPSaveOptions() | Inicializa una nueva instancia de la clase [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| save_format | Obtiene o establece el formato en el que se guardará el documento si se utiliza este objeto de opciones de guardado. |
| remove_invalid_assignments | Obtiene o establece un valor que indica si se deben eliminar asignaciones de recursos inválidas al guardar en MPP. |
| write_view_data | Obtiene o establece un valor que indica si se deben escribir datos de vista al guardar un proyecto en formato MPP. |
| write_filters | Obtiene o establece un valor que indica si se deben escribir datos de filtro al guardar un proyecto en formato MPP. |
| write_groups | Obtiene o establece un valor que indica si se deben escribir los datos de grupos al guardar un proyecto en formato MPP. |
| clear_vba | Obtiene o establece un valor que indica si se deben eliminar los datos de macros VBA existentes al guardar un proyecto en formato MPP. |
| write_vba | Obtiene o establece un valor que indica si se deben actualizar los datos de macros VBA existentes en el archivo MPP.<br/>            Actualmente se admite la escritura de VbaModule.SourceCode. |
| protection_password | Obtiene o establece una contraseña que se utiliza para proteger el archivo MPP resultante. Actualmente es compatible con los formatos de MS Project 2010 y posteriores. |
