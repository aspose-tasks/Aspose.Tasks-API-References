## XlsxOptions class

Permite especificar opciones adicionales al renderizar las páginas del proyecto en XLSX.

El tipo XlsxOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| XlsxOptions() | Inicializa una nueva instancia de la clase [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) que se puede usar para guardar el proyecto en formato XLSX. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| save_format | Obtiene o establece el formato en el que se guardará el documento si se utiliza este objeto de opciones de guardado. |
| resource_view | Obtiene o establece una lista de las columnas de vista de recursos para renderizar ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Obtiene o establece una lista de las columnas de vista de asignaciones para renderizar ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| encoding | Obtiene o establece la codificación del archivo XLSX resultante. El valor predeterminado es . |
| view | Obtiene o establece una lista de las columnas de vista ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) para guardar en formato XLSX.<br/>            Si no se establece, se guardan las columnas predeterminadas. |
