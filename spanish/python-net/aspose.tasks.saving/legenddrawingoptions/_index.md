## LegendDrawingOptions enumeration

Especifica las opciones posibles usadas al renderizar la leyenda de la vista.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NO_LEGEND | No se renderiza ninguna leyenda. |
| AFTER_LAST_PAGE | La leyenda se renderiza en una página separada después de la última página de las páginas del proyecto. |
| ON_EVERY_PAGE | La leyenda se renderiza en cada página. |
| DEFINED_IN_VIEW | La leyenda se renderiza según la propiedad View.PageInfo.Legend.LegendOn de la View renderizada. |
