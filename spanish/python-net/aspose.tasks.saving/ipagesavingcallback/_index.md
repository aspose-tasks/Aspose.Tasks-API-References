## IPageSavingCallback class

Representa una devolución de llamada que se invoca cuando cada página de un documento multipágina se guarda en un flujo separado.

El tipo IPageSavingCallback expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| page_saving(args) | El método que se llamará cuando una página se guarde en un flujo. |
| on_finish() | Método que se llamará cuando se hayan escrito todas las páginas. |
