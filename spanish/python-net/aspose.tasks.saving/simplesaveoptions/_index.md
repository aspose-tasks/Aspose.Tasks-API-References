## SimpleSaveOptions class

Esta es una clase base abstracta que permite al usuario especificar opciones básicas al guardar un proyecto en un formato particular.

El tipo SimpleSaveOptions expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| save_format | Obtiene o establece el formato en el que se guardará el documento si se utiliza este objeto de opciones de guardado. |
