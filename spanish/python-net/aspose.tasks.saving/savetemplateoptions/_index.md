## SaveTemplateOptions class

Permite especificar opciones adicionales al guardar un proyecto como plantilla.

El tipo SaveTemplateOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SaveTemplateOptions() | Inicializa una nueva instancia de la clase SaveTemplateOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| remove_actual_values | Obtiene o establece un valor que indica si se deben eliminar todos los valores reales de una plantilla de proyecto. |
| remove_baseline_values | Obtiene o establece un valor que indica si se deben eliminar todos los valores de referencia de una plantilla de proyecto. |
| remove_fixed_costs | Obtiene o establece un valor que indica si se deben eliminar todos los costos fijos de una plantilla de proyecto. |
| remove_resource_rates | Obtiene o establece un valor que indica si se deben eliminar las tarifas de recursos de una plantilla de proyecto. |
