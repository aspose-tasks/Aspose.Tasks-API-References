## PageSavingArgs class

Esta clase representa un conjunto de datos relacionados con el guardado de la página del documento en un flujo.

El tipo PageSavingArgs expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| page_number | Obtiene el número de página que se debe escribir. |
| keep_stream_open | Obtiene o establece un valor que indica si la rutina de renderizado debe mantener el [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) abierto después de que se escribe una página. |
| stream | Obtiene o establece un flujo para escribir una página. |
