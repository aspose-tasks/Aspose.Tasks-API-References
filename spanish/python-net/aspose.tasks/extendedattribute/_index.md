## ExtendedAttribute class

Representa atributos extendidos.

El tipo ExtendedAttribute expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| attribute_definition | Obtiene la definición del atributo. |
| field_id | Obtiene el id de un campo. |
| duration_value | Obtiene o establece el valor de los atributos con tipo 'Duration'. |
| numeric_value | Obtiene o establece un valor para los atributos con tipos numéricos (Cost, Number). |
| date_value | Obtiene o establece un valor para los atributos con tipos de fecha (Date, Start, Finish). |
| flag_value | Obtiene o establece un valor que indica si una bandera está establecida para un atributo con tipo 'Flag'. |
| text_value | Obtiene o establece un valor para los atributos con tipo 'Text'. |
| value_guid | Obtiene el guid de un valor de búsqueda. |
| value_read_only | Obtiene un valor que indica si el valor de esta instancia de [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) es de solo lectura. |
| is_error_value | Obtiene si el cálculo del valor del atributo extendido resultó en un error. |
