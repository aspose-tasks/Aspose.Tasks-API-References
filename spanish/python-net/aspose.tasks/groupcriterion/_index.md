## GroupCriterion class

Representa un criterio en una definición de grupo.<br/>            El objeto GroupCriterion es miembro de la colección [GroupCriterionCollection](/tasks/python-net/aspose.tasks/groupcriterioncollection/).

El tipo GroupCriterion expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| GroupCriterion() | Inicializa una nueva instancia de la clase GroupCriterion |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| ascendente | Obtiene o establece un valor que indica si un campo usado como criterio en una definición de grupo está ordenado en orden ascendente. False si el campo está ordenado en orden descendente. |
| cell_color | Obtiene o establece el color del fondo de la celda para un campo usado como criterio en una definición de grupo. |
| font_color | Obtiene o establece el color de la fuente para un campo usado como criterio en una definición de grupo. |
| field | Obtiene o establece el campo por el cual se agrupa. |
| group_on | Obtiene o establece el tipo de agrupación para un campo usado como criterio en una definición de grupo. |
| patrón | Obtiene o establece el patrón de la celda para un campo usado como criterio en una definición de grupo. |
| start_at | Obtiene o establece el inicio de los intervalos para un campo usado como criterio en una definición de grupo. |
| group_interval | Obtiene o establece el intervalo para un campo usado como criterio en una definición de grupo. |
| font | Obtiene o establece la fuente para un criterio en una definición de grupo. |
