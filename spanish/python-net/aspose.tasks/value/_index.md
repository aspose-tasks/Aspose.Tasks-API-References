## Value class

Representa un valor en una lista de valores.

El tipo Value expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Value() | Inicializa una nueva instancia de la clase [Value](/tasks/python-net/aspose.tasks/value/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| id | Obtiene o establece el identificador único de un valor en todo el proyecto. |
| value_guid | Obtiene un GUID que identifica este valor entre los demás en todo el proyecto. |
| val | Obtiene o establece el valor real en la representación interna. Prefiere usar propiedades fuertemente tipadas que se enumeran a continuación. |
| string_value | Obtiene o establece el valor real que se utiliza para representar una cadena de texto. |
| numeric_value | Obtiene o establece el valor real que se utiliza para representar un número o un valor de costo. |
| duration | Obtiene o establece el valor real que se utiliza para representar la duración. |
| date_time_value | Obtiene o establece el valor real si puede representarse como DateTime. El valor predeterminado es la fecha mínima. |
| description | Obtiene o establece la descripción de un valor. |
| phonetic | Obtiene o establece la información fonética sobre el nombre del campo personalizado. |
