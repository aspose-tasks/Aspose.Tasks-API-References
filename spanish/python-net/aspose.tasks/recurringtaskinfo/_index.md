## RecurringTaskInfo class

Representa los detalles de una tarea recurrente en un proyecto.

El tipo RecurringTaskInfo expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| recurrence_pattern | Obtiene o establece un patrón de recurrencia de la tarea recurrente. |
| start_date | Obtiene o establece la fecha de inicio de las ocurrencias. |
| end_date | Obtiene o establece la fecha de finalización de las ocurrencias. |
| duration | Obtiene o establece la duración de una ocurrencia de la tarea recurrente. |
| occurrences | Obtiene o establece un número de ocurrencias de la tarea recurrente. |
| use_end_date | Obtiene o establece un valor que indica si se debe usar la fecha de finalización o un número de ocurrencias para la tarea recurrente. |
| daily_repetitions | Obtiene o establece un número de repeticiones para el patrón de recurrencia diario. |
| daily_use_workdays | Obtiene o establece un valor que indica si se deben usar días laborables para el patrón de recurrencia diaria. |
| weekly_repetitions | Obtiene o establece un número de repeticiones para el patrón de recurrencia semanal. |
| weekly_days | Obtiene o establece una colección de días utilizados en el patrón de recurrencia semanal. |
| monthly_use_ordinal_day | Obtiene o establece un valor que indica si se debe usar el día ordinal para el patrón de recurrencia mensual. |
| monthly_ordinal_number | Obtiene o establece un número ordinal del patrón de recurrencia mensual. |
| monthly_ordinal_repetitions | Obtiene o establece un número de repeticiones para el patrón de recurrencia mensual al usar el día ordinal. |
| monthly_day | Obtiene o establece un número de día del patrón de recurrencia mensual. |
| monthly_repetitions | Obtiene o establece un número de repeticiones para el patrón de recurrencia mensual. |
| yearly_use_ordinal_day | Obtiene o establece un valor que indica si se debe usar el día ordinal para el patrón de recurrencia anual. |
| yearly_date | Obtiene o establece una fecha para el patrón de recurrencia anual. |
| yearly_ordinal_number | Obtiene o establece un número ordinal del patrón de recurrencia anual. |
| yearly_ordinal_month | Obtiene o establece un mes del patrón de recurrencia anual al usar el día ordinal. |
| task | Obtiene la tarea principal de esta instancia de la clase [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
