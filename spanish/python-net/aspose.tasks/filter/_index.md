## Filter class

Representa un filtro en Project.

El tipo Filter expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Filter() | Inicializa una nueva instancia de la clase Filter |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| filter_type | Obtiene el tipo del filtro. |
| name | Obtiene o establece el nombre de un objeto Filter. |
| show_in_menu | Obtiene o establece un valor que indica si el proyecto muestra el nombre del filtro en la lista desplegable Filter en la pestaña Vista de la cinta de opciones. |
| show_related_summary_rows | Obtiene o establece un valor que indica si se muestran filas de resumen relacionadas para el filtro. |
| index | Obtiene el índice de un objeto [Filter](/tasks/python-net/aspose.tasks/filter/) en el objeto que contiene los Filters. |
| uid | Obtiene el identificador único de un filtro. |
| criteria | Obtiene o establece los criterios que las tareas o recursos deben cumplir para mostrarse en la vista MSP. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| compare_to(other) | Compara esta instancia con la instancia especificada de la clase [Filter](/tasks/python-net/aspose.tasks/filter/) y devuelve una indicación de su orden relativo. |
| equals(other) | Devuelve un valor que indica si esta instancia es igual al objeto AssignmentBaseline especificado. |
