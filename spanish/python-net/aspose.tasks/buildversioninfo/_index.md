## BuildVersionInfo class

Contiene la versión de compilación y la información del producto.

El tipo BuildVersionInfo expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| ASSEMBLY_VERSION | Versión del ensamblado. |
| ASSEMBLY_INFORMATIONAL_VERSION | El número de versión informativa del ensamblado. |
| FILE_VERSION | Versión del archivo. |
| PRODUCTO | Nombre del producto. |
