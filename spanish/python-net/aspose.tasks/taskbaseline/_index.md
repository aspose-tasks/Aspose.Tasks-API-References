## TaskBaseline class

Representa la línea base de una tarea.

El tipo TaskBaseline expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TaskBaseline(task) | Inicializa una nueva instancia de la clase [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| baseline_number | Obtiene o establece el número único de un registro de datos de línea base. |
| work | Obtiene o establece el trabajo asignado a un recurso cuando se guarda la línea base. |
| cost | Obtiene o establece el costo proyectado de un recurso cuando se guarda la línea base. |
| bcws | Obtiene o establece el costo presupuestado de un trabajo programado para un recurso. |
| bcwp | Obtiene o establece el costo presupuestado de un trabajo realizado por un recurso para un proyecto hasta la fecha. |
| timephased_data | Obtiene o establece una instancia de TimephasedDataCollection para este objeto.<br/>            Los datos por fases de tiempo asociados con la línea base de la tarea. |
| interim | Obtiene o establece un valor que indica si esta es una Línea Base Interina. |
| inicio | Obtiene o establece la fecha de inicio programada de la tarea cuando se guardó la línea base. |
| finish | Obtiene o establece la fecha de finalización programada de la tarea cuando se guardó la línea base. |
| duration | Obtiene o establece la duración programada de la tarea cuando se guardó la línea base. |
| estimated_duration | Obtiene o establece un valor que indica si la duración de referencia de la tarea fue estimada. |
| fixed_cost | Obtiene o establece un costo fijo de la tarea cuando se guardó la referencia. |
