## Métodos
| Nombre | Descripción |
| :- | :- |
| get_timephased_data(start, end, timephased_type) | Devuelve una instancia de la clase [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) para este objeto con los valores de [timephased_data](/tasks/python-net/aspose.tasks/resource/) dentro de las fechas de inicio y fin dadas del [TimephasedDataType](/tasks/python-net/aspose.tasks/timephaseddatatype/) especificado. |
| get_timephased_data(start, end) | Devuelve una instancia de la clase [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) para este objeto con los valores de [timephased_data](/tasks/python-net/aspose.tasks/resource/) dentro de las fechas de inicio y fin dadas del [TimephasedDataType](/tasks/python-net/aspose.tasks/timephaseddatatype/) especificado. |
| equals(other) | Devuelve un valor que indica si esta instancia es igual a una instancia especificada de la clase [Resource](/tasks/python-net/aspose.tasks/resource/). |
| delete() | Elimina un recurso y sus asignaciones del proyecto. |
