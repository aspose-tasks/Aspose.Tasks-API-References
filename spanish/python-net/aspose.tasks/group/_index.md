## Group class

Representa una definición de grupo.<br/>            Un objeto Group es miembro de la colección ResourceGroups o de la colección TaskGroups.

El tipo Group expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Group() | Inicializa una nueva instancia de la clase [Group](/tasks/python-net/aspose.tasks/group/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene o establece un nombre de un objeto Group. |
| uid | Obtiene un identificador único de un grupo. |
| show_summary | Obtiene o establece un valor que indica si se muestran filas de resumen para el grupo. |
| maintain_hierarchy | Obtiene o establece un valor que indica si se muestran todos los niveles de tareas de resumen para subtareas dentro del grupo. |
| show_in_menu | Obtiene o establece un valor que indica si Project muestra el nombre del grupo en la lista desplegable Group en la cinta. |
| group_assignments | Obtiene o establece un valor que indica si las asignaciones deben agruparse en lugar de las tareas. |
| group_criteria | Obtiene o establece una colección GroupCriteria que representa los campos en una definición de grupo. |
