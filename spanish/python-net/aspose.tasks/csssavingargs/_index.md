## CssSavingArgs class

Esta clase representa un conjunto de datos relacionados con el guardado de archivos CSS externos que<br/>              ocurre durante la conversión al formato HTML.

El tipo CssSavingArgs expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| CssSavingArgs() | Inicializa una nueva instancia de la clase [CssSavingArgs](/tasks/python-net/aspose.tasks/csssavingargs/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| file_name | Obtiene o establece el nombre de archivo supuesto que pasa del convertidor al código del método personalizado.<br/>             Puede usarse en código personalizado para decidir cómo procesar o dónde guardar ese archivo. |
| keep_stream_open | Obtiene o establece un valor que indica si la secuencia permanecerá abierta después de que finalice el guardado del recurso. |
| stream | Obtiene o establece el contenido binario del archivo guardado. |
| uri | Obtiene o establece el URI del recurso. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| close_stream_if_required() | Cierra la secuencia si KeepStreamOpen es falso, de lo contrario la vacía. |
