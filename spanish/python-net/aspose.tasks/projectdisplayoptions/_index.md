## ProjectDisplayOptions class

Representa las opciones de visualización para una instancia de proyecto.

El tipo ProjectDisplayOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ProjectDisplayOptions() | Inicializa una nueva instancia de la clase [ProjectDisplayOptions](/tasks/python-net/aspose.tasks/projectdisplayoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| add_space_before_label | Obtiene o establece un valor que indica si se debe agregar un espacio antes del valor numérico y la abreviatura de tiempo (1 wk en lugar de 1wk). |
| underline_hyperlinks | Obtiene o establece un valor que indica si se deben subrayar los hipervínculos. |
| show_task_schedule_warnings | Obtiene o establece un valor que indica si se deben mostrar advertencias cuando Project identifica un posible conflicto de programación con una tarea programada manualmente. |
| show_task_schedule_suggestions | Obtiene o establece un valor que indica si se deben mostrar sugerencias cuando Project identifica un posible conflicto de programación con una tarea programada manualmente. |
| show_project_summary_task | Obtiene o establece un valor que indica si se debe mostrar información resumida de todo el proyecto en una sola fila con su propia barra de tarea resumida en la parte superior de la vista de diagrama de Gantt. |
| minute_label | Obtiene o establece cómo se muestra la etiqueta de minutos. |
| hour_label | Obtiene o establece cómo se muestra la etiqueta de horas. |
| day_label | Obtiene o establece cómo se muestra la etiqueta de días. |
| week_label | Obtiene o establece cómo se muestra la etiqueta de semanas. |
| month_label | Obtiene o establece cómo se muestra la etiqueta del mes. |
| year_label | Obtiene o establece cómo se muestra la etiqueta del año. |
