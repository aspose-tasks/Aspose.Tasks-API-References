## FilterComparisonType enumeration

El tipo de comparación realizada entre FieldName y Value que actúa como criterio de selección para un filtro o indicador gráfico.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| EQUALS | El valor de Field es igual a Value. |
| DOES_NOT_EQUAL | El valor de Field no es igual a Value. |
| IS_GREATER_THAN | El valor de Field es mayor que Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | El valor de Field es mayor o igual que Value. |
| IS_LESS_THAN | El valor de Field es menor que Value. |
| IS_LESS_THAN_OR_EQUAL_TO | El valor de Field es menor o igual que Value. |
| IS_WITHIN | El valor de Field está dentro de Value. |
| IS_NOT_WITHIN | El valor de Field no está dentro de Value. |
| CONTAINS | El valor de Field contiene Value. |
| DOES_NOT_CONTAIN | El valor de Field no contiene Value. |
| CONTAINS_EXACTLY | El valor de Field contiene exactamente Value. |
| IS_ONE_OF | El valor de Field es igual a uno de los Values especificados. Usado en AutoFilters. |
| UNDEFINED | Valor indefinido. |
| IS_ANY_VALUE | 'Is any value' condición. Aplicable a indicadores gráficos. |
