## AvailabilityPeriod class

Representa un período en el que un recurso está disponible.

El tipo AvailabilityPeriod expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| AvailabilityPeriod() | Inicializa una nueva instancia de [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | Inicializa una nueva instancia de [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) con el rango de fechas especificado y las unidades disponibles. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| available_from | Obtiene o establece la fecha en que un recurso está disponible para el período especificado. |
| available_to | Obtiene o establece la última fecha en que un recurso está disponible para el período especificado. |
| available_units | Obtiene o establece el porcentaje de un recurso que está disponible durante el período especificado. |
