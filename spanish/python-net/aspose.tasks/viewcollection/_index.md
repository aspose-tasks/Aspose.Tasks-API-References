## ViewCollection class

Contiene una lista de objetos [View](/tasks/python-net/aspose.tasks/view/) .<br/>            Implementa la interfaz ICollection<View>.

El tipo ViewCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| parent_project | Obtiene el padre del objeto View.<br/>            Solo lectura [Project](/tasks/python-net/aspose.tasks/project/). |
## Métodos
| Nombre | Descripción |
| :- | :- |
| to_list() | Convierte una colección de vistas en una lista de objetos [View](/tasks/python-net/aspose.tasks/view/). |
| get_by_view_screen(screen) | Busca una View con la propiedad Screen especificada y devuelve la primera aparición dentro de la colección. |
| get_by_name(view_name) | Busca una View con el nombre y devuelve la primera aparición dentro de la colección. |
