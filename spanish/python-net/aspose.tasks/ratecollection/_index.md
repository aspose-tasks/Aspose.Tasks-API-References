## RateCollection class

Representa una colección que contiene objetos [Rate](/tasks/python-net/aspose.tasks/rate/).

El tipo RateCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| count | Obtiene el número de elementos contenidos en RateCollection. |
| is_read_only | Obtiene un valor que indica si esta colección es de solo lectura. |
| parent_resource | Obtiene el objeto [Resource](/tasks/python-net/aspose.tasks/resource/) padre para esta colección. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add(rates_from) | Agrega una nueva instancia de [Rate](/tasks/python-net/aspose.tasks/rate/) a esta colección. |
| add(rates_from, type) | Agrega una nueva instancia de [Rate](/tasks/python-net/aspose.tasks/rate/) a esta colección. |
| to_list() | Convierte el objeto [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) en una lista de objetos [Rate](/tasks/python-net/aspose.tasks/rate/). |
| to_list(type) | Convierte el objeto [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) en una lista de objetos [Rate](/tasks/python-net/aspose.tasks/rate/) filtrados por el tipo [RateType](/tasks/python-net/aspose.tasks/ratetype/) especificado. |
| remove(item) | Elimina la instancia de Rate de esta colección. |
