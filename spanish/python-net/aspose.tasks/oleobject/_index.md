## OleObject class

Representa un objeto OLE que puede insertarse en la vista de diagrama de Gantt de un archivo MPP.

El tipo OleObject expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| OleObject() | Inicializa una nueva instancia de la clase [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene o establece el nombre de la instancia del objeto OLE. |
| application_name | Obtiene o establece el nombre de la aplicación con la que abrir el objeto incrustado. |
| file_format | Obtiene o establece el formato de archivo del objeto incrustado. |
| content | Obtiene o establece los datos del archivo incrustado; null si no se incrustó ningún dato. |
| label | Obtiene o establece la etiqueta del objeto insertado. |
| full_path | Obtiene o establece la ruta completa del objeto insertado. |
| temporary_file | Obtiene o establece la ruta al archivo temporal del objeto insertado. |
| display_as_icon | Obtiene o establece una bandera que indica que el objeto OLE debe mostrarse ya sea como un ícono o como su imagen regular. |
| vinculado | Obtiene un valor que indica si el archivo del proyecto contiene solo un enlace a los datos reales almacenados en la fuente del enlace. |
| view | Obtiene o establece la instancia de la clase [view](/tasks/python-net/aspose.tasks/oleobject/) a la que pertenece el objeto insertado. |
| id | Obtiene o establece el id del objeto. |
