## Rate class

Representa una definición de un período de tiempo y tarifas aplicables a un recurso durante ese período.

El tipo Rate expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| rates_from | Obtiene o establece la fecha en que una tarifa entra en vigor. |
| rates_to | Obtiene o establece la última fecha en que una tarifa es válida. |
| rate_table | Obtiene o establece el identificador único de una tabla de tarifas para un recurso. |
| standard_rate | Obtiene o establece la tarifa estándar por hora para un recurso. |
| standard_rate_format | Obtiene o establece las unidades utilizadas por Microsoft Project para mostrar la tarifa estándar. |
| overtime_rate | Obtiene o establece la tarifa de horas extra por hora para un recurso. |
| overtime_rate_format | Obtiene o establece las unidades utilizadas por Microsoft Project para mostrar la tarifa de horas extra. |
| cost_per_use | Obtiene o establece el costo por uso de un recurso. Este valor se recupera de la fecha actual si existe una tabla de tarifas para un recurso. |
