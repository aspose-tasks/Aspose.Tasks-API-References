## RecurringTaskParameters class

Representa el conjunto de parámetros que se utilizan para crear una tarea recurrente en un proyecto.

El tipo RecurringTaskParameters expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| RecurringTaskParameters() | Inicializa una nueva instancia de la clase [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| duration | Obtiene o establece la duración de una ocurrencia de la tarea recurrente. |
| ignore_resource_calendar | Obtiene o establece un valor que indica si programar la tarea recurrente incluso si no ocurre cuando hay recursos disponibles para trabajar en ella. |
| recurrence_pattern | Obtiene o establece el patrón de recurrencia de la tarea recurrente. |
| task_name | Obtiene o establece el nombre de la tarea recurrente. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| set_calendar(project, calendar_name) | Establece un calendario para la tarea recurrente. El calendario se selecciona de la colección de calendarios del proyecto. |
