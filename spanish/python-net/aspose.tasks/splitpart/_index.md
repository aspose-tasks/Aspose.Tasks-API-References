## SplitPart class

Representa una porción de tarea. SplitPart es un miembro de la colección SplitParts de la tarea.

El tipo SplitPart expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| inicio | Obtiene la fecha de inicio de un SplitPart. |
| finish | Obtiene la fecha de finalización de un SplitPart. |
