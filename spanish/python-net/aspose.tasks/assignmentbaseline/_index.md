## AssignmentBaseline class

Representa la línea base de una asignación de recurso.

El tipo AssignmentBaseline expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| AssignmentBaseline() | Inicializa una nueva instancia de la clase AssignmentBaseline |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| baseline_number | Obtiene o establece el número único de un registro de datos de línea base. |
| work | Obtiene o establece el trabajo asignado a un recurso cuando se guarda la línea base. |
| cost | Obtiene o establece el costo proyectado de un recurso cuando se guarda la línea base. |
| bcws | Obtiene o establece el costo presupuestado de un trabajo programado para un recurso. |
| bcwp | Obtiene o establece el costo presupuestado de un trabajo realizado por un recurso para un proyecto hasta la fecha. |
| timephased_data | Obtiene o establece la instancia de [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) para este objeto.<br/>            Los datos por fases de tiempo asociados con la línea base de asignación de recursos. |
| inicio | Obtiene o establece la fecha de inicio programada de la asignación de recursos cuando se guardó la línea base. |
| finish | Obtiene o establece la fecha de finalización programada de la asignación de recursos cuando se guardó la línea base. |
