## UndefinedConstraintHandlingBehavior enumeration

Especifica el comportamiento utilizado para manejar tareas con restricciones indefinidas.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | El comportamiento predeterminado para cargar desde el formato XER.<br/>            No se realiza ninguna acción. El tipo de restricción de tarea se establece en 'ConstraintType.Undefined'. |
| SUBSTITUTE_WITH_START_NO_EARLIER_THAN | Se añaden restricciones con el tipo 'ConstraintType.StartNoEarlierThan' y fecha = Start para tareas con restricción 'Undefined'. |
