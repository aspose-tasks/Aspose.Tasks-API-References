## TaskLink class

Representa un enlace de predecesor.

El tipo TaskLink expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_cross_project | Obtiene o establece un valor que indica si un predecesor forma parte de otro proyecto. |
| cross_project_name | Obtiene o establece el proyecto predecesor externo. |
| link_lag | Obtiene o establece el retraso en décimas de minuto o porcentaje. |
| link_lag_time_span | Obtiene o establece la duración del retraso, según el LagFormat. |
| lag_format | Obtiene o establece el formato para expresar el retraso. |
| pred_task | Obtiene o establece la tarea predecesora. |
| succ_task | Obtiene o establece la tarea sucesora. |
| link_type | Obtiene o establece el tipo de un enlace. |
