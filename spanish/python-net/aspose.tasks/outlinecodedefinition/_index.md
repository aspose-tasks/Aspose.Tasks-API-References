## OutlineCodeDefinition class

Representa una definición de código de esquema.

El tipo OutlineCodeDefinition expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| OutlineCodeDefinition() | Inicializa una nueva instancia de la clase [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| guid | Obtiene o establece el Guid de un código de esquema. |
| field_id | Obtiene o establece el número de campo de un código de esquema. |
| field_name | Obtiene o establece el nombre de un código de esquema personalizado. |
| alias | Obtiene o establece el alias de un código de esquema personalizado. |
| phonetic_alias | Obtiene o establece la pronunciación fonética del alias del código de esquema personalizado. |
| values | Obtiene el objeto OutlineValueCollection.<br/>            Los valores de la tabla asociados con este código de esquema. |
| enterprise | Obtiene o establece un valor que indica si un código de esquema personalizado es un código de esquema personalizado empresarial. |
| enterprise_outline_code_alias | Obtiene o establece una referencia a otro campo personalizado para el cual esta definición de código de esquema es un alias. |
| resource_substitution_enabled | Obtiene o establece un valor que indica si el código de esquema personalizado puede ser usado<br/>            por el Asistente de Sustitución de Recursos en Microsoft Project. |
| leaf_only | Obtiene o establece un valor que indica si los valores especificados en este campo de código de esquema deben ser valores hoja. |
| all_levels_required | Obtiene o establece un valor que indica si los nuevos códigos deben tener todos los niveles.<br/>            No disponible para códigos empresariales. |
| only_table_values_allowed | Obtiene o establece un valor que indica si los valores especificados deben provenir de la tabla de valores. |
| masks | Obtiene el objeto OutlineMaskCollection.<br/>            La tabla de entradas que define la máscara del código de esquema.<br/>            Instancia de solo lectura [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/). |
| show_indent | Obtiene o establece un valor que indica si los sangrados de este código de esquema deben mostrarse. |
