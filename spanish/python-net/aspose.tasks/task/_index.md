## Métodos
| Nombre | Descripción |
| :- | :- |
| get_timephased_data(start, end, timephased_type) | Devuelve un objeto [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) con valores [timephased_data](/tasks/python-net/aspose.tasks/task/) dentro de las fechas de inicio y fin dadas del tipo de datos con fase de tiempo especificado. |
| get_timephased_data(start, end) | Devuelve un objeto [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) con valores [timephased_data](/tasks/python-net/aspose.tasks/task/) dentro de las fechas de inicio y fin dadas del tipo de datos con fase de tiempo especificado. |
| move_to_sibling(before_task) | Mueve la tarea actual al mismo nivel de esquema antes de la tarea especificada.<br/>            Si ParentProject.CalculationMode es None, el usuario debe invocar Project.Recalculate() después de usar este método (Reprogramará todas las tareas del proyecto (fechas de inicio/fin, establece fechas tempranas/tardías) y calculará los campos dependientes como holguras, trabajo y costos, niveles de esquema).<br/>            Si ParentProject.CalculationMode es Manual, el método calculará solo el id de la tarea, el nivel de esquema y los números de esquema automáticamente.<br/>            Si ParentProject.CalculationMode es Automatic, el método reprograma todas las tareas del proyecto automáticamente<br/>            (fechas de inicio/fin, establece fechas tempranas/tardías, calcula holguras, trabajo y costos, recalcula los ids y los niveles de esquema). |
| move_to_sibling(before_task_id) |  |
| select_all_child_tasks() | Recopila recursivamente todas las tareas hijas de esta tarea. |
| clone() | Crea una copia completa de una tarea sin subtareas. |
| equals(other) | Devuelve un valor que indica si esta instancia es igual a una tarea especificada. |
| delete() | Elimina una tarea de la colección de tareas del proyecto principal y de todas sus asignaciones. |
| outline_indent() | Indenta una tarea en el esquema. |
| outline_outdent() | Promueve una tarea en el esquema. |
