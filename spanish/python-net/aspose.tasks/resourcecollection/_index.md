## ResourceCollection class

Representa una colección de objetos [Resource](/tasks/python-net/aspose.tasks/resource/).

El tipo ResourceCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| parent_project | Obtiene el proyecto principal del objeto ResourceCollection. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add() | Agrega un nuevo recurso en la última posición de la colección de recursos de un proyecto. |
| add(resource_name) | Agrega un nuevo recurso en la última posición de la colección de recursos de un proyecto. |
| add(resource_name, before_resource_id) |  |
| to_list() | Convierte el objeto ResourceCollection a una lista de objetos [Resource](/tasks/python-net/aspose.tasks/resource/). |
| get_by_id(id) | Devuelve un recurso con el id especificado. |
| get_by_uid(uid) | Devuelve un recurso con el Uid especificado. |
