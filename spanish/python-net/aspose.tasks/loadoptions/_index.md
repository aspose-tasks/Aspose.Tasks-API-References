## LoadOptions class

Permite especificar parámetros de carga adicionales al cargar un proyecto desde un archivo o flujo.

El tipo LoadOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LoadOptions() | Inicializa una nueva instancia de la clase [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| password | Obtiene o establece una contraseña de protección. |
| primavera_read_options | Obtiene o establece una instancia especificada de la clase [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) que puede usarse para personalizar el comportamiento de carga de formatos Primavera (Primavera P6 XER o Primavera P6 Xml). |
| encoding | Obtiene o establece la codificación que se usa para leer un proyecto desde los formatos HTML, MPX, XER y Primavera XML.<br/>            La codificación predeterminada es UTF8. |
