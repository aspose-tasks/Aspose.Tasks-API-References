## TableField class

Representa un campo de una tabla en un proyecto.

El tipo TableField expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TableField() | Inicializa una nueva instancia de la clase [TableField](/tasks/python-net/aspose.tasks/tablefield/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| align_data | Obtiene o establece la alineación de los datos en un campo de tabla. |
| align_title | Obtiene o establece la alineación del título en un campo de tabla. |
| field | Obtiene o establece el tipo de un campo de tabla. |
| título | Obtiene o establece el título del campo en una tabla. |
| width | Obtiene o establece el ancho en puntos de la columna del campo en una tabla. |
| wrap_header | Obtiene o establece un valor que indica si el encabezado de la columna de la tabla puede ajustarse a varias líneas, o si debe truncarse cuando supera el ancho de la columna. |
| wrap_text | Obtiene o establece un valor que indica si el texto de la columna puede ajustarse a varias líneas, o si debe truncarse cuando supera el ancho de la columna. |
