## SummaryRowsCalculationType enumeration

Especifica el tipo de cálculo del valor del atributo personalizado para filas de resumen.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | Indica que el valor del atributo personalizado para filas de resumen no se calcula. |
| ROLLUP | Indica que el valor del atributo personalizado para filas de resumen se calcula usando la función de acumulación definida en [rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
| USE_FORMULA | Indica que el valor del atributo personalizado para filas de resumen se calcula usando la fórmula definida en [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
