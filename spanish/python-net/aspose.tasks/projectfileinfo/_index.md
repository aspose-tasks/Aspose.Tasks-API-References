## ProjectFileInfo class

La instancia de la clase contiene información sobre el formato del archivo de proyecto y la versión de Microsoft Project donde<br/>            se creó el archivo.

El tipo ProjectFileInfo expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| can_read | Obtiene un valor que indica si Aspose.Tasks puede procesar el archivo del proyecto. |
| is_password_protected | Obtiene un valor que indica si un proyecto está protegido con contraseña. |
| project_file_format | Obtiene el formato del archivo del proyecto. |
| project_application_info | Obtiene la información de la aplicación del archivo del proyecto. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| equals(other) | Devuelve un valor que indica si esta instancia es igual a un objeto especificado. |
