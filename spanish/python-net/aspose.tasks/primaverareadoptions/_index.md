## PrimaveraReadOptions class

Permite especificar opciones adicionales al leer archivos Primavera Xml o Primavera Xer.

El tipo PrimaveraReadOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PrimaveraReadOptions() | Inicializa una nueva instancia de la clase [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| project_uid | Obtiene o establece el UID de un proyecto para leer de un archivo que contiene varios proyectos. |
| undefined_constraint_handling_behavior | Especifica el comportamiento utilizado para procesar tareas con restricciones indefinidas leídas del formato XER. |
| preserve_uids | Obtiene o establece una bandera que indica si los identificadores únicos originales de las entidades deben preservarse. |
| read_baseline_projects | Obtiene o establece una bandera que indica si los proyectos de línea base deben cargarse. El valor predeterminado es verdadero. |
