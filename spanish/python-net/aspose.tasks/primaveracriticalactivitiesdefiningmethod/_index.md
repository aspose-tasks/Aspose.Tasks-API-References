## PrimaveraCriticalActivitiesDefiningMethod enumeration

Especifica el método para definir actividades críticas en Primavera.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| TOTAL_FLOAT | Las actividades con TotalSlack (Flotación total en Primavera) menor o igual al valor de [critical_total_float_limit](/tasks/python-net/aspose.tasks/primaveraprojectproperties/) se marcan como críticas. |
| LONGEST_PATH | Las actividades en la ruta más larga se marcan como críticas. |
