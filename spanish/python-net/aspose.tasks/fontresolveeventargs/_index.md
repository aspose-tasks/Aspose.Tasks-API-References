## FontResolveEventArgs class

Proporciona argumentos para la devolución de llamada que se invoca cuando se resuelve la fuente.

El tipo FontResolveEventArgs expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| requested_font_name | Obtiene el nombre de la fuente solicitada. |
| resolved_font_name | Obtiene o establece el nombre de la fuente resuelta. Puede establecerse para controlar las fuentes usadas al renderizar una vista. |
