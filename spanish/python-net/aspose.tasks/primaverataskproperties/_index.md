## PrimaveraTaskProperties class

Representa propiedades específicas de Primavera para una tarea leída de archivos Primavera (XER o P6XML).

El tipo PrimaveraTaskProperties expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| sequence_number | Obtiene o establece el número de secuencia del elemento WBS (tareas resumidas). Se utiliza para ordenar las tareas resumidas en Primavera. |
| activity_id | Obtiene un campo de id de actividad - el identificador único de una tarea utilizado por Primavera. |
| remaining_early_finish | Obtiene la fecha de finalización temprana restante - la fecha en que se programó que el trabajo restante de la actividad se termine. |
| remaining_early_start | Obtiene la fecha de inicio temprano restante - la fecha en que se programó que el trabajo restante de la actividad comience. |
| remaining_late_start | Obtiene la fecha de inicio tardío restante. |
| remaining_late_finish | Obtiene la fecha de finalización tardía restante. |
| raw_duration_type | Obtiene la representación de texto sin procesar (como en el archivo fuente) del campo 'Duration Type' de la actividad. |
| duration_type | Obtiene el valor del campo 'Duration Type' de la actividad. |
| raw_activity_type | Obtiene la representación de texto sin procesar (como en el archivo fuente) del campo 'Activity Type' de la actividad. |
| activity_type | Obtiene el valor del campo 'Activity Type'. |
| percent_complete_type | Obtiene el valor del campo '% Complete Type' de la actividad. |
| raw_complete_percent_type | Obtiene la representación de texto sin procesar (como en el archivo fuente) del campo '% Complete Type' de la actividad. |
| raw_status | Obtiene la representación de texto sin formato (como en el archivo fuente) del campo 'Status' de la actividad. |
| physical_percent_complete | Obtiene el valor de Physical Percent Complete. |
| duration_percent_complete | Obtiene el valor de duration percent complete. |
| units_percent_complete | Obtiene el valor de units percent complete. |
| actual_labor_units | Obtiene el valor de actual labor units. |
| actual_non_labor_units | Obtiene el valor de actual non labor units. |
| remaining_labor_units | Obtiene el valor de remaining labor units. |
| remaining_non_labor_units | Obtiene el valor de remaining non labor units. |
| actual_labor_cost | Obtiene el valor de actual labor cost . |
| budgeted_labor_cost | Obtiene el valor de budgeted (or planned) labor cost . |
| actual_nonlabor_cost | Obtiene el valor de actual non labor cost . |
| budgeted_nonlabor_cost | Obtiene el valor de budgeted (or planned) non labor cost . |
| actual_material_cost | Obtiene el valor del costo material real. |
| budgeted_material_cost | Obtiene el valor del costo material presupuestado (o planificado). |
| actual_expense_cost | Obtiene el valor del costo de gasto real. |
| remaining_expense_cost | Obtiene el valor del costo de gasto restante. |
| budgeted_expense_cost | Obtiene el valor del costo de gasto presupuestado (o planificado). |
| actual_total_cost | Obtiene el valor total de los costos reales. |
| budgeted_total_cost | Obtiene el valor total de los costos presupuestados (o planificados). |
| primary_constraint_type | Obtiene un tipo de restricción primaria. |
| primary_constraint_date | Obtiene la fecha de la restricción primaria. |
| secondary_constraint_type | Obtiene un tipo de restricción secundaria. |
| secondary_constraint_date | Obtiene la fecha de la restricción secundaria. |
| planned_duration | Obtiene la duración original o planificada -- el tiempo total de trabajo desde la fecha de inicio planificada de la tarea hasta la fecha de finalización planificada.. |
