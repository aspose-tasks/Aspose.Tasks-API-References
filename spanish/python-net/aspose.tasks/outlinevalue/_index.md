## OutlineValue class

Representa un valor de esquema.

El tipo OutlineValue expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| OutlineValue() | Inicializa una nueva instancia de la clase OutlineValue |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| value_id | Obtiene o establece el Id único de un valor de código de esquema dentro de un proyecto. |
| value_guid | Obtiene un GUID que identifica este valor entre los demás en todo el proyecto. |
| type | Obtiene o establece el tipo de código de esquema. |
| parent_value_id | Obtiene o establece el Id de un nodo padre de un código de esquema. |
| value | Obtiene o establece el valor real. |
| duration_value | Obtiene o establece la duración si el Tipo es Duración. |
| description | Obtiene o establece la descripción de un valor de esquema. |
| is_collapsed | Obtiene o establece un valor que indica si el valor de esquema está colapsado o no. |
