## WorkingTime class

Representa un tiempo de trabajo durante un día de la semana.

El tipo WorkingTime expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| WorkingTime(from_time, to_time) | Inicializa una nueva instancia de la clase [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) con un intervalo con los tiempos de inicio y fin especificados. |
| WorkingTime(from_time, to_time) | Inicializa una nueva instancia de la clase [WorkingTime](/tasks/python-net/aspose.tasks/workingtime/) con un elemento de intervalo con los tiempos de inicio y fin especificados. |
| WorkingTime(from_hours, to_hours) | Inicializa una nueva instancia de la clase WorkingTime |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| from_address | Obtiene el inicio de un tiempo de trabajo. |
| to | Obtiene el final de un tiempo de trabajo. |
