## FontSettings class

Especifica la configuración de fuentes utilizada al renderizar la vista del proyecto.

El tipo FontSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| FontSettings() | Inicializa una nueva instancia de la clase FontSettings |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| default_font_name | Obtiene o establece la fuente predeterminada (o de respaldo) para la renderización. |
| use_project_default_font | Obtiene o establece un valor que indica si se debe usar la fuente predeterminada para la renderización. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| set_font_folders(font_folders, recursive) | Establece las carpetas donde Aspose.Tasks busca fuentes TrueType al renderizar la vista del proyecto. |
