## WeekDay class

Representa un día de la semana que define días regulares de una semana o días excepcionales en un calendario.

El tipo WeekDay expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| WeekDay(day_type) | Inicializa una nueva instancia de la clase [WeekDay](/tasks/python-net/aspose.tasks/weekday/) con el tipo de día especificado. |
| WeekDay(day_type, working_times) | Inicializa una nueva instancia de la clase WeekDay |
| WeekDay(day_type, working_times) | Inicializa una nueva instancia de la clase [WeekDay](/tasks/python-net/aspose.tasks/weekday/) con el tipo de día especificado y los períodos de tiempo de trabajo. |
| WeekDay() | Inicializa una nueva instancia de la clase [WeekDay](/tasks/python-net/aspose.tasks/weekday/) con el tipo de día especificado. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| day_type | Obtiene el tipo de un día. |
| day_working | Obtiene o establece un valor que indica si la fecha o el tipo de día especificado es laborable. |
| from_date | Obtiene o establece el inicio de un tiempo de excepción. |
| to_date | Obtiene o establece el final de un tiempo de excepción. |
| working_times | Obtiene WorkingTimeCollection para esta instancia de WeekDay.<br/>            La colección de tiempos de trabajo que define el tiempo trabajado en el día de la semana. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| create_default_working_day(day_type) | Crea un día de trabajo predeterminado. |
| set_default_working_time(day) | Establece los períodos de tiempo predeterminados para el día de la semana especificado. |
| get_working_time() | Devuelve el tiempo de trabajo para un día de la semana. |
| clone() | Devuelve una copia profunda del día de la semana. |
