## TaskLinkCollection class

Representa una colección de [Task](/tasks/python-net/aspose.tasks/task/) objetos.

El tipo TaskLinkCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| parent_project | Obtiene el proyecto principal del objeto ResourceAssignmentCollection. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add(pred, succ) | Devuelve una instancia de Finish-Start [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) que ha sido añadida al objeto TaskLinkCollection. |
| add(pred, succ, link_type) | Devuelve una instancia de [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) que ha sido añadida al objeto TaskLinkCollection. |
| add(pred, succ, link_type, lag) | Devuelve una instancia de [TaskLink](/tasks/python-net/aspose.tasks/tasklink/) que ha sido añadida al objeto TaskLinkCollection. |
