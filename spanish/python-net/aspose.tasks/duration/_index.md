## Duration class

Representa la duración en un proyecto.

El tipo Duration expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Duration() | Inicializa una nueva instancia de la clase Duration |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| time_span | Obtiene la instancia [time_span](/tasks/python-net/aspose.tasks/duration/) de este objeto Duration. |
| time_unit | Obtiene el tipo de unidad de tiempo para este objeto. |
| is_estimated | Obtiene un valor que indica si la unidad de tiempo es estimada. |
| is_elapsed | Obtiene un valor que indica si la unidad de tiempo ha transcurrido. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add(d) | Agrega la duración especificada a esta duración. |
| add(val) | Agrega el valor double especificado a esta duración. |
| subtract(d) | Resta la duración especificada de esta instancia de duración. |
| subtract(val) | Resta el valor double especificado de esta instancia de duración. |
| parse(p, value) | Convierte la cadena especificada a la instancia de la estructura [Duration](/tasks/python-net/aspose.tasks/duration/). |
| parse_time_span(value) | Analiza la cadena de duración en el formato "PT--H--M--S--". |
| to_double() | Convierte el objeto Duration a un valor float. |
| convert(time_unit_type) | Convierte el objeto Duration a otra duración con unidades de tiempo especificadas. |
| equals(other) | Devuelve un valor que indica si esta instancia es igual a un objeto especificado. |
