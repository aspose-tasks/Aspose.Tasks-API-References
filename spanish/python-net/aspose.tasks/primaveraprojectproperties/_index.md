## PrimaveraProjectProperties class

Representa propiedades específicas de Primavera para un proyecto leído de archivos Primavera (XER o P6XML).

El tipo PrimaveraProjectProperties expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| relationship_lag_calendar | Obtiene una opción que define qué calendario usar para programar el retraso de relación en proyectos Primavera. |
| use_expected_finish_dates | Obtiene una bandera que define si las fechas de finalización de la actividad deben programarse como las fechas de finalización esperadas. |
| make_open_ended_activities_critical | Obtiene una bandera que define si las actividades deben marcarse como críticas al programar el proyecto. |
| ignore_other_project_relationships | Obtiene una bandera que define si se deben ignorar las relaciones de actividad entre proyectos. |
| current_baseline_project_id | Obtiene el Id del proyecto base actual.<br/>            Es aplicable a proyectos leídos de archivos XML de Primavera que contienen bases exportadas. |
| baseline_projects | Obtiene la matriz de proyectos base del proyecto actual.<br/>            Es aplicable a proyectos leídos de archivos XML de Primavera que contienen bases exportadas. |
| critical_activities_defining_method | Obtiene el método para definir actividades críticas: enfoque de Ruta más larga o Flotación total. |
| critical_total_float_limit | Obtiene el valor umbral utilizado para definir actividades críticas si se usa el método TotalFloat. |
| short_name | Obtiene el nombre corto del proyecto (ID del proyecto). |
