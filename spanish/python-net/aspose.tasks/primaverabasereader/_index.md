## PrimaveraBaseReader class

Representa un lector base que puede usarse para leer los UID de proyecto de archivos Primavera XER o XML de múltiples proyectos.

El tipo PrimaveraBaseReader expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_project_uids() | Devuelve una lista de los identificadores únicos de los proyectos. |
| get_project_infos() | Devuelve una lista de los objetos de información breve del proyecto. |
| load_project(project_uid) | Carga el proyecto con el identificador único especificado. |
