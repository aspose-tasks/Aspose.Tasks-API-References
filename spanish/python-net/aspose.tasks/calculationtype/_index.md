## CalculationType enumeration

Especifica el tipo de cálculo del valor del atributo personalizado.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | Significa que el atributo extendido no tiene tabla de búsqueda de fórmula y simplemente almacena el valor establecido por el usuario. |
| LOOKUP | Significa que el valor del atributo extendido está restringido a valores de una tabla de búsqueda. |
| FORMULA | Significa que el valor del atributo extendido se calcula usando la fórmula definida en [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
