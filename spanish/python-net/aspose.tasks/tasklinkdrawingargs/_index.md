## TaskLinkDrawingArgs class

Proporciona argumentos para la devolución de llamada que se invoca cuando se renderiza el enlace de tarea.

El tipo TaskLinkDrawingArgs expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| link | Obtiene el enlace de tarea renderizado. |
| color | Obtiene o establece el color utilizado para renderizar el enlace de tarea. Puede usarse para personalizar los colores de los enlaces de tarea. |
