## Project class

Representa un proyecto.

El tipo Project expone los siguientes miembros:

| Project(project_template, options) | Inicializa una nueva instancia de la clase [Project](/tasks/python-net/aspose.tasks/project/) a partir de una plantilla (archivo MPP o MPT existente) <br/>            con la instancia especificada de la clase [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/). |
