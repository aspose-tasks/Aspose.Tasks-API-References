## VbaModule class

Representa un módulo VBA.

El tipo VbaModule expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| atributos | Obtiene una colección de los atributos del módulo. |
| name | Obtiene un nombre del módulo VBA |
| type | Obtiene el tipo del módulo. |
| source_code | Obtiene o establece el código fuente del módulo VBA |
## Métodos
| Nombre | Descripción |
| :- | :- |
| create_procedural_module(name) | Crea una instancia de [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) con el tipo VbaModuleType.ProceduralModule. |
| create_class_module(name) | Crea una instancia de [VbaModule](/tasks/python-net/aspose.tasks/vbamodule/) con el tipo VbaModuleType.ClassModule. |
