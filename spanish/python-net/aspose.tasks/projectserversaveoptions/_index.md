## ProjectServerSaveOptions class

Permite especificar opciones adicionales cuando el proyecto se guarda en Project Server o Project Online.

El tipo ProjectServerSaveOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ProjectServerSaveOptions() | Inicializa una nueva instancia de la clase [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| project_name | Obtiene o establece el nombre de un proyecto que se muestra en la lista de proyectos de Project Server \ Project Online. Debe ser único dentro de la instancia de Project Server \ Project Online.<br/>            Si el valor se omite, se utilizará el valor de la propiedad Prj.Name. |
| project_guid | Obtiene o establece el identificador único de un proyecto. Debe ser único dentro de la instancia de Project Server \ Project Online. |
| timeout | Obtiene o establece el tiempo de espera utilizado al esperar el procesamiento de la solicitud de guardado del proyecto por el servicio de procesamiento de colas de Project Server. El valor predeterminado de esta propiedad es 1 minuto. |
| polling_interval | Obtiene o establece el intervalo entre solicitudes de estado de trabajos en cola. El valor predeterminado es 2 segundos. |
