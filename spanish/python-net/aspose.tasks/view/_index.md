## View class

Representa una vista en Project.

El tipo View expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| View() | Inicializa una nueva instancia de la clase [View](/tasks/python-net/aspose.tasks/view/). |
| View(view_screen) | Inicializa una nueva instancia de la clase [View](/tasks/python-net/aspose.tasks/view/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| filter | Obtiene o establece un filtro utilizado en una vista única. |
| grupo | Obtiene o establece un grupo de la vista única. |
| uid | Obtiene el identificador único de una vista. |
| highlight_filter | Obtiene o establece un valor que indica si Microsoft Project resalta el filtro para una vista única. |
| name | Obtiene o establece el nombre de un objeto View. |
| screen | Obtiene el tipo de pantalla para la vista única.<br/>            Solo lectura [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Obtiene el padre del objeto View.<br/>            Solo lectura [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Obtiene o establece una tabla de la vista única. |
| type | Obtiene el tipo de elemento en la vista única, como tareas o recursos.<br/>            Solo lectura [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Obtiene o establece un valor que indica si Microsoft Project muestra el nombre de la vista única en la lista desplegable Vista o Otras Vistas en la cinta de opciones. |
| page_info | Obtiene una instancia de la clase [page_info](/tasks/python-net/aspose.tasks/view/). Representa los datos de configuración de página que están presentes en el formato de archivo mpp. |
| visual_objects_placements | Obtiene una colección de objetos que representan la ubicación y apariencia de [OleObject](/tasks/python-net/aspose.tasks/oleobject/) en la vista. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| compare_to(other) | Compara la instancia actual con otro objeto del mismo tipo y devuelve un entero que indica si la instancia actual precede, sigue o se encuentra en la misma posición en el orden de clasificación que el otro objeto. |
