## VbaModuleType enumeration

Especifica el tipo de un módulo en un proyecto VBA.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| DOCUMENT_MODULE | Un tipo de elemento de proyecto VBA que especifica un módulo para macros incrustados y operaciones de acceso programático que están asociadas a un documento. |
| PROCEDURAL_MODULE | Un módulo que contiene una colección de subrutinas y funciones. |
| CLASS_MODULE | Un módulo que contiene la definición de un nuevo objeto. Cada instancia de una clase crea un nuevo objeto, y los procedimientos que se definen en el módulo se convierten en propiedades y métodos del objeto. |
| DESIGNER_MODULE | Un módulo que amplía los métodos y propiedades de un control ActiveX que ha sido registrado en el proyecto. |
