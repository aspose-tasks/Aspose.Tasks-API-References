## GraphicalIndicatorCriteria class

Representa un criterio de indicador gráfico asociado a un atributo extendido.

El tipo GraphicalIndicatorCriteria expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Inicializa una nueva instancia de la clase GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Inicializa una nueva instancia de la clase GraphicalIndicatorCriteria |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| test | Obtiene el tipo de comparación realizado entre el valor del atributo extendido y Valores que actúa como criterio para la aplicación del indicador gráfico.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Obtiene el valor utilizado para probar el valor del atributo extendido. |
| value2 | Obtiene el segundo valor utilizado para probar el valor del atributo extendido en caso de los tipos de comparación 'IsWithin' y 'IsNotWithin'. |
| image_index | Obtiene el índice de la imagen a mostrar cuando el campo cumple con el criterio. |
| row_type | Obtiene el valor del enum [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) que indica para qué filas se aplica el indicador. |
