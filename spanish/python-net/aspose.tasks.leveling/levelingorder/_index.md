## LevelingOrder enumeration

Define los valores posibles del orden de nivelación.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| STANDARD | Se tienen en cuenta las siguientes propiedades: relaciones de predecesores, holgura total (una tarea con mayor holgura total se retrasa primero), fecha de inicio, prioridad.<br/>            Este es el valor predeterminado. |
| ID_ONLY | Las tareas se retrasan en orden ascendente de Id. |
| PRIORITY_THEN_STANDARD | La prioridad se considera primero, luego las mismas propiedades que en Standard. |
