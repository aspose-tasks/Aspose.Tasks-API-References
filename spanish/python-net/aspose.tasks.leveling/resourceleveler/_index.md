## ResourceLeveler class

Contiene métodos de nivelación de recursos.

El tipo ResourceLeveler expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| clear_leveling(project) | Elimina cualquier retraso de nivelación que se haya añadido previamente al proyecto durante la nivelación de recursos. |
| clear_leveling(tasks) |  |
| level_resources(project, options) | Nivela las tareas para los recursos especificados utilizando las opciones de nivelación especificadas. |
| level_all(project) | Nivela las tareas para todos los recursos del proyecto usando las opciones de nivelación predeterminadas. |
