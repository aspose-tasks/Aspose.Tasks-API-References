## LevelingOptions class

Permite especificar los parámetros de nivelación de recursos.

El tipo LevelingOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LevelingOptions() | Inicializa una nueva instancia de la clase [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| start_date | Obtiene o establece la fecha de inicio del período de nivelación. El valor predeterminado es la fecha de inicio del proyecto. |
| finish_date | Obtiene o establece la fecha de fin del período de nivelación. El valor predeterminado es la fecha de finalización del proyecto. |
| recursos | Obtiene o establece la lista de recursos que serán nivelados. Si se establece null, todos los recursos del proyecto serán nivelados. |
| leveling_order | Obtiene el orden en que el algoritmo de nivelación retrasa las tareas que tienen sobreasignaciones.<br/>            Después de determinar las tareas que causan la sobreasignación y qué tareas pueden retrasarse, se utiliza el orden especificado para decidir qué tarea debe retrasarse primero. |
| message_level | Obtiene o establece el nivel de los mensajes de registro emitidos por Aspose.Tasks durante la nivelación de recursos. |
| message_handler | Obtiene o establece la devolución de llamada del manejador de mensajes que puede usarse para interceptar los mensajes de registro producidos por Aspose.Tasks durante la nivelación de recursos. |
