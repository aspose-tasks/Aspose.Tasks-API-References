## ProbabilityDistributionType enumeration

Especifica los tipos de distribuciones de probabilidad soportadas.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| UNIFORM | La distribución cuando cada valor se elige con igual probabilidad. |
| NORMAL | La distribución que a veces se llama informalmente curva de campana (distribución gaussiana). |
