## RiskAnalyzer class

Realiza una simulación de Monte Carlo basada en la configuración de análisis de riesgos especificada.

El tipo RiskAnalyzer expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| RiskAnalyzer(settings) | Inicializa una nueva instancia de la clase [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| settings | Obtiene o establece la instancia de la clase [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) que define la configuración necesaria para el análisis de riesgos. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| analyze(project) | Realiza el análisis de riesgos para el proyecto especificado. El análisis se basa en una simulación de Monte Carlo y el resultado es una instancia de la clase [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/). |
