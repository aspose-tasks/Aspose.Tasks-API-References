## RiskAnalysisResult class

Representa un resultado del análisis de riesgos.

El tipo RiskAnalysisResult expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| save_report(stream) | Guarda el informe de análisis de riesgos en el flujo en formato PDF. |
| save_report(file_name) | Guarda el informe de análisis de riesgos en la ruta de archivo especificada en formato PDF. |
| get_risk_items(item_type) | Devuelve una instancia de la [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) para el tipo de riesgo especificado. |
