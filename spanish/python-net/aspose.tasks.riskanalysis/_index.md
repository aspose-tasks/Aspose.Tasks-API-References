Contiene clases para crear el informe de análisis de riesgos.

## Clases
| Clase | Descripción |
| :- | :- |
| [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) | Representa un resultado del análisis de riesgos. |
| [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) | Especifica la configuración para realizar el análisis de riesgos. |
| [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) | Realiza una simulación de Monte Carlo basada en la configuración de análisis de riesgos especificada. |
| [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) | Representa un elemento que almacena datos estadísticos para la tarea del proyecto analizado. |
| [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) | Representa una colección que contiene las instancias de la clase [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) | Representa un patrón de riesgo para una tarea de proyecto. |
| [RiskPatternCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskpatterncollection/) | Representa una colección que contiene las instancias de la clase [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
## Enumeraciones
