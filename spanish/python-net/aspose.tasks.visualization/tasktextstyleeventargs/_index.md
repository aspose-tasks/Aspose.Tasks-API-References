## TaskTextStyleEventArgs class

Esta clase representa un conjunto de datos relacionados con la renderización del contenido de la celda de la tabla.

El tipo TaskTextStyleEventArgs expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| cell_text_style | Obtiene o establece TextStyle que se utilizará para dibujar el contenido de la celda. Este objeto puede usarse para personalizar la apariencia de una celda de tabla. |
| task | Obtiene [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) que corresponde a la fila renderizada actualmente. |
| column | Obtiene [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) a la que pertenece la celda renderizada actualmente. |
