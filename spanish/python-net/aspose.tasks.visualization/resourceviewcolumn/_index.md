## ResourceViewColumn class

Clase de vista del proyecto utilizada en la vista ResourceUsage y en la vista ResourceSheet.

El tipo ResourceViewColumn expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ResourceViewColumn(width, field) | Inicializa una nueva instancia de la clase ResourceViewColumn |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| field | Campo de columna. <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/). |
| name | Obtiene el nombre de la columna. |
| string_alignment | Obtiene o establece la alineación del texto (puede ser uno de los valores de la enumeración [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Obtiene el ancho de la columna. |
| text_style_modification_callback | Obtiene o establece la función de devolución de llamada que puede usarse para personalizar la apariencia de las celdas de la columna. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_column_text(resource) | Convierte el recurso actual al texto de la columna. |
