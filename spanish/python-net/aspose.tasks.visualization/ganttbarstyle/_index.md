## GanttBarStyle class

Representa un estilo de barra usado por MSP en la vista de diagrama de Gantt.

El tipo GanttBarStyle expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| GanttBarStyle() | Inicializa una nueva instancia de la clase [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| bottom_field | Obtiene o establece los datos que se mostrarán en la parte inferior de la barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| end_shape | Obtiene o establece una forma final de la barra. |
| end_shape_color | Obtiene o establece un color de la forma final. |
| end_shape_type | Obtiene o establece un tipo de la forma final.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| from_address | Obtiene o establece la posición del punto de inicio de la barra Gantt.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | Obtiene o establece los datos que se mostrarán dentro de la barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| left_field | Obtiene o establece los datos que se mostrarán a la izquierda de la barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| middle_fill_pattern | Obtiene o establece un patrón de relleno de la barra Gantt. |
| middle_shape | Obtiene o establece una forma intermedia de la barra. |
| middle_shape_color | Obtiene o establece un color de la forma intermedia. |
| name | Obtiene o establece un nombre del estilo. |
| right_field | Obtiene o establece los datos que se mostrarán a la derecha de la barra.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| row | Obtiene o establece un número de fila. |
| show_for_categories | Obtiene o establece las categorías de tareas para las que se aplica el estilo. Es aplicable a los estilos padre (o comunes) de las barras en el diagrama de Gantt<br/>            (ver [bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| show_for_task_uid | Obtiene o establece el Id único de una tarea para la que se aplica el estilo. Es aplicable a los estilos de barra específicos de tareas en el diagrama de Gantt (ver [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | Obtiene o establece una forma de inicio de la barra. |
| start_shape_color | Obtiene o establece un color de la forma de inicio. |
| start_shape_type | Obtiene o establece un tipo de la forma de inicio. |
| to | Obtiene o establece la posición del punto de finalización de la barra de Gantt. |
| top_field | Obtiene o establece los datos que se mostrarán en la parte superior de la barra. |
| parent_style | Obtiene o establece el estilo padre (o común) para un estilo personalizado específico de tarea. |
