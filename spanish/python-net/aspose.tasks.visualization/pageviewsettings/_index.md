## PageViewSettings class

Representa la configuración de impresión para la vista del proyecto.

El tipo PageViewSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PageViewSettings() | Inicializa una nueva instancia de la clase PageViewSettings |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| first_columns_count | Obtiene o establece el número de primeras columnas que se imprimirán en todas las páginas. |
| fit_timescale_to_end_of_page | Obtiene o establece un valor que indica si se ajusta la escala de tiempo al final de una página al imprimir. |
| print_all_sheet_columns | Obtiene o establece un valor que indica si se imprimen todas las columnas de la hoja de una vista. |
| print_blank_pages | Obtiene o establece un valor que indica si se imprimen páginas en blanco de una vista. |
| print_first_columns_count_on_all_pages | Obtiene o establece un valor que indica si se imprimen un número especificado de primeras columnas en todas las páginas. |
| print_notes | Obtiene o establece un valor que indica si se imprimen notas. |
