## BarShape enumeration

Forma del rectángulo de una barra.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| FULL | Indica la forma de barra rectangular Full. |
| HALF_HEIGHT | Indica la forma de barra rectangular de media altura alineada en la parte superior. |
| HALF_HEIGHT_BOTTOM | Indica la forma de barra rectangular de media altura alineada en la parte inferior. |
| THIN | Indica una forma de línea centrada. |
| NONE | Indica la forma de barra None. |
| MIDDLE | Indica una forma de línea centrada. |
| LINE_BOTTOM | Indica una forma de línea alineada en la parte inferior. |
| LINE_TOP | Indica una forma de línea alineada en la parte superior. |
