## ITextStyleModificationCallback class

Representa una devolución de llamada que se invoca antes de que se aplique TextStyle a una celda de tabla.

El tipo ITextStyleModificationCallback expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| before_task_text_style_applied(args) | El método que se llamará antes de renderizar una celda de tabla para una fila de tarea en las siguientes vistas:<br/>            'Gantt Chart', 'Task Sheet', 'Task Usage'. |
