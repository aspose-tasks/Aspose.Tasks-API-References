## TimescaleTier class

Representa un nivel único de la escala de tiempo en un diagrama de Gantt.

El tipo TimescaleTier expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TimescaleTier() | Inicializa una nueva instancia de la clase [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Inicializa una nueva instancia de la clase TimescaleTier |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| count | Obtiene o establece el intervalo de unidad de tiempo en el que se mostrarán las etiquetas para el nivel.<br/>            El valor predeterminado es 1. |
| label | Obtiene o establece la etiqueta de fecha [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) para el nivel de escala de tiempo. |
| alignment | Obtiene o establece cómo alinear las etiquetas dentro de cada período de tiempo del nivel ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Obtiene o establece un valor que indica si las etiquetas del nivel se basan en el año fiscal. |
| show_ticks | Obtiene o establece un valor que indica si se deben mostrar marcas de graduación que separan los períodos de tiempo en el nivel. |
| unit | Obtiene o establece la unidad de escala de tiempo [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) para el nivel de escala de tiempo.<br/>            El valor predeterminado es |
| render_label_on_each_page | Obtiene o establece la bandera que define si las etiquetas de fecha deben renderizarse en cada página cuando un período de tiempo se extiende a varias páginas.<br/>            Si el valor es 'true', cuando el período de tiempo se extiende a varias páginas, las etiquetas de fecha para el período se renderizan en cada página.<br/>            Si el valor es 'false', la etiqueta de fecha se renderiza solo una vez según el valor de la propiedad [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
