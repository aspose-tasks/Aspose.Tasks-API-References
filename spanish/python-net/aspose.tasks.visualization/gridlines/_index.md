## Gridlines class

Representa las líneas de cuadrícula que aparecen en una vista de GanttChart.

El tipo Gridlines expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Gridlines() | Inicializa una nueva instancia de la clase Gridlines |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| interval | Obtiene o establece el número de 0 a 99 que especifica el intervalo entre líneas de cuadrícula. |
| interval_color | Obtiene o establece el color de las líneas de cuadrícula secundarias. |
| interval_pattern | Obtiene o establece el patrón de línea para las líneas de cuadrícula secundarias. |
| normal_color | Obtiene o establece el color de las líneas de cuadrícula normales. |
| normal_pattern | Obtiene o establece el patrón de línea para las líneas de cuadrícula normales. |
| type | Obtiene o establece el tipo de línea de cuadrícula. |
