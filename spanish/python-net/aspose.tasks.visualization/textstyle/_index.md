## TextStyle class

Cambia el estilo visual del texto para un elemento en la vista del proyecto.

El tipo TextStyle expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextStyle() | Inicializa una nueva instancia de la clase [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) con la configuración predeterminada. |
| TextStyle(font_size, font_style) | Inicializa una nueva instancia de la clase TextStyle |
| TextStyle(font_style) | Inicializa una nueva instancia de la clase [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) con la fuente predeterminada y el tamaño y estilo de fuente especificados. |
| TextStyle(font) | Inicializa una nueva instancia de la clase [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) con los ajustes de fuente especificados. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| font | Obtiene o establece la fuente del estilo de texto. |
| color | Obtiene o establece el color del texto. |
| item_type | Obtiene o establece [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) del estilo de texto. |
| background_pattern | Obtiene o establece el patrón de fondo del estilo de texto.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Obtiene o establece el color de fondo del estilo de texto.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
