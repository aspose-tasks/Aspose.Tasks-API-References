## Gridline class

La línea horizontal o vertical que aparece en la vista del proyecto.

El tipo Gridline expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Gridline() | Inicializa una nueva instancia de la clase [Gridline](/tasks/python-net/aspose.tasks.visualization/gridline/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| color | Obtiene o establece el [color](/tasks/python-net/aspose.tasks.visualization/gridline/) de un gridline. |
| gridline_type | Obtiene o establece el tipo de gridline ([gridline_type](/tasks/python-net/aspose.tasks.visualization/gridline/)). |
