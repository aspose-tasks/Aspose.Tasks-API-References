## PageInfo class

Representa los datos de configuración de página que están presentes en el formato de archivo MPP y se usan para la impresión.

El tipo PageInfo expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PageInfo() | Inicializa una nueva instancia de la clase [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/). <br/>            Representa los datos de configuración de página que están presentes en el formato de archivo MPP y se utilizan para imprimir. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| header | Obtiene o establece la instancia de la clase [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) que representa los datos de encabezado. |
| footer | Obtiene o establece una instancia de la clase [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) que representa los datos de pie de página. |
| name | Obtiene el nombre de la vista para la cual se utilizan los datos de configuración. |
| page_settings | Obtiene una instancia de la clase [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) que especifica la configuración de impresión de página. |
| page_view_settings | Obtiene una instancia de la clase [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) que especifica la configuración de impresión de vista de página. |
| margins | Obtiene una instancia de la clase [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) que especifica los márgenes de página. |
| legend | Obtiene o establece una instancia de la clase [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) que especifica las opciones de renderizado de la leyenda de página. |
