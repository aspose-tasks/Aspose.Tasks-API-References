## PageSettings class

Representa la configuración de impresión para una página de la vista del proyecto.

El tipo PageSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PageSettings() | Inicializa una nueva instancia de la clase [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Representa la configuración de impresión para una página de la vista del proyecto. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_portrait | Obtiene o establece un valor que indica si la orientación de la página es vertical; devuelve false si la orientación de la página es horizontal. |
| adjust_to_percent_of_normal_size | Obtiene o establece un valor que indica si se debe ajustar la impresión al porcentaje especificado ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) del tamaño normal. |
| percent_of_normal_size | Obtiene o establece un porcentaje del tamaño normal para ajustar la impresión. |
| pages_in_width | Obtiene o establece un número de páginas en ancho que se imprimirán. |
| pages_in_height | Obtiene o establece un número de páginas en alto que se imprimirán. |
| paper_size | Obtiene o establece un tamaño de papel. Puede ser uno de los valores de la enumeración [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | Obtiene o establece un entero que representa uno de los valores de PrinterPaperSize o un id de tamaño de página personalizado.<br/>            Este valor puede usarse para obtener PaperSize de la configuración del SO |
| first_page_number | Obtiene o establece un número de primera página para la impresión. |
