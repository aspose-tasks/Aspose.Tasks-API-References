## PageLegend class

Representa una leyenda de página que se usa para la impresión del proyecto.

El tipo PageLegend expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PageLegend() | Inicializa una nueva instancia de la clase PageLegend |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| left_text | Obtiene o establece el texto alineado a la izquierda que se mostrará en el elemento padre. |
| centered_text | Obtiene o establece el texto centrado que se mostrará en el elemento padre. |
| right_text | Obtiene o establece el texto alineado a la derecha que se mostrará en el elemento padre. |
| left_image | Obtiene o establece la imagen alineada a la izquierda que se mostrará en el elemento padre. |
| centered_image | Obtiene o establece la imagen centrada que se mostrará en el elemento padre. |
| right_image | Obtiene o establece la imagen alineada a la derecha que se mostrará en el elemento padre. |
| left_image_size | Obtiene o establece el tamaño mostrado de la imagen izquierda. |
| centered_image_size | Obtiene o establece el tamaño mostrado de la imagen central. |
| right_image_size | Obtiene o establece el tamaño mostrado de la imagen derecha. |
| legend_on | Obtiene o establece las páginas en las que aparece la leyenda. Puede ser uno de los valores de la enumeración [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | Obtiene o establece el ancho de la parte izquierda (que contiene el nombre y la fecha del proyecto por defecto) de la leyenda en centímetros. |
