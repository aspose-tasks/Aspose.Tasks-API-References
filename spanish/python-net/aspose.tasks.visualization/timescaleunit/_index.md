## TimescaleUnit enumeration

Especifica la unidad de tiempo para cualquier nivel de una escala de tiempo en un diagrama de Gantt u otra vista con fases de tiempo.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | Indica Ninguno. El nivel de escala de tiempo está oculto. |
| MINUTES | Indica la unidad de escala de tiempo en minutos. |
| HOURS | Indica la unidad de escala de tiempo Horas. |
| DAYS | Indica la unidad de escala de tiempo Días. |
| WEEKS | Indica la unidad de escala de tiempo Semanas. |
| THIRDS_OF_MONTHS | Indica la unidad de escala de tiempo Tercios de mes. |
| MONTHS | Indica la unidad de escala de tiempo Meses. |
| QUARTERS | Indica la unidad de escala de tiempo Trimestres de años. |
| HALF_YEARS | Indica la unidad de escala de tiempo Semestres. |
| YEARS | Indica la unidad de escala de tiempo Años. |
