## PageMargins class

Representa los márgenes de página para la impresión.

El tipo PageMargins expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PageMargins() | Inicializa una nueva instancia de la clase PageMargins |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| top | Obtiene o establece el tamaño del margen superior en centímetros. |
| bottom | Obtiene o establece el tamaño del margen inferior en centímetros. |
| left | Obtiene o establece el tamaño del margen izquierdo en centímetros. |
| right | Obtiene o establece el tamaño del margen derecho en centímetros. |
| borders | Obtiene o establece una posición donde imprimir los bordes. Puede ser uno de los valores de la enumeración [Border](/tasks/python-net/aspose.tasks.visualization/border/). |
