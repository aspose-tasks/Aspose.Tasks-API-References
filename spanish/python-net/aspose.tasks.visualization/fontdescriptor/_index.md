## FontDescriptor class

Representa información de la fuente.

El tipo FontDescriptor expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| FontDescriptor(font_family, size) | Inicializa una nueva instancia de la clase FontDescriptor |
| FontDescriptor(font_family, size, style) | Inicializa una nueva instancia de la clase FontDescriptor |
| FontDescriptor(font, style) | Inicializa una nueva instancia de la clase [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) con la familia de fuente, tamaño y estilo especificados. |

| Nombre | Descripción |
| :- | :- |

| size | Obtiene el tamaño de la fuente. |
| style | Obtiene el estilo de la fuente. |
