## RecurringInterval class

Representa los intervalos recurrentes utilizados en las líneas de progreso de una vista de diagrama de Gantt.

El tipo RecurringInterval expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| RecurringInterval() | Inicializa una nueva instancia de la clase RecurringInterval |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| interval | Obtiene o establece el intervalo recurrente.<br/>            Puede ser cualquier valor del tipo [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | Obtiene o establece el número de día diario. |
| daily_workday | Obtiene o establece un valor que indica si un día es laborable para las líneas de progreso diario. |
| weekly_week_number | Obtiene o establece el número de semana para las líneas de progreso semanales. |
| monthly_day | Obtiene o establece un valor que indica si se deben mostrar las líneas de progreso mensuales por día. |
| monthly_day_day_number | Obtiene o establece el número de día de las líneas de progreso mensuales. |
| monthly_day_month_number | Obtiene o establece el número de mes de las líneas de progreso mensuales. |
| monthly_first_last | Obtiene o establece un valor que indica si se deben mostrar las líneas de progreso por el primer o último día predefinido. |
| monthly_first_last_month_number | Obtiene o establece el número de mes de las líneas de progreso, que se muestran por el primer o último día predefinido. |
| monthly_first_last_day | Obtiene o establece el tipo de día primero o último de las líneas de progreso mensuales. |
| weekly_days | Obtiene una lista de días para las líneas de progreso semanales. |
