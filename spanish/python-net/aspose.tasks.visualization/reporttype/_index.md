## ReportType enumeration

Tipo del informe gráfico del proyecto.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| PROJECT_OVERVIEW | Muestra la fecha de inicio y finalización del proyecto, <br/>            porcentaje de duración completado, porcentaje completado para tareas de nivel superior y próximos hitos. |
| COST_OVERVIEW | Muestra las fechas de inicio y finalización del proyecto, el costo programado y restante actual<br/>            , % Completado y valores de costo para tareas de nivel superior. |
| WORK_OVERVIEW | Muestra la línea base, el trabajo real y restante para cada tarea de nivel superior y el trabajo para los recursos de trabajo. |
| RESOURCE_OVERVIEW | Muestra la línea base, el trabajo real y restante por recurso. |
| RESOURCE_COST_OVERVIEW | Muestra la línea base, el costo real y restante por recurso. |
| CRITICAL_TASKS | Muestra las tareas del proyecto que son críticas. |
| LATE_TASKS | Muestra las tareas del proyecto que están atrasadas. |
| MILESTONES | Muestra los hitos que están atrasados, próximos y completados. |
| UPCOMING_TASK | Muestra las tareas que vencen durante la semana actual y las tareas que comienzan durante la semana actual. |
| COST_OVERRUNS | Muestra la variación de costos por tarea y recurso. |
| TASK_COST_OVERVIEW | Muestra el costo base, real y restante de todas las tareas de nivel superior. |
| OVERALLOCATED_RESOURCES | Muestra el número de horas de trabajo restantes para recursos sobreasignados. |
| SLIPPING_TASKS | Muestra las tareas que deben terminar después de sus fechas de finalización base (la base debe estar establecida). |
| BEST_PRACTICE_ANALYZER | Muestra tareas sin trabajo real, tareas no asignadas, <br/>            tareas con una duración inferior a 8 horas y resúmenes asignados con los recursos. |
| BURNDOWN | Incluye gráficos de burndown de trabajo y de tareas.<br/>            El gráfico de burndown de trabajo muestra cuánto trabajo han terminado las personas, cuánto está programado para terminar antes de la fecha de finalización del proyecto, <br/>            y la estimación base de cuánto trabajo se completaría en este punto del proyecto.<br/>            El gráfico de burndown de tareas muestra el número de tareas terminadas, el número restante, <br/>            y la estimación base de cuántas se terminarían en este punto del proyecto. |
| CASH_FLOW | Muestra los costos y costos acumulados por trimestre para todas las tareas de nivel superior. |
