## VisualObjectPlacement class

Representa la ubicación y apariencia de [OleObject](/tasks/python-net/aspose.tasks/oleobject/) en una vista.

El tipo VisualObjectPlacement expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| VisualObjectPlacement() | Inicializa una nueva instancia de la clase [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| ole_object_id | Obtiene o establece el Id del objeto [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
| task_id | Obtiene o establece el Id de la tarea si la opción 'Attach to task' está seleccionada, -1 en caso contrario. |
| width | Obtiene o establece el ancho mostrado del objeto visual. |
| height | Obtiene o establece la altura mostrada del objeto visual. |
| vertical_offset | Obtiene o establece el desplazamiento vertical del objeto visual. |
| horizontal_offset | Obtiene o establece el desplazamiento horizontal del objeto visual. |
| timescale_date | Obtiene o establece la fecha de colocación del objeto visual cuando la opción 'Attach to timescale' está seleccionada. |
| attachment_point | Obtiene o establece la alineación del objeto visual respecto a una tarea cuando la opción 'Attach to task' está seleccionada. |
| border_line_color | Obtiene o establece el color de la línea del borde. |
| border_line_thickness | Obtiene o establece el grosor de la línea del borde (los valores permitidos son 0 - 5). |
| fill_color | Obtiene o establece el color de relleno. |
| fill_pattern | Obtiene o establece el patrón de relleno. |
