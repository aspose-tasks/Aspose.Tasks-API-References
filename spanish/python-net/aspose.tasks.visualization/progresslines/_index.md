## ProgressLines class

Representa las líneas de progreso en una vista de diagrama de Gantt.

El tipo ProgressLines expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ProgressLines() | Inicializa una nueva instancia de la clase ProgressLines |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| display_at_current_date | Obtiene o establece un valor que indica si se muestra la línea de progreso en la fecha actual. |
| display_at_recurring_intervals | Obtiene o establece un valor que indica si se muestra la línea de progreso en intervalos recurrentes. |
| recurring_interval | Obtiene o establece el intervalo recurrente.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Obtiene o establece un valor que indica si se muestran las líneas de progreso desde el inicio de la fecha de comienzo del proyecto. |
| begin_at_date | Obtiene o establece la fecha a partir de la cual se muestran las líneas de progreso. |
| display_selected | Obtiene o establece un valor que indica si se muestran las líneas de progreso en las fechas seleccionadas. |
| is_baseline_plan | Obtiene o establece un valor que indica si se muestran las líneas de progreso para el plan de referencia o el real. |
| show_date | Obtiene o establece un valor que indica si se muestra la fecha para cada línea de progreso. |
| date_format | Obtiene o establece el formato de fecha ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Obtiene o establece la fuente utilizada para la etiqueta de la línea de progreso. |
| line_pattern | Obtiene o establece el patrón de línea de la línea de progreso actual.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Obtiene o establece el color de línea para la línea de progreso actual. |
| progress_point_shape | Obtiene o establece la forma del punto de progreso.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Obtiene o establece el color del punto de progreso. |
| other_line_pattern | Obtiene o establece el patrón de línea para la otra línea de progreso. |
| other_line_color | Obtiene o establece el color de la otra línea de progreso. |
| other_progress_point_shape | Obtiene o establece la forma del punto de progreso de la otra línea de progreso. |
| other_progress_point_color | Obtiene o establece el color del otro punto de progreso. |
| selected_dates | Obtiene la lista de fechas seleccionadas para mostrar líneas de progreso. |
