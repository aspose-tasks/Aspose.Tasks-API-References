Contiene clases para trabajar con bases de datos.

## Clases
| Clase | Descripción |
| :- | :- |
| [DbSettings](/tasks/python-net/aspose.tasks.connectivity/dbsettings/) | Permite especificar la configuración para leer desde la base de datos del proyecto. |
| [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) | Permite establecer las opciones necesarias para leer datos del proyecto del formato MPD (formato de archivo de base de datos MS Access). |
| [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) | Permite establecer las opciones necesarias para leer datos del proyecto de la base de datos de MS Project Server. |
| [PrimaveraDbSettings](/tasks/python-net/aspose.tasks.connectivity/primaveradbsettings/) | Permite establecer las opciones necesarias para leer datos del proyecto de la base de datos Primavera. |
