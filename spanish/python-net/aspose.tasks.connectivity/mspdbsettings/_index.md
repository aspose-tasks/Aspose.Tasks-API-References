## MspDbSettings class

Permite establecer las opciones necesarias para leer datos del proyecto de la base de datos de MS Project Server.

El tipo MspDbSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Inicializa una nueva instancia de la clase [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| connection_string | Obtiene o establece la cadena de conexión. |
| provider_invariant_name | Obtiene o establece el nombre invariante del proveedor que se usa para obtener una instancia de la clase. |
| project_guid | Obtiene el GUID del proyecto a leer. |
| schema | Obtiene o establece el esquema del MS Project Server.<br/>            El valor predeterminado es "pub". |
