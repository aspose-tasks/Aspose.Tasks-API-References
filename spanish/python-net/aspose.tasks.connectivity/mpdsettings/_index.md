## MpdSettings class

Permite establecer las opciones necesarias para leer datos del proyecto del formato MPD (formato de archivo de base de datos MS Access).

El tipo MpdSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| MpdSettings(connection_string, project_id) | Inicializa una nueva instancia de la clase [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| connection_string | Obtiene o establece la cadena de conexión. |
| provider_invariant_name | Obtiene o establece el nombre invariante del proveedor que se usa para obtener una instancia de la clase. |
| project_id | Obtiene el id del proyecto a leer. |
