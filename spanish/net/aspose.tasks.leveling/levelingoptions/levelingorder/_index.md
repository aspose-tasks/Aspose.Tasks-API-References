## LevelingOptions.LevelingOrder property

Obtiene el orden en que el algoritmo de nivelado retrasa las tareas que tienen sobreasignaciones. Después de determinar las tareas que causan la sobreasignación y qué tareas pueden retrasarse, se utiliza el orden especificado para decidir cuál tarea debe retrasarse primero.

```csharp
public LevelingOrder LevelingOrder { get; set; }
```
