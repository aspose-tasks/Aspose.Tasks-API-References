## SaveOptions.FitTimescaleToEndOfPage property

Obtiene o establece si una sección de calendario de una vista debe renderizarse hasta el final (lado derecho) de la última página. Si el valor es false, la sección de calendario se renderiza exactamente hasta EndDate, aunque haya un espacio vacío en la página.

```csharp
public bool FitTimescaleToEndOfPage { get; set; }
```
