## HtmlSaveOptions.DefaultFontName property

Obtiene o establece la fuente predeterminada (o de respaldo) para el renderizado.

```csharp
public string DefaultFontName { get; set; }
```

### Ejemplos

Muestra cómo establecer una fuente personalizada que se utilizará para exportar el proyecto en un archivo HTML.

```csharp
var project = new Project(DataDir + "EstimatedMilestoneTasks.mpp");

var options = new HtmlSaveOptions
                  {
                      PresentationFormat = PresentationFormat.GanttChart,
                      FitContent = true,
                      UseProjectDefaultFont = false,
                      DefaultFontName = "Segoe UI Black"
                  };
project.Save(OutDir + "AddDefaultFontDuringSavingAsHtml_out.html", options);
```
