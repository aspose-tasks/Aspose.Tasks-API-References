Contiene clases necesarias para trabajar con formatos específicos de Primavera (XER, Primavera XML).

## Clases

| Clase | Descripción |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Representa información breve sobre un proyecto cargado desde el formato Primavera. |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [PrimaveraActivityType](./primaveraactivitytype/) | Especifica el tipo de actividad de Primavera. |
| [PrimaveraConstraintType](./primaveraconstrainttype/) | Especifica un tipo de restricción de la actividad. |
| [PrimaveraDurationType](./primaveradurationtype/) | Especifica el tipo de duración de la actividad de Primavera. |
| [PrimaveraPercentCompleteType](./primaverapercentcompletetype/) | Especifica el valor del campo '% Complete Type' para actividades de Primavera. |
| [PrimaveraRelationshipLagCalendar](./primaverarelationshiplagcalendar/) | Especifica qué calendario usar para programar el retraso de relaciones en proyectos de Primavera. |
