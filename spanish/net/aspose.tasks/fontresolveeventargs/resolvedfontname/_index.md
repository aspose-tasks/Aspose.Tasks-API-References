## FontResolveEventArgs.ResolvedFontName property

Obtiene o establece el nombre de la fuente resuelta. Puede establecerse para controlar las fuentes usadas al renderizar una vista.

```csharp
public string ResolvedFontName { get; set; }
```

### Valor devuelto

Nombre de la fuente solicitada si se encuentra la fuente, o nombre de la fuente de respaldo, o null si no se puede encontrar la fuente.
