## VbaModuleType enumeration

Especifica el tipo de módulo en un proyecto VBA.

```csharp
public enum VbaModuleType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| DocumentModule | `0` | Un tipo de elemento de proyecto VBA que especifica un módulo para macros incrustados y operaciones de acceso programático que están asociadas a un documento. |
| ProceduralModule | `1` | Un módulo que contiene una colección de subrutinas y funciones. |
| ClassModule | `2` | Un módulo que contiene la definición de un nuevo objeto. Cada instancia de una clase crea un nuevo objeto, y los procedimientos definidos en el módulo se convierten en propiedades y métodos del objeto. |
| DesignerModule | `3` | Un módulo que extiende los métodos y propiedades de un control ActiveX que ha sido registrado en el proyecto. |
