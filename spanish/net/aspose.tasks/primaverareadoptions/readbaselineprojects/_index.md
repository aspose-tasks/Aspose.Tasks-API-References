## PrimaveraReadOptions.ReadBaselineProjects property

Obtiene o establece una bandera que indica si los proyectos de línea base deben cargarse. El valor predeterminado es verdadero.

```csharp
public bool ReadBaselineProjects { get; set; }
```

## Observaciones

La bandera se aplica a archivos XML de Primavera que contienen proyectos de línea base (las líneas base no son compatibles con el formato XER). La opción puede establecerse en false para acelerar la carga de un proyecto grande con líneas base cuando no se necesitan los datos de línea base.
