## IProgressNotificationCallback interface

Representa una interfaz de devolución de llamada para recibir notificaciones durante operaciones de proyecto de larga duración.

```csharp
public interface IProgressNotificationCallback
```

| Nombre | Descripción |
| --- | --- |
| [Notify](../../aspose.tasks/iprogressnotificationcallback/notify/)(ProgressNotificationArgs) | Se llama durante operaciones de proyecto de larga duración para proporcionar información de progreso. |

## Observaciones

Esta interfaz permite a los clientes recibir actualizaciones de progreso. Implemente esta interfaz para rastrear el progreso de la operación.
