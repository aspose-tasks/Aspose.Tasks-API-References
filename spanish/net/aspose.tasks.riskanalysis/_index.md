Contiene clases para crear informes de análisis de riesgos.

## Clases

| Clase | Descripción |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | Representa un resultado del análisis de riesgos. |
| [RiskAnalysisSettings](./riskanalysissettings/) | Especifica la configuración para realizar el análisis de riesgos. |
| [RiskAnalyzer](./riskanalyzer/) | Ejecuta una simulación Monte Carlo basada en la configuración de análisis de riesgos especificada. |
| [RiskItemStatistics](./riskitemstatistics/) | Representa un elemento que almacena datos estadísticos para la tarea del proyecto analizado. |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | Representa una colección que contiene las instancias de la clase [`RiskItemStatistics`](../aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](./riskpattern/) | Representa un patrón de riesgo para una tarea del proyecto. |
| [RiskPatternCollection](./riskpatterncollection/) | Representa una colección que contiene las instancias de la clase [`RiskPattern`](../aspose.tasks.riskanalysis/riskpattern/). |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
| [ConfidenceLevel](./confidencelevel/) | Especifica los niveles de confianza admitidos utilizados en el análisis de riesgos que corresponden al porcentaje de tiempo en que los valores reales estarán dentro de las estimaciones optimistas y pesimistas. |
| [ProbabilityDistributionType](./probabilitydistributiontype/) | Especifica los tipos de distribuciones de probabilidad admitidas. |
| [RiskItemType](./riskitemtype/) | Especifica los campos de tarea para los que se recopila la información estadística durante el análisis de riesgos. |
