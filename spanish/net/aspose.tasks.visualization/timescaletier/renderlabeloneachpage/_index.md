## TimescaleTier.RenderLabelOnEachPage property

Obtiene o establece una bandera que define si las etiquetas de fecha deben renderizarse en cada página cuando un período de tiempo se extiende a varias páginas. Si el valor es 'true', cuando el período de tiempo se extiende a varias páginas, las etiquetas de fecha para el período se renderizan en cada página. Si el valor es 'false', la etiqueta de fecha se renderiza solo una vez según un valor de la propiedad [`Alignment`](../alignment/).

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
