Contiene clases para trabajar con bases de datos.

## Clases

| Clase | Descripción |
| --- | --- |
| [DbSettings](./dbsettings/) | Permite especificar configuraciones para leer de la base de datos del proyecto. |
| [MpdSettings](./mpdsettings/) | Permite establecer opciones necesarias para leer datos del proyecto desde el formato MPD (formato de archivo de base de datos MS Access). |
| [MspDbSettings](./mspdbsettings/) | Permite establecer opciones necesarias para leer datos del proyecto desde la base de datos de MS Project Server. |
| [PrimaveraDbSettings](./primaveradbsettings/) | Permite establecer opciones necesarias para leer datos del proyecto desde la base de datos de Primavera. |
