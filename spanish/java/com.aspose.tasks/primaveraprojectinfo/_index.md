### getExportFlag() {#getExportFlag--}
```
public final boolean getExportFlag()
```


Obtiene la bandera de exportación del proyecto. Cuando un proyecto se selecciona para exportar en Primavera, su ExportFlag es verdadero. Algunos proyectos no seleccionados explícitamente para exportar pueden exportarse a un archivo XER debido a su relación con el proyecto exportado.

**Returns:**
boolean - bandera de exportación del proyecto.
