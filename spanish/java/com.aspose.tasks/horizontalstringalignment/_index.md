Especifica la alineación de una cadena de texto respecto a su rectángulo de diseño.
## Campos

| Campo | Descripción |
| --- | --- |
| [Center](#Center) | Especifica que el texto está alineado en el centro del rectángulo de diseño. |
| [Far](#Far) | Especifica que el texto está alineado lejos de la posición de origen del rectángulo de diseño. |
| [Near](#Near) | Especifica que el texto esté alineado cerca del diseño. |
### Center {#Center}
```
public static final int Center
```


Especifica que el texto está alineado en el centro del rectángulo de diseño.

### Far {#Far}
```
public static final int Far
```


Especifica que el texto está alineado lejos de la posición de origen del rectángulo de diseño. En un diseño de izquierda a derecha, la posición lejana es a la derecha. En un diseño de derecha a izquierda, la posición lejana es a la izquierda.

### Near {#Near}
```
public static final int Near
```


Especifica que el texto esté alineado cerca del diseño. En un diseño de izquierda a derecha, la posición cercana es a la izquierda. En un diseño de derecha a izquierda, la posición cercana es a la derecha.
