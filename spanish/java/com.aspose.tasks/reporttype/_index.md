### Burndown {#Burndown}
```
public static final int Burndown
```


Incluye gráficos de burndown de trabajo y de tareas. El gráfico de burndown de trabajo muestra cuánto trabajo han terminado las personas, cuánto está programado para terminarse antes de la fecha de fin del proyecto, y la estimación de línea base de cuánto trabajo se completaría en este punto del proyecto. El gráfico de burndown de tareas muestra el número de tareas terminadas, el número restante y la estimación de línea base de cuántas se terminarían en este punto del proyecto.
