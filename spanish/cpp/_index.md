La API ofrece un modelo de objetos rico para manejar los formatos Project XML, MPX, MPP y Primavera XER, admitiendo tareas, recursos, asignaciones, calendarios y campos personalizados. Su funcionalidad está organizada en nueve espacios de nombres: Aspose::Tasks para entidades centrales, Connectivity para entrada/salida de archivos, Leveling para nivelación de recursos, Primavera para objetos específicos de Primavera, Properties para atributos extendidos, RiskAnalysis para modelado de riesgos Monte‑Carlo, Saving para opciones de exportación, Util para utilidades auxiliares y Visualization para la renderización de diagramas de Gantt e informes.

| [Aspose::Tasks::Connectivity](./aspose.tasks.connectivity/) | El espacio de nombres Aspose::Tasks::Connectivity suministra clases que definen configuraciones para conectar a diversas bases de datos de gestión de proyectos. |
| [Aspose::Tasks::Leveling](./aspose.tasks.leveling/) | El espacio de nombres Aspose::Tasks::Leveling ofrece clases para configurar y ejecutar la nivelación de recursos en los cronogramas de proyectos. |
| [Aspose::Tasks::Primavera](./aspose.tasks.primavera/) | Proporciona tipos para manejar datos de proyectos Primavera dentro de Aspose.Tasks for C++. |
