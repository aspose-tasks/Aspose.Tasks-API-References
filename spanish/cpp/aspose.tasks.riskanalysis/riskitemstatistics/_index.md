## RiskItemStatistics class

Representa un elemento que almacena datos estadísticos para la tarea del proyecto analizado.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | Obtiene el valor esperado del elemento de riesgo. |
| [get_ItemType](./get_itemtype/) | Obtiene una instancia de la enumeración RiskItemType. |
| [get_Maximum](./get_maximum/) | Obtiene el valor máximo que se generó durante la simulación Monte Carlo. |
| [get_Minimum](./get_minimum/) | Obtiene el valor mínimo que se generó durante la simulación Monte Carlo. |
| [get_StandardDeviation](./get_standarddeviation/) | Obtiene la desviación estándar del elemento de riesgo. |
| [GetPercentile](./getpercentile/) | Obtiene un valor por debajo del cual cae un porcentaje especificado de muestras generadas. |
| [ToString](./tostring/) | Devuelve una representación corta en forma de cadena de un elemento de riesgo. Los detalles exactos de la representación no están especificados y pueden cambiar. |
