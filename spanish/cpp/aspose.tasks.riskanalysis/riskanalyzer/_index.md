## RiskAnalyzer class

Ejecuta una simulación de Monte Carlo basada en la configuración de análisis de riesgos especificada.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [RiskAnalyzer](./riskanalyzer/) | Inicializa una nueva instancia de la clase RiskAnalyzer. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [Analyze](./analyze/) | Realiza un análisis de riesgos para el proyecto especificado. El análisis se basa en una simulación Monte Carlo y el resultado es una instancia de la clase RiskAnalysisResult. |
| [get_Settings](./get_settings/) | Obtiene la instancia de la clase RiskAnalysisSettings que define los ajustes necesarios para el análisis de riesgos. |
| [set_Settings](./set_settings/) | Establece la instancia de la clase RiskAnalysisSettings que define los ajustes necesarios para el análisis de riesgos. |
