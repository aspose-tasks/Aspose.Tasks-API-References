## Analyze {#analyze}

Realiza un análisis de riesgos para el proyecto especificado. El análisis se basa en una simulación Monte Carlo y el resultado es una instancia de la clase RiskAnalysisResult.

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| Parámetro | Descripción |
| --- | --- |
| proyecto | la instancia especificada de la clase Project para analizar. |
