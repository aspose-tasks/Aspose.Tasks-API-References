## ListUtils class

Clase de utilidad para el procesamiento de listas.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [Apply](./apply/) | Aplica el algoritmo a cada elemento de la lista a partir de la posición especificada. |
| [Filter](./filter/) | Filtra los elementos de la lista por la condición especificada. |
| [Find](./find/) | Encuentra la primera aparición de un elemento de lista que cumpla la condición especificada. |
