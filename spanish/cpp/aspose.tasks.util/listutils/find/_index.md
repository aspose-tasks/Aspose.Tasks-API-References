## Find {#find}

Encuentra la primera aparición de un elemento de lista que cumpla la condición especificada.

**Returns:** List element or null.

```cpp
Find(const System::SharedPtr< System::Collections::Generic::IList< T >> & list, const System::SharedPtr< ICondition < T >> & cond)
```

| Parámetro | Descripción |
| --- | --- |
| lista | Una lista para procesar. |
| cond | Condición usada para encontrar un elemento en la lista especificada. |
