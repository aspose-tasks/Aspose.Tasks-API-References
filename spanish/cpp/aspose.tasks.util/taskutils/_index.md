## TaskUtils class

Clase auxiliar que proporciona operaciones útiles con tareas.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [Apply](./apply/) | Aplica el algoritmo especificado a cada tarea de un árbol. |
| [Filter](./filter/) | Construye un nuevo árbol de tareas que cumplen la condición. |
| [Find](./find/) | Encuentra una tarea que cumple la condición en un árbol de tareas. |
| [TaskChildrenCount](./taskchildrencount/) | Calcula recursivamente el número de tareas hijas de una tarea a través de todos los niveles. |
