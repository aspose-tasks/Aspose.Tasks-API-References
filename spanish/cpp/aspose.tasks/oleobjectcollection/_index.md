## OleObjectCollection class

Representa una colección que contiene las instancias de la clase OleObject.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [Clear](./clear/) | Borra la colección. Para que estos cambios persistan, se debe llamar a project.Save con new MPPSaveOptions { WriteViewData = true; } |
| [GetEnumerator](./getenumerator/) | Devuelve un enumerador para esta colección. |
| [ToList](./tolist/) | Convierte la instancia de la clase OleObjectCollection en una lista que contiene las instancias de la clase OleObject. |
