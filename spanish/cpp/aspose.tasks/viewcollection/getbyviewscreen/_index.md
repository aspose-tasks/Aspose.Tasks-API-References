## GetByViewScreen {#getbyviewscreen}

Busca una View con la propiedad Screen especificada y devuelve la primera ocurrencia dentro de la colección.

**Returns:** The first View in collection which Screen property matches the specified screen argument, if found; otherwise, null.

```cpp
GetByViewScreen(ViewScreen screen)
```

| Parámetro | Descripción |
| --- | --- |
| screen | Valor de enumeración ViewScreen. |
