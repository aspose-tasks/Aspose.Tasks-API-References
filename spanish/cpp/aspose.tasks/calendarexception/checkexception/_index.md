## CheckException {#checkexception}

Devuelve true si la instancia especificada de la estructura DateTime es el día de excepción.

**Returns:** Returns true if DateTime value is the exception day; otherwise, false.

```cpp
CheckException(System::DateTime dt)
```

| Parámetro | Descripción |
| --- | --- |
| dt | la instancia especificada de la estructura DateTime. |
