## PrimaveraReadOptions class

Permite especificar opciones adicionales al leer archivos Primavera Xml o Primavera Xer.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [PrimaveraReadOptions](./primaverareadoptions/) | Inicializa una nueva instancia de la clase PrimaveraReadOptions. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_PreserveUids](./get_preserveuids/) | Obtiene una bandera que indica si se deben conservar los identificadores únicos originales de las entidades. |
| [get_ProjectUid](./get_projectuid/) | Obtiene el UID de un proyecto para leer del archivo que contiene varios proyectos. |
| [get_ReadBaselineProjects](./get_readbaselineprojects/) | Obtiene una bandera que indica si se deben cargar los proyectos de línea base. El valor predeterminado es verdadero. |
| [get_UndefinedConstraintHandlingBehavior](./get_undefinedconstrainthandlingbehavior/) | Especifica el comportamiento utilizado para procesar tareas con restricciones indefinidas leídas del formato XER. |
| [set_PreserveUids](./set_preserveuids/) | Establece una bandera que indica si se deben conservar los identificadores únicos originales de las entidades. |
| [set_ProjectUid](./set_projectuid/) | Establece el UID de un proyecto para leer del archivo que contiene varios proyectos. |
| [set_ReadBaselineProjects](./set_readbaselineprojects/) | Establece una bandera que indica si se deben cargar los proyectos de línea base. El valor predeterminado es verdadero. |
| [set_UndefinedConstraintHandlingBehavior](./set_undefinedconstrainthandlingbehavior/) | Especifica el comportamiento utilizado para procesar tareas con restricciones indefinidas leídas del formato XER. |
