## CompareTo {#compareto}

Implementación de la interfaz IComparable. Compara esta instancia con el objeto Baseline especificado.

**Returns:** returns -1 if this instance is less than the specified object, 1 if this instance is greater than the specified object; otherwise returns 0

```cpp
CompareTo(System::SharedPtr< Baseline > other)
```

| Parámetro | Descripción |
| --- | --- |
| otro | el objeto Baseline especificado para comparar con esta instancia. |
