## OleObject class

Representa un objeto OLE que puede insertarse en la vista de diagrama de Gantt de un archivo MPP.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [OleObject](./oleobject/) | Inicializa una nueva instancia de la clase OleObject. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_ApplicationName](./get_applicationname/) | Obtiene el nombre de la aplicación con la que abrir el objeto incrustado. |
| [get_Content](./get_content/) | Obtiene los datos del archivo incrustado; null si no se incrustó ningún dato. |
| [get_DisplayAsIcon](./get_displayasicon/) | Obtiene una bandera que indica si el objeto OLE debe mostrarse como un ícono o como su imagen regular. |
| [get_FileFormat](./get_fileformat/) | Obtiene el formato de archivo del objeto incrustado. |
| [get_FullPath](./get_fullpath/) | Obtiene la ruta completa del objeto insertado. |
| [get_Id](./get_id/) | Obtiene el id del objeto. |
| [get_Label](./get_label/) | Obtiene la etiqueta del objeto insertado. |
| [get_Linked](./get_linked/) | Obtiene un valor que indica si el archivo del proyecto contiene solo un enlace a los datos reales almacenados en la fuente del enlace. |
| [get_Name](./get_name/) | Obtiene el nombre de la instancia del objeto OLE. |
| [get_TemporaryFile](./get_temporaryfile/) | Obtiene la ruta al archivo temporal del objeto insertado. |
| [get_View](./get_view/) | Obtiene la instancia de la clase View a la que pertenece el objeto insertado. |
| [set_ApplicationName](./set_applicationname/) | Establece el nombre de la aplicación con la que abrir el objeto incrustado. |

| [set_FullPath](./set_fullpath/) | Establece la ruta completa del objeto insertado. |
| [set_Id](./set_id/) | Establece el id del objeto. |
| [set_Label](./set_label/) | Establece la etiqueta del objeto insertado. |
| [set_Name](./set_name/) | Establece el nombre de la instancia del objeto OLE. |
| [set_TemporaryFile](./set_temporaryfile/) | Establece la ruta al archivo temporal del objeto insertado. |
| [set_View](./set_view/) | Establece la instancia de la clase View a la que pertenece el objeto insertado. |
