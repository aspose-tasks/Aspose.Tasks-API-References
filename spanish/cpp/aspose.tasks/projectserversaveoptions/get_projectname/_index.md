## get_ProjectName {#get_projectname}

Obtiene el nombre de un proyecto que se muestra en la lista de proyectos de Project Server \ Project Online. Debe ser único dentro de la instancia de Project Server \ Project Online. Si el valor se omite, se utilizará el valor de la propiedad Prj.Name.

**Returns:** System::String Aspose::Tasks::

```cpp
get_ProjectName()
```
