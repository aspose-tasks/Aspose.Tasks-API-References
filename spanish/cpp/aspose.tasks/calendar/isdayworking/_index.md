## IsDayWorking {#isdayworking}

Determina si el día especificado es un día laborable según el calendario.

**Returns:** True if the day is a working day.

```cpp
IsDayWorking(System::DateTime dt)
```

| Parámetro | Descripción |
| --- | --- |
| dt | La fecha para comprobar si el día es laborable. |
