## Rate class

Representa una definición de un período de tiempo y tarifas aplicables a un recurso durante ese período.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Obtiene el costo por uso de un recurso. Este valor se recupera de la fecha actual si existe una tabla de tarifas para un recurso. |
| [get_OvertimeRate](./get_overtimerate/) | Obtiene la tarifa de horas extra por hora para un recurso. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Obtiene las unidades que usa Microsoft Project para mostrar la tarifa de horas extra. |
| [get_RatesFrom](./get_ratesfrom/) | Obtiene la fecha en que una tarifa entra en vigor. |
| [get_RatesTo](./get_ratesto/) | Obtiene la última fecha en que una tarifa es efectiva. |
| [get_RateTable](./get_ratetable/) | Obtiene el identificador único de una tabla de tarifas para un recurso. |
| [get_StandardRate](./get_standardrate/) | Obtiene la tarifa estándar por hora para un recurso. |
| [get_StandardRateFormat](./get_standardrateformat/) | Obtiene las unidades que usa Microsoft Project para mostrar la tarifa estándar. |
| [set_CostPerUse](./set_costperuse/) | Establece el costo por uso de un recurso. Este valor se recupera de la fecha actual si existe una tabla de tarifas para un recurso. |
| [set_OvertimeRate](./set_overtimerate/) | Establece la tarifa de horas extra por hora para un recurso. |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Establece las unidades que usa Microsoft Project para mostrar la tarifa de horas extra. |
| [set_RatesFrom](./set_ratesfrom/) | Establece la fecha en que una tarifa entra en vigor. |
| [set_RatesTo](./set_ratesto/) | Establece la última fecha en que una tarifa es efectiva. |
| [set_RateTable](./set_ratetable/) | Establece el identificador único de una tabla de tarifas para un recurso. |
| [set_StandardRate](./set_standardrate/) | Establece la tarifa estándar por hora para un recurso. |
| [set_StandardRateFormat](./set_standardrateformat/) | Establece las unidades que usa Microsoft Project para mostrar la tarifa estándar. |
