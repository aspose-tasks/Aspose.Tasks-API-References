## FontSettings class

Especifica la configuración de fuente utilizada al renderizar la vista del proyecto.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | Obtiene la fuente predeterminada (o de respaldo) para la renderización. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | Obtiene una devolución de llamada que puede usarse para personalizar las fuentes resueltas. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | Obtiene un valor que indica si la fuente predeterminada debe usarse para la renderización. |
| [set_DefaultFontName](./set_defaultfontname/) | Establece la fuente predeterminada (o de respaldo) para la renderización. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | Establece una devolución de llamada que puede usarse para personalizar las fuentes resueltas. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | Establece un valor que indica si se debe usar la fuente predeterminada para la renderización. |
| [SetFontFolders](./setfontfolders/) | Establece las carpetas donde Aspose.Tasks busca fuentes TrueType al renderizar la vista del proyecto. |
