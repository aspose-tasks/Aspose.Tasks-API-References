## RecurringTaskParameters class

Representa el conjunto de parámetros que se utilizan para crear una tarea recurrente en un proyecto.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [RecurringTaskParameters](./recurringtaskparameters/) | Inicializa una nueva instancia de la clase RecurringTaskParameters. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_Duration](./get_duration/) | Obtiene la duración de una ocurrencia de la tarea recurrente. |
| [get_IgnoreResourceCalendar](./get_ignoreresourcecalendar/) | Obtiene un valor que indica si programar la tarea recurrente incluso cuando no haya recursos disponibles para trabajar en ella. |
| [get_RecurrencePattern](./get_recurrencepattern/) | Obtiene el patrón de recurrencia de la tarea recurrente. |
| [get_TaskName](./get_taskname/) | Obtiene el nombre de la tarea recurrente. |
| [set_Duration](./set_duration/) | Establece la duración de una ocurrencia de la tarea recurrente. |
| [set_IgnoreResourceCalendar](./set_ignoreresourcecalendar/) | Establece un valor que indica si programar la tarea recurrente incluso cuando no haya recursos disponibles para trabajar en ella. |
| [set_RecurrencePattern](./set_recurrencepattern/) | Establece el patrón de recurrencia de la tarea recurrente. |
| [set_TaskName](./set_taskname/) | Establece el nombre de la tarea recurrente. |
| [SetCalendar](./setcalendar/) | Establece un calendario para la tarea recurrente. El calendario se selecciona de la colección de calendarios del proyecto. |
