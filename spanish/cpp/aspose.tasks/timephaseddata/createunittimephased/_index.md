## CreateUnitTimephased {#createunittimephased}

Crea e inicializa una nueva instancia de la clase Aspose::Tasks::TimephasedData para datos temporales basados en unidades de una asignación de un recurso material.

**Returns:** A instance of the Aspose::Tasks::TimephasedData class for cost-based time phased data.

```cpp
CreateUnitTimephased(int32_t uid, System::DateTime start, System::DateTime finish, double units, Aspose::Tasks::TimephasedDataType type)
```

| Parámetro | Descripción |
| --- | --- |
| uid | UID de la tarea. |
| inicio | Fecha y hora de inicio. |
| fin | fecha y hora de finalización. |
| unidades | Número de unidades. |
| type | Tipo de datos por fases de tiempo. |
