| [get_Count](./get_count/) | Obtiene el número de objetos contenidos en este objeto CalendarCollection. |
| [GetByName](./getbyname/) | Devuelve un calendario con el nombre especificado. |
| [GetByUid](./getbyuid/) | Devuelve un calendario con el UID especificado. |
| [GetEnumerator](./getenumerator/) | Devuelve un enumerador para esta colección. |
| [Remove](./remove/) | Elimina Calendar del CalendarCollection del proyecto. |
| [ToList](./tolist/) | Convierte el objeto CalendarCollection en una lista de objetos Calendar. |
