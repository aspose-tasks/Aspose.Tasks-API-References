## Metered class

Proporciona métodos para establecer la clave medida.

En este ejemplo, se intentará establecer la clave pública y privada medida <ms>

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> el archivo jar del componente:

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>

## Métodos

| Nombre | Descripción |
| --- | --- |
| [GetConsumptionCredit](./getconsumptioncredit/) | Obtiene crédito de consumo. |
| [GetConsumptionQuantity](./getconsumptionquantity/) | Obtiene el tamaño del archivo de consumo. |
| [IsLicensed](./islicensed/) | Comprueba si el producto está licenciado correctamente mediante una licencia por consumo. |
| [ResetMeteredKey](./resetmeteredkey/) | Elimina la licencia configurada previamente. |
| [SetMeteredKey](./setmeteredkey/) | Establece las claves públicas y privadas por consumo. |
