## ProjectServerCredentials class

Credenciales que se utilizan para conectarse a Project Online o a una instancia local de Project Server.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [ProjectServerCredentials (3 overloads)](./projectservercredentials/) | Inicializa una nueva instancia de la clase ProjectServerCredentials usando la URL del sitio SharePoint y un token de autorización SPOIDCRL válido para el sitio PWA (Project Web Access) de SharePoint. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_AuthToken](./get_authtoken/) | Obtiene el token de autorización para la instancia de SharePoint. |
| [get_SiteUrl](./get_siteurl/) | Obtiene la URL de PWA en el sitio de SharePoint o la URL del Project Server local. Por ejemplo, https://your_company_name.sharepoint.com/sites/pwa \"; |
| [get_UserName](./get_username/) | Obtiene el nombre de usuario para el sitio de SharePoint. |
