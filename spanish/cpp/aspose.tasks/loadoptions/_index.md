## LoadOptions class

Permite especificar parámetros de carga adicionales al cargar un proyecto desde un archivo o flujo.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [LoadOptions](./loadoptions/) | Inicializa una nueva instancia de la clase LoadOptions. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_Encoding](./get_encoding/) | Obtiene la codificación que se utiliza para leer un proyecto a partir de los formatos HTML, MPX, XER y Primavera XML. La codificación predeterminada es UTF8. |
| [get_ErrorHandler](./get_errorhandler/) | Obtiene un método de devolución de llamada para manejar errores de análisis XML. |
| [get_Password](./get_password/) | Obtiene una contraseña de protección. |
| [get_PrimaveraReadOptions](./get_primaverareadoptions/) | Obtiene una instancia especificada de la clase Tasks::PrimaveraReadOptions que puede usarse para personalizar el comportamiento de carga de formatos Primavera (Primavera P6 XER o Primavera P6 Xml). |
| [set_Encoding](./set_encoding/) | Establece la codificación que se utiliza para leer un proyecto a partir de los formatos HTML, MPX, XER y Primavera XML. La codificación predeterminada es UTF8. |
| [set_ErrorHandler](./set_errorhandler/) | Establece un método de devolución de llamada para manejar errores de análisis XML. |
| [set_Password](./set_password/) | Establece una contraseña de protección. |
| [set_PrimaveraReadOptions](./set_primaverareadoptions/) | Establece una instancia especificada de la clase Tasks::PrimaveraReadOptions que puede usarse para personalizar el comportamiento de carga de formatos Primavera (Primavera P6 XER o Primavera P6 Xml). |
