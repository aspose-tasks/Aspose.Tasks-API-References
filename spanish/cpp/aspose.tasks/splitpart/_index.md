## SplitPart class

Representa una porción de tarea. SplitPart es un miembro de la colección SplitParts de la tarea.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [Equals](./equals/) | Compara dos split parts. |
| [get_Finish](./get_finish/) | Obtiene la fecha de finalización de un SplitPart. |
| [get_Start](./get_start/) | Obtiene la fecha de inicio de un SplitPart. |
| [GetHashCode](./gethashcode/) | Devuelve un valor de código hash para la instancia de la clase SplitPart. |
