## ProjectFileInfo class

La instancia de la clase contiene información sobre el formato del archivo de proyecto y la versión de Microsoft Project en la que se creó el archivo.

Utilice la propiedad CanRead para definir que la biblioteca puede procesar el archivo de proyecto.
