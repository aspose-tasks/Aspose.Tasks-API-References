## ResourceSavingArgs class

Esta clase representa un conjunto de datos relacionados con el guardado de archivos de recursos externos que ocurre durante la conversión al formato HTML.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [CloseStreamIfRequired](./closestreamifrequired/) | Cierra el flujo si KeepStreamOpen es false, de lo contrario vacíalo. |
| [get_FileName](./get_filename/) | Obtiene el nombre de archivo supuesto que pasa del convertidor al código del método personalizado. Puede usarse en código personalizado para decidir cómo procesar o dónde guardar ese archivo. |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Obtiene un valor que indica si el flujo permanecerá abierto después de que finalice el guardado del recurso. |
| [get_Stream](./get_stream/) | Obtiene el contenido binario del archivo guardado. |
| [get_Uri](./get_uri/) | Obtiene el URI del recurso. |
| [set_FileName](./set_filename/) | Establece el nombre de archivo supuesto que pasa del convertidor al código del método personalizado. Puede usarse en código personalizado para decidir cómo procesar o dónde guardar ese archivo. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Establece un valor que indica si el flujo permanecerá abierto después de que finalice el guardado del recurso. |
| [set_Stream](./set_stream/) | Establece el contenido binario del archivo guardado. |
| [set_Uri](./set_uri/) | Establece el URI del recurso. |
