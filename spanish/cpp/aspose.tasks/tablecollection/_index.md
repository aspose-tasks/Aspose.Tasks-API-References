## TableCollection class

Contiene una lista de objetos Table. Implementa la interfaz ICollection< Table >.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [Add](./add/) | Agrega el elemento especificado a esta colección. |
| [Clear](./clear/) | Elimina todos los elementos de esta colección. |
| [Contains](./contains/) | Devuelve true si el elemento especificado se encuentra en esta colección; de lo contrario, false. |
| [CopyTo](./copyto/) | Copia los elementos de esta colección al arreglo especificado, comenzando en el índice de arreglo especificado. |
| [get_Count](./get_count/) | Obtiene el número de elementos contenidos en esta colección. |
| [get_IsReadOnly](./get_isreadonly/) | Obtiene un valor que indica si esta colección es de solo lectura; de lo contrario, false. |
| [GetEnumerator](./getenumerator/) | Devuelve un enumerador para esta colección. |
| [Remove](./remove/) | Elimina la primera aparición de un objeto específico de esta colección. |
| [ToList](./tolist/) | Convierte una colección de tablas en una lista de objetos Table. |
