## ExtendedAttribute class

Representa atributos extendidos.

Actualmente se admiten todos los tipos de atributos extendidos leídos desde MSP Xml 2003/2007 y mpp 2003. Para MSP mpp 2007 se admiten todos los atributos extendidos excepto duraciones y banderas.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_AttributeDefinition](./get_attributedefinition/) | Obtiene la definición del atributo. |
| [get_DateValue](./get_datevalue/) | Obtiene un valor para los atributos con tipos de fecha (Date, Start, Finish). |
| [get_DurationValue](./get_durationvalue/) | Obtiene el valor para los atributos con tipo ' Duration '. |
| [get_FieldId](./get_fieldid/) | Obtiene el id de un campo. |
| [get_FlagValue](./get_flagvalue/) | Obtiene un valor que indica si una bandera está establecida para un atributo con tipo 'Flag'. |
| [get_IsErrorValue](./get_iserrorvalue/) | Obtiene si el cálculo del valor del atributo extendido resultó en un error. |
| [get_NumericValue](./get_numericvalue/) | Obtiene un valor para atributos con tipos numéricos (Cost, Number). |
| [get_TextValue](./get_textvalue/) | Obtiene un valor para atributos con tipo 'Text'. |
| [get_ValueGuid](./get_valueguid/) | Obtiene el guid de un valor de búsqueda. |
| [get_ValueReadOnly](./get_valuereadonly/) | Obtiene un valor que indica si el valor de esta instancia de ExtendedAttribute es de solo lectura. devuelve true si una fórmula o acumulación está definida en ExtendedAttributeDefinition para este objeto. |
| [set_DateValue](./set_datevalue/) | Establece un valor para atributos con tipos de fecha (Date, Start, Finish). |
| [set_DurationValue](./set_durationvalue/) | Establece el valor para atributos con tipo ' Duration '. |
| [set_FlagValue](./set_flagvalue/) | Establece un valor que indica si una bandera está establecida para un atributo con tipo 'Flag'. |
| [set_NumericValue](./set_numericvalue/) | Establece un valor para atributos con tipos numéricos (Cost, Number). |
| [set_TextValue](./set_textvalue/) | Establece un valor para atributos con tipo 'Text'. |
| [ToString](./tostring/) | Devuelve la representación corta en cadena de un atributo extendido. |
