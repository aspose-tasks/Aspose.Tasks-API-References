## CheckPropAndGet {#checkpropandget}

Devuelve el valor al que la propiedad está asignada en este contenedor. Si este contenedor no contiene el registro ProjectItem, se añadirá con el valor predeterminado y se devolverá el valor predeterminado.

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| Parámetro | Descripción |
| --- | --- |
| clave | la propiedad especificada. |
