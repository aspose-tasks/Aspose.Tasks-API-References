## PropertyContainer< T > class

Representa un contenedor de propiedades.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [CheckPropAndGet](./checkpropandget/) | Devuelve el valor al que la propiedad está asignada en este contenedor. Si este contenedor no contiene el registro ProjectItem, se añadirá con el valor predeterminado y se devolverá el valor predeterminado. |
| [CheckPropAndSet](./checkpropandset/) | Mapea la propiedad especificada al valor especificado en este contenedor. Si este contenedor no contiene el registro ProjectItem, se añadirá. |
