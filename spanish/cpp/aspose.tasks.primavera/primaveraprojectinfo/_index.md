## PrimaveraProjectInfo class

Representa información breve sobre un proyecto cargado desde el formato Primavera.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_ExportFlag](./get_exportflag/) | Obtiene la bandera de exportación del proyecto. Cuando un proyecto se selecciona para exportar en Primavera, su ExportFlag es verdadero. Algunos proyectos no seleccionados explícitamente para exportar pueden exportarse a un archivo XER debido a su relación con el proyecto exportado. |
| [get_Name](./get_name/) | Obtiene el nombre del proyecto. |
| [get_Uid](./get_uid/) | Obtiene el Uid del proyecto. |
