## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Permite especificar opciones adicionales al renderizar páginas del proyecto a XLSX.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Inicializa una nueva instancia de la clase XlsxOptions que puede usarse para guardar el proyecto en formato XLSX. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Obtiene una lista de las columnas de vista de asignaciones para renderizar ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | Obtiene la codificación del archivo XLSX resultante. El valor predeterminado es System::Text::Encoding::UTF8. |
| [get_ResourceView](./get_resourceview/) | Obtiene una lista de las columnas de vista de recursos para renderizar ( ResourceViewColumn ). |
| [get_View](./get_view/) | Obtiene una lista de las columnas de vista ( GanttChartColumn ) para guardar en formato XLSX. Si no se establece, se guardan las columnas predeterminadas. |
| [set_AssignmentView](./set_assignmentview/) | Establece una lista de las columnas de vista de asignaciones para renderizar ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | Establece la codificación del archivo XLSX resultante. El valor predeterminado es System::Text::Encoding::UTF8. |
| [set_ResourceView](./set_resourceview/) | Establece una lista de las columnas de vista de recursos para renderizar ( ResourceViewColumn ). |
| [set_View](./set_view/) | Establece una lista de las columnas de vista ( GanttChartColumn ) para guardar en formato XLSX. Si no se establece, se guardan las columnas predeterminadas. |
