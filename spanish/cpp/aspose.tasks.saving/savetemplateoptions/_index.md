## SaveTemplateOptions class

Permite especificar opciones adicionales al guardar un proyecto como plantilla.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_RemoveActualValues](./get_removeactualvalues/) | Obtiene un valor que indica si se deben eliminar todos los valores reales de una plantilla de proyecto. |
| [get_RemoveBaselineValues](./get_removebaselinevalues/) | Obtiene un valor que indica si se deben eliminar todos los valores de referencia de una plantilla de proyecto. |
| [get_RemoveFixedCosts](./get_removefixedcosts/) | Obtiene un valor que indica si se deben eliminar todos los costos fijos de una plantilla de proyecto. |
| [get_RemoveResourceRates](./get_removeresourcerates/) | Obtiene un valor que indica si se deben eliminar las tarifas de recursos de una plantilla de proyecto. |
| [set_RemoveActualValues](./set_removeactualvalues/) | Establece un valor que indica si se deben eliminar todos los valores reales de una plantilla de proyecto. |
| [set_RemoveBaselineValues](./set_removebaselinevalues/) | Establece un valor que indica si se deben eliminar todos los valores de referencia de una plantilla de proyecto. |
| [set_RemoveFixedCosts](./set_removefixedcosts/) | Establece un valor que indica si se deben eliminar todos los costos fijos de una plantilla de proyecto. |
| [set_RemoveResourceRates](./set_removeresourcerates/) | Establece un valor que indica si se deben eliminar las tarifas de recursos de una plantilla de proyecto. |
