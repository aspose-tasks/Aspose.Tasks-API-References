## PageSavingArgs class

Esta clase representa un conjunto de datos relacionados con el guardado de la página del documento en un flujo.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Obtiene un valor que indica si la rutina de renderizado debe mantener el Stream abierto después de que se escriba una página. |
| [get_PageNumber](./get_pagenumber/) | Obtiene el número de página que se va a escribir. |
| [get_Stream](./get_stream/) | Obtiene un flujo para escribir una página. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Establece un valor que indica si la rutina de renderizado debe mantener el Stream abierto después de que se escriba una página. |
| [set_Stream](./set_stream/) | Establece un flujo para escribir una página. |
