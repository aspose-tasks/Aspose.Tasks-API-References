## get_ViewSettings {#get_viewsettings}

Obtiene una vista ( View ) para renderizar. Puede usar esta opción para especificar explícitamente qué vista debe guardarse en formatos PDF, HTML o Image. Si esta propiedad está establecida, se ignora la propiedad Visualization::PresentationFormat cuando se guarda el proyecto. La vista debe ser una de las siguientes pantallas (( Aspose::Tasks::View::Screen )): (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage).
