## IPageSavingCallback class

Representa una devolución de llamada que se invoca cuando cada página de un documento multipágina se guarda en un flujo separado.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [OnFinish](./onfinish/) | Método que se llamará cuando se hayan escrito todas las páginas. |
| [PageSaving](./pagesaving/) | El método que se llamará cuando una página se guarde en un flujo. |
