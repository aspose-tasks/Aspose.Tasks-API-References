## CsvOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Permite especificar opciones adicionales al guardar el proyecto en CSV.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [CsvOptions](./csvoptions/) | Inicializa una nueva instancia de la clase CsvOptions que puede usarse para guardar el proyecto en formato CSV. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_DataCategory](./get_datacategory/) | Obtiene una categoría de datos para guardar. |
| [get_Encoding](./get_encoding/) | Obtiene una codificación para guardar el CSV. |
| [get_IncludeHeaders](./get_includeheaders/) | Obtiene un valor que indica si se incluyen encabezados o no (el valor predeterminado es VERDADERO). |
| [get_TextDelimiter](./get_textdelimiter/) | Obtiene un delimitador de texto. |
| [get_View](./get_view/) | Obtiene una lista de las columnas de vista ( GanttChartColumn ) para guardar en formato XLSX. Si no se establece, se guardan las columnas predeterminadas. |
| [set_DataCategory](./set_datacategory/) | Establece una categoría de datos para guardar. |
| [set_Encoding](./set_encoding/) | Establece una codificación para guardar el CSV. |
| [set_IncludeHeaders](./set_includeheaders/) | Establece un valor que indica si se incluyen encabezados o no (el valor predeterminado es VERDADERO). |
| [set_TextDelimiter](./set_textdelimiter/) | Establece un delimitador de texto. |
| [set_View](./set_view/) | Establece una lista de las columnas de vista ( GanttChartColumn ) para guardar en formato XLSX. Si no se establece, se guardan las columnas predeterminadas. |
