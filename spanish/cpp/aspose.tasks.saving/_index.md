## Aspose::Tasks::Saving namespace

Utilice estos tipos para especificar opciones como delimitadores CSV, renderizado HTML, salida de imágenes, cifrado PDF, firmas digitales y devoluciones de llamada personalizadas para guardar páginas. Permiten un control granular sobre cómo se exportan los datos del proyecto.
