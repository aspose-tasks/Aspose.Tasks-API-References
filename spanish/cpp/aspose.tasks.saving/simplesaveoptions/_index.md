## SimpleSaveOptions class

Esta es una clase base abstracta que permite al usuario especificar opciones básicas al guardar un proyecto en un formato particular.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_SaveFormat](./get_saveformat/) | Obtiene el formato en el que se guardará el documento si se utiliza este objeto de opciones de guardado. |
| [get_TasksComparer](./get_taskscomparer/) | Obtiene el comparador para ordenar tareas en el diagrama de Gantt y en el diagrama de hoja de tareas. |
| [get_TasksFilter](./get_tasksfilter/) | Obtiene la condición que se usa para filtrar tareas mostradas en los diagramas de Gantt, hoja de tareas y uso de tareas. |
| [set_TasksComparer](./set_taskscomparer/) | Establece el comparador para ordenar tareas en el diagrama de Gantt y en el diagrama de hoja de tareas. |
| [set_TasksFilter](./set_tasksfilter/) | Establece la condición que se usa para filtrar tareas mostradas en los diagramas de Gantt, hoja de tareas y uso de tareas. |
