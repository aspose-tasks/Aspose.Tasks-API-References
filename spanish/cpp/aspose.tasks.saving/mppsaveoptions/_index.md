## MPPSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Permite especificar opciones adicionales al guardar los datos del proyecto en MPP.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [MPPSaveOptions](./mppsaveoptions/) | Inicializa una nueva instancia de la clase MPPSaveOptions. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_ClearVba](./get_clearvba/) | Obtiene un valor que indica si se deben eliminar los datos de macros VBA existentes al guardar un proyecto en formato MPP. |
| [get_ProtectionPassword](./get_protectionpassword/) | Obtiene una contraseña que se usa para proteger el archivo MPP resultante. Actualmente se admite para MS Project 2010 y formatos más recientes. |
| [get_RemoveInvalidAssignments](./get_removeinvalidassignments/) | Obtiene un valor que indica si se deben eliminar asignaciones de recursos inválidas al guardar en MPP. |
| [get_WriteFilters](./get_writefilters/) | Obtiene un valor que indica si se deben escribir datos de filtros al guardar un proyecto en formato MPP. |
| [get_WriteGroups](./get_writegroups/) | Obtiene un valor que indica si se deben escribir datos de grupos al guardar un proyecto en formato MPP. |
| [get_WriteVba](./get_writevba/) | Obtiene un valor que indica si se deben actualizar los datos de macros VBA existentes en el archivo MPP. Actualmente se admite la escritura de VbaModule.SourceCode. |
| [get_WriteViewData](./get_writeviewdata/) | Obtiene un valor que indica si se deben escribir los datos de vista al guardar un proyecto en formato MPP. |
| [set_ClearVba](./set_clearvba/) | Establece un valor que indica si se deben eliminar los datos de macros VBA existentes al guardar un proyecto en formato MPP. |

| [set_RemoveInvalidAssignments](./set_removeinvalidassignments/) | Establece un valor que indica si se deben eliminar asignaciones de recursos inválidas al guardar en MPP. |
| [set_WriteFilters](./set_writefilters/) | Establece un valor que indica si se deben escribir los datos de filtro al guardar un proyecto en formato MPP. |
| [set_WriteGroups](./set_writegroups/) | Establece un valor que indica si se deben escribir los datos de grupos al guardar un proyecto en formato MPP. |
| [set_WriteVba](./set_writevba/) | Establece un valor que indica si se deben actualizar los datos de macros VBA existentes en el archivo MPP. Actualmente se admite la escritura de VbaModule.SourceCode. |
| [set_WriteViewData](./set_writeviewdata/) | Establece un valor que indica si se deben escribir los datos de vista al guardar un proyecto en formato MPP. |
