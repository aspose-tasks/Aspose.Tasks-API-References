## PdfSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

Permite especificar opciones adicionales al renderizar páginas del proyecto a PDF.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [PdfSaveOptions](./pdfsaveoptions/) | Inicializa una nueva instancia de la clase PdfSaveOptions que puede usarse para guardar un documento en formato PDF. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_Compliance](./get_compliance/) | Obtiene el nivel de cumplimiento deseado para el documento PDF generado. El valor predeterminado es PdfCompliance::Pdf15 . |
| [get_DigitalSignatureDetails](./get_digitalsignaturedetails/) | Obtiene los detalles de la firma digital. Si no se establece, no se realizará ninguna firma. |
| [get_EncryptionDetails](./get_encryptiondetails/) | Obtiene los detalles del cifrado. Si no se establece, no se realizará ningún cifrado. |
| [get_FontSettings](./get_fontsettings/) | Especifica la configuración de fuente utilizada al renderizar la vista del proyecto. |
| [get_Pages](./get_pages/) | Obtiene la lista de números de página que se guardarán al guardar el diseño del proyecto en archivos separados. |
| [get_PageSavingCallback](./get_pagesavingcallback/) | Obtiene una devolución de llamada definida por el usuario que se utiliza para obtener un flujo de salida para cada página renderizada. Es aplicable cuando se usa la opción SaveToSeparateFiles. |
| [get_ReduceFooterGap](./get_reducefootergap/) | Obtiene un valor que indica si se debe reducir el espacio entre la última tarea y el pie de página. |
| [get_SaveToSeparateFiles](./get_savetoseparatefiles/) | Obtiene un valor que indica si se deben guardar las páginas del proyecto en archivos separados. |
| [get_TextCompression](./get_textcompression/) | Obtiene el tipo de compresión que se usará para todos los flujos de contenido, excepto imágenes. El valor predeterminado es PdfTextCompression::Flate . |
| [set_Compliance](./set_compliance/) | Establece el nivel de cumplimiento deseado para el documento PDF generado. El valor predeterminado es PdfCompliance::Pdf15 . |
| [set_DigitalSignatureDetails](./set_digitalsignaturedetails/) | Establece los detalles de la firma digital. Si no se establece, no se realizará ninguna firma. |
| [set_EncryptionDetails](./set_encryptiondetails/) | Establece los detalles del cifrado. Si no se establece, no se realizará ningún cifrado. |
| [set_Pages](./set_pages/) | Establece la lista de números de página que se guardarán al guardar el diseño del proyecto en archivos separados. |
| [set_PageSavingCallback](./set_pagesavingcallback/) | Establece una devolución de llamada definida por el usuario que se utiliza para obtener un flujo de salida para cada página renderizada. Es aplicable cuando se usa la opción SaveToSeparateFiles. |
| [set_ReduceFooterGap](./set_reducefootergap/) | Establece un valor que indica si se debe reducir el espacio entre la última tarea y el pie de página. |
| [set_SaveToSeparateFiles](./set_savetoseparatefiles/) | Establece un valor que indica si se deben guardar las páginas del proyecto en archivos separados. |
| [set_TextCompression](./set_textcompression/) | Establece un tipo de compresión que se usará para todas las secuencias de contenido excepto imágenes. El valor predeterminado es PdfTextCompression::Flate. |
