## Aspose::Tasks::Connectivity namespace

Utilice estos tipos para configurar conexiones a bases de datos de Microsoft Project Server (MspDbSettings), bases de datos Primavera (PrimaveraDbSettings), archivos MPD (MpdSettings) o fuentes de bases de datos genéricas (DbSettings). El espacio de nombres centraliza la configuración de conectividad para una integración fluida con las funciones de extracción y manipulación de datos de Aspose.Tasks.
