## DbSettings class

Permite especificar la configuración para leer de la base de datos del proyecto.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_ConnectionString](./get_connectionstring/) | Obtiene la cadena de conexión. |
| [get_ProviderInvariantName](./get_providerinvariantname/) | Obtiene el nombre invariante del proveedor que se usa para obtener una instancia de la clase System::Data::Common::DbProviderFactory. |
| [set_ConnectionString](./set_connectionstring/) | Establece la cadena de conexión. |
| [set_ProviderInvariantName](./set_providerinvariantname/) | Establece el nombre invariante del proveedor que se usa para obtener una instancia de la clase System::Data::Common::DbProviderFactory. |
