## get_LevelingOrder {#get_levelingorder}

Obtiene el orden en que el algoritmo de nivelación retrasa las tareas que tienen sobreasignaciones. Después de determinar las tareas que causan la sobreasignación y qué tareas pueden retrasarse, se utiliza el orden especificado para decidir qué tarea debe retrasarse primero.

**Returns:** Aspose::Tasks::Leveling::LevelingOrder Aspose::Tasks::Leveling::

```cpp
get_LevelingOrder()
```
