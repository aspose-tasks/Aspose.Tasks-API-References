## LevelingOptions class

Permite especificar parámetros de nivelación de recursos.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Inicializa una nueva instancia de la clase LevelingOptions. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_FinishDate](./get_finishdate/) | Obtiene la fecha de finalización del período de nivelación. El valor predeterminado es la fecha de finalización del proyecto`s. |
| [get_LevelingOrder](./get_levelingorder/) | Obtiene el orden en que el algoritmo de nivelación retrasa las tareas que tienen sobreasignaciones. Después de determinar las tareas que causan la sobreasignación y qué tareas pueden retrasarse, se utiliza el orden especificado para decidir qué tarea debe retrasarse primero. |
| [get_MessageHandler](./get_messagehandler/) | Obtiene la devolución de llamada del manejador de mensajes que puede usarse para interceptar los mensajes de registro producidos por Aspose.Tasks durante la nivelación de recursos. |
| [get_MessageLevel](./get_messagelevel/) | Obtiene el nivel de los mensajes de registro emitidos por Aspose.Tasks durante la nivelación de recursos. |
| [get_Resources](./get_resources/) | Obtiene la lista de los recursos que serán nivelados. Si se establece null, todos los recursos del proyecto serán nivelados. |
| [get_StartDate](./get_startdate/) | Obtiene la fecha de inicio del período de nivelación. El valor predeterminado es la fecha de inicio del proyecto`s. |
| [set_FinishDate](./set_finishdate/) | Establece la fecha de finalización del período de nivelación. El valor predeterminado es la fecha de finalización del proyecto`s. |
| [set_LevelingOrder](./set_levelingorder/) | Obtiene el orden en que el algoritmo de nivelación retrasa las tareas que tienen sobreasignaciones. Después de determinar las tareas que causan la sobreasignación y qué tareas pueden retrasarse, se utiliza el orden especificado para decidir qué tarea debe retrasarse primero. |
| [set_MessageHandler](./set_messagehandler/) | Establece la devolución de llamada del manejador de mensajes que puede usarse para interceptar los mensajes de registro producidos por Aspose.Tasks durante la nivelación de recursos. |
| [set_MessageLevel](./set_messagelevel/) | Establece el nivel de los mensajes de registro emitidos por Aspose.Tasks durante la nivelación de recursos. |
| [set_Resources](./set_resources/) | Establece la lista de los recursos que serán nivelados. Si se establece null, todos los recursos del proyecto serán nivelados. |
| [set_StartDate](./set_startdate/) | Establece la fecha de inicio del período de nivelación. El valor predeterminado es la fecha de inicio del proyecto`s. |
