## Aspose::Tasks::Visualization namespace

El espacio de nombres Aspose::Tasks::Visualization agrupa tipos que controlan la representación visual de los datos del proyecto, como estilos de barras de Gantt, configuraciones de líneas de cuadrícula y descriptores de fuentes. Utilice estas clases y enumeraciones para personalizar la apariencia de asignaciones, elementos de gráficos, encabezados y pies de página al generar o exportar informes del proyecto.
