## PageMargins class

Representa los márgenes de página para la impresión.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_Borders](./get_borders/) | Obtiene una posición donde imprimir los bordes. Puede ser uno de los valores de la enumeración Border. |
| [get_Bottom](./get_bottom/) | Obtiene el tamaño del margen inferior en centímetros. |
| [get_Left](./get_left/) | Obtiene el tamaño del margen izquierdo en centímetros. |
| [get_Right](./get_right/) | Obtiene el tamaño del margen derecho en centímetros. |
| [get_Top](./get_top/) | Obtiene el tamaño del margen superior en centímetros. |
| [set_Borders](./set_borders/) | Establece una posición donde imprimir los bordes. Puede ser uno de los valores de la enumeración Border. |
| [set_Bottom](./set_bottom/) | Establece el tamaño del margen inferior en centímetros. |
| [set_Left](./set_left/) | Establece el tamaño del margen izquierdo en centímetros. |
| [set_Right](./set_right/) | Establece el tamaño del margen derecho en centímetros. |
| [set_Top](./set_top/) | Establece el tamaño del margen superior en centímetros. |
