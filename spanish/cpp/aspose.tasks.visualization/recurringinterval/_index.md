## RecurringInterval class

Representa intervalos recurrentes utilizados en las líneas de progreso de una vista de diagrama de Gantt.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [DayType](./daytype/) | Representa un tipo de día utilizado en líneas de progreso. |
| [get_DailyDayNumber](./get_dailydaynumber/) | Obtiene el número diario del día. |
| [get_DailyWorkday](./get_dailyworkday/) | Obtiene un valor que indica si un día es laborable para líneas de progreso diarias. |
| [get_Interval](./get_interval/) | Obtiene el intervalo recurrente. Puede ser cualquier valor del tipo Interval. |
| [get_MonthlyDay](./get_monthlyday/) | Obtiene un valor que indica si se deben mostrar las líneas de progreso mensuales por día. |
| [get_MonthlyDayDayNumber](./get_monthlydaydaynumber/) | Obtiene el número de día de las líneas de progreso mensuales. |
| [get_MonthlyDayMonthNumber](./get_monthlydaymonthnumber/) | Obtiene el número de mes de las líneas de progreso mensuales. |
| [get_MonthlyFirstLast](./get_monthlyfirstlast/) | Obtiene un valor que indica si se deben mostrar las líneas de progreso por el primer o último día predefinido. |
| [get_MonthlyFirstLastDay](./get_monthlyfirstlastday/) | Obtiene el tipo de primer o último día de las líneas de progreso mensuales. |
| [get_MonthlyFirstLastMonthNumber](./get_monthlyfirstlastmonthnumber/) | Obtiene el número de mes de las líneas de progreso, que se muestran por el primer o último día predefinido. |
| [get_WeeklyDays](./get_weeklydays/) | Obtiene una lista de días para las líneas de progreso semanales. |
| [get_WeeklyWeekNumber](./get_weeklyweeknumber/) | Obtiene el número de semana para las líneas de progreso semanales. |
| [set_DailyDayNumber](./set_dailydaynumber/) | Establece el número de día diario. |
| [set_DailyWorkday](./set_dailyworkday/) | Establece un valor que indica si un día es laborable para las líneas de progreso diarias. |
| [set_Interval](./set_interval/) | Establece el intervalo recurrente. Puede ser cualquier valor del tipo Interval. |
| [set_MonthlyDay](./set_monthlyday/) | Establece un valor que indica si se deben mostrar las líneas de progreso mensuales por día. |
| [set_MonthlyDayDayNumber](./set_monthlydaydaynumber/) | Establece el número de día de las líneas de progreso mensuales. |
| [set_MonthlyDayMonthNumber](./set_monthlydaymonthnumber/) | Establece el número de mes de las líneas de progreso mensuales. |
| [set_MonthlyFirstLast](./set_monthlyfirstlast/) | Establece un valor que indica si se deben mostrar las líneas de progreso por el primer o último día predefinido. |
| [set_MonthlyFirstLastDay](./set_monthlyfirstlastday/) | Establece el tipo de primer o último día de las líneas de progreso mensuales. |
| [set_MonthlyFirstLastMonthNumber](./set_monthlyfirstlastmonthnumber/) | Establece el número de mes de las líneas de progreso, que se muestran por el primer o último día predefinido. |
| [set_WeeklyWeekNumber](./set_weeklyweeknumber/) | Establece el número de semana para las líneas de progreso semanales. |
