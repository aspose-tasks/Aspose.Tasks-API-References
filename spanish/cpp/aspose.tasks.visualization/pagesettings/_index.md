## PageSettings class

Representa la configuración de impresión para una página de la vista del proyecto.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [PageSettings](./pagesettings/) | Inicializa una nueva instancia de la clase PageSettings. Representa la configuración de impresión para una página de la vista del proyecto. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | Obtiene un valor que indica si se debe ajustar la impresión al porcentaje especificado ( PercentOfNormalSize ) del tamaño normal. |
| [get_FirstPageNumber](./get_firstpagenumber/) | Obtiene el número de la primera página para la impresión. |
| [get_IsPortrait](./get_isportrait/) | Obtiene un valor que indica si la orientación de la página es vertical; devuelve false si la orientación de la página es horizontal. |
| [get_PagesInHeight](./get_pagesinheight/) | Obtiene la cantidad de páginas en altura que se imprimirán. |
| [get_PagesInWidth](./get_pagesinwidth/) | Obtiene un número de páginas en ancho para imprimir. |
| [get_PaperSize](./get_papersize/) | Obtiene un tamaño de papel. Puede ser uno de los valores de la enumeración PrinterPaperSize. |
| [get_PaperSizeId](./get_papersizeid/) | Obtiene un entero que representa uno de los valores de PrinterPaperSize o un id de tamaño de página personalizado. Este valor puede usarse para obtener PaperSize de la configuración del SO. |
| [get_PercentOfNormalSize](./get_percentofnormalsize/) | Obtiene un porcentaje del tamaño normal al que ajustar la impresión. |
| [set_AdjustToPercentOfNormalSize](./set_adjusttopercentofnormalsize/) | Establece un valor que indica si se debe ajustar la impresión al porcentaje especificado ( PercentOfNormalSize ) del tamaño normal. |
| [set_FirstPageNumber](./set_firstpagenumber/) | Establece un número de primera página para imprimir. |
| [set_IsPortrait](./set_isportrait/) | Establece un valor que indica si la orientación de la página es vertical; devuelve false si la orientación de la página es horizontal. |
| [set_PagesInHeight](./set_pagesinheight/) | Establece un número de páginas en altura que se imprimirán. |
| [set_PagesInWidth](./set_pagesinwidth/) | Establece un número de páginas en ancho que se imprimirán. |
| [set_PaperSize](./set_papersize/) | Establece un tamaño de papel. Puede ser uno de los valores de la enumeración PrinterPaperSize. |
| [set_PaperSizeId](./set_papersizeid/) | Establece un entero que representa uno de los valores de PrinterPaperSize o un id de tamaño de página personalizado. Este valor puede usarse para obtener PaperSize de la configuración del SO. |
| [set_PercentOfNormalSize](./set_percentofnormalsize/) | Establece un porcentaje del tamaño normal al que ajustar la impresión. |
