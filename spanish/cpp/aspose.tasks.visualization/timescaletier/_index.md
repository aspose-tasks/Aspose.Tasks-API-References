## TimescaleTier class

Representa un nivel único de la escala de tiempo en un diagrama de Gantt.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [TimescaleTier (2 overloads)](./timescaletier/) | Inicializa una nueva instancia de la clase TimescaleTier. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_Alignment](./get_alignment/) | Obtiene cómo alinear las etiquetas dentro de cada período de tiempo del nivel ( HorizontalStringAlignment ). |
| [get_Count](./get_count/) | Obtiene el intervalo de unidad de tiempo en el que se mostrarán las etiquetas para el nivel. El valor predeterminado es 1. |

Si el valor es 'false', la etiqueta de fecha se renderiza solo una vez según el valor de la propiedad Alignment. |
