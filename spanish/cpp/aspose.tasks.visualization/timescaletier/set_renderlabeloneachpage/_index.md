## set_RenderLabelOnEachPage {#set_renderlabeloneachpage}

Establece la bandera que define si las etiquetas de fecha deben renderizarse en cada página cuando un período de tiempo abarca varias páginas. Si el valor es 'true', cuando el período de tiempo abarca varias páginas, las etiquetas de fecha para el período se renderizan en cada página. Si el valor es 'false', la etiqueta de fecha se renderiza solo una vez según el valor de la propiedad Alignment.
