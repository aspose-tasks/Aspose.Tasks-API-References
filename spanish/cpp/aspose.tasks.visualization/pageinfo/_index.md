## PageInfo class

Representa los datos de configuración de página que están presentes en el formato de archivo MPP y se utilizan para imprimir.

## Constructores

| Nombre | Descripción |
| --- | --- |
| [PageInfo](./pageinfo/) | Inicializa una nueva instancia de la clase PageInfo. Representa los datos de configuración de página que están presentes en el formato de archivo MPP y se utilizan para imprimir. |

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_Footer](./get_footer/) | Obtiene una instancia de la clase HeaderFooterInfo que representa datos de pie de página. |
| [get_Header](./get_header/) | Obtiene la instancia de la clase HeaderFooterInfo que representa datos de encabezado. |
| [get_Legend](./get_legend/) | Obtiene una instancia de la clase PageLegend que especifica las opciones de renderizado de la leyenda de página. |
| [get_Margins](./get_margins/) | Obtiene una instancia de la clase PageMargins que especifica los márgenes de página. |
| [get_Name](./get_name/) | Obtiene el nombre de la vista para la cual se utilizan los datos de configuración. |
| [get_PageSettings](./get_pagesettings/) | Obtiene una instancia de la clase PageSettings que especifica la configuración de impresión de página. |
| [get_PageViewSettings](./get_pageviewsettings/) | Obtiene una instancia de la clase PageViewSettings que especifica la configuración de impresión de la vista de página. |
| [set_Footer](./set_footer/) | Establece una instancia de la clase HeaderFooterInfo que representa datos de pie de página. |
| [set_Header](./set_header/) | Establece la instancia de la clase HeaderFooterInfo que representa datos de encabezado. |
| [set_Legend](./set_legend/) | Establece una instancia de la clase PageLegend que especifica las opciones de renderizado de la leyenda de página. |
