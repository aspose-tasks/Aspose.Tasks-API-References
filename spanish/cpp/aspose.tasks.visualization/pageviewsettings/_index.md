## PageViewSettings class

Representa la configuración de impresión para una vista del proyecto.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_FirstColumnsCount](./get_firstcolumnscount/) | Obtiene el número de primeras columnas que se imprimirán en todas las páginas. |
| [get_FitTimescaleToEndOfPage](./get_fittimescaletoendofpage/) | Obtiene un valor que indica si se ajusta la escala de tiempo al final de una página al imprimir. |
| [get_PrintAllSheetColumns](./get_printallsheetcolumns/) | Obtiene un valor que indica si se imprimen todas las columnas de la hoja de una vista. |
| [get_PrintBlankPages](./get_printblankpages/) | Obtiene un valor que indica si se imprimen páginas en blanco de una vista. |
| [get_PrintFirstColumnsCountOnAllPages](./get_printfirstcolumnscountonallpages/) | Obtiene un valor que indica si se imprimen un número especificado de primeras columnas en todas las páginas. |
| [get_PrintNotes](./get_printnotes/) | Obtiene un valor que indica si se imprimen notas. |
| [set_FirstColumnsCount](./set_firstcolumnscount/) | Establece el número de primeras columnas que se imprimirán en todas las páginas. |

| [set_PrintAllSheetColumns](./set_printallsheetcolumns/) | Establece un valor que indica si se imprimen todas las columnas de la hoja de una vista. |
| [set_PrintBlankPages](./set_printblankpages/) | Establece un valor que indica si se imprimen páginas en blanco de una vista. |
| [set_PrintFirstColumnsCountOnAllPages](./set_printfirstcolumnscountonallpages/) | Establece un valor que indica si se imprimen un número especificado de primeras columnas en todas las páginas. |
| [set_PrintNotes](./set_printnotes/) | Establece un valor que indica si se imprimen notas. |
