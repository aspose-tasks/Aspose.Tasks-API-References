## Gridlines class

Representa las líneas de cuadrícula que aparecen en una vista GanttChart.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [get_Interval](./get_interval/) | Obtiene el número de 0 a 99 que especifica el intervalo entre líneas de cuadrícula. |
| [get_IntervalColor](./get_intervalcolor/) | Obtiene el color de las líneas de cuadrícula secundarias. |
| [get_IntervalPattern](./get_intervalpattern/) | Obtiene el patrón de línea para las líneas de cuadrícula secundarias. |
| [get_NormalColor](./get_normalcolor/) | Obtiene el color de las líneas de cuadrícula normales. |
| [get_NormalPattern](./get_normalpattern/) | Obtiene el patrón de línea para las líneas de cuadrícula normales. |
| [get_Type](./get_type/) | Obtiene el tipo de línea de cuadrícula. |
| [set_Interval](./set_interval/) | Establece el número de 0 a 99 que especifica el intervalo entre líneas de cuadrícula. |
| [set_IntervalColor](./set_intervalcolor/) | Establece el color de las líneas de cuadrícula secundarias. |
| [set_IntervalPattern](./set_intervalpattern/) | Establece el patrón de línea para las líneas de cuadrícula secundarias. |
| [set_NormalColor](./set_normalcolor/) | Establece el color de las líneas de cuadrícula normales. |
| [set_NormalPattern](./set_normalpattern/) | Establece el patrón de línea para las líneas de cuadrícula normales. |
| [set_Type](./set_type/) | Establece el tipo de línea de cuadrícula. |
