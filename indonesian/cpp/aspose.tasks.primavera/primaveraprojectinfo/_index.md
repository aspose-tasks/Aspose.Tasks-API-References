## PrimaveraProjectInfo class

Mewakili info singkat tentang proyek yang dimuat dari format Primavera.

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_ExportFlag](./get_exportflag/) | Mendapatkan flag ekspor proyek. Ketika sebuah proyek dipilih untuk diekspor di Primavera, ExportFlag-nya bernilai true. Beberapa proyek yang tidak secara eksplisit dipilih untuk diekspor dapat diekspor ke file XER karena hubungannya dengan proyek yang diekspor. |
| [get_Name](./get_name/) | Mendapatkan nama proyek. |
| [get_Uid](./get_uid/) | Mendapatkan Uid proyek. |
