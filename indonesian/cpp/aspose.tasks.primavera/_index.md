## Aspose::Tasks::Primavera namespace

Namespace Aspose::Tasks::Primavera mengelompokkan kelas dan enumerasi yang memungkinkan membaca, membuat, dan memanipulasi file proyek Primavera P6. Gunakan tipe-tipe ini, seperti PrimaveraProjectInfo, untuk mengakses metadata proyek dan mengintegrasikan data Primavera dengan fungsionalitas Aspose.Tasks lainnya.
