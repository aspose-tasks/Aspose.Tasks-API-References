## set_View {#set_view}

Menetapkan daftar kolom tampilan yang akan dirender ( GanttChartColumn ). Jika tidak disetel, maka hanya ID tugas, nama tugas, mulai, dan selesai yang dirender. Jika properti View dan ViewSettings keduanya disetel, kolom dari View akan menggantikan kolom dari ViewSettings.
