## PdfSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

Memungkinkan untuk menentukan opsi tambahan saat merender halaman proyek ke PDF.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [PdfSaveOptions](./pdfsaveoptions/) | Menginisialisasi instance baru dari kelas PdfSaveOptions yang dapat digunakan untuk menyimpan dokumen dalam format PDF. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_Compliance](./get_compliance/) | Mendapatkan tingkat kepatuhan yang diinginkan untuk dokumen PDF yang dihasilkan. Defaultnya adalah PdfCompliance::Pdf15 . |
| [get_DigitalSignatureDetails](./get_digitalsignaturedetails/) | Mendapatkan detail tanda tangan digital. Jika tidak disetel, maka tidak akan ada penandatanganan yang dilakukan. |
| [get_EncryptionDetails](./get_encryptiondetails/) | Mendapatkan detail enkripsi. Jika tidak disetel, maka tidak akan ada enkripsi yang dilakukan. |
| [get_FontSettings](./get_fontsettings/) | Menentukan pengaturan font yang digunakan saat merender tampilan proyek. |
| [get_Pages](./get_pages/) | Mendapatkan daftar nomor halaman yang akan disimpan saat menyimpan tata letak proyek ke file terpisah. |
| [get_PageSavingCallback](./get_pagesavingcallback/) | Mendapatkan callback yang ditentukan pengguna yang digunakan untuk mendapatkan aliran output untuk setiap halaman yang dirender. Berlaku ketika opsi SaveToSeparateFiles digunakan. |
| [get_ReduceFooterGap](./get_reducefootergap/) | Mendapatkan nilai yang menunjukkan apakah celah antara tugas terakhir dan footer harus dikurangi. |
| [get_SaveToSeparateFiles](./get_savetoseparatefiles/) | Mendapatkan nilai yang menunjukkan apakah halaman proyek harus disimpan ke file terpisah. |

| [set_PageSavingCallback](./set_pagesavingcallback/) | Mengatur callback yang ditentukan pengguna yang digunakan untuk mendapatkan aliran output untuk setiap halaman yang dirender. Berlaku ketika opsi SaveToSeparateFiles digunakan. |
| [set_ReduceFooterGap](./set_reducefootergap/) | Mengatur nilai yang menunjukkan apakah celah antara tugas terakhir dan footer harus dikurangi. |
