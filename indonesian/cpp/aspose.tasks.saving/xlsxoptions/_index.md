## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Memungkinkan untuk menentukan opsi tambahan saat merender halaman proyek ke XLSX.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Menginisialisasi instance baru dari kelas XlsxOptions yang dapat digunakan untuk menyimpan proyek dalam format XLSX. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Mendapatkan daftar kolom tampilan penugasan untuk dirender ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | Mendapatkan encoding dari file XLSX yang dihasilkan. Nilai default adalah System::Text::Encoding::UTF8. |
| [get_ResourceView](./get_resourceview/) | Mendapatkan daftar kolom tampilan sumber daya untuk dirender ( ResourceViewColumn ). |
| [get_View](./get_view/) | Mendapatkan daftar kolom tampilan ( GanttChartColumn ) untuk disimpan ke format XLSX. Jika tidak disetel, maka kolom default akan disimpan. |
| [set_AssignmentView](./set_assignmentview/) | Mengatur daftar kolom tampilan penugasan untuk dirender ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | Mengatur encoding dari file XLSX yang dihasilkan. Nilai default adalah System::Text::Encoding::UTF8. |
| [set_ResourceView](./set_resourceview/) | Mengatur daftar kolom tampilan sumber daya untuk dirender ( ResourceViewColumn ). |
| [set_View](./set_view/) | Mengatur daftar kolom tampilan ( GanttChartColumn ) untuk disimpan ke format XLSX. Jika tidak disetel, maka kolom default akan disimpan. |
