## PageSavingArgs class

Kelas ini mewakili sekumpulan data yang terkait dengan penyimpanan halaman dokumen ke aliran.

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Mendapatkan nilai yang menunjukkan apakah rutin rendering harus menjaga Stream tetap terbuka setelah halaman ditulis. |
| [get_PageNumber](./get_pagenumber/) | Mendapatkan nomor halaman yang akan ditulis. |
| [get_Stream](./get_stream/) | Mendapatkan aliran untuk menulis sebuah halaman. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Menetapkan nilai yang menunjukkan apakah rutin rendering harus menjaga Stream tetap terbuka setelah halaman ditulis. |
| [set_Stream](./set_stream/) | Menetapkan aliran untuk menulis sebuah halaman. |
