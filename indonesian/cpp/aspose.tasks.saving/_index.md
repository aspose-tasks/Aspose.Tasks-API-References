## Aspose::Tasks::Saving namespace

Gunakan tipe ini untuk menentukan opsi seperti pemisah CSV, rendering HTML, output gambar, enkripsi PDF, tanda tangan digital, dan callback penyimpanan halaman khusus. Mereka memungkinkan kontrol terperinci atas cara data proyek diekspor.
