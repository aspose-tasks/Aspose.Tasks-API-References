## CsvOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Memungkinkan untuk menentukan opsi tambahan saat menyimpan proyek ke CSV.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [CsvOptions](./csvoptions/) | Menginisialisasi sebuah instance baru dari kelas CsvOptions yang dapat digunakan untuk menyimpan proyek dalam format CSV. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_DataCategory](./get_datacategory/) | Mendapatkan kategori data yang akan disimpan. |
| [get_Encoding](./get_encoding/) | Mendapatkan enkoding untuk menyimpan CSV. |
| [get_IncludeHeaders](./get_includeheaders/) | Mendapatkan nilai yang menunjukkan apakah menyertakan header atau tidak (nilai default adalah TRUE). |
| [get_TextDelimiter](./get_textdelimiter/) | Mendapatkan pembatas teks. |
| [get_View](./get_view/) | Mendapatkan daftar kolom tampilan ( GanttChartColumn ) untuk disimpan ke format XLSX. Jika tidak disetel, maka kolom default akan disimpan. |
| [set_DataCategory](./set_datacategory/) | Mengatur kategori data yang akan disimpan. |
| [set_Encoding](./set_encoding/) | Mengatur enkoding untuk menyimpan CSV. |
| [set_IncludeHeaders](./set_includeheaders/) | Mengatur nilai yang menunjukkan apakah menyertakan header atau tidak (nilai default adalah TRUE). |
| [set_TextDelimiter](./set_textdelimiter/) | Mengatur pembatas teks. |
| [set_View](./set_view/) | Mengatur daftar kolom tampilan ( GanttChartColumn ) untuk disimpan ke format XLSX. Jika tidak disetel, maka kolom default akan disimpan. |
