## Aspose::Tasks::Connectivity namespace

Gunakan tipe ini untuk mengkonfigurasi koneksi ke basis data Microsoft Project Server (MspDbSettings), basis data Primavera (PrimaveraDbSettings), file MPD (MpdSettings), atau sumber basis data generik (DbSettings). Namespace ini memusatkan konfigurasi konektivitas untuk integrasi mulus dengan fitur ekstraksi dan manipulasi data Aspose.Tasks.


## Kelas

| Nama | Deskripsi |
| --- | --- |
| [DbSettings](./dbsettings/) | Memungkinkan untuk menentukan pengaturan membaca dari basis data proyek. |
| [MpdSettings](./mpdsettings/) | Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari format MPD (MS Access |
| [MspDbSettings](./mspdbsettings/) | Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari data MS Project Server. |
| [PrimaveraDbSettings](./primaveradbsettings/) | Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari basis data Primavera. |
