## PropertyContainer< T > class

Mewakili kontainer properti.

## Metode

| Nama | Deskripsi |
| --- | --- |
| [CheckPropAndGet](./checkpropandget/) | Mengembalikan nilai yang dipetakan ke properti dalam kontainer ini. Jika kontainer ini tidak berisi catatan ProjectItem, maka akan ditambahkan dengan nilai default dan nilai default akan dikembalikan. |
| [CheckPropAndSet](./checkpropandset/) | Memetakan properti yang ditentukan ke nilai yang ditentukan dalam kontainer ini. Jika kontainer ini tidak berisi catatan ProjectItem, maka akan ditambahkan. |
