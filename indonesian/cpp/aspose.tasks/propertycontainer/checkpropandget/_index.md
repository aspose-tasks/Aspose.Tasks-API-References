## CheckPropAndGet {#checkpropandget}

Mengembalikan nilai yang dipetakan ke properti dalam kontainer ini. Jika kontainer ini tidak berisi catatan ProjectItem, maka akan ditambahkan dengan nilai default dan nilai default akan dikembalikan.

**Returns:** the value to which the property is mapped in this container or default value for property.

