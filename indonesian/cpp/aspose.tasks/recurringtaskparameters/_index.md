## RecurringTaskParameters class

Mewakili kumpulan parameter yang digunakan untuk membuat tugas berulang dalam sebuah proyek.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [RecurringTaskParameters](./recurringtaskparameters/) | Menginisialisasi instance baru dari kelas RecurringTaskParameters. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_Duration](./get_duration/) | Mendapatkan durasi untuk satu kejadian tugas berulang. |
| [get_IgnoreResourceCalendar](./get_ignoreresourcecalendar/) | Mendapatkan nilai yang menunjukkan apakah akan menjadwalkan tugas berulang meskipun tidak terjadi ketika ada sumber daya yang tersedia untuk mengerjakannya. |
| [get_RecurrencePattern](./get_recurrencepattern/) | Mendapatkan pola pengulangan dari tugas berulang. |
| [get_TaskName](./get_taskname/) | Mendapatkan nama tugas berulang. |
| [set_Duration](./set_duration/) | Mengatur durasi untuk satu kejadian tugas berulang. |
| [set_IgnoreResourceCalendar](./set_ignoreresourcecalendar/) | Mengatur nilai yang menunjukkan apakah akan menjadwalkan tugas berulang meskipun tidak terjadi ketika ada sumber daya yang tersedia untuk mengerjakannya. |
| [set_RecurrencePattern](./set_recurrencepattern/) | Mengatur pola pengulangan dari tugas berulang. |
| [set_TaskName](./set_taskname/) | Mengatur nama tugas berulang. |
| [SetCalendar](./setcalendar/) | Atur kalender untuk tugas berulang. Kalender dipilih dari koleksi kalender proyek. |
