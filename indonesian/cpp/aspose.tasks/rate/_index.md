## Rate class

Mewakili definisi periode waktu dan tarif yang berlaku untuk sumber daya selama periode tersebut.

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Mendapatkan biaya per penggunaan sumber daya. Nilai ini diambil dari tanggal saat ini jika tabel tarif ada untuk sumber daya. |
| [get_OvertimeRate](./get_overtimerate/) | Mendapatkan tarif lembur per jam untuk sumber daya. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Mendapatkan satuan yang digunakan oleh Microsoft Project untuk menampilkan tarif lembur. |
| [get_RatesFrom](./get_ratesfrom/) | Mendapatkan tanggal ketika tarif mulai berlaku. |
| [get_RatesTo](./get_ratesto/) | Mendapatkan tanggal terakhir ketika tarif berlaku. |
| [get_RateTable](./get_ratetable/) | Mendapatkan pengidentifikasi unik dari tabel tarif untuk sumber daya. |
| [get_StandardRate](./get_standardrate/) | Mendapatkan tarif standar per jam untuk sumber daya. |
| [get_StandardRateFormat](./get_standardrateformat/) | Mendapatkan satuan yang digunakan oleh Microsoft Project untuk menampilkan tarif standar. |
| [set_CostPerUse](./set_costperuse/) | Mengatur biaya per penggunaan sumber daya. Nilai ini diambil dari tanggal saat ini jika tabel tarif ada untuk sumber daya. |
| [set_OvertimeRate](./set_overtimerate/) | Mengatur tarif lembur per jam untuk sumber daya. |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Mengatur satuan yang digunakan oleh Microsoft Project untuk menampilkan tarif lembur. |
| [set_RatesFrom](./set_ratesfrom/) | Mengatur tanggal ketika tarif mulai berlaku. |
| [set_RatesTo](./set_ratesto/) | Mengatur tanggal terakhir ketika tarif berlaku. |
| [set_RateTable](./set_ratetable/) | Mengatur pengidentifikasi unik dari tabel tarif untuk sumber daya. |
| [set_StandardRate](./set_standardrate/) | Mengatur tarif standar per jam untuk sumber daya. |
| [set_StandardRateFormat](./set_standardrateformat/) | Mengatur satuan yang digunakan oleh Microsoft Project untuk menampilkan tarif standar. |
