## LoadOptions class

Memungkinkan menentukan parameter pemuatan tambahan saat memuat proyek dari file atau aliran.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [LoadOptions](./loadoptions/) | Menginisialisasi instance baru dari kelas LoadOptions. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_Encoding](./get_encoding/) | Mendapatkan enkoding yang digunakan untuk membaca proyek dari format HTML, MPX, XER, dan Primavera XML. Enkoding default adalah UTF8. |
| [get_ErrorHandler](./get_errorhandler/) | Mendapatkan metode callback untuk menangani kesalahan parsing xml. |
| [get_Password](./get_password/) | Mendapatkan kata sandi perlindungan. |
| [get_PrimaveraReadOptions](./get_primaverareadoptions/) | Mendapatkan instance tertentu dari kelas Tasks::PrimaveraReadOptions yang dapat digunakan untuk menyesuaikan perilaku pemuatan format Primavera (Primavera P6 XER atau Primavera P6 Xml). |
| [set_Encoding](./set_encoding/) | Mengatur enkoding yang digunakan untuk membaca proyek dari format HTML, MPX, XER, dan Primavera XML. Enkoding default adalah UTF8. |
| [set_ErrorHandler](./set_errorhandler/) | Mengatur metode callback untuk menangani kesalahan parsing xml. |
| [set_Password](./set_password/) | Mengatur kata sandi perlindungan. |
| [set_PrimaveraReadOptions](./set_primaverareadoptions/) | Mengatur instance tertentu dari kelas Tasks::PrimaveraReadOptions yang dapat digunakan untuk menyesuaikan perilaku pemuatan format Primavera (Primavera P6 XER atau Primavera P6 Xml). |
