## FilterCollection class

Berisi daftar objek Filter. Mengimplementasikan antarmuka ICollection< Filter >.

## Metode

| Nama | Deskripsi |
| --- | --- |
| [Add](./add/) | Menambahkan item yang ditentukan ke koleksi ini. |
| [Clear](./clear/) | Menghapus semua item dari koleksi ini. |
| [Contains](./contains/) | Mengembalikan true jika item yang ditentukan ditemukan dalam koleksi ini; jika tidak, false. |
| [CopyTo](./copyto/) | Menyalin elemen-elemen koleksi ini ke array yang ditentukan, mulai dari indeks array yang ditentukan. |
| [get_Count](./get_count/) | Mendapatkan jumlah elemen yang terdapat dalam koleksi ini. |
| [get_IsReadOnly](./get_isreadonly/) | Mengambil nilai yang menunjukkan apakah koleksi ini hanya-baca; jika tidak, false. |
| [GetEnumerator](./getenumerator/) | Mengembalikan enumerator untuk koleksi ini. |
| [Remove](./remove/) | Menghapus kemunculan pertama dari objek tertentu dari koleksi ini. |
| [ToList](./tolist/) | Mengonversi koleksi filter menjadi daftar objek Filter. |
