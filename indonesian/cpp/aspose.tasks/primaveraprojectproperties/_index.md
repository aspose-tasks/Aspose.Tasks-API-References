## PrimaveraProjectProperties class

Mewakili properti khusus Primavera untuk sebuah proyek yang dibaca dari file Primavera (XER atau P6XML).

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | Mendapatkan array proyek baseline dari proyek saat ini. Berlaku untuk proyek yang dibaca dari file XML Primavera yang berisi baseline yang diekspor. |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | Mendapatkan Id dari proyek baseline saat ini. Berlaku untuk proyek yang dibaca dari file XML Primavera yang berisi baseline yang diekspor. |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | Mendapatkan flag yang menentukan apakah mengabaikan hubungan aktivitas antar proyek. |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | Mendapatkan flag yang menentukan apakah aktivitas harus ditandai sebagai kritis saat penjadwalan proyek. |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | Mendapatkan opsi yang menentukan kalender mana yang akan digunakan untuk menjadwalkan Lag Hubungan dalam proyek Primavera. |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | Mendapatkan flag yang menentukan apakah tanggal selesai aktivitas harus dijadwalkan sebagai tanggal selesai yang diharapkan. |
