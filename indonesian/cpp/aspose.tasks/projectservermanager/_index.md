## ProjectServerManager class

Kelas yang menyediakan metode untuk membaca dan melakukan operasi pada proyek dalam akun Project Online yang ditentukan atau dalam instance Project Server on-premise yang ditentukan (versi Project Server 2016 dan 2019 didukung).

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [ProjectServerManager](./projectservermanager/) | Menginisialisasi instance baru dari kelas ProjectServerManager. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [CreateNewProject (2 overloads)](./createnewproject/) | Membuat proyek baru dalam instance Project Server\\Project Online menggunakan opsi penyimpanan default. |
| [GetProject](./getproject/) | Mendapatkan proyek dengan guid yang ditentukan dari akun Project Online \\ instance Project Server. |
| [GetProjectList](./getprojectlist/) | Mendapatkan daftar proyek dari penyimpanan 'Working' akun Project Online \\ instance Project Server saat ini. |
| [GetProjectRawData](./getprojectrawdata/) | Mendapatkan data biner proyek untuk tujuan pemecahan masalah. |
| [UpdateProject (2 overloads)](./updateproject/) | Memperbarui proyek yang ada dalam instance Project Server\\Project Online menggunakan opsi penyimpanan default. Proyek yang ada akan ditimpa. |
| [ExecutingWebRequest](./executingwebrequest/) | Sebuah peristiwa yang dipicu ketika permintaan web dikirim ke API web Project Server. |
