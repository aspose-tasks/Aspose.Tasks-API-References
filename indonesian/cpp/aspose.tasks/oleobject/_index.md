## OleObject class

Mewakili objek OLE yang dapat disisipkan ke dalam Tampilan Gantt Chart dari file MPP.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [OleObject](./oleobject/) | Menginisialisasi instance baru dari kelas OleObject. |
