## License class

Menyediakan metode untuk melisensikan komponen.

Dalam contoh ini, akan dicoba menemukan file lisensi bernama MyLicense.lic di folder yang berisi <ms> komponen, di folder yang berisi assembly pemanggil, di folder assembly entri, dan kemudian di sumber daya tersemat dari assembly pemanggil.

```cpp
[C#]
 
License license = new License();
license.SetLicense("MyLicense.lic");
 
 
[Visual Basic]
 
Dim license As license = New license
License.SetLicense("MyLicense.lic")
```

</ms> <java> file jar komponen:

```cpp
License license = new License();
license.setLicense("MyLicense.lic");
```

</java>
