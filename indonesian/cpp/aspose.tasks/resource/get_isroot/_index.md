## get_IsRoot {#get_isroot}

Mendapatkan bendera yang menunjukkan apakah sumber daya adalah sumber daya root. Sumber daya root adalah sumber daya khusus yang dimaksudkan untuk mendukung internal format MS Project 's dan tidak dimaksudkan untuk digunakan secara langsung dari kode pengguna.

**Returns:** virtual bool Aspose::Tasks::

```cpp
get_IsRoot()
```
