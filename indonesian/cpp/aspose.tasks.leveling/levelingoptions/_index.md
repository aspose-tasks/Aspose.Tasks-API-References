## LevelingOptions class

Memungkinkan untuk menentukan parameter leveling sumber daya.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Menginisialisasi instance baru dari kelas LevelingOptions. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_FinishDate](./get_finishdate/) | Mendapatkan tanggal akhir periode leveling. Nilai default adalah tanggal selesai project`s. |
| [get_LevelingOrder](./get_levelingorder/) | Mendapatkan urutan di mana algoritma leveling menunda tugas yang memiliki alokasi berlebih. Setelah penentuan tugas yang menyebabkan alokasi berlebih dan tugas mana yang dapat ditunda, urutan yang ditentukan digunakan untuk menentukan tugas mana yang harus ditunda pertama kali. |
| [get_MessageHandler](./get_messagehandler/) | Mendapatkan callback penangan pesan yang dapat digunakan untuk menyaring pesan log yang dihasilkan oleh Aspose.Tasks selama leveling sumber daya. |
| [get_MessageLevel](./get_messagelevel/) | Mendapatkan level pesan log yang dikeluarkan oleh Aspose.Tasks selama leveling sumber daya. |
| [get_Resources](./get_resources/) | Mendapatkan daftar sumber daya yang akan di-leveling. Jika null diatur, semua sumber daya proyek akan di-leveling. |
| [get_StartDate](./get_startdate/) | Mendapatkan tanggal mulai periode leveling. Nilai default adalah tanggal mulai project`s. |
| [set_FinishDate](./set_finishdate/) | Mengatur tanggal akhir periode leveling. Nilai default adalah tanggal selesai project`s. |
| [set_LevelingOrder](./set_levelingorder/) | Mendapatkan urutan di mana algoritma leveling menunda tugas yang memiliki alokasi berlebih. Setelah penentuan tugas yang menyebabkan alokasi berlebih dan tugas mana yang dapat ditunda, urutan yang ditentukan digunakan untuk menentukan tugas mana yang harus ditunda pertama kali. |
| [set_MessageHandler](./set_messagehandler/) | Mengatur callback penangan pesan yang dapat digunakan untuk menyaring pesan log yang dihasilkan oleh Aspose.Tasks selama leveling sumber daya. |
| [set_MessageLevel](./set_messagelevel/) | Mengatur level pesan log yang dikeluarkan oleh Aspose.Tasks selama leveling sumber daya. |
| [set_Resources](./set_resources/) | Mengatur daftar sumber daya yang akan di-leveling. Jika null diatur, semua sumber daya proyek akan di-leveling. |
| [set_StartDate](./set_startdate/) | Mengatur tanggal mulai periode leveling. Nilai default adalah tanggal mulai project`s. |
