## PageInfo class

Mewakili data pengaturan halaman yang ada dalam format file MPP dan digunakan untuk pencetakan.

## Konstruktor

| Nama | Deskripsi |
| --- | --- |
| [PageInfo](./pageinfo/) | Menginisialisasi instance baru dari kelas PageInfo. Mewakili data pengaturan halaman yang ada dalam format file MPP dan digunakan untuk pencetakan. |

## Metode

| Nama | Deskripsi |
| --- | --- |
| [get_Footer](./get_footer/) | Mendapatkan instance dari kelas HeaderFooterInfo yang mewakili data footer. |
| [get_Header](./get_header/) | Mendapatkan instance dari kelas HeaderFooterInfo yang mewakili data header. |
| [get_Legend](./get_legend/) | Mendapatkan instance dari kelas PageLegend yang menentukan opsi rendering legenda halaman. |
| [get_Margins](./get_margins/) | Mendapatkan instance dari kelas PageMargins yang menentukan margin halaman. |

| [get_PageSettings](./get_pagesettings/) | Mendapatkan instance dari kelas PageSettings yang menentukan pengaturan pencetakan halaman. |
| [get_PageViewSettings](./get_pageviewsettings/) | Mendapatkan instance dari kelas PageViewSettings yang menentukan pengaturan pencetakan tampilan halaman. |
| [set_Footer](./set_footer/) | Mengatur instance dari kelas HeaderFooterInfo yang mewakili data footer. |
| [set_Header](./set_header/) | Mengatur instance dari kelas HeaderFooterInfo yang mewakili data header. |
| [set_Legend](./set_legend/) | Mengatur instance dari kelas PageLegend yang menentukan opsi rendering legenda halaman. |
