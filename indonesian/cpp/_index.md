API menyediakan model objek yang kaya untuk menangani format Project XML, MPX, MPP, dan Primavera XER, mendukung tugas, sumber daya, penugasan, kalender, dan bidang khusus. Fungsionalitasnya diatur dalam sembilan namespace: Aspose::Tasks untuk entitas inti, Connectivity untuk file I/O, Leveling untuk penyeimbangan sumber daya, Primavera untuk objek khusus Primavera, Properties untuk atribut yang diperluas, RiskAnalysis untuk pemodelan risiko Monte‑Carlo, Saving untuk opsi ekspor, Util untuk utilitas pembantu, dan Visualization untuk rendering diagram Gantt dan laporan.

| [Aspose::Tasks::Leveling](./aspose.tasks.leveling/) | Namespace Aspose::Tasks::Leveling menawarkan kelas untuk mengkonfigurasi dan mengeksekusi penyeimbangan sumber daya dalam jadwal proyek. |

| [Aspose::Tasks::RiskAnalysis](./aspose.tasks.riskanalysis/) | Menyediakan kelas dan enum untuk melakukan analisis risiko Monte‑Carlo pada jadwal proyek. |
