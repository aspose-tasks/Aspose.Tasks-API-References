Menentukan bahwa teks diatur rata tengah dalam persegi panjang tata letak.

### Far {#Far}
```
public static final int Far
```


Menentukan bahwa teks diatur rata jauh dari posisi asal persegi panjang tata letak. Pada tata letak kiri-ke-kanan, posisi jauh adalah kanan. Pada tata letak kanan-ke-kiri, posisi jauh adalah kiri.

### Near {#Near}
```
public static final int Near
```


Menentukan teks diatur rata dekat dengan tata letak. Pada tata letak kiri-ke-kanan, posisi dekat adalah kiri. Pada tata letak kanan-ke-kiri, posisi dekat adalah kanan.
