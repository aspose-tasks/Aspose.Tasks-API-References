## TimescaleTier.RenderLabelOnEachPage property

Mendapatkan atau mengatur flag yang menentukan apakah label tanggal harus dirender pada setiap halaman ketika periode waktu melintasi beberapa halaman. Jika nilai 'true', ketika periode waktu melintasi beberapa halaman, label tanggal untuk periode tersebut dirender pada setiap halaman. Jika nilai 'false', label tanggal dirender hanya sekali sesuai nilai properti [`Alignment`](../alignment/).

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
