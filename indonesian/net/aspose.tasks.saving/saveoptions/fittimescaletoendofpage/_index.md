## SaveOptions.FitTimescaleToEndOfPage property

Mendapatkan atau mengatur apakah bagian kalender dari tampilan harus dirender ke akhir (sisi kanan) halaman terakhir. Jika nilai false, bagian kalender dirender tepat hingga EndDate, meskipun ada ruang kosong pada halaman.

```csharp
public bool FitTimescaleToEndOfPage { get; set; }
```
