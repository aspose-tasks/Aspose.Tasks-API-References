## WorkContourType enumeration

Menentukan kontur pekerjaan.

```csharp
public enum WorkContourType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Undefined | `-1` | Nilai tidak didefinisikan dalam file proyek asli. |
| Flat | `0` | Kontur kerja datar. |
| BackLoaded | `1` | Kontur kerja BackLoaded. |
| FrontLoaded | `2` | Kontur kerja FrontLoaded. |
| DoublePeak | `3` | Kontur kerja DoublePeak. |
| EarlyPeak | `4` | Kontur kerja EarlyPeak. |
| LatePeak | `5` | Kontur kerja LatePeak. |
| Bell | `6` | Kontur kerja Bell. |
| Turtle | `7` | Kontur kerja Turtle. |
| Contoured | `8` | Kontur kerja khusus. |

## Catatan

Saat mengekspor ke XML nilai Undefined akan dihilangkan dari XML yang dihasilkan.

## Contoh

Menampilkan cara mengatur kontur data berwaktu berbeda untuk penugasan sumber daya.

```csharp
var project = new Project();
project.Set(Prj.StartDate, new DateTime(2000, 1, 3, 8, 0, 0));
project.Set(Prj.FinishDate, new DateTime(2000, 1, 7, 17, 0, 0));

// tambahkan tugas
var task = project.RootTask.Children.Add("Task");
task.Set(Tsk.Start, new DateTime(2000, 1, 3, 8, 0, 0));
task.Set(Tsk.Duration, project.GetDuration(8, TimeUnitType.Hour));
task.Set(Tsk.Finish, new DateTime(2000, 1, 3, 17, 0, 0));

var resource = project.Resources.Add("Resource");

// tambahkan penugasan sumber daya
var resourceAssignment = project.ResourceAssignments.Add(task, resource);
resourceAssignment.Set(Asn.Start, new DateTime(2000, 1, 3, 8, 0, 0));
resourceAssignment.Set(Asn.Work, project.GetWork(8));
resourceAssignment.Set(Asn.Finish, new DateTime(2000, 1, 3, 17, 0, 0));

// Kontur datar adalah kontur default
Console.WriteLine("Flat contour");

var collection = task.GetTimephasedData(project.Get(Prj.StartDate), project.Get(Prj.FinishDate));
foreach (var td in collection)
{
    Console.WriteLine(td.Start.ToShortDateString() + " " + td.Value);
}

// Ubah kontur
Console.WriteLine("Turtle contour");
```
