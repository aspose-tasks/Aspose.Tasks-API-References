Berisi kelas untuk bekerja dengan basis data.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DbSettings](./dbsettings/) | Mengizinkan untuk menentukan pengaturan membaca dari basis data proyek. |
| [MpdSettings](./mpdsettings/) | Mengizinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari format MPD (format file basis data MS Access). |
| [MspDbSettings](./mspdbsettings/) | Mengizinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari basis data MS Project Server. |
| [PrimaveraDbSettings](./primaveradbsettings/) | Mengizinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari basis data Primavera. |
