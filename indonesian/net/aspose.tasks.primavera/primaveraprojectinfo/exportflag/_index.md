## PrimaveraProjectInfo.ExportFlag property

Mendapatkan flag ekspor proyek. Ketika sebuah proyek dipilih untuk diekspor di Primavera, ExportFlag-nya bernilai true. Beberapa proyek yang tidak dipilih secara eksplisit untuk ekspor dapat diekspor ke file XER karena hubungannya dengan proyek yang diekspor.

public bool ExportFlag { get; }
