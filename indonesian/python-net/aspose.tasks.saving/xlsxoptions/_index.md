## XlsxOptions class

Memungkinkan untuk menentukan opsi tambahan saat merender halaman proyek ke XLSX.

Tipe XlsxOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| XlsxOptions() | Menginisialisasi sebuah instance baru dari kelas [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) yang dapat digunakan untuk menyimpan proyek dalam format XLSX. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| save_format | Mendapatkan atau mengatur format di mana dokumen akan disimpan jika objek opsi penyimpanan ini digunakan. |
| resource_view | Mendapatkan atau mengatur daftar kolom tampilan sumber daya yang akan dirender ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Mendapatkan atau mengatur daftar kolom tampilan penugasan yang akan dirender ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| encoding | Mendapatkan atau mengatur encoding file XLSX yang dihasilkan. Nilai default adalah . |
| view | Mendapatkan atau mengatur daftar kolom tampilan ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) untuk disimpan ke format XLSX.<br/>            Jika tidak diatur maka kolom default akan disimpan. |
