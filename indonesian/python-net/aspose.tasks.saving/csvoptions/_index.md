## CsvOptions class

Memungkinkan untuk menentukan opsi tambahan saat menyimpan proyek ke CSV.

Jenis CsvOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| CsvOptions() | Memulai sebuah instance baru dari kelas [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) yang dapat digunakan untuk menyimpan proyek dalam format CSV. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| save_format | Mendapatkan atau mengatur format di mana dokumen akan disimpan jika objek opsi penyimpanan ini digunakan. |
| data_category | Mendapatkan atau mengatur kategori data yang akan disimpan. |
| encoding | Mendapatkan atau mengatur enkoding untuk menyimpan CSV. |
| include_headers | Mendapatkan atau mengatur nilai yang menunjukkan apakah menyertakan header atau tidak (nilai default adalah TRUE). |
| text_delimiter | Mendapatkan atau mengatur pembatas teks. |
| view | Mendapatkan atau mengatur daftar kolom tampilan ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) untuk disimpan ke format XLSX.<br/>            Jika tidak diatur maka kolom default akan disimpan. |
