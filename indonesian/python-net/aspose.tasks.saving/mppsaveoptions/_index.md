## MPPSaveOptions class

Memungkinkan untuk menentukan opsi tambahan saat menyimpan data proyek ke MPP.

Tipe MPPSaveOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| MPPSaveOptions() | Menginisialisasi instance baru dari kelas [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| save_format | Mendapatkan atau mengatur format di mana dokumen akan disimpan jika objek opsi penyimpanan ini digunakan. |
| remove_invalid_assignments | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menghapus penugasan sumber daya yang tidak valid saat menyimpan ke MPP. |
| write_view_data | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menulis data tampilan saat menyimpan proyek ke format MPP. |
| write_filters | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menulis data filter saat menyimpan proyek ke format MPP. |
| write_groups | Mendapatkan atau mengatur nilai yang menunjukkan apakah menulis data grup saat menyimpan proyek ke format MPP. |
| clear_vba | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menghapus data makro VBA yang ada saat menyimpan proyek ke format MPP. |
| write_vba | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan memperbarui data makro VBA yang ada dalam file MPP.<br/>            Saat ini penulisan VbaModule.SourceCode didukung. |
| protection_password | Mendapatkan atau mengatur kata sandi yang digunakan untuk melindungi file MPP yang dihasilkan. Saat ini didukung untuk MS Project 2010 dan format yang lebih baru. |
