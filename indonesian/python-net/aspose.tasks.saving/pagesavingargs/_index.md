## PageSavingArgs class

Kelas ini mewakili sekumpulan data yang terkait dengan penyimpanan halaman dokumen ke aliran.

Tipe PageSavingArgs menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| page_number | Mendapatkan nomor halaman yang akan ditulis. |
| keep_stream_open | Mendapatkan atau mengatur nilai yang menunjukkan apakah prosedur rendering harus menjaga [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) tetap terbuka setelah halaman ditulis. |
| stream | Mendapatkan atau mengatur aliran untuk menulis halaman. |
