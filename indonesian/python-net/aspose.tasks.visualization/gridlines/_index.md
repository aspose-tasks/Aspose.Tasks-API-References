## Gridlines class

Mewakili garis kisi yang muncul dalam tampilan GanttChart.

Tipe Gridlines menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Gridlines() | Menginisialisasi instance baru dari kelas Gridlines |
## Properti
| Nama | Deskripsi |
| :- | :- |
| interval | Mendapatkan atau mengatur angka dari 0 hingga 99 yang menentukan interval antara garis kisi. |
| interval_color | Mendapatkan atau mengatur warna garis kisi sekunder. |
| interval_pattern | Mendapatkan atau mengatur pola garis untuk garis kisi sekunder. |
| normal_color | Mendapatkan atau mengatur warna garis kisi normal. |
| normal_pattern | Mendapatkan atau mengatur pola garis untuk garis kisi normal. |
| tipe | Mendapatkan atau mengatur tipe garis kisi. |
