## GanttBarStyle class

Mewakili gaya batang yang digunakan oleh MSP dalam tampilan Gantt Chart.

Tipe GanttBarStyle menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| GanttBarStyle() | Menginisialisasi sebuah instance baru dari kelas [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| bottom_field | Mendapatkan atau mengatur data yang akan ditampilkan di bagian bawah bar.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| end_shape | Mendapatkan atau mengatur bentuk akhir dari bar. |
| end_shape_color | Mendapatkan atau mengatur warna dari bentuk akhir. |
| end_shape_type | Mendapatkan atau mengatur tipe dari bentuk akhir.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| from_address | Mendapatkan atau mengatur posisi titik awal dari bar gantt.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | Mendapatkan atau mengatur data yang akan ditampilkan di dalam bar.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| left_field | Mendapatkan atau mengatur data yang akan ditampilkan di sebelah kiri bar.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| middle_fill_pattern | Mendapatkan atau mengatur pola isi dari bar gantt. |
| middle_shape | Mendapatkan atau mengatur bentuk tengah dari batang. |
| middle_shape_color | Mendapatkan atau mengatur warna bentuk tengah. |
| name | Mendapatkan atau mengatur nama gaya. |
| right_field | Mendapatkan atau mengatur data yang ditampilkan di sebelah kanan batang.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| row | Mendapatkan atau mengatur nomor baris. |
| show_for_categories | Mendapatkan atau mengatur kategori tugas yang gaya diterapkan. Berlaku untuk gaya induk (atau umum) batang dalam diagram Gantt<br/>            (lihat [bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| show_for_task_uid | Mendapatkan atau mengatur Id Unik dari tugas yang gaya diterapkan. Berlaku untuk gaya batang khusus tugas dalam diagram Gantt (lihat [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | Mendapatkan atau mengatur bentuk awal batang. |
| start_shape_color | Mendapatkan atau mengatur warna bentuk awal. |
| start_shape_type | Mendapatkan atau mengatur tipe bentuk awal. |
| to | Mendapatkan atau mengatur posisi titik akhir batang gantt. |
| top_field | Mendapatkan atau mengatur data yang ditampilkan di bagian atas batang. |
| parent_style | Mendapatkan atau mengatur gaya induk (atau umum) untuk gaya khusus tugas. |
