## ResourceViewColumn class

Kelas tampilan proyek yang digunakan dalam tampilan ResourceUsage dan tampilan ResourceSheet.

Tipe ResourceViewColumn memperlihatkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ResourceViewColumn(width, field) | Menginisialisasi sebuah instance baru dari kelas ResourceViewColumn |
## Properti
| Nama | Deskripsi |
| :- | :- |
| field | Kolom field. <br/>            [field](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/). |
| name | Mendapatkan nama kolom. |
| string_alignment | Mendapatkan atau mengatur perataan teks (bisa menjadi salah satu nilai dari enumerasi [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Mendapatkan lebar kolom. |
| text_style_modification_callback | Mendapatkan atau mengatur callback yang dapat digunakan untuk menyesuaikan tampilan sel kolom. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| get_column_text(resource) | Mengonversi sumber daya saat ini menjadi teks kolom. |
