Tipe TableTextStyle menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TableTextStyle(row_uid) | Menginisialisasi instance baru dari kelas TableTextStyle |
| TableTextStyle(row_uid, font) | Menginisialisasi instance baru dari kelas TableTextStyle |
| TableTextStyle(row_uid, font_size, font_style) | Menginisialisasi instance baru dari kelas TableTextStyle |
| TableTextStyle(row_uid, font_style) | Menginisialisasi instance baru dari kelas TableTextStyle |

| Nama | Deskripsi |
| :- | :- |
