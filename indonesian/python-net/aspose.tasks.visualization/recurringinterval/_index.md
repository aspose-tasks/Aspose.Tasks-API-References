## RecurringInterval class

Mewakili interval berulang yang digunakan dalam garis kemajuan pada tampilan Diagram Gantt.

Tipe RecurringInterval menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| RecurringInterval() | Menginisialisasi instance baru dari kelas RecurringInterval |
## Properti
| Nama | Deskripsi |
| :- | :- |
| interval | Mendapatkan atau mengatur interval berulang.<br/>            Dapat berupa nilai apa pun dari tipe [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | Mendapatkan atau mengatur nomor hari harian. |
| daily_workday | Mendapatkan atau mengatur nilai yang menunjukkan apakah suatu hari adalah hari kerja untuk garis kemajuan harian. |
| weekly_week_number | Mendapatkan atau mengatur nomor minggu untuk garis kemajuan mingguan. |
| monthly_day | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menampilkan garis kemajuan bulanan per hari. |
| monthly_day_day_number | Mendapatkan atau mengatur nomor hari untuk garis kemajuan bulanan. |
| monthly_day_month_number | Mendapatkan atau mengatur nomor bulan untuk garis kemajuan bulanan. |
| monthly_first_last | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menampilkan garis kemajuan berdasarkan hari pertama atau terakhir yang telah ditentukan. |
| monthly_first_last_month_number | Mendapatkan atau mengatur nomor bulan dari garis kemajuan, yang ditampilkan berdasarkan hari pertama atau terakhir yang telah ditentukan. |
| monthly_first_last_day | Mendapatkan atau mengatur tipe hari pertama atau terakhir untuk garis kemajuan bulanan. |
| weekly_days | Mendapatkan daftar hari untuk garis kemajuan mingguan. |
