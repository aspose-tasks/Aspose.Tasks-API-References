## Gridline class

Tipe Gridline menampilkan anggota-anggota berikut:

| Nama | Deskripsi |
| :- | :- |
| Gridline() | Menginisialisasi instance baru dari kelas [Gridline](/tasks/python-net/aspose.tasks.visualization/gridline/). |
