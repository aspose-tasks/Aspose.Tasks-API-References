## PageInfo class

Mewakili data pengaturan halaman yang ada dalam format file MPP dan digunakan untuk pencetakan.

Tipe PageInfo menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PageInfo() | Menginisialisasi sebuah instance baru dari kelas [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/). <br/>            Mewakili data pengaturan halaman yang terdapat dalam format file MPP dan digunakan untuk pencetakan. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| header | Mendapatkan atau mengatur instance dari kelas [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) yang mewakili data header. |
| footer | Mendapatkan atau mengatur sebuah instance dari kelas [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) yang mewakili data footer. |
| name | Mendapatkan nama tampilan yang data penyiapannya digunakan. |
| page_settings | Mendapatkan sebuah instance dari kelas [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) yang menentukan pengaturan pencetakan halaman. |
| page_view_settings | Mendapatkan sebuah instance dari kelas [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) yang menentukan pengaturan pencetakan tampilan halaman. |
| margins | Mendapatkan sebuah instance dari kelas [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) yang menentukan margin halaman. |
| legend | Mendapatkan atau mengatur sebuah instance dari kelas [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) yang menentukan opsi rendering legenda halaman. |
