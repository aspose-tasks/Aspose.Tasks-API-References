## TaskTextStyleEventArgs class

Kelas ini mewakili sekumpulan data yang terkait dengan perenderan konten sel tabel.

Tipe TaskTextStyleEventArgs menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| cell_text_style | Mendapatkan atau mengatur TextStyle yang akan digunakan untuk menggambar konten sel. Objek ini dapat digunakan untuk menyesuaikan tampilan sel tabel. |
| task | Mendapatkan [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) yang sesuai dengan baris yang sedang dirender. |
| column | Mendapatkan [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) tempat sel yang sedang dirender berada. |
