## ProgressLines class

Mewakili garis kemajuan dalam tampilan Diagram Gantt.

Tipe ProgressLines menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ProgressLines() | Menginisialisasi instance baru dari kelas ProgressLines |
## Properti
| Nama | Deskripsi |
| :- | :- |
| display_at_current_date | Mendapatkan atau mengatur nilai yang menunjukkan apakah menampilkan garis kemajuan pada tanggal saat ini. |
| display_at_recurring_intervals | Mendapatkan atau mengatur nilai yang menunjukkan apakah menampilkan garis kemajuan pada interval berulang. |
| recurring_interval | Mendapatkan atau mengatur interval berulang.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Mendapatkan atau mengatur nilai yang menunjukkan apakah menampilkan garis kemajuan sejak tanggal mulai proyek. |
| begin_at_date | Mendapatkan atau mengatur tanggal untuk menampilkan garis kemajuan mulai dari. |
| display_selected | Mendapatkan atau mengatur nilai yang menunjukkan apakah menampilkan garis kemajuan pada tanggal yang dipilih. |
| is_baseline_plan | Mendapatkan atau mengatur nilai yang menunjukkan apakah menampilkan garis kemajuan untuk rencana baseline atau aktual. |
| show_date | Mendapatkan atau mengatur nilai yang menunjukkan apakah menampilkan tanggal untuk setiap garis kemajuan. |
| date_format | Mendapatkan atau mengatur format tanggal ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Mendapatkan atau mengatur font yang digunakan untuk label garis kemajuan. |
| line_pattern | Mendapatkan atau mengatur pola garis dari garis kemajuan saat ini.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Mendapatkan atau mengatur warna garis untuk garis kemajuan saat ini. |
| progress_point_shape | Mendapatkan atau mengatur bentuk titik kemajuan.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Mendapatkan atau mengatur warna titik kemajuan. |
| other_line_pattern | Mendapatkan atau mengatur pola garis untuk garis kemajuan lainnya. |
| other_line_color | Mendapatkan atau mengatur warna garis kemajuan lainnya. |
| other_progress_point_shape | Mendapatkan atau mengatur bentuk titik kemajuan dari garis kemajuan lainnya. |
| other_progress_point_color | Mendapatkan atau mengatur warna titik kemajuan lainnya. |
| selected_dates | Mendapatkan daftar tanggal yang dipilih untuk menampilkan garis kemajuan. |
