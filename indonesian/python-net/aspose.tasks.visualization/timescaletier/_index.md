## TimescaleTier class

Mewakili satu tingkat skala waktu pada Diagram Gantt.

Tipe TimescaleTier menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TimescaleTier() | Menginisialisasi instance baru dari kelas [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Menginisialisasi instance baru dari kelas TimescaleTier |
## Properti
| Nama | Deskripsi |
| :- | :- |
| count | Mendapatkan atau mengatur interval satuan waktu di mana label untuk tier ditampilkan.<br/>            Nilai default adalah 1. |
| label | Mendapatkan atau mengatur label tanggal [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) untuk tier skala waktu. |
| alignment | Mendapatkan atau mengatur cara menyelaraskan label dalam setiap periode waktu pada tier ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Mendapatkan atau mengatur nilai yang menunjukkan apakah label tier didasarkan pada tahun fiskal. |
| show_ticks | Mendapatkan atau mengatur nilai yang menunjukkan apakah menampilkan tanda penanda yang memisahkan periode waktu dalam tier. |
| unit | Mendapatkan atau mengatur satuan skala waktu [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) untuk tier skala waktu.<br/>            Nilai default adalah |
| render_label_on_each_page | Mendapatkan atau mengatur flag yang menentukan apakah label tanggal harus ditampilkan pada setiap halaman ketika suatu periode waktu melintasi beberapa halaman.<br/>            Jika nilai 'true', ketika periode waktu melintasi beberapa halaman, label tanggal untuk periode tersebut ditampilkan pada setiap halaman.<br/>            Jika nilai 'false', label tanggal hanya ditampilkan sekali sesuai nilai properti [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
