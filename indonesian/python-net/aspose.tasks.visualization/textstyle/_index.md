## TextStyle class

Ubah gaya visual teks untuk sebuah item dalam tampilan proyek.

Tipe TextStyle menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextStyle() | Menginisialisasi instance baru dari kelas [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) dengan pengaturan default. |
| TextStyle(font_size, font_style) | Menginisialisasi instance baru dari kelas TextStyle |
| TextStyle(font_style) | Menginisialisasi instance baru dari kelas [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) dengan font default dan ukuran serta gaya font yang ditentukan. |
| TextStyle(font) | Menginisialisasi instance baru dari kelas [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) dengan pengaturan font yang ditentukan. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| font | Mendapatkan atau mengatur font dari gaya teks. |
| color | Mendapatkan atau mengatur warna teks. |
| item_type | Mendapatkan atau mengatur [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) dari gaya teks. |
| background_pattern | Mendapatkan atau mengatur pola latar belakang dari gaya teks.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Mendapatkan atau mengatur warna latar belakang dari gaya teks.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
