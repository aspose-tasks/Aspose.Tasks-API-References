## BarStyle class

Ubah gaya visual batang untuk item dalam tampilan proyek.

Tipe BarStyle menyediakan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| BarStyle() | Menginisialisasi instance baru dari kelas [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| bar_color | Mendapatkan atau mengatur aspose.pydrawing.Color dari gaya bar. |
| start_shape_color | Mendapatkan atau mengatur aspose.pydrawing.Color dari bentuk di awal bar. |
| start_shape_type | Mendapatkan atau mengatur tipe bentuk awal. |
| end_shape_color | Mendapatkan atau mengatur aspose.pydrawing.Color dari bentuk di akhir bar. |
| end_shape_type | Mendapatkan atau mengatur tipe dari bentuk akhir.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | Mendapatkan atau mengatur [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) dari gaya bar. |
| bar_shape | Mendapatkan atau mengatur [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) dari gaya bar. |
| start_shape | Mendapatkan atau mengatur [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) di awal bar. |
| end_shape | Mendapatkan atau mengatur [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) di akhir bar. |
| text_style | Mendapatkan atau mengatur gaya teks bar. |
| left_field | Mendapatkan atau mengatur bidang yang ditampilkan di sebelah kiri bar. |
| top_field | Mendapatkan atau mengatur bidang yang ditampilkan di bagian atas bar. |
| right_field | Mendapatkan atau mengatur bidang yang ditampilkan di sebelah kanan bar. |
| bottom_field | Mendapatkan atau mengatur bidang yang akan ditampilkan di bagian bawah batang. |
| inside_field | Mendapatkan atau mengatur bidang yang akan ditampilkan di dalam batang. |
| from_address | Mendapatkan atau mengatur posisi titik awal dari bar gantt.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | Mendapatkan atau mengatur posisi titik akhir batang gantt. |
