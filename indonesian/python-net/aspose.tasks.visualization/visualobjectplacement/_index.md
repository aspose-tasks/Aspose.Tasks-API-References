## VisualObjectPlacement class

Mewakili penempatan dan tampilan [OleObject](/tasks/python-net/aspose.tasks/oleobject/) dalam sebuah tampilan.

Tipe VisualObjectPlacement menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| VisualObjectPlacement() | Menginisialisasi instance baru dari kelas [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| ole_object_id | Mendapatkan atau mengatur Id dari objek [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
| task_id | Mendapatkan atau mengatur Id tugas jika opsi 'Attach to task' dipilih, -1 jika tidak. |
| width | Mendapatkan atau mengatur lebar tampilan objek visual. |
| height | Mendapatkan atau mengatur tinggi tampilan objek visual. |
| vertical_offset | Mendapatkan atau mengatur offset vertikal objek visual. |
| horizontal_offset | Mendapatkan atau mengatur offset horizontal objek visual. |
| timescale_date | Mendapatkan atau mengatur penempatan tanggal objek visual ketika opsi 'Attach to timescale' dipilih. |
| attachment_point | Mendapatkan atau mengatur penyelarasan objek visual relatif terhadap tugas ketika opsi 'Attach to task' dipilih. |
| border_line_color | Mendapatkan atau mengatur warna garis batas. |
| border_line_thickness | Mendapatkan atau mengatur ketebalan garis batas (nilai yang diizinkan adalah 0 - 5). |
| fill_color | Mendapatkan atau mengatur warna isi. |
| fill_pattern | Mendapatkan atau mengatur pola isi. |
