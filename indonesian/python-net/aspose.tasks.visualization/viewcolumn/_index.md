## ViewColumn class

Mewakili sebuah kolom dalam tampilan proyek.

Tipe ViewColumn menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| field | Mendapatkan atau mengatur bidang kolom.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/viewcolumn/). |
| name | Mendapatkan nama kolom. |
| string_alignment | Mendapatkan atau mengatur perataan teks (bisa menjadi salah satu nilai dari enumerasi [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Mendapatkan lebar kolom. |
| text_style_modification_callback | Mendapatkan atau mengatur callback yang dapat digunakan untuk menyesuaikan tampilan sel kolom. |
