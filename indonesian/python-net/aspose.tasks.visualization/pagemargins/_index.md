## PageMargins class

Mewakili margin halaman untuk pencetakan.

Tipe PageMargins menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PageMargins() | Menginisialisasi instance baru dari kelas PageMargins |
## Properti
| Nama | Deskripsi |
| :- | :- |
| top | Mendapatkan atau mengatur ukuran margin atas dalam sentimeter. |
| bottom | Mendapatkan atau mengatur ukuran margin bawah dalam sentimeter. |
| left | Mendapatkan atau mengatur ukuran margin kiri dalam sentimeter. |
| right | Mendapatkan atau mengatur ukuran margin kanan dalam sentimeter. |
| borders | Mendapatkan atau mengatur posisi tempat mencetak batas. Dapat menjadi salah satu nilai dari enumerasi [Border](/tasks/python-net/aspose.tasks.visualization/border/). |
