## TimescaleUnit enumeration

Menentukan satuan waktu untuk setiap tingkat skala waktu dalam Gantt chart atau tampilan berfase waktu lainnya.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Menunjukkan Tidak Ada. Tingkat skala waktu disembunyikan. |
| MINUTES | Menunjukkan satuan skala waktu Menit. |
| HOURS | Menunjukkan satuan skala waktu Jam. |
| DAYS | Menunjukkan satuan skala waktu Hari. |
| WEEKS | Menunjukkan satuan skala waktu Minggu. |
| THIRDS_OF_MONTHS | Menunjukkan satuan skala waktu Sepertiga bulan. |
| MONTHS | Menunjukkan satuan skala waktu Bulan. |
| QUARTERS | Menunjukkan satuan skala waktu Kuartal tahun. |
| HALF_YEARS | Menunjukkan satuan skala waktu Setengah tahun. |
| YEARS | Menunjukkan satuan skala waktu Tahun. |
