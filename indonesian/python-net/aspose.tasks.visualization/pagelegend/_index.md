## PageLegend class

Mewakili legenda halaman yang digunakan untuk pencetakan proyek.

Tipe PageLegend menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PageLegend() | Menginisialisasi instance baru dari kelas PageLegend |
## Properti
| Nama | Deskripsi |
| :- | :- |
| left_text | Mendapatkan atau mengatur teks yang diratakan ke kiri untuk ditampilkan dalam elemen induk. |
| centered_text | Mendapatkan atau mengatur teks yang diratakan tengah untuk ditampilkan dalam elemen induk. |
| right_text | Mendapatkan atau mengatur teks yang diratakan ke kanan untuk ditampilkan dalam elemen induk. |
| left_image | Mendapatkan atau mengatur gambar yang diratakan ke kiri untuk ditampilkan dalam elemen induk. |
| centered_image | Mendapatkan atau mengatur gambar yang diratakan tengah untuk ditampilkan dalam elemen induk. |
| right_image | Mendapatkan atau mengatur gambar yang diratakan kanan untuk ditampilkan dalam elemen induk. |
| left_image_size | Mendapatkan atau mengatur ukuran tampilan gambar kiri. |
| centered_image_size | Mendapatkan atau mengatur ukuran tampilan gambar tengah. |
| right_image_size | Mendapatkan atau mengatur ukuran tampilan gambar kanan. |
| legend_on | Mendapatkan atau mengatur halaman tempat legenda muncul. Dapat menjadi salah satu nilai dari enumerasi [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | Mendapatkan atau mengatur lebar bagian kiri (yang berisi nama dan tanggal proyek secara default) dari legenda dalam sentimeter. |
