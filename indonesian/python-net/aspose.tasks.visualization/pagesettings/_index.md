## PageSettings class

Mewakili pengaturan pencetakan untuk satu halaman tampilan proyek.

Tipe PageSettings menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PageSettings() | Menginisialisasi instance baru dari kelas [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Mewakili pengaturan pencetakan untuk satu halaman tampilan proyek. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_portrait | Mendapatkan atau mengatur nilai yang menunjukkan apakah orientasi halaman portrait; mengembalikan false jika orientasi halaman landscape. |
| adjust_to_percent_of_normal_size | Mendapatkan atau mengatur nilai yang menunjukkan apakah mencetak harus disesuaikan ke persentase yang ditentukan ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) dari ukuran normal. |
| percent_of_normal_size | Mendapatkan atau mengatur persentase ukuran normal untuk menyesuaikan pencetakan. |
| pages_in_width | Mendapatkan atau mengatur jumlah halaman dalam lebar yang akan dicetak. |
| pages_in_height | Mendapatkan atau mengatur jumlah halaman dalam tinggi yang akan dicetak. |
| paper_size | Mendapatkan atau mengatur ukuran kertas. Bisa menjadi salah satu nilai dari enumerasi [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | Mendapatkan atau mengatur integer yang mewakili salah satu nilai PrinterPaperSize atau id ukuran halaman khusus.<br/>            Nilai ini dapat digunakan untuk mendapatkan PaperSize dari pengaturan OS |
| first_page_number | Mendapatkan atau mengatur nomor halaman pertama untuk pencetakan. |
