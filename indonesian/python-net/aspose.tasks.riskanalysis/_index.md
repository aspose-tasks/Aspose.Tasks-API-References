Berisi kelas untuk membuat Laporan Analisis Risiko.

## Kelas
| Kelas | Deskripsi |
| :- | :- |
| [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) | Mewakili hasil analisis risiko. |
| [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) | Menentukan pengaturan untuk melakukan analisis risiko. |
| [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) | Melakukan simulasi Monte Carlo berdasarkan pengaturan analisis risiko yang ditentukan. |
| [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) | Mewakili item yang menyimpan data statistik untuk tugas pada proyek yang dianalisis. |
| [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) | Mewakili koleksi yang berisi instance dari kelas [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) | Mewakili pola risiko untuk tugas proyek. |
| [RiskPatternCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskpatterncollection/) | Mewakili koleksi yang berisi instance dari kelas [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |

| Enumerasi | Deskripsi |
| :- | :- |
