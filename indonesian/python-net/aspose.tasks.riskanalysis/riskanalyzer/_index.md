## RiskAnalyzer class

Melakukan simulasi Monte Carlo berdasarkan pengaturan analisis risiko yang ditentukan.

Tipe RiskAnalyzer menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| RiskAnalyzer(settings) | Menginisialisasi sebuah instance baru dari kelas [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| settings | Mendapatkan atau mengatur instance dari kelas [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) yang mendefinisikan pengaturan yang diperlukan untuk analisis risiko. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| analyze(project) | Melakukan analisis risiko untuk proyek yang ditentukan. Analisis ini didasarkan pada simulasi Monte Carlo dan hasilnya adalah sebuah instance dari kelas [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/). |
