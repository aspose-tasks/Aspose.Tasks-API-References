## RiskItemStatistics class

Mewakili item yang menyimpan data statistik untuk tugas pada proyek yang dianalisis.

Tipe RiskItemStatistics menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| item_type | Mendapatkan sebuah instance dari enumerasi [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) . |
| minimum | Mendapatkan nilai minimum yang dihasilkan selama simulasi Monte Carlo. |
| maximum | Mendapatkan nilai maksimum yang dihasilkan selama simulasi Monte Carlo. |
| expected_value | Mendapatkan nilai harapan dari item risiko. |
| standard_deviation | Mendapatkan deviasi standar dari item risiko. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| get_percentile(percent) | Mendapatkan nilai di bawah mana persentase tertentu dari sampel yang dihasilkan jatuh. |
