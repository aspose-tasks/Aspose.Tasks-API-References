## PrimaveraProjectInfo class

Mewakili info singkat tentang proyek yang dimuat dari format Primavera.

Tipe PrimaveraProjectInfo menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| uid | Mendapatkan Uid proyek. |
| name | Mendapatkan nama proyek. |
| short_name | Mendapatkan nama singkat proyek (ID Proyek). |
| export_flag | Mendapatkan flag ekspor proyek. Ketika sebuah proyek dipilih untuk diekspor di Primavera, ExportFlag-nya bernilai true.<br/>            Beberapa proyek yang tidak secara eksplisit dipilih untuk ekspor dapat diekspor ke file XER karena hubungannya dengan proyek yang diekspor. |
