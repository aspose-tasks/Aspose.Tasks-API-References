## MpdSettings class

Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari format MPD (format file basis data MS Access).

Tipe MpdSettings menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| MpdSettings(connection_string, project_id) | Menginisialisasi sebuah instance baru dari kelas [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| connection_string | Mendapatkan atau mengatur string koneksi. |
| provider_invariant_name | Mendapatkan atau mengatur nama penyedia invariant yang digunakan untuk mendapatkan sebuah instance dari kelas. |
| project_id | Mendapatkan ID proyek yang akan dibaca. |
