## MspDbSettings class

Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari basis data MS Project Server.

Tipe MspDbSettings menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Menginisialisasi sebuah instance baru dari kelas [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| connection_string | Mendapatkan atau mengatur string koneksi. |
| provider_invariant_name | Mendapatkan atau mengatur nama penyedia invariant yang digunakan untuk mendapatkan sebuah instance dari kelas. |
| project_guid | Mendapatkan GUID proyek yang akan dibaca. |
| schema | Mendapatkan atau mengatur skema MS Project Server.<br/>            Nilai default adalah "pub". |
