Berisi kelas untuk bekerja dengan basis data.

## Kelas
| Kelas | Deskripsi |
| :- | :- |
| [DbSettings](/tasks/python-net/aspose.tasks.connectivity/dbsettings/) | Memungkinkan untuk menentukan pengaturan membaca dari basis data proyek. |
| [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) | Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari format MPD (format file basis data MS Access). |
| [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/) | Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari basis data MS Project Server. |
| [PrimaveraDbSettings](/tasks/python-net/aspose.tasks.connectivity/primaveradbsettings/) | Memungkinkan untuk mengatur opsi yang diperlukan untuk membaca data proyek dari basis data Primavera. |
