## LevelingOptions class

Memungkinkan untuk menentukan parameter penyeimbangan sumber daya.

Tipe LevelingOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| LevelingOptions() | Menginisialisasi sebuah instance baru dari kelas [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| start_date | Mendapatkan atau mengatur tanggal mulai periode leveling. Nilai default adalah tanggal mulai proyek. |
| finish_date | Mendapatkan atau mengatur tanggal akhir periode leveling. Nilai default adalah tanggal selesai proyek. |
| sumber daya | Mendapatkan atau mengatur daftar sumber daya yang akan di-leveling. Jika null diatur, semua sumber daya proyek akan di-leveling. |
| leveling_order | Mendapatkan urutan di mana algoritma leveling menunda tugas yang memiliki alokasi berlebih.<br/>            Setelah menentukan tugas yang menyebabkan alokasi berlebih dan tugas mana yang dapat ditunda, urutan yang ditentukan digunakan untuk menentukan tugas mana yang harus ditunda pertama. |
| message_level | Mendapatkan atau mengatur tingkat pesan log yang dihasilkan oleh Aspose.Tasks selama leveling sumber daya. |
| message_handler | Mendapatkan atau mengatur callback penangan pesan yang dapat digunakan untuk mencegat pesan log yang dihasilkan oleh Aspose.Tasks selama leveling sumber daya. |
