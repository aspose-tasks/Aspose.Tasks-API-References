## TableField class

Mewakili bidang dari sebuah tabel dalam proyek.

Tipe TableField menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TableField() | Menginisialisasi sebuah instance baru dari kelas [TableField](/tasks/python-net/aspose.tasks/tablefield/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| align_data | Mendapatkan atau mengatur perataan data dalam bidang tabel. |
| align_title | Mendapatkan atau mengatur perataan judul dalam bidang tabel. |
| field | Mendapatkan atau mengatur tipe bidang tabel. |
| title | Mendapatkan atau mengatur judul bidang dalam tabel. |
| width | Mendapatkan atau mengatur lebar dalam poin kolom bidang dalam tabel. |
| wrap_header | Mendapatkan atau mengatur nilai yang menunjukkan apakah judul kolom tabel dapat dibungkus ke beberapa baris, atau harus dipotong ketika melebihi lebar kolom. |
| wrap_text | Mendapatkan atau mengatur nilai yang menunjukkan apakah teks kolom dapat membungkus ke beberapa baris, atau apakah harus dipotong ketika melebihi lebar kolom. |
