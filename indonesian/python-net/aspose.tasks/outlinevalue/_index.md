## OutlineValue class

Mewakili nilai outline.

Tipe OutlineValue menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| OutlineValue() | Menginisialisasi instance baru dari kelas OutlineValue |
## Properti
| Nama | Deskripsi |
| :- | :- |
| value_id | Mendapatkan atau mengatur Id unik dari nilai kode outline dalam sebuah proyek. |
| value_guid | Mendapatkan GUID yang mengidentifikasi nilai ini di antara nilai lain dalam seluruh proyek. |
| tipe | Mendapatkan atau mengatur tipe kode outline. |
| parent_value_id | Mendapatkan atau mengatur Id dari node induk sebuah kode outline. |
| value | Mendapatkan atau mengatur nilai aktual. |
| duration_value | Mendapatkan atau mengatur durasi jika Tipe adalah Durasi. |
| description | Mendapatkan atau mengatur deskripsi dari nilai outline. |
| is_collapsed | Mendapatkan atau mengatur nilai yang menunjukkan apakah nilai outline terlipat atau tidak. |
