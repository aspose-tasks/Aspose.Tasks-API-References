## ProjectServerSaveOptions class

Memungkinkan untuk menentukan opsi tambahan ketika proyek disimpan ke Project Server atau Project Online.

Tipe ProjectServerSaveOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ProjectServerSaveOptions() | Menginisialisasi instance baru dari kelas [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| project_name | Mendapatkan atau mengatur nama proyek yang ditampilkan dalam daftar proyek Project Server \ Project Online. Harus unik dalam instance Project Server \ Project Online.<br/>            Jika nilai dihilangkan, nilai properti Prj.Name akan digunakan sebagai gantinya. |
| project_guid | Mendapatkan atau mengatur pengidentifikasi unik sebuah proyek. Harus unik dalam instance Project Server \ Project Online. |
| timeout | Mendapatkan atau mengatur batas waktu yang digunakan saat menunggu pemrosesan permintaan penyimpanan proyek oleh layanan pemrosesan antrean Project Server. Nilai default properti ini adalah 1 menit. |
| polling_interval | Mendapatkan atau mengatur interval antara permintaan status pekerjaan antrean. Nilai default adalah 2 detik. |
