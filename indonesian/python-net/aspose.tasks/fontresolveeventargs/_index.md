## FontResolveEventArgs class

Menyediakan argumen untuk callback yang dipanggil ketika font diselesaikan.

Tipe FontResolveEventArgs menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| requested_font_name | Mendapatkan nama font yang diminta. |
| resolved_font_name | Mendapatkan atau mengatur nama font yang telah diselesaikan. Dapat diatur untuk mengontrol font yang digunakan untuk merender tampilan. |
