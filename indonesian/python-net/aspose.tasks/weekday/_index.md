## WeekDay class

Mewakili hari kerja yang dapat mendefinisikan hari reguler dalam seminggu atau hari pengecualian dalam kalender.

Tipe WeekDay menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| WeekDay(day_type) | Menginisialisasi instance baru dari kelas [WeekDay](/tasks/python-net/aspose.tasks/weekday/) dengan tipe hari yang ditentukan. |
| WeekDay(day_type, working_times) | Menginisialisasi instance baru dari kelas WeekDay |
| WeekDay(day_type, working_times) | Menginisialisasi instance baru dari kelas [WeekDay](/tasks/python-net/aspose.tasks/weekday/) dengan tipe hari dan periode waktu kerja yang ditentukan. |
| WeekDay() | Menginisialisasi instance baru dari kelas [WeekDay](/tasks/python-net/aspose.tasks/weekday/) dengan tipe hari yang ditentukan. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| day_type | Mendapatkan tipe hari. |
| day_working | Mendapatkan atau mengatur nilai yang menunjukkan apakah tanggal atau tipe hari yang ditentukan adalah hari kerja. |
| from_date | Mendapatkan atau mengatur awal waktu pengecualian. |
| to_date | Mendapatkan atau mengatur akhir waktu pengecualian. |
| working_times | Mendapatkan WorkingTimeCollection untuk instance WeekDay ini.<br/>            Koleksi waktu kerja yang mendefinisikan waktu kerja pada hari kerja tersebut. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| create_default_working_day(day_type) | Membuat hari kerja default. |
| set_default_working_time(day) | Mengatur periode waktu default untuk hari minggu yang ditentukan. |
| get_working_time() | Mengembalikan waktu kerja untuk satu hari kerja. |
| clone() | Mengembalikan salinan mendalam dari hari kerja. |
