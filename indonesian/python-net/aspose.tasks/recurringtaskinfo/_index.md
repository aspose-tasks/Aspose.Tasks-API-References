## RecurringTaskInfo class

Mewakili detail tugas berulang dalam sebuah proyek.

Tipe RecurringTaskInfo menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| recurrence_pattern | Mendapatkan atau mengatur pola pengulangan dari tugas berulang. |
| start_date | Mendapatkan atau mengatur tanggal mulai terjadinya kejadian. |
| end_date | Mendapatkan atau mengatur tanggal berakhirnya kejadian. |
| duration | Mendapatkan atau mengatur durasi untuk satu kejadian tugas berulang. |
| occurrences | Mendapatkan atau mengatur jumlah kejadian dari tugas berulang. |
| use_end_date | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menggunakan tanggal akhir atau jumlah kejadian untuk tugas berulang. |
| daily_repetitions | Mendapatkan atau mengatur jumlah pengulangan untuk pola pengulangan harian. |
| daily_use_workdays | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menggunakan hari kerja untuk pola pengulangan harian. |
| weekly_repetitions | Mendapatkan atau mengatur jumlah pengulangan untuk pola pengulangan mingguan. |
| weekly_days | Mendapatkan atau mengatur kumpulan hari yang digunakan dalam pola pengulangan mingguan. |
| monthly_use_ordinal_day | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menggunakan hari ordinal untuk pola pengulangan bulanan. |
| monthly_ordinal_number | Mendapatkan atau mengatur nomor ordinal dari pola pengulangan bulanan. |
| monthly_ordinal_repetitions | Mendapatkan atau mengatur jumlah pengulangan untuk pola pengulangan bulanan ketika menggunakan hari ordinal. |
| monthly_day | Mendapatkan atau mengatur jumlah hari dari pola pengulangan bulanan. |
| monthly_repetitions | Mendapatkan atau mengatur jumlah pengulangan untuk pola pengulangan bulanan. |
| yearly_use_ordinal_day | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menggunakan hari ordinal untuk pola pengulangan tahunan. |
| yearly_date | Mendapatkan atau mengatur tanggal untuk pola pengulangan tahunan. |
| yearly_ordinal_number | Mendapatkan atau mengatur nomor ordinal dari pola pengulangan tahunan. |
| yearly_ordinal_month | Mendapatkan atau mengatur bulan dari pola pengulangan tahunan ketika menggunakan hari ordinal. |
| task | Mendapatkan tugas induk dari instance kelas [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/) ini. |
