## Rate class

Mewakili definisi periode waktu dan tarif yang berlaku untuk sumber daya selama periode tersebut.

Tipe Rate menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| rates_from | Mendapatkan atau mengatur tanggal ketika tarif mulai berlaku. |
| rates_to | Mendapatkan atau mengatur tanggal terakhir ketika tarif berlaku. |
| rate_table | Mendapatkan atau mengatur pengidentifikasi unik dari tabel tarif untuk sebuah sumber daya. |
| standard_rate | Mendapatkan atau mengatur tarif standar per jam untuk sebuah sumber daya. |
| standard_rate_format | Mendapatkan atau mengatur satuan yang digunakan oleh Microsoft Project untuk menampilkan tarif standar. |
| overtime_rate | Mendapatkan atau mengatur tarif lembur per jam untuk sebuah sumber daya. |
| overtime_rate_format | Mendapatkan atau mengatur satuan yang digunakan oleh Microsoft Project untuk menampilkan tarif lembur. |
| cost_per_use | Mendapatkan atau mengatur biaya per penggunaan sumber daya. Nilai ini diambil dari tanggal saat ini jika ada tabel tarif untuk sumber daya. |
