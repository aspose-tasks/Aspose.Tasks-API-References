## TaskBaseline class

Mewakili Baseline dari sebuah Tugas.

Tipe TaskBaseline menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TaskBaseline(task) | Menginisialisasi instance baru dari kelas [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| baseline_number | Mendapatkan atau mengatur nomor unik dari catatan data baseline. |
| pekerjaan | Mendapatkan atau mengatur pekerjaan yang ditugaskan ke sumber daya saat baseline disimpan. |
| cost | Mendapatkan atau mengatur biaya proyeksi sumber daya saat baseline disimpan. |
| bcws | Mendapatkan atau mengatur biaya anggaran pekerjaan yang dijadwalkan untuk sumber daya. |
| bcwp | Mendapatkan atau mengatur biaya anggaran pekerjaan yang dilakukan oleh sumber daya untuk proyek hingga saat ini. |
| timephased_data | Mendapatkan atau mengatur instance TimephasedDataCollection untuk objek ini.<br/>            Data berfase waktu yang terkait dengan baseline tugas. |
| interim | Mendapatkan atau mengatur nilai yang menunjukkan apakah ini adalah Baseline Interim. |
| mulai | Mendapatkan atau mengatur tanggal mulai terjadwal tugas saat baseline disimpan. |
| finish | Mendapatkan atau mengatur tanggal selesai terjadwal tugas saat baseline disimpan. |
| duration | Mendapatkan atau mengatur durasi terjadwal tugas saat baseline disimpan. |
| estimated_duration | Mendapatkan atau mengatur nilai yang menunjukkan apakah durasi baseline tugas diperkirakan. |
| fixed_cost | Mendapatkan atau mengatur biaya tetap tugas ketika baseline disimpan. |
