## TaskStatus enumeration

Menentukan status tugas.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| UNDEFINED | Status tugas tidak terdefinisi. |
| COMPLETE | Tugas selesai 100 persen. |
| ON_SCHEDULE | Tugas tepat waktu jika persentase selesai kumulatif berwaktu tersebar setidaknya sampai hari sebelum tanggal status. |
| LATE | Tugas terlambat jika persentase selesai kumulatif berwaktu tidak mencapai tengah malam pada hari sebelum tanggal status. |
| FUTURE | 'Future' status tugas diatur ketika tanggal mulai tugas lebih besar dari tanggal status. |
