## FilterComparisonType enumeration

Jenis perbandingan yang dibuat antara FieldName dan Value yang berfungsi sebagai kriteria pemilihan untuk filter atau indikator grafis.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| EQUALS | Nilai Field sama dengan Value. |
| DOES_NOT_EQUAL | Nilai Field tidak sama dengan Value. |
| IS_GREATER_THAN | Nilai Field lebih besar dari Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | Nilai Field lebih besar dari atau sama dengan Value. |
| IS_LESS_THAN | Nilai Field lebih kecil dari Value. |
| IS_LESS_THAN_OR_EQUAL_TO | Nilai Field lebih kecil dari atau sama dengan Value. |
| IS_WITHIN | Nilai Field berada dalam Value. |
| IS_NOT_WITHIN | Nilai dari Field tidak berada dalam Value. |
| CONTAINS | Nilai dari Field berisi Value. |
| DOES_NOT_CONTAIN | Nilai dari Field tidak berisi Value. |
| CONTAINS_EXACTLY | Nilai dari Field secara tepat berisi Value. |
| IS_ONE_OF | Nilai dari Field sama dengan salah satu Values yang ditentukan. Digunakan dalam AutoFilters. |
| UNDEFINED | Nilai tidak terdefinisi. |
| IS_ANY_VALUE | Kondisi 'Is any value'. Berlaku untuk indikator grafis. |
