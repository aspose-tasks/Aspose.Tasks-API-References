## View class

Mewakili tampilan dalam Project.

Tipe View menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| View() | Menginisialisasi sebuah instance baru dari kelas [View](/tasks/python-net/aspose.tasks/view/). |
| View(view_screen) | Menginisialisasi sebuah instance baru dari kelas [View](/tasks/python-net/aspose.tasks/view/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| filter | Mendapatkan atau mengatur filter yang digunakan dalam satu tampilan. |
| grup | Mendapatkan atau mengatur grup dari tampilan tunggal. |
| uid | Mendapatkan pengidentifikasi unik dari sebuah tampilan. |
| highlight_filter | Mendapatkan atau mengatur nilai yang menunjukkan apakah Microsoft Project menyorot filter untuk tampilan tunggal. |
| name | Mendapatkan atau mengatur nama objek View. |
| screen | Mendapatkan tipe layar untuk tampilan tunggal.<br/>            Read-only [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Mendapatkan induk dari objek View.<br/>            Read-only [Project](/tasks/python-net/aspose.tasks/project/). |
| tabel | Mendapatkan atau mengatur tabel dari tampilan tunggal. |
| type | Mendapatkan tipe item dalam tampilan tunggal, seperti tugas atau sumber daya.<br/>            Read-only [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Mendapatkan atau mengatur nilai yang menunjukkan apakah Microsoft Project menampilkan nama tampilan tunggal di daftar drop-down View atau Other Views pada Ribbon. |
| page_info | Mendapatkan sebuah instance dari kelas [page_info](/tasks/python-net/aspose.tasks/view/). Mewakili data pengaturan halaman yang terdapat dalam format file mpp. |
| visual_objects_placements | Mendapatkan koleksi objek yang mewakili penempatan dan tampilan [OleObject](/tasks/python-net/aspose.tasks/oleobject/) dalam tampilan. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| compare_to(other) | Membandingkan instance saat ini dengan objek lain dari tipe yang sama dan mengembalikan sebuah integer yang menunjukkan apakah instance saat ini mendahului, mengikuti, atau berada pada posisi yang sama dalam urutan penyortiran dibandingkan dengan objek lainnya. |
