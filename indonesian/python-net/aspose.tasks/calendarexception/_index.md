## CalendarException class

Mewakili periode waktu khusus dalam kalender.

Tipe CalendarException menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| CalendarException() | Menginisialisasi sebuah instance baru dari kelas [CalendarException](/tasks/python-net/aspose.tasks/calendarexception/) . |
## Properti
| Nama | Deskripsi |
| :- | :- |
| entered_by_occurrences | Mendapatkan atau mengatur nilai yang menunjukkan apakah rentang pengulangan didefinisikan dengan memasukkan jumlah kejadian.<br/>            False menunjukkan bahwa rentang pengulangan didefinisikan dengan memasukkan tanggal selesai. |
| from_date | Mendapatkan atau mengatur awal waktu pengecualian. |
| to_date | Mendapatkan atau mengatur akhir waktu pengecualian. |
| occurrences | Mendapatkan atau mengatur jumlah kejadian di mana pengecualian kalender berlaku. |
| name | Mendapatkan atau mengatur nama pengecualian. |
| tipe | Mendapatkan atau mengatur tipe pengecualian. |
| period | Mendapatkan atau mengatur periode pengulangan untuk pengecualian. |
| days_of_week | Mendapatkan DayTypeCollection untuk objek ini.<br/>            Hari-hari dalam seminggu di mana pengecualian berlaku. |
| month_item | Mendapatkan atau mengatur item bulan di mana pengulangan pengecualian dijadwalkan. |
| month_position | Mendapatkan atau mengatur posisi item bulan dalam satu bulan. |
| bulan | Mendapatkan atau mengatur bulan di mana pengulangan pengecualian dijadwalkan. |
| month_day | Mendapatkan atau mengatur hari dalam bulan di mana pengulangan pengecualian dijadwalkan. |
| day_working | Mendapatkan atau mengatur nilai yang menunjukkan apakah tanggal atau tipe hari yang ditentukan adalah hari kerja. |
| working_times | Mendapatkan atau mengatur objek WorkingTimeCollection.<br/>            Kumpulan waktu kerja yang mendefinisikan waktu kerja pada hari kerja. |
| parent_calendar | Mendapatkan kalender induk untuk objek ini. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| delete() | Menghapus instance Exception dari objek CalendarExceptionCollection kalender induk. |
| check_exception(dt) | Mengembalikan true jika instance datetime struct yang ditentukan adalah hari pengecualian. |
| get_working_time() | Mengembalikan waktu kerja untuk pengecualian kalender. |
| get_exception_dates() | Mengembalikan tanggal-tanggal di mana pengecualian kalender berlaku. |
