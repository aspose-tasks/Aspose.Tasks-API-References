## TaskLink class

Mewakili tautan pendahulu.

Tipe TaskLink menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_cross_project | Mendapatkan atau mengatur nilai yang menunjukkan apakah sebuah predecessor merupakan bagian dari proyek lain. |
| cross_project_name | Mendapatkan atau mengatur proyek predecessor eksternal. |
| link_lag | Mendapatkan atau mengatur lag dalam seperseratus menit atau persentase. |
| link_lag_time_span | Mendapatkan atau mengatur durasi lag, tergantung pada LagFormat. |
| lag_format | Mendapatkan atau mengatur format untuk mengekspresikan format lag. |
| pred_task | Mendapatkan atau mengatur tugas predecessor. |
| succ_task | Mendapatkan atau mengatur tugas successor. |
| link_type | Mendapatkan atau mengatur tipe sebuah tautan. |
