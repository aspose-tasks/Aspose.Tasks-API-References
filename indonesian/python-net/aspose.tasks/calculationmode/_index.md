## CalculationMode enumeration

Menentukan mode perhitungan proyek.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Tidak ada. Tanggal dan biaya proyek tidak dihitung ulang dalam mode ini. |
| AUTOMATIC | Mode otomatis. Tanggal dan biaya proyek dihitung ulang saat menggunakan mode ini. |
| MANUAL | Mode manual. Hanya bidang yang diperlukan yang dihitung ulang dalam mode ini, misalnya UID dan ID objek. |
