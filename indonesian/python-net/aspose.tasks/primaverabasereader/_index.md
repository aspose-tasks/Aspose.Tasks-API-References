## PrimaveraBaseReader class

Mewakili pembaca dasar yang dapat digunakan untuk membaca UID Proyek dari file Primavera XER atau XML multi proyek.

Tipe PrimaveraBaseReader menampilkan anggota-anggota berikut:
## Methods
| Nama | Deskripsi |
| :- | :- |
| get_project_uids() | Mengembalikan daftar pengidentifikasi unik proyek-proyek. |
| get_project_infos() | Mengembalikan daftar objek info singkat proyek. |
| load_project(project_uid) | Memuat proyek dengan pengidentifikasi unik yang ditentukan. |
