## RecurringTaskParameters class

Mewakili sekumpulan parameter yang digunakan untuk membuat tugas berulang dalam sebuah proyek.

Tipe RecurringTaskParameters menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| RecurringTaskParameters() | Menginisialisasi sebuah instance baru dari kelas [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| duration | Mendapatkan atau mengatur durasi untuk satu kejadian tugas berulang. |
| ignore_resource_calendar | Mendapatkan atau mengatur nilai yang menunjukkan apakah menjadwalkan tugas berulang meskipun tidak terjadi ketika tidak ada sumber daya yang tersedia untuk mengerjakannya. |
| recurrence_pattern | Mendapatkan atau mengatur pola pengulangan tugas berulang. |
| task_name | Mendapatkan atau mengatur nama tugas berulang. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| set_calendar(project, calendar_name) | Atur kalender untuk tugas berulang. Kalender dipilih dari koleksi kalender proyek. |
