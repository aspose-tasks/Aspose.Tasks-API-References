## FontSettings class

Menentukan pengaturan font yang digunakan saat merender tampilan proyek.

Tipe FontSettings menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| FontSettings() | Menginisialisasi instance baru dari kelas FontSettings |
## Properti
| Nama | Deskripsi |
| :- | :- |
| default_font_name | Mendapatkan atau mengatur font default (atau cadangan) untuk rendering. |
| use_project_default_font | Mendapatkan atau mengatur nilai yang menunjukkan apakah font default harus digunakan untuk rendering. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| set_font_folders(font_folders, recursive) | Mengatur folder tempat Aspose.Tasks mencari font TrueType saat merender tampilan proyek. |
