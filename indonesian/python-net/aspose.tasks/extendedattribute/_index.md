## ExtendedAttribute class

Mewakili atribut tambahan.

Tipe ExtendedAttribute menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| attribute_definition | Mendapatkan definisi atribut. |
| field_id | Mendapatkan id dari sebuah field. |
| duration_value | Mendapatkan atau mengatur nilai untuk atribut dengan tipe 'Duration'. |
| numeric_value | Mendapatkan atau mengatur nilai untuk atribut dengan tipe numerik (Cost, Number). |
| date_value | Mendapatkan atau mengatur nilai untuk atribut dengan tipe tanggal (Date, Start, Finish). |
| flag_value | Mendapatkan atau mengatur nilai yang menunjukkan apakah flag telah diatur untuk atribut dengan tipe 'Flag'. |
| text_value | Mendapatkan atau mengatur nilai untuk atribut dengan tipe 'Text'. |
| value_guid | Mendapatkan guid dari nilai lookup. |
| value_read_only | Mendapatkan nilai yang menunjukkan apakah nilai dari instance [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) ini bersifat read-only. |
| is_error_value | Mendapatkan apakah perhitungan nilai extended attribute menghasilkan error. |
