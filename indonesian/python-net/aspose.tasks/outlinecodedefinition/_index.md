## OutlineCodeDefinition class

Mewakili definisi kode outline.

Tipe OutlineCodeDefinition menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| OutlineCodeDefinition() | Menginisialisasi instance baru dari kelas [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| guid | Mendapatkan atau mengatur Guid dari kode outline. |
| field_id | Mendapatkan atau mengatur nomor bidang dari kode outline. |
| field_name | Mendapatkan atau mengatur nama dari kode outline khusus. |
| alias | Mendapatkan atau mengatur alias dari kode outline khusus. |
| phonetic_alias | Mendapatkan atau mengatur pengucapan fonetik dari alias kode outline khusus. |
| values | Mendapatkan objek OutlineValueCollection.<br/>            Nilai-nilai tabel yang terkait dengan kode outline ini. |
| enterprise | Mendapatkan atau mengatur nilai yang menunjukkan apakah kode outline khusus merupakan kode outline khusus enterprise. |
| enterprise_outline_code_alias | Mendapatkan atau mengatur referensi ke bidang khusus lain yang definisi kode outline ini menjadi aliasnya. |
| resource_substitution_enabled | Mendapatkan atau mengatur nilai yang menunjukkan apakah kode outline khusus dapat digunakan<br/>            oleh Resource Substitution Wizard di Microsoft Project. |
| leaf_only | Mendapatkan atau mengatur nilai yang menunjukkan apakah nilai yang ditentukan dalam bidang kode outline ini harus berupa nilai daun. |
| all_levels_required | Mendapatkan atau mengatur nilai yang menunjukkan apakah kode baru harus memiliki semua level.<br/>            Tidak tersedia untuk Kode Enterprise. |
| only_table_values_allowed | Mendapatkan atau mengatur nilai yang menunjukkan apakah nilai yang ditentukan harus berasal dari tabel nilai. |
| masks | Mendapatkan objek OutlineMaskCollection.<br/>            Tabel entri yang mendefinisikan mask kode outline.<br/>            Instansi [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/) hanya-baca. |
| show_indent | Mendapatkan atau mengatur nilai yang menunjukkan apakah indentasi kode outline ini harus ditampilkan. |
