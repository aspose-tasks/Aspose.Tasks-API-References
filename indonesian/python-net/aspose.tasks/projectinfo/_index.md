## ProjectInfo class

Info singkat tentang proyek yang dipublikasikan tersedia di Project Online.

Tipe ProjectInfo menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ProjectInfo() | Menginisialisasi instance baru dari kelas [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| id | Mendapatkan pengidentifikasi unik dari proyek. |
| name | Mendapatkan nama proyek. |
| created_date | Mendapatkan tanggal dan waktu saat proyek dibuat. |
| is_checked_out | Mendapatkan nilai yang menunjukkan apakah proyek sedang di-check out. |
| last_published_date | Mendapatkan tanggal terbaru saat proyek dipublikasikan. |
| last_saved_date | Mendapatkan tanggal terbaru saat proyek disimpan. |
| description | Mendapatkan deskripsi proyek. |
