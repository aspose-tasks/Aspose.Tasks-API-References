## Value class

Mewakili nilai dalam daftar nilai.

Tipe Value menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Value() | Menginisialisasi instance baru dari kelas [Value](/tasks/python-net/aspose.tasks/value/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| id | Mendapatkan atau mengatur pengidentifikasi unik dari nilai di seluruh proyek. |
| value_guid | Mendapatkan GUID yang mengidentifikasi nilai ini di antara nilai lain dalam seluruh proyek. |
| val | Mendapatkan atau mengatur nilai aktual dalam representasi internal. Lebih baik menggunakan properti bertipe kuat yang tercantum di bawah. |
| string_value | Mendapatkan atau mengatur nilai aktual yang digunakan untuk merepresentasikan string Teks. |
| numeric_value | Mendapatkan atau mengatur nilai aktual yang digunakan untuk merepresentasikan angka atau nilai biaya. |
| duration | Mendapatkan atau mengatur nilai aktual yang digunakan untuk merepresentasikan Durasi. |
| date_time_value | Mendapatkan atau mengatur nilai aktual jika dapat direpresentasikan sebagai DateTime. Nilai default adalah nilai tanggal minimum. |
| description | Mendapatkan atau mengatur deskripsi dari sebuah nilai. |
| phonetic | Mendapatkan atau mengatur informasi fonetik tentang nama bidang khusus. |
