## AssignmentBaseline class

Mewakili Baseline dari penugasan sumber daya.

Tipe AssignmentBaseline menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| AssignmentBaseline() | Menginisialisasi sebuah instance baru dari kelas AssignmentBaseline |
## Properti
| Nama | Deskripsi |
| :- | :- |
| baseline_number | Mendapatkan atau mengatur nomor unik dari catatan data baseline. |
| pekerjaan | Mendapatkan atau mengatur pekerjaan yang ditugaskan ke sumber daya saat baseline disimpan. |
| cost | Mendapatkan atau mengatur biaya proyeksi sumber daya saat baseline disimpan. |
| bcws | Mendapatkan atau mengatur biaya anggaran pekerjaan yang dijadwalkan untuk sumber daya. |
| bcwp | Mendapatkan atau mengatur biaya anggaran pekerjaan yang dilakukan oleh sumber daya untuk proyek hingga saat ini. |
| timephased_data | Mendapatkan atau mengatur instance [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) untuk objek ini.<br/>Data berfase waktu yang terkait dengan baseline penugasan sumber daya. |
| mulai | Mendapatkan atau mengatur tanggal mulai terjadwal penugasan sumber daya saat baseline disimpan. |
| finish | Mendapatkan atau mengatur tanggal selesai terjadwal penugasan sumber daya saat baseline disimpan. |
