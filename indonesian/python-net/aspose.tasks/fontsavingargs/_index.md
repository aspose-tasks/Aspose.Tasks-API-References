## FontSavingArgs class

Kelas ini mewakili sekumpulan data yang terkait dengan penyimpanan file font eksternal yang<br/>              terjadi selama konversi ke format HTML.

Tipe FontSavingArgs menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| FontSavingArgs() | Menginisialisasi instance baru dari kelas FontSavingArgs |
## Properti
| Nama | Deskripsi |
| :- | :- |
| file_name | Mendapatkan atau mengatur nama file yang diharapkan yang melewati konverter ke kode metode khusus.<br/>             Dapat digunakan dalam kode khusus untuk memutuskan bagaimana memproses atau dimana menyimpan file tersebut. |
| keep_stream_open | Mendapatkan atau mengatur nilai yang menunjukkan apakah aliran akan tetap terbuka setelah penyimpanan sumber daya selesai. |
| stream | Mendapatkan atau mengatur konten biner dari file yang disimpan. |
| uri | Mendapatkan atau mengatur URI sumber daya. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| close_stream_if_required() | Tutup aliran jika KeepStreamOpen bernilai false, jika tidak flush aliran tersebut. |
