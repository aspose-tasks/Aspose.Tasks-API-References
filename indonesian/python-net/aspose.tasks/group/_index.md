## Group class

Mewakili definisi grup.<br/>            Objek Group merupakan anggota koleksi ResourceGroups atau koleksi TaskGroups.

Tipe Group menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Group() | Menginisialisasi instance baru dari kelas [Group](/tasks/python-net/aspose.tasks/group/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| name | Mendapatkan atau mengatur nama objek Group. |
| uid | Mendapatkan pengidentifikasi unik dari sebuah grup. |
| show_summary | Mendapatkan atau mengatur nilai yang menunjukkan apakah baris ringkasan ditampilkan untuk grup. |
| maintain_hierarchy | Mendapatkan atau mengatur nilai yang menunjukkan apakah semua level tugas ringkasan ditampilkan untuk subtugas dalam grup. |
| show_in_menu | Mendapatkan atau mengatur nilai yang menunjukkan apakah Project menampilkan nama grup dalam daftar drop-down Group di Ribbon. |
| group_assignments | Mendapatkan atau mengatur nilai yang menunjukkan apakah penugasan harus dikelompokkan alih-alih tugas. |
| group_criteria | Mendapatkan atau mengatur koleksi GroupCriteria yang mewakili bidang-bidang dalam definisi grup. |
