## PrimaveraProjectProperties class

Mewakili properti khusus Primavera untuk proyek yang dibaca dari file Primavera (XER atau P6XML).

Tipe PrimaveraProjectProperties menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| relationship_lag_calendar | Mendapatkan opsi yang menentukan kalender mana yang akan digunakan untuk menjadwalkan Relationship Lag dalam proyek Primavera. |
| use_expected_finish_dates | Mendapatkan flag yang menentukan apakah tanggal selesai aktivitas harus dijadwalkan sebagai tanggal selesai yang diharapkan. |
| make_open_ended_activities_critical | Mendapatkan flag yang menentukan apakah aktivitas harus ditandai sebagai kritis saat menjadwalkan proyek. |
| ignore_other_project_relationships | Mendapatkan flag yang menentukan apakah harus mengabaikan hubungan aktivitas antar proyek. |
| current_baseline_project_id | Mendapatkan Id dari proyek baseline saat ini.<br/>            Berlaku untuk proyek yang dibaca dari file XML Primavera yang berisi baseline yang diekspor. |
| baseline_projects | Mendapatkan array proyek baseline dari proyek saat ini.<br/>            Berlaku untuk proyek yang dibaca dari file XML Primavera yang berisi baseline yang diekspor. |
| critical_activities_defining_method | Mendapatkan metode untuk menentukan aktivitas kritis: pendekatan Jalur Terpanjang atau Total Float. |
| critical_total_float_limit | Mendapatkan nilai ambang yang digunakan untuk menentukan aktivitas kritis jika metode TotalFloat digunakan. |
| short_name | Mendapatkan nama singkat proyek (ID Proyek). |
