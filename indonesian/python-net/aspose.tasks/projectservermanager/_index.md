## ProjectServerManager class

Kelas yang menyediakan metode untuk membaca dan melakukan operasi pada proyek dalam akun Project Online yang ditentukan atau<br/>            dalam instance Project Server yang di‑lokasi yang ditentukan (versi Project Server 2016 dan 2019 didukung).

Tipe ProjectServerManager menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ProjectServerManager(credentials) | Menginisialisasi instance baru dari kelas [ProjectServerManager](/tasks/python-net/aspose.tasks/projectservermanager/). |
## Methods
| Nama | Deskripsi |
| :- | :- |
| update_project(project) | Memperbarui proyek yang ada di instance Project Server\\Project Online menggunakan opsi penyimpanan default. Proyek yang ada akan ditimpa. |
| update_project(project, save_options) | Memperbarui proyek yang ada di instance Project Server\\Project Online menggunakan opsi penyimpanan yang ditentukan. Proyek yang ada akan ditimpa. |
| create_new_project(project) | Membuat proyek baru di instance Project Server\\Project Online menggunakan opsi penyimpanan default. |
