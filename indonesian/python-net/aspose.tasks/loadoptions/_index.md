## LoadOptions class

Memungkinkan untuk menentukan parameter pemuatan tambahan saat memuat proyek dari file atau aliran.

Tipe LoadOptions menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| LoadOptions() | Menginisialisasi sebuah instance baru dari kelas [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| password | Mendapatkan atau mengatur kata sandi perlindungan. |
| primavera_read_options | Mendapatkan atau mengatur instance tertentu dari kelas [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) yang dapat digunakan untuk menyesuaikan perilaku pemuatan format Primavera (Primavera P6 XER atau Primavera P6 Xml). |
| encoding | Mendapatkan atau mengatur encoding yang digunakan untuk membaca proyek dari format HTML, MPX, XER, dan Primavera XML.<br/>            Encoding default adalah UTF8. |
