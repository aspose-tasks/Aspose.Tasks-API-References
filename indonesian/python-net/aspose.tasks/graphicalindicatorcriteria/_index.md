## GraphicalIndicatorCriteria class

Mewakili satu kriteria indikator grafis yang terkait dengan atribut ekstended.

Tipe GraphicalIndicatorCriteria menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Menginisialisasi sebuah instance baru dari kelas GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Menginisialisasi sebuah instance baru dari kelas GraphicalIndicatorCriteria |
## Properti
| Nama | Deskripsi |
| :- | :- |
| test | Mendapatkan tipe perbandingan yang dibuat antara nilai atribut yang diperluas dan Values yang berfungsi sebagai kriteria untuk penerapan indikator grafis.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Mendapatkan nilai yang digunakan untuk menguji nilai atribut yang diperluas. |
| value2 | Mendapatkan nilai kedua yang digunakan untuk menguji nilai atribut yang diperluas dalam kasus tipe perbandingan 'IsWithin' dan 'IsNotWithin'. |
| image_index | Mendapatkan indeks gambar yang akan ditampilkan ketika bidang memenuhi kriteria. |
| row_type | Mendapatkan nilai dari enum [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) yang menunjukkan untuk baris mana indikator diterapkan. |
