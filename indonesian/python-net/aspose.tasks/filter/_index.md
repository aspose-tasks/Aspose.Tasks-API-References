## Filter class

Mewakili filter dalam Project.

Tipe Filter menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Filter() | Menginisialisasi instance baru dari kelas Filter |
## Properti
| Nama | Deskripsi |
| :- | :- |
| filter_type | Mendapatkan tipe filter. |
| name | Mendapatkan atau mengatur nama objek Filter. |
| show_in_menu | Mendapatkan atau mengatur nilai yang menunjukkan apakah proyek menampilkan nama filter dalam daftar drop-down Filter pada tab Tampilan di Ribbon. |
| show_related_summary_rows | Mendapatkan atau mengatur nilai yang menunjukkan apakah baris ringkasan terkait ditampilkan untuk filter. |
| index | Mendapatkan indeks objek [Filter](/tasks/python-net/aspose.tasks/filter/) dalam objek yang berisi Filters. |
| uid | Mendapatkan pengidentifikasi unik dari sebuah filter. |
| criteria | Mendapatkan atau mengatur kriteria yang harus dipenuhi oleh tugas atau sumber daya untuk ditampilkan dalam tampilan MSP. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| compare_to(other) | Membandingkan instance ini dengan instance yang ditentukan dari kelas [Filter](/tasks/python-net/aspose.tasks/filter/) dan mengembalikan indikasi urutan relatif mereka. |
| equals(other) | Mengembalikan nilai yang menunjukkan apakah instance ini sama dengan objek AssignmentBaseline yang ditentukan. |
