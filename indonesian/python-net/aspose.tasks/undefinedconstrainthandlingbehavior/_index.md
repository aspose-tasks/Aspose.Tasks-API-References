## UndefinedConstraintHandlingBehavior enumeration

Menentukan perilaku yang digunakan untuk menangani tugas dengan kendala yang tidak terdefinisi.

## Members

| :- | :- |
| NONE | Perilaku default untuk memuat dari format XER.<br/>            Tidak ada tindakan yang diambil. Tipe batasan tugas diatur ke 'ConstraintType.Undefined'. |
| SUBSTITUTE_WITH_START_NO_EARLIER_THAN | Batasan dengan tipe 'ConstraintType.StartNoEarlierThan' dan tanggal = Start ditambahkan untuk tugas dengan batasan 'Undefined'. |
