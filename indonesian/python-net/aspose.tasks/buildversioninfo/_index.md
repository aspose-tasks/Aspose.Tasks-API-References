## BuildVersionInfo class

Berisi versi build dan informasi produk.

Tipe BuildVersionInfo menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| ASSEMBLY_VERSION | Versi assembly. |
| ASSEMBLY_INFORMATIONAL_VERSION | Nomor versi informasional dari assembly. |
| FILE_VERSION | Versi berkas. |
| PRODUK | Nama produk. |
