## Table class

Mewakili tabel dalam Project

Tipe Table menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Table() | Menginisialisasi sebuah instance baru dari kelas [Table](/tasks/python-net/aspose.tasks/table/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| name | Mendapatkan atau mengatur nama objek Table. |
| show_in_menu | Mendapatkan atau mengatur nilai yang menunjukkan apakah proyek menampilkan nama tabel dalam daftar drop-down Tables pada tab View di Ribbon. |
| table_fields | Mendapatkan koleksi TableFields yang mewakili bidang-bidang dalam tabel. |
| table_type | Mendapatkan atau mengatur tipe tabel untuk tabel yang ditentukan. |
| uid | Mendapatkan pengidentifikasi unik dari sebuah tabel. |
| row_height | Mendapatkan atau mengatur tinggi baris dalam tabel, dimana tinggi baris adalah jumlah baris teks. |
| date_format | Mendapatkan atau mengatur format tanggal tabel. |
| adjust_header_row_height | Mendapatkan atau mengatur nilai yang menunjukkan apakah tinggi baris header tabel dapat disesuaikan. |
| show_add_new_column | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan menampilkan antarmuka 'Add New Column'. |
| lock_first_column | Mendapatkan atau mengatur nilai yang menunjukkan apakah kolom pertama tabel terkunci atau dapat diedit. |
