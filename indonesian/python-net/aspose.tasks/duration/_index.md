## Duration class

Mewakili durasi dalam sebuah proyek.

Tipe Duration menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Duration() | Menginisialisasi sebuah instance baru dari kelas Duration |
## Properti
| Nama | Deskripsi |
| :- | :- |
| time_span | Mendapatkan instance [time_span](/tasks/python-net/aspose.tasks/duration/) dari objek Duration ini. |
| time_unit | Mendapatkan tipe satuan waktu untuk objek ini. |
| is_estimated | Mendapatkan nilai yang menunjukkan apakah satuan waktu diperkirakan. |
| is_elapsed | Mendapatkan nilai yang menunjukkan apakah satuan waktu telah berlalu. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| add(d) | Menambahkan durasi yang ditentukan ke durasi ini. |
| add(val) | Menambahkan nilai double yang ditentukan ke durasi ini. |
| subtract(d) | Mengurangi durasi yang ditentukan dari instance durasi ini. |
| subtract(val) | Mengurangi nilai double yang ditentukan dari instance durasi ini. |
| parse(p, value) | Mengonversi string yang ditentukan menjadi instance struktur [Duration](/tasks/python-net/aspose.tasks/duration/). |
| parse_time_span(value) | Menganalisis string durasi dalam format "PT--H--M--S--". |
| to_double() | Mengonversi objek Duration menjadi nilai float. |
| convert(time_unit_type) | Mengonversi objek Duration ke durasi lain dengan satuan waktu yang ditentukan. |
| equals(other) | Mengembalikan nilai yang menunjukkan apakah instance ini sama dengan objek yang ditentukan. |
