## OleObject class

Mewakili objek OLE yang dapat dimasukkan ke dalam Tampilan Gantt Chart dari file MPP.

Tipe OleObject menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| OleObject() | Menginisialisasi instance baru dari kelas [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| name | Mendapatkan atau mengatur nama instance objek OLE. |
| application_name | Mendapatkan atau mengatur nama aplikasi untuk membuka objek tersemat. |
| file_format | Mendapatkan atau mengatur format file objek tersemat. |
| content | Mendapatkan atau mengatur data file yang tersemat; null jika tidak ada data yang tersemat. |
| label | Mendapatkan atau mengatur label objek yang disisipkan. |
| full_path | Mendapatkan atau mengatur jalur lengkap objek yang disisipkan. |
| temporary_file | Mendapatkan atau mengatur jalur ke file sementara objek yang disisipkan. |
| display_as_icon | Mendapatkan atau mengatur flag yang menunjukkan bahwa OLE object harus ditampilkan sebagai ikon atau sebagai gambar regulernya. |
| ditautkan | Mendapatkan nilai yang menunjukkan apakah file proyek hanya berisi tautan ke data sebenarnya yang disimpan di sumber tautan. |
| view | Mendapatkan atau mengatur instance dari kelas [view](/tasks/python-net/aspose.tasks/oleobject/) yang dimiliki oleh objek yang disisipkan. |
| id | Mendapatkan atau mengatur ID objek. |
