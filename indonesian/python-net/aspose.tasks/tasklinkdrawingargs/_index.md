## TaskLinkDrawingArgs class

Menyediakan argumen untuk callback yang dipanggil ketika tautan tugas dirender.

Tipe TaskLinkDrawingArgs menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| link | Mendapatkan tautan tugas yang dirender. |
| color | Mendapatkan atau mengatur warna yang digunakan untuk merender tautan tugas. Dapat digunakan untuk menyesuaikan warna tautan tugas. |
