## RateCollection class

Mewakili koleksi yang berisi objek [Rate](/tasks/python-net/aspose.tasks/rate/).

Tipe RateCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| count | Mendapatkan jumlah elemen yang terdapat dalam RateCollection. |
| is_read_only | Mendapatkan nilai yang menunjukkan apakah koleksi ini hanya-baca. |
| parent_resource | Mendapatkan objek [Resource](/tasks/python-net/aspose.tasks/resource/) induk untuk koleksi ini. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| add(rates_from) | Menambahkan sebuah instance [Rate](/tasks/python-net/aspose.tasks/rate/) baru ke koleksi ini. |
| add(rates_from, type) | Menambahkan sebuah instance [Rate](/tasks/python-net/aspose.tasks/rate/) baru ke koleksi ini. |
| to_list() | Mengonversi objek [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) menjadi daftar objek [Rate](/tasks/python-net/aspose.tasks/rate/). |
| to_list(type) | Mengonversi objek [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) menjadi daftar objek [Rate](/tasks/python-net/aspose.tasks/rate/) yang difilter berdasarkan tipe [RateType](/tasks/python-net/aspose.tasks/ratetype/) yang ditentukan. |
| remove(item) | Menghapus instance Rate dari koleksi ini. |
