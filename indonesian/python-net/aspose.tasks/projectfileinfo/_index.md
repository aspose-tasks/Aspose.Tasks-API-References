## ProjectFileInfo class

Instance kelas berisi informasi tentang format file proyek dan versi Microsoft Project dimana<br/>            file tersebut dibuat.

Tipe ProjectFileInfo menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| can_read | Mendapatkan nilai yang menunjukkan apakah definisi dapat diproses oleh Aspose.Tasks pada file proyek. |
| is_password_protected | Mendapatkan nilai yang menunjukkan apakah proyek dilindungi kata sandi. |
| project_file_format | Mendapatkan format file proyek. |
| project_application_info | Mendapatkan info aplikasi file proyek. |
## Methods

| :- | :- |
| equals(other) | Mengembalikan nilai yang menunjukkan apakah instance ini sama dengan objek yang ditentukan. |
