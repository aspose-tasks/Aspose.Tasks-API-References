## PrimaveraCalendarProperties class

Mewakili properti khusus Primavera untuk kalender yang dibaca dari file Primavera (XER atau P6XML).<br/>            Dapat digunakan untuk melakukan konversi satuan waktu khusus kalender.

Tipe PrimaveraCalendarProperties menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| hours_per_day | Mendapatkan jumlah jam per hari dari pengaturan 'Time Periods' pada kalender. |
| hours_per_week | Mendapatkan jumlah jam per minggu dari pengaturan 'Time Periods' pada kalender. |
| hours_per_month | Mendapatkan jumlah jam per bulan dari pengaturan 'Time Periods' pada kalender. |
| hours_per_year | Mendapatkan jumlah jam per bulan dari pengaturan 'Time Periods' pada kalender. |
