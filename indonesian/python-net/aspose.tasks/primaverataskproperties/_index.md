## PrimaveraTaskProperties class

Mewakili properti khusus Primavera untuk tugas yang dibaca dari file Primavera (XER atau P6XML).

Tipe PrimaveraTaskProperties menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| sequence_number | Mendapatkan atau mengatur nomor urut dari item WBS (tugas ringkasan). Ini digunakan untuk mengurutkan tugas ringkasan di Primavera. |
| activity_id | Mendapatkan bidang activity id - pengidentifikasi unik tugas yang digunakan oleh Primavera. |
| remaining_early_finish | Mendapatkan tanggal selesai awal yang tersisa - tanggal ketika pekerjaan yang tersisa untuk aktivitas dijadwalkan selesai. |
| remaining_early_start | Mendapatkan tanggal mulai awal yang tersisa - tanggal ketika pekerjaan yang tersisa untuk aktivitas dijadwalkan mulai. |
| remaining_late_start | Mendapatkan tanggal mulai akhir yang tersisa. |
| remaining_late_finish | Mendapatkan tanggal selesai akhir yang tersisa. |
| raw_duration_type | Mendapatkan representasi teks mentah (seperti dalam file sumber) dari bidang 'Duration Type' aktivitas. |
| duration_type | Mendapatkan nilai dari bidang 'Duration Type' aktivitas. |
| raw_activity_type | Mendapatkan representasi teks mentah (seperti dalam file sumber) dari bidang 'Activity Type' aktivitas. |
| activity_type | Mendapatkan nilai dari bidang 'Activity Type'. |
| percent_complete_type | Mendapatkan nilai dari bidang '% Complete Type' aktivitas. |
| raw_complete_percent_type | Mendapatkan representasi teks mentah (seperti dalam file sumber) dari bidang '% Complete Type' aktivitas. |
| raw_status | Mendapatkan representasi teks mentah (seperti dalam file sumber) dari bidang 'Status' aktivitas. |
| physical_percent_complete | Mendapatkan nilai Physical Percent Complete. |
| duration_percent_complete | Mendapatkan nilai duration percent complete. |
| units_percent_complete | Mendapatkan nilai units percent complete. |
| actual_labor_units | Mendapatkan nilai actual labor units. |
| actual_non_labor_units | Mendapatkan nilai actual non labor units. |
| remaining_labor_units | Mendapatkan nilai remaining labor units. |
| remaining_non_labor_units | Mendapatkan nilai remaining non labor units. |
| actual_labor_cost | Mendapatkan nilai actual labor cost. |
| budgeted_labor_cost | Mendapatkan nilai budgeted (or planned) labor cost. |
| actual_nonlabor_cost | Mendapatkan nilai actual non labor cost. |
| budgeted_nonlabor_cost | Mendapatkan nilai budgeted (or planned) non labor cost. |
| actual_material_cost | Mendapatkan nilai biaya material aktual. |
| budgeted_material_cost | Mendapatkan nilai biaya material yang dianggarkan (atau direncanakan). |
| actual_expense_cost | Mendapatkan nilai biaya pengeluaran aktual. |
| remaining_expense_cost | Mendapatkan nilai biaya pengeluaran yang tersisa. |
| budgeted_expense_cost | Mendapatkan nilai biaya pengeluaran yang dianggarkan (atau direncanakan). |
| actual_total_cost | Mendapatkan total nilai biaya aktual. |
| budgeted_total_cost | Mendapatkan total nilai biaya yang dianggarkan (atau direncanakan). |
| primary_constraint_type | Mendapatkan tipe kendala utama. |
| primary_constraint_date | Mendapatkan tanggal kendala utama. |
| secondary_constraint_type | Mendapatkan tipe kendala sekunder. |
| secondary_constraint_date | Mendapatkan tanggal kendala sekunder. |
| planned_duration | Mendapatkan durasi asli atau yang direncanakan -- total waktu kerja dari tanggal mulai yang direncanakan tugas hingga tanggal selesai yang direncanakan.. |
