### BestPracticeAnalyzer {#BestPracticeAnalyzer}
```
public static final int BestPracticeAnalyzer
```


Zeigt Aufgaben ohne tatsächliche Arbeit, nicht zugewiesene Aufgaben, Aufgaben mit einer Dauer von weniger als 8 Stunden und Zusammenfassungen, die den Ressourcen zugewiesen sind.

### Burndown {#Burndown}
```
public static final int Burndown
```


Enthält Arbeits‑Burndown‑ und Aufgaben‑Burndown‑Diagramme. Das Arbeits‑Burndown‑Diagramm zeigt, wie viel Arbeit Personen abgeschlossen haben, wie viel geplant ist, bis zum Projektenddatum abgeschlossen zu werden, und die Soll‑Schätzung, wie viel Arbeit zu diesem Zeitpunkt im Projekt abgeschlossen sein würde. Das Aufgaben‑Burndown‑Diagramm zeigt die Anzahl der abgeschlossenen Aufgaben, die verbleibende Anzahl und die Soll‑Schätzung, wie viele zu diesem Zeitpunkt im Projekt abgeschlossen sein würden.
