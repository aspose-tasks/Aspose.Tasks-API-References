Gibt den Status einer Aufgabe an.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Complete](#Complete) | Die Aufgabe ist zu 100 Prozent abgeschlossen. |
| [Future](#Future) | 'Future'-Aufgabenstatus wird gesetzt, wenn das Startdatum der Aufgabe größer als das Stichtag-Datum ist. |
| [Late](#Late) | Die Aufgabe ist verspätet, wenn der zeitphasierte kumulative Prozentsatz der Fertigstellung bis Mitternacht am Tag vor dem Stichtag nicht erreicht wird. |
| [OnSchedule](#OnSchedule) | Die Aufgabe ist im Zeitplan, wenn der zeitphasierte kumulative Prozentsatz der Fertigstellung mindestens bis zum Tag vor dem Stichtag verteilt ist. |
| [Undefined](#Undefined) | Undefinierter Aufgabenstatus. |
