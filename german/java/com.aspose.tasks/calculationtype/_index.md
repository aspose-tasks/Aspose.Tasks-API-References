Gibt den Typ einer Berechnung des Werts eines benutzerdefinierten Attributs an.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Formula](#Formula) | Bedeutet, dass der Wert des erweiterten Attributs mithilfe der in `ExtendedAttributeDefinition.Formula` definierten Formel berechnet wird ([ExtendedAttributeDefinition.getFormula()](../../com.aspose.tasks/extendedattributedefinition\#getFormula--)/[ExtendedAttributeDefinition.setFormula(String)](../../com.aspose.tasks/extendedattributedefinition\#setFormula-String-)). |
| [Lookup](#Lookup) | Bedeutet, dass der Wert des erweiterten Attributs auf Werte aus einer Nachschlagetabelle beschränkt ist. |
| [None](#None) | Bedeutet, dass das erweiterte Attribut keine Nachschlagetabelle oder Formel hat und den vom Benutzer festgelegten Wert einfach speichert. |
