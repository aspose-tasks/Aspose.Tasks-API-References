Stellt Primavera-spezifische Eigenschaften für einen Kalender dar, der aus Primavera-Dateien (XER oder P6XML) gelesen wurde. Kann verwendet werden, um kalender-spezifische Zeiteinheitenumwandlungen durchzuführen.
