Gibt die möglichen Optionen an, die beim Rendern der Legende einer Ansicht verwendet werden.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [AfterLastPage](#AfterLastPage) | Die Legende wird auf einer separaten Seite nach der letzten Seite der Projektseiten gerendert. |
| [DefinedInView](#DefinedInView) | Die Legende wird gemäß der Eigenschaft View.PageInfo.Legend.LegendOn der gerenderten Ansicht gerendert. |
| [NoLegend](#NoLegend) | Es wird keine Legende gerendert. |
| [OnEveryPage](#OnEveryPage) | Die Legende wird auf jeder Seite gerendert. |
