```
public class GlobalizationSettings
```

Stellt die Globalisierungseinstellungen des Projekts dar.

Die empfohlene Vorgehensweise ist, kulturunabhängige Literale oder Formate im gesamten Projekt zu verwenden. Sollte ein Projekt jedoch kulturspezifische Literale verwenden, kann diese Klasse verwendet werden, um der Formel‑Berechnungs‑Engine beim Parsen dieser Literale zu helfen.
