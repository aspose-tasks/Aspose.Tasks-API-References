### getParentStyle() {#getParentStyle--}
```
public final GanttBarStyle getParentStyle()
```


Ermittelt den übergeordneten (oder gemeinsamen) Stil für benutzerdefinierten aufgabenbezogenen Stil.

--------------------

Eine Aufgabe kann mehrere benutzerdefinierte Stile mit unterschiedlichen übergeordneten Stilen haben. Zum Beispiel eine Aufgabe mit einem benutzerdefinierten Stil, dessen übergeordneter Stil "Critical" ist, und einem anderen Stil mit dem übergeordneten Stil "Normal". Kurz gesagt, wenn die Aufgabe kritisch ist, wird der erste Stil angewendet. Wenn die Aufgabe nicht mehr kritisch ist, wird der zweite Stil angewendet (diese Logik wird von Microsoft Project Professional übernommen).

**Returns:**
[GanttBarStyle](../../com.aspose.tasks/ganttbarstyle) - parent (or common) style for custom task-specific style.
