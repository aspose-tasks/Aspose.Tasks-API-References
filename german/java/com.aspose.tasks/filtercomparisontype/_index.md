Der Typ des Vergleichs zwischen FieldName und Value, der als Auswahlkriterium für einen Filter oder grafischen Indikator dient.

| [DoesNotEqual](#DoesNotEqual) | Der Wert von Field ist nicht gleich Value. |
| [Equals](#Equals) | Der Wert von Field ist gleich Value. |
| [IsAnyValue](#IsAnyValue) | 'Ist irgendein Wert' Bedingung. |
| [IsGreaterThan](#IsGreaterThan) | Der Wert von Field ist größer als Value. |
| [IsGreaterThanOrEqualTo](#IsGreaterThanOrEqualTo) | Der Wert von Field ist größer als oder gleich Value. |
| [IsLessThan](#IsLessThan) | Der Wert von Field ist kleiner als Value. |
| [IsLessThanOrEqualTo](#IsLessThanOrEqualTo) | Der Wert von Field ist kleiner als oder gleich Value. |
| [IsNotWithin](#IsNotWithin) | Der Wert von Field ist nicht innerhalb Value. |
