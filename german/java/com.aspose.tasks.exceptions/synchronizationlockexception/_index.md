Die Ausnahme, die ausgelöst wird, wenn eine Methode verlangt, dass der Aufrufer das Sperre‑Lock eines bestimmten Monitors besitzt, und die Methode von einem Aufrufer aufgerufen wird, der dieses Lock nicht besitzt.
