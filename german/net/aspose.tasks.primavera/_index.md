Enthält Klassen, die zum Arbeiten mit Primavera-spezifischen Formaten (XER, Primavera XML) erforderlich sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Stellt kurze Informationen über ein aus dem Primavera-Format geladenes Projekt dar. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [PrimaveraActivityType](./primaveraactivitytype/) | Gibt den Typ einer Primavera-Aktivität an. |
| [PrimaveraConstraintType](./primaveraconstrainttype/) | Gibt einen Typ der Aktivitätsbeschränkung an. |
| [PrimaveraDurationType](./primaveradurationtype/) | Gibt den Dauertyp einer Primavera-Aktivität an. |
| [PrimaveraPercentCompleteType](./primaverapercentcompletetype/) | Gibt den Wert des Feldes „% Complete Type“ für Primavera-Aktivitäten an. |
| [PrimaveraRelationshipLagCalendar](./primaverarelationshiplagcalendar/) | Gibt an, welcher Kalender für die Terminierung von Beziehungsverzögerungen in Primavera-Projekten verwendet wird. |
