## HorizontalStringAlignment enumeration

Gibt die Ausrichtung einer Textzeichenkette relativ zu ihrem Layout-Rechteck an.

```csharp
public enum HorizontalStringAlignment
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Near | `0` | Gibt an, dass der Text nahe am Layout ausgerichtet wird. In einem links‑nach‑rechts Layout ist die nahe Position links. In einem rechts‑nach‑links Layout ist die nahe Position rechts. |
| Center | `1` | Gibt an, dass der Text in der Mitte des Layout‑Rechtecks ausgerichtet ist. |
| Far | `2` | Gibt an, dass der Text weit von der Ursprungposition des Layout‑Rechtecks ausgerichtet wird. In einem links‑nach‑rechts Layout ist die ferne Position rechts. In einem rechts‑nach‑links Layout ist die ferne Position links. |
