## LegendDrawingOptions enumeration

Gibt die möglichen Optionen an, die beim Rendern der Legende einer Ansicht verwendet werden.

```csharp
public enum LegendDrawingOptions
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| NoLegend | `0` | Keine Legende wird gerendert. |
| AfterLastPage | `1` | Die Legende wird auf einer separaten Seite nach der letzten Seite der Projektseiten gerendert. |
| OnEveryPage | `2` | Die Legende wird auf jeder Seite gerendert. |
| DefinedInView | `3` | Die Legende wird gemäß der Eigenschaft View.PageInfo.Legend.LegendOn der gerenderten Ansicht gerendert. |
