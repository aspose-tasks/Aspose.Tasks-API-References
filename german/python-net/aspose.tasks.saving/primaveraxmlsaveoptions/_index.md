## PrimaveraXmlSaveOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Speichern des Projekts im Primavera-XML-Format.

Der Typ PrimaveraXmlSaveOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PrimaveraXmlSaveOptions() | Initialisiert eine neue Instanz der [PrimaveraXmlSaveOptions](/tasks/python-net/aspose.tasks.saving/primaveraxmlsaveoptions/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| save_format | Ruft das Format ab oder legt es fest, in dem das Dokument gespeichert wird, wenn dieses Speicheroptionen-Objekt verwendet wird. |
| save_root_task | Liest oder setzt einen Wert, der angibt, ob eine Stammaufgabe gespeichert werden soll oder nicht. |
| skip_summary_assignments | Liest oder setzt einen Wert, der angibt, ob Zuweisungen von Ressourcen zu Summenaufgaben beim Export übersprungen werden sollen. |
