## Spreadsheet2003SaveOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Rendern von Projektseiten zu Spreadsheet2003.

Der Typ Spreadsheet2003SaveOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Spreadsheet2003SaveOptions() | Initialisiert eine neue Instanz der Klasse [Spreadsheet2003SaveOptions](/tasks/python-net/aspose.tasks.saving/spreadsheet2003saveoptions/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| save_format | Ruft das Format ab oder legt es fest, in dem das Dokument gespeichert wird, wenn dieses Speicheroptionen-Objekt verwendet wird. |
| resource_view | Ruft eine Liste der Ressourcenansichtsspalten ab oder legt sie fest, die gerendert werden sollen ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Ruft eine Liste der Zuweisungsansichtsspalten ab oder legt sie fest, die gerendert werden sollen ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| view | Ruft eine Liste der Ansichtsspalten ab oder legt sie fest, die gespeichert werden sollen ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)).<br/>            Wenn nicht festgelegt, werden Standardspalten gespeichert. |
