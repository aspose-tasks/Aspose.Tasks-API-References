## SimpleSaveOptions class

Dies ist eine abstrakte Basisklasse, die dem Benutzer ermöglicht, grundlegende Optionen beim Speichern eines Projekts in ein bestimmtes Format anzugeben.

Der Typ SimpleSaveOptions stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| save_format | Ruft das Format ab oder legt es fest, in dem das Dokument gespeichert wird, wenn dieses Speicheroptionen-Objekt verwendet wird. |
