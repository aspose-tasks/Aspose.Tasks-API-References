## TiffCompression enumeration

Gibt an, welcher Kompressionstyp beim Speichern von Seiten im TIFF-Format angewendet werden soll.

## Members
| Membername | Beschreibung |
| :- | :- |
| NONE | Gibt an, dass keine Kompression verwendet wird. |
| RLE | Gibt das RLE-Kompressionsverfahren an. |
| CCITT3 | Gibt das CCITT3-Kompressionsverfahren an. |
| CCITT4 | Gibt das CCITT4-Kompressionsverfahren an. |
| LZW | Gibt das LZW-Kompressionsverfahren an. |
