## PageSavingArgs class

Diese Klasse stellt einen Datensatz dar, der sich auf das Speichern einer Dokumentenseite in einen Stream bezieht.

Der PageSavingArgs-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| page_number | Ruft die zu schreibende Seitenzahl ab. |
| keep_stream_open | Ruft einen Wert ab oder legt ihn fest, der angibt, ob die Rendering‑Routine den [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) nach dem Schreiben einer Seite geöffnet lassen soll. |
| stream | Ruft einen Stream ab oder legt ihn fest, der zum Schreiben einer Seite verwendet wird. |
