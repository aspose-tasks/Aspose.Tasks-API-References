## CsvOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Speichern des Projekts als CSV.

Der CsvOptions-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| CsvOptions() | Initialisiert eine neue Instanz der [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) Klasse, die verwendet werden kann, um das Projekt im CSV-Format zu speichern. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| save_format | Ruft das Format ab oder legt es fest, in dem das Dokument gespeichert wird, wenn dieses Speicheroptionen-Objekt verwendet wird. |
| data_category | Ruft eine Datenkategorie ab oder legt sie fest, die gespeichert werden soll. |
| encoding | Liest oder setzt eine Kodierung, mit der CSV gespeichert wird. |
| include_headers | Liest oder setzt einen Wert, der angibt, ob Header einbezogen werden sollen oder nicht (Standardwert ist TRUE). |
| text_delimiter | Liest oder setzt ein Texttrennzeichen. |
| view | Liest oder setzt eine Liste der Ansichtsspalten ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) zum Speichern im XLSX-Format.<br/>            Wenn nicht gesetzt, werden Standardspalten gespeichert. |
