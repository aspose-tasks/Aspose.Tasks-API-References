## PrimaveraSaveOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Speichern des Projekts im Primavera XER-Format.

Der Typ PrimaveraSaveOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PrimaveraSaveOptions() | Initialisiert eine neue Instanz der [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| save_format | Ruft das Format ab oder legt es fest, in dem das Dokument gespeichert wird, wenn dieses Speicheroptionen-Objekt verwendet wird. |
| activity_id_increment | Liest oder setzt das Inkrement, das bei der Neunummerierung von Aktivitäts-IDs verwendet wird. |
| activity_id_prefix | Liest oder setzt das Präfix, das bei der Neunummerierung von Aktivitäts-IDs verwendet wird. |
| activity_id_suffix | Liest oder setzt das Suffix, das bei der Neunummerierung von Aktivitäts-IDs verwendet wird. |
| renumber_activity_ids | Liest oder setzt einen Wert, der angibt, ob die Aktivitäts-IDs neu nummeriert werden sollen. |
| skip_summary_assignments | Liest oder setzt einen Wert, der angibt, ob Zuweisungen von Ressourcen zu Summenaufgaben beim Export übersprungen werden sollen. |
