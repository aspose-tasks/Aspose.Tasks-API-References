## XlsxOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Rendern von Projektseiten zu XLSX.

Der Typ XxlsxOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| XlsxOptions() | Initialisiert eine neue Instanz der [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) Klasse, die verwendet werden kann, um ein Projekt im XLSX-Format zu speichern. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| save_format | Ruft das Format ab oder legt es fest, in dem das Dokument gespeichert wird, wenn dieses Speicheroptionen-Objekt verwendet wird. |
| resource_view | Ruft eine Liste der Ressourcenansichtsspalten ab oder legt sie fest, die gerendert werden sollen ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Ruft eine Liste der Zuweisungsansichtsspalten ab oder legt sie fest, die gerendert werden sollen ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| encoding | Liest oder setzt die Kodierung der resultierenden XLSX-Datei. Der Standardwert ist . |
| view | Liest oder setzt eine Liste der Ansichtsspalten ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) zum Speichern im XLSX-Format.<br/>            Wenn nicht gesetzt, werden Standardspalten gespeichert. |
