## IPageSavingCallback class

Stellt einen Callback dar, der aufgerufen wird, wenn jede Seite in einem mehrseitigen Dokument in einen separaten Stream gespeichert wird.

Der Typ IPageSavingCallback stellt die folgenden Mitglieder bereit:
## Methoden
| Name | Beschreibung |
| :- | :- |
| page_saving(args) | Die Methode, die aufgerufen wird, wenn eine Seite in einen Stream gespeichert wird. |
| on_finish() | Methode, die aufgerufen wird, wenn alle Seiten geschrieben sind. |
