## SaveTemplateOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Speichern eines Projekts als Vorlage.

Der Typ SaveTemplateOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| SaveTemplateOptions() | Initialisiert eine neue Instanz der Klasse SaveTemplateOptions |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| remove_actual_values | Ruft einen Wert ab oder legt ihn fest, der angibt, ob alle tatsächlichen Werte aus einer Projektschablone entfernt werden sollen. |
| remove_baseline_values | Ruft einen Wert ab oder legt ihn fest, der angibt, ob alle Basislinienwerte aus einer Projektschablone entfernt werden sollen. |
| remove_fixed_costs | Ruft einen Wert ab oder legt ihn fest, der angibt, ob alle festen Kosten aus einer Projektschablone entfernt werden sollen. |
| remove_resource_rates | Ruft einen Wert ab oder legt ihn fest, der angibt, ob Ressourcenraten aus einer Projektschablone entfernt werden sollen. |
