## MPPSaveOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Speichern von Projektdaten als MPP.

Der MPPSaveOptions-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| MPPSaveOptions() | Initialisiert eine neue Instanz der [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| save_format | Ruft das Format ab oder legt es fest, in dem das Dokument gespeichert wird, wenn dieses Speicheroptionen-Objekt verwendet wird. |
| remove_invalid_assignments | Liest oder setzt einen Wert, der angibt, ob ungültige Ressourcen‑Zuweisungen beim Speichern in MPP entfernt werden sollen. |
| write_view_data | Liest oder setzt einen Wert, der angibt, ob Ansichts‑Daten beim Speichern eines Projekts im MPP‑Format geschrieben werden sollen. |
| write_filters | Liest oder setzt einen Wert, der angibt, ob Filterdaten beim Speichern eines Projekts im MPP‑Format geschrieben werden sollen. |
| write_groups | Liest oder setzt einen Wert, der angibt, ob Gruppendaten beim Speichern eines Projekts im MPP‑Format geschrieben werden sollen. |
| clear_vba | Liest oder setzt einen Wert, der angibt, ob vorhandene VBA‑Makrodaten beim Speichern eines Projekts im MPP‑Format entfernt werden sollen. |
| write_vba | Liest oder setzt einen Wert, der angibt, ob vorhandene VBA‑Makrodaten in der MPP‑Datei aktualisiert werden sollen.<br/>            Derzeit wird das Schreiben von VbaModule.SourceCode unterstützt. |
| protection_password | Liest oder setzt ein Passwort, das zum Schutz der resultierenden MPP‑Datei verwendet wird. Derzeit wird es für MS Project 2010 und neuere Formate unterstützt. |
