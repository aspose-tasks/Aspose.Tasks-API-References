## PrimaveraRelationshipLagCalendar enumeration

Gibt an, welcher Kalender für die Zeitplanung von Beziehungsverzögerungen in Primavera-Projekten verwendet werden soll.

## Members
| Membername | Beschreibung |
| :- | :- |
| PREDECESSOR | Verwende den Vorgänger‑Aktivitätskalender |
| SUCCESSOR | Verwende den Nachfolger‑Aktivitätskalender |
| CALENDAR_24_HOUR | Verwende den 24‑Stunden‑Kalender |
| DEFAULT | Projektstandardkalender verwenden |
