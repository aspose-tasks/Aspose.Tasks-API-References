## PrimaveraProjectInfo class

Stellt kurze Informationen über ein aus dem Primavera-Format geladenes Projekt dar.

Der Typ PrimaveraProjectInfo stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| uid | Liefert die Uid des Projekts. |
| name | Liefert den Namen des Projekts. |
| short_name | Ruft den Kurznamen des Projekts (Projekt-ID) ab. |
| export_flag | Liefert das Export-Flag des Projekts. Wenn ein Projekt in Primavera für den Export ausgewählt wird, ist sein ExportFlag true.<br/>            Einige Projekte, die nicht explizit für den Export ausgewählt wurden, können aufgrund ihrer Beziehung zum exportierten Projekt in eine XER-Datei exportiert werden. |
