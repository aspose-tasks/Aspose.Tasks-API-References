## BuiltInProjectPropertyCollection class

Stellt eine Sammlung integrierter Projekteigenschaften dar.

Der BuiltInProjectPropertyCollection-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| title | Liefert oder setzt den Titel eines Projekts. |
| subject | Liefert oder setzt das Thema eines Projekts. |
| author | Liefert oder setzt den Autor eines Projekts. |
| manager | Liefert oder setzt den Manager eines Projekts. |
| company | Liefert oder setzt das Unternehmen eines Projekts. |
| category | Liefert oder setzt die Kategorie eines Projekts. |
| keywords | Liefert oder setzt die Schlüsselwörter eines Projekts. |
| comments | Liefert oder setzt die Kommentare eines Projekts. |
| hyperlink_base | Liefert oder setzt die Hyperlink-Basis eines Projekts. |
| Namen |  |
