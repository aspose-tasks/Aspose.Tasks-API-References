Enthält Klassen zum Erstellen von Risikoanalyseberichten.

## Klassen
| Klasse | Beschreibung |
| :- | :- |
| [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) | Stellt ein Ergebnis der Risikoanalyse dar. |
| [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) | Gibt die Einstellungen für die Durchführung einer Risikoanalyse an. |
| [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) | Führt eine Monte‑Carlo‑Simulation basierend auf den angegebenen Risikoanalyse‑Einstellungen durch. |
| [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) | Stellt ein Element dar, das statistische Daten für die Aufgabe des analysierten Projekts speichert. |
| [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) | Stellt eine Sammlung dar, die die Instanzen der Klasse [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) enthält. |
| [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) | Stellt ein Risikomuster für eine Projektaufgabe dar. |
| [RiskPatternCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskpatterncollection/) | Stellt eine Sammlung dar, die die Instanzen der Klasse [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) enthält. |
## Aufzählungen
| Aufzählung | Beschreibung |
| :- | :- |
| [ConfidenceLevel](/tasks/python-net/aspose.tasks.riskanalysis/confidencelevel/) | Gibt die unterstützten Konfidenzniveaus an, die in der Risikoanalyse verwendet werden, die dem <br/>            Prozentsatz der Zeit entsprechen, in dem die tatsächlichen Werte innerhalb optimistischer und pessimistischer Schätzungen liegen. |
| [ProbabilityDistributionType](/tasks/python-net/aspose.tasks.riskanalysis/probabilitydistributiontype/) | Gibt die Typen der unterstützten Wahrscheinlichkeitsverteilungen an. |
| [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) | Gibt die Aufgabenfelder an, für die während der Risikoanalyse statistische Informationen gesammelt werden. |
