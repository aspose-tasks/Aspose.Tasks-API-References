## RiskAnalyzer class

Führt eine Monte‑Carlo‑Simulation basierend auf den angegebenen Risikoanalyse‑Einstellungen durch.

Der Typ RiskAnalyzer stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| RiskAnalyzer(settings) | Initialisiert eine neue Instanz der Klasse [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| settings | Liest die Instanz der Klasse [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) aus oder legt sie fest, die die erforderlichen Einstellungen für die Risikoanalyse definiert. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| analyze(project) | Führt eine Risikoanalyse für das angegebene Projekt durch. Die Analyse basiert auf einer Monte‑Carlo‑Simulation und das Ergebnis ist eine Instanz der Klasse [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/). |
