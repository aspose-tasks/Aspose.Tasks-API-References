## RiskPattern class

Stellt ein Risikomuster für eine Projektaufgabe dar.

Der Typ RiskPattern stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| RiskPattern(task) | Initialisiert eine neue Instanz der Klasse [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| task | Liefert eine Projektaufgabe, auf die dieses Risiko-Muster angewendet wird. |
| Verteilung | Liest oder setzt die Wahrscheinlichkeitsverteilung, die in der Monte-Carlo-Simulation verwendet wird.<br/> Der Standardwert ist ProbabilityDistributionType.Normal. |
| vertrauensniveau | Liest oder setzt das Vertrauensniveau, das dem Prozentsatz der Zeit entspricht, in der die tatsächlich erzeugten Werte innerhalb der optimistischen und pessimistischen Schätzungen liegen.<br/> Der Standardwert ist CL99. |
| optimistisch | Liest oder setzt den Prozentsatz der wahrscheinlichsten Aufgabendauer, die im bestmöglichen Projektszenario auftreten kann.<br/> Der Standardwert ist 75, was bedeutet, dass wenn die geschätzte angegebene Aufgabendauer 4 Tage beträgt, die optimistische Dauer 3 Tage beträgt. |
| pessimistisch | Liest oder setzt den Prozentsatz der wahrscheinlichsten Aufgabendauer, die im ungünstigsten Projektszenario auftreten kann.<br/> Der Standardwert ist 125, was bedeutet, dass wenn die geschätzte angegebene Aufgabendauer 4 Tage beträgt, die pessimistische Dauer 5 Tage beträgt. |
