## ProbabilityDistributionType enumeration

Gibt die Typen der unterstützten Wahrscheinlichkeitsverteilungen an.

## Members
| Membername | Beschreibung |
| :- | :- |
| UNIFORM | Die Verteilung, wenn jeder Wert mit gleicher Wahrscheinlichkeit ausgewählt wird. |
| NORMAL | Die Verteilung, die manchmal informell als Glockenkurve (Gaußsche Verteilung) bezeichnet wird. |
