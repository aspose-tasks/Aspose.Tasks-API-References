## RiskItemStatistics class

Stellt ein Element dar, das statistische Daten für die Aufgabe des analysierten Projekts speichert.

Der Typ RiskItemStatistics stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| item_type | Liefert eine Instanz der [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) Aufzählung. |
| Minimum | Liefert den minimalen Wert, der während der Monte-Carlo-Simulation erzeugt wurde. |
| Maximum | Liefert den maximalen Wert, der während der Monte-Carlo-Simulation erzeugt wurde. |
| erwarteter_wert | Liefert den erwarteten Wert des Risiko-Elements. |
| standardabweichung | Liefert die Standardabweichung des Risiko-Elements. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| get_percentile(percent) | Liefert einen Wert, unter dem ein bestimmter Prozentsatz der erzeugten Stichproben liegt. |
