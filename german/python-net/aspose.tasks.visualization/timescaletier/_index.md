## TimescaleTier class

Stellt eine einzelne Ebene der Zeitskala in einem Gantt-Diagramm dar.

Der Typ TimescaleTier stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TimescaleTier() | Initialisiert eine neue Instanz der Klasse [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Initialisiert eine neue Instanz der TimescaleTier-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| count | Liest oder setzt das Zeitintervall, in dem Beschriftungen für die Stufe angezeigt werden.<br/>            Der Standardwert ist 1. |
| label | Liest oder setzt die Datumsbeschriftung [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) für die Zeitskala-Stufe. |
| alignment | Liest oder setzt, wie Beschriftungen innerhalb jedes Zeitraums der Stufe ausgerichtet werden ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Liest oder setzt einen Wert, der angibt, ob die Stufenbeschriftungen auf dem Geschäftsjahr basieren sollen. |
| show_ticks | Liest oder setzt einen Wert, der angibt, ob Markierungen angezeigt werden sollen, die Zeiträume in der Stufe trennen. |
| unit | Liest oder setzt die Zeitskala-Einheit [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) für die Zeitskala-Stufe.<br/>            Der Standardwert ist |
| render_label_on_each_page | Liest oder setzt ein Flag, das definiert, ob Datumsbeschriftungen auf jeder Seite gerendert werden sollen, wenn ein Zeitraum über mehrere Seiten hinweg reicht.<br/>            Wenn der Wert 'true' ist, werden Datumsbeschriftungen für den Zeitraum auf jeder Seite gerendert.<br/>            Wenn der Wert 'false' ist, wird die Datumsbeschriftung nur einmal gerendert, basierend auf dem Wert der [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/)-Eigenschaft. |
