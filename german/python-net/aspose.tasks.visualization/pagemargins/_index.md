## PageMargins class

Stellt Seitenränder für den Druck dar.

Der Typ PageMargins stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PageMargins() | Initialisiert eine neue Instanz der Klasse PageMargins |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| top | Liest oder setzt die Größe des oberen Randes in Zentimetern. |
| bottom | Liest oder setzt die Größe des unteren Randes in Zentimetern. |
| left | Liest oder setzt die Größe des linken Randes in Zentimetern. |
| right | Liest oder setzt die Größe des rechten Randes in Zentimetern. |
| borders | Liest oder setzt eine Position, an der Rahmen gedruckt werden sollen. Kann einer der Werte der Aufzählung [Border](/tasks/python-net/aspose.tasks.visualization/border/) sein. |
