## ProgressLines class

Stellt Fortschrittslinien in einer Gantt-Diagramm-Ansicht dar.

Der Typ ProgressLines stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ProgressLines() | Initialisiert eine neue Instanz der Klasse ProgressLines |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| display_at_current_date | Liest oder setzt einen Wert, der angibt, ob die Fortschrittslinie am aktuellen Datum angezeigt wird. |
| display_at_recurring_intervals | Liest oder setzt einen Wert, der angibt, ob die Fortschrittslinie in wiederkehrenden Intervallen angezeigt wird. |
| recurring_interval | Liest oder setzt das wiederkehrende Intervall.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Ruft den Wert ab oder legt ihn fest, der angibt, ob Fortschrittslinien ab dem Beginn des Projektstartdatums angezeigt werden sollen. |
| begin_at_date | Ruft das Datum ab oder legt es fest, ab dem Fortschrittslinien angezeigt werden sollen. |
| display_selected | Ruft den Wert ab oder legt ihn fest, der angibt, ob Fortschrittslinien an den ausgewählten Daten angezeigt werden sollen. |
| is_baseline_plan | Ruft den Wert ab oder legt ihn fest, der angibt, ob Fortschrittslinien für den Basisplan oder den Ist-Zustand angezeigt werden sollen. |
| show_date | Ruft den Wert ab oder legt ihn fest, der angibt, ob das Datum für jede Fortschrittslinie angezeigt werden soll. |
| date_format | Ruft das Datumsformat ab oder legt es fest ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Ruft die für das Fortschrittslinien-Label verwendete Schriftart ab oder legt sie fest. |
| line_pattern | Ruft das Linienmuster der aktuellen Fortschrittslinie ab oder legt es fest.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Ruft die Linienfarbe für die aktuelle Fortschrittslinie ab oder legt sie fest. |
| progress_point_shape | Ruft die Form des Fortschrittspunkts ab oder legt sie fest.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Ruft die Farbe des Fortschrittspunkts ab oder legt sie fest. |
| other_line_pattern | Ruft das Linienmuster für andere Fortschrittslinien ab oder legt es fest. |
| other_line_color | Ruft die Farbe anderer Fortschrittslinien ab oder legt sie fest. |
| other_progress_point_shape | Ruft die Form des Fortschrittspunkts anderer Fortschrittslinien ab oder legt sie fest. |
| other_progress_point_color | Liest oder setzt die Farbe des anderen Fortschrittspunkts. |
| selected_dates | Liest die Liste der ausgewählten Daten, für die Fortschrittslinien angezeigt werden sollen. |
