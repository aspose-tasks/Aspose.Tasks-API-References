## PageSettings class

Stellt die Druckeinstellungen für eine Seite der Projektansicht dar.

Der Typ PageSettings stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PageSettings() | Initialisiert eine neue Instanz der Klasse [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Stellt Druckeinstellungen für eine Seite der Projektansicht dar. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_portrait | Liest oder setzt einen Wert, der angibt, ob die Seitenorientierung Hochformat ist; gibt false zurück, wenn die Seitenorientierung Querformat ist. |
| adjust_to_percent_of_normal_size | Liest oder legt einen Wert fest, der angibt, ob der Druck auf den angegebenen Prozentsatz ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) der Normalgröße angepasst werden soll. |
| percent_of_normal_size | Liest oder legt einen Prozentsatz der Normalgröße fest, auf den der Druck angepasst werden soll. |
| pages_in_width | Liest oder legt die Anzahl der Seiten in der Breite fest, die gedruckt werden sollen. |
| pages_in_height | Liest oder legt die Anzahl der Seiten in der Höhe fest, die gedruckt werden sollen. |
| paper_size | Liest oder legt eine Papiergröße fest. Kann einer der Werte der Aufzählung [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/) sein. |
| paper_size_id | Liest oder legt eine Ganzzahl fest, die einen der PrinterPaperSize-Werte oder eine benutzerdefinierte Seitenformat-ID darstellt.<br/>            Dieser Wert kann verwendet werden, um die Papiergröße aus den Betriebssystemeinstellungen zu erhalten. |
| first_page_number | Liest oder legt die erste Seitennummer für den Druck fest. |
