## TableTextStyle class

Stellt einen Textstil in einer Ansichtstabelle dar.

Der TableTextStyle-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TableTextStyle(row_uid) | Initialisiert eine neue Instanz der TableTextStyle-Klasse |
| TableTextStyle(row_uid, font) | Initialisiert eine neue Instanz der TableTextStyle-Klasse |
| TableTextStyle(row_uid, font_size, font_style) | Initialisiert eine neue Instanz der TableTextStyle-Klasse |
| TableTextStyle(row_uid, font_style) | Initialisiert eine neue Instanz der TableTextStyle-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| font | Liest oder setzt die Schriftart des Textstils. |
| color | Liest oder setzt die Farbe des Textes. |
| item_type | Gibt einen Wert des [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) Enums zurück. |
| background_pattern | Liest oder setzt das Hintergrundmuster des Textstils.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Liest oder setzt die Hintergrundfarbe des Textstils.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| row_uid | Liefert eine eindeutige Zeilen-ID. |
| field | Ermittelt oder legt fest ein Feld, auf das der Stil angewendet wird.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/tabletextstyle/). |
