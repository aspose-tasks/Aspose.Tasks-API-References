## TimescaleFitBehavior enumeration

Stellt ein Verhalten dar, das verwendet wird, um den Zeitskala‑Bereich an die Seitenbreite anzupassen.

## Members
| Membername | Beschreibung |
| :- | :- |
| DEFINED_IN_VIEW | Der Kalenderabschnitt wird gemäß der Eigenschaft View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage der gerenderten Ansicht dargestellt. |
| NO_SCALE_TO_END_DATE | Der Kalenderabschnitt wird exakt bis zum Enddatum gerendert, selbst wenn auf einer Seite ein leerer Raum vorhanden ist. |
| NO_SCALE_TO_END_OF_PAGE | Der Kalenderabschnitt wird bis zum Ende (rechte Seite) der letzten Seite gerendert.<br/>            Daher kann das zuletzt gerenderte Datum das Enddatum überschreiten. |
| SCALE_TO_END_OF_PAGE | Die Rendering-Engine versucht, Daten so auszurichten, dass EndDate am Ende (rechte Seite) der letzten Seite ausgerichtet ist.<br/>            Entspricht der aktivierten Option "Page Setup \ View \ Fit timescale to end of page" von MS Project. |
