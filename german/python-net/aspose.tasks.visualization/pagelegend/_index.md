## PageLegend class

Stellt eine Seitenlegende dar, die für den Projekt‑Druck verwendet wird.

Der PageLegend-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PageLegend() | Initialisiert eine neue Instanz der PageLegend-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| left_text | Ruft den linksbündigen Text ab oder legt ihn fest, der im übergeordneten Element angezeigt wird. |
| centered_text | Ruft den zentrierten Text ab oder legt ihn fest, der im übergeordneten Element angezeigt wird. |
| right_text | Ruft den rechtsbündigen Text ab oder legt ihn fest, der im übergeordneten Element angezeigt wird. |
| left_image | Ruft das linksbündige Bild ab oder legt es fest, das im übergeordneten Element angezeigt wird. |
| centered_image | Ruft das zentrierte Bild ab oder legt es fest, das im übergeordneten Element angezeigt wird. |
| right_image | Ruft das rechtsbündige Bild ab oder legt es fest, das im übergeordneten Element angezeigt wird. |
| left_image_size | Ruft die angezeigte Größe des linken Bildes ab oder legt sie fest. |
| centered_image_size | Ruft die angezeigte Größe des mittleren Bildes ab oder legt sie fest. |
| right_image_size | Ruft die angezeigte Größe des rechten Bildes ab oder legt sie fest. |
| legend_on | Liest oder setzt die Seiten, auf denen die Legende angezeigt wird. Kann einer der Werte der [Legend](/tasks/python-net/aspose.tasks.visualization/legend/) Aufzählung sein. |
| width | Liest oder setzt die Breite des linken Teils (standardmäßig enthält er den Projektnamen und das Datum) der Legende in Zentimetern. |
