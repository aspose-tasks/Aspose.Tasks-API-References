## ITextStyleModificationCallback class

Stellt einen Callback dar, der aufgerufen wird, bevor TextStyle auf eine Tabellenzelle angewendet wird.

Der Typ ITextStyleModificationCallback stellt die folgenden Mitglieder bereit:
## Methoden
| Name | Beschreibung |
| :- | :- |
| before_task_text_style_applied(args) | Die Methode, die vor dem Rendern einer Tabellenzelle für eine Aufgabenzeile in den folgenden Ansichten aufgerufen wird:<br/>            'Gantt Chart', 'Task Sheet', 'Task Usage'. |
