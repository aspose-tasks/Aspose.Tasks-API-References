## GanttBarStyle class

Stellt einen Balkenstil dar, der von MSP in der Gantt‑Diagrammansicht verwendet wird.

Der Typ GanttBarStyle stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| GanttBarStyle() | Initialisiert eine neue Instanz der Klasse [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| bottom_field | Liest oder setzt Daten, die am unteren Rand des Balkens angezeigt werden.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| end_shape | Liest oder legt die Endform des Balkens fest. |
| end_shape_color | Liest oder legt die Farbe der Endform fest. |
| end_shape_type | Liest oder legt den Typ der Endform fest.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| from_address | Liest oder legt die Startpunktposition des Gantt-Balkens fest.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | Liest oder legt die im Balken anzuzeigenden Daten fest.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| left_field | Liest oder legt die links vom Balken anzuzeigenden Daten fest.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| middle_fill_pattern | Liest oder legt das Füllmuster des Gantt-Balkens fest. |
| middle_shape | Liest oder legt eine Mittelform des Balkens fest. |
| middle_shape_color | Liest oder legt die Farbe der Mittelform fest. |
| name | Liest oder legt den Namen des Stils fest. |
| right_field | Liest oder legt die rechts vom Balken anzuzeigenden Daten fest.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| row | Liest oder legt die Zeilennummer fest. |
| show_for_categories | Liest oder legt die Aufgaben­kategorien fest, für die der Stil angewendet wird. Gilt für übergeordnete (oder gemeinsame) Balkenstile im Gantt‑Diagramm<br/>            (siehe [bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| show_for_task_uid | Liest oder legt die eindeutige ID einer Aufgabe fest, für die der Stil angewendet wird. Gilt für aufgaben­spezifische Balkenstile im Gantt‑Diagramm (siehe [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | Liest oder legt eine Startform des Balkens fest. |
| start_shape_color | Liest oder legt die Farbe der Startform fest. |
| start_shape_type | Ruft den Typ der Startform ab oder legt ihn fest. |
| to | Ruft die Position des Endpunkts der Gantt-Leiste ab oder legt sie fest. |
| top_field | Ruft die anzuzeigenden Daten oben in der Leiste ab oder legt sie fest. |
| parent_style | Ruft den übergeordneten (oder gemeinsamen) Stil für benutzerdefinierte aufgabenspezifische Stile ab oder legt ihn fest. |
