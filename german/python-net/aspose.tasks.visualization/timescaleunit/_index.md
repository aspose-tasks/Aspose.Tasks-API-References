## TimescaleUnit enumeration

Gibt die Zeiteinheit für jede Ebene einer Zeitskala in einem Gantt-Diagramm oder einer anderen zeitphasierten Ansicht an.

## Members
| Membername | Beschreibung |
| :- | :- |
| NONE | Zeigt None an. Die Zeitskala-Ebene ist ausgeblendet. |
| MINUTES | Zeigt die Zeitskala-Einheit Minuten an. |
| HOURS | Zeigt die Zeitskala-Einheit Stunden an. |
| DAYS | Zeigt die Zeitskala-Einheit Tage an. |
| WEEKS | Zeigt die Zeitskala-Einheit Wochen an. |
| THIRDS_OF_MONTHS | Zeigt die Zeitskala-Einheit Drittel von Monaten an. |
| MONTHS | Zeigt die Zeitskala-Einheit Monate an. |
| QUARTERS | Zeigt die Zeitskala-Einheit Quartale von Jahren an. |
| HALF_YEARS | Zeigt die Zeitskala-Einheit Halbjahre an. |
| YEARS | Gibt die Zeitskalaeinheit Jahre an. |
