## RecurringInterval class

Stellt wiederkehrende Intervalle dar, die in Fortschrittslinien einer Gantt-Diagramm-Ansicht verwendet werden.

Der Typ RecurringInterval stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| RecurringInterval() | Initialisiert eine neue Instanz der Klasse RecurringInterval |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| interval | Ermittelt oder legt fest das wiederkehrende Intervall.<br/>            Kann jeder Wert des Typs [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/) sein. |
| daily_day_number | Ermittelt oder legt fest die tägliche Tagesnummer. |
| daily_workday | Ermittelt oder legt fest einen Wert, der angibt, ob ein Tag ein Arbeitstag für tägliche Fortschrittslinien ist. |
| weekly_week_number | Ermittelt oder legt fest die Wochennummer für wöchentliche Fortschrittslinien. |
| monthly_day | Ermittelt oder legt fest einen Wert, der angibt, ob monatliche Fortschrittslinien nach Tag angezeigt werden sollen. |
| monthly_day_day_number | Ermittelt oder legt fest die Tagesnummer der monatlichen Fortschrittslinien. |
| monthly_day_month_number | Ermittelt oder legt fest die Monatsnummer der monatlichen Fortschrittslinien. |
| monthly_first_last | Ermittelt oder legt fest einen Wert, der angibt, ob Fortschrittslinien nach dem ersten oder letzten vordefinierten Tag angezeigt werden sollen. |
| monthly_first_last_month_number | Ermittelt oder legt fest die Monatsnummer der Fortschrittslinien, die nach dem ersten oder letzten vordefinierten Tag angezeigt werden. |
| monthly_first_last_day | Ermittelt oder legt fest den Typ des ersten oder letzten Tages der monatlichen Fortschrittslinien. |
| weekly_days | Ermittelt eine Liste von Tagen für wöchentliche Fortschrittslinien. |
