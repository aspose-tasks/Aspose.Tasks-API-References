## Legend enumeration

Gibt die möglichen Optionen an, die beim Rendern der Legende der Ansicht verwendet werden.

## Members
| Membername | Beschreibung |
| :- | :- |
| NO_LEGEND | Keine Legende wird gerendert. |
| AFTER_LAST_PAGE | Die Legende wird auf einer separaten Seite nach der letzten Seite der Projektseiten gerendert. |
| ON_EVERY_PAGE | Die Legende wird auf jeder Seite gerendert. |
