## FontDescriptor class

Stellt Schriftinformationen dar.

Der FontDescriptor-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| FontDescriptor(font_family, size) | Initialisiert eine neue Instanz der FontDescriptor-Klasse |
| FontDescriptor(font_family, size, style) | Initialisiert eine neue Instanz der FontDescriptor-Klasse |
| FontDescriptor(font, style) | Initialisiert eine neue Instanz der [FontDescriptor](/tasks/python-net/aspose.tasks.visualization/fontdescriptor/) Klasse mit der angegebenen Schriftfamilie, Größe und Stil. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| font_family | Gibt den Namen der Schriftfamilie zurück. |
| size | Gibt die Größe der Schrift zurück. |
| style | Gibt den Stil der Schrift zurück. |
