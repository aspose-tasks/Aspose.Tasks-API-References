## Timescale enumeration

Definiert Optionen, die festlegen, wie die Zeitskala in Gantt-Diagramm-, Aufgabenverbrauchs- oder Ressourcennutzungsansichten gerendert wird, wenn das Projekt in ein Grafikformat exportiert wird.

## Members
| Membername | Beschreibung |
| :- | :- |
| DEFINED_IN_VIEW | Verwenden Sie die in den Eigenschaften der Projektansicht definierten Zeitskaleneinstellungen: [bottom_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/),<br/>            [middle_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/), [top_timescale_tier](/tasks/python-net/aspose.tasks/ganttchartview/).<br/>            Gültig für Formate, die Ansichts‑Daten enthalten. Zum Beispiel Projekte, die aus dem MPP‑Format gelesen werden. |
| DAYS | Vordefinierte zweistufige Zeitskala, bei der die minimale Detailstufe ein Tag beträgt. |
| THIRDS_OF_MONTHS | Vordefinierte zweistufige Zeitskala, bei der die Detailstufe ein Drittel eines Monats beträgt. |
| MONTHS | Vordefinierte zweistufige Zeitskala, bei der die minimale Detailstufe ein Monat beträgt. |
