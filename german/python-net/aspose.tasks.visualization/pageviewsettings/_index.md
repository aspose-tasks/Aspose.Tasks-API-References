## PageViewSettings class

Stellt die Druckeinstellungen für eine Projektansicht dar.

Der Typ PageViewSettings stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PageViewSettings() | Initialisiert eine neue Instanz der Klasse PageViewSettings |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| first_columns_count | Liest oder setzt die Anzahl der ersten Spalten, die auf allen Seiten gedruckt werden. |
| fit_timescale_to_end_of_page | Liest oder setzt einen Wert, der angibt, ob die Zeitskala beim Drucken an das Ende einer Seite angepasst werden soll. |
| print_all_sheet_columns | Liest oder setzt einen Wert, der angibt, ob alle Blattspalten einer Ansicht gedruckt werden sollen. |
| print_blank_pages | Liest oder setzt einen Wert, der angibt, ob leere Seiten einer Ansicht gedruckt werden sollen. |
| print_first_columns_count_on_all_pages | Liest oder setzt einen Wert, der angibt, ob eine bestimmte Anzahl erster Spalten auf allen Seiten gedruckt werden soll. |
| print_notes | Liest oder setzt einen Wert, der angibt, ob Notizen gedruckt werden sollen. |
