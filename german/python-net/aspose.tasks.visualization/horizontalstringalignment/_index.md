## HorizontalStringAlignment enumeration

Gibt die Ausrichtung einer Textzeichenfolge relativ zu ihrem Layoutrechteck an.

## Members
| Membername | Beschreibung |
| :- | :- |
| NEAR | Gibt an, dass der Text nahe am Layout ausgerichtet wird. In einem links‑nach‑rechts Layout ist die nahe Position links. In einem rechts‑nach‑links Layout ist die nahe Position rechts. |
| CENTER | Gibt an, dass der Text in der Mitte des Layout‑Rechtecks ausgerichtet wird. |
| FAR | Gibt an, dass der Text weit von der Ursprungposition des Layout‑Rechtecks ausgerichtet wird. In einem links‑nach‑rechts Layout ist die ferne Position rechts. In einem rechts‑nach‑links Layout ist die ferne Position links. |
