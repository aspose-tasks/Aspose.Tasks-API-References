## Shape enumeration

Form eines Markers am Anfang oder Ende des Balkenstils, der beim Speichern von Ansichtsdaten in einige der [SaveFileFormat](/tasks/python-net/aspose.tasks.saving/savefileformat/) gerendert wird.

## Members
| Membername | Beschreibung |
| :- | :- |
| NONE | Zeigt keine Form an. |
| VERTICAL_LINE | Zeigt die vertikale Linienform an. |
| PENTAGON | Zeigt die Pentagon-Form an. |
| TRIANGLE | Zeigt die Dreieck-Form an. |
| LEFT_BRACKET | Zeigt die Form Linke Klammer an. |
| RIGHT_BRACKET | Zeigt die Form Rechte Klammer an. |
| ARROW_DOWN | Zeigt die Form Pfeil nach unten an. |
| LEFT_FADE | Zeigt die Form Linkes Fade an. |
| RIGHT_FADE | Zeigt die Form Rechtes Fade an. |
| DIAMOND | Zeigt die Diamant-Form an. |
| CIRCLE | Zeigt die Kreis-Form an. |
