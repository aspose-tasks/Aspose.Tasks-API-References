## BarStyle class

Ändert den visuellen Stil der Leiste für das Element in der Projektansicht.

Der BarStyle-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| BarStyle() | Initialisiert eine neue Instanz der [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| bar_color | Liest oder setzt aspose.pydrawing.Color des Balkenstils. |
| start_shape_color | Liest oder setzt aspose.pydrawing.Color der Form am Anfang des Balkens. |
| start_shape_type | Ruft den Typ der Startform ab oder legt ihn fest. |
| end_shape_color | Liest oder setzt aspose.pydrawing.Color der Form am Ende des Balkens. |
| end_shape_type | Liest oder legt den Typ der Endform fest.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | Liest oder setzt [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) des Balkenstils. |
| bar_shape | Liest oder legt [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) des Balkenstils fest. |
| start_shape | Liest oder legt [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) am Anfang des Balkens fest. |
| end_shape | Liest oder legt [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) am Ende des Balkens fest. |
| text_style | Liest oder legt den Stil des Balkentextes fest. |
| left_field | Liest oder legt ein Feld fest, das links vom Balken angezeigt wird. |
| top_field | Liest oder legt ein Feld fest, das oben am Balken angezeigt wird. |
| right_field | Liest oder legt ein Feld fest, das rechts vom Balken angezeigt wird. |
| bottom_field | Liest oder legt ein Feld fest, das unten am Balken angezeigt wird. |
| inside_field | Liest oder legt ein Feld fest, das innerhalb des Balkens angezeigt wird. |
| from_address | Liest oder legt die Startpunktposition des Gantt-Balkens fest.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | Ruft die Position des Endpunkts der Gantt-Leiste ab oder legt sie fest. |
