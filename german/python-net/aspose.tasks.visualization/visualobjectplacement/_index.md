## VisualObjectPlacement class

Stellt die Platzierung und das Erscheinungsbild von [OleObject](/tasks/python-net/aspose.tasks/oleobject/) in einer Ansicht dar.

Der Typ VisualObjectPlacement stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| VisualObjectPlacement() | Initialisiert eine neue Instanz der Klasse [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| ole_object_id | Liest oder setzt die Id des [OleObject](/tasks/python-net/aspose.tasks/oleobject/) Objekts. |
| task_id | Liest oder setzt die Id der Aufgabe, wenn die Option 'Attach to task' ausgewählt ist, sonst -1. |
| width | Liest oder setzt die angezeigte Breite des visuellen Objekts. |
| Höhe | Liest oder setzt die angezeigte Höhe des visuellen Objekts. |
| vertical_offset | Liest oder setzt den vertikalen Versatz des visuellen Objekts. |
| horizontal_offset | Liest oder setzt den horizontalen Versatz des visuellen Objekts. |
| timescale_date | Liest oder setzt die Datumplatzierung des visuellen Objekts, wenn die Option 'Attach to timescale' ausgewählt ist. |
| attachment_point | Liest oder setzt die Ausrichtung des visuellen Objekts relativ zu einer Aufgabe, wenn die Option 'Attach to task' ausgewählt ist. |
| border_line_color | Liest oder setzt die Farbe der Rahmenlinie. |
| border_line_thickness | Liest oder setzt die Dicke der Rahmenlinie (zulässige Werte sind 0 - 5). |
| fill_color | Liest oder setzt die Füllfarbe. |
| fill_pattern | Liest oder setzt das Füllmuster. |
