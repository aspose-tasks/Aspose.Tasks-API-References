## Gridlines class

Stellt Rasterlinien dar, die in einer GanttChart‑Ansicht erscheinen.

Der Gridlines-Typ stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Gridlines() | Initialisiert eine neue Instanz der Gridlines-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Intervall | Liest oder setzt die Zahl von 0 bis 99, die das Intervall zwischen Rasterlinien angibt. |
| interval_color | Liest oder setzt die Farbe der sekundären Rasterlinien. |
| interval_pattern | Liest oder setzt das Linienmuster für sekundäre Rasterlinien. |
| normal_color | Liest oder setzt die Farbe der normalen Rasterlinien. |
| normal_pattern | Liest oder setzt das Linienmuster für normale Rasterlinien. |
| Typ | Liest oder setzt den Rasterlinientyp. |
