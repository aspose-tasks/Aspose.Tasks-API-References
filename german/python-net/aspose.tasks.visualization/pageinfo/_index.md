## PageInfo class

Stellt Seiteneinrichtungsdaten dar, die im MPP-Dateiformat vorhanden und zum Drucken verwendet werden.

Der PageInfo-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PageInfo() | Initialisiert eine neue Instanz der [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) Klasse. <br/>            Stellt Seiteneinrichtungsdaten dar, die im MPP-Dateiformat vorhanden sind und zum Drucken verwendet werden. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| header | Liest oder setzt die Instanz der [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) Klasse, die Kopfdaten darstellt. |
| footer | Liest oder setzt eine Instanz der [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) Klasse, die Fußzeilendaten darstellt. |
| name | Liest den Namen der Ansicht, für die Einrichtungsdaten verwendet werden. |
| page_settings | Liest eine Instanz der [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) Klasse, die Druckeinstellungen für die Seite festlegt. |
| page_view_settings | Liest eine Instanz der [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) Klasse, die Druckeinstellungen für die Seitenansicht festlegt. |
| margins | Liest eine Instanz der [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) Klasse, die Seitenränder festlegt. |
| legend | Liest oder setzt eine Instanz der [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) Klasse, die Renderoptionen der Seitenlegende festlegt. |
