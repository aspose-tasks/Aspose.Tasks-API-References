## TextStyle class

Ändern Sie den visuellen Stil des Textes für ein Element in der Projektansicht.

Der TextStyle-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextStyle() | Initialisiert eine neue Instanz der [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) Klasse mit Standardeinstellungen. |
| TextStyle(font_size, font_style) | Initialisiert eine neue Instanz der TextStyle-Klasse |
| TextStyle(font_style) | Initialisiert eine neue Instanz der [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) Klasse mit der Standardschrift und der angegebenen Schriftgröße und -stil. |
| TextStyle(font) | Initialisiert eine neue Instanz der [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) Klasse mit den angegebenen Schriftarteinstellungen. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| font | Liest oder setzt die Schriftart des Textstils. |
| color | Liest oder setzt die Farbe des Textes. |
| item_type | Liest oder setzt [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) des Textstils. |
| background_pattern | Liest oder setzt das Hintergrundmuster des Textstils.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Liest oder setzt die Hintergrundfarbe des Textstils.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
