## TaskTextStyleEventArgs class

Diese Klasse stellt einen Datensatz dar, der sich auf die Darstellung des Inhalts von Tabellenzellen bezieht.

Der Typ TaskTextStyleEventArgs stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| cell_text_style | Liest oder setzt TextStyle, das zum Zeichnen des Zellinhalts verwendet wird. Dieses Objekt kann zur Anpassung des Aussehens einer Tabellenzelle verwendet werden. |
| task | Liest [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/), das der aktuell gerenderten Zeile entspricht. |
| column | Liest [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/), zu dem die aktuell gerenderte Zelle gehört. |
