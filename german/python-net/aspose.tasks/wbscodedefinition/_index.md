## WBSCodeDefinition class

Stellt eine WBS-Code-Definition dar.

Der WBSCodeDefinition-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| WBSCodeDefinition() | Initialisiert eine neue Instanz der [WBSCodeDefinition](/tasks/python-net/aspose.tasks/wbscodedefinition/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| code_prefix | Liest oder setzt das Projektcode-Präfix. |
| generate_wbs_code | Liest oder setzt einen Wert, der angibt, ob für neue Aufgaben ein WBS-Code generiert werden soll. |
| verify_uniqueness | Liest oder setzt einen Wert, der angibt, ob die Eindeutigkeit neuer WBS-Codes überprüft werden soll. |
| code_mask_collection | Gibt die Sammlung von WBSCodeMask-Objekten zurück. |
