## UsageView class

Stellt eine Verwendungsansicht in einem Projekt dar.

Der Typ UsageView stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| filter | Liest oder setzt einen Filter, der in einer einzelnen Ansicht verwendet wird. |
| Gruppe | Liest oder setzt eine Gruppe der einzelnen Ansicht. |
| uid | Liest die eindeutige Kennung einer Ansicht. |
| highlight_filter | Liest oder setzt einen Wert, der angibt, ob Microsoft Project den Filter für eine einzelne Ansicht hervorhebt. |
| name | Liest oder setzt den Namen eines View-Objekts. |
| screen | Liest den Bildschirmentyp für die einzelne Ansicht.<br/>            Nur lesbar [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Liest das übergeordnete Element des View-Objekts.<br/>            Nur lesbar [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Liest oder setzt eine Tabelle der einzelnen Ansicht. |
| type | Liest den Typ des Elements in der einzelnen Ansicht, z. B. Aufgaben oder Ressourcen.<br/>            Nur lesbar [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Liest oder setzt einen Wert, der angibt, ob Microsoft Project den Namen der einzelnen Ansicht in den Dropdown-Listen „Ansicht“ oder „Weitere Ansichten“ im Ribbon anzeigt. |
| page_info | Liest eine Instanz der Klasse [page_info](/tasks/python-net/aspose.tasks/view/). Stellt Seiteneinrichtungsdaten dar, die im mpp-Dateiformat vorhanden sind. |
| visual_objects_placements | Liest eine Sammlung von Objekten, die die Platzierung und das Erscheinungsbild von [OleObject](/tasks/python-net/aspose.tasks/oleobject/) in der Ansicht darstellen. |
| align_details_data | Liest oder setzt die Ausrichtung der Detaildaten. |
| display_details_header_column | Liest oder setzt einen Wert, der angibt, ob die Kopfzeilen-Spalte der Details in der Ansicht angezeigt wird oder nicht. |
| display_short_detail_header_names | Liest oder setzt einen Wert, der angibt, ob kurze Detailkopfzeilenamen angezeigt werden sollen oder nicht. |
| repeat_details_header_on_all_rows | Liest oder setzt einen Wert, der angibt, ob die Detailkopfzeile in jeder Zuordnungszeile wiederholt wird oder nicht. |
| timescale_size_percentage |  |
| bottom_timescale_tier | Liest oder setzt die Einstellungen der unteren Zeitskala-Stufe der Ansicht.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | Liest oder setzt die Einstellungen der mittleren Zeitskala-Stufe der Ansicht.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | Liest oder setzt die Einstellungen der obersten Zeitskala‑Ebene der Ansicht.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
## Methoden
| Name | Beschreibung |
| :- | :- |
| compare_to(other) | Vergleicht die aktuelle Instanz mit einem anderen Objekt desselben Typs und gibt eine Ganzzahl zurück, die angibt, ob die aktuelle Instanz dem anderen Objekt vorausgeht, folgt oder an derselben Position in der Sortierreihenfolge liegt. |
