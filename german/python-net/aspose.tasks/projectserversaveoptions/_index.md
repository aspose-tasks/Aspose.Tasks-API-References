## ProjectServerSaveOptions class

Ermöglicht das Angeben zusätzlicher Optionen, wenn ein Projekt in Project Server oder Project Online gespeichert wird.

Der Typ ProjectServerSaveOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ProjectServerSaveOptions() | Initialisiert eine neue Instanz der Klasse [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| project_name | Liest oder setzt den Namen eines Projekts, das in der Projektliste von Project Server \ Project Online angezeigt wird. Sollte innerhalb der Project Server \ Project Online-Instanz eindeutig sein.<br/>            Wenn der Wert weggelassen wird, wird stattdessen der Wert der Eigenschaft Prj.Name verwendet. |
| project_guid | Liest oder setzt die eindeutige Kennung eines Projekts. Sollte innerhalb einer Project Server \ Project Online-Instanz eindeutig sein. |
| timeout | Liest oder setzt den Timeout, der beim Warten auf die Verarbeitung einer Projekt‑Speicherungsanfrage durch den Queue‑Verarbeitungsdienst eines Project Server verwendet wird. Der Standardwert für diese Eigenschaft beträgt 1 Minute. |
| polling_interval | Liest oder setzt das Intervall zwischen Anfragen zum Status von Queue‑Jobs. Der Standardwert beträgt 2 Sekunden. |
