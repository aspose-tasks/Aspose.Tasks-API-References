## ResourceSavingArgs class

Diese Klasse stellt einen Datensatz dar, der mit dem Speichern einer externen Ressourcendatei zusammenhängt, die<br/>              während der Konvertierung in das HTML‑Format erfolgt.

Der Typ ResourceSavingArgs stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ResourceSavingArgs() | Initialisiert eine neue Instanz der Klasse ResourceSavingArgs |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| file_name | Liest oder setzt den angenommenen Dateinamen, der vom Konverter zum Code der benutzerdefinierten Methode übergeht.<br/>             Kann im benutzerdefinierten Code verwendet werden, um zu entscheiden, wie die Datei verarbeitet oder wo sie gespeichert wird. |
| keep_stream_open | Liest oder setzt einen Wert, der angibt, ob der Stream nach Abschluss des Ressourcenspeicherns offen bleiben soll. |
| stream | Liest oder setzt den Binärinhalt der gespeicherten Datei. |
| uri | Liest oder setzt die Ressourcen-URI. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| close_stream_if_required() | Schließt den Stream, wenn KeepStreamOpen false ist, andernfalls wird er geleert. |
