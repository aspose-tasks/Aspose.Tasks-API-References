## PrimaveraBaseReader class

Stellt einen Baselleser dar, der verwendet werden kann, um Projekt-UIDs aus Mehrprojekt‑Primavera‑XER‑ oder XML‑Dateien zu lesen.

Der Typ PrimaveraBaseReader stellt die folgenden Mitglieder bereit:
## Methoden
| Name | Beschreibung |
| :- | :- |
| get_project_uids() | Gibt eine Liste der eindeutigen Bezeichner der Projekte zurück. |
| get_project_infos() | Gibt eine Liste der kurzen Informationsobjekte des Projekts zurück. |
| load_project(project_uid) | Lädt das Projekt mit dem angegebenen eindeutigen Bezeichner. |
