## PrimaveraCalendarProperties class

Stellt Primavera-spezifische Eigenschaften für einen Kalender dar, der aus Primavera-Dateien (XER oder P6XML) gelesen wurde.<br/>            Kann verwendet werden, um kalenderbezogene Zeiteinheiten-Konvertierungen durchzuführen.

Der PrimaveraCalendarProperties-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| hours_per_day | Ermittelt die Stundenzahl pro Tag aus den 'Time Periods'-Einstellungen des Kalenders. |
| hours_per_week | Ermittelt die Stundenzahl pro Woche aus den 'Time Periods'-Einstellungen des Kalenders. |
| hours_per_month | Ermittelt die Stundenzahl pro Monat aus den 'Time Periods'-Einstellungen des Kalenders. |
| hours_per_year | Ermittelt die Stundenzahl pro Monat aus den 'Time Periods'-Einstellungen des Kalenders. |
