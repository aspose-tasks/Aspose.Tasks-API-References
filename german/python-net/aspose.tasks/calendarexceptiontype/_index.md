## CalendarExceptionType enumeration

Gibt den Ausnahmetyp des Kalenders an.

| Membername | Beschreibung |
| :- | :- |
| DAILY | Gibt den täglichen Ausnahme-Typ an. |
| YEARLY_BY_DAY | Gibt den jährlichen Ausnahme-Typ nach Tag des Monats an. |
| YEARLY_BY_POSITION | Gibt den jährlichen Ausnahme-Typ nach Position an. |
| MONTHLY_BY_DAY | Gibt den monatlichen Ausnahme-Typ nach Tag des Monats an. |
| MONTHLY_BY_POSITION | Gibt den monatlichen Ausnahme-Typ nach Position an. |

| NO_EXCEPTION_TYPE | Gibt keinen Ausnahmetyp an. |
