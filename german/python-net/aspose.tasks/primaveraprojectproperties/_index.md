## PrimaveraProjectProperties class

Stellt Primavera-spezifische Eigenschaften für ein Projekt dar, das aus Primavera-Dateien (XER oder P6XML) gelesen wurde.

Der Typ PrimaveraProjectProperties stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| relationship_lag_calendar | Ruft eine Option ab, die definiert, welcher Kalender für die Terminplanung von Relationship Lag in Primavera-Projekten verwendet wird. |
| use_expected_finish_dates | Ruft ein Flag ab, das definiert, ob Aktivitätsenddaten als erwartete Enddaten geplant werden sollen. |
| make_open_ended_activities_critical | Ruft ein Flag ab, das definiert, ob Aktivitäten bei der Projektplanung als kritisch markiert werden sollen. |
| ignore_other_project_relationships | Ruft ein Flag ab, das definiert, ob Aktivitätsbeziehungen zwischen Projekten ignoriert werden sollen. |
| current_baseline_project_id | Ruft die ID des aktuellen Basislinienprojekts ab.<br/>            Gilt für Projekte, die aus Primavera-XML-Dateien mit exportierten Basislinien gelesen werden. |
| baseline_projects | Ruft ein Array von Basislinienprojekten des aktuellen Projekts ab.<br/>            Gilt für Projekte, die aus Primavera-XML-Dateien mit exportierten Basislinien gelesen werden. |
| critical_activities_defining_method | Ruft die Methode zur Definition kritischer Aktivitäten ab: Ansatz des längsten Pfads oder Total Float. |
| critical_total_float_limit | Ruft den Schwellenwert ab, der zur Definition kritischer Aktivitäten verwendet wird, wenn die TotalFloat-Methode eingesetzt wird. |
| short_name | Ruft den Kurznamen des Projekts (Projekt-ID) ab. |
