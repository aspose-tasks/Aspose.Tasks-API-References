## CalculationType enumeration

Gibt den Typ einer Berechnung des Werts des benutzerdefinierten Attributs an.

## Members
| Membername | Beschreibung |
| :- | :- |
| NONE | Bedeutet, dass das erweiterte Attribut keine Nachschlagetabelle für Formeln hat und den vom Benutzer festgelegten Wert einfach speichert. |
| LOOKUP | Bedeutet, dass der Wert des erweiterten Attributs auf Werte aus einer Nachschlagetabelle beschränkt ist. |
| FORMULA | Bedeutet, dass der Wert des erweiterten Attributs mithilfe der in [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/) definierten Formel berechnet wird. |
