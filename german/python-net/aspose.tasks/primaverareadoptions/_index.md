## PrimaveraReadOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Lesen von Primavera‑Xml‑ oder Primavera‑Xer‑Dateien.

Der Typ PrimaveraReadOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PrimaveraReadOptions() | Initialisiert eine neue Instanz der Klasse [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| project_uid | Liest oder setzt die UID eines Projekts, das aus einer Datei mit mehreren Projekten gelesen wird. |
| undefined_constraint_handling_behavior | Gibt das Verhalten an, das zur Verarbeitung von Aufgaben mit undefinierten Einschränkungen verwendet wird, die aus dem XER-Format gelesen werden. |
| preserve_uids | Liest oder setzt ein Flag, das angibt, ob die ursprünglichen eindeutigen Bezeichner von Entitäten beibehalten werden sollen. |
| read_baseline_projects | Liest oder setzt ein Flag, das angibt, ob Basislinienprojekte geladen werden sollen. Der Standardwert ist true. |
