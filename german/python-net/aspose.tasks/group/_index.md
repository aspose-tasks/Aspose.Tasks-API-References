## Group class

Stellt eine Gruppendefinition dar.<br/>            Ein Group-Objekt ist Mitglied der ResourceGroups‑Sammlung oder der TaskGroups‑Sammlung.

Der Typ Group stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Group() | Initialisiert eine neue Instanz der [Group](/tasks/python-net/aspose.tasks/group/)-Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| name | Liest oder legt den Namen eines Group‑Objekts fest. |
| uid | Liest einen eindeutigen Bezeichner einer Gruppe. |
| show_summary | Liest oder legt einen Wert fest, der angibt, ob Zusammenfassungszeilen für die Gruppe angezeigt werden. |
| maintain_hierarchy | Liest oder legt einen Wert fest, der angibt, ob alle Ebenen von Zusammenfassungsaufgaben für Unteraufgaben innerhalb der Gruppe angezeigt werden sollen. |
| show_in_menu | Liest oder legt einen Wert fest, der angibt, ob Project den Gruppennamen in der Group‑Dropdown‑Liste im Ribbon anzeigt. |
| group_assignments | Liest oder legt einen Wert fest, der angibt, ob Zuweisungen statt Aufgaben gruppiert werden sollen. |
| group_criteria | Liest oder legt eine GroupCriteria‑Sammlung fest, die die Felder einer Gruppendefinition darstellt. |
