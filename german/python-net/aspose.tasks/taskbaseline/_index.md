## TaskBaseline class

Stellt die Basislinie einer Aufgabe dar.

Der TaskBaseline-Typ stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TaskBaseline(task) | Initialisiert eine neue Instanz der [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| baseline_number | Liest oder setzt die eindeutige Nummer eines Basisdatensatzes. |
| Arbeit | Liest oder setzt die Arbeit, die einer Ressource zugewiesen wird, wenn die Basislinie gespeichert wird. |
| cost | Liest oder setzt die prognostizierten Kosten einer Ressource, wenn die Basislinie gespeichert wird. |
| bcws | Liest oder setzt die Budgetkosten einer für eine Ressource geplanten Arbeit. |
| bcwp | Liest oder setzt die budgetierten Kosten einer von einer Ressource für ein Projekt bis heute ausgeführten Arbeit. |
| timephased_data | Liest oder setzt eine TimephasedDataCollection-Instanz für dieses Objekt.<br/>            Die zeitlich gestaffelten Daten, die mit der Aufgabenbasislinie verknüpft sind. |
| interim | Liest oder setzt einen Wert, der angibt, ob dies eine Zwischenbasislinie ist. |
| Start | Liest oder setzt das geplante Startdatum der Aufgabe, als die Basislinie gespeichert wurde. |
| finish | Liest oder setzt das geplante Enddatum der Aufgabe, als die Basislinie gespeichert wurde. |
| duration | Liest oder setzt die geplante Dauer der Aufgabe, als die Basislinie gespeichert wurde. |
| estimated_duration | Liest oder setzt einen Wert, der angibt, ob die Basisliniendauer der Aufgabe geschätzt wurde. |
| fixed_cost | Liest oder setzt die feste Kosten der Aufgabe, als die Basislinie gespeichert wurde. |
