## TaskLink class

Stellt einen Vorgängerlink dar.

Der TaskLink-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_cross_project | Liest oder legt einen Wert fest, der angibt, ob ein Vorgänger Teil eines anderen Projekts ist. |
| cross_project_name | Liest oder legt das externe Vorgängerprojekt fest. |
| link_lag | Liest oder legt die Verzögerung in Zehntelminuten oder Prozent fest. |
| link_lag_time_span | Liest oder legt die Verzögerungsdauer fest, abhängig vom LagFormat. |
| lag_format | Liest oder legt das Format zur Darstellung des Verzögerungsformats fest. |
| pred_task | Liest oder setzt die Vorgängeraufgabe. |
| succ_task | Liest oder setzt die Nachfolgeraufgabe. |
| link_type | Liest oder setzt den Typ einer Verknüpfung. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| equals(other) | Gibt einen Wert zurück, der angibt, ob diese Instanz einem angegebenen Objekt gleich ist. |
