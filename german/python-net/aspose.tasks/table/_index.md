## Table class

Stellt eine Tabelle in Project dar

Der Typ Table stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Table() | Initialisiert eine neue Instanz der Klasse [Table](/tasks/python-net/aspose.tasks/table/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| name | Liest oder setzt den Namen eines Table-Objekts. |
| show_in_menu | Liest oder setzt einen Wert, der angibt, ob das Projekt den Tabellennamen in der Dropdown-Liste Tables auf der Registerkarte View des Ribbon anzeigt. |
| table_fields | Liest eine TableFields-Sammlung, die die Felder in der Tabelle darstellt. |
| table_type | Liest oder setzt den Tabellentyp für die angegebene Tabelle. |
| uid | Liest die eindeutige Kennung einer Tabelle. |
| row_height | Liest oder setzt die Zeilenhöhe in einer Tabelle, wobei die Zeilenhöhe die Anzahl der Textzeilen ist. |
| date_format | Liest oder setzt das Datumsformat der Tabelle. |
| adjust_header_row_height | Liest oder setzt einen Wert, der angibt, ob die Zeilenhöhe der Kopfzeile der Tabelle angepasst werden kann. |
| show_add_new_column | Liest oder setzt einen Wert, der angibt, ob die Benutzeroberfläche 'Add New Column' angezeigt werden soll. |
| lock_first_column | Liest oder setzt einen Wert, der angibt, ob die erste Spalte einer Tabelle gesperrt oder bearbeitbar ist. |
