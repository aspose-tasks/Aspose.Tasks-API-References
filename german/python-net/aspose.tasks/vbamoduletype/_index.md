## VbaModuleType enumeration

Gibt den Typ eines Moduls in einem VBA-Projekt an.

## Members
| Membername | Beschreibung |
| :- | :- |
| DOCUMENT_MODULE | Ein Typ von VBA-Projektobjekt, das ein Modul für eingebettete Makros und programmgesteuerte Zugriffsoperationen angibt, die mit einem Dokument verknüpft sind. |
| PROCEDURAL_MODULE | Ein Modul, das eine Sammlung von Subroutinen und Funktionen enthält. |
| CLASS_MODULE | Ein Modul, das die Definition für ein neues Objekt enthält. Jede Instanz einer Klasse erzeugt ein neues Objekt, und die im Modul definierten Prozeduren werden zu Eigenschaften und Methoden des Objekts. |
| DESIGNER_MODULE | Ein Modul, das die Methoden und Eigenschaften eines ActiveX-Steuerelements erweitert, das im Projekt registriert wurde. |
