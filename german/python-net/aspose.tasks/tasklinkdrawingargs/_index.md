## TaskLinkDrawingArgs class

Stellt Argumente für den Rückruf bereit, der aufgerufen wird, wenn ein Aufgabenlink gerendert wird.

Der Typ TaskLinkDrawingArgs stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| link | Ruft den gerenderten Aufgabenlink ab. |
| color | Ruft die zum Rendern des Aufgabenlinks verwendete Farbe ab oder legt sie fest. Kann zur Anpassung der Farben von Aufgabenlinks verwendet werden. |
