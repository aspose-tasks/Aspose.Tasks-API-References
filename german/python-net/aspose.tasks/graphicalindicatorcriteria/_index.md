## GraphicalIndicatorCriteria class

Stellt ein grafisches Indikator-Kriterium dar, das mit einem erweiterten Attribut verknüpft ist.

Der GraphicalIndicatorCriteria-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Initialisiert eine neue Instanz der GraphicalIndicatorCriteria-Klasse |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Initialisiert eine neue Instanz der GraphicalIndicatorCriteria-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| test | Ermittelt den Vergleichstyp, der zwischen dem Wert des erweiterten Attributs und den Werten durchgeführt wird und als Kriterium für die Anwendung des grafischen Indikators dient.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Ermittelt den Wert, der zum Testen des Wertes des erweiterten Attributs verwendet wird. |
| value2 | Ermittelt den zweiten Wert, der zum Testen des Wertes des erweiterten Attributs verwendet wird, falls die Vergleichstypen 'IsWithin' und 'IsNotWithin' vorliegen. |
| image_index | Ermittelt den Index des Bildes, das angezeigt wird, wenn das Feld die Kriterien erfüllt. |
| row_type | Ermittelt den Wert der Aufzählung [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/), die angibt, für welche Zeilen der Indikator angewendet wird. |
