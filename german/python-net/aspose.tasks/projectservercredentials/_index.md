## ProjectServerCredentials class

Anmeldeinformationen, die verwendet werden, um eine Verbindung zu Project Online oder einer lokalen Instanz von Project Server herzustellen.

Der ProjectServerCredentials-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | Initialisiert eine neue Instanz der [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) Klasse unter Verwendung der URL der SharePoint‑Site und eines gültigen SPOIDCRL‑Autorisierungstokens für die PWA (Project Web Access)-Site von SharePoint. |
| ProjectServerCredentials(site_url, user_name, password) | Initialisiert eine neue Instanz der [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) Klasse unter Verwendung der URL der SharePoint‑Site und eines gültigen SPOIDCRL‑Autorisierungstokens für die PWA (Project Web Access)-Site von SharePoint. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| site_url | Erhält die URL von PWA an der SharePoint‑Site oder die URL des lokalen Project Server.<br/>            Zum Beispiel, https://your_company_name.sharepoint.com/sites/pwa\"; |
| auth_token | Ruft das Autorisierungstoken für die SharePoint-Instanz ab. |
| user_name | Ruft den Benutzernamen für die SharePoint-Website ab. |
