## GroupCriterion class

Stellt ein Kriterium in einer Gruppendefinition dar.<br/>            Das GroupCriterion‑Objekt ist Mitglied der [GroupCriterionCollection](/tasks/python-net/aspose.tasks/groupcriterioncollection/)-Sammlung.

Der Typ GroupCriterion stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| GroupCriterion() | Initialisiert eine neue Instanz der Klasse GroupCriterion. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| aufsteigend | Legt einen Wert fest oder ruft ihn ab, der angibt, ob ein Feld, das als Kriterium in einer Gruppendefinition verwendet wird, in aufsteigender Reihenfolge sortiert ist. False, wenn das Feld in absteigender Reihenfolge sortiert ist. |
| cell_color | Legt die Farbe des Zellhintergrunds für ein Feld fest, das als Kriterium in einer Gruppendefinition verwendet wird, oder ruft sie ab. |
| font_color | Legt die Farbe der Schrift für ein Feld fest, das als Kriterium in einer Gruppendefinition verwendet wird, oder ruft sie ab. |
| field | Legt das Feld fest, nach dem gruppiert wird, oder ruft es ab. |
| group_on | Legt den Gruppierungstyp für ein Feld fest, das als Kriterium in einer Gruppendefinition verwendet wird, oder ruft ihn ab. |
| pattern | Legt das Muster der Zelle für ein Feld fest, das als Kriterium in einer Gruppendefinition verwendet wird, oder ruft es ab. |
| start_at | Legt den Beginn der Intervalle für ein Feld fest, das als Kriterium in einer Gruppendefinition verwendet wird, oder ruft ihn ab. |
| group_interval | Legt das Intervall für ein Feld fest, das als Kriterium in einer Gruppendefinition verwendet wird, oder ruft es ab. |
| font | Legt die Schriftart für ein Kriterium in einer Gruppendefinition fest oder ruft sie ab. |
