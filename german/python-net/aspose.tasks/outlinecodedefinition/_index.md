## OutlineCodeDefinition class

Stellt eine Definition eines Gliederungscodes dar.

Der Typ OutlineCodeDefinition stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| OutlineCodeDefinition() | Initialisiert eine neue Instanz der Klasse [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| guid | Ruft den Guid eines Outline-Codes ab oder legt ihn fest. |
| field_id | Ruft die Feldnummer eines Outline-Codes ab oder legt sie fest. |
| field_name | Ruft den Namen eines benutzerdefinierten Outline-Codes ab oder legt ihn fest. |
| alias | Ruft den Alias eines benutzerdefinierten Outline-Codes ab oder legt ihn fest. |
| phonetic_alias | Ruft die phonetische Aussprache des Alias des benutzerdefinierten Outline-Codes ab oder legt sie fest. |
| values | Ruft das OutlineValueCollection-Objekt ab.<br/>            Die Werte der Tabelle, die diesem Outline-Code zugeordnet ist. |
| enterprise | Ruft einen Wert ab oder legt ihn fest, der angibt, ob ein benutzerdefinierter Outline-Code ein Enterprise-Benutzerdefinierter Outline-Code ist. |
| enterprise_outline_code_alias | Ruft eine Referenz auf ein anderes benutzerdefiniertes Feld ab oder legt sie fest, für das diese Outline-Code-Definition ein Alias ist. |
| resource_substitution_enabled | Ruft einen Wert ab oder legt ihn fest, der angibt, ob der benutzerdefinierte Outline-Code<br/>            vom Resource Substitution Wizard in Microsoft Project verwendet werden kann. |
| leaf_only | Liest oder setzt einen Wert, der angibt, ob die in diesem Gliederungscode‑Feld angegebenen Werte Blattwerte sein müssen. |
| all_levels_required | Liest oder setzt einen Wert, der angibt, ob die neuen Codes alle Ebenen haben müssen.<br/>            Nicht verfügbar für Enterprise‑Codes. |
| only_table_values_allowed | Liest oder setzt einen Wert, der angibt, ob die angegebenen Werte aus der Wertetabelle stammen müssen. |
| masks | Liest das OutlineMaskCollection-Objekt.<br/>            Die Tabelle der Einträge, die die Gliederungscode‑Maske definieren.<br/>            Nur‑Lese [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/) Instanz. |
| show_indent | Liest oder setzt einen Wert, der angibt, ob die Einrückungen dieses Gliederungscodes angezeigt werden müssen. |
