## TaskValidationException class

Stellt eine Ausnahme dar, die ausgelöst wird, wenn nach der Neuberechnung Fehler in den Aufgaben des Projekts gefunden werden.

Der TaskValidationException-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| task | Gibt das task zurück, das die Ausnahme verursacht hat. |
