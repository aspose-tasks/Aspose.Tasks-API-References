## FontResolveEventArgs class

Stellt Argumente für den Callback bereit, der aufgerufen wird, wenn die Schriftart aufgelöst wird.

Der Typ FontResolveEventArgs stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| requested_font_name | Liefert den Namen der angeforderten Schriftart. |
| resolved_font_name | Liefert oder setzt den Namen der aufgelösten Schriftart. Kann gesetzt werden, um die zum Rendern einer Ansicht verwendeten Schriftarten zu steuern. |
