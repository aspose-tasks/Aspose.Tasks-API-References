## FilterComparisonType enumeration

Der Typ des Vergleichs zwischen FieldName und Value, der als Auswahlkriterium für einen Filter oder grafischen Indikator dient.

## Members
| Membername | Beschreibung |
| :- | :- |
| EQUALS | Der Wert von Field ist gleich Value. |
| DOES_NOT_EQUAL | Der Wert von Field ist nicht gleich Value. |
| IS_GREATER_THAN | Der Wert von Field ist größer als Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | Der Wert von Field ist größer als oder gleich Value. |
| IS_LESS_THAN | Der Wert von Field ist kleiner als Value. |
| IS_LESS_THAN_OR_EQUAL_TO | Der Wert von Field ist kleiner als oder gleich Value. |
| IS_WITHIN | Der Wert von Field liegt innerhalb Value. |
| IS_NOT_WITHIN | Der Wert von Field liegt nicht innerhalb Value. |
| CONTAINS | Der Wert von Field enthält Value. |
| DOES_NOT_CONTAIN | Der Wert von Field enthält Value nicht. |
| CONTAINS_EXACTLY | Der Wert von Field enthält Value exakt. |
| IS_ONE_OF | Der Wert von Field entspricht einem der angegebenen Values. Wird in AutoFilters verwendet. |
| UNDEFINED | Undefinierter Wert. |
| IS_ANY_VALUE | 'Is any value'-Bedingung. Anwendbar auf grafische Indikatoren. |
