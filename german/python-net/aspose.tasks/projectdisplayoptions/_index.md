## ProjectDisplayOptions class

Stellt die Anzeigeoptionen für eine Projektinstanz dar.

Der Typ ProjectDisplayOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ProjectDisplayOptions() | Initialisiert eine neue Instanz der Klasse [ProjectDisplayOptions](/tasks/python-net/aspose.tasks/projectdisplayoptions/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| add_space_before_label | Ruft den Wert ab oder legt ihn fest, der angibt, ob ein Leerzeichen vor dem Zahlenwert und der Zeitabkürzung eingefügt werden soll (1 wk im Gegensatz zu 1wk). |
| underline_hyperlinks | Ruft den Wert ab oder legt ihn fest, der angibt, ob Hyperlinks unterstrichen werden sollen. |
| show_task_schedule_warnings | Ruft den Wert ab oder legt ihn fest, der angibt, ob Warnungen angezeigt werden sollen, wenn Project einen möglichen Terminplanungskonflikt bei einer manuell geplanten Aufgabe erkennt. |
| show_task_schedule_suggestions | Ruft den Wert ab oder legt ihn fest, der angibt, ob Vorschläge angezeigt werden sollen, wenn Project einen möglichen Terminplanungskonflikt bei einer manuell geplanten Aufgabe erkennt. |
| show_project_summary_task | Liest oder setzt einen Wert, der angibt, ob Zusammenfassungsinformationen über ein gesamtes Projekt in einer einzelnen Zeile mit einer eigenen Zusammenfassungsaufgabenleiste oben in der Gantt-Diagrammansicht angezeigt werden sollen. |
| minute_label | Liest oder setzt, wie das Minute-Label angezeigt wird. |
| hour_label | Liest oder setzt, wie das Stunden-Label angezeigt wird. |
| day_label | Liest oder setzt, wie das Tages-Label angezeigt wird. |
| week_label | Liest oder setzt, wie das Wochen-Label angezeigt wird. |
| month_label | Liest oder setzt, wie das Monats-Label angezeigt wird. |
| year_label | Liest oder setzt, wie das Jahres-Label angezeigt wird. |
