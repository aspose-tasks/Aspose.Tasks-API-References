## LoadOptions class

Ermöglicht das Angeben zusätzlicher Ladeparameter beim Laden eines Projekts aus einer Datei oder einem Stream.

Der Typ LoadOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| LoadOptions() | Initialisiert eine neue Instanz der Klasse [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| password | Ruft ein Schutzkennwort ab oder legt es fest. |
| primavera_read_options | Ruft eine angegebene Instanz der Klasse [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) ab oder legt sie fest, die verwendet werden kann, um das Verhalten beim Laden von Primavera-Formaten (Primavera P6 XER oder Primavera P6 Xml) anzupassen. |
| encoding | Ruft die Kodierung ab, die zum Lesen eines Projekts aus HTML-, MPX-, XER- und Primavera-XML-Formaten verwendet wird, oder legt sie fest.<br/>            Die Standardkodierung ist UTF8. |
