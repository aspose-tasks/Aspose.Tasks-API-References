## UndefinedConstraintHandlingBehavior enumeration

Gibt das Verhalten an, das verwendet wird, um Aufgaben mit undefinierten Einschränkungen zu behandeln.

## Members
| Membername | Beschreibung |
| :- | :- |
| NONE | Das Standardverhalten beim Laden aus dem XER‑Format.<br/>            Es wird keine Aktion durchgeführt. Der Aufgabenkontraintyp wird auf 'ConstraintType.Undefined' gesetzt. |
| SUBSTITUTE_WITH_START_NO_EARLIER_THAN | Constraints mit dem Typ 'ConstraintType.StartNoEarlierThan' und Datum = Start werden für Aufgaben mit dem Constraint 'Undefined' hinzugefügt. |
