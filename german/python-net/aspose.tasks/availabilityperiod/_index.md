## AvailabilityPeriod class

Stellt einen Zeitraum dar, in dem eine Ressource verfügbar ist.

Der Typ AvailabilityPeriod stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| AvailabilityPeriod() | Initialisiert eine neue Instanz von [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | Initialisiert eine neue Instanz von [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) mit dem angegebenen Datumsbereich und den verfügbaren Einheiten. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| available_from | Liest oder setzt das Datum, zu dem eine Ressource für den angegebenen Zeitraum verfügbar wird. |
| available_to | Liest oder setzt das letzte Datum, an dem eine Ressource für den angegebenen Zeitraum verfügbar ist. |
| available_units | Liest oder setzt den Prozentsatz einer Ressource, die während des angegebenen Zeitraums verfügbar ist. |
