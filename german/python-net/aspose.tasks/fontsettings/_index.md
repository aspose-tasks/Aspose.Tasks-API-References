## FontSettings class

Gibt die Schriftarteinstellungen an, die beim Rendern der Projektansicht verwendet werden.

Der FontSettings-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| FontSettings() | Initialisiert eine neue Instanz der FontSettings-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| default_font_name | Liest oder legt die Standard‑ (oder Ersatz‑)Schriftart für das Rendern fest. |
| use_project_default_font | Liest oder legt einen Wert fest, der angibt, ob die Standardschriftart für das Rendern verwendet werden muss. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| set_font_folders(font_folders, recursive) | Legt die Ordner fest, in denen Aspose.Tasks nach TrueType-Schriftarten sucht, wenn die Projektansicht gerendert wird. |
