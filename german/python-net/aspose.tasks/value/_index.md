## Value class

Stellt einen Wert in einer Wertliste dar.

Der Typ Value stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Value() | Initialisiert eine neue Instanz der Klasse [Value](/tasks/python-net/aspose.tasks/value/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| ID | Liest oder setzt den eindeutigen Bezeichner eines Werts projektübergreifend. |
| value_guid | Liest eine GUID, die diesen Wert im gesamten Projekt eindeutig identifiziert. |
| val | Liest oder setzt den tatsächlichen Wert in interner Darstellung. Verwenden Sie vorzugsweise stark typisierte Eigenschaften, die unten aufgeführt sind. |
| string_value | Liest oder setzt den tatsächlichen Wert, der zur Darstellung einer Textzeichenkette verwendet wird. |
| numeric_value | Liest oder setzt den tatsächlichen Wert, der zur Darstellung einer Zahl oder eines Kostenwertes verwendet wird. |
| duration | Liest oder setzt den tatsächlichen Wert, der zur Darstellung einer Dauer verwendet wird. |
| date_time_value | Liest oder setzt den tatsächlichen Wert, wenn er als DateTime dargestellt werden kann. Der Standardwert ist der minimale Datumswert. |
| description | Liest oder setzt die Beschreibung eines Werts. |
| phonetic | Liest oder setzt die phonetischen Informationen zum Namen des benutzerdefinierten Feldes. |
