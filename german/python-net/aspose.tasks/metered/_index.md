## Metered class

Stellt Methoden zum Festlegen des gemessenen Schlüssels bereit.

Der Metered-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Metered() | Initialisiert eine neue Instanz der Metered-Klasse |
## Methoden
| Name | Beschreibung |
| :- | :- |
| set_metered_key(public_key, private_key) | Setzt die metered öffentlichen und privaten Schlüssel. |
| reset_metered_key() | Entfernt die zuvor eingerichtete Lizenz. |
| get_consumption_credit() | Ruft das Verbrauchsguthaben ab. |
| get_consumption_quantity() | Ruft die Dateigröße des Verbrauchs ab. |
| is_licensed() | Prüft, ob das Produkt erfolgreich mit einer Metered-Lizenz lizenziert ist. |
