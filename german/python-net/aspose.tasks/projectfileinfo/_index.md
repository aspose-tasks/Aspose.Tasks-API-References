## ProjectFileInfo class

Die Klasseninstanz enthält Informationen über das Projektdateiformat und die Version von Microsoft Project, in der<br/>            die Datei erstellt wurde.

Der Typ ProjectFileInfo stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| can_read | Liefert einen Wert, der angibt, ob definiert werden kann, dass Aspose.Tasks die Projektdatei verarbeitet. |
| is_password_protected | Gibt einen Wert zurück, der angibt, ob ein Projekt passwortgeschützt ist. |
| project_file_format | Gibt das Projektdateiformat zurück. |
| project_application_info | Gibt die Anwendungsinformationen der Projektdatei zurück. |
## Methoden

| :- | :- |
