## ExtendedAttribute class

Stellt erweiterte Attribute dar.

Der Typ ExtendedAttribute stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| attribute_definition | Ermittelt die Attributdefinition. |
| field_id | Ermittelt die ID eines Feldes. |
| duration_value | Ermittelt oder setzt den Wert für Attribute vom Typ 'Duration'. |
| numeric_value | Ermittelt oder setzt einen Wert für Attribute mit numerischen Typen (Cost, Number). |
| date_value | Ermittelt oder setzt einen Wert für Attribute mit Datumstypen (Date, Start, Finish). |
| flag_value | Liest oder setzt einen Wert, der angibt, ob ein Flag für ein Attribut vom Typ 'Flag' gesetzt ist. |
| text_value | Liest oder setzt einen Wert für Attribute vom Typ 'Text'. |
| value_guid | Liest die GUID eines Lookup-Werts. |
| value_read_only | Liest einen Wert, der angibt, ob ein Wert dieser [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) Instanz schreibgeschützt ist. |
| is_error_value | Liest, ob die Berechnung des Werts des erweiterten Attributs zu einem Fehler geführt hat. |
