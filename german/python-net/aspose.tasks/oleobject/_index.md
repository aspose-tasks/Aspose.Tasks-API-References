## OleObject class

Stellt ein OLE-Objekt dar, das in die Gantt-Diagramm-Ansicht einer MPP-Datei eingefügt werden kann.

Der Typ OleObject stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| OleObject() | Initialisiert eine neue Instanz der Klasse [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| name | Liest oder setzt den Namen der Instanz des OLE-Objekts. |
| application_name | Liest oder setzt den Anwendungsnamen, mit dem das eingebettete Objekt geöffnet wird. |
| file_format | Abrufen oder Festlegen des Dateiformats des eingebetteten Objekts. |
| content | Abrufen oder Festlegen der Daten der eingebetteten Datei; null, wenn keine Daten eingebettet wurden. |
| label | Abrufen oder Festlegen der Bezeichnung des eingefügten Objekts. |
| full_path | Abrufen oder Festlegen des vollständigen Pfads des eingefügten Objekts. |
| temporary_file | Abrufen oder Festlegen des Pfads zur temporären Datei des eingefügten Objekts. |
| display_as_icon | Abrufen oder Festlegen eines Flags, das angibt, dass das OLE-Objekt entweder als Symbol oder als reguläres Bild angezeigt werden soll. |
| linked | Ruft einen Wert ab, der angibt, ob die Projektdatei nur einen Link zu den tatsächlichen, an der Linkquelle gespeicherten Daten enthält. |
| view | Abrufen oder Festlegen der Instanz der [view](/tasks/python-net/aspose.tasks/oleobject/) Klasse, zu der das eingefügte Objekt gehört. |
| ID | Abrufen oder Festlegen der Objekt-ID. |
