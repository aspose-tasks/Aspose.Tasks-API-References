## TaskStatus enumeration

Gibt den Status einer Aufgabe an.

## Members
| Membername | Beschreibung |
| :- | :- |
| UNDEFINED | Undefinierter Aufgabenstatus. |
| ABGESCHLOSSEN | Die Aufgabe ist zu 100 Prozent abgeschlossen. |
| PLANMÄßIG | Die Aufgabe ist planmäßig, wenn der zeitlich gestufte kumulative Prozentsatz der Fertigstellung mindestens bis zum Tag vor dem Stichtag verteilt ist. |
| VERSPÄTET | Die Aufgabe ist verspätet, wenn der zeitlich gestufte kumulative Prozentsatz der Fertigstellung bis Mitternacht am Tag vor dem Stichtag nicht erreicht wird. |
| ZUKUNFT | 'Future'-Aufgabenstatus wird gesetzt, wenn das Startdatum der Aufgabe größer als das Stichtag ist. |
