## ProjectInfo class

Kurzinfo über das veröffentlichte Projekt, das in Project Online verfügbar ist.

Der Typ ProjectInfo stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ProjectInfo() | Initialisiert eine neue Instanz der Klasse [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| ID | Ruft die eindeutige Kennung des Projekts ab. |
| name | Ruft den Namen des Projekts ab. |
| created_date | Ermittelt das Datum und die Uhrzeit, zu der das Projekt erstellt wurde. |
| is_checked_out | Ermittelt einen Wert, der angibt, ob das Projekt ausgecheckt ist. |
| last_published_date | Ermittelt das zuletzt veröffentlichte Datum des Projekts. |
| last_saved_date | Ermittelt das zuletzt gespeicherte Datum des Projekts. |
| description | Ermittelt die Beschreibung des Projekts. |
