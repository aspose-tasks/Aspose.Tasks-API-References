## WeekdayType enumeration

Stellt einen Wochentag eines Projekts in der Instanz der Klasse [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/) dar.

| :- | :- |
| NONE | Gibt den Wochentagstyp Keine an. |
| SUNDAY | Gibt den Wochentagstyp Sonntag an. |
| MONTAG | Gibt den Wochentagstyp Montag an. |
| DIENSTAG | Gibt den Wochentagstyp Dienstag an. |
| MITTWOCH | Gibt den Wochentagstyp Mittwoch an. |
| DONNERSTAG | Gibt den Wochentagstyp Donnerstag an. |
| FREITAG | Gibt den Wochentyp Freitag an. |
