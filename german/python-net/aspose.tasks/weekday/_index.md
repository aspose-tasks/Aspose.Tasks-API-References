## WeekDay class

Stellt einen Wochentag dar, der entweder reguläre Tage einer Woche oder Ausnahme‑Tage in einem Kalender definiert.

Der Typ WeekDay stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| WeekDay(day_type) | Initialisiert eine neue Instanz der [WeekDay](/tasks/python-net/aspose.tasks/weekday/) Klasse mit dem angegebenen Tagtyp. |
| WeekDay(day_type, working_times) | Initialisiert eine neue Instanz der WeekDay-Klasse |
| WeekDay(day_type, working_times) | Initialisiert eine neue Instanz der [WeekDay](/tasks/python-net/aspose.tasks/weekday/) Klasse mit dem angegebenen Tagtyp und den Arbeitszeiträumen. |
| WeekDay() | Initialisiert eine neue Instanz der [WeekDay](/tasks/python-net/aspose.tasks/weekday/) Klasse mit dem angegebenen Tagtyp. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| day_type | Ruft den Typ eines Tages ab. |
| day_working | Liest oder setzt einen Wert, der angibt, ob das angegebene Datum oder der Tagtyp ein Arbeitstag ist. |
| from_date | Liest oder setzt den Beginn einer Ausnahmezeit. |
| to_date | Liest oder setzt das Ende einer Ausnahmezeit. |
| working_times | Liest WorkingTimeCollection für diese WeekDay-Instanz.<br/>            Die Sammlung von Arbeitszeiten, die die an einem Wochentag gearbeitete Zeit definieren. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| create_default_working_day(day_type) | Erstellt einen Standardarbeitstag. |
| set_default_working_time(day) | Setzt Standardzeiträume für den angegebenen Wochentag. |
| get_working_time() | Gibt die Arbeitszeit für einen Wochentag zurück. |
| clone() | Gibt eine tiefe Kopie des Wochentags zurück. |
