## ViewCollection class

Enthält eine Liste von [View](/tasks/python-net/aspose.tasks/view/) Objekten.<br/>            Implementiert die Schnittstelle ICollection<View>.

Der Typ ViewCollection stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| parent_project | Liest das übergeordnete Element des View-Objekts.<br/>            Nur lesbar [Project](/tasks/python-net/aspose.tasks/project/). |
## Methoden
| Name | Beschreibung |
| :- | :- |
| to_list() | Konvertiert eine Ansichtssammlung in eine Liste von [View](/tasks/python-net/aspose.tasks/view/) Objekten. |
| get_by_view_screen(screen) | Durchsucht eine View nach der angegebenen Screen‑Eigenschaft und gibt das erste Vorkommen in der Sammlung zurück. |
| get_by_name(view_name) | Durchsucht eine View nach dem Namen und gibt das erste Vorkommen in der Sammlung zurück. |
