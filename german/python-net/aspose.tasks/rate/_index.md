## Rate class

Stellt eine Definition eines Zeitraums und der für eine Ressource in diesem Zeitraum geltenden Sätze dar.

Der Rate-Typ stellt die folgenden Member bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| rates_from | Liest oder setzt das Datum, an dem ein Tarif wirksam wird. |
| rates_to | Liest oder setzt das letzte Datum, an dem ein Tarif wirksam ist. |
| rate_table | Liest oder setzt die eindeutige Kennung einer Tariftabelle für eine Ressource. |
| standard_rate | Liest oder setzt den Standardtarif pro Stunde für eine Ressource. |
| standard_rate_format | Liest oder setzt die von Microsoft Project verwendeten Einheiten zur Anzeige des Standardtarifs. |
| overtime_rate | Liest oder setzt den Überstundentarif pro Stunde für eine Ressource. |
| overtime_rate_format | Liest oder setzt die von Microsoft Project verwendeten Einheiten zur Anzeige des Überstundentarifs. |
| cost_per_use | Liest oder setzt die Kosten pro Nutzung einer Ressource. Dieser Wert wird vom aktuellen Datum abgerufen, wenn für die Ressource eine Tariftabelle existiert. |
