## PrimaveraTaskProperties class

Stellt Primavera-spezifische Eigenschaften für eine Aufgabe dar, die aus Primavera-Dateien (XER oder P6XML) gelesen wurde.

Der Typ PrimaveraTaskProperties stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| sequence_number | Liest oder setzt die Sequenznummer des WBS-Elements (Zusammenfassungsaufgaben). Sie wird verwendet, um Zusammenfassungsaufgaben in Primavera zu sortieren. |
| activity_id | Liest ein Aktivitäts‑ID‑Feld – die eindeutige Kennung einer Aufgabe, die von Primavera verwendet wird. |
| remaining_early_finish | Liest das verbleibende frühzeitige Enddatum – das Datum, an dem die verbleibende Arbeit für die Aktivität voraussichtlich abgeschlossen sein soll. |
| remaining_early_start | Liest das verbleibende frühzeitige Startdatum – das Datum, an dem die verbleibende Arbeit für die Aktivität voraussichtlich beginnen soll. |
| remaining_late_start | Liest das verbleibende späte Startdatum. |
| remaining_late_finish | Liest das verbleibende späte Enddatum. |
| raw_duration_type | Liest die Rohtextdarstellung (wie in der Quelldatei) des Feldes 'Duration Type' der Aktivität. |
| duration_type | Ermittelt den Wert des Feldes 'Duration Type' der Aktivität. |
| raw_activity_type | Ermittelt die Rohtextdarstellung (wie in der Quelldatei) des Feldes 'Activity Type' der Aktivität. |
| activity_type | Ermittelt den Wert des Feldes 'Activity Type'. |
| percent_complete_type | Ermittelt den Wert des Feldes '% Complete Type' der Aktivität. |
| raw_complete_percent_type | Ermittelt die Rohtextdarstellung (wie in der Quelldatei) des Feldes '% Complete Type' der Aktivität. |
| raw_status | Ermittelt die Rohtextdarstellung (wie in der Quelldatei) des Feldes 'Status' der Aktivität. |
| physical_percent_complete | Ermittelt den Wert von Physical Percent Complete. |
| duration_percent_complete | Ermittelt den Wert von duration percent complete. |
| units_percent_complete | Ermittelt den Wert von units percent complete. |
| actual_labor_units | Ermittelt den Wert von actual labor units. |
| actual_non_labor_units | Ermittelt den Wert von actual non labor units. |
| remaining_labor_units | Ermittelt den Wert von remaining labor units. |
| remaining_non_labor_units | Ermittelt den Wert der verbleibenden Nicht-Arbeitseinheiten. |
| actual_labor_cost | Ermittelt den Wert der tatsächlichen Arbeitskosten . |
| budgeted_labor_cost | Ermittelt den Wert der budgetierten (oder geplanten) Arbeitskosten . |
| actual_nonlabor_cost | Ermittelt den Wert der tatsächlichen Nichtarbeitskosten . |
| budgeted_nonlabor_cost | Ermittelt den Wert der budgetierten (oder geplanten) Nichtarbeitskosten . |
| actual_material_cost | Ermittelt den Wert der tatsächlichen Materialkosten. |
| budgeted_material_cost | Ermittelt den Wert der budgetierten (oder geplanten) Materialkosten. |
| actual_expense_cost | Ermittelt den Wert der tatsächlichen Aufwandskosten. |
| remaining_expense_cost | Ermittelt den Wert der verbleibenden Aufwandskosten. |
| budgeted_expense_cost | Ermittelt den Wert der budgetierten (oder geplanten) Aufwandskosten. |
| actual_total_cost | Ermittelt den Gesamtwert der tatsächlichen Kosten. |
| budgeted_total_cost | Ermittelt den Gesamtwert der budgetierten (oder geplanten) Kosten. |
| primary_constraint_type | Ermittelt einen Typ der primären Einschränkung. |
| primary_constraint_date | Ermittelt das Datum der primären Einschränkung. |
| secondary_constraint_type | Ermittelt einen Typ der sekundären Einschränkung. |
| secondary_constraint_date | Ermittelt das Datum der sekundären Einschränkung. |
| planned_duration | Ermittelt die ursprüngliche oder geplante Dauer – die gesamte Arbeitszeit vom geplanten Startdatum der Aufgabe bis zum geplanten Enddatum. |
