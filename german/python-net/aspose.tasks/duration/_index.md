## Duration class

Stellt die Dauer in einem Projekt dar.

Der Typ Duration stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Duration() | Initialisiert eine neue Instanz der Klasse Duration |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| time_span | Ruft die [time_span](/tasks/python-net/aspose.tasks/duration/) Instanz dieses Duration-Objekts ab. |
| time_unit | Ruft den Zeiteinheitstyp für dieses Objekt ab. |
| is_estimated | Ruft einen Wert ab, der angibt, ob die Zeiteinheit geschätzt ist. |
| is_elapsed | Ruft einen Wert ab, der angibt, ob die Zeiteinheit verstrichen ist. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| add(d) | Fügt die angegebene Dauer zu dieser Dauer hinzu. |
| add(val) | Fügt den angegebenen double-Wert zu dieser Dauer hinzu. |
| subtract(d) | Subtrahiert die angegebene Dauer von dieser Dauerinstanz. |
| subtract(val) | Subtrahiert den angegebenen double-Wert von dieser Dauerinstanz. |
| parse(p, value) | Konvertiert die angegebene Zeichenkette in die Instanz der Struktur [Duration](/tasks/python-net/aspose.tasks/duration/). |
| parse_time_span(value) | Parst die Dauerzeichenkette im Format "PT--H--M--S--". |
| to_double() | Konvertiert das Duration-Objekt in einen Float-Wert. |
| convert(time_unit_type) | Konvertiert das Duration-Objekt in eine andere Dauer mit den angegebenen Zeiteinheiten. |
| equals(other) | Gibt einen Wert zurück, der angibt, ob diese Instanz einem angegebenen Objekt gleich ist. |
