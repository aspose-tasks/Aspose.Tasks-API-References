## TableField class

Stellt ein Feld einer Tabelle in einem Projekt dar.

Der TableField-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TableField() | Initialisiert eine neue Instanz der [TableField](/tasks/python-net/aspose.tasks/tablefield/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| align_data | Liest oder legt die Ausrichtung der Daten in einem Tabellenfeld fest. |
| align_title | Liest oder legt die Ausrichtung des Titels in einem Tabellenfeld fest. |
| field | Liest oder legt den Typ eines Tabellenfelds fest. |
| title | Liest oder legt den Titel des Feldes in einer Tabelle fest. |
| width | Liest oder legt die Breite in Punkten der Feldspalte in einer Tabelle fest. |
| wrap_header | Liest oder legt einen Wert fest, der angibt, ob die Tabellenspaltenüberschrift in mehrere Zeilen umbrochen werden kann oder ob sie abgeschnitten werden soll, wenn sie die Spaltenbreite überschreitet. |
| wrap_text | Liest oder legt einen Wert fest, der angibt, ob der Spaltentext in mehrere Zeilen umbrochen werden kann oder ob er abgeschnitten werden soll, wenn er die Spaltenbreite überschreitet. |
