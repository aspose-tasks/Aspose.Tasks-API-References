## RecurringTaskInfo class

Stellt die Details einer wiederkehrenden Aufgabe in einem Projekt dar.

Der Typ RecurringTaskInfo stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| recurrence_pattern | Liest oder setzt ein Wiederholungsmuster der wiederkehrenden Aufgabe. |
| start_date | Liest oder setzt das Datum, an dem die Vorkommen beginnen. |
| end_date | Erhält oder legt das Datum fest, an dem die Vorkommen enden. |
| duration | Erhält oder legt die Dauer für ein Vorkommen der wiederkehrenden Aufgabe fest. |
| Vorkommen | Erhält oder legt die Anzahl der Vorkommen der wiederkehrenden Aufgabe fest. |
| use_end_date | Erhält oder legt einen Wert fest, der angibt, ob das Enddatum oder eine Anzahl von Vorkommen für die wiederkehrende Aufgabe verwendet werden soll. |
| daily_repetitions | Erhält oder legt die Anzahl der Wiederholungen für das tägliche Wiederholungsmuster fest. |
| daily_use_workdays | Erhält oder legt einen Wert fest, der angibt, ob Arbeitstage für das tägliche Wiederholungsmuster verwendet werden sollen. |
| weekly_repetitions | Erhält oder legt die Anzahl der Wiederholungen für das wöchentliche Wiederholungsmuster fest. |
| weekly_days | Erhält oder legt eine Sammlung von Tagen fest, die im wöchentlichen Wiederholungsmuster verwendet werden. |
| monthly_use_ordinal_day | Erhält oder legt einen Wert fest, der angibt, ob ein ordinaler Tag für das monatliche Wiederholungsmuster verwendet werden soll. |
| monthly_ordinal_number | Erhält oder legt eine ordinale Nummer des monatlichen Wiederholungsmusters fest. |
| monthly_ordinal_repetitions | Erhält oder legt die Anzahl der Wiederholungen für das monatliche Wiederholungsmuster fest, wenn ein ordinaler Tag verwendet wird. |
| monthly_day | Erhält oder legt die Anzahl der Tage des monatlichen Wiederholungsmusters fest. |
| monthly_repetitions | Erhält oder legt die Anzahl der Wiederholungen für das monatliche Wiederholungsmuster fest. |
| yearly_use_ordinal_day | Liest oder setzt einen Wert, der angibt, ob ein Ordinaltag für das jährliche Wiederholungsmuster verwendet wird. |
| yearly_date | Liest oder setzt ein Datum für das jährliche Wiederholungsmuster. |
| yearly_ordinal_number | Liest oder setzt eine Ordinalzahl des jährlichen Wiederholungsmusters. |
| yearly_ordinal_month | Liest oder setzt einen Monat des jährlichen Wiederholungsmusters, wenn ein Ordinaltag verwendet wird. |
| task | Liest die übergeordnete Aufgabe dieser Instanz der Klasse [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
