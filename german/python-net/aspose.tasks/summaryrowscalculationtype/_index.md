## SummaryRowsCalculationType enumeration

Gibt den Typ einer Berechnung des Werts eines benutzerdefinierten Attributs für Zusammenfassungszeilen an.

## Members
| Membername | Beschreibung |
| :- | :- |
| NONE | Bedeutet, dass der Wert des benutzerdefinierten Attributs für Zusammenfassungszeilen nicht berechnet wird. |
| ROLLUP | Bedeutet, dass der Wert des benutzerdefinierten Attributs für Zusammenfassungszeilen mithilfe der Rollup-Funktion berechnet wird, die in [rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/) definiert ist. |
| USE_FORMULA | Bedeutet, dass der Wert des benutzerdefinierten Attributs für Zusammenfassungszeilen mithilfe der in [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/) definierten Formel berechnet wird. |
