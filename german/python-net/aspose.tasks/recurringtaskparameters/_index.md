## RecurringTaskParameters class

Stellt die Menge von Parametern dar, die verwendet werden, um eine wiederkehrende Aufgabe in einem Projekt zu erstellen.

Der Typ RecurringTaskParameters stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| RecurringTaskParameters() | Initialisiert eine neue Instanz der Klasse [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| duration | Erhält oder legt die Dauer für ein Vorkommen der wiederkehrenden Aufgabe fest. |
| ignore_resource_calendar | Liest oder setzt einen Wert, der angibt, ob die wiederkehrende Aufgabe geplant werden soll, selbst wenn sie nicht ausgeführt werden kann, weil keine Ressourcen zur Verfügung stehen. |
| recurrence_pattern | Liest oder legt das Wiederholungsmuster der wiederkehrenden Aufgabe fest. |
| task_name | Liest oder legt den Namen der wiederkehrenden Aufgabe fest. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| set_calendar(project, calendar_name) | Legt einen Kalender für die wiederkehrende Aufgabe fest. Der Kalender wird aus der Projektkalender-Sammlung ausgewählt. |
