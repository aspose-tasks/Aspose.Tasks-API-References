## Baseline class

Stellt Basiswerte einer Ressource dar.

Der Baseline-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Baseline() | Initialisiert eine neue Instanz der Baseline-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| baseline_number | Liest oder setzt die eindeutige Nummer eines Basisdatensatzes. |
| Arbeit | Liest oder setzt die Arbeit, die einer Ressource zugewiesen wird, wenn die Basislinie gespeichert wird. |
| cost | Liest oder setzt die prognostizierten Kosten einer Ressource, wenn die Basislinie gespeichert wird. |
| bcws | Liest oder setzt die Budgetkosten einer für eine Ressource geplanten Arbeit. |
| bcwp | Liest oder setzt die budgetierten Kosten einer von einer Ressource für ein Projekt bis heute ausgeführten Arbeit. |
## Methoden

| :- | :- |
