## ResourceValidationException class

Stellt eine Ausnahme dar, die ausgelöst wird, wenn Fehler in den Eigenschaften einer Ressource gefunden werden.

Der Typ ResourceValidationException stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| resource | Liefert die Ressource, die die Ausnahme verursacht hat. |
