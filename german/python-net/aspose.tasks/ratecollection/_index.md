## RateCollection class

Stellt eine Sammlung dar, die [Rate](/tasks/python-net/aspose.tasks/rate/)‑Objekte enthält.

Der Typ RateCollection stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| count | Ermittelt die Anzahl der im RateCollection enthaltenen Elemente. |
| is_read_only | Ermittelt einen Wert, der angibt, ob diese Sammlung schreibgeschützt ist. |
| parent_resource | Ermittelt das übergeordnete [Resource](/tasks/python-net/aspose.tasks/resource/) Objekt für diese Sammlung. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| add(rates_from) | Fügt dieser Sammlung eine neue [Rate](/tasks/python-net/aspose.tasks/rate/) Instanz hinzu. |
| add(rates_from, type) | Fügt dieser Sammlung eine neue [Rate](/tasks/python-net/aspose.tasks/rate/) Instanz hinzu. |
| to_list() | Konvertiert das [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) Objekt in eine Liste von [Rate](/tasks/python-net/aspose.tasks/rate/) Objekten. |
| to_list(type) | Konvertiert das [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) Objekt in eine Liste von [Rate](/tasks/python-net/aspose.tasks/rate/) Objekten, gefiltert nach dem angegebenen [RateType](/tasks/python-net/aspose.tasks/ratetype/) Typ. |
| remove(item) | Entfernt eine Rate-Instanz aus dieser Sammlung. |
