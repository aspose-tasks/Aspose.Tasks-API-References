## LevelingOrder enumeration

Definiert die möglichen Werte der Leveling‑Reihenfolge.

## Members
| Membername | Beschreibung |
| :- | :- |
| STANDARD | Die folgenden Eigenschaften werden berücksichtigt: Vorgängerbeziehungen, Gesamtslack (eine Aufgabe mit höherem Gesamtslack wird zuerst verzögert), Startdatum, Priorität.<br/>            Dies ist der Standardwert. |
| ID_ONLY | Aufgaben werden in aufsteigender Id-Reihenfolge verzögert. |
| PRIORITY_THEN_STANDARD | Die Priorität wird zuerst berücksichtigt, dann die gleichen Eigenschaften wie in Standard. |
