## LevelingOptions class

Ermöglicht das Angeben von Parametern des Ressourcen‑Levelings.

Der LevelingOptions-Typ stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| LevelingOptions() | Initialisiert eine neue Instanz der [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| start_date | Liest oder setzt das Startdatum des Leveling-Zeitraums. Der Standardwert ist das Startdatum des Projekts. |
| finish_date | Liest oder setzt das Enddatum des Leveling-Zeitraums. Der Standardwert ist das Enddatum des Projekts. |
| resources | Liest oder setzt die Liste der Ressourcen, die ausgeglichen werden sollen. Wenn null gesetzt ist, werden alle Projektressourcen ausgeglichen. |
| leveling_order | Liest die Reihenfolge, in der der Leveling-Algorithmus Aufgaben mit Überbelegungen verzögert.<br/>            Nach der Bestimmung der Aufgaben, die die Überbelegung verursachen, und welcher Aufgaben verzögert werden können, wird die angegebene Reihenfolge verwendet, welche Aufgabe zuerst verzögert werden soll. |
| message_level | Liest oder setzt das Niveau der von Aspose.Tasks während des Ressourcen-Levelings ausgegebenen Protokollnachrichten. |
| message_handler | Liest oder setzt den Callback des Nachrichtenhandlers, der verwendet werden kann, um von Aspose.Tasks während des Ressourcen-Levelings erzeugte Protokollnachrichten abzufangen. |
