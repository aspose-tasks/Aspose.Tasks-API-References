## MspDbSettings class

Ermöglicht das Festlegen notwendiger Optionen zum Lesen von Projektdaten aus der MS Project Server-Datenbank.

Der Typ MspDbSettings stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Initialisiert eine neue Instanz der Klasse [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| connection_string | Liest oder setzt die Verbindungszeichenfolge. |
| provider_invariant_name | Liest oder setzt den Provider‑Invariant‑Namen, der verwendet wird, um eine Instanz der Klasse zu erhalten. |
| project_guid | Liest die GUID des zu lesenden Projekts. |
| schema | Liest oder setzt das Schema des MS Project Server.<br/>            Der Standardwert ist "pub". |
