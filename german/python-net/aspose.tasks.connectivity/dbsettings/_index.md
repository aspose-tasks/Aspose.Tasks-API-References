## DbSettings class

Ermöglicht das Festlegen von Einstellungen zum Lesen aus der Projektdatenbank.

Der DbSettings-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| connection_string | Liest oder setzt die Verbindungszeichenfolge. |
| provider_invariant_name | Liest oder setzt den Provider‑Invariant‑Namen, der verwendet wird, um eine Instanz der Klasse zu erhalten. |
