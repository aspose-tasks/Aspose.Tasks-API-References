## MpdSettings class

Ermöglicht das Festlegen notwendiger Optionen zum Lesen von Projektdaten im MPD-Format (MS Access-Datenbankdateiformat).

Der MpdSettings-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| MpdSettings(connection_string, project_id) | Initialisiert eine neue Instanz der [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| connection_string | Liest oder setzt die Verbindungszeichenfolge. |
| provider_invariant_name | Liest oder setzt den Provider‑Invariant‑Namen, der verwendet wird, um eine Instanz der Klasse zu erhalten. |
| project_id | Ermittelt die ID des zu lesenden Projekts. |
