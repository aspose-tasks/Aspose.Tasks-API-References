## get_RenderLabelOnEachPage {#get_renderlabeloneachpage}

Ermittelt das Flag, das definiert, ob Datumslabels auf jeder Seite gerendert werden sollen, wenn ein Zeitraum über mehrere Seiten hinweg reicht. Wenn der Wert 'true' ist, werden bei einem über mehrere Seiten reichenden Zeitraum die Datumslabels für den Zeitraum auf jeder Seite gerendert. Wenn der Wert 'false' ist, wird das Datumslabel nur einmal gemäß dem Wert der Eigenschaft Alignment gerendert.

**Returns:** bool Aspose::Tasks::Visualization::

```cpp
get_RenderLabelOnEachPage()
```
