## TimescaleTier class

Stellt eine einzelne Ebene der Zeitskala in einem Gantt‑Chart dar.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [TimescaleTier (2 overloads)](./timescaletier/) | Initialisiert eine neue Instanz der TimescaleTier-Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Alignment](./get_alignment/) | Ermittelt, wie Beschriftungen innerhalb jedes Zeitraums der Stufe ausgerichtet werden ( HorizontalStringAlignment ). |
| [get_Count](./get_count/) | Ermittelt das Zeitintervall, in dem Beschriftungen für die Stufe angezeigt werden. Der Standardwert ist 1. |
| [get_DateTimeConverter](./get_datetimeconverter/) | Ermittelt eine Callback-Funktion zur Behandlung der Darstellung von Datums-Ticks in dieser Stufe. |
| [get_Label](./get_label/) | Ermittelt das Datumslabel DateLabel für die Zeitskala-Stufe. |
| [get_RenderLabelOnEachPage](./get_renderlabeloneachpage/) | Ermittelt das Flag, das definiert, ob Datumslabels auf jeder Seite gerendert werden sollen, wenn ein Zeitraum über mehrere Seiten hinweg reicht. Wenn der Wert 'true' ist, werden bei einem über mehrere Seiten reichenden Zeitraum die Datumslabels für den Zeitraum auf jeder Seite gerendert. Wenn der Wert 'false' ist, wird das Datumslabel nur einmal gemäß dem Wert der Eigenschaft Alignment gerendert. |
| [get_ShowTicks](./get_showticks/) | Ermittelt einen Wert, der angibt, ob Trennstriche angezeigt werden sollen, die Zeiträume in der Stufe voneinander trennen. |
