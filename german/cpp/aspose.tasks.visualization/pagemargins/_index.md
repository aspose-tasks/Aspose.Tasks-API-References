## PageMargins class

Stellt Seitenränder für den Druck dar.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Borders](./get_borders/) | Ermittelt eine Position, an der Rahmen gedruckt werden sollen. Kann einer der Werte der Aufzählung Border sein. |
| [get_Bottom](./get_bottom/) | Ermittelt die Größe des unteren Randes in Zentimetern. |
| [get_Left](./get_left/) | Ermittelt die Größe des linken Randes in Zentimetern. |
| [get_Right](./get_right/) | Ermittelt die Größe des rechten Randes in Zentimetern. |
| [get_Top](./get_top/) | Ermittelt die Größe des oberen Randes in Zentimetern. |
| [set_Borders](./set_borders/) | Legt eine Position fest, an der Ränder gedruckt werden sollen. Kann einer der Werte der Border-Aufzählung sein. |
| [set_Bottom](./set_bottom/) | Legt die Größe des unteren Randes in Zentimetern fest. |
| [set_Left](./set_left/) | Legt die Größe des linken Randes in Zentimetern fest. |
| [set_Right](./set_right/) | Legt die Größe des rechten Randes in Zentimetern fest. |
| [set_Top](./set_top/) | Legt die Größe des oberen Randes in Zentimetern fest. |
