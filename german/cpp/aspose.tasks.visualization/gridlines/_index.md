## Gridlines class

Stellt Rasterlinien dar, die in einer GanttChart‑Ansicht erscheinen.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Interval](./get_interval/) | Ruft die Zahl von 0 bis 99 ab, die das Intervall zwischen Rasterlinien angibt. |
| [get_IntervalColor](./get_intervalcolor/) | Ruft die Farbe der sekundären Rasterlinien ab. |
| [get_IntervalPattern](./get_intervalpattern/) | Ruft das Linienmuster für sekundäre Rasterlinien ab. |
| [get_NormalColor](./get_normalcolor/) | Ruft die Farbe der normalen Rasterlinien ab. |
| [get_NormalPattern](./get_normalpattern/) | Ruft das Linienmuster für normale Rasterlinien ab. |
| [get_Type](./get_type/) | Ruft den Rasterlinientyp ab. |
| [set_Interval](./set_interval/) | Setzt die Zahl von 0 bis 99, die das Intervall zwischen Rasterlinien angibt. |
| [set_IntervalColor](./set_intervalcolor/) | Setzt die Farbe der sekundären Rasterlinien. |
| [set_IntervalPattern](./set_intervalpattern/) | Setzt das Linienmuster für sekundäre Rasterlinien. |
| [set_NormalColor](./set_normalcolor/) | Setzt die Farbe der normalen Rasterlinien. |
| [set_NormalPattern](./set_normalpattern/) | Setzt das Linienmuster für normale Rasterlinien. |
| [set_Type](./set_type/) | Setzt den Rasterlinientyp. |
