## ITextStyleModificationCallback class

Stellt einen Rückruf dar, der aufgerufen wird, bevor TextStyle auf eine Tabellenzelle angewendet wird.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [BeforeTaskTextStyleApplied](./beforetasktextstyleapplied/) | Die Methode, die vor dem Rendern einer Tabellenzelle für eine Aufgabenzeile in den folgenden Ansichten aufgerufen wird: 'Gantt Chart', ' Task Sheet', ' Task Usage'. |
