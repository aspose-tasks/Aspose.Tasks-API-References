## PageViewSettings class

| Name | Beschreibung |

| [get_PrintAllSheetColumns](./get_printallsheetcolumns/) | Ermittelt einen Wert, der angibt, ob alle Blattspalten einer Ansicht gedruckt werden sollen. |
| [get_PrintBlankPages](./get_printblankpages/) | Ermittelt einen Wert, der angibt, ob leere Seiten einer Ansicht gedruckt werden sollen. |
| [get_PrintFirstColumnsCountOnAllPages](./get_printfirstcolumnscountonallpages/) | Ermittelt einen Wert, der angibt, ob eine festgelegte Anzahl der ersten Spalten auf allen Seiten gedruckt werden soll. |
