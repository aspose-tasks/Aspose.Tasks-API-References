## TaskTextStyleEventArgs class

Diese Klasse stellt einen Datensatz dar, der sich auf das Rendern des Inhalts einer Tabellenzelle bezieht.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | Liefert TextStyle, das zum Zeichnen des Zellinhalts verwendet wird. Dieses Objekt kann zur Anpassung des Aussehens einer Tabellenzelle verwendet werden. |
| [get_Column](./get_column/) | Liefert ViewColumn, zu dem die aktuell gerenderte Zelle gehört. |
| [get_Task](./get_task/) | Liefert Task, der der aktuell gerenderten Zeile entspricht. |
| [set_CellTextStyle](./set_celltextstyle/) | Setzt TextStyle, das zum Zeichnen des Zellinhalts verwendet wird. Dieses Objekt kann zur Anpassung des Aussehens einer Tabellenzelle verwendet werden. |
