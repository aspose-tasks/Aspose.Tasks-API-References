## PageInfo class

Stellt Seiteneinrichtungsdaten dar, die im MPP-Dateiformat vorhanden sind und zum Drucken verwendet werden.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [PageInfo](./pageinfo/) | Initialisiert eine neue Instanz der PageInfo Klasse. Stellt Seiteneinrichtungsdaten dar, die im MPP-Dateiformat vorhanden sind und zum Drucken verwendet werden. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Footer](./get_footer/) | Gibt eine Instanz der HeaderFooterInfo Klasse zurück, die Fußzeilendaten darstellt. |
| [get_Header](./get_header/) | Gibt die Instanz der HeaderFooterInfo Klasse zurück, die Kopfdaten darstellt. |
| [get_Legend](./get_legend/) | Gibt eine Instanz der PageLegend Klasse zurück, die Rendering-Optionen der Seitenlegende festlegt. |
| [get_Margins](./get_margins/) | Gibt eine Instanz der PageMargins Klasse zurück, die Seitenränder festlegt. |
| [get_Name](./get_name/) | Gibt den Namen der Ansicht zurück, für die Einrichtungsdaten verwendet werden. |
| [get_PageSettings](./get_pagesettings/) | Gibt eine Instanz der PageSettings Klasse zurück, die Druckeinstellungen der Seite festlegt. |
| [get_PageViewSettings](./get_pageviewsettings/) | Gibt eine Instanz der PageViewSettings Klasse zurück, die Druckeinstellungen der Seitenansicht festlegt. |
| [set_Footer](./set_footer/) | Legt eine Instanz der HeaderFooterInfo Klasse fest, die Fußzeilendaten darstellt. |
| [set_Header](./set_header/) | Legt die Instanz der HeaderFooterInfo Klasse fest, die Kopfdaten darstellt. |
| [set_Legend](./set_legend/) | Legt eine Instanz der PageLegend Klasse fest, die Rendering-Optionen der Seitenlegende festlegt. |
