## PageLegend class

**Inherits:** Aspose::Tasks::Visualization::HeaderFooterInfo

Stellt eine Seitenlegende dar, die für den Projekt‑Druck verwendet wird.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_LegendOn](./get_legendon/) | Ermittelt die Seiten, auf denen die Legende erscheint. Kann einer der Werte der Legend‑Aufzählung sein. |
| [get_Width](./get_width/) | Ermittelt die Breite des linken Teils (standardmäßig enthält er den Projektnamen und das Datum) der Legende in Zentimetern. |
| [set_LegendOn](./set_legendon/) | Legt die Seiten fest, auf denen die Legende erscheint. Kann einer der Werte der Legend‑Aufzählung sein. |
| [set_Width](./set_width/) | Legt die Breite des linken Teils (standardmäßig enthält er den Projektnamen und das Datum) der Legende in Zentimetern fest. |
