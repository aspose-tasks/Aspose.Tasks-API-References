## PageSettings class

Stellt Druckeinstellungen für eine Seite der Projektansicht dar.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [PageSettings](./pagesettings/) | Initialisiert eine neue Instanz der Klasse PageSettings. Stellt Druckeinstellungen für eine Seite der Projektansicht dar. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | Ruft einen Wert ab, der angibt, ob der Druck auf den angegebenen Prozentsatz ( PercentOfNormalSize ) der Normalgröße angepasst werden soll. |
| [get_FirstPageNumber](./get_firstpagenumber/) | Liefert eine erste Seitennummer für den Druck. |
| [get_IsPortrait](./get_isportrait/) | Gibt einen Wert zurück, der angibt, ob die Seitenausrichtung Hochformat ist; gibt false zurück, wenn die Seitenausrichtung Querformat ist. |
| [get_PagesInHeight](./get_pagesinheight/) | Liefert die Anzahl der Seiten in der Höhe, die gedruckt werden sollen. |
| [get_PagesInWidth](./get_pagesinwidth/) | Liefert die Anzahl der Seiten in der Breite, die gedruckt werden sollen. |
| [get_PaperSize](./get_papersize/) | Liefert eine Papiergröße. Kann einer der Werte der Aufzählung PrinterPaperSize sein. |
| [get_PaperSizeId](./get_papersizeid/) | Liefert einen Integer, der einen der Werte von PrinterPaperSize oder eine benutzerdefinierte Seitengrößen-ID darstellt. Dieser Wert kann verwendet werden, um PaperSize aus den OS-Einstellungen zu erhalten. |
| [get_PercentOfNormalSize](./get_percentofnormalsize/) | Liefert einen Prozentsatz der Normalgröße, auf die der Druck angepasst werden soll. |
| [set_AdjustToPercentOfNormalSize](./set_adjusttopercentofnormalsize/) | Setzt einen Wert, der angibt, ob der Druck auf den angegebenen Prozentsatz ( PercentOfNormalSize ) der Normalgröße angepasst werden soll. |
| [set_FirstPageNumber](./set_firstpagenumber/) | Setzt eine erste Seitennummer für den Druck. |
| [set_IsPortrait](./set_isportrait/) | Legt einen Wert fest, der angibt, ob die Seitenausrichtung Hochformat ist; gibt false zurück, wenn die Seitenausrichtung Querformat ist. |
| [set_PagesInHeight](./set_pagesinheight/) | Setzt die Anzahl der Seiten in der Höhe, die gedruckt werden sollen. |
| [set_PagesInWidth](./set_pagesinwidth/) | Setzt die Anzahl der Seiten in der Breite, die gedruckt werden sollen. |
| [set_PaperSize](./set_papersize/) | Setzt eine Papiergröße. Kann einer der Werte der Aufzählung PrinterPaperSize sein. |
| [set_PaperSizeId](./set_papersizeid/) | Setzt einen Integer, der einen der Werte von PrinterPaperSize oder eine benutzerdefinierte Seitengrößen-ID darstellt. Dieser Wert kann verwendet werden, um PaperSize aus den OS-Einstellungen zu erhalten. |
| [set_PercentOfNormalSize](./set_percentofnormalsize/) | Setzt einen Prozentsatz der Normalgröße, auf die der Druck angepasst werden soll. |
