## TaskUtils class

Hilfsklasse, die nützliche Operationen mit Aufgaben bereitstellt.

## Methoden

| --- | --- |
| [Apply](./apply/) | Wendet den angegebenen Algorithmus auf jede Aufgabe eines Baums an. |

| [TaskChildrenCount](./taskchildrencount/) | Berechnet rekursiv die Anzahl der Unteraufgaben einer Aufgabe über alle Ebenen hinweg. |
