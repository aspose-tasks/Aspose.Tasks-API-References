## Find {#find}

Findet das erste Vorkommen eines Listenelements, das die angegebene Bedingung erfüllt.

**Returns:** List element or null.

```cpp
Find(const System::SharedPtr< System::Collections::Generic::IList< T >> & list, const System::SharedPtr< ICondition < T >> & cond)
```

| Parameter | Beschreibung |
| --- | --- |
| Liste | Eine Liste zum Verarbeiten. |
| cond | Bedingung, die zum Finden eines Elements in der angegebenen Liste verwendet wird. |
