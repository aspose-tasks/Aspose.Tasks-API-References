## Spreadsheet2003SaveOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Ermöglicht das Angeben zusätzlicher Optionen beim Rendern von Projektseiten nach Spreadsheet2003.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [Spreadsheet2003SaveOptions](./spreadsheet2003saveoptions/) | Initialisiert eine neue Instanz der Spreadsheet2003SaveOptions Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Ermittelt eine Liste der Ansichtsspalten für Zuweisungen, die gerendert werden sollen ( AssignmentViewColumn ). |
| [get_ResourceView](./get_resourceview/) | Ermittelt eine Liste der Ansichtsspalten für Ressourcen, die gerendert werden sollen ( ResourceViewColumn ). |
| [get_View](./get_view/) | Ermittelt eine Liste der Ansichtsspalten ( GanttChartColumn ), die gespeichert werden sollen. Wenn nicht festgelegt, werden Standardspalten gespeichert. |
| [set_AssignmentView](./set_assignmentview/) | Legt eine Liste der Ansichtsspalten für Zuweisungen fest, die gerendert werden sollen ( AssignmentViewColumn ). |
| [set_ResourceView](./set_resourceview/) | Legt eine Liste der Ansichtsspalten für Ressourcen fest, die gerendert werden sollen ( ResourceViewColumn ). |
| [set_View](./set_view/) | Legt eine Liste der Ansichtsspalten ( GanttChartColumn ) fest, die gespeichert werden sollen. Wenn nicht festgelegt, werden Standardspalten gespeichert. |
