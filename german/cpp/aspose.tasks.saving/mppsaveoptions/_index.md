## MPPSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Ermöglicht das Angeben zusätzlicher Optionen beim Speichern von Projektdaten im MPP‑Format.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [MPPSaveOptions](./mppsaveoptions/) | Initialisiert eine neue Instanz der MPPSaveOptions Klasse. |
