## PageSavingArgs class

Diese Klasse stellt einen Datensatz dar, der sich auf das Speichern einer Dokumentenseite in einen Stream bezieht.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Ermittelt einen Wert, der angibt, ob die Rendering‑Routine den Stream nach dem Schreiben einer Seite geöffnet lassen soll. |
| [get_PageNumber](./get_pagenumber/) | Ermittelt die Nummer der zu schreibenden Seite. |
| [get_Stream](./get_stream/) | Ermittelt einen Stream zum Schreiben einer Seite. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Legt einen Wert fest, der angibt, ob die Rendering‑Routine den Stream nach dem Schreiben einer Seite geöffnet lassen soll. |
| [set_Stream](./set_stream/) | Legt einen Stream zum Schreiben einer Seite fest. |
