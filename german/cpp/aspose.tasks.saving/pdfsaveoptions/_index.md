## PdfSaveOptions class

**Inherits:** Aspose::Tasks::Saving::SaveOptions

Ermöglicht das Angeben zusätzlicher Optionen beim Rendern von Projektseiten zu PDF.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [PdfSaveOptions](./pdfsaveoptions/) | Initialisiert eine neue Instanz der PdfSaveOptions‑Klasse, die zum Speichern eines Dokuments im PDF‑Format verwendet werden kann. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Compliance](./get_compliance/) | Gibt das gewünschte Konformitätsniveau für das erzeugte PDF‑Dokument zurück. Standard ist PdfCompliance::Pdf15. |
| [get_DigitalSignatureDetails](./get_digitalsignaturedetails/) | Gibt die Details der digitalen Signatur zurück. Wenn nicht festgelegt, wird keine Signatur durchgeführt. |
| [get_EncryptionDetails](./get_encryptiondetails/) | Gibt die Verschlüsselungsdetails zurück. Wenn nicht festgelegt, wird keine Verschlüsselung durchgeführt. |
| [get_FontSettings](./get_fontsettings/) | Gibt die Schriftarteinstellungen an, die beim Rendern der Projektansicht verwendet werden. |
| [get_Pages](./get_pages/) | Gibt die Liste der Seitenzahlen zurück, die beim Speichern des Projektlayouts in separate Dateien gespeichert werden sollen. |
| [get_PageSavingCallback](./get_pagesavingcallback/) | Gibt einen benutzerdefinierten Callback zurück, der verwendet wird, um für jede gerenderte Seite einen Ausgabestream zu erhalten. Gilt, wenn die Option SaveToSeparateFiles verwendet wird. |
| [get_ReduceFooterGap](./get_reducefootergap/) | Liest einen Wert, der angibt, ob ein Abstand zwischen der letzten Aufgabe und der Fußzeile reduziert werden muss. |
| [get_SaveToSeparateFiles](./get_savetoseparatefiles/) | Gibt einen Wert zurück, der angibt, ob Projektseiten in separate Dateien gespeichert werden sollen. |
| [get_TextCompression](./get_textcompression/) | Gibt den Kompressionstyp zurück, der für alle Inhaltsstreams außer Bildern verwendet werden soll. Standard ist PdfTextCompression::Flate. |
| [set_Compliance](./set_compliance/) | Setzt das gewünschte Konformitätsniveau für das erzeugte PDF‑Dokument. Standard ist PdfCompliance::Pdf15. |
| [set_DigitalSignatureDetails](./set_digitalsignaturedetails/) | Setzt die Details der digitalen Signatur. Wenn nicht festgelegt, wird keine Signatur durchgeführt. |
| [set_EncryptionDetails](./set_encryptiondetails/) | Setzt die Verschlüsselungsdetails. Wenn nicht festgelegt, wird keine Verschlüsselung durchgeführt. |
| [set_Pages](./set_pages/) | Setzt die Liste der Seitenzahlen, die beim Speichern des Projektlayouts in separate Dateien gespeichert werden sollen. |
| [set_PageSavingCallback](./set_pagesavingcallback/) | Legt einen benutzerdefinierten Callback fest, der verwendet wird, um für jede gerenderte Seite einen Ausgabestream zu erhalten. Gilt, wenn die Option SaveToSeparateFiles verwendet wird. |
| [set_ReduceFooterGap](./set_reducefootergap/) | Legt einen Wert fest, der angibt, ob ein Abstand zwischen der letzten Aufgabe und der Fußzeile verringert werden muss. |
| [set_SaveToSeparateFiles](./set_savetoseparatefiles/) | Legt einen Wert fest, der angibt, ob Projektseiten in separate Dateien gespeichert werden sollen. |
| [set_TextCompression](./set_textcompression/) | Legt einen Kompressionstyp fest, der für alle Inhaltsstreams außer Bildern verwendet wird. Standard ist PdfTextCompression::Flate. |
