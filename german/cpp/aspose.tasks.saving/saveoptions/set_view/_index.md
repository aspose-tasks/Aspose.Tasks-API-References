## set_View {#set_view}

Legt eine Liste der anzuzeigenden Ansichtsspalten fest ( GanttChartColumn ). Wenn nicht festgelegt, werden nur Aufgaben‑IDs, Aufgabennamen, Start und Ende gerendert. Wenn sowohl die Eigenschaften View als auch ViewSettings festgelegt sind, überschreiben die Spalten aus View die Spalten aus ViewSettings.
