## set_FitTimescaleToEndOfPage {#set_fittimescaletoendofpage}

Legt fest, ob ein Kalenderabschnitt einer Ansicht bis zum Ende (rechte Seite) der letzten Seite gerendert werden soll. Wenn der Wert false ist, wird der Kalenderabschnitt exakt bis zum Enddatum gerendert, selbst wenn auf einer Seite ein leerer Raum verbleibt.
