## get_RenderToSinglePage {#get_rendertosinglepage}

Gibt einen Wert zurück, der angibt, ob ein Projekt in einer einzelnen Seite gerendert werden soll, wenn das Projekt im grafischen Format gespeichert wird. Die Seitengröße wird geändert, damit das gerenderte Projekt auf eine Seite passt.

**Returns:** bool Aspose::Tasks::Saving::

get_RenderToSinglePage()
