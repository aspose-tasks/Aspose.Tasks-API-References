## set_RenderToSinglePage {#set_rendertosinglepage}

Legt einen Wert fest, der angibt, ob ein Projekt in einer einzelnen Seite gerendert werden soll, wenn das Projekt im grafischen Format gespeichert wird. Die Seitengröße wird angepasst, sodass das gerenderte Projekt auf eine Seite passt.
