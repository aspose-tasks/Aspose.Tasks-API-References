## IPageSavingCallback class

Stellt einen Rückruf dar, der aufgerufen wird, wenn jede Seite in einem mehrseitigen Dokument in einen separaten Stream gespeichert wird.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [OnFinish](./onfinish/) | Methode, die aufgerufen wird, wenn alle Seiten geschrieben wurden. |
| [PageSaving](./pagesaving/) | Die Methode, die aufgerufen wird, wenn eine Seite in einen Stream gespeichert wird. |
