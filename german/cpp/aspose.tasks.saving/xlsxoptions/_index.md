## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Ermöglicht das Angeben zusätzlicher Optionen beim Rendern von Projektseiten zu XLSX.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Initialisiert eine neue Instanz der XlsxOptions Klasse, die zum Speichern des Projekts im XLSX-Format verwendet werden kann. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Ermittelt eine Liste der Ansichtsspalten für Zuweisungen, die gerendert werden sollen ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | Liest die Kodierung der resultierenden XLSX-Datei. Der Standardwert ist System::Text::Encoding::UTF8. |
| [get_ResourceView](./get_resourceview/) | Ermittelt eine Liste der Ansichtsspalten für Ressourcen, die gerendert werden sollen ( ResourceViewColumn ). |
| [get_View](./get_view/) | Ruft eine Liste der Ansichtsspalten ( GanttChartColumn ) ab, die im XLSX-Format gespeichert werden sollen. Wenn nicht festgelegt, werden die Standardspalten gespeichert. |
| [set_AssignmentView](./set_assignmentview/) | Legt eine Liste der Ansichtsspalten für Zuweisungen fest, die gerendert werden sollen ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | Legt die Kodierung der resultierenden XLSX-Datei fest. Der Standardwert ist System::Text::Encoding::UTF8. |
| [set_ResourceView](./set_resourceview/) | Legt eine Liste der Ansichtsspalten für Ressourcen fest, die gerendert werden sollen ( ResourceViewColumn ). |
| [set_View](./set_view/) | Setzt eine Liste der Ansichtsspalten ( GanttChartColumn ), die im XLSX-Format gespeichert werden sollen. Wenn nicht festgelegt, werden die Standardspalten gespeichert. |
