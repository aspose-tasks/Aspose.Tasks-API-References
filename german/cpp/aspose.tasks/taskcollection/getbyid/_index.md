## GetById {#getbyid}

Gibt eine Aufgabe mit der angegebenen Id zurück, deren Vorgänger die übergeordnete Aufgabe dieser Sammlung ist.

**Returns:** returns the instance of Task class with the specified id whose ancestor is parent task of this collection.

```cpp
GetById(int32_t id)
```
