## GetByUid {#getbyuid}

Gibt eine Aufgabe mit der angegebenen Uid zurück, deren Vorgänger die übergeordnete Aufgabe dieser Sammlung ist.

**Returns:** returns the instance of Task class with the specified uid whose ancestor is parent task of this collection.

```cpp
GetByUid(int32_t uid)
```

| Parameter | Beschreibung |
| --- | --- |
| uid | TaskEntity Uid. |
