## OleObjectCollection class

Stellt eine Sammlung dar, die die Instanzen der OleObject-Klasse enthält.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [Clear](./clear/) | Leert die Sammlung. Um diese Änderungen zu speichern, sollte project.Save mit neuen MPPSaveOptions { WriteViewData = true; } aufgerufen werden. |
| [GetEnumerator](./getenumerator/) | Gibt einen Enumerator für diese Sammlung zurück. |
| [ToList](./tolist/) | Konvertiert die Instanz der OleObjectCollection‑Klasse in eine Liste, die die Instanzen der OleObject‑Klasse enthält. |
