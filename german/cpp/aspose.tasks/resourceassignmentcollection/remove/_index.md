## Remove {#remove}

Entfernt die angegebene Zuordnung aus der Sammlung, sofern sie nicht schreibgeschützt ist, andernfalls wird NotSupportedException ausgelöst.

**Returns:** true, if specified item was removed, false otherwise.

```cpp
Remove(const System::SharedPtr< ResourceAssignment > & item)
```

| Parameter | Beschreibung |
| --- | --- |
| Element | Die zu entfernende Zuweisung. |
