## get_CriticalPath {#get_criticalpath}

Gibt eine Sammlung zurück, die eine Liste kritischer Aufgaben enthält, die den kritischen Pfad dieses Projekts bilden.

**Returns:** a collection which represents a list of all critical tasks.

```cpp
get_CriticalPath()
```
