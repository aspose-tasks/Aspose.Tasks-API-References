## CheckException {#checkexception}

Gibt true zurück, wenn die angegebene Instanz des DateTime-Structs der Ausnahme‑Tag ist.

**Returns:** Returns true if DateTime value is the exception day; otherwise, false.

```cpp
CheckException(System::DateTime dt)
```

| Parameter | Beschreibung |
| --- | --- |
| dt | die angegebene Instanz der DateTime-Struktur. |
