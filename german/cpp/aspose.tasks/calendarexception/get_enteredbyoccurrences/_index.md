## get_EnteredByOccurrences {#get_enteredbyoccurrences}

Liefert einen Wert, der angibt, ob der Wiederholungsbereich durch Angabe einer Anzahl von Wiederholungen definiert ist. False bedeutet, dass der Wiederholungsbereich durch Angabe eines Enddatums definiert wird.

**Returns:** bool Aspose::Tasks::

```cpp
get_EnteredByOccurrences()
```
