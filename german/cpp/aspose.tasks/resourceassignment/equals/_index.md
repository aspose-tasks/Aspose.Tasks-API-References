## Equals (1 of 2) {#equals_1}

Gibt einen Wert zurück, der angibt, ob diese Instanz gleich einer angegebenen Instanz der ResourceAssignment‑Klasse ist.

**Returns:** True if the specified instance of the ResourceAssignment class has the same UID value as this instance; otherwise, false .

```cpp
Equals(System::SharedPtr< ResourceAssignment > other)
```

| Parameter | Beschreibung |
| --- | --- |
| andere | Die angegebene Instanz der ResourceAssignment-Klasse, die mit dieser Instanz verglichen wird. |

## Equals (2 of 2) {#equals_2}
