## LoadOptions class

Ermöglicht das Angeben zusätzlicher Ladeparameter beim Laden eines Projekts aus einer Datei oder einem Stream.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [LoadOptions](./loadoptions/) | Initialisiert eine neue Instanz der LoadOptions-Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Encoding](./get_encoding/) | Liefert die Codierung, die zum Lesen eines Projekts aus HTML-, MPX-, XER- und Primavera-XML-Formaten verwendet wird. Die Standardcodierung ist UTF8. |
| [get_ErrorHandler](./get_errorhandler/) | Liefert eine Callback-Methode zur Behandlung von XML-Parsing-Fehlern. |
| [get_Password](./get_password/) | Liefert ein Schutzkennwort. |
| [get_PrimaveraReadOptions](./get_primaverareadoptions/) | Liefert eine angegebene Instanz der Tasks::PrimaveraReadOptions-Klasse, die verwendet werden kann, um das Verhalten beim Laden von Primavera-Formaten (Primavera P6 XER oder Primavera P6 Xml) anzupassen. |
| [set_Encoding](./set_encoding/) | Setzt die Codierung, die zum Lesen eines Projekts aus HTML-, MPX-, XER- und Primavera-XML-Formaten verwendet wird. Die Standardcodierung ist UTF8. |
| [set_ErrorHandler](./set_errorhandler/) | Setzt eine Callback-Methode zur Behandlung von XML-Parsing-Fehlern. |
| [set_Password](./set_password/) | Setzt ein Schutzkennwort. |
| [set_PrimaveraReadOptions](./set_primaverareadoptions/) | Setzt eine angegebene Instanz der Tasks::PrimaveraReadOptions-Klasse, die verwendet werden kann, um das Verhalten beim Laden von Primavera-Formaten (Primavera P6 XER oder Primavera P6 Xml) anzupassen. |
