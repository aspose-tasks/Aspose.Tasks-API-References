## ProjectDisplayOptions class

Stellt die Anzeigeoptionen für eine Projektinstanz dar.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [ProjectDisplayOptions](./projectdisplayoptions/) | Initialisiert eine neue Instanz der ProjectDisplayOptions‑Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_AddSpaceBeforeLabel](./get_addspacebeforelabel/) | Liefert einen Wert, der angibt, ob vor dem Zahlenwert und der Zeitabkürzung ein Leerzeichen eingefügt werden soll (1 wk im Gegensatz zu 1wk). |
| [get_DayLabel](./get_daylabel/) | Liefert, wie das Tageslabel angezeigt wird. |
| [get_HourLabel](./get_hourlabel/) | Liefert, wie das Stundenlabel angezeigt wird. |
| [get_MinuteLabel](./get_minutelabel/) | Ermittelt, wie das Minuten‑Label angezeigt wird. |

| [get_ShowTaskScheduleSuggestions](./get_showtaskschedulesuggestions/) | Ermittelt einen Wert, der angibt, ob Vorschläge angezeigt werden sollen, wenn Project einen möglichen Termin­konflikt mit einer manuell geplanten Aufgabe erkennt. |
