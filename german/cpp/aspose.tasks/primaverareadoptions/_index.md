## PrimaveraReadOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Lesen von Primavera-Xml- oder Primavera-Xer-Dateien.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [PrimaveraReadOptions](./primaverareadoptions/) | Initialisiert eine neue Instanz der Klasse PrimaveraReadOptions. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_PreserveUids](./get_preserveuids/) | Ermittelt ein Flag, das angibt, ob ursprüngliche eindeutige Kennungen von Entitäten beibehalten werden sollen. |
| [get_ProjectUid](./get_projectuid/) | Ermittelt die UID eines Projekts, das aus einer Datei mit mehreren Projekten gelesen werden soll. |
| [get_ReadBaselineProjects](./get_readbaselineprojects/) | Ermittelt ein Flag, das angibt, ob Basislinienprojekte geladen werden sollen. Der Standardwert ist true. |
| [get_UndefinedConstraintHandlingBehavior](./get_undefinedconstrainthandlingbehavior/) | Gibt das Verhalten an, das zur Verarbeitung von Aufgaben mit undefinierten Einschränkungen aus dem XER-Format verwendet wird. |
| [set_PreserveUids](./set_preserveuids/) | Setzt ein Flag, das angibt, ob ursprüngliche eindeutige Kennungen von Entitäten beibehalten werden sollen. |
| [set_ProjectUid](./set_projectuid/) | Setzt die UID eines Projekts, das aus einer Datei mit mehreren Projekten gelesen werden soll. |
| [set_ReadBaselineProjects](./set_readbaselineprojects/) | Setzt ein Flag, das angibt, ob Basislinienprojekte geladen werden sollen. Der Standardwert ist true. |
| [set_UndefinedConstraintHandlingBehavior](./set_undefinedconstrainthandlingbehavior/) | Gibt das Verhalten an, das zur Verarbeitung von Aufgaben mit undefinierten Einschränkungen aus dem XER-Format verwendet wird. |
