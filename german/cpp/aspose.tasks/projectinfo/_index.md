## ProjectInfo class

Kurze Informationen über das veröffentlichte Projekt, das in Project Online verfügbar ist.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [ProjectInfo](./projectinfo/) | Initialisiert eine neue Instanz der Klasse ProjectInfo. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_CreatedDate](./get_createddate/) | Liefert das Datum und die Uhrzeit, zu der das Projekt erstellt wurde. |
| [get_Description](./get_description/) | Liefert die Beschreibung des Projekts. |
| [get_Id](./get_id/) | Liefert die eindeutige Kennung des Projekts. |
| [get_IsCheckedOut](./get_ischeckedout/) | Liefert einen Wert, der angibt, ob das Projekt ausgecheckt ist. |
| [get_LastPublishedDate](./get_lastpublisheddate/) | Liefert das zuletzt veröffentlichte Datum des Projekts. |
| [get_LastSavedDate](./get_lastsaveddate/) | Liefert das zuletzt gespeicherte Datum des Projekts. |
| [get_Name](./get_name/) | Liefert den Namen des Projekts. |
