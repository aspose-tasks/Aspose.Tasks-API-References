## OutlineCodeDefinition class

Stellt eine Gliederungscode-Definition dar.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [OutlineCodeDefinition](./outlinecodedefinition/) | Initialisiert eine neue Instanz der OutlineCodeDefinition Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Alias](./get_alias/) | Liefert den Alias eines benutzerdefinierten Gliederungscodes. |
| [get_AllLevelsRequired](./get_alllevelsrequired/) | Liefert einen Wert, der angibt, ob die neuen Codes alle Ebenen haben müssen. Nicht verfügbar für Enterprise-Codes. |
| [get_Enterprise](./get_enterprise/) | Liefert einen Wert, der angibt, ob ein benutzerdefinierter Gliederungscode ein Enterprise‑benutzerdefinierter Gliederungscode ist. |
| [get_EnterpriseOutlineCodeAlias](./get_enterpriseoutlinecodealias/) | Liefert eine Referenz zu einem anderen benutzerdefinierten Feld, für das diese Gliederungscode‑Definition ein Alias ist. |
| [get_FieldId](./get_fieldid/) | Liefert die Feldnummer eines Gliederungscodes. |
| [get_FieldName](./get_fieldname/) | Liefert den Namen eines benutzerdefinierten Gliederungscodes. |
| [get_Guid](./get_guid/) | Liefert die GUID eines Gliederungscodes. |
| [get_LeafOnly](./get_leafonly/) | Liefert einen Wert, der angibt, ob die in diesem Gliederungscode‑Feld angegebenen Werte Blattwerte sein müssen. |
| [get_Masks](./get_masks/) | Liefert das OutlineMaskCollection‑Objekt. Die Tabelle der Einträge, die die Gliederungscode‑Maske definieren. Nur‑Lese‑Instanz von OutlineMaskCollection. |
| [get_OnlyTableValuesAllowed](./get_onlytablevaluesallowed/) | Liefert einen Wert, der angibt, ob die angegebenen Werte aus der Wertetabelle stammen müssen. |
| [get_PhoneticAlias](./get_phoneticalias/) | Liefert die phonetische Aussprache des Alias des benutzerdefinierten Gliederungscodes. |
| [get_ResourceSubstitutionEnabled](./get_resourcesubstitutionenabled/) | Liefert einen Wert, der angibt, ob der benutzerdefinierte Gliederungscode vom Ressourcen‑Substitutions‑Assistenten in Microsoft Project verwendet werden kann. |
| [get_ShowIndent](./get_showindent/) | Liefert einen Wert, der angibt, ob die Einrückungen dieses Gliederungscodes angezeigt werden müssen. |
| [get_Values](./get_values/) | Liefert das OutlineValueCollection‑Objekt. Die Werte der Tabelle, die mit diesem Gliederungscode verknüpft ist. |
| [set_Alias](./set_alias/) | Legt den Alias eines benutzerdefinierten Gliederungscodes fest. |
| [set_AllLevelsRequired](./set_alllevelsrequired/) | Legt einen Wert fest, der angibt, ob die neuen Codes alle Ebenen haben müssen. Nicht verfügbar für Enterprise-Codes. |
| [set_Enterprise](./set_enterprise/) | Legt einen Wert fest, der angibt, ob ein benutzerdefinierter Gliederungscode ein Enterprise‑benutzerdefinierter Gliederungscode ist. |
| [set_EnterpriseOutlineCodeAlias](./set_enterpriseoutlinecodealias/) | Legt eine Referenz zu einem anderen benutzerdefinierten Feld fest, für das diese Gliederungscode‑Definition ein Alias ist. |
| [set_FieldId](./set_fieldid/) | Legt die Feldnummer eines Gliederungscodes fest. |
| [set_FieldName](./set_fieldname/) | Legt den Namen eines benutzerdefinierten Gliederungscodes fest. |
| [set_Guid](./set_guid/) | Legt die Guid eines Gliederungscodes fest. |
| [set_LeafOnly](./set_leafonly/) | Legt einen Wert fest, der angibt, ob die in diesem Gliederungscode-Feld angegebenen Werte Blattwerte sein müssen. |
| [set_OnlyTableValuesAllowed](./set_onlytablevaluesallowed/) | Legt einen Wert fest, der angibt, ob die angegebenen Werte aus der Wertetabelle stammen müssen. |
