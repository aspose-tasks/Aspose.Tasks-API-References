## Value class

Stellt einen Wert in einer Wertliste dar.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [Value](./value/) | Initialisiert eine neue Instanz der Value Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_DateTimeValue](./get_datetimevalue/) | Gibt den tatsächlichen Wert zurück, wenn er als DateTime dargestellt werden kann. Standardwert ist DateTime::MinValue. |
| [get_Description](./get_description/) | Gibt die Beschreibung eines Wertes zurück. |
| [get_Duration](./get_duration/) | Gibt den tatsächlichen Wert zurück, der zur Darstellung von Duration verwendet wird. |
| [get_Id](./get_id/) | Gibt den eindeutigen Bezeichner eines Wertes im gesamten Projekt zurück. |
| [get_NumericValue](./get_numericvalue/) | Gibt den tatsächlichen Wert zurück, der zur Darstellung einer Zahl oder Kostenwertes verwendet wird. |
| [get_Phonetic](./get_phonetic/) | Gibt die phonetischen Informationen zum Namen des benutzerdefinierten Feldes zurück. |
| [get_StringValue](./get_stringvalue/) | Gibt den tatsächlichen Wert zurück, der zur Darstellung einer Textzeichenfolge verwendet wird. |
| [get_Val](./get_val/) | Gibt den tatsächlichen Wert in interner Darstellung zurück. Verwenden Sie vorzugsweise die unten aufgeführten stark typisierten Eigenschaften. |
| [get_ValueGuid](./get_valueguid/) | Gibt eine GUID zurück, die diesen Wert im gesamten Projekt unter den anderen identifiziert. |

| [set_NumericValue](./set_numericvalue/) | Setzt den tatsächlichen Wert, der zur Darstellung einer Zahl oder eines Kostenwertes verwendet wird. |
