## WeekDayCollection class

Stellt eine Sammlung von WeekDay-Objekten dar.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [Add](./add/) | Fügt diesem Objekt eine WeekDay-Instanz hinzu. |
| [Clear](./clear/) | Löscht das WeekDayCollection-Objekt. |
| [Contains](./contains/) | Überprüft, ob die Sammlung das angegebene WeekDay enthält. |
| [CopyTo](./copyto/) | Kopiert den Inhalt der Sammlung in ein Array an dem angegebenen Index. |
| [get_Count](./get_count/) | Ermittelt die Anzahl der in diesem WeekDayCollection-Objekt enthaltenen Objekte. |
| [GetEnumerator](./getenumerator/) | Gibt einen Enumerator für diese Sammlung zurück. |
| [idx_get](./idx_get/) | Ermittelt den Elementwert am angegebenen Index. |
| [idx_set](./idx_set/) | Setzt den Elementwert am angegebenen Index. |
| [IndexOf](./indexof/) | Gibt den Index des angegebenen WeekDay zurück. |
| [Insert](./insert/) | Fügt ein WeekDay an dem angegebenen Index ein. |
| [Remove](./remove/) | Entfernt das angegebene WeekDay, falls vorhanden. |
| [RemoveAt](./removeat/) | Entfernt ein Element am angegebenen Index. |
| [ToList](./tolist/) | Konvertiert das WeekDayCollection-Objekt in eine Liste von WeekDay-Objekten. |
