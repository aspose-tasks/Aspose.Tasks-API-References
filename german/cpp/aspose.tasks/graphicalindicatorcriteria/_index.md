## GraphicalIndicatorCriteria class

Stellt ein grafisches Indikator-Kriterium dar, das mit einem erweiterten Attribut verknüpft ist.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [GraphicalIndicatorCriteria (2 overloads)](./graphicalindicatorcriteria/) | Initialisiert eine neue Instanz des Typs GraphicalIndicatorCriteria. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_ImageIndex](./get_imageindex/) | Gibt den Index des Bildes zurück, das angezeigt wird, wenn das Feld die Kriterien erfüllt. |
| [get_RowType](./get_rowtype/) | Gibt den Wert des Enums GraphicalIndicatorCriteriaType zurück, das angibt, für welche Zeilen der Indikator angewendet wird. |
| [get_Test](./get_test/) | Gibt den Typ des Vergleichs zurück, der zwischen dem Wert des erweiterten Attributs und den Werten durchgeführt wird und als Kriterium für die Anwendung des grafischen Indikators dient. FilterComparisonType |
| [get_Value1](./get_value1/) | Gibt den Wert zurück, der zum Testen des Werts des erweiterten Attributs verwendet wird. |
| [get_Value2](./get_value2/) | Gibt den zweiten Wert zurück, der zum Testen des Werts des erweiterten Attributs im Fall der Vergleichstypen 'IsWithin' und 'IsNotWithin' verwendet wird. |
| [ToString](./tostring/) | Gibt die Zeichenkettenrepräsentation der Instanz der Klasse GraphicalIndicatorCriteria zurück. |
