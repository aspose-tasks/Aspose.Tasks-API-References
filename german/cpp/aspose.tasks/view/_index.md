## View class

Stellt eine Ansicht in Project dar.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [View (2 overloads)](./view/) | Initialisiert eine neue Instanz der View-Klasse. |

| [Equals](./equals/) | Gibt einen Wert zurück, der angibt, ob diese Instanz einem angegebenen Objekt gleich ist. |
