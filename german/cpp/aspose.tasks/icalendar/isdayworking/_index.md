## IsDayWorking {#isdayworking}

Bestimmt, ob der angegebene Tag gemäß dem Kalender ein Arbeitstag ist.

**Returns:** True if the day is a working day.

```cpp
IsDayWorking(System::DateTime dt)
```

| Parameter | Beschreibung |
| --- | --- |
| dt | Das Datum, um zu prüfen, ob der Tag ein Arbeitstag ist. |
