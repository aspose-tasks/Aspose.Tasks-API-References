## PrimaveraBaseReader class

Stellt einen Basisleser dar, der verwendet werden kann, um Projekt-UIDs aus mehreren Primavera XER- oder XML-Dateien zu lesen.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [GetProjectInfos](./getprojectinfos/) | Gibt eine Liste der Kurzinfo-Objekte des Projekts zurück. |
| [GetProjectUids](./getprojectuids/) | Gibt eine Liste der eindeutigen Kennungen der Projekte zurück. |
| [LoadProject](./loadproject/) | Lädt das Projekt mit der angegebenen eindeutigen Kennung. |
