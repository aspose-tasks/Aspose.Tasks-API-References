## FontSettings class

Gibt die Schriftarteinstellungen an, die beim Rendern der Projektansicht verwendet werden.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | Liefert die Standard- (oder Ersatz-)Schriftart für die Darstellung. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | Liefert einen Callback, der verwendet werden kann, um aufgelöste Schriftarten anzupassen. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | Liefert einen Wert, der angibt, ob die Standardschriftart für die Darstellung verwendet werden muss. |
| [set_DefaultFontName](./set_defaultfontname/) | Setzt die Standard- (oder Ersatz-)Schriftart für die Darstellung. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | Legt einen Rückruf fest, der verwendet werden kann, um aufgelöste Schriftarten anzupassen. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | Legt einen Wert fest, der angibt, ob die Standardschriftart für das Rendern verwendet werden muss. |
| [SetFontFolders](./setfontfolders/) | Legt die Ordner fest, in denen Aspose.Tasks nach TrueType-Schriftarten sucht, wenn die Projektansicht gerendert wird. |
