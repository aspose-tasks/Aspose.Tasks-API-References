## SetFontFolders {#setfontfolders}

Legt die Ordner fest, in denen Aspose.Tasks nach TrueType-Schriftarten sucht, wenn die Projektansicht gerendert wird.

**Returns:** void Aspose::Tasks::

```cpp
SetFontFolders(const System::ArrayPtr< System::String > & fontFolders, bool recursive)
```

| Parameter | Beschreibung |
| --- | --- |
| fontFolders | Ein Array von Ordnern, die TrueType‑Schriften enthalten. |
| recursive | Wenn true, werden die angegebenen Ordner rekursiv durchsucht. |
