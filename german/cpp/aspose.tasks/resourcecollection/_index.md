## ResourceCollection class

Stellt eine Sammlung von Resource-Objekten dar.

| [get_Count](./get_count/) | Liefert die Anzahl der im ResourceCollection enthaltenen Elemente. |
| [get_ParentProject](./get_parentproject/) | Liefert das übergeordnete Projekt des ResourceCollection‑Objekts. |
| [GetById](./getbyid/) | Gibt eine Ressource mit der angegebenen ID zurück. |
| [GetByUid](./getbyuid/) | Gibt eine Ressource mit der angegebenen UID zurück. |
| [GetEnumerator](./getenumerator/) | Gibt einen Enumerator für diese Sammlung zurück. |
| [idx_get](./idx_get/) | Gibt das Element am angegebenen Index zurück. |
| [idx_set](./idx_set/) | Gibt das Element am angegebenen Index zurück. |
| [Remove](./remove/) | Dies ist die Stub-Implementierung der Remove-Methode von ICollection, die nur NotSupportedException auslöst. |
| [ToList](./tolist/) | Konvertiert das ResourceCollection‑Objekt in eine Liste von Resource‑Objekten. |
