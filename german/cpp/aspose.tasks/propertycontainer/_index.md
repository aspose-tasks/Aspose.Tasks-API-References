## PropertyContainer< T > class

Stellt einen Eigenschaftscontainer dar.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [CheckPropAndGet](./checkpropandget/) | Gibt den Wert zurück, dem die Eigenschaft in diesem Container zugeordnet ist. Wenn dieser Container keinen Datensatz ProjectItem enthält, wird er mit dem Standardwert hinzugefügt und der Standardwert zurückgegeben. |
| [CheckPropAndSet](./checkpropandset/) | Ordnet die angegebene Eigenschaft dem angegebenen Wert in diesem Container zu. Wenn dieser Container den Datensatz ProjectItem nicht enthält, wird er hinzugefügt. |
