## CheckPropAndGet {#checkpropandget}

Gibt den Wert zurück, dem die Eigenschaft in diesem Container zugeordnet ist. Wenn dieser Container keinen Datensatz ProjectItem enthält, wird er mit dem Standardwert hinzugefügt und der Standardwert zurückgegeben.

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| Parameter | Beschreibung |
| --- | --- |
| Schlüssel | die angegebene Eigenschaft. |
