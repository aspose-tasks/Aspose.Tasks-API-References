## OleObject class

Stellt ein OLE-Objekt dar, das in die Gantt‑Diagrammansicht einer MPP‑Datei eingefügt werden kann.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [OleObject](./oleobject/) | Initialisiert eine neue Instanz der OleObject class. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_ApplicationName](./get_applicationname/) | Ermittelt den Anwendungsnamen, mit dem das eingebettete Objekt geöffnet wird. |
| [get_Content](./get_content/) | Ermittelt die Daten der eingebetteten Datei; null, wenn keine Daten eingebettet wurden. |
| [get_DisplayAsIcon](./get_displayasicon/) | Ermittelt ein Flag, das angibt, ob das OLE-Objekt entweder als Symbol oder als reguläres Bild angezeigt werden soll. |
| [get_FileFormat](./get_fileformat/) | Ermittelt das Dateiformat des eingebetteten Objekts. |
| [get_FullPath](./get_fullpath/) | Ermittelt den vollständigen Pfad des eingefügten Objekts. |
| [get_Id](./get_id/) | Ermittelt die Objekt‑ID. |
| [get_Label](./get_label/) | Ermittelt das Etikett des eingefügten Objekts. |
| [get_Linked](./get_linked/) | Ermittelt einen Wert, der angibt, ob die Projektdatei nur einen Link zu den tatsächlichen Daten enthält, die an der Linkquelle gespeichert sind. |
| [get_Name](./get_name/) | Ermittelt den Namen der Instanz des OLE-Objekts. |
| [get_TemporaryFile](./get_temporaryfile/) | Ermittelt den Pfad zur temporären Datei des eingefügten Objekts. |
| [get_View](./get_view/) | Ermittelt die Instanz der View-Klasse, zu der das eingefügte Objekt gehört. |
| [set_ApplicationName](./set_applicationname/) | Legt den Anwendungsnamen fest, mit dem das eingebettete Objekt geöffnet wird. |
| [set_Content](./set_content/) | Setzt die Daten der eingebetteten Datei; null, wenn keine Daten eingebettet wurden. |
| [set_DisplayAsIcon](./set_displayasicon/) | Setzt ein Flag, das angibt, dass das OLE-Objekt entweder als Symbol oder als reguläres Bild angezeigt werden soll. |
| [set_FileFormat](./set_fileformat/) | Setzt das Dateiformat des eingebetteten Objekts. |
| [set_FullPath](./set_fullpath/) | Setzt den vollständigen Pfad des eingefügten Objekts. |
| [set_Id](./set_id/) | Setzt die Objekt-ID. |
| [set_Label](./set_label/) | Setzt das Etikett des eingefügten Objekts. |
| [set_Name](./set_name/) | Setzt den Namen der Instanz des OLE-Objekts. |
| [set_TemporaryFile](./set_temporaryfile/) | Setzt den Pfad zur temporären Datei des eingefügten Objekts. |
