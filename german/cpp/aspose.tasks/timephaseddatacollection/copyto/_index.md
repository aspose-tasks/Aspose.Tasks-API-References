## CopyTo {#copyto}

Kopiert die Elemente der TimephasedDataCollection in ein System::Array, beginnend an einem bestimmten System::Array-Index.

**Returns:** void Aspose::Tasks::

```cpp
CopyTo(System::ArrayPtr< System::SharedPtr< TimephasedData >> array, int32_t arrayIndex)
```

| Parameter | Beschreibung |
| --- | --- |
| Array | Das eindimensionale System::Array, das das Ziel der aus TimephasedDataCollection kopierten Elemente ist. Das System::Array muss eine nullbasierte Indizierung haben. |
| arrayIndex | Der nullbasierte Index im Array, an dem das Kopieren beginnt. |
