## idx_get {#idx_get}

Gibt das Element am angegebenen Index zurück. Der Set-Accessor wird nicht unterstützt. Eigenschaft zum Setzen von timephased-Daten.

**Returns:** the element at the specified index.

```cpp
idx_get(int32_t index)
```

| Parameter | Beschreibung |
| --- | --- |
| Index | Der nullbasierte Index des abzurufenden Elements. |
