## TimephasedDataCollection class

Stellt eine Sammlung von TimephasedData-Objekten dar.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [Add](./add/) | Fügt eine TimephasedData-Instanz zu diesem Sammlungsobjekt hinzu. |
| [AddRange](./addrange/) | Fügt eine Sammlung von TimephasedData-Instanzen zu diesem Sammlungsobjekt hinzu. |
| [Clear](./clear/) | Entfernt alle Elemente aus der TimephasedDataCollection. |
| [Contains](./contains/) | Bestimmt, ob die TimephasedDataCollection einen bestimmten Wert enthält. |
| [CopyTo](./copyto/) | Kopiert die Elemente der TimephasedDataCollection in ein System::Array, beginnend an einem bestimmten System::Array-Index. |
| [get_Count](./get_count/) | Liefert die Anzahl der Objekte, die in diesem TimephasedDataCollection-Objekt enthalten sind. |
| [get_IsReadOnly](./get_isreadonly/) | Liefert einen Wert, der angibt, ob das System::Collections::Generic::ICollection<T> schreibgeschützt ist. |
| [GetEnumerator](./getenumerator/) | Gibt einen Enumerator für diese Sammlung zurück. |
| [idx_get](./idx_get/) | Gibt das Element am angegebenen Index zurück. Der Set-Accessor wird nicht unterstützt. Eigenschaft zum Setzen von timephased-Daten. |
| [idx_set](./idx_set/) | Gibt das Element am angegebenen Index zurück. Der Set-Accessor wird nicht unterstützt. Eigenschaft zum Setzen von timephased-Daten. |
| [Remove](./remove/) | Entfernt eine TimephasedData-Instanz aus diesem Sammlungsobjekt. |
| [SelectBetweenStartAndFinish](./selectbetweenstartandfinish/) | Wählt alle Zeitphasen zwischen startTime und finishTime aus. Hat im Durchschnitt O(log n)-Komplexität. |
| [ToList](./tolist/) | Konvertiert das TimephasedDataCollection-Objekt in eine Liste von TimephasedData-Objekten. |
