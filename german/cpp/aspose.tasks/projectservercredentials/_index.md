## ProjectServerCredentials class

Anmeldeinformationen, die verwendet werden, um eine Verbindung zu Project Online oder einer lokalen Instanz von Project Server herzustellen.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [ProjectServerCredentials (3 overloads)](./projectservercredentials/) | Initialisiert eine neue Instanz der Klasse ProjectServerCredentials unter Verwendung der URL der SharePoint‑Site und eines gültigen SPOIDCRL‑Autorisierungstokens für die PWA‑Site (Project Web Access) von SharePoint. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_AuthToken](./get_authtoken/) | Liefert das Autorisierungstoken für die SharePoint-Instanz. |
| [get_SiteUrl](./get_siteurl/) | Liefert die URL von PWA auf der SharePoint‑Site oder die URL des lokalen Project Server. Zum Beispiel, https://your_company_name.sharepoint.com/sites/pwa "; |
| [get_UserName](./get_username/) | Liefert den Benutzernamen für die SharePoint‑Site. |
| [ToString](./tostring/) | Gibt eine Zeichenkettenrepräsentation dieser Instanz zurück. |
