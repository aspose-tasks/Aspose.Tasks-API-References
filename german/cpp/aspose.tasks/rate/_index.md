## Rate class

Stellt eine Definition eines Zeitraums und der für eine Ressource in diesem Zeitraum geltenden Tarife dar.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Ermittelt die Kosten pro Nutzung einer Ressource. Dieser Wert wird vom aktuellen Datum abgerufen, wenn für die Ressource eine Kostentabelle existiert. |
| [get_OvertimeRate](./get_overtimerate/) | Ermittelt den Überstundensatz pro Stunde für eine Ressource. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Ermittelt die von Microsoft Project verwendeten Einheiten zur Anzeige des Überstundensatzes. |
| [get_RatesFrom](./get_ratesfrom/) | Ermittelt das Datum, an dem ein Satz wirksam wird. |
| [get_RatesTo](./get_ratesto/) | Ermittelt das letzte Datum, an dem ein Satz wirksam ist. |
| [get_RateTable](./get_ratetable/) | Ermittelt die eindeutige Kennung einer Kostentabelle für eine Ressource. |
| [get_StandardRate](./get_standardrate/) | Ermittelt den Standardtarif pro Stunde für eine Ressource. |
| [get_StandardRateFormat](./get_standardrateformat/) | Ermittelt die von Microsoft Project verwendeten Einheiten zur Anzeige des Standardtarifs. |
| [set_CostPerUse](./set_costperuse/) | Legt die Kosten pro Nutzung einer Ressource fest. Dieser Wert wird vom aktuellen Datum abgerufen, wenn für die Ressource eine Kostentabelle existiert. |
| [set_OvertimeRate](./set_overtimerate/) | Legt den Überstundensatz pro Stunde für eine Ressource fest. |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Legt die von Microsoft Project verwendeten Einheiten zur Anzeige des Überstundensatzes fest. |
| [set_RatesFrom](./set_ratesfrom/) | Legt das Datum fest, an dem ein Satz wirksam wird. |
| [set_RatesTo](./set_ratesto/) | Legt das letzte Datum fest, an dem ein Satz wirksam ist. |
| [set_RateTable](./set_ratetable/) | Legt die eindeutige Kennung einer Kostentabelle für eine Ressource fest. |
| [set_StandardRate](./set_standardrate/) | Legt den Standardtarif pro Stunde für eine Ressource fest. |
| [set_StandardRateFormat](./set_standardrateformat/) | Legt die von Microsoft Project verwendeten Einheiten zur Anzeige des Standardtarifs fest. |
