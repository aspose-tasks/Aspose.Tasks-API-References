## FilterCriteria class

Definiert die Kriterien, die Aufgaben oder Ressourcen erfüllen müssen, um in der MSP-Ansicht angezeigt zu werden.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_CriteriaRows](./get_criteriarows/) | Ruft die Liste der untergeordneten FilterCriteria‑Zeilen ab. Wenn der Filter mehr als eine Kriterienzeile enthält, bewirkt ein Und‑Operator, dass die Kriterien beider Zeilen erfüllt sein müssen, damit die Aufgabe oder Ressource als Ergebnis dieses Filters angezeigt wird. Der Effekt eines Oder‑Operators ist, dass die Kriterien der einen oder der anderen Zeile erfüllt sein müssen. |
| [get_Field](./get_field/) | Ruft ein Feld zum Ändern ab. |
| [get_Operation](./get_operation/) | Ruft das mit FieldName, Test und Value festgelegte Kriterium ab, das sich auf andere Kriterien im Filter bezieht. |
| [get_Test](./get_test/) | Ruft den Typ des Vergleichs zwischen FieldName und Value ab, der als Auswahlkriterium für den Filter dient. FilterComparisonType |
| [get_Values](./get_values/) | Ruft die Objektwerte ab, die mit dem Wert des mit FieldName angegebenen Feldes verglichen werden. |
| [IsFieldValue](./isfieldvalue/) | Ruft ab, ob der rechte Wert von FilterCriteria eine Feldreferenz und kein konstanter Wert ist. |
| [set_Field](./set_field/) | Setzt ein Feld zum Ändern. |
| [set_Operation](./set_operation/) | Setzt das mit FieldName, Test und Value festgelegte Kriterium, das sich auf andere Kriterien im Filter bezieht. |
| [set_Test](./set_test/) | Setzt den Typ des Vergleichs zwischen FieldName und Value, der als Auswahlkriterium für den Filter dient. FilterComparisonType |
| [SetValueField](./setvaluefield/) | Setzt das Feld, dessen Wert mit dem Wert des durch FieldName angegebenen Feldes verglichen wird. |
| [ToString](./tostring/) | Gibt die Zeichenkettenrepräsentation der Instanz der Klasse FilterCriteria zurück. |
