## set_ProjectName {#set_projectname}

Legt den Namen eines Projekts fest, der in der Projektliste von Project Server \\ Project Online angezeigt wird. Der Name sollte innerhalb einer Project Server \\ Project Online‑Instanz eindeutig sein. Wird der Wert weggelassen, wird stattdessen der Wert der Eigenschaft Prj.Name verwendet.
