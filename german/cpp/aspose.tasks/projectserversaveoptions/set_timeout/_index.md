## set_Timeout {#set_timeout}

Legt den Timeout fest, der beim Warten auf die Verarbeitung einer Speicherprojekt-Anforderung durch den Queue-Verarbeitungsdienst eines Project Server verwendet wird. Der Standardwert für diese Eigenschaft beträgt 1 Minute.

**Returns:** void Aspose::Tasks::

set_Timeout(System::TimeSpan value)
