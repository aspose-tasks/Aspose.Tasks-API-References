## ProjectServerSaveOptions class

Ermöglicht das Angeben zusätzlicher Optionen, wenn ein Projekt in Project Server oder Project Online gespeichert wird.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [ProjectServerSaveOptions](./projectserversaveoptions/) | Initialisiert eine neue Instanz der ProjectServerSaveOptions-Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_PollingInterval](./get_pollinginterval/) | Ruft das Intervall zwischen Anfragen zum Status von Warteschlangenjobs ab. Der Standardwert beträgt 2 Sekunden. |
| [get_ProjectGuid](./get_projectguid/) | Ruft die eindeutige Kennung eines Projekts ab. Sie sollte innerhalb einer Project Server \ Project Online-Instanz eindeutig sein. |
| [get_ProjectName](./get_projectname/) | Ruft den Namen eines Projekts ab, der in der Projektliste von Project Server \ Project Online angezeigt wird. Er sollte innerhalb einer Project Server \ Project Online-Instanz eindeutig sein. Wird der Wert weggelassen, wird stattdessen der Wert der Prj.Name‑Eigenschaft verwendet. |
| [get_Timeout](./get_timeout/) | Ermittelt den Timeout, der beim Warten auf die Verarbeitung einer Speicherprojekt-Anforderung durch den Queue-Verarbeitungsdienst eines Project Server verwendet wird. Der Standardwert für diese Eigenschaft beträgt 1 Minute. |
| [set_PollingInterval](./set_pollinginterval/) | Legt das Intervall zwischen Anfragen zum Status von Queue-Jobs fest. Der Standardwert beträgt 2 Sekunden. |
| [set_ProjectGuid](./set_projectguid/) | Legt die eindeutige Kennung eines Projekts fest. Sie sollte innerhalb einer Project Server \\ Project Online‑Instanz eindeutig sein. |
| [set_ProjectName](./set_projectname/) | Legt den Namen eines Projekts fest, der in der Projektliste von Project Server \\ Project Online angezeigt wird. Der Name sollte innerhalb einer Project Server \\ Project Online‑Instanz eindeutig sein. Wird der Wert weggelassen, wird stattdessen der Wert der Eigenschaft Prj.Name verwendet. |
| [set_Timeout](./set_timeout/) | Legt den Timeout fest, der beim Warten auf die Verarbeitung einer Speicherprojekt-Anforderung durch den Queue-Verarbeitungsdienst eines Project Server verwendet wird. Der Standardwert für diese Eigenschaft beträgt 1 Minute. |
