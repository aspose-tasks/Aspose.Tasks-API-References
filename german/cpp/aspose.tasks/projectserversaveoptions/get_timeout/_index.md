## get_Timeout {#get_timeout}

Ermittelt den Timeout, der beim Warten auf die Verarbeitung einer Speicherprojekt-Anforderung durch den Queue-Verarbeitungsdienst eines Project Server verwendet wird. Der Standardwert für diese Eigenschaft beträgt 1 Minute.

**Returns:** System::TimeSpan Aspose::Tasks::
