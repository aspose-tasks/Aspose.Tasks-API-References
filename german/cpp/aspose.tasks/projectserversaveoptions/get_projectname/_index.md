## get_ProjectName {#get_projectname}

Ruft den Namen eines Projekts ab, der in der Projektliste von Project Server \ Project Online angezeigt wird. Er sollte innerhalb einer Project Server \ Project Online-Instanz eindeutig sein. Wird der Wert weggelassen, wird stattdessen der Wert der Prj.Name‑Eigenschaft verwendet.

**Returns:** System::String Aspose::Tasks::

```cpp
get_ProjectName()
```
