## ProjectServerManager class

Die Klasse, die die Methoden zum Lesen und Ausführen von Vorgängen an Projekten im angegebenen Project Online‑Konto oder in der angegebenen lokalen Project Server‑Instanz bereitstellt (Versionen 2016 und 2019 von Project Server werden unterstützt).

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [ProjectServerManager](./projectservermanager/) | Initialisiert eine neue Instanz der ProjectServerManager‑Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [CreateNewProject (2 overloads)](./createnewproject/) | Erstellt ein neues Projekt in einer Project Server\Project Online‑Instanz mit den standardmäßigen Speicheroptionen. |
| [GetProject](./getproject/) | Liefert das Projekt mit der angegebenen GUID aus dem Project Online‑Konto \ der Project Server‑Instanz. |
| [GetProjectList](./getprojectlist/) | Liefert die Projektliste aus dem 'Working'-Speicher des aktuellen Project Online‑Kontos \ der Project Server‑Instanz. |
| [GetProjectRawData](./getprojectrawdata/) | Liefert die Binärdaten des Projekts zu Diagnosezwecken. |
| [UpdateProject (2 overloads)](./updateproject/) | Aktualisiert ein bestehendes Projekt in einer Project Server\Project Online‑Instanz mit den standardmäßigen Speicheroptionen. Das bestehende Projekt wird überschrieben. |
| [ExecutingWebRequest](./executingwebrequest/) | Ein Ereignis, das ausgelöst wird, wenn die Webanfrage an die Web‑API von Project Server gesendet wird. |
