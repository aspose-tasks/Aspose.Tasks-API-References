## CopyToOptions class

Ermöglicht das Angeben zusätzlicher Optionen beim Kopieren von Projektdaten.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [CopyToOptions](./copytooptions/) | Initialisiert eine neue Instanz der CopyToOptions Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_CopyViewData](./get_copyviewdata/) | Ermittelt einen Wert, der angibt, ob Ansichts‑Daten beim Kopieren von Projektdaten kopiert werden sollen. Der Standardwert ist true. |
| [set_CopyViewData](./set_copyviewdata/) | Legt einen Wert fest, der angibt, ob Ansichts‑Daten beim Kopieren von Projektdaten kopiert werden sollen. Der Standardwert ist true. |
