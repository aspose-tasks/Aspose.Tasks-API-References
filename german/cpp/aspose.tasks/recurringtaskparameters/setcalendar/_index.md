## SetCalendar {#setcalendar}

Legt einen Kalender für die wiederkehrende Aufgabe fest. Der Kalender wird aus der Projektkalender-Sammlung ausgewählt.

**Returns:** void Aspose::Tasks::

```cpp
SetCalendar(const System::SharedPtr< Project > & project, const System::String & calendarName)
```

| Parameter | Beschreibung |
| --- | --- |
| project | Das Projekt mit Kalendersammlung. |
| calendarName | Der Name des Kalenders. |
