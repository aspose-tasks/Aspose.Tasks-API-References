## RecurringTaskParameters class

Stellt die Menge von Parametern dar, die zum Erstellen einer wiederkehrenden Aufgabe in einem Projekt verwendet werden.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [RecurringTaskParameters](./recurringtaskparameters/) | Initialisiert eine neue Instanz der RecurringTaskParameters Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Duration](./get_duration/) | Gibt die Dauer für ein Vorkommen der wiederkehrenden Aufgabe zurück. |
| [get_IgnoreResourceCalendar](./get_ignoreresourcecalendar/) | Liefert einen Wert, der angibt, ob die wiederkehrende Aufgabe geplant werden soll, selbst wenn sie nicht ausgeführt wird, obwohl Ressourcen verfügbar sind. |
| [get_RecurrencePattern](./get_recurrencepattern/) | Liefert das Wiederholungsmuster der wiederkehrenden Aufgabe. |
| [get_TaskName](./get_taskname/) | Liefert den Namen der wiederkehrenden Aufgabe. |
| [set_Duration](./set_duration/) | Legt die Dauer für ein Vorkommen der wiederkehrenden Aufgabe fest. |
| [set_IgnoreResourceCalendar](./set_ignoreresourcecalendar/) | Setzt einen Wert, der angibt, ob die wiederkehrende Aufgabe geplant werden soll, selbst wenn sie nicht ausgeführt wird, obwohl Ressourcen verfügbar sind. |
| [set_RecurrencePattern](./set_recurrencepattern/) | Setzt das Wiederholungsmuster der wiederkehrenden Aufgabe. |
| [set_TaskName](./set_taskname/) | Setzt den Namen der wiederkehrenden Aufgabe. |
| [SetCalendar](./setcalendar/) | Legt einen Kalender für die wiederkehrende Aufgabe fest. Der Kalender wird aus der Projektkalender-Sammlung ausgewählt. |
