## Metered class

Stellt Methoden zum Festlegen eines gemessenen Schlüssels bereit.

In diesem Beispiel wird versucht, den gemessenen öffentlichen und privaten Schlüssel <ms> zu setzen

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> die Komponenten-JAR-Datei:

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>

## Methoden

| Name | Beschreibung |
| --- | --- |
| [GetConsumptionCredit](./getconsumptioncredit/) | Liefert das Verbrauchsguthaben. |
| [GetConsumptionQuantity](./getconsumptionquantity/) | Ermittelt die Größe der Verbrauchsdatei. |
| [IsLicensed](./islicensed/) | Überprüft, ob das Produkt erfolgreich mit einer Metered license lizenziert ist. |
| [ResetMeteredKey](./resetmeteredkey/) | Entfernt die zuvor eingerichtete Lizenz. |
| [SetMeteredKey](./setmeteredkey/) | Setzt öffentliche und private Metered-Schlüssel. |
