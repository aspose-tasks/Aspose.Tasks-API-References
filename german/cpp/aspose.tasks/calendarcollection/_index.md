## CalendarCollection class

Stellt eine Sammlung von Kalender-Objekten dar.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [Add (2 overloads)](./add/) | Fügt diesem CalendarCollection-Objekt einen neuen Basiskalender hinzu und gibt den hinzugefügten Kalender zurück. |
| [get_Count](./get_count/) | Ermittelt die Anzahl der Objekte, die in diesem CalendarCollection-Objekt enthalten sind. |
| [GetByName](./getbyname/) | Gibt einen Kalender mit dem angegebenen Namen zurück. |
| [GetByUid](./getbyuid/) | Gibt einen Kalender mit der angegebenen UID zurück. |
| [GetEnumerator](./getenumerator/) | Gibt einen Enumerator für diese Sammlung zurück. |
| [Remove](./remove/) | Entfernt den Kalender aus der Projekt-CalendarCollection. |
| [ToList](./tolist/) | Konvertiert das CalendarCollection-Objekt in eine Liste von Kalenderobjekten. |
