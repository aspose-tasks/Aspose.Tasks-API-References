## CalendarExceptionCollection class

Stellt eine Sammlung von CalendarException-Objekten dar.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [Add](./add/) | Fügt eine CalendarException‑Instanz zu diesem Sammlungsobjekt hinzu. |
| [AddRange](./addrange/) | Fügt einen Bereich von Ausnahmen zur internen Liste hinzu. |
| [Clear](./clear/) | Entfernt alle Elemente aus der CalendarExceptionCollection. |
| [get_Count](./get_count/) | Ermittelt die Anzahl der Objekte, die in diesem CalendarExceptionCollection‑Objekt enthalten sind. |
| [get_ParentCalendar](./get_parentcalendar/) | Ermittelt den übergeordneten Kalender für dieses Objekt. |
| [GetEnumerator](./getenumerator/) | Gibt einen Enumerator für diese Sammlung zurück. |
| [idx_get](./idx_get/) | Gibt das Element am angegebenen Index zurück. |
| [idx_set](./idx_set/) | Gibt das Element am angegebenen Index zurück. |
| [Remove](./remove/) | Entfernt die CalendarException‑Instanz aus dieser Sammlung. |
| [ToList](./tolist/) | Konvertiert das CalendarExceptionCollection‑Objekt in eine Liste von CalendarException‑Objekten. |
