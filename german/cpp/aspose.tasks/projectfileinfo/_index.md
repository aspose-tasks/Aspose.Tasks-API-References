## ProjectFileInfo class

Die Klasseninstanz enthält Informationen über das Projektdateiformat und die Version von Microsoft Project, in der die Datei erstellt wurde.

Verwenden Sie die Eigenschaft CanRead, um festzulegen, dass die Bibliothek die Projektdatei verarbeiten kann.
