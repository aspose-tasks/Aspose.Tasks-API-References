## ExtendedAttribute class

Stellt erweiterte Attribute dar.

Derzeit werden alle Arten von erweiterten Attributen unterstützt, die aus MSP Xml 2003/2007 und mpp 2003 gelesen werden. Für MSP mpp 2007 werden alle erweiterten Attribute unterstützt, außer Dauern und Flags.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_AttributeDefinition](./get_attributedefinition/) | Liefert die Attributdefinition. |
| [get_DateValue](./get_datevalue/) | Liefert einen Wert für Attribute mit Datumstypen (Date, Start, Finish). |
| [get_DurationValue](./get_durationvalue/) | Liefert einen Wert für Attribute mit dem Typ ' Duration '. |
| [get_FieldId](./get_fieldid/) | Liefert die ID eines Feldes. |
| [get_FlagValue](./get_flagvalue/) | Liefert einen Wert, der angibt, ob ein Flag für ein Attribut vom Typ 'Flag' gesetzt ist. |
| [get_IsErrorValue](./get_iserrorvalue/) | Ermittelt, ob die Berechnung des Werts des erweiterten Attributs einen Fehler ergeben hat. |
| [get_NumericValue](./get_numericvalue/) | Ermittelt einen Wert für Attribute mit numerischen Typen (Cost, Number). |
| [get_TextValue](./get_textvalue/) | Ermittelt einen Wert für Attribute mit dem Typ 'Text'. |
| [get_ValueGuid](./get_valueguid/) | Ermittelt die GUID eines Lookup-Werts. |
| [get_ValueReadOnly](./get_valuereadonly/) | Ermittelt einen Wert, der angibt, ob ein Wert dieser ExtendedAttribute-Instanz schreibgeschützt ist. Gibt true zurück, wenn eine Formel oder Rollup in der ExtendedAttributeDefinition für dieses Objekt definiert ist. |
| [set_DateValue](./set_datevalue/) | Setzt einen Wert für Attribute mit Datentypen (Date, Start, Finish). |
| [set_DurationValue](./set_durationvalue/) | Setzt einen Wert für Attribute mit dem Typ ' Duration '. |
| [set_FlagValue](./set_flagvalue/) | Setzt einen Wert, der angibt, ob ein Flag für ein Attribut mit dem Typ 'Flag' gesetzt ist. |
| [set_NumericValue](./set_numericvalue/) | Setzt einen Wert für Attribute mit numerischen Typen (Cost, Number). |
| [set_TextValue](./set_textvalue/) | Setzt einen Wert für Attribute mit dem Typ 'Text'. |
| [ToString](./tostring/) | Gibt eine kurze Zeichenkettenrepräsentation eines erweiterten Attributs zurück. |
