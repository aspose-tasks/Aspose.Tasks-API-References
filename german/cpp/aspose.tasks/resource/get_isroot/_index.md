## get_IsRoot {#get_isroot}

Ruft das Flag ab, das angibt, ob die Ressource eine Root‑Ressource ist. Eine Root‑Ressource ist eine spezielle Ressource, die dazu dient, die internen Formate von MS Project zu unterstützen und nicht direkt aus dem Code des Benutzers verwendet werden soll.

**Returns:** virtual bool Aspose::Tasks::
