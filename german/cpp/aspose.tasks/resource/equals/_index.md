## Equals (1 of 2) {#equals_1}

Gibt einen Wert zurück, der angibt, ob diese Instanz einer angegebenen Instanz der Klasse Resource entspricht.

**Returns:** True if the specified instance of the Resource class has the same Uid value as this instance; otherwise, false .

```cpp
Equals(System::SharedPtr< Resource > other)
```

| Parameter | Beschreibung |
| --- | --- |
| andere | Die angegebene Instanz der Resource-Klasse zum Vergleich mit dieser Instanz. |

## Equals (2 of 2) {#equals_2}

Gibt einen Wert zurück, der angibt, ob diese Instanz einem angegebenen Objekt gleich ist.

**Returns:** True if the specified object is a Resource that has the same Uid value as this instance; otherwise, false .

```cpp
Equals(System::SharedPtr< System::Object > obj)
```

| Parameter | Beschreibung |
| --- | --- |
| obj | Das Objekt zum Vergleich mit dieser Instanz. |
