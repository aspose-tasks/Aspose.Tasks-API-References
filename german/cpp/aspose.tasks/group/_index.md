## Group class

Stellt eine Gruppendefinition dar. Ein Group-Objekt ist Mitglied der ResourceGroups‑Sammlung oder der TaskGroups‑Sammlung.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [Group](./group/) | Initialisiert eine neue Instanz der Group‑Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_GroupAssignments](./get_groupassignments/) | Gibt einen Wert zurück, der angibt, ob Zuweisungen anstelle von Aufgaben gruppiert werden sollen. |
| [get_GroupCriteria](./get_groupcriteria/) | Gibt eine GroupCriteria‑Sammlung zurück, die die Felder einer Gruppendefinition darstellt. |
| [get_Index](./get_index/) | Gibt den Index eines Group‑Objekts in der Groups‑Liste zurück. |
| [get_MaintainHierarchy](./get_maintainhierarchy/) | Gibt einen Wert zurück, der angibt, ob alle Ebenen von Zusammenfassungsaufgaben für Unteraufgaben innerhalb der Gruppe angezeigt werden sollen. |
| [get_Name](./get_name/) | Gibt den Namen eines Group‑Objekts zurück. |
