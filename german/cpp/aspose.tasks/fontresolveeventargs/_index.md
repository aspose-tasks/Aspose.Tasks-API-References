## FontResolveEventArgs class

Stellt Argumente für den Callback bereit, der aufgerufen wird, wenn die Schriftart aufgelöst wird.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_RequestedFontName](./get_requestedfontname/) | Ermittelt den Namen der angeforderten Schriftart. |
| [get_ResolvedFontName](./get_resolvedfontname/) | Ermittelt den Namen der aufgelösten Schriftart. Kann festgelegt werden, um die zum Rendern einer Ansicht verwendeten Schriftarten zu steuern. |
| [set_ResolvedFontName](./set_resolvedfontname/) | Setzt den Namen der aufgelösten Schriftart. Kann festgelegt werden, um die zum Rendern einer Ansicht verwendeten Schriftarten zu steuern. |
