## PrimaveraProjectProperties class

Stellt Primavera-spezifische Eigenschaften für ein Projekt dar, das aus Primavera-Dateien (XER oder P6XML) gelesen wurde.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_BaselineProjects](./get_baselineprojects/) | Ermittelt ein Array von Basislinienprojekten des aktuellen Projekts. Gilt für Projekte, die aus Primavera-XML-Dateien mit exportierten Basislinien gelesen wurden. |
| [get_CurrentBaselineProjectId](./get_currentbaselineprojectid/) | Ermittelt die ID des aktuellen Basislinienprojekts. Gilt für Projekte, die aus Primavera-XML-Dateien mit exportierten Basislinien gelesen wurden. |
| [get_IgnoreOtherProjectRelationships](./get_ignoreotherprojectrelationships/) | Ermittelt ein Flag, das definiert, ob Aktivitätsbeziehungen zwischen Projekten ignoriert werden sollen. |
| [get_MakeOpenEndedActivitiesCritical](./get_makeopenendedactivitiescritical/) | Ermittelt ein Flag, das definiert, ob Aktivitäten beim Planen des Projekts als kritisch markiert werden sollen. |
| [get_RelationshipLagCalendar](./get_relationshiplagcalendar/) | Ermittelt eine Option, die definiert, welcher Kalender für die Zeitverzögerung von Beziehungen in Primavera-Projekten verwendet wird. |
| [get_UseExpectedFinishDates](./get_useexpectedfinishdates/) | Ermittelt ein Flag, das definiert, ob Aktivitätsenddaten als erwartete Enddaten geplant werden sollen. |
