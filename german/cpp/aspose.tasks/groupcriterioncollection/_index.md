## GroupCriterionCollection class

Enthält eine Sammlung von GroupCriterion-Objekten. Implementiert die Schnittstelle ICollection< GroupCriterion >.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [Add](./add/) | Fügt das angegebene Element zu dieser Sammlung hinzu. |
| [Clear](./clear/) | Entfernt alle Elemente aus dieser Sammlung. |
| [Contains](./contains/) | Gibt true zurück, wenn das angegebene Element in dieser Sammlung gefunden wird; andernfalls false. |
| [CopyTo](./copyto/) | Kopiert die Elemente dieser Sammlung in das angegebene Array, beginnend beim angegebenen Array‑Index. |
| [get_Count](./get_count/) | Gibt die Anzahl der in dieser Sammlung enthaltenen Elemente zurück. |
| [get_IsReadOnly](./get_isreadonly/) | Gibt einen Wert zurück, der angibt, ob diese Sammlung schreibgeschützt ist; andernfalls false. |
| [GetEnumerator](./getenumerator/) | Gibt einen Enumerator für diese Sammlung zurück. |
| [Remove](./remove/) | Entfernt das erste Vorkommen eines bestimmten Objekts aus dieser Sammlung. |
| [ToList](./tolist/) | Konvertiert eine GroupCriterion-Sammlung in eine Liste von GroupCriterion-Objekten. |
