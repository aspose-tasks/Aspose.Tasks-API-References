## OutlineMask class

Stellt vier Elemente einer Maske dar, die ein Gliederungscode-Format definiert.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [OutlineMask](./outlinemask/) | Initialisiert eine neue Instanz der OutlineMask‑Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_Length](./get_length/) | Liefert die maximale Länge (in Zeichen) der Outline‑Code‑Werte. 0, wenn die Länge nicht definiert ist. |
| [get_Level](./get_level/) | Liefert die Ebene einer Maske. |
| [get_Separator](./get_separator/) | Liefert das Trennzeichen der Code‑Werte. |
| [get_Type](./get_type/) | Liefert den Typ einer Maske. |
| [set_Length](./set_length/) | Legt die maximale Länge (in Zeichen) der Outline‑Code‑Werte fest. 0, wenn die Länge nicht definiert ist. |
| [set_Level](./set_level/) | Legt die Ebene einer Maske fest. |
| [set_Separator](./set_separator/) | Legt das Trennzeichen der Code‑Werte fest. |
| [set_Type](./set_type/) | Legt den Typ einer Maske fest. |
