## RiskPattern class

Stellt ein Risikomuster für eine Projektaufgabe dar.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [RiskPattern](./riskpattern/) | Initialisiert eine neue Instanz der RiskPattern‑Klasse. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_ConfidenceLevel](./get_confidencelevel/) | Liefert das Konfidenzniveau, das dem Prozentsatz der Zeit entspricht, in der die tatsächlich erzeugten Werte innerhalb optimistischer und pessimistischer Schätzungen liegen. Der Standardwert ist CL99. |
| [get_Distribution](./get_distribution/) | Liefert die Wahrscheinlichkeitsverteilung, die in der Monte‑Carlo‑Simulation verwendet wird. Der Standardwert ist ProbabilityDistributionType.Normal. |
| [get_Optimistic](./get_optimistic/) | Liefert den Prozentsatz der wahrscheinlichsten Aufgabendauer, die im bestmöglichen Projektszenario auftreten kann. Der Standardwert ist 75, was bedeutet, dass bei einer geschätzten Aufgabendauer von 4 Tagen die optimistische Dauer 3 Tage beträgt. |
| [get_Pessimistic](./get_pessimistic/) | Liefert den Prozentsatz der wahrscheinlichsten Aufgabendauer, die im ungünstigsten Projektszenario auftreten kann. Der Standardwert ist 125, was bedeutet, dass bei einer geschätzten Aufgabendauer von 4 Tagen die pessimistische Dauer 5 Tage beträgt. |
| [get_Task](./get_task/) | Liefert eine Projektaufgabe, auf die dieses Risiko‑Muster angewendet wird. |
| [set_ConfidenceLevel](./set_confidencelevel/) | Legt das Konfidenzniveau fest, das dem Prozentsatz der Zeit entspricht, in der die tatsächlich erzeugten Werte innerhalb optimistischer und pessimistischer Schätzungen liegen. Der Standardwert ist CL99. |
| [set_Distribution](./set_distribution/) | Legt die Wahrscheinlichkeitsverteilung fest, die in der Monte‑Carlo‑Simulation verwendet wird. Der Standardwert ist ProbabilityDistributionType.Normal. |
| [set_Optimistic](./set_optimistic/) | Legt den Prozentsatz der wahrscheinlichsten Aufgabendauer fest, die im bestmöglichen Projektszenario auftreten kann. Der Standardwert ist 75, was bedeutet, dass bei einer geschätzten Aufgabendauer von 4 Tagen die optimistische Dauer 3 Tage beträgt. |
| [set_Pessimistic](./set_pessimistic/) | Legt den Prozentsatz der wahrscheinlichsten Aufgabendauer fest, die im ungünstigsten Projektszenario auftreten kann. Der Standardwert ist 125, was bedeutet, dass bei einer geschätzten Aufgabendauer von 4 Tagen die pessimistische Dauer 5 Tage beträgt. |
