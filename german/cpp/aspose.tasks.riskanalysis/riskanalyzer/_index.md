## RiskAnalyzer class

Führt eine Monte‑Carlo‑Simulation basierend auf den angegebenen Risikoanalyse‑Einstellungen aus.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [RiskAnalyzer](./riskanalyzer/) | Initialisiert eine neue Instanz der Klasse RiskAnalyzer. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [Analyze](./analyze/) | Führt eine Risikoanalyse für das angegebene Projekt durch. Die Analyse basiert auf einer Monte‑Carlo‑Simulation und das Ergebnis ist eine Instanz der Klasse RiskAnalysisResult. |
| [get_Settings](./get_settings/) | Liest die Instanz der Klasse RiskAnalysisSettings, die die erforderlichen Einstellungen für die Risikoanalyse definiert. |
| [set_Settings](./set_settings/) | Setzt die Instanz der Klasse RiskAnalysisSettings, die die erforderlichen Einstellungen für die Risikoanalyse definiert. |
