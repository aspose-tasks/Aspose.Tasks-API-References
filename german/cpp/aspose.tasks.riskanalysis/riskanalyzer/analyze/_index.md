## Analyze {#analyze}

Führt eine Risikoanalyse für das angegebene Projekt durch. Die Analyse basiert auf einer Monte‑Carlo‑Simulation und das Ergebnis ist eine Instanz der Klasse RiskAnalysisResult.

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| Parameter | Beschreibung |
| --- | --- |
| project | die angegebene Instanz der Klasse Project zum Analysieren. |
