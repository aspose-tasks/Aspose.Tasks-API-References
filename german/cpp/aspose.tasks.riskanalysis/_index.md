## Aspose::Tasks::RiskAnalysis namespace

Der Namensraum Aspose::Tasks::RiskAnalysis enthält die Kerntypen, die zum Konfigurieren, Ausführen und Abrufen von Ergebnissen von Risikosimulationen verwendet werden, einschließlich Einstellungen, Muster, statistischer Sammlungen und des Analysators selbst. Diese Objekte ermöglichen Entwicklern, Unsicherheit zu modellieren, mehrere Iterationen durchzuführen und die Auswirkungen auf Aufgabendaten sowie den gesamten Projektabschluss zu bewerten.


## Klassen

| Name | Beschreibung |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | Stellt ein Ergebnis der Risikoanalyse dar. |
| [RiskAnalysisSettings](./riskanalysissettings/) | Gibt Einstellungen für die Durchführung einer Risikoanalyse an. |
| [RiskAnalyzer](./riskanalyzer/) | Führt eine Monte‑Carlo‑Simulation basierend auf den angegebenen Risikoanalyse‑Einstellungen aus. |
| [RiskItemStatistics](./riskitemstatistics/) | Stellt ein Element dar, das statistische Daten für die Aufgabe des analysierten pr speichert. |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | Stellt eine Sammlung dar, die die Instanzen der Klasse RiskItemStatistics enthält |
| [RiskPattern](./riskpattern/) | Stellt ein Risikomuster für eine Projektaufgabe dar. |
| [RiskPatternCollection](./riskpatterncollection/) | Stellt eine Sammlung dar, die die Instanzen der Klasse RiskPattern enthält. |
