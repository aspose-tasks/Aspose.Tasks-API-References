## GetPercentile {#getpercentile}

Liefert einen Wert, unter dem ein bestimmter Prozentsatz der erzeugten Stichproben liegt.

**Returns:** a value below which a specified percentage of generated samples fall.

```cpp
GetPercentile(int32_t percent)
```

| Parameter | Beschreibung |
| --- | --- |
| Prozent | der angegebene Prozentsatz zwischen 0 und 100. |
