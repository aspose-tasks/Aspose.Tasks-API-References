## RiskItemStatistics class

Stellt ein Element dar, das statistische Daten für die Aufgabe des analysierten Projekts speichert.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | Liefert den erwarteten Wert des Risiko‑Elements. |
| [get_ItemType](./get_itemtype/) | Liefert eine Instanz der Aufzählung RiskItemType. |
| [get_Maximum](./get_maximum/) | Liefert den maximalen Wert, der während der Monte‑Carlo‑Simulation erzeugt wurde. |
| [get_Minimum](./get_minimum/) | Liefert den minimalen Wert, der während der Monte‑Carlo‑Simulation erzeugt wurde. |
| [get_StandardDeviation](./get_standarddeviation/) | Liefert die Standardabweichung des Risiko‑Elements. |
| [GetPercentile](./getpercentile/) | Liefert einen Wert, unter dem ein bestimmter Prozentsatz der erzeugten Stichproben liegt. |
| [ToString](./tostring/) | Gibt eine kurze Zeichenketten‑Darstellung eines Risiko‑Elements zurück. Die genauen Details der Darstellung sind nicht spezifiziert und können sich ändern. |
