## Aspose::Tasks::Connectivity namespace

Verwenden Sie diese Typen, um Verbindungen zu Microsoft Project Server‑Datenbanken (MspDbSettings), Primavera‑Datenbanken (PrimaveraDbSettings), MPD‑Dateien (MpdSettings) oder generischen Datenbankquellen (DbSettings) zu konfigurieren. Der Namespace zentralisiert die Konfigurations‑Konnektivität für nahtlose Integration mit den Datenextraktions‑ und Manipulations‑Funktionen von Aspose.Tasks.


## Klassen

| Name | Beschreibung |
| --- | --- |
| [DbSettings](./dbsettings/) | Ermöglicht das Angeben von Einstellungen zum Lesen aus der Projektdatenbank. |
| [MpdSettings](./mpdsettings/) | Ermöglicht das Festlegen notwendiger Optionen zum Lesen von Projektdaten aus dem MPD‑Format (MS Access |
| [MspDbSettings](./mspdbsettings/) | Ermöglicht das Festlegen notwendiger Optionen zum Lesen von Projektdaten aus MS Project Server‑Daten. |
| [PrimaveraDbSettings](./primaveradbsettings/) | Ermöglicht das Festlegen notwendiger Optionen zum Lesen von Projektdaten aus einer Primavera‑Datenbank. |
