## LevelingOptions class

Ermöglicht das Angeben von Parametern des Ressourcen‑Levelings.

## Konstruktoren

| Name | Beschreibung |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Initialisiert eine neue Instanz der Klasse LevelingOptions. |

## Methoden

| Name | Beschreibung |
| --- | --- |
| [get_FinishDate](./get_finishdate/) | Ruft das Enddatum des Leveling‑Zeitraums ab. Der Standardwert ist das `project`s` Abschlussdatum. |
| [get_LevelingOrder](./get_levelingorder/) | Ruft die Reihenfolge ab, in der der Leveling‑Algorithmus Aufgaben mit Überbelegungen verzögert. Nachdem die Aufgaben, die die Überbelegung verursachen, und welche Aufgaben verzögert werden können, ermittelt wurden, wird die angegebene Reihenfolge verwendet, um zu bestimmen, welche Aufgabe zuerst verzögert werden soll. |
| [get_MessageHandler](./get_messagehandler/) | Ruft den Callback des Nachrichtenhandlers ab, der verwendet werden kann, um Protokollnachrichten abzufangen, die von Aspose.Tasks während der Ressourcenlevelung erzeugt werden. |
| [get_MessageLevel](./get_messagelevel/) | Ruft das Protokollierungslevel der von Aspose.Tasks während der Ressourcenlevelung ausgegebenen Meldungen ab. |
| [get_Resources](./get_resources/) | Ruft die Liste der Ressourcen ab, die levelt werden sollen. Wenn null gesetzt ist, werden alle Projektressourcen levelt. |
| [get_StartDate](./get_startdate/) | Ruft das Startdatum des Leveling‑Zeitraums ab. Der Standardwert ist das `project`s` Startdatum. |
| [set_FinishDate](./set_finishdate/) | Setzt das Enddatum des Leveling‑Zeitraums. Der Standardwert ist das `project`s` Abschlussdatum. |
| [set_LevelingOrder](./set_levelingorder/) | Ruft die Reihenfolge ab, in der der Leveling‑Algorithmus Aufgaben mit Überbelegungen verzögert. Nachdem die Aufgaben, die die Überbelegung verursachen, und welche Aufgaben verzögert werden können, ermittelt wurden, wird die angegebene Reihenfolge verwendet, um zu bestimmen, welche Aufgabe zuerst verzögert werden soll. |
| [set_MessageHandler](./set_messagehandler/) | Setzt den Callback des Nachrichtenhandlers, der verwendet werden kann, um Protokollnachrichten abzufangen, die von Aspose.Tasks während der Ressourcenlevelung erzeugt werden. |
| [set_MessageLevel](./set_messagelevel/) | Setzt das Protokollierungslevel der von Aspose.Tasks während der Ressourcenlevelung ausgegebenen Meldungen. |
| [set_Resources](./set_resources/) | Setzt die Liste der Ressourcen, die levelt werden sollen. Wenn null gesetzt ist, werden alle Projektressourcen levelt. |
| [set_StartDate](./set_startdate/) | Setzt das Startdatum des Leveling‑Zeitraums. Der Standardwert ist das `project`s` Startdatum. |
