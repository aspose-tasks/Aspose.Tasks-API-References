## Aspose::Tasks::Leveling namespace

Verwenden Sie LevelingOptions, um Leveling‑Parameter anzugeben, ResourceLeveler, um den Leveling‑Vorgang auszuführen, und LevelingResult, um die Ergebnisse zu erhalten. Dieses Namespace bietet feinkörnige Kontrolle über die Ressourcenzuweisung und Konfliktlösung innerhalb von Aspose.Tasks.


## Klassen

| Name | Beschreibung |
| --- | --- |
| [LevelingOptions](./levelingoptions/) | Ermöglicht das Angeben von Parametern des Ressourcen‑Levelings. |
| [LevelingResult](./levelingresult/) | Stellt die Ergebnisse des Ressourcen‑Levelings dar. |
| [ResourceLeveler](./resourceleveler/) | Enthält Methoden für das Ressourcen‑Leveling. |
