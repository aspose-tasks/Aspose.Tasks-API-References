## set_ViewSettings {#set_viewsettings}

Définit une vue ( View ) à rendre. Vous pouvez utiliser cette option pour spécifier explicitement quelle vue doit être enregistrée aux formats PDF, HTML ou Image. Si cette propriété est définie, la propriété Visualization::PresentationFormat est ignorée lors de l'enregistrement du projet. La vue doit provenir de l'un des écrans suivants (( Aspose::Tasks::View::Screen )) : (Gantt, TaskSheet, TaskUsage, ResourceSheet, ResourceUsage).
