## XlsxOptions class

**Inherits:** Aspose::Tasks::Saving::SimpleSaveOptions

Permet de spécifier des options supplémentaires lors du rendu des pages du projet en XLSX.

## Constructeurs

| Nom | Description |
| --- | --- |
| [XlsxOptions](./xlsxoptions/) | Initialise une nouvelle instance de la classe XlsxOptions qui peut être utilisée pour enregistrer le projet au format XLSX. |

## Méthodes

| Nom | Description |
| --- | --- |
| [get_AssignmentView](./get_assignmentview/) | Obtient une liste des colonnes de vue des affectations à rendre ( AssignmentViewColumn ). |
| [get_Encoding](./get_encoding/) | Obtient l'encodage du fichier XLSX résultant. La valeur par défaut est System::Text::Encoding::UTF8. |
| [get_ResourceView](./get_resourceview/) | Obtient une liste des colonnes de vue des ressources à rendre ( ResourceViewColumn ). |
| [get_View](./get_view/) | Obtient une liste des colonnes de vue ( GanttChartColumn ) à enregistrer au format XLSX. Si aucune n'est définie, les colonnes par défaut sont enregistrées. |
| [set_AssignmentView](./set_assignmentview/) | Définit une liste des colonnes de vue des affectations à rendre ( AssignmentViewColumn ). |
| [set_Encoding](./set_encoding/) | Définit l'encodage du fichier XLSX résultant. La valeur par défaut est System::Text::Encoding::UTF8. |
| [set_ResourceView](./set_resourceview/) | Définit une liste des colonnes de vue des ressources à rendre ( ResourceViewColumn ). |
| [set_View](./set_view/) | Définit une liste des colonnes de vue ( GanttChartColumn ) à enregistrer au format XLSX. Si aucune n'est définie, les colonnes par défaut sont enregistrées. |
