## SaveTemplateOptions class

Permet de spécifier des options supplémentaires lors de l'enregistrement d'un projet en tant que modèle.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_RemoveActualValues](./get_removeactualvalues/) | Obtient une valeur indiquant si toutes les valeurs réelles d'un modèle de projet doivent être supprimées. |
| [get_RemoveBaselineValues](./get_removebaselinevalues/) | Obtient une valeur indiquant si toutes les valeurs de référence d'un modèle de projet doivent être supprimées. |
| [get_RemoveFixedCosts](./get_removefixedcosts/) | Obtient une valeur indiquant si tous les coûts fixes d'un modèle de projet doivent être supprimés. |
| [get_RemoveResourceRates](./get_removeresourcerates/) | Obtient une valeur indiquant si les tarifs des ressources d'un modèle de projet doivent être supprimés. |
| [set_RemoveActualValues](./set_removeactualvalues/) | Définit une valeur indiquant si toutes les valeurs réelles d'un modèle de projet doivent être supprimées. |
| [set_RemoveBaselineValues](./set_removebaselinevalues/) | Définit une valeur indiquant si toutes les valeurs de référence d'un modèle de projet doivent être supprimées. |
| [set_RemoveFixedCosts](./set_removefixedcosts/) | Définit une valeur indiquant si tous les coûts fixes d'un modèle de projet doivent être supprimés. |
