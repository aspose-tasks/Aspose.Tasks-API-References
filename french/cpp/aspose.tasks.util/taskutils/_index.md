## TaskUtils class

Classe d'aide qui fournit des opérations utiles sur les tâches.

## Méthodes

| Nom | Description |
| --- | --- |
| [Apply](./apply/) | Applique l'algorithme spécifié à chaque tâche d'un arbre. |
| [Filter](./filter/) | Construit un nouvel arbre de tâches qui satisfont la condition. |
| [Find](./find/) | Trouve une tâche qui satisfait la condition dans un arbre de tâches. |
| [TaskChildrenCount](./taskchildrencount/) | Calcule récursivement le nombre de sous‑tâches d'une tâche à tous les niveaux. |
