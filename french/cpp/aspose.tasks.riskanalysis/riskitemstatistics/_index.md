## RiskItemStatistics class

Représente un élément qui stocke les données statistiques pour la tâche du projet analysé.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_ExpectedValue](./get_expectedvalue/) | Obtient la valeur attendue de l'élément de risque. |
| [get_ItemType](./get_itemtype/) | Obtient une instance de l'énumération RiskItemType. |
| [get_Maximum](./get_maximum/) | Obtient la valeur maximale qui a été générée lors de la simulation Monte Carlo. |
| [get_Minimum](./get_minimum/) | Obtient la valeur minimale qui a été générée lors de la simulation Monte Carlo. |
| [get_StandardDeviation](./get_standarddeviation/) | Obtient l'écart type de l'élément de risque. |
| [GetPercentile](./getpercentile/) | Obtient une valeur en dessous de laquelle un pourcentage spécifié d'échantillons générés se situe. |
| [ToString](./tostring/) | Renvoie une représentation courte sous forme de chaîne d'un élément de risque. Les détails exacts de la représentation ne sont pas spécifiés et peuvent changer. |
