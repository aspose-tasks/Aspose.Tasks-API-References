## Analyze {#analyze}

Effectue une analyse de risque pour le projet spécifié. L'analyse est basée sur une simulation Monte Carlo et le résultat est une instance de la classe RiskAnalysisResult.

**Returns:** the instance of the RiskAnalysisResult which represents a result of the analysis.

```cpp
Analyze(const System::SharedPtr< Project > & project)
```

| Paramètre | Description |
| --- | --- |
| projet | l'instance spécifiée de la classe Project à analyser. |
