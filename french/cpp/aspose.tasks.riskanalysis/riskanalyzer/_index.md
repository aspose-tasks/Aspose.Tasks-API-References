## RiskAnalyzer class

Effectue une simulation de Monte Carlo basée sur les paramètres d'analyse des risques spécifiés.

## Constructeurs

| Nom | Description |
| --- | --- |
| [RiskAnalyzer](./riskanalyzer/) | Initialise une nouvelle instance de la classe RiskAnalyzer. |

## Méthodes

| Nom | Description |
| --- | --- |
| [Analyze](./analyze/) | Effectue une analyse de risque pour le projet spécifié. L'analyse est basée sur une simulation Monte Carlo et le résultat est une instance de la classe RiskAnalysisResult. |
| [get_Settings](./get_settings/) | Obtient l'instance de la classe RiskAnalysisSettings qui définit les paramètres nécessaires à l'analyse de risque. |
| [set_Settings](./set_settings/) | Définit l'instance de la classe RiskAnalysisSettings qui définit les paramètres nécessaires à l'analyse de risque. |
