## RiskPattern class

Représente un modèle de risque pour une tâche de projet.

## Constructeurs

| Nom | Description |
| --- | --- |
| [RiskPattern](./riskpattern/) | Initialise une nouvelle instance de la classe RiskPattern. |

## Méthodes

| Nom | Description |
| --- | --- |
| [get_ConfidenceLevel](./get_confidencelevel/) | Obtient le niveau de confiance qui correspond au pourcentage du temps où les valeurs réellement générées seront comprises entre les estimations optimistes et pessimistes. La valeur par défaut est CL99. |
| [get_Distribution](./get_distribution/) | Obtient la distribution de probabilité utilisée dans la simulation Monte Carlo. La valeur par défaut est ProbabilityDistributionType.Normal. |
| [get_Optimistic](./get_optimistic/) | Obtient le pourcentage de la durée de tâche la plus probable qui peut se produire dans le meilleur scénario de projet possible. La valeur par défaut est 75, ce qui signifie que si la durée de tâche estimée spécifiée est de 4 jours, alors la durée optimiste sera de 3 jours. |
| [get_Pessimistic](./get_pessimistic/) | Obtient le pourcentage de la durée de tâche la plus probable qui peut se produire dans le pire scénario de projet possible. La valeur par défaut est 125, ce qui signifie que si la durée de tâche estimée spécifiée est de 4 jours, alors la durée pessimiste sera de 5 jours. |
| [get_Task](./get_task/) | Obtient une tâche de projet à laquelle ce modèle de risque est appliqué. |
| [set_ConfidenceLevel](./set_confidencelevel/) | Définit le niveau de confiance qui correspond au pourcentage du temps où les valeurs réellement générées seront comprises entre les estimations optimistes et pessimistes. La valeur par défaut est CL99. |
| [set_Distribution](./set_distribution/) | Définit la distribution de probabilité utilisée dans la simulation Monte Carlo. La valeur par défaut est ProbabilityDistributionType.Normal. |
| [set_Optimistic](./set_optimistic/) | Définit le pourcentage de la durée de tâche la plus probable qui peut se produire dans le meilleur scénario de projet possible. La valeur par défaut est 75, ce qui signifie que si la durée de tâche estimée spécifiée est de 4 jours, alors la durée optimiste sera de 3 jours. |
| [set_Pessimistic](./set_pessimistic/) | Définit le pourcentage de la durée de tâche la plus probable qui peut se produire dans le pire scénario de projet possible. La valeur par défaut est 125, ce qui signifie que si la durée de tâche estimée spécifiée est de 4 jours, alors la durée pessimiste sera de 5 jours. |
