L'API propose un modèle d'objets riche pour gérer les formats Project XML, MPX, MPP et Primavera XER, en prenant en charge les tâches, les ressources, les affectations, les calendriers et les champs personnalisés. Sa fonctionnalité est organisée en neuf espaces de noms : Aspose::Tasks pour les entités de base, Connectivity pour les entrées/sorties de fichiers, Leveling pour le nivellement des ressources, Primavera pour les objets spécifiques à Primavera, Properties pour les attributs étendus, RiskAnalysis pour la modélisation de risque Monte‑Carlo, Saving pour les options d'exportation, Util pour les utilitaires d'aide, et Visualization pour le rendu des diagrammes de Gantt et des rapports.
