## ProjectServerManager class

La classe qui fournit les méthodes pour lire et effectuer des opérations sur les projets dans le compte Project Online spécifié ou dans l'instance Project Server on-premise spécifiée (les versions 2016 et 2019 de Project Server sont prises en charge).

## Constructeurs

| Nom | Description |
| --- | --- |
| [ProjectServerManager](./projectservermanager/) | Initialise une nouvelle instance de la classe ProjectServerManager. |

## Méthodes

| Nom | Description |
| --- | --- |
| [CreateNewProject (2 overloads)](./createnewproject/) | Crée un nouveau projet dans l'instance Project Server\Project Online en utilisant les options d'enregistrement par défaut. |
| [GetProject](./getproject/) | Récupère le projet avec le guid spécifié depuis le compte Project Online \ instance Project Server. |
| [GetProjectList](./getprojectlist/) | Récupère la liste des projets du magasin 'Working' du compte Project Online actuel \ instance Project Server. |
| [GetProjectRawData](./getprojectrawdata/) | Récupère les données binaires du projet à des fins de dépannage. |
| [UpdateProject (2 overloads)](./updateproject/) | Met à jour le projet existant dans l'instance Project Server\Project Online en utilisant les options d'enregistrement par défaut. Le projet existant sera écrasé. |
| [ExecutingWebRequest](./executingwebrequest/) | Un événement qui est déclenché lorsque la requête web est envoyée à l'API web de Project Server. |
