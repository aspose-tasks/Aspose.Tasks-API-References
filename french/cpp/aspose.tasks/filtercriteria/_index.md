## FilterCriteria class

Définit les critères que les tâches ou ressources doivent satisfaire pour être affichés dans la vue MSP.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_CriteriaRows](./get_criteriarows/) | Obtient la liste des lignes enfant FilterCriteria. Si le filtre contient plus d'une ligne de critère, l'effet d'un opérateur And est que les critères des deux lignes doivent être remplis pour que la tâche ou la ressource soit affichée en résultat de ce filtre. L'effet d'un opérateur Or est que les critères d'une des deux lignes doivent être remplis. |
| [get_Field](./get_field/) | Obtient un champ à modifier. |
| [get_Operation](./get_operation/) | Obtient le critère établi avec FieldName, Test et Value qui se rapporte aux autres critères du filtre. |
| [get_Test](./get_test/) | Obtient le type de comparaison effectué entre FieldName et Value qui sert de critère de sélection pour le filtre. FilterComparisonType |
| [get_Values](./get_values/) | Obtient les valeurs d'objet à comparer avec la valeur du champ spécifié par FieldName. |
| [IsFieldValue](./isfieldvalue/) | Obtient si la valeur à droite de FilterCriteria est une référence de champ, et non une valeur constante. |
| [set_Field](./set_field/) | Définit un champ à modifier. |
| [set_Operation](./set_operation/) | Définit le critère établi avec FieldName, Test et Value qui se rapporte aux autres critères du filtre. |
| [set_Test](./set_test/) | Définit le type de comparaison effectué entre FieldName et Value qui sert de critère de sélection pour le filtre. FilterComparisonType |
| [SetValueField](./setvaluefield/) | Définit le champ dont la valeur sera comparée à la valeur du champ spécifié par FieldName. |
| [ToString](./tostring/) | Renvoie la représentation sous forme de chaîne de l'instance de la classe FilterCriteria. |
