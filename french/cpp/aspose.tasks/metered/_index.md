## Metered class

Fournit des méthodes pour définir la clé mesurée.

Dans cet exemple, une tentative sera faite de définir la clé publique et privée mesurée <ms>

```cpp
[C#]
 
Metered metered = new Metered();
metered.SetMeteredKey("PublicKey", "PrivateKey");
 
 
[Visual Basic]
 
Dim metered As Metered = New Metered
metered.SetMeteredKey("PublicKey", "PrivateKey")
```

</ms> <java> le fichier jar du composant :

```cpp
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

</java>

| Nom | Description |
