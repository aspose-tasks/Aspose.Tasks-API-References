## PrimaveraBaseReader class

Représente un lecteur de base qui peut être utilisé pour lire les UID de projet à partir de fichiers Primavera XER ou XML multi‑projets.

## Méthodes

| Nom | Description |
| --- | --- |
| [GetProjectInfos](./getprojectinfos/) | Renvoie une liste des objets d'informations courtes du projet. |
| [GetProjectUids](./getprojectuids/) | Renvoie une liste des identifiants uniques des projets. |
| [LoadProject](./loadproject/) | Charge le projet avec l'identifiant unique spécifié. |
