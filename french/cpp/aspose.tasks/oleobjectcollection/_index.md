## OleObjectCollection class

Représente une collection contenant les instances de la classe OleObject.

## Méthodes

| Nom | Description |
| --- | --- |
| [Clear](./clear/) | Efface la collection. Afin de persister ces modifications, project.Save doit être appelé avec new MPPSaveOptions { WriteViewData = true; } |
| [GetEnumerator](./getenumerator/) | Renvoie un énumérateur pour cette collection. |
| [ToList](./tolist/) | Convertit l'instance de la classe OleObjectCollection en une liste contenant les instances de la classe OleObject. |
