## FilterCollection class

Contient une liste d'objets Filter. Implémente l'interface ICollection< Filter >.

## Méthodes

| Nom | Description |
| --- | --- |
| [Add](./add/) | Ajoute l'élément spécifié à cette collection. |
| [Clear](./clear/) | Supprime tous les éléments de cette collection. |
| [Contains](./contains/) | Renvoie vrai si l'élément spécifié est trouvé dans cette collection ; sinon, faux. |
| [CopyTo](./copyto/) | Copie les éléments de cette collection dans le tableau spécifié, en commençant à l'index de tableau spécifié. |
| [get_Count](./get_count/) | Obtient le nombre d'éléments contenus dans cette collection. |
| [get_IsReadOnly](./get_isreadonly/) | Obtient une valeur indiquant si cette collection est en lecture seule ; sinon, false. |
| [GetEnumerator](./getenumerator/) | Renvoie un énumérateur pour cette collection. |
| [Remove](./remove/) | Supprime la première occurrence d'un objet spécifique de cette collection. |
| [ToList](./tolist/) | Convertit une collection de filtres en une liste d'objets Filter. |
