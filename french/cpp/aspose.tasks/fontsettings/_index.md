## FontSettings class

Spécifie les paramètres de police utilisés lors du rendu de la vue du projet.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_DefaultFontName](./get_defaultfontname/) | Obtient la police par défaut (ou de secours) pour le rendu. |
| [get_FontResolveCallback](./get_fontresolvecallback/) | Obtient un rappel qui peut être utilisé pour personnaliser les polices résolues. |
| [get_UseProjectDefaultFont](./get_useprojectdefaultfont/) | Obtient une valeur indiquant si la police par défaut doit être utilisée pour le rendu. |
| [set_DefaultFontName](./set_defaultfontname/) | Définit la police par défaut (ou de secours) pour le rendu. |
| [set_FontResolveCallback](./set_fontresolvecallback/) | Définit un rappel qui peut être utilisé pour personnaliser les polices résolues. |
| [set_UseProjectDefaultFont](./set_useprojectdefaultfont/) | Définit une valeur indiquant si la police par défaut doit être utilisée pour le rendu. |
| [SetFontFolders](./setfontfolders/) | Définit les dossiers où Aspose.Tasks recherche les polices TrueType lors du rendu de la vue du projet. |
