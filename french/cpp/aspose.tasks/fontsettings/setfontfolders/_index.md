## SetFontFolders {#setfontfolders}

Définit les dossiers où Aspose.Tasks recherche les polices TrueType lors du rendu de la vue du projet.

**Returns:** void Aspose::Tasks::

```cpp
SetFontFolders(const System::ArrayPtr< System::String > & fontFolders, bool recursive)
```

| Paramètre | Description |
| --- | --- |
| fontFolders | Un tableau de dossiers contenant des polices TrueType. |
| recursive | Si true les dossiers spécifiés seront analysés de manière récursive. |
