## get_ProjectName {#get_projectname}

Obtient le nom d'un projet qui est affiché dans la liste des projets Project Server \ Project Online. Il doit être unique au sein de l'instance Project Server \ Project Online. Si la valeur est omise, la valeur de la propriété Prj.Name sera utilisée à la place.

**Returns:** System::String Aspose::Tasks::

```cpp
get_ProjectName()
```
