## ProjectServerSaveOptions class

Permet de spécifier des options supplémentaires lorsque le projet est enregistré sur Project Server ou Project Online.

## Constructeurs

| Nom | Description |
| --- | --- |
| [ProjectServerSaveOptions](./projectserversaveoptions/) | Initialise une nouvelle instance de la classe ProjectServerSaveOptions. |

## Méthodes

| Nom | Description |

| [get_ProjectGuid](./get_projectguid/) | Obtient l'identifiant unique d'un projet. Il doit être unique au sein de l'instance Project Server \ Project Online. |
| [get_ProjectName](./get_projectname/) | Obtient le nom d'un projet qui est affiché dans la liste des projets Project Server \ Project Online. Il doit être unique au sein de l'instance de Project Server \ Project Online. Si la valeur est omise, la valeur de la propriété Prj.Name sera utilisée à la place. |
