## PropertyContainer< T > class

Représente le conteneur de propriétés.

## Méthodes

| Nom | Description |
| --- | --- |
| [CheckPropAndGet](./checkpropandget/) | Renvoie la valeur à laquelle la propriété est mappée dans ce conteneur. Si ce conteneur ne contient pas l'enregistrement ProjectItem, il sera ajouté avec la valeur par défaut et la valeur par défaut sera renvoyée. |
| [CheckPropAndSet](./checkpropandset/) | Mappe la propriété spécifiée à la valeur spécifiée dans ce conteneur. Si ce conteneur ne contient pas l'enregistrement ProjectItem, il sera ajouté. |
