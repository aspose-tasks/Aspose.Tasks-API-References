## CheckPropAndGet {#checkpropandget}

Renvoie la valeur à laquelle la propriété est mappée dans ce conteneur. Si ce conteneur ne contient pas l'enregistrement ProjectItem, il sera ajouté avec la valeur par défaut et la valeur par défaut sera renvoyée.

**Returns:** the value to which the property is mapped in this container or default value for property.

```cpp
CheckPropAndGet(const Key < TValue, T > & key)
```

| Paramètre | Description |
| --- | --- |
| clé | la propriété spécifiée. |
