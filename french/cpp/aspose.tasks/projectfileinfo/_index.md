## ProjectFileInfo class

L'instance de la classe contient des informations sur le format du fichier de projet et la version de Microsoft Project avec laquelle le fichier a été créé.

Utilisez la propriété CanRead pour définir que la bibliothèque peut traiter le fichier de projet.
