## OutlineCode class

Représente une valeur d'un code de contour.

Deux éléments de données sont nécessaires – un pointeur vers la table du code de plan spécifiée par le FieldId, et la valeur spécifiée soit par le ValueId, soit par le pointeur ValueGuid vers la liste des valeurs.
