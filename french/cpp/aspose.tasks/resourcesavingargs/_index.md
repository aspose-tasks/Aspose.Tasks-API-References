## ResourceSavingArgs class

Cette classe représente un ensemble de données liées à l'enregistrement du fichier de ressource externe qui se produit lors de la conversion au format HTML.

## Méthodes

| Nom | Description |
| --- | --- |
| [CloseStreamIfRequired](./closestreamifrequired/) | Fermez le flux si KeepStreamOpen est faux, sinon videz-le. |
| [get_FileName](./get_filename/) | Obtient le nom de fichier supposé qui passe du convertisseur au code de la méthode personnalisée. Peut être utilisé dans le code personnalisé pour décider comment le traiter ou où enregistrer ce fichier. |
| [get_KeepStreamOpen](./get_keepstreamopen/) | Obtient une valeur indiquant si le flux restera ouvert après la fin de l'enregistrement de la ressource. |
| [get_Stream](./get_stream/) | Obtient le contenu binaire du fichier enregistré. |
| [get_Uri](./get_uri/) | Obtient l'URI de la ressource. |
| [set_FileName](./set_filename/) | Définit le nom de fichier supposé qui passe du convertisseur au code de la méthode personnalisée. Peut être utilisé dans le code personnalisé pour décider comment le traiter ou où enregistrer ce fichier. |
| [set_KeepStreamOpen](./set_keepstreamopen/) | Définit une valeur indiquant si le flux restera ouvert après la fin de l'enregistrement de la ressource. |
| [set_Stream](./set_stream/) | Définit le contenu binaire du fichier enregistré. |
| [set_Uri](./set_uri/) | Définit l'URI de la ressource. |
