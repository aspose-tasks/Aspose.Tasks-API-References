## IsDayWorking {#isdayworking}

Détermine si le jour spécifié est un jour ouvrable selon le calendrier.

**Returns:** True if the day is a working day.

```cpp
IsDayWorking(System::DateTime dt)
```

| Paramètre | Description |
| --- | --- |
| dt | La date à vérifier pour savoir si le jour est ouvrable. |
