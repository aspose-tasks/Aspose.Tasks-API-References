## Rate class

Représente une définition d'une période de temps et des tarifs applicables à une ressource pendant cette période.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_CostPerUse](./get_costperuse/) | Obtient le coût par utilisation d'une ressource. Cette valeur est récupérée à partir de la date actuelle si un tableau de tarifs existe pour une ressource. |
| [get_OvertimeRate](./get_overtimerate/) | Obtient le taux des heures supplémentaires par heure pour une ressource. |
| [get_OvertimeRateFormat](./get_overtimerateformat/) | Obtient les unités utilisées par Microsoft Project pour afficher le taux des heures supplémentaires. |
| [get_RatesFrom](./get_ratesfrom/) | Obtient la date à laquelle un tarif devient effectif. |
| [get_RatesTo](./get_ratesto/) | Obtient la dernière date à laquelle un tarif est effectif. |
| [get_RateTable](./get_ratetable/) | Obtient l'identifiant unique d'un tableau de tarifs pour une ressource. |
| [get_StandardRate](./get_standardrate/) | Obtient le taux standard par heure pour une ressource. |
| [get_StandardRateFormat](./get_standardrateformat/) | Obtient les unités utilisées par Microsoft Project pour afficher le taux standard. |
| [set_CostPerUse](./set_costperuse/) | Définit le coût par utilisation d'une ressource. Cette valeur est récupérée à partir de la date actuelle si un tableau de tarifs existe pour une ressource. |
| [set_OvertimeRate](./set_overtimerate/) | Définit le taux des heures supplémentaires par heure pour une ressource. |
| [set_OvertimeRateFormat](./set_overtimerateformat/) | Définit les unités utilisées par Microsoft Project pour afficher le taux des heures supplémentaires. |
| [set_RatesFrom](./set_ratesfrom/) | Définit la date à laquelle un tarif devient effectif. |
| [set_RatesTo](./set_ratesto/) | Définit la dernière date à laquelle un tarif est effectif. |
| [set_RateTable](./set_ratetable/) | Définit l'identifiant unique d'un tableau de tarifs pour une ressource. |
| [set_StandardRate](./set_standardrate/) | Définit le taux standard par heure pour une ressource. |
| [set_StandardRateFormat](./set_standardrateformat/) | Définit les unités utilisées par Microsoft Project pour afficher le taux standard. |
