## PageSettings class

Représente les paramètres d'impression pour une page de la vue du projet.

## Constructeurs

| Nom | Description |
| --- | --- |
| [PageSettings](./pagesettings/) | Initialise une nouvelle instance de la classe PageSettings. Représente les paramètres d'impression pour une page de la vue du projet. |

## Méthodes

| Nom | Description |
| --- | --- |
| [get_AdjustToPercentOfNormalSize](./get_adjusttopercentofnormalsize/) | Obtient une valeur indiquant s'il faut ajuster l'impression au pourcentage spécifié ( PercentOfNormalSize ) de la taille normale. |
| [get_FirstPageNumber](./get_firstpagenumber/) | Obtient le numéro de la première page pour l'impression. |
| [get_IsPortrait](./get_isportrait/) | Obtient une valeur indiquant si l'orientation de la page est portrait ; renvoie false si l'orientation de la page est paysage. |
| [get_PagesInHeight](./get_pagesinheight/) | Obtient le nombre de pages en hauteur à imprimer. |
| [get_PagesInWidth](./get_pagesinwidth/) | Obtient un nombre de pages en largeur à imprimer. |
| [get_PaperSize](./get_papersize/) | Obtient une taille de papier. Peut être l'une des valeurs de l'énumération PrinterPaperSize. |
| [get_PaperSizeId](./get_papersizeid/) | Obtient un entier représentant l'une des valeurs de PrinterPaperSize ou un identifiant de taille de page personnalisé. Cette valeur peut être utilisée pour obtenir PaperSize à partir des paramètres du système d'exploitation. |
| [get_PercentOfNormalSize](./get_percentofnormalsize/) | Obtient un pourcentage de la taille normale pour ajuster l'impression. |
| [set_AdjustToPercentOfNormalSize](./set_adjusttopercentofnormalsize/) | Définit une valeur indiquant s'il faut ajuster l'impression au pourcentage spécifié ( PercentOfNormalSize ) de la taille normale. |
| [set_FirstPageNumber](./set_firstpagenumber/) | Définit le numéro de première page pour l'impression. |
| [set_IsPortrait](./set_isportrait/) | Définit une valeur indiquant si l'orientation de la page est portrait ; renvoie false si l'orientation de la page est paysage. |
| [set_PagesInHeight](./set_pagesinheight/) | Définit un nombre de pages en hauteur à imprimer. |
| [set_PagesInWidth](./set_pagesinwidth/) | Définit un nombre de pages en largeur à imprimer. |
| [set_PaperSize](./set_papersize/) | Définit une taille de papier. Peut être l'une des valeurs de l'énumération PrinterPaperSize. |
| [set_PaperSizeId](./set_papersizeid/) | Définit un entier représentant l'une des valeurs de PrinterPaperSize ou un identifiant de taille de page personnalisé. Cette valeur peut être utilisée pour obtenir PaperSize à partir des paramètres du système d'exploitation. |
| [set_PercentOfNormalSize](./set_percentofnormalsize/) | Définit un pourcentage de la taille normale pour ajuster l'impression. |
