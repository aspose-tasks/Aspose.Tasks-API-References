## PageInfo class

Représente les données de configuration de page présentes dans le format de fichier MPP et utilisées pour l'impression.

## Constructeurs

| Nom | Description |
| --- | --- |
| [PageInfo](./pageinfo/) | Initialise une nouvelle instance de la classe PageInfo. Représente les données de configuration de page présentes dans le format de fichier MPP et utilisées pour l'impression. |

## Méthodes

| Nom | Description |
| --- | --- |
| [get_Footer](./get_footer/) | Obtient une instance de la classe HeaderFooterInfo qui représente des données de pied de page. |
| [get_Header](./get_header/) | Obtient l'instance de la classe HeaderFooterInfo qui représente des données d'en-tête. |
| [get_Legend](./get_legend/) | Obtient une instance de la classe PageLegend qui spécifie les options de rendu de la légende de page. |

| [get_PageSettings](./get_pagesettings/) | Obtient une instance de la classe PageSettings qui spécifie les paramètres d'impression de la page. |
