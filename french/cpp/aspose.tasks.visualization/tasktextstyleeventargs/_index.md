## TaskTextStyleEventArgs class

Cette classe représente un ensemble de données liées au rendu du contenu d'une cellule de tableau.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_CellTextStyle](./get_celltextstyle/) | Obtient TextStyle qui sera utilisé pour dessiner le contenu de la cellule. Cet objet peut être utilisé pour personnaliser l'apparence d'une cellule de tableau. |
| [get_Column](./get_column/) | Obtient ViewColumn auquel appartient la cellule actuellement rendue. |
| [get_Task](./get_task/) | Obtient Task qui correspond à la ligne actuellement rendue. |
| [set_CellTextStyle](./set_celltextstyle/) | Définit TextStyle qui sera utilisé pour dessiner le contenu de la cellule. Cet objet peut être utilisé pour personnaliser l'apparence d'une cellule de tableau. |
