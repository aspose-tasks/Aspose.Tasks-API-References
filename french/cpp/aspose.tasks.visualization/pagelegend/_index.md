## PageLegend class

**Inherits:** Aspose::Tasks::Visualization::HeaderFooterInfo

Représente une légende de page qui est utilisée pour l'impression du projet.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_LegendOn](./get_legendon/) | Obtient les pages sur lesquelles la légende apparaît. Peut être l'une des valeurs de l'énumération Legend. |
| [get_Width](./get_width/) | Obtient la largeur de la partie gauche (contenant le nom du projet et la date par défaut) de la légende en centimètres. |
| [set_LegendOn](./set_legendon/) | Définit les pages sur lesquelles la légende apparaît. Peut être l'une des valeurs de l'énumération Legend. |
| [set_Width](./set_width/) | Définit la largeur de la partie gauche (contenant le nom du projet et la date par défaut) de la légende en centimètres. |
