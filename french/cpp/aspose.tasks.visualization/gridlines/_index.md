## Gridlines class

Représente les lignes de grille qui apparaissent dans une vue GanttChart.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_Interval](./get_interval/) | Obtient le nombre de 0 à 99 qui spécifie l'intervalle entre les lignes de grille. |
| [get_IntervalColor](./get_intervalcolor/) | Obtient la couleur des lignes de grille secondaires. |
| [get_IntervalPattern](./get_intervalpattern/) | Obtient le motif de ligne pour les lignes de grille secondaires. |
| [get_NormalColor](./get_normalcolor/) | Obtient la couleur des lignes de grille normales. |
| [get_NormalPattern](./get_normalpattern/) | Obtient le motif de ligne pour les lignes de grille normales. |
| [get_Type](./get_type/) | Obtient le type de ligne de grille. |
| [set_Interval](./set_interval/) | Définit le nombre de 0 à 99 qui spécifie l'intervalle entre les lignes de grille. |
| [set_IntervalColor](./set_intervalcolor/) | Définit la couleur des lignes de grille secondaires. |
| [set_IntervalPattern](./set_intervalpattern/) | Définit le motif de ligne pour les lignes de grille secondaires. |
| [set_NormalColor](./set_normalcolor/) | Définit la couleur des lignes de grille normales. |
| [set_NormalPattern](./set_normalpattern/) | Définit le motif de ligne pour les lignes de grille normales. |
| [set_Type](./set_type/) | Définit le type de ligne de grille. |
