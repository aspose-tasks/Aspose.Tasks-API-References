## PrimaveraProjectInfo class

Représente des informations succinctes sur un projet chargé au format Primavera.

## Méthodes

| Nom | Description |
| --- | --- |
| [get_ExportFlag](./get_exportflag/) | Obtient le drapeau d'exportation du projet. Lorsqu'un projet est sélectionné pour l'exportation dans Primavera, son ExportFlag est vrai. Certains projets non explicitement sélectionnés pour l'exportation peuvent être exportés vers un fichier XER en raison de leur relation avec le projet exporté. |
| [get_Name](./get_name/) | Obtient le nom du projet. |
| [get_Uid](./get_uid/) | Obtient l'Uid du projet. |
