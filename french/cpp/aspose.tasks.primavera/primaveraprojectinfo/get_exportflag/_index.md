## get_ExportFlag {#get_exportflag}

Obtient le drapeau d'exportation du projet. Lorsqu'un projet est sélectionné pour l'exportation dans Primavera, son ExportFlag est vrai. Certains projets non explicitement sélectionnés pour l'exportation peuvent être exportés vers un fichier XER en raison de leur relation avec le projet exporté.
