Contient des classes pour créer le Rapport d'analyse des risques.

## Classes
| Classe | Description |
| :- | :- |
| [RiskAnalysisResult](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysisresult/) | Représente un résultat d'analyse de risque. |
| [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) | Spécifie les paramètres pour effectuer une analyse de risque. |
| [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/) | Effectue une simulation Monte Carlo basée sur les paramètres d'analyse de risque spécifiés. |
| [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/) | Représente un élément qui stocke les données statistiques pour la tâche du projet analysé. |
| [RiskItemStatisticsCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatisticscollection/) | Représente une collection contenant les instances de la classe [RiskItemStatistics](/tasks/python-net/aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/) | Représente un modèle de risque pour une tâche de projet. |
| [RiskPatternCollection](/tasks/python-net/aspose.tasks.riskanalysis/riskpatterncollection/) | Représente une collection contenant les instances de la classe [RiskPattern](/tasks/python-net/aspose.tasks.riskanalysis/riskpattern/). |
