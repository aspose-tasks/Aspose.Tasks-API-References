## RiskItemStatistics class

Représente un élément qui stocke les données statistiques pour la tâche du projet analysé.

Le type RiskItemStatistics expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| item_type | Obtient une instance de l'énumération [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/). |
| minimum | Obtient la valeur minimale qui a été générée lors de la simulation de Monte Carlo. |
| maximum | Obtient la valeur maximale qui a été générée lors de la simulation de Monte Carlo. |
| expected_value | Obtient la valeur attendue de l'élément de risque. |
| standard_deviation | Obtient l'écart type de l'élément de risque. |
## Méthodes
| Nom | Description |
| :- | :- |
| get_percentile(percent) | Obtient une valeur en dessous de laquelle un pourcentage spécifié d'échantillons générés se situe. |
