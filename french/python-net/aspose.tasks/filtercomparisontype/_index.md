## FilterComparisonType enumeration

Le type de comparaison effectué entre FieldName et Value qui sert de critère de sélection pour un filtre ou un indicateur graphique.

## Members
| Nom du membre | Description |
| :- | :- |
| EQUALS | La valeur de Field est égale à Value. |
| DOES_NOT_EQUAL | La valeur de Field n'est pas égale à Value. |
| IS_GREATER_THAN | La valeur de Field est supérieure à Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | La valeur de Field est supérieure ou égale à Value. |
| IS_LESS_THAN | La valeur de Field est inférieure à Value. |
| IS_LESS_THAN_OR_EQUAL_TO | La valeur de Field est inférieure ou égale à Value. |
| IS_WITHIN | La valeur de Field est comprise dans Value. |
| IS_NOT_WITHIN | La valeur de Field n'est pas dans Value. |
| CONTIENT | La valeur de Field contient Value. |
| NE_CONTIENT_PAS | La valeur de Field ne contient pas Value. |
| CONTIENT_EXACTEMENT | La valeur de Field contient exactement Value. |
| EST_UN_DE | La valeur de Field est égale à l'une des Values spécifiées. Utilisé dans AutoFilters. |
| NON_DÉFINI | Valeur indéfinie. |
| EST_NIMPORTE_QUE_VALEUR | Condition 'Is any value'. Applicable aux indicateurs graphiques. |
