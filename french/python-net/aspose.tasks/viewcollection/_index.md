## ViewCollection class

Contient une liste d'objets [View](/tasks/python-net/aspose.tasks/view/).<br/>            Implémente l'interface ICollection<View>.

Le type ViewCollection expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| parent_project | Obtient le parent de l'objet View.<br/>            Lecture seule [Project](/tasks/python-net/aspose.tasks/project/). |
## Méthodes
| Nom | Description |
| :- | :- |
| to_list() | Convertit une collection de vues en une liste d'objets [View](/tasks/python-net/aspose.tasks/view/). |
| get_by_view_screen(screen) | Recherche une View avec la propriété Screen spécifiée, et renvoie la première occurrence dans la collection. |
| get_by_name(view_name) | Recherche une View avec le nom, et renvoie la première occurrence dans la collection. |
