## TimelineView class

Représente une vue de chronologie d'un projet.

Le type TimelineView expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TimelineView() | Initialise une nouvelle instance de la classe [TimelineView](/tasks/python-net/aspose.tasks/timelineview/). |
