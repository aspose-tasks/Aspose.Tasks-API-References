## FontSavingArgs class

Cette classe représente un ensemble de données liées à l'enregistrement du fichier de polices externes qui<br/>              se produit lors de la conversion au format HTML.

Le type FontSavingArgs expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| FontSavingArgs() | Initialise une nouvelle instance de la classe FontSavingArgs |
## Propriétés
| Nom | Description |
| :- | :- |
| file_name | Obtient ou définit le nom de fichier supposé qui passe du convertisseur au code de la méthode personnalisée.<br/>             Peut être utilisé dans le code personnalisé pour décider comment le traiter ou où enregistrer ce fichier. |
| keep_stream_open | Obtient ou définit une valeur indiquant si le flux restera ouvert après la fin de l'enregistrement de la ressource. |
| stream | Obtient ou définit le contenu binaire du fichier enregistré. |
| uri | Obtient ou définit l'URI de la ressource. |
## Méthodes
| Nom | Description |
| :- | :- |
| close_stream_if_required() | Ferme le flux si KeepStreamOpen est faux, sinon le vide. |
