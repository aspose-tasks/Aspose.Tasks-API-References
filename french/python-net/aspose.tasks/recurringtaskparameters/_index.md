## RecurringTaskParameters class

Représente l'ensemble des paramètres utilisés pour créer une tâche récurrente dans un projet.

Le type RecurringTaskParameters expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| RecurringTaskParameters() | Initialise une nouvelle instance de la classe [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Propriétés
| Nom | Description |
| :- | :- |
| duration | Obtient ou définit la durée d'une occurrence de la tâche récurrente. |
| ignore_resource_calendar | Obtient ou définit une valeur indiquant s'il faut planifier la tâche récurrente même si aucune ressource n'est disponible pour la réaliser. |
| recurrence_pattern | Obtient ou définit le modèle de récurrence de la tâche récurrente. |
| task_name | Obtient ou définit le nom de la tâche récurrente. |
## Méthodes
| Nom | Description |
| :- | :- |
| set_calendar(project, calendar_name) | Définit un calendrier pour la tâche récurrente. Le calendrier est sélectionné parmi la collection de calendriers du projet. |
