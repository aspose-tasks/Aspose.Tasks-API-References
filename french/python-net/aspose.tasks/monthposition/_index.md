## MonthPosition enumeration

Spécifie la position d'un élément du mois au sein d'un mois.

## Members
| Nom du membre | Description |
| :- | :- |
| NON_DÉFINI | Indique une position de mois non définie. |
| FIRST | Indique la première position du mois. |
| SECOND | Indique la deuxième position du mois. |
| THIRD | Indique la troisième position du mois. |
| FOURTH | Indique la quatrième position du mois. |
| LAST | Indique la dernière position du mois. |
