## Méthodes
| Nom | Description |
| :- | :- |
| get_timephased_data(start, end, timephased_type) | Renvoie l'objet [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) avec les valeurs [timephased_data](/tasks/python-net/aspose.tasks/task/) entre les dates de début et de fin données du type de données temporelles spécifié. |
| get_timephased_data(start, end) | Renvoie l'objet [TimephasedDataCollection](/tasks/python-net/aspose.tasks/timephaseddatacollection/) avec les valeurs [timephased_data](/tasks/python-net/aspose.tasks/task/) entre les dates de début et de fin données du type de données temporelles spécifié. |
| move_to_sibling(before_task) | Déplace la tâche actuelle au même niveau d'outline avant la tâche spécifiée.<br/>            Si ParentProject.CalculationMode est None, l'utilisateur doit appeler Project.Recalculate() après avoir utilisé cette méthode (cela replanifiera toutes les tâches du projet (dates de début/fin, définit les dates anticipées/retardées) et calculera les champs dépendants tels que les marges, le travail et les champs de coût, les niveaux d'outline).<br/>            Si ParentProject.CalculationMode est Manual, la méthode calculera uniquement l'ID de la tâche, le niveau d'outline et les numéros d'outline automatiquement.<br/>            Si ParentProject.CalculationMode est Automatic, la méthode replanifie automatiquement toutes les tâches du projet<br/>            (dates de début/fin, définit les dates anticipées/retardées, calcule les marges, le travail et les champs de coût, recalcul les IDs et les niveaux d'outline). |
| move_to_sibling(before_task_id) |  |
| select_all_child_tasks() | Collecte récursivement toutes les tâches enfants de cette tâche. |

| equals(other) | Renvoie une valeur indiquant si cette instance est égale à une tâche spécifiée. |
| delete() | Supprime une tâche de la collection des tâches du projet parent et de toutes ses affectations. |
