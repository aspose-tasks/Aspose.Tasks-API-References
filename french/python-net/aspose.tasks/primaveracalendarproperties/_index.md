## PrimaveraCalendarProperties class

Représente les propriétés spécifiques à Primavera pour un calendrier lu à partir de fichiers Primavera (XER ou P6XML).<br/>            Peut être utilisé pour effectuer la conversion d'unités de temps spécifiques au calendrier.

Le type PrimaveraCalendarProperties expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| hours_per_day | Obtient le nombre d'heures par jour à partir des paramètres 'Time Periods' du calendrier. |
| hours_per_week | Obtient le nombre d'heures par semaine à partir des paramètres 'Time Periods' du calendrier. |
| hours_per_month | Obtient le nombre d'heures par mois à partir des paramètres 'Time Periods' du calendrier. |
| hours_per_year | Obtient le nombre d'heures par mois à partir des paramètres 'Time Periods' du calendrier. |
