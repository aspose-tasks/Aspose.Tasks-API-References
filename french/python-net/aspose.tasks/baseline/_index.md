## Baseline class

Représente les valeurs de ligne de base d'une ressource.

Le type Baseline expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Baseline() | Initialise une nouvelle instance de la classe Baseline |
## Propriétés
| Nom | Description |
| :- | :- |
| baseline_number | Obtient ou définit le numéro unique d'un enregistrement de données de ligne de base. |
| work | Obtient ou définit le travail assigné à une ressource lorsque la ligne de base est enregistrée. |
| cost | Obtient ou définit le coût projeté d'une ressource lorsque la ligne de base est enregistrée. |
| bcws | Obtient ou définit le coût budgétaire d'un travail planifié pour une ressource. |
| bcwp | Obtient ou définit le coût budgété d'un travail effectué par une ressource pour un projet à ce jour. |
