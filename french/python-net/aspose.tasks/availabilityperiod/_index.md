## AvailabilityPeriod class

Représente une période pendant laquelle une ressource est disponible.

Le type AvailabilityPeriod expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| AvailabilityPeriod() | Initialise une nouvelle instance de [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/). |
| AvailabilityPeriod(available_from, available_to, available_units) | Initialise une nouvelle instance de [AvailabilityPeriod](/tasks/python-net/aspose.tasks/availabilityperiod/) avec la plage de dates spécifiée et les unités disponibles. |
## Propriétés
| Nom | Description |
| :- | :- |
| available_from | Obtient ou définit la date à laquelle une ressource devient disponible pour la période spécifiée. |
| available_to | Obtient ou définit la dernière date à laquelle une ressource est disponible pour la période spécifiée. |
| available_units | Obtient ou définit le pourcentage d'une ressource qui est disponible pendant la période spécifiée. |
