## SummaryRowsCalculationType enumeration

Spécifie le type de calcul de la valeur d'un attribut personnalisé pour les lignes de résumé.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Indique que la valeur de l'attribut personnalisé pour les lignes de synthèse n'est pas calculée. |
| ROLLUP | Indique que la valeur de l'attribut personnalisé pour les lignes de synthèse est calculée à l'aide de la fonction d'agrégation définie dans [rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
| USE_FORMULA | Indique que la valeur de l'attribut personnalisé pour les lignes de synthèse est calculée à l'aide de la formule définie dans [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
