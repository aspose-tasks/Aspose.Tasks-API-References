## Group class

Représente une définition de groupe.<br/>            Un objet Group est un membre de la collection ResourceGroups ou de la collection TaskGroups.

Le type Group expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Group() | Initialise une nouvelle instance de la classe [Group](/tasks/python-net/aspose.tasks/group/). |
## Propriétés
| Nom | Description |
| :- | :- |
| name | Obtient ou définit le nom d'un objet Group. |
| uid | Obtient un identifiant unique d'un groupe. |
| show_summary | Obtient ou définit une valeur indiquant si les lignes de résumé sont affichées pour le groupe. |
| maintain_hierarchy | Obtient ou définit une valeur indiquant s'il faut afficher tous les niveaux des tâches de résumé pour les sous‑tâches au sein du groupe. |
| show_in_menu | Obtient ou définit une valeur indiquant si Project affiche le nom du groupe dans la liste déroulante Group du Ruban. |
| group_assignments | Obtient ou définit une valeur indiquant si les affectations doivent être regroupées au lieu des tâches. |
| group_criteria | Obtient ou définit une collection GroupCriteria représentant les champs d'une définition de groupe. |
