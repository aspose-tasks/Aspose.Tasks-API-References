## MessageLevel enumeration

Définit les niveaux de verbosité de message possibles.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Ne pas afficher les messages. |
| ERROR | Afficher uniquement les messages d'erreur. |
| CRITICAL | Afficher les messages critiques. |
| WARNING | Afficher les avertissements. |
| INFORMATION | Afficher les messages d'information. |
| VERBOSE | Afficher les messages de débogage. |
