## CalculationMode enumeration

Spécifie le mode de calcul du projet.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Aucun. Les dates et les coûts du projet ne sont pas recalculés dans ce mode. |
| AUTOMATIC | Mode automatique. Les dates et les coûts du projet sont recalculés lors de l’utilisation de ce mode. |
| MANUAL | Mode manuel. Seuls les champs nécessaires sont recalculés dans ce mode, par exemple les UID et les ID des objets. |
