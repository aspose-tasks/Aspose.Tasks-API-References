## FontResolveEventArgs class

Fournit les arguments pour le rappel qui est invoqué lorsque la police est résolue.

Le type FontResolveEventArgs expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| requested_font_name | Obtient le nom de la police demandée. |
| resolved_font_name | Obtient ou définit le nom de la police résolue. Peut être défini pour contrôler les polices utilisées pour rendre une vue. |
