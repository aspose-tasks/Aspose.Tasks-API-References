## TaskLink class

Représente un lien prédécesseur.

Le type TaskLink expose les membres suivants:
## Propriétés
| Nom | Description |
| :- | :- |
| is_cross_project | Obtient ou définit une valeur indiquant si un prédécesseur fait partie d’un autre projet. |
| cross_project_name | Obtient ou définit le projet prédécesseur externe. |
| link_lag | Obtient ou définit le retard en dixièmes de minute ou en pourcentage. |
| link_lag_time_span | Obtient ou définit la durée du retard, selon le LagFormat. |
| lag_format | Obtient ou définit le format d’expression du retard. |
| pred_task | Obtient ou définit la tâche prédécesseur. |
| succ_task | Obtient ou définit la tâche successeur. |
| link_type | Obtient ou définit le type d’un lien. |
