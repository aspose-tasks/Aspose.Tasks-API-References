## PrimaveraTaskProperties class

Représente les propriétés spécifiques à Primavera pour une tâche lue à partir de fichiers Primavera (XER ou P6XML).

Le type PrimaveraTaskProperties expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| sequence_number | Obtient ou définit le numéro de séquence de l'élément WBS (tâches récapitulatives). Il est utilisé pour trier les tâches récapitulatives dans Primavera. |
| activity_id | Obtient un champ d'identifiant d'activité - l'identifiant unique d'une tâche utilisé par Primavera. |
| remaining_early_finish | Obtient la date de fin anticipée restante - la date à laquelle le travail restant pour l'activité est prévu d'être terminé. |
| remaining_early_start | Obtient la date de début anticipée restante - la date à laquelle le travail restant pour l'activité est prévu de commencer. |
| remaining_late_start | Obtient la date de début tardif restante. |
| remaining_late_finish | Obtient la date de fin tardive restante. |
| raw_duration_type | Obtient la représentation texte brute (comme dans le fichier source) du champ 'Duration Type' de l'activité. |
| duration_type | Obtient la valeur du champ 'Duration Type' de l'activité. |
| raw_activity_type | Obtient la représentation texte brute (comme dans le fichier source) du champ 'Activity Type' de l'activité. |
| activity_type | Obtient la valeur du champ 'Activity Type'. |
| percent_complete_type | Obtient la valeur du champ '% Complete Type' de l'activité. |
| raw_complete_percent_type | Obtient la représentation texte brute (comme dans le fichier source) du champ '% Complete Type' de l'activité. |
| raw_status | Obtient la représentation texte brute (comme dans le fichier source) du champ 'Status' de l'activité. |
| physical_percent_complete | Obtient la valeur de Physical Percent Complete. |
| duration_percent_complete | Obtient la valeur de duration percent complete. |
| units_percent_complete | Obtient la valeur de units percent complete. |
| actual_labor_units | Obtient la valeur de actual labor units. |
| actual_non_labor_units | Obtient la valeur de actual non labor units. |
| remaining_labor_units | Obtient la valeur de remaining labor units. |
| remaining_non_labor_units | Obtient la valeur de remaining non labor units. |
| actual_labor_cost | Obtient la valeur de actual labor cost. |
| budgeted_labor_cost | Obtient la valeur de budgeted (or planned) labor cost. |
| actual_nonlabor_cost | Obtient la valeur de actual non labor cost. |
| budgeted_nonlabor_cost | Obtient la valeur de budgeted (or planned) non labor cost. |
| actual_material_cost | Obtient la valeur du coût réel du matériel. |
| budgeted_material_cost | Obtient la valeur du coût budgété (ou prévu) du matériel. |
| actual_expense_cost | Obtient la valeur du coût réel des dépenses. |
| remaining_expense_cost | Obtient la valeur du coût restant des dépenses. |
| budgeted_expense_cost | Obtient la valeur du coût budgété (ou prévu) des dépenses. |
| actual_total_cost | Obtient la valeur totale des coûts réels. |
| budgeted_total_cost | Obtient la valeur totale des coûts budgétés (ou prévus). |
| primary_constraint_type | Obtient un type de contrainte principale. |
| primary_constraint_date | Obtient la date de la contrainte principale. |
| secondary_constraint_type | Obtient un type de contrainte secondaire. |
| secondary_constraint_date | Obtient la date de la contrainte secondaire. |
| planned_duration | Obtient la durée originale ou prévue — le temps de travail total entre la date de début prévue de la tâche et la date de fin prévue. |
