## FontSettings class

Spécifie les paramètres de police utilisés lors du rendu de la vue du projet.

Le type FontSettings expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| FontSettings() | Initialise une nouvelle instance de la classe FontSettings |
## Propriétés
| Nom | Description |
| :- | :- |
| default_font_name | Obtient ou définit la police par défaut (ou de secours) pour le rendu. |
| use_project_default_font | Obtient ou définit une valeur indiquant si la police par défaut doit être utilisée pour le rendu. |
