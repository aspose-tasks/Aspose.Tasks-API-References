## ProjectFileInfo class

L'instance de classe contient des informations sur le format du fichier projet et la version de Microsoft Project où<br/>            le fichier a été créé.

Le type ProjectFileInfo expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| can_read | Obtient une valeur indiquant si les définitions peuvent être traitées par Aspose.Tasks le fichier de projet. |
| is_password_protected | Obtient une valeur indiquant si un projet est protégé par mot de passe. |
| project_file_format | Obtient le format du fichier de projet. |
| project_application_info | Obtient les informations d'application du fichier de projet. |
