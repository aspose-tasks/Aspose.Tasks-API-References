## OleObject class

Représente un objet OLE qui peut être inséré dans la vue du diagramme de Gantt d'un fichier MPP.

Le type OleObject expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| OleObject() | Initialise une nouvelle instance de la classe [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Propriétés
| Nom | Description |
| :- | :- |
| name | Obtient ou définit le nom de l'instance de l'objet OLE. |
| application_name | Obtient ou définit le nom de l'application avec laquelle ouvrir l'objet intégré. |
| file_format | Obtient ou définit le format de fichier de l'objet intégré. |
| content | Obtient ou définit les données du fichier intégré ; null si aucune donnée n'a été intégrée. |
| label | Obtient ou définit l'étiquette de l'objet inséré. |
| full_path | Obtient ou définit le chemin complet de l'objet inséré. |
| temporary_file | Obtient ou définit le chemin du fichier temporaire de l'objet inséré. |
| display_as_icon | Obtient ou définit un indicateur indiquant que l'objet OLE doit être affiché soit sous forme d'icône, soit sous forme de son image normale. |
| lié | Obtient une valeur indiquant si le fichier de projet ne contient qu'un lien vers les données réelles stockées à la source du lien. |
| view | Obtient ou définit l'instance de la classe [view](/tasks/python-net/aspose.tasks/oleobject/) à laquelle appartient l'objet inséré. |
| id | Obtient ou définit l'identifiant de l'objet. |
