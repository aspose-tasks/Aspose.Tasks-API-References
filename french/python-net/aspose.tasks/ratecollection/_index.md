## RateCollection class

Représente une collection qui contient des objets [Rate](/tasks/python-net/aspose.tasks/rate/).

Le type RateCollection expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| count | Obtient le nombre d'éléments contenus dans le RateCollection. |
| is_read_only | Obtient une valeur indiquant si cette collection est en lecture seule. |
| parent_resource | Obtient l'objet parent [Resource](/tasks/python-net/aspose.tasks/resource/) pour cette collection. |
## Méthodes
| Nom | Description |
| :- | :- |
| add(rates_from) | Ajoute une nouvelle instance de [Rate](/tasks/python-net/aspose.tasks/rate/) à cette collection. |
| add(rates_from, type) | Ajoute une nouvelle instance de [Rate](/tasks/python-net/aspose.tasks/rate/) à cette collection. |
| to_list() | Convertit l'objet [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) en une liste d'objets [Rate](/tasks/python-net/aspose.tasks/rate/). |
| to_list(type) | Convertit l'objet [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/) en une liste d'objets [Rate](/tasks/python-net/aspose.tasks/rate/) filtrée par le type [RateType](/tasks/python-net/aspose.tasks/ratetype/) spécifié. |
| remove(item) | Supprime l'instance Rate de cette collection. |
