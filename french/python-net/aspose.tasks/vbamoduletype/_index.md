## VbaModuleType enumeration

Spécifie le type d'un module dans un projet VBA.

## Members
| Nom du membre | Description |
| :- | :- |
| DOCUMENT_MODULE | Un type d'élément de projet VBA qui spécifie un module pour les macros intégrées et les opérations d'accès programmatique associées à un document. |
| PROCEDURAL_MODULE | Un module contenant une collection de sous-routines et de fonctions. |
| CLASS_MODULE | Un module qui contient la définition d’un nouvel objet. Chaque instance d’une classe crée un nouvel objet, et les procédures définies dans le module deviennent des propriétés et des méthodes de l’objet. |
| DESIGNER_MODULE | Un module qui étend les méthodes et les propriétés d’un contrôle ActiveX qui a été enregistré dans le projet. |
