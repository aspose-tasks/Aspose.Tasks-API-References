## CalculationType enumeration

Spécifie le type de calcul de la valeur de l'attribut personnalisé.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Indique que l'attribut étendu n'a pas de table de correspondance de formule et stocke simplement la valeur définie par l'utilisateur. |
| LOOKUP | Indique que la valeur de l'attribut étendu est limitée aux valeurs d'une table de correspondance. |
| FORMULA | Indique que la valeur de l'attribut étendu est calculée à l'aide de la formule définie dans [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
