## Propriétés
| Nom | Description |
| :- | :- |
| name | Obtient ou définit le nom d'un objet Table. |
| show_in_menu | Obtient ou définit une valeur indiquant si le projet affiche le nom du tableau dans la liste déroulante Tables de l'onglet Affichage du ruban. |
| table_fields | Obtient une collection TableFields représentant les champs du tableau. |
| table_type | Obtient ou définit le type de tableau pour le tableau spécifié. |
| uid | Obtient l'identifiant unique d'un tableau. |
| row_height | Obtient ou définit la hauteur de la ligne dans un tableau, où la hauteur de la ligne correspond au nombre de lignes de texte. |
| date_format | Obtient ou définit le format de date du tableau. |
| adjust_header_row_height | Obtient ou définit une valeur indiquant si la hauteur de la ligne d'en-tête du tableau peut être ajustée. |
| show_add_new_column | Obtient ou définit une valeur indiquant s'il faut afficher l'interface « Add New Column ». |
| lock_first_column | Obtient ou définit une valeur indiquant si la première colonne d'un tableau est verrouillée ou modifiable. |
