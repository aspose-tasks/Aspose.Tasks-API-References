## Rate class

Représente une définition d'une période de temps et des tarifs applicables à une ressource pendant cette période.

Le type Taux expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| rates_from | Obtient ou définit la date à laquelle un taux devient effectif. |
| rates_to | Obtient ou définit la dernière date à laquelle un taux est effectif. |
| rate_table | Obtient ou définit l'identifiant unique d'une table de taux pour une ressource. |
| standard_rate | Obtient ou définit le taux standard par heure pour une ressource. |
| standard_rate_format | Obtient ou définit les unités utilisées par Microsoft Project pour afficher le taux standard. |
| overtime_rate | Obtient ou définit le taux des heures supplémentaires par heure pour une ressource. |
| overtime_rate_format | Obtient ou définit les unités utilisées par Microsoft Project pour afficher le taux des heures supplémentaires. |
| cost_per_use | Obtient ou définit le coût par utilisation d'une ressource. Cette valeur est récupérée à la date actuelle si une table de taux existe pour la ressource. |
