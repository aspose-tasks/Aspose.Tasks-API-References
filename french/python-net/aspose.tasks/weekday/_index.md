## WeekDay class

Représente un jour de la semaine qui définit soit des jours réguliers d'une semaine, soit des jours d'exception dans un calendrier.

Le type WeekDay expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| WeekDay(day_type) | Initialise une nouvelle instance de la classe [WeekDay](/tasks/python-net/aspose.tasks/weekday/) avec le type de jour spécifié. |
| WeekDay(day_type, working_times) | Initialise une nouvelle instance de la classe WeekDay |
| WeekDay(day_type, working_times) | Initialise une nouvelle instance de la classe [WeekDay](/tasks/python-net/aspose.tasks/weekday/) avec le type de jour spécifié et les périodes de temps de travail. |
| WeekDay() | Initialise une nouvelle instance de la classe [WeekDay](/tasks/python-net/aspose.tasks/weekday/) avec le type de jour spécifié. |
## Propriétés
| Nom | Description |
| :- | :- |
| day_type | Obtient le type d'un jour. |
| day_working | Obtient ou définit une valeur indiquant si la date ou le type de jour spécifié est travaillé. |
| from_date | Obtient ou définit le début d'une période d'exception. |
| to_date | Obtient ou définit la fin d'une période d'exception. |
| working_times | Obtient WorkingTimeCollection pour cette instance WeekDay.<br/>            La collection des temps de travail qui définissent le temps travaillé pendant le jour de la semaine. |
## Méthodes
| Nom | Description |
| :- | :- |
| create_default_working_day(day_type) | Crée un jour de travail par défaut. |
| set_default_working_time(day) | Définit les périodes de temps par défaut pour le jour de la semaine spécifié. |
| get_working_time() | Renvoie le temps de travail pour un jour de la semaine. |
| clone() | Renvoie une copie profonde du jour de la semaine. |
