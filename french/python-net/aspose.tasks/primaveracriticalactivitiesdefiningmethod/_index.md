## PrimaveraCriticalActivitiesDefiningMethod enumeration

Spécifie la méthode de définition des activités critiques dans Primavera.

## Members
| Nom du membre | Description |
| :- | :- |
| TOTAL_FLOAT | Les activités dont le TotalSlack (Marge totale dans Primavera) est inférieur ou égal à la valeur de [critical_total_float_limit](/tasks/python-net/aspose.tasks/primaveraprojectproperties/) sont marquées comme critiques. |
| LONGEST_PATH | Les activités sur le chemin le plus long sont marquées comme critiques. |
