## GraphicalIndicatorCriteria class

Représente un critère d'indicateur graphique associé à un attribut étendu.

Le type GraphicalIndicatorCriteria expose les membres suivants:
## Constructeurs
| Nom | Description |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Initialise une nouvelle instance de la classe GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Initialise une nouvelle instance de la classe GraphicalIndicatorCriteria |
## Propriétés
| Nom | Description |
| :- | :- |
| test | Obtient le type de comparaison effectué entre la valeur de l'attribut étendu et les Valeurs qui sert de critère pour l'application de l'indicateur graphique.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Obtient la valeur utilisée pour tester la valeur de l'attribut étendu. |
| value2 | Obtient la deuxième valeur utilisée pour tester la valeur de l'attribut étendu dans le cas des types de comparaison 'IsWithin' et 'IsNotWithin'. |
| image_index | Obtient l'index de l'image à afficher lorsque le champ répond aux critères. |
| row_type | Obtient la valeur de l'énumération [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) qui indique pour quelles lignes l'indicateur est appliqué. |
