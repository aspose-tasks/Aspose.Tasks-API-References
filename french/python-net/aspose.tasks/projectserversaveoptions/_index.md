## ProjectServerSaveOptions class

Permet de spécifier des options supplémentaires lorsque le projet est enregistré sur Project Server ou Project Online.

Le type ProjectServerSaveOptions expose les membres suivants:
## Constructeurs
| Nom | Description |
| :- | :- |
| ProjectServerSaveOptions() | Initialise une nouvelle instance de la classe [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/). |
## Propriétés
| Nom | Description |
| :- | :- |
| project_name | Obtient ou définit le nom d'un projet qui est affiché dans la liste des projets Project Server \ Project Online. Doit être unique au sein de l'instance Project Server \ Project Online.<br/>            Si la valeur est omise, la valeur de la propriété Prj.Name sera utilisée à la place. |
| project_guid | Obtient ou définit l'identifiant unique d'un projet. Doit être unique au sein de l'instance Project Server \ Project Online. |
| timeout | Obtient ou définit le délai d'attente utilisé lors de l'attente du traitement de la demande d'enregistrement du projet par le service de traitement de la file d'attente d'un Project Server. La valeur par défaut de cette propriété est de 1 minute. |
| polling_interval | Obtient ou définit l'intervalle entre les requêtes d'état des travaux de la file d'attente. La valeur par défaut est de 2 secondes. |
