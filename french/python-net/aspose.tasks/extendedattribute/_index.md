## ExtendedAttribute class

Représente des attributs étendus.

Le type ExtendedAttribute expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| attribute_definition | Obtient la définition de l'attribut. |
| field_id | Obtient l'identifiant d'un champ. |
| duration_value | Obtient ou définit la valeur des attributs de type 'Duration'. |
| numeric_value | Obtient ou définit une valeur pour les attributs de types numériques (Cost, Number). |
| date_value | Obtient ou définit une valeur pour les attributs de types date (Date, Start, Finish). |
| flag_value | Obtient ou définit une valeur indiquant si un drapeau est défini pour un attribut de type 'Flag'. |
| text_value | Obtient ou définit une valeur pour les attributs de type 'Text'. |
| value_guid | Obtient le GUID d'une valeur de recherche. |
| value_read_only | Obtient une valeur indiquant si la valeur de cette instance [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) est en lecture seule. |
| is_error_value | Obtient si le calcul de la valeur de l'attribut étendu a entraîné une erreur. |
