## TaskStatus enumeration

Spécifie le statut d'une tâche.

## Members
| Nom du membre | Description |
| :- | :- |
| NON_DÉFINI | Statut de tâche non défini. |
| COMPLETE | La tâche est terminée à 100 %. |
| ON_SCHEDULE | La tâche est à l'heure si le pourcentage cumulé temporel complet est réparti au moins jusqu'au jour précédant la date d'état. |
| LATE | La tâche est en retard si le pourcentage cumulé temporel complet n'atteint pas minuit le jour précédant la date d'état. |
| FUTURE | Le statut de tâche « Future » est défini lorsque la date de début de la tâche est supérieure à la date du statut. |
