## PrimaveraBaseReader class

Représente un lecteur de base qui peut être utilisé pour lire les UID de projet à partir de fichiers Primavera XER ou XML multi‑projets.

Le type PrimaveraBaseReader expose les membres suivants :
## Méthodes
| Nom | Description |
| :- | :- |
| get_project_uids() | Renvoie une liste des identifiants uniques des projets. |
| get_project_infos() | Renvoie une liste des objets d'informations courtes du projet. |
| load_project(project_uid) | Charge le projet avec l'identifiant unique spécifié. |
