## OutlineCodeDefinition class

Représente une définition de code de plan.

Le type OutlineCodeDefinition expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| OutlineCodeDefinition() | Initialise une nouvelle instance de la classe [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/). |
## Propriétés
| Nom | Description |
| :- | :- |
| guid | Obtient ou définit le Guid d'un code de plan. |
| field_id | Obtient ou définit le numéro de champ d'un code de plan. |
| field_name | Obtient ou définit le nom d'un code de plan personnalisé. |
| alias | Obtient ou définit l'alias d'un code de plan personnalisé. |
| phonetic_alias | Obtient ou définit la prononciation phonétique de l'alias du code de plan personnalisé. |
| values | Obtient l'objet OutlineValueCollection.<br/>            Les valeurs du tableau associé à ce code de plan. |
| enterprise | Obtient ou définit une valeur indiquant si un code de plan personnalisé est un code de plan personnalisé d'entreprise. |
| enterprise_outline_code_alias | Obtient ou définit une référence à un autre champ personnalisé pour lequel cette définition de code de plan est un alias. |
| resource_substitution_enabled | Obtient ou définit une valeur indiquant si le code de plan personnalisé peut être utilisé<br/>            par l'assistant de substitution de ressources dans Microsoft Project. |
| leaf_only | Obtient ou définit une valeur indiquant si les valeurs spécifiées dans ce champ de code de plan doivent être des valeurs feuille. |
| all_levels_required | Obtient ou définit une valeur indiquant si les nouveaux codes doivent comporter tous les niveaux.<br/>            Non disponible pour les codes d'entreprise. |
| only_table_values_allowed | Obtient ou définit une valeur indiquant si les valeurs spécifiées doivent provenir de la table des valeurs. |
| masks | Obtient l'objet OutlineMaskCollection.<br/>            Le tableau des entrées qui définissent le masque du code de plan.<br/>            Instance en lecture seule de [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/). |
| show_indent | Obtient ou définit une valeur indiquant si les retraits de ce code de plan doivent être affichés. |
