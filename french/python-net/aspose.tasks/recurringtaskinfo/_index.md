## RecurringTaskInfo class

Représente les détails d'une tâche récurrente dans un projet.

Le type RecurringTaskInfo expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| recurrence_pattern | Obtient ou définit un modèle de récurrence de la tâche récurrente. |
| start_date | Obtient ou définit la date de début des occurrences. |
| end_date | Obtient ou définit la date de fin des occurrences. |
| duration | Obtient ou définit la durée d'une occurrence de la tâche récurrente. |
| occurrences | Obtient ou définit le nombre d'occurrences de la tâche récurrente. |
| use_end_date | Obtient ou définit une valeur indiquant s'il faut utiliser la date de fin ou un nombre d'occurrences pour la tâche récurrente. |
| daily_repetitions | Obtient ou définit le nombre de répétitions pour le modèle de récurrence quotidien. |
| daily_use_workdays | Obtient ou définit une valeur indiquant s'il faut utiliser les jours ouvrés pour le modèle de récurrence quotidien. |
| weekly_repetitions | Obtient ou définit un nombre de répétitions pour le modèle de récurrence hebdomadaire. |
| weekly_days | Obtient ou définit une collection de jours utilisés dans le modèle de récurrence hebdomadaire. |
| monthly_use_ordinal_day | Obtient ou définit une valeur indiquant s'il faut utiliser le jour ordinal pour le modèle de récurrence mensuel. |
| monthly_ordinal_number | Obtient ou définit un numéro ordinal du modèle de récurrence mensuel. |
| monthly_ordinal_repetitions | Obtient ou définit un nombre de répétitions pour le modèle de récurrence mensuel lorsqu'on utilise le jour ordinal. |
| monthly_day | Obtient ou définit un nombre de jours du modèle de récurrence mensuel. |
| monthly_repetitions | Obtient ou définit un nombre de répétitions pour le modèle de récurrence mensuel. |
| yearly_use_ordinal_day | Obtient ou définit une valeur indiquant s'il faut utiliser le jour ordinal pour le modèle de récurrence annuel. |
| yearly_date | Obtient ou définit une date pour le modèle de récurrence annuel. |
| yearly_ordinal_number | Obtient ou définit un numéro ordinal du modèle de récurrence annuel. |
| yearly_ordinal_month | Obtient ou définit un mois du modèle de récurrence annuel lorsqu'on utilise le jour ordinal. |
| task | Obtient la tâche parente de cette instance de la classe [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
