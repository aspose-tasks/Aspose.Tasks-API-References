## Value class

Représente une valeur dans une liste de valeurs.

Le type Value expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Value() | Initialise une nouvelle instance de la classe [Value](/tasks/python-net/aspose.tasks/value/). |
## Propriétés
| Nom | Description |
| :- | :- |
| id | Obtient ou définit l'identifiant unique d'une valeur dans l'ensemble d'un projet. |
| value_guid | Obtient un GUID qui identifie cette valeur parmi les autres dans l'ensemble du projet. |
| val | Obtient ou définit la valeur réelle dans la représentation interne. Privilégiez l'utilisation de propriétés fortement typées qui sont listées ci-dessous. |
| string_value | Obtient ou définit la valeur réelle utilisée pour représenter une chaîne de texte. |
| numeric_value | Obtient ou définit la valeur réelle utilisée pour représenter un nombre ou une valeur de coût. |
| duration | Obtient ou définit la valeur réelle utilisée pour représenter une durée. |
| date_time_value | Obtient ou définit la valeur réelle si elle peut être représentée comme DateTime. La valeur par défaut est la date minimale. |
| description | Obtient ou définit la description d'une valeur. |
| phonetic | Obtient ou définit les informations phonétiques concernant le nom du champ personnalisé. |
