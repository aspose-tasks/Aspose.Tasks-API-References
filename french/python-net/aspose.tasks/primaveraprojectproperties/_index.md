## PrimaveraProjectProperties class

Représente les propriétés spécifiques à Primavera pour un projet lu à partir de fichiers Primavera (XER ou P6XML).

Le type PrimaveraProjectProperties expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| relationship_lag_calendar | Obtient une option qui définit le calendrier à utiliser pour la planification du retard de relation dans les projets Primavera |
| use_expected_finish_dates | Obtient un indicateur qui définit si les dates de fin d'activité doivent être planifiées comme les dates de fin attendues. |
| make_open_ended_activities_critical | Obtient un indicateur qui définit si les activités doivent être marquées comme critiques lors de la planification du projet. |
| ignore_other_project_relationships | Obtient un indicateur qui définit s'il faut ignorer les relations d'activité entre les projets. |
| current_baseline_project_id | Obtient l'Id du projet de base actuel.<br/>            S'applique aux projets lus à partir de fichiers XML Primavera contenant des bases de référence exportées. |
| baseline_projects | Obtient le tableau des projets de base du projet actuel.<br/>            S'applique aux projets lus à partir de fichiers XML Primavera contenant des bases de référence exportées. |
| critical_activities_defining_method | Obtient la méthode de définition des activités critiques : chemin le plus long ou approche du Total Float. |
| critical_total_float_limit | Obtient la valeur seuil utilisée pour définir les activités critiques si la méthode TotalFloat est utilisée. |
| short_name | Obtient le nom court du projet (ID du projet). |
