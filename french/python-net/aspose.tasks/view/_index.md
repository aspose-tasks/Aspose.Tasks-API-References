## View class

Représente une vue dans Project.

Le type View expose les membres suivants:
## Constructeurs
| Nom | Description |
| :- | :- |
| View() | Initialise une nouvelle instance de la classe [View](/tasks/python-net/aspose.tasks/view/). |
| View(view_screen) | Initialise une nouvelle instance de la classe [View](/tasks/python-net/aspose.tasks/view/). |
## Propriétés
| Nom | Description |
| :- | :- |
| filter | Obtient ou définit un filtre utilisé dans une vue unique. |
| groupe | Obtient ou définit un groupe de la vue unique. |
| uid | Obtient l'identifiant unique d'une vue. |
| highlight_filter | Obtient ou définit une valeur indiquant si Microsoft Project met en surbrillance le filtre pour une vue unique. |
| name | Obtient ou définit le nom d'un objet View. |
| screen | Obtient le type d'écran pour la vue unique.<br/>            Lecture seule [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Obtient le parent de l'objet View.<br/>            Lecture seule [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Obtient ou définit une table de la vue unique. |
| type | Obtient le type d'élément dans la vue unique, tel que les tâches ou les ressources.<br/>            Lecture seule [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Obtient ou définit une valeur indiquant si Microsoft Project affiche le nom de la vue unique dans la liste déroulante Vue ou Autres Vues du ruban. |
| page_info | Obtient une instance de la classe [page_info](/tasks/python-net/aspose.tasks/view/). Représente les données de configuration de page présentes dans le format de fichier mpp. |
| visual_objects_placements | Obtient une collection d'objets représentant le placement et l'apparence de [OleObject](/tasks/python-net/aspose.tasks/oleobject/) dans la vue. |
