## PrimaveraProjectInfo class

Représente des informations courtes sur un projet chargé depuis le format Primavera.

Le type PrimaveraProjectInfo expose les membres suivants:
## Propriétés
| Nom | Description |
| :- | :- |
| uid | Obtient l'Uid du projet. |
| name | Obtient le nom du projet. |
| short_name | Obtient le nom court du projet (ID du projet). |
| export_flag | Obtient le drapeau d'exportation du projet. Lorsqu'un projet est sélectionné pour l'exportation dans Primavera, son ExportFlag est vrai.<br/>            Certains projets non explicitement sélectionnés pour l'exportation peuvent être exportés vers un fichier XER en raison de leur relation avec le projet exporté. |
