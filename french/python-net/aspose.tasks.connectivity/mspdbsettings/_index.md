## MspDbSettings class

Permet de définir les options nécessaires pour lire les données du projet depuis la base de données MS Project Server.

Le type MspDbSettings expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Initialise une nouvelle instance de la classe [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Propriétés
| Nom | Description |
| :- | :- |
| connection_string | Obtient ou définit la chaîne de connexion. |
| provider_invariant_name | Obtient ou définit le nom invariant du fournisseur qui est utilisé pour obtenir une instance de la classe. |
| project_guid | Obtient le guid du projet à lire. |
| schema | Obtient ou définit le schéma du serveur MS Project.<br/>            La valeur par défaut est "pub". |
