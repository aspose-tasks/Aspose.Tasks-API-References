## SaveTemplateOptions class

Permet de spécifier des options supplémentaires lors de l'enregistrement d'un projet en tant que modèle.

Le type SaveTemplateOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| SaveTemplateOptions() | Initialise une nouvelle instance de la classe SaveTemplateOptions |
## Propriétés
| Nom | Description |
| :- | :- |
| remove_actual_values | Obtient ou définit une valeur indiquant si toutes les valeurs réelles d'un modèle de projet doivent être supprimées. |
| remove_baseline_values | Obtient ou définit une valeur indiquant si toutes les valeurs de référence d'un modèle de projet doivent être supprimées. |
| remove_fixed_costs | Obtient ou définit une valeur indiquant si tous les coûts fixes d'un modèle de projet doivent être supprimés. |
| remove_resource_rates | Obtient ou définit une valeur indiquant si les taux de ressources d'un modèle de projet doivent être supprimés. |
