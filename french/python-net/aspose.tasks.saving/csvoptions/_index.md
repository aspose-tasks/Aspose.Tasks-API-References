## CsvOptions class

Permet de spécifier des options supplémentaires lors de l'enregistrement du projet au format CSV.

Le type CsvOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| CsvOptions() | Initialise une nouvelle instance de la classe [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) qui peut être utilisée pour enregistrer le projet au format CSV. |
## Propriétés
| Nom | Description |
| :- | :- |
| save_format | Obtient ou définit le format dans lequel le document sera enregistré si cet objet d'options d'enregistrement est utilisé. |
| data_category | Obtient ou définit une catégorie de données à enregistrer. |
| encodage | Obtient ou définit un encodage avec lequel enregistrer le CSV. |
| include_headers | Obtient ou définit une valeur indiquant s'il faut inclure les en-têtes ou non (la valeur par défaut est TRUE). |
| text_delimiter | Obtient ou définit un délimiteur de texte. |
| view | Obtient ou définit une liste des colonnes de vue ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) à enregistrer au format XLSX.<br/>            Si non définie, les colonnes par défaut sont enregistrées. |
