## IPageSavingCallback class

Représente un rappel qui est appelé chaque fois qu'une page d'un document multipage est enregistrée dans un flux séparé.

Le type IPageSavingCallback expose les membres suivants :
## Méthodes
| Nom | Description |
| :- | :- |
| page_saving(args) | La méthode à appeler lorsqu'une page est enregistrée dans un flux. |
| on_finish() | Méthode qui sera appelée lorsque toutes les pages sont écrites. |
