## PrimaveraSaveOptions class

Permet de spécifier des options supplémentaires lors de l'enregistrement du projet au format Primavera XER.

Le type PrimaveraSaveOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| PrimaveraSaveOptions() | Initialise une nouvelle instance de la classe [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/). |
## Propriétés
| Nom | Description |
| :- | :- |
| save_format | Obtient ou définit le format dans lequel le document sera enregistré si cet objet d'options d'enregistrement est utilisé. |
| activity_id_increment | Obtient ou définit l'incrément utilisé lors du renumérotage des ID d'activité. |
| activity_id_prefix | Obtient ou définit le préfixe utilisé lors du renumérotage des ID d'activité. |
| activity_id_suffix | Obtient ou définit le suffixe utilisé lors du renumérotage des ID d'activité. |
| renumber_activity_ids | Obtient ou définit une valeur indiquant s'il faut renuméroter les ID d'activité. |
| skip_summary_assignments | Obtient ou définit une valeur indiquant si les affectations de ressources aux tâches récapitulatives doivent être ignorées lors de l'exportation. |
