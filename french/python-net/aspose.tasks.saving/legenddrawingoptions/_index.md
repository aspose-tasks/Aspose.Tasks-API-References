## LegendDrawingOptions enumeration

Spécifie les options possibles utilisées lors du rendu de la légende de la vue.

## Members
| Nom du membre | Description |
| :- | :- |
| NO_LEGEND | Aucune légende n'est rendue. |
| AFTER_LAST_PAGE | La légende est rendue sur une page séparée après la dernière page des pages du projet. |
| ON_EVERY_PAGE | La légende est rendue sur chaque page. |
| DEFINED_IN_VIEW | La légende est rendue selon la propriété View.PageInfo.Legend.LegendOn de la vue rendue. |
