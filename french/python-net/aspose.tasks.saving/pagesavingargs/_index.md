## PageSavingArgs class

Cette classe représente un ensemble de données liées à l'enregistrement d'une page de document dans un flux.

Le type PageSavingArgs expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| page_number | Obtient le numéro de page à écrire. |
| keep_stream_open | Obtient ou définit une valeur indiquant si la routine de rendu doit garder le [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) ouvert après l'écriture d'une page. |
| stream | Obtient ou définit un flux pour écrire une page. |
