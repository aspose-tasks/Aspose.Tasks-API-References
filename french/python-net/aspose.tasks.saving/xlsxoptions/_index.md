## XlsxOptions class

Permet de spécifier des options supplémentaires lors du rendu des pages du projet au format XLSX.

Le type XlsxOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| XlsxOptions() | Initialise une nouvelle instance de la classe [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) qui peut être utilisée pour enregistrer le projet au format XLSX. |
## Propriétés
| Nom | Description |
| :- | :- |
| save_format | Obtient ou définit le format dans lequel le document sera enregistré si cet objet d'options d'enregistrement est utilisé. |
| resource_view | Obtient ou définit une liste des colonnes de vue des ressources à rendre ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Obtient ou définit une liste des colonnes de vue des affectations à rendre ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| encodage | Obtient ou définit l'encodage du fichier XLSX résultant. La valeur par défaut est . |
| view | Obtient ou définit une liste des colonnes de vue ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) à enregistrer au format XLSX.<br/>            Si non définie, les colonnes par défaut sont enregistrées. |
