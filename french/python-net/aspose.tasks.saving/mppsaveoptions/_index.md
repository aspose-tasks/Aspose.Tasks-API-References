## MPPSaveOptions class

Permet de spécifier des options supplémentaires lors de l'enregistrement des données du projet au format MPP.

Le type MPPSaveOptions expose les membres suivants:
## Constructeurs
| Nom | Description |
| :- | :- |
| MPPSaveOptions() | Initialise une nouvelle instance de la classe [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## Propriétés
| Nom | Description |
| :- | :- |
| save_format | Obtient ou définit le format dans lequel le document sera enregistré si cet objet d'options d'enregistrement est utilisé. |
| remove_invalid_assignments | Obtient ou définit une valeur indiquant s'il faut supprimer les affectations de ressources invalides lors de l'enregistrement au format MPP. |
| write_view_data | Obtient ou définit une valeur indiquant s'il faut écrire les données de vue lors de l'enregistrement d'un projet au format MPP. |
| write_filters | Obtient ou définit une valeur indiquant s'il faut écrire les données de filtre lors de l'enregistrement d'un projet au format MPP. |
| write_groups | Obtient ou définit une valeur indiquant s'il faut écrire les données de groupes lors de l'enregistrement d'un projet au format MPP. |
| clear_vba | Obtient ou définit une valeur indiquant s'il faut supprimer les données de macros VBA existantes lors de l'enregistrement d'un projet au format MPP. |
| write_vba | Obtient ou définit une valeur indiquant s'il faut mettre à jour les données de macros VBA existantes dans le fichier MPP.<br/>            L'écriture de VbaModule.SourceCode est actuellement prise en charge. |
| protection_password | Obtient ou définit le mot de passe utilisé pour protéger le fichier MPP résultant. Il est actuellement pris en charge pour les formats MS Project 2010 et ultérieurs. |
