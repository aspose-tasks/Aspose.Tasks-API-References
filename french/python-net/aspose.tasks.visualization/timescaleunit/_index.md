## TimescaleUnit enumeration

Spécifie l'unité de temps pour tout niveau d'une échelle de temps dans un diagramme de Gantt ou une autre vue à phases temporelles.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Indique Aucun. Le niveau d'échelle de temps est masqué. |
| MINUTES | Indique l'unité d'échelle de temps Minutes. |
| HOURS | Indique l'unité de l'échelle de temps en heures. |
| DAYS | Indique l'unité de l'échelle de temps en jours. |
| WEEKS | Indique l'unité de l'échelle de temps en semaines. |
| THIRDS_OF_MONTHS | Indique l'unité de l'échelle de temps en tiers de mois. |
| MONTHS | Indique l'unité de l'échelle de temps en mois. |
| QUARTERS | Indique l'unité de l'échelle de temps en trimestres d'années. |
| HALF_YEARS | Indique l'unité de l'échelle de temps en demi-années. |
| YEARS | Indique l'unité de l'échelle de temps en années. |
