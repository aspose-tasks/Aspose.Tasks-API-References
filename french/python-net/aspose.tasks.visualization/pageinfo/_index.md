## PageInfo class

Représente les données de configuration de page présentes dans le format de fichier MPP et utilisées pour l'impression.

Le type PageInfo expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| PageInfo() | Initialise une nouvelle instance de la classe [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/) . <br/>            Représente les données de configuration de page présentes dans le format de fichier MPP et utilisées pour l'impression. |
## Propriétés
| Nom | Description |
| :- | :- |
| header | Obtient ou définit l'instance de la classe [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) qui représente les données d'en-tête. |
| footer | Obtient ou définit une instance de la classe [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) qui représente les données de pied de page. |
| name | Obtient le nom de la vue pour laquelle les données de configuration sont utilisées. |
| page_settings | Obtient une instance de la classe [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) qui spécifie les paramètres d'impression de la page. |
| page_view_settings | Obtient une instance de la classe [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) qui spécifie les paramètres d'impression de la vue de page. |
| margins | Obtient une instance de la classe [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) qui spécifie les marges de la page. |
| legend | Obtient ou définit une instance de la classe [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) qui spécifie les options de rendu de la légende de la page. |
