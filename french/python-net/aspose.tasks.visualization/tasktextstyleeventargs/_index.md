## TaskTextStyleEventArgs class

Cette classe représente un ensemble de données liées au rendu du contenu des cellules du tableau.

Le type TaskTextStyleEventArgs expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| cell_text_style | Obtient ou définit TextStyle qui sera utilisé pour dessiner le contenu de la cellule. Cet objet peut être utilisé pour personnaliser l'apparence d'une cellule de tableau. |
| task | Obtient [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) qui correspond à la ligne actuellement rendue. |
| column | Obtient [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) auquel appartient la cellule actuellement rendue. |
