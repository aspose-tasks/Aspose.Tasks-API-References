## ViewColumn class

Représente une colonne dans une vue de projet.

Le type ViewColumn expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| field | Obtient ou définit le champ de colonne.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/viewcolumn/). |
| name | Obtient le nom de la colonne. |
| string_alignment | Obtient ou définit l'alignement du texte (peut être l'une des valeurs de l'énumération [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| width | Obtient la largeur de la colonne. |
| text_style_modification_callback | Obtient ou définit le rappel qui peut être utilisé pour personnaliser l'apparence des cellules de la colonne. |
