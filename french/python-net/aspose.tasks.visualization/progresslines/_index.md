## ProgressLines class

Représente les lignes de progression dans une vue de diagramme de Gantt.

Le type ProgressLines expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| ProgressLines() | Initialise une nouvelle instance de la classe ProgressLines |
## Propriétés
| Nom | Description |
| :- | :- |
| display_at_current_date | Obtient ou définit une valeur indiquant s’il faut afficher la ligne de progression à la date actuelle. |
| display_at_recurring_intervals | Obtient ou définit une valeur indiquant s’il faut afficher la ligne de progression à des intervalles récurrents. |
| recurring_interval | Obtient ou définit l’intervalle récurrent.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Obtient ou définit une valeur indiquant s’il faut afficher les lignes de progression depuis le début de la date de démarrage du projet. |
| begin_at_date | Obtient ou définit la date à partir de laquelle afficher les lignes de progression. |
| display_selected | Obtient ou définit une valeur indiquant s’il faut afficher les lignes de progression aux dates sélectionnées. |
| is_baseline_plan | Obtient ou définit une valeur indiquant s’il faut afficher les lignes de progression pour le plan de référence ou réel. |
| show_date | Obtient ou définit une valeur indiquant s’il faut afficher la date pour chaque ligne de progression. |
| date_format | Obtient ou définit le format de date ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Obtient ou définit la police utilisée pour le libellé de la ligne de progression. |
| line_pattern | Obtient ou définit le motif de ligne de la ligne de progression actuelle.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Obtient ou définit la couleur de ligne pour la ligne de progression actuelle. |
| progress_point_shape | Obtient ou définit la forme du point de progression.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Obtient ou définit la couleur du point de progression. |
| other_line_pattern | Obtient ou définit le motif de ligne pour l'autre ligne de progression. |
| other_line_color | Obtient ou définit la couleur de l'autre ligne de progression. |
| other_progress_point_shape | Obtient ou définit la forme du point de progression de l'autre ligne de progression. |
| other_progress_point_color | Obtient ou définit la couleur de l'autre point de progression. |
| selected_dates | Obtient la liste des dates sélectionnées pour afficher les lignes de progression. |
