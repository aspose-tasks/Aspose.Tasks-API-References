## Gridlines class

Représente les lignes de grille qui apparaissent dans une vue GanttChart.

## Constructeurs
| Nom | Description |
| :- | :- |
| Gridlines() | Initialise une nouvelle instance de la classe Gridlines |
## Propriétés
| Nom | Description |
| :- | :- |
| interval | Obtient ou définit le nombre de 0 à 99 qui spécifie l'intervalle entre les lignes de grille. |
| interval_color | Obtient ou définit la couleur des lignes de grille secondaires. |
| interval_pattern | Obtient ou définit le motif de ligne pour les quadrillages secondaires. |

| normal_pattern | Obtient ou définit le motif de ligne pour les quadrillages normaux. |
