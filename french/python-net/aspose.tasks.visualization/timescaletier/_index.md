## TimescaleTier class

Représente un niveau unique de l'échelle de temps sur un diagramme de Gantt.

Le type TimescaleTier expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TimescaleTier() | Initialise une nouvelle instance de la classe [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Initialise une nouvelle instance de la classe TimescaleTier |
## Propriétés
| Nom | Description |
| :- | :- |
| count | Obtient ou définit l'intervalle d'unité de temps dans lequel afficher les libellés pour le niveau.<br/>            La valeur par défaut est 1. |
| label | Obtient ou définit le libellé de date [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) pour le niveau d'échelle de temps. |
| alignment | Obtient ou définit comment aligner les libellés à l'intérieur de chaque période de temps du niveau ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Obtient ou définit une valeur indiquant s'il faut baser les libellés du niveau sur l'année fiscale. |
| show_ticks | Obtient ou définit une valeur indiquant s'il faut afficher les marques de graduation qui séparent les périodes de temps dans le niveau. |
| unit | Obtient ou définit l'unité d'échelle de temps [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) pour le niveau d'échelle de temps.<br/>            La valeur par défaut est |
| render_label_on_each_page | Obtient ou définit le drapeau qui indique si les libellés de date doivent être rendus sur chaque page lorsqu'une période de temps s'étend sur plusieurs pages.<br/>            Si la valeur est 'true', lorsque la période de temps s'étend sur plusieurs pages, les libellés de date pour la période sont rendus sur chaque page.<br/>            Si la valeur est 'false', le libellé de date est rendu une seule fois selon la valeur de la propriété [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
