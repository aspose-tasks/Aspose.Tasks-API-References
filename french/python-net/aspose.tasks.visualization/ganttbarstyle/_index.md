## GanttBarStyle class

Représente un style de barre utilisé par MSP dans la vue du diagramme de Gantt.

Le type GanttBarStyle expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| GanttBarStyle() | Initialise une nouvelle instance de la classe [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/). |
