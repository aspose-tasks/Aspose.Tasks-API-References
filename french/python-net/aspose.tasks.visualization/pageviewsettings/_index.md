## PageViewSettings class

Représente les paramètres d'impression pour une vue du projet.

Le type PageViewSettings expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| PageViewSettings() | Initialise une nouvelle instance de la classe PageViewSettings |
## Propriétés
| Nom | Description |
| :- | :- |
| first_columns_count | Obtient ou définit le nombre de premières colonnes à imprimer sur toutes les pages. |
| fit_timescale_to_end_of_page | Obtient ou définit une valeur indiquant s'il faut ajuster l'échelle de temps à la fin d'une page lors de l'impression. |
| print_all_sheet_columns | Obtient ou définit une valeur indiquant s'il faut imprimer toutes les colonnes de la feuille d'une vue. |
| print_blank_pages | Obtient ou définit une valeur indiquant s'il faut imprimer les pages vierges d'une vue. |
| print_first_columns_count_on_all_pages | Obtient ou définit une valeur indiquant s'il faut imprimer un nombre spécifié de premières colonnes sur toutes les pages. |
| print_notes | Obtient ou définit une valeur indiquant s'il faut imprimer les notes. |
