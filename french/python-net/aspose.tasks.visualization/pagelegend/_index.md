## PageLegend class

Représente une légende de page qui est utilisée pour l'impression du projet.

Le type PageLegend expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| PageLegend() | Initialise une nouvelle instance de la classe PageLegend |
## Propriétés
| Nom | Description |
| :- | :- |
| left_text | Obtient ou définit le texte aligné à gauche à afficher dans l'élément parent. |
| centered_text | Obtient ou définit le texte centré à afficher dans l'élément parent. |
| right_text | Obtient ou définit le texte aligné à droite à afficher dans l'élément parent. |
| left_image | Obtient ou définit l'image alignée à gauche à afficher dans l'élément parent. |
| centered_image | Obtient ou définit l'image centrée à afficher dans l'élément parent. |
| right_image | Obtient ou définit l'image alignée à droite à afficher dans l'élément parent. |
| left_image_size | Obtient ou définit la taille affichée de l'image de gauche. |
| centered_image_size | Obtient ou définit la taille affichée de l'image centrée. |
| right_image_size | Obtient ou définit la taille affichée de l'image de droite. |
| legend_on | Obtient ou définit les pages sur lesquelles la légende apparaît. Peut être l'une des valeurs de l'énumération [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | Obtient ou définit la largeur de la partie gauche (contenant le nom et la date du projet par défaut) de la légende en centimètres. |
