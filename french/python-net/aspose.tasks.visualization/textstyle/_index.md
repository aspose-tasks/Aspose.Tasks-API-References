## TextStyle class

Modifiez le style visuel du texte d'un élément dans la vue du projet.

Le type TextStyle expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TextStyle() | Initialise une nouvelle instance de la classe [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) avec les paramètres par défaut. |
| TextStyle(font_size, font_style) | Initialise une nouvelle instance de la classe TextStyle |
| TextStyle(font_style) | Initialise une nouvelle instance de la classe [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) avec la police par défaut et la taille et le style de police spécifiés. |
| TextStyle(font) | Initialise une nouvelle instance de la classe [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) avec les paramètres de police spécifiés. |
## Propriétés
| Nom | Description |
| :- | :- |
| font | Obtient ou définit la police du style de texte. |
| color | Obtient ou définit la couleur du texte. |
| item_type | Obtient ou définit le [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) du style de texte. |
| background_pattern | Obtient ou définit le motif d'arrière-plan du style de texte.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Obtient ou définit la couleur d'arrière-plan du style de texte.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
