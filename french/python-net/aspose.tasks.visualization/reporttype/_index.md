## ReportType enumeration

Type du rapport graphique du projet.

## Members
| Nom du membre | Description |
| :- | :- |
| PROJECT_OVERVIEW | Affiche la date de début et de fin du projet, <br/>            le pourcentage de la durée qui est complet, le pourcentage d'achèvement des tâches de niveau supérieur et les jalons à venir. |
| COST_OVERVIEW | Affiche les dates de début et de fin du projet, le coût actuel<br/>            prévu et restant, % d'achèvement et les valeurs de coût pour les tâches de niveau supérieur. |
| WORK_OVERVIEW | Affiche le travail de référence, réel et restant pour chaque tâche de niveau supérieur et le travail pour les ressources de travail. |
| RESOURCE_OVERVIEW | Affiche le travail de référence, réel et restant par ressource. |
| RESOURCE_COST_OVERVIEW | Affiche le coût de référence, réel et restant par ressource. |
| CRITICAL_TASKS | Affiche les tâches du projet qui sont critiques. |
| LATE_TASKS | Affiche les tâches du projet qui sont en retard. |
| MILESTONES | Affiche les jalons qui sont en retard, à venir et terminés. |
| UPCOMING_TASK | Affiche les tâches qui sont dues pendant la semaine en cours et les tâches commençant pendant la semaine en cours. |
| COST_OVERRUNS | Affiche la variance des coûts par tâche et par ressource. |
| TASK_COST_OVERVIEW | Affiche le coût de référence, réel et restant de toutes les tâches de niveau supérieur. |
| OVERALLOCATED_RESOURCES | Affiche le nombre d'heures de travail restantes pour les ressources sur‑allouées. |
| SLIPPING_TASKS | Affiche les tâches qui doivent se terminer après leurs dates de fin de référence (la référence doit être définie). |
| BEST_PRACTICE_ANALYZER | Affiche les tâches sans travail réel, les tâches non assignées, <br/>            les tâches d'une durée inférieure à 8 heures et les résumés assignés avec les ressources. |
| BURNDOWN | Inclut les graphiques d'avancement du travail et d'avancement des tâches.<br/>            Le graphique d'avancement du travail montre la quantité de travail terminée par les personnes, la quantité prévue à terminer avant la date de fin du projet, <br/>            et l'estimation de référence de la quantité de travail qui serait terminée à ce stade du projet.<br/>            Le graphique d'avancement des tâches montre le nombre de tâches terminées, le nombre restant, <br/>            et l'estimation de référence du nombre de tâches qui seraient terminées à ce stade du projet. |
| CASH_FLOW | Affiche les coûts et les coûts cumulatifs par trimestre pour toutes les tâches de niveau supérieur. |
