## PageSettings class

Représente les paramètres d'impression pour une page de la vue du projet.

Le type PageSettings expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| PageSettings() | Initialise une nouvelle instance de la classe [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Représente les paramètres d'impression pour une page de la vue du projet. |
## Propriétés
| Nom | Description |
| :- | :- |
| is_portrait | Obtient ou définit une valeur indiquant si l'orientation de la page est portrait ; renvoie false si l'orientation de la page est paysage. |
| adjust_to_percent_of_normal_size | Obtient ou définit une valeur indiquant s'il faut ajuster l'impression au pourcentage spécifié ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) de la taille normale. |
| percent_of_normal_size | Obtient ou définit un pourcentage de la taille normale pour ajuster l'impression. |
| pages_in_width | Obtient ou définit un nombre de pages en largeur à imprimer. |
| pages_in_height | Obtient ou définit un nombre de pages en hauteur à imprimer. |
| paper_size | Obtient ou définit une taille de papier. Peut être l'une des valeurs de l'énumération [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | Obtient ou définit un entier représentant l'une des valeurs de PrinterPaperSize ou un identifiant de taille de page personnalisé.<br/>            Cette valeur peut être utilisée pour obtenir PaperSize à partir des paramètres du système d'exploitation. |
| first_page_number | Obtient ou définit le numéro de première page pour l'impression. |
