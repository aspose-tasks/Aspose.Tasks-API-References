## RecurringInterval class

Représente les intervalles récurrents utilisés dans les lignes de progression d'une vue de diagramme de Gantt.

Le type RecurringInterval expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| RecurringInterval() | Initialise une nouvelle instance de la classe RecurringInterval |
## Propriétés
| Nom | Description |
| :- | :- |
| interval | Obtient ou définit l'intervalle récurrent.<br/>            Peut être n'importe quelle valeur du type [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | Obtient ou définit le numéro du jour quotidien. |
| daily_workday | Obtient ou définit une valeur indiquant si un jour est ouvrable pour les lignes de progression quotidiennes. |
| weekly_week_number | Obtient ou définit le numéro de semaine pour les lignes de progression hebdomadaires. |
| monthly_day | Obtient ou définit une valeur indiquant s'il faut afficher les lignes de progression mensuelles par jour. |
| monthly_day_day_number | Obtient ou définit le numéro du jour des lignes de progression mensuelles. |
| monthly_day_month_number | Obtient ou définit le numéro du mois des lignes de progression mensuelles. |
| monthly_first_last | Obtient ou définit une valeur indiquant s'il faut afficher les lignes de progression par le premier ou le dernier jour prédéfini. |
| monthly_first_last_month_number | Obtient ou définit le numéro du mois des lignes de progression, qui sont affichées par le premier ou le dernier jour prédéfini. |
| monthly_first_last_day | Obtient ou définit le type du premier ou du dernier jour des lignes de progression mensuelles. |
| weekly_days | Obtient une liste de jours pour les lignes de progression hebdomadaires. |
