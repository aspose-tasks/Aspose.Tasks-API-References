## VisualObjectPlacement class

Représente le placement et l'apparence de [OleObject](/tasks/python-net/aspose.tasks/oleobject/) dans une vue.

Le type VisualObjectPlacement expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| VisualObjectPlacement() | Initialise une nouvelle instance de la classe [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Propriétés
| Nom | Description |
| :- | :- |
| ole_object_id | Obtient ou définit l'Id de l'objet [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
| task_id | Obtient ou définit l'Id de la tâche si l'option 'Attach to task' est sélectionnée, -1 sinon. |
| width | Obtient ou définit la largeur affichée de l'objet visuel. |
| height | Obtient ou définit la hauteur affichée de l'objet visuel. |
| vertical_offset | Obtient ou définit le décalage vertical de l'objet visuel. |
| horizontal_offset | Obtient ou définit le décalage horizontal de l'objet visuel. |
| timescale_date | Obtient ou définit la date de placement de l'objet visuel lorsque l'option 'Attach to timescale' est sélectionnée. |
| attachment_point | Obtient ou définit l'alignement de l'objet visuel par rapport à une tâche lorsque l'option 'Attach to task' est sélectionnée. |
| border_line_color | Obtient ou définit la couleur de la ligne de bordure. |
| border_line_thickness | Obtient ou définit l'épaisseur de la ligne de bordure (les valeurs autorisées sont 0 - 5). |
| fill_color | Obtient ou définit la couleur de remplissage. |
| fill_pattern | Obtient ou définit le motif de remplissage. |
