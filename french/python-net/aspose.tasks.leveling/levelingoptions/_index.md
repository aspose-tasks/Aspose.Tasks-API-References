## LevelingOptions class

Permet de spécifier les paramètres du nivellement des ressources.

Le type LevelingOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| LevelingOptions() | Initialise une nouvelle instance de la classe [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/). |
## Propriétés
| Nom | Description |
| :- | :- |
| start_date | Obtient ou définit la date de début de la période de nivellement. La valeur par défaut est la date de début du projet. |
| finish_date | Obtient ou définit la date de fin de la période de nivellement. La valeur par défaut est la date de fin du projet. |
| ressources | Obtient ou définit la liste des ressources qui seront nivelées. Si null est défini, toutes les ressources du projet seront nivelées. |
| leveling_order | Obtient l'ordre dans lequel l'algorithme de nivellement retarde les tâches qui ont des surallocations.<br/>            Après la détermination des tâches provoquant la surallocation et des tâches pouvant être retardées, l'ordre spécifié est utilisé pour déterminer quelle tâche doit être retardée en premier. |
| message_level | Obtient ou définit le niveau des messages de journal émis par Aspose.Tasks lors du nivellement des ressources. |
| message_handler | Obtient ou définit le rappel du gestionnaire de messages qui peut être utilisé pour intercepter les messages de journal produits par Aspose.Tasks lors du nivellement des ressources. |
