## LevelingOrder enumeration

Définit les valeurs possibles de l'ordre de nivellement.

## Members
| Nom du membre | Description |
| :- | :- |
| STANDARD | Les propriétés suivantes sont prises en compte : relations de prédécesseur, marge totale (une tâche avec une marge totale plus élevée est retardée en premier), date de début, priorité.<br/>            C’est la valeur par défaut. |
| ID_ONLY | Les tâches sont retardées par ordre croissant d'Id. |
| PRIORITY_THEN_STANDARD | La priorité est considérée en premier, puis les mêmes propriétés que dans Standard. |
