## ResourceLeveler class

Contient les méthodes de nivellement des ressources.

Le type ResourceLeveler expose les membres suivants :
## Méthodes
| Nom | Description |
| :- | :- |
| clear_leveling(project) | Supprime tout retard de nivellement qui a été précédemment ajouté au projet lors du nivellement des ressources. |
| clear_leveling(tasks) |  |
| level_resources(project, options) | Nivelle les tâches pour les ressources spécifiées en utilisant les options de nivellement spécifiées. |
| level_all(project) | Nivelle les tâches pour toutes les ressources du projet en utilisant les options de nivellement par défaut. |
