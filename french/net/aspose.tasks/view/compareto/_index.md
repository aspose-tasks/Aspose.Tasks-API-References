## View.CompareTo method

Compare l’instance actuelle avec un autre objet du même type et renvoie un entier indiquant si l’instance actuelle précède, suit ou se trouve à la même position dans l’ordre de tri que l’autre objet.

```csharp
public int CompareTo(View other)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| autre | View | l’objet View spécifié avec lequel comparer cette instance. |

### Valeur de retour

Un entier signé de 32 bits qui indique l’ordre relatif des objets comparés. La valeur de retour a les significations suivantes : Valeur Signification Inférieure à zéro Cette instance précède *other* dans l’ordre de tri. Zéro Cette instance se trouve à la même position dans l’ordre de tri que *other*. Supérieure à zéro Cette instance suit *other* dans l’ordre de tri.
