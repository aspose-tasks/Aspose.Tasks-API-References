## TaskStatus enumeration

Spécifie le statut d'une tâche.

```csharp
public enum TaskStatus
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Undefined | `-1` | Statut de tâche indéfini. |
| Complete | `0` | La tâche est terminée à 100 pour cent. |
| OnSchedule | `1` | La tâche est dans les temps si le pourcentage cumulé temporel est réparti jusqu’au moins le jour précédant la date d’état. |
| Late | `2` | La tâche est en retard si le pourcentage cumulé temporel n’atteint pas minuit le jour précédant la date d’état. |
| Future | `3` | Le statut de tâche « Future » est défini lorsque la date de début de la tâche est postérieure à la date d’état. |
