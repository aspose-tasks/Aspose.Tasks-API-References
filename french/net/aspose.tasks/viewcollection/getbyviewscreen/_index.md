## ViewCollection.GetByViewScreen method

Recherche une View avec la propriété Screen spécifiée et renvoie la première occurrence dans la collection.

```csharp
public View GetByViewScreen(ViewScreen screen)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| screen | ViewScreen | Valeur d'énumération [`ViewScreen`](../../viewscreen/). |

### Valeur de retour

La première View dans la collection dont la propriété Screen correspond à l'argument screen spécifié, si trouvée ; sinon, null.
