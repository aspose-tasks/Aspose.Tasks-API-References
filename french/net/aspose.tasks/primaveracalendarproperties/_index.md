## PrimaveraCalendarProperties class

Représente les propriétés spécifiques à Primavera pour un calendrier lu à partir de fichiers Primavera (XER ou P6XML). Peut être utilisé pour effectuer la conversion d'unités de temps spécifiques au calendrier.

public sealed class PrimaveraCalendarProperties
