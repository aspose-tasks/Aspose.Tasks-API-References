Contient les classes nécessaires pour travailler avec les formats spécifiques à Primavera (XER, Primavera XML).

## Classes

| Classe | Description |
| --- | --- |
| [PrimaveraProjectInfo](./primaveraprojectinfo/) | Représente des informations succinctes sur un projet chargé depuis le format Primavera. |
