Contient des classes pour créer le Rapport d'analyse des risques.

## Classes

| Classe | Description |
| --- | --- |
| [RiskAnalysisResult](./riskanalysisresult/) | Représente un résultat d'analyse des risques. |
| [RiskAnalysisSettings](./riskanalysissettings/) | Spécifie les paramètres pour effectuer l'analyse des risques. |
| [RiskAnalyzer](./riskanalyzer/) | Effectue une simulation Monte Carlo basée sur les paramètres d'analyse des risques spécifiés. |
| [RiskItemStatistics](./riskitemstatistics/) | Représente un élément qui stocke les données statistiques pour la tâche du projet analysé. |
| [RiskItemStatisticsCollection](./riskitemstatisticscollection/) | Représente une collection contenant les instances de la classe [`RiskItemStatistics`](../aspose.tasks.riskanalysis/riskitemstatistics/). |
| [RiskPattern](./riskpattern/) | Représente un modèle de risque pour une tâche de projet. |
| [RiskPatternCollection](./riskpatterncollection/) | Représente une collection contenant les instances de la classe [`RiskPattern`](../aspose.tasks.riskanalysis/riskpattern/). |
## Énumération

| Énumération | Description |
| --- | --- |
| [ConfidenceLevel](./confidencelevel/) | Spécifie les niveaux de confiance pris en charge utilisés dans l'analyse des risques qui correspondent au pourcentage du temps où les valeurs réelles se situeront entre les estimations optimistes et pessimistes. |
| [ProbabilityDistributionType](./probabilitydistributiontype/) | Spécifie les types de distributions de probabilité prises en charge. |
| [RiskItemType](./riskitemtype/) | Spécifie les champs de tâche pour lesquels les informations statistiques sont recueillies lors de l'analyse des risques. |
