## TimescaleTier.RenderLabelOnEachPage property

Obtient ou définit un indicateur qui détermine si les libellés de date doivent être rendus sur chaque page lorsqu'une période de temps s'étend sur plusieurs pages. Si la valeur est 'true', lorsque la période s'étend sur plusieurs pages, les libellés de date pour la période sont rendus sur chaque page. Si la valeur est 'false', le libellé de date est rendu une seule fois selon une valeur de la propriété [`Alignment`](../alignment/) .

```csharp
public bool RenderLabelOnEachPage { get; set; }
```
