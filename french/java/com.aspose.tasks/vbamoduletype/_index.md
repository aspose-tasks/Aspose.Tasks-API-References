Spécifie le type d'un module dans un projet VBA.
## Champs

| Champ | Description |
| --- | --- |
| [ClassModule](#ClassModule) | Un module qui contient la définition d'un nouvel objet. |
| [DesignerModule](#DesignerModule) | Un module qui étend les méthodes et propriétés d'un contrôle ActiveX qui a été enregistré dans le projet. |
| [DocumentModule](#DocumentModule) | Un type d'élément de projet VBA qui spécifie un module pour les macros intégrées et les opérations d'accès programmatique associées à un document. |
| [ProceduralModule](#ProceduralModule) | Un module contenant une collection de sous-routines et de fonctions. |
### ClassModule {#ClassModule}
```
public static final int ClassModule
```


Un module qui contient la définition d'un nouvel objet. Chaque instance d'une classe crée un nouvel objet, et les procédures définies dans le module deviennent des propriétés et des méthodes de l'objet.

### DesignerModule {#DesignerModule}
```
public static final int DesignerModule
```


Un module qui étend les méthodes et propriétés d'un contrôle ActiveX qui a été enregistré dans le projet.

### DocumentModule {#DocumentModule}
```
public static final int DocumentModule
```


Un type d'élément de projet VBA qui spécifie un module pour les macros intégrées et les opérations d'accès programmatique associées à un document.

### ProceduralModule {#ProceduralModule}
```
public static final int ProceduralModule
```


Un module contenant une collection de sous-routines et de fonctions.
