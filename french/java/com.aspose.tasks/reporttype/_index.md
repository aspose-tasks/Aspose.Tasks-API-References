### BestPracticeAnalyzer {#BestPracticeAnalyzer}

```
public static final int BestPracticeAnalyzer
```

### Burndown {#Burndown}
```
public static final int Burndown
```


Inclut les graphiques d’avancement du travail et d’avancement des tâches. Le graphique d’avancement du travail montre la quantité de travail terminée par les personnes, la quantité prévue à terminer avant la date de fin du projet, ainsi que l’estimation de référence du travail qui serait accompli à ce stade du projet. Le graphique d’avancement des tâches montre le nombre de tâches terminées, le nombre restant, et l’estimation de référence du nombre de tâches qui seraient terminées à ce stade du projet.
