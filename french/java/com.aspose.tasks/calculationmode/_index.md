### Automatic {#Automatic}

Mode automatique. Les dates et les coûts du projet sont recalculés lors de l'utilisation de ce mode.

### Manual {#Manual}
```
public static final int Manual
```


Mode manuel. Seuls les champs nécessaires sont recalculés dans ce mode, par exemple les UID et les ID des objets.

### None {#None}
```
public static final int None
```


Aucun. Les dates et les coûts du projet ne sont pas recalculés dans ce mode.
