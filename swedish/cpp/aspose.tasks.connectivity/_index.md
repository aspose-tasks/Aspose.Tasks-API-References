## Aspose::Tasks::Connectivity namespace

Använd dessa typer för att konfigurera anslutningar till Microsoft Project Server-databaser (MspDbSettings), Primavera-databaser (PrimaveraDbSettings), MPD-filer (MpdSettings) eller generiska databaskällor (DbSettings). Namnrymden centraliserar konfigurationsinställningar för anslutning för sömlös integration med Aspose.Tasks-funktioner för dataextraktion och manipulation.

| [PrimaveraDbSettings](./primaveradbsettings/) | Tillåter att ange nödvändiga alternativ för att läsa projektdata från Primavera-databasen. |
