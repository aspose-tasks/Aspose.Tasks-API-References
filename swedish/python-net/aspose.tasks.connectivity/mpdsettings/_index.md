## MpdSettings class

Tillåter att ställa in nödvändiga alternativ för att läsa projektdata från MPD-format (MS Access-databasfilformat).

MpdSettings-typen visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| MpdSettings(connection_string, project_id) | Initierar en ny instans av klassen [MpdSettings](/tasks/python-net/aspose.tasks.connectivity/mpdsettings/) . |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| connection_string | Hämtar eller anger anslutningssträngen. |
| provider_invariant_name | Hämtar eller anger provider invariant name som används för att få en instans av klassen. |
| project_id | Hämtar id för projektet som ska läsas. |
