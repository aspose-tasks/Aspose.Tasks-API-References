## DbSettings class

Tillåter att ange inställningar för att läsa från projektdatabas.

DbSettings-typen visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| connection_string | Hämtar eller anger anslutningssträngen. |
| provider_invariant_name | Hämtar eller anger provider invariant name som används för att få en instans av klassen. |
