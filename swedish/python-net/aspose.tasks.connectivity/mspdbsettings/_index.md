## MspDbSettings class

Tillåter att ställa in nödvändiga alternativ för att läsa projektdata från MS Project Server-databas.

Typen MspDbSettings exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| MspDbSettings(connection_string, project_guid) | Initierar en ny instans av klassen [MspDbSettings](/tasks/python-net/aspose.tasks.connectivity/mspdbsettings/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| connection_string | Hämtar eller anger anslutningssträngen. |
| provider_invariant_name | Hämtar eller anger provider invariant name som används för att få en instans av klassen. |
| project_guid | Hämtar guid för projektet som ska läsas. |
| schema | Hämtar eller anger schemat för MS Project Server.<br/>            Standardvärdet är "pub". |
