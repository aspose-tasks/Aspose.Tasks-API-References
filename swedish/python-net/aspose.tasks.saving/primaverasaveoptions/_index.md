## PrimaveraSaveOptions class

Tillåter att ange ytterligare alternativ när projektet sparas till Primavera XER-format.

PrimaveraSaveOptions‑typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PrimaveraSaveOptions() | Initierar en ny instans av klassen [PrimaveraSaveOptions](/tasks/python-net/aspose.tasks.saving/primaverasaveoptions/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| save_format | Hämtar eller anger formatet som dokumentet kommer att sparas i om detta sparalternativobjekt används. |
| activity_id_increment | Hämtar eller anger inkrementet som används vid omnumrering av aktivitets‑ID:n. |
| activity_id_prefix | Hämtar eller anger prefixet som används vid omnumrering av aktivitets‑ID:n. |
| activity_id_suffix | Hämtar eller anger suffixet som används vid omnumrering av aktivitets‑ID:n. |
| renumber_activity_ids | Hämtar eller anger ett värde som indikerar om aktivitets‑ID:n behöver omnummeras. |
| skip_summary_assignments | Hämtar eller anger ett värde som indikerar om tilldelningar av resurser till sammanfattningsuppgifter ska hoppas över vid export. |
