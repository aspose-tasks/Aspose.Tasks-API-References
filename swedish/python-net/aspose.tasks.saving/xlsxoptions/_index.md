## XlsxOptions class

Tillåter att ange ytterligare alternativ när projektsidor renderas till XLSX.

XxlsxOptions‑typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| XlsxOptions() | Initierar en ny instans av klassen [XlsxOptions](/tasks/python-net/aspose.tasks.saving/xlsxoptions/) som kan användas för att spara projekt i XLSX‑format. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| save_format | Hämtar eller anger formatet som dokumentet kommer att sparas i om detta sparalternativobjekt används. |
| resource_view | Hämtar eller anger en lista över resurssynskolumner som ska renderas ([ResourceViewColumn](/tasks/python-net/aspose.tasks.visualization/resourceviewcolumn/)). |
| assignment_view | Hämtar eller anger en lista över uppgiftssynskolumner som ska renderas ([AssignmentViewColumn](/tasks/python-net/aspose.tasks.visualization/assignmentviewcolumn/)). |
| encoding | Hämtar eller anger kodningen för den resulterande XLSX‑filen. Standardvärdet är . |
| view | Hämtar eller anger en lista över visningskolumnerna ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) att spara i XLSX-format.<br/>            Om den inte anges sparas standardkolumnerna. |
