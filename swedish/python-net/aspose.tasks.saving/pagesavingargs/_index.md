## PageSavingArgs class

Denna klass representerar en uppsättning data som är relaterade till sparande av dokumentets sida till ett flöde.

Typen PageSavingArgs visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| page_number | Hämtar ett sidnummer som ska skrivas. |
| keep_stream_open | Hämtar eller anger ett värde som indikerar om renderingsrutinen ska hålla [stream](/tasks/python-net/aspose.tasks.saving/pagesavingargs/) öppen efter att en sida har skrivits. |
| stream | Hämtar eller anger en ström för att skriva en sida. |
