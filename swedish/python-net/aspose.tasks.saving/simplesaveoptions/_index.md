## SimpleSaveOptions class

Detta är en abstrakt basklass som låter användaren ange grundläggande alternativ när ett projekt sparas i ett specifikt format.

Typen SimpleSaveOptions visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| save_format | Hämtar eller anger formatet som dokumentet kommer att sparas i om detta sparalternativobjekt används. |
