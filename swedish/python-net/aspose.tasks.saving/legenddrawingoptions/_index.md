## LegendDrawingOptions enumeration

Anger de möjliga alternativ som används när vyens legend renderas.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NO_LEGEND | Ingen legend renderas. |
| AFTER_LAST_PAGE | Legenden renderas på en separat sida efter den sista sidan av projektets sidor. |
| ON_EVERY_PAGE | Legenden renderas på varje sida. |
| DEFINED_IN_VIEW | Legenden renderas enligt egenskapen View.PageInfo.Legend.LegendOn för den renderade vyn. |
