## MPPSaveOptions class

Tillåter att ange ytterligare alternativ när projektdata sparas till MPP.

Typen MPPSaveOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| MPPSaveOptions() | Initierar en ny instans av klassen [MPPSaveOptions](/tasks/python-net/aspose.tasks.saving/mppsaveoptions/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| save_format | Hämtar eller anger formatet som dokumentet kommer att sparas i om detta sparalternativobjekt används. |
| remove_invalid_assignments | Hämtar eller anger ett värde som indikerar om ogiltiga resursuppdrag ska tas bort vid sparande till MPP. |
| write_view_data | Hämtar eller anger ett värde som indikerar om vydata ska skrivas när ett projekt sparas i MPP-format. |
| write_filters | Hämtar eller anger ett värde som indikerar om filterdata ska skrivas när ett projekt sparas i MPP-format. |
| write_groups | Hämtar eller anger ett värde som indikerar om gruppdata ska skrivas när ett projekt sparas i MPP-format. |
| clear_vba | Hämtar eller anger ett värde som indikerar om befintliga VBA-makrodata ska tas bort när ett projekt sparas i MPP-format. |
| write_vba | Hämtar eller anger ett värde som indikerar om befintliga VBA-makrodata ska uppdateras i MPP-filen.<br/>            För närvarande stöds skrivning av VbaModule.SourceCode. |
| protection_password | Hämtar eller anger ett lösenord som används för att skydda den resulterande MPP-filen. För närvarande stöds det för MS Project 2010 och nyare format. |
