## CsvOptions class

Tillåter att ange ytterligare alternativ när projektet sparas till CSV.

Typen CsvOptions visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| CsvOptions() | Initierar en ny instans av klassen [CsvOptions](/tasks/python-net/aspose.tasks.saving/csvoptions/) som kan användas för att spara projektet i CSV-format. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| save_format | Hämtar eller anger formatet som dokumentet kommer att sparas i om detta sparalternativobjekt används. |
| data_category | Hämtar eller anger en datakategori som ska sparas. |
| encoding | Hämtar eller anger en kodning att spara CSV med. |
| include_headers | Hämtar eller anger ett värde som indikerar om rubriker ska inkluderas eller inte (standardvärdet är TRUE). |
| text_delimiter | Hämtar eller anger en textavgränsare. |
| view | Hämtar eller anger en lista över visningskolumnerna ([GanttChartColumn](/tasks/python-net/aspose.tasks.visualization/ganttchartcolumn/)) att spara i XLSX-format.<br/>            Om den inte anges sparas standardkolumnerna. |
