## ProjectInfo class

Kort information om det publicerade projektet som finns tillgängligt på Project Online.

Typen ProjectInfo exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ProjectInfo() | Initierar en ny instans av klassen [ProjectInfo](/tasks/python-net/aspose.tasks/projectinfo/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| id | Hämtar projektets unika identifierare. |
| name | Hämtar projektets namn. |
| created_date | Hämtar datum och tid när projektet skapades. |
| is_checked_out | Hämtar ett värde som indikerar om projektet är utlånat. |
| last_published_date | Hämtar det senaste datumet då projektet publicerades. |
| last_saved_date | Hämtar det senaste datumet då projektet sparades. |
| description | Hämtar projektets beskrivning. |
