## Value class

Representerar ett värde i en värdelista.

Value‑typen visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Value() | Initierar en ny instans av klassen [Value](/tasks/python-net/aspose.tasks/value/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| id | Hämtar eller anger det unika identifieraren för ett värde i ett projekt. |
| value_guid | Hämtar en GUID som identifierar detta värde bland andra i hela projektet. |
| val | Hämtar eller anger det faktiska värdet i intern representation. Föredra att använda starkt typade egenskaper som listas nedan. |

| numeric_value | Hämtar eller anger det faktiska värdet som används för att representera ett tal eller kostnadsvärde. |
| duration | Hämtar eller anger det faktiska värdet som används för att representera en varaktighet. |
| date_time_value | Hämtar eller anger det faktiska värdet om det kan representeras som DateTime. Standardvärdet är minsta datumvärdet. |
| description | Hämtar eller anger beskrivningen av ett värde. |
| phonetic | Hämtar eller anger den fonetiska informationen om det anpassade fältnamnet. |
