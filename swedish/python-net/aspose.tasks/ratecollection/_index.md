## RateCollection class

Representerar en samling som innehåller [Rate](/tasks/python-net/aspose.tasks/rate/)‑objekt.

Typen RateCollection visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| count | Hämtar antalet element som finns i RateCollection. |
| is_read_only | Hämtar ett värde som indikerar om samlingen är skrivskyddad. |
| parent_resource | Hämtar det överordnade [Resource](/tasks/python-net/aspose.tasks/resource/)‑objektet för denna samling. |
## Methods
| Namn | Beskrivning |
| :- | :- |
| add(rates_from) | Lägger till en ny [Rate](/tasks/python-net/aspose.tasks/rate/)‑instans i denna samling. |
| add(rates_from, type) | Lägger till en ny [Rate](/tasks/python-net/aspose.tasks/rate/)‑instans i denna samling. |
| to_list() | Konverterar [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/)‑objektet till en lista med [Rate](/tasks/python-net/aspose.tasks/rate/)‑objekt. |
| to_list(type) | Konverterar [RateCollection](/tasks/python-net/aspose.tasks/ratecollection/)‑objektet till en lista med [Rate](/tasks/python-net/aspose.tasks/rate/)‑objekt filtrerade efter angiven [RateType](/tasks/python-net/aspose.tasks/ratetype/)‑typ. |
| remove(item) | Tar bort Rate‑instans från denna samling. |
