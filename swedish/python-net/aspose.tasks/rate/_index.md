## Rate class

Representerar en definition av en tidsperiod och priser som gäller för en resurs under den perioden.

Rate-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| rates_from | Hämtar eller anger datumet när en taxa blir giltig. |
| rates_to | Hämtar eller anger det sista datumet när en taxa är giltig. |
| rate_table | Hämtar eller anger den unika identifieraren för en taxatabell för en resurs. |
| standard_rate | Hämtar eller anger standardtaxa per timme för en resurs. |
| standard_rate_format | Hämtar eller anger enheterna som Microsoft Project använder för att visa standardtaxan. |
| overtime_rate | Hämtar eller anger övertidstaxa per timme för en resurs. |
| overtime_rate_format | Hämtar eller anger enheterna som Microsoft Project använder för att visa övertidstaxan. |
| cost_per_use | Hämtar eller anger kostnaden per användning av en resurs. Detta värde hämtas från det aktuella datumet om en taxatabell finns för en resurs. |
