## PrimaveraProjectProperties class

Representerar Primavera-specifika egenskaper för ett projekt läst från Primavera-filer (XER eller P6XML).

Typen PrimaveraProjectProperties exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| relationship_lag_calendar | Hämtar ett alternativ som definierar vilken kalender som ska användas för schemaläggning av Relationship Lag i Primavera-projekt |
| use_expected_finish_dates | Hämtar en flagga som definierar om aktivitetsavslutsdatum ska schemaläggas som de förväntade avslutsdatumen. |
| make_open_ended_activities_critical | Hämtar en flagga som definierar om aktiviteter ska markeras som kritiska vid schemaläggning av projektet. |
| ignore_other_project_relationships | Hämtar en flagga som definierar om aktivitetsrelationer mellan projekt ska ignoreras. |
| current_baseline_project_id | Hämtar ID för det aktuella baslinjeprojektet.<br/>            Gäller för projekt som läses från Primavera XML-filer som innehåller exporterade baslinjer. |
| baseline_projects | Hämtar en array av baslinjeprojekt för det aktuella projektet.<br/>            Gäller för projekt som läses från Primavera XML-filer som innehåller exporterade baslinjer. |
| critical_activities_defining_method | Hämtar metoden för att definiera kritiska aktiviteter: Längsta vägen eller Total Float‑metoden. |
| critical_total_float_limit | Hämtar tröskelvärdet som används för att definiera kritiska aktiviteter om TotalFloat‑metoden används. |
| short_name | Hämtar projektets korta namn (Projekt‑ID). |
