## PrimaveraBaseReader class

Representerar en grundläsare som kan användas för att läsa projekt-UID:n från multipla Primavera XER- eller XML-filer.

Typen PrimaveraBaseReader exponerar följande medlemmar:
## Methods
| Namn | Beskrivning |
| :- | :- |
| get_project_uids() | Returnerar en lista med projektens unika identifierare. |
| get_project_infos() | Returnerar en lista med projektets korta informationsobjekt. |
| load_project(project_uid) | Läser in projektet med den angivna unika identifieraren. |
