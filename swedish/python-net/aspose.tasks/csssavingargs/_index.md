## CssSavingArgs class

Denna klass representerar en uppsättning data som är relaterade till sparande av extern CSS-fil som<br/>              sker under konvertering till HTML-format.

Typen CssSavingArgs exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| CssSavingArgs() | Initierar en ny instans av klassen [CssSavingArgs](/tasks/python-net/aspose.tasks/csssavingargs/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| file_name | Hämtar eller anger det förmodade filnamnet som går från konverteraren till koden för den anpassade metoden.<br/>             Kan användas i anpassad kod för att bestämma hur man ska bearbeta eller var man sparar filen. |
| keep_stream_open | Hämtar eller anger ett värde som indikerar om strömmen ska hållas öppen efter att resursens sparning är klar. |
| stream | Hämtar eller anger det binära innehållet i den sparade filen. |
| uri | Hämtar eller anger resursens URI. |
## Methods
| Namn | Beskrivning |
| :- | :- |
| close_stream_if_required() | Stäng strömmen om KeepStreamOpen är falskt, annars spola den. |
