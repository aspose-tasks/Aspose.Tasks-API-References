## Baseline class

Representerar baslinjevärden för en resurs.

Typen Baseline visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Baseline() | Initierar en ny instans av klassen Baseline |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| baseline_number | Hämtar eller anger det unika numret för en baslinjedatapost. |
| work | Hämtar eller anger arbetet som tilldelats en resurs när baslinjen sparas. |
| cost | Hämtar eller anger den beräknade kostnaden för en resurs när baslinjen sparas. |
| bcws | Hämtar eller anger budgetkostnaden för ett arbete som är schemalagt för en resurs. |
| bcwp | Hämtar eller anger den budgeterade kostnaden för ett arbete som utförts av en resurs för ett projekt hittills. |
