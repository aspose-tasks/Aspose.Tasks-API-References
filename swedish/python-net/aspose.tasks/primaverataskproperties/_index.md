## PrimaveraTaskProperties class

Representerar Primavera-specifika egenskaper för en uppgift läst från Primavera-filer (XER eller P6XML).

Typen PrimaveraTaskProperties visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| sequence_number | Hämtar eller anger sekvensnumret för WBS‑objektet (sammanfattande uppgifter). Det används för att sortera sammanfattande uppgifter i Primavera. |
| activity_id | Hämtar ett aktivitets‑id‑fält – en uppgifts unika identifierare som används av Primavera. |
| remaining_early_finish | Hämtar återstående tidiga slutdatum – datumet då det återstående arbetet för aktiviteten är planerat att vara färdigt. |
| remaining_early_start | Hämtar återstående tidiga startdatum – datumet då det återstående arbetet för aktiviteten är planerat att påbörjas. |
| remaining_late_start | Hämtar återstående sena startdatum. |
| remaining_late_finish | Hämtar återstående sena slutdatum. |
| raw_duration_type | Hämtar rå textrepresentation (som i källfilen) av fältet 'Duration Type' för aktiviteten. |
| duration_type | Hämtar värdet för fältet 'Duration Type' i aktiviteten. |
| raw_activity_type | Hämtar råtextrepresentation (som i källfilen) av fältet 'Activity Type' i aktiviteten. |
| activity_type | Hämtar värdet för fältet 'Activity Type'. |
| percent_complete_type | Hämtar värdet för fältet '% Complete Type' i aktiviteten. |
| raw_complete_percent_type | Hämtar råtextrepresentation (som i källfilen) av fältet '% Complete Type' i aktiviteten. |
| raw_status | Hämtar råtextrepresentation (som i källfilen) av fältet 'Status' i aktiviteten. |
| physical_percent_complete | Hämtar värdet för Physical Percent Complete. |
| duration_percent_complete | Hämtar värdet för duration percent complete. |
| units_percent_complete | Hämtar värdet för units percent complete. |
| actual_labor_units | Hämtar värdet för actual labor units. |
| actual_non_labor_units | Hämtar värdet för actual non labor units. |
| remaining_labor_units | Hämtar värdet för remaining labor units. |
| remaining_non_labor_units | Hämtar värdet av återstående icke-arbetsenheter. |
| actual_labor_cost | Hämtar värdet av faktisk arbetskostnad . |
| budgeted_labor_cost | Hämtar värdet av budgeterad (eller planerad) arbetskostnad . |
| actual_nonlabor_cost | Hämtar värdet av faktisk icke-arbetskostnad . |
| budgeted_nonlabor_cost | Hämtar värdet av budgeterad (eller planerad) icke-arbetskostnad . |
| actual_material_cost | Hämtar värdet av faktisk materialkostnad. |
| budgeted_material_cost | Hämtar värdet av av budgeterad (eller planerad) materialkostnad. |
| actual_expense_cost | Hämtar värdet av faktisk utgiftkostnad. |
| remaining_expense_cost | Hämtar värdet av återstående utgiftkostnad. |
| budgeted_expense_cost | Hämtar värdet av budgeterad (eller planerad) utgiftkostnad. |
| actual_total_cost | Hämtar det totala värdet av faktiska kostnader. |
| budgeted_total_cost | Hämtar det totala värdet av budgeterade (eller planerade) kostnader. |
| primary_constraint_type | Hämtar en typ av primär begränsning. |
| primary_constraint_date | Hämtar datumet för primär begränsning. |
| secondary_constraint_type | Hämtar en typ av sekundär begränsning. |
| secondary_constraint_date | Hämtar datumet för sekundär begränsning. |
| planned_duration | Hämtar den ursprungliga eller planerade varaktigheten – den totala arbetstiden från uppgiftens planerade startdatum till det planerade slutdatumet.. |
