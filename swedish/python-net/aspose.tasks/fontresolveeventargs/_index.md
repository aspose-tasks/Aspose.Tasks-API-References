## FontResolveEventArgs class

Tillhandahåller argument för återanropet som anropas när teckensnittet har lösts upp.

Typen FontResolveEventArgs exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| requested_font_name | Hämtar namnet på den begärda teckensnittet. |
| resolved_font_name | Hämtar eller anger namnet på det lösta teckensnittet. Kan anges för att styra vilka teckensnitt som används för att rendera en vy. |
