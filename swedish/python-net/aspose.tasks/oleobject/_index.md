## OleObject class

Representerar ett OLE-objekt som kan infogas i Gantt-diagrambilden för en MPP-fil.

Typen OleObject exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| OleObject() | Initierar en ny instans av klassen [OleObject](/tasks/python-net/aspose.tasks/oleobject/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar eller anger namnet på instansen av OLE‑objektet. |
| application_name | Hämtar eller anger applikationsnamnet för att öppna det inbäddade objektet med. |
| file_format | Hämtar eller anger filformatet för det inbäddade objektet. |
| innehåll | Hämtar eller anger den inbäddade filens data; null om ingen data har inbäddats. |
| etikett | Hämtar eller anger etiketten för det infogade objektet. |
| full_path | Hämtar eller anger den fullständiga sökvägen för det infogade objektet. |
| temporary_file | Hämtar eller anger sökvägen till den temporära filen för det infogade objektet. |
| display_as_icon | Hämtar eller anger en flagga som indikerar att OLE-objektet ska visas antingen som en ikon eller som sin vanliga bild. |
| linked | Hämtar ett värde som indikerar om projektfilen endast innehåller en länk till den faktiska data som lagras vid länkkällan. |
| view | Hämtar eller anger instansen av klassen [view](/tasks/python-net/aspose.tasks/oleobject/) som det infogade objektet tillhör. |
| id | Hämtar eller anger objektets id. |
