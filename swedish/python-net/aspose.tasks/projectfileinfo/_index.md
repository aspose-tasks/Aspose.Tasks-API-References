## ProjectFileInfo class

Klassinstansen innehåller information om projektfilformatet och versionen av Microsoft Project där<br/>            filen skapades.

Typen ProjectFileInfo exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| can_read | Hämtar ett värde som indikerar om Aspose.Tasks kan bearbeta projektfilen. |
| is_password_protected | Hämtar ett värde som indikerar om ett projekt är lösenordsskyddat. |
| project_file_format | Hämtar projektfilens format. |
| project_application_info | Hämtar projektfilens applikationsinformation. |
