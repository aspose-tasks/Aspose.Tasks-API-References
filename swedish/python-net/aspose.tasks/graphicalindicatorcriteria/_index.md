## GraphicalIndicatorCriteria class

Representerar ett grafiskt indikatorvillkor som är associerat med ett utökat attribut.

Typen GraphicalIndicatorCriteria exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| GraphicalIndicatorCriteria(row_type, test, image_index, value1, value2) | Initierar en ny instans av klassen GraphicalIndicatorCriteria |
| GraphicalIndicatorCriteria(row_type, test, image_index, value) | Initierar en ny instans av klassen GraphicalIndicatorCriteria |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| test | Hämtar typen av jämförelse som görs mellan det utökade attributets värde och Värden som fungerar som ett kriterium för tillämpningen av den grafiska indikatorn.<br/>            [FilterComparisonType](/tasks/python-net/aspose.tasks/filtercomparisontype/) |
| value1 | Hämtar värdet som används för att testa det utökade attributets värde. |
| value2 | Hämtar det andra värdet som används för att testa det utökade attributets värde vid jämförelsetyperna 'IsWithin' och 'IsNotWithin'. |
| image_index | Hämtar indexet för bilden som ska visas när fältet uppfyller kriterierna. |
| row_type | Hämtar värdet av enumen [GraphicalIndicatorCriteriaType](/tasks/python-net/aspose.tasks/graphicalindicatorcriteriatype/) som anger för vilka rader indikatorn tillämpas. |
