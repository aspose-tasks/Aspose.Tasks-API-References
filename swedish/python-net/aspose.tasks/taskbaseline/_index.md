## TaskBaseline class

Representerar en baslinje för en uppgift.

Typen TaskBaseline exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TaskBaseline(task) | Initierar en ny instans av klassen [TaskBaseline](/tasks/python-net/aspose.tasks/taskbaseline/) . |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| baseline_number | Hämtar eller anger det unika numret för en baslinjedatapost. |
| work | Hämtar eller anger arbetet som tilldelats en resurs när baslinjen sparas. |
| cost | Hämtar eller anger den beräknade kostnaden för en resurs när baslinjen sparas. |
| bcws | Hämtar eller anger budgetkostnaden för ett arbete som är schemalagt för en resurs. |
| bcwp | Hämtar eller anger den budgeterade kostnaden för ett arbete som utförts av en resurs för ett projekt hittills. |
| timephased_data | Hämtar eller anger en TimephasedDataCollection-instans för detta objekt.<br/>            Tidsfasade data som är associerade med uppgiftens baslinje. |
| interim | Hämtar eller anger ett värde som indikerar om detta är en Interim-baslinje. |
| start | Hämtar eller anger det planerade startdatumet för uppgiften när baslinjen sparades. |
| finish | Hämtar eller anger det planerade slutdatumet för uppgiften när baslinjen sparades. |
| duration | Hämtar eller anger den planerade varaktigheten för uppgiften när baslinjen sparades. |
| estimated_duration | Hämtar eller anger ett värde som indikerar om baslinjens varaktighet för uppgiften var uppskattad. |
| fixed_cost | Hämtar eller anger en fast kostnad för uppgiften när baslinjen sparades. |
