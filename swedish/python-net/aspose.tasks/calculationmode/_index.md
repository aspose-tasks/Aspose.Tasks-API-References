## CalculationMode enumeration

Anger projektberäkningsläge.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Ingen. Projektdatum och kostnader omberäknas inte i detta läge. |
| AUTOMATIC | Automatiskt läge. Projektdatum och kostnader omberäknas när detta läge används. |
| MANUAL | Manuellt läge. Endast nödvändiga fält omberäknas i detta läge, till exempel UID:n och ID:n för objekt. |
