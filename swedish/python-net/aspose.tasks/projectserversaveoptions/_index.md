## ProjectServerSaveOptions class

Tillåter att ange ytterligare alternativ när projektet sparas till Project Server eller Project Online.

Typen ProjectServerSaveOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ProjectServerSaveOptions() | Initierar en ny instans av klassen [ProjectServerSaveOptions](/tasks/python-net/aspose.tasks/projectserversaveoptions/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| project_name | Hämtar eller anger namn på ett projekt som visas i listan över projekt i Project Server \ Project Online. Ska vara unik inom Project Server \ Project Online‑instansen.<br/>            Om värdet utelämnas används värdet för egenskapen Prj.Name istället. |
| project_guid | Hämtar eller anger ett unikt identifierare för ett projekt. Ska vara unikt inom Project Server \ Project Online-instansen. |
| timeout | Hämtar eller anger tidsgränsen som används när man väntar på bearbetning av spara-projekt-förfrågan av en Project Server's köbearbetningstjänst. Standardvärdet för denna egenskap är 1 minut. |
| polling_interval | Hämtar eller anger intervallet mellan förfrågningar om köjobbsstatus. Standardvärdet är 2 sekunder. |
