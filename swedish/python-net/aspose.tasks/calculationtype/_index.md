## CalculationType enumeration

Anger typen av beräkning av det anpassade attributets värde.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Betyder att det utökade attributet saknar en uppslagstabell för formel och helt enkelt lagrar värdet som anges av användaren. |
| LOOKUP | Betyder att värdet för det utökade attributet är begränsat till värden från en uppslagstabell. |
| FORMULA | Betyder att värdet för det utökade attributet beräknas med formeln som definieras i [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
