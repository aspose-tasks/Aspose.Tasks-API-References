## ExtendedAttribute class

Representerar utökade attribut.

Typen ExtendedAttribute exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| attribute_definition | Hämtar attributdefinitionen. |
| field_id | Hämtar ID för ett fält. |
| duration_value | Hämtar eller anger värde för attribut med typen 'Duration'. |
| numeric_value | Hämtar eller anger ett värde för attribut med numeriska typer (Cost, Number). |
| date_value | Hämtar eller anger ett värde för attribut med datumtyper (Date, Start, Finish). |
| flag_value | Hämtar eller anger ett värde som indikerar om en flagga är satt för ett attribut med typen 'Flag'. |
| text_value | Hämtar eller anger ett värde för attribut med typen 'Text'. |
| value_guid | Hämtar guid för ett uppslagsvärde. |
| value_read_only | Hämtar ett värde som indikerar om ett värde för den här [ExtendedAttribute](/tasks/python-net/aspose.tasks/extendedattribute/) instansen är skrivskyddad. |
| is_error_value | Hämtar om beräkning av det utökade attributets värde resulterade i ett fel. |
