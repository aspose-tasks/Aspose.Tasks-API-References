## UsageView class

Representera en användningsvy i ett projekt.

Typen UsageView exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| filter | Hämtar eller anger ett filter som används i en enskild vy. |
| grupp | Hämtar eller anger en grupp för den enkla vyn. |
| uid | Hämtar den unika identifieraren för en vy. |
| highlight_filter | Hämtar eller anger ett värde som indikerar om Microsoft Project markerar filtret för en enkel vy. |
| name | Hämtar eller anger namnet på ett View-objekt. |
| screen | Hämtar skärmtypen för den enkla vyn.<br/>            Read-only [ViewScreen](/tasks/python-net/aspose.tasks/viewscreen/). |
| parent_project | Hämtar föräldern till View-objektet.<br/>            Read-only [Project](/tasks/python-net/aspose.tasks/project/). |
| table | Hämtar eller anger en tabell för den enkla vyn. |
| type | Hämtar typen av objekt i den enkla vyn, såsom uppgifter eller resurser.<br/>            Read-only [ItemType](/tasks/python-net/aspose.tasks/itemtype/). |
| show_in_menu | Hämtar eller anger ett värde som indikerar om Microsoft Project visar namnet på den enkla vyn i rullgardinslistorna View eller Other Views i Ribbon. |
| page_info | Hämtar en instans av klassen [page_info](/tasks/python-net/aspose.tasks/view/). Representerar sidinställningsdata som finns i mpp-filformat. |
| visual_objects_placements | Hämtar en samling objekt som representerar placering och utseende för [OleObject](/tasks/python-net/aspose.tasks/oleobject/) i vyn. |
| align_details_data | Hämtar eller anger justering av detaljerad data. |
| display_details_header_column | Hämtar eller anger ett värde som indikerar om detaljerad rubrikkolumn ska visas i vyn eller inte. |
| display_short_detail_header_names | Hämtar eller anger ett värde som indikerar om korta rubriknamn för detaljer ska visas eller inte. |
| repeat_details_header_on_all_rows | Hämtar eller anger ett värde som indikerar om detaljerad rubrik ska upprepas på alla tilldelningsrader eller inte. |
| timescale_size_percentage |  |
| bottom_timescale_tier | Hämtar eller anger inställningar för den nedre tidslinjestapeln i vyn.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/) |
| middle_timescale_tier | Hämtar eller anger inställningar för den mellersta tidslinjestapeln i vyn.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| top_timescale_tier | Hämtar eller anger inställningar för vyns översta tidslinjenivå.<br/>            [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
## Methods
| Namn | Beskrivning |
| :- | :- |
| compare_to(other) | Jämför den aktuella instansen med ett annat objekt av samma typ och returnerar ett heltal som indikerar om den aktuella instansen föregår, följer eller hamnar på samma position i sorteringsordningen som det andra objektet. |
