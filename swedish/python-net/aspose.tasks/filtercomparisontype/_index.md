## FilterComparisonType enumeration

Typen av jämförelse som görs mellan FieldName och Value och som fungerar som urvalskriterium för ett filter eller en grafisk indikator.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| EQUALS | Värdet på Field är lika med Value. |
| DOES_NOT_EQUAL | Värdet på Field är inte lika med Value. |
| IS_GREATER_THAN | Värdet för Field är större än Value. |
| IS_GREATER_THAN_OR_EQUAL_TO | Värdet för Field är större än eller lika med Value. |
| IS_LESS_THAN | Värdet för Field är mindre än Value. |
| IS_LESS_THAN_OR_EQUAL_TO | Värdet för Field är mindre än eller lika med Value. |
| IS_WITHIN | Värdet för Field är inom Value. |
| IS_NOT_WITHIN | Värdet för Field är inte inom Value. |
| CONTAINS | Värdet för Field innehåller Value. |
| DOES_NOT_CONTAIN | Värdet för Field innehåller inte Value. |
| CONTAINS_EXACTLY | Värdet för Field innehåller exakt Value. |
| IS_ONE_OF | Värdet för Field är lika med ett av de angivna Values. Används i AutoFilters. |
| ODEFINIERAD | Odefinierat värde. |
| IS_ANY_VALUE | 'Is any value'-villkor. Tillämpligt på grafiska indikatorer. |
