## SummaryRowsCalculationType enumeration

Anger typen av beräkning av det anpassade attributets värde för sammanfattningsrader.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Betyder att det anpassade attributets värde för sammanfattningsrader inte beräknas. |
| ROLLUP | Betyder att det anpassade attributets värde för sammanfattningsrader beräknas med rollup-funktionen som definieras i [rollup_type](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
| USE_FORMULA | Betyder att det anpassade attributets värde för sammanfattningsrader beräknas med formeln som definieras i [formula](/tasks/python-net/aspose.tasks/extendedattributedefinition/). |
