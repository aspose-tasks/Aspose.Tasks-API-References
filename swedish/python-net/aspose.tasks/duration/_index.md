| :- | :- |
| Duration() | Initierar en ny instans av klassen Duration |

| Namn | Beskrivning |
| :- | :- |
| time_span | Hämtar [time_span](/tasks/python-net/aspose.tasks/duration/) instans av detta Duration‑objekt. |
