## TaskLinkDrawingArgs class

Tillhandahåller argument för återanropet som anropas när uppgiftslänken renderas.

TaskLinkDrawingArgs-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| link | Hämtar den renderade uppgiftslänken. |
| color | Hämtar eller anger färg som används för att rendera uppgiftslänken. Kan användas för anpassning av färger för uppgiftslänkar. |
