## Table class

Representerar en tabell i Project

Typen Table exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Table() | Initierar en ny instans av klassen [Table](/tasks/python-net/aspose.tasks/table/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar eller anger namnet på ett Table-objekt. |
| show_in_menu | Hämtar eller anger ett värde som indikerar om projektet visar tabellnamnet i rullgardinslistan Tables på fliken Visa i Ribbon. |
| table_fields | Hämtar en TableFields-samling som representerar fälten i tabellen. |
| table_type | Hämtar eller anger tabelltypen för den angivna tabellen. |
| uid | Hämtar den unika identifieraren för en tabell. |
| row_height | Hämtar eller anger radhöjden i en tabell, där radhöjden är antalet textrader. |
| date_format | Hämtar eller anger datumformatet för tabellen. |
| adjust_header_row_height | Hämtar eller anger ett värde som indikerar om rubrikradens höjd i tabellen kan justeras. |
| show_add_new_column | Hämtar eller anger ett värde som indikerar om gränssnittet 'Add New Column' ska visas. |
| lock_first_column | Hämtar eller anger ett värde som indikerar om den första kolumnen i en tabell är låst eller redigerbar. |
