## PrimaveraCalendarProperties class

Representerar Primavera-specifika egenskaper för en kalender läst från Primavera-filer (XER eller P6XML).<br/>            Kan användas för att utföra kalender-specifik konvertering av tidsenheter.

Typen PrimaveraCalendarProperties exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| hours_per_day | Hämtar antalet timmar per dag från inställningarna 'Time Periods' i kalendern. |
| hours_per_week | Hämtar antalet timmar per vecka från inställningarna 'Time Periods' i kalendern. |
| hours_per_month | Hämtar antalet timmar per månad från inställningarna 'Time Periods' i kalendern. |
| hours_per_year | Hämtar antalet timmar per månad från inställningarna 'Time Periods' i kalendern. |
