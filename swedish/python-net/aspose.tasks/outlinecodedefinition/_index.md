## OutlineCodeDefinition class

Representerar en definition av en konturkod.

Typen OutlineCodeDefinition exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| OutlineCodeDefinition() | Initierar en ny instans av klassen [OutlineCodeDefinition](/tasks/python-net/aspose.tasks/outlinecodedefinition/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| guid | Hämtar eller anger Guid för en outline-kod. |
| field_id | Hämtar eller anger fältnumret för en outline-kod. |
| field_name | Hämtar eller anger namnet på en anpassad outline-kod. |
| alias | Hämtar eller anger aliaset för en anpassad outline-kod. |
| phonetic_alias | Hämtar eller anger den fonetiska uttalningen av aliaset för den anpassade outline-koden. |
| values | Hämtar OutlineValueCollection-objektet.<br/>            Värdena i tabellen som är associerad med denna outline-kod. |
| enterprise | Hämtar eller anger ett värde som indikerar om en anpassad outline-kod är en enterprise-anpassad outline-kod. |
| enterprise_outline_code_alias | Hämtar eller anger en referens till ett annat anpassat fält som denna outline-koddefinition är ett alias för. |
| resource_substitution_enabled | Hämtar eller anger ett värde som indikerar om den anpassade outline-koden kan användas<br/>            av Resource Substitution Wizard i Microsoft Project. |
| leaf_only | Hämtar eller anger ett värde som indikerar om de värden som anges i detta konturkodfält måste vara lövvärden. |
| all_levels_required | Hämtar eller anger ett värde som indikerar om de nya koderna måste ha alla nivåer.<br/>            Inte tillgängligt för Enterprise‑koder. |
| only_table_values_allowed | Hämtar eller anger ett värde som indikerar om de specificerade värdena måste komma från värdetabellen. |
| masks | Hämtar OutlineMaskCollection‑objektet.<br/>            Tabellen med poster som definierar konturkodmasken.<br/>            Skrivrättighetsfri [OutlineMaskCollection](/tasks/python-net/aspose.tasks/outlinemaskcollection/)‑instans. |
| show_indent | Hämtar eller anger ett värde som indikerar om indragen för denna konturkod ska visas. |
