## LoadOptions class

Tillåter att ange ytterligare inläsningsparametrar när ett projekt laddas från fil eller ström.

LoadOptions-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LoadOptions() | Initierar en ny instans av klassen [LoadOptions](/tasks/python-net/aspose.tasks/loadoptions/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| password | Hämtar eller anger ett skyddslösenord. |
| primavera_read_options | Hämtar eller anger en specificerad instans av klassen [PrimaveraReadOptions](/tasks/python-net/aspose.tasks/primaverareadoptions/) som kan användas för att anpassa beteendet vid inläsning av Primavera-format (Primavera P6 XER eller Primavera P6 Xml). |
| encoding | Hämtar eller anger kodning som används för att läsa ett projekt från HTML-, MPX-, XER- och Primavera XML-format.<br/>            Standardkodningen är UTF8. |
