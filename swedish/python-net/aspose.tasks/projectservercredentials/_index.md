## ProjectServerCredentials class

Referenser som används för att ansluta till Project Online eller en lokal instans av Project Server.

Typen ProjectServerCredentials visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ProjectServerCredentials(site_url, auth_token) | Initierar en ny instans av klassen [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) med URL till SharePoint‑platsen och en giltig SPOIDCRL‑auktoriseringstoken för SharePoints PWA (Project Web Access)-plats. |
| ProjectServerCredentials(site_url, user_name, password) | Initierar en ny instans av klassen [ProjectServerCredentials](/tasks/python-net/aspose.tasks/projectservercredentials/) med URL till SharePoint‑platsen och en giltig SPOIDCRL‑auktoriseringstoken för SharePoints PWA (Project Web Access)-plats. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| site_url | Hämtar URL:en till PWA på SharePoint‑platsen eller URL:en till en lokal Project Server.<br/>            Till exempel, https://your_company_name.sharepoint.com/sites/pwa\"; |
| auth_token | Hämtar auktoriseringstoken för SharePoint‑instansen. |
| user_name | Hämtar användarnamnet för SharePoint‑webbplatsen. |
