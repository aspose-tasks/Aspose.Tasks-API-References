## Group class

Representerar en gruppdefinition.<br/>            Ett Group-objekt är en medlem av samlingen ResourceGroups eller samlingen TaskGroups.

Group‑typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Group() | Initierar en ny instans av klassen [Group](/tasks/python-net/aspose.tasks/group/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar eller anger ett namn på ett Group‑objekt. |
| uid | Hämtar en unik identifierare för en grupp. |
| show_summary | Hämtar eller anger ett värde som indikerar om sammanfattningsrader visas för gruppen. |
| maintain_hierarchy | Hämtar eller anger ett värde som indikerar om alla nivåer av sammanfattningsuppgifter för deluppgifter inom gruppen ska visas. |
| show_in_menu | Hämtar eller anger ett värde som indikerar om Project visar gruppnamnet i Group‑rullgardinsmenyn i Ribbon. |
| group_assignments | Hämtar eller anger ett värde som indikerar om tilldelningar ska grupperas istället för uppgifter. |
| group_criteria | Hämtar eller anger en GroupCriteria‑samling som representerar fälten i en gruppdefinition. |
