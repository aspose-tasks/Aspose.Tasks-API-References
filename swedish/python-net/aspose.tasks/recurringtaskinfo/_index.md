## RecurringTaskInfo class

Representerar detaljerna för en återkommande uppgift i ett projekt.

Typen RecurringTaskInfo exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| recurrence_pattern | Hämtar eller anger ett återkommande mönster för den återkommande uppgiften. |
| start_date | Hämtar eller anger datumet då förekomsterna ska börja. |
| end_date | Hämtar eller anger datumet för när förekomsterna ska avslutas. |
| duration | Hämtar eller anger varaktigheten för en förekomst av den återkommande uppgiften. |
| förekomster | Hämtar eller anger antalet förekomster av den återkommande uppgiften. |
| use_end_date | Hämtar eller anger ett värde som indikerar om slutdatum eller ett antal förekomster ska användas för den återkommande uppgiften. |
| daily_repetitions | Hämtar eller anger antalet upprepningar för det dagliga återkommande mönstret. |
| daily_use_workdays | Hämtar eller anger ett värde som indikerar om arbetsdagar ska användas för det dagliga återkommande mönstret. |
| weekly_repetitions | Hämtar eller anger antalet upprepningar för det veckovisa återkommande mönstret. |
| weekly_days | Hämtar eller anger en samling av dagar som används i det veckovisa återkommande mönstret. |
| monthly_use_ordinal_day | Hämtar eller anger ett värde som indikerar om ordinaldag ska användas för det månatliga återkommande mönstret. |
| monthly_ordinal_number | Hämtar eller anger ett ordinaltal för det månatliga återkommande mönstret. |
| monthly_ordinal_repetitions | Hämtar eller anger antalet upprepningar för det månatliga återkommande mönstret när ordinaldag används. |
| monthly_day | Hämtar eller anger antalet dagar i det månatliga återkommande mönstret. |
| monthly_repetitions | Hämtar eller anger antalet upprepningar för det månatliga återkommande mönstret. |
| yearly_use_ordinal_day | Hämtar eller anger ett värde som indikerar om ordinaldag ska användas för det årliga återkommande mönstret. |
| yearly_date | Hämtar eller anger ett datum för det årliga återkommande mönstret. |
| yearly_ordinal_number | Hämtar eller anger ett ordinaltal för det årliga återkommande mönstret. |
| yearly_ordinal_month | Hämtar eller anger en månad för det årliga återkommande mönstret när ordinaldag används. |
| task | Hämtar föräldrauppgiften för den här instansen av klassen [RecurringTaskInfo](/tasks/python-net/aspose.tasks/recurringtaskinfo/). |
