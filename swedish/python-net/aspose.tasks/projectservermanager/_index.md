## ProjectServerManager class

Klassen som tillhandahåller metoderna för att läsa och utföra operationer på projekt i det angivna Project Online‑kontot eller<br/>            i den angivna lokala Project Server‑instansen (versionerna 2016 och 2019 av Project Server stöds).

ProjectServerManager-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ProjectServerManager(credentials) | Initierar en ny instans av klassen [ProjectServerManager](/tasks/python-net/aspose.tasks/projectservermanager/). |
## Methods
| Namn | Beskrivning |
| :- | :- |
| update_project(project) | Uppdaterar befintligt projekt i Project Server\\Project Online-instans med standardalternativ för sparande. Det befintliga projektet kommer att skrivas över. |
| update_project(project, save_options) | Uppdaterar befintligt projekt i Project Server\\Project Online-instans med de angivna sparalternativen. Det befintliga projektet kommer att skrivas över. |
| create_new_project(project) | Skapar nytt projekt i Project Server\\Project Online-instans med standardalternativ för sparande. |
| create_new_project(project, save_options) | Skapar ett nytt projekt i Project Server\\Project Online-instans med de angivna sparalternativen. |
| get_project(project_guid) | Hämtar projektet med den angivna guid från Project Online‑kontot \\ Project Server‑instans. |
| get_project_raw_data(project_guid) | Hämtar projektets binära data för felsökning. |
| get_project_list() | Hämtar listan över projekt från 'Working'-lagret i det aktuella Project Online‑kontot \\ Project Server‑instans. |
