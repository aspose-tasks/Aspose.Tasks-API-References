## RecurringTaskParameters class

Representerar den uppsättning parametrar som används för att skapa en återkommande uppgift i ett projekt.

Typen RecurringTaskParameters exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| RecurringTaskParameters() | Initierar en ny instans av klassen [RecurringTaskParameters](/tasks/python-net/aspose.tasks/recurringtaskparameters/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| duration | Hämtar eller anger varaktigheten för en förekomst av den återkommande uppgiften. |
| ignore_resource_calendar | Hämtar eller anger ett värde som anger om återkommande uppgift ska schemaläggas även om den inte kan utföras när några resurser är tillgängliga för att arbeta med den. |
| recurrence_pattern | Hämtar eller anger återkomstmönstret för den återkommande uppgiften. |
| task_name | Hämtar eller anger namnet på den återkommande uppgiften. |
## Methods
| Namn | Beskrivning |
| :- | :- |
| set_calendar(project, calendar_name) | Ange en kalender för återkommande uppgift. Kalendern väljs från projektets kalendersamling. |
