## TaskStatus enumeration

Anger statusen för en uppgift.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| ODEFINIERAD | Odefinierad uppgiftsstatus. |
| COMPLETE | Uppgiften är 100 procent klar. |
| ON_SCHEDULE | Uppgiften är i tid om timephased cumulative percent complete är spridd till minst dagen före statusdatumet. |
| LATE | Uppgiften är försenad om timephased cumulative percent complete inte når midnatt dagen före statusdatumet. |
| FUTURE | 'Future' uppgiftsstatus sätts när uppgiftens startdatum är senare än statusdatumet. |
