## TaskLink class

Representerar en föregångarlänk.

Typen TaskLink exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_cross_project | Hämtar eller anger ett värde som indikerar om en föregångare är en del av ett annat projekt. |
| cross_project_name | Hämtar eller anger det externa föregångarprojektet. |
| link_lag | Hämtar eller anger fördröjningen i tiondelar av en minut eller i procent. |
| link_lag_time_span | Hämtar eller anger fördröjningsvaraktigheten, beroende på LagFormat. |
| lag_format | Hämtar eller anger formatet för att uttrycka fördröjningsformatet. |
| pred_task | Hämtar eller anger föregående uppgift. |
| succ_task | Hämtar eller anger efterföljande uppgift. |
| link_type | Hämtar eller anger typen av en länk. |
## Methods

| :- | :- |
| equals(other) | Returnerar ett värde som indikerar om denna instans är lika med ett specificerat objekt. |
