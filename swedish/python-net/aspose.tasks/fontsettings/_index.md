## FontSettings class

Specificerar teckensnittsinställningar som används vid rendering av projektets vy.

FontSettings-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| FontSettings() | Initierar en ny instans av FontSettings-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| default_font_name | Hämtar eller anger standard‑ (eller reserv‑) typsnitt för rendering. |
| use_project_default_font | Hämtar eller anger ett värde som indikerar om standardtypsnittet måste användas för rendering. |
## Methods

| :- | :- |
