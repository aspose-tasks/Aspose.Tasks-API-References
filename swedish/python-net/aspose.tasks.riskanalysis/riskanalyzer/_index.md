## RiskAnalyzer class

Utför en Monte Carlo-simulering baserad på de angivna riskanalysinställningarna.

Typen RiskAnalyzer visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| RiskAnalyzer(settings) | Initierar en ny instans av klassen [RiskAnalyzer](/tasks/python-net/aspose.tasks.riskanalysis/riskanalyzer/). |

| Namn | Beskrivning |
| :- | :- |
| settings | Hämtar eller anger instansen av klassen [RiskAnalysisSettings](/tasks/python-net/aspose.tasks.riskanalysis/riskanalysissettings/) som definierar nödvändiga inställningar för riskanalys. |
