## RiskItemStatistics class

Representerar ett objekt som lagrar statistiska data för uppgiften i det analyserade projektet.

Typen RiskItemStatistics visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| item_type | Hämtar en instans av [RiskItemType](/tasks/python-net/aspose.tasks.riskanalysis/riskitemtype/) enumerationen. |
| minimum | Hämtar det minsta värdet som genererades under Monte Carlo-simulering. |
| maximum | Hämtar det största värdet som genererades under Monte Carlo-simulering. |
| expected_value | Hämtar det förväntade värdet för riskobjektet. |
| standard_deviation | Hämtar standardavvikelsen för riskobjektet. |
## Methods
| Namn | Beskrivning |
| :- | :- |
| get_percentile(percent) | Hämtar ett värde som en angiven procentandel av de genererade proverna ligger under. |
