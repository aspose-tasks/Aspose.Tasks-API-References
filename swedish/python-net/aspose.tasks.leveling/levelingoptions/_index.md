## LevelingOptions class

Tillåter att specificera parametrar för resursutjämning.

Typen LevelingOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LevelingOptions() | Initierar en ny instans av klassen [LevelingOptions](/tasks/python-net/aspose.tasks.leveling/levelingoptions/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| start_date | Hämtar eller anger startdatum för nivåinställningsperioden. Standardvärdet är projektets startdatum. |
| finish_date | Hämtar eller anger slutdatum för nivåinställningsperioden. Standardvärdet är projektets slutdatum. |
| resources | Hämtar eller anger listan över resurser som ska nivåinställas. Om null anges, kommer alla projektresurser att nivåinställas. |
| leveling_order | Hämtar ordningen i vilken nivåinställningsalgoritmen fördröjer uppgifter som har överallokeringar.<br/>            Efter att ha identifierat uppgifter som orsakar överallokeringen och vilka uppgifter som kan fördröjas, används den angivna ordningen för att bestämma vilken uppgift som ska fördröjas först. |
| message_level | Hämtar eller anger nivån på loggmeddelanden som genereras av Aspose.Tasks under resursnivåinställning. |
| message_handler | Hämtar eller anger återuppringning för meddelandehanterare som kan användas för att avlyssna loggmeddelanden som produceras av Aspose.Tasks under resursnivåinställning. |
