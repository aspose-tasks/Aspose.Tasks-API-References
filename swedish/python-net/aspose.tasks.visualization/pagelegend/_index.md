## PageLegend class

Representerar en sidlegend som används för projektutskrift.

PageLegend-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PageLegend() | Initierar en ny instans av klassen PageLegend |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| left_text | Hämtar eller anger den vänsterjusterade texten som ska visas i det överordnade elementet. |
| centered_text | Hämtar eller anger den centrerade texten som ska visas i det överordnade elementet. |
| right_text | Hämtar eller anger den högerjusterade texten som ska visas i det överordnade elementet. |
| left_image | Hämtar eller anger den vänsterjusterade bilden som ska visas i det överordnade elementet. |
| centered_image | Hämtar eller anger den centrerade bilden som ska visas i det överordnade elementet. |
| right_image | Hämtar eller anger den högerjusterade bilden som ska visas i det överordnade elementet. |
| left_image_size | Hämtar eller anger den visade storleken på den vänstra bilden. |
| centered_image_size | Hämtar eller anger den visade storleken på den centrerade bilden. |
| right_image_size | Hämtar eller anger den visade storleken på den högra bilden. |
| legend_on | Hämtar eller anger de sidor där legenden visas. Kan vara ett av värdena i uppräkningen [Legend](/tasks/python-net/aspose.tasks.visualization/legend/). |
| width | Hämtar eller anger bredden på den vänstra delen (innehåller projektets namn och datum som standard) av legenden i centimeter. |
