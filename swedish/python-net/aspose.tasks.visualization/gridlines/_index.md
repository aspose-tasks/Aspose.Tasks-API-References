## Gridlines class

Representerar rutnätlinjer som visas i en GanttChart‑vy.

Typen Gridlines exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Gridlines() | Initierar en ny instans av klassen Gridlines |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| intervall | Hämtar eller anger talet från 0 till 99 som specificerar intervallet mellan rutnätlinjer. |
| interval_color | Hämtar eller anger färgen på sekundära rutnätlinjer. |
| interval_pattern | Hämtar eller anger linjemönstret för sekundära rutnätlinjer. |
| normal_color | Hämtar eller anger färgen på normala rutnätlinjer. |
| normal_pattern | Hämtar eller anger linjemönstret för normala rutnätlinjer. |
| type | Hämtar eller anger rutnätlinjetypen. |
