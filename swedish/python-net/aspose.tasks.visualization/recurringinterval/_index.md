## RecurringInterval class

Representerar återkommande intervall som används i förloppslinjer i en Gantt-diagramvy.

Typen RecurringInterval visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| RecurringInterval() | Initierar en ny instans av klassen RecurringInterval |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| interval | Hämtar eller anger det återkommande intervallet.<br/>            Kan vara vilket värde som helst av typen [interval](/tasks/python-net/aspose.tasks.visualization/recurringinterval/). |
| daily_day_number | Hämtar eller anger det dagliga dagnumret. |
| daily_workday | Hämtar eller anger ett värde som indikerar om en dag är arbetsdag för dagliga förloppslinjer. |
| weekly_week_number | Hämtar eller anger veckonumret för veckovisa förloppslinjer. |
| monthly_day | Hämtar eller anger ett värde som indikerar om månatliga förloppslinjer ska visas per dag. |
| monthly_day_day_number | Hämtar eller anger dagnumret för månatliga förloppslinjer. |
| monthly_day_month_number | Hämtar eller anger månadsnumret för månatliga förloppslinjer. |
| monthly_first_last | Hämtar eller anger ett värde som indikerar om förloppslinjer ska visas efter den första eller sista fördefinierade dagen. |
| monthly_first_last_month_number | Hämtar eller anger månadsnumret för förloppslinjer som visas efter den första eller sista fördefinierade dagen. |
| monthly_first_last_day | Hämtar eller anger typen av den första eller sista dagen för månatliga förloppslinjer. |
| weekly_days | Hämtar en lista med dagar för veckovisa förloppslinjer. |
