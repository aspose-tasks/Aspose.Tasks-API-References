## PageViewSettings class

Representerar utskriftsinställningar för en projektvy.

PageViewSettings-typen visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PageViewSettings() | Initierar en ny instans av PageViewSettings-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| first_columns_count | Hämtar eller anger antalet första kolumner som ska skrivas ut på alla sidor. |
| fit_timescale_to_end_of_page | Hämtar eller anger ett värde som indikerar om tidslinjen ska anpassas till slutet av en sida vid utskrift. |
| print_all_sheet_columns | Hämtar eller anger ett värde som indikerar om alla bladkolumner i en vy ska skrivas ut. |
| print_blank_pages | Hämtar eller anger ett värde som indikerar om tomma sidor i en vy ska skrivas ut. |
| print_first_columns_count_on_all_pages | Hämtar eller anger ett värde som indikerar om ett specificerat antal första kolumner ska skrivas ut på alla sidor. |
| print_notes | Hämtar eller anger ett värde som indikerar om anteckningar ska skrivas ut. |
