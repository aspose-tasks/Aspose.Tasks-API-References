## TaskTextStyleEventArgs class

Denna klass representerar en uppsättning data som är relaterade till rendering av en tabellcells innehåll.

Typen TaskTextStyleEventArgs exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| cell_text_style | Hämtar eller anger TextStyle som kommer att användas för att rita cellens innehåll. Detta objekt kan användas för att anpassa utseendet på en tabellcell. |
| task | Hämtar [task](/tasks/python-net/aspose.tasks.visualization/tasktextstyleeventargs/) som motsvarar den för närvarande renderade raden. |
| column | Hämtar [ViewColumn](/tasks/python-net/aspose.tasks.visualization/viewcolumn/) som den för närvarande renderade cellen tillhör. |
