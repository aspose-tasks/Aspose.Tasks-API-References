## BarStyle class

Ändra den visuella stilen för stapeln för objektet i projektvyn.

BarStyle-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| BarStyle() | Initierar en ny instans av klassen [BarStyle](/tasks/python-net/aspose.tasks.visualization/barstyle/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| bar_color | Hämtar eller anger aspose.pydrawing.Color för stapelstilen. |
| start_shape_color | Hämtar eller anger aspose.pydrawing.Color för formen i början av stapeln. |
| start_shape_type | Hämtar eller anger en typ av startformen. |
| end_shape_color | Hämtar eller anger aspose.pydrawing.Color för formen i slutet av stapeln. |
| end_shape_type | Hämtar eller anger en typ av slutformen.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| item_type | Hämtar eller anger [BarItemType](/tasks/python-net/aspose.tasks.visualization/baritemtype/) för stapelstilen. |
| bar_shape | Hämtar eller anger [bar_shape](/tasks/python-net/aspose.tasks.visualization/barstyle/) för stapelstilen. |
| start_shape | Hämtar eller anger [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) i början av stapeln. |
| end_shape | Hämtar eller anger [Shape](/tasks/python-net/aspose.tasks.visualization/shape/) i slutet av stapeln. |
| text_style | Hämtar eller anger stil för stapelns text. |
| left_field | Hämtar eller anger ett fält som ska visas till vänster om stapeln. |
| top_field | Hämtar eller anger ett fält som ska visas ovanför stapeln. |
| right_field | Hämtar eller anger ett fält som ska visas till höger om stapeln. |
| bottom_field | Hämtar eller anger ett fält som ska visas under stapeln. |
| inside_field | Hämtar eller anger ett fält som ska visas inuti stapeln. |
| from_address | Hämtar eller anger en startpunktposition för Gantt-stapeln.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| to | Hämtar eller anger en slutpunktsposition för gantt-fältet. |
