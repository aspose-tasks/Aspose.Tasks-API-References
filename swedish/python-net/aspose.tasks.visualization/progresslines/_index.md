## ProgressLines class

Representerar förloppslinjer i en Gantt-diagramvy.

Typen ProgressLines exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ProgressLines() | Initierar en ny instans av klassen ProgressLines |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| display_at_current_date | Hämtar eller anger ett värde som indikerar om framstegslinjen ska visas på aktuellt datum. |
| display_at_recurring_intervals | Hämtar eller anger ett värde som indikerar om framstegslinjen ska visas vid återkommande intervall. |
| recurring_interval | Hämtar eller anger det återkommande intervallet.<br/>            [recurring_interval](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| begin_at_project_start | Hämtar eller anger ett värde som indikerar om framstegslinjer ska visas från början av projektets startdatum. |
| begin_at_date | Hämtar eller anger datumet som framstegslinjer ska visas från. |
| display_selected | Hämtar eller anger ett värde som indikerar om framstegslinjer ska visas på de valda datumen. |
| is_baseline_plan | Hämtar eller anger ett värde som indikerar om framstegslinjer ska visas för baslinjeplan eller faktiskt. |
| show_date | Hämtar eller anger ett värde som indikerar om datum ska visas för varje framstegslinje. |
| date_format | Hämtar eller anger datumformatet ([DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/)). |
| font | Hämtar eller anger teckensnittet som används för etiketten på framstegslinjen. |
| line_pattern | Hämtar eller anger linjemönstret för den aktuella framstegslinjen.<br/>            [line_pattern](/tasks/python-net/aspose.tasks.visualization/progresslines/). |
| line_color | Hämtar eller anger linjefärgen för den aktuella framstegslinjen. |
| progress_point_shape | Hämtar eller anger formen på framstegspunkten.<br/>            [GanttBarEndShape](/tasks/python-net/aspose.tasks.visualization/ganttbarendshape/). |
| progress_point_color | Hämtar eller anger färgen på framstegspunkten. |
| other_line_pattern | Hämtar eller anger linjemönstret för annan framstegslinje. |
| other_line_color | Hämtar eller anger färgen på annan framstegslinje. |
| other_progress_point_shape | Hämtar eller anger formen på framstegspunkten för annan framstegslinje. |
| other_progress_point_color | Hämtar eller anger färgen på en annan framstegspunkt. |
| selected_dates | Hämtar listan med valda datum för att visa framstegslinjer. |
