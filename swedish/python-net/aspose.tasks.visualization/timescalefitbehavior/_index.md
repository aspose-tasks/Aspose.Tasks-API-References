## TimescaleFitBehavior enumeration

Representerar ett beteende som används för att justera tidslinjeområdet med sidbredden.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| DEFINED_IN_VIEW | Kalendersektionen renderas enligt egenskapen View.PageInfo.PageViewSettings.FitTimescaleToEndOfPage för den renderade vyn. |
| NO_SCALE_TO_END_DATE | Kalendersektionen renderas exakt till EndDate, även om det finns ett tomt utrymme på en sida. |
| NO_SCALE_TO_END_OF_PAGE | Kalendersektionen renderas till slutet (höger sida) av den sista sidan.<br/>            Så kan det sista renderade datumet överskrida EndDate. |
| SCALE_TO_END_OF_PAGE | Renderingsmotorn kommer att försöka justera datum så att EndDate är justerat med slutet (höger sida) på den sista sidan.<br/>            Motsvarar MS Projects "Page Setup \ View \ Fit timescale to end of page" alternativ aktiverat. |
