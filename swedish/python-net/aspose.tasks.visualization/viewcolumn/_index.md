## ViewColumn class

Representerar en kolumn i en projektvy.

Typen ViewColumn exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| field | Hämtar eller anger kolumnfält.<br/>            [field](/tasks/python-net/aspose.tasks.visualization/viewcolumn/). |
| name | Hämtar kolumnnamnet. |
| string_alignment | Hämtar eller anger justering av texten (kan vara ett av värdena i [HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)‑enumerationen). |
| width | Hämtar kolumnens bredd. |
| text_style_modification_callback | Hämtar eller anger återanropet som kan användas för att anpassa utseendet på kolumnens celler. |
