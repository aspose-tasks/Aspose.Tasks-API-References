## PageInfo class

Representerar sidinställningsdata som finns i MPP‑filformatet och används för utskrift.

PageInfo-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PageInfo() | Initierar en ny instans av klassen [PageInfo](/tasks/python-net/aspose.tasks.visualization/pageinfo/). <br/>            Representerar sidinställningsdata som finns i MPP-filformatet och används för utskrift. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| header | Hämtar eller anger instansen av klassen [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) som representerar rubrikdata. |
| footer | Hämtar eller anger en instans av klassen [HeaderFooterInfo](/tasks/python-net/aspose.tasks.visualization/headerfooterinfo/) som representerar sidfotdata. |
| name | Hämtar namnet på vyn för vilken inställningsdata används. |
| page_settings | Hämtar en instans av klassen [page_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) som specificerar sidutskriftsinställningar. |
| page_view_settings | Hämtar en instans av klassen [page_view_settings](/tasks/python-net/aspose.tasks.visualization/pageinfo/) som specificerar utskriftsinställningar för sidvyn. |
| margins | Hämtar en instans av klassen [PageMargins](/tasks/python-net/aspose.tasks.visualization/pagemargins/) som specificerar sidmarginaler. |
| legend | Hämtar eller anger en instans av klassen [PageLegend](/tasks/python-net/aspose.tasks.visualization/pagelegend/) som specificerar renderingsalternativ för sidlegenden. |
