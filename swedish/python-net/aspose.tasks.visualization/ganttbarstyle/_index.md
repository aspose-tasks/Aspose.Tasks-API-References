## GanttBarStyle class

Representerar en stapelstil som används av MSP i Gantt‑diagramvyn.

GanttBarStyle-typen visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| GanttBarStyle() | Initierar en ny instans av [GanttBarStyle](/tasks/python-net/aspose.tasks.visualization/ganttbarstyle/) klassen. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| bottom_field | Hämtar eller anger data som ska visas längst ner på stapeln.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| end_shape | Hämtar eller anger en slutform för stapeln. |
| end_shape_color | Hämtar eller anger en färg för slutformen. |
| end_shape_type | Hämtar eller anger en typ av slutformen.<br/>            [GanttBarType](/tasks/python-net/aspose.tasks.visualization/ganttbartype/). |
| from_address | Hämtar eller anger en startpunktposition för Gantt-stapeln.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| inside_field | Hämtar eller anger data som ska visas inuti stapeln.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| left_field | Hämtar eller anger data som ska visas till vänster om stapeln.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |
| middle_fill_pattern | Hämtar eller anger ett fyllningsmönster för Gantt-stapeln. |
| middle_shape | Hämtar eller anger en mittform för stapeln. |
| middle_shape_color | Hämtar eller anger en färg för mittformen. |
| name | Hämtar eller anger ett namn på stilen. |
| right_field | Hämtar eller anger data som ska visas till höger om stapeln.<br/>            [Field](/tasks/python-net/aspose.tasks/field/). |

| show_for_task_uid | Hämtar eller anger unikt ID för en uppgift som stilen tillämpas på. Gäller för uppgiftsspecifika stapelstilar i Gantt-diagrammet (se [custom_bar_styles](/tasks/python-net/aspose.tasks/ganttchartview/)). |
| start_shape | Hämtar eller anger en startform för stapeln. |

| to | Hämtar eller anger en slutpunktsposition för gantt-fältet. |
| top_field | Hämtar eller anger data som ska visas högst upp på fältet. |
| parent_style | Hämtar eller anger föräldra‑ (eller gemensam) stil för anpassad uppgiftsspecifik stil. |
