## TimescaleTier class

Representerar ett enskilt lager av tidslinjen i ett Gantt-diagram.

Typen TimescaleTier exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TimescaleTier() | Initierar en ny instans av klassen [TimescaleTier](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
| TimescaleTier(unit, count) | Initierar en ny instans av TimescaleTier-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| count | Hämtar eller anger tidsenhetsintervallet som etiketter för nivån ska visas i.<br/>            Standardvärdet är 1. |
| label | Hämtar eller anger datumetikett [DateLabel](/tasks/python-net/aspose.tasks.visualization/datelabel/) för tidslinjenivån. |
| alignment | Hämtar eller anger hur etiketter ska justeras inom varje tidsperiod i nivån ([HorizontalStringAlignment](/tasks/python-net/aspose.tasks.visualization/horizontalstringalignment/)). |
| uses_fiscal_year | Hämtar eller anger ett värde som indikerar om nivåetiketterna ska baseras på räkenskapsåret. |
| show_ticks | Hämtar eller anger ett värde som indikerar om markeringar som separerar tidsperioder i nivån ska visas. |
| unit | Hämtar eller anger tidslinjeenhet [TimescaleUnit](/tasks/python-net/aspose.tasks.visualization/timescaleunit/) för tidslinjenivån.<br/>            Standardvärdet är |
| render_label_on_each_page | Hämtar eller anger en flagga som definierar om datumetiketter ska renderas på varje sida när en tidsperiod sträcker sig över flera sidor.<br/>            Om värdet är 'true' renderas datumetiketter för perioden på varje sida när tidsperioden sträcker sig över flera sidor.<br/>            Om värdet är 'false' renderas datumetiketten endast en gång enligt ett värde av egenskapen [alignment](/tasks/python-net/aspose.tasks.visualization/timescaletier/). |
