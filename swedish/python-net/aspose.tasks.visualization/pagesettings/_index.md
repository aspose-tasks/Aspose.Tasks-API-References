## PageSettings class

Representerar utskriftsinställningar för en sida i projektvyn.

Typen PageSettings visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PageSettings() | Initierar en ny instans av klassen [PageSettings](/tasks/python-net/aspose.tasks.visualization/pagesettings/). <br/>            Representerar utskriftsinställningar för en sida i projektvyn. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_portrait | Hämtar eller anger ett värde som indikerar om sidorienteringen är stående; returnerar false om sidorienteringen är liggande. |
| adjust_to_percent_of_normal_size | Hämtar eller anger ett värde som indikerar om utskriften ska justeras till den angivna procenten ([percent_of_normal_size](/tasks/python-net/aspose.tasks.visualization/pagesettings/)) av normal storlek. |
| percent_of_normal_size | Hämtar eller anger en procentandel av normal storlek att justera utskriften till. |
| pages_in_width | Hämtar eller anger ett antal sidor i bredd som ska skrivas ut. |
| pages_in_height | Hämtar eller anger ett antal sidor i höjd som ska skrivas ut. |
| paper_size | Hämtar eller anger en pappersstorlek. Kan vara ett av värdena i uppräkningen [PrinterPaperSize](/tasks/python-net/aspose.tasks.visualization/printerpapersize/). |
| paper_size_id | Hämtar eller anger ett heltal som representerar ett av värdena i PrinterPaperSize eller ett anpassat sidstorleks‑id.<br/>            Detta värde kan användas för att hämta PaperSize från OS‑inställningarna. |
| first_page_number | Hämtar eller anger ett första sidnummer för utskrift. |
