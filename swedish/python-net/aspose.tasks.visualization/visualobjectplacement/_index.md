## VisualObjectPlacement class

Representerar placering och utseende av [OleObject](/tasks/python-net/aspose.tasks/oleobject/) i en vy.

Typen VisualObjectPlacement exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| VisualObjectPlacement() | Initierar en ny instans av klassen [VisualObjectPlacement](/tasks/python-net/aspose.tasks.visualization/visualobjectplacement/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| ole_object_id | Hämtar eller anger Id för [OleObject](/tasks/python-net/aspose.tasks/oleobject/) objektet. |
| task_id | Hämtar eller anger Id för uppgift om alternativet 'Attach to task' är valt, -1 annars. |
| width | Hämtar eller anger visad bredd för visuellt objekt. |
| höjd | Hämtar eller anger den visade höjden på det visuella objektet. |
| vertical_offset | Hämtar eller anger vertikal offset för det visuella objektet. |
| horizontal_offset | Hämtar eller anger horisontell offset för det visuella objektet. |
| timescale_date | Hämtar eller anger datumplacering för det visuella objektet när alternativet 'Attach to timescale' är valt. |
| attachment_point | Hämtar eller anger justering av det visuella objektet i förhållande till en uppgift när alternativet 'Attach to task' är valt. |
| border_line_color | Hämtar eller anger färg på kantlinjen. |
| border_line_thickness | Hämtar eller anger tjocklek på kantlinjen (tillåtna värden är 0 - 5). |
| fill_color | Hämtar eller anger fyllningsfärg. |
| fill_pattern | Hämtar eller anger fyllningsmönster. |
