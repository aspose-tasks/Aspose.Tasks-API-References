## ReportType enumeration

Typ av projektets grafiska rapport.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| PROJECT_OVERVIEW | Visar projektets start- och slutdatum, <br/>            procentandel av varaktigheten som är slutförd, procentuell färdigställning för uppgifter på högsta nivå och kommande milstolpar. |
| COST_OVERVIEW | Visar projektets start- och slutdatum, den aktuella<br/>            planerade och återstående kostnaden, % färdig och kostnadsvärden för uppgifter på högsta nivå. |
| WORK_OVERVIEW | Visar baslinje, faktiskt och återstående arbete för varje uppgift på högsta nivå samt arbete för resurser. |
| RESOURCE_OVERVIEW | Visar baslinje, faktiskt och återstående arbete per resurs. |
| RESOURCE_COST_OVERVIEW | Visar baslinje, faktiskt och återstående kostnad per resurs. |
| CRITICAL_TASKS | Visar projektuppgifter som är kritiska. |
| LATE_TASKS | Visar projektuppgifter som är försenade. |
| MILESTONES | Visar milstolpar som är försenade, kommande och slutförda. |
| UPCOMING_TASK | Visar uppgifter som förfaller under den aktuella veckan och uppgifter som startar under den aktuella veckan. |
| COST_OVERRUNS | Visar kostnadsavvikelse per uppgift och resurs. |
| TASK_COST_OVERVIEW | Visar baslinje, faktiskt och återstående kostnad för alla överordnade uppgifter. |
| OVERALLOCATED_RESOURCES | Visar antalet återstående arbetstimmar för överallokerade resurser. |
| SLIPPING_TASKS | Visar uppgifter som förväntas slutföras efter deras baslinjedatum (baslinje måste vara inställd). |
| BEST_PRACTICE_ANALYZER | Visar uppgifter utan faktiskt arbete, oassignerade uppgifter, <br/>            uppgifter med varaktighet mindre än 8 timmar och sammanfattningar tilldelade med resurserna. |
| BURNDOWN | Inkluderar arbetsburndown- och uppgiftsburndown-diagram.<br/>            Arbetsburndown-diagrammet visar hur mycket arbete folk har slutfört, hur mycket som är planerat att slutföras före projektets slutdatum, <br/>            och baslinjeestimatet för hur mycket arbete som skulle vara färdigt vid denna tidpunkt i projektet.<br/>            Uppgiftsburndown-diagrammet visar antalet slutförda uppgifter, antalet återstående, <br/>            och baslinjeestimatet för hur många som skulle vara färdiga vid denna tidpunkt i projektet. |
| CASH_FLOW | Visar kostnaderna och kumulativa kostnader per kvartal för alla överordnade uppgifter. |
