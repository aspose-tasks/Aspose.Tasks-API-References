## TextStyle class

Ändra den visuella stilen för texten för ett objekt i projektvyn.

Typen TextStyle exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TextStyle() | Initierar en ny instans av klassen [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) med standardinställningar. |
| TextStyle(font_size, font_style) | Initierar en ny instans av TextStyle-klassen |
| TextStyle(font_style) | Initierar en ny instans av klassen [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) med standardtypsnittet och angiven teckenstorlek och stil. |
| TextStyle(font) | Initierar en ny instans av klassen [TextStyle](/tasks/python-net/aspose.tasks.visualization/textstyle/) med de angivna typsnittsinställningarna. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| font | Hämtar eller anger teckensnitt för textstilen. |
| color | Hämtar eller anger färg för texten. |
| item_type | Hämtar eller anger [TextItemType](/tasks/python-net/aspose.tasks.visualization/textitemtype/) för textstilen. |
| background_pattern | Hämtar eller anger bakgrundsmönster för textstilen.<br/>            [background_pattern](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
| background_color | Hämtar eller anger bakgrundsfärg för textstilen.<br/>            [color](/tasks/python-net/aspose.tasks.visualization/textstyle/). |
