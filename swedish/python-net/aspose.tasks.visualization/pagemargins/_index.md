## PageMargins class

Representerar sidmarginaler för utskrift.

The PageMargins type exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PageMargins() | Initierar en ny instans av klassen PageMargins |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| top | Hämtar eller anger storleken på den övre marginalen i centimeter. |
| bottom | Hämtar eller anger storleken på den nedre marginalen i centimeter. |
| left | Hämtar eller anger storleken på den vänstra marginalen i centimeter. |
| right | Hämtar eller anger storleken på den högra marginalen i centimeter. |
| borders | Hämtar eller anger en position där kanter ska skrivas ut. Kan vara ett av värdena i enumet [Border](/tasks/python-net/aspose.tasks.visualization/border/). |
