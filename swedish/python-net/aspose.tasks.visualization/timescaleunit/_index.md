## TimescaleUnit enumeration

Anger tidsenheten för varje nivå av en tidslinje i ett Gantt-diagram eller annan tidsfasad vy.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Anger Ingen. Tidslinjenivån är dold. |
| MINUTES | Anger minuter som tidslinjeenhet. |
| HOURS | Anger timmar som tidslinjeenhet. |
| DAYS | Anger dagar som tidslinjeenhet. |
| WEEKS | Anger veckor som tidslinjeenhet. |
| THIRDS_OF_MONTHS | Anger tredjedelar av månader som tidslinjeenhet. |
| MONTHS | Anger månader som tidslinjeenhet. |
| QUARTERS | Anger kvartal av år som tidslinjeenhet. |
| HALF_YEARS | Anger halva år som tidslinjeenhet. |
| YEARS | Anger tidsenhet för år. |
