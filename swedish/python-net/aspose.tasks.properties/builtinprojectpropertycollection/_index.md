## BuiltInProjectPropertyCollection class

Representerar en samling av inbyggda projektegenskaper.

Typen BuiltInProjectPropertyCollection exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| title | Hämtar eller anger titeln på ett projekt. |
| subject | Hämtar eller anger ämnet för ett projekt. |
| author | Hämtar eller anger författaren till ett projekt. |
| chef | Hämtar eller anger projektledaren för ett projekt. |
| company | Hämtar eller anger företaget för ett projekt. |
| category | Hämtar eller anger kategorin för ett projekt. |
| nyckelord | Hämtar eller anger nyckelorden för ett projekt. |
| comments | Hämtar eller anger kommentarer för ett projekt. |
| hyperlink_base | Hämtar eller anger hyperlänksbasen för ett projekt. |
| namn |  |
