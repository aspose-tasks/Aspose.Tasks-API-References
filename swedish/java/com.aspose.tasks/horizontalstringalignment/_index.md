Anger justeringen av en textsträng i förhållande till dess layoutrektangel.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [Center](#Center) | Anger att texten är centrerad i layoutrektangeln. |

### Center {#Center}
```
public static final int Center
```


Anger att texten är centrerad i layoutrektangeln.

### Far {#Far}
```
public static final int Far
```


Anger att texten är placerad långt från ursprungspositionen i layoutrektangeln. I en layout från vänster till höger är den avlägsna positionen höger. I en layout från höger till vänster är den avlägsna positionen vänster.

### Near {#Near}
```
public static final int Near
```


Anger att texten är placerad nära layouten. I en layout från vänster till höger är den närmaste positionen vänster. I en layout från höger till vänster är den närmaste positionen höger.
