### Burndown {#Burndown}
```
public static final int Burndown
```


Inkluderar diagram för arbetsnedbrytning och uppgiftsnedbrytning. Arbetsnedbrytningsdiagrammet visar hur mycket arbete som har slutförts, hur mycket som är planerat att slutföras före projektets slutdatum, samt baslinjeestimatet för hur mycket arbete som skulle vara färdigt vid denna tidpunkt i projektet. Uppgiftsnedbrytningsdiagrammet visar antalet slutförda uppgifter, antalet återstående och baslinjeestimatet för hur många som skulle vara färdiga vid denna tidpunkt i projektet.
